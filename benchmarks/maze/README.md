# 滑移迷宫基准（v1，2026-11-03）

**性质：量具。** 给"策略 / 规划 / 搜索"这一类实验一个**难度可测**的任务，
以及一组**可复现的基线**。它出身于脉冲 SoS 那条线（[`research/sos/`](../../research/sos/DESIGN.md)），
但它本身与方法无关。

## 任务

- **DFS 迷宫**，边长 9 / 11 / 13 三档（走廊在奇数坐标，偶数坐标是墙，再打通 5% 的内墙）；
- 起点 `(1,1)`、终点 `(size-2, size-2)`；4 个动作，撞墙 = 原地；
- **滑移**：每个动作有 `p_slip = 0.10` 的概率滑到其余三个方向之一；
- **episode 上限 `T = 3L + 20`**（`L` = 该迷宫的最短路长度）。

为什么要滑移：确定性、全观测的迷宫能被世界模型零误差拟合，于是"预测误差"这类信号恒为 0，
P2 一类的设计就没有信息（见 [`research/sos/prereg-e0-e1.md`](../../research/sos/prereg-e0-e1.md)）。

## Fixture：不存数据，靠种子

迷宫完全由 `(seed, size)` 决定（`research/sos/grid.py::make_maze`），**仓库里不存迷宫文件**。
`research/sos/tests/test_grid.py` 把几个最短路长度钉死：

| size | seed 0 | seed 1 | seed 2 |
| :--- | ---: | ---: | ---: |
| 9 | 28 | 16 | 28 |
| 11 | 36 | 16 | 16 |
| 13 | 40 | 30 | 52 |

改生成算法必须同时改那张表，并说明为什么。

**难度分布**（每档 200 张）：三个尺寸合起来 **23 个不同的最短路长度，范围 [12, 62]**，
全部可解（迷宫由构造连通）。

## 基线

| 基线 | 成功率 | 说明 |
| :--- | ---: | :--- |
| 随机策略 | **0.006** | 4 个动作均匀 |
| 贪心朝终点（曼哈顿） | **0.250** | 只看距离，不看墙 |
| **沿最短路走** | **0.975** | 上界参考（有滑移，所以不是 1.0） |
| **GRU(128) 序列策略** | **训练池 0.930 / confirm 0.900** | 见 E7；输入 = 相对位移 + 四邻墙 + 朝向 + 上一步动作 |

前三条来自 [`sweep_results/sos_e0_e1_v2/README.md`](../../sweep_results/sos_e0_e1_v2/README.md)（E0），
最后一条来自 [`sweep_results/sos_e7/README.md`](../../sweep_results/sos_e7/README.md)（5 个种子、2000 张训练迷宫、200 张 confirm）。

## 状态阶梯：这个基准最有用的一条

同一个 GRU 之外，我们换过三次**状态表示**，训练池成功率是：

| 状态里有什么 | 训练池 |
| :--- | ---: |
| 只有相对位移 | **0.140** |
| + 四邻墙（4 bit） | **0.390** |
| + 朝向（2 bit 记忆） | **0.740** |
| + 序列模型的隐藏状态（GRU） | **0.930** |

**结论：在这类任务上，瓶颈几乎总是状态，不是学习规则。** 任何"策略学不会"的实验，
第一件该查的是状态是否 Markov。

## 怎么跑

```
python -m research.sos.run_e7 --out <仓外>     # GRU 基线
python -m research.sos.run_e0_e1_v2 --out <仓外>  # 环境与三个无学习基线
uv run pytest research/sos/tests -q            # fixture 守卫
```

## 边界

- 单机、5 个种子；GRU 那条是**基线**，不是"SOTA"；
- 滑移 0.10、上限 `3L+20` 都是设计选择，换掉要重测全部基线；
- 迷宫是单连通的——它测"在已知结构下找路"，不测"未知环境的探索"。
