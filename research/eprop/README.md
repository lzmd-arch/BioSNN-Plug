# W2：e-prop 认知层

**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

## 在验证什么命题

计划书 §3.1 的认知层学习规则：**e-prop（ALIF + 自适应阈值 + 资格痕迹）能否在顺序任务上
跑通，且活跃神经元比例 > 60%**——后者是 §七 第一阶段的硬指标，也是 §3.1「死亡神经元
防护」的触发线。

## 当前结论

**达到。测试准确率 77.48%（种子 0 的验收运行），活跃神经元比例 1.0000。**

计划书没给"可用"的数字，所以把它拆成两件可查的事，两件都过：

| 指标 | 实测 | 判据 |
| :--- | ---: | :--- |
| 测试准确率（sMNIST） | **0.7748** | 显著高于随机（10 类基线 0.10） |
| **活跃神经元比例** | **1.0000** | §七：「> 60%」 |
| 脉冲稀疏度 | 0.8527 | §九 第二阶段才设阈值（> 90%），本次不作判据 |

### 两个预算：30 epoch（验收）与 100 epoch（放开）

验收预算下，验证集准确率从第 1 个 epoch 的 0.4165 升到第 30 个 epoch 的 0.7695——**还在
上升**，所以 0.7748 不是收敛值，是**预算截断**的结果。把预算放开到 100 epoch（同一批种子
0–4、同一份代码，只改 epoch 数）之后：

| | 30 epoch（验收预算） | 100 epoch（放开预算） |
| :--- | ---: | ---: |
| 测试准确率，5 种子均值 | 0.7764 | **0.8519** |
| 测试准确率，种子 0（验收运行 / 同种子重跑） | 0.7748 | 0.8534 |
| 5 种子极差 | 1.79 个百分点 | **0.82 个百分点** |
| 验证准确率，5 种子均值（最后一个 epoch） | 0.7735 | 0.8491 |

**逐种子配对**（同一份代码、同一个种子，只换预算）的截断代价：均值 **+7.55 个百分点**
（最小 +6.05、最大 +8.66，5 对）。**前 30 轮与 30 epoch 批逐点相同**（5/5 种子 × 30/30 轮，
两次独立运行核对），所以 30 epoch 的数字是这条轨迹的**前缀**，不是另一个结果。曲线见
[`figures/f2-w2-epoch-accuracy.png`](../../figures/f2-w2-epoch-accuracy.png)：红线止于第 30 轮、
蓝线画到第 100 轮，灰竖线标出验收预算停在哪。

⚠️ **口径**：上面两种「测试准确率」不是同一个量——验收运行（种子 0，有复现记录）与 5 种子
均值是两件事，本仓库两处都写、各自标名，**不拿一种口径的数字去减另一种口径的**。同理，
**+7.55 是配对差**（5 对同种子差的均值）；种子 0 单独看是 **+7.86**。引用时要说清是哪一个。

⚠️ **但 100 epoch 也仍然没有收敛。** 每 20 轮的窗口均值增量是 +0.1428 → +0.0423 → +0.0206
→ **+0.0114**，在对折但**没到零**；而且**逐种子看最后 20 轮窗口的增量，5 个种子上全为正**
（+0.0084 … +0.0147）——不是均值掩盖了个别种子。所以 **0.8519 同样是预算截断的结果**，只是
截断得晚一些，**不是这条规则在 sMNIST 上的上限**。

⚠️ **判据用窗口均值，不用「最后一个 epoch 的增量」——那一步是噪声。** 100 epoch 批的跨种子
均值曲线在第 100 轮是 **−0.0003**（第 99 轮 0.8493 → 第 100 轮 0.8491），逐种子里也有负的。
这些数字由

| 指标 | 实测 | 判据 |

## 方程到模块的对应

| 论文 | 内容 | 模块 |
| :--- | :--- | :--- |
| LIF/ALIF 动力学 | `v ← αv + W_in·x + W_rec·z − ϑ·z`；`a ← ρa + z`；阈值 `ϑ + βa` | `neurons.ALIFCell` |

## 「局部」的准确表述

计划书 §9 的「无全局反向传播」在本实现里是**可查的**，不只是文档承诺：

* 前向模拟在 `torch.no_grad()` 下跑，脉冲网络内部没有可回传的图；
* 资格痕迹是显式递推出来的，不是求导得到的；
* 学习信号有**闭式**（`W_out` 乘 softmax 误差），连"求导到滤波后的脉冲为止"这一步
  都省掉了——整个 `eprop.py` 没有一次 `backward()` 或 `autograd.grad`；
* 读出层用普通梯度下降（它就是个线性分类器，论文的做法）。

三条测试盯着它：权重变化必须**等于按公式手算的** `−ηΣ_t L_j^t e_ij^t`；更新后
`w_rec.grad is None`；以及一条**对照**——同样的架构换成 BPTT 基线时 `.grad` 不为 `None`、
前向必须建图。单看一边只能说明"没建图"，两边一起看才说明差别在哪。

## 因子分解：精确与近似是两件事

e-prop 的 `Σ_t L_j^t e_ij^t` **不是** BPTT 的梯度。它丢掉了两类路径：跨神经元的循环路径，
以及**复位项** `−ϑ·z^{t−1}` 带来的自身脉冲介导路径——后者与 `W_rec` 无关，所以把循环
权重置零也去不掉。

这件事有两条测试分别钉住：

* **精确**：在"没有可丢掉的路径"的配置下（`W_rec` 置零、无不应期、损失只看最后一步），
  因子分解与 BPTT **相对差 0.000e+00**。这条把 Eq. (25) 的公式与时间对齐钉死；
* **近似**：一般情形下两者不等，实测 20–40%。这是 e-prop 的设计取舍，测试把差值
  **测出来**并断言它落在可解释范围，而不是断言一个它并不满足的精度。

## 已知边界

这一节比结论重要。

1. **Trace Propagation 不在本条目里实现——这一条是考证的结论，不是欠账。**
   §3.1「关键修正 1」要求把资格痕迹存储降到 O(N)。逐条查过原文（arXiv:2509.13053）之后：
   - **计划书的前件成立。** Table 3 有独立的 `E-prop [2]` 行、Space Complexity = `LH²`；
     §1.3.1 还点名 e-prop 作为「按突触存储」这一族属性的实例。所以「本仓库把该复杂度单独
     归给 e-prop」**不是**引申（`docs/references.md` 此前那条判断已撤回）。
   - **但「上 TP」这条补救措施不适用。** TP 不是 e-prop 的省内存版，而是**换掉空间信用
     分配的另一条规则**（论文把两者分列两行、分轴评价，从未说 TP 是 e-prop 的优化）；它的
     **全部**实验都是 **LIF**，而本条的验收配置是 **ALIF（β=0.07）**；而且在论文自己的
     N-MNIST 上 **e-prop 97.90 > TP 97.33 ± 0.06**——e-prop 标 `Partial (time)` local，
     根本不在「fully local」那个比较集里。裁决见 `docs/adr/ADR-0010`。
   - **本实现真正该做的那一条已经做了。** `epsilon_v` 曾按 `(batch, n_pre, n_post)` 分配，
     但它的递推**不含后突触下标 j**——改成 `(batch, n_pre, 1)` 后**逐位等价**
     （`torch.equal=True`、`max|diff|=0`），验收形状下墙钟 **−18.2%**。`epsilon_a` 的系数含
     `(ρ − β·ψ_j)`，**不可因式化**，所以内存的大头由 ALIF 的适应项决定；LIF（β=0）下两者
     都退化成外积，整个迹的状态可降到 O(batch·N)。
   - 在线累积那一步仍然有效：它省掉的是**时间维**（`O(T·batch·N²)` → `O(batch·N²)`），
     实测从「n_rec=256 下一个 epoch 都跑不完」到 50 s/epoch。
2. **验收预算是 30 个 epoch，没有收敛；放开到 100 epoch 之后仍没有收敛。**
   ⚠️ 判据**不是**「最后一个 epoch 的增量」——那一步是噪声（100 epoch 批的跨种子均值曲线第
   100 轮是 −0.0003，逐种子有正有负）。判据是**窗口均值**：20 轮窗口的增量从 +0.1428 一路
   对折到 **+0.0114** 仍没到零，且**两个批次的最后 20 轮窗口增量在 5 个种子上全为正**
   （30 epoch 批 +0.1247 … +0.1338；100 epoch 批 +0.0084 … +0.0147）——见「两个预算」一节。
   所以 W2 目前报出的任何测试准确率都是**预算截断**的结果，不是这条规则在 sMNIST 上的上限。
3. **多种子统计有了（5 个种子）；但"比论文好／差"这句话没有对象——论文没在这个任务上评测过。**
   与 W1 同一口径（`uv run python -m research.eprop.sweep_seeds --seeds 0-4 --device cuda`）：

   | 种子 | 测试准确率 | 活跃神经元比例 |
   | ---: | ---: | ---: |
   | 0 | 0.7748 | 1.0000 |
   | 1 | 0.7678 | 1.0000 |
   | 2 | 0.7789 | 1.0000 |
   | 3 | 0.7857 | 1.0000 |
   | 4 | 0.7746 | 1.0000 |
   | **均值** | **0.7764** | **1.0000** |
   | 最小 / 最大 | 0.7678 / 0.7857 | 1.0000 / 1.0000 |
   | **极差** | **1.79 个百分点** | **0.00 个百分点** |

   ⚠️ **活跃比例这一列没有任何种子方差**（5 个种子全是 1.0000）——它离 §七 的
   60% 阈值太远，**不是一条有区分度的指标**，报它只是因为计划书要求报。
   ⚠️ **准确率这一侧的关键事实不是极差，是它没收敛**：30 epoch 批的最后 20 轮窗口增量在
   5 个种子上全为正（+0.1247 … +0.1338），曲线见
   [`figures/f2-w2-epoch-accuracy.png`](../../figures/f2-w2-epoch-accuracy.png)，
   所以 0.7764 是**预算截断**的结果，不是这条规则在 sMNIST 上的能力上限。放开预算之后它确实

   - **(a) 它的训练方法是 BPTT + DEEP R 重连，不是 e-prop。** 该教程脚本用

6. **与 BPTT 的量化差距报告：同预算下差 23.3 个百分点。**
   `bptt_baseline.py`（同架构、同损失、同预算、同一个 seed，唯一差别是学习规则）：

   | 臂 | 学习规则 | 测试准确率 |
   | :--- | :--- | ---: |
   | e-prop | 局部资格痕迹，**无跨层梯度** | **0.5274** |
   | BPTT | 代理梯度穿脉冲，不切断计算图 | **0.7602** |
   | | **差距** | **+0.2328** |

   配置 `n_rec=256, epochs=10, n_train=20000, batch=64, seed=0`。原始 stdout（含复现记录块）在
   [`sweep_results/w2_bptt.log`](../../sweep_results/w2_bptt.log)。

   **三条口径必须先说，否则这个数会被误读**：
   - **两条臂的学习率不同**（e-prop 2e-3、BPTT 5e-3，脚本各自给的默认值）。所以这是「各自
     默认学习率下的差距」，**不是超参对齐之后的差距**——差距里有一部分可能只是学习率。
   - **这个预算下 e-prop 远未收敛**（10 epoch × 2 万样本），所以 23.3 个
     百分点里很大一块是「收敛慢」，不是「上限低」。
   - **跨预算看，更刺眼的是算力效率差**（这一条**不是**配对比较，两边预算不同）：
     BPTT 用 **20 万**次样本展示拿到 0.7602；而验收配置的 e-prop 用了
     **约 162 万**次（30 epoch × 5.4 万，其中 5.4 万 = 6 万训练集
     扣掉 10% 验证集）才拿到 0.7748——**约 8 倍算力换一两个百分点**。
     这才是这份报告真正的信息量：把「e-prop 慢」从印象变成了可引用的数字，也是 §九
     第四阶段目标「差距收窄或有明确归因分析」的起点。

   ⚠️ **不要把「两个预算」那一节的 100 epoch 数字拿来和这份报告比。** 那边是
   100 epoch × 5.4 万 = 540 万次样本展示，这里的 BPTT 臂是 10 epoch × 2 万 = 20 万次——
   **两边预算都不同**，而且 BPTT 没有跑过对应的长预算。能比的只有上面这一对**同预算**的臂。
