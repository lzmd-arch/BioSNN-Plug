# 仲裁器设计笔记：原生点、符号约定与判据

**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

本文件记**设计决策**，不记结果。结果见 [README](README.md) 与
[`sweep_results/arbiter_synergy_task_spec.md`](../../sweep_results/arbiter_synergy_task_spec.md)；
裁决的正式文本见 [ADR-0013](../../docs/adr/ADR-0013-synergy-benchmark-priority-and-arbiter-scope.md)。

## 一、原生点：共享哪一处权重

协同性基准只认**两条线本来就共享的那一处**——`输入 → 隐藏` 的映射。

* 不新建接口，不做形状投影，不用「把 R-STDP 的更新压到这个形状上」那种做法；
* 形状由任务决定：sMNIST 每步喂一行像素，于是共享权重是 `28 → 256`，不是静态 MNIST 的
  `784 → 256`。**这不是缩小模型**，是任务形态的结果；
* 任何需要"桥"的方案都不是原生点，只能作为**标注清晰的 counterfactual arm**。

## 二、符号约定（最容易写错的一处）

`ESArbiter.blend(a, b)` 的定义是：

```text
blend(a, b) = (1 − α) · a + α · b
```

而调用约定里 **`a` = e-prop、`b` = Hebbian**。因此：

| α | 含义 |
| ---: | :--- |
| `α = 1` | **纯 Hebbian**（不是纯 e-prop） |
| `α = 0` | 纯 e-prop |
| `α = 0.5` | 对半混合——MIX 臂的**起点** |

⚠️ 这条写反过一次：MIX 臂默认 `α = 1` 于是退化成纯 Hebbian，`‖ΔW‖/‖W‖` 与 H 臂**逐位相同**
才被发现。任何报告 MIX 数字的地方都要先确认 α 的方向。

## 三、三条臂与两个对照

| 臂 | 配置 | 回答的问题 |
| :--- | :--- | :--- |
| **H** | 只用 Hebbian 更新 | 单独能到什么水平 |
| **E** | 只用 e-prop 更新 | 单独能到什么水平 |
| **MIX** | α 由 ES 仲裁器学 | 合起来是否**显著更好** |

| 对照 | 配置 | 作用 |
| :--- | :--- | :--- |
| **初始权重** | 训练前 | Fisher 的零点；任何臂都必须明显超过它 |
| **MIX 冻结** | α 固定 0.5，不学 | 排除"随便混一下就行"：若与 ES 学出来的一样，仲裁器没有价值 |
| **打乱标签** | 训练标签重排 | 若 MIX 仍显著更高，说明它没在用标签 |

## 四、门禁：为什么必须有

每次运行都量 `‖ΔW‖ / ‖W₀‖`，**低于 0.05 判该次作废**。

理由是一次真实事故：更新写回后循环里的变量没有重新指向，每一步都从同一个初始权重算起，
于是"两臂给出同一个数"看起来像"两臂能力相同"，实际是**更新根本没进到权重里**。门禁把
这件事从"需要肉眼怀疑"变成"自动作废"。

作废的运行**不进统计，但数量必须报出来**——5 个种子悄悄变成 3 个，结论就不成立了。

## 五、判据：现行口径与演化留痕

主指标是**特征的可分性（Fisher 比）**，不是端到端准确率，也不是线性探针——探针在随机投影上
就已经饱和（0.620），看不出差别。

| 项 | 定义 | 门限 |
| :--- | :--- | :--- |
| 协同量 | `Fisher(MIX) − max(Fisher(H), Fisher(E))`，**按种子成对** | 中位数 ≥ **δ = 0.05** |
| 稳定性 | 5 个种子的四分位区间 | MIX 的**下四分位** > H/E 的**上四分位** |

⚠️ **判据改过，改动本身是记录的一部分**：原判据要求"H 单独失败、E 单独失败"，实测不成立
（纯 Hebbian 把 Fisher 从 0.309 抬到 0.472）。2026-10-18 改为协同量判据，**写在看到 MIX
数字之前**。改判据的理由与边界见 [ADR-0013](../../docs/adr/ADR-0013-synergy-benchmark-priority-and-arbiter-scope.md)。

## 六、本设计不做什么

* 不声称 H 与 E 在生物上真的通过同一个突触协同——这是基准设计，不是神经科学主张；
* 不使用 α→0 的"冲突减少"作为成绩：最优解可能就是关掉一条规则，那是退化不是协同；
* 不涉及**三方混合与调度维度**（阶段五，ADR-0013 维持不动）；
* 不涉及 e-prop ↔ R-STDP 反事实臂（排在基准结果之后）。
