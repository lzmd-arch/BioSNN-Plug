# 检索线：跨模态 R@K

[English](README.en.md) · [日本語](README.ja.md)
**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

## 在验证什么命题

计划书 §七 第二阶段那条唯一还是 ❌ 的成功标准：**跨模态检索 R@1 50%+**。

预注册写在 [`sweep_results/retrieval_procedural_prereg.md`](../../sweep_results/retrieval_procedural_prereg.md)，
**先于数据**。读结论之前先读它。

## 第一轮：外积 Hebb（2026-10-17，5 个种子）

**没有达标。R@1 = 0.141**（种子间 0.121–0.172），随机基线 0.034；**R@5 = 0.528**。

| 栏目 | 结果 | 说明 |
| :--- | :--- | :--- |
| 同模态检索（读法 a） | 文本 1.000；图像 0.759–0.931 | 编码本身保住了身份 |
| 总线直接比（零联想对照） | 0.034 / 0.000–0.069 | **与随机基线相同**——两路是不同投影，正是预注册预期 |
| 外积 Hebb 联想（验收线） | **R@1 0.141 / R@5 0.528** | 高于随机 4 倍，但离 50% 很远 |

R@5 到 0.528 而 R@1 只有 0.141，说明**联想确实带上了跨模态信息，但排序头部很散**——
正确项常常在附近而不在第一位。

## 第二轮：换成 delta 规则（2026-10-17）

预注册：[`retrieval_delta_prereg.md`](../../sweep_results/retrieval_delta_prereg.md)。同样的数据、
切分、种子与编码，只换联想规则。

| 联想规则 | R@1（5 种子均值） | R@5 |
| :--- | ---: | ---: |
| 外积 Hebb（第一轮） | 0.141 | 0.528 |
| **delta（Widrow–Hoff，本轮）** | **0.359** | **0.845** |

**仍然没有达到 50%。** 但 R@5 从 0.528 抬到 0.845、R@1 从 0.141 抬到 0.359，说明第一轮那句
诊断是对的：外积和只是把训练目标按相似度加权平均，没有抑制近邻的机制；误差修正确实把
排序头部收紧了。

⚠️ **delta 不是无监督 Hebb**：误差项 `v − W·t` 里的 `v` 是配对训练时给出的教师信号，
所以它是**有教师的局部规则**——每个突触只用自己两端的前后活动加一个误差，不走链式法则。
这条边界不许含糊。

⚠️ **大步长会发散**：网格里 η=0.1 的部分配置会溢出成 inf/NaN。现在发散被显式标记、在
交叉验证里记 0 分，不让它把平均值污染成 NaN。第一版没有这一步，日志里出现过
`RuntimeWarning: invalid value encountered`——**这条警告不是噪声，是选参被 NaN 污染的信号**。

## 一个必须记下来的发现：这层规则没有可调超参

预注册写了两个超参 `η`（学习率）与 `λ`（遗忘）。实测**两个都选不动**：

* 外积和的变换是 `η·(t ⊤ Σ v t⊤) / (1+λ)`，**η 与 λ 都只是全局缩放**；
* 余弦对全局缩放不敏感 → 网格上所有组合的留一分数**完全并列**，选中的只是并列里的第一个。

所以「选参」这一步实际上什么也没选。这不是实现缺陷，是这条规则在**余弦排序**下的
代数性质。真要调，得换成带伪逆的联想（那就不再是纯 Hebb，留作下一个预注册）。

## 怎么跑出来

```bash
uv run pytest research/retrieval -q                  # 36 条测试
uv run python -m research.retrieval.run_retrieval --seeds 0,1,2,3,4
```

文本侧走本机 Ollama 的 `nomic-embed-text`（冻结前端），token 级 embedding 缓存在
`data/embeddings/nomic-embed-text.json`。**Ollama 不可用时实验不跑**，不退回假后端。

## 已知边界

1. **数据集是程序生成的**（4 形状 × 3 明度 × 6 方位 × 2 尺寸 = 144），不能对标文献。
   Flickr8k 的**加载器已就位**（`flickr8k.py`：只加载、不下载，目录结构与那个少一个 r 的
   `Flicker8k_Dataset` 都写在模块文档里），**真实数据上的运行还没做**——下载来源与逐文件
   校验和尚未登记。
2. **总线两路不在同一空间**：`semantic` 与 `temporal` 各自经过独立种子的随机投影，
   直接比余弦恒在随机水平。对照实测 0.034 = 1/29，与这句话一致。
3. **联想层是单向的**：两个方向各拟合一个 `W`，不假设互为转置。
4. **只报 R@1 / R@5**，不报平均精度之类的其它口径——预注册只写死了这两个。
