# 预注册模板（本仓的研究纪律，2026-11-12）

**这是模板，不是预注册。** 复制一份、改名、填满、落盘、**然后再跑**。

本仓的规矩：**判据先落盘、之后不得回改**；负结果照登；不调阈值让结果变绿；
要改已发布的判据，新写一份 `*_amend*.md` 并在两边互相链接，不静默覆盖。

> 模板里每一条"必填"都对应一次**真实踩过的坑**。删掉任何一条，就等于把那个坑重新挖开。

---

## 0. 头部（必填）

```markdown
# 预注册：<实验名>（<日期>）

**状态：判据先落盘。** <这一行在跑完之后也不改>
**取代 / 修订**：<若是 amend，写清取代哪一份、理由一句话；不是就写"无">
**上游**：<本实验要回答的是哪一份文档/ADR 留下的问题>
```

- **日期必须是落盘日**，不是计划日。跑完之后改日期会让"先写后跑"变成不可核。
- **`amend` 不覆盖原文**：原文保留，新文写清"什么变了、为什么变"。

## 1. 问题与前提（必填）

一两句话把问题写成**可判真假**的形状。然后列**前提**：这个实验成立需要哪些已知事实。

- 前提必须是**已经从仓库里核过的**，并给出路径或 ADR 编号；
- 任何"我们觉得应该是这样"的东西，**不算前提**，算待检验的假设。

## 2. 判据（必填）

分三段写，缺一不可：

### 2.1 前置闸门（`<名>-0`）

**跑之前就要能判的**条件：数据齐不齐、基线复现不、服务起没起。
前置不过则**整轮作废**，不进入主判据。

### 2.2 主判据（`<名>-1`、`<名>-2`…）

每条写成"**度量 + 阈值 + 比较对象 + 单/双边**"：

- 度量必须**能被另一个脚本算出同一个数**；
- 阈值必须写绝对值，不写"明显提升"；
- 比较对象必须写清是**哪一臂**，跨语料比较要写两边的三元组；
- **噪声地板要写出来**。阈值落在噪声里时必须现在就写明"与零不可分辨"是允许的结论。

### 2.3 kill 判据（必填）

**什么结果出来就停线**，以及停线的后果（归档？换方向？不再分配算力？）。

没有 kill 判据的预注册不是预注册——那样无论结果如何都能继续花钱。

## 3. 预算与停止点（必填）

| 项 | 值 |
| :--- | :--- |
| 步数 / epoch / 样本数 | |
| 单臂预计耗时 | |
| 早停与检查点策略 | |
| **停止点怎么定** | 固定步数 / 预注册平台判据 / 峰后回落 |

- 收敛性判据用**run 内自标定**的形式（U 形最低点、双平台），**不用跨语料常数**；
- **峰值必须在评测网格里真的出现过**。"还在涨"不能推断"还会涨"——
  报告时必须给出峰值步数，以及终点落后峰值多少。

## 4. 数据与边界（必填）

| 项 | 值 |
| :--- | :--- |
| 数据来源与许可 | |
| 是否出本机 | |
| 产出落在哪（不入库的写清路径） | |
| 是否碰产品路径 | |

**三条默认边界**（不适用就写"不适用"并给理由）：

1. 真实会话正文**不出本机**；云端只收合成内容；
2. 检查点与语料放 `D:\AxoData\`，**不入库**；
3. 不接生产路径、不改默认开关。

## 5. 结果入库时的四问（必填，写在结果表下面）

每个结果写进 README / AGENTS 时，逐条回答。**缺一条的结论不许进结论段落。**

1. **是预算截断吗？**（峰值在最后一个评测点 / 还没见顶）——若是，数字只能当**下界**；
2. **是跨语料 / 跨预算比较吗？**——若是，必须写出两边的三元组与预算；
3. **是单边指标吗？**（只赢了一个方向的指标）——若是，写明是哪一边赢；
4. **cos 先验兑换成 Δ 了吗？**——若只报了代理指标、没跑对应臂，写"**先验，未兑换**"。

## 6. 意识相关产出：双里程碑门禁（触及意识/情感/自主时才填，否则写"不涉及"）

见 [ADR-0036](../docs/adr/ADR-0036-consciousness-claims-discipline.md)。三件套缺一不可：

- [ ] **合规声明草稿**：声称级别（L0/L1/L2）、明确不碰什么、评测方式；
- [ ] **词汇审查**：黑名单词零出现；白名单词都在允许的意义上；最强措辞不超过"与 X 一致"；
- [ ] **反例**：本轮的结论里至少给出一项**不成立**的签名或条件。

基底里程碑（若涉及物理基底）另加：AI welfare 预防审查 + 监管重新扫描，并新写一篇 ADR。

## 7. 负结果的登记位置（必填）

写清这一轮的产出会落在哪个目录（如 `sweep_results/<tag>/README.md`），
以及**判红时也要写**这件事。**判红不等于不写**，判红恰恰是最需要留档的那一个。

## 附：常见错法（都是本仓真发生过的）

| 错法 | 表现 | 正确做法 |
| :--- | :--- | :--- |
| 阈值先验不可达 | 分母异号时比值恒为 ±2 | 先做**标度标定**，再定阈值 |
| 跨语料常数 | 大语料上同一个比值必然不过 | 用 run 内自标定 |
| 把第一个 <1% 区间当平台 | 多算了 2pp | 连击 k 次要真连上 |
| 峰后回落还叫收敛 | 平台规则永不触发 | 跟踪 running max，回落 >1pp 判已过峰 |
| 上界与拟合预算不对齐 | 闭式解"天花板"其实用了更少样本 | 上界必须与拟合预算同口径 |
| 单臂配置手抄 | 两臂差一个开关，结论归因错 | 配置写进文件，两臂从同一份派生 |
