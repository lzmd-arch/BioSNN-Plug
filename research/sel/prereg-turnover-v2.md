# 预注册 v22：按静默比例触发的生死规则（+ 两种诞生方式）

**写于** 2026-11-16，**在任何一档跑之前**。

## 上一轮的结论

**数量通道在 5% 损伤时 `d'=2.09`，强度通道要 25%** ⇒ 触发条件应该用**静默比例**。

## 但 v19 的失败可能有两个原因，必须拆开

| 原因 | 修法 |
| :--- | :--- |
| **触发放错通道**（用活动） | 改成按静默比例 |
| **动作放错**（新单元权重随机，摧毁组成） | 改成**从高活跃存活单元复制 + 噪声** |

生物学依据：新生神经元不是"凭空一个新类型"，而是**分化成已有的类型**
（成年海马新生颗粒细胞整合进现有环路）。

## 规则

```
静默 = 块内活跃 < ε（只统计存活单元）
诞生：静默比例 > θ_hi  ⇒ 复活一个死单元
      方式 random：入边权重随机（v19）
      方式 clone ：从高活跃存活单元复制入边权重 + 10% 噪声
死亡：静默比例 < θ_lo  ⇒ 让最低活跃的存活单元死亡（维持周转）
```

## 四档

| 臂 | 触发 | 诞生方式 |
| :--- | :--- | :--- |
| `static` | — | — |
| `act/random` | 活动 | 随机（= v19） |
| **`silent/random`** | **静默** | 随机 |
| **`silent/clone`** | **静默** | **复制 + 噪声** |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **T-0** | 50% 切除后 `static` 的 `n_viable` ≈ 7.3（基线） | 复现 |
| **T-1′ 静默触发更好** | `silent/*` 的最好一档 **> `act/random`** | 触发的贡献 |
| **T-2′ 复制更好** | `silent/clone` > `silent/random` | 动作的贡献 |
| **T-3′ 超过不修** | 最好一档 **> `static` 的 7.3** | **最终判据** |

**T-3′ 才是真正要的** —— 生死规则必须比"什么都不做"更好，否则它没有存在理由。
