# 预注册 v13：把波函数坍缩加进来 —— 它是混沌缺的那一块

**写于** 2026-11-16，**在任何一档跑之前**。

## 用户的主张

> 「我们何不把波函数坍缩也加上呢，少了这一步，也许就导致了混沌系统是不完整的。」

**这个诊断是对的，而且可以写成定理。**

## 一、为什么纯酉演化**不可能**混沌

酉演化是**等距**的：

```
‖Uψ₁ − Uψ₂‖ = ‖ψ₁ − ψ₂‖        对所有 U†U = I
```

⇒ 两个邻近初态的间距**永远不变** ⇒ **最大 Lyapunov 指数恒为 0** ⇒ **不可能有对初值的敏感依赖**。

这解释了 v12 的结果：`K ≈ 0.015`（与正弦同量级）。
那个系统名义上有非线性项 `g|ψ|²ψ`，但 `|ψ|² ≈ 1/N` 使它在量纲上被摊薄，
**所以它实际是线性的** —— 不是在"参数没调好"，是**结构上不可能混沌**。

## 二、坍缩补的正是这一块

测量/坍缩是**非线性**（归一化依赖状态本身）**且随机**的：

```
以概率 |⟨k|ψ⟩|² 选出 k；ψ ← P_k ψ / ‖P_k ψ‖
```

- 非线性：投影后要按 `‖P_kψ‖` 重新归一，这个因子依赖 ψ；
- 随机：选择 `k` 是随机的。

**两者都是混沌所需的成分。**

## 三、生物学上站得住

环境对系统的**连续"测量"（退相干）是真实的**，不需要任何量子脑假设。
坍缩只是它的**离散化模型**（quantum jump / quantum trajectory，标准方法）。

⇒ 加上坍缩之后，模型与生物合理性的关系**更强**了，不是更弱。

## 四、输出序列 = **观测记录**（这才符合"只看结果"）

观测者能看到的只有**测量结果**。所以本轮的输出标量是：

```
φ(t) = ⟨ψ(t)|H|ψ(t)⟩          （能量期望，实标量）
```

坍缩时它会跳变。**这就是"只检查结果、不看过程"最彻底的形式** ——
我们连 `ψ` 都不看，只看它能被观测到的那个数。

## 五、扫描与判据

| 参数 | 值 |
| :--- | :--- |
| `η`（**弱测量强度**，每步一次） | 0 / 0.05 / 0.2 / 0.5 / 1.0 |

**为什么用弱测量强度而不是"坍缩概率"**（写在跑之前）：
**完全坍缩到计算基态 `e_k` 时，`⟨ψ|H|ψ⟩ = H_kk = J_kk + Γ = Γ`（自耦合为 0）**
⇒ 输出序列会退化成"每步都等于 `Γ` 的分段常数"，`K` 无意义。
所以用弱测量：

```
以概率 |ψ_k|² 选出 k；ψ ← normalize( (1−η)ψ + η·ψ_k·e_k )
```

`η=1` 即完全坍缩，`η=0` 即不测。**输出仍是 `φ(t)=⟨ψ|H|ψ⟩`。**

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **X-1** | 判据自检（v12 已过，沿用同一实现） | 不过 ⇒ 作废 |
| **C-0** | `φ(t)` 序列有限、std 不退化（>1e-6） | 不过 ⇒ 该档无效 |
| **C-1 坍缩带来混沌** | 存在 `p` 使 `K > 0.7` | **本轮核心** |
| **C-2 剂量–反应** | `K` 随 `p` 从 0 上升（不是一上来就满） | 趋势 |
| — | `λ` 照报；两判据不一致记"未定" | — |

**C-1 是全部意义所在**：若 `p=0` 给 `K≈0` 而某个 `p>0` 给 `K>0.7`，
那"少了坍缩所以不混沌"就**被证实了**。

## 六、若 C-1 不过

⇒ 坍缩在这个实现里也没造出混沌（可能被投影重置成了马尔可夫链）。
照实记，**不改 0.7 这条线**。

## 不做的事

- 不读 `ψ` 的内部结构，只算 `⟨H⟩`；
- 不声称"脑里真有量子坍缩"（§14.1 的退相干论证不变）；
- **不声称任何超出本轮的结论**。
