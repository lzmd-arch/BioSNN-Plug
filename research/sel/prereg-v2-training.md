## 一、已经冻结、不再训练的东西（有实测支撑）

| 件 | 结论 | 证据 |
| :--- | :--- | :--- |
| 传感器**编码** | **解析构造**，不学 | 设计后 5 个种子逐位相同；随机抽签 11–13pp |
| 池**神经元数** | **64**（不是 16） | 基因搜索：0.402 → 1.000 |
| 各池**膜 τ** | 逐池标定（temp 要快、presence 要慢） | τ 异质：temp τ=5 +10.8pp |
| 千问**权重** | **冻结**（改权重维度=量化，已证不是杠杆） | S0c |
| **token 级融合** | **不做** | 四种算子 + S0 加性偏置全部为零 |
| **激素当增益 / 侧抑制 / 脱敏 / 缩放** | **不做** | 五次实测为零或负 |
| **文本侧生成/判别/编码** | **不做** | 四测四负 |

## 二、要训的三件（按顺序，每件都有 kill gate）

### T-1 读出层（唯一必须训的）

| 项 | 值 |
| :--- | :--- |
| 训什么 | 线性读出 `W`（池特征 → 行为/类别） |
| 算法 | **解析梯度**（softmax + 交叉熵），无 autograd |
| 数据 | 冻结特征（池 64，解析编码） |
| 判据 | **AF ≤ 0.25**（Route R Step 0 已在池 16 上做到 0.22；池 64 需要复测） |
| 代价 | **分钟级**（每步 4 ms，5 任务 × 300 步 × 5 种子 ≈ 3 分钟） |
| 前置 | 无——立刻可跑 |

### T-2 条件算子（自适应标定）

| 项 | 值 |
| :--- | :--- |
| 训什么 | `τ(p) = softplus(p·w + b₀)`，9 个参数 |
| 算法 | 解析梯度，无 autograd |
| 数据 | **真实使用数据**：p 必须来自设备侧（传感器/人格/记忆），不是文本统计 |
| 判据 | **ECE 低于全局 T=1.5 的 0.0425**，且置换检验 p<0.05（**不用平均 log p**——它混淆标定与锐度） |
| 代价 | 分钟级 |
| **阻塞** | **缺数据**：真实传感器配对记录从 2026-11-14 才开始，量不够 |

### T-3 千问所有权重（如果还要）

| 项 | 值 |
| :--- | :--- |
| 现状 | HF 权重已下载（7.6 GB，`D:/AxoData/models/hf/Qwen3-4B`） |
