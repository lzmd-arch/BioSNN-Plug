# 预注册 v15：稳态场 vs 固定场

**写于** 2026-11-16，在 v14 之后、**本轮任何一档跑之前**。

## v14 留下的不对称

| `g_field` | 完整 `n_viable` | 50% 损伤 `n_viable` |
| ---: | :---: | :---: |
| −0.5 | **8–9** | 5 |
| 0 | 2 | **7** |

**抑制性固定场在完整网络扩大窗口（2→8.5），在损伤网络收窄（7→5）。**

原因：损伤后活动本就减半，固定强度再抑制就掉到地板下。

## 改法：场强**跟着活动走**

生物学的对应是**稳态可塑性**（synaptic scaling / intrinsic plasticity）：
活动高了就压，低了就放。

```
f_run(t) = EMA( mean_i z_i(t) )              λ = 0.9
g_eff    = g0 · ( f_run / f* )               f* = 0.08
输入     += − g_eff · Φ(t)                    Φ = mean z
```

活动高 ⇒ 抑制强；活动低 ⇒ 抑制弱。**负反馈。**

## 三档

| 模式 | 输入 |
| :--- | :--- |
| `fixed` | `+ g_field · Φ`（v14 原样） |
| **`homeo`** | `− g0 · (f_run/f*) · Φ` |
| `off` | 无场（对照） |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **H-0** | `fixed` 复现 v14 的不对称（完整 > 损伤） | 不过 ⇒ 作废 |
| **H-1 稳态场两边都扩** | `homeo` 的 `n_viable` 在**完整与损伤两个状态**都 ≥ `off` 的 **2 倍** | **本轮核心** |
| **H-2 剂量–反应** | `n_viable` 随 `g0` 先升后降 | 趋势 |
| — | 参考：`off` 的完整 2 / 损伤 7 | — |

**H-1 是全部意义**：v14 的场只在一侧有用。若稳态场能在**两侧同时**扩大余量，
那"场买余量"才成立 —— 而且它靠的是**反馈**，不是调参。

- 不引入可学参数（`g0`、`f*` 是超参，扫出来）；
- **不声称任何超出本轮的结论**。
