# 预注册 v16：内在兴奋性上调 —— 内部机制能否做到外部补偿做到的事

**写于** 2026-11-16，在 v15 之后、**本轮任何一档跑之前**。

## 为什么是这一条

| 干预 | 完整 `n_viable` | 50% 损伤 `n_viable` | 是什么 |
| :--- | :---: | :---: | :--- |
| 抑制性固定场 | 8–9 | 5 | 外部、全局 |
| 稳态场 | **11–12** | 6 | 内部、全局 |
| **补偿（调输入增益）** | — | **拉回窗内** | **外部** |

**唯一能救损伤网络的是"从外部把输入增益调上去"**。那是我们在 v9 里做的，
它不是生物机制 —— 是我们从外面拧的旋钮。

**内在兴奋性上调**（intrinsic plasticity / homeostatic excitability）是它的生物版：
**每个神经元自己调自己的增益**，把活动拉回目标（Turrigiano 2008）。

⇒ 问题很具体：**一个内部的、逐神经元的机制，能不能做到外部全局调参做到的事？**

## 机制

```
f_i(t)  = EMA( z_i )                    λ = 0.99
a_i     *= exp( η · (f* − f_i) )         每 k 步更新一次，clip 到 [0.2, 5]
cur_i   = a_i · w_in[tok]
```

- **逐神经元**（不是全局）；
- **局部**（只看自己的发放）；
- **无梯度**；
- 生物学对应：离子通道密度/阈值的稳态调节。

## 四档

| 模式 | 说明 |
| :--- | :--- |
| `off` | 无（基线） |
| **`intrinsic`** | 逐神经元增益上调 |
| `homeo_field` | v15 的稳态场（只调抑制） |
| `global_gain` | v9 的外部补偿（**参考上限，不是生物机制**） |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **P-0** | `off` 复现基线（完整 2 / 损伤 7） | 不过 ⇒ 作废 |
| **P-1 内部能救伤** | `intrinsic` 的**损伤 `n_viable` > `off` 的 7** | **本轮核心** |
| **P-2 不伤健康** | `intrinsic` 的完整 `n_viable` ≥ `off` 的 2（不下降） | — |
| — | `global_gain` 作参考，**不作判据** | — |

**P-1 是 M5「再生」的定义性判据**：它问的是"系统自己的机制能不能在损伤后恢复功能"。

若成立 ⇒ 「内部调节 → 功能恢复」第一次被确立。
若不过 ⇒ 损伤后的余量只能靠外部调参，那 M5 在本架构里不成立。
