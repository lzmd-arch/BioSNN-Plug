# 预注册：发育（结构由自身活动长出）

**写于** 2026-11-16，**在任何一档跑之前**。

## 为什么是这一步

代谢内核（`metabolic_core`）测到：`E` 不可由输入还原（R² = −0.016）、
强约束行为（corr = −0.990）。**但 `E` 现在只是一个被动计分器** ——
它改变阈值，不改变结构。要让"边界"真的成立，**内部量必须反过来塑造结构**。

这也是唯一一条同时服务目标、又可能有能力收益的路：`structure_ladder` 的证据是
**结构单加没用**（C 0.348 < 平坦 0.370），**结构 + 匹配的读出**才 +7.6pp（D 0.446），
而那个匹配现在是**我们手工搜出来的**。发育 = 让系统自己长出来。

## 机制：过度生长 + 活动依赖修剪 + 稳态缩放

生物学上，发育的普遍模式是**先过量生长，后按用途修剪**。

1. **过度生长**：起始入度 `D0 = 32`（目标 `D1 = 8`）；
2. **共活动痕迹**（局部，无全局误差）：
   `s_j ← λ·s_j + |z_pre_j · z_post|`，窗口 `λ = 0.95`；
3. **随机修剪，存活概率按痕迹偏置**：
   `p_keep ∝ s^β`，`β = 1` 为活动驱动，`β = 0` 为随机（对照）；
4. **稳态缩放**：存活突触重新归一化到修剪前的总驱动
   —— **否则"修剪了"与"驱动变小了"会混在一起**。

## 四档

| 臂 | `β` | 代谢 | 作用 |
| :--- | ---: | :--- | :--- |
| `acid`（活动驱动） | 1 | 开 | 主臂 |
| `rand`（随机修剪） | 0 | 开 | 对照：活动依赖是否真的做功 |
| `acid_nometab` | 1 | 关 | 检查 `E` 是否影响发育出的结构 |
| `noprune` | — | 开 | 上界：不修剪的过度生长网络 |

## 判据

| 编号 | 判据 | 通过线 |
| :--- | :--- | :--- |
| **D-0** | 发育后真实发放率 ∈ [0.03, 0.20]，且 `acid` acc ≥ 底板 + 15pp | 不过 ⇒ 作废 |
| **D-1 渠化** | 3 个种子的存活结构**两两 Jaccard < 0.8**，且 acc 极差 **< 2pp** | 结构不同、能力相同 |
| **D-2 活动依赖做功** | `acid` acc ≥ `rand` acc **+ 3pp** | 修剪不是随便剪 |
| **D-3 `E` 塑造结构** | `acid` 与 `acid_nometab` 的结构 **Jaccard < 0.9** | 代谢改变发育轨迹 |

**D-1 是这一轮的定义性判据。** 它同时排除两件事：
结构是随机的（那样能力会散）、以及我们在搜索结构（那样结构会收敛到同一个）。

## 不做的事

- 不加可学参数（修剪规则是局部的、无梯度）；
- 不改任务与读出（沿用隐状态解码 + 播种 `mlp_probe`）；
- **不声称任何超出本轮的结论**。

## 若 D-2 不过

说明活动依赖的修剪不比随机好 —— 那么"发育"在这个实现下只是个随机结构生成器。
照实记，不调 3pp 这条线。
