# 预注册 v19：受调控的细胞更替（生与死）

**写于** 2026-11-16，**在任何一档跑之前**。

## 前提修正（§24）

用户：**「模拟基因调控很显然需要神经元自然死亡和新生。」**

§23 把"外部随机破坏"和"内部受调控的更替"混成了一件，推论太粗。
本轮建的是**后者**。

## 机制（两条规则，都由活动驱动）

```
死亡：  f_i 的块均活跃 < θ_dead          ⇒ 永久静默
诞生：  群体活动 < f_target 持续 K 块     ⇒ 随机选一个已死的单元复活
        复活时：入边权重重新随机、增益 ×g_new（关键期超兴奋）
```

生物学对应：
- **活动依赖的存活**（拿不到营养因子就凋亡）—— 真实机制；
- **新生神经元在关键期内超兴奋**（成年海马齿状回，实测）；
- **群体层面的稳态**（生/死率与群体活动耦合）。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **T-0** | `static`（无更替）在 50% 切除后 `n_viable` = 基线 7 左右 | 复现 v8；不过 ⇒ 作废 |
| **T-1 更替能恢复群体** | 跑 `turnover` 若干块后，`n_viable` **> `static` 切除后的值** | **本轮核心** |
| **T-2 组成随输入改变** | 在流 A 与流 B 上发育后，存活集合的 Jaccard **< 0.9** | 组成不是固定的 |
| **T-3 组成可逆** | A→B→A 后，组成与"A 的组成"的 Jaccard **> 与"B 的组成"的** | 组成记忆 |

**T-2/T-3 是新的东西**：它测的不是"信息能不能取出来"，而是"**组织被经验重塑成了什么**"。

## 流 A 与流 B 怎么不同

`make_task` 的 `pref` 由 `seeded_dirichlet(alpha, K, seed)` 决定。
取 `alpha` 不同（例如 A: α=1，B: α=8）⇒ 词分布一个稀疏、一个平坦，
**哪些神经元被驱动得更多就不同** ⇒ 死亡选择会不同。

## 不做的事

- 不改读出与任务；
- 基因（`θ_dead`、诞生率、`g_new`）本周固定，不做演化（演化是下一层）；
- **不声称任何超出本轮的结论**。
