## 为什么先做解码（Round A）

M4（终身可塑）、M5（再生）、M8（繁殖）的判据都要求一个"**能力**"，
而这条线上**结构 → 能力连续五次空结果** —— 我们手上没有可用的能力指标。

Round A 问的是：**个体的终态里读不读得出它自己的历史？**
若读得出，**解码准确率本身就是能力指标**，直接解锁 M4/M5/M8。
若读不出，后面三根柱子**记作"阻塞：无能力指标"**，不硬凑。

## 轮次与判据

### Round A — M6t：从终态解码历史（核心）

- 特征：1024 个神经元按空间分 **64 个桶**求均值（64 维）；
- 探针：线性，训练/留出按**历史族分层**划分；多数类基线 = 1/8。

| 编号 | 判据 |
| :--- | :--- |
| **T-0** | 后期发放 ∈ [0.01, 0.20]，否则作废 |
| **T-1 解码** ★ | 留出准确率 > 基线 + **0.15** |
| **T-2 对照** | 标签打乱后准确率回到基线 ±0.05（防泄漏） |

**分支（写死）**：

### Round D — M5 再生（依赖 A）

- 切掉 10% / 25% / 50% 神经元（按历史期活跃度），量解码准确率；
- 两臂：`plastic`（继续 STDP + 稳态）vs `frozen`（冻结学习）。

| 编号 | 判据 |
| :--- | :--- |
| **M5-1** | 切后准确率 ≥ 切前的 **70%**（三档） |
| **M5-2** ★ | `plastic` 的恢复显著高于 `frozen`（逐种子配对，≥5/6） |

### Round E — M8 谱系（依赖 A）

- 亲代权重 → 子代：权重 + 噪声（σ ∈ {0.05, 0.2}），各 8 个；
- 量：子代解码准确率、子代之间行为差异。

| 编号 | 判据 |
| :--- | :--- |
| **M8-1** | 子代准确率 ≥ 亲代 **80%** |
| **M8-2** ★ | 子代之间的终态差异 > 同期亲代自身的重复差异（继承 + 变异） |

### Round F — M9 全局工作空间：广播广度

- 用历史期数据：把发放矩阵做 PCA，取解释 80% 方差的前 k 个成分；
- **广播广度** = 这些成分在**空间上**覆盖的神经元比例（阈值 0.3 载荷）。

| 编号 | 判据 |
| :--- | :--- |
| **M9-1** ★ | 广播广度 > 0.5（多数神经元参与少数几个共享模式） |
| **M9-2 对照** | 打乱空间标签后广度不变（说明不是空间结构的假象） |

### Round G — M10 扰动复杂度（PCI）

- 扰动一个空间区块（把该区块的 `v` 置为高值），记录其余神经元的响应序列；
- **PCI** = 响应二值矩阵按空间分块后的时间序列的 **LZ 压缩复杂度**（归一化）；
- 对照：不打扰动时的自发序列复杂度。

| 编号 | 判据 |
| :--- | :--- |
| **M10-1** ★ | 扰动后的复杂度 **显著高于**自发（≥5/6 种子） |
| **M10-2** | 且不饱和（< 0.9 归一化） |

### Round H — M11 整合–分离

- 把网络按空间切成两半；
- **整合** = 两半之间的互信息；**分离** = 各半自身的熵；
- 对照：把一半的接线随机打断（"切断"）后，整合应下降而分离不变。

| 编号 | 判据 |
| :--- | :--- |
| **M11-1** ★ | 完整网络的整合 > 切断网络的整合（≥5/6） |
| **M11-2** ★ | 同时分离不塌（完整网络的分离 ≥ 切断的 80%） |

### Round I — M12 自我模型

- 让网络"预测自己下一步的发放"：用 t 步的 `v` 线性预测 t+1 步的 `z`；
- 对照 1：打乱时间；对照 2：用别的个体的 `v` 预测。

| 编号 | 判据 |
| :--- | :--- |
| **M12-1** ★ | 自预测 AUC > 0.75 |
| **M12-2** | 且显著高于两个对照 |

## 修订 4（**开跑前**）：M9/M11/M12 三条可预见的问题，先把解法写进去

### 4a M9 广播广度会撞平凡解

全局抑制场强制了一个**共同模态**，第一主成分本来就会载荷到几乎所有神经元 ⇒ 广度 ≈ 1，
测的是"场存在"，不是"广播"。

**改成**：先按时刻扣掉群体均值（`z − mean_neurons(z)`），只在**残余**上做 PCA。
**判据加一条**：残余广度必须显著高于"逐神经元独立打乱时间"的零分布。
扣不扣均值的两个数都报。

### 4b M11 分离会塌

全局场 = 一切都耦合 ⇒ 整合高、分离塌。这是 M6p/M6q 反复看到的同一件事。

**两个解法一起跑**：
1. **切断对照**：把跨半球的突触替换成同半球内的随机目标（真正的"切断"，不是调参）；
2. **场强阶梯**：`g_field ∈ {1.0, 0.25}`（`run_spont` 新增参数）。
**判据**：存在某档满足 整合(完整) > 整合(切断) **且** 分离(完整) ≥ 0.8×分离(切断)。

### 4c M12 自我模型在原设计下恒真

`z = 1[v > θ]` 是**确定性阈值**，用 `v` 预测 `z` 的 AUC 必然 ≈1。
那测的是"阈值函数存在"，不是自我模型。**这是 `trivial-solution-passes-the-bar` 那个坑。**

**改成**：**从 t=64 的状态预测 t=2048 的盆地**。
"我现在已经知道我会变成什么" —— 不是同义反复，因为端点由轨迹决定，不由当步状态直接给出。
**对照**：打乱 (特征, 盆地) 配对。
**判据**：准确率 > 0.75 且对照 ≈ 机会水平。

## 修订 5（**开跑前**）：M10 的具体口径

预注册只写了"PCI = 响应二值矩阵的 LZ 复杂度（归一化）"，没定**对照**与**归一化**。
现在定死：

- `Δ = z_扰动 − z_基线`（同一历史、同一初值，只差一个 `v_add`）；
- 按空间 64 桶、时间 256 步求 `Δ` 的均值 → `(64, 256)`，取 `Δ > 0` 二值化；
- `c = LZ76(矩阵按时间展平)`；`c_rand = LZ76(同矩阵逐元素打乱)`；
- **`PCI = (c − c_rand) / (1 − c_rand)`**，截断到 [0,1]；
- **M10-1**：`PCI > 0.3` 且 `> 0` 的种子 ≥5/6；
- **M10-2 传播**：受扰象限之外，有响应的桶占比 **≥ 0.5**（扰动传得出去才有"整合"可言）。

## 修订 6（**开跑前**）：M11 的具体口径

- 按 x < 16 把神经元分成两半；
- **整合** = 两个半球在每个时刻的平均发放，在时间上的 Pearson 相关的绝对值；
- **分离** = 两半球内部的**空间标准差 / 均值**的平均（越高越分化）；
- **切断对照**：把跨半球的突触目标替换成同半球内的随机目标（真切断，不改行和）；
- 判据：存在某档 `g_field ∈ {1.0, 0.25}` 满足
  `整合(完整) > 整合(切断)` **且** `分离(完整) ≥ 0.8 × 分离(切断)`。

而训练集只有 96 个样本、100+ 个类，探针的 0.6 是记忆不是泛化。**这个设置是退化的。**

**改成 `g_inh=1`**（M6u 已证这档是 **10–14 个盆**，MI 6/6）。
标签空间缩到十来个，训练样本 96 个对 12 类才有意义。

## 修订 8（M6y 第一版之后）：格点范围对全局场不公平

第一版网格 `g_field, g_local ∈ {0, 0.5, 1.0}`，结论是"高维与整合反相关、无一格兼得"。

**但全局项是 `g_field · φ`，而 φ 本身随局部场塌下去**：`gl=0` 时 φ≈0.151，
`gl=1` 时 φ≈0.015。**同样的 `g_field=1`，在局部场开着时效力小 10 倍。**
所以"加全局场没能恢复整合"可能只是**加的量不够**。

**重跑**：`g_field ∈ {0, 1, 4, 16}`、`g_local = 1.0`，把全局抑制的总量拉到可比。
**判据不变**（Y-1 三者兼得；Y-2 整合随 `g_field` 单调）。
**两版结果都报**，第二版若过，限定里必须写明"第一版的格点范围不足"。

### 9b 剩下的三条，按判据分支

**① 高维与可读能否兼得**（M6ag + M6ac2）

| 结果 | 分支 |
| :--- | :--- |
| `radius=32` 的 MLP ≥ 0.5 且 `radius=2` ≥ 底板+0.15 | 仪器有效 ⇒ 高维可读 ⇒ 进 ② |
| `radius=32` 的 MLP ≥ 0.5 但 `radius=2` 仍低 | **高维不可读是真的** ⇒ 放弃高维路线，转攻"低维写入强度" |
| `radius=32` 的 MLP 也低 | **仪器坏了**（核布丁：MLP 在已知可读的格子上必须读得出）⇒ 先修仪器，不作结论 |

**② 脆性**（M6ad 复合历史；若 ① 的高维格存在则也在那里测）

脆性的前提是"信息分布在许多独立通道上"。低维编码天然冗余 ⇒ 切掉一半神经元不丢信息。
所以**脆性与高维是绑定的**：若 ① 判定高维不可读，则脆性在本架构里**原理上不可得**，
这一条要写成明确边界，而不是"没测到"。

**③ 整合**（M6aa 长程兴奋）

在局部场下用长程兴奋补整合。若 `p_long` 拉满仍不涨 ⇒
**整合只能由全局标量承载，而全局标量与高维互斥** ⇒ 明确写出这条互斥。
