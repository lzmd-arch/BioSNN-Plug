# 预注册：R10——数据 × 读出：两个已知杠杆是叠加还是饱和（2026-11-08）

**状态：判据先落盘。**

## 理由：这是路线图问题，不是"还能不能涨"

手上有两个**已知有效**的杠杆，但从来没同时拧过：

| 杠杆 | 证据 | 幅度 |
| :--- | :--- | ---: |
| **数据 5×**（3,000 → 15,000 对） | R2：R2-A −6.16pp → R2-B **−1.67pp** | **+4.49pp** |
| **读出 4×**（1,024 → 4,096 维，4 个 τ） | R4：−6.16pp → **−1.28pp** | **+4.88pp** |

两者都在**同一个语料（R2-A，3k 对）**上测过基线，但**从没叠加**。

- **若叠加**：R2-B 的 −1.67pp + 4.88 ≈ **+3.2pp**——**这条支线第一次出现正 Δ**，
  且意味着局部规则有机会靠"已知杠杆"摸到 BP 附近，信用分配从近平价起步；
- **若饱和**：仍在 −1.67pp 附近，那 5.41pp 只能靠信用分配硬啃，③ 的预注册要按"全缺口"设计。

## 设计（跑之前定死）

| 项 | 基线（R2-B） | **R10** |
| :--- | :--- | :--- |
| 语料 | `H_r2`（15,000 对） | 相同 |
| 折 | group 0 / 1 | 相同 |
| updates | 93,750（120 epoch） | 相同 |
| 读出 | 1,024 维单 EMA | **4,096 维（τ ∈ {2, 8, 32, 128}）** |
| 其余 | N=1,024、`fan_in=32`、`batch=16`、`max_len=192`、`max_vocab=800`、`lr_in=1e-3`、`lr_out=0.5`、种子 0 | **完全相同** |

**基线**：R2-B 均值 top-1 **0.2639**，bigram 0.2806，**Δ = −1.67pp**。

**参数代价**：读出 **0.82M → 3.28M（4×）**，整机 1.65M → 4.1M。词表 801，与 R4 同口径。
（注意：这是"每 token 参数"随语料守恒——15k 对语料下 3.28M 读出仍只有 1,024 宽的 4 倍，
没有出现"读出参数随语料膨胀"的问题，因为 `max_vocab` 把词表钉在 800。）

## 判据

| # | 门槛 | 判什么 |
| :--- | :--- | :--- |
| **R10-0** | 两折跑完；`readout_dims=4096` 入档 | 实验无效 |
| **R10-1** | **Δ ≥ +1.5pp**（改善 ≥ +3.2pp） | **完全叠加**，第一次正 Δ，路径成立 |
| **R10-2** | 改善 ≤ +1.5pp | **不叠加**（饱和），5.41pp 归信用分配 |
| 中间带 | 改善 +1.5 ～ +3.2pp | 部分叠加，如实报 |

**为什么阈值取 +1.5pp 而不是 +3pp**：R8 的门槛（+3pp）是"机制是否成立"，
这里的门槛是"两个杠杆是否可加"——**+1.5pp 就是"完全可加"预测（+3.2pp）的一半**，
低于它就说明叠加性已经损失过半，不能叫叠加。

## 预期

**押中间带（改善 +2 ～ +3pp，Δ 落在 −1.7 ～ +1.3pp）**。理由：两个杠杆都在**同一个瓶颈**（读出维度）上，
大概率部分重叠而非完全独立；同时 R2-B 已经比 R2-A 更接近 bigram（−1.67pp），
**离零越近，同样的杠杆越难再推**（天花板效应）。

## 不做的事

- 不扫数据规模（只做 15k 这一个点）；
- 不叠加 τ 组合（R9 的变量）；
- 不做多种子。

## 边界

- 两折、单种子；合成语料不是真实对话；字符级 next-token，**不代表能闲聊**；
- 若 R10-1 成立（正 Δ），**这仍然只是"在自建合成语料上首次超过 bigram"**，
  真语料（−6.24pp）与 BP 的对照（−0.83pp）都不因它改变。

## 成本

93,750 updates × ~40 步 × 2 折，读出 4 倍宽 ≈ **2–2.5 小时**。
