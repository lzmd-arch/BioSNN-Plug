# 预注册：1B 组合模型的「合格涌现」

**日期**：2026-11-16
**对象**：Semprea-Anchor 1B（0.5B 千问人格核 + 0.5B 局部规则脉冲核 + FiLM 桥）
**依据**：用户 2026-11-16 给的「合格涌现小模型」四件套与三个机制来源，以及本仓 Paper B 的四轴赌注。

---

## 一、把「合格」钉死

「涌现」是被用滥的词。Mirage 一系的反方文献已经证明：很多「涌现」是**度量的人造产物**——
曲线形状随指标选择而变。所以本仓的涌现主张必须同时满足四条，缺一不可：

| # | 要求 | 落成本仓的可执行形式 |
| :-- | :--- | :--- |
| **Q-1** | 可操作定义 | 涌现出**什么能力**，写成能跑的判据。**禁止裸说「智能涌现」**（与「心智」同一条词汇纪律） |
| **Q-2** | 非线性证据 | 能力–复杂度曲线上有**真实膝点**：多个指标、多个坐标尺度都指向同一位置，防 Mirage 伪影 |
| **Q-3** | 归因对照 | **去掉那个结构，能力随之消失**。否则涌现来自数据，不来自结构 |
| **Q-4** | 位级复现 | 同种子同配置可复现。这是本仓现成资产（已验证：同输入重复编码最大差 `0.0`） |

**没有 Q-3 的「涌现」一律按「训练集拟合」处理，不进结论段。**

---

## 二、现状审计：我们的 1B 现在是**开环**的

用户给的三个机制来源里，第一条是「闭环动力学」，并给了试金石：

> 拿掉这个环，系统的行为是否变得可预测地平庸。

我们现在的结构：

```
状态文本 ──▶ SNN 核心 ──▶ p ──▶ FiLM ──▶ 千问 ──▶ 输出
                                                  │
                                            （没有回到 SNN）
```

**实测确认**：`SNNCoreState.encode()` 每次都从零建膜电位
（`scripts/snn_core_state.py` 的 `v = zeros / ref = zeros / readouts = zeros`）。
⇒ **跨调用无状态，回路是开的。**

这不满足 Q-3 的前提：连「环」都没有，谈不上「拿掉环会不会平庸」。

## 三、改造：把环闭上

### 3.1 闭环的定义

```
第 t 轮： (用户输入_t, 模型输出_t) ──▶ SNN 核心（**沿用上一步的膜电位与痕迹**）
                                              │
                                        p_t ──┴──▶ FiLM ──▶ 第 t+1 轮
```

**关键改动只有一条**：SNN 的膜电位 / 不应期 / 读出**跨轮保留**，不再每次归零。

### 3.2 环里必须携带一样上下文带不走的东西

这是整个设计的成立前提。纯文本上下文已经带着历史，如果 SNN 只是把历史再编码一遍，
**它是冗余的**——那就不构成涌现来源，只是昂贵的传声筒。

所以闭环只在一种条件下有意义：

> **状态活过上下文**。

具体说：**跨会话**。会话 A 结束时 SNN 带着痕迹；会话 B 从**空上下文**开始，
但 SNN 是温的。此时 B 的行为如果受 A 影响，那是**上下文给不了的信息**。

**这就是 Q-1 的可操作定义：跨会话状态延续能力。**

### 3.3 三个机制来源的诚实盘点

| 机制 | 我们有什么 | 缺什么 |
| :--- | :--- | :--- |
| **① 闭环动力学** | 三个环的原料都有：稳态环（状态→FiLM→行为）、离线环（A1 睡眠巩固）、自驱环（SNN 空步漂移已在 `snn_state_p.py` 用过） | **回路没闭上**（本文档要改的） |
| **② 组织** | 模块化已有（两个半）；仲裁器 P4 在 `research/arbiter/` | 预测模型的接线；液态 τ 只在 `model.py` 里当超参，没进组织层 |
| **③ 接地** | **输入半边有**：传感器多池（五池、设计编码、τ 异质、侧抑制、激素路由）已在 `TokenEProp` 里建好并逐条测过（`sweep_results/sensor_pools/`，2026-11-14） | **回路半边没有**：没有「行动 → 环境 → 再感知」的反馈 |

**更正（2026-11-16）**：本文档初稿写「接地：无」，这是错的。我们已经有的：

- 五个传感器池（`temp / presence / time / memory / persona`），四池单跑成立；
- **设计编码**（温度计码 / QR 正交投影）——把抽签方差 11–13pp 压到 0.0pp；
- 逐池标定的膜时间常数（τ 异质 +10.8pp）；
- 区间侧抑制、多路激素、受体矩阵与路由——**这几条实测为零或负**，
  与 AGENTS §2.8 的规律一致：**改标量/增益/学习无效，改信息几何有效**。

**真正缺的是回路**：我们的传感器只进不出——行为不改变环境，所以没有反馈。
「接地」在涌现语境里指的是**闭环**（Braitenberg 车那种），不是「有传感器输入」。

**还有一个具体缺口**：部署用的 0.5B 核心（`snn_core_state.py` 加载的 `semprea_v1`）
`sensor_dim=0`，**根本没接传感器池**。传感器那套只在研究层的 `TokenEProp` 里。

⇒ 可做的是把**接地输入**接进 1B（把已建好的池接上），
**不可做的是闭环接地**（需要真实环境），后者本文档不承诺。

## 四、判据（先落盘）

### 实验设置

- **会话 A**：喂 N 轮合成对话（固定内容，不含要考的事实以外的信息）；
- **会话 B**：**清空上下文**，只给一个新的问题，问的是 A 里出现过的事实；
- **对照臂**：B 开始前把 SNN 状态**重置**（= 现在的开环行为）。

### 四条判据

| 编号 | 判据 | 通过线 |
| :--- | :--- | :--- |
| **E-1** | `acc(状态延续) − acc(状态重置)` | **≥10pp**（跨会话状态真的携带信息） |
| **E-2** | 在 N ∈ {0, 2, 4, 8, 16, 32} 上的 E-1 曲线 | 存在膝点：某点前后斜率比 **≥3×**，且跨过 10pp |
| **E-3** | 消融：重置状态后 E-1 回到 | **<3pp**（归因成立） |
| **E-4** | 同种子两次跑 | **逐位相同** |

### 预先写死的失败条件

- **E-1 不过** ⇒ 跨会话状态不携带信息，「闭环」这条路**不能作为涌现主张**，
  只能作为工程特性（省 token）记一笔，不进结论段；
- **E-2 曲线是线性的**（无膝点）⇒ 即使 E-1 过，也只能说「状态有用」，
  **不能说「涌现」**。按 Q-2，线性增长 = 可加性 = 不是涌现；
- **E-3 不过** ⇒ 提升不来自环，来自别的东西（比如评测集泄漏），**整个结论作废**。

## 五、grokking 候选：值得做，但不作为主证

用户建议的「延迟泛化」是这个方向里最干净的现成范式。我们的条件：

**支持它的**：
- 局部规则有资格痕迹，窗口 α=e^(−1/20) ≈ 20 步，**给「延迟」一个机制假说**；
- 全窗痕迹可消融（把 trace 截断到 5 步），这是现成的 Q-3 对照；
- 位级复现已具备。

**不支持它的**：
- 我们现有的任务都**没有训练/测试分布的分裂**，而 grokking 需要它；
- 0.5B 的容量下，延迟泛化可能根本不会出现（grokking 主要见于小算子的算法任务）。

**所以先写死**：

| 编号 | 判据 |
| :--- | :--- |
| **G-1** | 在一个**有算法结构**的合成任务（如模运算、括号匹配）上，训练损失收敛后测试指标出现 ≥15pp 的跃升 |
| **G-2** | 跃升时刻前后的学习曲线斜率比 ≥3×（相变而非缓慢爬升） |
| **G-3** | 把资格痕迹截断到 5 步后，跃升**消失或推迟 ≥2×** |
| **G-4** | 三种子都能复现（允许跃升时刻有抖动，但必须出现） |

**G-1/G-2 都不过就照实报「本模型没有 grokking」，不调任务去找一个能 grok 的。**

## 六、叙事纪律

对外只说：

> **涌现出「跨会话状态延续」能力（操作定义见 §四，膝点在 N=Z，消融后消失）**

不说「智能涌现」，不说「涌现出心智」，不把 E-1 通过写成「产生了智能」。

**这个命题的正名是 Paper B 的赌注**：动力学 × 组织能否替代基质产生涌现。
这台仪器本来就是为了测它。

---

## 七、不做什么

- **不做接地（机制③）**：纯文本模型没有感知-行动闭环，硬做只会变成「把传感器数据当token」，
  那不是闭环；
- **不在 Q-3 不成立时保留涌现叙事**：删掉那句话，不留「可能有」；
- **不为找膝点而换指标**：Q-2 要求多指标同指一处，单一指标的膝点不算；
- **不把开环版的结果混进来**：开环与闭环的数是两个 regime，必须分开报。
