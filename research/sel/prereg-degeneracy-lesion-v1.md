# 预注册 v8：损伤下的简并（结构值钱的地方可能不在正常功能里）

**写于** 2026-11-16，在 v7 之后、**本轮任何一档跑之前**。

## 假说

到目前五次都测到「不同接线 → 同一功能」：

| 自变量 | 结构差异 | 功能差异 |
| :--- | :--- | :--- |
| γ（`E` 进痕迹） | 10% | 平 |
| 折叠（3 维 vs 薄片接线） | **21%** | **+0.5%（5/7）** |

这个模式在生物学里有名字：**简并（degeneracy）** —— 不同结构实现同一功能。
但简并的价值**不在正常功能里，在损伤下**：

> **如果两套接线在正常时等价，但在损伤后不等价，那么"结构"就不是无关变量 ——
> 它买的是韧性，不是能力。**

**本轮就是测这个。**

## 设计

复用 v7 的两套接线（`cortical_fold`），逐级损伤**神经元**：

| 臂 | 接线 |
| :--- | :--- |
| `sheet` | 薄片（2D 环面）距离 |
| `space` | 3 维距离（折叠改变了谁和谁连） |

- 损伤方式：随机选 `frac` 的神经元，**它们不再放电**（`z ← z · alive`），
  其读出位置恒为零；
- 水平：**0% / 25% / 50%**；
- 指标：**线索保持的峰值解码准确率**（lag=1）。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **L-0** | 0% 损伤时两臂峰值 ≥ 底板 + 10pp，发放在 [0.03, 0.20] | 不过 ⇒ 作废 |
| **L-1 简并成立** | 25% 与 50% 损伤下，两臂峰值仍 ≥ 底板 + 10pp | 退化后仍可用 |
| **L-2 损伤下分家** | `space − sheet` 在 **50% 损伤**时 **6/6 种子**同号 | **本轮核心** |
| — | 效应量与逐级掉落照报 | — |

**L-2 是全部意义所在**：它在测"正常时看不见的结构差异，损伤后是否显形"。
若 6/6 成立 ⇒ **结构不是无关变量，是韧性变量** ——
这一条会把前面五次的"平"重新解释成"正常功能对结构不敏感，不等于结构无用"。

## 若 L-2 不过

⇒ 两套接线连抗损伤也一样。那"简并"就不只是功能层面，而是**贯穿到损伤层面**。
照实记，**不改 6/6**。

## 不做的事

- 不加可学参数（**没有再生机制**，本轮测的是"能不能扛住"，不是"能不能修好"）；
- 不改读出与任务；
- **不声称任何超出本轮的结论**。M5 的"再生"（恢复依赖自身活动）要等有可塑性之后才能测。
