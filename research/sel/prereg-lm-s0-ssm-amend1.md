# 预注册修订 1：S0 的发放率前置分臂判定（2026-11-06）

**状态：本条在跑 S0 之前写下。** 修订 [`prereg-lm-s0-ssm.md`](prereg-lm-s0-ssm.md) 的 S0-0。

## 为什么改

S0-0 原来写"三臂发放率均在 [1%, 30%]"。写代码时在玩具配置（V=40、N=128）上冒烟，得到：

| 递推 | 发放率 |
| :--- | ---: |
| `random` | 1.5% |
| **`none`** | **0.7%** |
| `ssm` | 11.9% |

`none`（纯前馈 LIF）在这个输入幅度下**本来就接近不发放**——这是"没有循环电流"的**性质**，
不是实验坏了。若沿用原来的写法，`none` 会因为一条它本来就该违反的前置把整轮判成无效。

## 改成什么

- **`random` 与 `ssm` 两臂**：发放率必须落在 **[1%, 30%]**（这两臂才是本轮要比的）；
- **`none` 臂**：不设下限，但**必须记录**。若其发放率 <0.5%，在结论里明写"`none` 臂接近不发放，
  作为基线其判读力有限"；
- S0-0 的判定改为：**`random` 与 `ssm` 都落在带内**即过。

## 不变的部分

判据 S0-1（SSM 赢随机循环）、S0-2（赢 bigram）、S0-3（诊断齐全）一个字不动。
学习率、数据、预算、读出、种子全部沿用 M0b，不调。
