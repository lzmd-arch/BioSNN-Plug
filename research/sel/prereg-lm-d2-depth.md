## 为什么先做深度

`prereg-lm-p1-public-corpus.md` 里早就写死了：

> **D2 = +1 层 LIF**（`w12`=N×N；每层自己的 v/z/不应期/资格痕迹；信号经 `w12` 对称回传）。
> 判据 **D2−D1 ≥ +3pp** 才算深度是杠杆；≤ +1pp 转宽度。

这条**从未实现**（`research/eprop/README.md` 写死「只有一个隐藏层…多层堆叠尚未实现」）。
而今天的证据把所有别的方向都挤掉了：

| 方向 | 今日状态 |
| :--- | :--- |
| 读出维度 | 2 抽头见顶，4 抽头回落（+1.17pp 反向） |
| 低秩读出 | −1.3pp，否 |
| 低精度存储 | −11pp，否；镜像可用但只是速度 |
| 异质膜 τ | −0.6 ～ −0.9pp，否 |
| 分组归一化 | 发散，否 |
| 神经元数 N | 512→1024 只值 0.96pp，低杠杆 |

**深度是唯一还没被碰过的表征维度。**

## 结构（写死）

```
token → w_in → LIF₁ → w12 → LIF₂ → K 抽头 EMA → w_out → softmax
```

| 项 | 值 |
| :--- | :--- |
| 层数 | **2**（D1 = 现有单层，D2 = 加一层） |
| `w12` | N × N = 1024² ≈ 1.05M 参数（相对 9.2M 是 **+11%**） |
| 每层状态 | 各自的 `v` / `z` / `refractory` / `α`（同 τ=20） |
| 读出 | **仍只从第 2 层读**，K=2 抽头不变 |
| 反向信号 | **对称反馈**：`signal₁ = post₂ @ w12ᵀ`（真转置，不是随机反馈） |
| 学习规则 | 逐层 e-prop：`w_out` ← NLMS；`w12` ← `eps_{z1}ᵀ · post₂`；`w_in` ← `eps_inᵀ · post₁` |
| 范围限制 | `depth=2` 时**只支持** `recurrence="none"` + 无 groups / candidates / 低秩（其余组合直接报错，不静默降级） |

## 实装时才发现的硬前置：`w12` 的尺度必须标定（2026-11-11 补，**跑任何臂之前**）

第 1 层发放率只有 ~4%，所以第 2 层的电流 ≈ `N · f₁ · w`。用 `randn/√N` 初始化时这个值是 **1.27**，
而阈值只有 **0.62** —— 第 2 层一上来就饱和。

实测两个失败点：

| `w12_scale` | 第 2 层电流 | 现象 |
| ---: | ---: | :--- |
| 0.1 | ≈ 0.13 | **`z2` 几乎为 0，读出完全不学**（train CE 恒等于 ln(V)） |
| **0.4** | ≈ 0.5 | **两层都在发放**，200 步 train CE 8.005 → 7.076 |
| 1.0 | ≈ 1.27 | 预期饱和，未实测 |

⇒ **新增判据 D2-1b（前置）**：训练中第 2 层发放率必须 **≥ 1%** 且 **≤ 第 1 层的 2 倍**。
不满足则该臂作废、先调 `w12_scale`，**不许带着饿死或饱和的第 2 层去报"深度没用"**。

**这一条是 M0/M0b（2.16 倍电流比）和 S0/S1（标定后仍负）的教训在深度上的复现**——
递推那条线上我们花了五轮才学会"先标定再谈效果"，深度这条线一次就补上。

## 判据

| # | 门槛 | 判什么 |
| :--- | :--- | :--- |
| **D2-0** | `depth=1` 与现模型**逐位等价** | 改动是"加一层"，不是"换模型" |
| **D2-1** | `depth=2` 的前向在 `w12` 全零时**逐位等于** `depth=1` | 第二层确实只经由 `w12` 接入 |
| **D2-2** | **D2 − D1 ≥ +3pp**（16,000 步、2 抽头） | **深度是杠杆** |
| **D2-3** | D2 − D1 ≤ +1pp | 深度不是杠杆，**转回合结构 / 记忆** |
| **D2-4** | 训练后两层放电率都 ≤ 初始 2× | 工作点没被第二层带崩 |

**D2-2 与 D2-3 是同一门槛的两侧，中间带（+1 ～ +3pp）报数不判。**

D1 的参照值：**16,000 步 / 2 抽头 = top-1 0.3090 / CE 3.874**（已实测）。

## 混淆项（写死）

- D2 比 D1 多 1.05M 参数（+11%）。**若 D2 过，必须补一条"等参数量的 D1 加宽/加抽头"对照**，
  才能说增益来自"深度"而不是"参数"。这条**不在本轮**，但必须写在结论里；
- 单折、单种子；16,000 步峰值未到 ⇒ Δ 是**下界**；
- 两层的 ψ 用同一套（`dampening/θ · clamp(1−|scaled|,0)`），不单独调。

## 不做的事

- 不改读出、不改 τ、不改精度、不改伪导数；
- 不做 3 层以上（先看 2 层）；
- 不与递推同时上（S8 是另一条臂）。
