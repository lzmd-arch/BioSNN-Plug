# P4 预注册修正之一：先做 CE-only，KL 暂缓（跑学生之前写死）

**日期**：2026-11-03
**父文档**：[`prereg_p4.md`](prereg_p4.md)。

## 为什么改

P4.0 探针证明教师（llama.cpp 1.5B）能给 **token 级** top-5 logprobs（覆盖 0.967）。
但 P4 的学生是**字符级**的：要在每个字符位置拿教师的下一 token 分布，必须把 token
序列与字符序列逐位对齐，并把 token 概率边缘化到字符——那需要教师的 tokenizer 与
一个对齐算法，本仓没有，llama.cpp 的 Python 侧也不提供现成的分词。

**不能在没对齐的情况下把 CE 叫成"蒸馏"**，也不能拿"取不到 logprobs"当借口——探针
明确显示能取到，是我们没有对齐层。

## 修正

- **P4a 只做序列级 CE**（教师文本作为目标），报告里写"监督微调/序列蒸馏（CE）"，
  **不写"自蒸馏"**；
- **P4-4（KD 相对 CE 的改善）本批不适用**（N/A），不是不过；要判它，先补一份
  tokenizer 对齐的修正与实现；
- 其余 P4-1/P4-2/P4-3/P4-5/P4-6 不变。

## 先跑什么

1. **bigram 基线**（字符级、加一平滑）——给出 P4-1 的分母；
2. 再跑 GRU(256) 与 ALIF/TI-LIF 学生（CE-only），5 种子；
3. P4-1 不过就停，不写 CWSSA/SSM、不补 KD。
