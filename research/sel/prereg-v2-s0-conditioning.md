# 预注册：V2 的 S0 —— 条件偏置在真实骨架上有没有头寸

**日期**：2026-11-14
**问题**：V2-A（`logits' = logits_qwen + U·p`）到底值不值得做。
**写下来之后不得回改**；要改另写 `*-amend*.md`。

---

## 一、为什么必须先跑这条

V1 的四种 token 级融合算子（线性 / 秩 / 一致性门 / 可学门）**全部没有超过温度对照**。
V2-A 换的是接口（低维状态向量 → logits 的低秩偏置），但**没有任何证据说它会有头寸**。
如果连"给定一个推理期可算的 p，能不能在留出位置上改善真值的 log 概率"都做不到，
那 V2-A 就是个换名字的旧东西，**V2 的形态要退到 V2-B（行为读出）**。

## 二、装置（写死）

| 项 | 值 |
| :--- | :--- |
| 骨架 | **Qwen3-4B-Q4_K_M**，本地 llama-server @ `127.0.0.1:8081`，`temperature=0`、`n_probs=100` |
| 数据 | FineWeb-2 `cmn_Hani` 中文切片（ODC-By），取 **600 个 token 边界**，按位置 **70/30** 划分训练/留出 |
| 真值 | 语料在该位置的下一个 token（由 llama-server `/tokenize` 对齐，**同一分词器，无跨表问题**） |
| 算子 | `log q'(c) = log q(c) + (A·p)_c`，`A ∈ R^{2×C}`，`C` = 该位置的 top-20 ∪ {真值} |
| 训练 | 交叉熵对线性偏置的**闭式梯度**，无 autograd；L2 = 1e-2；20 轮 |
| 随机性 | 只有划分与随机 A 的种子；**同一份划分给所有臂** |

### p 的 8 个分量（**全部在推理期可算**）

1. 上下文长度（除以 512）
2. Qwen top-1 logprob（置信度）
3. top-20 的熵
4. top1 − top2 的 logprob 差
5. 最近 8 个字符里的标点比例
6. 最近 8 个字符里的重复率
7. 最近 8 个字符里的数字比例
8. 常数 1（偏置项）

**注意**：2–4 是 Qwen **自己输出**的函数。它们存在的意义是让"自适应温度"这个解释
**能被 B2 检验**——如果 D 的增益与 B2 打平，结论是"只是重标定"，不是"条件化"。

## 三、臂

| 臂 | 做法 |
| :--- | :--- |
| **B0** | 不加偏置（Qwen 原样）——基线 |
| **B2** | 全局温度：`log q / T`，T 在**训练折**上选 |
| **B1** | 随机 `A`，**5 个种子** |
| **D** | 学出来的 `A` |

## 四、判据（跑之前写死）

| # | 判据 | 阈值 |
| :--- | :--- | :--- |
| **S0-1** | 留出集上 D 的真值平均 log p 相对 B0 的提升 | **≥ 0.05 nats** |
| **S0-1b** | 同上，相对 B2（温度对照） | **必须更高** |
| **S0-1c** | 同上，相对 B1（5 个随机种子里的最好者） | **必须更高** |
| **S0-2** | 置换检验：把 p 与位置的配对打乱 200 次，真实增益的 p 值 | **< 0.05** |

**S0-1 全过且 S0-2 过 ⇒ V2-A 有头寸，形态照 §一 走。否则 ⇒ V2 退到 V2-B。**

## 五、诚实边界（写在前面）

- **p 是"文本统计"，不是传感器**。所以本轮测的是**算子的头寸**，不是"传感器信息值多少钱"。
  传感器信息（千问结构上拿不到的）只会让 p 更有用，不会更差；
- 600 个位置上的 0.05 nats 是一个**中等的效应量**；没测到不等于没有，只说明"用这件仪器看不见"；
- 骨架是 **Q4_K_M**，V1 的慢半也是它；换 Q6_K 数字会动，本轮不换。
