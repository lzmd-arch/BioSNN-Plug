# 预注册 v21：可检测下界（d′）—— 级联是否让数量通道更灵敏

**写于** 2026-11-16，**在任何一档跑之前**。

## 上一轮的教训

**AUC 问的是"有没有信号"，不是"够不够大到能行动"。**
强补偿后差异只有 26%，组内方差小 ⇒ AUC 0.997。

⇒ 本轮改用 **d′**（效应量对自身噪声）：

```
d' = |mean(损伤) − mean(完好)| / sqrt((sd_损伤² + sd_完好²) / 2)
```

惯例：`d' ≈ 1` 边缘可判，`d' ≈ 2` 清楚可判。

## 两个通道

| 通道 | 量 |
| :--- | :--- |
| **强度** | 每存活神经元的平均发放 |
| **数量** | 长期静默的神经元比例 |

## 可证伪的预测

上一轮测到**级联**：杀 10% → 静默比例从 0.012 涨到 0.196（近两倍）。

⇒ **预测：数量通道的可检测下界更低**（在更小的损伤比例上就越过 `d'=2`）。

若成立，那"该数静默单元而不是看活动"这条设计原则就有了**定量支撑**。
若不成立（两通道下界相同或强度更低），那这条原则**没有依据**，照实记。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **C-0** | 50% 损伤时两通道 `d' > 2` | 不过 ⇒ 作废 |
| **C-1 数量通道更灵敏** | 最小越线损伤比例：数量 **≤** 强度 | **本轮核心** |
| — | 六个损伤比例的 `d'` 曲线照报 | — |

损伤比例：**1% / 2% / 5% / 10% / 25% / 50%**，20 种子。
