## 一、整机

```
用户文本 ──────────────────────────────► 千问 4B（冻结）
                                             │ logits
本机独占输入（不出设备）                      │
  温度/气体/图像嵌入 ─┐              logits' = logits / τ(p)
  节奏/停顿/在场     ─┤                       │
  人格状态（跨会话） ─┼─► 池向量 p ───────────┘   （τ(p) 只做标定，不改 token 排序）
  记忆检索命中       ─┘        │
                               └─► 读出层 W ─► 行为：检索/语气/追问
```

**融合接口有两个，各管一件事**（S0/S0b 的直接产物）：

| 接口 | 做什么 | 证据 |
| :--- | :--- | :--- |
| **全局 `T≈1.5`** | **标定**（ECE 0.135 → 0.043） | `sweep_results/v2_s0/README_CALIBRATION.md` |
| `τ(p)`，9 个参数 | 自适应标定 | **在 ECE 上反而更差（0.185）**，需以 ECE 为目标重训 |
| `W`，线性读出 | **行为决策**（检索/语气/追问） | CL 上 AF 0.80 → 0.22 |

**不做**：token 级的加性偏置（S0 两次为零）、把 p 当内容注入。

## 二、池（唯一被证实的"生物特性"落点）

| 项 | 定值 | 依据 |
| :--- | :--- | :--- |
| 每池神经元数 | **64** | 基因搜索 0.402 → 1.000；池 128 过拟合回落到 0.894 |
| 编码 | **解析构造**：1 维标量 → 温度计码（阈值等距）；d 维向量 → QR 正交投影 | 抽签方差 11–13pp → **0.0pp** |
| 膜时间常数 | **逐池标定**（temp 5、presence 80） | τ 异质：temp +10.8pp；两池最优点相反 |
| 侧抑制 | **关** | 不降冗余，`time` −20pp |
| 激素 | **一路标量 + 自适应标定**，不做多路/路由/脱敏/缩放 | 六次实测为零或负 |

五个池：`temp`（恒定标量）、`time`（张力性积分器）、`memory`（一次性向量）、
`persona`（持续向量）、`presence`（时变标量）。

## 三、读出

| :--- | :--- |

## 六、还没定的两件（都**不是**架构问题）

1. **真实传感器数据的形态**——决定 p 的维度与内容；高维优于低维（16 维 0.92–0.98，1 维 0.24–0.42）；
2. **全局温度要不要动**——它改变生成行为，是产品决策不是研究结论。
