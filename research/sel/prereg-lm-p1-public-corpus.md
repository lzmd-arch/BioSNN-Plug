## 补注（2026-11-10，写在峰值出现之前）

**2,000 步的绝对/相对脱钩**：同一预算下模型在 KdConv 上学到的**绝对量**接近私有语料的**两倍**
（0.1928 vs 0.0967），但 bigram 的水位也从 0.1669 涨到 0.2887（+12pp），于是**相对差距反而更深**。

⇒ **公共对话的局部规整性 disproportionately 喂养了 n-gram 基线。** 这句话要写进结论，
比"起点差异来自水位"更准：它同时解释了"绝对学习量翻倍"与"Δ 反而更深"。

**外推的修正**：私有语料那条"+2.5pp（2k→峰值）、8k 见顶"的形状来自**饥饿语料**（每折 118–252 对）。
KdConv 的数据量约 **150 倍**，而 R0b 的剂量反应说得很清楚——**语料越大，最优点越晚、总增益越大**。
所以：**峰值可能落在 12,000–16,000 步，2k→峰值的增益也可能明显超过 +2.5pp**。
着陆带 **−4 ～ −7pp 只作中枢，不作边界**。

**判别带（出数后按这个判，比只看 Δ 的正负多一层解释力）**：KdConv 的 bigram **0.2887**
恰好落在最难合成语料的邻域（R2-A 0.288 / R1b-H 0.294），而 **R10 在同一邻域上 Δ = −1.7 ～ +0.6pp**。

| P1 峰值 | 判读 |
| :--- | :--- |
| **显著高于该带**（Δ ≥ −3pp） | **规模 + 真源的增益**：公开语料确实比自建合成语料更值钱 |
| 落在带内（−1.7 ～ +0.6pp 附近） | 与合成语料**同档**——真源没有额外信息 |
| **显著低于该带**（Δ ≤ −6pp） | **两个解释，结论相反**：①真文本有合成语料没有的结构；②**未观测上下文**（见下）。P2 探针一刀判别 |

**「未观测上下文」这个竞争解释（2026-11-10 补，P2 必做）**：KdConv 的每句回复都锚在那
**18,535 条知识三元组**上，而逐对输入的模型**根本看不到三元组**。引用不可见知识的回复，
**对任何规则都是不可约的不确定**——缺口可能是**输入侧的可观测性问题，不是规则的无能**。

**判别实验（P2 的第一项）**：把该轮的三元组拼进输入（`input = 三元组文本 + 用户话`），其余不变。

| 结果 | 判读 |
| :--- | :--- |
| Δ **显著跳升** | 「规则一直饿着上下文」——局部规则的账要重记；这条比"真文本更难"更有利于规则 |
| Δ **不跳** | 真结构赤字，规则确实吃不下来 |

三元组在仓外、操纵干净——这是 KdConv 相对合成语料多送的实验自由度。

## 参数分支（**先写死，等 P1 出数才执行**）

参数在哪（V=3,001、N=1,024、4 τ）：`w_in` 3.07M（20%）+ `w_out` 12.29M（**80%**）。
**读出占八成，且是逐字查表、不跨时间共享。**

| 轴 | 参数量 | 单步计算 | 证据 |
| :--- | ---: | :--- | :--- |
| 宽度 N 1024→2048 | +15.4M | ~2× | 未在宽读出下测过（R3 的 N 检验是读出卡在 256 时做的） |
| τ 4→8 | +12.3M | ~2× | 已关闭（R11） |
| **深度 +1 层** | **+1.05M** | **+5%（KdConv 配置）** | **完全未测**；且**仓库里没有任何多层 e-prop 可复用**（`research/eprop/README.md` 写死「只有一个隐藏层…多层堆叠尚未实现」），实现约半天 |

| P1 结果 | 参数动作 |
| :--- | :--- |
| **P1-1 过** | **D2 = +1 层 LIF**（`w12`=N×N；每层自己的 v/z/不应期/资格痕迹；信号经 `w12` 对称回传）。判据 **D2−D1 ≥ +3pp** 才算深度是杠杆；≤ +1pp 转宽度 |
| **P1-2** | **不加参数**——问题不在容量 |
| 中间带 | 不加参数，先查明"为什么没迁移" |

**参数必须跟着数据涨**：深度若有效，下一步是"深度 × 数据"（1.57M → 6M 字），
**数据翻倍之前不加第二层以上、不加宽**。

## 不做的事

- 不加注意力（全局、二次复杂度，破坏局部规则与 O(N) 叙事）；
- 不在 τ 轴上继续加（R11 已关闭）；
- P1 出数前不动模型结构。

## 边界

- 单折（官方 test，4,868 对）、单种子；
- 测试集 token 数会随结果报出（统计噪声）；
- 字符级；**不代表能聊**；本轮只回答"公开语料上单层落后 bigram 多少"。
