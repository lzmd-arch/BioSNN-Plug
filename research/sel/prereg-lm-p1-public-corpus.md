## P1 设计

`TokenEProp`：N=1,024、`tau=20`、`input_std=0.12`、`lr_in=1e-3`、`lr_out=0.5`、
**4 个 τ（{2,8,32,128}）**、`max_len=192`、种子 0、词表 3,001。
`--updates 16000 --eval-every 2000`（约 7–8 epoch）。
参数：`w_in` 3.07M + `w_out` 12.29M ≈ **15.4M**。

## 判据

| # | 门槛 | 判定 | 下一步 |

| **P1-0** | 三元组 / bigram / BP 对照齐 | ✅ | — |

**判读按规则③ v3**：报 running max 峰值 + 峰值步数 + 终点落后峰值多少。

## 参数分支（**先写死，等 P1 出数才执行**）

参数在哪（V=3,001、N=1,024、4 τ）：`w_in` 3.07M（20%）+ `w_out` 12.29M（**80%**）。
**读出占八成，且是逐字查表、不跨时间共享。**

| 轴 | 参数量 | 单步计算 | 证据 |
| :--- | ---: | :--- | :--- |
| 宽度 N 1024→2048 | +15.4M | ~2× | 未在宽读出下测过（R3 的 N 检验是读出卡在 256 时做的） |
| τ 4→8 | +12.3M | ~2× | 已关闭（R11） |
| **深度 +1 层** | **+1.05M** | **+5%（KdConv 配置）** | **完全未测**；且**仓库里没有任何多层 e-prop 可复用**（`research/eprop/README.md` 写死「只有一个隐藏层…多层堆叠尚未实现」），实现约半天 |

| P1 结果 | 参数动作 |
| :--- | :--- |
| **P1-1 过** | **D2 = +1 层 LIF**（`w12`=N×N；每层自己的 v/z/不应期/资格痕迹；信号经 `w12` 对称回传）。判据 **D2−D1 ≥ +3pp** 才算深度是杠杆；≤ +1pp 转宽度 |
| **P1-2** | **不加参数**——问题不在容量 |
| 中间带 | 不加参数，先查明"为什么没迁移" |

**参数必须跟着数据涨**：深度若有效，下一步是"深度 × 数据"（1.57M → 6M 字），
**数据翻倍之前不加第二层以上、不加宽**。

## 不做的事

- 不加注意力（全局、二次复杂度，破坏局部规则与 O(N) 叙事）；
- 不在 τ 轴上继续加（R11 已关闭）；
- P1 出数前不动模型结构。

## 边界

- 单折（官方 test，4,868 对）、单种子；
- 测试集 token 数会随结果报出（统计噪声）；
- 字符级；**不代表能聊**；本轮只回答"公开语料上单层落后 bigram 多少"。
