# 预注册 v17：幂律（无标度）接线 —— 分形那条路的第一步

**写于** 2026-11-16，**在任何一档跑之前**。

## 用户的方向

> 「神经元的自发生，这在分形上显然可行。」

分形的两条结构性性质正好对着我们的两个问题：

| 性质 | 对我们意味着 |
| :--- | :--- |
| **自相似** | 生长廉价 —— 新单元插进同一条局部规则（**神经发生**需要这个） |
| **无标度** | **对随机节点失效鲁棒**（Albert–Jeong–Barabási 2000） |

而我们的 **50% 随机损伤正是"随机失效"**。

## 但现在的接线不是无标度的

```
w ∝ exp(−d/λ)      指数衰减 ⇒ 有特征尺度 λ ⇒ 不是分形
```

**这一轮先测最便宜的那一半：把指数换成幂律。**

```
w ∝ d^(−α)          α ∈ {1, 2, 3}，候选窗内归一
```

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **S-0** | `exp` 与 `power` 在完整网络都能工作（`n_viable > 0`） | 不过 ⇒ 作废 |
| **S-1 无标度更抗损伤** | 最好的 `power` 的**损伤 `n_viable` > `exp` 的** | **本轮核心** |
| **S-2 剂量–反应** | 损伤 `n_viable` 随 `α` 变化（不是无关） | 趋势 |
| — | `exp` 基线：完整 2 / 损伤 7 | — |

## 神经发生是下一步，不是这一轮

它需要**可生长的表示**（固定尺寸张量加不了神经元）。
所以顺序是：**先验证幂律接线有没有用，再谈加神经元。**

## 不做的事

- 不加神经元（本轮只换接线统计）；
- 不改读出与任务；
- **不声称任何超出本轮的结论**。
