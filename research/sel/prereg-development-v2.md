# 预注册 v2：能量进入痕迹（让内部量塑造结构）

**写于** 2026-11-16，在 v1 之后、**本轮任何一档跑之前**。
v1（`prereg-development-v1.md`）的结果：**D-0 不过 ⇒ 作废**，但留下四条信息：

- 活动依赖修剪 **−0.2pp**（不优于随机）；
- **去掉 75% 突触能力不掉**（0.233 vs noprune 0.237）；
- 结构两两 **Jaccard = 0.002**（完全由种子决定）；
- 发育期开代谢 **3/3 种子更差** 1.9pp。

## 为什么 v1 失败：通路不对

v1 里 `E` 只改**阈值**（放电率），而修剪看的是**共活动痕迹**。两条通路不相交，
所以 `E` 当然塑造不了结构。

**v2 把能量直接放进痕迹**：

```
s  ←  λ·s + mean_b( z_post · z_pre · E_post )
```

生物学解释：**突触由后突触神经元供养**。一个供不起自己突触的神经元，其突触竞争不过别人。
这就是资源竞争，不是外加的规则。
