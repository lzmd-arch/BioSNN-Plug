# 预注册附录：R8 延到 16,000 步（2026-11-08）

**状态：判据先落盘。R8 主轮的判据（R8-0/1/2/3）不动，本文件只加一条延续实验。**

## 理由

R8 在 8,000 步的 top-1 是 **0.1044**，四个评测点单调上升（0.0895 → 0.0983 → 0.1011 → 0.1044），
**"还没见顶"目前只是形状观察，没有终点**。把同一配置延到 **16,000 步**，与 R0b 大折的 x 轴对齐，
图可以直接并排，也让规则③ v2 的"top-1 平台"判定有足够的点。

## 设计

R8 的配置逐字不变（真语料大折、N=1,024、`tau=20`、读出 τ ∈ {2,8,32,128}、种子 0），
只把 `updates` 从 8,000 改成 **16,000**，`--eval-every 2000`。

## 判据

| # | 门槛 | 判什么 |
| :--- | :--- | :--- |
| **R8a-0** | 跑完；`updates=16000`、`readout_dims=4096` 入档 | 实验无效 |
| **R8a-1** | `Δ(16k) ≥ −7.12pp`（与 R8-1 同门槛） | **8,000 步的结论在 16,000 步仍成立** |
| **R8a-2** | `top-1(16k) > top-1(8k)` | "未见顶"成立；否则**封顶**，并报峰值步数 |
| **R8a-3** | `Δ(16k) − Δ(8k) ≥ +1pp` | 延长有实质收益；否则"延长"到此为止 |

**8,000 步的结论（R8-1 过，+3.88pp）不因延长而改变**——延长只回答"还会不会涨"和"峰值在哪"。

## 预期

押 **R8a-2 成立、R8a-3 不成立**：top-1 还会涨 1～2pp，但涨幅 <1pp 的实质门槛，
即"延长有方向、没有量级"。理由：R8 的 test CE 从 2,000 步起就在升（5.743 → 6.258），
已经进入过拟合段，top-1 的上涨是"argmax 排序"的继续改善，不是学到了更多。

## 边界

- 单折、单种子、13 对测试；
- 与 R8 同一语料、同一折、同一种子，**可直接并排到同一张图**；
- 字符级 next-token，**不代表能闲聊**。

## 成本

16,000 updates × 192 步，读出 4 倍宽 ≈ **2 小时**。
