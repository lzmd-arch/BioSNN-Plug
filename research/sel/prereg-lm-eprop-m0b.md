# 预注册：M0b——把隐藏层真正训起来，再问一次（2026-11-06）

**状态：判据先落盘，代码未跑。** 本文件修订 [`prereg-lm-eprop.md`](prereg-lm-eprop.md)（M0）。

## M0 为什么不算数

M0 不通过，但它**没有测到它要测的东西**。诊断（`sweep_results/lm_eprop_m0/README.md`）：

| 300 步后的相对变化 | learned | frozen |
| :--- | ---: | ---: |
| `w_in` | 0.082% | 0.082% |
| `w_rec` | 0.070% | 0.000% |
| `w_out` | **179%** | 179% |

读出动了 179%，隐藏层只动了 0.07%——**那一轮实际训的是"固定随机脉冲储层 + 局部规则训的线性读出"**。
M0-2（"循环权重真的在学"）拿 0.07% 去比 0%，当然没有差别。

**这是 M0 预注册的设计缺陷：隐藏层学习率比读出的 NLMS 有效步长小三个数量级。**

## 唯一的改动

**只改学习率，其它一律不动**（N=1024、τ=20、τ_read=8、输入 std 0.12、L=64、B=16、2,000 updates、种子 0）：

| 参数 | M0 | **M0b** |
| :--- | ---: | ---: |
| `lr_in` | 2e-4 | **1e-3**（5×） |
| `lr_rec` | 1e-4 | **1e-3**（10×） |
| `lr_out`（NLMS） | 0.5 | 0.5（不变） |

压缩比取 5–10× 是为了让 `w_rec` 的相对变化从 0.07% 抬到 **≥5%** 的量级；**不扫描**。

**M0b-0 是这一轮的全部意义。** M0 的教训是：前置不达标时，后面的"不过"什么都不能说明。

## 预期

**押 M0b-0 过、M0b-3 过；M0b-1 不确定、M0b-2 不确定。**

- `w_rec` 相对变化：预期 5–20%；
- top-1：预期 **0.60–0.80**（M0 是 0.540，bigram 0.646）；
- CE：预期 **1.2–1.8**。

若 M0b-0 过而 M0b-1 不过，那就是一个**干净的负结果**：在 1,024 神经元、2,000 updates、
301 条模板语料这个工作点上，逐时刻局部学习赢不了二阶 bigram。**那才配叫"局部学习学不到字符统计"。**

## 不做的事

- 不调 τ、不加抽头、不加区、不改块长、不换种子；
- M0b-0 不过时**不调大学习率重跑**——那会变成"一直调到动为止"，是另一种调参；
- 不改 M0 的结论：M0 仍是不通过，本文件只是补一个能测到问题的实验。

## 边界

- 单种子；测试集 46 条 / 1,369 字符（top-1 的 SE ≈0.9pp）；
- 语料是模板化单轮 SIR，不是对话；M0b 即便通过也**不代表能闲聊**；
- 学习率放大 10 倍可能带来不稳定；若 CE 发散，按"实验无效"处理，不调小重跑。
