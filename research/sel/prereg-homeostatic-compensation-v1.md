# 预注册 v9：稳态补偿 —— M5（再生）的第一个可测形式

**写于** 2026-11-16，在 v8 之后、**本轮任何一档跑之前**。

## v8 测出的两件事

1. **少 25% 神经元，活动塌两个数量级**（0.081 → 0.004）——
   工作点离**自持放电的临界点很近**；
2. 上一轮的"稳健"是假的：网络静默了，残留的 0.71 准确率是线索注入的回声。

## 生物学对照

神经元损伤后会**上调兴奋性**来维持活动（homeostatic plasticity / 稳态可塑性）。
这是 M5「再生」在细胞层面最基本的形式，而且**它本身就是一个生物机制**，不是外加规则。

**本轮把补偿当自变量。**

## 设计

固定在 `sheet` 接线上（两套接线的比较已连续三次为零，不在本轮重复）。

| 条件 | 损伤后 | 含义 |
| :--- | :--- | :--- |
| `nocomp` | 输入尺度保持完整时的值 | 无补偿（v8 的行为） |
| `comp` | **重新标定输入尺度，使发放回到 0.08** | 稳态补偿 |

损伤水平：**25% / 50%**（0% 作为共同基线）。

**补偿的实现是"全局输入增益"** —— 这是真实稳态机制（逐神经元阈值/兴奋性调整）的**粗糙替身**，
必须在限定里写明。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **C-0** | 0% 损伤：峰值 ≥ 底板 + 10pp，发放在 [0.03, 0.20] | 不过 ⇒ 作废 |
| **C-1 补偿有效** | `comp` 在 25% 与 50% 的发放都回到 [0.03, 0.20] | 机制成立 |
| **C-2 补偿能救回能力** | `comp` 在 50% 的峰值 ≥ 底板 + 10pp | 功能恢复 |
| **C-3 补偿确实做功** | `comp − nocomp` 在 **50% 损伤**时 **6/6 种子**同号 | **本轮核心** |
| — | 效应量与逐档数字照报 | — |

**C-3 是 M5 的定义性判据**：它问的是"**系统自己的调节机制有没有把功能救回来**"。
若成立 ⇒ 这是本项目第一次测到"内部调节 → 功能恢复"的因果链。

## 若 C-3 不过

⇒ 补偿只改了活动水平，没改能力（与 v4 的 η 一致）。
照实记，**不改 6/6**。

## 不做的事

- 不加可学参数（补偿是标定，不是学习）；
- 不改读出与任务；
- **不声称任何超出本轮的结论** —— 真正的"再生"（损伤后慢慢长回来）需要可塑性，本轮没有。

## amend1：加 sham 对照（在看到 C-3 之后）

**为什么要加**：补偿后准确率随损伤**上升**（0.808 → 0.889 → **0.971**）。
这不正常，而且有一个显而易见的解释：

> 死亡神经元的读出特征恒为零 ⇒ **有效特征维数从 8192 降到 4096**
> ⇒ 同样的 1536 个训练样本下，MLP **过拟合更少**。

这不是"损伤让网络变强"，是**读出的容量变了**。

### 控制

`sham`：**网络完好**（照常放电），但把**同样那些神经元**的读出特征置零。
只改读出、不改动力学。

| 条件 | 网络 | 读出 | 作用 |
| :--- | :--- | :--- | :--- |
| `nocomp` | 损伤 | 损伤 | v8 的行为 |
| `comp` | 损伤 + 补偿 | 损伤 | 主臂 |
| **`sham`** | **完好** | **同样这些位置置零** | **分离"读出容量"与"网络损伤"** |

### 判读规则（写在跑之前）

- 若 `sham` 也随"损伤比例"上升到 ~0.97 ⇒ **补偿带来的收益全部是读出容量造成的**，
  C-3 的数字不能解释为"功能恢复"；
- 若 `sham` 停留在 0.81 附近 ⇒ 收益来自网络本身，C-3 成立。

**C-1/C-2/C-3 的字面判定不变**；这一条只是给 C-3 的数字一个可解释的前提。

## amend2：发放必须按**存活神经元**求平均

### sham 的结论

| 条件 | 0% | 25% | 50% |
| :--- | ---: | ---: | ---: |
| `nocomp` | 0.808 | 0.789 | 0.710 |
| `comp` | 0.808 | 0.889 | 0.971 |
| **`sham`**（网络完好、只遮读出） | 0.808 | 0.784 | **0.707** |

**sham 不升** ⇒ 读出容量的解释被**排除**，`comp` 的上升来自网络。

### 但还有第二个混淆

`z.mean()` 对**全部 N** 求平均，而死亡神经元恒为零。
所以"把发放标定到 0.081"实际是让**存活的 50% 神经元放电到 ~0.16**（两倍）。
⇒ 那个 +26pp 是「**活动更多**」，不是「**补偿**」。

### 改法（度量修正，判据不变）

发放一律按 `z.sum() / alive.sum()` 计算 —— **每存活神经元的平均发放**。
这样"标定到 0.08"在损伤前后是同一个含义。

**C-0…C-3 一个字不改**，重跑。
