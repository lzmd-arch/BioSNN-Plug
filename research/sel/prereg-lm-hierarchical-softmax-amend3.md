# 预注册修正 3：把树统计对齐到 H-1 臂的真实词表（2026-11-11）

**amend2 统计时用了 `--max-vocab 0`（V=3,609），而 H-1 的对照臂用的是 `--max-vocab 3000`
（V=3,001）。方向与结论都不变，但数字要以本文为准。**

| 量 | amend2（V=3,609） | **本文（V=3,001，H-1 同款）** |
| :--- | ---: | ---: |
| 加权深度（训练成本） | 8.34 | **8.34** |
| 不加权深度（评测成本） | 16.11 | **15.18** |
| 最深 | 22 | **20** |
| B=256 的训练倍数 | 1.69x | **1.41x** |
| 评测慢几倍 | 16.1x | **15.2x** |
| 打平 V | 2,136 | **2,134** |
| 3x 所需 V | 6,407 | **6,403** |

**唯一实质变化：H-1 臂上树比稠密**只快 1.41x，不是 1.69x。1.4x 的量级对质量判定毫无帮助，
所以 H-1 **只判质量**这一条不变；H-2 仍然只在 V=32,000 的形状上判。

（加权深度在两种词表下都是 8.34 —— 被截断掉的是 608 个稀有字，它们本来就落在最深的路径上，
对按频次加权的期望几乎无贡献。这一点反过来验证了「两个深度必须分开报」。）
