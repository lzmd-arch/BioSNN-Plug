# 多池 + 生物合理的脑区特化与激素调控（设计）

**依据**：2026-11-14 在传感器池上验证了一个可复现的机制——
**独立神经元池 + 合适的驱动尺度 + 池内探针** ⇒ 0.109 → 0.306（+19.7pp）。
本文件把同一机制推广到另外四种量，并把"脑区特化 / 激素"从工程比喻改成有生理对应的设计。

## 一、四个新池

| 池 | 驱动量 | 已有的证据 |
| :--- | :--- | :--- |
| **时间 / 节奏** | 输入间隔 → 空步数 | 同 token 序列插空步，状态差 1.78/3.99；节奏可解码 AUC 1.000 |
| **记忆** | 检索命中向量的投影 | 天然与文本正交（记忆是外部库） |
| **人格状态** | 跨会话累积 | 这正是"人格核"要的形状：独立、持续、有界 |
| **在场 / 输入速率** | 打字节奏、停顿、会话间隔 | 千问结构上拿不到 |

**每个池的三条硬要求**（缺一条退回随机）：
1. 独立神经元，别的模态写不进来；
2. 驱动尺度落在**静默与饱和之间**（传感器池实测 θ=0.62 时约 1.0）；
3. 探针**只看该池**——全特征会被恒定维稀释。

## 二、脑区特化：从"分区"改成"有生理意义的异质性"

今天的"分区"只是把神经元切成互不相连的块。**生物上，脑区的区别在于四件事**，
每件都有对应的工程写法：

| 生理事实 | 工程写法 | 为什么必须这样 |
| :--- | :--- | :--- |
| **各区输入统计不同** | 每区只接自己模态的输入（已做） | 共享会淹没（实测） |
| **各区阈值/时间常数不同** | 每区独立的 θ、τ 分布 | 同质网络只有一个"有效时间尺度"；异质才能同时编码快慢 |
| **区之间存在侧抑制** | 区之间的竞争项（WTA 或减法） | 没有竞争，各区会退化成彼此冗余的拷贝 |
| **区有自己的受体表达谱** | 每区一个受体向量 ρ_r ∈ R^d（见 §三） | 全局激素产生**分区**效果的唯一机制 |

**侧抑制是今天缺的那一件**：现在四个池互不相干，等于四个独立的编码器；
生物上它们竞争同一份"注意力"。

## 三、激素：从"标量广播"改成"多路、分时程、可脱敏"

今天用的是一个标量（树信号的均值），或三路激素的加权和。生物上激素有四条性质，
今天一条都没实现：

| 生理事实 | 工程写法 | 现状 |
| :--- | :--- | :--- |
| **多路、各管一件事**（多巴胺=显著性/奖赏；乙酰胆碱=注意/新奇；去甲肾上腺素=唤醒） | `h ∈ R^d`，d≈3–5，分别由不同本地量算 | ◐ 三路已接，但只在标量层加权 |
| **时程不同**（紧张性 tonic 慢、相位性 phasic 快） | 每路自己的衰减 τ：`h_k ← h_k + (x_k − h_k)·Δ/τ_k` | ❌ 没有 |
| **受体分区表达** | `Δw = η·(h·ρ_r)·pre·post`，ρ_r 每区独立 | ❌ 没做（用的全局标量） |
| **受体脱敏**（持续刺激后反应减弱） | `ρ_r ← ρ_r − λ·(h·ρ_r)·ρ_r`，即受体随被激活而钝化 | ❌ 没有 |

**受体脱敏**是这里最值钱的一条：它让"同一个激素反复出现"不再线性放大，
而是趋向饱和——**这正是今天所有调制方案（DFA、三因子、标量激素）都缺的稳定性机制**。
DFA 的范数爆炸（0 → 155）就是没有脱敏的直接后果。

## 四、判据

| # | 判据 |
| :--- | :--- |
| **P-1** | 新池必须复现传感器池的结果：带驱动 vs 不带的 top-1 差 ≥ 10pp |
| **P-2** | 侧抑制加入后，四个池的特征**不再高度相关**（两两余弦 < 0.5） |
| **P-3** | 受体脱敏加入后，调制范数**有界**（不出现 0→155 那类爆炸），且任务指标不降 |
| **P-4** | 全程 `.backward()` 出现 **0 次** |

## 五、不做什么

- 不一次上四个池——**每个池要单独标定驱动尺度**，一起上分不清是哪个在起作用；
- 不引入对比/度量学习目标（那是另一种学习范式，与"纯局部"的前提冲突）。

## 六、已实现：受体脱敏（P-3 的前半）

```
Δsensor_proj = η·(h·ρ)·cov(c, z)
ρ_k ← ρ_k · (1 − λ·|h_k|)_clip[0.05, 1]      λ=0.05
```

**逐路脱敏**：每一路激素按自己的激活强度钝化自己的受体，互不影响。

### 实测（1500 步，`add` 臂）

| 配置 | top-1 |
| :--- | ---: |
| 无脱敏 | **0.306** |
| **有脱敏** | **0.306** |

**任务指标不受影响**——脱敏没有拖累准确性。

### 为什么这条值得留着

它治的是今天反复出现的那个症状：**调制范数无界放大**
（DFA 从 0 炸到 155、训练中 norm 顶到 20 的夹取）。夹取是**工程补丁**，
脱敏是**机制**——它的稳态由激活强度自己决定，不需要外部阈值。

**P-3 的后半（范数有界的定量验证）还没做**：需要在长跑中记录 `‖sensor_proj‖`
的时间序列，看它是否收敛到一个与激活水平相称的稳态，而不是靠 clip 停住。

### P-3 后半：**没通过**——脱敏并没有让范数有界

记录 `‖sensor_proj‖` 每 300 步：

| 步 | λ=0（无脱敏） | λ=0.05（有脱敏） |
| ---: | ---: | ---: |
| 0 | 14.86 | 14.86 |
| 300 | 16.17 | 18.69 |
| 600 | 19.92 | 24.07 |
| 900 | 25.51 | 30.42 |
| 1200 | **32.32** | **37.41** |

**两条都在单调增长，而且加了脱敏之后增长更快。**

⇒ "脱敏提供有界性的机制"这个说法**不成立**。脱敏只改变 `(h·ρ)` 这个标量的组合，
管不到外积的累积；范数的增长来自 `Σ η·(h·ρ)·cov(c,z)` 本身，与受体怎么衰减无关。

### 这说明了什么

要范数有界，需要的是**权重归一化**（每次更新后把 `sensor_proj` 的每个输入通道归一化），
而不是受体层面的机制。**今天没做，也不知道它会不会损害 top-1。**

**诚实记录**：这条修法是我基于"生物上有脱敏"推的，实测方向错了。又一次
"机制听起来对、实测不成立"。

### 突触缩放：实现了，但在当前参数下**是恒等映射**

```
ratio_j = (target_rate / rate_j)^α       target_rate = 0.1
w[:, j] *= ratio_j
```

| α | 范数轨迹（每 300 步） |
| ---: | :--- |
| 0.0 | 14.86 → 16.17 → 19.92 → 25.51 |
| **1.0** | **14.86 → 16.17 → 19.93 → 25.51** |

**两条完全相同。**

原因：`target_rate = 0.1` 恰好约等于传感器池的实际平均发放率（0–0.375，批均值 ~0.1）
⇒ `ratio ≈ 1` ⇒ 缩放是**恒等**。

### 这说明的是同一件事，而不是新的一件事

**"有设定点"不等于"设定点会起作用"。** 设定点必须与当前工作点**有差**，负反馈才有量。
今天已经是第三次这类失败：

| 修法 | 为什么没用 |
| :--- | :--- |
| 受体脱敏（固定 λ） | 单向衰减，管不到外积累积 |
| 突触缩放（target 0.1） | 设定点 ≈ 工作点 ⇒ 恒等 |
| clip 到 20 | 是补丁，不是机制 |

**共同点：机制的名字对了，参数/方向没对上系统当前的状态。**

### 真正要绑住范数，得先回答一个问题

**范数应该是多少？** 现在没有任何依据说 `‖sensor_proj‖` 该停在哪个值——
所以 clip 只能拍一个数，缩放也只能拍一个 target。

正确的顺序是：**先测出"top-1 对范数不敏感的区间"**（扫 clip 上限 5/10/20/40 看 top-1），
再让机制去维持那个区间内的一个点。**没有这个测量，任何"有界"都只是阈值挑得好不好。**
