# P3 预注册：教师数据（Phase 1 当教师）

**日期**：2026-11-03
**父计划**：SEL-001 分阶段方案（P2 教师未达标）；ADR-0032。
**为什么要这一份**：P2 的混合渲染教师 T4 不过（0.5B 0.88×、1.5B 0.76×、3B 0.99×，
预注册要求 ≤0.5×）。用户拍板：**3B 不行就降级用 Phase 1 当教师**。所以本文件把
"教师是谁、数据怎么来、什么算可用"先写死，再生成数据。

## 教师

- Phase 1：`ExpressionLayer`（SIR + 本机小模型渲染 + 事实核对）；
- 模型：`qwen2.5-0.5b-instruct-q4_k_m.gguf`（CPU，`gpu_layers=0`）；
- 采样：`temperature=0.7`、`max_tokens=160`、`think=None`（该后端自带模板参数）；
- **不是 Phase 2**：模板优先不参与教师（`template_first` 关）。

## 数据

- **400 条 SIR**：5 意图 × 3 语气 × 2 长度 × 一组**虚构**话题/事实；不取任何用户会话
  正文，不碰记忆库。
- 每条 SIR 带 1–2 个要点；约 1/4 带一个事实（数字或 URL），用于事实保真筛查。
- 教师文本由 Phase 1 生成；**过滤**：`source == "styled"` 且 `facts_preserved` 全过；
  按正文去重。
- 切分：按 `sir_id` 的 sha256 排序，320/40/40（训练/验证/测试）；**同一 sir_id 不跨集**。

## 判据（写死）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| D1 | 可用配对数（过滤+去重后） | ≥ 300 |
| D2 | 教师的 styled 比例 | ≥ 70%（否则教师自己都多数退回草稿） |
| D3 | 多样性：不同正文数 / 配对数；单条最高重复占比 | ≥ 0.85；≤ 5% |
| D4 | 切分无重叠 | 0 条重叠 |

任一条不过：不写进 P4，先报告并修数据生成；**不调教师温度去凑数**（温度是预注册的）。

  教师模型名、生成时间）；**不入库**，仓库里只放脚本与本预注册。
- 脚本：`research/sel/gen_data.py`（拒绝把 `--out` 写进仓库根目录）。
- 报告：`research/sel/README.md` 记一次运行的计数与判据判定。
