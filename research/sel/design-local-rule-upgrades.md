# 局部规则升级：外部参照与四条可动的刀（2026-11-11）

**性质**：设计笔记，**不是预注册**。具体判据在各 `prereg-lm-*.md` 里。

## 为什么去找外部

今天量到的账：KdConv 上局部规则 **0.3090**、同数据同预算的 GRU-BP **0.5318**。
**22.8pp** 的缺口里，数据已由 B0 排除（同数据 BP 照样拿 24pp），剩下规则与架构。
而检索结果里**没有任何一篇用局部规则训出语言模型**——这一格是空的，没有前人可抄。
但**别的格子里有**：有人在分类任务上把全局部规则做到只差 BPTT 1.4pp。

## 参照一：Traces Propagation（TP）——**时间侧最该抄的一篇**

Pes, Yin, Stuijk, Corradi. *Neuromorphic Computing and Engineering* 6(1):014002 (2026).
[arXiv:2509.13053](https://arxiv.org/abs/2509.13053v1)

| 项 | TP | 我们 |
| :--- | :--- | :--- |
| 学习信号 | 跨样本**对比**（softmax over 痕迹相似度），需 batch ≥ 2 | 逐样本 CE 的局部分量 |
| 痕迹 | **每神经元**两条：`ε = βε + s`、`ε̃ = βε̃ + s̃`（目标侧） | `eps_in` 按词表逐突触、`eps_rec` 每神经元 |
| **衰减 β** | **每层独立超参**：SHD 递归 0.85 / 前馈 0.96 / DVS-CIFAR10 0.18 | **等于膜 α = 0.951，写死在推导里** |
| 空间侧 | 层间对比损失，**不需要**辅助投影矩阵 | 单层，不适用 |
| 结果 | SHD 递归 LIF：**81.80% vs BPTT 83.23%** | — |

**可动的刀（S7）**：把资格痕迹的 β 从 α 解耦。**已实现并写预注册**
（[`prereg-lm-s7-trace-window.md`](prereg-lm-s7-trace-window.md)），
关键是**必须同时跑"幅度补偿"控制臂**——β 从 0.951 抬到 0.99 等于把 lr_in 放大 5 倍。

**不抄的部分**：TP 的对比损失要 batch ≥ 2 且是跨样本的，与我们的在线逐 token 语义冲突；
单层也没有层间损失可用。

## 参照二：结构化递归 + 固定长程连接

*Scalable Learning in Structured Recurrent SNNs without Backpropagation*，
[arXiv:2605.00402](https://arxiv.org/abs/2605.00402)（2026-05，**只读了摘要**）

机制：局部稠密递推 + **稀疏小世界长程投影到读出**，长程连接**基本固定不训**；
三因子可塑性 + 群体 WTA 教学 + **固定随机广播对齐反馈**。

**对我们的启发**：我们 S0 试过"冻结**稠密随机**循环"（失败，2.16 倍电流比）。
这篇不是"不训"，是**按结构不训**——短程训、长程固定。两者不是一回事。
**这是 S8 的候选**，但代价高（要改连接结构），**排在 S7 之后**。

## 参照三：自适应反馈（adaptive e-prop）

Bellec 组的标准做法：反馈权重 `B_fb` 随即机初始化，之后与 `W_out` **同步更新 + L2 衰减**。
我们现在用**对称真反馈 `w_out.T`**，而读出是 NLMS `lr=0.5`、**每步大改** ⇒ 反馈矩阵一直在跳。
**低成本可测**：给反馈单独一条慢速更新的副本。

## 参照四：外部标尺（不是算法，是审计）

**NeuroTrain**（[arXiv:2605.15058](https://arxiv.org/html/2605.15058v1)，2026）——
基于 snnTorch 的**局部学习规则开放基准框架**。
摘要里**没有给仓库地址**（只说是 snnTorch-based、开源），需要拉全文或检索作者仓库。

**为什么这条最重要**：我们所有"−1.3pp / +0.62pp"都是**内部相对比较**。
接上它，才有"我们的规则在同行里排第几"的**外部锚点**。**不依赖任何判决实验。**

## 参照五：速度侧（暂不动）

**PSN**（Parallel Spiking Neuron，NeurIPS 2023）：去掉 reset 与泄漏时序依赖，T=64 时比串行 LIF 快 43.8×。
**但它去掉 reset，与"膜电位即工作记忆"的叙事直接冲突** ⇒ 只在算力再次成为瓶颈时考虑。

## 不适用 / 要避开的

- **SpikeLM / QSLM 一类"脉冲 LLM"**：仍是 BPTT + 代理梯度，**不是**局部规则，不能作为我们的对照；
- **Forward-Forward**：需要两次前向，与在线逐 token 冲突；
- **候选剪枝、事件驱动稀疏、自定义内核**：本项目已各自实测为负，不再回头。

## 排序

| 序 | 动作 | 依赖 | 成本 |
