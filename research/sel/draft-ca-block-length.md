# 草案（**不是预注册**）：CA——块长扫描（局部 ↔ 全局插值）

**状态：草案，等审。** 审过之后再写成 `prereg-lm-r12-ca-block-length.md` 并落盘。
**为什么先给草案**：这是本轮之后最贵的一跑（要新写一份 BPTT 训练器），判据一旦落进中间带就白烧。

## 问题

R8 之后，真语料上残余缺口 **5.41pp**（局部规则 −6.24pp vs BP 对照组 −0.83pp）。
R3/R4/R5/R6q/R8/R9/R10 已经把**训练侧、读出侧、数据侧**的账都结清了——
**剩下的唯一候选是信用分配（credit assignment）本身。**

局部规则与 BP 的差别可以压缩成一个旋钮：**截断长度 B**。

- **B = 1**：只用当前时刻的损失梯度（无跨时间信用）；
- **B = 192**：整条序列的 BPTT（与 B0 的 GRU 同等深度）；
- **B 在中间**：块内反向传播、块间只传状态（truncated BPTT）。

**这就是一条天然的剂量–反应曲线**，而且它正好接上本项目"用剂量曲线判机制"的一贯做法。

## 设计（草案，待审）

### 臂

| 臂 | 信用分配 | 说明 |
| :--- | :--- | :--- |
| **L（基线）** | e-prop（现有 `TokenEProp`） | 已有：R8 的峰值 Δ = **−6.24pp** |
| **B8** | 块内 BPTT，B = 8 | |
| **B32** | 块内 BPTT，B = 32 | |
| **B192** | 整条序列 BPTT，B = 192 | 与 B0 的 GRU 同深度 |

**四个臂同语料、同分词、同预算、同读出**：真语料大折、8,000 步、每 2,000 评测、N=1,024、
`max_len=192`、种子 0，**读出统一用 R8 的 4 个 τ（4,096 维）**——
因为要测的是"在**当前最好的局部配置**上，信用分配还能买多少"。

### 实现要求（这是本轮的主要工作量）

1. **替代梯度**：脉冲的阶跃函数用 `psi = dampening/threshold * clamp(1-|v/θ-1|, 0, 1)` 的同一形状做伪导数
   （与 e-prop 的 `psi` 逐字相同，保证两臂的"神经元模型"一致）；
2. **块间状态结转**：`v, z, refractory, readout` 跨块传递，**梯度不跨块**；
3. **同样的输入/读出**：`w_in` 稀疏 fan-in 32、NLMS 读出换成可微读出（**这是必须改的**：
   现在的 NLMS 是手写更新，BPTT 臂要用 `nn.Linear` + 优化器）；
4. **守卫测试**：B=192 时的参数量、前向数值与 e-prop 臂在同一初始权重下**逐步一致**（只差梯度）。

> ⚠️ **第 3 条是本草案里最需要你拍板的**：NLMS 读出是局部规则的一部分，BPTT 臂若换成 Adam + `nn.Linear`，
> 就把**读出规则**也一起改了——CA 的效应会和读出优化的效应混在一起。两个选项：
> **(a)** 读出也换成可微的、两臂都用 Adam（干净，但改变了 R8 的读出规则）；
> **(b)** 读出保持 NLMS（局部），只让**隐藏层**用 BPTT（保留读出规则，但实现别扭——NLMS 的梯度流不经过 BPTT）。
> **我倾向 (a)，并在预注册里写明"读出规则随臂改变"这条代价。**

### 数据与预算

- 8,000 步（与 R8 的峰值点对齐）；若 B192 明显更好，再按需延长（**要另写 amend**）；
- 单折、单种子（与 R8 同折），噪声 ±0.6–0.9pp。

## 判据（草案，待审）

设 `改善(B) = Δ(B) − Δ(L)`，其中 `Δ(L) = −6.24pp`（R8 峰值）。

| # | 门槛 | 判什么 | 后果 |
| :--- | :--- | :--- | :--- |
| **CA-0** | 四臂跑完；守卫测试通过；**CE 与 top-1 同报**；按规则③ v3 报峰值 | — | 实验无效 |
| **CA-1** | `改善(B192) ≥ +3pp`（Δ ≥ −3.24pp） | **CA 有牙**：5.41pp 主要就是信用分配 | 进入"块长 × 数据/读出"的下一层 |
| **CA-2** | `+1pp ≤ 改善(B192) < +3pp` | **部分** | 报曲线；**这是中间带，草案里必须设计成尽量不落进来** |
| **CA-3** | `改善(B192) ≤ +1pp` | **CA 没牙** | 5.41pp 的归因要重写——不是信用分配，那是什么？ |
| **CA-4** | 单调性：`Δ(B)` 随 B 单调不降 | 剂量–反应成立 | 若不单调，说明块长不是有效旋钮，`CA-1/3` 的判读要打折 |

### 怎么避免落进中间带（草案里要写死的设计）

中间带（+1 ～ +3pp）之所以危险，是因为它既不能说"CA 有牙"也不能说"没牙"。
两个预防：

1. **预期效应很大**：若 CA 是真瓶颈，B=192 应当接近 B0 的 −0.83pp（差距 −6.24 → −0.83 = **5.41pp**），
   即 `改善 ≈ +5pp`，远在中间带之上。**如果只拿到 +1 ～ +3pp，那本身就是"CA 只解释了一小半"的结论**，
   应写成 CA-2 而不是失败；
2. **先跑 B192 一个臂**（最贵的判据点），若它 ≥ +3pp 再补 B8/B32 画曲线；
   若它 ≤ +1pp，直接判 CA-3，省掉两个中间臂。**顺序执行，节省 2/3 的算力**。
