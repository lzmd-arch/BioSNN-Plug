# 预注册 v24：M6 内源驱动 —— 起搏神经元带来的自发行为

**写于** 2026-11-16，**在任何一档跑之前**。

## 为什么是这一步

R-STDP 的结论是：**第三因子必须提供 STDP 看不到的东西**。
而"系统自己产生行为"正是那样一个东西 —— 一个**内部的、由自身动力学产生的**信号。

**生物学依据**：起搏神经元真实存在（丘脑 relay 细胞、多巴胺能神经元、
下橄榄核），它们**不需要突触输入就能放电**。

## 机制

给比例为 `p` 的神经元一个**持续性去极化电流** `I_pace`：

```
cur_i += I_pace · pace_i        pace_i ∈ {0,1}，随机选 p 的比例
```

之后**输入全零**，看系统还能不能产生活动。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **M6-1 自发活动存在** | 零输入时，某个 `p` 的发放 ∈ **[0.01, 0.20]** | 不过 ⇒ 作废 |
| **M6-2 不是均匀的** | 神经元之间的发放**标准差 > 0.5 × 均值** | 结构化，不是全一起 |
| **M6-3 带自己的历史** ★ | 两个不同历史的实例，零输入下的自发模式**比值 > 1.5 且 10/10** | **本轮核心** |

**M6-3 是定义性判据**：它问的是"**没人问它的时候，它做的事是不是它自己的**"。

对照与 M7 相同：**统计相同、随机不同的两条历史**。

## 与 M7 的差别

| | M7 | M6 |
| :--- | :--- | :--- |
| 什么时候测 | **有探针输入** | **零输入** |
| 测什么 | 对同一输入的响应差异 | **它自己产生什么** |

⇒ **M6 比 M7 强**：M7 的差异可以被"输入驱动"解释，**M6 没有输入可推诿**。
