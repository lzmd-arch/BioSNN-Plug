# 预注册：R5——膜时间常数（2026-11-07）

**状态：判据先落盘。**

## 理由

前馈 LIF 的**全部记忆就是膜电位 v**，`tau=20`（α=0.9512）意味着 ~20 步的窗口。
而真语料每对中位 **69 字**、p90 **269 字**，`MAX_LEN=192` 还会截掉 17.7% 的序列——
**模型能看到的上下文远短于序列本身**。

R0b 在真文本上落后 bigram **10.2 / 11.5pp**，两折都已收敛（CE 比 0.13 / 0.39），
训练侧（R1b 训练量、R2 数据量）都推不动它。**τ 是这条支线从没动过的唯一一个"记忆长度"旋钮。**

## 设计（跑之前定死）

| 项 | 基线（R0b 大折） | **R5** |
| :--- | :--- | :--- |
| 语料 | `D:/AxoData/sel/lm/v1/real.jsonl`（真会话 265 对） | 相同 |
| 折 | **大折**（留出 `20261018-154235-861faf`，训练 252 对） | 相同 |
| updates | 16,000 | **8,000** |
| `tau` | 20 | **100**（第一臂）；**500**（条件臂，见下） |
| 其余 | N=1,024、`fan_in=16`、`tau_read=8`、`input_std=0.12`、`lr_in=1e-3`、`lr_out=0.5`、`max_len=192`、种子 0 | **完全相同** |

**基线取自已测的曲线，不重跑**：R0b 大折每 2,000 步评测一次，**第 8,000 步 top-1 = 0.0657**
（test CE 7.240），对 bigram 0.1669 → **Δ(τ=20) = −10.12pp**。
种子与配置逐字相同、训练是确定性的，所以"跑 8,000 步停下"与"16,000 步的第 8,000 步"是同一组权重。

**为什么是 8,000 而不是 16,000**：R0b 的曲线显示 top-1 在 4,000 步见顶（0.0691）、之后缓慢下滑，
CE 从 2,000 步起单调上升。8,000 步已经在过拟合区里，再加倍只买到更差的数字。
选 8,000 是为了把每臂的成本压到 **~1.5 小时**，从而**跑得起两个 τ**。

**为什么是 100 和 500**：α(20)=0.9512、α(100)=0.9900、α(500)=0.9980。
在 p50=69 字的序列上，τ=100 的保留率 0.50、τ=500 是 0.87；在 p90=269 字上分别是 0.07 / 0.58。
**两臂只在长序列上分开**——这是它们不是冗余的理由。

### 发放率（开跑前实测，防止重犯 S0 的错）

真实语料前 32 条、96 步、N=1,024、种子 0、不训练：

| τ | α | 初始发放率 | 初始 CE |
| ---: | ---: | ---: | ---: |
| 20 | 0.9512 | **0.0139** | 6.527 |
| 100 | 0.9900 | **0.0178** | 6.548 |
| 500 | 0.9980 | **0.0185** | 6.550 |

**差 1.28×，不是 S0 那种 7.36× 的量级**，所以主臂**不预先标定** `input_std`；
但**每折都记 `firing_rate` 并写进结果表**（`run_r0.py` 已加），若增益出现再走控制臂（R5-3）。

## 判据

| # | 判据 | 门槛 | 不过时判什么 |
| :--- | :--- | :--- | :--- |
| **R5-0** | 前置：跑通并记录发放率 | 8,000 步跑完；`firing_rate` 写进 JSON | 实验无效 |
| **R5-1** | **记忆长度是杠杆** | `Δ(τ=100) − Δ(τ=20) ≥ +3pp`（即 Δ ≥ −7.12pp） | τ 不是杠杆 → 转 R6（BPE） |
| **R5-2** | 剂量–反应 | 条件臂：`Δ(τ=500) ≥ Δ(τ=100)`（同向，不比幅度） | — |
| **R5-3** | 不是靠更兴奋 | 若 R5-1 过：追加 `τ=100 + input_std` 缩放到把初始发放率标定回 0.0139，该臂 Δ 仍 ≥ −7.12pp | 增益归因于兴奋性，不归因于记忆 |

### 条件执行（写死）

- **R5-1 不过** → **不跑 τ=500**。理由：假设是单调的（更长记忆 → 更好）；
  5 倍的 τ 在 3pp 门槛上失败，25 倍需要非常强的非单调效应才可能翻盘，那种情形不在本轮的假设里。
- **R5-1 过** → 跑 τ=500（同样大折、同样 8,000 步），再按 R5-2 判剂量–反应；然后才跑 R5-3 的控制臂。

## 预期

**押 R5-1 不过**：`Δ(τ=100) − Δ(τ=20)` 落在 **−1 ～ +2pp**。
理由：前馈 LIF 的长时记忆其实是"窗口里输入的加权和"，更像字频统计而不是条件概率建模；
R2 的 +4.49pp（数据 ×5）都没能跨零，靠一个时间常数跨 3pp 门槛不乐观。
**若过 +3pp**，说明记忆长度是此前所有实验的共同瓶颈——那要报告后再决定是否叠加 R4 的读出。

## 不做的事

- 不改 `MAX_LEN`（截断本身是另一个变量）；
- **不叠加 R4 的多尺度读出**（那是另一轮的变量，叠加就分不清）；
- R5-1 不过时不扫 τ=50 / 200（要新预注册）；
- 不用 16,000 步重跑基线（曲线已经给了第 8,000 步的点）。

## 边界

- **单折、单种子**（大折是训练对最多的一折：252 对；另一折只有 118 对训练对）；
- 真实语料只有 265 对，测试集 13 对（大折）——**top-1 的抽样噪声不可忽视**；
- 字符级 next-token，**不代表能闲聊**。

## 成本

每臂：8,000 updates × 192 步 × 252 对语料 ≈ **1.5 小时**（按 R0b 大折 16,000 步 ~3 小时外推）。
τ=100 一臂 1.5 小时；条件臂与 τ=500 再各 1.5 小时。
