# 预注册 v26：M6q 慢增益 —— 让"个体"有一个比窗口更慢的变量

**写于** 2026-11-16 深夜，**在任何一档跑之前**。

## 为什么是这一步

M6p 的判决：**总体有分布，个体没状态**（总体 3.14×，逐个体 1.02×）。

诊断（不是猜的，是把模型里所有状态量的时间常数列出来）：

| 量 | 时间常数 | 相对测量窗（256 步） |
| :--- | ---: | ---: |
| `v` 膜电位 | 20 步（0.95 泄漏） | 1/13 |
| `ref` 不应期 | ~2 步 | 1/128 |
| `gain`（`eta_gain=2`） | ~2 步 | 1/128 |
| `gain`（`eta_gain=0.2`） | ~20 步 | 1/13 |
| `gain`（`eta_gain=-1`） | **不施加、不更新** | — |
| 突触权重 | 不变 | — |

**测量窗从输入停止后第 192 步取到第 255 步。没有任何一个量活得到那里。**
所以"M6 起就没测到个体状态"不是实验设计的问题，是**模型里根本没有那个时间尺度**。

## 改什么（只改一个数）

`eta_gain` 的剂量，把增益时间常数从 ~20 步拉到 ~800 步：

| `eta_gain` | τ（步） | 相对窗口 |
| ---: | ---: | ---: |
| 0.2 | 20 | 1/13 |
| 0.05 | 80 | 1/3 |
| 0.02 | 200 | ≈0.8 |
| 0.01 | 400 | 1.6 |
| 0.005 | 800 | 3.1 |

### 修订 1（**开跑前**）：τ 那一列只是开环估计，不要当数用

`gain` 的更新是 `gain *= exp(eta·(0.08 − f_i))`，每 4 步一次，`f_i` 是 τ=10 的 EMA。
**开环**看它是"滞后 10 步的积分器" —— 它没有泄漏，对历史的记忆是**无界**的。
时间常数只在**闭环**里才有定义：把 `r ≈ r₀·gain` 线性化，得到
`λ² + 0.1λ + 0.002·eta = 0` ⇒ 慢极点 `≈ −0.002·eta/0.1` ⇒ **τ ≈ 50/eta**。

| `eta` | 开环估计 4/eta | 闭环估计 50/eta |
| ---: | ---: | ---: |
| 0.2 | 20 | ~250 |
| 0.05 | 80 | ~1000 |
| 0.02 | 200 | ~2500 |
| 0.01 | 400 | ~5000 |
| 0.005 | 800 | ~10000 |

**两个估计都不精确**（线性化假设 `d r/d log g = r₀`，而实际只有 2% 的神经元有起搏电流）。
所以判据不钉在 τ 的绝对值上：**Q-3 只要求单调**，阶梯跨 40 倍 eta 是设计意图，
不是"某档等于 200 步"这种断言。

**不加新机制，只把已有的那个慢变量的时间常数调对。**

## 判据（口径全部换成**逐个体** —— 这正是 M6p 失败的那一列）

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **Q-0 仪器** | `K=4/g=2/eta=-1` 复现 M6p：总体 **3.14×**、逐个体 **1.02×**（容差 ±0.15 / ±0.05） | 不过 ⇒ 作废 |
| **Q-1 存在** | 后期发放 ∈ **[0.01, 0.20]** | 不过 ⇒ 该档无效 |
| **Q-2 逐个体带历史** ★★ | 逐个体比 **> 1.5 且 ≥ 5/6 种子** | **本轮核心** |
| **Q-3 剂量–反应** ★ | 五个 `eta` 的逐个体比随 τ 增大**单调**（Spearman = 1） | 没有它，Q-2 过了也说明不了机制 |
| **Q-4 状态停住了** | **稳态窗内前 32 vs 后 32** 的池向量距离 **< 逐个体历史距离** | 没有它，Q-2 过了也不知道停没停 |

**Q-2 用逐个体口径**，因为 M6p 已经证明总体均值会给出假阳性（3.14× 对 1.02×）。
**这一轮的预注册里，总体均值只作附注，不进判据。**

## 对照（不变）

历史 A：α=0.5 seed `100+s`；历史 B：α=20.0 seed `100+s`；对照 A'：α=0.5 seed `900+s`。

## 已知未修的混淆（照实记）

**A vs B 同时改了 `pref` 矩阵与输入稀疏度**：`seeded_dirichlet` 用固定的 `PREF_SEED=0`，
所以同 α 的两条历史共享同一个 `pref`。本轮不修 —— 修它要动 `make_task` 的签名，
会把 M6/M7/M6p 全部变不可比。修法留作下一轮。

## 限定

- K=4 固定（M6p 已证 K 的效应是**纯分辨率**，不是机制）；
- `g_inh ∈ {0, 2}`；6 种子；
- 线性谱与非平稳动力学仍是盲区；Q-4 只测"窗口内停没停"，不测更长时间；
- **Q-4 的口径在开跑前改成"稳态窗内前 32 vs 后 32"**：拿自发期最前面的 64 步比，
  测到的是暂态不是平稳性。
