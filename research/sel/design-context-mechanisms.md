# 上下文机制排查清单（2026-11-11）

**为什么写这份**：问"离聊天多远"时，答案不是算力，是**这个结构没有内容寻址的记忆**。
这份清单把"还没试过的上下文机制"排成可执行的最小实验，每一条都写死判据。

## 一、为什么记忆停在 ~128 步——这是结构结论，不是调参问题

读出的特征是 K 个指数滑动平均：

```
f_k(t) = Σ_{s≤t} d_k^(t-s) · z_s,    d_k = exp(-1/τ_k),    τ ∈ {2, 128}
logits = f · W
```

**这是一组线性 IIR 滤波器。** 它能做的是"对过去加权求和"；它**做不到**的是"按内容检索"——
没有 q·k 的匹配，没有"看到 X 时把当时的 Y 取出来"。

于是过去一年的四条延长路，本质都是在**同一个能力边界内加码**：

| 试法 | 结果 | 为什么必然如此 |
| :--- | :--- | :--- |
| 加抽头 4→8（R11） | +0.93pp，判饱和 | EMA 再多也还是平均 |
| 膜 τ 100（R5） | +0.62pp（噪声内），发放率失控 4.7× | 同上 |
| 痕迹长窗 β=0.99（S7） | +0.37pp，幅度对照更差 | 同上 |
| 递推 `w_rec`（S0/S1） | **更差** | 输入侧噪声被放大 |

**四条都不是"没调好"，是"加错了地方"。**

## 二、先造尺子：延迟回忆探针（P）

**没有这把尺子，后面每一条改动都只是"感觉变好了"。**

```
序列 = [A][s][填充 N 步][Q][s]
```

预测 `Q` 的下一个 token 时，模型必须从 **N 步之前**取回 `s`。

- 符号集 32；N 从 {1, 2, 4, …, 1024} 里抽；
- 指标：答案位置的 top-1 准确率 **对 N 的曲线**；
- 训练集与测试集都覆盖全部 N（否则模型会猜 N）。

**判据（写死）**

| # | 判据 | 不满足怎么办 |
| :--- | :--- | :--- |
| **P-0** | 基线在 N=1 上 top-1 ≥ 0.90，且 50% 交叉点落在 τ_read 附近（±1 个档） | 探针本身有问题（编码/位置泄漏），**先修探针，不改模型** |
| **P-1** | 任何机制的达标线：**50% 交叉点至少翻倍** | 该机制判负 |
| **P-2** | 且 N ≤ 8 的点掉 **≤ 1pp** | 是"牺牲近程换远程"，不算赢 |

## 三、五个候选（按"能否用局部规则实现"排序）

### C1 快速权重 / 线性注意力（Hebbian 外积记忆）—— **最看好**

```
M_t = λ·M_{t-1} + φ(k_t)·v_tᵀ        （外积写入，Hebbian）
o_t = M_t · q_t                       （内容寻址读出）
```

- `k_t, v_t, q_t` 由当前输入经**冻结的随机投影**得到（或经 `w_in` 一起学）；
- **O(1) 状态**：`d×d`，d=64 时 4,096 个数，可忽略；
- **每 token 成本** `O(d²)` ≈ 4k MAC —— 比读出便宜**四个数量级**；
- **更新是外积**，正是本项目要的局部规则；不需要反向传播。
- **实验**：把 `o_t` 当作**额外一组特征**拼进读出（不动现有通路）。
- **风险**：线性注意力会数值爆炸，需要分母归一化；λ 太小记不住、太大淹没。

### C2 校准过的 SSM（补做公平检验）

记录里 SSM 的判负带着 **7.36 倍递推/输入电流比**——那是一次不公平的检验。
- **实验**：用 S0 的标定方法把电流比压到 1.0 再跑同样的探针；
- **成本**：半天（代码在 `model.py` 的 `recurrence="ssm"` 分支）。

### C3 稀疏注意力（局部规则版）

每个 token 从过去 W 步里按 q·k 选 top-k 位置，只用这些位置的 `z` 加权。
- 成本 `O(W·d)`；W=256、d=64 时 16k MAC；
- **难点**：q/k 怎么用局部规则学。若答不上来就不做（排除 softmax 注意力）。
- 排序在 C1 之后——**C1 是它的"无 softmax"版本，先看无 softmax 够不够**。

### C4 吸引子工作记忆（Modern Hopfield）

写入用 Hebbian，读出用迭代。成本 `O(迭代数 × N·d)`。
- **风险**：脉冲域里迭代很贵；且和 C1 是同一族（都是联想记忆），**C1 更便宜，先做 C1**。
- 若 C1 判负再考虑。

### C5 门控痕迹（最便宜，当对照）

把 EMA 的固定衰减 `d` 换成**由输入门控**：`d_t = σ(g·x_t)`，即"学出来的选择性遗忘"。
- 成本每 token `O(N)`；
- **仍然没有内容寻址**，所以预期低——但它是唯一半天能做完的，用来确认
  "问题真是缺内容寻址，而不是缺选择性"。
