# 两个人格核能不能组合

**日期**：2026-11-15
**涉及**：V1 的 Transformer 核（Qwen2.5-0.5B 全参微调）与 V0.5 的 SNN 核（0.5B 局部规则）

---

## 一、两个核各自是什么

| | **Transformer 核（V1）** | **SNN 核（V0.5 快半）** |
| :--- | :--- | :--- |
| 结构 | Qwen2.5-0.5B，24 层，词表 151,936 | emb(32000×256) + proj(256×7812)，**7,812 神经元**，2 个时间常数 |
| 学习规则 | 全参反向传播 | **e-prop，局部，无反传** |
| 训练成本 | 241 tok/s | **33.9k tok/s** |
| 语言能力 | 好（能答、能写） | **弱**：top-1 0.110；四测四负 |
| 状态编码 | 无（只有文本） | **强**：池状态解码 0.64–1.0 |
| 身份 | 已在权重里（无锚 8/8） | 无 |

**一句话**：一个会说话但不知道"此刻是什么状态"，一个知道状态但不会说话。

---

## 二、能不能组合：**能，而且机制已经建好了**

组合不是新设计——`research/sel/lm/fusion_model.py` 就是它：

```
SNN 池 p（8–80 维）
      │
      ▼
StateModulator（低秩、无偏置、20.5k 参数）
      │  每层 (scale, shift)
      ▼
Transformer 每层隐藏状态  h ← h·(1+scale) + shift
```

已经实测的三条性质：

| 性质 | 结果 |
| :--- | :--- |
| `p=0`、未训练 | 与原模型**逐位相同** |
| **`p=0`、训练后** | 仍然**逐位相同**（无偏置保证） |
| `p≠0`、训练后 | 输出差 16.8（耦合真实存在） |

**"拆不开"在这里是可执行的**：拿掉 SNN 就没有 `p`，每一层都变。

---

## 三、三种组合形态，只有一种成立

| 形态 | 有没有证据 | 结论 |
| :--- | :--- | :--- |
| **A. 输出分布融合**（两个核各出 token 分布再混） | 四种算子全败 + SNN 四测四负 | **不做** |
| **B. FiLM 状态调制**（SNN 出 p，调制 Transformer 每层） | 骨架已验证三条性质 | **这是要走的那条** |
| **C. 集成/路由**（按问题选一个核回答） | SNN 的语言能力 top-1 0.110 | **没有意义** |

---

## 四、做成还差什么

| # | 事项 | 成本 |
| :--- | :--- | :--- |
| 1 | 把 SNN 的池状态接成 `p`（同一批样本，CPU 上算，可**预计算缓存**） | 小 |
| 2 | 训 `StateModulator`（Transformer 冻结，只有 20.5k 参数要梯度） | 前向仍走 24 层，约与全参同量级 |
| 3 | **判据 I-5/I-6**：`p` 消融后，回答在"记忆事实覆盖 / 状态一致性"上的差 | 需要行为评测 |
| 4 | 打包：两个核约 1.5 GB | 小 |

**关键点**：`p` 是**冻结的 SNN 输出**，可以离线预计算成向量表 ⇒ 训练调制器时不必每次跑 SNN。

---

## 五、它不能给你什么（必须写在前面）

1. **不能让 SNN 变会说话**——它不参与生成，只调"怎么说"；
2. **不改变 token 分布的形状**（加性偏置那条路已死），改的是**每层的增益与偏置**；
3. **身份不来自 SNN**——身份已经在 Transformer 权重里。SNN 提供的是**状态**：
   此刻在场/节奏/记忆命中/人格漂移。

⇒ 分工是：**身份 = Transformer 权重；状态 = SNN 池；表达 = 云端。**

---

## 六、第一个该测的

**I-5**：`p` 消融前后，同一个问题在"记忆事实覆盖"上的差 ≥ +10pp，且**置换检验**通过。

若不过 ⇒ SNN 的池状态对 Transformer 的行为没有可测影响，这条组合线**在这一层就结束**，
不要往下做打包。若过 ⇒ 再谈把 `p` 换成真实传感器/记忆流。
