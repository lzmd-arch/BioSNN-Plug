# 预注册 v4：稳态设定点由代谢史决定（+ 每脉冲能力）

**写于** 2026-11-16，在 v3 之后、**本轮任何一档跑之前**。

## v3 留下的断点

| 环节 | 证据 | 状态 |
| :--- | :--- | :--- |
| M1 内部量自持 | R²(输入→E) = −0.016 | ✅ |
| M2 内部量约束行为 | corr(E, 发放) = −0.990 | ✅ |
| M3 内部量塑造结构 | γ 单调控制 0.895→0.763 | ✅ |
| **结构 → 能力** | 四个 γ 极差 1.5pp | ❌ |

原因很清楚：**修剪只决定"谁留下"，而稳态缩放把活动钉回修剪前同一个设定点**
（`target = rate_before`，对每一档都一样）。结构变了，工作点没变，
读出能拿到的信息也就没变。

## 机制：设定点本身是代谢的函数

```
target_rate  =  rate_before · Ē^η          Ē = 发育期平均能量
w_new        ←  稳态缩放到 target_rate
```

生物学依据：**ATP 敏感的钾通道会改变神经元的活动设定点**；
睡眠剥夺、代谢状态都会移动稳态设定点。设定点不是常数。

`η = 0` 即 v3 的做法（常数设定点）。`η > 0` 时，**代谢史更"穷"的个体
把自己的目标活动调得更低** —— 这是 M2 说的"策略改变"。

## 三档（`γ` 固定为 1，v3 里最好的一档）

| 臂 | `η` | 含义 |
| :--- | ---: | :--- |
| `eta0` | 0 | 常数设定点（v3 的 `g1`，参照） |
| `eta1` | 1 | 设定点 ∝ Ē |
| `eta2` | 2 | 设定点 ∝ Ē² |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **E-0** | 天花板 ≥ 底板 + 20pp；每臂 > 底板；发放在 [0.03, 0.20] | 不过 ⇒ 作废 |
| **E-1 策略改变** | `η>0` 的稳态发放率 **低于** `η=0`，且随 η 单调 | 三个 γ 严格单调 |
| **E-2 能力** | 最好的 η 的 acc ≥ `eta0` + 3pp | 方向不预注册 |
| **E-3 每脉冲能力** | `eff = (acc − 底板) / 发放率`，最好的 η 的 `eff` ≥ `eta0` 的 **1.15 倍** | **本轮的核心** |

**E-3 是这一轮存在的理由。** 准确率看不见的东西，效率可能看得见：
如果系统**用更少的脉冲拿到同等能力**，那才是代谢真正的收益。
这个量在 v1–v3 里一次都没测过。

## 若 E-3 不过

⇒ 让设定点随代谢走，在本设定下也不产生能力/效率收益。
那就照实记"结构 → 能力这一段仍未打通"，**不改 1.15 这条线**。

## 不做的事

- 不加可学参数；
- 不改任务与读出（沿用 `mlp_probe`）；
- **不声称任何超出本轮的结论**。
