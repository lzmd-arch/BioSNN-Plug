## 三个已定事项

1. **读出规则不换**（审阅意见①，采纳）。线性读出的局部梯度就是精确梯度
   （`dL_t/dW_out = δ_t · h_tᵀ` 不依赖其他时间步），e-prop 在这里**没有近似**；
   近似全在隐层——那正是本臂要测的对象。**"读出保持 NLMS、与 R11 逐字相同"是本轮的硬约束**，
   不许在结果不好看时改它。
2. **先跑 B=192 作最大剂量探针**（审阅意见②，采纳），三条路见下。
3. **中间带用预写措辞**（审阅意见③，采纳），见「预写措辞」一节。

## 块边界的操作定义（**本轮新写死的一条**）

审阅意见问"块边界跨不跨序列、会不会泄漏相邻对"。**本实现里不会，因为根本没有拼包**：

- 每一行就是**一对独立对话**（`make_batches` 逐行填、批内行与行之间没有共享状态、也没有梯度通路）；
- 所以 **BPTT 不可能跨行**，"跨序列泄漏"在结构上不存在——除非主动把多对拼进一行，**我们不拼**；
- **但块长会被该行的实际长度截断**：`B=192` 的实际语义是"**整条序列（≤192）**"，不是"跨 5 条对话对"。

**长度分布（真语料 265 对，截断到 `MAX_LEN=192` 之后）**

| | 中位 | 均值 | p10 | p90 |
| :--- | ---: | ---: | ---: | ---: |
| 每对 token 数 | **69** | 90.1 | 25 | 192 |

| B | 实际块长中位 | 被 B 截断的对数占比 |
| ---: | ---: | ---: |
| 6 | 6 | 98.1% |
| 24 | 24 | 90.6% |
| 64 | 64 | 52.1% |
| **192** | **69** | **0%（= 整条序列）** |

⇒ **B=192 与 B=96 对 82% 的对子是同一个实验**。阶梯必须按**实际长度**选：
**{6, 24, 64, 192}**，其中 192 是"整条"，64 覆盖一半对子、24 覆盖不到一成。

## 设计

| 臂 | 信用分配 | 说明 |
| :--- | :--- | :--- |
| **L（基线，已有）** | e-prop（`TokenEProp`） | R11 的**峰值** Δ = **−5.31pp**（8 个 τ、8,192 维读出） |
| **B192（探针，先跑）** | 整条序列 BPTT | 实际块长中位 69 |
| B6 / B24 / B64（按需） | 块内 BPTT | 中间剂量点 |

**共同配置**：真语料大折、8,000 步、每 2,000 评测、N=1,024、`fan_in=32`、`input_std=0.12`、
`tau=20`、`max_len=192`、种子 0、**读出 = 8 个 τ 的 NLMS（与 R11 逐字相同）**。

### 实现约束（写死）

1. **读出规则不变**：`w_out` 仍由 NLMS 更新；反向传播到隐层时把 `w_out` 视为**当步常数**（detach），
   即 `dL/dh_t = w_outᵀ · δ_t`；
2. **替代梯度与 e-prop 同形**：`psi = (dampening/threshold) · clamp(1 − |v/θ − 1|, 0, 1)`——
   两臂的神经元模型逐字相同，唯一的差别是**梯度走多远**；
3. **块间只传状态、不传梯度**：`v, z, refractory, readout` 跨块结转；
4. **守卫测试**：同一初始权重下，B=1 的前向数值与 e-prop 臂逐步一致（容差 0）；B=192 的参数量与 L 臂相同。

## 判据

`改善(B) = Δ(peak, B) − (−5.31pp)`。峰值按规则③ **v3** 取 running max，并注明峰值步数与终点落后峰值多少。

### 探针路径（先只跑 B192）

| B192 的改善 | 判定 | 下一步 |
| :--- | :--- | :--- |
| **≤ +1pp** | **CA 轴关闭**（探针即终审） | 不扫中间块长；按 CA-3 措辞归档 |
| **+1 ～ +2pp** | 不定生死 | **补 B=24 一个点**看单调性，再决定要不要全阶梯 |
| **≥ +2pp** | **CA 有牙** | 全阶梯 {B6, B24, B64}，拿插值曲线 |

### 退出后的判据

| # | 门槛 | 判定 |
| :--- | :--- | :--- |
| **CA-0** | 跑完；守卫测试通过；CE 与 top-1 同报；按 v3 报峰值 | 实验无效 |
| **CA-1** | `改善(B192) ≥ +3pp`（Δ ≥ −2.31pp） | **实质增益** |
| **CA-2** | `+1pp ≤ 改善 < +3pp` | **真实但有限** |
| **CA-3** | `改善 ≤ +1pp` | **与零不可分辨，轴关闭** |
| **CA-4** | `Δ(B)` 随 B 单调不降 | 剂量–反应成立；不单调则 CA-1/3 的判读打折 |

**门槛的统计依据**（审阅意见复核）：噪声 ±0.6–0.9pp ⇒ **+3pp 是 3.3–5σ（够硬）**；
**+1pp 的 kill 线是 1.1–1.7σ，故意放在"宁可错杀"侧**——τ 轴的教训是这类杠杆边际收益递减极快，
CA 若只有 <1pp 的牙口，不值得一个章节。

## 预写措辞（出数前写死，防事后找说法）

| 结果 | 措辞 |
| :--- | :--- |
| **≥ +3pp** | 「信用分配产生实质增益；插值曲线给出局部↔全局连续谱，在块长 **X** 处饱和。」（X 出数后填） |
| **+1 ～ +3pp** | 「CA 有真实但有限的效应：**超出噪声（±0.6–0.9pp），低于实用阈值**；是否继续**由剂量–反应形状决定，不由单点决定**。」 |
| **≤ +1pp** | 「改善**与零不可分辨**；信用分配轴在该语料上关闭。插值曲线（即使平坦）作为**负面结果归档**——它划定的是 e-prop 近似误差的实际代价边界，本身有引用价值。」 |

**两条沿用 R11 的纪律**：说"**与零不可分辨**"而不是"无效"；**单点判据降级为形状判据**。

## 预期

**押 CA-1（≥ +3pp）**：若 CA 是真瓶颈，B192 应接近 BP 对照的 −0.83pp（差距 4.48pp）。
次押 CA-2。理由：本项目从未在**同一架构、同一读出、只改信用分配**的条件下测过这件事，
而 R11 之后所有其他解释都已排除。

## 不做的事

- 不换读出规则、不改神经元模型、不改语料、不改读出 τ；
- B192 不过 +1pp 时不扫中间块长；
- 不做多种子（先看单点；若 CA-1 成立再补）。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp）；
- 8,000 步（与 R11 峰值点对齐），可能有峰值/过冲，按 v3 处理；
- **BPTT 只是"信用分配深度"的一种实现**：若 CA-1 不过，不能断言"信用分配不重要"，
  只能断言"**这种深度**的 BPTT 在这个架构/语料上买不到"；
- 字符级 next-token，**不代表能闲聊**。

## 成本

B192 探针：8,000 步 × 192 步 × 252 对 ≈ **1.7 小时**（按 R11 的 3.3 小时/16,000 步外推）。
全阶梯（仅 CA-1 成立时）：再加 B6/B24/B64 各 1.7 小时 ⇒ **合计最多 ~7 小时**。
