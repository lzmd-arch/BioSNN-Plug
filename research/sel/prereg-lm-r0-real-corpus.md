# 预注册：R0——在真实会话语料上，局部学习还能不能赢 bigram（2026-11-06）

**状态：判据先落盘，代码未写（导出与基线已量）。**

## 已量到的两个数（决定了本轮的口径）

| 语料 | 规模 | bigram top-1 | bigram CE |
| :--- | :--- | ---: | ---: |
| SEL 模板语料（S0–S2） | 391 对 / 11,427 字 | **0.646** | 1.423 |
| **真实会话（本轮）** | **265 对 / 34,183 字 / 34,713 token** | **0.181** | **5.60** |

真实语料由 `research/sel/lm/export_sessions.py` 从 `D:/AxoData/sessions/` 导出
（只取紧邻 user→assistant、非空、非 tool、非 proactive）。六折留一会话的基线如上。

**两条直接后果：**

1. **真语料比模板语料难三倍以上**（bigram 0.646 → 0.181）。所以 S2 的 0.7226 **不能**当本轮的预期——
   那是模板语料上的数；
2. 语料在会话间**极不平衡**：一个会话占 147 对 / 23,245 token，其余五个各 13–59 对、715–6,199 token。
   最小的留一折只有 **715 token**，top-1 的 SE ≈1.5pp。

## 要回答什么

**在真实对话上，逐时刻局部学习（前馈 LIF + 局部读出）能不能超过同语料的字符 bigram？**

注意：**本轮不问"能不能闲聊"**。34k token、1,246 个唯一字、6 个会话，离对话模型还差几个数量级。
本轮只测"局部规则在真文本上是不是仍然有效"。

## 设计（跑之前定死）

- **模型**：与 S2 完全一致——前馈 LIF、N=1,024、fan_in 32、EMA 读出、逐时刻 e-prop、无 autograd；
- **唯一改动**：语料换成真实会话；
- **词表**：**1,246 个唯一字**（不截断、不扩）；特殊 token `bos/sep/eos/unk`；
- **序列**：`<bos> user <sep> assistant <eos>`，每条一对；
- **切分**：**留一会话（LOO）**，六折，报告每折与均值；
- **序列长度上限**：**192**（开跑前量过：中位 70、p90 270、max 1,782；按 S2 的 64 截断只能完整保留 **47%** 的序列，会把回复尾巴砍掉一半；192 保留 **82%**）；
- **训练**：每折 2,000 updates、batch 16、`lr_in=1e-3`、`lr_out=0.5`、种子 0（六折共用同一超参）；
- **基线**：同折上的字符 bigram（k=0.5）。

## 判据

| # | 判据 | 门槛 | 不过时判什么 |
| :--- | :--- | :--- | :--- |
| **R0-0** | 前置：模型真的在学 | 每折训练 CE 尾/首 <0.6 | 管线/超参不适用，实验无效 |
| **R0-1** | **赢同折 bigram** | **六折均值 `top1 ≥ bigram + 3pp`** | 局部学习在真语料上没有增益 |
| **R0-2** | 不是靠一折 | 至少 **4/6 折**各自赢 bigram | 均值的赢来自个别折 |
| **R0-3** | CE 同向 | 六折均值 `CE < bigram CE` | 只在 top-1 上赢 |

**R0-2 是本轮的关键判据**。六折里有一折只有 715 token，均值很容易被它带偏；
"至少 4/6 折各自赢"才是"普遍有效"的证据。

## 预期

**押 R0-0 过、R0-1 不确定、R0-2 不确定。** 具体：

- 真语料上模型 top-1 预期 **0.20–0.35**（bigram 是 0.181）；
- 与 bigram 的差预期 **0 到 +8pp**，**很可能不显著**——因为每折只有 700–23,000 token。

**若 R0-1 不过但 top-1 明显高于 0.181（如 +2pp 内）**，结论写成"方向为正、样本不够判"，不写成"无效"。

- 不因为某折差就改切分。
