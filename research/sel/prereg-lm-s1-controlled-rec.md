# 预注册：S1——递推电流受控时，循环还有没有价值（2026-11-06）

**状态：判据先落盘，代码未写。**

## 背景

S0（[`../sweep_results/lm_eprop_s0/README.md`](../sweep_results/lm_eprop_s0/README.md)）发现：
三臂的 top-1 与「递推电流 / 输入电流」**完全单调**（0× → 0.717、2.16× → 0.516、7.36× → 0.352）。
M0/M0b/S0 的递推臂从初始化起就在淹没 token 信号，所以它们关于"递推"的负结果**不能引用**
（已在 ADR-0035-c 标记为"证据受污染"）。

**本轮唯一的问题**：把递推电流压到与输入同量级之后，循环连接能不能**进一步提升**纯前馈基线 0.717？
还是前馈已经够了？

## 设计（跑之前定死）

**四臂**，同一份语料、同一个种子、同一预算（301 条、2,000 updates、batch 16、seed 0、per-step CE）：

| 臂 | 递推 | 目标电流比 | `w_rec` |
| :--- | :--- | ---: | :--- |
| `none` | 无 | 0 | — |
| `rec@0.5` | 冻结随机 `w_rec` | **0.5×** | 冻结 |
| `rec@1.0` | 冻结随机 `w_rec` | **1.0×** | 冻结 |
| `rec@0.5-learned` | 同上 | **0.5×** | **学习**（`lr_rec=1e-3`） |

**标定方式（写死，写代码时按实测修正过一次）**：初始化后，用同一批前 120 步测出
`median|I_rec| / median|I_in|`。**不能一次乘到位**——实测递推电流对 `w_rec` 是**超线性**的
（缩放 0.5 倍，电流比掉 6.6 倍），固定步长会来回震荡。做法是先用 `base`、`probe=0.8`
两点估出幂指数 `k`（`r ∝ s^k`，实测 k≈4.8–4.9），解出所需缩放，再用局部指数精修，
直到达成值落在目标 **±0.05** 内（最多 4 轮）。标定完成后 `w_rec` **不再动**（除非该臂要学）。
每臂记录实际达成值。

`w_in` 与读出（NLMS）在所有臂上一致；学习率、τ、读出衰减、块长全部沿用 M0b。

## 判据

| # | 判据 | 门槛 | 不过时判什么 |
| :--- | :--- | :--- | :--- |
| **S1-0** | 前置：标定到位 | 三个受控臂的实际比值都在目标 **±0.15** 内 | 实验无效 |
| **S1-1** | 受控递推有价值（0.5×） | `top1 ≥ top1(none) + 2pp` **或** `CE ≤ CE(none) − 0.05` | 在这个工作点上，0.5× 递推没有增益 |
| **S1-2** | 受控递推有价值（1.0×） | 同上，对 `rec@1.0` | 同上 |
| **S1-3** | 受控条件下，学习循环权重有用 | `rec@0.5-learned` 对 `rec@0.5` 达到同一门槛 | 学习循环权重仍无益（但这次不是被淹没导致的） |
| **S1-4** | 没有任何受控臂明显变差 | 三个受控臂的 `top1` 都 **≥ top1(none) − 2pp** | 递推即使受控也有害 |

**S1-1/S1-2 是核心。** 若四条 S1-1..S1-4 里除了"不变差"之外全不过，结论就是：
**在这个工作点上，前馈已经够了，循环不带来增益**——这是一个干净的、可以引用的结论。

## 附带诊断（必须记）

1. **自持性**：把输入置零后跑 50 步，记录发放率。若某臂在零输入下仍显著发放，
   说明它进入了自持振荡——这是"淹没"的机制证据；
2. **电流比**：每臂记录标定后的实际 `I_rec / I_in`；
3. **发放率**：四臂对比。

## 预期

**押 S1-0 过、S1-4 过、S1-1/S1-2/S1-3 全不过。** 具体：

- `none` 复现 **0.717 / 1.139**（同代码同种子，应当逐位一致）；
- `rec@0.5` 与 `rec@1.0` 落在 **0.69–0.73**，与 `none` 差在 ±2pp 内；
- `rec@0.5-learned` 略低于冻结（模板语料撑不起循环权重的自由度）。

**若 S1-1 过**（0.5× 递推把 top-1 抬到 ≥0.74），那"循环有价值但需要标定"成立，
下一步才是加 τ 分组 / 多衰减抽头。

## 不做的事

- 不扫 0.25× / 2× 等其他比值；
- 不调 τ、不加抽头、不切块、不改语料；
- S1-0 不过时不调标定重跑（标定公式是写死的）；
- 不因为某臂略差就删掉它。

## 边界

- 单种子；测试集 46 条 / 1,369 字符（top-1 的 SE ≈0.9pp），所以 **2pp 的门槛约 2.2 个 SE**——
  能判"有没有增益"，判不了"增益多大"；
- 语料是模板化单轮 SIR，不是对话；
- 电流比的定义是**初始化后前 120 步的平均绝对值**，训练会改变它；它衡量的是"起步时的平衡"。

## 成本

四臂各约 7–9 分钟，**合计约 30 分钟**。
