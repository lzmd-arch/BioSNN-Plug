# 预注册 v10：基因组与演化（补 Program / Improvisation 两根柱子）

**写于** 2026-11-16，**在任何一代跑之前**。

## 为什么

v8 测出：少 25% 神经元，活动塌两个数量级 —— **工作点是我手调到刀锋上的**。
生物皮层也工作在临界点附近，但那是**稳态调节自组织出来的**。

现在有 **9 个量是我手拍的**（c、r、k、λ、deg、β、γ、η、目标发放）。
**基因组应该替代的正是这些。**

基因组不是权重：生物约 2 万基因 → 约 10¹¹ 神经元。
基因编码的是**发育规则与稳态设定点**。

## 适应度**不含准确率**（硬纪律）

若适应度 = 准确率，就只是把 benchmark 追逐换成用进化做。
生物选的是**存活**。

| 分量 | 权重 | 定义 |
| :--- | ---: | :--- |
| **可行性** | 3 | 完整网络长时程发放 ∈ [0.03, 0.20] |
| **抗损伤** | 4 | **50% 神经元受损后**发放仍在该区间 |
| **稳定性** | 1 | `exp(−std/mean)`，不爆不灭 |
| **能量效率** | 1 | 越靠近区间下限越省 |

满分 9。**准确率只作报告量**，不进适应度。

## 基因组：7 个实数

| 基因 | 范围 | 对应我原来手拍的 |
| :--- | :--- | :--- |
| `c` 代谢成本 | log[0.005, 0.2] | 0.05 |
| `r` 恢复率 | log[5e-4, 0.05] | 0.00435 |
| `k` 阈值调制 | [0, 3] | 1.0 |
| `λ` 扩展半径 | log[1, 16] | 4 |
| `deg` 入度 | log[8, 64] | 32 |
| `A` 折叠幅度 | [0, 24] | 16 |
| **`target` 目标发放** | log[0.03, 0.20] | 0.08 |

**≤ 16 个实数**，符合"基因必须小"的纪律。

## 演化

- 种群 **32**，**8 代**；
- 锦标赛选择（k=3）+ 精英保留（前 4）+ 变异（σ = 范围的 10%）；
- 每个基因组：发育（按 λ/deg/A 建接线）→ 标定到 `target` → 评估。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **G-0** | 手调基因组（我原来的值）在本评估下适应度有限 | 不过 ⇒ 作废 |
| **G-1 进化有效** | 第 8 代最优适应度 > 第 0 代最优 | 单调趋势 |
| **G-2 打败手调** | 进化最优基因组的**抗损伤分量** > 手调基因组的 | **本轮核心** |
| — | 准确率与各分量逐项报 | 不作判据 |

**G-2 是这一层存在的理由**：如果进化出来的基因组不比我的手调值更抗损伤，
那"基因组"就是装饰。

## 若 G-2 不过

⇒ 在这 7 个自由度上，我手调的值已经不错，或者适应度地形太平。
照实记，**不改进化参数让它过**。

## 不做的事

- 不加可学参数（演化只改基因组，不改突触）；
- 适应度**不含准确率**；
- **不声称任何超出本轮的结论**。
