# 预注册：R2——加数据：把合成语料放大 5 倍（2026-11-07）

**状态：判据先落盘，数据未生成。**

## 背景

R0b 判红（[`../sweep_results/lm_eprop_r0b/README.md`](../../sweep_results/lm_eprop_r0b/README.md)）：
真实语料两折各输 bigram **10–11pp**，**两折都收敛**（CE 尾/首 0.13 / 0.39），
曲线显示第 2,000 步起测试 CE 单调上升——**过拟合 + 边界，不是欠拟合**。

排除了"更多训练"之后，剩下三条：**加数据、缩读出、早停**。本轮测**加数据**。

**唯一的问题**：把合成语料从 3,000 对放大到 15,000 对（同一难度档、同一生成管线），
`Δ = 模型 − bigram` 会不会显著改善？

## 先修一处实现偏差（照登）

R1 的预注册写"风格参数从真实语料的**聚合统计**取"，但 `gen_synth.py` 实际用的是**手写列表**，
**没读任何统计量**。R2 修对：从真实语料只取**聚合量**（每轮字数分位、标点占比），
用来约束 prompt 的长度与标点；**不取任何正文，不进 prompt**。

**这带来一个必须显式处理的混杂**：换生成口径 + 加数据是两件事。所以本轮**不用 R1b-H 当对照**，
而是在**新语料内部**做一个 3,000 对的对照臂——**同一生成管线、同一 epoch，只差数据量**。

## 设计（跑之前定死）

| 项 | 取值 |
| :--- | :--- |
| 难度档 | **H**（R1 里最难，bigram 0.294，最接近真实语料的 0.184） |
| 生成 | 本地 `qwen3-4b`、`think=false`；prompt 的长度/标点由**真实语料的聚合统计**约束 |
| 语料 | **15,000 对**，六折（按生成顺序轮转 `group`） |
| 臂 A（对照） | 取语料的前 **3,000 对**（group 0–5 各 500），2 折（group 0、1） |
| 臂 B（主臂） | 全部 **15,000 对**，同样 2 折（group 0、1） |
| epochs | **100**：臂 A = 18,750 updates；臂 B = **93,750 updates** |
| 训练配置 | 前馈 LIF、N=1,024、单 τ=20、`input_std=0.12`、`lr_in=1e-3`、`lr_out=0.5`、`max_len=192`、V≤800 |
| 基线 | 同折字符 bigram（k=0.5） |

**两臂的测试集相同**（都是 group 0 / 1 的留出对），所以 Δ 可以直接相减。

## 判据

| # | 判据 | 门槛 | 不过时判什么 |
| :--- | :--- | :--- | :--- |
| **R2-0** | 前置：两臂都收敛 | 每折 CE 尾/首 **<0.6** | 还没训够，本轮不可判 |
| **R2-1** | **加数据是杠杆** | `Δ(15k) − Δ(3k) ≥ +3pp` | 数据量不是杠杆 → 只剩"缩读出" |
| **R2-2** | 至少不更差 | 两臂的 Δ 均值差 **≥ −1pp** | 加数据反而更糟，要查生成口径 |
| **R2-3** | 难度守住 | 15k 语料的 bigram 落在 **0.25–0.34** | 生成口径改变了难度，本轮不可比，重跑 |

**R2-3 是闸门**：换了 prompt 约束后 bigram 可能漂移；漂出去就说明"加数据"和"改口径"混在一起了。

## 预期

**押 R2-0 过、R2-3 过；R2-1 不确定。**

- R2-1 过 → 数据量是杠杆，下一步推到 30k–100k（成本线性上涨）；
- R2-1 不过 → 数据量不是杠杆；剩下的"缩读出"之外，早停已被 R0b 证明抬不动 top-1，
  **纯前馈这条支线就该收口**。

## 不做的事

- 不调 N、不调 τ、不改架构；
- 不把真实语料混进来（那要另开一轮）；
- R2-1 不过时不立刻换"缩读出"重跑。

## 边界

- 两臂各 2 折、单种子；测试集很小（group 0/1 各 500 对中的留出部分）；
- 合成语料不是真实对话；本轮**不回答**"合成→真实能否迁移"；
- 字符级 next-token，**不代表能闲聊**。

## 成本

生成 15,000 对：R1 实测 3.7 对/s → **约 68 分钟**；
训练：臂 A 18,750 updates × 2 折 ≈ 42 分钟；臂 B 93,750 × 2 ≈ 3.5 小时；
**合计约 5.5 小时**（外推值，基准是 R1 的实测）。
