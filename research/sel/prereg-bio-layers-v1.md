# 预注册：把生物特性放在"信息几何"上（τ 异质 / 激素路由 / 读出维度 / 基因）

**日期**：2026-11-14，跑之前写。
**依据**：本轮 12 次"加生物机制"的实验给出了一条干净的经验律——

> **改标量/增益的：全部为零或负；改信息几何的：全部为正。**

本文件只做**改几何**的那一类，四件事一次做完，每件都有独立的判据与 kill 条件。

## 一、四个实验

| # | 实验 | 改的几何 | 关闭条件（先写死） |
| :--- | :--- | :--- | :--- |
| **B-1** | **τ 异质**：各池用自己的膜时间常数 | 同时编码快/慢 | 异质相对同质的最佳点 **< +5pp** |
| **B-2** | **激素路由**：激素选"哪条突触可塑"，而不是"可塑多快" | 可塑性的**资格分布** | 路由相对标量增益的**最好**结果 < +5pp |
| **B-3** | **读出维度**：增加时间尺度数（2→4） | 读出宽度 | 4 τ 相对 2 τ **< +5pp** |
| **B-4** | **基因**：外循环搜架构（池大小/τ/读出/尺度），内循环冻结 | 架构先验 | 搜到的最好个体相对**手设计**基线 **< +3pp** |

**四条都用同一个任务与同一把尺**（解析编码 + 池内探针，`lr-sensor=0`，纯编码测量），
**互相可比**，且都不需要训练。

## 二、为什么这四个能放在一起

因为它们**不是四个独立的猜测**：B-1/B-3 是同一个"时间尺度多样性"的两端（膜 vs 读出），
B-2 是"资格分布"，B-4 是把前三者当基因再搜一遍。合起来是一次**架构层的扫描**。

## 三、判据细节

- 基线 = 手设计的现役配置：`POOL=16`、`τ=20`（同质）、读出 τ=(2,128)、尺度按预注册 §amend4 标定；
- 所有臂**同种子、同批样本**（解析编码 ⇒ 无抽签方差）；
- 每个臂至少 **3 个种子**（种子只影响文本路径与评测采样）；
- 报 **top-1 的中位与极差**；
- **不调阈值**：<5pp 就是 <5pp。

## 四、B-4 的搜索空间（写死）

| 基因 | 取值 |
| :--- | :--- |
| 池神经元数 | 8 / 16 / 32 |
| 池膜 τ | 5 / 20 / 80 |
| 读出时间尺度数 | 2 / 4 |
| 驱动尺度 | 0.5 / 1 / 2 / 4 |
| 激素路由 | 开 / 关 |

共 3×3×2×4×2 = **144 个个体**，随机抽 48 个（固定种子），按留出 top-1 排序。
**"基因"的定义就是这套先验，不是权重。**

## 五、不做什么

- 不改文本主干、不改千问；
- 不引入反传；
- 不在本轮调激素的**路数**（作为增益已经被否过两次）。
