# 预注册附录：R4 × R3 的读出宽度标定（2026-11-08，写在 R4 出数之前）

**状态**：R4 于 2026-11-08 01:20 开跑（18,750 updates × 2 折，约 3 小时）；本文件写于开跑后、
**训练尚未结束、未看任何 R4 数据**之前。R4 的判据 R4-0/1/2 不动，本文件只**加一条跨实验对照**。

## 为什么现在加

R3 出数之后，R4 的解读方式变了——R3 给了本轮一个**外生标定**：

| | 读出宽度 | 读出参数 | Δ |
| :--- | ---: | ---: | ---: |
| R3 臂 (b) | 256 | 205k | **−10.14pp** |
| R2-A 基线 | 1,024 | 820k | **−6.16pp** |
| | **4×** | **4×** | **+3.98pp** |

同一个 N=1,024、同语料、同步数：**把读出宽度加 4 倍，买到 ~+4pp**。

R4 把读出宽度从 **1,024 加到 4,096（也是 4×）**，但**不是靠加神经元**——是每个神经元给 4 个数
（EMA τ ∈ {2, 8, 32, 128}）。所以 R4 顺带回答了另一个问题：**"读出维度"本身是不是杠杆，还是必须是不同的神经元？**

## 预先写死的跨实验对照

设 `改善(R4) = Δ(R4) − Δ(R2-A)`（R2-A 的 Δ = −6.16pp）。

| 改善(R4) | 判读 | 与 R4-1 的关系 |
| :--- | :--- | :--- |
| **≥ +3pp** | 与"**读出维度是杠杆**、来源不限"一致——时间尺度买来的宽度和神经元买来的一样能用 | R4-1 过 |
| **+1 ～ +3pp** | 方向对但打了折。**不许直接说"宽度不重要"**：R3 的标定点在 256→1024，收益递减会让 1024→4096 本来就该小 | R4-1 不过 |
| **≤ +1pp** | **宽度不是充分条件**——必须是**不同的神经元**；同一批神经元多给几个时间尺度换不来 | R4-1 不过 |

**必须一起报的量**：R4 的读出参数是 4,096×801 = **3.3M**，是 R2-A 的 4 倍。若改善 < +3pp，
这 4 倍参数就是**净亏**（R4-2 已写死要报这个代价）。

## 这条对照不能做什么

- **不能当成"宽度的剂量–反应曲线"**：R3 只给了两个点（256、1024），R4 给第三个点（4096）
  但**换了机制**（时间尺度 ≠ 神经元），所以三点不共线；
- **不能外推到 N**：R3 已经证明 N 在 256 处有 slack（N=256 与 N=1024 终值只差 0.24pp），
  所以"加神经元买宽度"这条在本轮**还没有被检验过**——它是下一个候选实验，不是本轮的结论。

## 与路线的关系

- 若 R4 的改善 ≥ +3pp：**"读出是瓶颈"从 A 线（A3/A5/A7）延伸到 LM 线**，两条线共用同一个机制主张；
- 若 R4 的改善 ≤ +1pp：LM 线的读出**不吃时间尺度**，这条支线的下一步就不是读出结构，而是
  **数据（R6q 的 2×2）与分词（BPE）**；
- 无论哪种，**R4 都不改变 R3 的结论**（缩读出在这个语料上净损失 3.7–4.0pp，四折 top-1 未平台）。
