# 模型接入 Axo 的基础设施（2026-11-12）

**先说一个好消息：Axo 侧不需要新造接口。** 三个能力面各自对应一个已经存在的协议。

## 一、接入面：三个已有接口

| 我们的能力 | Axo 已有协议 | 位置 |
| :--- | :--- | :--- |
| 文本 → 向量（记忆通道） | `EmbeddingBackend.embed(texts) -> np.ndarray` | `src/axo/llm/base.py:312` |
| 脉冲编码（模态） | `ModalityPlugin.encode / decode` | `src/axo/busd/plugin.py` |
| 逐 token 生成 | `ChatBackend.stream` | `src/axo/llm/base.py:274` |

**只有前两个要实现。**

**`ChatBackend` 明确不实现**——这个模型记不住超过 ~64 步、没对齐、top-1 只有 0.09。
把它套成聊天后端，等于在接口层面承诺一件它做不到的事。要兜底就走单独的"候选补全"接口，
名字里不许出现 chat。

## 二、进程边界（最硬的约束）

仓库有一条既定红线：**torch 不进 Axo 的依赖**（语音组件就是因此独立的）。
0.5B 的 SNN 离不开 torch ⇒ **模型必须跑在独立进程里**，Axo 通过本地 HTTP 访问——
**和现在的 Ollama 完全同构**。

Axo 已经有这套东西可以照抄：

| 件 | 现成参照 |
| :--- | :--- |
| 守护进程 + 启动器 | `src/axo/busd/{daemon,launcher}.py` |
| 健康检查与就绪 | `busd/state.py` |
| "默认不存在"的开关语义 | `propose_server.py`（关着时"没有这个服务器"，不是"有个服务器但什么都不写"） |

## 三、接口契约（先定形状，再写代码）

```
GET  /health
  -> {"ready": bool, "model": "snn-0.5b", "step": 20000, "device": "cpu"}

POST /encode        {"texts": ["...", ...]}          # 记忆通道（F1）
  -> {"vectors": [[...], ...], "dim": 15625, "normalized": true}

POST /complete      {"context": "...", "k": 10}      # 离线候选（兜底）
  -> {"candidates": [{"text": "的", "logprob": -1.2}, ...]}

POST /consolidate   {"since": "2026-11-11T00:00:00"}  # 夜间巩固
  -> {"encoded": 37, "merged": 3, "rejected": 1}
```

**四条硬规矩**：

1. **`/complete` 的返回是 token 不是句子**——它只做"下一个候选"，不做生成；
2. **`/encode` 必须返回归一化向量**，否则和 nomic 的分数不可比；
3. **`/consolidate` 幂等**：同一个 `since` 跑两次结果相同；
4. **服务不在时 Axo 行为与今天完全一致**（默认关闭，探测失败即降级）。

## 四、四个接线点与各自的判据

| 接线点 | 改什么 | 判据 | 现在的状态 |
| :--- | :--- | :--- | :--- |
| **记忆召回第三通道** | 新增一个 `EmbeddingBackend` 实现 + 融合权重里加一路 | `paraphrase` 子集 hit@1 ≥ 0.30（词法 0.20） | 等改述集 |
| **夜间巩固** | 新调度任务调 `/consolidate` | 次日 hit@5 **+3pp** | 未开始 |
| **离线候选** | 输入框旁一个候选条组件 | 不联网时首位/次位命中可测 | 未开始 |
| **触发器** | 用 `/complete` 的分布替代 M3b 的脚本特征 | 调用降 ≥30% 且质量掉 ≤1pp | 语料未解决 |

## 五、和"云端为主"的定位对齐

| | 云端（DeepSeek） | 本地 SNN |
| :--- | :--- | :--- |
| 角色 | **全部对话** | 编码 / 夜间 / 兜底 |
| 触发条件 | 有网、有 key | 常驻 |
| 失败怎么办 | 报错 | **静默降级，不补位** |

**本地模型绝不"接管"对话**——它的职责边界是"记住发生了什么"，不是"回答"。

## 六、落地顺序

```
1  /encode 服务（最小：加载检查点 + 一个 HTTP 端点）      ← 半天
2  在 Axo 里加 EmbeddingBackend 实现 + 开关                ← 半天
3  改述集 + G-B 判据                                       ← 已在做
4  /consolidate + 夜间调度                                 ← 需要先确认巩固的判据
5  离线候选 UI                                              ← 最后
```

**第 1、2 步不需要模型训完**——现在这个 0.5B 检查点就够把管道打通。**先打通管道，
再谈质量**，这样模型一训好就能立刻接进去量。
