# 预注册修正案 1：R12 的判决探针改成 **2×2 缺格**（2026-11-11）

**状态：判据先落盘，随后开跑。** 原文件
[`prereg-lm-r12-ca-block-length.md`](prereg-lm-r12-ca-block-length.md) 的判据**不执行**（其自身的"暂不执行"补注仍然有效）；本文件取代它的第一条臂。

## 为什么改

原设计是"只训练隐层 + 块长阶梯"，但它回答不了一个更基本的问题：**22.8pp 里，多少是规则的账、多少是架构的账？**
现在把它做成 2×2，缺的只有一格：

|            | 局部规则 | BPTT（真梯度） |
| :--------- | :------- | :------------- |
| **单层 LIF（我们的）** | **0.3090**（2 抽头、16k）✅ 已有 | **???** ← 本轮补 |
| **GRU**    | —        | **0.5318** ✅ 已有 |

- **`local-SNN` vs `BPTT-SNN`** = 规则的账（架构完全相同）
- **`BPTT-SNN` vs `BPTT-GRU`** = 架构的账（规则完全相同）

## 设计（写死）

- 架构与 `TokenEProp`（`recurrence="none"`、多抽头 EMA 读出）**逐位等价**，
  守卫见 `tests/test_bptt_equiv.py`（同权重下前向差 < 1e-5，含 padding 掩码）。
- 伪导数与 `TokenEProp` 的 ψ 同口径：`dz/dv = dampening/θ · clamp(1 − |scaled|, 0)`。
- 语料/切分/预算与局部规则臂**完全一致**：KdConv test 留出、`max_vocab=3000`、
  `max_len=192`、batch 16、**4,000 步**、抽头 **τ = {2, 128}**（与当前的 2 抽头最优臂同）。
- 优化器 **Adam，lr = 1e-3，梯度范数裁剪 1.0**。

## 判据

| # | 门槛 | 判什么 |
| :--- | :--- | :--- |
| **B-1** | 前向与 `TokenEProp` 逐位等价（1e-5） | **硬前置**：不是同一个模型，下面的比较全部无效 |
| **B-2** | `top1(BPTT) − top1(局部)` 在**同一步数**（4,000）上报告 | 规则的账 |
| **B-3** | CE 一并报 | 防止"排序涨、校准崩" |

**判读（预写，出数前定死）**：

| BPTT−local（4,000 步） | 结论 |
| :--- | :--- |
| **≥ +10pp** | **规则是主账**。CA 轴重开，按 F2 → F3 → F123 的顺序推进 |
| +2 ～ +10pp | **两者都有份**，用 2×2 的第三格（`BPTT-GRU` 0.5318 对 `BPTT-SNN`）继续拆 |
| **≤ +2pp** | **架构是天花板**，规则被洗清。转向深度（D2）与可训练递推，**F 系列降级** |

## 必须一起写的混淆项（写死，不许事后补）

1. **优化器不同**：BPTT 用 Adam 1e-3，局部规则用 NLMS `lr_out=0.5`。这不是同一个优化器，
   所以 B-2 的差里**含优化器的贡献**，不能全部记到"梯度对不对"上。
2. **BPTT 训练全部参数**（`w_in` 与 `w_out`），局部规则也是全部参数——各自的规则不同，但覆盖面相同。
3. **单折、单种子**；4,000 步**峰值未必到**，所有 Δ 是**下界**。

## 不做的事

- 不扫块长（原设计的阶梯作废）；
- 不调 BPTT 的超参去找最好成绩——1e-3 / clip 1.0 是写死的；
- 不在本臂改架构。

## 成本

实测 1.7 s/更新（200 步 5 分 41 秒）⇒ 4,000 步 **约 1.9 小时**。
