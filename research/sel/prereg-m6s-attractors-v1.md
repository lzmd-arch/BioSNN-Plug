# 预注册 v28：M6s 数吸引子 —— "个体坐进不同状态"存不存在

**写于** 2026-11-16，**在任何一档跑之前**。

## 为什么不再扫参数

M6p/M6q/M6r 三轮都在调乘性参数（池数、交叉抑制、增益时间常数、增益接线、历史时长）。
M6r 的 1.68× 是这条线上最高的，但**它"停住"是 0/6** —— 状态还在动。

数学上把话说死了：**冻结的增益让动力学成为一族仿射映射 `v ↦ A(gain)·v + b(gain)`，
而一个仿射映射最多只有一个不动点。** 所以 1.68× 可能只是**暂态被拉长**，
不是个体真的落进了不同状态。`rel` 距离这个口径分不出来。

## 测什么

同一网络、**零输入**（`t_hist=0`）、**随机初值** `v0 ~ N(0, σ²)`，跑到 `T=1024` 步收敛。
同一吸引子的两个初值收敛到**逐位相同**的状态（浮点意义下）；不同吸引子不会。

- 收敛判据：相邻两个 64 步窗（896–959 vs 960–1023）的相对距离 **< 0.05**；
- 簇判据：两个收敛终态的相对距离 **< 1e-3** 记为同一簇（单链接）。

**同一段轨迹的两次调用是确定性的**，所以用 `t_spont=1024` 与 `t_spont=960` 两次调用
取相邻窗，不改变动力学。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **S-0 存在** | 后期发放 ∈ [0.01, 0.20] | 不过 ⇒ 该格作废 |
| **S-1 收敛** | **≥50% 初值**的相邻窗距离 < 0.05 | 不过 ⇒ 谈不上吸引子 |
| **S-2 多吸引子** ★★ | 任一格 **≥2 簇** | **本轮核心** |

**S-2 不过的后果是写死的**：若所有格都只有 1 个簇，
则"个体坐进不同状态"在这个动力学族里**数学上不存在**，再调任何乘性参数都无效 ——
那时要换的是动力学族，不是参数。

## 我自己的预测（可证伪）

- **`g_inh=0` 应该只有 1 个吸引子**（M6 的"一维个体"就是它的症状）；
- **`g_inh` 大时可能出现多个**（M6p 测到支配度最高 578×，那本身就暗示了双稳）。

若两边都只有 1 簇，上面第二条错，且 M6p 的"竞争"是暂态而非吸引子。

## 设计

- `K=4`，`g_inh ∈ {0, 1, 2, 4}`；
- `σ ∈ {1.0, 4.0}`（初值幅度跨一个量级，防止只落在一个盆里）；
- 每格 **64 个初值** × 2 种子；
- 固定网络种子与起搏图样（同一网络，只改初值）。

## 限定

- 收敛判据 5%、簇判据 1e-3 都是本轮定的，没有外部依据；
- 只数**定点/短周期**；长周期或混沌会被判成"不收敛"（S-1 不过），那也是结论；
- 线性谱盲区仍在。

## 修订 1（**正式跑之前**，1 种子 × 32 初值冒烟之后）

### 为什么改

冒烟暴露两件事：

1. **簇阈值 1e-3 不能用。** 不动点是渐近逼近的，数值散射在 1e-3–1e-2 量级 ——
   这个阈值和它同量级，分不开"同一吸引子"与"不同"。
   冒烟里 `g_inh=1` 的 32 个终态两两相距 **0.005–0.007**，被判成 32 簇，
   但它们显然是**同一个**状态；
2. **"数簇"这个统计量本身不对。** 如果不动点是一个**连续统**，簇数恒等于初值数，
   这个数不区分"连续吸引子"与"离散吸引子"。

### 改成什么

用**距离分布的形态**分类，不用簇数。对每格的全部收敛终态两两求相对距离：

| 统计量 | 定义 |
| :--- | :--- |
| `near` | 距离 **< 0.05** 的配对占比（与收敛判据同尺度） |
| `far` | 距离 **> 0.5** 的配对占比 |

| 形态 | 判据 | 含义 |
| :--- | :--- | :--- |
| **单一吸引子** | `far < 0.1` | 所有初值殊途同归 —— 个体没有选择 |
| **连续吸引子** | `near < 0.1` 且 `far ≥ 0.5` | 终态随初值连续变化 —— **个体状态存在且可携带连续信息** |
| **离散多吸引子** | `near ≥ 0.1` 且 `far ≥ 0.1` | 双峰 —— 少数几个盆 |

### 另加一条持久性检验（原预注册没有）

**P-1 持久**：同一初值跑到 `T=1024` 与 `T=2048`，两个终态的相对距离中位数 **< 0.05**。
没有它，"收敛"可能只是**慢漂移**被 5% 的窗口判据误判。

### 判据表（替换原 S-2）

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| S-0 存在 | 发放 ∈ [0.01, 0.20] | 不变 |
| S-1 收敛 | ≥50% 初值相邻窗 < 0.05 | 不变 |
| **P-1 持久** ★ | 中位 rel(T=1024, T=2048) **< 0.05** | 新 |
| **S-2' 形态** ★★ | 每格按上表分类 | 替换 S-2 |

**S-2' 不过的后果仍然写死**：若所有格都是"单一吸引子"，
则"个体坐进不同状态"在这个动力学族里**数学上不存在**，再调任何乘性参数都无效。
