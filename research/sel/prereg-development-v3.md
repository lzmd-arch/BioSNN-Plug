# 预注册 v3：耦合强度的剂量–反应

**写于** 2026-11-16，在 v2 之后、**本轮任何一档跑之前**。

## v2 留下的缺口

`E` 进痕迹后，3 个种子的存活结构**稳定地**差出约 **10%**
（Jaccard 0.892 / 0.892 / 0.895），D-2 **边缘通过**（线 <0.9）。
但准确率只高 **+1.0pp**（要 ≥3pp），渠化也不过（能力极差 3.2pp）。

⇒ 环闭上了，但**耦合太弱**。这一轮把耦合强度当自变量。

## 机制

```
s  ←  λ·s + mean_b( z_post · z_pre · E_post^γ )
```

`γ = 0` 即不带 `E`（v2 的 `noE_acid`）。`γ` 越大，痕迹越被能量主导，
而不是被共活动主导。

## 四档

| 臂 | `γ` | 含义 |
| :--- | ---: | :--- |
| `g0` | 0 | 不带能量（v2 的 `noE_acid`，参照） |
| `g1` | 1 | v2 的设置 |
| `g2` | 2 | 加倍 |
| `g4` | 4 | 强耦合 |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **C-0** | 窗口天花板 ≥ 底板 + 20pp；每臂 > 底板；发放在 [0.03, 0.20] | 不过 ⇒ 作废 |
| **C-1 剂量–反应** | `Jaccard(gγ, g0)` **随 γ 单调下降**（耦合越强，结构越不同） | 三个 γ 严格单调 |
| **C-2 能力** | 最好的 γ 的 acc ≥ `g0` **+ 3pp** | 能量驱动的发育真的有用 |
| **C-3 渠化** | 三个种子结构两两 Jaccard < 0.8，且 acc 极差 < 2pp | 结构不同、能力相同 |

**C-1 是这一轮的主判据**：它测的是"我加的这根旋钮有没有用"。
若 Jaccard 不随 γ 单调下降，说明结构差异不是能量造成的，v2 的 D-2 就是噪声。

**C-2 是方向未知的**：`γ` 更大不一定更好 —— 能量过度主导可能破坏共活动提供的信息。
所以 C-2 只要求"某个 γ 能到 +3pp"，不预注册哪个。

## 若 C-1 不过

⇒ v2 的 D-2（0.895 边缘过）就是噪声，`E` 塑造结构这条**不成立**。
照实记，不调线。

## 不做的事

- 不加可学参数；
- 不改任务与读出（沿用 v2）；
- **不声称任何超出本轮的结论**。
