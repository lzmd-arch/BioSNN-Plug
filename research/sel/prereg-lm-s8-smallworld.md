# 预注册：S8 —— 结构化稀疏递归（小世界），2026-11-11

**状态：判据先落盘，实现随后。** 依据见 [`design-local-rule-upgrades.md`](design-local-rule-upgrades.md)。

## 为什么还要再试一次递推

本仓在递推上已经有 **五连负**，而且**全部是 2026-11-06 同一天内的快速变体**（整条局部学习 LM 支线只跨 11-06 ～ 11-10 五天）：

| 轮次 | 做了什么 | 结果 |
| :--- | :--- | :--- |
| M0 / M0b | 随机稀疏 `w_rec`，电流比 **2.16×** | 输给 bigram |
| S0 | 冻结随机循环 / 冻结对角 SSM（**7.36×**） | 单调变差（0×→0.717、2.16×→0.516、7.36×→0.352） |
| S1 | 把电流标定到 0.5× / 1.0× | 仍低于无递推（0.698 / 0.668 对 0.717） |

S1 的结论是"这个工作点上前馈 LIF 最优，任何循环电流都是拖累"。**但五次试的全是同一种东西：随机拓扑。**

[arXiv:2605.00402](https://arxiv.org/abs/2605.00402) 用的是另一种：**局部稠密 + 稀疏小世界长程投影**，长程基本固定。差别不在于"训不训"，在于**拓扑形状**——
随机循环给每个神经元注入的是**与输入独立**的电流（纯噪声），而小世界的区内连接给的是**与输入相关**的电流（近似软归一化/簇内放大）。

**这是一个可检验的机制主张，不是"再试一次"。**

## 先验（写死，出数后不许改口）

**低。** 但要把话说准：那五连负是**一天之内、同一族拓扑（随机）的快速变体**，
不是五次独立的调查——所以它们是"**随机拓扑不行**"的证据，不是"**递推不行**"的证据。
其中真正有分量的是 S1（把电流标定到 0.5×／1.0× 后仍负），因为那一条已经排除了"只是尺度没调好"。

这条值得跑的唯一理由不是期望为正，而是它**第一次带匹配控制臂**，
所以无论正负都能归因——不像 S0/S1，跑完还是不知道是"递推没用"还是"我们接错了"。

## 设计

N = 1,024（沿用），簇数 **G = 8**（每簇 128）。

| 项 | 值 | 理由 |
| :--- | :--- | :--- |
| **区内连接** | 每个神经元连本簇内 **32** 个（25% 密度） | "局部稠密" |
| **跨区连接** | 每个神经元 **2** 条，指向**簇外**均匀随机 | "稀疏小世界" |
| **总 fan-in** | **34**（与现有 `fan_in=32` 同量级） | 避免用参数数解释差异 |
| **权重初始化** | `randn/sqrt(fan_in)` | 与现模型一致 |
| **电流比标定** | **必须先标到 median\|I_rec\|/\|I_in\| = 0.5**，复用现成的 `calibrate_recurrent(target=0.5)` | **M0/M0b 的教训：不标定就是拿噪声上场** |

## 四条臂（**B 与 C 只差拓扑，其余全同**）

| 臂 | 拓扑 | 训练 |
| :--- | :--- | :--- |
| **A 基线** | 无递推（`recurrence="none"`） | — |
| **B 小世界** | 区内 32 + 跨区 2 | **全部 34 条可训** |
| **C 匹配随机** | 34 条全随机（无簇结构），**同 fan-in、同电流比** | 全部可训 |
| **D 小世界·跨区冻结** | 同 B | 区内可训、跨区冻结（论文配置） |

**C 是本轮的核心**：A vs B 只说明"加递推有没有用"（这条我们已经有答案：没用）；
**B vs C 才说明"结构有没有用"**——这是这条支线里**第一次**能把这两个问题分开。

## 判据

| # | 门槛 | 判什么 | 不过怎么办 |
| :--- | :--- | :--- | :--- |
| **S8-0** | 跨区系数置 0 时**逐位等价于**纯前馈现模型 | 实现没换模型 | 修实现 |
| **S8-1** | 四条臂启动后 120 步内，中位电流比落在 **[0.4, 0.6]** | 标定有效 | 重标；**标不定就不许跑质量臂** |
| **S8-2** | **B − C ≥ +1pp**（同预算） | **结构**有没有用 | 结构否，S8 收口，递推轴彻底关闭 |
| **S8-3** | B − A ≥ +1pp | 递推整体仍是正的 | 递推再负一次，照登 |
| **S8-4** | 训练后放电率 ≤ 初始的 **2×** | 工作点没崩 | 该臂作废，报数并说明 |

**S8-2 是判决点。** S8-2 不过而 S8-3 过 ⇒ 只是"又加了一次递推"，与结构无关，**结论按 S8-2 记**。

## 预算与阶梯

| 阶 | 预算 | 臂 | 通过条件 |
| :--- | :--- | :--- | :--- |
| 1 筛选 | 4,000 步、2 抽头 | A/B/C/D | 见上表 |
| 2 确认 | 16,000 步、2 抽头 | 仅 S8-2 与 S8-3 都过的臂 | — |
| 3 组合 | 16,000 步 | 通过臂 + **D2（+1 层）** | 仅当阶 2 过 |

**先只跑阶 1**（4 条 × 约 15 分钟 ≈ 1 小时）。阶 2/3 要另起预算。

## 必须一起报的混淆项

1. **A 基线与 B/C/D 的参数量不同**（多了 34×1024 ≈ 35k 个递归权重，占 3.4M 的 1%）；
2. **B/C 的电流比是按目标标定的，A 没有递推** ⇒ B−A 的差里含"多了一个被标定过的电流源"；
3. 单折、单种子；4,000 步峰值未到 ⇒ 所有 Δ 是**下界**。

## 不做的事

- 不改读出（K 固定 2）、不改 τ、不改精度、不改伪导数；
- 不做学习型 router、不做 MoE 式门控；
- 不在阶 1 通过前碰深度。

## 边界

- 单折（KdConv test，4,868 对）、单种子、字符级；
- 小世界的效果**依赖簇的划分是否与输入语义对齐**，本轮用随机划分（不引入外部结构）——
  若阶 1 是负的，**这不能否证"语义对齐的簇"**，只能否证"随机簇的小世界"。
  **这一条必须写进结论**，否则又是一次过度推广。
