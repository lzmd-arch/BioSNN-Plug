# 预注册：+50.3pp 是"更多神经元"还是"更细的分辨率"？

**日期**：2026-11-14，跑之前写。
**背景**：基因搜索把池从 16 加到 32 神经元，top-1 从 0.309 涨到 0.8125（+50.3pp）。
**但池 32 同时改了两件事**：神经元数量 ×2，以及温度计码的阈值级数 ×2。
不分开它们，这个结果就会被误读成"加神经元有用"——而容量轴已经归档过相反的结论。

## 一、判据（写死）

三个配置，同一任务、同批样本、同一尺度标定：

| 配置 | 神经元 | 阈值级数 |
| :--- | ---: | ---: |
| **A 基线** | 16 | 16 |
| **B 级数翻倍** | 32 | 32 |
| **C 只加数量** | 32 | **16（每级重复两次）** |

| # | 判据 | 阈值 |
| :--- | :--- | :--- |
| **R-1** | B 相对 A | 复现 +40pp 以上（确认基因结果是真的） |
| **R-2** | C 与 A 的差 | **≤ 5pp ⇒ 增益来自分辨率**；**≥ 20pp ⇒ 增益来自数量**；中间 = 两者都有 |

## 二、成本曲线

另跑池 ∈ {8, 16, 32, 64}，都取满分辨率，报 **top-1 与神经元数**，给出**每 1pp 要多少神经元**。

## 三、不做什么

- 不改任务、不改编码族（仍是温度计码）；
- 不调尺度（沿用预注册 amend4 的标定值 2.0）；
- 不在本轮换到向量池。
