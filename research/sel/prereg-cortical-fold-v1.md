# 预注册 v7：折叠的皮层薄片 —— 物理 3 维嵌入是否起作用

**写于** 2026-11-16，**在任何一档跑之前**。

## 前提修正

用户指出：**脑组织就是 3 维的，硅基不可能低于 3 维。**
这纠正了我此前把"1D/2D/3D 格点拓扑"当成"空间结构"的错误 ——
那些神经元**没有物理坐标**，连接也不服从 3 维空间的距离定律。

三个"维"必须分开：
**嵌入维（物理，固定为 3）· 状态空间维（大）· 内在流形维（低，动力学的产物）**。
⇒ **嵌入维不是可选项**。可变的是"3 维空间如何约束接线"。

## 设计：在 3 维中折叠的 2 维薄片

- `n = 4096` 个神经元排在 `64 × 64` 的**环面薄片**上（`x, y` 周期）；
- 折叠：`z = A · sin(2π·k·x / L)`，`A = 16`、`k = 1`（薄片尺度 64，折叠幅度相当大）；
- 每个神经元取 `deg = 32` 个前突触伙伴，概率 `∝ exp(−d/λ)`，`λ = 4`；
- **候选窗**：薄片坐标 ±12。

**两个接线度量**：

| 臂 | `d` 用哪个 | 折叠的影响 |
| :--- | :--- | :--- |
| `sheet` | **薄片（2D 环面）距离** | 无 —— 图与不折叠**完全相同** |
| `space` | **3 维欧氏距离** `√(dx²+dy²+dz²)` | 有 —— 折叠改变了谁和谁连 |

`sheet` 臂同时是**内置的零对照**：无论折没折，它的图都一样。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **P-0** | 两臂真实发放率 ∈ [0.03, 0.20]，且**记忆曲线的峰值** > 底板 + 10pp | 不过 ⇒ 作废 |
| **P-1 折叠确实改了接线** | `Jaccard(sheet, space)` | **< 0.8** |
| **P-2 折叠改变能力** | `acc(space) − acc(sheet)` 在 **7/7 种子**同号 | 符号检验 p<0.05 |
| **P-3 折叠改变记忆保持** | `AUC(space) − AUC(sheet)` 同样 7/7 同号 | 同上 |
| — | 效应量照报，不作判据 | — |

（说明：本轮只跑**线索保持任务**，不再跑循环任务 —— 循环任务的准确率已在
v3/v4 里四次证明对自变量不敏感；"acc" 一律指记忆曲线的峰值解码准确率。）

**P-2/P-3 同时测两个量**：因为我们已四次的经验是"准确率对很多自变量都不敏感"，
所以同时报记忆保持曲线，避免再一次把结论压在单一指标上。

## 若 P-1 过而 P-2/P-3 都不过

⇒ **折叠确实改变了接线，但改变不了能力**。那就是一个干净的负结果：
物理 3 维嵌入改变了图，但在这个读出下不产生可测差异。
照实记，**不改符号检验**。
