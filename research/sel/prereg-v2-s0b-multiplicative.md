# 预注册 S0b：标定型（乘性）算子 —— 把 S0 的负结果变成可测的下一步

**日期**：2026-11-14，**在看到任何 S0b 结果之前**。
**前置**：S0 已跑完并落盘（`sweep_results/v2_s0/README.md`）。S0 的结论是
**这份数据上的全部头寸在标定上**（全局温度 +0.862 nats，加性条件偏置 +0.0025 nats），
而预注册的加性算子**结构上表达不出整体缩放**。本文件测能表达它的那一族。

## 一、算子

```
z_c = log q(c) / τ(p) + (p·W)·A_c        τ(p) = softplus(p·w + b₀) + 0.1
```

| 臂 | 自由度 |
| :--- | :--- |
| **B0** | 无（Qwen 原样） |
| **B2** | 全局温度（1 个标量，训练折选） |
| **B3** | **只学 τ(p)**（8+1 个参数）——纯自适应标定 |
| **B4** | **τ(p) + 加性偏置**（8+1+r·C） |
