# 预注册：双曲几何用在推理 / 读出 / 记忆

**日期**：2026-11-16
**前置事实**：`geom_hyperbolic.py` 已测——在**无层级**的隐状态任务上，
双曲（0.591）略低于欧氏 2D（0.606），度数锁死 64.0、工作点全部合规。

> **结论不是"双曲没用"，是"那个任务没有层级可吃"。**
> 所以下面三处，每一处都必须配一个**真有层级**的任务，否则重演同一个负结果。

---

## 一、三处的形态

| 用途 | 双曲做什么 | 必须有层级的任务 |
| :--- | :--- | :--- |
| **记忆** | Poincaré 嵌入：会话→轮次→句子→事实 | 层级检索：按上层话题缩小范围，再在下层定位 |
| **读出** | 特征映射到 Poincaré 球，用**双曲距离到原型**分类 | 层级分类：粗类→细类 |
| **推理** | 在树上走：向上到共同祖先、再向下 | 树遍历题：`A 和 B 的共同上级是谁` |

---

## 二、判据

### H-M 记忆

| 编号 | 判据 | 通过线 |
| :--- | :--- | :--- |
| **HM-1** | 同嵌入维度下，`hit@1` 随条数增长的**保持长度** | 双曲 ≥ 欧氏 **2×** |
| **HM-2** | 在 N=1,024 时 `hit@1` | 双曲 ≥ 欧氏 **+10pp** |
| **HM-3** | 打乱树的层级（同节点、随机父子关系）后增益消失 | 归因成立 |

**HM-3 是关键**：如果打乱层级后双曲仍然赢，那赢的就不是层级。

### H-R 读出

| 编号 | 判据 | 通过线 |
| :--- | :--- | :--- |
| **HR-1** | 层级分类上，双曲读出 > 欧氏读出（同维度、同参数量） | **≥5pp** |
| **HR-2** | 换成**扁平**分类（无层级）后增益消失 | 归因成立 |

### H-I 推理

| 编号 | 判据 | 通过线 |
| :--- | :--- | :--- |
| **HI-1** | 树遍历题正确率 | 双曲 ≥ 欧氏 **+10pp** |
| **HI-2** | 树深 D 加倍时，正确率下降幅度 | 双曲下降 **≤** 欧氏的一半 |

---

## 三、纪律

1. **三处都要先过"层级是真的"这一关**（HM-3 / HR-2），否则不进结论；
2. **度数、维度、参数量必须锁死**——今天已经证明不锁就是在比别的；
3. **不顺带宣传**：`docs/consciousness-framework` 的叙事层可以写"器灵/修仙"，
   **这里只写数**。

---

## 四、实跑结果（2026-11-16）——**三条测法，全部没有优势**

### 4.1 无层级任务（`geom_hyperbolic.py`，度数锁死 64.0）

| 几何 | gain 0.1 | gain 0.2 | gain 0.4 |
| :--- | ---: | ---: | ---: |
| 欧氏 2D | 0.583 | 0.602 | **0.606** |
| 欧氏 3D | 0.593 | 0.590 | 0.597 |
| **双曲** | 0.573 | 0.590 | 0.591 |

X-0（度数极差 0.0%）、X-1（发放 0.115–0.171、全部 >门槛）**全过** ⇒ 比较有效。
**X-2 不过**（双曲 − 欧氏 2D = **−1.6pp**）。

### 4.2 检索抗噪（`hyperbolic_memory.py`）

| N | σ=5e-4 | σ=2e-3 | σ=5e-3 |
| ---: | :--- | :--- | :--- |
| 64 | 欧 1.00 / 双 1.00 | 欧 1.00 / 双 1.00 | 欧 1.00 / 双 1.00 |
| 256 | 欧 1.00 / 双 1.00 | 欧 1.00 / 双 1.00 | 欧 0.99 / 双 0.98 |
| 1024 | 欧 1.00 / 双 1.00 | 欧 0.85 / 双 0.87 | 欧 0.46 / 双 0.45 |
| 4096 | 欧 0.89 / 双 0.88 | 欧 0.32 / 双 0.30 | 欧 0.13 / 双 0.13 |

**逐格差 ≤0.02，且这是数学上必然的**：同一个角度扰动，双曲里的弧长放大
`sinh(r)` 倍，但噪声同步放大同样的倍数 ⇒ **噪声/间隔的比值是不变量**。
抗噪性上双曲不可能赢。

### 4.3 树的距离秩相关（深度 2–4，叶子间树距离 vs 嵌入距离）

| 叶子数 | 欧氏 | 双曲 |
| ---: | ---: | ---: |
| 256 | 0.504 | 0.496 |

**持平。**（深度 5 因内存不足未完成，前三档已足以判读。）

## 五、结论：**不把双曲进产品路径**

三条测法覆盖了"推理/读出/记忆"里最能量化的部分，**全部没有优势**。

**但准确的说法不是"双曲没用"**，而是：

> **我们没有实现出能兑现那个理论优势的构造。**
> 本实验的双曲嵌入把**所有叶子放在同一半径**、角度按分支扇区均分——
> 那不是 Sarkar 的树嵌入（Sarkar 让**深度决定半径**，才拿到指数容量）。

要它成立，需要同时满足三件：

1. 正确的 Sarkar 型构造（深度→半径）；
2. 任务真的含层级（本轮的检索任务是"同一圈上等距点"，层级只体现在扇区）；
3. **嵌入维度是瓶颈**——而我们的记忆瓶颈是 EMA 轨迹容量（N≈64 墙），不是嵌入维度。

**所以：记为"理论有据、我们未兑现"的负结果，不写进架构。**

### 反诱惑条款

材料里"双曲记忆空间"的论证是**成立的一般命题**，但它**不构成在我们这套系统里采用的证据**。
凡引用它，必须同时引用本节的三条零结果。
