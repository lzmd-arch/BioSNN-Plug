# 预注册 v5：时序记忆深度（线索保持任务）

**写于** 2026-11-16，在 v4 之后、**本轮任何一档跑之前**。

## 为什么换判据

v3/v4 里两个自变量都通了机制、都没接到能力上：

| 自变量 | 机制 | 能力 |
| :--- | :--- | :--- |
| `γ`（`E` 进痕迹） | 结构 0.895 → 0.763 | 极差 1.5pp |
| `η`（`E` 定设定点） | 发放 −17% | +0.5pp |

而且 v4 测到**能力对活动水平有 17% 的余量**。两条一起看，指向同一个怀疑：
**是分类准确率对我们的自变量不敏感，不是机制失效。**

## 为什么不能用现有任务测记忆

现有任务是**循环**的：`s_t = (phase + t) mod K`，所以 `s_{t−k}` 由 `s_t` 唯一决定。
解出"上一步是什么状态"与解出"当前状态"信息量相同 —— **用它测记忆深度是假的**。

## 新任务：线索保持（delay task）

1. 每条序列在 `t = 0` 注入一个**随机线索** `c ∈ [0, 16)`；
2. 之后跑中性背景流（与线索无关）；
3. 在特征步 `i`（`t = 8i`）上，从网络状态解码 `c`。

`lag = i` 就是"多少步之前的信息还在"。**网络必须自己把 `c` 保持在状态里**，
没有任何输入再提它。这正是结构/活动该直接影响的东西。

## 四档

| 臂 | 自变量 | 取自 |
| :--- | :--- | :--- |
| `g0` | `γ=0` | v3 的参照 |
| `g4` | `γ=4` | v3 里结构差异最大的一档 |
| `eta0` | `η=0` | v4 的参照 |
| `eta2` | `η=2` | v4 里活动最低的一档 |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **MD-0** | `lag=0` 的 acc ≥ 底板 + 10pp；发放在 [0.03, 0.20] | 不过 ⇒ 作废 |
| **MD-1** | 每臂的曲线随 lag **单调下降**（允许一步持平） | 基本合理性 |
| **MD-2 深度定义** | 深度 = 最大的 lag 使 acc ≥ 底板 + 10pp | — |
| **MD-3 判据能看见差异** | 至少一对臂的深度差 **≥1 步**，且 **3/3 种子同向** | **本轮的核心** |

**MD-3 是这一轮存在的理由**：若成立 ⇒ 上一轮"结构/活动不重要"是**判据的问题**，
不是机制的问题；若不成立 ⇒ 两个自变量连记忆深度也不影响，
那就要怀疑"修剪与设定点这两个自由度本身太弱"。

## 不做的事

- 不加可学参数，不改读出（沿用 `mlp_probe`）；
- **不声称任何超出本轮的结论**。

## amend1：样本预算 384 → 1536

**写于**第一次运行之后、**任何有效结果之前**。

第一次跑 `--train-seq 384`，MD-0 直接不过：lag=0 的准确率 **0.059 < 底板 0.066**。
原因不是线索没保持住，是**读出学不动**：384 个样本对 4096 维特征
（**0.09 样本/特征**），16 类，MLP 必然背训练集。

对照：`dim_ladder` 的比值是 **0.375**（3072 样本 / 8192 特征），那里能到 0.44。
本实验要的是同一量级，所以 `--train-seq 1536 --test-seq 384`。

**判据一个字没改**：MD-0/MD-1/MD-2/MD-3 全部保留。
只改测量工具的样本预算 —— 这与 `state_info` 的 amend2（探针 λ 要选）是同一类修正。

## amend2：线索保持 4 步；MD-0 改判「曲线峰值」

**写于**第二次运行之后、**任何有效结果之前**（前两轮都因 MD-0 不过而作废）。

### 第一次暴露的：样本预算
384 样本 / 4096 特征（0.09 样本/特征）⇒ 读出学不动。已改 1536（amend1）。

### 第二次暴露的：锚点和强度都不对

补足样本后：

| lag | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `g0` | **0.055** | 0.087 | **0.093** | 0.069 | 0.069 | 0.069 | 0.064 | 0.069 |

底板 0.055。两件事：

1. **`lag=0` 恰好等于底板**，而 `lag=1/2` 更高。原因：`t=0` 时膜电位 `v` 还是零，
   单步注入**还没变成放电模式**。⇒ 判在 `lag=0` 是**锚点选错**，
   不是"线索没保持住"。
2. **线索太弱**：峰值只比底板高 **3.9pp**，到 `lag=3` 就回到地板。
   单步注入扛不过背景流。

### 改法（判据的**意图**不变，形式修正）

- 线索在 `t < 4` 的**前 4 步**持续注入（生物学上对应"刺激有持续时间"，不是单帧闪光）；
- **MD-0 改为"曲线的峰值 ≥ 底板 + 10pp"** —— 它要问的本来就是
  "**线索在状态里到底有没有**"，而不是"在第 0 步有没有"；
- MD-1 / MD-2 / MD-3 一个字没改。

前两轮**作废**，数据不作判据。
