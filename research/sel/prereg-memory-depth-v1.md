# 预注册 v5：时序记忆深度（线索保持任务）

**写于** 2026-11-16，在 v4 之后、**本轮任何一档跑之前**。

## 为什么换判据

v3/v4 里两个自变量都通了机制、都没接到能力上：

| 自变量 | 机制 | 能力 |
| :--- | :--- | :--- |
| `γ`（`E` 进痕迹） | 结构 0.895 → 0.763 | 极差 1.5pp |
| `η`（`E` 定设定点） | 发放 −17% | +0.5pp |

而且 v4 测到**能力对活动水平有 17% 的余量**。两条一起看，指向同一个怀疑：
**是分类准确率对我们的自变量不敏感，不是机制失效。**

## 为什么不能用现有任务测记忆

现有任务是**循环**的：`s_t = (phase + t) mod K`，所以 `s_{t−k}` 由 `s_t` 唯一决定。
解出"上一步是什么状态"与解出"当前状态"信息量相同 —— **用它测记忆深度是假的**。

## 新任务：线索保持（delay task）

1. 每条序列在 `t = 0` 注入一个**随机线索** `c ∈ [0, 16)`；
2. 之后跑中性背景流（与线索无关）；
3. 在特征步 `i`（`t = 8i`）上，从网络状态解码 `c`。

`lag = i` 就是"多少步之前的信息还在"。**网络必须自己把 `c` 保持在状态里**，
没有任何输入再提它。这正是结构/活动该直接影响的东西。

| 臂 | 自变量 | 取自 |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **MD-0** | `lag=0` 的 acc ≥ 底板 + 10pp；发放在 [0.03, 0.20] | 不过 ⇒ 作废 |
| **MD-1** | 每臂的曲线随 lag **单调下降**（允许一步持平） | 基本合理性 |
| **MD-2 深度定义** | 深度 = 最大的 lag 使 acc ≥ 底板 + 10pp | — |
| **MD-3 判据能看见差异** | 至少一对臂的深度差 **≥1 步**，且 **3/3 种子同向** | **本轮的核心** |

**MD-3 是这一轮存在的理由**：若成立 ⇒ 上一轮"结构/活动不重要"是**判据的问题**，
不是机制的问题；若不成立 ⇒ 两个自变量连记忆深度也不影响，
那就要怀疑"修剪与设定点这两个自由度本身太弱"。
