# 预注册 v25：M6p 多池竞争 —— 给"图案"一个能存在的地方

**写于** 2026-11-16，**在任何一档跑之前**。

## 为什么是这一步

M6 结案：零输入下的持续状态**只有一维**（一个由历史决定的活跃水平）。
残余 PR 1.83、图案比 1.05×、四档场强全不成立，且**方向与预测相反**。

诊断：这不是参数没调好，是**架构里没有"图案"这个东西可以存在**。
一个同质池 + 全局抑制 ⇒ 唯一的不动点就是一个标量。

## 改三样（都不是调参，是加结构）

1. **多池**：32×32 环面切成 K 个**连续**域（K = 2 / 4 / 8）。
   同池候选的接线分数 ×`(1+β)`，β ∈ {0, 2}。β=0 是"有池名但无池结构"的零对照。
2. **交叉抑制**：`cur_i += g_inh·(φ_{k(i)} − φ)`，φ_k 是第 k 池的平均发放、φ 是总平均。
   数学上等价于"同池自兴奋 + 全局抑制"，即经典 WTA。`g_inh=0` 时逐项退化。
3. **慢增益**：内增益更新率 `eta_gain` 可调（{-1 = 不施加, 0.2, 2.0}）。
   生物上稳态可塑性是小时级、放电是毫秒级；M6 的代码让增益 **40 步**就追平 ⇒
   它本身就是一个把图案抹平的力。`eta_gain=-1` 时**自发期不施加增益**（= M6 原样）。

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **P-0 仪器** | `K=1, β=0, g_inh=0, eta_gain=-1` 复现 M6 的 `gf=1.0/p=0.02` 后期发放 **0.1420 ± 0.010** | 不过 ⇒ 全部作废 |
| **P-1 存在** | 至少一档 4 池或 8 池臂的后期自发发放 ∈ **[0.01, 0.20]** | 不过 ⇒ 该架构无自发活动，作废 |
| **P-2 竞争真的发生** ★ | 最好那档：**胜者池发放 ≥ 2× 其余池均值，且 ≥ 5/6 种子** | 不过 ⇒ 没有 WTA |
| **P-3 胜者由历史定** ★★ | 同一 seed 的三种历史 {A, B, A'} 里，获胜池**不恒定**（≥2 个不同胜者），**≥ 4/6 种子** | **本轮核心之一** |
| **P-4 图案带历史** ★★★ | 去均值后的池向量 `R̃` 上，历史距离 / 对照距离 **> 1.5 且 ≥ 5/6 种子** | **本轮核心之二** |

**P-4 是定义性判据**：它只问**图案**（去掉整体活跃水平之后剩下的那一部分）带不带历史。
M6 测的正是这个，得到 1.05×。若本轮仍是 1.0× 附近，则"一维个体"不是场强问题、
也不是池数量问题，而是**这个动力学族本身**的问题。

## 对照（与 M6/M7 一致）

- **历史 A**：Dirichlet α=0.5、seed `100+s`
- **历史 B**：Dirichlet α=20.0、seed `100+s`（统计不同 = 内容不同）
- **对照 A'**：Dirichlet α=0.5、seed `900+s`（**统计相同、随机流不同**）

历史期 T=1024，自发期 T=256，末 64 步取率。每条件 B=32 个个体（按个体测，不再先平均）。

## 已知的口径变化（必须写进结果）

M6 的残余 PR 是**先对 batch 平均再算**的。本轮**按个体算**（32 个个体，样本更足），
所以 P-4 的绝对值与 M6 的 1.83 不可直接比。为可比，同时报告两端：
`PR(批次均值)`（对齐 M6 口径）与 `PR(逐个体)`（本轮主用）。

## 限定

- 6 种子；K 与 β 各二到三档，不是穷举；
- `eigvalsh` 是线性谱 ⇒ **非线性图案仍是盲区**（M6 §五-3 未解决）；
- 池是**连续空间域**（生物上像皮层分区）；交错池不在本轮。

## 修订 1（**开跑前**，2026-11-16，冒烟之后、正式跑之前）

实测同池入边比例：

| 配置 | 同池入边 | 随机基线 |
| :--- | ---: | ---: |
| K=4, β=0 | **0.901** | 0.250 |
| K=4, β=2 | **1.000** | 0.250 |
| K=8, β=0 | **0.850** | 0.125 |
| K=8, β=2 | **1.000** | 0.125 |

**`exp(−d/4)` 的几何本身就已经在分区**（环面距离短），β 只是把池从 0.90 推到 1.00 ——
后者是**四个断开的子网**，不是"有池"。**β 这个维度没有信息量，砍掉，固定 β=0。**

预算改给 `g_inh`（四档）与 `eta_gain`（三档）。K=1 时 `g_inh` 是恒等零算子
（`φ_k ≡ φ`），所以 K=1 只跑一档 `g_inh=0`。

**判据不变**（P-0 … P-4 原样）。
