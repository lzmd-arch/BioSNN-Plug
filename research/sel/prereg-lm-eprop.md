## 要回答的唯一问题

**在完全不使用反向传播的前提下，一个脉冲网络能不能学会"预测下一个字"？**

这个问题在本仓**目前零证据**：P4 那条脉冲 LM（`research/sel/student.py`）用的是 `.backward()`；
真正的局部规则实现 `research/eprop/event_driven.py` 只做"整段一个标签"的分类。

## 设计（跑之前定死）

| 项 | 取值 | 理由 |
| :--- | :--- | :--- |
| 模型 | 新写 `research/sel/lm/model.py` 的 `TokenEProp` | per-step + streaming + one-hot 输入 |
| 神经元 | **N = 1,024**，LIF，**单区 τ = 20** | 最小切片；ALIF 在本规模下 O(N²) 内存不可用 |
| fan-in | 32（稀疏循环，沿用 `EventDrivenEProp`） | 与 A 线同口径 |
| 词表 | **V = 274**（字符级，从训练集构建） | 与 P4/bigram 直接可比 |
| 读出 | **单抽头**，τ_read = 8 的 EMA，`(N, V)` | M0 只验"能不能学"，多抽头留到 M1 |
| 块长 | L = 64，batch = 16 | |
| 更新 | 2,000 次 `update`；lr_in = 2e-4，lr_rec = 1e-4，读出 NLMS | |
| 数据 | `D:\AxoData\sel\pairs\v1_amend3\pairs.jsonl`，按 manifest 的 301/44/46 切分 | 与 P4 同一份 |
| 种子 | 0 | 单种子，M0 只判"有没有信号" |

**两个必须做的对照臂**（同一份数据、同一个种子、同一预算）：

- **F（冻结循环）**：`w_rec` 固定不学，其余相同；
- **B（bigram）**：`research/sel/baseline_bigram.py` 在同一测试集上重算。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **M0-0** | 前置：数据与切分对得上 | 重算的 bigram top-1 落在 **0.6457 ± 0.02** |
| **M0-0b** | 前置：初始 CE 接近 `ln V` | 第 0 步 CE ∈ **[5.0, 6.2]**（ln 274 = 5.61） |
| **M0-0c** | 前置：网络真的在发放 | 平均发放率 ∈ **[1%, 30%]** |
| **M0-1** | 局部规则学到了 | 测试集 top-1 **≥ 0.70**（bigram + 5.4pp） |
| **M0-2** | 循环权重真的在学 | `CE(学习 w_rec) ≤ 0.95 × CE(冻结 w_rec)` |
| **M0-3** | 损失单调性 | 末 200 步的训练 CE 中位数 < 首个 200 步中位数的 **0.5×** |

**M0-1 与 M0-2 必须同时成立**，否则"局部学习能做 LM"这个结论不成立：
- 只有 M0-1 过、M0-2 不过 → 模型只是个**可训练的 n-gram**，循环没起作用，扩规模无意义；
- M0-1 不过 → **kill**（按计划 §五）：局部规则连字符统计都学不到，整条线停。

## 预期

**押 M0-1 过、M0-2 过。** 具体：top-1 落在 **0.72–0.82**，CE 落在 **1.6–2.4**。

依据：bigram 已经 0.6457；一层 LIF + 逐时刻局部规则应当能超过它（P4 的 GRU 是 0.8831，
但那是 BPTT）。**若 top-1 < 0.70，我不会调参重跑**，按 kill 判据处理。

## 不做的事

- 不调 τ、不扫学习率、不加抽头、不加区——M0 只答"有没有信号"；
- 不碰真实会话数据（那是合成之后的事）；
- 不因为 M0-1 不过就换种子/换数据重试。

## 边界

- 单种子；语料只有 391 条（测试 46 条、约 1,334 字符），**top-1 的 SE ≈ 0.9pp**，
  所以 0.70 这个门槛约等于 bigram + 6 个标准误——够判"有没有信号"，不够判"好多少"；
- 这个语料是**模板化的单轮 SIR**，不是对话；M0 通过**不代表**能闲聊。
