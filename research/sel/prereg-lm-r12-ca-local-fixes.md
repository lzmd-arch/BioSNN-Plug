## F1 是 bugfix，不是臂

`TokenEProp.step` 的 ψ 掩码用的是**本步更新之后**的 `trace.refractory`，而仓库自己的
`research/eprop/traces.py::refractory_mask` 的 docstring 写死："**判据是上一步之后的计数器，
不是本步之后的**"，并注明用错会让痕迹系统性偏掉 ~20%。A 线（`brainregions/`、`predictive.py`）
用的都是正确口径，**只有 LM 这条线用错**。**2026-11-10 已修**。

- **守卫复跑**：修完后按 **R11 的配置**（8 τ、真语料大折、8,000 步、每 2,000 评测）复跑一次。
  预期 Δ 在噪声内（±0.6–0.9pp）不动——若明显变好，说明 F1 本身值钱，先报再往下走。
- **历史口径**：**R 系全部臂（R0–R11）都在错误掩码下跑出**，结果按当时口径报告，**不重跑**；
  今后引用它们时必须带这句。

## 阶梯：F2 → F3 → F123

**臂顺序按预测的 cos 增量从大到小**，每一步用上一步的实测更新先验。

| 臂 | 改什么 | 预测 cos | 预算 |
| :--- | :--- | ---: | --- |
| **F2** | 学习信号做反向 EMA（补读出滤波的反向路径） | +0.07～0.11 | 8,000 步 |
| **F3** | 资格痕迹乘 `(α − θ·ψ̄_t)`（标量近似，见下） | 剩 ~0.08–0.10 | 8,000 步 |
| **F123** | 三者合并 | 目标 ≥0.97 | 8,000 步 |

**共同配置**：真语料大折、**8 个 τ 的读出（与 R11 逐字相同）**、N=1,024、`tau=20`、
`input_std=0.12`、`lr_in=1e-3`、`lr_out=0.5`、`max_len=192`、种子 0、**每 2,000 步评测**。
**基线**：R11 的峰值 Δ = **−5.31pp**（规则③ v3：报 running max）。

### F2 的实现与两条诚实注记

`signal'_t = d·signal'_{t+1} + signal_t`（`d = exp(−1/τ_read)`），再乘 ψ。

1. **空间局部、时间非因果**：需要**一个序列的延迟**（缓冲 τ_read 步）。批训练无碍；
   **端上持续学习的故事里必须写成"一个序列的延迟"**，不能含糊成"完全在线"；
2. **cos → Δ 的映射无人知道**：cos 0.80 → 0.93 **不线性兑换成 pp**。F2 的 cos 数字是**先验**，
   不是 Δ 承诺；臂的存在就是为了测这个兑换率。

### F3 的实现

正确形式是逐神经元的 `e_t[j,n] = (α − θ·ψ_t^n)·e_{t−1}[j,n] + x_t[j,n]`，那要把痕迹从 `(B,V)`
扩成 `(B,V,N)`（20M 浮点/批），**先做标量近似**：用每步该 batch 的平均 ψ 调制 `(B,V)` 的痕迹。
**若 F3 有效，再上逐神经元版本**（另写预注册）。

## 后备仪器：块长 BPTT（写死触发条件，防情怀）

**只有当以下两条同时成立时，块长阶梯才重新激活**：

1. **F123 之后 cos 仍卡在 ~0.95 以下**（说明还有非局部的缺口）；
2. **F123 的 Δ 改善 ≤ +1pp**（说明局部修法在性能上买不到东西）。

届时按 `prereg-lm-r12-ca-block-length.md` 的设计执行（B192 最大剂量探针先行）。

这是它降级的理由。**

## 预写措辞（沿用 R11 的纪律）

| 结果 | 措辞 |
| :--- | :--- |
| ≥ +3pp | 「局部规则的近似误差是残余缺口的主要来源；三块修正合计兑现 X pp。」 |
| +1 ～ +3pp | 「修正有真实但有限的效应：**超出噪声，低于实用阈值**；是否继续**由形状决定，不由单点决定**。」 |
| ≤ +1pp | 「改善**与零不可分辨**；e-prop 的近似误差在该语料上不是性能瓶颈。**插值/余弦曲线作为负面结果归档**——它划定了"局部规则离真梯度多远"的实测边界。」 |

## 不做的事

- 不重跑 R0–R11（历史臂按当时口径报告）；
- F1 不单独作为"提升臂"宣传（它是 bugfix）；
- 不把 F2 的 cos 数字写成 Δ 承诺；
- 不叠加数据、不改读出 τ、不换语料。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp）；
- 8,000 步（R11 的峰值点），按 v3 处理峰值/过冲；
- 训练后的余弦只在**单抽头读出**上测过（`grad_cosine_trained.py`），8 τ 下的逐抽头反向滤波未测——
  **F2 在 8 τ 下的实际增量可能更大**；
- 字符级 next-token，**不代表能闲聊**。
