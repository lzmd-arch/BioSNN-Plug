# 预注册：R9——归因：4 个**相同** τ 的读出（宽度 4×，信息 0×）（2026-11-08）

**状态：判据先落盘。**

## 理由：R8 一次改了两个变量

R8 把读出从 1,024 维单 EMA 换成 4,096 维（4 个 τ），改善了 **+3.88pp**。
但这一改**同时**动了：

- **宽度**：1,024 → 4,096（参数 1.25M → 4.98M）；
- **τ 多样性**：1 个时间尺度 → 4 个。

"读出维度是杠杆"这句话目前把两者吞在一起。**这直接决定"8 个 τ 值不值得做"**：
若增益来自宽度本身，8 τ 只是继续加参数；若来自 τ 多样性，8 τ 才是真梯度。

## 设计：把 τ 全设成 8.0——宽度不动，信息归零

`readout_taus = (8.0, 8.0, 8.0, 8.0)`：四个抽头的 EMA 衰减**完全相同**，
所以四组特征**逐位相同**（w_out 的 4,096 列里有 1,024 个独立方向，其余是副本）。
宽度、参数量、初始化尺度、NLMS 归一化口径——**全部与 R8 相同**；**只有信息量不同**。

**这是本轮能付得起的最干净的"宽度 vs 多样性"控制**：它把"多 4 倍参数"这件事单独拿出来，
而 τ 多样性归零。

> 更强的对照是"N=4,096 神经元 + 单 EMA"（宽度 4,096，来自神经元而不是抽头），
> 但它把神经元数也改了，且单折成本约 3.4 小时——**本轮不做，记在候选里**。

## 设计（跑之前定死）

| 项 | 基线（R0b） | R8（4 个不同 τ） | **R9（4 个相同 τ）** |
| :--- | :--- | :--- | :--- |
| 语料 / 折 | 真语料大折 | 相同 | 相同 |
| updates | 8,000 | 8,000 | 8,000 |
| 读出维度 | 1,024（单 EMA，τ=8） | 4,096 | **4,096** |
| τ 集合 | {8} | {2, 8, 32, 128} | **{8, 8, 8, 8}** |
| 其余 | N=1,024、`tau=20`、`input_std=0.12`、`lr_in=1e-3`、`lr_out=0.5`、`max_len=192`、种子 0 | 相同 | 相同 |

**对照点**：基线 Δ = **−10.12pp**；R8 Δ = **−6.24pp**（改善 +3.88pp）。

## 预期

**押 R9-2（改善 ≈ 0，甚至略负）**。理由：四个抽头的特征逐位相同，模型类别与基线**完全一致**，
任何差异只能来自初始化尺度（`w_out` 初始 `/sqrt(4096)` 而非 `/sqrt(1024)`）与 NLMS 的归一化——
这两者都是优化层面的扰动，不该产生 +2pp 以上的增益。
**若 R9-1 真的触发，那说明 R8 的增益里有相当一部分是优化假象，这会改写 R8 的结论。**

## 不做的事

- 不做 N=4,096 的对照（成本 3.4 小时，记为候选）；
- 不扫 τ 组合；
- 不改 updates、不改语料、不做多种子。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp）——**+1pp 量级的差别不可分辨**，
  所以判据的中线放在 +1 / +2pp；
- 8,000 步在 CE 的上升段；
- 字符级 next-token，**不代表能闲聊**。

## 成本

8,000 updates × 192 步 × 252 对，读出 4 倍宽 ≈ **1–1.5 小时**（与 R8 同量级）。
