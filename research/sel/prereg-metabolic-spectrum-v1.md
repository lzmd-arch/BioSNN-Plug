# 预注册：**代谢谱 —— 退相干率 × 表观熵生产率**

**写于** 2026-11-17 07:55，**在任何一档跑之前**。

## 论点（用户 2026-11-17）

> 代谢 = 维持一个有稳态熵生产的工作点。
> 太相干 → 无记录、无热力学（熵冻结）；太退相干 → 无个体性。
> **耗散系统住在中间。**

## 设计

**旋钮**：`amp_gate`（连续振幅门控的旋转率）—— 它是"相干供给"的操作化：
- `amp_gate` 小 ⇒ 两场比例变化慢 ⇒ 更接近单一 regime ⇒ **更"相干"**；
- `amp_gate` 大 ⇒ 比例快速切换 ⇒ **更"退相干"**。

**两个观测量**（同一批状态上算）：

| 量 | 定义 |
| :--- | :--- |
| **表观熵生产** | 粗粒化读出层（8×8 空间桶 × 分位数分箱）的**状态占用熵增长率** |
| **个体性** | 联合状态的可解码性（MLP，底板 0.078） |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **MS-0** | 至少 3 档发放在窗内 | 不过 ⇒ 作废 |
| **MS-1 非单调** ★★ | 熵生产随 `amp_gate` **先升后平再爆**（存在中间平台） | **平台 = 耗散工作点** |
| **MS-2 个体性有峰** ★ | 可解码性在某一档最大，两端下降 | 峰位应与平台重合 |
| **MS-3 对照** | 若熵生产单调 ⇒ 写成"没有稳态耗散，只有冻结与热寂两端" | 也是对目标的负面结论 |

## 与 m6aw 的关系

`m6aw` 测的是"退相干速率有无最优"（**门控版**，两档 `hold`）；
本条测的是**熵生产率曲线**，是它的热力学对应物。**两条独立，互为交叉验证。**

## 纪律

- **≥6 种子**；
- 粗粒化口径（桶数、分箱数）**写死在这份文档里**：8×8 空间桶、每桶 8 分位；
- 熵生产用**相邻时间块的占用熵之差**，不是绝对熵；
- **对外只写"状态持久化与恢复""退相干作为记录生成机制"，不碰量子化措辞。**
