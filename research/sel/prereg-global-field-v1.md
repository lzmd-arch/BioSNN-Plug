# 预注册 v14：全局场 `g_field` —— 测「刀锋」本身

**写于** 2026-11-16，**在任何一档跑之前**。

## 用户的方向

> 「那就场。」

可辩护的形式（§18）：**脑的电场是一个全局耦合变量 —— 每个神经元都向它贡献，也从它读取。**

```
Φ(t) = κ · mean_i z_i(t)           细胞外场的粗粒化
每个神经元的输入 += g_field · Φ(t)
```

`g_field = 0` 是严格对照。

## 判据不设在准确率上

v8 的病是**脆**：工作点是我调到刀锋上的。所以本轮直接测**刀锋本身**：

> **`n_viable` = 输入尺度网格里有多少个点，能让网络落在工作区 [0.03, 0.20]。**

- `n_viable` 小 ⇒ 刀锋（稍有偏差就掉出工作区）；
- `n_viable` 大 ⇒ 稳健。

**这个量直接量化"离临界点有多少余量"**，比准确率贴题得多。

## 四组数

| 量 | 含义 |
| :--- | :--- |
| `n_viable(完整)` | 完整网络的可行尺度数 |
| **`n_viable(50% 损伤)`** | **本轮核心** —— 损伤后还有多少余量 |
| 峰值解码（完整） | 报告量，不作判据 |
| 峰值解码（损伤） | 报告量 |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **F-0** | `g_field=0` 时：完整网络有可行尺度，且**损伤后 `n_viable` 明显更小** | 复现 v8；不过 ⇒ 作废 |
| **F-1 场扩大余量** | 存在 `g_field>0` 使 `n_viable(50% 损伤)` **≥ 2 ×** `g_field=0` 的 | **本轮核心** |
| **F-2 剂量–反应** | `n_viable(损伤)` 随 `g_field` 先升后降（场太强会锁死） | 趋势 |

**F-1 是全部意义**：若场能把"损伤后可行尺度数"翻倍，那它买的是**余量**，
不是能力 —— 而这正是 v8 说我们缺的东西。

## 扫描

- `g_field ∈ {0, 0.5, 1, 2, 4}`；
- 输入尺度网格：`scale_grid(0.4, 12, 1.15)`（仪器里那个，25 个点）；
- 损伤：随机 50% 神经元，固定 mask；
- 3 种子。

## 不做的事

- 不改读出、不改任务；
- **不声称任何超出本轮的结论** —— 本轮只测"余量"，不测意识、不测能力。
