# 预注册：S11 —— 冻结 `w_in`，判"隐层学习有没有贡献"（2026-11-11）

**状态：判据先落盘。** 动机见 [`design-local-rule-upgrades.md`](design-local-rule-upgrades.md) 的"不适用"一节。

## 为什么先跑这一条，而不是先建世界模型

"世界模型作为辅助预测目标"只有一格的适用性（想象 rollout 不产生信息、SoS 已归档）。
但**它的前提是"隐层的学习确实在出力"**——否则给它加一条新信号等于往一个已经饱和的方向浇水。

我们从来没有单独量过这件事。模型现在是"输入查表 → 一层阈值 → EMA → 线性读出"，
**如果冻结 `w_in` 后性能不变，那它本质上就是一个随机特征 + 训练过的线性头**，
所有针对隐层的想法（辅助目标、世界模型、递推）都没有增益空间。

## 设计

只改一件事：`learn_hidden=False`（`w_in` 不更新）。其余全同基线。

| 项 | 值 |
| :--- | :--- |
| 语料 / 切分 | KdConv，官方 test（4,868 对） |
| 预算 | 4,000 步、batch 16、2 抽头（τ = 2, 128） |
| 基线 | 同配置不冻结：top-1 **0.2451** / CE **4.417** |
| 种子 | 0 |

## 判据

| # | 门槛 | 结论 |
| :--- | :--- | :--- |
| **S11-1** | 冻结后 top-1 与基线差 **≤ 1pp** | **隐层学习无贡献**。世界模型 / 辅助目标 / 递推增益**这一整类**关闭，按负结果登记 |
| 中间带 | 1 ～ 3pp | 报数，不判；不据此立项 |
| **S11-2** | 差 **≥ 3pp** | 隐层学习有实质贡献 ⇒ 辅助预测目标值得写预注册，**且必须绑定 S8（有状态才有世界模型）** |

CE 一并报。**判读钉在 top-1 上，不钉在 CE 上**（本仓已有多次 CE/top-1 脱钩）。

## 混淆项（写死）

- 冻结臂的参数量**不变**（`w_in` 仍存在，只是不更新）⇒ 与基线严格同参数量；
- 单折、单种子、4,000 步、峰值未到 ⇒ Δ 是**下界**；
- 冻结会让**放电率轨迹不同**（`w_in` 不漂移），故同时报 `firing_rate`。

## 成本

一条臂，约 10 分钟。
