# PINN 式约束残差：把幻觉变成可测的"物理违背"（v1 设计，2026-11-14）

## 一、为什么借 PINN 的框架

PINN 的核心不是"神经网 + 物理"，是**把不可违反的约束写成残差，用残差去筛解**。
语言的幻觉恰好可以这样写：一句话要么被证据蕴含，要么不是；数字要么自洽，要么不自洽；
声称做过的事要么有调用记录，要么没有。**这些都不是"概率高低"，是对/错。**

⇒ 幻觉门控从"打分"改成"**残差是否为零**"。

## 二、五条残差（都可算，不需要训练）

| 残差 | 定义 | 怎么算 | 零残差含义 |
| :--- | :--- | :--- | :--- |
| **R1 证据蕴含** | 事实断言里的实体/数值是否出现在注入证据中 | 断言抽取 + 证据内子串/近邻匹配 | 有据 |
| **R2 工具一致** | 声称做过的动作是否有对应调用记录 | 对照工具轨迹 | 真的做过 |
| **R3 数值自洽** | 同一回答内的数字/日期是否互相矛盾 | 提取所有数值，检查序关系与等值 | 不矛盾 |
| **R4 时间序** | 事件时间是否与记忆里的先后一致 | 对照记忆时间戳 | 顺序对 |
| **R5 实体已知** | 断言提到的人/物是否在记忆或工具结果里出现过 | 实体名对照词表 | 不是凭空造的名 |

**R1 与 R5 是幻觉的主力**；R2 是"说了没做"的主力；R3/R4 是长回答里最常见的自相矛盾。

## 三、门控规则（先分模态，再验残差）

**不能一刀切**——上一轮一刀切的教训：拒答率 0.65。

| 断言类型 | 需要的残差 | 不过怎么办 |
| :--- | :--- | :--- |
| 用户私有事实 | R1 + R5 | 拒答 |
| 工具事实 | R2 | 拒答并纠正（"我没有查到"） |
| 世界知识 | 不需要 R1；只查 R3 | 降级措辞（"据我所知"） |
| **意愿/期望/想象/评价** | **不验** | **放行** |

## 四、和置信度校准的关系

残差是**硬判据**（过/不过）；校准后的置信度是**软判据**（有多确定）。

两者配合：残差为零但置信度低 → 给但加限定；残差非零 → 不给。
⇒ 温度校准是这套门控的**第二根支柱**，不是可选项。

## 五、SNN 在这里的位置：把残差当作它的输入通道

前面诊断得很清楚：**SNN 发挥不出能力，是因为它的输入与千问完全同构**
（同一套分词、没有时间戳、传感器通道零初始化）。

残差向量恰好是一类**千问拿不到的连续输入**：

```
(claim, evidence) → 五维残差 + 时序统计  →  SNN  → 支撑概率
```

- 残差是**连续量**（匹配度、距离、时间差），不是文本；
- 它带**时间结构**（R4 的先后、R3 的序），SNN 的 τ 才有意义；
- 千问只能看到"答案文本 + 证据文本"，看不到这五个数。

**这就是差集。** 不是"让 SNN 更会说话"，是"让它看一个别人看不见的量"。

### 判据（V2，需训练）

| # | 判据 |
| :--- | :--- |
| **PN-1** | 只用残差（无 SNN）的规则门：B1 编造 = 0 且守卫拒答 ≤ 10% —— **先证规则够用** |
| **PN-2** | SNN 门在留出集上**优于 PN-1 的规则门** ≥ 3pp（AUC 或 F1），否则 SNN 不必接入 |
| **PN-3** | 接入 SNN 后，C 组（意愿/期望）拒答率仍为 0 |

**PN-1 先做**：如果规则门已经够了，SNN 就没有位置——这条要先证伪，再谈训练。

## 六、这次先做什么

1. 实现 R1/R2/R3/R5 四条残差（R4 需要时间戳，DB 里已有 `created_at`）；
2. 按模态分组的门控，跑同一批 18 + 40 条；
3. **验收**：B1 编造 = 0、守卫拒答 ≤ 10%、C 组拒答 = 0，三条同时成立；
4. 只有三条都过了，才谈把残差喂给 SNN（V2）。

## 七、不做什么

- 不因为"PINN 好听"就去训一个残差网络——先证规则够不够；
- 不把 R1 做成"整句相似度"（那是旧的验答，口径太钝，拒答 65%）；
- 不动千问权重。
