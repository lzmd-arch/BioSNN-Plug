# 预注册：**行为熵 0.99 是「丰富」还是「掷骰子」**

**写于** 2026-11-17 07:20，**在任何一档追试跑之前**。

## 要解决的问题

`m6ay`：量子闭环的符号熵 **0.98–0.99**（极大值 1.0），四种子方差近零。

**熵在极大值处分不清「丰富」与「噪声」。** 而且**方差塌缩是警报**：
真量子采样应在种子间引入差异；方差塌缩说明分布本身已近均匀 ⇒ Born 采样退化为掷骰子。

## 关键设计：**熵匹配的 shuffle 对照**

把行为串的符号**打乱**（保留每个符号的计数 ⇒ **熵完全相同**），再算结构测度。
**两者熵相同，只有时间结构不同。**

## 结构测度（三个，都算）

| 测度 | 定义 | 有结构时 |
| :--- | :--- | :--- |
| **LZ76 归一化复杂度** | 与 `M10` 同实现（**有自检**） | **real < shuffled**（可压缩） |
| **一阶自相关** | lag 1 的 Pearson | \|real\| > \|shuffled\| |
| **压缩长度** | zlib 压缩后字节数 / 原始长度 | real < shuffled |

## 判据

| 编号 | 判据 | 线 |
| :--- | :--- | :--- |
| **S-0 仪器** | LZ 自检：全零 < 周期3 < 随机 | 不过 ⇒ 作废 |
| **S-1 排除伪丰富** ★★ | 量子串的 LZ **显著低于**熵匹配 shuffle（≥5/6 种子） | 低于 ⇒ **伪丰富成立，正结果降级** |
| **S-2 结构确认** ★ | 若 S-1 不过，则至少一个结构测度显著（自相关或压缩） | 全部不显著 ⇒ **行为是无结构噪声** |
| **S-3 对照** | 经典 argmax 串（熵 0.59）应当**结构明显** | 若它也没结构 ⇒ 仪器或任务有问题 |

## 三种结局

1. **S-1 成立（real < shuffled）** ⇒ 熵 0.99 是**真丰富**，今晚唯一的量子正结果保住；
2. **S-1 不过、S-2 过** ⇒ 部分结构，结论写"弱丰富"；
3. **S-1 与 S-2 都不过、S-3 过** ⇒ **伪丰富确认**，正结果**降级为"不自毁"**，
   并要求解释：**为什么 Born 采样在 12 比特上退化为均匀。**

## 纪律

- **≥6 种子**；
- 串长 ≥ 512（LZ 在短串上不可靠）；
- **熵匹配 shuffle 必须做到计数逐类相同**（不是随机重采）。
