## 主张一：读出**独立信息**的维度是杠杆，且与 regime 无关

| regime | 缩容量 | 扩容量 |
| :--- | :---: | :---: |
| 合成 A（容量约束区） | **−3.74pp**（R3a） | **+4.88pp**（R4） |
| 真语料（记忆化区） | **−1.04pp**（R6q） | **+3.88pp**（R8） |

四格同向：**扩容量在两边都好、缩容量在两边都坏**；"两个 regime 方向相反"的假设被否掉。

**R9 把"维度"这个词收紧了**：同样 4,096 维、同样 4 倍参数，**四个 τ 全设 8.0**（特征逐位相同）
只拿到 **−0.32pp**（噪声内）。所以正确的说法是 **"读出**独立信息**的维度是杠杆"**，
不是"参数多就是好"。

**边界**：缩的一侧是干净的纯宽度操作（单 EMA）；扩的一侧是**宽度 + τ 多样性**一起动，
R9 证明多样性是必要的——但**4 → 8 个 τ 是未测的剂量点**。

## 主张二：数据与规则是两条独立的账

同折、同分词、同截断、同数据暴露、参数量级相近（BP 1.77M vs SNN 2.49M，**SNN 还多一些**）：

| 量 | 数值 |
| :--- | ---: |
| bigram → BP（数据的账） | **0.83pp** |
| BP → SNN（规则的账） | **9.29pp** |
| 读出补上之后（R8）残余的规则账 | **5.41pp** |

**约 92% 的缺口是学习规则/架构，8% 是数据。**

## 主张三：两个已知杠杆**只能叠加 45%**

预注册写死的算法：完全叠加 = R2-B + 读出杠杆 = −1.67 + 4.88 = **+3.21pp**；**实测 +0.55pp** ⇒
**读出杠杆的效应在 5× 数据之后只剩 45%**（+2.22 / +4.88）。

⇒ **"加数据 + 加读出"这条路的上限已经摸到**：它能把局部规则推过 bigram（+0.55pp，两折全赢），
但推不到 BP（真语料 −0.83pp）。再往上只能靠信用分配。

## 主张四：CE 与 top-1 会以六种方式脱钩

| 出处 | 形状 |
| :--- | :--- |
| R0b | CE 升、top-1 平（过拟合） |
| B0（GRU） | top-1 好、CE 极差（自信地错） |
| R6q | top-1 全低、CE 全好（分布更平） |
| R8 / R10 | CE 早见底、top-1 继续涨 |
| **R10** | **top-1 赢 bigram、CE 输 bigram**（3.689 vs 3.438） |

**跨架构的那一种（B0）是主证据**：BP 赢排序（0.1586 vs 0.0657）、输似然（CE 9.31 vs 7.24）。
**但"e-prop 优化概率质量、BP 优化排序"这个解释是反的**——BP 的损失就是交叉熵，
它把训练 CE 压到初始值的 1.75%，是**在测试集上校准崩了**。
准确的画面：**局部规则学到扁平分布（CE 不难看、排序弱），BP 学到尖锐分布（排序强、置信度不迁移）。**

## "核心经验结果"那一行的新口径

> 旧：训练侧没有修复。
> **新：训练侧（数据、训练量、膜时间常数）与读出侧的账已经结清；已知杠杆叠加到 45%，首次推过 bigram（+0.55pp）；
> 残余 5.41pp 的缺口归于信用分配。**

## 不能声称的（写进论文时逐条挡住）

1. **不能**声称局部规则能做闲聊——最好的一臂在真语料上仍输 bigram 6.24pp，语料只有 3.4 万字；
2. **不能**声称"正 Δ"有实用意义——它是**自建合成语料**上的 +0.55pp，且 **CE 仍输**；
3. **不能**声称 8 个 τ 会更好（未测）；**不能**声称 N=4,096 会有用（R9 的决策树已把它降级）；
4. **不能**声称与 BP 的差距"只"由信用分配解释——两者还有优化器、更新次数、稀疏性等差异；
5. **不能**把 R3 的 −3.7/−4.0pp 说成"天花板更低"——三方到 120 epoch 都还在涨；
6. **不能**再把"曲线还在涨"当作"还会涨"——R8 的 16k 补测已经证伪过一次。

## 待验清单（按优先级）

| # | 项 | 状态 / 触发条件 |
| :--- | :--- | :--- |
| 1 | **8 个 τ（4 → 8 的剂量点）** | R9 已判"多样性是真梯度"，可排；预期递减，判据要按"叠加率 45%"的先验写 |
| 2 | **CA：块长扫描（局部 ↔ 全局插值）** | 最大的未解问题（5.41pp）；块长从 1 连续拧到近似全局就是剂量–反应曲线 |
| 3 | 真语料上的"数据 × 读出" | 已知杠杆在真语料上是否也部分叠加；贵（需要先定数据规模） |
| 4 | 膜 τ 与发放率的耦合 | R5 观察：膜 τ ×5 让训练后发放率 0.0132 → 0.0620（4.7×），n=1，需专门设计 |
| 5 | N=4,096 + 单 EMA | **已降级**（R9 判定宽度本身无信息时不涨） |

## 共同边界

- 全部是**单种子或两折**、**固定步数、无早停**；多处仍是"下界"或"峰值"，逐条注明；
- 合成语料不是真实对话；字符级 next-token；**不代表能闲聊**；
- 真语料的测试集只有 **13 对**（噪声 ±0.6–0.9pp），+1pp 量级的差别不可分辨。
