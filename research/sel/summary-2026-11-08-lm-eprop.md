## 主张一：读出维度是杠杆，且与 regime 无关

| regime | 缩容量 | 扩容量 |
| :--- | :---: | :---: |
| 合成 A（容量约束区） | **−3.74pp**（R3a） | **+4.88pp**（R4） |
| 真语料（记忆化区） | **−1.04pp**（R6q） | **+3.88pp**（R8） |

四格同向：**扩容量在两边都好、缩容量在两边都坏。** 这否掉了此前"两个 regime 方向相反"的假设。

**边界（必须写进去）**：

- **缩的一侧是干净的纯宽度操作**（R3 a/b 都是单 EMA，只有宽度 256 vs 1024 在变）；
- **扩的一侧把宽度与 τ 多样性混在一起**（R4/R8 的 4 个 τ），归因实验 **R9** 未跑
  ⇒ 目前只能说"**4 个时间尺度**买到 +3.88～+4.88pp"，**不能说"τ 多样性买到"**。

## 主张二：数据与规则是两条独立的账

同折、同分词、同截断、同数据暴露、参数量级相近（BP 1.77M vs SNN 2.49M，**SNN 还多一些**）：

| 量 | 数值 |
| :--- | ---: |
| bigram → BP（数据的账） | **0.83pp** |
| BP → SNN（规则的账） | **9.29pp** |
| 读出补上之后（R8）残余的规则账 | **5.41pp** |

**约 92% 的缺口是学习规则/架构，8% 是数据。** 这条把"加数据"从主线降到"天花板"。

## 主张三：CE 与 top-1 会以五种方式脱钩——其中一种是跨架构的

| 出处 | 形状 |
| :--- | :--- |
| R0b | CE 升、top-1 平（过拟合） |
| B0（GRU） | top-1 好、CE 极差（自信地错） |
| R6q | top-1 全低、CE 全好（分布更平） |
| R8 | CE 在 2,000 步见底、top-1 一路涨到 8,000 步 |
| R4/R3 | CE 与 top-1 同向（少数例外） |

**跨架构的那一种（B0）**：BP 赢了排序（0.1586 vs 0.0657），输了似然（CE 9.31 vs 7.24）。
**但"e-prop 优化概率质量、BP 优化排序"这个解释是反的**——BP 的损失就是交叉熵，
它把训练 CE 压到初始值的 1.75%，是**在测试集上校准崩了**，不是不会优化似然。
准确的画面是：**局部规则学到扁平分布（CE 不难看、排序弱），BP 学到尖锐分布（排序强、置信度不迁移）。**

## "核心经验结果"那一行的新口径

> 旧：训练侧没有修复。
> **新：训练侧（数据、训练量、膜时间常数）与读出侧的账已经结清；残余 5.41pp 的缺口归于信用分配。**

## 不能声称的（写进论文时逐条挡住）

1. **不能**声称局部规则能做闲聊——最好的一臂在真语料上仍输 bigram 6.24pp，语料只有 3.4 万字；
2. **不能**声称多时间尺度的增益已归因到 τ 多样性（R9 未跑）；
3. **不能**声称 8 个 τ 会更好（R9/R10 未跑）；
4. **不能**声称与 BP 的差距"只"由信用分配解释——两者还有优化器、更新次数、稀疏性等差异；
5. **不能**把 R3 的 −3.7/−4.0pp 说成"天花板更低"——三方到 120 epoch 都还在涨。

| # | 项 | 触发条件 / 状态 |

## 五轮的共同边界

- 全部是**单种子或两折**、**固定步数、无早停**；判读按规则③ v2，多处仍是"下界"；
- 合成语料不是真实对话；字符级 next-token；**不代表能闲聊**；
- 真语料的测试集只有 **13 对**（噪声 ±0.6–0.9pp），+1pp 量级的差别不可分辨。
