# 预注册：R0b——真实语料按 epoch 对齐重跑（2026-11-06）

**状态：判据先落盘，代码未跑。**

## 为什么要这一轮

R0（[`../sweep_results/lm_eprop_r0/README.md`](../../sweep_results/lm_eprop_r0/README.md)）在真实语料上
六折全输、均值 **−10.37pp**，同时每折 CE 尾/首是 **0.57–0.63**——**在收敛判据的边缘**。

R1b 已经证明"2,000 updates 的结果不可信"：同样的语料与架构，把 updates 提到 16,000 之后，
合成语料的 E 档从 +2.1pp 涨到 **+13.6pp**、M 档从 −10.7pp 收窄到 **−1.1pp**。

**所以 R0 的 −10.4pp 大概率也是欠拟合。这一轮测的就是这件事。**

## 设计（跑之前定死）

- **只改 updates**：2,000 → **16,000**（每折 118–252 条训练对，2,000 updates 已是 128–271 epoch；
  16,000 是 **1,024–2,170 epoch**——这一轮不是"补 epoch"，是**把预算拉到与 R1b 同级**，看还会不会再降）；
- 其余与 R0 **逐字相同**：前馈 LIF、N=1,024、**单 τ=20**（不是草案里写的"逐区 τ"——LM 模型没有）、
  `input_std=0.12`、`lr_in=1e-3`、`lr_out=0.5`、`max_len=192`、V 不设上限（R0 同款）、
  六折留一会话、同折 bigram（k=0.5）、种子 0；
- **数据不动**：同一份 265 对，同一套切分。

## 判据

| # | 判据 | 门槛 | 不过时判什么 |
| :--- | :--- | :--- | :--- |
| **R0b-0** | 前置：六折都收敛 | 每折 CE 尾/首 **<0.6** | 仍未收敛 → 标"需 R0c"，**不判红** |

**三种结局：**

| 结局 | 条件 | 含义 |
| :--- | :--- | :--- |
| 🟢 | R0b-1 与 R0b-2 都过 | 真实对话上前馈局部学习也能工作，LM 支线可继续（扩词表 / 扩 N / 混合语料） |
| 🟡 | 2–3/6 折赢，或均值在 0–3pp | 真实语料是边缘任务；下一步是**更深前馈或更长 τ**，不改循环 |
| 🔴 | 0–1/6 折赢**且 R0b-0 过** | **前馈 LIF 在真实对话上的硬边界**：τ≈150 步覆盖不了跨数百 token 的依赖 |

## 预期

**押 R0b-0 过、R0b-1 不过、R0b-2 不过（🟡 或 🔴）。**

具体：均值 Δ 从 −10.4pp 收窄到 **−3 ～ +1pp**。理由：R1b 里最难那档（bigram 0.293）都只到 −3.9pp，
真实语料的 bigram 只有 **0.184**——比合成语料最难那档还低一半。

**若 R0b-1 过（≥4/6 折赢），那是我低估了真实语料上的可学性，要立刻报告并重估整条线。**

## 不做的事

- 不改 N、不改 τ、不加层、不扩词表；
- R0b-0 不过时**不直接跳到 R0c**——那要另写预注册；
- 不把这一轮与 R1b 的 Δ 并列成一条曲线（语料族不同：真实 / 合成）。

## 边界

- 单种子、六折；最小一折只有 715 token（top-1 的 SE ≈1.5pp）；
- 每折独立建词表（R0 同款，V 不设上限，986–1,244 字）；
- **结果文件只写聚合指标，不含任何对话正文**；数据不出本机。

## 成本

R0（2,000 updates × 6 折）约 20 分钟；本轮 8 倍 → **约 2.5 小时**（外推值）。
