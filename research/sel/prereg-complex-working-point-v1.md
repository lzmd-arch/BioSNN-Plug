## 0. 为什么值得认真测

今晚所有工作都建在**实值 LIF** 上：状态 `v ∈ ℝ^N`，读出前 m 个主成分，再展开到二阶。

- 「三轴不可兼得」→ 已被 `m6az` 的连续振幅门控推翻一次（旋转两个模的**振幅**）；

| 说法 | 本实验的对应 |
| :--- | :--- |
| **虚数空间** | 膜电位取复值 `z = a·e^{iφ}`，每个神经元多一个**相位**自由度 |

## 1. 核心机制假设

**实值网络的困境**：共同模态与个体差异**争同一个自由度**（振幅）。
全局场做强 → 积分高、分化塌；做弱 → 反过来。这就是 `m6av/m6aw` 反复看到的权衡。

**复值网络给出第二个自由度**：相位。于是可以

- **共同模态住在相位锁定**（全群同相 → 强整合）；
- **个体差异住在幅度与相位散布**（不同神经元不同频 → 强分化）。

这就是**频率复用**：实值网络只有直流，所有东西挤在 DC 上；复值网络有频带。

**关键预言（C-2）**：若这条机制成立，信息应当**部分住进相位**——
把相位打乱（保留 `|z|`）后解码应当**显著下降**。
若下降为零，则复值只是「多了一倍实数维度」，用户的直觉应被判为**维度效应**而非**相空间效应**。

## 2. 引擎

`scripts/m6bc_complex.py`，与 `m6_pools.run_spont` 并列，不修改它。

```
z_n ← α_n · z_n + scale·Σ_m W_nm·φ(z_m) + I_n
α_n = leak · exp(i·ω_n)          ω_n ~ N(0, σ_ω)   ← 异质固有频率
φ(z) = z · 1[|z| > θ]            发放 = |z| 越过 θ
复位 = z ← z·(1 − θ/|z|)          **保相位**减去阈值（复数版 v − θ）
```

- 用两路实张量实现（`x, y`），三个实数 matmul，不依赖复数 CUDA 支持；
- 连接矩阵、输入、池结构全部复用 `build_pools`，**只换状态空间**；
- `σ_ω = 0` 时 `α` 退化为实数 `leak`，应复现实值引擎的行为（仪器自检 C-0）。

### C-1 存在复值工作点 ★★

存在某一档 `σ_ω > 0` 使五条**同时**成立：

1. 发放 ∈ [0.01, 0.20]
2. PR > 10
3. 整合 > 0.3
4. 分离 > 0.5
5. 可读 > 底板 + 0.15

### C-2 信息在相位里 ★★（决定性控制）

对每个（样本, 神经元）独立随机旋转 `z ← z·e^{iψ}`（**保留 `|z|`**）后重跑解码：

- **掉幅 > 0.15** ⇒ 相位承载信息，**相空间效应成立**；
- **掉幅 < 0.05** ⇒ 只判「复值 = 双倍维度」，用户的直觉在这一档被否；
- 中间 ⇒ 报数，不判方向。

### C-3 频率复用 ★

相位打乱后：若**整合显著保留**（掉幅 < 0.1）而**分离显著塌**（掉幅 > 30%），
则「共同模态住相位、个体差异住幅度/相位散布」成立。

### C-4 全负 ⇒ 登记

若 `σ_ω > 0` 的所有档 C-1 都不过 ⇒ **「工作点不在复平面」**，照登负结果，
**不得调剂量或判据重跑**。

### C-5 超欧臂（次要，只在 C-1 有工作点时跑）

在 M6ba2 判定的**信息方向**（`|z|` 的小方差尾部）上做二阶 vs 三阶展开：

- **增益 > 0.02** ⇒ 高阶仍有信息，§36 的「二次到顶」作废（那是在方差方向上量的）；
- **增益 ≤ 0.02** ⇒ 「二次到顶」升级为**在信息方向上也成立**。

## 4. 已知的坑（写进预注册，免得重犯）

1. **复值 = 2N 维**：`[Re, Im]` 是 2048 维也可能是「维度更多」而不是「相位有用」。
   这正是 C-2 存在的原因——**必须靠打乱相位来分离这两种解释**；
2. **相位打乱必须逐（样本，神经元）独立**。整体旋转所有神经元等于什么都没做；
3. **`|z|` 的边缘分布要在打乱前后逐位相同**，否则测的是分布变化不是相位；
4. **频率异质是一种「旋转的 τ 异质」**。`m6ay` 测过 τ 异质（temp +10.8pp），
   所以 `σ_ω > 0` 若有效，要分清是「第二个自由度」还是「又一种异质」——
   **对照：同幅度异质但不旋转**（`α = leak·r_n`，`r_n` 随机，无相位）。
   这条作为 **C-6**：若 C-1 过但 C-6 对照也同样过，则效应来自**异质**不是**相位**。
