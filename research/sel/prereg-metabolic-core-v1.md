# 预注册：代谢内核（自维持边界 + 能量）

**写于** 2026-11-16，**在任何一档跑之前**。

## 为什么先做这个

目标路线里排第一，因为：**没有可消耗、可恢复的内部资源，稳态、内源驱动、
自我模型都没有附着点**。这是一块地基，不是一项指标。

## 机制（只加一条，且它是生物学里真实存在的）

逐神经元能量 `E ∈ [0,1]`：

```
E  ←  clip( E − c·z + r·(1 − z),  0, 1 )       z = 该神经元本步是否放电
θ_eff = θ · (1 + k·(1 − E))                    饥饿时阈值升高
```

- **放电消耗**（`−c·z`）：动作电位后 Na⁺/K⁺ 泵要还债；
- **静默恢复**（`+r·(1−z)`）：不应期与恢复过程；
- **阈值随能量升高**：能量不足时更难放电。

取 `c = 0.05`、`r = c·f/(1−f)`，`f = 0.08` ⇒ `r = 0.00435`，平衡点在 `E ≈ 0.5`；
`k = 1.0`。

**关键性质**：`E` 的轨迹由**神经元自己的放电历史**决定，**不由输入决定**。
这正是"内部量不可由输入还原"要的东西。

## 三档

| 臂 | 设置 | 作用 |
| :--- | :--- | :--- |
| `ctrl` | `E ≡ 1`（无代谢） | 对照，阈值恒为 `θ` |
| `metab` | 上面那条 | 代谢开 |
| `starve` | `r = 0`（不恢复） | 强制饥饿，检查行为是否**可预测地**退化 |

## 判据

| 编号 | 判据 | 通过线 |
| :--- | :--- | :--- |
| **E-0** | 工作点：真实发放率 ∈ [0.03, 0.20] | 不过 ⇒ 该臂无效 |
| **E-1** | 从**输入 token 序列**预测平均 `E` 的留出 R² | **< 0.5** —— 内部量不可由输入还原 |
| **E-2** | `corr(E, 发放率)` | **< −0.5** —— 能量确实在约束行为 |
| **E-3** | `metab` 准确率 ≥ `ctrl` − 5pp | 代谢不摧毁能力 |
| **E-4** | `starve` 的发放率 < `metab` 的 **0.5 倍** | 饥饿 → 行为可预测地退化 |

E-1 是这一轮的核心：**它把"内部状态是它自己的"变成一个数**。
E-3 则不设"必须更好"——**这一步不追性能**，只要求不塌。

## 不做的事

- 不加新的可学参数；
- 不改任务、不改读出（沿用 `bio_all` 的隐状态解码 + `mlp_probe`）；
- **不声称任何超出本轮的结论** —— 这一轮只测"内部量是否自持"。

## 若 E-1 不过

说明 `E` 能从输入重建 ⇒ 它不是一个独立内部量，只是一个输入的影子。
那就要改的是"能量从哪来"，不是判据。
