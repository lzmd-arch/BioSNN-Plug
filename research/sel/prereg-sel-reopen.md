# 预注册：SEL 风格层的**重新立项**（2026-11-11）

**这不是推翻 ADR-0034，是换一个更窄的问题重开。** 原文写的是「概念保留、路径停止」——
本文把"保留的那个概念"落到一个可判的最小形态上。

## 一、ADR-0034 关掉的到底是什么

关掉的是 **P0–P4 那条蒸馏路径**：TI-LIF 学生去逼近 ALIF/GRU 教师。

| 判据 | 结果 |
| :--- | :--- |
| P4-1（≥0.7457） | 过 |
| P4-2（≥GRU−5pp） | 过 |
| **P4-3（TI-LIF CE ≤ ALIF 的 0.90×）** | **不过：1.148×** |

**那个结论不变，也不重做。** 换后端模型时语气不变这个痛点仍然真实，只是"训一个脉冲学生去蒸馏"
这条路被证否了。

## 二、现在手里多了什么（ADR-0034 写的时候还没有）

| 资产 | 日期 | 意义 |
| :--- | :--- | :--- |
| 局部规则 LM 跑通 | 2026-11-06 起 | 有一个**已训好的 SNN 基底**，不再是"要先造一个学生" |
| 多抽头读出（K=2） | R11 | 特征从 1 个 EMA 变成 2 个，表达力翻倍且饱和点已知 |
| **层次 softmax 树** | 2026-11-11 | 读出成本降到 `M·12.18`，**1B 在 CPU（N100）上可行** |
| 共享特征的四头架构 | 本文 | 风格/触发器/记忆编码都只是特征上的小头，**不到 LM 的 1%** |

**关键差异：P4 要造一个新网络；现在只需要在已有基底上加一个头。**

## 三、方案（最小形态）

风格向量加在**特征**上，不加在输出上：

```
f' = f + s[style]          s: (S, M)，S 是风格数
logits = f' · W[node]      （树读出不变）
```

- 参数：`S × M`。S=8、M=20,833 ⇒ **167k，是 LM 的 0.017%**；
- 更新仍是局部的：`∂L/∂s = delta · W[node]` 按路径求和，与读出信号同构，**不需要反向传播**；
- 等价守卫天然成立：`s` 全零时与原模型**逐位一致**。

## 四、判据（写死，缺一条不算过）

| # | 判据 | 不过怎么办 |
| :--- | :--- | :--- |
| **S-0** | `s ≡ 0` 时与现模型逐位一致 | 实现错了，先修 |
| **S-1** | **风格可分**：用留出集训一个线性探针，从 `f` 判风格的准确率 ≥ 0.70（多数类基线 +20pp） | **共享特征里根本没有风格信息** ⇒ 收口（这正是 M-3 踩过的坑） |
| **S-2** | **不干扰**：加头并训练后，LM 的 top-10 掉 ≤ 0.5pp | 头在抢容量，收口 |
| **S-3** | **可切换**：同一输入换风格标签，下一个 token 分布的 KL ≥ 0.1 nats，且方向与标签语义一致（人工看 20 例） | 头学了个没用的偏移，收口 |

**S-1 是前置**：如果连"从特征里线性读出风格"都做不到，加风格向量就是自欺。

## 五、数据（这是最大的障碍，先说清楚）

KdConv 没有风格标签，SkyPile 也没有。三条可选：

1. **合成**：用模板把同一批内容改写成 N 种语气（正式/口语/简短/热情…）——本项目已有
   `gen_synth.py` 的教师管线，但**教师是本机 Ollama**，产出只落仓外；
2. **半自动**：用云端模型给现有对话打风格标签（**正文不出本机，只出标签**）；
3. **人工标 50–100 条**做验证集，其余靠规则。

**在第 1 或 2 条落地之前，S-1 无法开跑。** 这是本文档写下的阻塞项，不是可以绕过的细节。

## 六、四条限定

1. **单折单种子**起步；S-1/S-3 过了再谈复现；
2. **风格是"加性偏移"这个假设本身可错**——若 S-1 过而 S-3 不过，说明风格不是特征空间的平移；
3. **不与 BPTT 比数字**，只看 S-1/S-2/S-3 三条产品口径；
4. **N100 部署是最终约束**：风格头让每 token 多读 `S×M`（S=8 时 167k×4B = 0.67 MB）
   —— **比树读出的 1.01 MB 只小一点，必须按行/按风格稀疏化**，否则 1B 在 CPU 上会被它拖慢一半。
