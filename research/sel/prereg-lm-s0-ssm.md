**状态：判据先落盘，代码未写。** 本文件承接用户给的 S0 草案，**改了三处**（见 §0）。

## 0. 相对草案改了哪三处

| 草案 | 改成 | 为什么 |
| :--- | :--- | :--- |
| 通过线 top-1 ≥0.60 | **主判据是赢 bigram（0.646）**；0.60 只作"没死"的次判据 | 0.60 高于冻结循环 0.566，但**仍输给一个字符 bigram 0.646**——那不是"通过"，是"换了个方式输" |

另：神经元用 **LIF**（不是 TI-LIF）——TI-LIF 是 SEL 的神经元，换它等于同时改两件事，本轮只该改"递推结构"。

## 1. 要回答的唯一问题

**把冻结的随机循环换成冻结的结构化递推（对角 SSM），在同样的局部学习框架下，能不能改善 next-token？**

M0b 已知（同一份语料、同一预算）：

| 臂 | CE | top-1 |
| :--- | ---: | ---: |
| bigram（k=0.1） | **1.423** | **0.646** |
| 冻结随机循环 | 1.741 | 0.566 |
| 学习循环 | 1.861 | 0.516 |

## 2. 设计（跑之前定死）

**三个臂，同一份数据、同一个种子、同一预算，只有"递推从哪来"不同：**

| 臂 | 循环电流的来源 | 可学 | 冻结 |
| :--- | :--- | :--- | :--- |
| `none` | 无（纯前馈 LIF） | `w_in`、读出 | — |
| `random` | 冻结随机 `w_rec`（M0b 同款） | `w_in`、读出 | `w_rec` |
| **`ssm`** | **对角 SSM 状态**：`h_t = a ⊙ h_{t-1} + E[x_t]`，电流 `C·h_t + D[x_t]` | `E`、`C`、`D`、读出 | **极点 `a`** |

- **极点**：S=32 个实数极点，时间常数 τ 在 [1, 128] 上对数等距，`a_s = exp(−1/τ_s)`，**冻结**；
- **E**：`V×S`（token → SSM 输入），Xavier 初始化，可学；
- **C**：`N×S`（状态 → 电流），`1/√S` 初始化，可学；
- **D**：`V×N`（跳跃连接），**这是"SSM 有没有被用上"的诊断**，可学；
- **LIF**：与 M0b 完全一致（N=1,024、τ=20、θ=0.62、2 步不应期）；
- **读出**：EMA（τ_read=8）+ NLMS，与 M0b 一致；
- **训练**：301 条、2,000 updates、batch 16、per-step CE、`lr_in=1e-3`、`lr_out=0.5`、种子 0、**不切块**（先不引入 M2 的复杂度）；
- `E/C/D` 的更新用**与 `w_in` 同一套局部规则**（它们都在"输入→神经元"这条路径上，学习信号相同、资格痕迹按各自的前置量算）。

## 3. 判据

| # | 判据 | 门槛 | 不过时判什么 |
| :--- | :--- | :--- | :--- |
| **S0-0** | 前置：三臂都跑通 | 发放率均在 [1%, 30%]，CE 有限 | 实验无效 |
| **S0-1** | SSM 赢过随机循环 | `top1(ssm) ≥ top1(random) + 2pp` **或** `CE(ssm) ≤ CE(random) − 0.05` | 归纳偏置在冻结条件下无优势 |
| **S0-2** | **赢过 bigram**（真正的生死线） | `top1(ssm) ≥ 0.65` **或** `CE(ssm) ≤ 1.45` | 结构化递推也救不了这条工作点 |
| **S0-3** | 诊断齐全 | 状态范数、`D` 的变化量、发放率都记录 | 结果不可解释 |

**S0-1 与 S0-2 是两个不同的问题**，必须分开报：
- S0-1 过、S0-2 不过 → "SSM 比随机循环好，但仍不如 bigram"；
- S0-1 不过 → 结构本身没帮助，**方案 A 的先验更差**（因为 M0b 已证明"学循环权重有害"）。

## 4. 诊断（必须记）

1. **`D` 的相对变化**：若 `D` 几乎不动而 `E/C` 在动 → 模型主要走 SSM 路径；若 `D` 主导 → SSM 被绕过；
2. **SSM 状态范数** `||h_t||` 的均值与分位（训练前后），确认状态没饱和/塌缩；
3. **有效记忆长度**：极点 τ 的最大值（128）与"数据里真实的最长依赖"（模板语料约 30 字）对比；
4. **发放率**：`none` / `random` / `ssm` 三臂的发放率对比。

## 5. 预期

**押 S0-1 不过、S0-2 不过。** 理由：M0b 已经显示这条工作点上"递推结构"不是杠杆——
放出 179% 学习量的是读出，而给递推更多自由度（学 `w_rec`）反而变差。换一个**冻结**的结构化递推，
大概率落在同一个区间（top-1 0.55–0.60、CE 1.70–1.80）。

**若 S0-1 过**，那是本轮最有价值的结果：说明"结构化冻结递推"确实比"随机冻结递推"更适合共学读出，
值得按草案切方案 A。

**若三臂都在 0.55–0.60、CE 1.7–1.8**，结论就是：**这个工作点上，递推用什么结构都不重要，
瓶颈在别处（语料太小、或读出容量不够）**——那才是该记下来的东西。

## 6. 不做的事

- 不调 S、不调极点分布、不调学习率（与 M0b 相同）；
- 不引入 TI-LIF、不加抽头、不切块；
- S0-1 不过时不立刻切方案 A（先由用户拍板，并按 §0 的说明——本实验不能证明"学不动"）。

## 7. 边界

- 单种子；测试集 46 条 / 1,369 字符（top-1 的 SE ≈0.9pp）；
- 语料是模板化单轮 SIR，**不是对话**；本轮任何结论都不涉及"能不能闲聊"；
- 极点分布是**预设的**（不是我调出来的），但 S=32 与 τ 范围 [1,128] 是先验选择，不是最优；
- SSM 是**实数对角**（S4D-real 思路），不是完整的 S4/S6。
