# 预注册 amend 1：DFS 的邻居顺序必须打乱（2026-11-02）

**状态：写在 E3 的任何训练与评测之前——只跑过轨迹生成本身。**

## 发现了什么

预注册只写了「DFS 带回溯」，没写邻居的**尝试顺序**。按固定顺序（上、右、下、左）实现时，
在完美迷宫上 DFS 几乎总是先走对分支，于是：

| 迷宫数 | `len(D_search) / len(D_opt)` |
| :--- | :--- |
| 20 张 11×11 | 中位 **1.00**，15/20 张**完全相同** |

两臂的训练数据逐条一样，H1' 就等于在比"同样的数据"。

## 改成

**邻居顺序按 seed 打乱**（每个迷宫一个确定的种子，可复现）。重测同样的 20 张：

| | 比值 |
| :--- | :--- |
| 最小 | 1.00 |
| **中位** | **1.26** |
| 最大 | 2.44 |

## 这意味着什么

- `D_search` 的样本池比 `D_opt` 大 26%（中位），对齐后仍有约四分之一是不同的经历；
- **对比是真实的，但不强**。若 H1' 不成立，不能把原因归结为"过程信息太少"——
  这只是一种可能的解释，需要另做实验区分（例如把 DFS 改成"深度受限的随机游走"以拉大差距）。

这条写在这里，是为了在结果出来之前就把"对比有多强"钉住，而不是事后按结果挑解释。

## 什么没变

判据 E3-0…E3-3 一个没动；任务、状态表示、样本对齐规则、种子数都没动。
