# 预注册：脉冲 SoS 的 E0–E1（环境、基线、世界模型与不确定度）（2026-11-02）

**状态：判据先落盘，代码未写，数据未跑。**

## 为什么只预注册 E0–E1

ADR-0030 规定三条前提落地之前不跑训练。E0（环境与基线）与 E1（世界模型 + 不确定度）就是
**前提 P1 的验收**。E2 以后的一切都建立在 E1 过线的基础上——所以这一份只管到 E1 为止，
不写 E2–E5 的判据（那要看 E1 的结果再谈）。

## 从设计草案里改掉的一处（**这一版最重要的决定**）

`research/sos/DESIGN.md` 写的是「网格：离散转移，可精确拟合」。
**这句话把 P2 从根上毁掉了**：一个确定性、全观测的网格，世界模型可以做到零误差，
于是「预测误差的减少」恒为 0，reward 没有任何信息。

**改法：环境必须是随机的。** 本预注册采用**滑移网格**——每个动作以 `p_slip = 0.10` 的概率
滑到另一个动作（在其余三个方向里均匀）。这样：

- 世界模型只能预测**期望**下一状态，误差不为零；
- 误差的大小**随覆盖度变化**（没去过的区域误差大），这正是 P2 要的信号；
- 方差（子集集成的方差）于是有可能成为「这里我不熟」的指示器，H2 才有东西可测。

这条改动写在跑之前。若它是错的（例如滑移让任务难度不可控），在 E0 的判据里会被抓出来。

## 任务（先定死）

- **8×8 网格，20% 墙**（墙随机撒，保证可解），起点固定左下角、终点固定右上角；
- 动作 4 个（上下左右）；撞墙 = 原地不动；
- **滑移**：`p_slip = 0.10`，滑到其余三个动作里均匀选一个；
- 观测 = 位置 one-hot（64 维）；
- episode 上限 `T = 60` 步；成功 = 到达终点；
- **难度 = BFS 最短路径长度**（在确定性骨架上算，作为客观标尺）。

## 判据（跑之前写死）

### E0 环境与基线

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| E0-1 | 确定性 | 同一 seed 两次生成逐位相同（网格、墙、起点终点） |
| E0-2 | BFS 正确 | 4×4 与 5×5 全部小网格上，BFS 结果与穷举最短路一致 |
| E0-3 | 可解率 | 生成 200 个 8×8 网格，可解 ≥ **95%** |
| E0-4 | 难度有跨度 | 可解网格的最短路长度至少覆盖 **4 个不同值**，最小 ≤ **6**、最大 ≥ **18** |
| E0-5 | 三个无学习基线可跑 | 随机走 / 贪心朝终点 / BFS 上界（= 最短路的成功率 1.0，作为天花板） |

E0 全过才进 E1。

### E1 世界模型与不确定度（**P1 的验收**）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| E1-1 | 世界模型能学 | 留出集上「期望下一位置」的**格子级命中率** ≥ **0.85**（随机基线约 0.25） |
| E1-2 | **方差携带信息** | 留出集上 Spearman ρ(预测方差, 绝对误差) ≥ **0.30** |
| E1-3 | **方差追踪的是"不熟"** | 按该 (状态, 动作) 在训练集出现的次数分两档（少/多），少档的平均方差更大，且 **≥ 4/5 个种子**成立 |
| E1-4 | 不确定性不是常数 | 方差的变异系数 ≥ **0.10**（否则它是个常数，不可能是信号） |

## 怎么搭（跑之前定死）

- **世界模型**：闭式岭回归（`research/cognitive/world_model.py` 的 `RidgeActionModel` 同款姿态），
  输入 = 状态 one-hot ⊗ 动作 one-hot（256 维），输出 = 期望下一位置（2 维，归一化坐标）；
- **不确定度**：**k 折子集集成**（k=5）——在 5 个训练子集上各拟合一个，取 5 个预测的标准差
  作为该样本的方差。不引入新依赖；
- **数据**：随机策略在 200 个网格上各走 60 步，共 12000 条转移；按 **网格** 划分训练/留出
  （不是按转移随机划分——同一网格的转移高度相关）；
- **种子**：5 个种子（只影响数据采样与子集划分；模型本身是闭式的）。

## 跑之前的预期

**E0 预期全过**（环境是纯确定性的实现，可验证）。

**E1 的预期：E1-1 过、E1-2 可能过、E1-3 不确定。** 理由：滑移噪声让"期望下一位置"本身就
有不可约误差，所以方差可能主要反映**噪声**而不是**覆盖度**——如果是这样，E1-3 会失败，
而 E1-3 恰恰是 H2 需要的那一半。写在这里，是为了防止事后把"方差只追踪噪声"说成"方差有用"。

## 死亡条件（照 ADR-0021）

- 若 E1-2 过而 E1-3 不过，**不得**用"方差还是有信息"来宣布 P1 通过——那说明它追踪的是噪声；
  这时要么改环境（降低滑移），要么改用覆盖度直接作不确定度，**另写预注册**；
- 若 E0-4 不过（难度没有跨度），E4 的自适应性就无从谈起，任务规格要重写，**另写预注册**。

## 不做的事

- 不跑任何策略学习（E2 以后的事）；
- 不因为 E1 不过就调 k 或换模型重试——那属于下一次预注册；
- 不把 E1 的过线写成"SoS 可行"：它只说明**前提 P1 成立**。
