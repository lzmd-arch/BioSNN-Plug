# 脉冲 SoS：实验设计草案（v0，2026-11-02）

**状态：草案，不是预注册。** ADR-0030 规定三条前提落地之前只允许产出实验设计、预注册与最小环境骨架。
这份是第一步——先把**现有零件够不够**说清楚，再谈实验。

## 1. 要回答什么

- **H1**：用 R-STDP 强化「预测误差减少」的轨迹，比强化「最终成功」更容易形成搜索能力。
- **H2**：世界模型的预测方差可以作为「是否继续搜索」的元认知信号。
- **H3**：多轨迹并行的容量随神经元数线性增长，而非二次增长。

H3 是三条里最弱的一条（见 §6）。

## 2. 现有零件盘点（逐个核过代码，不是凭印象）

| 零件 | 现在有什么 | 缺口 |
| :--- | :--- | :--- |
| 世界模型 | `research/cognitive/world_model.py` 的 `Prediction(delta, termination)` + 四个基线（`copy_last` / `mean_delta` / `per_action_mean` / `ridge_action`） | **没有方差**。`Prediction` 只有点预测与终止分数 |
| 工作记忆 | `research/cognitive/working_memory.py`，WM v4 0.9990 | **不支持分支与重置** |
| R-STDP actor | `research/rstdp/rstdp.py::RSTDPActor` | reward 从外部传进来；没有「误差减少」这种自生成信号 |
| Critic | `research/rstdp/td_ltp.py::TDLCritic` / `PopulationCritic` | 同上 |
| 环境 | `research/rstdp/cartpole.py`（CartPole） | **没有网格/迷宫**——而搜索任务需要一个离散、可枚举的世界 |

一句话：**四个零件都有，但没有一个是为"搜索"准备的。** 三条前提不是修辞，是四处具体的改动。

## 3. 最小任务：为什么先做网格而不是 CartPole

| 维度 | 网格/迷宫 | CartPole |
| :--- | :--- | :--- |
| 动作空间 | 4 个离散方向 | 2 个，但状态连续 |
| 成功判定 | 到终点，无歧义 | 活够 500 步，与「搜索」无关 |
| 最短路径 | BFS 精确可算 → **难度的客观标尺** | 没有"难度"这个概念 |
| 世界模型 | 离散转移，**但确定性会毁掉 P2**（见下方修正） | 连续动力学，误差永远不为零 |

**先做网格**。只有它能直接检验「搜索步数随难度自适应」——而那是 ADR-0030 的回退条件之一。

任务规格（先定死，写进预注册之前不改）：

- N×N 网格（建议 8×8），随机墙，起点与终点固定若干组；
- 动作 4 个；观测 = 位置（或位置 one-hot）；
- episode 上限 T 步；成功 = 到达终点；
- **难度 = BFS 最短路径长度**，用来分层。

> **2026-11-02 修正（写预注册时发现）**：上面那句「离散转移，可精确拟合」是错的——
> 一个**确定性**网格能被世界模型零误差拟合，于是「预测误差的减少」恒为 0，P2 就没有任何信息。
> 所以环境和任务必须**随机**：[`prereg-e0-e1.md`](prereg-e0-e1.md) 改用**滑移网格**（`p_slip = 0.10`）。
> 这条修正改掉的是设计里最要害的一步，记在这里而不是悄悄改。

## 4. 三条前提怎么落地

### P1 不确定度

在 `Prediction` 上补一个 `variance`（`(n, n_dims)`），或另开一个 `PredictiveDistribution`。
闭式做法：岭回归的残差方差，或对训练集做 k 折子集集成取方差。

**验收（先写在预注册里）**：方差与绝对误差的秩相关 **> 0**。若它和目标误差不相关，
那 H2 从第一步就不成立，不必往下做。

### P2 reward 重定义

`r_t = -(留出预测误差_t)`——奖励「预测变准」，而不是「走到终点」。

**必须防的平凡解**：如果 reward 用训练误差，模型把方差学大就能让"误差减少"变好看。
所以 P2 的验收要包含一条：**reward 只能用留出误差算**。

### P3 多轨迹与回溯

先做**串行回溯**：一次只维持一条轨迹，走到死路时把 WM 重置到上一个分支点。
并行多轨迹（H3）留到 E5，且先不做——复杂度会在拿到任何信号之前翻倍。

## 5. 实验序列（判据留到预注册里写）

| 步 | 做什么 | 产出 |
| :--- | :--- | :--- |
| E0 | 环境 + 三个无学习基线：随机走 / 贪心朝终点 / BFS 上界 | 成功率与步数的参照 |
| E1 | 世界模型 + 不确定度，先在网格上验证 P1 验收 | 方差是否有信息 |
| E2 | 串行 SoS：一条轨迹 + 回溯，`r = -留出误差` | H1 的实验臂 |
| E3 | 对照臂：`r = 最终成功` | H1 的对照 |
| E4 | 搜索步数 vs BFS 难度 | ADR-0030 的回退条件之一 |
| E5 | （可选）并行多轨迹 | H3，先不做 |

## 6. 风险与不做的事

- **H3 建议先不做。** 它要在同一任务上把宽度从几十扫到上千，成本最高，而且结论最容易被
  实现细节（初始化、阈值、编码）影响——W3 就是这么走偏的。
- **不用 CartPole 做第一版**（理由见 §3）。
- **前提未落地不跑训练**（ADR-0030 写死的）。
- 不把 E0 的三个基线当成"方法"——它们是标尺。

## 7. 待定（写预注册之前要定下来）

1. 网格规模与墙密度（建议 8×8、20% 墙）；
2. 世界模型先用闭式岭回归还是直接用 ALIF 群体（**建议先闭式**，ALIF 只作为对照臂）；
3. 回溯的触发条件是用预测误差还是用方差（两者都要试，但一次只改一个）。
