# 预注册：E2——串行 SoS 的第一版与 H1 的三臂比较（2026-11-02）

**状态：判据先落盘，代码未写。**

## 写之前先纠一处（**这一版最重要的判断**）

ADR-0030 把 P2 写成「R-STDP 的 reward 从『外部成功信号』改为『预测误差的减少』」。
按字面实现会有一个**平凡解**：agent 待在最熟的格子里不动，surprisal 最低，reward 最高。
那不是搜索，是蹲着。

所以这一版不把 P2 当成"已经定义好了"，而是把 reward 的三种定义**并排当三个臂**跑，
让 H1 变成可检验的比较，而不是一个信念：

| 臂 | reward | 它代表什么 |
| :--- | :--- | :--- |
| **A 过程** | `r_t = −surprisal_t` | ADR-0030 的字面定义（预期会退化，见 E2-0） |
| **B 稠密外部** | 朝终点近了 `+1`、远了 `−1` | 有一个强得多的稠密信号 |
| **C 稀疏外部** | 到达终点 `+1`，其余 0 | H1 的对照臂（"只给结果"） |

**H1 的原话是「过程 reward 比结果 reward 更容易形成搜索能力」**——所以 A 对 C 是主比较。
B 是"如果稠密外部信号存在会怎样"的参照，不参与 H1。

## 任务与数据

- 环境：`prereg-e0-e1-v2.md` 的滑移迷宫（9/11/13 三档、`p_slip = 0.10`、`T = 3L + 20`）；
- **迷宫池切两半**：迷宫 0–99 = 训练（同时也是 pilot，用来标定门槛），100–199 = **confirm（只判）**；
- 策略：**全局**一张表（不分迷宫），`状态 → 4 个动作的 softmax`；
- 更新：REINFORCE 式（R-STDP 的类比：`Δw ∝ (r − b) · ∇log π`），`b` = 该状态的滑动平均 reward；
- 训练：每个臂在训练池上跑固定轮数（5 个种子），评测在 confirm 池上跑，贪心动作。

## 判据（跑之前写死，pilot 标定）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **E2-0** | **A 臂不许退化** | A 臂在 confirm 上的**访问格子熵** ≥ `0.5 × C 臂`；否则记"A 臂退化，H1 不可测" |
| E2-1 | C 臂能学到东西 | C 臂 confirm 成功率 ≥ `0.5 × B 臂`（否则稀疏信号太弱，H1 无从比较） |
| **E2-2** | **H1：A 优于 C** | A 的 confirm 成功率 `≥ C + pilot 的半程差`（见下） |
| E2-3 | 难度自适应 | B 臂的「平均步数 / 最短路长度」随难度档位单调不减（9 < 11 < 13） |

**门槛怎么定**：`E2-2` 的差门槛 = **训练池上 A 与 C 的成功率差的中位**（pilot 量级），
confirm 只要达到它的一半即算成立。理由：训练池的差是"能学到多少"的上界估计，
confirm 只要求复现其一半，是**对两半可交换性的一次让步**，不是给自己放水——
放水的话应当直接写"confirm ≥ 0"。

## 跑之前的预期

- **A 臂预期退化**（E2-0 大概率不过）：`−surprisal` 的最优解就是不动；
- **C 臂（稀疏成功）预期学得很慢**：T 步里只有最后一次有信号；
- **B 臂预期最好**：稠密外部信号是作弊级的信息；
- 因此 **H1 大概率不可测**，这一版的价值在于把"过程 reward 的定义"这个坑挖出来。

写在这里，是为了防止事后把"A 退化"解释成"再调调就好"。

## 死亡条件

- E2-0 不过 → **H1 在本版不可测**，不调 reward 重跑；要改 reward 定义（例如改成
  "学习进步的滑动基线"或"模型预测的成功概率"）必须另写预注册；
- E2-1 不过 → 稀疏臂太弱，H1 也不可测；同样另写预注册。

## 不做的事

- 不调超参（学习率、轮数）救 A 臂；
- 不把 B 臂的成绩写成"SoS 有效"——它是稠密外部信号，不是过程 reward；
- 不跑任何"多轨迹/回溯"（那是 E5）。
