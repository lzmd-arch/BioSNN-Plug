# 预注册 v4：E1 改成 **pilot / confirm** 划分（2026-11-02）

**状态：判据先落盘，代码未跑。**

## 为什么有 v4

三次 E1 尝试，三次挂在"差一点点"上，其中 v2 的门槛实测根本不可达：

| 版本 | 挂在哪 | 实测 vs 门槛 |
| :--- | :--- | :--- |
| v2 | 格子命中 | 0.627 vs 0.85（**该批数据上限 0.789**） |
| v3 | 比边际高 | +0.139 vs 0.20 |
| v3 | 熵 CV | 0.097 vs 0.10 |

根因不是模型，是**门槛的定法**：每次都先拍一个数再看数据。仓库里早已记过这条
（「预注册比值判据要先标度标定」），这一版照它办。

## 做法

迷宫池 200 张切成两半：

- **pilot 半**（seed 0–99）：只用来**标定量级**；
- **confirm 半**（seed 100–199）：**只在这里判**。

门槛按 pilot 的量级定，带一个**有依据的 margin**：

| 判据 | 门槛 |
| :--- | :--- |
| E1-1' | `gap_confirm ≥ 0.7 × gap_pilot` |
| E1-2' | `ρ_confirm ≥ 0.30`（绝对值——它离门槛有 0.5 以上的余量，不需要相对化） |
| E1-3' | 覆盖 ≥ 4/5 种子（绝对值，同上） |
| E1-4' | `cv_confirm ≥ 0.8 × cv_pilot` |

**margin 的依据**：v3 的 5 个种子给出的 seed-to-seed 抖动是——`gap` 0.113–0.158（中位 0.139，
极差约 ±16%）、`熵 CV` 0.094–0.101（±4%）。pilot 与 confirm 是**同样大小的两组独立迷宫**，
按这个抖动，30%（gap）与 20%（CV）的折扣约为观测抖动的 **2–5 倍**，不苛刻也不放水。

## 为什么这不是"调门槛让它变绿"

判据的形状变了（从拍绝对值改成"confirm 复现 pilot 的量级"），**而 pilot 的数字这一版还没算过**。
也就是说：门槛里唯一的未知量来自另一半数据，而判在另一半。这正是标度标定的标准做法。
`pilot` 的数字会在结果里一并报出来，不能被"只看 confirm"藏掉。

## 跑之前的预期

pilot 与 confirm 是同一分布的两半，`gap` 应当在 **0.13–0.16**、`熵 CV` 在 **0.09–0.10**。
若 confirm 显著低于 pilot 的 70%/80%，那说明这两半不可交换——那本身就是结论，
要写进结果，而不是调 margin。

## 死亡条件

- 若 `gap_pilot` 本身 ≤ 0（模型不如边际基线），**不再谈 confirm**，直接记为 P1 不成立；
- 若 confirm 与 pilot 的差超过上述 margin，记录为「两半不可交换」，**不调 margin 重跑**。

## 不做的事

- 不改数据、不改种子、不改世界模型；
- 不用 confirm 的数字反过来改 pilot 的门槛。
