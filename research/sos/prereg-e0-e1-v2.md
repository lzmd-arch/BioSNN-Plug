# 预注册 v2：脉冲 SoS 的 E0–E1（迷宫任务）（2026-11-02）

**状态：判据先落盘，代码未跑。**

## 为什么有 v2

v1（[`prereg-e0-e1.md`](prereg-e0-e1.md)）的 E0 挂了两条，按它自己写的死亡条件：
「若 E0-4 不过（难度没有跨度），任务规格要重写，另写预注册」。这份是重写。

v1 的问题：8×8 撒 20% 墙 → 可解率 0.835、**最短路只有 14 与 16 两个值**（14 就是曼哈顿距离，
墙几乎不制造绕行）。**那份任务里没有难度可言**，而 ADR-0030 的回退条件之一是
「搜索步数随任务难度自适应」——所以 E4 根本无从谈起。

## 规格怎么定的（**这是任务设计，不是拿方法调参**）

改规格之前先探过路径长度分布（`_trigger_v2_tmp/maze_probe.py`，一次性脚本，不入库）：
DFS 迷宫 + 三个尺寸，角到角最短路为

| 尺寸 | 最短路范围 | 不同取值 |
| :--- | ---: | ---: |
| 9×9 | 12–28 | 5–6 |
| 11×11 | 16–40 | 7–10 |
| 13×13 | 20–64 | 12–15 |

（每个尺寸 60 张、`loop=0.05`。）这套分布有真实跨度、且**由构造保证连通**。
**探的是环境本身，不是任何 SoS 方法**——后者一行都还没写。

## 任务（先定死）

- **DFS 迷宫**：尺寸取 **9 / 11 / 13** 三档，奇数边长；走廊在奇数坐标，偶数坐标是墙；
- **打通 5% 的剩余内墙**（`loop=0.05`）制造少数回路，避免全是单通路；
- 起点 **(1, 1)**、终点 **(size−2, size−2)**；
- 动作 4 个；撞墙 = 原地；
- **滑移 `p_slip = 0.10`**（理由同 v1：确定性会毁掉 P2）；
- **episode 上限 `T = 3·L + 20`**（L = 该迷宫的最短路长度）——固定 60 步在 13×13 上
  连"跟着最短路走"都走不完，那会把难度与步数上限混在一起；
- 难度 = 该迷宫的最短路长度 L。

## 判据（跑之前写死）

### E0 环境与基线

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| E0-1 | 确定性 | 同 seed 两次生成逐位相同 |
| E0-2 | BFS 正确 | 4×4 与 5×5 撒墙网格上，BFS 与穷举一致 |
| E0-3 | 可解率 | 每个尺寸 200 张，可解 **100%**（迷宫由构造保证连通，这里验的是实现） |
| E0-4 | **难度跨度** | 三个尺寸合起来：不同最短路长度 ≥ **8** 档、最小 ≤ **14**、最大 ≥ **40** |
| E0-5 | 基线 | **BFS 跟随 ≥ 0.90**，且比随机策略高 ≥ **40pp** |

E0 全过才进 E1。

### E1 世界模型与不确定度（**P1 的验收**，只做 11×11）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| E1-1 | 世界模型能学 | 留出集格子级命中率 ≥ **0.85** |
| E1-2 | 方差携带信息 | Spearman ρ(方差, 绝对误差) ≥ **0.30** |
| E1-3 | 方差追踪"不熟" | 少访问档的平均方差更大，≥ **4/5 种子** |
| E1-4 | 不确定不是常数 | 方差变异系数 ≥ **0.10** |

E1 只在 **11×11** 上做：世界模型的输入维度要固定，混尺寸会把"学动力学"与"跨尺寸泛化"
两件事混在一起。多尺寸的分层留给 E4。

## 怎么搭

同 v1：闭式岭回归（输入 = 状态 one-hot ⊗ 动作 one-hot），不确定度 = **5 个不相交子集的
集成标准差**，数据按**网格**划分训练/留出，5 个种子。

## 跑之前的预期

**E0 预期全过。** 迷宫由构造连通（E0-3 是验实现）；路径跨度按探针的分布应当明显过线。

**E1：E1-1 过；E1-2 可能过；E1-3 不确定。** 理由同 v1——滑移噪声让"期望下一位置"本身有
不可约误差，方差可能主要反映噪声而不是覆盖度。这条写在这里，防止事后把"只追噪声"说成"有用"。

## 死亡条件

- E1-2 过而 E1-3 不过 → **不得**宣布 P1 通过（方差只追噪声）；要么降滑移、要么改用覆盖度
  直接作不确定度，**另写预注册**；
- E0-4 再不过 → 说明迷宫也没造出跨度，停下来重想任务，不再调参数。

## 不做的事

- 不跑任何策略学习；
- 不因为 E1 不过就换 k、换 λ、换模型重试；
- 不把 E0/E1 的过线写成"SoS 可行"。
