# 预注册 v3：脉冲 SoS 的 E1——世界模型改成"下一格分布"，判据改成相对基线（2026-11-02）

**状态：判据先落盘，代码未跑。**

## 为什么有 v3

v2（[`prereg-e0-e1-v2.md`](prereg-e0-e1-v2.md)）的 **E0 全过**（难度跨度 23 档 [12, 62]，
跟随策略 0.975），但 **E1-1 挂了**：格子级命中率中位 **0.627**，门槛 0.85。

查了原因（**诊断，不是重跑判据**）：

| 测法 | 命中率 |
| :--- | ---: |
| 5 个不相交子集的岭回归（v2 的做法） | 0.592 |
| **全量**岭回归（λ=1.0） | 0.717 |
| **查表取众数**（同一批数据能到的上限） | **0.789** |

也就是说：**0.85 这个门槛在这份任务 + 这份数据量下根本不可达**。上限约 0.79，不是模型不行。

而且这条诊断还暴露出一个更根本的问题：**"预测期望下一位置再四舍五入"本来就是个坏的点估计**。
滑移下真实分布是双峰的（90% 走成、10% 滑到别处），期望落在两格之间，四舍五入的结果没有意义。

## 改什么（只改 E1，E0 不动）

**世界模型改成"下一格的分布"**，这是离散网格上正确的对象：

- 模型 = `p(下一格 | 状态, 动作)`，用训练集计数 + **拉普拉斯平滑**（α=1）估计；
- **点估计** = 众数；
- **误差** = 对该样本真实下一格的 **surprisal** `−log p`；
- **不确定度** = 预测分布的**熵**（不再用子集集成——分布本身就有熵，不需要再近似）。

## 判据（跑之前写死）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| E1-1 | **模型用了状态** | 众数命中率比**只看动作的边际基线**高 ≥ **20 个百分点** |
| E1-2 | 熵携带信息 | Spearman ρ(熵, surprisal) ≥ **0.30** |
| E1-3 | 熵追踪"不熟" | 训练计数少的那一档平均熵更大，≥ **4/5 种子** |
| E1-4 | 熵不是常数 | 熵的变异系数 ≥ **0.10** |

E1-1 换成"比边际基线高 20pp"，而不是绝对命中率：绝对命中率被数据量、滑移强度、
网格大小一起决定，**没有可移植性**；而"用了状态就比不用强得多"是这个世界模型的本质要求。

## 怎么搭

- 数据、划分、种子与 v2 完全相同（160 训练网格 / 40 留出网格、5 个种子、11×11）；
- 计数表：`(状态, 动作) → Counter(下一格)`，Laplace α=1，分母 = 观测数 + α × 合法下一格数；
- 熵的底用自然对数；surprisal 同底；
- 边际基线：`p(下一格 | 动作)`，同样平滑。

## 跑之前的预期

**预期三条过、一条不稳。** E1-1 应当大幅过线（查表命中 0.79 vs 边际基线大约 0.2–0.3）；
E1-2 大概率过（熵高的地方 surprisal 也高）；**E1-3 才是真考验**——计数少的格子熵天然大，
这条几乎是恒真的，除非平滑把差异抹平；E1-4 看熵有没有跨度。

写下来是为了防止事后把 E1-3 的"几乎恒真"说成"方差有用"。

## 死亡条件

- 若 E1-3 在 5 个种子上全过但 E1-2 不过，说明**熵只反映访问次数、不反映实际误差**，
  那 H2 仍然不成立，**不得**宣布 P1 通过；
- 若 E1-1 不过，说明连"状态有用"都不成立，回头查数据与划分，不调门槛。

## 不做的事

- 不改 E0 的任何判据；
- 不改数据划分、种子、网格规格；
- 不把 E1 的过线写成"SoS 可行"。
