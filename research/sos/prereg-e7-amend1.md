# 预注册 amend 1：E7 的训练预算与一处评测 bug（2026-11-03）

**状态：写在 E7 的**正式运行**之前。之前只跑过调试用的 pilot（16 张迷宫）。**

## 1. 评测 bug（必须记）

`evaluate` 里把观测喂成 `torch.tensor([obs_vector(...)])`，形状是 **(1, D)** 而不是 **(1, 1, D)**。
GRU 把二维输入当成"无 batch 的序列"，于是 `logits` 形状是 `(D, 4)`，
下游的 `logits[0, -1]` 取到的是标量，`argmax` 恒为 0——**agent 每步都执行动作 0**，
两臂成功率恒为 0.000。

已修成 `([[obs_vector(...)]])`（3 维）。修完在 16 张迷宫上闭环成功率 **0.875**。

**这个 bug 说明 E7 的第一次全量跑（0.000）是废数据，不能当作"H1' 不成立"的证据。**

## 2. 训练预算：10 轮不够

预注册写的是 `EPOCHS = 10`、`lr = 1e-3`、`BATCH = 64`。pilot 显示这个预算连**过拟合都做不到**：

| 设置 | 训练损失 |
| :--- | :--- |
| 10 轮、lr 1e-3、8 张迷宫 | 1.408 → **1.190**（几乎没动，ln 4 = 1.386） |
| 300 轮、lr 3e-3、16 张迷宫 | **0.006**，闭环成功率 0.875 |

改：`EPOCHS = 100`、`lr = 3e-3`、`BATCH = 128`。在 2000 张迷宫上是
16 个 batch × 100 轮 = **1600 次更新**，比原来的 320 次多五倍，且 batch 更大。

**为什么这不是"调参调到能用"**：E7-0 判的是"模型能不能学会这个任务"，那是**前置工程**，
不是假设本身。改它的理由是一条 pilot 证据（损失几乎没动），不是"结果不好看"。

## 3. 什么没变

判据 E7-0 / E7-1 / E7-2 的门槛一个字没动；语料规模仍是 2000 张训练迷宫；
`D_opt` / `D_search` 的对齐规则、滑移、评测协议都没动。
