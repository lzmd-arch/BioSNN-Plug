# 预注册：E4——状态里加入四邻墙信息（2026-11-03）

**状态：判据先落盘，代码未跑。**

## 为什么有 E4

E3（[`prereg-e3.md`](prereg-e3.md)）两臂训练池只有 **0.140 / 0.120**。根因不是学习信号，
是**状态里没有墙**：状态只有「相对终点的位移」，同一个 `(dx, dy)` 对应许多格子，最优动作各不相同。
按预注册 agent 只观测位置，任务本质是 **POMDP**，无记忆的策略在原理上解不了。

E2 的两轮（换了三种 reward 都不动）与 E3 是同一个根因的三种表现。

## 改什么（只改状态，不改别的）

```
state = (dx, dy, wall_bits)
```

- `dx, dy` = 相对终点的位移（**不裁剪**，同 E2 v2）；
- `wall_bits` = 4 位：上/右/下/左四个邻居是否**不可走**（墙或在界外）。

**为什么这够了**：完美迷宫是**单连通**的——沿着一侧的墙一直走必然绕到终点。
四邻墙信息正是「沿墙走」这个策略需要的最小观测。状态数上限 25×25×16 ≈ 10⁴，表格承受得住。

## 判据（**全部绝对门槛**，不接受没有下限的相对判据）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **E4-0** | 两臂在训练池上都学得会 | **两臂**成功率均 ≥ **0.50** |
| E4-1 | H1'：过程优于结果 | `search_confirm − opt_confirm` ≥ **0.05**（绝对差下限） |
| E4-2 | 不是靠步数换成功 | `search` 平均步数 ≤ **1.5 ×** `opt` 平均步数 |

E4-0 不过 → 说明加了墙信息还不够，停下来重新想策略类（**不调轮数或学习率重跑**）。
E4-1 不过但 E4-0 过 → H1' 在该任务上不成立，记为负结果。

  而 `opt` 每一步都是朝终点的正确一步。**这次我仍然倾向 `opt` 不输。**
