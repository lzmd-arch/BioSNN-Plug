# W1：核化 IB-Hebbian 感知层

**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

## 在验证什么命题

计划书 §3.3 的感知层学习规则：**Pogodin & Latham (2020) 由核化信息瓶颈导出的三因子
Hebbian 规则，加上除法归一化，能否作为感知层特征提取器在 MNIST 上达到计划书 §七
第一阶段要求的 70%+。**

除法归一化不是可选项。论文摘要的原话：

> In addition, to work on hard problems and remain biologically plausible, our update
> rules need divisive normalization, a computation done by the primary visual cortex
> and beyond.

论文实验部分进一步区分了「分组」与「分组 + 除法归一化」两种变体，结论是**高斯核必须
有分组 + 除法归一化才有像样的准确率**。这正是计划书 §十一 把它列为 P0 的那一条。

## 当前结论

**达到。** 阈值 70%，**两个读出都在其上**：**岭回归闭式解读出（现行默认）97.79%**、
交叉熵 + SGD **98.01%**。两个数字都是「局部学到的特征 + 监督读出」的**联合结果**，不是局部规则
单独达到的精度——先说清楚，再往下看。

**但这个数字是两段拼起来的，必须说清**：隐藏层用**局部规则**学特征，最后**用一个监督训练的
线性读出**分类。98.01% 是这两段的联合结果，**不是「局部规则单独达到的精度」**。

读出有两种实现，都在阈值之上：

| 读出 | 测试准确率 | 怎么学的 |
| :--- | ---: | :--- |
| 交叉熵 + SGD | 98.01% | 反向传播 + 学习率 + 动量 + 100 个 epoch |
| **岭回归闭式解（现行默认）** | **97.79%** | 累积 `XᵀX / XᵀY` 后**一次解出**：无反向传播、无学习率、无迭代；λ=1e-4 由**验证集**选出（`{0, 1e-4, 1e-3, 1e-2, 1e-1}` 里验证准确率最高，0.9793） |

**两者都不是「局部」的读出**——都用标签、都是监督的。闭式解去掉的是**反向传播与迭代**，
**不是全局性**：`XᵀX` 是 `(H+1)²` 的矩阵，需要**全体训练样本**才能累积出来。详见
「「局部」的准确表述」一节。

隐藏层那一侧不受读出选择影响：它用的是**自己的**目标（Eq. 35 的二值教学信号），训练期间
完全不知道读出是什么。实测它的局部目标在训练中从 −0.1299 降到 −0.2931（**最低点在 epoch 90**；epoch 100 收在
−0.2929，末段有轻微回升，所以**不是严格单调**），所以
**差的 0.22 个百分点只来自分类那一步换了算法**，不是特征变差了。

论文在 3 层 × 1024 全连接、高斯核 + 分组 + 除法归一化下的 MNIST 数字是 **98.1%**
（backprop 98.6%），所以本实现与论文基本一致——不是"刚好过线"，而是复现了那条规则。

## 「局部」的准确表述

计划书 §3.3 说第三因子「无需自顶向下传递即可获得」，§9 的「生物合理性」一行要求
「无全局反向传播」。本实现让这两句话有据可依，所以把边界写清楚：

**成立的部分**：每层有**自己的目标函数**与**自己的优化器**，在该层的前向过程中就地
更新参数；层的输入被显式切断梯度，所以**任何梯度都不会流回上一层**——不存在从输出层
一路回传到输入的全局反向传播。这有测试断言，不是文档里的承诺：在模型层面，读出层的
交叉熵反向传播后，每个隐藏层权重的 `.grad` 必须是 `None`。

**不成立、也不应声称的部分**：本实现用 autograd 计算**该层局部目标**对其自身权重的
梯度。autograd 在这里是**仿真手段**，不是学习机制。局部性主张的根据是论文由 Eq. (10)
推导出的三因子 Hebbian 形式（Eq. 12 / Eq. 18）：

```text
ΔW^k_{αnm} ∝ M^k_{α,ij} ( r^k_{αn,i} r^{k−1}_{m,i} − r^k_{αn,j} r^{k−1}_{m,j} )
```

即更新正比于「前突触活动 × 后突触活动 × 一个每对数据点一个标量的第三因子」。论文明文
说实验里用的就是批量版的 Eq. (10) 梯度（"We used the batch version of the update rule
(Eq. (10)) only to make large-scale simulations computationally feasible"），所以本
实现与论文的实现是同一条路径。

**因此对外表述应当是**：「每层用局部目标更新，无跨层梯度回传，更新规则具有三因子
Hebbian 形式（Eq. 18）」；**不应**说「完全没有反向传播」。

**读出那一段是哪一种「不局部」，要单独说清。** 闭式解读出（`readout.py`）**没有反向传播、
没有迭代**，它的两个累积量 `h hᵀ`（前后突触活动之积）与 `h yᵀ`（前突触活动 × 教学信号）
都是**逐样本可加**的 Hebbian 式相关——累积这一步是这里唯一"像 Hebbian"的地方。**但它们累积
出来的 `XᵀX` 是 `(H+1)²` 的全局二阶统计量**，需要**全体训练样本**；最后那次求逆也是全局的；
而且它用了标签。所以正确的说法是「**无反向传播、非迭代的闭式读出**」，**不应**说「局部学习的
读出」或「纯局部分类」。它相对于 SGD 读出的改进是**去掉了反向传播与迭代，不是去掉了全局性**。

## 最小复现脚本

`examples/paper_pogodin2020.py`（计划书 §12.3）。它刻意**不依赖 MNIST 下载**：用合成的
高维二分类数据，几十秒内在 CPU 上跑完，CI 里直接执行。它验证三件事——局部目标能算、
它的梯度只落在本层权重上、反复更新后准确率显著高于随机——并带一个除法归一化的消融。

实测（本机 CPU，`uv run python examples/paper_pogodin2020.py`）：

| 配置 | 准确率 |
| :--- | ---: |
| p = 0.2（论文设置） | 0.9805 |
| p = 0.0（去掉按方差缩放） | 0.7480 |

这是一个**弱**消融：它只说明归一化这一项在本任务上起作用，不构成对论文那条断言的
独立验证。

## 已知边界

这一节比结论重要——数字好看不等于结论没有边界。

1. **这是速率型网络，不是脉冲型。** 隐藏层是 LReLU，不是脉冲神经元。所以计划书 §9 的
   「活跃神经元比例」「脉冲稀疏度」在这里是**类比量**，不是原义指标。本实现量的是
   **除法归一化之前**的活动：归一化按组居中了活动，之后恒有一半左右单元为负，
   在那个量上算"活跃比例"只是在数分组。归一化前实测活跃单元比例 0.9639。
2. **单次运行，不是 5 次平均。** 论文表 1/表 4 报的是 5 个随机种子的均值与极差
   （MNIST 上的极差约 0.3–0.4 个百分点）。本条目只报种子 `base=0` 的一次运行。
   要报"与论文一致"需要的多运行统计**尚未做**。
3. **η_l（局部学习率）没有照抄论文。** 论文 Table 3 的列与 PDF 抽取出的数值对不齐
   （10 列数值、只有 6 个 η_l 与 6 个 c_k），逐列映射无法可靠还原。论文自己也是在
   验证集上调的（D.5）。本次用 η_l = 1.0、c_k = 32、读出 η_f = 5e-3，**未做系统调参**
   ——98.01% 是在这些取值下拿到的，不是"调到最好"的结果。
4. **教学信号用了论文的二值简化形式。** 论文的 Eq. (35) 是"居中标签的余弦相似度"，
   类别均衡时化简为二值信号，论文实验用的就是它。所以标签信息只经一个标量进入第三
   因子——这一点在代码里是显式的，不是隐含假设。
5. **消融只做了除法归一化那一条**，且是弱形式。论文要求的其他对照（HSIC vs pHSIC、
   余弦核 vs 高斯核、分组 vs 无分组）**本条目尚未复现**。
