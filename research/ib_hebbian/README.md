# W1：核化 IB-Hebbian 感知层

**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

## 在验证什么命题

计划书 §3.3 的感知层学习规则：**Pogodin & Latham (2020) 由核化信息瓶颈导出的三因子
Hebbian 规则，加上除法归一化，能否作为感知层特征提取器在 MNIST 上达到计划书 §七
第一阶段要求的 70%+。**

除法归一化不是可选项。论文摘要的原话：

> In addition, to work on hard problems and remain biologically plausible, our update
> rules need divisive normalization, a computation done by the primary visual cortex
> and beyond.

论文实验部分进一步区分了「分组」与「分组 + 除法归一化」两种变体，结论是**高斯核必须
有分组 + 除法归一化才有像样的准确率**。这正是计划书 §十一 把它列为 P0 的那一条。

## 当前结论

**达到。** 阈值 70%，**两个读出都在其上**：**岭回归闭式解读出（现行默认）97.79%**、
交叉熵 + SGD **98.01%**。两个数字都是「局部学到的特征 + 监督读出」的**联合结果**，不是局部规则
单独达到的精度——先说清楚，再往下看。

**但这个数字是两段拼起来的，必须说清**：隐藏层用**局部规则**学特征，最后**用一个监督训练的
线性读出**分类。98.01% 是这两段的联合结果，**不是「局部规则单独达到的精度」**。

读出有两种实现，都在阈值之上：

| 读出 | 测试准确率 | 怎么学的 |
| :--- | ---: | :--- |
| 交叉熵 + SGD | 98.01% | 反向传播 + 学习率 + 动量 + 100 个 epoch |
| **岭回归闭式解（现行默认）** | **97.79%** | 累积 `XᵀX / XᵀY` 后**一次解出**：无反向传播、无学习率、无迭代；λ=1e-4 由**验证集**选出（`{0, 1e-4, 1e-3, 1e-2, 1e-1}` 里验证准确率最高，0.9793） |

**多随机种子（论文口径）**：论文表 1/表 4 报的是 5 个随机种子的**均值与极差**（MNIST 上对应列的极差是 **0.2** 个百分点，见论文 Table 5），所以这里用同一口径重跑了一遍（`uv run python -m research.ib_hebbian.sweep_seeds --seeds 0-4`）：

| 种子 0–4（5 个） | 测试准确率 |
| :--- | ---: |
| 均值 | **0.9774** |
| 最小 / 最大 | 0.9765 / 0.9779 |
| **极差** | **0.14 个百分点**（论文同列 0.2） |

逐种子的记录（含配置与耗时）在 [`sweep_results/w1_seeds/`](../../sweep_results/w1_seeds/)。

**两者都不是「局部」的读出**——都用标签、都是监督的。闭式解去掉的是**反向传播与迭代**，
**不是全局性**：`XᵀX` 是 `(H+1)²` 的矩阵，需要**全体训练样本**才能累积出来。详见
「「局部」的准确表述」一节。

隐藏层那一侧不受读出选择影响：它用的是**自己的**目标（Eq. 35 的二值教学信号），训练期间
完全不知道读出是什么。实测它的局部目标在训练中从 −0.1299 降到 −0.2931（**最低点在 epoch 90**；epoch 100 收在
−0.2929，末段有轻微回升，所以**不是严格单调**），所以
**差的 0.22 个百分点只来自分类那一步换了算法**，不是特征变差了。

论文在 3 层 × 1024 全连接、高斯核 + 分组 + 除法归一化下的 MNIST 数字是 **98.1%**
（backprop 98.6%），所以本实现与论文基本一致——不是"刚好过线"，而是复现了那条规则。

## 「局部」的准确表述

计划书 §3.3 说第三因子「无需自顶向下传递即可获得」，§9 的「生物合理性」一行要求
「无全局反向传播」。本实现让这两句话有据可依，所以把边界写清楚：

**成立的部分**：每层有**自己的目标函数**与**自己的优化器**，在该层的前向过程中就地
更新参数；层的输入被显式切断梯度，所以**任何梯度都不会流回上一层**——不存在从输出层
一路回传到输入的全局反向传播。这有测试断言，不是文档里的承诺：在模型层面，读出层的
交叉熵反向传播后，每个隐藏层权重的 `.grad` 必须是 `None`。

**不成立、也不应声称的部分**：本实现用 autograd 计算**该层局部目标**对其自身权重的
梯度。autograd 在这里是**仿真手段**，不是学习机制。局部性主张的根据是论文由 Eq. (10)
推导出的三因子 Hebbian 形式（Eq. 12 / Eq. 18）：

```text
ΔW^k_{αnm} ∝ M^k_{α,ij} ( r^k_{αn,i} r^{k−1}_{m,i} − r^k_{αn,j} r^{k−1}_{m,j} )
```

即更新正比于「前突触活动 × 后突触活动 × 一个每对数据点一个标量的第三因子」。论文明文
说实验里用的就是批量版的 Eq. (10) 梯度（"We used the batch version of the update rule
(Eq. (10)) only to make large-scale simulations computationally feasible"），所以本
实现与论文的实现是同一条路径。

**因此对外表述应当是**：「每层用局部目标更新，无跨层梯度回传，更新规则具有三因子
Hebbian 形式（Eq. 18）」；**不应**说「完全没有反向传播」。

**读出那一段是哪一种「不局部」，要单独说清。** 闭式解读出（`readout.py`）**没有反向传播、
没有迭代**，它的两个累积量 `h hᵀ`（前后突触活动之积）与 `h yᵀ`（前突触活动 × 教学信号）
都是**逐样本可加**的 Hebbian 式相关——累积这一步是这里唯一"像 Hebbian"的地方。**但它们累积
出来的 `XᵀX` 是 `(H+1)²` 的全局二阶统计量**，需要**全体训练样本**；最后那次求逆也是全局的；
而且它用了标签。所以正确的说法是「**无反向传播、非迭代的闭式读出**」，**不应**说「局部学习的
读出」或「纯局部分类」。它相对于 SGD 读出的改进是**去掉了反向传播与迭代，不是去掉了全局性**。

## 已知边界

这一节比结论重要——数字好看不等于结论没有边界。

1. **这是速率型网络，不是脉冲型。** 隐藏层是 LReLU，不是脉冲神经元。所以计划书 §9 的
   「活跃神经元比例」「脉冲稀疏度」在这里是**类比量**，不是原义指标。本实现量的是
   **除法归一化之前**的活动：归一化按组居中了活动，之后恒有一半左右单元为负，
   在那个量上算"活跃比例"只是在数分组。归一化前实测活跃单元比例 0.9639。
2. **多种子统计已经做了，但它不等于「与论文一致」。** 用论文的口径跑了 5 个种子
   （`--seeds 0-4`）：均值 **0.9774**、极差 **0.14 个百分点**
   （论文 Table 5 在 MNIST 同一列上给的极差是 **0.2** 个百分点——同量级）。**它说明的是稳定性，不是逐点复现**——
   η_l 与 c_k 没有照抄论文（见下一条），读出也换成了闭式解。
3. **超参：用的就是论文 Table 3 里 MNIST 那一行的值（此前无法确认，现已考证）。**
   这里原来写着「Table 3 的列与 PDF 抽取出的数值对不齐，逐列映射无法可靠还原，未做系统调参」。
   **那个"对不齐"是 PDF 文本抽取的假象**：`pdftotext` 会丢掉空单元格、并把标签列与数值列拆散
   （η_l 行只剩 6 个数、c^k 行也只剩 6 个，看着像缺格）。改用 arXiv 的 HTML 与 LaTeX 源**逐格解析**
   后，Table 3 可以**完整还原**，并可用官方仓库的网格脚本交叉核对（MNIST 那一行 30 格逐格吻合）。

   MNIST 里与本条目对应的是 **`pHSIC: Gaussian` + `grp+div`** 那一列：**η_l = 1.0、c^k = 32**，
   另有全实验共享的 **σ = 5、γ = 2**。本条目用的正是这三个值——所以那句「没有照抄论文」的正确说法是
   **照抄了，只是此前无法确认**。

   ⚠️ **仍然不同的是读出**：论文这一列的 η_f = 1e-3（最后一层用 SGD 训），本条目默认用岭回归闭式解
   （λ 由验证集选），保留的 SGD 读出用的是 η_f = 5e-3。
   ⚠️ **引用 Table 3 时注意论文自身的一处排版错位**：CIFAR10 区块第 2、4 列的 `c^k = 32` 被排到了
   η_l 行（官方网格脚本里那两列是 `lrb=0, dim=32`）。本条目不涉及 CIFAR10，只记在这里备查。
   ⚠️ 官方实现是 `github.com/romanpogodin/plausible-kernelized-bottleneck`（论文 §5.1 的地址；
   仓库此前草稿里写的 `linear-kernel-IB` 不存在）。
4. **教学信号用了论文的二值简化形式。** 论文的 Eq. (35) 是"居中标签的余弦相似度"，
   类别均衡时化简为二值信号，论文实验用的就是它。所以标签信息只经一个标量进入第三
   因子——这一点在代码里是显式的，不是隐含假设。
5. **消融做齐了，但五条臂里有一条没复现——而且原因不是"差一点"，是那条臂跑飞了。**
   论文点名的三组对照（HSIC/pHSIC、核、分组）加上除法归一化，一共**五条臂**（1 条基线 + 4 条对照），
   每条对应论文 Table 4 里 MNIST 的**某一列**（映射见 `research/ib_hebbian/ablation.py`）。种子 0：

   | 臂 | 对应论文的列（Table 3 的 η_l / c^k） | 论文（5 种子均值 / 极差） | 本条目（种子 0） | Δ vs baseline |
   | :--- | :--- | ---: | ---: | ---: |
   | `baseline` | Gaussian `grp+div`（η_l=1.0、c^k=32） | 98.1 / 0.2 | **97.79** | — |
| `divnorm_off` | Gaussian `grp`（η_l=1.0、c^k=32） | 98.4 / 0.3 | **92.61** | -5.18 |
| `grouping_off` | Gaussian `plain`（η_l=0.6） | 94.6 / 0.2 | **94.25** | -3.54 |
| `cossim` | cossim `grp+div`（η_l=0.4、c^k=16） | 96.3 / 0.6 | **95.82** | -1.97 |
| `hsic` | **论文没有这一列的数**（—） | — | **97.69** | -0.10 |

   逐臂逐种子的 JSON 在 [`sweep_results/w1_ablation/`](../../sweep_results/w1_ablation/)，完整 stdout 在
   [`sweep_results/w1_ablation.log`](../../sweep_results/w1_ablation.log)——五条臂的复现记录块都在里面，
   `Git 状态` 逐条为"干净"。**读这张表要注意五点**：

   - `baseline` 是空覆盖，数字与验收配置**逐字一致**（0.9779）——这是"加了开关没改默认路径"的自检，
     不是又一个结果。
   - **三条臂复现得上**：`plain` 94.25 对论文 94.6、`grp+div` 97.79 对 98.1、`cossim grp+div`
     95.82 对 96.3，三条都在 **0.5 个百分点以内**。
   - **`divnorm_off` 没复现，而且那条臂是发散的**：它的局部目标在第 10 轮前后触底（−0.2484）之后
     **一路上爬**，第 50 轮回到 −0.0936、终值 −0.1614，其余四条臂都是单调改善。所以 92.61 是
     **一次跑飞的读数**，不能读成"论文那一列在本实现下的表现"。一个可信的机制是：关掉除法归一化后
     前向输出不再被归一化、三层叠起来尺度失控（旁证是这条臂的闭式读出在验证集上选了 λ=0，
     其余臂选 1e-4）。**但这只是解释，没有实验证据，不要当结论用。**
   - **超参没有逐列重调**：论文每一列的 η_l / c^k 都不同（Table 3），本条目全部沿用验收配置
     （η_l=1.0、c^k=32）。所以 `grouping_off` 用的是 η_l=1.0 而论文那一列是 0.6、`cossim` 用 1.0
     而论文是 0.4。**五条臂里只有 `baseline` 与 `divnorm_off` 两臂与论文同列同超参**——而恰恰是后者发散了。
   - **`hsic` 那一臂没有论文数字可比**：论文跑了这个对照，但只在 §5.1 与附录 D.8 给了定性结论
     （"Optimizing HSIC instead of our approximation, pHSIC, didn't improve performance"；
     D.8："training with HSIC instead did not lead to a significant change in the results (not shown)"）。
     本条目 −0.10 个百分点，与那句定性结论方向一致。
