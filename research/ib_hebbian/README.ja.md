# W1：カーネル化 IB-Hebbian 知覚層

[中文](README.md) · [English](README.en.md)

**⚠️ 破壊的変更の免責期間：2027-09 まで**（プロジェクト計画書 §12.5、ADR-0005）。

## どの命題を検証しているのか

プロジェクト計画書 §3.3 の知覚層学習則：**Pogodin & Latham (2020) がカーネル化情報
ボトルネックから導いた三因子 Hebbian 則に除法正規化を加えたものが、知覚層の特徴抽出器
として MNIST で §七 フェーズ 1 が要求する 70%+ に到達できるか。**

除法正規化は任意ではありません。論文の要旨の原文：

> In addition, to work on hard problems and remain biologically plausible, our update
> rules need divisive normalization, a computation done by the primary visual cortex
> and beyond.

論文の実験部はさらに「グループ化」と「グループ化 + 除法正規化」の二変種を分けており、
結論は**ガウスカーネルはグループ化 + 除法正規化がなければまともな精度にならない**と
いうものです。これはまさに計画書 §十一 が P0 に挙げている項目です。

## 現時点の結論

**達成。** 閾値は 70% で、**どちらの読み出しもそれを上回る**：**リッジ回帰の閉形式解
（現在の既定）が 97.79%**、交差エントロピー + SGD が **98.01%**。どちらの数値も
「局所的に学んだ特徴 + 教師あり読み出し」の**共同の結果**であり、局所規則だけが単独で
到達した精度ではない——先に明記してから話を進める。

**ただしこの数字は二つの部分を繋ぎ合わせたものであり、それを明記する必要がある**：
隠れ層は**局所規則**で特徴を学び、分類は**教師ありで訓練した線形読み出し**が行う。98.01% は
その二つの**共同の結果**であり、**「局所規則だけが単独で到達した精度」ではない**。

読み出しには二つの実装があり、どちらも閾値を上回る：

| 読み出し | テスト精度 | どう学ぶか |
| :--- | ---: | :--- |
| 交差エントロピー + SGD | 98.01% | 逆伝播 + 学習率 + モメンタム + 100 エポック |
| **リッジ回帰の閉形式解（現在の既定）** | **97.79%** | `XᵀX / XᵀY` を累積し、**一度だけ解く**：逆伝播なし・学習率なし・反復なし。λ=1e-4 は**検証セット**が選択（`{0, 1e-4, 1e-3, 1e-2, 1e-1}` の中で検証精度が最高、0.9793） |

**複数シード（論文自身の口径）**：論文の表 1・表 4 は 5 つの乱数シードの**平均と最大最小差**を
報告しています（MNIST の対応列では **0.2** パーセントポイント、論文 Table 5）。そこで同じ口径で再実行しました
（`uv run python -m research.ib_hebbian.sweep_seeds --seeds 0-4`）：

| シード 0–4（5 回） | テスト精度 |
| :--- | ---: |
| 平均 | **0.9774** |
| 最小 / 最大 | 0.9765 / 0.9779 |
| **最大最小差** | **0.14 パーセントポイント**（論文の同列は 0.2） |

シードごとの記録（設定と所要時間を含む）は [`sweep_results/w1_seeds/`](../../sweep_results/w1_seeds/) にあります。

**どちらも「局所」な読み出しではない**——どちらもラベルを使い、教師ありである。閉形式解が
取り除いたのは**逆伝播と反復**であって、**大域性ではない**：`XᵀX` は `(H+1)²` の行列で、
**全訓練サンプル**を必要とする。「『局所』の正確な表現」の節を参照。

隠れ層の側は読み出しの選択に影響されない：**自身の**目的関数（式 35 の二値教示信号）を
最適化し、訓練中は読み出しが何であるかを一切知らない。その局所目的関数は −0.1299 から
−0.2931 まで低下するのを実測している（**最低点は epoch 90**、epoch 100 は −0.2929 で
終わり、末尾はわずかに戻るので**厳密な単調ではない**）。したがって**0.22 ポイントの差は分類段のアルゴリズムを
差し替えたことだけに由来する**のであって、特徴が悪化したのではない。

3 層 × 1024 全結合、ガウスカーネル + グループ化 + 除法正規化における論文の MNIST の
数値は **98.1%**（backprop 98.6%）ですので、本実装は論文とほぼ一致しています——
「ぎりぎり超えた」のではなく、あの則を再現したものです。

## 「局所」の正確な表現

計画書 §3.3 は第三因子が「トップダウンの伝播なしに得られる」と述べ、§9 の生物学的
妥当性の行は「大域的な逆伝播なし」を要求しています。本実装はその二文を根拠づけられる
ものにするため、境界を明記します。

**成り立つ部分**：各層は**自分自身の目的関数**と**自分自身のオプティマイザ**を持ち、
その層の前向き計算の中でその場でパラメータを更新します。層の入力は勾配を明示的に
切断されているため、**いかなる勾配も前の層へ流れ戻りません**——出力層から入力まで
さかのぼる大域的な逆伝播は存在しません。これは文章上の約束ではなくテストで断言されて
います：モデル水準で、読み出し層の交差エントロピーを逆伝播させた後、各隠れ層の重みの
`.grad` は `None` でなければなりません。

**成り立たず、主張してもいけない部分**：本実装は autograd を用いて**その層の局所目的**の
自身の重みに関する勾配を計算します。ここでの autograd は**シミュレーションの手段**であり、
学習の仕組みではありません。局所性の主張の根拠は、論文が Eq. (10) から導いた三因子
Hebbian 形式（Eq. 12 / Eq. 18）です：

```text
ΔW^k_{αnm} ∝ M^k_{α,ij} ( r^k_{αn,i} r^{k−1}_{m,i} − r^k_{αn,j} r^{k−1}_{m,j} )
```

すなわち更新は「前シナプス活動 × 後シナプス活動 × データ点の各対について 1 つの
スカラーである第三因子」に比例します。論文は実験で Eq. (10) のバッチ版の勾配を用いたと
明記しています（"We used the batch version of the update rule (Eq. (10)) only to make
large-scale simulations computationally feasible"）。したがって本実装と論文の実装は
同じ道筋をたどっています。

**したがって対外的な表現は**「各層は局所目的で更新し、層をまたぐ勾配の戻りはなく、
更新則は三因子 Hebbian 形式（Eq. 18）を持つ」とすべきです；「逆伝播は一切ない」と
述べてはいけません。

**読み出しがどの種類の「非局所」なのかは、別に明記する必要があります。** 閉形式解の読み出し
（`readout.py`）は**逆伝播も反復もありません**。その二つの累積量 `h hᵀ`（前後シナプス活動の積）
と `h yᵀ`（前シナプス活動 × 教示信号）は**サンプルごとに加算可能**な Hebbian 型の相関であり、
ここで唯一「Hebbian 的」なのはこの累積の段だけです。**しかしそれらが累積する `XᵀX` は
`(H+1)²` の大域的な二次統計量**で、**全訓練サンプル**を必要とします。最後の求解も大域的であり、
ラベルも使います。したがって表現は「**逆伝播なし・反復なしの閉形式解の読み出し**」とすべきで、
「局所学習の読み出し」や「純局所的な分類」と述べてはいけません。SGD 読み出しに対する改善は
**逆伝播と反復を取り除いたことであって、大域性を取り除いたことではありません**。

## 最小再現スクリプト

`examples/paper_pogodin2020.py`（プロジェクト計画書 §12.3）。これは意図的に **MNIST の
ダウンロードに依存しません**：合成の高次元二値分類データを使い、CPU で数十秒で終わり、
CI が直接実行します。検証するのは三点——局所目的が計算できること、その勾配がその層の
重みだけに落ちること、反復更新後の精度が偶然水準を大きく上回ること——に加えて除法
正規化のアブレーションです。

ローカル実測（CPU、`uv run python examples/paper_pogodin2020.py`）：

| 設定 | 精度 |
| :--- | ---: |
| p = 0.2（論文の設定） | 0.9805 |
| p = 0.0（分散によるスケーリングなし） | 0.7480 |

これは**弱い**アブレーションです：この課題で正規化の項が効いていることを示すだけで、
論文のあの主張の独立した検証にはなりません。

## 既知の境界

この節は結論より重要です——数値が良いことは、結論に境界がないことを意味しません。

1. **これはレート型のネットワークであり、スパイク型ではありません。** 隠れ層は LReLU で、
   スパイクニューロンではありません。したがって計画書 §9 の「活動ニューロン比率」と
   「スパイク疎度」はここでは**類似量**であり、本来の指標ではありません。本実装は
   **除法正規化の前**の活動を測ります：正規化はグループ内で活動を中心化するため、その後は
   常に半数ほどのユニットが負になります。その量で「活動比率」を計算しても、グループを
   数えているだけです。正規化前の実測活動ユニット比率は 0.9639 です。
2. **複数シードの統計は取りました——ただしそれは「論文と一致する」と同じ意味ではありません。**
   論文自身の口径で 5 シードを実行（`--seeds 0-4`）：平均 **0.9774**、
   最大最小差 **0.14 パーセントポイント**（論文 Table 5 の MNIST 同一列の最大最小差は **0.2** パーセントポイント——同じ桁です）。
   **これが示すのは安定性であり、逐点の再現ではありません**——読み出しは閉形式解に変えています
   （一方 η_l と c_k は、次の項目のとおり**論文の列と一致**していました）。
3. **ハイパーパラメータ：論文 Table 3 の MNIST 行の値そのものです**（従来は確認できず、今回考証）。
   ここには以前「Table 3 の列と PDF 抽出値が対応せず、列対応を復元できない」と書かれていました。
   **その「ずれ」は PDF テキスト抽出の産物です**：`pdftotext` は空セルを落とし、ラベル列と数値列を
   分断します（η_l 行は 6 個、c^k 行も 6 個しか出ず、欠落に見えます）。arXiv の HTML と LaTeX
   ソースから**セル単位で解析**すると Table 3 は**完全に復元**でき、公式リポジトリのグリッド
   スクリプトとも一致します（MNIST 行の 30 セルすべて）。

   本項目に対応するのは **`pHSIC: Gaussian` + `grp+div`** の列で、**η_l = 1.0、c^k = 32**、
   さらに全実験共通の **σ = 5、γ = 2** です。本項目が使っているのはまさにこれらの値——
   つまり「論文から写していない」の正確な形は **「写していた。ただし従来は確認できなかった」** です。

   ⚠️ **読み出しだけは依然として異なります**：その列の η_f は 1e-3（最終層を SGD で訓練）ですが、
   本項目の既定はリッジ回帰の閉形式解（λ は検証集合で選択）で、保持している SGD 読み出しは
   η_f = 5e-3 です。
   ⚠️ **Table 3 を引用する際は論文自身の組版ずれに注意**：CIFAR10 ブロックの第 2・4 列の
   `c^k = 32` が η_l 行に印字されています（公式グリッドスクリプトでは `lrb=0, dim=32`）。
   本項目は CIFAR10 を扱わないため、備考としてのみ記します。
   ⚠️ 公式実装は `github.com/romanpogodin/plausible-kernelized-bottleneck`（論文 §5.1 のアドレス）。
4. **教学信号は論文の二値簡略形を用いています。** 論文の Eq. (35) は「中心化したラベルの
   コサイン類似度」であり、クラスが均衡なとき二値信号に簡約され、論文の実験はそれを
   使っています。したがってラベル情報は 1 つのスカラーを通じて第三因子に入ります——
   これはコード上で明示的であり、隠れた仮定ではありません。
5. **行ったアブレーションは除法正規化の一つだけ**であり、しかも弱い形式です。論文が
   行っている他の比較（HSIC 対 pHSIC、コサインカーネル対ガウスカーネル、グループ化の
   有無）は**本項目ではまだ再現していません**。
