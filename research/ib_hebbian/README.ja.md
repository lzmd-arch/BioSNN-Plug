# W1：カーネル化 IB-Hebbian 知覚層

[中文](README.md) · [English](README.en.md)

**⚠️ 破壊的変更の免責期間：2027-09 まで**（プロジェクト計画書 §12.5、ADR-0005）。

## どの命題を検証しているのか

プロジェクト計画書 §3.3 の知覚層学習則：**Pogodin & Latham (2020) がカーネル化情報
ボトルネックから導いた三因子 Hebbian 則に除法正規化を加えたものが、知覚層の特徴抽出器
として MNIST で §七 フェーズ 1 が要求する 70%+ に到達できるか。**

除法正規化は任意ではありません。論文の要旨の原文：

> In addition, to work on hard problems and remain biologically plausible, our update
> rules need divisive normalization, a computation done by the primary visual cortex
> and beyond.

論文の実験部はさらに「グループ化」と「グループ化 + 除法正規化」の二変種を分けており、
結論は**ガウスカーネルはグループ化 + 除法正規化がなければまともな精度にならない**と
いうものです。これはまさに計画書 §十一 が P0 に挙げている項目です。

## 現時点の結論

**達成。テスト精度 98.01%、閾値 70%。**

3 層 × 1024 全結合、ガウスカーネル + グループ化 + 除法正規化における論文の MNIST の
数値は **98.1%**（backprop 98.6%）ですので、本実装は論文とほぼ一致しています——
「ぎりぎり超えた」のではなく、あの則を再現したものです。

## 「局所」の正確な表現

計画書 §3.3 は第三因子が「トップダウンの伝播なしに得られる」と述べ、§9 の生物学的
妥当性の行は「大域的な逆伝播なし」を要求しています。本実装はその二文を根拠づけられる
ものにするため、境界を明記します。

**成り立つ部分**：各層は**自分自身の目的関数**と**自分自身のオプティマイザ**を持ち、
その層の前向き計算の中でその場でパラメータを更新します。層の入力は勾配を明示的に
切断されているため、**いかなる勾配も前の層へ流れ戻りません**——出力層から入力まで
さかのぼる大域的な逆伝播は存在しません。これは文章上の約束ではなくテストで断言されて
います：モデル水準で、読み出し層の交差エントロピーを逆伝播させた後、各隠れ層の重みの
`.grad` は `None` でなければなりません。

**成り立たず、主張してもいけない部分**：本実装は autograd を用いて**その層の局所目的**の
自身の重みに関する勾配を計算します。ここでの autograd は**シミュレーションの手段**であり、
学習の仕組みではありません。局所性の主張の根拠は、論文が Eq. (10) から導いた三因子
Hebbian 形式（Eq. 12 / Eq. 18）です：

```text
ΔW^k_{αnm} ∝ M^k_{α,ij} ( r^k_{αn,i} r^{k−1}_{m,i} − r^k_{αn,j} r^{k−1}_{m,j} )
```

すなわち更新は「前シナプス活動 × 後シナプス活動 × データ点の各対について 1 つの
スカラーである第三因子」に比例します。論文は実験で Eq. (10) のバッチ版の勾配を用いたと
明記しています（"We used the batch version of the update rule (Eq. (10)) only to make
large-scale simulations computationally feasible"）。したがって本実装と論文の実装は
同じ道筋をたどっています。

**したがって対外的な表現は**「各層は局所目的で更新し、層をまたぐ勾配の戻りはなく、
更新則は三因子 Hebbian 形式（Eq. 18）を持つ」とすべきです；「逆伝播は一切ない」と
述べてはいけません。

## 最小再現スクリプト

`examples/paper_pogodin2020.py`（プロジェクト計画書 §12.3）。これは意図的に **MNIST の
ダウンロードに依存しません**：合成の高次元二値分類データを使い、CPU で数十秒で終わり、
CI が直接実行します。検証するのは三点——局所目的が計算できること、その勾配がその層の
重みだけに落ちること、反復更新後の精度が偶然水準を大きく上回ること——に加えて除法
正規化のアブレーションです。

ローカル実測（CPU、`uv run python examples/paper_pogodin2020.py`）：

| 設定 | 精度 |
| :--- | ---: |
| p = 0.2（論文の設定） | 0.9805 |
| p = 0.0（分散によるスケーリングなし） | 0.7480 |

これは**弱い**アブレーションです：この課題で正規化の項が効いていることを示すだけで、
論文のあの主張の独立した検証にはなりません。

## 既知の境界

この節は結論より重要です——数値が良いことは、結論に境界がないことを意味しません。

1. **これはレート型のネットワークであり、スパイク型ではありません。** 隠れ層は LReLU で、
   スパイクニューロンではありません。したがって計画書 §9 の「活動ニューロン比率」と
   「スパイク疎度」はここでは**類似量**であり、本来の指標ではありません。本実装は
   **除法正規化の前**の活動を測ります：正規化はグループ内で活動を中心化するため、その後は
   常に半数ほどのユニットが負になります。その量で「活動比率」を計算しても、グループを
   数えているだけです。正規化前の実測活動ユニット比率は 0.9639 です。
2. **単一の実行であり、5 回の平均ではありません。** 論文の表 1・表 4 は 5 つの乱数シードの
   平均と最大最小差を報告しています（MNIST での差は約 0.3〜0.4 パーセントポイント）。
   本項目はシード `base=0` の 1 回の実行を報告します。「論文と一致する」と主張するために
   必要な複数実行の統計は**まだ取っていません**。
3. **η_l（局所学習率）は論文から写していません。** 表 3 の列と PDF から抽出した数値が
   対応しません（数値の列が 10 個あるのに対し η_l と c_k はそれぞれ 6 個）。列と値の
   対応は信頼できる形で復元できません。論文自身も検証集合で調整しています（D.5）。
   本実行では η_l = 1.0、c_k = 32、読み出し η_f = 5e-3 を用い、**系統的な調整はして
   いません**——98.01% はこれらの値で得られる結果であり、到達しうる最良ではありません。
4. **教学信号は論文の二値簡略形を用いています。** 論文の Eq. (35) は「中心化したラベルの
   コサイン類似度」であり、クラスが均衡なとき二値信号に簡約され、論文の実験はそれを
   使っています。したがってラベル情報は 1 つのスカラーを通じて第三因子に入ります——
   これはコード上で明示的であり、隠れた仮定ではありません。
5. **行ったアブレーションは除法正規化の一つだけ**であり、しかも弱い形式です。論文が
   行っている他の比較（HSIC 対 pHSIC、コサインカーネル対ガウスカーネル、グループ化の
   有無）は**本項目ではまだ再現していません**。
