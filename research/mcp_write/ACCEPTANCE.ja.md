## この受け入れで見つけて直したこと

**最初の実行では S4 が赤でした**：書き込み前に庫ファイルが無く、取り消し後に空の JSON が
残りました——中身は同じでもハッシュが違います。S4 は「庫ファイルのハッシュが書き込み前に戻る」
ことを求めるので、`_restore` は前像が空のとき**ファイルを削除**するように変えました。
この挙動はテストで固定しています（`test_revert_of_the_first_write_leaves_no_store_file`）。

## この実行が示していないこと

- **Axo のインストーラは作っていない**：二段階は同じコードと同じパッケージを共有し（決定 1、§4.1）、
  UI スイッチ（P4）は動くが、PyInstaller のパッケージングと二段階の配布説明は未実施。
- **書き込み先は biosnn 側の代替核のまま**：Axo の実ライブラリは P1–P6 の範囲外（決定 2）。
- **実モデルは未接続**：`source` はスクリプトが埋め、顕著度は定数だけで計算している。
- **Linux は wheel のみ**：Axo の二段階は Windows でしか動かしていない。
