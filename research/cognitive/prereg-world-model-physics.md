# 预注册：Acrobot 的世界模型——能量偏置采集 + 多样化物理约束（2026-11-12）

**状态：判据先落盘。**

**上游**：`sweep_results/world_model_cubic/README.md` 的根因发现——
**目标区域不在训练分布里**（`cos θ1` 训练范围 `[−0.065, +1.000]`，而成功需要 `cos θ1 ≈ −1`）。

## 1. 问题

Acrobot 上，世界模型 + 3 步前瞻能到 −178，但**目标区域从未被观测过**。
此前三条优化（裁剪 / 集成分歧度 / 三次项）全是负结果，方向一致：它们都在**回避**无数据区，
而任务要求模型**进入**那里。

**两个独立的问题必须分开问**：

- **Q1 数据**：把目标区域采进训练集，控制能不能显著变好？
- **Q2 约束**：在数据之外，物理约束能不能让外推**有界且可用**？

## 2. 数据：能量偏置采集

随机动作在 Acrobot 上很难积累动量（需要持续同向施力）。改用 **β-能量策略**：

| 策略 | 动作选择 |
| :--- | :--- |
| 均匀随机 | `a ~ U{0,1,2}`（现行） |
| **能量偏置** | 以概率 `p_stick` **重复上一步动作**，否则均匀随机 |

`p_stick` ∈ {0.5, 0.75}。重复动作能持续注入能量，把摆荡到 `cos θ1 < −0.5` 的区域。

**采集前置（`PC-0`）**：能量偏置采到的数据里，`cos θ1` 的 **1% 分位数 ≤ −0.5**，
且总转移数不少于均匀随机的 50%。（否则"目标区域已覆盖"这个前提不成立。）

## 3. 多样化物理约束（四条，可独立开关）

| # | 约束 | 内容 | 作用在哪 |
| :--- | :--- | :--- | :--- |
| **C1** | 单位圆 | `(cos θ_i, sin θ_i)` 投影回单位圆 | 角度块自身 |
| **C2** | **运动学一致** | 由 `(cos θ_i, sin θ_i)` 解缠后的角度差 `Δθ_i` 应约等于 `ω_i · Δt`；投影使二者一致 | **耦合角度块与速度块**（当前完全独立预测） |
| **C3** | **能量上界** | 单步动能变化 `ΔE` 落在 `±τ_max·|Δθ|` 内；超界则按比例缩回 | 速度块（此前溢出的地方） |
| **C4** | 速度上限 | `|ω_i|` 不超过**由能量守恒推出的上界**，不是观测范围 | 速度块 |

**C4 的关键**：上限由物理推（给定初始能量与最大力矩输入），**不是**训练数据的 min/max——
后一种已被证否（会连目标区一起裁掉）。

## 4. 判据

### 4.1 前置（`PC-0`）

- [ ] 能量偏置数据的 `cos θ1` 1% 分位 ≤ −0.5；
- [ ] 四条约束各自开启时**都不改变一步预测的合法性**（不产生 NaN）。

### 4.2 主判据（`PC-1`，双臂对照）

| # | 判据 | 阈值 |
| :--- | :--- | :--- |
| **PC-1a** | **数据起作用** | 能量偏置数据训练的模型，h=10 回报 **优于** 均匀随机数据模型（5 种子，配对） |
| **PC-1b** | **约束起作用** | 在能量偏置数据上，`C1+C2+C3+C4` 全开时 h=20 的回报 **优于全关** |

**PC-1a 与 PC-1b 相互独立**：数据是数据，约束是约束，不能用一个的改善掩盖另一个的不成立。

### 4.3 kill（`PC-2`）

- PC-1a 不过 ⇒ 判"**目标区域覆盖不是瓶颈**"，回到模型类方向；
- PC-1b 不过 ⇒ 判"**这四条物理约束对多步外推无效**"，并**逐条报告是哪一条起了反作用**
  （允许单独剔除那一条再测一次，总共最多剔除两条）。
