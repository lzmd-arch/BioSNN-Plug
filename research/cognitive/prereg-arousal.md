**这份文件补的正是那个缺口**：给 `arousal` 一个能判真假的验收条件。

## 1. 问题

一个**只调制增益、不进权重**的标量控制器，有没有可能让系统在**非平稳**环境里适应得更快？

**为什么必须在非平稳任务上测**：在平稳任务上，固定增益调好一次就够，任何自适应都只可能更差
（这正是仲裁器那条线的教训——ADV：最优值恰好是任务的默认值，见
[`../audit-axis-defects-2026-11-12.md`](../audit-axis-defects-2026-11-12.md) 的 D2）。
**非平稳是唤醒通道唯一可能证明自己的场景。**

## 2. 前提

| 前提 | 在哪 |
| :--- | :--- |

## 3. 任务：规则在未知时刻切换的迷宫

在既有滑移迷宫（9×9、`p_slip=0.10`）上做一处改动：**每 K 个回合，把四个动作到方向的映射
做一次随机置换，不告知被试**。

- 环境本身不变（同样的迷宫、同样的滑移），变的只有"按哪个键往哪走"；
- 于是**策略必须重学**，而重学需要探索；
- 被试只能通过**预测误差上升**察觉这件事——这正是唤醒通道该响应的地方。

| 参数 | 值 |
| :--- | :--- |
| 迷宫 | size 9，seed 0–4（每个种子一条独立流） |
| 每段长度 K | **40 回合** |
| 段数 | 6 段（共 240 回合） |
| 评估 | 每段的**恢复回合数**，以及段尾成功率 |

## 4. 两支

| 臂 | 控制器 |
| :--- | :--- |
| **A 固定** | 探索温度 τ = 1.0 常数（现网默认） |
| **B 唤醒** | `τ = 1.0 × exp(a)`，`a = clip(β · (Ê − Ê_ref), 0, 2)`；`Ê` 是预测误差的 EMA，`Ê_ref` 是上段的均值 |

**arousal 的定义沿用 ADR-0016**：由输入强度与近期发放统计更新，**不由反向传播训练**；
这里只把它接到探索温度上（其余调制点留作后续迭代）。

**唯一超参** `β` 在两个种子上扫一遍后固定，**在留出的三个种子上评估**。

## 5. 判据

### 5.1 前置（`AR-0`）

- [ ] 五条流上，A 臂的段尾成功率 ≥ 0.60（任务可解，否则测的是学习能力不是适应）；
- [ ] 置换后第一回合的成功率确实下降（中位跌幅 ≥ 10pp）——**否则切换没有被感知到**，
      整个实验无效；
- [ ] B 臂的 `a` 在切换后确实上升（否则不是"唤醒通道"在起作用，是别的什么）。

任一条不过 ⇒ **不判主判据**，先修任务或接线。

### 5.2 主判据（`AR-1`）

| # | 判据 | 阈值 |
| :--- | :--- | :--- |
| AR-1a | **恢复更快** | B 的恢复回合数中位数 **≤ 0.8 × A**（5 种子，配对） |
| AR-1b | **平稳段不掉** | B 在段中后期（切换后 20 回合起）的成功率 **不低于 A − 1pp** |

**两条都过才算成立。** 只过 AR-1a 是"靠抖动换适应"，不算。

### 5.3 kill（`AR-2`）

- B 恢复更慢，或平稳段掉 > 2pp ⇒ **这一个调制方向（探索温度）判否**；
- 允许换一个调制对象（巩固频率或发放阈值）**再测一次**，但**总共只测两个对象**；
- 两个都不行 ⇒ 唤醒通道在本任务族上判否，写进负结果并说明测过哪两个方向。

| 早停 | 无 |
| 停止点 | 固定回合数；报告段尾与恢复回合数两条曲线 |

## 7. 数据与边界

- 全部合成、可复现，**不入库数据文件**（迷宫由种子生成）；
- 不接产品路径；
- 本实验的 `arousal` 只是研究侧实现，**不声称它与任何生物构念等价**（ADR-0016 的措辞边界）。
