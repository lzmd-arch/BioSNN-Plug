## 1. 上一轮测到了什么，以及它为什么不够

`sweep_results/consolidation/README.md`（2026-10-24）：

| 臂 | ACC | AF |
| :--- | ---: | ---: |
| C0 无巩固 | 0.658 | 0.127 |
| C1 巩固（向全体均值收缩，λ=0.02，3 轮） | 0.637 | **0.196** |
| C2 打乱目标（同量算力） | 0.531 | 0.399 |

**两条判据都没过**（AF 要降 0.02，实际升 0.068；ACC 要跌不超 0.01，实际跌 0.021）。

三个必须修的问题：

1. **"5 个种子"其实是同一个确定性运行。** 冻结前端 + 缓存特征 + 原型累加，整条管线没有随机性，
   五个种子给出完全相同的 ACC（0.658 ×5）。**这张表没有方差，不能支持"差 0.021 显著"。**
2. **只测了一种形态。** "向全体均值收缩"把类中心拉到一起，降低的是类间可分性——
   而 AF 的分母正是"旧任务还认不认得出"。这是**主动遗忘**，不是巩固。
3. **原实验的脚本与 commit 没有登记**（README 里两者都找不到）。所以 v2 **必须自己带自证块**，
   不能指望复原上一轮的实现。

## 2. 这一轮要回答的问题

在一个**真有随机性**的持续学习设定里，**投入相同的算力**，哪一种巩固形态能降低遗忘？

## 3. 任务与随机性（D3 的修法）

沿用 ResNet18 冻结前端 + 类原型 + 对角白化（与前一轮同口径，便于对照），
但**把随机性真正放进去**：

| 随机源 | 做法 |
| :--- | :--- |
| 任务顺序 | 每种子独立打乱 10 个任务的顺序 |
| 每任务的样本子集 | 每类随机抽 80%（不放回） |
| 复演的样本 | 每轮从旧任务里**随机**抽 k 个（见 C3） |

**守卫（`CG-0c`）**：五个种子的 C0 结果**必须互不相同**（否则实验作废，不许报告）。

## 4. 四臂（D4 的修法）

| 臂 | 形态 | 算力 |
| :--- | :--- | :--- |
| **C0** | 无巩固 | 基线 |
| **C3** | **定预算复演**：每个旧任务保留 k 个样本，与本任务混合 | 与 C1 对齐 |
| **C4** | **原型重定心**：把旧类中心推开（而不是拉近） | 与 C1 对齐 |
| **C2** | 打乱复演顺序（C3 的对照，"排除多跑一遍"） | 同 C3 |

## 5. 判据

### 5.1 前置（`CG-0`）

- [ ] **CG-0a** 自证块完整：commit、工作区干净、五个采集种子；
- [ ] **CG-0b** C0 的 ACC 量级与前一轮一致（0.658 ± 0.02）——说明口径没漂；
- [ ] **CG-0c** 五个种子的 C0 **不完全相同**（真随机守卫）。

任一条不过 ⇒ 不判主判据。

### 5.2 主判据（`CG-1`，沿用上一轮阈值，不放松）

| # | 判据 | 阈值 |
| :--- | :--- | :--- |
| CG-1a | **AF 降** | 相对 C0 **≥ 0.02**（5 种子中位，配对） |
| CG-1b | **ACC 不降** | 相对 C0 **跌 ≤ 0.01** |

**C3 或 C4 任一同时过两条**，即判"巩固在该前端上成立"，并记录是哪一种形态。

### 5.3 kill（`CG-2`）

- C3 与 C4 **都不满足** CG-1a/CG-1b ⇒ 判"巩固这一族**在这个前端上**不成立"，
  写进负结果，并**明确写出测过两种形态**——这比上一轮"只测一种"的结论强得多；
- 若 C3 显著优于 C4 或反之，也照实登记为形态差异，不合并成一句"巩固有用/没用"。
