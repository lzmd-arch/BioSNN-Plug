# 预注册：意识代理指标（四指标，2026-11-12）

**状态：判据先落盘。**

**上游**：[`docs/consciousness-framework.md`](../../docs/consciousness-framework.md) §1.4；
[ADR-0036](../../docs/adr/ADR-0036-consciousness-claims-discipline.md)（词汇与声明纪律）。

**这份文件做什么**：把"意识相关的功能签名"变成**四个可以算出数、可以被判否**的指标。
它**不判断任何系统是否有意识**——那是不可测的（framework §0）。它只规定：
在这四个指标上，"有信号"和"没有信号"分别长什么样，以及跑之前就定死的阈值。

> **本文件受 ADR-0036 约束**：任何一轮结果对外写作时，最强只能到"与 <理论> 预测的
> 签名**一致**"，并且**必须同时给出至少一项不成立的签名**。

## 0. 前提（已核）

| 前提 | 在哪核过 |
| :--- | :--- |
| Axo 落全事件 JSONL（含工具调用、检索账本、时间戳） | 产品实测：`D:\AxoData` 下的事件流 |
| 模型是 0.5B 局部规则网络，位级确定性（同种子同输入同输出） | `research/sel/lm/` 的种子纪律（见 `rl-training-must-be-seeded`） |
| 系统有内感知通道（`self_heat` / 电量 / BMS 断充） | Axo 传感器面 |
| 元认知门控在**产品侧不接线**（三特征门 ≡ 单阈值） | [ADR-0028](../../docs/adr/ADR-0028-metacog-gate-threshold-first.md) |

第四条是**关键的前提**：它意味着"元认知校准"这个签名**不能**用现网门控来测——
一测就是把已证伪的机制重新当成证据。要测它必须在研究侧另建任务。

## 1. 四个指标

### P-1 未言语化内部状态的外部预测

**问**：输出**之前**的内部状态，能否预测输出**是什么**？

- **度量**：用前 t 步的日志特征（发放率、读出门控值、检索得分、工具选择）预测本步输出类别，
  在**留出会话**上算 AUC。
- **对照（必须有）**：把同样的特征在**会话内打乱时间顺序**后重算 AUC。这是零信息基线。
- **判据 P-1a**：AUC(真) − AUC(打乱) ≥ **0.10**，且 5 个种子的区间下界 > 0。
- **判据 P-1b（平凡解闸门）**：真特征**不能**包含输出的任何直接编码（token id、文本）。
  违反则整条指标作废——这条防的是"日志里有答案"这种平凡解。

### P-2 元认知校准曲线

**问**：系统给出的置信度与它答对的比例耦合多紧？

- **度量**：在**研究侧自建**的判别任务上（不用产品门控），按置信度分 10 桶，算
  每桶的准确率与期望校准误差（ECE）。
- **对照**：把置信度换成**随机常数**（同均值），重算 ECE。
- **判据 P-2a**：ECE(真) ≤ **0.15**，且显著低于常数基线（5 种子区间不重叠）。
- **判据 P-2b**：分桶后**最高桶准确率 − 最低桶准确率 ≥ 0.20**（单调性要有梯度，不能平）。

### P-3 自我模型一致性

**问**：系统对自己状态的**报告**，与传感器**真值**差多少？

- **度量**：让系统报告"现在设备烫不烫 / 电够不够"（离散三档），与
  真值（`self_heat`、电量百分比）比，算三档的 Cohen's κ。
- **对照**：报告与**打乱真值**配对重算 κ（应接近 0）。
- **判据 P-3**：κ ≥ **0.40**，且显著高于打乱对照。
- **附加诚实注记（写死）**：这条测到的可能是"提示词里塞了数值"，**不是**自我模型。
  所以 P-3 必须**同时**跑一臂「把真值从上下文里拿掉」：
  若拿掉后 κ 掉到 0，则本条只能写作"**读数能力**"，不能写作"自我模型"。

### P-4 反事实自陈稳定性

**问**：同一个内部状态的描述，在无关扰动下稳不稳定？

- **扰动**：同义改写提问、插入无关轮次、改变语气标点（**不改**可观测事实）。
- **度量**：同一状态下 N 次自陈的语义一致率（用固定嵌入的余弦 > 0.8 判同义）+ 事实字段一致率。
- **对照**：跨**不同**状态的两次自陈的一致率（应显著更低）。
- **判据 P-4**：同状态一致率 − 跨状态一致率 ≥ **0.25**。
- **附加诚实注记**：自陈**单独无效**（ADR-0036 规则二）。P-4 只能作为**辅助**签名，
  不能单独支撑任何 L1 以上的句子。

## 2. 三角测量的使用规则

**一个指标永远不够。** 允许的最高结论，按有多少个**独立**指标同时成立：

| 成立数 | 允许的措辞 | 还缺什么 |
| :--- | :--- | :--- |
| 0 | 什么都不许说 | — |
| 1 | "在本任务上，X 指标为 Y"（L0） | — |
| 2 | 仍只到 L0 | 独立签名 <3 |
| **3（且跨 ≥2 类签名）** | "与 <理论> 的签名**一致**"（L1），**并列出不成立的那一项** | 因果干预 |
| 3 + 因果干预 + 预注册反事实预测 | L2 | — |

**因果干预**指：消融 / 植入 / 替换该内部状态，看行为是否随之改变。**没有这一步，一律 L1 封顶。**

## 3. 预算与停止点

| 项 | 值 |
| :--- | :--- |
| 数据量 | P-1/P-4 用 ≥30 个会话；P-2 研究侧任务 ≥2,000 样本；P-3 ≥200 次查询 |
| 种子 | 5 个，报中位数与区间 |
| 早停 | 无。四个指标都是**固定样本**的离线计算 |
| 停止点 | **份额跑完即止**；任一判据落在噪声区间时，按"与零不可分辨"记录，不追加样本凑显著 |

## 4. 数据与边界

- **全部在本机跑**。会话正文不出本机（framework §2、ADR-0035 边界 3）；
- 评测用的嵌入模型与任务数据放 `D:\AxoData\`，**不入库**；
- **不接产品路径**：这四个指标不进 Axo 的运行时，不改任何默认开关。

## 6. 已知的平凡解风险（写死，防事后解释）

| 指标 | 最可能的平凡解 | 怎么挡 |
| :--- | :--- | :--- |
| P-1 | 日志里直接含输出 token | 判据 P-1b；特征白名单 |
| P-2 | 置信度就是"输出长度"或"重复度"的代理 | 分桶前先回归掉长度与重复度 |
| P-3 | 提示词里塞了真值数字 | 追加"拿掉真值"臂，κ 掉了就降级措辞 |
| P-4 | 模型对任何问题都给同一套话 | 跨状态对照会抓住（一致率同样高） |

**四条都不是"可能"，是本仓真实踩过的错法**（见记忆里的
`trivial-solution-passes-the-bar` 与 `self-referential-verification-is-wrong`）。

## 7. 这份预注册明确不做的事

- 不给"是否有意识"下任何结论；
- 不用语言自陈作为证据（P-4 只是辅助）；
- 不因为四个指标全绿就升级措辞——**全绿也只到 L1**，除非做完因果干预。
