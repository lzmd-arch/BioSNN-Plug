## 迭代顺序与判据草案

排序依据：**先做"判据缺失"再做"形态不对"**，因为前者连方向都不知道对不对。

### 迭代 1：唤醒通道拿到下游任务（最高优先）

**为什么**：它是唯一没有判据的组件。没有判据的组件不可能"实现得更好"，只能靠猜。

**设计**：arousal 只在**非平稳**任务里有意义——增益该变的时候它才该变。

| 项 | 内容 |
| :--- | :--- |
| 任务 | 任务分布会在**未知时刻**切换（maze 的规则切换，或 CIFAR 的任务顺序随机化） |
| 臂 A | 固定增益（现网做法） |
| 臂 B | `arousal` 调制增益（巩固频率 / 探索温度 / 阈值），arousal 由输入强度与近期发放统计给出 |
| 主判据 | **切换后的恢复轮数**：B 的中位数 ≤ A 的 0.8 倍（5 种子，配对） |
| 次判据 | 平稳段的性能不得下降 >1pp——**否则就是"靠抖动换适应"** |
| kill | B 在切换后恢复更慢，或平稳段掉 >2pp ⇒ 判"这条调制方向是错的"，换调制对象再试一次 |

**为什么这个判据是对的**：固定增益在非平稳任务上必然有"要么太迟钝、要么太抖"的取舍；
arousal 若真有用，它买到的是**不必手工选那个取舍点**。

### 迭代 2：巩固换成复演（rehearsal）

**为什么**：现有形态（向全体均值收缩）测出来是主动遗忘——它把类中心拉到一起，
而 AF 的分母正是"旧任务还认不认得出"。这不是巩固，是平滑。

| 项 | 内容 |
| :--- | :--- |
| 臂 C3 | **定预算复演**：每个旧任务保留 k 个样本，与当前任务混合；算力与 C1 对齐 |
| 臂 C4 | 原型重定心（把旧类中心推开，而不是拉近） |
| 对照 C2 | 打乱复演顺序——沿用现有的"多跑一遍"排除法 |
| 主判据 | **AF 降 ≥0.02 且 ACC 不降 >0.01**（沿用原预注册，不放松） |
| 前置修正 | **必须引入真随机**：随机任务顺序 + 随机采样；现有"5 种子"是同一个确定性运行，不能用来算方差 |

**kill**：C3/C4 都不过 ⇒ 巩固这一族在这个前端上不成立，写进负结果并说明"测过两种形态"。

### 迭代 3：仲裁器——先承认它的"惰性"已经被解释掉了

**已做的（R1 静态 α 搜索，5 种子/点，预注册后执行）**：

| α | Fisher 中位数 |
| ---: | ---: |
| 0.3 | 0.3640 |
| 0.4 | 0.5767 |
| **0.5** | **0.6506** |
| 0.6 | 0.6430 |
| 0.7 | 0.6211 |

**最优是内点、且正好落在基准的默认值（等权）上**；α=0.6 在噪声内（中位 −0.008），
α=0.4 明显更差（−0.073）。所以：

- **景观不是平的**——它有结构，只是**峰正好盖在默认值上**；
- 于是"任何自适应都打不过固定 50/50"这句话的真实含义是：**这条基准上没有可超越的空间**，
  而不是"自适应不行"。

**⇒ 迭代 3 的真问题不是调 ES，是换任务**：需要一个**最优 α 会变**的基准
（不同 regime 的最优混合比不同），按 regime 学一组权重才有意义。

| 步 | 内容 | 成本 |
| :--- | :--- | :--- |
| 3a | ~~先验景观~~ **已完成**（R1） | 0 |
| 3b | 造一个**最优 α 随 regime 变化**的基准；按 regime 学权重 | 1 天 |
| 判据 | 按 regime 的自适应在**留出的切换**上 ≥ 最优固定值 +3pp；否则判"没有可学的仲裁结构" |

### 迭代 4：世界模型从"预测得准"走到"用得上"

**为什么**：四条验收项测的全是**预测精度**（NMSE、AUROC、发散步数）。没有一条问
"用它选动作会不会更好"。这就是 [AGENTS.md](../../AGENTS.md) 里那句
"AUROC 1.0 是 one-step 预测，不是策略形成"的准确含义。

| 项 | 内容 |
| :--- | :--- |
| 任务 | CartPole（已有 rollout 与闭环数据，模型精度 ~115 步） |
| 臂 | ① 随机策略；② 无模型基线；③ **1 步前瞻**：用世界模型逐步评估候选动作，贪心选 |
| 主判据 | ③ 的回合长度中位数 ≥ ② 的 1.2 倍 |
| 次判据 | 前瞻深度 1 → 3 时回合长度不降（否则说明模型误差压过了规划收益） |
| 已知风险 | 闭环在 ~115 步后发散 ⇒ **多步 rollout 规划大概率被误差吃掉**，先做 1 步 |

## 一个关键合并：两条迭代缺的是**同一件东西**

迭代 1（唤醒）要"增益该变"的任务，迭代 3b（仲裁）要"最优 α 会变"的任务——
**这两件是同一个资产：一个非平稳基准**（分布/规则在未知时刻切换）。

造一次，两条都能跑。而且它还能顺带服务迭代 2 的"真随机"要求（随机任务顺序）。

**所以建议的下一步不是先跑某一条实验，而是先把这个基准做出来。**
它也是动力学轴其余几件（世界模型的决策回路除外）共同缺的基础设施。

## 纪律（沿用本仓的硬规矩）

1. 每条判据开跑前落盘，跑完不改；要改就写 `*_amend*.md`；
2. 负结果照登——**"测过两种形态都不行"比"没测"值钱得多**；
3. 种子的含义要真：确定性管线不许报"5 个种子"；
4. 达标数字先查平凡解：AUROC 1.000 / NMSE 3×10⁻⁶ 这类数，要先问"任务是不是太容易"。
