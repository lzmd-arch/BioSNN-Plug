# 预注册：世界模型的"用得上"判据——1 步前瞻控制（2026-11-12）

**状态：判据先落盘。**

**上游**：[ADR-0015](../../docs/adr/ADR-0015-world-model-as-phase-four-component.md) 的四条验收项
**全部已过**（动作敏感度 0.102、自由 rollout NMSE 3×10⁻⁶、闭环 H=10 比 `copy_last` 低十个数量级、
终止 AUROC 1.000）。

**但四条量的全是**预测精度**。没有一条问："拿它去选动作，会不会更好？"
[AGENTS.md](../../AGENTS.md) 那句"AUROC 1.0 是 one-step 预测，不是策略形成"说的就是这个缺口
（缺陷类型 D7，见 [`../audit-axis-defects-2026-11-12.md`](../audit-axis-defects-2026-11-12.md)）。

---

## 1. 问题

**一个预测得准的世界模型，能不能改善决策？** 如果不能，那它就是一个昂贵的拟合器。

## 2. 前提

| 前提 | 在哪 |
| :--- | :--- |
| `ridge_quadratic` 模型与其训练协议 | `sweep_results/world_model_rollout/`、`world_model_acrobot/` |
| 闭环在约 115 步后发散 | `world_model_closed_loop_h500`（首发散步 115.5） |
| CartPole 的终止判据已知 | 同上 |

**第三条决定了前瞻深度必须从 1 开始**：模型误差在 ~115 步累积到不可用，而多步 rollout
规划会把这份误差当成真实收益。**先做 1 步，再谈 3 步。**

## 3. 三臂（**关键是控制臂**）

| 臂 | 搜索 | 预测器 |
| :--- | :--- | :--- |
| **R 随机** | 无 | 无（下限 sanity） |
| **C 控制** | **与 W 完全相同的搜索、相同的评估次数** | `copy_last`（平凡预测器） |
| **W 实验** | 同上 | 学出来的 `ridge_quadratic` 世界模型 |

**为什么控制臂必须是"同样的搜索 + 平凡预测器"**：如果只跟随机策略比，赢了也只能说明
"搜索有用"，不能说明"模型有用"。加上 C 臂之后，W − C 才是**世界模型的净贡献**。

## 4. 判据

### 4.1 前置（`WM-0`）

- [ ] C 臂不显著优于 R（否则说明搜索本身在 CartPole 上就能赢，W 的增益要重新归因）；
- [ ] W 与 C 的**单回合模型评估次数完全相同**（同算力，可数）；
- [ ] 模型在测试回合上的 1 步 NMSE ≤ 1e-3（复现既有结果）。

### 4.2 主判据（`WM-1`）

| # | 判据 | 阈值 |
| :--- | :--- | :--- |
| **WM-1a** | **世界模型有净贡献** | W 的回合长度中位数 **≥ 1.2 × C**（100 测试回合，5 采集种子） |
| WM-1b | 前瞻更深不更差 | W 在 horizon 3 上的中位回合长度**不低于** horizon 1 |

**WM-1a 是唯一的主判据**；WM-1b 是稳健性检查。

### 4.3 kill（`WM-2`）

- W 与 C 统计上不可分（区间重叠）⇒ **判"世界模型在本任务上对决策无净贡献"**，
  写进负结果，并且**不再加深前瞻**（误差会吃掉收益，加深度不改变结论）；
- W 显著劣于 C ⇒ 同上，并额外记录"预测越准、决策越差"这个反直觉现象的具体形状。

## 5. 预算与停止点

| 项 | 值 |
| :--- | :--- |
| 测试回合 | 100 / 臂 / 采集种子 |
| 采集种子 | 5 |
| 前瞻深度 | 1（主）→ 3（仅当 WM-1a 过） |
| 早停 | 无 |

## 6. 数据与边界

- 全部合成（CartPole），数据不入库；
- 不接产品路径；
- **不声称世界模型"理解了物理"**——这里只测它对下一步选择的贡献。

## 8. 四问

1. 预算截断？—— 固定回合数，不看曲线是否还在涨；
2. 跨语料？—— 不涉及；
3. 单边指标？—— 只有回合长度一个主指标，**属单边**；因此必须同时报 WM-1b 与 C/R 两臂的
   绝对值，不能只报比值；
4. 先验未兑换？—— 不涉及（这是直接测量）。

## 9. 为什么这条值得单独做

ADR-0015 的四条验收让"世界模型"在**预测层**成立了，但产品的价值在决策层。
这条实验是**唯一**能把"预测得准"翻译成"用得上"的桥——过了就补上动力学轴的最后一块，
不过就是一条比"预测很好"更有信息量的负结果。
