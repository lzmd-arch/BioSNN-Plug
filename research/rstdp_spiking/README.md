# 脉冲执行层：CartPole 上的脉冲 R-STDP

[English](README.en.md) · [日本語](README.ja.md)
**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

## 在验证什么命题

计划书 §七 第三阶段的**执行层脉冲化**：把 `research/rstdp/` 的速率型 actor-critic 换成脉冲
实现（LIF + **带真实 Δt 窗口的 STDP 资格痕迹** + 奖励预测 Critic），使 §3.2 的 `STDP(Δt_ij)`
公式与「仅计 pre-before-post」那处结构差别**第一次可验**。

速率版保留为**对照基线**（同任务、同规则、脉冲 vs 速率），它回答的是「脉冲化之后性能掉多少」。

## 当前结论（2026-10-17，5 个种子，各 1200 回合）

**能学，但不稳定：5 个种子里只有 1 个越过 200 步的验收线。**

| 种子 | 最好评测（步） |
| :--- | ---: |
| 0 | 102.8 |
| 1 | 39.0 |
| 2 | 19.6 |
| 3 | 138.5 |
| 4 | **249.0** |
| **均值** | **109.8** |

对照：

| 实现 | 结果 |
| :--- | :--- |
| 速率版（`research/rstdp/`） | 中位数 **237.8 步**，验收通过 |
| 脉冲版 + EMA 基线（无 Critic） | 65.3 步（1 种子，300 回合） |
| 脉冲版 + 线性 TD Critic | **109.8 步均值**，1/5 过线 |

两条能说得住的结论：

1. **Critic 是结构性的，不是调参问题。** 去掉奖励预测、改用回报的指数滑动平均当基线，
   同一套 Actor 停在 65 步；接上线性 TD Critic 后均值到 109.8——与 §3.2 引 Frémaux et al.
   的说法一致（R-STDP 需要刺激特异性的奖励预测）。
2. **脉冲化付出了稳定性代价。** 速率版中位数 237.8 且验收通过；脉冲版最好种子 249 但最差 19.6，
   方差大得多。这是"同一份权重跑两次给不同动作"的直接后果（见下面的评测协议）。

## 怎么跑出来

```bash
uv run pytest research/rstdp_spiking -q
uv run python -m research.rstdp_spiking.cartpole --smoke
uv run python -m research.rstdp_spiking.cartpole
uv run python -m research.rstdp_spiking.cartpole --seeds 0,1,2,3,4 --episodes 1200 --learning-rate 1e-4
```

**评测协议：冻结随机流。** 脉冲网络的输出本身是随机的（输入是伯努利脉冲编码），同一份权重
跑两次会给出不同动作。所以每个评测回合按固定种子重置环境、并按固定种子重采输入脉冲——同一份
权重 + 同一个种子 → 同一串动作。不这么做，量到的是一个随机策略（速率版在 `boltzmann`
分支上踩过同类坑）。

## TD-LTP 群体 Critic：已实现，但没有学起来（同日追加）

按计划书 §3.2 的结构把 Critic 换成**群体 + 固定读出**（`pop_critic.py`）：单元活动
`y_j = σ(g(w_j·x − b))`、值 `V = Σ u_j y_j + out_bias`、痕迹 `e_ji ← λ e_ji + x_i y_j`、
更新 `w_j ← w_j + η δ e_j` 后行归一化。**输出偏置可学**——速率版的 README 记过这个病：
临死那步真值≈0 而群体读出到不了那么低，终止步会稳定拿到一个大负 δ。

**结果是否定的。** 同一套 Actor，换 Critic：

| 配置 | 最好评测（步） |
| :--- | ---: |
| 线性 TD（5 种子 × 1200） | **109.8 均值，1/5 过线** |
| 群体，actor lr 1e-4、critic 1e-2 | 9.2 |
| 群体，actor 1e-3、critic 1e-2（无输出偏置） | 28.9 |
| 群体，actor 1e-3、critic 1e-2（有输出偏置） | 20.8 |
| 群体，actor 1e-3、critic **1e-1**、800 回合 | 78.4 |
| 群体，**同上、1200 回合** | **9.3** |
| 群体，critic 5e-2 / 2e-1 / 3e-1 / 1.0 | 27.2 / 18.0 / 9.2 / 9.2 |
| **群体，5 种子 @ critic 1e-1、800 回合** | **36.2 / 12.9 / 9.4 / 40.8 / 15.7 —— 均值 23.0，0/5** |

三条读法：

1. **它是脆的，不是"还没调好"。** 同一配置 800 回合到 78.4、1200 回合塌到 9.3；
   相邻步长（0.05 / 0.2 / 0.3 / 1.0）全部塌掉。这种"参数动了就碎"的形态更像
   **训练动力学不稳**，不是欠调。
2. **输出偏置不是这里的病根。** 加上它从 28.9 变 20.8——方向都不对，
   说明速率版记的那个终止步问题在本线没有复现成主要矛盾。
3. **最可能的解释：速率版里被我省略的机制是承重的。** 那份实现还有有符号读出 + `gradient`
   后因子的组合约束、以及偏置用独立步长学习；本移植是**精简版**，模块文档里写明了省略。
   负结果因此指向"这些机制不能省"，而不是"群体 Critic 不行"。

⚠️ **不要把这个负结果读成"TD-LTP 群体 Critic 不可行"**：它只说明**这份精简移植**在
**这个 harness** 上没学起来。要把问题定位到结构本身，下一步是把速率版剩下的机制逐条移植
并单独消融。

## 已知边界

1. **默认 Critic 是线性 TD(0)。** TD-LTP 群体 Critic 已实现（`pop_critic.py`，`--critic pop`），
   但当前学不起来（见上一节），所以它是**实验入口，不是可用默认**。
2. **只有单层 LIF。** 没有多层堆叠，也没有把编码层（群体编码 + 伯努利采样）纳入学习。
3. **超参没有系统扫描。** 试过的四个变体都更差：窗口 10 步 → 9.2、特征 128 → 10.3、
   Critic 步长 1e-1 → 66.9、γ=0.95 → 60.2（各 1 种子、800 回合）。当前配置是局部最优，
   **不是**证明过的最优。
4. **训练回合数影响很大**：同一配置 400 回合 83.9、1200 回合 102.8（种子 0）。
5. **与速率版不是同一个评测口径的严格对照**：速率版的评测是确定性的，脉冲版要冻结随机流并
   多回合平均；报告里的差距同时包含"脉冲化代价"与"评测协议差异"。
