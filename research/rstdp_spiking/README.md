[English](README.en.md) · [日本語](README.ja.md)

## 在验证什么命题

计划书 §七 第三阶段的**执行层脉冲化**：把 `research/rstdp/` 的速率型 actor-critic 换成脉冲
实现（LIF + **带真实 Δt 窗口的 STDP 资格痕迹** + 奖励预测 Critic），使 §3.2 的 `STDP(Δt_ij)`
公式与「仅计 pre-before-post」那处结构差别**第一次可验**。

速率版保留为**对照基线**（同任务、同规则、脉冲 vs 速率），它回答的是「脉冲化之后性能掉多少」。

## 历史结论（2026-10-17，5 个种子，各 1200 回合，**未播种，已作废**）

**能学，但不稳定：5 个种子里只有 1 个越过 200 步的验收线。**

| 种子 | 最好评测（步） |
| :--- | ---: |
| 0 | 102.8 |
| 1 | 39.0 |
| 2 | 19.6 |
| 3 | 138.5 |
| 4 | **249.0** |
| **均值** | **109.8** |

对照：

| 实现 | 结果 |
| :--- | :--- |
| 速率版（`research/rstdp/`） | 中位数 **237.8 步**，验收通过 |
| 脉冲版 + EMA 基线（无 Critic） | 65.3 步（1 种子，300 回合） |
| 脉冲版 + 线性 TD Critic | **109.8 步均值**，1/5 过线 |

两条能说得住的结论：

1. **Critic 是结构性的，不是调参问题。** 去掉奖励预测、改用回报的指数滑动平均当基线，
   同一套 Actor 停在 65 步；接上线性 TD Critic 后均值到 109.8——与 §3.2 引 Frémaux et al.
   的说法一致（R-STDP 需要刺激特异性的奖励预测）。
2. **脉冲化付出了稳定性代价。** 速率版中位数 237.8 且验收通过；脉冲版最好种子 249 但最差 19.6，
   方差大得多。这是"同一份权重跑两次给不同动作"的直接后果（见下面的评测协议）。

## 怎么跑出来

```bash
uv run pytest research/rstdp_spiking -q
uv run python -m research.rstdp_spiking.cartpole --smoke
uv run python -m research.rstdp_spiking.cartpole
uv run python -m research.rstdp_spiking.cartpole --seeds 0,1,2,3,4 --episodes 1200 --learning-rate 1e-4
uv run python -m research.rstdp_spiking.diagnose_critic
```

**评测协议：冻结随机流。** 脉冲网络的输出本身是随机的（输入是伯努利脉冲编码），同一份权重
跑两次会给出不同动作。所以每个评测回合按固定种子重置环境、并按固定种子重采输入脉冲——同一份
权重 + 同一个种子 → 同一串动作。不这么做，量到的是一个随机策略（速率版在 `boltzmann`
分支上踩过同类坑）。

## TD-LTP 群体 Critic：已实现，但没有学起来（同日追加）

按计划书 §3.2 的结构把 Critic 换成**群体 + 固定读出**（`pop_critic.py`）：单元活动
`y_j = σ(g(w_j·x − b))`、值 `V = Σ u_j y_j + out_bias`、痕迹 `e_ji ← λ e_ji + x_i y_j`、
更新 `w_j ← w_j + η δ e_j` 后行归一化。**输出偏置可学**——速率版的 README 记过这个病：
临死那步真值≈0 而群体读出到不了那么低，终止步会稳定拿到一个大负 δ。

**结果是否定的。** 同一套 Actor，换 Critic：

| 配置 | 最好评测（步） |
| :--- | ---: |
| 线性 TD（5 种子 × 1200） | **109.8 均值，1/5 过线** |
| 群体，actor lr 1e-4、critic 1e-2 | 9.2 |
| 群体，actor 1e-3、critic 1e-2（无输出偏置） | 28.9 |
| 群体，actor 1e-3、critic 1e-2（有输出偏置） | 20.8 |
| 群体，actor 1e-3、critic **1e-1**、800 回合 | 78.4 |
| 群体，**同上、1200 回合** | **9.3** |
| 群体，critic 5e-2 / 2e-1 / 3e-1 / 1.0 | 27.2 / 18.0 / 9.2 / 9.2 |
| **群体，5 种子 @ critic 1e-1、800 回合** | **36.2 / 12.9 / 9.4 / 40.8 / 15.7 —— 均值 23.0，0/5** |

### 消融：把省略的机制补回来，问题不在这里（同日）

上一版留下的假设是「速率版里被我省略的机制是承重的」。补上那些机制后，**这个假设被
自己推翻了**——每项都单独开关，5 种子 × 800 回合，其余配置不变：

| 变体 | 最好评测均值 | 逐种子 |
| :--- | ---: | :--- |
| rate 后因子 + 均匀读出 + 行归一化（原基线） | 23.0 | 36.2 / 12.9 / 9.4 / 40.8 / 15.7 |
| `gradient` 后因子 + 均匀 + 归一化 | 32.9 | 61.7 / 14.3 / 9.2 / 69.8 / 9.7 |
| `gradient` + **有符号读出** + 归一化 | 14.3 | 9.2 / 9.2 / 34.4 / 9.2 / 9.7 |
| `gradient` + 均匀 + **去掉行归一化** | **56.8** | 69.2 / 37.3 / 104.9 / 63.1 / 9.3 |
| `gradient` + 有符号 + 去掉归一化 | 41.3 | 49.2 / 9.2 / 105.1 / 33.9 / 9.3 |
| 参照：线性 TD（不是群体） | 109.8 | 102.8 / 39.0 / 19.6 / 138.5 / 249.0 |

读法：

1. **`gradient` 后因子有一点点用**（23.0 → 32.9），**有符号读出有害**（32.9 → 14.3，
   不归一化时 56.8 → 41.3）。
2. **最大的单项是行归一化**：去掉它 32.9 → **56.8**。这条归一化是从速率版抄来的，
   那里的作用是防发散；在这条线上它压扁了值的动态范围。
3. **全都补上也没到 200，连线性 TD 的 109.8 也没追上**（0/5 对 1/5）。

### 工作点：从「几乎全死」到「能跟踪回报」（同日）

上一节量到 76% 的单元活动 < 0.05——偏置 `b=0.4` 比它收到的前激活尺度（0.16）大一个数量级。
预注册：[`rstdp_spiking_operating_point_prereg.md`](../../sweep_results/rstdp_spiking_operating_point_prereg.md)。

筛选（单种子 300 回合，固定 `gradient` + 不归一化）：

| bias | gain | 单元 | 最好评测 |
| ---: | ---: | ---: | ---: |
| 0.4（现状） | 8 | 64 | 73.5 |
| 0.0 | 8 | 64 | 42.2 |
| −0.2 | 8 | 64 | 33.0 |
| **0.0** | **16** | **64** | **123.4** |
| 0.0 | 8 | **256** | 9.2 |

**起作用的是 gain（把 `z` 的跨度拉到 ±2），不是单元数**——H1（工作点）成立、H2（容量）不成立。

确认（5 种子 × 800 回合，`b=0, g=16`）：**均值 64.8**（原最好 56.8），逐种子
44.4 / 89.4 / 33.2 / 72.4 / 84.6。⚠️ **仍 0/5**，但**最差种子从 9.3 升到 33.2**——
稳定性明显改善。

直接判据 `corr(V,G)`：**−0.496 → +0.697**（线性 TD 是 +0.965）。Critic 现在**跟踪得上回报**了。

### 同质化：假设被证实，而且比预期严重（同日）

预注册：[`rstdp_spiking_homogenisation_prereg.md`](../../sweep_results/rstdp_spiking_homogenisation_prereg.md)。
度量脚本：`diagnose_homogenisation.py`（800 回合，`b=0, g=16`，`gradient`，不归一化）。

| 量 | 训练前 | 训练后 | 判据 |
| :--- | ---: | ---: | :--- |
| 单元间余弦均值 | −0.002 | **+0.823** | 随机基线标准差 0.125 ⇒ 约 6.6σ，超过预注册的 5σ 阈值 |
| 有效秩 `exp(H)/n` | 0.613 | **0.025** | 同质化 ⇒ 下降 |
| 单元活动两两相关 | — | **+0.928** | 同质化 ⇒ 升高 |
| 平均活动 | — | **0.003** | 单元几乎全静默 |

**64 个单元的权重向量训练后几乎指向同一方向**，活动一起归零。于是
`V = Σ u_j y_j + out_bias ≈ 200 × 0.003 + out_bias`——**值几乎完全由一个标量偏置承担**
（反推约 15–16，与实测 `V ∈ [14.4, 17.6]` 吻合）。这就是"`V` 只有 3.2 宽、自举失效"的机制。

这与推断一致：`gradient` 后因子下痕迹恒非负（`x ≥ 0`、`σ' > 0`），读出一律为正，
两者的乘积把每个单元的权重推向**同一个非负方向的叠加**，单元之间因此趋同。

### 单元级稳态：让单元活了，但没打破同质化（同日）

预注册：[`rstdp_spiking_homeostasis_prereg.md`](../../sweep_results/rstdp_spiking_homeostasis_prereg.md)。

规则：`b_j ← b_j + β(y_j − y*)`，**只用该单元自己的活动与一个常数目标**，不读别单元、
也不经过 `δ`（稳态是与 TD-LTP 并行的另一条局部规则）。

筛选（单种子 300 回合）：`y*=0.05, β=0.01` 最好（69.0），其余三组 30.6 / 26.9 / 25.7。
⚠️ **筛选取错了方向**：同一 300 回合下无稳态的配置是 **123.4**，看起来稳态更差；但到 800 回合，
无稳态掉到 64.8，而稳态保持 69.4——**无稳态的组会随时间退化，稳态的那组不会**。

确认（5 种子 × 800，`y*=0.05, β=0.01`）：**均值 69.4**，逐种子 72.9 / 87.1 / 57.8 / 52.4 / 76.6。
对照无稳态 64.8（33.2–89.4）。**最差种子 33.2 → 52.4，五个种子全部 ≥ 52**——稳定性显著改善。
**仍 0/5。**

### 机制没被打破：活动水平不是同质化的原因

同样的度量（800 回合）：

| 量 | 无稳态 | 有稳态 |
| :--- | ---: | ---: |
| 单元间余弦 | +0.823 | **+0.778** |
| 有效秩 | 0.025 | **0.024** |
| 平均活动 | 0.003 | **0.089** |
| `V` 范围 | 14.4 – 17.6 | **11.7 – 202.4** |
| 单元阈值均值 | 0 | −5.15 |

**单元被拉回活动区间（0.003 → 0.089），权重却照样趋同（余弦 +0.78、有效秩 0.024）。**
所以"单元静默"不是同质化的原因——共模推力来自痕迹的符号结构，与活动水平无关。

⚠️ **`V` 撞上了 `value_scale=200` 的天花板**（实测 202.4）。预注册写明：撞上界就记为
该配置失败、**不偷偷改尺度**。这一条也解释了为什么分数没有跟着涨：δ 被截断的信号污染了。

### 有符号读出：在工作点修好后重测，仍然有害

上一轮的 14.3 是在**饱和工作点**上得到的，那时单元几乎不动，符号可能没有发挥作用的空间。
预注册要求重测。结果：

| 读出 | 均值 | 逐种子 |
| :--- | ---: | :--- |
| 均匀（`b=0, g=16`） | **64.8** | 44.4 / 89.4 / 33.2 / 72.4 / 84.6 |
| 有符号（同工作点） | **29.2** | 43.9 / 9.2 / 74.2 / 9.3 / 9.3 |

**仍然更差，且更不稳**（三个种子跌回随机水平）。所以"换个读出符号就能修同质化"这条被否掉——
一致的解释是：符号只改变读出如何组合，改变不了**权重本身在趋同**这件事。

### 仍未解决：训练把值的动态范围压塌

同一个诊断还给出：`V ∈ [14.4, 17.6]`，**只有 3.2 宽**，而回报是 1–10.5。
短跑（2 回合）时 `V` 还有 3.9–36.8 的跨度，训练 800 回合后塌成一条窄带。

含义：`δ = r + γV(s′) − V(s)` 里 `V` 的差只有回报的约三分之一，`δ` 被奖励项主导，
自举（bootstrap）几乎没起作用。这与「`gradient` 后因子下痕迹恒非负、读出一律为正 →
权重被同向推、单元趋同」的机制一致——**这是目前最有解释力的下一个假设**，但它需要
另一次预注册单独验证，不在本轮结论里。

### 诊断：群体 Critic 根本没学会值函数

`diagnose_critic.py` 在训练后冻结策略，比较 `V(s_t)` 与蒙特卡洛回报 `G_t`：

| Critic | corr(V, G) | V 的范围 | G 的范围 |
| :--- | ---: | :--- | :--- |
| 线性 TD(0) | **+0.965** | 0.8 – 17.2 | 1.0 – 10.5 |
| 群体（gradient，行归一化） | **−0.496** | **18.3 – 19.9** | 1.0 – 10.5 |
| 群体（gradient，去掉归一化） | +0.217 | 12.0 – 18.2 | 1.0 – 27.5 |

群体 Critic 的 `V` 在一个 1.6 宽的区间里打转、与回报还反相关——**Actor 收到的是噪声**，
所以换读出方式、换学习率都救不回来。去掉归一化把它从"反相关"拉到"弱相关"，方向对了，
但离 +0.965 还远。

⚠️ **不要把这个负结果读成"TD-LTP 群体 Critic 不可行"**：它只说明**这份实现**在
**这个 harness** 上没学起来。已知的三条线索（归一化、梯度的尺度、读出符号）都排除之后，
剩下的嫌疑是「群体的容量/初始化与这套 64 维群体编码不匹配」——那需要另一轮预注册来查。

## Actor 痕迹规则：新增 `sign-consistent`（2026-10-26）

默认规则**没有变**（`pair-stdp`，与所有记录在案的数字逐位一致）。新增一个显式开关
`--trace-rule sign-consistent`：保留真实 Δt 的 LTP/LTD，但只给被选动作列累计两条非负
痕迹，回合末按成功信号的符号选相位（预注册见
[`sweep_results/rstdp_spiking_actor_fix_prereg.md`](../../sweep_results/rstdp_spiking_actor_fix_prereg.md)，
修订见 [`..._amend1.md`](../../sweep_results/rstdp_spiking_actor_fix_prereg_amend1.md)）。

A1 量到的问题（被选动作的资格列和在 20 个窗口里只有 7 个更大、3 个为负）在 A1′ 里
变成 **18/18**（两个空窗口剔除）、负 20/20、门控 20/20。但阶段 2 的 10 种子配对：

## 已知边界

1. **默认 Critic 是线性 TD(0)。** TD-LTP 群体 Critic 已实现（`pop_critic.py`，`--critic pop`），
   但当前学不起来（见上一节），所以它是**实验入口，不是可用默认**。
2. **只有单层 LIF。** 没有多层堆叠，也没有把编码层（群体编码 + 伯努利采样）纳入学习。
3. **超参没有系统扫描。** 试过的四个变体都更差：窗口 10 步 → 9.2、特征 128 → 10.3、
   Critic 步长 1e-1 → 66.9、γ=0.95 → 60.2（各 1 种子、800 回合）。当前配置是局部最优，
   **不是**证明过的最优。
4. **训练回合数影响很大**：同一配置 400 回合 83.9、1200 回合 102.8（种子 0）。
5. **与速率版不是受控对照，两处口径都不同。** ①**评测**：速率版是确定性的，脉冲版要冻结
   随机流并多回合平均；②**编码参数**：速率版的群体中心四轴统一取 `[-1.5, 1.5]`、
   `--encoding-sigma` 默认 0.5，本目录按 `CARTPOLE_HALF_WIDTHS` 分轴取（±2.4 / ±3.0 /
   ±0.21 / ±3.0）、`--sigma` 默认 1.0。**实现是同一份**
   （`research/components/cartpole_encoding.py`），差异只是参数——所以报告里的差距同时
   包含"脉冲化代价"、"评测协议差异"与"编码参数差异"，**不是一个能归因到单一变量的结论**。
