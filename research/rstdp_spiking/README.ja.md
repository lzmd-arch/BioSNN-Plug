# スパイク実行層：CartPole 上のスパイク R-STDP

[中文](README.md) · [English](README.en.md)
**⚠️ 破壊的変更の免責期間：2027-09 まで**（計画書 §12.5、ADR-0005）。

## 何を検証するか

計画書 §七 第三段階の**実行層のスパイク化**：`research/rstdp/` のレート型 actor-critic を
スパイク実装（LIF + **実 Δt 窓を持つ STDP 資格痕跡** + 報酬予測 Critic）に置き換え、§3.2 の
`STDP(Δt_ij)` 式と「pre-before-post のみ」という構造差を**初めて検証可能にする**。

レート版は**対照ベースライン**として残す（同一タスク、同一規則、スパイク vs レート）。
これは「スパイク化で性能がどれだけ落ちるか」に答える。

## ⚠️ このページの 2026-10-18 より前の数値はすべて無効

訓練エピソードに環境シードを渡していなかった（`env.reset(seed=None)`、RNG はシステムの
エントロピーで初期化）。そのため**同じシードでも二回の訓練軌跡が異なる**——評価自体には
シードがあったが、評価される重みは再現不能な訓練に由来していた。発見・修正・影響一覧は
[`sweep_results/rstdp_spiking_seeding_fix.md`](../../sweep_results/rstdp_spiking_seeding_fix.md)。

修正後の 5 シード再実行では**順位が全面的に反転**した（線形 TD 109.8 → 51.0、元の既定設定が
最良に）。以下の節は履歴として残すが、その数値とそこから導いた結論は**もはや成立しない**。
新しい結論は文末の 10 シード比較に基づく。

## 履歴（2026-10-17、5 シード、各 1200 エピソード、**未シード・無効**）

**学習はするが不安定：5 シード中 200 歩の合格線を越えたのは 1 つだけ。**

| シード | 最高評価（歩） |
| :--- | ---: |
| 0 | 102.8 |
| 1 | 39.0 |
| 2 | 19.6 |
| 3 | 138.5 |
| 4 | **249.0** |
| **平均** | **109.8** |

対照：

| 実装 | 結果 |
| :--- | :--- |
| レート版（`research/rstdp/`） | 中央値 **237.8 歩**、合格 |
| スパイク版 + EMA ベースライン（Critic なし） | 65.3 歩（1 シード、300 エピソード） |
| スパイク版 + 線形 TD Critic | **平均 109.8 歩**、1/5 が合格 |

データが支える主張は二つ：

1. **Critic は構造上の要件であり、調整の細部ではない。** 報酬予測をリターンの指数移動平均に
   置き換えると、同じ Actor は 65 歩で止まる。線形 TD Critic を加えると平均 109.8 に上がる
   ——§3.2 が Frémaux et al. から引く内容（R-STDP には刺激特異的な報酬予測が必要）と一致する。
2. **スパイク化は安定性を犠牲にする。** レート版は中央値 237.8 で合格；スパイク版は最高 249
   だが最低 19.6。分散がはるかに大きい。これは「同じ重みでも二回で違う行動になる」ことの
   直接の帰結である（下の評価プロトコルを参照）。

## 再現方法

```bash
uv run pytest research/rstdp_spiking -q
uv run python -m research.rstdp_spiking.cartpole --smoke
uv run python -m research.rstdp_spiking.cartpole
uv run python -m research.rstdp_spiking.cartpole --seeds 0,1,2,3,4 --episodes 1200 --learning-rate 1e-4
uv run python -m research.rstdp_spiking.diagnose_critic
```

**評価プロトコル：乱数流を凍結する。** スパイクネットワークの出力自体が確率的（入力が
ベルヌーイ・スパイク符号）なので、同じ重みでも二回で違う行動になる。したがって各評価エピソードは
環境を固定シードでリセットし、入力スパイクも固定シードで引き直す——同じ重み + 同じシード →
同じ行動列。これをしないと「貪欲評価」は確率方策を測ってしまう（レート版は `boltzmann` 分岐で
同じ罠を踏んだ）。

## TD-LTP 集団 Critic：実装したが学習しない（同日追記）

計画書 §3.2 の構造に従い、Critic を**集団 + 固定読み出し**（`pop_critic.py`）に置き換えた：
ユニット活動 `y_j = σ(g(w_j·x − b))`、値 `V = Σ u_j y_j + out_bias`、痕跡
`e_ji ← λ e_ji + x_i y_j`、更新 `w_j ← w_j + η δ e_j` の後に各行を正規化。**出力バイアスは学習可能**
——レート版の README が記録した病（死の直前の真値は ≈0 だが集団読み出しはそこまで下がらず、
終端ステップが安定して大きな負の δ を受け取る）への対処である。

**結果は否定的。** 同じ Actor で Critic だけを替えた：

| 設定 | 最高評価（歩） |
| :--- | ---: |
| 線形 TD（5 シード × 1200） | **平均 109.8、1/5 が合格** |
| 集団、actor lr 1e-4、critic 1e-2 | 9.2 |
| 集団、actor 1e-3、critic 1e-2（出力バイアスなし） | 28.9 |
| 集団、actor 1e-3、critic 1e-2（出力バイアスあり） | 20.8 |
| 集団、actor 1e-3、critic **1e-1**、800 エピソード | 78.4 |
| 集団、**同設定、1200 エピソード** | **9.3** |
| 集団、critic 5e-2 / 2e-1 / 3e-1 / 1.0 | 27.2 / 18.0 / 9.2 / 9.2 |
| **集団、5 シード @ critic 1e-1、800 エピソード** | **36.2 / 12.9 / 9.4 / 40.8 / 15.7 —— 平均 23.0、0/5** |

### アブレーション：省いた機構を戻しても、問題はそこではない（同日）

前版の仮説は「この移植で省いた機構が効いている」だった。移植してみると、**その仮説は
自ら反証された**——各項目を個別に切り替え、5 シード × 800 エピソード、他は固定：

| 変種 | 最高評価の平均 | 各シード |
| :--- | ---: | :--- |
| `rate` 後因子 + 一様読み出し + 行正規化（元の基準） | 23.0 | 36.2 / 12.9 / 9.4 / 40.8 / 15.7 |
| `gradient` 後因子 + 一様 + 正規化 | 32.9 | 61.7 / 14.3 / 9.2 / 69.8 / 9.7 |
| `gradient` + **符号付き読み出し** + 正規化 | 14.3 | 9.2 / 9.2 / 34.4 / 9.2 / 9.7 |
| `gradient` + 一様 + **行正規化なし** | **56.8** | 69.2 / 37.3 / 104.9 / 63.1 / 9.3 |
| `gradient` + 符号付き + 正規化なし | 41.3 | 49.2 / 9.2 / 105.1 / 33.9 / 9.3 |
| 参照：線形 TD（集団ではない） | 109.8 | 102.8 / 39.0 / 19.6 / 138.5 / 249.0 |

読み方：

1. **`gradient` 後因子はわずかに効く**（23.0 → 32.9）。**符号付き読み出しは害**（32.9 → 14.3、
   正規化なしでは 56.8 → 41.3）。
2. **最大の単一要因は行正規化**：外すと 32.9 → **56.8**。この正規化はレート版から引き継いだ
   もので、あちらでは発散防止の役割があるが、この線では値の動的範囲を潰している。
3. **全部戻しても 200 に届かず、線形 TD の 109.8 にも追いつかない**（0/5 対 1/5）。

### 動作点：「ほぼ全滅」から「収益を追える」へ（同日）

前節で測ったのは、76% のユニット活動が 0.05 未満という事実——バイアス `b=0.4` は、受け取る
前活性の尺度（0.16）より一桁大きい。事前登録：
[`rstdp_spiking_operating_point_prereg.md`](../../sweep_results/rstdp_spiking_operating_point_prereg.md)。

スクリーニング（1 シード 300 エピソード、`gradient` と正規化なしを固定）：

| bias | gain | ユニット | 最高評価 |
| ---: | ---: | ---: | ---: |
| 0.4（現状） | 8 | 64 | 73.5 |
| 0.0 | 8 | 64 | 42.2 |
| −0.2 | 8 | 64 | 33.0 |
| **0.0** | **16** | **64** | **123.4** |
| 0.0 | 8 | **256** | 9.2 |

**効くのは gain（`z` の広がりを ±2 に引き伸ばす）であり、ユニット数ではない**——H1（動作点）は
成立し、H2（容量）は成立しない。

確認（5 シード × 800 エピソード、`b=0, g=16`）：**平均 64.8**（従来最良 56.8）、各シード
44.4 / 89.4 / 33.2 / 72.4 / 84.6。⚠️ **依然 0/5** だが、**最悪シードが 9.3 から 33.2 に上昇**し、
安定性は明確に改善した。

直接の判定基準 `corr(V,G)`：**−0.496 → +0.697**（線形 TD は +0.965）。Critic は今、
**収益を追えている**。

### 同質化：仮説は成立し、予想より深刻（同日）

事前登録：
[`rstdp_spiking_homogenisation_prereg.md`](../../sweep_results/rstdp_spiking_homogenisation_prereg.md)。
計測スクリプト：`diagnose_homogenisation.py`（800 エピソード、`b=0, g=16`、`gradient`、正規化なし）。

| 量 | 訓練前 | 訓練後 | 判定 |
| :--- | ---: | ---: | :--- |
| ユニット間コサインの平均 | −0.002 | **+0.823** | ランダムの標準偏差 0.125 ⇒ 約 6.6σ、事前登録の 5σ 閾値を超える |
| 有効ランク `exp(H)/n` | 0.613 | **0.025** | 同質化 ⇒ 低下 |
| ユニット活動の相互相関 | — | **+0.928** | 同質化 ⇒ 上昇 |
| 平均活動 | — | **0.003** | ユニットはほぼ全滅 |

**訓練後、64 本の重みベクトルはほぼ同じ方向を向き**、活動はそろってゼロに潰れる。したがって
`V = Σ u_j y_j + out_bias ≈ 200 × 0.003 + out_bias`——値はほぼ完全に一つのスカラー・バイアスが
担っている（逆算で約 15–16、実測 `V ∈ [14.4, 17.6]` と整合）。これが「`V` の幅が 3.2 しかなく
ブートストラップが死んでいる」の機構である。

推論と一致する：`gradient` 後因子では痕跡が常に非負（`x ≥ 0`、`σ' > 0`）で読み出しも全て正なので、
その積は各ユニットの重みを**同じ非負方向の重ね合わせ**へ押し、ユニットは収束してしまう。

### ユニット単位の恒常性：ユニットは生き返ったが、同質化は破れない（同日）

事前登録：
[`rstdp_spiking_homeostasis_prereg.md`](../../sweep_results/rstdp_spiking_homeostasis_prereg.md)。

規則：`b_j ← b_j + β(y_j − y*)`。**そのユニット自身の活動と定数目標だけ**を使い、他のユニットも
読まず `δ` も通らない（恒常性は TD-LTP と並走するもう一つの局所規則）。

スクリーニング（1 シード 300 エピソード）：`y*=0.05, β=0.01` が最良（69.0）、他は 30.6 / 26.9 / 25.7。
⚠️ **スクリーニングは逆を指した**：同じ 300 エピソードで恒常性なしは **123.4** であり、一見
恒常性が悪い。しかし 800 エピソードでは恒常性なしが 64.8 まで落ち、恒常性ありは 69.4 を保つ
——**恒常性なしの側が時間とともに劣化し、ありの側は劣化しない**。

確認（5 シード × 800、`y*=0.05, β=0.01`）：**平均 69.4**、各シード 72.9 / 87.1 / 57.8 / 52.4 / 76.6。
恒常性なしは 64.8（33.2–89.4）。**最悪シードが 33.2 → 52.4、五つすべて ≥ 52**——安定性は明確に改善。
**依然 0/5。**

### 機構は破れていない：活動水準は同質化の原因ではない

同じ計測（800 エピソード）：

| 量 | 恒常性なし | 恒常性あり |
| :--- | ---: | ---: |
| ユニット間コサイン | +0.823 | **+0.778** |
| 有効ランク | 0.025 | **0.024** |
| 平均活動 | 0.003 | **0.089** |
| `V` の範囲 | 14.4 – 17.6 | **11.7 – 202.4** |
| ユニット閾値の平均 | 0 | −5.15 |

**ユニットは活動範囲に引き戻され（0.003 → 0.089）、重みはそれでも収束する（コサイン +0.78、
有効ランク 0.024）。** したがって「ユニットの沈黙」は同質化の原因ではない——同方向への押しは
痕跡の符号構造に由来し、活動水準とは独立である。

⚠️ **`V` は `value_scale=200` の天井に達した**（実測 202.4）。事前登録のとおり、この設定は
**失敗として記録し、尺度をこっそり変えない**。これがスコアが伸びなかった理由でもある——
δ がクリップされた信号で汚染されている。

### 符号付き読み出し：動作点を直した後に再測定、依然として有害

以前の 14.3 は**飽和した**動作点での値であり、ユニットがほとんど動かず符号の出番がなかった。
事前登録は再測定を要求した。結果：

| 読み出し | 平均 | 各シード |
| :--- | ---: | :--- |
| 一様（`b=0, g=16`） | **64.8** | 44.4 / 89.4 / 33.2 / 72.4 / 84.6 |
| 符号付き（同動作点） | **29.2** | 43.9 / 9.2 / 74.2 / 9.3 / 9.3 |

**依然として悪く、さらに不安定**（三つのシードがランダム水準に落ちる）。「符号を変えれば
同質化が直る」は反証された——符号は読み出しの合成の仕方を変えるだけで、**重み自体が収束して
いる**という事実は変わらない、という読みと整合する。

### 未解決：訓練が値の動的範囲を潰す

同じ診断は `V ∈ [14.4, 17.6]`、**幅わずか 3.2** も報告する（収益は 1–10.5）。短い実行
（2 エピソード）では 3.9–36.8 の広がりがあるのに、800 エピソードで細い帯に潰れる。

意味：`δ = r + γV(s′) − V(s)` において `V` の差は報酬尺度の約三分の一しかなく、`δ` は報酬項に
支配され、ブートストラップがほとんど効いていない。これは「`gradient` 後因子では痕跡が常に
非負で、読み出しが全て正なので、重みが同方向に押されユニットが均質化する」という説明と整合する
——**最も説明力の高い次の仮説**だが、別の事前登録で検証すべきものであり、本ラウンドの結論では
ない。

### 診断：集団 Critic は値関数をまったく学習していない

`diagnose_critic.py` は訓練後に方策を凍結し、`V(s_t)` とモンテカルロ収益 `G_t` を比較する：

| Critic | corr(V, G) | V の範囲 | G の範囲 |
| :--- | ---: | :--- | :--- |
| 線形 TD(0) | **+0.965** | 0.8 – 17.2 | 1.0 – 10.5 |
| 集団（gradient、行正規化） | **−0.496** | **18.3 – 19.9** | 1.0 – 10.5 |
| 集団（gradient、正規化なし） | +0.217 | 12.0 – 18.2 | 1.0 – 27.5 |

集団 Critic の `V` は幅 1.6 の範囲をさまよい、収益とは逆相関している——**Actor には雑音が
届いている**ので、読み出しや歩長を変えても救えない。正規化を外すと「逆相関」から「弱い相関」へ
移る。方向は正しいが +0.965 には遠い。

⚠️ **これを「TD-LTP 集団 Critic は実現不可能」と読んではならない**：言えるのは「この実装が
このハーネスで学習しない」ことだけである。既知の三つの容疑（正規化、勾配のスケール、読み出しの
符号）を除外した結果、残るのは「集団の容量と初期化がこの 64 次元の集団符号化に合っていない」で
あり、それには別の事前登録が要る。

## Actor 痕跡規則：`sign-consistent` を追加（2026-10-26）

既定の規則は**変えていません**（`pair-stdp`、記録済みのすべての数値とビット単位で同一）。
新しい明示スイッチ `--trace-rule sign-consistent` は、実 Δt の LTP/LTD を保ちながら、
**選択された行動の列だけ**に 2 本の非負の痕跡を積み、エピソード終了時に成功信号の符号で
位相を選びます（事前登録：
[`sweep_results/rstdp_spiking_actor_fix_prereg.md`](../../sweep_results/rstdp_spiking_actor_fix_prereg.md)、
修正：
[`..._amend1.md`](../../sweep_results/rstdp_spiking_actor_fix_prereg_amend1.md)）。

A1 が測った問題（選択行動の資格列和が 20 窗口中 7 窓でしか大きくなく、3 窓では負）は、
A1′ では **18/18**（無発火の 2 窓を除外）、負 20/20、ゲーティング 20/20 になります。
しかし 10 シードのペア比較（段階 2）は：

- ペア差の中央値 **+17.95 歩**（基準 +20、未達；bootstrap 95% CI −0.30 … +29.20）；
- **8/10** シードで改善（この条件は通過）；
- 中央値 **75.65** 歩、200 歩到達は 0/10（受け入れ基準は未達）。

結論：**符号の一致性は痕跡を直したが、（唯一の）ボトルネックではない**。次の疑いは
Critic／信用の時間軸です。表と自証：
[`sweep_results/rstdp_spiking_actor_fix/README.md`](../../sweep_results/rstdp_spiking_actor_fix/README.md)。

## 既知の境界

1. **既定の Critic は線形 TD(0)。** TD-LTP 集団 Critic は実装済み（`pop_critic.py`、`--critic pop`）
   だが現状は学習しない（上の節を参照）。したがって**実験用の入口であり、使用可能な既定ではない**。
2. **LIF 一段のみ。** 多層化なし、符号化層（集団符号化 + ベルヌーイ標本化）も学習しない。
3. **体系的なハイパーパラメータ探索はない。** 試した四つの変種はいずれも悪化：窓 10 歩 → 9.2、
   特徴 128 → 10.3、Critic 率 1e-1 → 66.9、γ = 0.95 → 60.2（各 1 シード、800 エピソード）。
   現在の構成は局所最適であり、**証明された最良ではない**。
4. **訓練エピソード数に強く依存する**：同一設定で 400 エピソード 83.9、1200 エピソード 102.8
   （シード 0）。
5. **レート版との比較は統制比較ではない——二つの口径が違う。** ①**評価**：レート版は決定的、
   スパイク版は乱数流を凍結して複数エピソードで平均する。②**符号化**：レート版は四軸とも
   一律 `[-1.5, 1.5]` の中心と `--encoding-sigma` 既定 0.5、本ディレクトリは
   `CARTPOLE_HALF_WIDTHS` による軸別（±2.4 / ±3.0 / ±0.21 / ±3.0）と `--sigma` 既定 1.0。
   **実装は共通**（`research/components/cartpole_encoding.py`）で、違うのはパラメータだけです。
   したがって報告の差には「スパイク化の代償」「評価プロトコルの違い」「符号化パラメータの
   違い」が混ざっており、**単一要因に帰属できない**。
