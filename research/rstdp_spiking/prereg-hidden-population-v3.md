# 预注册：给脉冲执行层加一层隐藏群体（v3，2026-11-02）

**状态：判据先落盘，代码未写。**

## 为什么要加

v2 的三条读出路线全部撞墙，根因是同一个：**当前 actor 的输出层就是动作空间**
（`LIFLayer(n_features → n_actions)`，每个动作一个神经元），所以"群体读出"没有对象，
任何解码都退化成"每个输出神经元连到自己"。要继续，必须先有群体。

## 加什么（两条臂，同一套判据）

| 臂 | 隐藏层 | 输出层 | 是否越红线 |
| :--- | :--- | :--- | :--- |
| **H1 储层** | 固定随机权重，**不学** | 由局部规则（R-STDP）学 | 否 |
| **H2 储层 + 拟合读出** | 固定随机权重 | 由岭回归**一次拟合** | **是**（监督读出） |

H2 是上一轮明确标红的做法。**仍然把它列进来，是因为要有一个上界参照**：
如果 H1 过不了判据而 H2 过了，结论应写成"瓶颈在读出的学习方式，不在群体是否存在"；
如果两者都过不了，说明加群体本身不够。**H2 的结论永远不能当作"局部学习能解决执行层"的证据。**

## 结构（跑之前定死）

- 输入编码 → 隐藏层 `LIFLayer(n_features → n_hidden)`，`n_hidden = 128`（比动作数 2 大两个量级），
  权重从固定种子初始化后**冻结**；
- 隐藏 → 输出：`n_hidden → n_actions` 的线性读出；
- 时间窗与其余超参沿用第三阶段既有设置，不额外调；
- 种子：0–9，共 10 个。

## 判据（跑之前写死）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| H-1 | 10 个种子的回报**中位数** | ≥ 200 |
| H-2 | **逐 seed 一致性** | ≥ 8/10 个种子单次也过 200 |
| H-3 | 与旧 actor（无隐藏层）的**同种子配对** | ≥ 8/10 更好 |

三条全过才算成功；只过中位数记为"有效但不稳定"。

## 跑之前的预期

- **H1 大概率不过**：储层的随机投影会把输入的线性可分性打散，而输出层只能学线性组合；
  CartPole 的四个状态量本来接近线性可分，加一层随机非线性很可能先掉分。
- **H2 可能过**：岭回归能利用群体的高维表示，但那已经越了红线。
- 如果 H1 掉了而 H2 过了，这一项的正确结论不是"方案成功"，而是**"群体 + 监督读出有效、
  局部规则下的读出仍未被证明"**——那正是阶段三一直没解决的那半。

## 不做的事

- 不调隐藏层规模（128 是预设，不是扫出来的）；
- 不训练隐藏层权重（那是另一个问题，需要自己的预注册）；
- 不因为 H1 不过就默认切到 H2 当"成功"。
