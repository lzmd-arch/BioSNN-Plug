# 预注册：线 A v3——多抽头读出：让局部规则也能看到多个时间点（2026-11-04）

**状态：判据先落盘，代码未写。**

## 诊断给出的方向

A2 把天花板定位到了**读出设计**：

| 探针 | 准确率 |
| :--- | ---: |
| P1 在线读出（最后一步） | 0.759 |
| P2 离线岭回归（**同一组**最后一步特征） | 0.772 |
| **P3 离线岭回归（全 28 步）** | **0.869** |

学习规则只差 **1.3pp**，而"只取最后一步"差 **9.7pp**——**信息在时序里，我们只读了一帧。**

## 这一版要回答什么

**把同一套局部规则用在多个时间点上，能不能吃回那 9.7pp 的一半？**

「一半」= **5pp**。这不是拍脑袋：P3 是**闭式解 + 全部 28 步**的上界，局部规则在同样抽头数下
本来就会低一档（P1 vs P2 已知差 1.3pp），所以拿 5pp 当门槛是"至少吃到一半以上"。

## 设计（跑之前定死）

- **多抽头**：把滤波发放在 `k` 个**等距**时间点各取一份、拼接成 `k × 8,192` 的特征；
  `k = 1` 就是现状（只取最后一步）；
- **读出**：`k × 8,192 → 10` 的线性层，**用同一套 e-prop 局部规则更新**
  （错误信号对每个抽头相同，资格痕迹各取各的）；
- 回传到神经元的信号 = 各抽头贡献**求和**；
- 其余全部不变：8,192 神经元、fan_in 32、sMNIST 全量、2 epoch、种子 0。

**三个抽头数**：`k ∈ {1, 7, 28}`。`k=1` 是基准，`k=28` 等于"每一步都读"。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **A3-0** | 基准没变 | `acc(k=1)` 复现 0.759 ± 0.01 |
| **A3-1** | 多抽头买得到精度 | `acc(k=28) − acc(k=1) ≥ 5pp` |
| **A3-2** | 代价可接受 | `k=28` 的墙钟 ≤ **1.5 ×** `k=1` |

A3-1 过 → **读出设计是本阶段最便宜的改进**，下一轮把它做成默认并复测；
A3-1 不过 → 说明 P3 的增益来自"闭式解"而不是"多时间点"，那要重新定位。

## 跑之前的预期

**倾向 A3-1 过，但幅度小于 9.7pp。** 理由：P3 同时改了"多时间点"和"闭式解"两件事，
A2 的 P2 说明后者只值 1.3pp，所以多时间点应当是大头；但局部规则的信用分配更粗，
吃到 5pp 以上、9pp 以下是合理区间。

若 A3-1 大幅超过 9.7pp，那说明我漏算了什么，要回头查。

## 边界

- 单种子；三档抽头同预算；
- `k=28` 的读出参数是 `28 × 8,192 × 10 ≈ 2.3M`，比原来多 28 倍——**这不是"免费"**；
- 不把 A3 的结果写成"系统能力提升"：它是同一条管线上的读出改动，尚未做多种子与真实语料。

## 不做的事

- 不改学习率、不改 epoch、不挑抽头位置（等距是定死的）；
- 不换成岭回归——那会违反纯局部学习的定位（ADR-0002）。
