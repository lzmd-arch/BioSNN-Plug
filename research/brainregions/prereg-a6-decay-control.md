# 预注册：检验"多抽头增益 ∝ 看不见的比例"（A6，2026-11-04）

**状态：判据先落盘。**

## 要检验的那句话

A3/A5 之后我写下的一条**观察**（当时就标明只有两个点、不算定律）：

| 任务 | T | 最后一步看得见的比例 | 多抽头增益 |
| :--- | ---: | ---: | ---: |
| sMNIST | 28 | 20/28 = 71% | +14.3pp |
| SHD | 100 | 20/100 = 20% | +42.1pp |

看不见的比例 2.76×、增益 2.94×——**大致成正比**。这里"20 步"来自读出滤波的衰减 `decay_out = 0.95`。

**如果这个机制是真的，那它可以直接改一个旋钮来检验：把衰减调到 0.99。**
那样最后一步的有效窗口从 20 步变成 100 步，在 T=100 的 SHD 上**覆盖整段**——
多抽头的优势应当显著缩小。

## 设计（跑之前定死）

SHD、8,192 神经元、fan_in 32、10 epoch、batch 8、seed 0，与 A5 完全一致，只加两个臂：

| 臂 | decay_out | taps | 已有？ |
| :--- | ---: | ---: | :--- |
| 参照 | 0.95 | 1 | ✅ S8 = 0.338 |
| 参照 | 0.95 | 28 | ✅ A5 = 0.759（**+42.1pp**） |
| **新** | **0.99** | **1** | 跑 |
| **新** | **0.99** | **28** | 跑 |

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **K-0** | 两臂都学到了 | 两臂准确率都 >0.20 |
| **K-1** | 机制成立：增益缩小 | `acc(0.99,28) − acc(0.99,1) < 0.421 / 2`，即 **< 21.1pp** |
| **K-2** | 而且不是全无作用 | `acc(0.99,28) − acc(0.99,1) > 0` |
| **K-3** | 长窗口本身有代价（参考，不设门槛） | 记录 `acc(0.99,1)` 相对 0.338 的变化 |

**K-1 是核心。** 机制说"增益来自补上最后一步看不见的那部分"；
把看不见的部分从 80% 降到 0% 之后，增益应当至少减半。

## 预期

**押 K-0 过、K-1 过、K-2 过。** 具体：`acc(0.99,1)` 落在 **0.55–0.70**（长窗口救回一部分但拿不到全部，
因为 0.99 的窗口对早期脉冲权重很小、时间分辨率也糊），`acc(0.99,28)` 落在 **0.72–0.80**。

若 K-1 **不过**（增益仍有 21pp 以上），说明多抽头的好处不只是"看得更久"，
那 A5 里那条"∝ 看不见的比例"的解释要作废，改写成"还有别的机制"。

## 边界

- 单种子；只改 `decay_out`，其余不动；
- **写这份预注册时核对过代码**：`decay_out` 只出现在读出的 `exp_convolve` 里，
  e-prop 的资格痕迹用的是 `alpha = exp(−1/tau)`，两者互不影响。所以这一臂**确实只改读出**；
- 但 `decay_out` 一改，读出的**权重尺度**也会变（0.99 的滤波对整段积分，特征范数更大），
  所以严格说改的是"读出的时间常数"，不是"抽头数"；
- 只测 SHD，不回头重跑 sMNIST。
