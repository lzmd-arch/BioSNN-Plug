# 预注册：SHD 上 32k + 28 抽头——补全规模 × 读出的 2×2（A8，2026-11-05）

**状态：判据先落盘。**

## 与 A4 的区别：这次有真正的余量

A4 在 sMNIST 上做过同一件事：32k + 28 抽头 = 0.914，8k = 0.917（−0.3pp）。
但那是在 **0.917 已经贴着线性读出天花板（4,000 样本岭回归 0.916）** 的情况下测的——
没有余量，规模当然买不到东西。

**SHD 不是一个贴天花板的任务**：8k + 28 抽头是 **0.757**，离该任务的好结果还有距离。
所以"规模还有没有用"在这里是一个**新的、没被回答过**的问题。

## 已有的三个点

| 神经元 | k=1 | k=28 |
| ---: | ---: | ---: |
| 8,192 | 0.338（S8） | **0.757**（A5，三种子中位） |
| 32,768 | 0.348（S8） | **跑** |

## 设计（跑之前定死）

- **一臂**：`n_rec = 32,768`、`taps = 28`、SHD、10 epoch、batch 8、seed 0、fan_in 32；
- 除了神经元数，与 A5 **完全一致**（同代码 `build`、同数据、同预算）；
- 对照不重跑：8k + 28 抽头的三种子是 0.759 / 0.745 / 0.757。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **N-0** | 前置：跑得动 | 峰值显存 < **8,000 MiB**（S8 的 32k SHD 已经到 7,393 MiB，加上抽头可能紧） |
| **N-1** | 规模买得到精度 | `acc(32k) − 0.757 ≥ 2pp` |
| **N-2** | 没练坏 | `acc(32k) ≥ 0.737` |

**N-1 的分辨率这次是够的**：8k + 28 抽头的种子分布是极差 **1.4pp、sd 0.76pp**（A5 三种子），
所以 2pp 的门槛约等于 **2.6 个标准差**——比 A4 那次（用 sd 2.2pp 去判 2pp）干净得多。

## 预期

**押 N-1 不过，差 +0～+2pp。** 理由：sMNIST 上换掉读出之后规模就不值钱了；
但 SHD 还有余量，所以我不排除小幅为正。**若过 2pp，说明"规模在有余量的任务上仍然有用"，
那 ADR-0033 的"容量饱和"要加上"在饱和任务上"这个条件，不能一概而论。**

若 N-1 大幅通过（>5pp），先报告再动，不自行扩实验。

## 边界

- **单种子**；只测 32k 一个规模；
- 不与 sMNIST 的数字横向比较（任务、类别数、序列长度都不同）；
- 32k 的读出是 `32768 × 28 × 20 ≈ 18.3M` 参数——比 8k 那臂大 4 倍，**这是第二个混杂**，
  若结果为正，不能直接归因给"神经元更多"。

## 成本

S8 的 32k / 10 epoch 是 2,587 s；A5 的 8k / 28 抽头约 3,100 s。**预计 60–80 分钟。**
