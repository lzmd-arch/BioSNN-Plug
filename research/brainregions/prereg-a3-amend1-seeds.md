# 预注册修订 1：A3 补种子 1、2（2026-11-04）

**状态：判据先落盘，代码未跑。** 本文件修订 [`prereg-a3-multitap.md`](prereg-a3-multitap.md)，
**在跑 seed 1、2 之前写下**，写的时候只看过 seed 0 的结果（0.917）。

## 为什么要补

A3 的预注册只写死了 **seed 0**。0.759 → 0.917 的增益（+15.8pp）远大于 k=1 在三个种子上的极差
（0.759 / 0.762 / 0.763，见 A1），看起来不像种子噪声；但"看起来不像"不是证据。

## 补什么

- 只补 **`taps = 28`** 在 **seed 1、2** 上各一次；
- **不重跑 k=1**：A1 的均匀臂就是 k=1（同一模型、`intra_fraction=0.0`、同预算），
  已有 0.759 / 0.762 / 0.763，且 seed 0 的 0.759 与 A3 的 k=1 逐位相同；
- 其余全部不动：8,192 神经元、fan_in 32、sMNIST、2 epoch、batch 8。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **S-0** | 两档都学到了 | seed 1、2 的 `acc(k=28)` 均 ≥ 0.90 |
| **S-1** | 每个种子都赢 | 每个种子 `acc(k=28) − acc(k=1) ≥ 5pp` |
| **S-2** | 增益不是单点 | 三种子增益**中位** ≥ 10pp |

三条全过 → 0.917 可以写成"三种子的结果"，不再是单种子；
任一条不过 → 结论退回"A3 只有 seed 0 支持"，并按实际数字改写。

## 预期

**全过。** 预期三种子 `acc(k=28)` 落在 0.90–0.93，中位增益 14–16pp。
若 seed 1/2 掉到 0.90 以下，说明 seed 0 是运气，那 A3 的主结论要降级。

## 不做的事

- 不补 k=7、k=28 的其他中间档；
- 不因为 S-1 不过就调阈值或换种子；
- 不把这一修订当成新实验——它只是同一实验的重复。
