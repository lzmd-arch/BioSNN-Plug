# 预注册：补全 (decay × k) 的 k 阶梯，直接检验"每个神经元几个数"（A7，2026-11-04）

**状态：判据先落盘。**

## 为什么跑这一轮

A6 推翻了"增益 ∝ 看不见的比例"，换上一条新解释：**限制不是"看见多久"，是"每个神经元给出几个数"**。
那条解释在 A6 的 README 里明确标着"**还没有直接检验过**"，并写下了该怎么验：

> 在 decay 0.99 下扫 `k`（1 / 7 / 28），若增益主要发生在 1→7，解释就得到支持。

这一轮就是补那两格。

## 已有的四个点

| decay_out | k=1 | k=7 | k=28 |
| ---: | ---: | ---: | ---: |
| 0.95 | 0.338（S8） | **缺** | 0.759（A5） |
| 0.99 | 0.425（A6） | **缺** | 0.710（A6） |

SHD、8,192、10 epoch、batch 8、seed 0，其余全部与 A5/A6 一致。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **L-0** | 前置：两臂都学到 | 两臂准确率都 >0.20 |
| **L-1** | **主要增益在 1→7** | 在 decay 0.99 上，`(acc7 − acc1) / (acc28 − acc1) ≥ 0.70` |
| **L-2** | 7→28 已经饱和 | `acc28 − acc7 ≤ 5pp`（在 decay 0.99 上） |
| **L-3** | 同形状在另一个衰减下复现 | 在 decay 0.95 上，`acc7 − acc1 ≥ 0.70 × (0.759 − 0.338)` |

**L-1 是核心。** "每个神经元几个数"这条解释预言：**从 1 个数变成 7 个数就拿到了大头**，
再加密到 28 个数只是边际改善。若 L-1 不过（大头发生在 7→28），解释要再改。

## 预期

**押 L-0/L-1/L-2/L-3 全过。** 具体：

- `acc(0.99, 7)` 落在 **0.65–0.70**；
- `acc(0.95, 7)` 落在 **0.70–0.76**（sMNIST 上 k=7 是 k=28 的 97.6%，这里打个折）。

依据：sMNIST 的阶梯是 0.759 / 0.895 / 0.917——1→7 拿了 86%，7→28 只多 2.2pp。
如果 SHD 上也是这个形状，L-1 会以大比分通过。

## 不做的事

- 不补 k 的其他档（2/4/14 之类）；
- 不改 epoch、不改学习率；
- 不因为 L-1 不过就换 decay 再试——那要另写预注册。
