# W3：R-STDP 执行层 + TD-LTP Critic

**⚠️ 破坏性变更免责期：至 2027-09**（计划书 §12.5、ADR-0005）。

## 在验证什么命题

计划书 §3.2 的执行层：**带 TD-LTP Critic 的 R-STDP 能否在 CartPole 上稳定学到 200 步
以上，且成功偏移 < 10%σR。**

Critic 不是可选项。§3.2 引 Frémaux et al. (2010)：成功偏移达 σR 的约 25% 就无法学习，
偏移 < −0.4σR 时性能甚至低于学习前。该敏感性是通用特性，调 STDP 窗口或换权重依赖模型
都解决不了；唯一的结构性解法是刺激特异性奖励预测。

## 当前结论

**仍未达到验收，但原因已经换了一个。** Critic 那一侧修好了，剩下的是 Actor 那一侧。

### 改动后（群体 + 固定读出的 Critic）

五种子的实测（`--seed 0..4`，其余配置相同）：

| seed | 贪心评测平均步数 | \|偏移\|/σR（末段） |
| ---: | ---: | ---: |
| 0 | 114.6 | 0.0076 ✓ |
| 1 | 61.1 | 0.0127 ✓ |
| 2 | 60.2 | 0.0142 ✓ |
| 3 | 119.9 | 0.0290 ✓ |
| 4 | 81.6 | 0.0162 ✓ |
| **判据** | **≥ 200** | **< 0.10** |

**偏移 5/5 全部达标**，步数 60–120。比改动前（偏移 1/5、步数 9–37）是**结构性**的改善：
Critic 真的收敛了，`δ` 不再有直流偏移——这正是换群体结构的目的。

**但 200 步仍没到。** 最好的种子 119.9 步，离判据还差四成。见「改动前后对比」一节对原因的
分析：现在瓶颈明确在 Actor 的信用分配，不在 Critic。

### 改动前（单单元 Critic，已作为对照保留）

`--critic-kind single` 可复现改动前的行为：

| seed | 步数 | \|偏移\|/σR |
| ---: | ---: | ---: |
| 0 | 9.3 | 0.9676 ✗ |
| 1 | 23.1 | 0.4364 ✗ |
| 2 | 37.3 | **0.0530** ✓ |
| 3 | 9.4 | 0.7571 ✗ |
| 4 | 9.5 | 1.3705 ✗ |

五个种子**没有一个**达到 200 步；偏移只有 1 个达标。随机策略在 CartPole 上约 9–10 步，
所以 seed 0/3/4 事实上没有学到任何东西。

### 改动前那张表里有一个与论文预测方向一致的信号

把两列并排看：**偏移大的种子恰好是学不动的种子**。

* seed 0/3/4：偏移 0.97 / 0.76 / 1.37 → 9.3 / 9.4 / 9.5 步（等于随机策略）
* seed 2：偏移 0.053（唯一达标） → 37.3 步（五个里最好）

这正是 §3.2 那条断言的方向：**成功信号一旦有直流偏移，Actor 就学不动。** 本条目
**没有**复现出"偏移到某个具体阈值就失效"的定量边界（那需要设计一个动作分布保持混合的
任务才能干净地量），但定性方向与论文一致。这条相关性是本条目最有价值的部分。

## 方程到模块的对应

| 论文 | 内容 | 模块 |
| :--- | :--- | :--- |
| Frémaux 2013 Eq. 17 | TD-LTP：`Δw = η·δ·e`，`e ← λe + x·y` | `td_ltp.TDLCritic` |
| §3.2 | R-STDP：`Δw = η·S·e`，`e ← λe + x·a` | `rstdp.RSTDPActor` |
| §3.2 | 权重归一化 | 两个类各自实现 |
| §3.2 / §七 | 成功偏移 / σR | `measure_bias` |

## 实现过程中修掉的三个结构性 bug

每一个都配了回归测试，且都不是"调参能绕过"的。

**1. Critic 的零点锁死。** 资格痕迹是 `e ← λe + x·V`，被 Critic **自己的输出**门控。
最初用零初始化 → `V ≡ 0` → 痕迹恒为 0 → 更新量 `η·δ·e` 恒为 0 → Critic 永远学不动。
这是三因子结构里"后突触活动作为第二因子"带来的锁死。

**2. 正值反馈导致发散。** 改成小幅随机初始化后能动了，但学习率一调高权重就发散成 NaN：
`V` 变大 → `e = x·V` 变大 → `Δw` 变大 → `V` 更大。

**3. 缺了 Critic 的权重归一化。** §3.2 明写「同时引入权重归一化：每个神经元层面保持
权重总和恒定，防止突触动态失控」——我当初只给 Actor 加了。补上 L2 归一化后回路断开，
CartPole 上从 9.5 步升到 84 步。另配 `value_scale` 恢复被归一化拿掉的整体增益。

另修两处**测量/复现**缺陷：进度日志里的痕迹列打印时机错了（`end_episode()` 之后取，
恒为 0）；以及 **CartPole 环境从未播种**——同一 seed 连跑两次得到 20.4 步与 9.3 步。
后者对结论尤其要紧：修复之前，"种子间差异"里有多少来自算法、多少来自环境 RNG 是分不清的。

## 容量探针：一个否定性结果

`research/rstdp/capacity_probe.py` 用 CartPole 的经典启发式控制器当靶子，测**这个编码上
线性策略的容量上限**——线性分类器的形式与 `RSTDPActor` 的动作选择完全一致。

| 特征数 N | σ=0.25 | σ=0.5 | σ=1.0 |
| ---: | ---: | ---: | ---: |
| 16 | 24.6 | 209.8 | 494.2 |
| 64 | 294.2 | **497.2** | 500.0 |
| 256 | 449.4 | 500.0 | 500.0 |
| 1024 | 498.4 | 500.0 | 500.0 |

（表内是拟合出的线性策略的平均存活步数；专家启发式本身是 500.0。）

**当前配置就是 N=64、σ=0.5，对应 497.2 步。** 也就是说：这个编码上**存在**一个几乎解出
CartPole 的线性策略，而 R-STDP 没找到它。

所以「Actor 容量不足」这个假设**被否定**，改学习规则之外的方向（加容量）不是答案。这也
排除了一个原本看起来最省事的解释。

## 改动前后对比：为什么换群体结构

单单元 Critic 把"单元输出"与"值"当成了同一个量，于是它的资格痕迹是 `e = x·V`。这带来三个
连锁问题，实测都出现过：

| 问题 | 症状 | 群体结构为什么治得了 |
| :--- | :--- | :--- |
| 零点锁死 | 零初始化下 `V ≡ 0` → 痕迹恒 0 → 永远学不动 | `y_j = σ(…)` 在 0 处是 0.5，不是 0 |
| 正值反馈 | `V`↑ → `e=x·V`↑ → `Δw`↑ → `V`↑，权重发散成 NaN | 第二因子是 `y_j ∈ (0,1)`，**有界** |
| 尺度自由度被夺走 | 为堵上一条加了 `‖w‖=1`，于是 `V` 顶到上界、`δ` 变常数 | 尺度由**固定读出**承担，`w_j` 只管形状 |

改动之后的数字见上一节：偏移 1/5 → 5/5，步数 9–37 → 60–120。**这条改动值不值得做，看这两个
数字就够了**，不需要再去猜哪个超参更敏感。

## 已知边界

1. **验收未通过**，没有任何种子达到 200 步。
2. **成功信号换掉了默认值。** §3.2 写 `S = R − ⟨R⟩`，但 CartPole 每步都给 +1 的**密集
   恒定奖励**，`⟨R⟩ ≡ 1`，于是 `S ≈ 0`、毫无对比度——那个式子是给**稀疏终末奖励**的设定
   写的（Frémaux 2010 的原始场景）。默认改用 TD 误差，两种都保留可选。所以本条目验的
   不是计划书字面上的那个成功信号。
3. **速率型而非脉冲型。** 速率型下没有"脉冲先后"，所以 `STDP(Δt)` 的窗口形状退化成同时
   刻的乘积，**TD-LTP 与 TD-STDP 那处"有无 post-before-pre 分量"的差别在本实现里无从
   体现**。ADR-0007 的备选 C（退回 TD-STDP）因此不是本实现里的一个开关——真要退需要先
   改回脉冲型。**没有尝试过那个回退。**
4. **调参必须在环境播种之后重做。** 我此前扫出的那些"敏感"结论（例如 Critic 学习率
   1e-3 与 5e-4 差 44 步 vs 223 步）**都是在环境播种之前测的，因而不可信**——那时同一
   配置连跑两次就能差一倍。播种后重扫的结果（见边界第 6 条）是另一个图景：所有配置都
   在 9–59 步之间，且都以 Critic 饱和告终。**这意味着本条目此前基于那批数据做的调参判断
   大部分要作废。**
5. **"Actor 容量不足"这个假设已经被否定。** 见「容量探针」一节：在**同一个编码**上，一个
   线性策略能跑 497 步。所以容量不是瓶颈。
6. **换 Critic 结构解决了信号有偏的问题，没有解决步数。** 偏移从 1/5 达标变成 5/5 达标，
   步数从 9–37 提到 60–120，但 200 步仍没到。**瓶颈现在明确在 Actor 那一侧**：
   - Actor 仍是一个线性策略，用 L1 归一化（这一条**没有**随本次改动一起复核，仍是候选干扰源）；
   - 资格痕迹的第二因子取"被选中动作的指示量"，credit assignment 相当粗糙；
   - 学习信号用的是 TD 误差，而 Critic 与本条目一样在同步学习（非两阶段）。
   这三条都没有单独消融过。
7. **单单元 Critic 的两个病已定位并修复，但那只解释了改动前的一部分。** 它的资格痕迹被自己的
   输出门控（零点锁死）、更新量正比于 `V`（正值反馈 → 发散）、我加的归一化又夺走了它的尺度
   自由度（`V` 顶到上界 → `δ` 变常数）。换成群体后这三个都消失。但把单单元版换成标准 TD(λ)
   也只到 21–40 步——**说明那时还有别的因素在起作用**，那些因素现在大概率还在。
8. **§3.2 那条定量边界未复现。** "偏移达 ~25%σR 就无法学习"需要设计一个动作分布保持
   混合的任务才能干净地量出来；`examples/paper_fremaux2013.py` 刻意**不**演示它，因为
   我第一版写的演示量的其实是"actor 恰好选哪个动作"，不是偏差结构。
