### Critic 学不准，原因已经定位到读出

把 Actor 学习率设为 0 就得到**完全静止**的目标，非平稳这条解释被排除——EV(V, V\*) 仍是
−1.00 / −0.51 / −0.81。也**不是步长**：Critic 学习率往下调，EV 单调变差
（5e-4 → 1e-4 → 2e-5 对应 −0.75 → −1.30 → −6.45）。

把固定读出换成**最小二乘解**、其余一律不动，**同一批单元活动**的 EV 从 −0.9 变成 **+0.6**：
特征里有信息，是「固定、全正、均匀」这个读出把它扔了。（对照：**未训练**的随机方向已经有
+0.53，所以训练单元方向这件事本身收益极小。）

于是加了 `critic_readout="random"`（固定但**有符号**）配完整的半梯度后因子
`u_j·g·y_j(1−y_j)`。**机制上确实有效**：EV −1.00 → −0.21，平均绝对误差 10.8 → 5.4。

**但步数 0/10 变好**（配对 −50.7）。原因是一个量得出来的混淆：有符号读出让 `V = Σu_j y_j`
变成正负相消的差，**σR 从 4.30 掉到 1.40**，等于把标定过的 Actor 有效步长压小了 3 倍。

**步长补偿的对照已经跑完，结论不变。** 把 Actor 学习率按 σR 的比例放大到 9e-3
（`3e-3 × 4.30 ≈ 9e-3 × 1.40`，乘积即有效步长），配对数仍是 **−40.6、4/10 变好**，
中位数 45.9。**所以「把 δ 变准并不能把策略变好」这一条在补偿之后依然成立**——
预登记的分叉推断（EV < 0.5 ⇒ 瓶颈在 Critic）就是这样被它自己的干预否证的。

### 已经确立的（不再是假设）

- **Actor 的规则从不比较任何两个动作，而且它面对的目标恒为零。** `learn_step` 只在非探索步
  更新 Actor，而那些步的 `action = argmax` 是状态的确定性函数——所以更新只落在**被选中那一列**
  （实测 `U 只碰到一列的状态占比 = 1.0000`；这是离散事实，不依赖任何阈值）。更深一层：
  确定策略下 `A(s, π(s)) ≡ 0` 是**恒等式**，于是「优势加权方向」这个目标**在访问到的状态上
  恒等于零**（实测 `逐状态 |T| 中位数 = 0.0000`）——因为好策略访问到的状态上杆子接近竖直、
  **两个动作几乎等价**。所以规则面对的不是「方向不对」，而是**没有可学的目标**：被选中的
  那一列拿到的是与动作无关的残差 δ 造成的漂移。
- **规则不做动作之间的比较。** `learn_step` 只在非探索步更新 Actor，而那些步的
  `action = argmax` 是状态的确定性函数，所以它只强化**当时选的那个**动作。这也是为什么
  按 `a_j − π_j` 中心化**单独做会把 Actor 完全停掉**（`a_j − π_j ≡ 0`）——代码里有断言挡着。
- **Boltzmann + 中心化是本阶段唯一通过采纳规则的杠杆**——只要把评测缺陷修掉。此前记为
  「无效」是被污染的（见「本阶段修掉的五个真缺陷」的第 5 条）：用真贪心评测重测，恒定
  logit 20 给出中位数 283.8（选择集）/ **177.3**（留出集 10–24）、配对 **+204.0**、9/10 变好。
  **但它仍够不到 200，而且约十分之一的种子会塌陷**（峰值只有 10–12 步，是从头到尾没启动，
  不是学会了又丢掉）。
- **容量不是瓶颈**：同一编码上监督拟合的线性策略跑 497 步（见下一节）。
- **Critic 的值域不是瓶颈**：V 的宽度是 V* 的 0.73–0.84，够宽；错的是形状。

### 本阶段修掉的五个真缺陷

1. **截断被当成终止。** 跑满 500 步的回合最后一步拿到 `δ ≈ 1 − 99.3 = −98`，约 56 倍典型
   权重，而且**策略越好打得越狠**——这是「峰值 500 → 崩到 14」最直接的解释。修完后
   不衰减那一档的前 5 个种子与修复前**逐位相同**，说明改动精确落在截断路径上。
2. **观测污染了被观测。** 中途贪心评测推进了训练环境自己的 RNG 流，改掉后面每个训练回合的
   初始状态（同配置同种子 seed 6 终值 107.3 → 335.4）。改成用另一个环境实例后逐位一致。
3. **Critic 偏好方向的采样池给了 `critic_units` 一个隐藏上限**（约 850–960），
   `critic_units=1024` 时十个种子全挂。
4. **我自己写错的一条符号论证。** 「读出必须全正」只在 `rate` 后因子下成立；换成 `gradient`
   后因子后，符号由 `u_j` 自己带进更新方向。
5. **`boltzmann` 分支不看 `exploration`，于是它的「贪心评测」量的是随机策略。** `select_action`
   在 `action_sampling="boltzmann"` 下无条件按 softmax 采样，而 `_greedy_score`（途中曲线与末次
   验收**都**走它）传的是 `exploration=0.0`。那个尺度的天花板被压得极低——**满分**策略（启发式，
   500 步）在动作准确率 70% 时只值 97.4 步、60% 时只值 36.3 步。代价是实打实的：它把本阶段
   唯一有效的杠杆判成了「无效」并写进了文档。修法是 `select_action(greedy=True)` **无视采样
   方案**返回 argmax，ε-贪心下与原路径逐位一致（所以既有数字全部不变）。

## 实现过程中修掉的三个结构性 bug

每一个都配了回归测试，且都不是"调参能绕过"的。

**1. Critic 的零点锁死。** 资格痕迹是 `e ← λe + x·V`，被 Critic **自己的输出**门控。
最初用零初始化 → `V ≡ 0` → 痕迹恒为 0 → 更新量 `η·δ·e` 恒为 0 → Critic 永远学不动。
这是三因子结构里"后突触活动作为第二因子"带来的锁死。

**2. 正值反馈导致发散。** 改成小幅随机初始化后能动了，但学习率一调高权重就发散成 NaN：
`V` 变大 → `e = x·V` 变大 → `Δw` 变大 → `V` 更大。

**3. 缺了 Critic 的权重归一化。** §3.2 明写「同时引入权重归一化：每个神经元层面保持
权重总和恒定，防止突触动态失控」——我当初只给 Actor 加了。补上 L2 归一化后回路断开，
CartPole 上从 9.5 步升到 84 步。另配 `value_scale` 恢复被归一化拿掉的整体增益。

另修两处**测量/复现**缺陷：进度日志里的痕迹列打印时机错了（`end_episode()` 之后取，
恒为 0）；以及 **CartPole 环境从未播种**——同一 seed 连跑两次得到 20.4 步与 9.3 步。
后者对结论尤其要紧：修复之前，"种子间差异"里有多少来自算法、多少来自环境 RNG 是分不清的。

| 256 | 449.4 | 500.0 | 500.0 |
| 1024 | 498.4 | 500.0 | 500.0 |

（表内是拟合出的线性策略的平均存活步数；专家启发式本身是 500.0。）

**当前配置就是 N=64、σ=0.5，对应 497.2 步。** 也就是说：这个编码上**存在**一个几乎解出

所以「Actor 容量不足」这个假设**被否定**，改学习规则之外的方向（加容量）不是答案。这也
排除了一个原本看起来最省事的解释。

## 改动前后对比：为什么换群体结构

单单元 Critic 把"单元输出"与"值"当成了同一个量，于是它的资格痕迹是 `e = x·V`。这带来三个
连锁问题，实测都出现过：

| 问题 | 症状 | 群体结构为什么治得了 |
| :--- | :--- | :--- |
| 零点锁死 | 零初始化下 `V ≡ 0` → 痕迹恒 0 → 永远学不动 | `y_j = σ(…)` 在 0 处是 0.5，不是 0 |
| 正值反馈 | `V`↑ → `e=x·V`↑ → `Δw`↑ → `V`↑，权重发散成 NaN | 第二因子是 `y_j ∈ (0,1)`，**有界** |
| 尺度自由度被夺走 | 为堵上一条加了 `‖w‖=1`，于是 `V` 顶到上界、`δ` 变常数 | 尺度由**固定读出**承担，`w_j` 只管形状 |

改动之后的数字见上一节：偏移 1/5 → 5/5，步数 9–37 → 60–120。**这条改动值不值得做，看这两个
数字就够了**，不需要再去猜哪个超参更敏感。

## 已知边界

1. **验收已通过**——§七 的两项与我自加的「稳定」条件都达到了，见「当前结论」。但下面这些
   边界仍然成立，而且本条目最有价值的部分**不是那个数字**，是那些被一条条否证的方向：它们
   排除了「不是这个原因」，剩下的才是真原因。
2. **成功信号换了默认值。** §3.2 写 `S = R − ⟨R⟩`，但 CartPole 每步都给 +1 的**密集恒定
   奖励**，`⟨R⟩ ≡ 1`，于是 `S ≈ 0`、毫无对比度——那个式子是给**稀疏终末奖励**的设定写的
   （Frémaux 2010 的原始场景）。默认改用 TD 误差，两种都保留可选。所以本条目验的**不是**
   计划书字面上的那个成功信号。
3. **速率型而非脉冲型。** 速率型下没有"脉冲先后"，所以 `STDP(Δt)` 的窗口形状退化成同时刻的
   乘积，**TD-LTP 与 TD-STDP 那处"有无 post-before-pre 分量"的差别在本实现里无从体现**。
   ADR-0007 的备选 C（退回 TD-STDP）因此不是本实现里的一个开关——真要退需要先改回脉冲型。
   **没有尝试过那个回退。**
4. **策略不收敛，这是最要紧的一条边界。** 每 50 回合评一次的曲线显示二十条轨迹**全部**在
   全程大幅震荡（相邻检查点差 5–30 倍）。所以「最终权重在 10 个贪心回合上的均值」这个验收
   口径量到的很大程度是**相位**而不是水平；**验收配置下的峰值中位数 389.8（全新 45–64）/
   441.7（调参 25–44）**，比终值中位数高一截。任何只报一个终值的结论在这里都要打折看。
5. **「Actor 容量不足」已被否定。** 在**同一个编码**上，一个监督拟合的线性策略能跑 497 步。
6. **把 Critic 变准并不改善步数——这条否掉了本阶段预登记的分叉推断。** 分叉规则说
   「EV < 0.5 ⇒ 瓶颈在 Critic」，实测确实 EV < 0（−1.0 … −2.0），于是我去修 Critic：
   换固定有符号读出 + 完整半梯度后因子，**EV −1.00 → −0.21、平均绝对误差 10.8 → 5.4**，
   机制上成功了。**结果步数 0/10 个种子变好**（配对中位数 −50.7）。
   **混淆已量出并已补偿**：有符号读出让 `σR` 从 4.30 掉到 1.40（Actor 有效步长被压小 3 倍）；
   把 Actor 学习率按同一比例放大到 9e-3 之后，配对中位数仍是 **−40.6、4/10 变好**。
   **所以「先把 Critic 修准」这条路已经被排除，不是「还没试」。**
7. **Actor 的规则不做动作之间的比较，而且确定策略下它没有可学的目标。** `learn_step` 只在
   非探索步更新 Actor，那些步的 `action = argmax` 是状态的确定性函数，所以规则只强化当时选的
   那个动作（`U 只碰到一列的状态占比 = 1.0000`）。更根本的是 `A(s, π(s)) ≡ 0` 是恒等式，
   于是「优势加权方向」在访问到的状态上**恒等于零**（`逐状态 |T| 中位数 = 0.0000`）——
   好策略访问到的状态上两个动作几乎等价。**换成 Boltzmann + `a_j − π_j` 中心化是本阶段唯一
   通过采纳规则的杠杆**（留出集 177.3、配对 +204.0）。**注意那一句量的是当时的中间配置**：
   它还没上逆温度退火、学习率也没衰减到 0.01×，所以 177.3 够不到 200，且约十分之一的种子会
   塌陷。最终配置（退火 1 → 40 + 学习率末期 0.01）在全新种子 45–64 上中位数 237.8、最小 121，
   **已达标**——那一批里没有低于 100 的种子，所以「十分之一塌陷」至少不适用于最终配置。
   **此处原先写的「规则方向对，cos = 0.74」与「步长比 20–36 倍即步长过大」两条都已撤回**：
   前者是目标近零时的噪声（seed 1 上只有 0.078），后者是分母小而不是分子大。
8. **调参必须在环境播种之后重做。** 更早那批"超参敏感"的结论（例如「Critic 学习率 1e-3 与
   5e-4 差 44 步 vs 223 步」）**是在环境播种之前测的，因而不可信**——那时同一配置连跑两次
   就能差一倍。本条目此前的调参判断大部分已作废。
9. **一处网格设计错误记在这里。** Actor 成功信号裁剪那三档取的是 {0.3, 1.0, 3.0}，而实测
   `σR` 的中位数是 4.78——三档**全部低于信号自身的标准差**，于是那一轮实际扫的是「更小的
   有效学习率」，而不是「削掉极端尾巴」。要测后者，阈值得在 `σR` 之上。
10. **单单元 Critic 的两个病已定位并修复，但那只解释了改动前的一部分。** 它的资格痕迹被自己
    的输出门控（零点锁死）、更新量正比于 `V`（正值反馈 → 发散）、为堵上一条加的归一化又夺走
    了它的尺度自由度（`V` 顶到上界 → `δ` 变常数）。换成群体后这三个都消失。但把单单元版换成
    标准 TD(λ) 也只到 21–40 步——说明那时还有别的因素在起作用，**而那些因素现在大概率还在**。
11. **§3.2 那条定量边界：结构复现了，数值没复现。** 现在有了
    [`examples/paper_fremaux2010.py`](../../examples/paper_fremaux2010.py)（计划书 §12.3 要求 [3]
    这篇核心文献有一个最小复现，此前缺着）：8 个刺激、one-hot 编码、**固定温度**的 Boltzmann 策略
    （动作分布保持混合——上次写错就错在这里），奖励带**逐刺激的基线偏置** `b_k`，比较两种基线：

    * **全局滑动平均**（这就是有偏的 R-STDP）——它只知道总均值，对每个刺激都减错了基线；
    * **按刺激的预测**（§3.2 点名的结构性解法）——每个刺激各维护一个均值。

    偏移是方案的**涌现属性**，不是外面加进去的。种子 0–4：

    | `b_k` 幅度 | 偏移/σR | 全局基线：学之前 → 学之后（最差种子） | 按刺激预测：偏移/σR → 学之后（最差种子） |
    | ---: | ---: | :--- | :--- |
    | 0.000 | 0.034 | 0.525 → **1.000**（1.000） | 0.090 → **0.975**（0.875） |
    | 0.125 | 0.261 | 0.525 → **0.975**（0.875） | 0.090 → **0.975**（0.875） |
    | 0.500 | 0.719 | 0.525 → **0.825**（0.750） | 0.088 → **0.975**（0.875） |
    | 2.000 | 0.965 | 0.525 → **0.625**（**0.375**） | 0.218 → **0.975**（0.875） |

    **复现的是结构**：偏移随逐刺激奖励差异增大而增大；全局基线方案学完的性能**单调下降**；
    换成按刺激的预测后偏移被压到 0.09–0.22σR、性能在所有幅度下都不降；而且在最大幅度上
    **最差的种子（0.375）掉到了学之前（0.525）之下**——论文那个 "unlearning" 分支确实出现了。

    **没复现的是那两个数值**：论文说 ~25%σR 就足以让 R-STDP 学不会，本任务在 **0.26σR** 时
    准确率仍有 **0.975**；论文说 S̄ < −0.4σR 时学完不如学之前，本任务要一直推到 **0.97σR**
    才看到退化，而且**按均值并没有**低于学之前（0.625 对 0.525），只有最差的种子掉下去了。
    本任务（查表式的线性 Actor）比论文的脉冲时序学习任务**宽容得多**，所以数值阈值对不上——
    **不要把那个脚本读成对 25% 这个数字的验证**。

    ⚠️ 上一次这条写的是「未复现，需要设计一个任务」。那个说法现在过时了：任务设计了，
    而且**结构上是对的**；对不上的是数值。
12. **种子方差极大，且它是动力学的而非统计的。** CartPole 的动力学是确定性的，随机性只来自
    初始状态、探索与初始权重。10 个种子的中位数仍有很宽的置信区间，所以此处的每一个"达标"
    或"不达标"都按 ≥10 种子报，并**必报最小值与最大值**。
13. **CPU 与 CUDA 的数字不可比**（浮点与随机流不同），所有扫描都固定在 CPU 上跑。

### 还没试的结构性方向

按证据强度排序，都仍在「无代理梯度、纯局部」之内：

1. **按动作拆开 Critic**（两群单元给 `Q(s,0)`、`Q(s,1)`，用 `A = Q − V` 驱动 Actor）。单个
   **状态值** Critic 只能给出状态级的优势，而 CartPole 的失败是动作特异的。这是经典解法，
   也是本条目结构上唯一还没动过的一环。**但注意边界第 6 条**：把 Critic 变准这条路已经被
   否证过一次，所以这一条的先验要相应调低。
2. **让局部可塑性塑造编码本身**（现在是固定随机编码 + 线性读出）。容量探针给的是这个组合的
   上限（497 步）够高，但学习规则可能够不到。
3. **刺激特异性奖励预测**——§3.2 点名的结构性解法：把「一个全局 δ」换成按刺激通道分组的预测。
4. **Trace Propagation**（Pes 2025）——不在本阶段实现，**而且这与 W2 那条线是同一件事**：
   经考证，计划书 §3.1 把它当作「e-prop 的存储优化」**不成立**（它是另一条规则、只覆盖
   LIF、且在论文自己的 N-MNIST 上不如 e-prop）。裁决见 [ADR-0010](../../docs/adr/ADR-0010-eprop-quadratic-storage-and-trace-propagation.md)。
