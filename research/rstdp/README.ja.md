# W3：R-STDP 実行層 + TD-LTP Critic

[中文](README.md) · [English](README.en.md)

**⚠️ 破壊的変更の免責期間：2027-09 まで**（プロジェクト計画書 §12.5、ADR-0005）。

## どの命題を検証しているのか

プロジェクト計画書 §3.2 の実行層：**TD-LTP Critic を伴う R-STDP が CartPole で 200 歩以上を
安定して学習でき、かつ成功信号の偏移が 10%σR 未満になるか。**

Critic は任意ではありません。§3.2 は Frémaux et al. (2010) を引いてこう述べています：成功
偏移が σR の約 25% に達すると R-STDP は学習できず、−0.4σR を下回ると学習前より性能が悪く
なります。この敏感性は一般特性であり、STDP 窓の調整や重み依存モデルの変更では解決しません。
唯一の構造的解決は**刺激特異的な報酬予測**です。

## 現時点の結論

**未達。** 二つの判定基準のどちらも満たしていません。

五つのシードでの実測（`--seed 0..4`、他は同一）：

| seed | 貪欲評価の平均歩数 | \|偏移\|/σR（末段） |
| ---: | ---: | ---: |
| 0 | 9.3 | 0.9676 ✗ |
| 1 | 23.1 | 0.4364 ✗ |
| 2 | 37.3 | **0.0530** ✓ |
| 3 | 9.4 | 0.7571 ✗ |
| 4 | 9.5 | 1.3705 ✗ |
| **判定基準** | **≥ 200** | **< 0.10** |

**どのシードも** 200 歩に達しておらず、偏移が基準を満たすのは seed 2 だけです。CartPole で
ランダム方策は約 9〜10 歩生き延びるので、seed 0/3/4 は実質的に何も学んでいません。

### ただし論文の予測方向に一致する信号がある

二列を並べて読むと：**偏移が大きいシードは、まさに学習できないシードです。**

- seed 0/3/4：偏移 0.97 / 0.76 / 1.37 → 9.3 / 9.4 / 9.5 歩（ランダム方策と同じ）
- seed 2：偏移 0.053（唯一基準を満たす） → 37.3 歩（五つの中で最良）

これは §3.2 の主張の方向そのものです：**成功信号に直流偏移が生じると Actor は学習できない。**
本項目は「偏移が約 25%σR で破綻する」という**定量的な境界を再現してはいません**（それを
きれいに測るには行動分布が混ざり続ける課題の設計が必要です）が、定性的な方向は論文と一致
します。この相関が本項目で最も価値のある部分です。

## 方程式とモジュールの対応

| 論文 | 内容 | モジュール |
| :--- | :--- | :--- |
| Frémaux 2013 Eq. 17 | TD-LTP：`Δw = η·δ·e`、`e ← λe + x·y` | `td_ltp.TDLCritic` |
| §3.2 | R-STDP：`Δw = η·S·e`、`e ← λe + x·a` | `rstdp.RSTDPActor` |
| §3.2 | 重み正規化 | 両クラスに実装 |
| §3.2 / §七 | 成功信号の偏移 / σR | `measure_bias` |

## 実装中に修正した三つの構造的バグ

いずれも回帰テストを伴い、どれも「パラメータ調整では回避できない」ものです。

**1. Critic のゼロ点ロック。** 資格痕跡は `e ← λe + x·V` であり、Critic **自身の出力**に
よってゲートされます。ゼロ初期化では `V ≡ 0` → 痕跡は 0 のまま → 更新量 `η·δ·e` も 0 →
Critic は永久に学習できません。第二因子が後シナプス活動である三因子構造そのものに由来する
ロックです。

**2. 正のフィードバックによる発散。** 小幅なランダム初期化で動くようになりましたが、学習率を
上げると重みが NaN に発散します：`V` が増える → `e = x·V` が増える → `Δw` が増える → `V` が
さらに増える。

**3. Critic の重み正規化が欠けていた。** §3.2 は明記しています——「同時に重み正規化を導入する：
ニューロンごとに重みの総和を一定に保ち、シナプス動態の暴走を防ぐ」。私は当初 Actor にしか
入れていませんでした。L2 正規化を加えるとループが切れ、CartPole は 9.5 歩から 84 歩に
上がりました。正規化で失われる全体利得は `value_scale` で戻しています。

さらに**測定／再現性**の欠陥を二つ修正しました：進捗ログの痕跡列を `end_episode()` の後に
読んでいたため常に 0 だったこと、そして **CartPole 環境に一度もシードを与えていなかった**
こと——同じシードで二回走らせると 20.4 歩と 9.3 歩になりました。後者は結論にとって重要です：
修正前は「シード間の差」のうちどこまでがアルゴリズム由来でどこまでが環境の RNG 由来かを
区別できませんでした。

## 容量プローブ：否定された仮説

`research/rstdp/capacity_probe.py` は CartPole の古典的なヒューリスティック制御器を靶子として、
**この符号化における線形方策の容量上限**を測ります——線形分類器の形式は `RSTDPActor` の行動
選択と完全に同一です。

| 特徴数 N | σ=0.25 | σ=0.5 | σ=1.0 |
| ---: | ---: | ---: | ---: |
| 16 | 24.6 | 209.8 | 494.2 |
| 64 | 294.2 | **497.2** | 500.0 |
| 256 | 449.4 | 500.0 | 500.0 |
| 1024 | 498.4 | 500.0 | 500.0 |

（表はフィットした線形方策の平均生存歩数。専門家ヒューリスティック自体は 500.0 です。）

**現在の設定は N=64、σ=0.5 で、これは 497.2 歩に対応します。** つまり：この符号化の上に
CartPole をほぼ解く線形方策が**存在する**のに、R-STDP はそれを見つけられていないのです。

したがって「Actor の容量が足りない」という仮説は**反証**され、容量を増やすのは答えでは
ありません。最も安価に見えた説明もこれで排除されました。

## 既知の境界

1. **受入は未達**です。どのシードも 200 歩に達していません。
2. **成功信号の既定値を変更しました。** §3.2 は `S = R − ⟨R⟩` と書いていますが、CartPole は
   毎ステップ +1 の**密で一定な報酬**を与えるため `⟨R⟩ ≡ 1` となり、`S ≈ 0` でコントラストが
   皆無です。あの式は**疎な終端報酬**の設定（Frémaux 2010 の元の状況）のために書かれたもの
   です。既定を TD 誤差に変更し、両方を選択可能にしました。したがって本項目は計画書に
   字義どおりに書かれた成功信号を検証しているわけではありません。
3. **レート型であり、スパイク型ではありません。** レート型にはスパイクの前後が無いため、
   `STDP(Δt)` の窓の形は同時刻の積に退化し、**TD-LTP と TD-STDP の違い（post-before-pre
   成分の有無）は本実装では表現できません**。したがって ADR-0007 の代替案 C（TD-STDP への
   退回）は本実装のスイッチではなく、戻すにはスパイク型に戻す必要があります。**その退回は
   試していません。**
4. **環境のシード修正後に、調整をやり直す必要があります。** 以前に私がスキャンした「敏感さ」の
   結論（たとえば Critic 学習率 1e-3 と 5e-4 で 44 歩 対 223 歩）は、**すべて環境にシードを
   与える前に測ったものであり、信用できません**——当時は同じ設定でも二回の実行で倍違いました。
   シード後に再スキャンすると別の姿になります（下記 6）：どの設定も 9〜59 歩に収まり、いずれも
   Critic の飽和で終わります。**本項目がそれ以前のデータに基づいて下した調整の判断は、大半を
   破棄しなければなりません。**
5. **「Actor の容量が足りない」という仮説は反証されました。** 下の容量プローブを参照：
   **同じ符号化**の上で、線形方策が 497 歩に達します。容量はボトルネックではなく、問題は
   信用割当／学習信号の側にあります。
6. **失敗の直接原因は半分まで特定できました：Critic の出力飽和です。** 実測では `V` は常に
   その上限（`value_scale · ‖x‖`）に張り付き、その結果 `δ = r + γV(s') − V(s)` が**定数**に
   退化します（`1 − 0.01·V_上限`）。Actor が受け取るのはまさに §3.2 が警告している有偏信号
   です。これが本項目が受入に失敗した直接の機序です。
7. **しかし Critic を標準 TD(λ) に替えても解決しません。** 対照実験を行いました：第二因子を
   ユニット自身の出力にすると重みが NaN に発散し（あの正のフィードバックは実在します）、
   標準 TD(λ) の `e ← λe + x` にすると発散はしなくなりますが、800 エポックでも 21〜40 歩に
   しか達しません。**つまり第二因子の構造的欠陥は実在しますが、それが全てではありません**
   ——真の根因はまだ特定できていません。既知の候補：Actor の信用割当、L1 重み正規化の干渉、
   そして Critic が未収束のまま Actor が δ を信号として使っていること自体です。
8. **§3.2 の定量的境界は再現していません。** 「偏移が約 25%σR で破綻する」を測るには行動
   分布が混ざり続ける課題が必要です。`examples/paper_fremaux2013.py` は意図的にそれを
   演示して**いません**——最初の版は実際には「actor がたまたまどの行動を選ぶか」を測って
   おり、偏差構造を測っていなかったためです。
