# Paper C §4.1 草稿：脉冲 Stream of Search 的尝试与证伪（2026-11-04）

**性质：章节草稿，不是最终正文。** 数字来自 `sweep_results/sos_e0_e1_v2` … `sos_e7` 与
`sweep_results/scale_s7`；凡属推断而非测量的，句子里明写"推断"。

## 4.1 脉冲 SoS：把过程显式化，值不值

### 4.1.1 动机

Gandhi et al.（SoS, CoLM 2024）在语言模型上给出了一个反直觉的结论：
**让模型学"搜索的过程"（探索、死路、回溯、再试）比只让它学"最优轨迹"更能形成搜索能力。**

这个结论对本项目的吸引力在于两点：它把"过程"变成了一等公民；而它用的载体（连续
hidden state + 反向传播）恰好是我们这条线（纯局部学习 + 脉冲）拿不到的。

于是问题变成：**在脉冲域里，用局部规则强化"过程"，能不能复现同一个结论？**（H1′）

### 4.1.2 实验设计

先把任务造出来，再谈方法。整条线分三段：

| 段 | 做什么 | 判据 |
| :--- | :--- | :--- |
| **E0** | 滑移迷宫环境（不是确定性网格——见下） | 难度有跨度、全部可解、无学习基线可跑 |
| **E1** | 每迷宫在线世界模型 + **不确定度** | 不确定度必须携带信息、且追踪"不熟" |
| **E2–E7** | 策略学习与 H1′ 检验 | 两臂配对差的可信区间 |

**一处设计上的关键修正**（写进了预注册，跑之前）：最早的网格是**确定性**的。确定性网格
能被世界模型零误差拟合，于是"预测误差的减少"恒为 0——P2 那条设计从根上没有信息。
改成 **滑移网格**（`p_slip = 0.10`）之后，期望下一位置本身带不可约误差，误差的大小才可能
随覆盖度变化。

**E0 的实测**：三个尺寸（9/11/13 边）合起来，最短路覆盖 **23 个不同长度 [12, 62]**，
全部可解；三个无学习基线的成功率是 随机 **0.006** / 贪心 **0.250** / 沿最短路 **0.975**。

**E1 的实测**（每迷宫在线模型，5 个种子）：众数命中 **0.735**，只看动作的边际基线 **0.592**；
Spearman ρ(预测熵, surprisal) **0.842**；少访问档的熵更大，**5/5** 个种子成立。
这三条合起来才是"不确定度可用"的证据。

### 4.1.3 先失败的是状态，不是学习信号

E2 试了三种 reward：`−surprisal`（过程）、单调距离进步（稠密外部）、到达终点（稀疏外部）。
**三种全部失败**：`−surprisal` 两次退化（agent 学会蹲在最熟的格子里），另外两种学不动
（最好 0.020）。

但继续往下拆，问题不在 reward：

| 版本 | 状态里有什么 | 训练池成功率 |
| :--- | :--- | ---: |
| E3 | 相对终点位移 | **0.140** |
| E4 | + 四邻墙（4 bit） | **0.390** |
| E5 | + 朝向（2 bit 记忆） | **0.740** |
| E7 | + GRU 的隐藏状态 | **0.930** |

**四轮失败链的根因是同一个：状态里没有墙、没有记忆。** 只观测位置的任务是 POMDP，
无记忆策略在原理上解不了；而"沿墙走"本身就需要记住"我在贴哪一侧"。

这条是本节**最可复用**的结论，而且它与 H1′ 无关：任何"策略学不会"的实验，
第一件该查的是状态是否 Markov。

### 4.1.4 H1′ 的两次检验

等两臂都能把任务做到 0.90 之后，H1′ 才第一次成为**可测**的问题。

**E6（表格编码，20 个种子、200 张确认迷宫）**：

> `D_search − D_opt` 的确认集配对差 **中位 −0.015，95% 区间 [−0.045, +0.015]**。

**E7（GRU，2000 张训练迷宫、5 个种子）**：

> **中位 −0.005，95% 区间 [−0.050, +0.050]**。

两次都跨 0，两次点估计都不是正的。E7 时两臂确认集准确率是 **0.900 / 0.910**——
任务被解决了，差别仍然测不出来。

顺带一个方法论上的读数：E5 曾在 5 个种子上给出 **+0.03**，当时很容易被读成"方向对了"；
把种子加到 20 之后它变成 −0.015。**小样本上的方向不是方向。**

### 4.1.5 为什么会这样（推断，不是测量）

下面两条是**解释**，不是本节测到的东西，写在这里是为了让后来的人知道我们想到过：

1. **信用分配的时间尺度错配**：R-STDP 的资格痕迹有效窗口在毫秒到几十毫秒量级，
   而"尝试 → 回溯 → 再尝试"的循环在任务时间上是数百步。延迟到达的学习信号撞上已经
   衰减的痕迹，网络无法把"成功"归因到"正确的搜索步骤"。
2. **回溯的软硬之别**：Transformer 的回溯是"软"的——改注意力权重，之前的状态仍在
   KV cache 里；脉冲实现的回溯是"硬"的——膜电位清零，状态直接丢失。
   这不是实现细节，是两种架构对"状态"的不同承诺。

两条都能被证伪，但都需要新的机制（更长的痕迹窗口、或容量大得多的脉冲工作记忆）才能测。

### 4.1.6 与 Gandhi SoS 的差异

| 维度 | Gandhi SoS（Transformer） | 本项目（脉冲 + 局部规则） |
| :--- | :--- | :--- |
| 过程表示 | 连续文本 / hidden state | 脉冲时序 + 逐神经元状态 |
| 回溯 | 改注意力，保留状态 | 膜电位重置，状态丢失 |
| 信用分配 | 反向传播，跨任意长度 | 局部规则，受痕迹窗口限制 |
| 结果 | H1 成立 | **H1′ 不成立** |

### 4.1.7 我们说什么、不说什么

**可以说**：

1. 在本仓库能支撑的设置里（表格策略、GRU、滑移迷宫、局部规则），**"给过程"相对"给结果"
   没有可测的优势**；
2. 这条线的失败**首先是状态表示问题**，而且这一点被四轮实验逐层定位；
3. 世界模型的不确定度是**可用的**（ρ 0.842、覆盖 5/5），它的问题不在信号本身。

**不能说**：

1. **不能说"脉冲网络不能做搜索"**——只测了一种编码、一种学习规则、一个任务族；
2. **不能说"证明没有效应"**——只能说效应小于当前实验的分辨率；
3. **不能把 §4.1.5 的两条解释当作结论**——它们是推断，没有对应的实验。
