# Paper C 叙事结构（2026-11-04）

**状态：结构落盘，不是正文。** 本文件把已经归档的结果排成论文的章节顺序；数字全部来自
对应 ADR / 结果目录。任何一节在写正文前都要先确认证据仍在仓库里、口径没有漂移。

## 4.1 脉冲 SoS：归档（已证伪）——**正文草稿：[`sec4-1-sos-archive.md`](sec4-1-sos-archive.md)**

**要回答的问题**：把搜索过程（探索、死路、回溯、再试）显式化给脉冲网络，是否比只给
最优结果更容易学？

**证据**：

- E6（表格编码）H1' 区间 `[−0.045, +0.015]`，跨 0；
- E7（GRU 编码）H1' 区间 `[−0.050, +0.050]`，跨 0；
- 两次独立设置的效应量都小于实验噪声 floor。

**解释**：Transformer 的回溯是"软"的（改注意力、保留状态），脉冲实现是"硬"的
（膜电位清零、状态丢失）；R-STDP 的 eligibility 窗口（10–50 ms）与搜索循环的时间
尺度（数百步）错配。**这不是实现问题，是架构差异**（见 ADR-0031 的重开条件）。

**不能写**：不能写"脉冲网络不能做搜索"——只测了这一种编码与学习规则；也不能把
E6/E7 的不显著写成"证明没有效应"，只能说"小于当前实验的分辨率"。

## 4.2 容量轴：归档（已验收）

**要回答的问题**：在事件驱动 e-prop 管线上，加神经元或加连接能不能稳定换来精度？

**证据**（详见 [`sec4-2-scaling-and-saturation.md`](sec4-2-scaling-and-saturation.md)）：

- 8k → 32k（5 epoch）只 +0.5pp；64k 相对 16k **−0.3pp**；
- 换 SHD、10 epoch：8k 0.338 vs 32k 0.348，**+1.0pp**；
- 固定 8k，fan-in 32→128：**0.774 → 0.766**，时间 3.2×；
- 训练一次 update 在 16k 上只要 129.9 MiB；"8 GB 上限"是评测批次的产物。

**结论**：膝点在 8k 附近，饱和不是资源限制。**不能再说"只是规模不够"**。

**限定（2026-11-04 补）**：以上全部在**最后一步读出**下成立。A3 只改读出就把 8k 从 0.759 拉到 0.917（seed 0；三种子中位 **0.899**），
所以 0.83 是"最后一步读出的上限"，不是"容量上限"。**A4 当场复验了规模这一侧**：
同样 28 抽头，32k = 0.914 vs 8k = 0.917（同为 seed 0，−0.3pp）——换掉读出之后规模仍然买不到，
而 S6 那个 +3.1pp 也随读出补全而消失。措辞见 [`sec4-2`](sec4-2-scaling-and-saturation.md) §4.2.10。

## 4.3 脑区特化：第一轮跑完——**+0.3pp，不成立**（可解释的负结果）

**要回答的问题**：同样 8,192 个神经元、同样 fan_in=32、同样总突触数，只改"怎么组织"
（按区分组的阈值/时间常数 + 区内偏置连接），能不能买到精度？

**预注册**：[`research/brainregions/prereg-brain-region-specialization.md`](../../research/brainregions/prereg-brain-region-specialization.md)

**判据**：

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| H_A0 | 两臂都没坏（前置） | 两臂准确率 ≥0.60 |
| H_A1 | 组织买得到精度 | `acc(特化) − acc(均匀) > 3pp`（3 个种子中位） |
| H_A2 | 组织不更密 | 特化臂平均发放稀疏度 ≥ 均匀臂 |

**成本**：2 臂 × 3 种子 ≈ 1.8 小时（sMNIST，2 epoch）。

**结果**（详见 [`../../sweep_results/brainregions_a1/README.md`](../../sweep_results/brainregions_a1/README.md)）：

| 臂 | 三个种子 | 中位 | 稀疏度 |
| :--- | :--- | ---: | ---: |
| 均匀 | 0.759 / 0.762 / 0.763 | **0.762** | 0.8767 |
| 特化 | 0.767 / 0.759 / 0.765 | **0.765** | 0.8776 |

- **H_A0 过**（两臂都 0.76）——这次是**可解释的负结果**，不是 S7 那种两臂贴地板的无效实验；
- **H_A1 不过**：中位差 **+0.3pp**，门槛 3pp；
- **H_A2 踩线过**：0.8776 vs 0.8767。
- 两臂的种子区间**几乎完全重合**（0.759–0.763 vs 0.759–0.767），中位差小于任何一臂的极差。

**写作姿态**：这一节写的是"**这一种组织方案没用**"，不是"组织没用"——只测了 4 类参数原型 +
75% 区内偏置、一个任务、2 epoch、3 个种子。换组织维度（区间方向性、抑制性连接）要新预注册。
论文里 **§4.3 的叙事是负结果**：组织的一个自然变体不足以突破容量膝点。

## 4.4 读出诊断：天花板在读出设计，不在表示、也不在学习规则（A2，已跑完）

**要回答的问题**：8k 管线卡在 0.76，是**表示**不够、**学习规则**不行，还是**读出**丢了信息？

**预注册**：[`research/brainregions/prereg-a2-diagnosis.md`](../../research/brainregions/prereg-a2-diagnosis.md)
（三个探针，同一个训好的网络、同样的 1,000 个训练 / 1,000 个测试样本）

**结果**（详见 [`../../sweep_results/brainregions_a2/README.md`](../../sweep_results/brainregions_a2/README.md)）：

| 探针 | 设置 | 准确率 | 相对 P1 |
| :--- | :--- | ---: | ---: |
| P1 | 在线读出（最后一步，现状） | 0.759 | — |
| P2 | 离线岭回归，**同一组**最后一步特征 | 0.772 | **+1.3pp** |
| P3 | 离线岭回归，全 28 步拼接 | **0.869** | **+9.7pp** |

**判定**：D-0 过（管线复现）；**D-1 不过**（换闭式解只值 1.3pp）→ **D-2 过**（只取最后一步
是瓶颈）→ 表示不是瓶颈。**信息在时序里，我们只读了一帧。**

**写作姿态**：P3 是**诊断**，不是可部署的结果——它用闭式解、吃全部 28 步、单种子、1,000 个样本。
能写的只有"天花板位置"，不能写成"系统精度 0.869"。这条边界要写在正文里，不能只写在脚注。

**下一步（已跑完）**：让局部规则也读多个时间点——见 §4.5。

## 4.5 多抽头读出：8,192 神经元从 0.759 到 0.899（三种子中位；A3）

**正文草稿：[`sec4-3-readout-bottleneck.md`](sec4-3-readout-bottleneck.md)**
（含 A2 诊断、A5 的 SHD 复现、A6/A7 的机制推翻与替换、A4 的容量轴闭合）

**要回答的问题**：把同一套局部规则铺到多个时间点（读出在 `k` 个等距时刻各取一份滤波发放），
能不能吃回 §4.4 那 9.7pp？

**预注册**：[`research/brainregions/prereg-a3-multitap.md`](../../research/brainregions/prereg-a3-multitap.md)
**结果（下表为 seed 0）**：[`sweep_results/brainregions_a3/README.md`](../../sweep_results/brainregions_a3/README.md)

| 抽头数 | 准确率 | 相对 k=1 | 发放率 | 峰值显存 |
| ---: | ---: | ---: | ---: | ---: |
| 1（最后一步） | 0.759 | — | 0.1233 | 757.7 MiB |
| 7 | 0.895 | +13.6pp | 0.1224 | 759.8 MiB |
| 28（每一步） | **0.917** | **+15.8pp** | 0.1187 | 766.2 MiB |

**判据**：A3-0 基准复现 0.759 ✅；A3-1 `acc(28)−acc(1) ≥ 5pp` → **+15.8pp** ✅；
A3-2 墙钟 ≤1.5× → 过，**但这个比值不可用**（三档墙钟随抽头数单调下降，是预热与缓存造成的，
不是真的更快）。可靠的代价口径是峰值显存 **+8.5 MiB（+1.1%）**。

**补种子（修订 1）**：`taps=28` 另跑 seed 1、2，k=1 用 A1 均匀臂现成值。

| 种子 | k=1 | k=28 | 增益 |
| :---: | ---: | ---: | ---: |
| 0 | 0.759 | 0.917 | +15.8pp |
| 1 | 0.762 | 0.873 | +11.1pp |
| 2 | 0.763 | 0.906 | +14.3pp |
| **中位** | 0.762 | **0.899** | **+14.3pp** |

**S-0 不过**（门槛是"seed 1、2 都 ≥0.90"，seed 1 落到 0.873），S-1、S-2 过。
所以**引用时要报中位 0.899、区间 0.873–0.917，不能单引 0.917**；
但"多抽头买得到精度"这条**三种子都成立**。种子噪声 sd **2.2pp**、极差 **4.4pp**。

**机制（事后探针，非预注册）**：

| 在哪个网络上做岭回归 | 单帧 · 1,000 样本 | 全时序 · 1,000 样本 | 全时序 · 4,000 样本 |
| :--- | ---: | ---: | ---: |
| `k=1` 训出的网络 | 0.772 | 0.869 | **0.916** |
| `k=28` 训出的网络 | 0.774 | 0.866 | **0.914** |

**表示没有变好**（同拟合预算下两边一致），变的是**读出终于读了时间轴**。
并且 0.916 说明 §4.4 的 P3 = 0.869 是"1,000 个样本拟合出的下限"，不是表示的容量上限。

**可以写**：局部规则（在线、无闭式解、无批求解）把 229k 参数的读出训到了
4,000 样本岭回归的同一水平（0.917 vs 0.914–0.916）。

**不能写**：

1. 不能写"局部规则超过了闭式解上界"——0.869 从来不是上界；
2. 不能写"多抽头让表示变好了"——探针直接否定了这条；
3. 不能写"更快"——墙钟那一条是预热；
4. 不能写"0.917 是这条管线的能力上限"——单种子、2 epoch、一个任务，
   且抽头数与读出参数数没有分离（57k vs 229k）。

**第二个任务（A5，已跑完）**：同样的 28 抽头放到 **SHD**（20 类、700 通道、T=100）上，
8,192 神经元、10 epoch：**只读最后一步 0.338 → 28 抽头三种子 0.759 / 0.745 / 0.757（中位 0.757），≈ +42pp**
（[`sweep_results/brainregions_a5`](../../sweep_results/brainregions_a5/README.md)）。

涨得比 sMNIST 多三倍。**机制在 A6 里被重新解释过**（见下）：
限制不是"最后一步看见多久"，而是"**每个神经元给出几个数**"。

**对照实验（A6）推翻了第一版解释**：把读出窗口从 20 步拉到 100 步（`decay_out` 0.95 → 0.99），
单抽头只从 0.338 涨到 **0.425**，多抽头的增益只从 +42.1pp 降到 **+28.5pp**，**没有减半**。
窗口拉长 5 倍只买回 8.7pp——所以"看不见的比例"不是主因。

正确的说法：最后一步读出把每个神经元一段窗口内的活动压成**一个标量**；多抽头给的是**多个数**。
A3 自己的阶梯支持这一条——sMNIST 上 `k = 1/7/28` 是 0.759/0.895/0.917，
**从 1 到 7 就拿到 15.8pp 里的 13.6pp（86%）**，而 7 个抽头的窗口与 1 个抽头**完全相同**。

这条把 A3 最大的边界（只有一个任务）补上了：**"读出扔掉十几点"不是 sMNIST 的特殊结构造成的**，
在真正的时序任务上代价更大。

**后续（A4，已跑完）**：同样的 28 抽头放到 32,768 神经元上给 **0.914**，比 8k 同种子的 0.917 低 0.3pp
（8k 的种子噪声 sd 2.2pp、极差 4.4pp，所以这只是"买不到大于噪声的增益"）。
所以"读出是瓶颈"这条**不随规模变化**——加神经元补不上读出丢的信息，
补上读出之后加神经元也不再额外给什么。详见 §4.2.10 与
[`sweep_results/brainregions_a4`](../../sweep_results/brainregions_a4/README.md)。

## 5. SEL：脉冲表达层的尝试与技术路径反思（不是"实现"）

**要回答的问题**：能不能把"换后端模型时语气不变"从 prompt 下沉到脉冲动力学？

**证据**：

- P0 TI-LIF 数值正确（`biosnn_bus.TernaryMembrane` 0.6.0，D=1 与 ALIF 逐位一致）；
- P1 召回、G1 门控均为负结果（hit@1 0.012 vs 词法 0.259；AUROC 0.410 vs 0.825）；
- P2 教师 T4 风格离散 0.5B 0.88×、1.5B 0.76×、3B 0.99×，未达 0.5×；
- P3 391 对教师数据通过 D1–D4；
- P4 五种子：P4-1/P4-2 过，**P4-3 不过**（TI-LIF CE 是 ALIF 的 1.148×，要求 ≤0.90×）；
  P4-4 N/A，P4-5 未做，P4-6 过。

**要写清楚的区分**：

1. **概念成立**：换模型语气不变的产品痛点真实存在；
2. **路径不成立**：在 8 GB 显存、CPU 教师、缺少 tokenizer 对齐的条件下，
   TI-LIF + CWSSA + SSM + KD 的效率不达标；
3. **产品回退**：Phase 2（模板 + 模型混合渲染）保留为回退，默认关；T4 未过，
   不能声称"语气已统一"；
4. **数据去向**：P3 的 391 对可转 SFT，不做蒸馏；另写数据卡与预注册；
5. **远期备选**：ALIF-only SEL，现在不写预注册、不分配算力。

**对应 ADR**：[ADR-0034](../../docs/adr/ADR-0034-sel-distillation-archival.md)。

## 这一结构的总边界

四条硬边界：纯 CIL（ADR-0029）、脉冲 SoS（ADR-0031）、容量轴（ADR-0033）、
SEL 脉冲蒸馏（ADR-0034）。论文的贡献不是"这些方向都失败了"，而是：

> 用一个可核对的负结果集，说明**哪些失败是数据/评测的、哪些是架构的、哪些只是路径的**，
> 并把仍可继续的那一条（组织轴）写成预注册。
