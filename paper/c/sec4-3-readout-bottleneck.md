# Paper C §4.3 草稿：读出瓶颈——8k 卡在 0.76，卡的不是容量（2026-11-05）

**性质：章节草稿，不是最终正文。** 数字全部来自 `sweep_results/brainregions_a1` … `brainregions_a7`
与 `sweep_results/scale_s2` … `scale_s9`；凡本文没测过的，一律写成"未测"。

## 4.3 读出瓶颈

### 4.3.1 我们问的是什么

§4.2 把规模轴走完了：8,192 个循环神经元之后，加神经元和加连接都买不到精度。
于是"系统不够好"不能再用"规模不够"来解释。那一节留下的问题是：

> 容量之外，还有哪一个**设计选择**在压着准确率？

这一节的答案是**读出**——具体说，是"读出取几个时间点"这件事。结论先给：
**在 sMNIST 上它值 14pp，在 SHD 上它值 42pp，而它一个神经元都没加。**

### 4.3.2 先把账算清：读出、表示、还是学习规则（A2）

在一个训好的 8,192 网络（sMNIST、2 epoch、seed 0）上做三个探针：

| 探针 | 做法 | 准确率 |
| :--- | :--- | ---: |
| P1 | 在线读出（现行：只取最后一步的滤波发放） | 0.759 |
| P2 | 离线闭式岭回归，**同一组**最后一步特征 | 0.772 |
| P3 | 离线闭式岭回归，全 28 步拼接 | **0.869** |

**换闭式解只值 1.3pp，换成全时序值 9.7pp。** 学习规则不是瓶颈，**"只取最后一步"是**。

⚠️ **这个 P3 后来被证明是低估的**（见 §4.3.5）：它只用了 1,000 个拟合样本。
同一组特征、把拟合样本加到 4,000，**同一个网络**就到 **0.916**。
所以本节引用 P3 时必须带上这个注记。

### 4.3.3 多抽头：让局部规则也读多个时间点（A3）

改法很小：把读出的滤波发放在 `k` 个**等距**时间点各取一份、拼接起来，
每个抽头用**同一套 e-prop 规则**更新（学习信号各取各的，资格痕迹取各自时刻）。
`k = 1` 就是原来的系统。

sMNIST、8,192 神经元、fan_in 32、2 epoch、seed 0：

| 抽头数 | 准确率 | 相对 k=1 | 发放率 | 峰值显存 |
| ---: | ---: | ---: | ---: | ---: |
| 1（最后一步） | 0.759 | — | 0.1233 | 757.7 MiB |
| 7 | 0.895 | +13.6pp | 0.1224 | 759.8 MiB |
| 28（每一步） | **0.917** | **+15.8pp** | 0.1187 | 766.2 MiB |

**补种子之后（`taps=28`，seed 0/1/2）：0.917 / 0.873 / 0.906，中位 0.899。**
单点 0.917 是三种子里最高的那个，**不能单引**；相对 k=1 的 0.762（A1 三种子中位）约 **+14pp**。

**代价**：峰值显存 +8.5 MiB（+1.1%）。训练墙钟的比值**不可用**——三档墙钟随抽头数单调下降，
是预热与缓存造成的，不是真的更快。

### 4.3.4 第二个任务：SHD（A5）

sMNIST 有个特殊性：它是把**同一张图**按行拆成 28 步喂进去，时序里装的是**空间**信息。
所以必须换一个真正的时序任务。

SHD（20 类、700 通道、T=100）、8,192 神经元、10 epoch：

| 臂 | 准确率 |
| :--- | ---: |
| 只读最后一步（S8） | 0.338 |
| **28 抽头（三种子）** | **0.759 / 0.745 / 0.757，中位 0.757** |

**≈ +42pp**，仍然是单点对照（0.338 只有 seed 0），所以**不能写成"每个种子都涨了 42pp"**。

三个种子只差 **1.4pp**（sd 0.76pp）——比 sMNIST 那边（极差 4.4pp）稳得多，
尽管 SHD 的读出是 `8192 × 28 × 20 ≈ 4.6M` 参数配 8,156 个训练样本。
**"读出太宽会过拟合"这个担心在种子维度上没有出现。**

### 4.3.5 机制：一条被推翻、又被换上的解释

这一节值得单独写，因为它是"预注册 > 事后解释"的一个具体例子。

**第一版解释（A5 时写下，当时只有两个点）**：读数滤波的衰减是 0.95、有效窗口约 20 步，
在 T=28 的 sMNIST 上覆盖 71%、在 T=100 的 SHD 上只覆盖 20%；
**看不见的比例 2.76×、增益 2.94×**——多抽头的增益 ∝ 最后一步看不见的比例。

**检验（A6）**：把这个窗口从 20 步拉到 100 步（`decay_out` 0.95 → 0.99），在 SHD 上重跑两臂。

| decay_out | k=1 | k=28 | 增益 |
| ---: | ---: | ---: | ---: |
| 0.95 | 0.338 | 0.759 | +42.1pp |
| **0.99** | **0.425** | **0.710** | **+28.5pp** |

**窗口拉长 5 倍，单抽头只从 0.338 到 0.425（+8.7pp）；增益只降到 28.5pp，没有减半。**
第一版解释**被推翻**。

**第二版解释（现在用的）**：限制不是"看见多久"，是"**每个神经元给出几个数**"。
`k` 改的是窗口里取几个值，`decay_out` 改的是窗口长度；而**每个神经元始终只有 1 个数**时，
窗口再长也救不回被压扁的轨迹。

**检验（A7）**：补 `k=7` 的两格，看增益是不是主要发生在 1→7。

| decay_out | k=1 | k=7 | k=28 | 1→7 占全部增益 |
| ---: | ---: | ---: | ---: | ---: |
| 0.95 | 0.338 | 0.726 | 0.759 | 38.8 / 42.1 = **92%** |
| 0.99 | 0.425 | 0.657 | 0.710 | 23.2 / 28.5 = **81%** |

**k=7 与 k=1 的窗口完全相同**（窗口由 `decay_out` 定，与 `k` 无关），
所以那 80–92% 的增益**不可能来自"看见更久"**。sMNIST 上的阶梯是同一形状
（0.759 / 0.895 / 0.917，1→7 占 86%）。

**顺带一条同向的旁证**：

| k | decay 0.95 | decay 0.99 | 谁赢 |
| ---: | ---: | ---: | :--- |
| 1 | 0.338 | 0.425 | 长窗口 |
| 7 | 0.726 | 0.657 | 短窗口 |
| 28 | 0.759 | 0.710 | 短窗口 |

只有一个数时窗口越宽越好；有多个数时**短窗口**更好——因为抽头要靠窗口的**形状**区分，
0.99 把相邻抽头抹得几乎一样。

### 4.3.6 与容量轴的闭合（A4）

§4.2 的全部规模实验都用同一种读出。所以 A3 一出，一个必须回答的问题是：
**换掉读出之后，规模是不是就有用了？**

32,768 神经元 + 28 抽头（其余与 A3 的 8k 臂完全一致）：**0.914**，
对 8k 同种子的 **0.917**，**−0.3pp**。

| | 抽头 = 1 | 抽头 = 28 | 读出效应 |
| :--- | ---: | ---: | ---: |
| 8,192 | 0.774 | 0.917 | +14.3pp |
| 32,768 | 0.805 | 0.914 | +10.9pp |
| **规模效应** | **+3.1pp** | **−0.3pp** | |

**S6 里 32k 在 2 epoch 下领先的 3.1pp，在读出补全之后整个消失**——那 3.1pp 本身也是
"最后一步读出"的产物。

⚠️ **分辨率**：A4 只有单种子，而 8k + 28 抽头的种子噪声是 sd **2.2pp**、极差 **4.4pp**。
所以能写的是"规模买不到**大于种子噪声**的精度"，**不能写"规模一点用都没有"**。
预注册把门槛定在 2pp，那个数当时就落在噪声之内——这条弱点照登。

### 4.3.7 我们说什么、不说什么

**可以说**：

1. 在这条事件驱动管线上，**读出取几个时间点**是一个被长期忽略、代价极大的设计选择：
   sMNIST **+14pp**、SHD **≈+42pp**，神经元数一个没变，显存 +1.1%；
2. 这个收益**不是**"看不见的时间比例"造成的（A6 推翻了那条）；
   直接证据是**窗口不变、只增加抽头数就拿到 80–92% 的增益**（A7）；
3. 局部学习规则**没有吃亏**：28 抽头 e-prop（在线、无闭式解、无批求解）在 sMNIST 上
   训出的 229k 参数读出达到 0.917，与 4,000 样本岭回归的 0.914–0.916 持平；
4. 换掉读出之后，**规模仍然买不到精度**（A4），§4.2 的结论在两种读出下都成立。

**不能说**：

1. **不能说"0.899 / 0.757 是这条管线的能力上限"**——单/三种子、两个任务、一个工作点；
2. **不能说"k 越大越好"**——k 只测了 1 / 7 / 28，1→7 是大头，7→28 在 decay 0.99 上还有 5.3pp；
3. **不能说"读出修好了，系统就好了"**——SHD 的 0.757 离该任务的好结果仍有距离（未做外部对照）；
4. **不能把 sMNIST 的 +14pp 与 SHD 的 +42pp 相减**——两个任务的类别数、样本量、序列长度都不同；
5. **不能引用 P3 的 0.869 当"全时序的上限"**——那是 1,000 样本拟合的下限。

**未测**：k 的更细阶梯；decay 的中间值；32k + 多抽头在 SHD 上；多抽头与
更长训练（>10 epoch）的交互；以及**"每个神经元几个数"这条解释在第三个任务上是否仍成立**。
