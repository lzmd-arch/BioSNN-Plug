# Semprea-4.5B 论文规划（2026-11-12 改：**以 SNN 为主体**）

**状态：结构落盘，不是正文。**

**一句话定位**：一篇讲**局部学习规则的脉冲语言模型能做到哪一步、被什么卡住**的论文。
0.5B 是它的规模坐标，三道瓶颈（读出 / 信用分配 / 递推）是它的内容，组合模型只是它的
落地场景之一。

**为什么改**：上一版把重心放在"融合是零结果"。但仓库里真正厚的是 SNN 这一侧——
七轮读出实验、梯度余弦分析、递推电流的两次证伪、以及 8 GB 单卡上 41k tok/s 的系统。
零结果适合做一节，不适合做全文。

## 摘要骨架

1. 问题：**不用反向传播**，能不能训出 5 亿参数级别的语言模型？
2. 做法：逐时刻 e-prop 资格痕迹 + 层次 softmax 树读出 + 局部读出更新，全程无 autograd；
3. 结论一（读出）：这条管线上**瓶颈是读出而不是容量**——多抽头读出在 sMNIST 上
   0.762 → **0.899**、在 SHD 上 0.338 → **0.757（+42pp）**；同期加神经元 8k → 32k 只有 −0.3pp；
4. 结论二（信用分配）：e-prop 的方向与真梯度的余弦只有 **0.80**，不是 1；修掉 ψ 掩码的
   **口径 bug** 与补上读出滤波的反向 EMA 后到 **0.93**，其中掩码修复实测值 **+0.78pp**；
5. 结论三（递推）：在这个工作点上，**任何循环电流都是拖累**（前馈 0.717 vs 校准后 0.698/0.668）；
6. 系统：0.512B、8 GB 单卡 **41k token/s**、显存 **2.34 GB**、ragged 树布局 **1.79×**。

## 1. Introduction

**问题的形状**：纯局部学习规则（无反向传播）在大模型上一直被"能做小任务、上不了规模"的
印象笼罩。这个印象缺的不是观点，是**规模的实测**。

**本文做什么**：把一条具体的局部规则管线（逐时刻 e-prop + 树读出）推到 5 亿参数，并且
**逐层定位它在哪里掉**——不是报告一个终值，而是报告三道瓶颈各自的量级与修法。

**贡献（按可信度排序）**：

1. **读出是杠杆，容量不是**：多抽头读出在 sMNIST +13.7pp、SHD **+42pp**；
   同期加神经元 8k→32k 是 **−0.3pp**。机制：**每个神经元多给几个数**（A7：1→7 抽头拿到
   81–92% 的增益），不是"看见更多时间"（A6 已推翻）；
2. **e-prop 不是精确梯度，但缺口可量化、可部分修补**：余弦 0.80 → 0.93；
   其中 ψ 掩码用错不应期时刻是一个**实现口径 bug**（与仓库另一处正确实现不一致），修完 +0.78pp；
3. **递推在这个工作点上是有害的**，且原因是初始化尺度不是"递推没用"——电流标定到 1.0× 后
   仍比无递推差，单调排序与电流/输入比完全一致；
4. **一个能跑的系统**：0.512B、41k tok/s、2.34 GB，含两个可复用的工程修正
   （batch 归一化的更新尺度、ragged 树布局）。

**不能写**：不能写"局部学习可以替代反向传播"。同口径下 BP 比局部规则高 **9.29pp**
（B0：BP −0.83pp vs bigram、SNN −10.12pp），**缺口就是学习规则本身**。

## 2. 设定

### 2.1 模型

| 项 | 值 |
| :--- | :--- |
| 隐层 | 全前馈 LIF（e-prop 资格痕迹），N = 7,812；可选 ALIF |
| 读出 | 层次 softmax（Huffman 树），32,000 词表，加权深度 11.80 / 最深 75 |
| 参数 | 0.512B（读出 0.500B） |
| 词表来源 | 千问词表的 32k 子集（**千问不改**，两边分布可直接相加） |

### 2.2 学习规则

- `v ← α·v + I − z·θ`，`z = 1[v ≥ θ]`；
- 资格痕迹逐时刻累加，**ψ 掩码的判据是"上一步之后"的不应期计数器**；
- 读出更新是局部的：每个内部节点只按自己的二分类标签改；
- **全程没有 autograd**（有守卫测试：把 `.backward()` 引进这条路径会红）。

### 2.3 任务

| 任务 | 用途 |
| :--- | :--- |
| sMNIST / SHD | 读出与容量的受控对比（有明确天花板，好判） |
| 真中文文本（SkyPile → FineWeb-2） | 规模化与系统指标 |
| 合成模板语料 | 与 bigram 的可控对照 |

## 3. 瓶颈一：读出

**主表**（多抽头读出，k = 1 / 7 / 28）：

| 任务 | k=1 | k=28 | 增益 |
| :--- | ---: | ---: | ---: |
| sMNIST（三种子中位） | 0.762 | **0.899** | **+13.7pp** |
| SHD（三种子中位） | 0.338 | **0.757** | **+42pp** |

**机制**：不是"看见更多时间"，是"**每个神经元给出几个数**"。A6 把读出衰减 0.95→0.99，
增益只降到 28.5pp（若是"看不见的时间比例"驱动，应当大幅缩小）；A7 补 k=7，
1→7 抽头就拿到 **81–92%** 的增益。

**同期容量轴**：8k → 32k **−0.3pp**（sMNIST）、SHD 上 32k+28 抽头 **−0.9pp** 且峰值显存
9,960 MiB 装不进 8 GB。⇒ **"只是规模不够"在这条管线上不成立**。

**多时间尺度读出**（语言模型侧）：单 EMA → 4 个 τ 在合成语料 **+4.88pp**、真语料 **+3.88pp**；
8 个 τ 相对 4 个 τ 只剩 +0.93pp（**边界饱和**）。

## 4. 瓶颈二：信用分配

**测量**：e-prop 的方向与整段 BPTT 的 `dL/dw_in` 的**余弦**。

| 变体 | 随机初始化 | 训练 200 步 |
| :--- | ---: | ---: |
| `eprop`（现状） | 0.815 | 0.816 |
| **F1** ψ 掩码改用上一步的不应期 | 0.816 | **0.860** |
| **F1 + F2** 读出滤波的反向 EMA | **0.923** | **0.932** |

**F1 是 bugfix，不是臂**：`TokenEProp.step` 用的是**本步更新之后**的不应期，而仓库另一处
（`research/eprop/traces.py`）的 docstring 明确写死要**上一步之后**，并注明用错会让痕迹偏 ~20%。
只有 LM 这条线用错。**修完实测 +0.78pp**（top-1 0.1215 vs 0.1138，在噪声正边缘）。
**历史口径**：R0–R11 全部在错误掩码下跑出，引用时必须带这句。

**残余缺口**：F1+F2 之后仍差 ~0.07，怀疑是痕迹缺复位调制。**cos → Δ 的映射未知**，
不能把余弦写成性能承诺。

## 5. 瓶颈三：递推与初始化

**发现**：早期的递推臂从初始化起就带着 **2.16×** 于输入的电流，等于顶着噪声上场；
把递推整个拿掉之后，前馈 LIF 第一次赢过 bigram（CE 1.139 / top-1 0.717）。

**然后是证伪**：把电流标定到 0.5× / 1.0× 后，两臂**仍比无递推差**（0.698 / 0.668 对 0.717），
单调性与"递推/输入电流比"完全一致；零输入发放率全为 0（不是自持振荡）。
⇒ **在这个工作点上，前馈 LIF + 局部读出最优，任何循环电流都是拖累。**

**跨任务不外推**：A9 在 sMNIST 上去掉递推只差 +0.5pp（−1.3/+1.7/+1.2 逐种子）。
那个斜率不能搬到 LM 上。

## 6. 系统

| 项 | 值 |
| :--- | ---: |
| 参数 | 0.512B（读出 0.500B） |
| 吞吐 | **41.0k token/s**（batch 256 × window 192，8 GB 单卡） |
| 显存峰值 | **2.34 GB** |
| ragged 树布局 | **1.79×**（矩形按最深 75 层补位，真实路径平均 11.8 层） |

**两个可复用的工程修正**：

1. **更新的 batch 归一化**：`w_in += epsᵀ @ post` 是**对 batch 求和**，不是平均。
   直接套用在小 batch 上调好的学习率，在 batch=1024 时把隐层打崩
   （发放率 0.0087 → 0.0006、CE 8.2 → 51.4）。正确写法是 `lr × 16/(batch × scale)`。
2. **ragged 布局**：Huffman 树最深 75 层，真实路径平均 11.8 层；按最深补位会让绝大多数
   算力花在"走 -1 的填充"上。

## 7. 它做不到什么

- **同口径下 BP 高 9.29pp**（B0），且 CE 与 top-1 **反向脱钩**：BP 的 CE 9.31 比均匀分布
  （6.69）还差——几乎完全记住训练集，测试集上成了"自信地错"；
- **没有注意力 ⇒ 没有 in-context learning**：架构天花板，不是调参问题；
- **top-1 在真文本上是个位数到十几个百分点**，它不产生回答。

## 8. 在组合系统里的角色（一节，不是全文）

Semprea-4.5B = 冻结的千问 3-4B（只出分布）+ 本模型（快半）。融合在输出分布上做：
`score = log q + α·log p`，跨分词器靠字符串前缀归并，**α 默认 0（此时逐位等于云端）**。

**测量结果**：文本-only 条件下 **α\* = 0 且剂量–反应**（α ∈ {0,0.1,0.25,0.5,1}：
top-1 0.225 → 0.075），互补性 **F-0 = 0/30**。机制是两侧吃同一份公开语料、无信息不对称。

**唯一可能让 α 离开 0 的是传感器通道**（环境/设备状态，云端拿不到），
但**配对的（传感器, 文本）数据今天不存在** ⇒ 这一条**无法测**，不是测出来没用。

**落地**：断网时真正服务的是**检索直出**（原文 + 明确标注"未经模型改写"），
不是让弱模型假装回答。
