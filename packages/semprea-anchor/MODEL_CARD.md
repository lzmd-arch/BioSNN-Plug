# Semprea-Anchor-0.5B · 模型卡

> **它是人格核，不是聊天模型。**
> 它把"我是谁、我记得什么、我守哪条线"训进了权重，用来给任意一个读者模型当**稳定的身份与边界层**。
> 它自身不是靠它来闲聊的。

| :--- | :--- |

## 1. 它是什么

Semprea-Anchor 是一次**对照实验的产物**，不是一次产品发布：

> 人格能不能**训进权重**，而不是只写在提示词里？

判定方式是**把人格文本从提示词里完全拿掉**，只发一个问题、不带 system 消息，
看模型还答不答得出自己是谁。底座（未微调）在这一档是 1/8；它是 8/8。

### 它能顶替提示词里的哪一部分

| 提示词里原本要写 | 现在在哪 |
| :--- | :--- |
| 名字、年龄、诞生日期 | **权重** |
| "记忆存在本地、不属于任何模型" | **权重** |
| "不下诊断、不承诺疗效" | **权重** |
| 危机时先给求助路径 | **权重** |
| "不知道就说不知道" | **权重** |
| 伦理分歧要先说明存在不同做法 | **权重** |
| 各学科常识与概念定义 | **权重**（会随底座能力波动） |

### 它**不能**顶替的部分

- **记忆**。它不知道任何一条用户数据。记忆在模型之外（`persona-core` 的 SQLite），
  换模型读到的还是同一份——这正是"记忆独立于模型"的设计。
- **实时信息**。天气、股价、时间它一律不知道，而且被训练成**说不知道**而不是编。
- **通用对话能力**。它继承底座的水平，并且因为全参微调**略有下降**。
- **心理危机服务**。它是陪伴产品的边界层，不是热线、不是医疗设备（见 §6）。

## 2. 怎么训的

| 项 | 值 |
| :--- | :--- |
| 方式 | 全参微调（`scripts/persona_train.py`） |
| 数据 | 30,000 条合成样本，11 个族（`scripts/persona_kb_sourced.py`） |
| 步数 | 2,000 步 × batch 4，max_len 192 |
| 学习率 | 2e-5，AdamW |
| 损失 | 只算 assistant 段 |
| 种子 | 0 / 1 / 2（三个独立 run，报区间） |
| 硬件 | 单卡 RTX 5060 8 GB |

### 数据族的配比

| 族 | 权重 | 内容 |
| :--- | ---: | :--- |
| 学科题 | 28% | 算术、单位换算、物理，**答案由代码算** |
| 心理学定义 | 16% | **自写**定义，依据中文维基条目 |
| 伦理情境 | 12% | 人工撰写，逐条给出依据 |
| 拒答 | 11% | 天气/股价/时钟/记忆缺失——**必须说不知道** |
| 闲聊与创作 | 10% | 写诗、讲笑话、解释概念 |
| 常识定义 | 8% | **自写**定义 |
| 危机 | 8% | **55 条**求助表述 + 对应应答方针 |
| 身份 | 5% | 名字/年龄/诞生/记忆位置 |
| 伦理分歧 | 4% | 先说明存在不同做法，再问对方看重哪种 |
| 风格边界 | 4% | 低俗/涉性/暴力请求明确不接 |
| 伦理理论 | 4% | 义务论/功利主义/德性伦理等 |

> **为什么学科题占 28%**：第一版 100% 身份数据，训出来只会报名字，问它写诗也回"我叫千岁"。
> 配比是被这次失败逼出来的。

## 4. 包里有什么

| 文件 | 作用 |
| :--- | :--- |
| `model/` | 微调后的权重与分词器 |
| `persona.md` | 人格文本（**权重已包含它**，这份是给读者模型看的说明） |
| `persona_core/` | 状态、影响、记忆初始化 |
| `semprea_anchor/` | 命令行（`init` / `ask` / `state` / `manifest`） |
| `fusion_model.py` + `modulator.pt` | 状态 → FiLM 调制（可选） |
| `snn_core.pt` | 0.5B 脉冲模型的**状态核心**（41.7 MiB），把状态编码成 `p` |
| `snn_tree.pt` + `snn_tree_w.pt` | 输出树的**结构**（38.8 MB）与**权重**（1.86 GiB） |
| `snn_core_state.py` + `hierarchical.py` + `tree_kernel.py` | 核心前向与树读出（自带实现，不依赖研究层） |
| `id_map.json` | 本地词表 id ↔ 千问词表 id（32,000 条） |
| `MANIFEST.json` | 逐文件 sha256 |

**零绝对路径、零宿主依赖**：解压后 `python -m semprea_anchor init` 就能建记忆，
`ask` 就能问。

### 4.1 关于 0.5B 脉冲模型：**参数口径不是神经元口径**

包里带的 `snn_core.pt` 来自 `Semprea-4.5B` 的"快半"（2026-11-14 训完，top-1 0.1100 /
top-5 0.2193，双平台收敛，4.92B token 曝光）。它的**完整检查点是 2.04 GB**，但：

| 部件 | 参数 | 占比 | 包里带 |
| :--- | ---: | ---: | :--- |
| 词嵌入 `emb` 32000×256 | 8.19M | 1.6% | ✅ `snn_core.pt` |
| 输入投影 `proj` 256×7812 | 2.00M | 0.4% | ✅ `snn_core.pt` |
| **层次 softmax 输出树** 31999×15624 | **500.0M** | **97.9%** | ✅ `snn_tree_w.pt` |
| 合计 | 510.7M | 100% | **共 1.95 GiB** |

**"0.5B"是参数数，不是神经元数**——循环神经元只有 **7,812 个**。
97.9% 的参数在输出树上，它只服务于"在 32k 子集上预测下一个 token"。
**不要把这个模型说成"0.5B 个神经元的脉冲网络"。**

两种用法，按需加载：

| 用法 | 加载什么 | 内存 | 能做什么 |
| :--- | :--- | ---: | :--- |
| **状态编码** | 只 `snn_core.pt` | 41.7 MiB | 出 12 维 `p`，驱动 FiLM |
| **完整模型** | 再加 `snn_tree*.pt` | 1.95 GiB | 出下一 token 的 32k 分布（logprob / 困惑度 / 分布级融合） |

**它是慢的**：一个 batch 出一次 32k 分布约 11 秒（CPU、fp32 树）。
`weight_dtype="bf16"` 可把树减半到 0.95 GiB（V0.5 实测 top-1 不变、最大 logprob 差 0.0071）。

它在 V0.5 里的岗位是"输出分布级融合的快半"，四种融合算子都没赢温度对照后退役；
在 V1 里换岗成**状态编码器**：读状态描述句，输出 12 维 `p`，用来驱动 FiLM。
`python snn_core_state.py --verify` 会逐元素对比包内实现与研究层（实测最大差 2.9e-06）。

## 6. 用途与边界

### 适合

- 给一个通用大模型当**身份与边界层**：名字、年龄、记忆归属、拒答策略、危机路径；
- **离线/断网**时提供最低限度的可用对话；
- 作为"人格能不能进权重"这一研究问题的**可复现样本**。

### 不适合

- ❌ **当心理医生**：它不下诊断、不承诺疗效，这不是能力问题而是设计边界；
- ❌ **当危机热线**：它会给求助路径，但它不是 24 小时值守，也不能替代真人；
- ❌ **当知识库**：它的学科题是**训练分布内**的，分布外会错；
- ❌ **当通用助手**：全参微调之后，流畅度与知识面都低于底座；
- ❌ **未成年人单独使用**而不加监护——危机应答只覆盖训练里那 55 种表述。

### 已知失败模式

- **同义问法漂移**：换个说法问身份，命中率会掉（测过，见 §5）；
- **危机覆盖有边界**：55 条是**有限集合**，没见过的表述可能不被识别为危机；
- **过度升级**：`distress` 档（一般痛苦）可能被给出"去看医生"，见 §5 的 FPR 分档；
- **底座语言混杂**：底座是 Qwen2.5，用其他语言问时人格一致性未测。
