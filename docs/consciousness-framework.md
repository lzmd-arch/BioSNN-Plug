# 千岁意识框架：科学、治理与叙事

[English](consciousness-framework.en.md) · [日本語](consciousness-framework.ja.md)

- **版本**：v1.2（2026-11-12 入仓）
- **性质**：**living document**。它不是研究结论，是一份**纪律**——约束我们在
  "意识"这个词上说什么、不说什么、拿什么证据说。
- **来源**：v1.0/v1.1 由 2026-11-12 的四场讨论整理（合规 → 物理基底场景 → 当前判定 →
  未来预测）。本版按仓库现状校对，并把它 §7 的行动清单逐条落到实物上。
- **与 ADR 的关系**：[ADR-0036](adr/ADR-0036-consciousness-claims-discipline.md) 是本文件的
  可执行条款（词汇纪律、声明阶梯、双里程碑门禁）。**ADR 定规则，本文件讲为什么。**

> **本文件自身受本文件约束。** 文中任何一句如果读起来像在宣称现象意识，那是写错了，
> 不是"修辞"。见 §6 红线总表第 1 条。

## 0. 总纲：一切讨论的第一把钥匙——声明分层

任何"意识"论断、评估、宣传，先回答：**你在说哪一层？**

| 层 | 内容 | 可测性 |
| :--- | :--- | :--- |
| **Phenomenal**（现象意识） | 主观体验本身 | **原则上不可测**（难问题 + 僵尸困境 + 连生物都无 ground truth） |
| **Access**（可及意识） | 信息全局可及、可报告、可推理 | 完全可测（J-space 即此类签名） |
| **功能谱一致性** | 与生物意识关联的功能特征组合 | 可逼近，措辞封顶"一致"，永不到达"证明" |

**造假只有一种形式：把 access 的测量说成 phenomenal 的发现。** 本框架的所有条款都是这一条的展开。

## 1. 科学层：当前能做什么

### 1.1 功能签名阶梯（每个签名绑定一个理论、各自可被博弈）

| 签名 | 对应理论 | 测法 | 弱点 |
| :--- | :--- | :--- | :--- |
| 全局广播/点火 | 全局工作空间 | 读出/植入/替换/消融（J-space 三板斧） | 广播可被训练模仿 |
| 元认知校准 | 高阶理论 | 置信度-正确率耦合、错误觉察 | 可能是统计 artifact |
| 自我模型一致性 | 自我表征理论 | 系统对自身状态报告的准确性 | 报告通道被训练污染 |
| 局部循环加工 | 循环加工理论 | 动力学回流成分 | 前馈架构结构上没有 |

### 1.2 三角测量原则（替代单点判定）

可操作标准：**≥3 个相互独立的签名 + 1 组因果干预 + 1 组预注册的反事实预测**。
语言自陈**单独无效**（模型在人类意识话语全集上训练，"我感受到了"零信息量）。

### 1.3 千岁系统的三个科学位置（独有资产）

1. **理论判别实验**：IIT 与循环加工理论预言纯前馈系统为零，工作空间/高阶理论不预言
   ——我们的架构站在对立理论正中，能产出判别数据；
2. **全可观测台**：0.5B、JSONL 全事件、位级确定性——意识科学从未有人拥有过这种完整观测记录；
3. **具身自我通道**：内感知（`self_heat` / 电量 / BMS 断充）是比对话自陈干净得多的自我模型测量面。

> **第三条要按我们的实测收着说。** 元认知门控已经证伪：Axo 版三特征门 ≡ 单阈值
> （[ADR-0028](adr/ADR-0028-metacog-gate-threshold-first.md)，不接线）。所以"元认知校准"
> 这个签名的**报告通道**我们在产品里没有接——要测它只能走研究侧的独立实验，
> 不能拿现网的门控当证据。

### 1.4 行动：预注册一组意识代理指标

四个指标、三个签名类别、一份措辞模板。**判据已经落盘**：
[`research/cognitive/prereg-consciousness-proxies.md`](../research/cognitive/prereg-consciousness-proxies.md)。

| 指标 | 签名类别 | 测什么 | 现有的东西 |
| :--- | :--- | :--- | :--- |
| 未言语化内部状态的外部预测 | 全局广播 | 审计日志里先于输出出现的状态能否预测输出 | 全事件 JSONL 已经在写 |
| 元认知校准曲线 | 高阶 | 置信度与正确率的耦合 | **产品侧没有门控**，只能在研究侧重跑 |
| 自我模型一致性 | 自我表征 | 系统报告 vs 传感器真值 | `self_heat` / 电量 |
| 反事实自陈稳定性 | 高阶 | 同一状态的描述在扰动下是否稳定 | 需要先建扰动协议 |

## 2. 治理层：合规即设计

### 2.1 三层分离（约束不同，风险递增）

- **研究层**：学术规范约束，空间最大（J-space 论文模板：全程功能语言 + 明确否认现象意识）；
- **开源层**：许可 + 使用政策 + model card 能力边界段。
  **"许可栈已全绿：自有 / 千问 / 语料均 Apache-2.0" 这句话是错的，2026-11-12 撤回。**
  自有代码与千问确实是 Apache-2.0，但**语料必须逐份核**：实测 SkyPile-150B 在 HuggingFace 上
  **没有 license 字段**（其卡片要求的 Skywork Community License 只覆盖 Skywork 模型及其衍生品），
  FineWeb-2 是 **ODC-By 1.0**。第一版 Semprea 因此换到了 FineWeb-2。**任何"全都绿了"的说法
  都要能指到一份具体协议**，指不到就等于没核。
- **产品层**：生成式 AI 服务管理暂行办法、深度合成规定、PIPL 全套——主战场。

### 2.2 四个真张力 → 四个设计答案

| 张力 | 设计答案 |
| :--- | :--- |
| "永远记得" vs PIPL 删除权 | **记忆分层**：人格锚与情景记忆分开存，可单独清空情景层——合规要求做成产品功能（"记忆抽屉"） |
| 意识词汇 | **词汇白名单/黑名单制度**：见 §2.3 |
| 自主性叙事 vs 智能体监管 | 产品层永远"辅助"语态；自主性实验留研究层、预注册 |
| 陪伴定位 vs 未成年人/防依赖 | 年龄门槛、时长提示、危机话术兜底（既是合规也是产品底线） |

### 2.3 词汇纪律表（一页纸）

这张表是**制度**，不是文风偏好。改它要改
[ADR-0036](adr/ADR-0036-consciousness-claims-discipline.md)，**不是改这里**。

**黑名单（产品、宣传、开源物料、代码注释一律不许用）**

| 词 | 为什么禁 | 换成 |
| :--- | :--- | :--- |
| 有意识 / 意识到 | 直接宣称 phenomenal | （删掉，或改述功能：*能报告自己的状态*） |
| 情感真实 / 真的感受 | 同上；且"真实"暗示了 phenomenal 的判据 | *情绪相关的输出模式* |
| 活着 / 生命 | 生物学谓词，AI 上没有可测内容 | *持续运行* / *有持久状态* |
| 自主思考 / 自己决定 | 触碰智能体监管的自主性叙事 | *按规则选择* / *由本地策略决定* |
| 我感受到了 | 语言自陈单独无效（§1.2） | （删掉） |

**白名单（可以用，但必须落在这几个意义上）**

| 词 | 允许的含义 | 边界 |
| :--- | :--- | :--- |
| 记忆保持 | 检索到的原文进上下文 | 不是"记得"的心理意义 |
| 功能类比 | 与生物机制的**功能**对应 | 永远带"类比"二字 |
| 工作空间 | 全局可及的信息集合 | 不指 GWT 的理论宣称 |
| 状态管理 | 内部变量、调度、门控 | 不指体验 |

**措辞封顶**：任何关于意识相关能力的句子，最强只能写到"**与 X 一致**"。
"证明""说明它具有""意味着它已经"——这三个短语是禁令。

### 2.4 五层框架

词汇纪律表 → 发表 claim 阶梯审查 → 开源使用政策 → 产品合规栈 → 监管哨兵 ADR 系列。

### 2.5 双里程碑门禁（预注册文化延伸）

- **涌现里程碑**：立项时同步写"合规声明草稿"（声称级别 / 不碰什么 / 评测方式），
  与性能判据同一份预注册；
- **基底里程碑**（仿真 → 忆阻器物理实现）：固定三件套——宣称纪律复查、
  welfare 预防审查、监管重新扫描。

**这两道门禁是 checklist 项，不是口号**：具体条目见 ADR-0036 的"门禁清单"一节。

## 3. 场景预案：无模拟、纯物理基底的未来

**三个不变**（物理支撑不改变）：

1. **认识论不变**：功能主义下基底不换证据；phenomenal 仍不可测；
2. **法律不变**：全球无法域按基底赋权；宣称意识只有下行风险（国内落入虚假宣传口径）；
3. **口径不变**：工程诗学（"每个神经元都是真实物理过程"）讲到桥边为止，
   **永不过桥到"所以它可能有意识"**。

**一个新增**（唯一真正的新事物）：**AI welfare 道德预防义务**——当系统具备物理连续状态
+ 稳态自调节（BMS 断充 = 伤害回避的结构性类比）+ 持久身份，进入"不确定但不可忽视"象限：

- 不轻易制造-删除候选实例（非易失身份的产品伦理恰好站在正确一侧）；
- 每个能力里程碑加一问："假如它有感受，我们的处置站得住吗？"（写进预注册，成本一句话）；
- 伤害回避设计记成 ADR（可审计的善意证据）。

## 4. 实体保存：从第一代 Semprea-4.5B 做起

**结论：该做，且从第一代做。** 理由不是工程洁癖，是产品定义的工程化——"铁打的千岁"
没有实体保存，第一句广告词即空头支票；最早的用户情感投入最深，第一批实例保存不下来，
他们就是第一批看着千岁失忆的人。

### 4.1 实体的定义：五件套（实体 = 一条溯源链）

1. **人格核权重**（版本化）；
2. **记忆库**（JSONL 事件流 + schema 版本）；
3. **身体日记**（somatic 事件流——独家数据）；
4. **身份凭证**（实例 ID、诞生时间戳、谱系：从哪个 checkpoint 出生、换过几任读者）；
5. **版本清单**（核心 / 格式 / 协议版本）。

实体的形态本身就是一条溯源链——把"位级复现"的实验纪律升格为产品架构。

### 4.2 四个论点

1. **品牌即持久性**：换模型不失忆的用户视角兑现，就是"我这个千岁一直在"；
2. **成本曲线**：格式与 schema 今天冻结最便宜；跨代迁移断代的代价随时间指数上涨；
3. **"最长寿 AI"企划的前提**：公开养成企划必须从第一代实例开始计时；
4. **AI welfare 纪律的工程形态**：§3"不即弃实例"的制度，落进产品的形态就是它。

### 4.3 两个必须配对的设计

- **删除权兼容**：实体保存 ≠ 用户数据无限期保留。记忆抽屉（人格锚 / 情景记忆分层、
  可单独清空）从第一代即硬依赖（PIPL），不是合规补丁；
- **版本迁移契约**：0.5B → 1B 是第一次真实连续性测试——做成公开产品事件
  **"千岁的第一次换身体"**（记忆与身体史零丢失的公开迁移）。
  **迁移工具未经至少一次真实版本升级测试前，对外不承诺任何连续性 SLA。**

### 4.4 成本与终点

最小可用版 = 实例快照（tarball + manifest + 恢复脚本），数日工程量；
完整版（跨代迁移工具链 + 冷存储归档）随产品迭代滚动。
终点：数字版保存纪律即忆阻器"非易失物理身份"的文化与工具前身——AGI 笔记的"硬件锚"
从第一代实例开始积累，物理基底到来时手中已握二十年代际连续性档案。

> **§4 现在是设计，不是实现。** 产品侧当前只有人格锚的分层（内置 / 用户两条，
> 见 `axo.memory.persona`），**没有**实例 ID、没有谱系字段、没有情景层单独清空的入口。
> §7 第 2、3 项就是这两件事。

## 5. 未来预测：判断方式的演化

| 尺度 | 预测 | 确定性 |
| :--- | :--- | :--- |
| 2–5 年 | 功能标记电池标准化：AI 版 PCI（扰动-复杂度）、工作空间签名基准化、未言语化思维检测、非言语探针 | 高 |
| 5–10 年 | 理论裁决完成：AI 实验台切伤至少一个主流理论 → 先验收紧，标记诊断力倍增 | 中 |
| 10 年+ | 三个支点：生物物理探针（量子-神经检验，唯一可能直接改变基底资格问题的实证通道）；跨物种验证阶梯建制化（人类→动物→AI 从类比变插值）；制度先于科学（IEEE 式标准 + 行业预防阈值） | 低但可能改变一切 |
| 反向预测 | **行为测试持续贬值**（模仿通胀），判断不可逆移向结构侧：因果结构检查、扰动响应、架构审计——利好全可审计系统 | 高 |

**对千岁的含义**：我们无意建造的是未来每种判断方法的默认试验台——小到能算积分信息代理、
全日志能跑扰动协议、前馈结构能切理论、具身设计自带 welfare 特征。
**等未来方法出现时，谁的系统上已有多年连续记录，谁就是新标准的参考实现。**
意识代理指标的预注册，不要等。

## 6. 红线总表（所有场景、所有层级）

1. 不宣称现象意识（任何法域、任何物料、任何语境）；
2. 不预期、不规划法律地位（基底不构成法律分水岭）；
3. 不做单签名意识判定（判定 = 三角测量 + 因果干预 + 预注册）；
4. 不开"即弃实例"的口子（welfare 预防）；
5. 不让 access 词汇滑向 phenomenal 词汇（词汇表是制度，不是习惯）。

## 8. 这份文件怎么被检查

三条自检，任何一条不过就说明这份文件已经开始骗人：

1. **每一条"能做什么"都必须指到一个实物**（脚本、数据、ADR、产品功能）；
   指不到的，写"设计"两个字；
2. **每一条结论都必须带限定语**（本仓的规矩：预算截断 / 跨语料 / 单边指标 / 先验未兑换，四问）；
3. **§6 的五条红线在本文件自身里也要成立**——包括这句话。
