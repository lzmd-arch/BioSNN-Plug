## 2. 実行層：なぜスパイク版ができなかったか

### 2.1 修正後の主対照（2026-10-18 以降）

> 同じシードでも二回の軌跡が違っていました。

三本のスパイク・アームは**区間が完全に重なり**、互いに区別できません。

### 2.2 診断の連鎖（D3–D18）

| ラウンド | 問い | 答え |
| :--- | :--- | :--- |
| D3 | 読み出しを替えれば（rate vs count）救えるか | 救えない（65.2 / 9.55） |
| D4 | 方策は状態に依存するか | 学習後の slope はすべて 0 |
| D5–D6 | 出力の崩壊／温度で直るか | エントロピー崩壊。温度でエントロピーは直るが末次は 9.5 のまま |
| D7 | 劣化を帰属できるか | 5/5 `unattributed` |
| D8 | 末期の読み出しに状態情報は残っているか | 5/5 `no_state_information` |
| D10 | 差の方向は存在するか | **ある**（4/5）。ただし相対的な大きさは **0.5%–7.3%** のみ |
| D11–D13 | しきい値・予算・別の読み出し（低域通過率・膜電位） | 足りない（最良でも 0.7–3.45 カウント、しきい値 2） |
| D14 | K 窓平均 | **唯一効くレバー**：0.57→2.12（K=1→8）。ただし 5/5 で 3/5 止まり、窓を伸ばしても利得なし |
| D15 | 初回発火潜時 | カウントが 0 のシードでは信号あり、ただし <2 のまま |
| D16 | 差の方向を状態平均に対して直交化 | 符号は零を跨がない（0/5） |
| **D17** | **上流の確認：エンコーダは極角に敏感か** | **2.9% のみ**（cos 0.9988）、他三軸は 1.1–1.4 → D4/D8/D9 の slope=0 はほぼ変化しない次元で測っていた |
| **D18** | **軸ごとの正規化後に再測定** | Δ の極差中央値 0.2 → **6.2（30 倍）**、読み出しは状態を見えるようになった。しかし **slope は依然 0/10 が正、末次中央値も 9.85**（seed 4 = 269.1） |

**一行で**：読み出しが状態を見えるようになっても、**方策は状態に応じて変わらない**——
欠けているのは**学習信号**であり、読み出しでも大きさでも雑音でもありません。

連鎖の全体は [`sweep_results/stage3_readout_audit.md`](../sweep_results/stage3_readout_audit.md) に。

## 4. 境界（上の数字を読むときに知っておくこと）

- ネットワークは **256 個のスパイクニューロン**、計画書 §2.2 の目標は約 5 万——**約 195 倍**の差；
  8 GB での実測上限は約 **1.35k** 循環ニューロン；
- 動作点は **L1 正規化（各列 L1=1）＋しきい値 1.0**。他の動作点は測っていません；
- D17 以前の診断のいくつかは**極角**という、入力側ではほとんど変化しない次元で行っています——
  古い結論はその注記とともに読んでください；
- 「再学習 3×」の 0.957 は**ペア中央値**であり、単発の最良値ではありません。

## 5. アーカイブと再開

**アーカイブ済み**（ADR-0029）：純 CIL、W3 スパイク actor。

**再開条件**（ADR-0029 より、検証可能な形で）：

| ライン | どの証拠があればアーカイブが無効になるか |
| :--- | :--- |
| スパイク actor | 規模実験（5k–8k ニューロン）で、読み出しの制約が「レート読み出し」ではなく**規模**に由来すると示される |
| 純 CIL | **本物のタスク境界**を持つ長い系列で、タスク推論が **0.8** に達する |

**2026-11-02 に追加した第三の条件（D18 より）**：変えるのが**学習信号**（読み出し・大きさ・雑音ではない）
なら、それはもはや「第 3 フェーズの再開」ではなくスパイク SoS——いまのメインラインです
（[ADR-0030](adr/ADR-0030-mainline-shift-to-spiking-sos.ja.md)）。
言い換えれば：**実行層のこの項目は「もう一度調整する」では埋まらず、「学習信号を変える」によってのみ継承されます。**

### 本レビューの結論（2026-11-02）

**第 3 フェーズの実験は再開しない。** D18 がすでに欠落を学習信号に特定しており、学習信号を変えることこそ
スパイク SoS の定義です。SoS の事前登録が落ちるまで、この項目はアーカイブのままにします。
