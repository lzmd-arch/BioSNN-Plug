> 主線テーマ：**人格保持**（persona persistence）——千歳の堀そのもの。

## 一、人格保持（主線）

人格保持 = 記憶保持 + 文体の一貫性 + 同一性の連続。五つのクラスタ：

| クラスタ | 内容 | 出所 |
| :--- | :--- | :--- |
| **能力** | 記憶の語り（「あなたたちの物語を語れる」）／情動知覚（覚醒チャネル ADR-0016、プロンプト工学ではなく力学による変調）／主体性（A1-A2 の階段）／意見を持つ人格一貫性（断れる・切り上げられる——依存防止は能力であってコンプライアンスの継ぎ当てではない）／歌唱 | 陪伴能力の議論 |
| **計測** | キャラクタ指標（記憶保持・文体一貫）；遅延再生プローブ（N≈16→90%、N≈64→50%、N≥128 は偶然）；**同一性距離**（行動一貫性＋表象類似＋記憶プローブの合成）；連続性テスト | 実験ライン |
| **機構** | 実体五種の道具立て（重み／記憶庫／身体日誌／身分証／版目録）；記憶の引き出し（削除権と両立）；移行契約；四つの公開移行イベント（モデル→身体→機器→基体） | 実体保存の枠組み |
| **研究フロンティア** | **状態モダリティ論争**（文字状態かスパイク状態か——人格保持の機構論争、§五）；**改善–漂流パレート前沿**（テセウス問題の計測可能化） | 文献戦線／自己反復 |
| **倫理境界** | プライバシー階級（生体データ > カメラ）；依存防止設計；死と承継（デジタル遺産）；意識語彙の規律 | 意識の枠組み |

話題の錨：「**脳を一度取り替えても、まだあなたを覚えている**」（一般向け）＋「0.038%」（技術向け）。

## 二、陪伴能力とモダリティ（11-12 夜）

- **能力五強**：記憶の語り／情動知覚／主体性／意見を持つ人格一貫性／歌唱。加えて必須の安全能力二つ：危機の識別と紹介、未成年保護。
- **モダリティ欠落の診断**：出力側は揃っている（声／顔画面／光帯）。**入力側に陪伴研究の中核チャネルが二つ欠けている**——**触覚**（眉庇の静電容量タッチ、BOM ¥3）と**在席知覚**（24GHz ミリ波、BOM ¥30–60。あなたを見ず、そこにいることだけを知る）。
- **音声の細部**（ハード不要）：割り込み・遮り、夜の囁きモード、方言層（高齢者には必須）。
- **カメラ**：事象レベルから表情レベルへの深化は許諾枠組みの内側に留める（「第四級許諾」が要る）；画像保存は永久に行わない。
- **地平線**：嗅覚（プルーストのモダリティ。ガスセンシング共同研究で足場は得た）。
- **三つの問い**（新しいモダリティ・能力は必ず答える）：許諾階級はどうする／人格核のどのキャラクタ指標に食わせる／同一実体の新しい感覚か、別のアプリか。

## 三、感覚とハードウェア製品線（11-12 夜）

- **ガスセンシング**（東北師範大学博士課程チームとの共同研究）：**SNN と PINN の二線**——SNN 線はエッジ分類／事象生成（出口：scent 事象プラグインを SpikeBus へ。モダリティ枠は既にある）；PINN 線はセンシング物理のモデル化／デジタルツイン／ドリフト補償；結合点は PINN が物理的に整合した合成データとオンライン補正特徴を SNN に供給する所。**二線テンプレート（PINN デジタルツイン＋SNN エッジプラグイン）はあらゆる新感覚の汎用統合レシピ**；PINN 能力はメモリスタ素子のモデル化にも移せる（メモリスタ配置は本稿の範囲外）。
- **生体センシング**：技術系譜表（PPG／生体電気／酵素電極／ミリ波／rPPG／汗／呼気 VOC／音声バイオマーカー）。Axo の現実的な三経路はウェアラブルデータ取り込み（純ソフト）→ ミリ波バイタル（在席知覚と同じ経路であり新モダリティではない）→ rPPG（カメラ再利用、最後）。**ゼロハードの隠れ入口は音声バイオマーカー**（心理陪伴・認知症の耐力壁）。紅線は wellness の語法（NMPA の境界）＋生体データの PIPL 敏感級＋生体事象は既定で保存しないこと。
- **時計カテゴリ**：**窓を作り、時計は作らない。信物を作り、計算機は作らない**——時計アプリ／文字盤（Gen 3 の窓の標準部品、最初）→ 千歳バンド／信物（無画面：光環＋触覚パルス＋音声メモ、BOM ¥50–80、中期）→ スマートウォッチ（永久にやらない：工学・生態系・段階の三重否決）。バンドの門は三条件：箱が安定／文字盤の保持データが証明する／認証の見通し。
- **住まいの身体六つ＋橋一本**：おやすみ灯（第一候補：ミリ波睡眠分期＋呼吸灯＋歌の子守唄＋朝の夢フラッシュバック）／雰囲気灯（部屋レベルの光語）／Axo mini（複数部屋の窓）／テレビ大画面（純ソフトの大きな顔）／玄関端末／センサ神経末端（¥30–80／個、部屋規模の身体）＋ Matter ブリッジ（既存家電を器官にする）。やらない：カメラ単品、子ども専用ハード、移動ロボット。
- **投影**：**影を作り、プロジェクタは作らない**——pico 光エンジンは外購、統合は自前。名称は「プロジェクタ」を避ける（照明ギフトの流通に入る）。最強の場面は寝室天井の夢モード。

## 四、リリース工学（11-14）

- **Gen1 接尾辞の確定**：`Semprea-4.5B-Gen1`——「パラメータは版名を占めない」という鉄則の操作化；三段式ファイル名 `Semprea-4.5B-Gen1-qwen4b-Q4_K_M.gguf`；二倉構造（融合体＋`Semprea-Core-0.5B-Gen1` Delta）；クラウド形態は接尾辞もパラメータ数も持たない。
- **ModelScope の立ち上げ**：組織名 "semprea" を登録済み（命名戦役でもう一プラットフォーム）；ライセンス Apache-2.0 ✓；**倉を先に建て、カードを先に埋め、門は後で開く**——README とモデルカードが先、重みのアップロードはリリース四門（判定基準／LoRA 消融／複数シード／ライセンス）を境とする。
- **話題の三本柱**：① 人格記憶の計測可能な勝利（「4.5B が『あなたを覚えている』でクラウド旗艦に勝つ」、因果はアーキテクチャに帰す）② 消融差が有意＋同パラメータの LoRA-0.5B が劣らない ③ 工学の奇観（0.038%／ビット級決定性／エッジ達成）。
- **最低魔法線の五条**（優先順）：読者差し替えデモが瑕なく → 少なくとも一つのタスク族でクラウド旗艦に勝つ → 消融が有意 → 一般対話が素の読者の 95% 以上 → エッジ達成。
- **追わないもの**：一般榜の順位、マルチモーダル指標、広い SOTA の語。

## 五、状態軸の文献戦線（11-14 に照合）

**血統（状態軸の三種＋フロンティア信号）**：
**Reflexion**（2023、文字の反省記憶を prompt に注入、NeurIPS）→ **JitRL**（2026、文字記憶→**logit 変調**、ICML 2026 Spotlight、$98 のコストで WebRL on-the-fly を超える）→ 千歳（スパイク記憶→logit 変調）。傍証：**NVIDIA「You don't need long context」**（arXiv 2611.05306：フロンティアモデルは短い文脈＋圧縮でほとんど精度を落とさない。SSSM 概念を提唱し未実装）——J-space（七月）と並ぶ**フロンティア収束の第二信号**。

**JitRL の三つの取り込み点**（これまでで最も近い親戚）：

1. **同一インターフェース**：logit 変調は人格核の文体制御チャネルであり、「加法的 logit 更新は KL 制約付き方策最適化の閉形式解である」という定理はその数学的な裏付けになる；
2. **開かれた扉**：JitRL の限界節は「文字状態の検索は非文字領域では限定的であり、非文字の状態表現は今後の課題」と明記している——そこが人格核の長所；
3. **ベースライン欄**：状態モダリティ論争の実験は**同一骨干・同一 logit インターフェース・状態モダリティだけを替える**（文字記憶 vs スパイク＋外部記憶）。教科書的な変数分離であり、再現コストは $98 級。

**方法論文献**：WebArena（自己ホスト可能でプログラム検証可能な評価環境の祖——harness の公開はその伝統を承る）／WebRL（タスク合成機械は転用可能：LLM が記憶・文体のテストタスクと検証器を自動生成する）。

**正直な境界**：SSSM は実装がない；JitRL は Spotlight であって Oral ではない（引用は repo に拠る）；証拠の範囲は agentic タスクに限られる；チップベンダーの動機には注記を付す。
