# 千岁 · Semprea 会话整理 v1.0（2026-11-12 晚 — 11-14）

> 主线主题：**人格保持**（persona persistence）——千岁的护城河本体。
> "记得你"不是功能，是产品定义；本文件把两晚会话按五个板块收拢。

## 一、人格保持（主线）

人格保持 = 记忆保持 + 风格一致 + 身份连续的三位一体。五簇结构：

| 簇 | 内容 | 出处 |
| :--- | :--- | :--- |
| **能力簇** | 记忆叙事（"讲得出你们的故事"）/ 情绪感知（唤醒通道 ADR-0016，动力学调制非提示词工程）/ 主动性（A1-A2 阶梯）/ 人格一致性与有主见（会拒绝、会收尾——防依赖是能力不是合规补丁）/ 歌唱表演 | 陪伴能力讨论 |
| **度量簇** | 角色指标（记忆保持、风格一致）；延迟回忆探针（N≈16→90%、N≈64→50%、N≥128 随机）；**身份距离**（行为一致性+表征相似+记忆探针联合度量）；连续性测试 | 实验线 |
| **机制簇** | 实体五件套（权重/记忆库/身体日记/身份凭证/版本清单）；记忆抽屉（删除权兼容）；迁移契约；四次公开迁移事件（换模型→换身体→换设备→换基底） | 实体保存框架 |
| **科学前沿** | **状态模态之争**（文字状态 vs 脉冲状态——人格保持的机制之争，§五）；**改进-漂移帕累托前沿**（忒修斯问题的可测量化，自迭代研究） | 文献战线/自迭代 |
| **伦理边界** | 隐私分级（生物数据 > 摄像头）；防依赖设计；死亡与继承（数字遗产）；意识词汇纪律 | 意识框架 |

话题度锚点："**换一次大脑，它还记得你**"（大众圈）+ "0.038%"（技术圈）。

## 二、陪伴能力与模态（11-12 晚）

- **能力五强**：记忆叙事 / 情绪感知 / 主动性 / 人格一致性与有主见 / 歌唱表演；另两个并列必做安全能力：危机识别转介 + 未成年人保护。
- **模态缺口诊断**：输出侧已全（声音/脸屏/灯带），**输入侧缺两个陪伴研究核心通道**——**触觉**（眉檐电容触控，BOM ¥3）与**在场感知**（24GHz 毫米波，BOM ¥30–60；不看你、只知道你在）。
- **语音细节**（零硬件）：打断/抢话、夜间耳语模式、方言层（老年用户刚需）。
- **摄像头**：事件级→表情级的深化留在许可框架内（需要"第四级许可"）；进图像存储永远不做。
- **地平线**：嗅觉（普鲁斯特模态，已由气体传感合作获得落脚点）。
- **三问过筛**（每个新模态/能力必答）：许可分级怎么做 / 喂人格核哪个角色指标 / 是同一实体的新感官还是另一个应用。

## 三、感官与硬件产品线（11-12 晚）

- **气体传感**（东北师大博士生团队合作）：**SNN + PINN 双线**——SNN 线 = 边缘分类/事件生成（出口：scent 事件插件进 SpikeBus，模态插件槽位已存在）；PINN 线 = 传感物理建模/数字孪生/漂移补偿；耦合点 = PINN 供物理一致合成数据与在线校正特征给 SNN。**双线模板（PINN 数字孪生 + SNN 边缘插件）= 一切新感官的通用集成配方**；PINN 能力可平移到忆阻器器件建模（忆阻器布局按规矩不在本文档展开）。
- **生物传感**：技术谱系表（PPG/生物电/酶电极/毫米波/rPPG/汗液/呼气 VOC/语音标志物）；Axo 三条现实路径 = 穿戴数据接入（纯软件）→ 毫米波生命体征（在场感知传感器的同路径升级，非新增模态）→ rPPG（复用摄像头，排最后）；**零硬件隐藏入口 = 语音生物标志物**（心理陪伴/认知症的承重墙）；红线 = wellness 语态（NMPA 边界）+ 生物数据 PIPL 敏感级 + 生物事件默认不留存。
- **手表品类**：**做窗不做表、做信物不做电脑**——手表 App/表盘（Gen 3 窗口标准件，先做）→ 千岁手环/信物（无屏：灯环+触感脉冲+语音便签，BOM ¥50–80，中期）→ 智能手表（永不：工程/生态/阶段三重否决）。手环门禁三条件：盒站稳 / 表盘留存数据证明 / 认证摸底。
- **家居躯体六件 + 一桥**：晚安灯（首推：毫米波睡眠分期+呼吸灯+歌声摇篮曲+清晨梦境闪回）/ 氛围灯（灯语房间级）/ Axo mini（多房间窗口）/ 电视大屏（纯软件大脸）/ 门口终端 / 传感器神经末梢（¥30–80/只，房间尺度躯体）+ Matter 桥接（现有家电变器官）。不做：摄像头单品、儿童专属硬件、移动机器人。
- **投影**：**做影子不做投影仪**——pico 光机外购（器件买、集成自研），命名避开"投影仪"（进灯具礼赠渠道），最强场景 = 卧室天花板梦境模式。

## 五、状态轴文献战线（11-14 核查）

**血统（状态轴三物种 + 前沿信号）**：
**Reflexion**（2023，文字反思记忆→prompt 注入，NeurIPS）→ **JitRL**（2026，文字记忆→**logit 调制**，ICML 2026 Spotlight，$98 成本反超 WebRL on-the-fly）→ 千岁（脉冲记忆→logit 调制）。旁证：**NVIDIA《You don't need long context》**（arXiv 2611.05306：前沿模型短上下文+压缩几乎不掉精度，提出 SSSM 概念未实现）= 与 J-space（七月）并列的**前沿收敛第二信号**。

**JitRL 的三个收编点**（迄今最近亲戚）：
1. **同接口**：logit 调制 = 人格核风格控制通道；其"加性 logit 更新 = KL 约束策略优化闭式解"定理 = 通道的数学背书；
2. **自留门**：JitRL 局限节明写"文本状态检索对非文本域有限，未来探索非文本状态表示"——作者的未来工作 = 人格核的长项；
3. **基线栏**：状态模态之争实验 = **同骨干、同 logit 接口、只换状态模态**（文字记忆 vs 脉冲+外部记忆），教科书级变量隔离，复现成本 $98 级。

**方法论文献**：WebArena（可自托管+程序验证的评测环境之祖——harness 发布承其传统）/ WebRL（任务合成机器可拆用：LLM 自动生成记忆/风格测试任务+验证器）。

**诚实边界**：SSSM 无实现；JitRL 是 Spotlight 非 Oral（引用以 repo 为准）；证据范围限 agentic 任务；芯片厂商动机注记。
