# SEL 对召回与门控是否适用

[中文](sel-applicability.md) · [English](sel-applicability.en.md) · [日本語](sel-applicability.ja.md)

**日期**：2026-11-03
**结论**：**不适用。** SEL（脉冲表达层）解决的是"序列生成里的风格"，召回是排序、
门控是二分类；三者共享的只有"脉冲神经元"这一个零件，而那个零件在这两条线上已经有
三次方向一致的负结果。SEL 值得做，但它不该被拿来论证召回或门控。

## 一句话版

- **召回**：查询与记忆是静态集合，时间步是人为加的；发放率是点积的量化，信息只减不增。
  512 个 ALIF 的 hit@1 是 0.024（词法 0.259）；换 TI-LIF 之后是 **0.012**。
- **门控**：只有 3 个静态特征，kNN 与单阈值 AUROC 都是 **1.000**；任何只用到这 3 个
  特征的确定性映射都不增加互信息（数据处理不等式）。512 群体在 gold 上 AUROC 0.41，
  词法单阈值 0.825。
- **可迁移的是方法**：预注册、基线、留出集、负结果登记、双向判据。不是架构。

## 召回

**机制为什么不适用。** 召回是对一批候选打分排序：给定查询与记忆，答案在排序好的
前几条里。SEL 的时序结构、跨 token 状态、脉冲注意力都建立在"输出是一段序列"上；
召回没有序列可生成。把查询编码成脉冲电流跑 T 步再读发放率，等价于对同一个点积
做一次带阈值、不应期与量化的非线性变换——信息只会减少。

**证据。**

| 试验 | 结果 |
| :--- | :--- |
| `research/spiking_512`（512 ALIF，gold） | hit@1 **0.024** vs 词法 **0.259**；hit@5 0.094 vs 0.424 |
| 同上，TI-LIF D=1/D=2（2026-11-03，10 种子） | hit@1 **0.012**；hit@5 0.047 |
| 同上，ALIF + K 窗平均（5 套独立投影） | hit@1 **0.035**（+2.3pp，阳性对照成立） |
| 同上，TI-LIF D=2 + K 窗 | hit@1 **0.012**（没从 K 窗受益） |
| Axo 基质补全（512 ALIF） | hit@1 0.000 vs 线性 0.025；延迟 +40.7 ms |

K 窗那一行很关键：它是唯一被证明有效的读出改进（∝K^0.6），在 ALIF 上复现了方向
（0.012 → 0.035），但 TI-LIF 没有拿到同样的增益。也就是说，问题不在"脉冲是二值
还是有符号"，而在"发放率丢掉了排序需要的那点分辨力"。

**什么情况下重开**：出现一个真正流式的召回任务（查询随时间到达、只允许一次前向、
没有可重排的候选集），且线性/词法基线不在 0.10 以下的地板上。

## 门控

**机制为什么不适用。** 门控问的是"这一句话在库里有支撑吗"，输入是 3 个标量
（`top_score` / `mean_topk` / `density`），输出是一个二分类。kNN(5) 密度门与
`top_score` 单阈值在这批数据上的 AUROC 都是 **1.000**。AUROC 只看排序；对这 3 个
特征做任何确定性映射（含脉冲群体编码）都不会比原始排序多出信息——最多改变有限样本
上的决策边界，而那更像过拟合。

**证据。**

| 试验 | 结果 |
| :--- | :--- |
| Axo 元认知门控（217 条真实库） | kNN **1.000** vs 单阈值 **1.000**；难正样本 0.996 vs 0.996；判据 2 不过，未接线 |
| `research/spiking_512` 门控（gold） | 512 ALIF **0.535**；TI-LIF D=2 **0.410**；词法 top-1 余弦 **0.825** |
| 产品路径 | 一个门槛 0.20（ADR-0028），在真实分布上标定过 |

**什么情况下重开**：有一批**近域难 OOD**（单阈值 AUROC < 0.95）的人工标注，且速率型
基线先跑出来、证明有提升空间。没有这两样，任何"脉冲门控"都只是在 1.000 的天花板下
换一种写法。

## 与 SEL 的关系

- SEL 与召回/门控**共享神经元实现**（`biosnn_bus.AdaptiveMembrane` /
  `TernaryMembrane`），不共享任务结构；
- 召回/门控的负结果**不能**用来否定 SEL：SEL 的任务是生成，评价是风格与事实保真，
  风险在**数据、规模与教师 logits**，不在"脉冲"这个词；
- 反过来，SEL 的叙事**也不能**用来给召回/门控背书。两边的预注册、基线与报告必须
  分开写，这正是本文件存在的原因。

## 可迁移的部分

1. **先写判据再跑**（S1–S3、A1/A2/B1/B2、T1–T5 都是先落盘的）；
2. **平凡解与阳性对照要一起报**（K 窗的 +2.3pp 就是这次实验的阳性对照）；
3. **负结果照登**（`research/spiking_512`、`benchmarks/substrate_spiking.md`）；
4. **双向判据**（B1/B2：既看脉冲领先，也看它是否落后）。
