# フェーズ4コンポーネントの状態とロードマップ（2026-10-27）

[中文](stage4_status.md) · [English](stage4_status.en.md)

**性質：状態の締めくくりであり、受け入れ合格ではない。** フェーズ4の入口は
[ADR-0018](adr/ADR-0018-task-aware-cl-gate.ja.md)（タスク認識 CIL）と
[ADR-0019](adr/ADR-0019-stage-four-entry-decoupled-from-relearn.ja.md)
（再学習 3× からの切り離し）に基づいて開かれた。本書は 2026-10-27 時点のコンポーネント
状態・境界・未解決の研究項目を記録し、フェーズ4の後続計画に用いる。いかなる事前登録も
置き換えず、「コンポーネント ready」を「フェーズ4エンドツーエンド成立」とは書かない。

## 2. 「ready」の意味

- そのコンポーネントの**事前登録した基準を通過した**ことだけを意味する（各結果 README を
  参照）。次は含まない：
  - フェーズ4エンドツーエンド課題；
  - バス／プラグインとの統合；
  - スパイク化（作業記憶）や完全局所化（メタ認知校正ヘッド）。
- 負の結果・境界はそのまま残す。事後に基準を変えていない。計画書の台帳 ㊽–106 が完全な
  索引である。

## 3. 未解決の研究項目（推奨順）

1. **エンドツーエンド v3（ストレステスト）は完了、4/5**：主設定 K=8/σ=0.3/t=100 で落ちた
   のは OOD 棄権だけ（0.7056 < 0.80）で、5 seed すべてが線を下回る。OOD の順位付け自体は
   まだ使える（AUROC 0.835）。容量境界は K=8–16（K=16 の E top-1 は 0.7736）。v2 の 0.824 は
   基準を 2.4 pp 上回るだけでもともと薄い。次は**本当に記憶を要する**課題へ替えるか、棄権を
   固定カバレッジ閾値から校正／リスク管理へ変える。同じ系統のストレスを足し続けず、K=8 の
   0.904 を汎用的な記憶能力と見なさない。**v4 は DPAR を統合済み**：DPAR 0.9628 は通るが
   WM が干渉を受け（R² 0.6558、MSE 0.3507）、事前登録の R²≥0.50 と MSE≤0.10 も両立
   しない。基準を直すか目標を分割するまで v4 を ready と呼ばない。**v5 は二段階設計で
   6/6 に達した**（WM t=35、DPAR t=85、最終状態を共有しない）が、これは順序組合せの
   上界であり、v4 の共存干渉を覆さない。**v6 の二重 bank ルーティング**は WM R² を
   0.527 から 0.994 へ上げるが、OOD 棄権を 0.793 から 0.622 へ下げる。両腕とも未 ready
   で、共存と棄権はまだ同時に満たされていない。**v7 は bank W だけで信頼度を計算**：
   棄権 0.622→0.786、AUROC 0.782→0.882 だが 0.80 まで 1.4 pp 足りない。差は t=85 の
   A/B/Q 減衰で、閾値の位置ではない。**v8 は bank W の `state_norm`** を加え、棄権
   0.9368、AUROC 0.9562 で六条全通過。ただし**尺度 OOD 専用**であり、汎用棄権ではなく、
   v6/v7 の情報喪失型 OOD 境界も変えない。**v9 頑健性**：s=2 の棄権 0.720、K=8 の
   WM R² 0.89975 で `v9_robust=false`。v8 の ready は s≥3、K≤4 と書く。**v10 は bank W
   の収縮 Mahalanobis** で s=2 の棄権を 0.8276 に上げ（カバレッジ 0.7900、AUROC 0.8937）、
   s3/s5 も通過。K=8 は容量／カバレッジ境界（0.89975 / 0.7532）のまま。**v11 は K=8 を
   三腕に分けた**：snapshot85 の R² 0.9936、longtau 0.90145 だが、カバレッジ
   0.7552/0.7776 は 0.78 未満。K8 の残る境界は WM 容量ではなく**ゲート校正**。
   **v12 は diag ゲートに変更**：snapshot85 0.7820、longtau 0.8052 で二腕とも七項通過。
   shrunk は依然不合格。K8 の境界は **28×28 共分散推定**で、WM でも DPAR でもない。
2. **作業記憶 v6（スパイキング）**：v5 の失敗は読み出しではなく**表現**（60 ステップの
   カウントが一桁）にある。v6 は膜電位／閾値下状態、より長い積分窓、または rate 入力が
   必要。v5 は 2598.7 s かかったので、次回は seed／窓を減らすか並列化する。
3. **メタ認知 v4 は完了（境界付き）**：独立校正集 + 三次元密度ゲート（disagreement /
   surprise / state_norm）により、e2e v3 の棄権は 0.7056 から **0.8456**、AUROC は
   0.8350 から **0.9003** へ上がり、選択的 MSE はほぼ不変。ただし **gauss2 はむしろ悪化**
   （0.6984）しており、利得は `state_norm` が A/B×3 の尺度偏移を検出したことによる。
   **尺度非依存の OOD**（共分散／周波数／位相偏移）で再検証が必要で、汎用の棄権能力とは
   見なさない。v3 の分類校正ヘッドは依然として回帰へ未移行。**v5 の保范直交回転は OOD
   ではない**（誤差 0.0679 対 in-dist 0.0681）ため、v5 から汎化の結論は出せない。次は
   「OOD 誤差 ≥2× in-dist」の有効性ゲートを先に通してから棄権を議論する。**v6 の量子化
   OOD は有効性ゲートを通る**（6.38×）が、gauss3 の棄権 0.1716、AUROC 0.4876 で四つの
   ゲートはすべて失敗。**v7 は特徴を高次モーメント**（mean z²/|z|/z⁴/尾比率）に替えても
   0.2048／0.5024 で、尺度 sanity も 0.7544 に落ちる。v4 は尺度偏移に限定され、汎用の
   棄権能力とは書けない。
4. **世界モデル P3 の後続**：終了の閉ループ分布偏移（オフライン 0.999 → 閉ループ 0.665）は
   未解決。方向はより強い状態モデル（初手ばらつきを 115 より十分大きくする）か、想像分布に
   合わせた終了ヘッド。一手先想像の増強は試したが 0.632 で不足。
5. **エピソード記憶**：DPAR（v4）は課題が本当に結合を要することを示した（状態制御 0.121
   ≈ chance）。**非局所擬似逆**は K=8/σ=0.1 で通過（0.828）、字義 NN は 0.938 でより高く、
   **局所 Hebbian は依然 0.311 のみ**。容量境界は K=8–16。元の CartPole 課題／ノイズ／
   時間順序の境界は保持する。次は局所または低次元キーを試すか、参照表ベースラインを受け入れる。
   k/β／符号化次元の調整を続けない。
6. **作業記憶 v5 の代替**：「純粋なスパイク数」に固執するなら、まず低カウント表現の問題を
   解決する。そうでなければ v4 の rate 漏れ積分器をフェーズ4の実用局所表現として受け入れる。

## 4. フェーズ3との関係

- フェーズ3の CL ゲートは ADR-0018 のタスク認識 CIL として通過した（構成的 AF=0 であり、
  忘却耐性アルゴリズムではない）。
- **再学習 3× は未達**であり、ADR-0019 によりフェーズ4入口から切り離されたが、未解決の
  ままである。
- 本書は上記二点を**変えない**し、フェーズ4コンポーネント ready をフェーズ3の完全な
  受け入れ合格とはしない。
