## 2. 「ready」の意味

- そのコンポーネントの**事前登録した基準を通過した**ことだけを意味する（各結果 README を
  参照）。次は含まない：
  - フェーズ4エンドツーエンド課題；
  - バス／プラグインとの統合；
  - スパイク化（作業記憶）や完全局所化（メタ認知校正ヘッド）。
- 負の結果・境界はそのまま残す。事後に基準を変えていない。計画書の台帳 ㊽–110 が完全な
  索引である。

   ステップ誤差 0.00305**。`p3_v5_ready=true` は開環のみ、`p3_closed_loop_ready=false`。
5. **エピソード記憶**：DPAR（v4）は課題が本当に結合を要することを示した（状態制御 0.121

## 4. フェーズ3との関係

- フェーズ3の CL ゲートは ADR-0018 のタスク認識 CIL として通過した（構成的 AF=0 であり、
  忘却耐性アルゴリズムではない）。
- **再学習 3× は未達**であり、ADR-0019 によりフェーズ4入口から切り離されたが、未解決の
  ままである。
- 本書は上記二点を**変えない**し、フェーズ4コンポーネント ready をフェーズ3の完全な
  受け入れ合格とはしない。
