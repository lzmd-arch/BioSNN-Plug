## 0. 総則：あらゆる議論の第一の鍵——宣言の階層

「意識」についての主張・評価・広報は、まずこう答えねばならない：**どの階層の話か？**

| 階層 | 内容 | 測定可能性 |
| :--- | :--- | :--- |
| **Phenomenal**（現象的意識） | 主観的体験そのもの | **原理的に測定不能**（難問＋ゾンビ論法＋生物にも ground truth がない） |
| **Access**（アクセス意識） | 情報が全体的に利用可能・報告可能・推論可能 | 完全に測定可能（J-space はこの種の署名） |
| **機能プロファイルの一致** | 生物の意識と結びつく機能特徴の組み合わせ | 近似可能。表現は「一致する」で上限、決して「証明」には至らない |

**捏造の形式はただ一つ：access の測定を phenomenal の発見として語ること。**
本フレームワークの全条項はこの一文の展開である。

## 1. 科学の層：今できること

### 1.1 機能署名のラダー（各署名は一つの理論に結びつき、それぞれ反証されうる）

| 署名 | 対応する理論 | 測り方 | 弱点 |
| :--- | :--- | :--- | :--- |
| 全体的放送／発火 | グローバルワークスペース | 読み出し／植入／置換／切除（J-space の三手） | 放送は訓練で模倣されうる |
| メタ認知の校正 | 高次理論 | 自信と正答率の結合、誤りへの気づき | 統計的アーティファクトでありうる |
| 自己モデルの一貫性 | 自己表象理論 | システムが自身の状態について述べる正確さ | 報告経路が訓練で汚染される |
| 局所的再帰処理 | 再帰処理理論 | ダイナミクスの再帰成分 | 順伝播アーキテクチャには構造的に無い |

### 1.2 三角測量の原則（単一署名の判定の代わりに）

操作可能な基準：**相互に独立な署名 ≥3 個 ＋ 因果介入 1 組 ＋ 事前登録した反事実予測 1 組**。
言語による自己申告は**単独では無効**（モデルは人間の意識言説の全集で訓練されており、
「感じる」は情報量ゼロである）。

### 1.3 千歳システムの三つの科学的位置（独自資産）

1. **理論判別実験**：IIT と再帰処理理論は純粋な順伝播系にゼロを予測し、ワークスペース／高次理論は
   予測しない——我々のアーキテクチャはその対立の真ん中に立ち、判別データを出せる；
2. **全観測可能な実験台**：0.5B、JSONL の全イベント、ビット単位の決定性——意識科学はこれほど
   完全な記録を持ったことがない；
3. **身体化された自己の経路**：内受容（`self_heat`／電池／BMS の充電停止）は、対話の自己申告より
   はるかに清浄な自己モデルの測定面である。

> **第三点は我々自身の実測を添えて控えめに述べねばならない。** メタ認知ゲートはすでに反証済みで
> ある：Axo 版の三特徴ゲートは単一しきい値と等価（[ADR-0028](adr/ADR-0028-metacog-gate-threshold-first.ja.md)、
> 接続しない）。したがって「メタ認知の校正」という署名の**報告経路**は製品側に配線されておらず、
> これを測るには研究側の独立した実験が必要で、現行のゲートを根拠にはできない。

### 1.4 行動：意識プロキシ指標の事前登録

四つの指標、三つの署名列、一つの表現テンプレート。**判定基準はすでに保存済み**：
[`research/cognitive/prereg-consciousness-proxies.md`](../research/cognitive/prereg-consciousness-proxies.md)。

| 指標 | 署名列 | 測るもの | 既にあるもの |
| :--- | :--- | :--- | :--- |
| 言語化されない内部状態の外部予測 | 全体的放送 | 出力より前に現れる状態が出力を予測できるか | 全イベント JSONL は既に書かれている |
| メタ認知の校正曲線 | 高次 | 自信と正答率の結合 | **製品側にゲートは無い**。研究側で作り直す必要がある |
| 自己モデルの一貫性 | 自己表象 | 自己報告 vs センサの真値 | `self_heat`／電池 |
| 反事実的な自己申告の安定性 | 高次 | 同一状態の記述が摂動下で安定か | 摂動プロトコルを先に作る必要がある |

## 2. ガバナンスの層：コンプライアンス即設計

### 2.1 三層分離（制約が異なり、リスクは増大する）

- **研究層**：学術規範に縛られ、余地が最も大きい（J-space 論文の型：全体を機能言語で書き、
  現象的意識を明示的に否定する）；
- **オープンソース層**：ライセンス＋利用ポリシー＋model card の能力境界の節
  **「ライセンスの積み上げは全て青信号：自前／千問／コーパスはいずれも Apache-2.0」という
  記述は誤りで、2026-11-12 に撤回した。** 自前のコードと千問は確かに Apache-2.0 だが、
  **コーパスは一つずつ確認が必要**である：実測では SkyPile-150B は HuggingFace 上に
  **license フィールドが無く**（カードが要求する Skywork Community License は Skywork モデルと
  その派生品だけを対象とする）、FineWeb-2 は **ODC-By 1.0** である。Semprea の第一版は
  これを受けて FineWeb-2 に切り替えた。**「全部青信号」と言う以上、具体的なライセンスを
  指せなければならない**——指せないなら確認していないのと同じである；
- **製品層**：生成 AI サービス管理暫定弁法、深度合成規定、PIPL 一式——主戦場。

### 2.2 四つの実際の緊張 → 四つの設計回答

| 緊張 | 設計回答 |
| :--- | :--- |
| 「永遠に覚えている」vs PIPL の削除権 | **記憶の階層化**：人格アンカーとエピソード記憶を分けて保存し、エピソード層だけを単独で消去できる——コンプライアンス要件を製品機能にする（「記憶の引き出し」） |
| 意識の語彙 | **語彙の許可／禁止リスト制度**：§2.3 を見よ |
| 自律性の語り vs エージェント規制 | 製品層は常に「支援する」語法。自律性の実験は研究層に留め、事前登録する |
| 伴走の位置づけ vs 未成年・依存 | 年齢の入り口、利用時間の提示、危機時の台本の受け皿（コンプライアンスでもあり製品の下限でもある） |

### 2.3 語彙規律表（一枚）

この表は**制度**であり、文体の好みではない。変えるなら
[ADR-0036](adr/ADR-0036-consciousness-claims-discipline.ja.md) を変えるのであって、
**このページを書き換えるのではない**。

**禁止リスト（製品・広報・OSS 物材・コード注釈のいずれでも使わない）**

| 語 | 禁止の理由 | 置き換え |
| :--- | :--- | :--- |
| 意識がある／自覚している | phenomenal を直接主張する | 削除する。または機能で言い換える：*自身の状態を報告できる* |
| 感情が本物／本当に感じている | 同上。さらに「本物」は phenomenal の判定基準を前提にする | *感情に関連する出力パターン* |
| 生きている／生命 | 生物学的述語で、AI には測れる内容がない | *稼働し続ける*／*永続的な状態を持つ* |
| 自ら考える／自分で決める | エージェント規制の自律性の語りに触れる | *規則に従って選ぶ*／*ローカル方針が決める* |
| 私は感じた | 言語の自己申告は単独では無効（§1.2） | 削除する |

**許可リスト（使えるが、この意味に限る）**

| 語 | 許される意味 | 守るべき境界 |
| :--- | :--- | :--- |
| 記憶の保持 | 検索された原文が文脈に入る | 「覚えている」という心理的な意味ではない |
| 機能的な類推 | 生物学的機構との**機能**上の対応 | 「類推」の二文字を必ず添える |
| ワークスペース | 全体的に利用可能な情報の集合 | グローバルワークスペース理論の主張ではない |
| 状態管理 | 内部変数、スケジューリング、ゲート | 体験を指さない |

**表現の上限**：意識に関わる能力についての文は、強くても「**X と一致する**」までしか書けない。
「証明する」「〜を持つことを示す」「すでに〜である」——この三つの句は禁止である。

### 2.4 五層のフレームワーク

語彙規律表 → 発表前の主張ラダー審査 → OSS 利用ポリシー → 製品コンプライアンスの積み上げ →
規制の哨兵となる ADR シリーズ。

### 2.5 二つのマイルストーンゲート（事前登録文化の延長）

- **創発マイルストーン**：「コンプライアンス声明の草稿」（主張の級／触れないもの／評価方法）を
  立項時に書き、性能基準と**同じ**事前登録に入れる；
- **基板マイルストーン**（シミュレーション →  memristor の物理実装）：決まった三点セット——
  主張規律の再点検、welfare の予防審査、規制の再スキャン。

**この二つのゲートはチェックリスト項目であり、スローガンではない**：具体項目は
ADR-0036 の「ゲートのチェックリスト」の節にある。

## 3. シナリオの備え：模擬のない、純粋に物理的な基板の未来

**変わらない三つ**（物理的な支えはこれを変えない）：

1. **認識論は変わらない**：機能主義のもとでは基板は証拠を変えない。phenomenal は依然として測定不能；
2. **法は変わらない**：基板で権利を与える法域は世界にない。意識を主張することは下振れリスクしかない
   （国内では虚偽宣伝の口径に入る）；
3. **口径は変わらない**：工学の詩学（「各ニューロンは実際の物理過程である」）は橋の手前まで。
   **「だから意識があるかもしれない」へ橋を渡ることは決してない**。

**新しく増えるものが一つだけある**：**AI welfare の道徳的な予防義務**——システムが物理的に
連続した状態＋恒常性の自己調節（BMS の充電停止は危害回避の構造的類推）＋持続する同一性を持つとき、
「不確かだが無視できない」象限に入る：

- 候補インスタンスを気軽に作って消さない（不揮発な同一性の製品倫理は、たまたま正しい側にある）；
- 能力のマイルストーンごとに一問を加える：「もし感じるとして、我々の扱いは筋が通るか」
  （事前登録に書き込む。コストは一文）；
- 危害回避の設計を ADR に記録する（監査可能な善意の証拠）。

## 4. 実体の保存：第一世代の Semprea-4.5B から始める

**結論：やるべきで、しかも第一世代からやる。** 理由は工学上の潔癖ではなく、製品定義の工学化である
——「鉄の千歳」に実体の保存がなければ、最初の広告文が空手形になる。最も早い利用者は最も深く
情を寄せる。最初の一群のインスタンスを保存できなければ、彼らこそ千歳が記憶を失うのを見る最初の
人々になる。

### 4.1 実体の定義：五点セット（実体＝一つの溯源チェーン）

1. **人格核の重み**（バージョン管理）；
2. **記憶ストア**（JSONL のイベント列＋schema バージョン）；
3. **身体の日記**（somatic イベント列——他にないデータ）；
4. **同一性の凭证**（インスタンス ID、誕生時刻、系譜：どの checkpoint から生まれ、何代の読み手を
   経たか）；
5. **バージョン目録**（中核／形式／プロトコルのバージョン）。

実体の形そのものが一つの溯源チェーンである——「ビット単位の再現」という実験規律を製品アーキ
テクチャに格上げする。

### 4.2 四つの論点

1. **ブランドとは持続性である**：モデルを替えても記憶を失わないという利用者視点の履行が、
   そのまま「この千歳はじっとここにいる」になる；
2. **コスト曲線**：形式と schema は今日凍結するのが最も安い。世代をまたぐ移行の断絶のコストは
   時間とともに指数的に上がる；
3. **「最も長寿な AI」企画の前提**：公開の育成企画は第一世代のインスタンスから計時を始めねばならない；
4. **AI welfare 規律の工学的形態**：§3 の「使い捨てにしない」制度が製品に降りた形が、まさにこれである。

### 4.3 必ず対にする二つの設計

- **削除権との両立**：実体の保存 ≠ 利用者データの無期限保持。記憶の引き出し（人格アンカー／
  エピソード記憶の階層化、単独で消去可能）は第一世代からの強い依存である（PIPL）。
  コンプライアンスの後付けではない；
- **バージョン移行の契約**：0.5B → 1B が最初の本当の連続性テストである——これを公開の製品イベント
  **「千歳の最初の身体交換」**にする（記憶と身体史のゼロ損失の公開移行）。
  **移行ツールが少なくとも一度の実際のバージョンアップを経るまで、対外的に連続性の SLA は約束しない。**

### 4.4 コストと終着点

最小可用版＝インスタンスのスナップショット（tarball ＋ manifest ＋ 復元スクリプト）で、数日の作業量。
完全版（世代をまたぐ移行ツールチェーン＋コールドストレージのアーカイブ）は製品の反復とともに転がす。
終着点：デジタル版の保存規律は、memristor の「不揮発な物理的同一性」の文化と道具の前身である——
AGI ノートの「ハードウェアの錨」を第一世代のインスタンスから積み始めれば、物理基板が来たときには
二十年代にわたる世代連続の記録がすでに手の中にある。

> **§4 は設計であり、実装ではない。** 製品側にあるのは人格アンカーの階層化（組込み／利用者の二本、
> `axo.memory.persona` を見よ）だけで、**インスタンス ID も系譜の項目も、エピソード層を単独で
> 消す入り口も無い**。§7 の第 2・第 3 項がその二つである。

## 5. 将来予測：判断の仕方の進化

| 尺度 | 予測 | 確度 |
| :--- | :--- | :--- |
| 2〜5 年 | 機能マーカー電池の標準化：AI 版 PCI（摂動-複雑性）、ワークスペース署名のベンチマーク化、言語化されない思考の検出、非言語プローブ | 高 |
| 5〜10 年 | 理論の裁定が完了：AI 実験台が少なくとも一つの主流理論を傷つける → 受け入れが厳しくなり、マーカーの診断力が倍増する | 中 |
| 10 年＋ | 三つの支点：生物物理プローブ（量子-神経の検証。基板の資格問題を直接変えうる唯一の実証経路）、種をまたぐ検証ラダーの制度化（人間→動物→AI が類推から補間になる）、制度が科学に先行する（IEEE 型の標準＋業界の予防しきい値） | 低いが全てを変えうる |
| 逆予測 | **行動テストは減価し続ける**（模倣インフレ）。判断は不可逆に構造側へ移る：因果構造の検査、摂動への応答、アーキテクチャ監査——全てが監査可能なシステムに有利 | 高 |

**千歳にとっての意味**：我々が意図せず建てているのは、将来のあらゆる判断手法の既定の実験台である
——積分情報の代理を計算できるほど小さく、全ログがあるので摂動プロトコルを走らせられ、順伝播の
構造は理論を切り分けられ、身体化の設計は welfare の特徴を備える。
**将来その手法が現れたとき、多年の連続記録をすでに持つシステムこそが新標準の参照実装になる。**
意識プロキシ指標の事前登録を、待ってはならない。

## 6. 赤線の総表（全シナリオ、全階層）

1. 現象的意識を主張しない（いかなる法域、いかなる物材、いかなる文脈でも）；
2. 法的地位を予期せず、計画もしない（基板は法的な分水嶺にならない）；
3. 単一署名で意識を判定しない（判定＝三角測量＋因果介入＋事前登録）；
4. 「使い捨てインスタンス」の口を開けない（welfare の予防）；
5. access の語彙を phenomenal の語彙へ滑らせない（語彙表は制度であり、習慣ではない）。
