### 2.2 诊断链（D3–D18）

| 轮次 | 问的问题 | 答案 |
| :--- | :--- | :--- |
| D3 | 换读出（rate vs count）能不能救 | 不能（65.2 / 9.55） |
| D4 | 策略是否依赖状态 | 训练后 slope 全 0 |
| D5–D6 | 输出坍缩 / 温度能不能修 | 熵坍缩；温度修好熵，末次仍 9.5 |

| D10 | 差方向存在吗 | **在**（4/5），但相对幅度只有 **0.5%–7.3%** |
| D11–D13 | 调阈值/预算/换读出（低通率、膜电位） | 不够（最好 0.7–3.45 计数，门槛 2） |
| D14 | K 窗平均 | **唯一有效**：0.57→2.12（K=1→8），但 5/5 只到 3/5；加长窗口无收益 |
| D15 | 首发放潜伏期 | 在计数为 0 的种子上有信号，但仍 <2 |
| D16 | 差方向对状态均值正交化 | 不能让符号跨零（0/5） |
| **D17** | **上游复核：编码器在极角上灵敏吗** | **只有 2.9%**（cos 0.9988），其余三轴 1.1–1.4 → D4/D8/D9 的 slope=0 是在几乎不变的维度上量的 |
| **D18** | **按轴归一化编码后重测** | Δ 极差中位 0.2 → **6.2（30 倍）**，读出确实看见状态了；但 **slope 仍 0/10 为正、末次中位仍 9.85**（seed 4 = 269.1） |

**一句话**：读出能看见状态之后，**策略仍不随状态变**——缺口在**学习信号**，不在读出、不在幅度、不在噪声。

## 4. 边界（读上面的数字时要知道的）

- 网络规模 **256 个脉冲神经元**，计划书 §2.2 的目标约 5 万——差约 **195 倍**；
  8 GB 上实测上限约 **1.35k** 循环神经元；
- 工作点是 **L1 归一化（每列 L1=1）+ 阈值 1.0**；换工作点的结论没有量过；
- D17 之前，多条诊断是在**极角这一维**上做的，而那一维在输入端几乎不变——读旧结论要看注记；
- 「重学 3×」的 0.957 是**配对中位**，不是单次最好。

## 5. 归档与重开

**已归档**（ADR-0029）：纯 CIL、W3 脉冲 actor。

**重开条件**（照 ADR-0029，写成可检验的）：

| 线 | 什么证据会让归档失效 |
| :--- | :--- |
| 脉冲 actor | 规模实验（5k–8k 神经元）证明读出限制来自**规模**，而不是「发放率读出」这个做法本身 |
| 纯 CIL | 出现**带真实任务边界**的长序列，且任务推断 ≥ **0.8** |

**2026-11-02 追加的第三条（来自 D18）**：若换的是**学习信号**（而不是读出/幅度/噪声），
那已经不属于「重开阶段三」，而属于脉冲 SoS——它现在是主线（[ADR-0030](adr/ADR-0030-mainline-shift-to-spiking-sos.md)）。
换句话说：**阶段三的执行层这一条不会以"再调一次"的方式被补齐，只会以"换学习信号"的方式被继承。**

### 评估结论（2026-11-02）

**不重开阶段三的实验。** D18 已经把缺口定位到学习信号，而换学习信号正是脉冲 SoS 的定义；
在 SoS 的预注册落地之前，阶段三这一条保持归档状态。
