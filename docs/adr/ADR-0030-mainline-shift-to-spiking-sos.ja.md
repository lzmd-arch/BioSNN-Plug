# ADR-0030：メインラインをスパイク SoS へ切り替える

[中文](ADR-0030-mainline-shift-to-spiking-sos.md) · [English](ADR-0030-mainline-shift-to-spiking-sos.en.md)

- **状態**：採用済み
- **日付**：2026-11-02
- **関連**：[ADR-0029](ADR-0029-research-line-archival.ja.md)、[第 4 フェーズの状態](../stage4_status.ja.md)、[Paper C 設計草案](../../paper/c/DESIGN.md)

## Context

W3 のスパイク actor は**同じ失敗の形**で十数回ぶつかってきました：読み出しが雑音と量子化の
二重制約を受け、差の向きはあるものの相対的な大きさは 0.5%–7.3% にとどまり、読み出しを変えても
しきい値を変えても広がりません（ADR-0029 でアーカイブ済み）。「方策を直接学ぶ」に計算資源を
足し続けるのは、「もう一度調整する」を方法論にすることです。

第 4 フェーズは使える部品を二つ残しましたが、**どちらも方策ではありません**：

- 世界モデル（AUROC 1.0 / FP 0.0009）は **one-step のダイナミクス予測**で、状態と行動から次の状態を予測します；
- ワーキングメモリ（0.9990）は現在の状態を保持できますが、**分岐もリセットもできません**。

その間の隙間が「**予測を使って行動列を探す**」です。SoS（Gandhi et al., CoLM 2024、arXiv 2404.03683）は、
**探索の過程**（探索・行き止まり・バックトラック・再試行）を学ばせるほうが、最適軌跡を学ばせるより
探索能力が育つという証拠を示しています。

ユーザーが 2026-11-02 に、スパイク SoS を新しいメインラインとすることを決定しました。

## Decision

1. **メインラインをスパイク SoS に切り替える**。計算資源と注意力はまずそこへ、Paper C は非メインに降格。
2. **三つの前提を先に整える。整うまで訓練は回さない**：
   - 世界モデルが**不確実性の推定**（予測分散）を出すこと（点予測だけでは不可）；
   - **R-STDP の reward を再定義**：外部の成功信号から**予測誤差の減少**へ；
   - **複数軌跡の実験フレーム**：N 本の並行軌跡とリセット／バックトラックのインターフェース。
3. 前提が整うまでに許される成果物は **実験設計・事前登録・最小環境（グリッド／迷路）の骨組み**の三つだけ。
   事前登録は `research/sos/` に書き、判据を先に落とすこと。

## 再評価の条件（いま書いておく）

| 条件 | 結論 |
| :--- | :--- |
| 単純なグリッド／迷路で成功率 **80% 未満** | 撤回し、追加投入しない。負の結果としてアーカイブ |
| 探索ステップが**課題難度に応じて適応しない** | 同上——固定方策を学んだのであって探索ではない |
| H1 が不成立（過程 reward が結果 reward に勝てない） | 負の結果を記録し、ラインを再評価 |

いずれかが発火したら ADR-0021 の規律に従う：新しい事前登録か新しい ADR を書き、古い判据は書き換えない。

## Consequences

- 計算資源は Paper C と規模実験から SoS へ移る；
- Paper C の設計草案（`paper/c/DESIGN.md`）は残すが**執筆は進めない**——前提は 40 件の注釈と
  召喚カバレッジで、どちらもいまメインライン上にない；
- 代償：**SoS が失敗するリスクは高い**——W3 がすでにこのラインで一度失敗している。受け入れる理由は、
  SoS が変えるのが**学習信号**（過程か結果か）であってパラメータではないこと。パラメータ側の失敗は
  ADR-0029 で書き切ってある；
- 代償：SoS には新しい部品（不確実性・複数軌跡）が必要で、短期的に公表できる数字は出ない。

## Alternatives

- **スパイク actor の直接訓練を続ける**：ADR-0029 でアーカイブ済み。同じ失敗の形で十数回。却下。
- **Paper C をメインラインにする**：LoCoMo の証拠カバレッジ@8 は 0.439 しかなく、エンドツーエンド比較は
  記憶システムではなく回答器を測ることになる。メインラインの資格を否定（設計草案は残す）。
- **SoS をやらない**：ユーザーが決定済み。却下。
