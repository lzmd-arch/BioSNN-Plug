# ADR-0023：LLM 協調の主張にはアブレーション腕を必須とする

[中文](ADR-0023-llm-ablation-arm.md) · [English](ADR-0023-llm-ablation-arm.en.md)

- **状態**：採用済み
- **日付**：2026-10-29
- **関連**：第 5 フェーズ M3a–M3k、[ADR-0024](ADR-0024-stub-llm-probe.ja.md)

## Context

本プロジェクトの賭けは「基質を機構で置き換える」ことです。学習と記憶は SNN の力学に住み、LLM は外部の推論エンジンにすぎません。しかし LLM を繋いだ瞬間、それは基質を静かに連れ戻します——回答品質は主にモデルのものであり、SNN のものではありません。既存の第 5 フェーズ結果（M3b：完了率 0.975 対 ベースライン 0.350）には同一タスクでの LLM 有無のアブレーションが無く、「SNN 側が何に寄与したか」を答えられません。

## Decision

第 5 フェーズの各協調結論は**三腕**を同時に報告する：

1. **SNN-only**：LLM なし、記憶検索と規則のみ；
2. **SNN + stub-LLM**：LLM はプレースホルダ回答のみを返し、「呼び出し経路」と「モデル内容」を分離；
3. **SNN + real-LLM**：実モデル。

単腕の数字（特に real-LLM のみ）は受入に使わない。

## Consequences

- 約 3 倍のコストだが、帰属が可能になる：経路の寄与とモデルの寄与を分ける；
- M3b の 0.975 は三腕再実行の後でのみ協調の証拠になる；
- 代償：実 LLM の呼び出し回数と費用が増える。

## Alternatives

- **real-LLM のみ**：現在のやり方で帰属不能；却下。
- **stub のみ**：経路は検証できるがモデルの価値は示せない；同様に不完全。
