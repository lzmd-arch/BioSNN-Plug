# ADR-0037：版番号の振り直し——旧 V1 は V0.5 として保管、人格・記憶核が V1 になる

[中文](ADR-0037-version-renumbering-anchor-v1.md) · [English](ADR-0037-version-renumbering-anchor-v1.en.md)

- **状態**：承認済み
- **日付**：2026-11-15

## Context

2026-11-14 まで「V1」は **Semprea-4.5B**（Qwen 4B 凍結＋0.5B の局所規則ハーフを
**出力分布**で融合）を指していた。この版は凍結済みで、動かない負の結果を三つ残している：
トークン単位の融合四演算子はいずれも温度対照を超えられなかった；スパイク側は生成・
符号化・判別・系列で四連敗（0/543、0.015、0.763、0.562）；実バックボーン上の加法的
条件バイアスは二度ゼロ（S0）。

その後方針が変わり、融合は**出力分布**から**人格と記憶**へ移った。ローカル側は生成器
として競うのをやめ、**錨**（同一性・記憶・行動制約）となり、生成はクラウドに任せる。
この路線は正の結果を出している：プール状態の復号 0.64–1.0、読み出し層の継続学習
AF 0.80→0.22、危機ゲートの再現率 0.996（FPR 0.11）。

ここで名前の衝突が生じた：無関係な二つが同じく V1 を名乗っている。

## Decision

1. 旧 Semprea-4.5B を **V0.5** に振り直し、**保管して外部公開を停止**する。
   結果と負の知見は保持し、引用時は `V0.5` と書く。
2. 人格・記憶核を **V1** とし、名称を **Semprea-Anchor-0.5B**（中国語：錨核）とする。
3. 本 ADR 以前の文書では「V2」は「V1」、「V1」は「V0.5」と読む。
   歴史的文書は書き換えない（時刻の意味が壊れる）。
4. `dist/semprea-4.5b-v1.0/` と `dist/v1.0/` はそのまま残し、それぞれに
   `ARCHIVED.md` を置いて本 ADR を指す。

## Consequences

- 外部向けの説明は「V0.5 は出力レベルの融合で、保管済み。四演算子はいずれも温度対照を
  超えていない」。
- **V1 の判定基準はトークン単位の利得ではなく**、`prereg-persona-in-weights.md` の I-1…I-7。
- パッケージ名 `persona-core` は変えない——機構の名前であって版の名前ではない。

## Alternatives

- **旧を V1 のままにし、新しいものを V2 と呼ぶ**：V1 が二つ併存するか、まだ存在しない
  もののために V2 を空けることになる。どちらも「V1 はどうか」の指示対象が一つでなくなる。
- **旧を V1-final、新を V1-next と呼ぶ**：同じ曖昧さを、より深く隠すだけ。
