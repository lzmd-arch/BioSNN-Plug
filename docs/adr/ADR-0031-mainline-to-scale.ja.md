# ADR-0031：メインラインをスパイク SoS から規模実験へ移す

[中文](ADR-0031-mainline-to-scale.md) · [English](ADR-0031-mainline-to-scale.en.md)

- **状態**：採用済み
- **日付**：2026-11-03
- **関連**：[ADR-0029](ADR-0029-research-line-archival.ja.md)、[ADR-0030](ADR-0030-mainline-shift-to-spiking-sos.ja.md)、`research/sos/`、`benchmarks/maze/`

## Context

ADR-0030 は SoS の中核主張——**探索の過程を見せるほうが最適解を見せるより探索を学ぶ**（以下 H1'）——
を根拠にスパイク SoS をメインラインとしました。三つの前提を挙げ、整うまで訓練しないと決めました。

三つとも整い（P1 は `sweep_results/sos_e1_v4/`、P2/P3 は E2–E7 で実装）、その後 H1' は**二度、
独立に**検証されました：

| 設定 | モデル | コーパス | `D_search − D_opt` |
| :--- | :--- | :--- | :--- |
| E6 | テーブル softmax（変位＋壁＋朝向） | 迷路 100 | **−0.015 [−0.045, +0.015]** |
| E7 | GRU(128) | 迷路 2000 | **−0.005 [−0.050, +0.050]** |

いずれも区間が 0 をまたぎ、点推定も正ではありません。E7 では両アームとも迷路を **0.90** で解いており、
課題は解決済みなのに差は測れません。

一方でこのラインは三つの資産を残しました：迷路ベンチマーク（難度 23 通り）、世界モデルの不確実性
（p1_ready：rho 0.842、カバレッジ 5/5）、そして「**状態／記憶こそがボトルネック**」の階段
（0.14 → 0.39 → 0.74 → 0.93）。

しかし**メインライン**としては中核主張を支える証拠がありません。2026-11-03、ユーザーが決定しました：
メインラインを**規模実験**へ移す。

## Decision

1. **メインラインを規模実験へ**：イベント駆動 e-prop の路線で循環層を **5k–8k ニューロン**まで押し上げ、
   一つの具体的な問いに答える——**この規模で精度はサイズとともにどう伸び、代償（メモリ／実時間）は
   いくらか。**
2. **SoS は研究項目に降格し、メインラインの計算資源を占めない。** 三つの資産は引用可能なまま残す：
   迷路ベンチマーク（`benchmarks/maze/`）、世界モデルの不確実性（E1）、状態の階段。
3. **規模の判据は実行前に落とす**：「大きいほど良い」の物語ではなく、**固定予算での精度-規模曲線**と
   資源曲線を報告する。

## 既知の硬い制約（同じ道を再び歩かないために書く）

- **稠密経路の上限は循環ニューロン約 1.35k**（計画書 v6.3 の資源スキャン、log-log 傾き 0.863）；
- **イベント駆動経路は 10k を既に走っている**：疎重み 320k、1 回の update 0.10 s、60k サンプル 1 epoch が
  **40 分 / acc 0.697**（単一 epoch、精度の結論ではない）；
- 500k の**単一 batch update** は 5.27 s で、外挿すると epoch 訓練は不可能。

つまり 5k–8k は「載るかどうか」ではなく「**載った上で割に合うか**」の問いです——それを測ります。

## 再評価の条件

| 条件 | 結論 |
| :--- | :--- |
| 5k–8k が 1k–2k を **2 ポイント**しか上回らない | 規模はこの路線のボトルネックではない。拡幅を止め、軸を変える |
| epoch の実時間が **4 時間**を超える | 8 GB の民生カードでは反復不能。使えないものとしてアーカイブ |
| 同規模の稠密よりイベント駆動が**明確に低い**（稠密が載る場合） | 疎実装に欠陥がある。規模を語る前に実装を直す |

## Consequences

- 計算資源は SoS から規模スキャンへ移る；
- SoS の資産は無駄にならない：迷路ベンチマークと状態の階段は固定済み、H1' の零結果は本 ADR に
  記録したので誰も再実行しなくてよい；
- 代償：規模実験は**おそらく平坦な曲線**を出す——W2 は 256 ニューロンで既に 0.8889 であり、
  広げて伸びるかは未知数。平坦な曲線を後から「調整不足」と言い訳しないよう、先に書いておく。

## Alternatives

- **SoS にさらに投入**（transformer + Countdown の再現）：費用最大、しかも二度支持されず。却下。
- **Paper C 方法論に戻る**：前提（40 件の注釈）が手元になく、証拠カバレッジ 0.439 ではエンドツーエンド比較が
  回答器を測ることになる。メインラインには不適。
- **メインラインを置かず保守に入る**：ユーザーは規模を推すことを選択。却下。
