# ADR-0015：世界模型成为阶段四的正式组件

[English](ADR-0015-world-model-as-phase-four-component.en.md) · [日本語](ADR-0015-world-model-as-phase-four-component.ja.md)

- **状态**：已采纳（组件**立项**，排期不动）
- **日期**：2026-10-24
- **相关**：计划书 §2.2（认知核心）、§七（阶段划分）；[ADR-0016](ADR-0016-arousal-channel-and-consolidation-experiment.md)（同批动力学轴裁决）；[research/eprop](../../research/eprop/README.md)（Predictive E-prop 的定位）

## Context

**计划书里没有世界模型这个组件。** 2026-10-24 的盘点把最接近的四样东西逐一对了一遍，没有一样是它：

| 现有的 | 它是什么 | 缺什么 |
| :--- | :--- | :--- |
| 工作记忆 RSNN | 对**当前**输入的维持 | 不预测"如果动作不同会怎样" |
| Predictive E-prop | 有误差信号，没有预测对象 | 预测的是自身状态，不是环境动力学 |
| 情景记忆 | 过去发生过什么 | 是"曾经"，不是"假如" |
| 元认知门控 | 对不确定性的监控 | 不产生候选未来 |

按 Dreamer 一类的标准，一个世界模型至少要四块：**动作条件化的动力学**、**想象/规划回路**、
**世界模型质量指标**、**明确的预测对象**。四块本项目一块都没有。

**为什么此前没有，以及为什么现在需要。** 此前没有不是疏忽：一到三阶段的目标是"规则能不能学"，
不需要一个会预测未来的模型——预测是**在规则被验证之后**才值得花钱的东西。现在需要，是因为动力学轴
的盘点暴露了"厚而不均"：R-STDP 与 Critic 已有验证，而巩固、唤醒、世界模型这些**跨时间的部件**
要么在册未实现，要么连名字都没有。世界模型是其中最贵、也最能给其它部件提供度量的一块：
没有它，"巩固是否改善了预测"这类问题连问法都没有。

## Decision

**① 世界模型立为阶段四的正式组件**，承接 Predictive E-prop（它提供误差信号的机制，世界模型提供
预测的对象）。**当前排期不动**：一到三阶段的任务与验收标准一个字不改。

**② 组件的定义收窄到可验收的四条**，缺一条就不算"有了世界模型"：

| 条 | 验收形式 |
| :--- | :--- |
| 动作条件化动力学 | 给定状态与动作，预测下一状态；换动作必须换预测 |
| 明确的预测对象 | 状态（或状态的低维投影）与奖励，二者分开报 |
| 质量指标 | 预注册的预测误差指标，与"不做预测"的基线比 |
| 想象/规划回路 | 阶段四后期；可先用**一步**前向代替多步 rollout |

**③ 边界写死**：世界模型回答"如果"，情景记忆回答"曾经"，工作记忆回答"现在"。
三者共用表征不是问题，**共用措辞**是问题——文档与代码里不许混用。

## Consequences

- 阶段四的任务表要新增这一行，并给出上面四条各自的验收；**在那之前它只是立项，不是排期**。
- 质量指标必须在**看到任何数字之前**预注册，否则"世界模型有用"和"预测器拟合了训练分布"分不开。
- 与 [ADR-0014](ADR-0014-adaptive-arbitration-unmeasurable-and-fit-retained.md) 同一条纪律：
  **可测量的东西才有资格进组件表**；不可测量的先留在探索项里。
