# ADR-0029：三条研究线的归档与「暂缓」的边界

[English](ADR-0029-research-line-archival.en.md) · [日本語](ADR-0029-research-line-archival.ja.md)

- **状态**：已采纳
- **日期**：2026-11-02
- **相关**：[ADR-0018](ADR-0018-task-aware-cl-gate.md)、[ADR-0019](ADR-0019-stage-four-entry-decoupled-from-relearn.md)、[ADR-0021](ADR-0021-criterion-death-conditions.md)、[阶段四状态](../stage4_status.md)、[触发判据 v2](../../sweep_results/phase5_trigger_v2/README.md)

## Context

三条研究线各自跑了很多轮，都停在「再调一次也许就行」的状态。没有一份文件说清**哪条到此为止、
哪条还要继续**，于是算力和注意力按惯性分配：谁最近碰过，谁就继续烧。

三条线的现状（全部有落盘的预注册与结果）：

1. **纯 CIL（无任务 oracle 的类增量学习）**：纯 CIL ACC **8.76%**、AF **0.290**；任务推断最好
   **0.5855 / 0.1285**。ADR-0018 已把 CL 门改成任务感知后过线（oracle per-task **0.8195 / AF 0.0**），
   ADR-0019 又把阶段四的入口与该指标解耦。**纯 CIL 这条已不再有任何判据挂在它身上。**
2. **W3 的脉冲 actor-critic（R-STDP + TD-LTP）**：D10–D15 十轮诊断的结论是「读出受噪声与量化
   双重限制」——差的方向在，幅度只有 **0.5%–7.3%**；换读出、调阈值都不放大它，只有 K 窗平均
   有效，且提升 ∝ **K^0.6**。储层演员 v3（冻结储层 + 两种读出）的 H1/H2 在 10 个种子上中位数
   **10.0 / 12.0**，判据是 200，过线 **0/10**。
3. **阶段五的触发器**：M3l–M3p 反复出现「换一批语料优势就没了」。判据 v2 把失败拆开之后，
   **误触发控制成立**（500 次随机划分的误触发率均值 **0.100 = α**），**失败落在打分函数**
   （命中均值 **0.385**，仅 **9%** 的划分 ≥ 0.50）。判据 v3 正在检验一个更基础的问题：
   M3p 的目标轮是脚本安排的事实句，表面线索可能就把语料解开了。

## Decision

1. **纯 CIL 归档。** 不再新开纯 CIL 实验，不再为它分配算力。CL 的验收口径以 ADR-0018 为准。
2. **W3 脉冲 actor-critic 归档。** 不再在该线上投入训练。速率版执行层照常保留——归档的是
   「用脉冲读出做策略」这条路线，不是执行层本身。
3. **阶段五触发器不归档，标为「暂缓」。** 它的判据是好的、误触发控制是成立的，坏的是分数与
   （可能）语料。v3 的结论出来之前，不做新的分数（那是下一份预注册的事），也不把整条线判死。

## 重新开启的条件（先写下，不靠事后判断）

| 线 | 什么证据会让归档失效 |
| :--- | :--- |
| 纯 CIL | 出现**带真实任务边界**的长序列（不是人工切分的基准），且任务推断能到 **0.8** 以上 |
| W3 脉冲 actor | 规模实验（5k–8k 神经元）证明读出限制来自**规模**，而不是「发放率读出」这个做法本身 |
| 触发器 | 出现**目标轮不由脚本安排**的语料，且某个分数族在 T-2 上 **≥ 0.50** |

三条都要求**新预注册**，不得把旧结果重新解释成通过（ADR-0021）。

## Consequences

- 算力从两条死线里释放出来，集中到 Paper C 与规模实验；
- **归档不等于删证据**：三条线的预注册、结果与负结果全部留在仓库里，可被重新引用；
- 代价：如果真有人解决了读出限制、或拿到了真实任务边界，这两篇归档不会自动复活——必须有人
  按上表重开预注册；
- 代价：触发器只标「暂缓」，意味着它仍占一点注意力到 v3 出结果为止。这是有意的：v2 刚证明
  判据本身没坏，此时归档等于把还能修的部件一起扔掉。

## Alternatives

- **三条全归档（含触发器）**：v3 还没跑，而 v2 已经把失败定位到了分数。此时归档是用「结果
  不好」代替「诊断清楚」，本仓库一贯反对这种做法。否决。
- **三条都不归档、继续迭代**：前两条已经在**同一种失败形态**上各撞了十轮以上（读出限制、
  判据不可达），继续投入是把「再调调」当成方法。否决。
- **按时间自动过期**（例如「三个月没进展就归档」）：不写证据条件的过期只是懒惰。否决。
