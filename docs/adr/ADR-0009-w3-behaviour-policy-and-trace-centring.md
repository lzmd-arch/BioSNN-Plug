# ADR-0009：W3 的行为策略改为 Boltzmann 采样并按采样概率中心化痕迹

- **状态**：已采纳
- **日期**：2026-09-23
- **相关**：计划书 §3.2、§七 第一阶段；[ADR-0007](ADR-0007-td-ltp-critic-provenance.md)；
  `research/rstdp/rstdp.py`、`research/rstdp/cartpole.py`、`research/rstdp/README.md`

## Context

W3（R-STDP + TD-LTP Critic 在 CartPole 上）长期未达标：≥10 种子中位数 **100.0 步**，阈值 200。
本阶段把失效模式测清楚之后，定位到**两个叠在一起的问题**。

### 一、确定策略下不存在可学的目标

`learn_step` 只在**非探索步**更新 Actor，而那些步的 `action = argmax` 是状态的**确定性**
函数。于是更新只落在被选中那一列——实测 `U 只碰到一列的状态占比 = 1.0000`（离散事实，
不依赖任何阈值）。

更根本的是：`A(s, π(s)) ≡ 0` 是**恒等式**（强制走策略自己会走的动作、再按策略走，那就是
`V^π` 的定义）。所以「优势加权方向」这个目标在**访问到的状态上恒等于零**——实测
`逐状态 |T| 中位数 = 0.0000`。原因是好策略访问到的状态上杆子接近竖直、**两个动作几乎等价**。

合起来：规则拿到的不是「方向不对」，而是**没有可学的目标**。被选中那一列拿到的是与动作
无关的残差 δ 造成的漂移。这也解释了长期观察到的两件事：策略在全程大幅游走（二十条曲线
相邻检查点差 5–30 倍），以及 `|U|/|T|` 很大（那是**分子小**——目标近零——不是分母小）。

### 二、评测路径本身有缺陷

`select_action` 在 `boltzmann` 分支**不看 `exploration`**，直接按 softmax 采样；而
`_greedy_score`（途中曲线与末次验收**都**走它）传的是 `exploration=0.0`。于是那一档的
「贪心评测」量的是一个**随机策略**，而那个尺度的天花板极低：**满分**策略（启发式，500 步）
在动作准确率 70% 时只值 97.4 步、60% 时只值 36.3 步。这是与截断、RNG 污染、采样池上限、
错误符号论证并列的**第五个同类缺陷**，而且它的代价已经落地——它把本阶段唯一有效的杠杆
判成了「无效」并写进了三语 README。

## Decision

1. **`action_sampling="boltzmann"`**：按 `softmax(logit_scale · 得分)` 采样，**每一步都更新
   Actor**（没有「探索步」这回事）。`logit_scale` 是必需的——L1 归一化后两列得分差只有
   0.05–0.5，不放大的 softmax 几乎是均匀的。
2. **`trace_center="sampling"`**：痕迹第二因子取 `a_j − π_j`，其中 π 是**采样**分布。
   它的期望是 0，所以 `E[Δw] = η·E[x·(a−π)·S]` 里那个「要求 Critic 逐状态无偏」的偏置项被
   精确消掉；而且**未选中的那一列会被削弱**——这正是此前结构上缺失的**动作比较**。
   **断言**：`trace_center="sampling"` 只在 `boltzmann` 下有意义。ε-贪心下 `a_j − π_j ≡ 0`，
  会让 Actor 完全停摆——代码里用 `ValueError` 挡住，不让它静默停机。
3. **逆温度退火**：`logit_scale` 从 **2** 在 **log 空间**插值到 20（或 40）。恒定值的两端各丢
   一半：近均匀（5）学得起来但策略一直钝（中位数 141.4）；较尖锐（20）上限高（留出集 177.3、
   最大 494）但**约十分之一的轨迹从头到尾启动不了**（峰值仅 10–12 步）。退火先钝后尖，
   把最小值从 9 抬到 90–123。log 空间插值是因为 `logit_scale` 是温度的倒数，线性插值它等价于
   对温度做双曲退火（前期过慢、后期过快）。
4. **`select_action(greedy=True)`**：**无视采样方案**返回 `argmax`。评测路径必须走它。
   ε-贪心下与原 `exploration=0.0` 路径逐位一致（所以既有数字全部不变）。
5. 验收配置沿用本仓库的惯例——**显式指定**（与 `actor_lr_final_fraction=0.1` 同一层），
   但把上述四项设为默认值，使默认运行即达标配置。

## Consequences

- **达到 §七 字面判据的两项**：留出种子（25–44，20 个，完全未参与任何选择）中位数
  **260.0**（阈值 200）、偏移最大 **0.0359**（阈值 0.10，全部种子通过）。
  选择集（0–9）中位数 250.4——两者接近，说明这不是种子选择效应。
- **未达到「稳定」这一附加条件**：最小值 **74**（我们自己预登记的口径要求 ≥100），
  20 个种子里 2 个低于 100。诊断：那两颗的**峰值是 90–124**，是「学得不够好」，
  **不是塌陷**（对比恒定温度下峰值仅 10–12 的真正塌陷）。所以失败模式已经换了一种。
- **「W3 验的是什么」随之变化**：训练期的行为策略从「ε 衰减到 0.02 的 ε-贪心」变成
  「Boltzmann 采样 + 逆温度退火（2 → 20）」。**部署与验收仍然是 `argmax`**，所以 §七
  判据量到的对象没变。
- **局部性不变**：非局部量仍然只有标量 δ；新增的是每个动作单元**自己的** π_j——一个由该
  单元自身输入算出的标量，而 `trace_center="sampling"` 早已在用同一个量。
- 默认行为改变，因此 `--seed 0` 之类的历史数字（例如 114.6）对应的是**旧默认**；
  它们在 README 的账里保留为对照，但不再是「默认配置」的结果。

## Alternatives

- **动作混合 `π = (1−κ)·onehot(argmax) + κ/n`**（用固定 κ 解耦策略尖锐度与少数动作的采样率）：
  **否决**。对抗性复核指出 κ=0.2 时 `(0.9, 0.1)` 与 ε-贪心 ε=0.2 是**同一个分布**，部署策略
  也都是 argmax——而 boltzmann 分支**本来就没有闸门**，所以它相对现状新增的内容只有
  「评测修理」，而那件事不需要它。此外它自立的通过线（逐状态余弦 > 0.95）在它自己的规则下
  **数学上不可达**（恒为 `1/√2`）。
- **按动作拆开 Critic（两群 Q，用 `A = Q − V` 驱动 Actor）**：**否决**。Frémaux 原文的 Actor
  规则本来就是「只有被直接负责该动作选择的那些被强化」，所以这不是偏离；而把 δ 换成 A
  **只改调制量、不改痕迹**，Actor 的信用结构逐位不变。且它所属的族已在账上测过
  （Boltzmann 不中心化：配对 −26.0、2/10 变好）。
- **论文 Eq. 37 的性能驱动学习率调度**：**暂缓**。复核指出按其现有形式少一个 7 倍因子，
  `eta/peak ∈ [0.871, 1.000]`，于是「性能塌了就回升到一个大步」这个机制在实现里
  **不可能出现**。即便修回因子，晚期 η 仍高于唯一有效杠杆的终点 3e-4。另：论文里
  `eta_act = 0.5·eta_crit`（Critic 是 Actor 的两倍）与本仓库「Critic 调快是 0/10 灾难」
  直接冲突，需要单独考证后另开 ADR。
- **固定有符号读出（`readout="random"`）**：**否决**。Frémaux 原文 Eq. 13 把价值定义成群体的
  **平均发放率**——`readout="uniform"` 就是论文，有符号读出才是偏离。它确实把解释方差从
  −1.00 改到 −0.21、平均绝对误差减半，但步数 **0/10 变好**（配对 −50.7；按 σR 补偿后仍 −40.6）。
