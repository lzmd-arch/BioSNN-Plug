# ADR-0021：判据死亡条件必须先写

[English](ADR-0021-criterion-death-conditions.en.md) · [日本語](ADR-0021-criterion-death-conditions.ja.md)

- **状态**：已采纳
- **日期**：2026-10-29
- **相关**：计划书 §12.4、[ADR-0022](ADR-0022-restatement-dashboard.md)、阶段三/四/五的全部预注册

## Context

本仓库的判据被重述过三次：跨模态检索从 R@1 改为恢复率；TAAF 的「无需微调」标准被 ADR-0012 消解；仲裁判据被 P4 协同性基准取代。三次重述各有正当理由，但**没有任何规则约束重述本身**——重述可以在看到结果之后发生，于是「判据」随时可以变成事后解释。

阶段三的口径复核（台账 148）又暴露了另一种死亡：判据没变，但**测量口径**（best 与末次）不同，结论会反转。判据的死亡条件必须与判据同时写下。

## Decision

1. 每份预注册必须包含「**死亡条件**」一节：写明在什么证据下该判据作废或需要重述，以及重述时必须做什么（新开预注册、登记原因、链接旧文）。
2. 死亡条件必须在**看到数据之前**写下；事后补充无效。
3. 重述不得直接改旧预注册的判据；只能新开一份并注明取代关系。
4. 每次重述登记进 [ADR-0022](ADR-0022-restatement-dashboard.md) 的仪表板。

## Consequences

- 重述变慢、变贵，但不再能静默发生；
- 负结果更难被「换个判据」绕过；
- 代价：早期实验的预注册没有死亡条件，只能在新一轮补写，旧轮不追认。

## Alternatives

- **禁止任何重述**：会冻结明显错误的判据（如 v4 自相矛盾的 R²/MSE 判据）；否决。
- **只靠作者自觉**：已经失效三次；否决。
