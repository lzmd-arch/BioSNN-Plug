# ADR-0014：自适应仲裁「不可测量」、`ESArbiter.fit` 保留待命，以及 P4 的标题转向

[English](ADR-0014-adaptive-arbitration-unmeasurable-and-fit-retained.en.md) · [日本語](ADR-0014-adaptive-arbitration-unmeasurable-and-fit-retained.ja.md)

- **状态**：已采纳
- **日期**：2026-10-24
- **相关**：[ADR-0013](ADR-0013-synergy-benchmark-priority-and-arbiter-scope.md)（协同性基准升为 P0）；[`sweep_results/arbiter_synergy_task_spec.md`](../../sweep_results/arbiter_synergy_task_spec.md)（预注册与两次目标检验）；[`sweep_results/arbiter_synergy/`](../../sweep_results/arbiter_synergy/README.md)（结果）；[research/arbiter](../../research/arbiter/README.md)

## Context

协同性基准 v3 的五种子结果显示：固定 50/50 混合显著优于任一单臂（Fisher 0.651 对 0.472 / 0.331，
协同量 +0.179），但 **ES 学出的 α 与冻结 0.5 逐位相同**——目标是整数冲突事件数，在 α = 0.5
附近恒为 0，没有梯度，α 一步未动。

随后按裁决先写预注册、再检验两个候选目标：

1. **Fisher 直接当目标**：8 / 50 / 200 / 800 步探针上，Fisher 对 α 的极差 0.026–0.039，
   不随步数增长也不随 α 单调——是噪声。完整训练需 37,480 步才到 0.65，探针够长的代价约 7 小时。
2. **连续代理**（两臂余弦均值）：峰在 α = 0.9（Fisher 的峰在 0.5），且 **α = 0 与 α = 1
   给出同一个值 0.501**，而这两个端点的 Fisher 差 0.14。

两个候选各自在自己的检验上失败，**自适应臂因此未运行**。

## Decision

**① 措辞红线：「不可测量」不是「被证伪」。** 任何文档与论文里，不得写"仲裁器没有价值"。
准确表述是：**自适应仲裁在本基准中不可测量**——在预算约束内（单次 ≤ 主导数单种子耗时的 5%、
总 ≤ 2×）不存在通过预检验的目标函数；唯一已知有效的目标（全程探针）标价约 **7 小时**，
留作 future work。静态 0.5 的胜出只说明"在这个基准上没人能用便宜的方法打败它"。

**② `ESArbiter.fit` 保留，但标注为"待命"而非"现役"。** 它是一次有 72 条测试支撑的库改进，
回退是浪费；但必须满足三条：

1. `fit()` 的 docstring 写明：**未用于任何已报告结果**，协同基准臂因无目标通过预检验而未运行；
2. 公开状态：当前**没有任何裁决认可的目标挂载在这个 `fit()` 上**；
3. 本 ADR 即为其登记。

**③ P4 的标题级问题改写。** 头条不再是"仲裁能否买回局部性代价"，而是
**「When Can Arbitration Be Measured?」**——把"我们没测成"转化为"测的成本结构本身"。

**④ 两个阴性诊断进 Discussion**，因为它们的诊断价值高于结果本身：

* **时间尺度分离**：混合权重对表征质量的影响只在收敛后显现——短程指标在原则上无法为
  长程训练做目标。这对所有用短程指标做外层优化的 ES 元学习工作是具体警告；
* **对齐 ≠ 可分性**：代理测的构念与验收测的构念不是同一样东西（α = 0 与 α = 1 在代理上同值、
  在 Fisher 上差 0.14）。

## Consequences

- 论文里"自适应 α 打败静态 0.5"这一问**保持开放**，并附带明确标价：这是从"不可行"到
  "有明确价格"的升级，而不是一条否定结论。
- `research/arbiter` 的三语 README、DESIGN.md、结果文档与任务规格统一到新措辞；
  预注册原文保留不动，措辞变更以**数据之后的日期**单独标注，不改判据。
- 若将来要重开这条线，前置条件是：**先有一个在可接受成本内通过区分力检验的目标**，
  再谈自适应臂；在那之前不产生任何"自适应 α 更好"的结论。
- P4 的 §3.3 triviality 分析至此四案齐：α→0 退化、逐突触余弦退化、整数目标 ES 惰性、
  代理-构念错位。
