# ADR-0017：CL の主路線を Route R へ切り替え、リプレイを先行させる

[中文](ADR-0017-cl-main-route-switch-and-replay-first.md) · [English](ADR-0017-cl-main-route-switch-and-replay-first.en.md)

- **状態**：採用済み
- **日付**：2026-10-25
- **関連**：計画書 §七 第 3・4 フェーズ、§5.2；[ADR-0015](ADR-0015-world-model-as-phase-four-component.ja.md)；[事前登録 v2](../../sweep_results/continual_v2_replay_prereg.md)；[formal_cil](../../sweep_results/continual_cifar100/formal_cil/README.md)

## Context

第 3 フェーズの持続学習の正式実行（W1 特徴 + delta 読み出し、事前登録 CIL 口径）は
**ACC 0.0876 / AF 0.290**。同じ特徴上で、**タスク id を与えた oracle 上界でも 0.322** に
とどまります。失敗の形は破滅的忘却（最終行の旧タスクがすべてゼロ）ですが、より根本的な
制約は**表現層**です。oracle でも 65% の門に届かず、リプレイは「特徴が 100 クラスを
分離できない」問題を直せません。

探索期の Route R（凍結 ResNet18 avgpool + クラス原型）は ACC 0.658 / AF 0.127 を報告しましたが、
この 2 値は**旧い累積クラス集合の行列**で計算されたもので CIL 口径ではありません。基準として
使う前に再測定が必要です。

## Decision

1. **CL 研究の主路線を Route R（凍結した強い表現 + 抗忘却）へ切り替える**。**Route W は
   宣言済みの元の路線として残し**、そのまま報告を続ける。削除も書き換えもしない。
2. 機構は**帰属の連鎖**で並べる：**リプレイを先行**、足りなければ正規化、さらに足りなければ
   パラメータ隔離。**一度に一つだけ**。
3. **第 4 フェーズの入口を「Route R + リプレイ：AF < 8% かつ ACC ≥ 65%」に書き換える**
   （CIL 口径）。具体的なしきい値は Step 0 の再測定基線から導き、結果 README に日付を
   添える——**旧い 0.658/0.127 をそのまま当てはめない**。
4. **第 3 フェーズを分割**：3a（本日終了、そのまま封存）/ 3b（リプレイ腕；「3 倍の再学習」の
   設計はリプレイ結果の後；スパイク W3 の診断はしきい値を書き終えてから GPU を使う）。
5. 旧結果と旧事前登録は編集しない。本 ADR と日付が、路線変更が門を通すためのものではない
   という証拠になる。

## Consequences

- latent replay（クラスごとに固定枠の特徴バッファ、ρ ∈ {0.1, 0.3}）を実装し、**まず** Route R
  の基線を再測定する必要がある；
- 「3 倍の再学習」とスパイク診断の日程は変えないが、それぞれリプレイ結果の後／しきい値の
  記述後に待つ；
- 第 4 フェーズの構成要素（世界モデル、神経発生）は第 3 フェーズの受入で引き続き門控される。
  世界モデルの打底（1 歩ダイナミクス、rollout、Acrobot）は門の状態を変えない。

## Alternatives

- **正規化を先に**：リプレイの帰属を汚し、汎用トリックでもある。先に使うと「どの機構が効いたか」
  という答えを捨てることになる；
- **パラメータ隔離（EWC 系）を先に**：P4 §2.4（正規化はタスク境界のない衝突を扱えない）と
  緊張する。同じ論文で引用しながら使うことはできない；
- **Route W に留まる**：oracle 上界が 32.2%。65% の門は表現層で破綻しており、リプレイでは
  特徴を直せない。
