## Context

ADR-0032 把 SEL 立为研究项，路径是 **TI-LIF + CWSSA + 选择性 SSM + 蒸馏 + 在线
R-STDP**。P0–P4 走完了：

| 阶段 | 结果 |
| :--- | :--- |
| P0 TI-LIF | `biosnn_bus.TernaryMembrane` 0.6.0；`D=1, signed=False` 与 `AdaptiveMembrane` 逐位一致 |
| P1 召回 | 负结果：ALIF / TI-LIF hit@1 0.012，词法基线 0.259 |
| G1 门控 | 负结果：TI-LIF AUROC 0.410，词法基线 0.825 |
| P2 教师 | 模板命中 T1 58% 过；T4 风格离散 0.5B 0.88×、1.5B 0.76×、3B 0.99×，均未达 0.5× |
| P3 数据 | 391 对（301/44/46），D1–D4 全过；教师降级为 Phase 1（1.5B GGUF） |
| P4 学生 | 5 种子 × 10k 步：P4-1/P4-2 过，**P4-3 不过** |

P4 的五种子中位数（两臂同为 CE-only，不是 KD）：

| 臂 | test top-1 | test CE | 中位秒 |
| :--- | ---: | ---: | ---: |
| bigram（分母） | 0.6457 | — | — |
| GRU(256) | 0.8831 [0.8795, 0.8846] | 0.5203 [0.4686, 0.5540] | 83 |
| ALIF(512) | 0.8685 [0.8634, 0.8729] | **0.4594** [0.4304, 0.5518] | 620 |
| TI-LIF(512, D=3) | 0.8641 [0.8532, 0.8685] | 0.5274 [0.4987, 0.8482] | 946 |

P4-1（≥0.7457）与 P4-2（≥GRU−5pp=0.8331）过；**P4-3 的 TI-LIF CE 是 ALIF 的
1.148×**（要求 ≤0.90×），5 个种子里 4 个同种子比较更差。P4-4 因缺少 tokenizer
对齐而 N/A（`prereg_p4_amend1.md`）；P4-5 生成验收尚未做；P4-6 成本过。

**要区分概念与路径。** "换后端模型时语气不变"这个产品痛点仍然真实；TI-LIF/ALIF
作为神经元实现数值正确；失败的是**用 TI-LIF + CWSSA + SSM + KD 在 8 GB 显存、
CPU 教师和字符级对齐缺失的条件下做蒸馏**这一条路径的效率。

## Decision

1. **SEL 脉冲蒸馏路径停止。** P4 之后不启动 P5 在线 R-STDP；不实现 CWSSA/SSM；
   不再补 KD。P3 的数据不用于蒸馏。
2. **产品侧以 Phase 2（模板 + 模型混合渲染）为回退。** 不把脉冲表达层接进产品；
   Phase 2 当前仍默认关闭，T4 未过，文档与界面不得声称"语气已统一"。
3. **P3 的 391 对教师数据保留，可转作 SFT 语料。** 这是数据复用，不是蒸馏；
   另写数据卡与训练预注册后才能用。数据仍不入库。
4. **研究端唯一活跃线是线 A（脑区特化）。** 预注册已锁
   （`research/brainregions/prereg-brain-region-specialization.md`）；2 臂 × 3 种子的第一轮
   已起跑（2026-11-04），结果待出；
   ALIF-only SEL 只作为远期备选，现在不写预注册、不分配算力。
5. **Paper C 的叙事按已归档结果调整**：§4.1 脉冲 SoS 归档；§4.2 容量轴归档；
   §4.3 线 A 预注册；§5 SEL 写成"脉冲表达层的尝试与技术路径反思"，不写成"实现"。

到这里，四条硬边界都摸到了：**纯 CIL（ADR-0029）、脉冲 SoS（ADR-0031）、
容量轴（ADR-0033）、SEL 脉冲蒸馏（本 ADR）**。

## 重新开启条件

以下任一条成立时要**另写预注册**，不得把本 ADR 当挡箭牌：

- **ALIF-only SEL**：去掉 CWSSA/SSM/KD，只保留 ALIF 表达层；先回答教师质量、
  数据来源与评测口径三件事；
- **有 tokenizer 对齐层**：能把 token 级教师分布边缘化到字符级学生，才谈 KD；
- **工作点变化**：出现 >8 GB 显存、或更小的教师/学生组合，使 P4-3 的效率比
  可以在公平预算下测量；
- **产品侧新需求**：出现可量化的语气一致性需求，且 Phase 2 的 T4 仍过不了。

## Consequences

- 不再为 SEL 分配训练算力；P5 取消；`research/sel/` 保留代码、预注册与结果供复现；
- 产品继续 Phase 2，默认关；不发布权重、不接产品；
- P3 数据可复用于 SFT，但需要新的数据使用说明与预注册；
- Paper C §5 写成反思章节，避免把"概念成立"偷换成"路径成功"；
- ADR-0032 是立项，本文是收口：**概念保留、路径停止**。

## Alternatives

- **把 P4-3 不过解释成"再多训几步"**：否决。5 种子中位数已经稳定，预注册写死
  ≤0.90×；继续加步数没有预注册依据；
- **改 T4 口径让 Phase 2 变绿**：否决。T4 是跑之前定的尺子，跑完再换是主张漂移；
- **用 P3 数据直接做 SFT 并宣称 SEL 成功**：否决。SFT 是另一条路径，需要新的
  预注册与评测，不能继承 SEL 的结论；
- **把召回/门控的负结果当成 SEL 的失败**：否决。任务不同；SEL 的收敛点在 P4-3，
  不在 P1/G1。
