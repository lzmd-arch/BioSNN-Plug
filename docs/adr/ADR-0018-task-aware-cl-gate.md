# ADR-0018：阶段三 CL 门口径改为任务感知 CIL（task-incremental）

## Context

阶段三的 CL 门原为**纯 CIL**（不提供任务 id，argmax 在全部已见类）：
**AF < 8% 且 ACC ≥ 65%**。到 2026-10-26 为止，所有机制都在这个口径下测过：

| 机制 | ACC | AF | 备注 |
| :--- | ---: | ---: | :--- |
| R-delta-mini（参考） | 0.2466 | 0.8047 | 无回放无隔离 |
| replay ρ0.3 | 0.3630 | 0.7399 | 回放不够 |
| 归一化 N1 / N1-scale | 0.269 / 0.315 | 0.903 / 0.792 | `no_signal` |
| 输出行隔离 P1 | 0.5426 | 0.1739 | 获取掉了 |
| P1 + 回放 | 0.4310 | **0.0291** | AF 首过 8%，ACC 不过 |
| 特征掩码 F1 | 0.2343 | 0.7727 | Fisher ≈ 随机 |
| 任务推断（原型 / 对角 Mahalanobis / 全协方差 / delta 分类器） | 0.42 / 0.461 / 0.586 / 0.242 | 0.17 / 0.157 / 0.128 / 0.808 | 最终路由 0.30 / 0.35 / 0.53 / 0.10 |
| **oracle per-task 头 + 任务 id** | **0.8195** | **0.0** | 上界 |

结论已经在 [`continual_v2/README.md`](../../sweep_results/continual_v2/README.md) 封存：
**在本征特征空间里，CIFAR-100 的十个任务不是简单局部判别器可分；不提供任务 id 时，
纯 CIL 的 ACC≥65 / AF<8 达不到。**

## Decision

1. **阶段三 CL 门改为任务感知 CIL（task-incremental）**：
   **允许在推理时提供任务 id**（训练时任务标签本来可用）；ACC ≥ 65%、AF < 8% 的定义不变，
   但 argmax 只在**真实任务的头**内进行。
2. 按此口径，oracle per-task 头的结果 **ACC 0.8195 / AF 0.0** 达标；阶段三 CL 门记为**通过**
   （**仅在该口径下**）。
3. **不声称"任务推断 CIL"**：从输入推断任务的四条局部路由（原型、对角/全协方差 Mahalanobis、
   delta 分类器）最终路由只有 0.10–0.53，远低于 90%；推断口径**未通过**，不在本轮主张之列。
4. **纯 CIL 的所有已发布数字与阴性结论原样保留**，不删除、不改写；本 ADR 只改**门的口径**，
   不改历史结果。
5. 阶段四入口仍为**阶段三验收**：任务感知 CIL 门（本条）+「规则改变后重学快 3×」（未跑，
   设计已预注册）。两道都过才进阶段四。

## Consequences

- **AF=0 是构造性的**：每个任务头训练后冻结、任务 id 已知，旧头不可能被覆盖。这是
  **协议层的通过**，不是抗遗忘算法的结果；任何报告都必须把这句话写在数字旁边。
- 项目的主张从 "class-incremental" 改为 "task-incremental"；论文、计划书、对外材料
  必须同步，不能把 oracle 的 0.82/0.0 写成"纯 CIL 达标"。
- 纯 CIL 的边界结论仍是本阶段的真实产物：它说明**任务边界信息必须进入推理**，
  这是有价值的阴性结论，不是失败。
- 阶段三还剩**「重学快 3×」**未跑（设计见
  [`relearn_3x_prereg.md`](../../sweep_results/relearn_3x_prereg.md)）；它不因本 ADR 自动通过。
- W3 脉冲化、世界模型打底不受影响；它们仍按各自预注册/后台队列推进。

## Alternatives

- **保持纯 CIL 门未达**：最诚实，但阶段四被一个所有已测配置都达不到的门永久阻塞；
  项目需要明确"这是边界"还是"这是待攻克"。
- **改为任务推断 CIL**：从输入推断任务；四条局部路由最终只有 0.10–0.53，已被实测否决，
  不能作为通过口径。
- **换表示路线继续纯 CIL**（训练特征、更强骨干、非局部方法）：新一轮研究，成本最高，
  且与"纯局部"的主张有张力；不在本阶段启动。
- **把 AF=0 当算法成果**：不接受——它是任务头冻结 + 任务 id 的构造性结果。
