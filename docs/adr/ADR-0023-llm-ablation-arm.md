# ADR-0023：LLM 协同结论必须带消融臂

[English](ADR-0023-llm-ablation-arm.en.md) · [日本語](ADR-0023-llm-ablation-arm.ja.md)

- **状态**：已采纳
- **日期**：2026-10-29
- **相关**：阶段五 M3a–M3k、[ADR-0024](ADR-0024-stub-llm-probe.md)

## Context

本项目的赌注是「机制替代基质」：学习与记忆住在 SNN 的动力学里，LLM 只是外部推理引擎。
但只要 LLM 一接入，它就会把「基质」偷偷带回来——回答质量主要是模型的，不是 SNN 的。
现有阶段五结果（M3b：完成率 0.975 vs 基线 0.350）没有 LLM 与 no-LLM 的同任务消融，
无法回答「SNN 侧贡献了什么」。

## Decision

阶段五的每个协同结论必须同时报**三臂**：

1. **SNN-only**：没有 LLM，只有记忆检索与规则；
2. **SNN + stub-LLM**：LLM 只返回占位回答，用来分离「调用管道」与「模型内容」；
3. **SNN + real-LLM**：真实模型。

只报单臂（尤其只报 real-LLM）的协同数字不进入验收。

## Consequences

- 成本约 ×3，但结论可归因：管道贡献 vs 模型贡献分开；
- M3b 的 0.975 只能在三臂重跑后作为协同证据；
- 代价：真实 LLM 的调用次数与费用上升。

## Alternatives

- **只跑 real-LLM**：当前做法，无法归因；否决。
- **只跑 stub**：能验证管道，但不能证明模型价值；同样不完整。
