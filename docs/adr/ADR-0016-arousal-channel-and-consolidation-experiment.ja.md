# ADR-0016：覚醒チャネルのコンポーネント化と、固定化の比較実験の予定

[中文](ADR-0016-arousal-channel-and-consolidation-experiment.md) · [English](ADR-0016-arousal-channel-and-consolidation-experiment.en.md)

- **状態**：採択
- **日付**：2026-10-24
- **関連**：計画書 §3.4（動力学軸）、§七（フェーズ）；[ADR-0015](ADR-0015-world-model-as-phase-four-component.ja.md)（同批次）；`research/arbiter`（retention 割引の項目）

## Context

2026-10-24 の動力学軸の棚卸しは三つの所見を出した。本 ADR はそのうち二つを扱う。

**① 欠落：覚醒にコンポーネント名がない。** 計画書は動力学軸にホルモン・情動・固定化・本能を
挙げているが、**覚醒（arousal）** は形容詞としてしか現れず、コンポーネントも状態変数も
インターフェースも存在しない。同じ穴に**「本能」**もある——「遺伝的に符号化された配線規則」は
形だけで名前がなく、引用も受入もできない。

**② 逆転：固定化は本番で動き、研究では検証ゼロ。** ターミナル Axo の常駐プロセス `axo.busd` は
毎日固定化（「夢」）を行っているが、本プロジェクトには固定化の利益を測った**実験が一つもない**。
これは最も危険な状態である：**「動いているから検証済み」に見える**が、利益は一度も測られていない。

## Decision

**① 覚醒チャネルを動力学軸の正式コンポーネントとする。**

| 項目 | 定義 |
| :--- | :--- |
| 状態変数 | スカラー `arousal`。入力強度と直近の発火統計から更新し、**逆伝播では訓練しない** |
| 作用点 | 他コンポーネントの**ゲイン**を変調する（固定化頻度・探索温度・覚醒閾値）。重みを直接変えない |
| 「本能」との関係 | 本能をチャネルの**下位項目**として命名する：**学習なしに存在する**初期値と配線規則 |
| やらないこと | 生物学的構念との等価を主張しない。本プロジェクト独自の制御変数である |

**② 固定化の比較実験を予定する**（GPU 半日、第 5 フェーズの予行）：

| 項目 | 値 |
| :--- | :--- |
| 問い | 固定化の有無で**遅延想起**は改善するか |
| 事前登録指標 | N 回遅延後の想起率の差（対応あり・シードごと）と、固定化自体のコスト（時間／エネルギーの代理量） |
| 対照 | 固定化なし；順序をシャッフルした固定化（「もう一度走らせただけ」を排除） |
| 主張の境界 | 現行のタスクと実装に限る。生物学的睡眠への外挿はしない |

## Consequences

- **「daemon が動いている」はもはや検証ではない**。本番は製品を動かし、研究は数字を要する。
  どちらも同じ `run_consolidation` を使うが、**検証は実験だけが与える**。
- 覚醒がコンポーネントになれば、状態依存のゲインはすべてこのスカラーの関数として書く。
  コード各处のマジック定数は認めない。
- 固定化実験は ADR-0015 と同じ規律を共有する：指標を先に事前登録し、それから数字を見る。
- これで計画書の動力学軸の棚卸しにある二つの ❌（覚醒・本能に名前がない）は閉じる。
  `retention = 0.3` の割引は ADR-0014 の表現で `research/arbiter` に残る。
