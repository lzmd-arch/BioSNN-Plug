# ADR-0014：適応的仲裁は「測定不能」、`ESArbiter.fit` は待機状態で保持、P4 は見出しを転換

[中文](ADR-0014-adaptive-arbitration-unmeasurable-and-fit-retained.md) · [English](ADR-0014-adaptive-arbitration-unmeasurable-and-fit-retained.en.md)

- **状態**：採択済み
- **日付**：2026-10-24
- **関連**：[ADR-0013](ADR-0013-synergy-benchmark-priority-and-arbiter-scope.ja.md)（協同性ベンチマークを P0 へ）；[`sweep_results/arbiter_synergy_task_spec.md`](../../sweep_results/arbiter_synergy_task_spec.md)（事前登録と二つの目的関数の検証）；[`sweep_results/arbiter_synergy/`](../../sweep_results/arbiter_synergy/README.md)（結果）；[research/arbiter](../../research/arbiter/README.ja.md)

## Context

協同性ベンチマーク v3 の 5 シード結果では、固定 50/50 混合が単腕を明確に上回った
（Fisher 0.651 対 0.472 / 0.331、協同量 +0.179）。しかし **ES が学んだ α は凍結 0.5 と
ビット単位で同一**だった——目的関数が整数の衝突イベント数で、α = 0.5 付近では恒等的に 0、
勾配がなく α は一度も動いていない。

その後、事前登録を先に書いたうえで二つの候補を検証した：

1. **Fisher を目的にする案**：8 / 50 / 200 / 800 ステップの探針で、α に対する Fisher の
   レンジは 0.026–0.039。ステップ数でも α でも単調に伸びない——ノイズである。完全な訓練は
   37,480 ステップを要して 0.65 に達するため、α が見える長さの探針は約 7 時間かかる。
2. **連続代理**（混合更新と両腕の余弦の平均）：ピークは α = 0.9（Fisher のピークは 0.5）、
   しかも **α = 0 と α = 1 で同じ値 0.501** を与える。両端の Fisher は 0.14 離れているのに。

それぞれが自分の検証で落ちたため、**適応腕は実行していない**。

## Decision

**① 表現のレッドライン：「測定不能」は「反証された」ではない。** 文書・論文のいずれでも
「アービターに価値はない」と書いてはならない。正確な表現は：**このベンチマークにおいて
適応的仲裁は測定不能**——予算制約（1 回の評価 ≤ 主导数 1 シードの 5%、総計 ≤ 2×）の範囲内で
事前検証を通る目的関数が存在しない。唯一有効と分かっている目的（全程探針）は約 **7 時間**の
値札が付き、future work とする。静的 0.5 の勝利は「このベンチマーク上で、安く勝てる方法が
誰にも無い」ことしか意味しない。

**② `ESArbiter.fit` は保持し、「待機」と表示する（現役ではない）。** 72 件のテストに支えられた
ライブラリの改善であり、差し戻しはその資産の無駄になる。ただし次の三条件を満たす：

1. `fit()` の docstring に、**報告済みの結果には一切使われていない**こと、
   協同ベンチマーク腕が事前検証を通る目的関数の不在により未実行であることを明記する；
2. 公開状態として、**この `fit()` に裁定に承認された目的関数は現在搭載されていない**；
3. 本 ADR をもって登録とする。

**③ P4 の見出しの問いを転換する。** 「仲裁は局所性の代償を取り戻せるか」から
**「When Can Arbitration Be Measured?」**へ——「測れなかった」を「測ることのコスト構造」へ
変換する。

**④ 二つの陰性診断は Discussion に入れる**。結果そのものより診断価値が高いため：

* **時間スケールの分離**：混合重みが表現品質に効くのは収束後であり、短い視野の指標は
  原理的に長い訓練の目的関数になりえない。短い指標で外側を最適化する ES メタ学習研究への
  具体的な警告になる；
* **整列 ≠ 可分性**：代理が測る構成概念と受入が測る構成概念は別物（代理では α = 0 と
  α = 1 が同値、Fisher では 0.14 差）。

## Consequences

**⚠️ 執行機構のない制約は制約ではない。** 両側境界を実装して分かったこと：
「より良い候補」だけを受け入れる探索では、α は**区間の外に留まったまま**形式的には
制約を満たしてしまう——開始 0.5、区間 [0.2, 0.3] でも結果は 0.5 のまま。
これは `α → 0` と同じ家族である：**最適化器は制約の外に駐車することで制約を満たした
ふりができる**。修正は入口での clip とテスト；今後のあらゆる制約に対して
「違反状態が拒否されずに生き残れるか」を問うこと。

- 「適応 α は静的 0.5 に勝つか」は**未決のまま**残り、明示的な値札が付く。「実行不能」から
  「値段が付いた」への昇格であり、否定結論ではない。
- アービターの三言語 README、`DESIGN.md`、結果文書、タスク仕様を新しい表現に揃える。
  事前登録の原文は動かさず、表現の変更には**データ取得後の日付**を付し、判定基準は変えない。
- この路線を再開する前提は、まず**許容コストで識別力検証を通る目的関数**を持つこと。
  それまでは「適応 α の方が良い」という結論を出さない。
- P4 の退化解分析（本文の一節＋付録 C）はこれで四件揃う：α→0 の退化、逐シナプス余弦の退化、
  整数目的 ES の惰性、代理と構成概念の不一致。
