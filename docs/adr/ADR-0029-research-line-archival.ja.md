# ADR-0029：研究ライン 2 本のアーカイブと「保留」の境界

[中文](ADR-0029-research-line-archival.md) · [English](ADR-0029-research-line-archival.en.md)

- **状態**：採用済み
- **日付**：2026-11-02
- **関連**：[ADR-0018](ADR-0018-task-aware-cl-gate.ja.md)、[ADR-0019](ADR-0019-stage-four-entry-decoupled-from-relearn.ja.md)、[ADR-0021](ADR-0021-criterion-death-conditions.ja.md)、[第 4 フェーズの状態](../stage4_status.ja.md)、[トリガ基準 v2](../../sweep_results/phase5_trigger_v2/README.md)

## Context

3 本の研究ラインはどれも何十回と回してきて、いずれも「もう一度調整すれば通るかもしれない」
状態で止まっています。**どこまでで終わり、どれを続けるのか**を書いた文書が無いため、計算資源と
注意力は惰性で配分されます——直近で触ったラインが燃やし続ける。

3 本の現状（いずれも事前登録と結果が残っています）：

1. **純 CIL（タスク oracle 無しのクラス増分学習）**：純 CIL の ACC **8.76%**、AF **0.290**、
   タスク推論の最良は **0.5855 / 0.1285**。ADR-0018 が CL ゲートをタスク認識型に変えて通過
   （oracle per-task **0.8195 / AF 0.0**）、ADR-0019 が第 4 フェーズの入口をこの指標から切り
   離しました。**純 CIL に判据はもう掛かっていません。**
2. **W3 のスパイク actor-critic（R-STDP + TD-LTP）**：D10–D15 の十数回の診断は「読み出しが
   雑音と量子化の二重制約を受ける」に収束——差の向きはあるが大きさは **0.5%–7.3%**、読み出しや
   しきい値を変えても増えず、K 窓平均だけが効いて伸びは **K^0.6** に比例。リザバー actor v3
   （凍結リザバー＋2 種の読み出し）の H1/H2 は 10 シードで中央値 **10.0 / 12.0**、判据は 200 で
   **0/10**。
3. **第 5 フェーズのトリガ**：M3l–M3p は「コーパスを替えると優位が消える」を繰り返しました。
   判据 v2 が失敗を分解し、**誤発火の制御は成立**（500 回のランダム分割で平均 **0.100 = α**）、
   **失敗はスコア関数**（命中率平均 **0.385**、0.50 に届く分割は **9%** のみ）。判据 v3 はいま
   より基本的な問いを検証中です：M3p の目標ターンはスクリプトが配置した事実文なので、表層の
   手がかりだけでコーパスが解けてしまう可能性があります。

## Decision

1. **純 CIL をアーカイブ。** 新規の純 CIL 実験は行わず、計算資源も配分しません。CL の受入口径は
   ADR-0018 に従います。
2. **W3 のスパイク actor-critic をアーカイブ。** このラインへの学習投入を止めます。レート版の
   実行層はそのまま残します——アーカイブするのは「スパイク読み出しで方策を学ぶ」路線であり、
   実行層そのものではありません。
3. **第 5 フェーズのトリガはアーカイブせず「保留」。** 判据は健全で誤発火制御も成立しており、
   壊れているのはスコアと（おそらく）コーパスです。v3 の結論が出るまで、新しいスコアは試さず
   （それは別の事前登録）、ライン全体を死んだともしません。

## 再開の条件（後から判断せず、いま書く）

| ライン | どの証拠があればアーカイブが無効になるか |
| :--- | :--- |
| 純 CIL | **本物のタスク境界**を持つ長い系列（人手で分割したベンチマークではない）で、タスク推論が **0.8** 以上に達する |
| W3 スパイク actor | 規模実験（5k–8k ニューロン）で、読み出しの制約が「レート読み出し」という手法ではなく**規模**に由来すると示される |
| トリガ | **目標ターンがスクリプト配置でない**コーパスで、いずれかのスコア系が **T-2 >= 0.50** に達する |

いずれも**新しい事前登録**を要求します。古い結果を通過と読み替えてはいけません（ADR-0021）。

## Consequences

- 計算資源が 2 本の死んだラインから解放され、Paper C と規模実験に集中できます；
- **アーカイブは証拠の削除ではありません**：3 本の事前登録・結果・負の結果はすべてリポジトリに
  残り、再引用できます；
- 代償：読み出し制約が本当に解決されたり、本物のタスク境界が手に入ったりしても、このアーカイブは
  自動では復活しません——上の表に従って誰かが新しい事前登録を開く必要があります；
- 代償：トリガを「保留」に留める以上、v3 の結果が出るまで多少の注意力を占有します。これは意図的
  です：v2 は判据自体が壊れていないことを示したばかりで、いまアーカイブするのは直せる部品まで
  捨てることになります。

## Alternatives

- **3 本ともアーカイブ（トリガ含む）**：v3 はまだ走っておらず、v2 は失敗をスコアに特定済みです。
  いまアーカイブするのは「結果が悪い」を「原因が分かった」の代わりにすることで、本リポジトリが
  一貫して拒んできた姿勢です。却下。
- **1 本もアーカイブせず反復を続ける**：最初の 2 本は**同じ失敗の形**で十数回ぶつかっています
  （読み出し制約、到達不能な判据）。続けるのは「もう一度調整すれば」を方法論にすることです。却下。
- **時間による自動失効**（例：「3 か月進展が無ければアーカイブ」）：証拠条件を書かない失効は
  ただの怠慢です。却下。
