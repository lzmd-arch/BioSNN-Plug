# ADR-0030：主线切换到脉冲 SoS

[English](ADR-0030-mainline-shift-to-spiking-sos.en.md) · [日本語](ADR-0030-mainline-shift-to-spiking-sos.ja.md)

- **状态**：已采纳
- **日期**：2026-11-02
- **相关**：[ADR-0029](ADR-0029-research-line-archival.md)、[阶段四状态](../stage4_status.md)、[Paper C 设计草案](../../paper/c/DESIGN.md)

## Context

W3 的脉冲 actor 已经在**同一种失败形态**上撞了十几轮：读出受噪声与量化双重限制，
差的方向在、相对幅度只有 0.5%–7.3%，换读出与调阈值都不放大它（ADR-0029 已归档）。
继续往"直接学策略"里加算力，是把"再调调"当成方法。

阶段四留下两件可用的东西，但它们**都还不是策略**：

- 世界模型 AUROC 1.0 / FP 0.0009——它是 **one-step 动力学预测**，给定状态与动作预测下一状态；
- 工作记忆 0.9990——它能存住当前状态，但**不支持分支与重置**。

中间的缺口是"**用预测去找动作序列**"。SoS（Gandhi et al., CoLM 2024，arXiv 2404.03683）给的证据是：
让模型学**搜索过程**（探索、死路、回溯、再试）比让它学**最优轨迹**更能形成搜索能力。

用户于 2026-11-02 拍板：脉冲 SoS 作为新主线。

## Decision

1. **主线切到脉冲 SoS**：后续的算力与注意力优先给它，Paper C 降为非主线。
2. **三条前提先落地，未落地不跑训练**：
   - 世界模型输出**不确定性估计**（预测方差），而不只是点预测；
   - **R-STDP 的 reward 重定义**：从"外部成功信号"改为"预测误差的减少"；
   - **多轨迹实验框架**：N 条并行轨迹 + 重置/回溯的接口。
3. 前提落地之前，本阶段允许的产出只有三样：**实验设计、预注册、最小可行环境（网格/迷宫）的骨架**。
   预注册必须写进 `research/sos/`，判据先落盘。

## 重新评估条件（先写下）

| 条件 | 结论 |
| :--- | :--- |
| 简单迷宫/网格上成功率 **< 80%** | 回退，不追加投入，按负结果归档 |
| 搜索步数**不随任务难度自适应** | 同上——那说明学到的是固定策略，不是搜索 |
| H1 不成立（过程 reward 没有优于结果 reward） | 记录负结果，重新评估这条主线 |

任何一条触发，都按 ADR-0021 的规矩：新开预注册或新写 ADR，不得回改旧判据。

## Consequences

- 算力从 Paper C 与规模实验挪到 SoS；
- Paper C 的设计草案（`paper/c/DESIGN.md`）保留，但**不推进写作**——它的前置是 40 条标注与召回覆盖率，
  两件都不在主线上了；
- 代价：**SoS 的失败风险很高**——W3 已经在这条线上失败过一次。接受这个风险的理由是：
  它换的是**学习信号**（过程 vs 结果），不是换参数；换参数的失败已经被 ADR-0029 写死；
- 代价：SoS 需要的新部件（不确定度、多轨迹）都不小，短期不会有可发表的数字。

## Alternatives

- **继续直接训练脉冲 actor**：ADR-0029 已归档，同一种失败形态撞了十几轮。否决。
- **以 Paper C 为主线**：LoCoMo 召回的证据覆盖@8 只有 0.439，端到端对比主要在量答题器，
  不是在量记忆系统。否决它作为主线的资格（设计草案保留）。
- **不做 SoS**：用户已拍板。否决。
