## Context

判定基準の書き換えは計画書・結果 README・ADR に散在し、「この線は何度書き換えられたか、なぜか」を一目で答えられません。ADR-0021 は各書き換えの記録を求めますが、記録先が一つでないと記録自体が漂流します。

## Decision

本文末のダッシュボードを書き換えの**唯一**の登録先とします。各書き換えは一行追加：日付、基準、from → to、理由、リンク（ADR／事前登録／台帳）。古い行は編集せず、訂正は新しい行で行います。

## Consequences

- 書き換えが数えられるようになる。「何度目か」が記憶に依存しない；
- 代償：書き換えごとに記録の一手間。記録漏れはレビューで見つかり得る（CI はまだ強制しない）；
- ダッシュボードは書き換えの正否を判定しない。起きた事実だけを記録する。

## Alternatives

- **各 README に分散記録**：すでに分散し、全体像が無い；却下。
- **issue/PR で記録**：単独リポジトリで PR フローが無い；却下。
