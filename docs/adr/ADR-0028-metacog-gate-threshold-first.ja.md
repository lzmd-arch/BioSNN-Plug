# ADR-0028：メタ認知ゲート — 仕組みは実物どおりに実装し、製品側はまず閾値を測る

[中文](ADR-0028-metacog-gate-threshold-first.md) · [English](ADR-0028-metacog-gate-threshold-first.en.md)

- **状態**：採用済み
- **日付**：2026-11-01
- **関連**：メタ認知 v8–v11、[ADR-0021](ADR-0021-criterion-death-conditions.ja.md)、
  `BioSNN-Plug_项目计划书_v6.3_amend1.md`、Axo の `docs/prereg-metacog-v1.md`

## Context

外部の統合タスク指示書は「メタ認知ゲート」を**検証済みの 512 ニューロン SNN 部品**
（「MG v11 は検証済み、三次元ゲートは OOD をすべて通過」）と書いていた。両リポジトリを
確認した事実は次のとおり：

- MG v11 は 4 次元のエピソード記憶課題において、読み出し残差 `[max_errors, errors,
  state_norm]` の 3 スカラーによる **kNN(5) 密度ゲート**である。スパイクも ALIF も
  e-prop もなく、重みファイルも存在しない。
- 自身の README が「四ファミリすべて通過」は 4 種類の**合成入力変換**のみを指し、
  汎用 OOD の証明ではないと明記している。
- `biosnn_bus` の `SpikeBus` は依然として骨格（`state()` なし、層なし）。

Axo は**実物の仕組み**（3 スカラーを召回台帳の `top_score` / `mean_topk` / `density` に
対応）を実装し、217 件の実ライブラリの複製でオフライン評価した：ゲートの AUROC は
**1.000**、単一特徴 `top_score` の閾値も **1.000**（難正例 0.996 対 0.996）。事前登録の
判定基準（+0.05 以上の増分）は**未達**のため、配線していない。

## Decision

1. **名前ではなく仕組みを実装する。** 「MG v11 / メタ認知 SNN を接続する」という要求は、
   まず `research/cognitive/run_metacognitive_gate_v11.py` の実物と突き合わせる。存在
   しない部品を前提にした提案は書き直す。
2. **製品側はまず閾値を測る。** 「弱い記憶を注入しない」は召喚層の融合スコア閾値 1 本で
   実装し、実ライブラリで較正する（未知話題の top スコア最大 0.163、正例の p5 は 0.211
   → 閾値 0.20）。
3. **増分を必須の判定基準にする**：配線前に AUROC が最良の単一特徴ベースラインより
   0.05 以上高いこと。満たさなければ自明解として扱う
   （[ADR-0021](ADR-0021-criterion-death-conditions.ja.md) と同じ規律）。
4. **スパイク版はスケジュールに載せるが実装しない。** 着手条件（bus に層がある／
   ラベル付き自然言語 OOD 集合がある／レート版が製品に入り計測済み）は
   `BioSNN-Plug_项目计划书_v6.3_amend1.md` に記載する。

## Consequences

- 研究層の MG v11 は自ベンチマークで動く部品としてリポジトリに残る。製品は使わない。
- 不透明な層が 1 つ減る。閾値は説明でき、戻せて、分布の曲線が根拠になる。
- 代償：製品における「メタ認知」は「カットオフ 1 本」に縮退する。現時点の証拠が支持
  する唯一の主張である。

## Alternatives

- **指示書どおり SNN ゲートを接続**：部品が存在せず、研究をゼロから始めて検証を飛ばす
  ことになる。却下。
- **三次元ゲートを接続（閾値と同等）**：AUROC は同じで複雑さと調整点だけが増える。却下。
- **一切フィルタしない**：未知話題でも毎回約 60 件の弱関連記憶を注入する。実在する
  製品上の傷である。却下。
