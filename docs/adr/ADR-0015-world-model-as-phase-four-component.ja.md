# ADR-0015：世界モデルを第 4 フェーズの正式コンポーネントとする

[中文](ADR-0015-world-model-as-phase-four-component.md) · [English](ADR-0015-world-model-as-phase-four-component.en.md)

- **状態**：採択（コンポーネントの**登録**であり、スケジュールは動かさない）
- **日付**：2026-10-24
- **関連**：計画書 §2.2（認知コア）、§七（フェーズ）；[ADR-0016](ADR-0016-arousal-channel-and-consolidation-experiment.ja.md)（同批次）；[research/eprop](../../research/eprop/README.ja.md)

## Context

**計画書に世界モデルというコンポーネントは存在しない。** 2026-10-24 の棚卸しで、最も近い
四つを順に照合したが、いずれも世界モデルではない：

| 既存のもの | 何であるか | 欠けているもの |
| :--- | :--- | :--- |
| 作業記憶 RSNN | **現在**の入力の維持 | 「行動が違えばどうなるか」の予測がない |
| Predictive E-prop | 予測対象を持たない誤差信号 | 環境の動力学ではなく自身の状態を予測する |
| エピソード記憶 | 起きたこと | 「かつて」であり「もし」ではない |
| メタ認知ゲーティング | 不確実性の監視 | 候補となる未来を生成しない |

Dreamer 系の基準では、世界モデルには少なくとも四つの部品が要る：**行動条件付きの動力学**、
**想像／計画ループ**、**品質指標**、**明示的な予測対象**。本プロジェクトには四つともない。

**なぜ今まで無かったか、なぜ今必要か。** 無かったのは見落としではない：第 1〜3 フェーズは
「規則が学べるか」を問うており、予測器は要らない。必要になったのは、動力学軸の棚卸しで
**厚いが不均一**だと分かったからである——R-STDP と Critic は検証済みだが、**時間をまたぐ**
部品（固定化・覚醒・世界モデル）は未実装か無名である。世界モデルはその中で最も高価であり、
他の部品に測るものを与える：これが無ければ「固定化は予測を改善したか」は問いとして成立しない。

## Decision

**① 世界モデルを第 4 フェーズの正式コンポーネントとする**。Predictive E-prop の誤差信号の
仕組みを継承し、予測の対象を供給する。**現行スケジュールは動かさない**：第 1〜3 フェーズの
タスクと受入基準は一字も変えない。

**② 定義は検証可能な四項目に絞る**。一つでも欠ければ「世界モデルがある」とは言わない：

| 項目 | 受入の形 |
| :--- | :--- |
| 行動条件付き動力学 | 状態と行動から次の状態を予測する。行動を変えれば予測も変わること |
| 明示的な予測対象 | 状態（またはその低次元射影）と報酬を分けて報告する |
| 品質指標 | 事前登録した予測誤差を「予測しない」ベースラインと比較する |
| 想像／計画ループ | 第 4 フェーズ後半。まずは**一歩**の前向き計算でよい |

**③ 境界を固定する**：世界モデルは「もし」、エピソード記憶は「かつて」、作業記憶は「いま」に
答える。表現の共有はよいが、**語彙の共有はよくない**——文書でもコードでも混用しない。

## Consequences

- 第 4 フェーズのタスク表にこの行が加わり、上の四つの受入が付く。**それまでは登録であって
  スケジュール項目ではない**。
- 品質指標は**数字が存在する前に**事前登録しなければならない。さもないと「世界モデルが効く」と
  「予測器が訓練分布に適合した」を分けられない。
- [ADR-0014](ADR-0014-adaptive-arbitration-unmeasurable-and-fit-retained.ja.md) と同じ規律：
  **測定可能なものだけがコンポーネント表に入る**。測定不能なものは探索リストに留める。
