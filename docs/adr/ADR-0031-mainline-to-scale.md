# ADR-0031：主线从脉冲 SoS 切到规模实验

[English](ADR-0031-mainline-to-scale.en.md) · [日本語](ADR-0031-mainline-to-scale.ja.md)

- **状态**：已采纳
- **日期**：2026-11-03
- **相关**：[ADR-0029](ADR-0029-research-line-archival.md)、[ADR-0030](ADR-0030-mainline-shift-to-spiking-sos.md)、`research/sos/`、`benchmarks/maze/`

## Context

ADR-0030 把脉冲 SoS 定为主线，立论基础是 SoS 的核心主张：**给搜索过程比给最优结果更能让模型学会搜索**（下称 H1'）。
它写了三条前提，并要求前提落地前不跑训练。

三条前提都落地了（P1 见 `sweep_results/sos_e1_v4/`，P2/P3 在 E2–E7 里实现），
然后 H1' 被**两次独立地**检验：

| 设置 | 模型 | 语料 | `D_search − D_opt` |
| :--- | :--- | :--- | :--- |
| E6 | 表格 softmax（位移+墙+朝向） | 100 张迷宫 | **−0.015 [−0.045, +0.015]** |
| E7 | GRU(128) | 2000 张迷宫 | **−0.005 [−0.050, +0.050]** |

两次都跨 0，点估计都不是正的。E7 那一版两臂都能把迷宫做到 **0.90**——任务被解决了，
差别仍然测不出来。

同时，这条线留下了三件站得住的东西：迷宫基准（难度跨度 23 档）、世界模型的不确定度
（p1_ready：ρ 0.842、覆盖 5/5）、以及「**状态/记忆才是瓶颈**」的状态阶梯（0.14 → 0.39 → 0.74 → 0.93）。

但作为**主线**，它的核心主张没有证据支持。用户于 2026-11-03 拍板：主线切到**规模实验**。

## Decision

1. **主线切到规模实验**：在事件驱动 e-prop 这条线上，把循环层推到 **5k–8k 神经元**，
   回答一个具体问题——**在这个规模上，精度随规模怎么长，代价（显存 / 墙钟）是多少。**
2. **SoS 降为研究项，不再占主线算力**。它的三件资产保留并可被引用：迷宫基准
   （`benchmarks/maze/`）、世界模型不确定度（E1）、状态阶梯这条结论。
3. **规模实验的判据要先落盘**：它不做"越大越好"的叙事，要报**固定预算下的精度-规模曲线**
   与对应的资源曲线。

## 已知的硬约束（写下来，避免又走一遍）

- **稠密路径的上限约 1.35k 循环神经元**（计划书 v6.3 §1163 的资源扫描，log-log 斜率 0.863）；
- **事件驱动路径已经跑过 10k**：稀疏权重 320k、一次 update 0.10 s、完整 1 epoch 60k 样本 **40 min / acc 0.697**
  （单 epoch，不作精度结论）；
- 500k 的**单 batch update** 5.27 s，按此外推 epoch 训练不可行。

所以 5k–8k **不是"能不能放下"的问题，是"放得下之后值不值"的问题**——这正是要量的。

## 重新评估条件

| 条件 | 结论 |
| :--- | :--- |
| 5k–8k 相对 1k–2k 的精度提升 **≤ 2 个百分点** | 规模不是这条管线上的瓶颈，停止加宽，转向别的轴 |
| epoch 墙钟超过 **4 小时** | 在 8 GB 消费级卡上不可迭代，按"不可用"归档 |
| 事件驱动在 5k–8k 上**精度显著低于**同规模稠密（若能放下） | 稀疏实现有缺陷，先修实现再谈规模 |

## Consequences

- 算力从 SoS 转到规模扫描；
- SoS 的资产不浪费：迷宫基准与状态阶梯的结论已经固化，H1' 的零结果写进本文档，后来的人不需要重跑；
- 代价：规模实验**大概率给出的是"曲线很平"**——W2 在 256 神经元上已经 0.8889，
  再加宽能不能涨是未知数；这一点写在前面，免得事后把平曲线解释成"没调好"。

## Alternatives

- **继续在 SoS 上加码**（transformer + Countdown 复现）：成本最高，且已经两次不支持。否决。
- **回到 Paper C 方法论**：它的前置（40 条标注）不在我手上，且召回覆盖率 0.439
  意味着端到端对比主要在量答题器。作为主线不合适。
- **不设主线、进入维护**：用户选择继续推规模。否决。
