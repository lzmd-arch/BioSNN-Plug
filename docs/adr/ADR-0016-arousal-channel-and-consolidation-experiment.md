# ADR-0016：唤醒通道组件化，以及巩固对比实验的排期

[English](ADR-0016-arousal-channel-and-consolidation-experiment.en.md) · [日本語](ADR-0016-arousal-channel-and-consolidation-experiment.ja.md)

- **状态**：已采纳
- **日期**：2026-10-24
- **相关**：计划书 §3.4（动力学轴）、§七（阶段划分）；[ADR-0015](ADR-0015-world-model-as-phase-four-component.md)（同批动力学轴裁决）；`research/arbiter`（retention 折扣的挂账）

## Context

2026-10-24 的动力学轴盘点得到三个结论，本 ADR 处理其中的两个：

**① 缺位：唤醒通道没有组件名。** 计划书在动力学轴列了激素、情绪、巩固、本能，但
**"唤醒"（arousal）** 这一档只以形容词出现，从来没有一个组件、一个状态变量、一个接口。
同一个洞里还有**"本能"**——"基因编码的布线规则"这个想法有形无实，没有名字，因而无法被引用或验收。

**② 倒挂：巩固在生产里跑，在研究中零验证。** 终端 Axo 的 `axo.busd` 常驻进程每天在做巩固
（"做梦"），而本项目**没有任何一个实验**测量过巩固带来的收益。这是最危险的一种状态：
**一个部件因为"在跑"而显得被验证过了**，实际上它的收益从未被测量。

## Decision

**① 唤醒通道立为动力学轴的正式组件。**

| 项 | 定义 |
| :--- | :--- |
| 状态变量 | 一个标量 `arousal`，由输入强度与近期发放统计更新，**不由反向传播训练** |
| 作用点 | 调制其它组件的**增益**（巩固频率、探索温度、唤醒阈值），不直接改变权重 |
| 与"本能"的关系 | "本能"作为唤醒通道的**子项**命名：那些**不经学习就存在**的初值/布线规则 |
| 不做什么 | 不声称唤醒等价于任何生物构念；它是本项目自选的控制器变量 |

**② 巩固对比实验排期**（半天 GPU，作为阶段五的预演）：

| 项 | 取值 |
| :--- | :--- |
| 问题 | 有巩固 vs 无巩固，**延迟召回**是否更好 |
| 预注册指标 | 延迟 N 轮后的召回率差（配对、逐种子），以及巩固本身的代价（时间/能量代理量） |
| 对照 | 无巩固；巩固但打乱巩固顺序（排除"多跑一遍"这个混淆） |
| 结论的边界 | 只在当前任务与当前巩固实现上成立；不外推到生物睡眠 |

## Consequences

- **"daemon 在跑"从此不算验证**。终端里跑的是产品，研究里要的是数字；两者共用同一份
  `run_consolidation` 实现，但**验证只能由实验提供**。
- 唤醒通道进入组件表后，凡是"随状态变化的增益"都必须写成对这个标量的函数，而不是散在各处的
  魔法常数。
- 巩固实验与 ADR-0015 的世界模型共用一条纪律：先预注册指标，再看数字。
- 计划书的动力学轴盘点里那两个 ❌（唤醒无名、本能无名）由本 ADR 关闭；`retention` 0.3 折扣
  那一项仍挂在 `research/arbiter`，按 ADR-0014 的措辞处理。
