# ADR-0021：判定基準の死亡条件を先に書く

[中文](ADR-0021-criterion-death-conditions.md) · [English](ADR-0021-criterion-death-conditions.en.md)

- **状態**：採用済み
- **日付**：2026-10-29
- **関連**：計画書 §12.4、[ADR-0022](ADR-0022-restatement-dashboard.ja.md)、第 3〜5 フェーズの全事前登録

## Context

本リポジトリの判定基準は三度書き換えられています。クロスモーダル検索は R@1 から回復率へ、TAAF の「微調整不要」基準は ADR-0012 で解消され、仲裁の基準は P4 相乗性ベンチマークに置き換えられました。いずれも正当な理由がありますが、**書き換え自体を縛る規則がありません**——結果を見た後に書き換えられるため、「基準」が事後説明になり得ます。

第 3 フェーズの口径再確認（台帳 148）は別の死を示しました：基準は変わらないのに**測定**（best と最終）が変わると結論が反転します。基準の死亡条件は基準と同時に書かねばなりません。

## Decision

1. 各事前登録に「**死亡条件**」節を必須とする：どの証拠で基準が無効／書き換え必要になるか、書き換え時に何をするか（新規事前登録、理由の記録、旧文書へのリンク）。
2. 死亡条件は**データを見る前**に書く。後付けは無効。
3. 書き換えは旧事前登録の基準を直接編集してはならない。新しい文書がそれを置き換える。
4. 各書き換えは [ADR-0022](ADR-0022-restatement-dashboard.ja.md) のダッシュボードに記録する。

## Consequences

- 書き換えは遅く高コストになるが、静かに起こることはなくなる；
- 負の結果を「基準を変える」ことで回避しにくくなる；
- 代償：初期実験の事前登録には死亡条件が無く、新しい回でしか追加できない（遡及しない）。

## Alternatives

- **書き換えを全面禁止**：明らかに誤った基準（v4 の矛盾した R²/MSE など）を凍結してしまう；却下。
- **著者の自覚に任せる**：すでに三度失敗している；却下。
