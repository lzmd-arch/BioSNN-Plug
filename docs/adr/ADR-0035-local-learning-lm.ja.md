# ADR-0035：局所学習規則による言語モデルの事前学習——新しい支線として再開、M0 を先行

[中文](ADR-0035-local-learning-lm.md) · [English](ADR-0035-local-learning-lm.en.md)

- **状態**：採用済み
- **日付**：2026-11-06
- **関連**：[ADR-0034](ADR-0034-sel-distillation-archival.ja.md)（SEL のアーカイブと再開条件）、
  [ADR-0029](ADR-0029-research-line-archival.ja.md)（研究線のアーカイブ）、
  [ADR-0033](ADR-0033-capacity-axis-archival.ja.md)（容量軸のアーカイブ）、
  `research/sel/prereg-lm-eprop.md`（M0 の判定基準）

## Context

ユーザーの目的は「少なくとも雑談できるモデル」。三つの事実が問題の形を変えました：

1. **本リポジトリは局所規則で言語モデルを訓練したことがありません。** P4 のスパイキング LM
   （`research/sel/student.py`）は `.backward()`（代理勾配＋BPTT）を使っています。本当の局所規則の
   実装（`research/eprop/event_driven.py`）は「系列に一つのラベル」の分類しか扱えません。
   したがって「局所学習で事前学習できるか」には**正例も反例もありません**。
2. **P4 の CE 0.5274 は BPTT の成績であり、局所学習の起点ではありません。** 局所モデルは
   CE = `ln V` から始まります。0.5274 を起点と誤解すると、基準を下限と取り違えます。
3. **ADR-0034 の再開条件の一つが満たされました**：「token レベルの教師分布を文字レベルの生徒へ
   周辺化できる tokenizer 整合層が存在すること」——`research/sel/probe_logprobs.py` が教師の
   top-5 カバレッジ **0.967** を実測しており、先頭文字への周辺化は算術的に可能です。

線 A（A1–A8）は間接的な支持を与えます：このパイプラインでは分類のボトルネックは**読み出し**であり、
学習規則ではありませんでした（読み出しの変更で 14–42pp、組織の変更で 0.3pp）。
これは言語モデルへ直接外挿できませんが、「局所規則は学べない」が既成事実ではないことを示します。

## Decision

**新しい支線を開く：局所学習規則による next-token の事前学習。** これは SEL 蒸留経路の復活では
ありません——SEL の TI-LIF + CWSSA + SSM + KD は停止したままで、製品は Phase 2 に留まります。

四つの固定した境界：

1. **M0 を先行し、判定基準を先に残す。** `research/sel/prereg-lm-eprop.md` の M0-1（top-1 ≥0.70）と
   M0-2（循環重みが実際に学習している）が**同時に**成立した場合のみ M1 に進めます。
   成立しなければ kill 基準に従って支線を止めます。
2. **製品に触れない。** 召回・ゲートに接続せず、重みも公開せず、Axo の既定バックエンドも変えません。
3. **データは本機から出さない。** 実会話の本文は本機の訓練にのみ使い、クラウドには合成の
   話題/SIR だけを送ります。データとチェックポイントは `D:\AxoData\sel\lm\` に置き、リポジトリには入れません。
4. **雑談できると主張しない。** 目標は**狭領域・単一〜少数ターン・人設内**のテキストです。
   汎用の雑談には 5〜7 桁上のデータと計算量が必要で、しかも「注意機構なし ⇒ in-context learning なし」
   というアーキテクチャ上の上限に縛られます。本 ADR の範囲外です。

技術的な要点（詳細は `research/sel/prereg-lm-eprop.md`）：

- **LIF＋領域ごとの τ** を使い、**ALIF は使わない**（`traces.py` の `epsilon_a` は O(B·N²) で、
  N=8192 では 4.3 GB）；
- **ストリーミング痕跡**を書き、`eprop_gradient` は再利用しない（後者は無条件に O(N²) を確保）；
- **分割訓練＝チャンク間の状態持ち越し**（v / z / 不応期 / 入力痕跡 / 循環痕跡 / タップのフィルタを
  すべて持ち越し、リセットは会話境界のみ）。**チャンク長は更新頻度を決め、記憶は τ が決める**——
  これが TBPTT との本質的な違いです。

## Alternatives

- **SEL 蒸留の再開**：却下。P4-3 が不合格（TI-LIF の CE は ALIF の 1.148×、基準は ≤0.90×）で、
  8 GB の作業点も変わっておらず、ADR-0034 の再開条件は満たされていません。
- **オープン LLM の微調整（QLoRA）**：技術的には可能ですが、別路線（局所学習ではない）であり、
  本プロジェクトの前提と衝突します。ユーザーは局所規則を維持することを明示的に選びました。
- **汎用基盤モデルをゼロから事前学習**：却下。6〜8 桁の差があり、本機でも本プロジェクトでも不可能です。
- **M0 を飛ばして規模へ**：却下。「局所規則が next-token を学べる」証拠なしに規模を拡大すると、
  「未検証」を「また一つの負の結果」に変えてしまいます。

## Consequences

**利点**：0.2 GPU 時間で「できるか」を判定できます。どちらの結果でも引用可能な境界になります。

**代償**：M0 のコーパスは 391 件のみ（テスト 46 件、top-1 の SE ≈0.9pp）で、信号の有無は判定できますが
大きさは測れません。M1–M5 は 50–200 GPU 時間に増えます。

**失敗時**：M0 が不合格なら負の結果を記録し、支線をアーカイブし、kill 基準が発動したことをここに追記します。
パラメータを調整して再実行したり、別シードで再試行したりしません。

**2026-11-06 追記：M0b も不合格、支線の停止を確定。**

M0b は隠れ層の学習率だけを上げ（`lr_in` 1e-3、`lr_rec` 1e-3）、他は変えていません。結果は
`sweep_results/lm_eprop_m0b/README.md`：

- 隠れ層は実際に動いた：`w_rec` の相対変化 **4.976%**（M0 は 0.070%、70 倍）。ただし事前登録の 5% 基準に
  対して **M0b-0 は 0.024pp 差で形式的に不合格**——規則に従い「実験は無効」と判定し、結論は出さず、
  学習率をさらに上げて再実行もしません；
- その前提の下で、**循環重みを学習すると悪化した**：CE 1.861 対 凍結 1.741（**+6.9%**）、top-1 0.516 対 0.566；
- どちらの版も**文字 bigram に負ける**（CE 1.423 / top-1 0.646）。

**結論**：1,024 ニューロン、2,000 updates、301 件のテンプレート・コーパスという作業点では、
逐次局所学習は二次の文字 bigram に勝てず、**循環重みの訓練は有害**です。この負の結果は M0 より強固で、
M0 の「差がない」は「測れていない」と言い訳できますが、M0b はできません。

**支線は停止**。二つの事前登録の kill 基準はともに実行済みです。再開に必要なのは**新しいコーパスと規模**
（M3 の段）であり、この作業点のハイパーパラメータ調整ではありません。


**2026-11-06 さらなる訂正：M0/M0b の kill は根拠を欠き、支線は再評価すべき。**

S0（`sweep_results/lm_eprop_s0/README.md`）は「再帰の出どころ」だけを変えた三臂を測りました：

| 臂 | CE | top-1 | 再帰／入力の電流比 |
| :--- | ---: | ---: | ---: |
| 再帰なし | **1.139** | **0.717** | 0× |
| 凍結ランダム再帰 | 1.861 | 0.516 | 2.16× |
| 凍結対角 SSM | 2.639 | 0.352 | 7.36× |

**順序は「再帰電流／入力電流」に対して完全に単調です。** 最初の二巡の再帰臂は初期化の時点で入力の
2.16 倍の電流を流しており、**テスト前からハンデを負っていました**——したがって
「局所学習は bigram に負ける」は成立しません。再帰を除くと、**前向き LIF＋局所学習の読み出しが
初めて bigram を上回ります（1.139 / 0.717 対 1.423 / 0.646）**。

**処置**：本 ADR の「停止」の結論は**撤回**します（数値は残り、推論は無効）。再開に新しいデータは不要で、
「再帰電流／入力電流 ∈ [0.8, 1.3]」を前提条件として書き込んだ**新しい事前登録**が必要です。
これは実装上の欠陥の修正であり、結果を緑にするための調整ではありません。
