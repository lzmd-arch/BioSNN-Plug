# ADR-0035：局所学習規則による言語モデルの事前学習——新しい支線として再開、M0 を先行

[中文](ADR-0035-local-learning-lm.md) · [English](ADR-0035-local-learning-lm.en.md)

- **状態**：採用済み
- **日付**：2026-11-06
- **関連**：[ADR-0034](ADR-0034-sel-distillation-archival.ja.md)（SEL のアーカイブと再開条件）、
  [ADR-0029](ADR-0029-research-line-archival.ja.md)（研究線のアーカイブ）、
  [ADR-0033](ADR-0033-capacity-axis-archival.ja.md)（容量軸のアーカイブ）、

## Context

ユーザーの目的は「少なくとも雑談できるモデル」。三つの事実が問題の形を変えました：

1. **本リポジトリは局所規則で言語モデルを訓練したことがありません。** P4 のスパイキング LM
   （`research/sel/student.py`）は `.backward()`（代理勾配＋BPTT）を使っています。本当の局所規則の
   実装（`research/eprop/event_driven.py`）は「系列に一つのラベル」の分類しか扱えません。
   したがって「局所学習で事前学習できるか」には**正例も反例もありません**。
2. **P4 の CE 0.5274 は BPTT の成績であり、局所学習の起点ではありません。** 局所モデルは
   CE = `ln V` から始まります。0.5274 を起点と誤解すると、基準を下限と取り違えます。
3. **ADR-0034 の再開条件の一つが満たされました**：「token レベルの教師分布を文字レベルの生徒へ
   周辺化できる tokenizer 整合層が存在すること」——`research/sel/probe_logprobs.py` が教師の
   top-5 カバレッジ **0.967** を実測しており、先頭文字への周辺化は算術的に可能です。

線 A（A1–A8）は間接的な支持を与えます：このパイプラインでは分類のボトルネックは**読み出し**であり、
学習規則ではありませんでした（読み出しの変更で 14–42pp、組織の変更で 0.3pp）。
これは言語モデルへ直接外挿できませんが、「局所規則は学べない」が既成事実ではないことを示します。

## Decision

**新しい支線を開く：局所学習規則による next-token の事前学習。** これは SEL 蒸留経路の復活では
ありません——SEL の TI-LIF + CWSSA + SSM + KD は停止したままで、製品は Phase 2 に留まります。

四つの固定した境界：

1. **M0 を先行し、判定基準を先に残す。** `research/sel/prereg-lm-eprop.md` の M0-1（top-1 ≥0.70）と
   M0-2（循環重みが実際に学習している）が**同時に**成立した場合のみ M1 に進めます。
   成立しなければ kill 基準に従って支線を止めます。
2. **製品に触れない。** 召回・ゲートに接続せず、重みも公開せず、Axo の既定バックエンドも変えません。
3. **データは本機から出さない。** 実会話の本文は本機の訓練にのみ使い、クラウドには合成の
   話題/SIR だけを送ります。データとチェックポイントは `D:\AxoData\sel\lm\` に置き、リポジトリには入れません。
4. **雑談できると主張しない。** 目標は**狭領域・単一〜少数ターン・人設内**のテキストです。
   汎用の雑談には 5〜7 桁上のデータと計算量が必要で、しかも「注意機構なし ⇒ in-context learning なし」
   というアーキテクチャ上の上限に縛られます。本 ADR の範囲外です。

技術的な要点（詳細は `research/sel/prereg-lm-eprop.md`）：

- **LIF＋領域ごとの τ** を使い、**ALIF は使わない**（`traces.py` の `epsilon_a` は O(B·N²) で、
  N=8192 では 4.3 GB）；
- **ストリーミング痕跡**を書き、`eprop_gradient` は再利用しない（後者は無条件に O(N²) を確保）；
- **分割訓練＝チャンク間の状態持ち越し**（v / z / 不応期 / 入力痕跡 / 循環痕跡 / タップのフィルタを
  すべて持ち越し、リセットは会話境界のみ）。**チャンク長は更新頻度を決め、記憶は τ が決める**——
  これが TBPTT との本質的な違いです。

## Alternatives

- **SEL 蒸留の再開**：却下。P4-3 が不合格（TI-LIF の CE は ALIF の 1.148×、基準は ≤0.90×）で、
  8 GB の作業点も変わっておらず、ADR-0034 の再開条件は満たされていません。
- **オープン LLM の微調整（QLoRA）**：技術的には可能ですが、別路線（局所学習ではない）であり、
  本プロジェクトの前提と衝突します。ユーザーは局所規則を維持することを明示的に選びました。
- **汎用基盤モデルをゼロから事前学習**：却下。6〜8 桁の差があり、本機でも本プロジェクトでも不可能です。
- **M0 を飛ばして規模へ**：却下。「局所規則が next-token を学べる」証拠なしに規模を拡大すると、
  「未検証」を「また一つの負の結果」に変えてしまいます。

## Consequences

**利点**：0.2 GPU 時間で「できるか」を判定できます。どちらの結果でも引用可能な境界になります。

**代償**：M0 のコーパスは 391 件のみ（テスト 46 件、top-1 の SE ≈0.9pp）で、信号の有無は判定できますが
大きさは測れません。M1–M5 は 50–200 GPU 時間に増えます。

**失敗時**：M0 が不合格なら負の結果を記録し、支線をアーカイブし、kill 基準が発動したことをここに追記します。
パラメータを調整して再実行したり、別シードで再試行したりしません。

**2026-11-06 追記：M0b も不合格、支線の停止を確定。**

M0b は隠れ層の学習率だけを上げ（`lr_in` 1e-3、`lr_rec` 1e-3）、他は変えていません。結果は
`sweep_results/lm_eprop_m0b/README.md`：

- 隠れ層は実際に動いた：`w_rec` の相対変化 **4.976%**（M0 は 0.070%、70 倍）。ただし事前登録の 5% 基準に
  対して **M0b-0 は 0.024pp 差で形式的に不合格**——規則に従い「実験は無効」と判定し、結論は出さず、
  学習率をさらに上げて再実行もしません；
- その前提の下で、**循環重みを学習すると悪化した**：CE 1.861 対 凍結 1.741（**+6.9%**）、top-1 0.516 対 0.566；
- どちらの版も**文字 bigram に負ける**（CE 1.423 / top-1 0.646）。

**結論**：1,024 ニューロン、2,000 updates、301 件のテンプレート・コーパスという作業点では、
逐次局所学習は二次の文字 bigram に勝てず、**循環重みの訓練は有害**です。この負の結果は M0 より強固で、
M0 の「差がない」は「測れていない」と言い訳できますが、M0b はできません。

**支線は停止**。二つの事前登録の kill 基準はともに実行済みです。再開に必要なのは**新しいコーパスと規模**
（M3 の段）であり、この作業点のハイパーパラメータ調整ではありません。


**2026-11-06 さらなる訂正：M0/M0b の kill は根拠を欠き、支線は再評価すべき。**

S0（`sweep_results/lm_eprop_s0/README.md`）は「再帰の出どころ」だけを変えた三臂を測りました：

| 臂 | CE | top-1 | 再帰／入力の電流比 |
| :--- | ---: | ---: | ---: |
| 再帰なし | **1.139** | **0.717** | 0× |
| 凍結ランダム再帰 | 1.861 | 0.516 | 2.16× |
| 凍結対角 SSM | 2.639 | 0.352 | 7.36× |

**順序は「再帰電流／入力電流」に対して完全に単調です。** 最初の二巡の再帰臂は初期化の時点で入力の
2.16 倍の電流を流しており、**テスト前からハンデを負っていました**——したがって
「局所学習は bigram に負ける」は成立しません。再帰を除くと、**前向き LIF＋局所学習の読み出しが
初めて bigram を上回ります（1.139 / 0.717 対 1.423 / 0.646）**。

**処置**：本 ADR の「停止」の結論は**撤回**します（数値は残り、推論は無効）。再開に新しいデータは不要で、
「再帰電流／入力電流 ∈ [0.8, 1.3]」を前提条件として書き込んだ**新しい事前登録**が必要です。
これは実装上の欠陥の修正であり、結果を緑にするための調整ではありません。

## ADR-0035-c：M0/M0b の結論を「証拠が汚染されている」と記録

**M0/M0b の停止判断は不完全な証拠に基づいています。** 両者の再帰臂は初期化時に入力の 2.16 倍の
再帰電流を持ち、内部ダイナミクスが e-prop の学習信号を支配していました。したがって：

- M0/M0b の**数値**は有効で再現可能（保持する）；
- M0/M0b の**推論**（「局所学習は文字 bigram に負ける」「循環重みの訓練は有害」）は
  **「証拠が汚染されている」**と記録し、引用してはならない；
- 支線を再開するかは S1 の事前登録が決める。本 ADR は決めない。


**2026-11-06 第三巡：S1 は「制御された再帰に価値はあるか」に答えました——ない。**

再帰電流を入力の 0.5×／1.0× に較正（冪則較正、実測 0.556／1.021）、他は S0 と同じ：

| 臂 | CE | top-1 |
| :--- | ---: | ---: |
| 再帰なし | **1.139** | **0.717** |
| rec@0.5（凍結） | 1.231 | 0.698 |
| rec@1.0（凍結） | 1.330 | 0.668 |
| rec@0.5（学習、`w_rec` は 7.2% 変化） | 1.213 | 0.687 |

- **単調性は制御された範囲でも成立**（0× → 0.717、0.56× → 0.698、1.02× → 0.668）；
- **循環重みの学習も依然として無益**——今回は電流を較正しているので「水没」では説明できません；
- 四臂とも**ゼロ入力での発火率は 0**。自励発振ではなく、大きく無情報な電流が token 信号を薄めたものです。

**結論**：この作業点では**前向き LIF＋局所学習の読み出しが最良**で、循環電流はすべて足を引っ張ります。
SSM の支線もここで閉じます——構造的な帰納バイアスは、水没時にも助けにならず、公正な再試験の必要もありません。
**最も単純な再帰すら残す価値がない**からです。

**付記**：線 A の `EventDrivenEProp`（sMNIST、N=8192、fan-in 32）の再帰／入力電流比は **1.106** で、
今回 4.9pp を失ったのと同じ領域です。線 A の**相対的な結論は影響を受けません**（両臂が同じ再帰）。
**同日の A9 がその系を否定しました**：再帰を外すと三シード中位 0.904 対 0.899、差は +0.5pp のみ
（シードごとに −1.3 / +1.7 / +1.2pp）。**「再帰電流の傾き」はタスクを跨いで外挿できません**。


**2026-11-06 第四巡：S2 が五シードで確認——0.717 は偶然ではない。**

前向き LIF＋局所読み出し、五シード（他は S1 の `none` 臂と同一）：

| シード | 0 | 1 | 2 | 3 | 4 | 平均 | std |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| top-1 | 0.7166 | 0.7137 | 0.7115 | 0.7312 | 0.7400 | **0.7226** | **0.0124** |
| CE | 1.139 | 1.195 | 1.222 | 1.152 | 1.156 | **1.173** | — |

- **五つの判定基準すべて合格**：平均 0.7226 ≥0.70、std 0.0124 ≤0.02、
  **すべてのシードが bigram を 6.6–9.4pp 上回る**、CE 平均 1.173 < 1.423；
- 範囲は **2.85pp** のみで、A3 の三シード（4.4pp）よりずっと安定。

**本支線で初めてのシード頑健な正の結果**です：純粋な局所学習規則（逐次 e-prop＋NLMS 読み出し、
autograd は一切なし）が、このコーパスで二次の文字 bigram を安定的に上回り、しかも**再帰は不要**
（S1 で足すと悪化することを確認済み）。

**境界**：文字レベル、テンプレート・コーパス、一層、N=1,024、2,000 updates、テスト 46 件。
「雑談できる」への外挿はできません。


**2026-11-06 第五巡：R0——実コーパスに切り替えると六折すべて敗北。**

コーパスを SEL のテンプレートから**実会話**（265 対／34,183 字／1,246 の異なり字、リポジトリ外・未コミット）へ。
会話単位の leave-one-out 六折、他は S2 と同じ：

| コーパス | 異なり字 | bigram top-1 | モデル top-1 | 差 |
| :--- | ---: | ---: | ---: | ---: |
| SEL テンプレート（S2） | 274 | 0.646 | **0.7226** | **+7.7pp** |
| **実会話（R0）** | **986–1,244** | **0.184** | **0.080** | **−10.4pp** |

**四つの判定基準はすべて不合格**：0/6 折が勝ち、平均差 −10.37pp、損失は初期値の 0.57–0.63 までしか下がりません。

**結論**：S2 の 0.7226 は**実テキストへ外挿できません**——あれは低エントロピーのテンプレート・コーパスの結果です。
本巡の予算（各折 118–252 対の訓練サンプル、2,000 updates、N=1,024）では、前向き局所学習は**文字 bigram にも
追いつけません**。学習はしていますが（0.080 は 1/1,200 の偶然線を大きく上回る）、まったく足りません。

**切り分けられないこと**：「データが少なすぎる」のか「アーキテクチャが浅すぎる」のか。
計画上の次は**合成による拡充**（数千〜数万対）を同じ基準で回すこと。それ以前に N や τ を調整してはいけません
——それは基準を結果に合わせることになります。


**2026-11-06 第六巡：R1 難易度ラダー——最も易しい段だけが有効。**

ローカル `qwen3-4b` で三つの合成コーパスを生成（各 3,000 対、変えたのは話題・性格・温度・ターン数のみ）：

| 段 | bigram | モデル | Δ | 勝った折 | CE 尾/頭 |
| :--- | ---: | ---: | ---: | ---: | :--- |
| **E** | 0.4765 | **0.4973** | **+2.08pp** | **6/6** | 0.50–0.54（収束） |
| M | 0.3463 | 0.2390 | −10.72pp | 0/6 | **0.71–0.73（未学習）** |
| H | 0.2919 | 0.1752 | −11.67pp | 0/6 | **0.79–0.82（未学習）** |

**R1-2（各段が収束）が不合格なので、M/H は「判定不能」であり「負け」ではありません。**
原因は**私の設計ミス**：S2 は 301 サンプルを 2,000 updates（106 epoch）、R1 は各折 2,500 を同じ 2,000 updates
（**12.8 epoch**）——コーパスは 8 倍になったのに更新回数を増やしていませんでした。

一つの疑いは排除：M/H の崩壊は**語彙の切り詰めではない**（top-800 で文字の 97%+ をカバー）。

**有効な点は三つ**：bigram 0.646 → **+7.7pp**（S2）、0.4765 → **+2.1pp**（R1-E）、0.184 → **−10.4pp**（R0）。
**三点的に単調**ですが、0.35–0.30 の区間は空白のままです。

**次は R1b：更新回数を epoch に合わせる**（約 20,000 updates、三折なら 1.5–2 時間）。
**それ以前に N や τ を変えない**——「学習不足」を「アーキテクチャ不足」と誤読することになります。


**2026-11-06 第七巡：R1b——十分に訓練すると R1 の「M/H が負ける」は消えました。**

updates を 2,000 から **16,000**（約 103 epoch、S2 の 106 に合わせる）へ変えただけ、三段×三折：

| 段 | bigram | モデル | **Δ** | R1（2k） | CE 尾/頭 |
| :--- | ---: | ---: | ---: | ---: | :--- |
| **E** | 0.4766 | 0.6123 | **+13.58pp** | +2.1pp | 0.32（収束） |
| **M** | 0.3505 | 0.3397 | **−1.08pp** | −10.7pp | 0.51（収束） |
| H | 0.2933 | 0.2542 | −3.92pp | −11.7pp | 0.62（まだ少し未学習） |

**同じコーパス・同じアーキテクチャ・同じハイパーパラメータで、訓練量だけを変えて三つの Δ が
11.5 / 9.6 / 7.8pp 上がりました。** したがって **R1 の「M/H は 10–12pp 負ける」は無効**です（12.8 epoch の結果）。

**交点は bigram 0.35–0.48 の間**：0.48 では 13.6pp の勝ち、0.35 では引き分け（−1.1pp）。
H は依然として判定不能（R1b-0 不合格）。

**未解決の一点**：R0（実コーパス）も 2,000 updates 級でした。未学習の直接証拠はありません
（CE 比 0.57–0.63、128–271 epoch）が、**epoch を揃えた再実行はしていません**——
−10.4pp が本当の負けか未学習かは未解決です。


**2026-11-07 第八巡：R0b は 🔴——実テキストはハードな境界であり、未学習ではありません。**

実コーパスにも epoch を揃えた予算（16,000 updates）を与え、二折（第一折＋訓練集合が最大の折）を実行：

| 折 | 訓練対数 | 16k 後の top-1 | bigram | Δ | CE 尾/頭 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 折 1 | **118** | 0.0604 | 0.1754 | **−11.49pp** | 0.13（収束） |
| 最大折 | **252** | 0.0652 | 0.1669 | **−10.17pp** | 0.39（収束） |

最大折の全曲線（2,000 ステップごと）：test CE は **6.35 → 7.93 へ単調に上昇**、top-1 は **4,000 ステップで
0.0691 に達した後**下降。

**二つのことが同時に成り立ちます**：① **未学習ではない**（CE 比 0.13 / 0.39、十分に訓練済み）；
② **「十分に訓練すれば追いつく」わけでもない**——曲線の最良点でも bigram に **9.8pp** 劣ります。

**これが本支線の 🔴 境界**：34k 文字・1,246 字種の実会話において、前向き LIF＋局所読み出しは
**文字 bigram に追いつけず**、その差は訓練量では縮まりません。用量反応は成立します（118→252 対で
16k 時の CE が 11.26→7.93）が、**top-1 は 0.060–0.069 のままで、データ量に応じて上がりません**。

**実行の逸脱**：事前登録は六折、実際は二折。停止基準は結果ファイルに記載（折 1 で決定的な過学習の特徴が出たこと、
一折に実測 1.75 時間かかり六折では 8–10 時間になること）。方向性の結論には影響しません。

**残る修复は三つだけ**：データを増やす（合成拡充で数十万対まで上げ、パラメータ/データ比を下げる）、
読み出しを小さくする（または正則化を強める）、早期停止（被害は抑えられるが top-1 は上がらない）。
**訓練量を増やすことは含まれません。**


**2026-11-07 第九巡：R2——データ量はレバー（+4.49pp）だが 15k でもゼロを越えない。**

同じ生成器・同じ 120 epoch で、変えたのはデータ量だけ：

| 臂 | コーパス | top-1 | bigram | Δ | CE 尾/頭 |
| :--- | ---: | ---: | ---: | ---: | :--- |
