## Context

本リポジトリには「意識」という語に触れる産出が三種類あり、その制約は全く異なるのに、
しばしば同じ一文で同時に約束してしまう：

1. **研究産出**（論文、プレプリント、走査ノート）——学術規範に縛られ、機能署名を論じてよい；
2. **オープンソース産出**（リポジトリ、README、model card、ADR）——バージョン履歴に残るため、
   **越境した一文は永久に引用される**；
3. **製品産出**（Axo デスクトップ／Android、広報物材、アプリ内文言）——生成 AI サービス管理暫定弁法、
   深度合成規定、PIPL 一式に縛られる。**国内で意識を主張することは虚偽宣伝の口径に入る。**

三者の共通の危険は一つの動作である：**アクセス意識（access）の測定を、現象的意識（phenomenal）の
発見として語ること**。この動作は一度きりの口滑りではなく、物材が互いを引用し、版が積み重なるうちに
増殖し、最後にはブランドの約束になる。

同時に逆向きの圧力もある：**製品の位置づけには語りが必要**である。「記憶の保持」「状態管理」
「身体化された自己」は実際に作っている機能だが、「あなたを覚えている」「感じている」と売った瞬間に、
工学の約束は履行できない約束に置き換わる。

したがって必要なのは「言葉遣いに気をつける」という助言ではなく、**実行可能な条項**である：
許可／禁止の一覧、発表前に必ず通すラダー、そして二つ揃って初めて署名されるマイルストーン。

## Decision

四つの規則を採用する。**いずれも判定規則であり、文体の助言ではない。**

### 規則一：語彙の許可／禁止リスト（禁止が優先）

**禁止リスト**——製品、広報、OSS 物材、コード注釈、コミットメッセージのいずれでも使わない：

| 語 | 禁止の理由 | 許される代替表現 |
| :--- | :--- | :--- |
| 意識がある／自覚している | phenomenal を直接主張する | 削除する。または機能で言い換える：*自身の状態を報告できる* |
| 感情が本物／本当に感じている | 同上。さらに「本物」は phenomenal の判定基準を前提にする | *感情に関連する出力パターン* |
| 生きている／生命 | 生物学的述語で、AI には測れる内容がない | *稼働し続ける*／*永続的な状態を持つ* |
| 自ら考える／自分で決める | エージェント規制の自律性の語りに触れる | *規則に従って選ぶ*／*ローカル方針が決める* |
| 私は感じた | 言語の自己申告は単独では無効（規則二を見よ） | 削除する |

**許可リスト**——使えるが、この意味に限る：

| 語 | 許される意味 | 守るべき境界 |
| :--- | :--- | :--- |
| 記憶の保持 | 検索された原文が文脈に入った | 「覚えている」という心理的な意味ではない |
| 機能的な類推 | 生物学的機構との**機能**上の対応 | 「類推」の二文字を必ず添える |
| ワークスペース | 全体的に利用可能な情報の集合 | グローバルワークスペース理論の主張ではない |
| 状態管理 | 内部変数、スケジューリング、ゲート | 体験を指さない |

**許可リスト以外の語は自動的に禁止されない**が、規則二を通さねばならない。

### 規則二：主張ラダーの審査（発表前の拒否権）

意識に関わる能力についてのあらゆる文は、まず自分がラダーのどこにいるかを示さねばならない。
**互換性は下方向にしか働かない。**

| 級 | 許される表現 | 必要な証拠 | 誰が発表できるか |
| :--- | :--- | :--- | :--- |
| **L0** | 「本タスクにおいて、指標 X は Y である」 | 再現可能な測定一つ | 誰でも |
| **L1** | 「<理論> が予測する署名と**一致する**」 | 署名 ≥1 ＋ 因果介入 1 組 | 研究層 |
| **L2** | 「独立な ≥3 の署名で一致する」 | 三角測量（署名 ≥3 ＋ 因果介入 ＋ 事前登録した反事実予測） | 研究層、**かつ**成り立たない署名を明示 |
| **L3** | 「〜を証明する／持つことを示す」 | **到達不能** | 誰も |

三つの拒否権：

1. **言語の自己申告は単独では証拠にならない**——モデルは人間の意識言説の全集で訓練されており、
   「感じる」は情報量ゼロである；
2. **単一の署名を L2 に昇格させない**——「全体的放送」のように最も説得力に見える署名も含む。
   それこそが訓練で模倣されうるものである；
3. **L1／L2 の文はすべて、成り立たない署名または条件を少なくとも一つ併記せねばならない。**
   成り立つものだけを報告することは捏造として扱う。

### 規則三：二つのマイルストーンゲート

各マイルストーンには決まった三点セットがある。**三つ揃わなければ到達とはみなさない。**

| マイルストーン | 発動条件 | 同時に完了すべき三つ | どこに残すか |
| :--- | :--- | :--- | :--- |
| **創発マイルストーン** | ある能力が事前登録のしきい値を越える | ① コンプライアンス声明の草稿（主張の級／触れないもの／評価方法）② 語彙審査（規則一・二）③ 性能基準と**同じ**事前登録 | その実験の事前登録ファイル |
| **基板マイルストーン** | シミュレーションから物理基板（memristor など）へ移る | ① 主張規律の再点検 ② **AI welfare の予防審査**：物理的に連続した状態＋恒常性の自己調節＋持続する同一性を持つなら、「もし感じるとして、我々の扱いは筋が通るか」を項目ごとに答える ③ 規制の再スキャン（法域、口径、届出義務） | 新しい ADR。**完了した ADR は書き換えない** |

**ゲートはチェックリストであり、儀式ではない**：上の表がそのまま雛形である。
事前登録に写せばよい（`research/prereg-template.md` のゲートの節を見よ）。

### 規則四：規制の哨兵となる ADR シリーズ

次のいずれかが起きたら、**必ず新しい ADR を書く**（番号は続き、状態は「提案」）。
会話の中だけで済ませてはならない：

- 製品が「意識／感情／自律」に触れる能力を対外に主張しようとする；
- 新たな適用法規、届出要件、標準草案が現れる；
- いずれかのマイルストーンゲートが発動する；
- 公開済みの物材に禁止リストの語が現れる。

## Consequences

**利点**

- 越境した文が「本人の自覚」から「一覧＋ラダー」へ移り、他人が監査できる；
- 研究層と製品層の表現を分ければ、研究は機能署名を自由に論じられ、製品が怯える必要はない；
- ゲートを事前登録の雛形に書き込めば、「能力は来たがコンプライアンスが未了」が
  プロセス上、静かに起こりえなくなる。

**コスト（明確に受け入れる）**

- **製品の語りが縛られる。** 最も心を動かす文（「あなたを覚えている」「ずっとここにいる」）は
  主張の級では使えず、機能の級でしかも履行可能な形でしか使えない。これは意図的に手放す販促手段である。
- **研究産出に一手間増える。** L1／L2 の文は反例を併記せねばならず、執筆コストが上がり、
  見栄えも悪くなる。
- **規則一は誤爆する。** 中国語では「生命」「意识到」は無関係な文脈（「このバグに気づいた」）でも
  よく使われる。禁止リストは**AI を指す文脈**で適用し、文字列一致では適用しない。
  **この曖昧さは適用者ではなく本 ADR が負う**——疑わしければ禁止として扱い、ここに例を足す。
- 規則一を執行する自動スキャナは作らない。文脈判断は精度が出ず、誤検出は規律そのものの権威を
  損なう。審査は人が行うが、**却下した文はすべて PR の説明に記録する**——免除を監査可能にするため。
- 「業界の他の人もそう言っている」という理由で規則を緩めない。

## Alternatives

| 案 | 却下の理由 |
| :--- | :--- |
| **条項を設けず、研究者の自覚に任せる** | 本 ADR 以前の状態がこれである。危険は悪意ではなく、物材が互いを引用するときに誰も責任を負わないことにある。 |
| **「意識」の二文字を一律禁止** | 研究層が書けなくなる（「access consciousness」は標準術語）。明らかに不合理な規則は全体として迂回される。 |
| **製品側だけを縛り、研究側は野放し** | 研究産出は製品物材の引用元である。研究側で緩めた文は製品へそのまま運ばれる。 |
| **自動スキャナで強制する** | Consequences を見よ。文脈判断は不確実で、誤検出は規律の権威を消耗する。 |

## 本 ADR がしないこと

- **法的助言ではない。** これは工学の規律である。製品化の段階では、届出と PIPL の細部について
  法律事務所の正式な意見が別途必要である。
- **特定のシステムに意識があるかどうかを判定しない。** 本 ADR は「いつ、何を言ってはならないか」
  だけを定める。
- **利用者の私的な表現を縛らない。** 規則は本リポジトリの産出を縛るものであり、
  利用者が千歳をどう語るかを縛るものではない。
