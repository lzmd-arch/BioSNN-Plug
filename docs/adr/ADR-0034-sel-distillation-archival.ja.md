# ADR-0034：SEL パルス蒸留経路のアーカイブ——概念は保持、TI-LIF + CWSSA + SSM + KD は停止

## Context

ADR-0032 は SEL を **TI-LIF + CWSSA + 選択的 SSM + 蒸留 + オンライン R-STDP** の
経路で研究項目として開始した。P0–P4 は走り終えた：

| 段階 | 結果 |
| :--- | :--- |
| P0 TI-LIF | `biosnn_bus.TernaryMembrane` 0.6.0；`D=1, signed=False` は `AdaptiveMembrane` とビット一致 |
| P1 召回 | 負の結果：ALIF / TI-LIF hit@1 0.012、語彙ベースライン 0.259 |
| G1 ゲーティング | 負の結果：TI-LIF AUROC 0.410、語彙ベースライン 0.825 |
| P2 教師 | テンプレート命中 T1 58% は合格；T4 スタイル分散は 0.5B 0.88×、1.5B 0.76×、3B 0.99× でいずれも 0.5× に届かず |
| P3 データ | 391 対（301/44/46）、D1–D4 全合格；教師は Phase 1（1.5B GGUF）に降格 |
| P4 学生 | 5 シード × 10k ステップ：P4-1/P4-2 合格、**P4-3 不合格** |

P4 の 5 シード中央値（両アーム CE-only、KD ではない）：

| アーム | test top-1 | test CE | 中央値秒 |
| :--- | ---: | ---: | ---: |
| bigram（分母） | 0.6457 | -- | -- |
| GRU(256) | 0.8831 [0.8795, 0.8846] | 0.5203 [0.4686, 0.5540] | 83 |
| ALIF(512) | 0.8685 [0.8634, 0.8729] | **0.4594** [0.4304, 0.5518] | 620 |
| TI-LIF(512, D=3) | 0.8641 [0.8532, 0.8685] | 0.5274 [0.4987, 0.8482] | 946 |

P4-1（>= 0.7457）と P4-2（>= GRU - 5pp = 0.8331）は合格；**P4-3 は不合格：
TI-LIF の CE は ALIF の 1.148 倍**（基準 <= 0.90 倍）で、5 シード中 4 シードが
同一シード比較で悪い。P4-4 は tokenizer アラインメントがないため N/A
（`prereg_p4_amend1.md`）；P4-5 の生成検収は未実施；P4-6 はコスト合格。

**概念と経路を分ける。** 「バックエンドのモデルを変えても口調を保つ」という製品の
痛点は今も実在する；TI-LIF/ALIF は数値的に正しいニューロン実装である；失敗したのは
**8 GB VRAM、CPU 教師、文字/トークン・アラインメントなしで TI-LIF + CWSSA + SSM +
KD を回す**という経路の効率である。

## Decision

1. **SEL パルス蒸留経路を停止する。** P4 の後に P5 オンライン R-STDP を開始しない；
   CWSSA/SSM を実装しない；KD を追加しない。P3 データは蒸留に使わない。
2. **製品側は Phase 2（テンプレート + モデル混合レンダリング）へ戻す。** パルス表現層を
   製品に接続しない。Phase 2 は現在もデフォルト無効で、T4 が未合格なので、文書も UI も
   「口調が統一された」と主張してはならない。
3. **P3 の 391 対の教師データは保持し、SFT コーパスとして再利用してよい。** これは
   データ再利用であり蒸留ではない。新しいデータカードと学習の事前登録が必要。
   データは引き続きリポジトリに入れない。
4. **研究側の唯一の活動線は線 A（脳領域特化）。** 事前登録は確定済み
   （`research/brainregions/prereg-brain-region-specialization.md`）。2 アーム × 3 シードの
   初回実行は 2026-11-04 に開始し、結果待ち。
   ALIF-only SEL は遠期の代替案にすぎず、今は事前登録も計算資源も割かない。
5. **Paper C の叙事をアーカイブ済みの結果に合わせる**：§4.1 パルス SoS アーカイブ；
   §4.2 容量軸アーカイブ；§4.3 線 A の事前登録；§5 SEL は「実装」ではなく
   「パルス表現層の試みと技術経路の反省」として書く。

これで四つの硬い境界に到達した：**純粋 CIL（ADR-0029）、パルス SoS（ADR-0031）、
容量軸（ADR-0033）、SEL パルス蒸留（本 ADR）**。

## 再開条件

以下のいずれかが成立したら**新しい事前登録**が必要で、本 ADR を盾にしてはならない：

- **ALIF-only SEL**：CWSSA/SSM/KD を外し、ALIF 表現層だけにする；教師品質、データ
  由来、評価口径の三つを先に答える；
- **tokenizer アラインメント層**：トークン級教師分布を文字級学生に周辺化できるように
  なって初めて KD を論じる；
- **異なる作業点**：>8 GB VRAM、またはより小さな教師/学生の組で、P4-3 の効率比を
  公平な予算で測れるようになる；
- **製品側の新要件**：測定可能な口調一貫性の要件が現れ、Phase 2 の T4 が依然として
  不合格である。

## Consequences

- SEL に学習計算を割かない；P5 は取消；`research/sel/` はコード、事前登録、結果を
  再現用に保持する；
- 製品は Phase 2 のまま、デフォルト無効；重みを公開せず、製品にも接続しない；
- P3 データは SFT に再利用できるが、新しいデータ利用説明と事前登録が必要；
- Paper C §5 は反省章として書き、「概念が成立する」を「経路が成功した」に
  すり替えない；
- ADR-0032 が開始、本 ADR が終了：**概念は保持、経路は停止**。

## Alternatives

- **P4-3 を「もう少し訓練すれば」で説明する**：却下。5 シード中央値は安定しており、
  事前登録は <= 0.90 倍で固定されている。追加ステップには事前登録の根拠がない；
- **T4 の口径を変えて Phase 2 を緑にする**：却下。T4 は実行前に決めた物差しであり、
  後から変えるのは主張の漂流である；
- **P3 データで SFT して SEL 成功と主張する**：却下。SFT は別経路であり、独自の
  事前登録と評価が必要で、SEL の結論を継承できない；
- **召回/ゲーティングの負の結果を SEL の失敗とみなす**：却下。タスクが異なる；
  SEL の停止点は P4-3 であり、P1/G1 ではない。
