## Context

计划书把阶段四入口设为**阶段三验收**，其中一条是「规则改变后重学速度比从头训练快 3 倍
以上」。到 2026-10-26，这条在 CartPole + 速率版 R-STDP agent 上做了三轮预注册实验：

| 轮次 | 规则 | warm 初值 <150 | 比值中位 | 结论 |
| :--- | :--- | :---: | ---: | :--- |
| v1 | 重力 14 | 1/10 | 1.03 | 规则太弱（9/10 已过线） |
| v2 正式 | 重力 20 | 2/10 | 0.957 | 仍太弱（8/10 已过线） |
| v3 校准 | 杆长 0.3 / 0.2、重力 30 | 1/5 / 2/5 / 3/5 | ≈1.06 | 三候选全不合格；Phase A 中位 186.3，pilot 批次不可用 |

v2 的探索性阈值扫描（250/300/350）配对中位为 0.95 / 0.78 / 0.88，也没有 3×；它不是
预注册结论，只说明"换阈值"不解决问题。旧策略对这三类规则变化都很鲁棒，而 scratch 总能
在 800 回合内学会；再加硬规则会同时压低 scratch 的可学性。

另一方面，阶段三的 CL 门已按 [ADR-0018](ADR-0018-task-aware-cl-gate.md) 改为**任务感知
CIL**并达标（oracle 0.8195 / 0.0，构造性）；世界模型的打底（ADR-0015 的 P1/P2）已经
在进行。**继续让阶段四被一个三轮实验都没达到的判据完全阻塞，代价大于收益。**

## Decision

1. **阶段四入口与「重学快 3×」解耦**：阶段四可以在**任务感知 CL 门（ADR-0018）通过**
   后开始，不再等待 3×。
2. **3× 记为未达**，不是通过。论文、计划书与对外材料必须写"3× 未达（见 ADR-0019）"，
   不能把阶段四的启动写成阶段三全部验收。
3. **3× 转为阶段四的开放研究项**：允许在阶段四用**实用重学**（warm 臂保留训练末的
   探索温度与学习率，scratch 用完整调度）或换任务/元学习来测；这些是**新的主张**
   （"实用重学速度"/新任务），需要各自的新预注册，且不得与原始 3× 混报。
4. **阶段三的其它结果原样保留**：CL 的纯 CIL 阴性、任务推断边界、重学三轮的阴性，
   都不删改；本 ADR 只改**阶段四的入口条件**，不改历史。
5. 阶段四启动后，第一个组件仍按 ADR-0015 的世界模型打底继续；神经发生/规模扩展/
   元认知门控等按各自预注册推进。

## Consequences

- **阶段四可以开始**，不再被一个未达的判据锁死；
- **代价**：阶段三记为"部分验收"——CL（任务感知）过，重学 3× 未达。这是**治理决定，
  不是测量结果**；所有对外材料必须这样写；
- 3× 仍是开放风险：如果阶段四的实用重学也测不出 3×，这条指标可能需要在更后期的
  复盘里重新定义或放弃；
- 原计划书的"巩固 → AF → 阶段三 → 阶段四"链条中，AF 部分已由 ADR-0018 口径改变；
  本 ADR 改的是另一条（重学）。

## Alternatives

- **保持阻塞**：最保守，但阶段四会被一个三轮实验都没达到的判据长期锁死；项目需要
  的是"边界已测"还是"门必须过"，这是治理选择。
- **把门改成实用重学并等它通过**：可能是真 3× 的唯一剩余路径，但它改变了两臂的比较
  （不再只差初始权重），且仍可能失败；因此列为阶段四开放项，而不是阻塞入口。
- **换任务/算法重做 3×**：新一轮研究，成本最高；不在入口处阻塞，作为开放项保留。
- **把 3× 写成通过**：不接受——三轮预注册实验都没有支持它。
