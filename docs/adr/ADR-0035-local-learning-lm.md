# ADR-0035：局部学习规则的语言模型预训练——重开为一条新支线，M0 先行

[English](ADR-0035-local-learning-lm.en.md) · [日本語](ADR-0035-local-learning-lm.ja.md)

- **状态**：已采纳
- **日期**：2026-11-06
- **相关**：[ADR-0034](ADR-0034-sel-distillation-archival.md)（SEL 归档与其重开条件）、
  [ADR-0029](ADR-0029-research-line-archival.md)（研究线归档）、
  [ADR-0033](ADR-0033-capacity-axis-archival.md)（容量轴归档）、

## Context

用户的诉求是"做一个至少能闲聊的模型"。查清三件事之后，问题的形状变了：

1. **本仓从来没有用局部规则训过语言模型。** `research/sel/student.py` 里 P4 那条脉冲 LM
   用的是 `.backward()`（替代梯度 + BPTT）；真正的局部规则实现 `research/eprop/event_driven.py`
   只支持"整段一个标签"的分类。所以"局部学习能不能预训练"**既没有正例也没有反例**。
2. **P4 的 CE 0.5274 是 BPTT 的成绩，不是局部学习的起点。** 局部学习从零开始的初始 CE 是 `ln V`。
   把它当起点会把门槛误当成基线。
3. **ADR-0034 给 SEL 列的重开条件之一已经具备**："有 tokenizer 对齐层，能把 token 级教师分布
   边缘化到字符级学生"——`research/sel/probe_logprobs.py` 已实测教师 top-5 覆盖率 **0.967**，
   首字符边缘化在算术上可行。

同时，线 A（A1–A8）给了一条间接支持：在这条管线上，**分类任务的瓶颈是读出而不是学习规则**
（换读出值 14–42pp，换组织只值 0.3pp）。这**不能**直接外推到语言模型，但足以说明
"局部规则学不动"不是一个已经被证实的先验。

## Decision

**开一条新支线：局部学习规则的 next-token 预训练。** 它不是 SEL 蒸馏路径的恢复——
SEL 的 TI-LIF + CWSSA + SSM + KD 仍然停止，产品仍回退 Phase 2。

四条写死的边界：

1. **M0 先行，判据先落盘。** 只有 `research/sel/prereg-lm-eprop.md` 的 M0-1（top-1 ≥0.70）
   与 M0-2（循环权重真的在学）**同时成立**，才允许进入 M1。不成立即按 kill 判据停线。
2. **不碰产品。** 不接召回、不接门控、不发权重、不改 Axo 默认后端。
3. **数据不出本机。** 真实会话正文只用于本机训练；云端只发合成话题/SIR，不发正文。
   数据与检查点在 `D:\AxoData\sel\lm\`，不入库。
4. **不声称能闲聊。** 本支线的目标是**窄域、单轮到少轮、人设内**的文本；通用闲聊需要
   5–7 个数量级的数据/算力，且受"无注意力 ⇒ 无 in-context learning"的架构天花板限制，
   不在本 ADR 的射程内。

技术路线的要点（细节见 `research/sel/prereg-lm-eprop.md` 与计划书）：

- 用 **LIF + 逐区 τ**，**不用 ALIF**（`traces.py` 的 `epsilon_a` 是 O(B·N²)，N=8192 时 4.3 GB）；
- 写**流式痕迹**，不复用 `eprop_gradient`（后者无条件分配 O(N²)）；
- **分块训练 = 跨块状态结转**（v / z / 不应期 / 输入痕迹 / 循环痕迹 / 抽头滤波全部携带），
  只在会话边界重置；**块长决定更新频率，记忆由 τ 决定**——这是与 TBPTT 的根本区别。

## Alternatives

- **恢复 SEL 的蒸馏路径**：否决。P4-3 不过（TI-LIF CE 是 ALIF 的 1.148×，要求 ≤0.90×），
  且 8 GB 下 TI-LIF + SSM 的工作点没有变化，ADR-0034 的重开条件没有满足。
- **直接微调开源 LLM（QLoRA）**：技术上可行，但那是另一条路线（不是局部学习），
  与本项目的立项前提冲突。用户已明确选择坚持局部规则，本 ADR 不覆盖它。
- **从零预训练一个通用基座**：否决。差 6–8 个数量级，不是本机、也不是本项目能做的事。
- **不设 M0 直接上规模**：否决。没有"局部规则能学 next-token"的证据就扩规模，
  会把"没验证"变成"又一条负结果"。

## Consequences

**正面**：把"能不能"这个问题变成一个 0.2 GPU-h 就能回答的实验；无论正负都产出一条可引用的边界。

**代价**：M0 用的语料只有 391 条（测试 46 条，top-1 的 SE ≈0.9pp），只能判"有没有信号"，
判不了"好多少"。M1–M5 的成本按计划书递增到 50–200 GPU-h。

**失败时的处理**：M0 不过 → 写负结果，支线归档，本 ADR 加补注说明 kill 判据生效；
不调参重跑，不换种子重试。

## 补注

**2026-11-06：M0 不通过，kill 判据生效。** 结果见 `sweep_results/lm_eprop_m0/README.md`。

- test top-1 **0.540** < bigram **0.646**；CE **1.811** > bigram **1.423**；
- 三条前置全过（bigram 复现 0.6457、初始 CE 5.792≈ln V、发放率 5.2%），损失降到 0.444 倍——
  **管线是通的，逐时刻 e-prop 确实在优化**；
- 但诊断显示：300 步后 `w_in` 只动 **0.082%**、`w_rec` 只动 **0.070%**，而读出动了 **179%**。
  本轮实际训的是「固定随机脉冲储层 + 局部规则训的线性读出」，**M0-2 因此不构成证据**。
  **这是本 ADR 所依据的那份预注册的设计缺陷**，不是"循环学习无效"的证据。

**处置**：按预注册的 kill 判据停线，不调参、不换种子重跑。重开需一份新预注册（M0b），
并把"训练后 `w_rec` 的相对变化量 ≥5%"写成**前置判据**——不达标判"实验无效"，而不是"规则无效"。
