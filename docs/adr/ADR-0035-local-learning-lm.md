# ADR-0035：局部学习规则的语言模型预训练——重开为一条新支线，M0 先行

[English](ADR-0035-local-learning-lm.en.md) · [日本語](ADR-0035-local-learning-lm.ja.md)

- **状态**：已采纳
- **日期**：2026-11-06
- **相关**：[ADR-0034](ADR-0034-sel-distillation-archival.md)（SEL 归档与其重开条件）、
  [ADR-0029](ADR-0029-research-line-archival.md)（研究线归档）、
  [ADR-0033](ADR-0033-capacity-axis-archival.md)（容量轴归档）、

## Context

用户的诉求是"做一个至少能闲聊的模型"。查清三件事之后，问题的形状变了：

1. **本仓从来没有用局部规则训过语言模型。** `research/sel/student.py` 里 P4 那条脉冲 LM
   用的是 `.backward()`（替代梯度 + BPTT）；真正的局部规则实现 `research/eprop/event_driven.py`
   只支持"整段一个标签"的分类。所以"局部学习能不能预训练"**既没有正例也没有反例**。
2. **P4 的 CE 0.5274 是 BPTT 的成绩，不是局部学习的起点。** 局部学习从零开始的初始 CE 是 `ln V`。
   把它当起点会把门槛误当成基线。
3. **ADR-0034 给 SEL 列的重开条件之一已经具备**："有 tokenizer 对齐层，能把 token 级教师分布
   边缘化到字符级学生"——`research/sel/probe_logprobs.py` 已实测教师 top-5 覆盖率 **0.967**，
   首字符边缘化在算术上可行。

同时，线 A（A1–A8）给了一条间接支持：在这条管线上，**分类任务的瓶颈是读出而不是学习规则**
（换读出值 14–42pp，换组织只值 0.3pp）。这**不能**直接外推到语言模型，但足以说明
"局部规则学不动"不是一个已经被证实的先验。

## Decision

**开一条新支线：局部学习规则的 next-token 预训练。** 它不是 SEL 蒸馏路径的恢复——
SEL 的 TI-LIF + CWSSA + SSM + KD 仍然停止，产品仍回退 Phase 2。

四条写死的边界：

1. **M0 先行，判据先落盘。** 只有 `research/sel/prereg-lm-eprop.md` 的 M0-1（top-1 ≥0.70）
   与 M0-2（循环权重真的在学）**同时成立**，才允许进入 M1。不成立即按 kill 判据停线。
2. **不碰产品。** 不接召回、不接门控、不发权重、不改 Axo 默认后端。
3. **数据不出本机。** 真实会话正文只用于本机训练；云端只发合成话题/SIR，不发正文。
   数据与检查点在 `D:\AxoData\sel\lm\`，不入库。
4. **不声称能闲聊。** 本支线的目标是**窄域、单轮到少轮、人设内**的文本；通用闲聊需要
   5–7 个数量级的数据/算力，且受"无注意力 ⇒ 无 in-context learning"的架构天花板限制，
   不在本 ADR 的射程内。

技术路线的要点（细节见 `research/sel/prereg-lm-eprop.md` 与计划书）：

- 用 **LIF + 逐区 τ**，**不用 ALIF**（`traces.py` 的 `epsilon_a` 是 O(B·N²)，N=8192 时 4.3 GB）；
- 写**流式痕迹**，不复用 `eprop_gradient`（后者无条件分配 O(N²)）；
- **分块训练 = 跨块状态结转**（v / z / 不应期 / 输入痕迹 / 循环痕迹 / 抽头滤波全部携带），
  只在会话边界重置；**块长决定更新频率，记忆由 τ 决定**——这是与 TBPTT 的根本区别。

## Alternatives

- **恢复 SEL 的蒸馏路径**：否决。P4-3 不过（TI-LIF CE 是 ALIF 的 1.148×，要求 ≤0.90×），
  且 8 GB 下 TI-LIF + SSM 的工作点没有变化，ADR-0034 的重开条件没有满足。
- **直接微调开源 LLM（QLoRA）**：技术上可行，但那是另一条路线（不是局部学习），
  与本项目的立项前提冲突。用户已明确选择坚持局部规则，本 ADR 不覆盖它。
- **从零预训练一个通用基座**：否决。差 6–8 个数量级，不是本机、也不是本项目能做的事。
- **不设 M0 直接上规模**：否决。没有"局部规则能学 next-token"的证据就扩规模，
  会把"没验证"变成"又一条负结果"。

## Consequences

**正面**：把"能不能"这个问题变成一个 0.2 GPU-h 就能回答的实验；无论正负都产出一条可引用的边界。

**代价**：M0 用的语料只有 391 条（测试 46 条，top-1 的 SE ≈0.9pp），只能判"有没有信号"，
判不了"好多少"。M1–M5 的成本按计划书递增到 50–200 GPU-h。

**失败时的处理**：M0 不过 → 写负结果，支线归档，本 ADR 加补注说明 kill 判据生效；
不调参重跑，不换种子重试。

## 补注

**2026-11-06：M0 不通过，kill 判据生效。** 结果见 `sweep_results/lm_eprop_m0/README.md`。

- test top-1 **0.540** < bigram **0.646**；CE **1.811** > bigram **1.423**；
- 三条前置全过（bigram 复现 0.6457、初始 CE 5.792≈ln V、发放率 5.2%），损失降到 0.444 倍——
  **管线是通的，逐时刻 e-prop 确实在优化**；
- 但诊断显示：300 步后 `w_in` 只动 **0.082%**、`w_rec` 只动 **0.070%**，而读出动了 **179%**。
  本轮实际训的是「固定随机脉冲储层 + 局部规则训的线性读出」，**M0-2 因此不构成证据**。
  **这是本 ADR 所依据的那份预注册的设计缺陷**，不是"循环学习无效"的证据。

**处置**：按预注册的 kill 判据停线，不调参、不换种子重跑。重开需一份新预注册（M0b），
并把"训练后 `w_rec` 的相对变化量 ≥5%"写成**前置判据**——不达标判"实验无效"，而不是"规则无效"。

**2026-11-06 补充：M0b 也不通过，支线确认停止。**

M0b 只把隐藏层学习率放大（`lr_in` 1e-3、`lr_rec` 1e-3），其余不变。结果见
`sweep_results/lm_eprop_m0b/README.md`：

- 隐藏层确实动了：`w_rec` 相对变化 **4.976%**（M0 是 0.070%，差 70 倍）；但按预注册 5% 的门槛，
  **M0b-0 形式不过，只差 0.024pp**——按规矩判"实验无效"，不据此下结论，也不调大学习率重跑；
- 在这个前提下，**学循环权重让结果变差**：CE 1.861 vs 冻结 1.741（**+6.9%**），top-1 0.516 vs 0.566；
- 两个版本**都输给字符 bigram**（CE 1.423 / top-1 0.646）。

**结论**：在 1,024 神经元、2,000 updates、301 条模板语料这个工作点上，逐时刻局部学习赢不了二阶字符
bigram，且**训循环权重是有害的**。这个负结果比 M0 硬：M0 的"没差别"可以说成"没测到"，M0b 不能。

**支线停止**，两条预注册的 kill 判据都已执行。重开需要的是**新语料与新规模**（M3 那一档），
不是继续调这一轮的超参。


**2026-11-06 再更正：M0/M0b 的 kill 证据基础不成立，支线应予重开评估。**

S0（`sweep_results/lm_eprop_s0/README.md`）测了三臂，只改"递推从哪来"：

| 臂 | CE | top-1 | 递推/输入电流 |
| :--- | ---: | ---: | ---: |
| 无递推 | **1.139** | **0.717** | 0× |
| 冻结随机循环 | 1.861 | 0.516 | 2.16× |
| 冻结对角 SSM | 2.639 | 0.352 | 7.36× |

**排序与"递推电流 / 输入电流"完全单调。** 前两轮的递推臂从初始化起就带着 2.16 倍于输入的电流，
等于让它们顶着噪声上场——**M0/M0b 的"局部学习赢不了 bigram"因此不成立**。
而在无递推的条件下，**前馈 LIF + 局部读出第一次赢过 bigram（1.139 / 0.717 对 1.423 / 0.646）**。

**处置**：本 ADR 的"停止"结论**撤回**（数字保留，结论作废）。重开不需要新语料——
需要一份**新预注册**，把"递推电流/输入电流 ∈ [0.8, 1.3]"写成前置判据，再公平地问一次
"递推有没有用、SSM 有没有用"。这是**修正一个实现缺陷**，不是调参让结果变绿。

## ADR-0035-c：M0/M0b 的结论标记为「证据受污染」

**M0/M0b 的停线决策基于不完整证据。** 它们的递推臂在初始化时带着 2.16 倍于输入的递推电流，
使 e-prop 的学习信号被内部动力学主导。因此：

- M0/M0b 的**数字**保留且有效（可复现）；
- M0/M0b 的**推论**（"局部学习赢不了字符 bigram"、"训循环权重有害"）**标记为「证据受污染」**，不得引用；
- 支线是否重开，由 S1 的预注册决定，不由本 ADR 决定。


**2026-11-06 第三轮：S1 回答了"受控递推有没有价值"——没有。**

把递推电流标定到输入的 0.5× 与 1.0×（幂律标定，实测达 0.556 / 1.021），其余与 S0 一致：

| 臂 | CE | top-1 |
| :--- | ---: | ---: |
| 无递推 | **1.139** | **0.717** |
| rec@0.5（冻结） | 1.231 | 0.698 |
| rec@1.0（冻结） | 1.330 | 0.668 |
| rec@0.5（学习，`w_rec` 动 7.2%） | 1.213 | 0.687 |

- **单调性在受控区间仍然成立**（0× → 0.717、0.56× → 0.698、1.02× → 0.668）；
- **学习循环权重仍无收益**——这一轮排除了"淹没"这个解释，因为电流是受控的；
- 四臂的**零输入发放率全为 0**，所以不是"自持振荡"，是大而无信息的电流稀释了 token 信号。

**结论**：在这个工作点上，**前馈 LIF + 局部读出是最优配置**，任何循环电流都在拖后腿。
SSM 那一支也随之收口：结构先验既没有在淹没时帮上忙，也没有在受控时被公平检验的必要——
因为**连最简单的循环都不值得留**。

**顺带**：A 线的 `EventDrivenEProp`（sMNIST、N=8192、fan-in 32）递推/输入电流比是 **1.106**，
与本轮掉 4.9pp 的那一档同量级。A 线的**相对结论不受影响**（两臂同一递推）。
**当天补测（A9）否掉了那个猜想**：A 线去掉递推后三种子中位 0.904 对 0.899，只差 +0.5pp
（逐种子 −1.3 / +1.7 / +1.2pp）。**所以"读推电流的斜率"不能跨任务外推**，A 线的绝对数字没有被递推拉低。


**2026-11-06 第四轮：S2 五种子确认——0.717 不是运气。**

纯前馈 LIF + 局部读出，五个种子（其余与 S1 的 `none` 臂逐字相同）：

| 种子 | 0 | 1 | 2 | 3 | 4 | 均值 | std |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| top-1 | 0.7166 | 0.7137 | 0.7115 | 0.7312 | 0.7400 | **0.7226** | **0.0124** |
| CE | 1.139 | 1.195 | 1.222 | 1.152 | 1.156 | **1.173** | — |

- **S2-0..S2-4 五条判据全过**：均值 0.7226 ≥0.70、std 0.0124 ≤0.02、
  **每个种子都赢 bigram 6.6–9.4pp**、CE 均值 1.173 < 1.423；
- 极差只有 **2.85pp**，比 A3 的三种子（4.4pp）稳得多。

**这是本支线第一个种子稳健的正结果**：纯局部学习规则（逐时刻 e-prop + NLMS 读出，全程无 autograd）
在这份语料上稳定优于二阶字符 bigram，而且**不需要任何递推**（S1 已证明加了只会更差）。

**边界**：字符级、模板语料、单层、N=1,024、2,000 updates；测试集 46 条；不能外推到"能闲聊"。


**2026-11-06 第五轮：R0——换真实语料，六折全输。**

把语料从 SEL 模板换成**真实会话**（265 对 / 34,183 字 / 1,246 唯一字，仓外，不入库），
留一会话六折，其余与 S2 相同：

| 语料 | 唯一字 | bigram top-1 | 模型 top-1 | 差 |
| :--- | ---: | ---: | ---: | ---: |
| SEL 模板（S2） | 274 | 0.646 | **0.7226** | **+7.7pp** |
| **真实会话（R0）** | **986–1,244** | **0.184** | **0.080** | **−10.4pp** |

**R0-0..R0-3 四条判据全不过**：0/6 折赢，均值差 −10.37pp，损失只降到初值的 0.57–0.63。

**结论**：S2 的 0.7226 **不能外推到真实文本**——那是低熵模板语料的结果。
在本轮预算下（每折 118–252 对训练样本、2,000 updates、N=1,024），前馈局部学习**连字符 bigram 都追不上**。
模型确实在学（0.080 远高于 1/1,200 的随机线），但远远不够。

**分不开的一件事**：是"数据太少"还是"架构太浅"。下一步按计划是**合成扩充**（几千到几万对）再跑同一套判据；
在那之前**不调 N 或 τ**——那是"调到绿为止"。


**2026-11-06 第六轮：R1 三档难度阶梯——只有最容易那档有效。**

用本地 `qwen3-4b` 造三档合成语料（各 3,000 对，只改话题/性格/温度/轮数四个旋钮）：

| 档 | bigram | 模型 | Δ | 赢的折 | 每折 CE 尾/首 |
| :--- | ---: | ---: | ---: | ---: | :--- |
| **E** | 0.4765 | **0.4973** | **+2.08pp** | **6/6** | 0.50–0.54（已收敛） |
| M | 0.3463 | 0.2390 | −10.72pp | 0/6 | **0.71–0.73（欠拟合）** |
| H | 0.2919 | 0.1752 | −11.67pp | 0/6 | **0.79–0.82（欠拟合）** |

**R1-2（每档都收敛）不过，所以 M/H 判为「不可判」，不判为「输」。**
根因是**我的设计错误**：S2 是 301 条样本跑 2,000 updates（106 epoch），
R1 每折 2,500 条还是 2,000 updates（**12.8 epoch**）——语料扩了 8 倍，更新次数没跟着扩。

顺带排除了一个怀疑：M/H 的崩溃**不是**词表截断（top-800 覆盖 97%+ 的字符）。

**现在有三个有效点**：bigram 0.646 → **+7.7pp**（S2）、0.4765 → **+2.1pp**（R1-E）、
0.184 → **−10.4pp**（R0）。**三点单调**，但中间 0.35–0.30 那段仍空白。

**下一步是 R1b：把更新次数按 epoch 对齐**（约 20,000 updates，三折可把成本压到 1.5–2 小时）。
**在那之前不改 N 或 τ**——那是把"没训够"误读成"架构不够"。


**2026-11-06 第七轮：R1b——训够之后，R1 的"M/H 输"消失了。**

只把 updates 从 2,000 提到 **16,000**（≈103 epoch，与 S2 的 106 对齐），三档三折：

| 档 | bigram | 模型 | **Δ** | R1（2k） | 每折 CE 尾/首 |
| :--- | ---: | ---: | ---: | ---: | :--- |
| **E** | 0.4766 | 0.6123 | **+13.58pp** | +2.1pp | 0.32（收敛） |
| **M** | 0.3505 | 0.3397 | **−1.08pp** | −10.7pp | 0.51（收敛） |
| H | 0.2933 | 0.2542 | −3.92pp | −11.7pp | 0.62（仍欠一点） |

**同一语料、同一架构、同一超参，只改训练量，三档 Δ 分别抬了 11.5 / 9.6 / 7.8pp。**
所以 **R1 的"M/H 输 10–12pp"作废**，那是 12.8 epoch 的结果。

**拐点在 bigram 0.35–0.48 之间**：0.48 上赢 13.6pp，0.35 上打平（−1.1pp）。H 仍不可判（R1b-0 不过）。

**悬着的一条**：R0（真实语料）也是 2,000 updates 级，虽然没有欠拟合的直接证据
（CE 比 0.57–0.63、epoch 128–271），但**没做过 epoch 对齐的复跑**——"−10.4pp 是真输还是欠拟合"
目前无解。这是唯一悬着的点。
