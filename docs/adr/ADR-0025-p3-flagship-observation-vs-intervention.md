# ADR-0025：把「观察学习 vs 干预学习」设为阶段四旗舰问题

[English](ADR-0025-p3-flagship-observation-vs-intervention.en.md) · [日本語](ADR-0025-p3-flagship-observation-vs-intervention.ja.md)

- **状态**：已采纳
- **日期**：2026-10-29
- **相关**：世界模型 P3 v2–v6、[阶段四状态](../stage4_status.md)、ADR-0015

## Context

P3 的两组结果形成鲜明对照：**开环**固定动作的终止预测 AUROC **0.999996**（FP 0.000504、
命中 0.998），**闭环**滚动时域 v6 AUROC **1.0**、终止步误差 1.14e-5；而 **500 步纯想象**
闭环只有 **0.63–0.67**，根因已定位到动作反馈与 float32 逐位敏感性（结构性，不是调参）。

这组对照不是「一个组件好坏」，而是**两种学习设定的签名**：观察学习（外部动作序列固定）
下模型几乎完美；干预学习（模型自己的动作进入反馈回路）下误差累积。它是阶段四最锋利、
也最可证伪的问题。

## Decision

1. 把「**观察学习 vs 干预学习**」设为阶段四旗舰问题：后续世界模型实验必须明确属于哪一侧，
   并报告两侧的差。
2. 纯想象 500 步的边界**原样保留**，不再尝试用阈值/精度调参绕过；要跨越它需要新的机制
   （如动作离散化/误差重参数化），并新开预注册。
3. 阶段四的其他组件（WM/元认知/情景）作为支撑，不再单独充当旗舰。

## Consequences

- 研究方向集中到一个可证伪的差别上；
- 边界被写成「签名」而非「缺陷」，避免把它误读为训练不足；
- 代价：旗舰问题短期内不会有「ready」结论，可能长期是开放问题。

## Alternatives

- **继续调纯想象闭环**：根因是 float32 与动作翻转，已证明不可达；否决。
- **放弃 P3**：会丢掉阶段四最锋利的对照结果；否决。
