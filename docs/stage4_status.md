## 2. “ready”是什么意思

- 只表示**在该组件的预注册判据下**通过（见各结果 README），不包括：
  - 阶段四端到端任务；
  - 与总线/插件的集成；
  - 脉冲化（工作记忆）或全局部化（元认知标定头）；
- 所有“负结果/边界”原样保留，没有事后改判据；计划书台账 ㊽–87 是完整索引。

## 3. 开放研究项（按建议顺序）

1. **端到端 v3（压力测试）**：v2 五条全过，但情景目标是分离良好的离散 E（top-1 1.000，
   管道通而非难记忆）。下一步应加**容量/噪声/更多事件**的压力测试，或换一个真正需要记忆的
   任务；不要把 1.000 当一般化记忆能力。
2. **工作记忆 v6（脉冲）**：v5 的失败在**表示**（60 步计数只有个位数），不在读出；
   v6 需改膜电位/亚阈值状态、更长积分窗口或 rate 输入。注意 v5 跑了 2598.7 s，下一轮
   要减种子/窗口或并行。
3. **元认知 v4（全局部标定 + 跨任务）**：v3 的标定头是 IRLS 测量头；且分类置信度在
   WM 回归任务上 AUROC 0.562，不能自动迁移。v4 需局部标定并在目标端到端任务上重验。
4. **世界模型 P3 后续**：终止闭环的分布偏移（离线 0.999 → 闭环 0.665）没有解决；
   方向是更强状态模型（把发散步从 115 推远）或与想象分布匹配的终止头；一步想象增广
   已试，0.632，不够。
5. **情景记忆**：现有任务/噪声/评估口径下没有可用配置；若重启，应换任务/时间编码/
   评估口径，而不是继续调 k/β 或编码维度。
6. **工作记忆 v5 的替代**：如果项目坚持“纯脉冲计数”，需要先解决低计数表示问题；
   否则接受 v4 的速率漏积分器作为阶段四的可用局部表示。
