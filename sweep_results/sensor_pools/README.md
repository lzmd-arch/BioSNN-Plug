## 一句话结论

**五个池里四个单跑成立、一个（`presence`）按判据不合格；五池共存时四个保持，
`presence` 掉 16.6pp；区间侧抑制与分时程激素都没有可测收益，激素"分时程"与

## 〇、**重要更正：§一/§二 的数字都是单次抽签的结果**

2026-11-14 晚补做的配对实验推翻了这一轮的两个说法，先看这里再看下面的表。

### 更正 1：`presence` 在共存里**没有系统性失效**，之前那 −16.6pp 是比较口径错

原先比的是"单跑（`--init-scale`）"与"共存（`--pool-scales`）"，两者**初始化不是同一次抽样**：
随机流位置不同、分母还跟着 `n_rec` 走（单跑 √172、共存 √236）。
换成"每个池用自己的固定生成器 + 固定参考分母"之后，单跑与共存拿到的是**同一块初值**，
5 个种子的配对比：

| 种子 | `presence` 单跑 | 共存 | Δ | | `temp` 单跑 | 共存 | Δ |
| ---: | ---: | ---: | ---: | :--- | ---: | ---: | ---: |
| 0 | 0.202 | 0.352 | **+15.0pp** | | 0.097 | 0.109 | +1.2pp |
| 1 | 0.094 | 0.211 | **+11.7pp** | | 0.097 | 0.216 | +11.9pp |
| 2 | 0.195 | 0.067 | **−12.8pp** | | 0.211 | 0.330 | +11.9pp |
| 3 | 0.195 | 0.198 | +0.3pp | | 0.206 | 0.216 | +1.0pp |
| 4 | 0.223 | 0.241 | +1.8pp | | 0.097 | 0.320 | **+22.3pp** |
| **中位** | | | **+1.8pp** | | | | **+11.9pp** |

⇒ **共存对 `presence` 没有系统性影响**（中位 +1.8pp，五个种子里四个 ≥ 0，一个 −12.8pp 是抽签）。
`temp` 则是**系统性变好**（中位 +11.9pp，5/5 为正）——与"读出维度是杠杆、来源不限"一致。

### 更正 2：`temp 0.31 / presence 0.24` **不是下界**，是**抽签的结果**

同一任务、同一尺度、同一训练步数，只换池初值的随机种子：

| 池 | 单跑（5 个种子） | 极差 |
| :--- | :--- | ---: |
| `temp`（1 维标量） | 0.097 / 0.097 / 0.211 / 0.206 / 0.097 | **11.4pp** |
| `presence`（1 维标量） | 0.202 / 0.094 / 0.195 / 0.195 / 0.223 | **12.9pp** |

而同一条曲线**从 250 步到 6000 步是平的**（每 250 步评测一次，24 个点）：

| 步 | 250 | 1000 | 2000 | 3000 | 4000 | 5000 | 6000 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `temp`（种子 0） | 0.114 | 0.102 | 0.084 | 0.105 | 0.111 | 0.117 | 0.111 |
| `presence`（种子 0） | 0.197 | 0.169 | 0.244 | 0.220 | 0.147 | 0.205 | 0.191 |

⇒ **训练不是杠杆，初值的随机投影才是。** 这是 F4（"信息来自结构、不来自学习"）的第五次独立印证，
也是四次里**最直接**的一次：不是"学得慢"，是"学完之后仍在原来那个位置"。

**对上面 §一 表的影响**：`memory` / `persona` / `time` 在多个种子上都稳定（共存里
`time` 4/5 次 1.000、`memory` 0.936–0.986、`persona` 0.947–0.988），**结论不变**；
`temp` 的 "+19.6pp 过 S-1" 只在种子 2/3/4 成立（种子 0/1 是 0.097 vs zero 0.109，**不过**）。
⇒ **`temp` 的 S-1 是 3/5 通过**，不是稳定通过。

`presence` 修好任务后（§I-4）在合格档 `init_scale=8` 上单跑 0.094–0.223（中位 0.195），
对 `zero` 0.136 是 **+5.9pp**，**仍不过 S-1（要 10pp）**。
它的标定扫描里最高的 0.320 出现在 `init_scale=16`，而那一档发放率 0.037 **低于 0.05 的下限**，
按判据不能选。⇒ **`presence` 仍然判"不过"**，但原因是"1 维标量码太弱"，不是"任务坏了"。

## 一、单池（S-1 / S-2 / S-3）

标定：`init_scale ∈ {2,4,8,16,24,32,48,64}`，`lr-sensor=0`（纯编码），200 步，
按预注册规则取**平均发放率离 0.275 最近**的一档，并要求档间变异系数 `rate_cv > 0.10`。

| 池 | 标定尺度 | zero | add（欧氏） | add（余弦） | **Δ（弱探针）** | 发放率 | S-1 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | :--- |
| `temp`（恒定 1 维标量） | 32 | 0.109 | **0.309** | 0.305 | **+19.6pp** | 0.225 | ✅ |
| `time`（张力性积分器） | 2 | 0.000 | **1.000** | 1.000 | **+100pp** | 0.244 | ✅ |
| `memory`（一次性 16 维注入） | 2 | 0.092 | **0.931** | 0.928 | **+83.6pp** | 0.176 | ✅ |
| `persona`（持续 16 维语境） | 2 | 0.100 | **0.916** | 0.909 | **+80.9pp** | 0.168 | ✅ |
| `presence`（时变 1 维标量） | **（无合格档）** | 0.141 | 0.244 | 0.244 | **+10.3pp** | 0.125 | ❌ 见下 |

**S-2（发放率 ∈ [0.05, 0.50] 且档间变异系数 > 0.10）**：前四池全过；**`presence` 没有一档合格**——
`init_scale ≤ 16` 时 `rate_cv = 0.00`（池对驱动幅度完全不敏感），`≥ 24` 时发放率跌到 0.003–0.010
（静默区）。按预注册 §3 的标定规则，`presence` 应判 **"驱动不进来"**。

表里 `presence` 那一行的 **+10.3pp 是在 `init_scale=2` 上跑出来的，而那一档 `rate_cv = 0.00`，
按判据不合格**。它作为**协议外观察**登记，不算 S-1 通过。这一条必须原样写出来，
否则就成了"跳过判据挑一个好看的尺度"。
**S-3（`zero` 不许高出基线）**：五池全过（`presence` 的基线是它自己末值分布的多数类 0.129，
`zero` 0.141 = +1.2pp，在 3pp 内）。

### 最值得记住的一条：**维度决定成败**

| 驱动形状 | 池 | 单跑 top-1 |
| :--- | :--- | ---: |
| **16 维向量** | `memory` / `persona` | **0.92 / 0.93** |
| 1 维标量（且**档间有变化**） | `time` | **1.000** |
| 1 维标量（10 档，**同一时刻只有一个值**） | `temp` | 0.31 |
| 1 维标量（**时变、答案取末值**） | `presence` | 0.24 |

16 维向量给 0.92 是因为它**直接作用在 16 个池内神经元的电流上**——编码几乎是恒等的。
1 维标量只调"整体增益"，能被读出的是**阈值穿越的时刻**，信息量小一个量级。
`time` 之所以能到 1.000，是因为它的量是**空步数**，直接等于脉冲计数。

⇒ **"传感器通道有用"不是一句话**：**高维传感器（温度/湿度/气体阵列/图像嵌入）几乎是免费的；
低维标量（CPU 占用率、系统小时）只值十几到三十几个点。**

## 二、五池共存（S-4 / S-5 / S-6）

`--pools temp,time,memory,persona,presence`，逐池尺度 `temp:32,time:2,memory:2,persona:2,presence:2`，
1500 步，`clip=0`。

| 池 | 单跑（弱探针） | 共存 | 变化 | S-4（下降 ≤5pp） |
| :--- | ---: | ---: | ---: | :--- |
| `temp` | 0.305 | **0.489** | **+18.4pp** | ✅ |
| `time` | 1.000 | **1.000** | 0 | ✅ |
| `memory` | 0.928 | **0.978** | +5.0pp | ✅ |
| `persona` | 0.909 | **0.956** | +4.7pp | ✅ |
| `presence` | 0.244 | **0.078** | **−16.6pp** | ❌ |

**`temp` 在共存时反而更好（+18pp）**：它的 1 维标量编码本来受"池内神经元同质性"限制，
旁边多出 64 个各干各的神经元之后，读出空间变大，阈值穿越的多样性也被摊开了。
这条与"读出维度是杠杆、来源不限"（R4/R8/R11）一致——**这次买宽度的是别的池**。

### S-5：两个统计量给出相反结论

| 统计量 | 最大两两值 | 判 S-5（< 0.5） |
| :--- | ---: | :--- |
| **批次均值特征的余弦**（预注册原话） | **0.888** | ❌ |
| **逐样本池活动的皮尔逊相关**（冗余口径） | **0.217** | ✅ |

**批次均值余弦不是冗余度量**：五个池的"静息图案"本来就相似——都是同一套阈值动力学、
同一套读出 EMA 打出来的零输入响应，所以**均值向量**天然高度对齐。它测的是
"池的静止形状像不像"，不是"池在不在算同一件事"。

**逐样本相关才是冗余**：同一个样本上，池 A 的活动与池 B 的活动几乎无关（最大 0.217，
`time`–`persona`；其余多在 0.03 以下）。⇒ **五个池装的是五件不同的事，没有塌成拷贝。**

**诚实标注**：预注册写的是前者，后者是看到前者失败**之后**才补的口径。两个数都照登，
不许只报后者。

### S-6：区间侧抑制**没有收益**

| 配置 | temp | time | memory | persona | presence | 最大余弦 | 最大相关 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 无侧抑制 | 0.489 | **1.000** | 0.978 | 0.959 | 0.078 | 0.888 | 0.217 |
| 增益 0.5 | 0.489 | **0.800** | 0.967 | 0.956 | 0.078 | 0.882 | 0.189 |

- 最大余弦只降 0.006、最大相关只降 0.028，**远不到预注册要求的 −0.1**；
- 而 `time` **掉 20pp**（积分器的斜坡被邻居的发放压掉了——抑制正好打在它积分的那条通路上）。

⇒ **S-6 不过，侧抑制不默认开启。**「不冗余」这件事**本来就不需要侧抑制**（见 S-5 的逐样本相关），
这是今天的负结果里最干净的一条：**机制的名字（竞争注意力）听起来对，实测既没买到去冗余，
又赔掉一个池。**

## 三、激素（S-7 / S-8）

| 配置 | temp | time | memory | persona | presence | 最大相关 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| **分时程 + 分区受体**（基线） | 0.489 | 1.000 | 0.978 | 0.959 | 0.078 | 0.217 |
| 分时程 + 全局受体 | 0.384 | 0.900 | 0.977 | 0.958 | 0.078 | 0.220 |
| **单一标量 + 分区受体** | 0.489 | 1.000 | 0.980 | 0.961 | 0.120 | 0.214 |

**S-7（分时程 vs 单一标量）**：所有池的 |Δ| ≤ 4.2pp（`presence` 0.078 → 0.120 是唯一变化，
但它在共存里本来就贴着地板）。按预注册**事先写死的读法**，结论是
**"与单一标量不可分辨"**，不写"更好"。

**S-8（分区受体 vs 全局受体）**：池间相关 **0.217 → 0.220，没有更低** ⇒ 按判据"没有可测差别"。
但**任务指标反而分开**：`temp` 0.489 → 0.384（−10.5pp）、`time` 1.000 → 0.900（−10pp）。
⇒ 分区受体**不是靠"降低池间相关"起作用的**；它更像是在给各池**不同的调制强度**，
把弱驱动的那两个池（1 维标量）往上抬。**这是相关性解释之外的一条，未单独验证，别当结论用。**

## 五、这一轮改掉的两个"仪器错误"（比结果本身更该记住）

| # | 错在哪 | 怎么发现的 | 影响 |
| :--- | :--- | :--- | :--- |
| **I-1** | 探针用**余弦最近原型** ⇒ 对整体缩放不变，而标量驱动的池**把答案编码在发放率上** | 同一权重、同一任务，换欧氏探针结论从 0.100 变到 0.300 | 温度池的结论**随探针摇摆** ⇒ 改成**两个探针同时过才算过**（更严） |
| **I-2** | 多池共存时**共用一个训练缓冲** ⇒ 池 A 的类原型被"池 B 里同名的类"污染 | `memory` 从 0.931 掉到 0.459，但传感器权重根本没变 | 改成**逐池缓冲**，`memory` 回到 0.978 |

| **I-3** | `time` 的**标签与实际空步数脱钩**（驱动器插了 g 个空步，标签被另一条路径覆盖） | `zero` 臂 0.000、`add` 臂 1.000 | 池被跑成随机 |
| **I-4** | `presence` 的随机游走**写死 5 步**，而回合只有 2 步 ⇒ **答案那个末值从来没被喂进去** | 单跑 0.13 → 修后 0.25–0.35 | 任务本身就是坏的 |
| **I-5** | 单跑与共存的**池初值不是同一次抽样**（流位置不同、分母跟着 `n_rec` 变） | 见 §〇，−16.6pp 是假的 | 把抽签差异读成"共存有害" |

## 六、`clip` 默认值：**从 10 改回 0**

| 配置 | 温度池 top-1 |
| :--- | ---: |
| `clip=0`（不限，自然范数 ~128） | **0.306** |
| `clip=10` | **0.209**（−9.7pp） |

原来"clip 5 / 20 / 60 都是 0.306 ⇒ [5, 60] 免费"的结论，是在**范数自然落在 10–32 的配置**上测的。
按发放率标定之后，温度池的自然范数是 **~128**，clip=10 会把它削掉三分之一。

⇒ **"有界免费"不是普适结论，只在"自然范数本来就在区间内"时成立。**
`AXO_SENSOR_CLIP` 默认改成 `0`，需要时显式给。设计文档 §七 的结论据此更正。

## 七、结果入库的四问（`AGENTS.md` §2.7）

1. **是预算截断吗？** 单池与共存都是固定 1500 步、没有早停；`memory`/`persona` 在 1500 步
   已到 0.92–0.98，`temp` 0.31、`presence` 0.24 **没有跑收敛曲线**，这两个数**是下界**，
   不许当上限用。
2. **是跨语料 / 跨预算比较吗？** 不是。全部是同一套合成任务、同一批原型、同一训练步数。
   唯一跨的是**单池 vs 五池**（同一模型类、同一超参，只有神经元数与池数不同），已在 §二 注明。
3. **是单边指标吗？** 不是——两个探针（方向 / 方向+幅度）都报，S-1 取**两者中更弱的**。
4. **cos 先验兑换成 Δ 了吗？** 本轮的激素/受体的"先验"没有直接兑换成性能承诺；
   S-7 明确写成"不可分辨"，没有写"更好"。

## 八、不做 / 没做

- **`time` 的 1.000 不是"学会了计时"**：它测的是"空步数 → 脉冲计数"的单调映射，
  任务里空步是**精确插入**的。真实打字间隔有抖动、有分布外，这条离产品还差一次实测。
- **`presence` 在共存里失效**，原因未查（它是唯一"答案取末值"的池，可能被后面几步的空转冲掉）。
- **没有跑真实传感器数据**：本轮的驱动量全部是合成的（客户端不动）。
- **`rate_cv` 曾经在 `persona` 上恒为 0**：最初的人格池用 8 个簇心**循环**给簇号，
  评测里每批只有一档，变异系数没有定义。那本身就是 S-3 会抓的泄露形状——
  改成每回合随机抽簇之后 `rate_cv = 0.25`，`zero` 也从 1.000 掉回 0.100。

## 九、解析编码：把"抽签"消掉（修订 4，E-1…E-3）

既然 §〇 证明**是抽签决定成败、不是学习**，那编码就不该抽。`design_sensor_encoder`
按 LIF 的**暂态**解解析构造：神经元 j 在标量值 `s*_j` 处越过阈值，
`w_j = θ/(gainₙ·s*_j)`，`s*` 在 [0.05, 0.95] 等距铺开。

| 编码 | 池 | 种子 0–4 的 top-1（欧氏/余弦） | **极差** | 发放率 |
| :--- | :--- | :--- | ---: | ---: |
| **解析（温度计码）** | `temp` | **0.417/0.378 × 5 次完全相同** | **0.0pp** | 0.14 |
| **解析（温度计码）** | `presence` | **0.377/0.352 × 5 次完全相同** | **0.0pp** | 0.15 |
| 随机 | `temp`（尺度 32） | 0.097 / 0.097 / 0.211 / 0.206 / 0.097 | 11.4pp | 0.04–0.23 |
| 随机 | `presence`（尺度 8） | 0.202 / 0.094 / 0.195 / 0.195 / 0.223 | 12.9pp | 0.10 |

- **E-1 过**：解析编码的极差 **0.0pp**（判据 ≤3pp），随机是 11–13pp；
- **E-2 过**：解析中位 0.417 远高于随机（同尺度 0.097 / 改尺度 0.225）；
- **E-3 过**：解析的发放率 0.14–0.15，在 [0.05, 0.50] 内。

### 实现里踩的一个坑

第一版用**稳态**增益 `I/(1−α)` 算阈值电流，结果把阈值放到 10 倍远处，**整池静默、
发放率 0.00**。回合只有 2 步，必须用 n 步暂态解 `gainₙ = (1−αⁿ)/(1−α)`。
守卫 `test_ramp_encoder_places_thresholds_where_designed` 现在同时钉住
"单调"与"两端分开"；写它时还踩了第二个坑——只看**最后一步**的 `tr.z` 会被不应期错开相位，
必须**累计**。

### 一条关于修订 4 的诚实注记

"合格档里取 CV 最大"这条规则在 `temp` 的随机编码上选到了尺度 64：
CV 0.33 看着漂亮，但它的发放率只有 **0.056**（贴着下限），预测全部塌到同一个类，
top-1 恒为 **0.225**（= 多数类占比）。⇒ **CV 高不等于编码好**——分子是噪声时它也高。
后续判据应当要求 `rate` 离下限有余量（下一轮再改，本轮照实记）。
