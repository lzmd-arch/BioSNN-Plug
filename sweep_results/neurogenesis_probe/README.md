# 阶段四神经发生最小探针：控制器触发，但没带来收益（2026-10-29）

**预注册：** [`../neurogenesis_prereg.md`](../neurogenesis_prereg.md)。
玩具规模：4 个顺序任务、每任务 4 类（共 16 类）、随机 ReLU 特征、旧类读出冻结；
固定 64 特征 vs 增长 64→112/128。5 种子。

## 结果

| 臂 | 最后任务准确率 | 旧任务最低准确率 | 最终特征数 | 增长次数 |
| :--- | ---: | ---: | ---: | ---: |
| 固定 64 | **0.526** | 0.323 | 64 | 0 |
| 增长 64→128 | **0.432** | 0.310 | 112/128 | 3–4 |

`neurogenesis_ready=false`：

- 新任务准确率远低于 0.90；
- 旧任务保持也远低于 0.98（新类竞争使旧样本被判到新类）；
- 增长没有改善新任务，甚至略差。

## 为什么失败（不是“控制器没触发”）

- 控制器**确实触发**：固定臂每任务训练准确率 <0.90，增长臂 3–4 次、到 112/128；
- 但随机 ReLU 特征 + 线性 delta 读出在这个噪声/类别密度下本身学不好（单任务训练
  准确率约 0.8 量级）；
- 旧类行冻结并不能防止**新类行对旧样本给出更高 logits**——这是 class-incremental
  的竞争性遗忘，不是增长能单独解决的；
- 因此本探针的负结果说明：**只加特征神经元、不解决读出竞争/回放，神经发生不够**。

## 边界

- 玩具随机特征，不是多模态真实插件；不能外推到计划书的“多模态场景验证”；
- 旧类读出冻结是控制变量，不是抗遗忘算法；
- 没有调噪声/类别数/学习率来把结果做绿；协议按预注册。
