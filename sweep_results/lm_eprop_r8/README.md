## 三件必须一起说的事

### 1. 2×2 补齐了，而且**方向与 regime 无关**

| regime | 缩容量 | 扩容量 |
| :--- | :---: | :---: |
| 合成 A（容量约束区） | **−3.74pp**（R3 臂 a） | **+4.88pp**（R4） |
| 真语料（记忆化区） | **−1.04pp**（R6q） | **+3.88pp**（R8） |

**扩容量在两边都好、缩容量在两边都坏。** 原来那个"两个 regime 方向相反"的漂亮故事**被数据否掉了**，
换来的是一句更简单、也更结实的话：**读出维度是杠杆，regime 无关。**

（幅度不同——合成 +4.88 / 真 +3.88——合理解释是合成语料的基线天花板更高，容量更值钱。）

### 2. 补上读出之后，离 BP 还差 5.4pp——那是**信用分配**的账

| 模型 | 参数 | Δ |
| :--- | ---: | ---: |
| BP（GRU + BPTT，B0） | 1.77M | **−0.83pp** |
| 局部规则 + 多时间尺度读出（R8） | **6.2M** | **−6.24pp** |

**SNN 现在比 BP 多 3.5 倍参数，仍差 5.41pp。** 读出的账已经付掉一大半（B0 的 9.29pp 里 3.88pp 归读出），
**剩下的是 BPTT 与逐时刻局部更新之间的差距**。

### 3. CE 与 top-1 的第三种脱钩形状

- R0b：CE 升、top-1 平；
- B0：top-1 好、CE 极差；
- R6q：top-1 全低、CE 全好；
- **R8：CE 在 2,000 步见底、top-1 一路涨到 8,000 步。**

四种形状说明：**这两个指标在这条支线上必须同时报**，任何一个单独都能给出错的故事。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp）——+3.88pp 明显超出噪声，但**具体的 pp 数不可当精度**；
- 8,000 步在 CE 的上升段（top-1 仍涨），**不代表更晚的停止点**；
- 读出参数 4 倍（1.25M → 4.98M，整机 2.49M → 6.2M）——**这不是免费改进**；
- 四个 τ（2/8/32/128）是一个选择，**没扫**；更多 τ 是否继续增益**未测**；
- 字符级 next-token，**不代表能闲聊**。

## 对路线的影响

1. **停止条件（字面已触发）暂缓**：读出杠杆在真语料上成立，这条支线没死；
2. **剩下的缺口是信用分配**：5.41pp，且是在 SNN 参数多 3.5 倍的情况下；
3. **下一步的候选**（都不在本轮预注册里，要新写）：
   - **τ 组合的剂量–反应**：4 个 → 8 个 τ 还能不能继续涨？（最便宜，1.5 小时）
   - **数据 × 读出**：R8 的读出 + 更多数据是否叠加？（贵，需先定数据规模）
   - **信用分配本身**：更深/更密的资格痕迹、或块内 BPTT——这是最难的，也是真正的研究问题。
