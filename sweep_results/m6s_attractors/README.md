## 二、判决：**"个体坐进不同状态"存在**

- `g_inh = 0`：**连续吸引子** —— 每个初值收敛到**自己的**状态（近配对 0.00、远配对 1.00），
  且 1024→2048 只漂 **1.5%**。**状态携带的是连续信息。**
- `g_inh ≥ 1`：**离散多吸引子** —— 近配对 0.11–0.15、远配对 0.85–0.89 的双峰分布。
  等大盆的粗估是 **6–9 个盆**。

## 三、这条推翻了我自己先前的一个论证

我在这轮之前说过"冻结的增益让动力学成为仿射映射，而仿射映射最多只有一个不动点，
所以个体选择在数学上不存在"。**这个论证在这里不成立。**

系统不是仿射的，是**分段仿射**：`z = 1[nv > θ]` 把状态空间切成 `2^N` 块，
每一块有自己的仿射映射与不动点。**"至多一个不动点"只在块内成立**，
跨块完全可以有很多个。

实测正是如此。这条记在这里，免得下次再拿它当结论。

## 四、把前三轮重新定位

M6p（3.14×/1.02×）、M6q（1.35×）、M6r（1.68×）量的一直是**"历史能写多深"**。
**从来没有检查过"状态有没有地方可去"。** 现在知道有了 —— 而且停得住。

⇒ **写不深是另一个问题，不是"没有状态"的问题。** 前三轮的负结果不需要撤回，
但它们的意思变了：不是"个体不存在"，是"**历史对盆地的指派太弱**"。

## 五、下一问：盆地指派

既然盆存在，正确的问法就不是连续的 `rel` 距离，而是**离散的盆地下标**：

1. 从真实历史（A / B / A'）接着跑到 T=2048，把每个个体**指派**到一个盆；
2. 比较三种条件下的**盆地占用分布**；
3. **判据**：A vs B 的分布距离 >> A vs A' 的分布距离。

这比 `rel` 距离干净得多：它不关心"状态差多少"，只关心"**有没有被送到不同的地方**"。

## 六、限定

- 收敛 5% / 近 0.05 / 远 0.5 三个阈值都是本轮定的，没有外部依据；
- 只数**定点与短周期**；长周期或混沌会被判成"不收敛"（S-1=0 时该格作废）；
- 随机初值不等于"历史可达的初值" —— 盆的存在性不等于历史能到达它们，**这正是 §五 要测的**；
- 线性谱盲区仍在。
