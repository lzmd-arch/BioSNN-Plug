# 黑箱混沌判据：工具可用；**复数哈密顿系统不是混沌的**

## 一、判据自检（X-1）—— 这是本轮最重要的东西

| 序列 | `K`（0–1 test） | `λ`（Rosenstein） | 判定 |
| :--- | ---: | ---: | :--- |
| 正弦 | **−0.005** | −0.0002 | 规则 ✅ |
| 周期 3 | **−0.000** | −0.0000 | 规则 ✅ |
| Logistic r=4 | **+0.997** | +0.367 | 混沌 ✅ |

**三个已知序列全部给对。** 所以后面两个判定是可信的 —— 这一步没有它，后面全是自欺。

## 二、复数哈密顿系统：**不是混沌**

| `Γ` | `K` | `λ` | 输出序列 std | 判定 |
| ---: | ---: | ---: | ---: | :--- |
| 0.1 | +0.017 | +0.076 | 2.10 | 未定（不一致） |
| 0.4 | +0.015 | +0.075 | 2.06 | 未定 |
| 1.6 | +0.013 | +0.076 | 2.12 | 未定 |

**`K ≈ 0.015`，与正弦的 −0.005 同量级** ⇒ 0–1 test 说的是**规则（准周期）**。
`λ` 给出 +0.076，但 Rosenstein 在准周期序列上本就容易给小的正斜率。

按预注册记为「**未定**」（两判据不一致），但证据是偏的：
**`K` 在三个 `Γ` 上几乎不动（0.013–0.017），这本身就是"不是混沌"的强证据** ——
混沌系统的 `K` 会随参数明显变化。

⇒ **v11 那个模型在现在的参数下是准周期的，不是混沌的。**
"模拟量子混沌系统"这个提法在**这个实现下不成立**。

## 三、LIF 参照：序列退化，判定无效

`K = +0.998`（看着像混沌），但**输出序列 std = 4.975e-06** —— 序列几乎是常数。
在一个近常数的序列上，0–1 test 给任何值都没有意义。

原因是那次 `build` 用的尺度让网络基本不放电。**这一条作废，需在工作点上重跑。**

## 四、这一轮的收获

1. **拿到了一个可信的黑箱混沌计**（三个已知序列全对），
   它只吃标量序列，**不读任何内部状态** —— 这正是用户要的纪律；
2. **否掉了"复数哈密顿系统是混沌的"这个假设**（在现参数下）；
3. 暴露了 LIF 参照的退化（又一次分母/工作点问题，但这次被 std 拦住了）。

## 五、要让这个模型真的进混沌，需要什么

现在 `g = 1.0`、无驱动。`K` 对 `Γ` 完全不敏感 ⇒ 系统没有被激发到非线性区。
候选：

1. **加大非线性 `g`**（当前 `|ψ|² ≈ 1/N`，`g|ψ|²` 很小，非线性几乎不起作用）；
2. **归一化到 `|ψ|² = O(1)` 再乘 `g`** —— 现在量纲上非线性项被摊薄了；
3. **加时变驱动**。

**这是量纲/归一化的问题，不是"量子启发"本身的问题。** 但按纪律，
下一次要在预注册里写明归一化方式，再测 `K` 是否随 `g` 上升。

## 六、结论

| 提法 | 判定 |
| :--- | :--- |
| 黑箱判混沌（只吃输出） | ✅ 工具可用，已验证 |
| 复数哈密顿系统 = 混沌 | ❌ **现参数下不成立** |
| "量子启发"这个方向 | **未定** —— 先修非线性量纲再测 |
