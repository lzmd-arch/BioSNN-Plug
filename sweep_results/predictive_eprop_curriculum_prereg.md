# 预注册：Predictive E-prop 的误差课程（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景

`predictive_eprop` 的三种子里只有 seed0 的自由运行三条全过（seed1 的 DTW 差 0.004、
seed2 幅度 0.119）。当时的读法是：训练时误差通道持续提供目标信息，网络可以部分依赖它；
关掉后能否自持取决于学到的循环动力学是否恰好落在振荡区。

## 改动（只加课程，不改规则/结构）

在训练的**最后 30% epoch**，把误差回注增益 `error_gain` 从 1.0 **线性降到 0**
（此后仍以 target 计算误差与学习信号，只是不再把误差送回网络输入）。其余与
`predictive_eprop_prereg.md` 完全一致：n_rec=300、T=500、4 trial/更新、chunk=10、
150 epoch、lr_rec=3e-4、lr_out=1e-2、gain=1、种子 0–2。

## 判据（三种子中 ≥2 个满足才 `predictive_curriculum_ready=true`）

对每个种子，沿用原预注册的三条：

1. 重建 MSE ≤ **0.1×** 初值；
2. 自由运行幅度比 ∈ **[0.5, 2.0]**；
3. 自由运行 DTW ≤ **0.5×** 未训练对照。

**并且**加一条不许退化：

4. 课程结束时的重建 MSE 不得高于同一配置无课程对照（`predictive_eprop/summary.json`
   的同种子终值）的 **2×**——否则“把误差关掉”只是把重建也关掉了。

## 不做什么

- 不调网络结构、超参、种子数；
- 不把课程写成“睡眠”或“自监督能力”；
- 不在看到结果后改比例（30%）或判据。

## 边界

- 仍是正弦任务、3 种子；不外推到 Lorenz；
- 课程只是消融误差通道的一种方式，不是原文的做法。
