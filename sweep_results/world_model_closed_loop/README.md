| 0 | 2.61e-8 | 120.42 | 5.49e-10 | 0.000 | 101 |

| 3 | 1.84e-8 | 123.23 | 4.47e-10 | 0.000 | 101 |

- 闭环 H=10 比 `copy_last` 低 **10 个数量级**（比值 ~2e-10）✅；
- 闭环误差比开环大约 **40×**，但仍在 1e-8 量级；
- H=100 内**没有终止**，所以终止 AUROC `not_evaluable`——这是测量窗口问题，不是模型问题；
- 首发散步 101（H=100 内没有超过 0.5）。

## 结论

v1 只能回答"闭环状态预测在 100 步内很准"；终止不可评。按预注册不判失败、不调参，
由修订 1 换 H=500 重跑。
