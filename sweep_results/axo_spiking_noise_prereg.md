# 预注册：Axo 真脉冲原型第三轮（噪声、流式整合、候选子集延迟）

**定稿时间：2026-10-18。**
前两轮：[`axo_spiking_prototype_results.md`](axo_spiking_prototype_results.md)、
[`axo_spiking_sparse_results.md`](axo_spiking_sparse_results.md)。
结论都是：脉冲没有赢过同预算的速率基线；5 万条单次查询 160.7 ms。

这一轮不再重复“静态补全 / 相邻轮次”，而是问一个此前没有回答的问题：
**在输入有噪声、或者证据分片到达时，脉冲的阈值与适应带来的非线性，能不能赢过
一个时间常数相同、步数相同的线性泄漏积分器？**

## 要回答什么

1. **噪声下**：同一条记忆的探针被反复呈现 T 次，每次带不同的位翻转噪声。
   脉冲（阈值 + 适应 + 不应期）会不会比线性泄漏积分器更抗噪？
2. **流式整合**：同一条记忆的活跃位被切成 T 片、每步只给一片。
   脉冲能不能把 T 片整合成接近“完整探针一次给”的水平？线性积分器同样做对照。
3. **延迟**：用倒排索引先取候选子集，只对子集跑稀疏 matvec；5 万条单次查询能不能
   压到 100 ms 以内。

## 数据与表示

- 166 条真库只读副本；164 条有词法码；全局 `idf-2.0`、`k=64`、4096 位。
- 稀疏码 `(idx, weights)`；`matvec` / `transpose_matvec` 同第二轮。
- 噪声与分片都由**确定性**规则生成（固定种子，不用 `np.random` 的全局状态）。

## 任务与臂

**任务 A：重复呈现 + 噪声**

- 基础探针：目标记忆的关联码丢 50% 位。
- 噪声：再随机把 `ρ` 比例的非活跃位加上随机权重（ρ ∈ {0, 0.05, 0.10, 0.20}）。
- 重复 T=5 次，每次用不同的确定性噪声图案。
- 臂：
  - `rate-once`：只用第一次带噪探针，一步 `A·(Aᵀ(A·p))`。
  - `rate-integ`：线性泄漏积分器 `v ← α·v + I_in(t)`，末态读出（α=0.95）。
  - `spiking`：同样的输入，LIF 膜电位读出（α=0.95）。
  - `spiking-alif`：再加适应（β=1）与全局抑制。
- 判据：在任一噪声档上，`spiking_top1 > rate-integ_top1 + 0.05` 才算“非线性有增益”；
  ±0.05 内“打平”；否则“输”。

**任务 B：流式分片整合**

- 把 50% 丢位探针的活跃位确定性切成 T=5 片，每步只给一片。
- 臂：
  - `rate-full`：完整探针一次给（上界，不是可实现的在线方案）。
  - `rate-first`：只给第一片（下界）。
  - `rate-integ`：线性泄漏积分器，5 步。
  - `spiking` / `spiking-alif`：同 5 步。
- 判据：`spiking` 与 `rate-integ` 比差；同时报它与 `rate-full` / `rate-first` 的距离。
  只有 `spiking > rate-integ + 0.05` 才算“非线性在整合上有增益”。

**任务 C：候选子集延迟**

- 50,000 条确定性合成稀疏码；倒排索引 `bit → rows`（CSR 形式）。
- 查询：对探针的每个位取倒排表，合并成候选集；候选数上限 M=2,000。
- 只对候选子集跑稀疏 `rate` 一步，取 top-1。
- 报：建索引时间、单次查询时间、候选数、top-1 与全量扫描是否一致（合成码上
  全量 top-1 是可算的）。
- 判据：单次查询 **≤ 100 ms** 且 top-1 与全量扫描一致（允许候选上限导致的差异，
  但必须报出来）。

## 停止规则

- 只在上面定义的噪声档、T=5、α=0.95、单一种子下跑；不在看到结果后追加网格。
- 不写真实库；临时副本用完删除。
- 没有学习（STDP/e-prop）；转移矩阵与编码都是既有的。

## 边界

1. 166 条真实记忆；任务 C 的 50,000 条是**合成码**，不是真实记忆。
2. 噪声是位级翻转，不是自然语言扰动；结论不能直接推到“真实输入噪声”。
3. 任务 B 的分片是人为切分，不是真实的时间流。
4. 墙钟时间不能论证神经形态能效。

## 怎么被核验

`scripts/axo_spiking_noise_stream_prototype.py` 输出每个配置一行 JSON，含完整参数、
top-1/top-5、每步脉冲数、耗时与候选统计。执行者按上表机械判定。
