# P1：公开语料第一臂——**Δ +0.86pp，首次在公开语料上越过 bigram**（2026-11-10）

**预注册**：[`research/sel/prereg-lm-p1-public-corpus.md`](../../research/sel/prereg-lm-p1-public-corpus.md)
**原始数据**：[`p1_kdconv.json`](p1_kdconv.json)、[`bp_kdconv.json`](bp_kdconv.json)

## 一句话

KdConv（Apache-2.0，1,574,749 字）官方 test 切分上，单层局部规则模型
**top-1 0.2973 > bigram 0.2887 → Δ = +0.86pp**（1/1 折赢）。

**这是这条线第一次在公开语料上赢 bigram**——但只跑了 **7.7 个真 epoch**，**峰值就在最后一个评测点**，
曲线还在涨。**CE 仍落后**（3.949 vs 3.769），所以这是"**排序赢了、似然没赢**"的又一例（第七种脱钩形状）。

## 三件必须一起说的事

### 1. "首次在公开语料上赢 bigram"要带两个限定

- **只跑了 7.7 个 epoch、峰值就在最后一个点**——这是**预算截断**，不是收敛；
- **CE 仍落后**（3.949 vs 3.769）。按纪律，措辞是"**first-pass 就追平并小幅超过**"，不是能力声明。

### 2. 判别带：落在 R10 那一带的上沿，不是"显著高于"

R10 在 bigram 0.288–0.294 的同邻域上 Δ = −1.7 ～ +0.6pp；P1 是 **+0.86pp**——
**略高于带顶（+0.6pp）约 0.26pp**，但跨语料、跨预算，**不能算"显著"**。
按预写的三档，属于"**规模 + 真源的增益**"一侧，但幅度温和。

### 3. 与 BP 的差距仍是 23.4pp

同语料、同 batch、同 8,000 步：**BP 236 秒拿到 +24.3pp**；SNN 每步约 0.47 秒（约 15 倍 wall-clock）
在 16,000 步拿到 +0.86pp。**规则相对 BP 的账在健康语料上第一次可以按同等数据暴露来算**——
结论是：**23.4pp 的缺口，不是数据的问题**（同一份数据 BP 能吃下 24pp）。

## 边界

- 单折（官方 test，4,868 对 / 226,709 token）、单种子；
- **7.7 epoch、峰值未到**——所有数字是"这个预算下的"，不是天花板；
- 字符级；**不代表能聊**；
- 未做「三元组喂进输入」的判别实验（P2 第一项，已预注册）。
