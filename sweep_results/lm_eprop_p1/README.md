# P1：公开语料第一臂——**Δ +0.86pp，首次在公开语料上越过 bigram**（2026-11-10）

**预注册**：[`research/sel/prereg-lm-p1-public-corpus.md`](../../research/sel/prereg-lm-p1-public-corpus.md)
**原始数据**：[`p1_kdconv.json`](p1_kdconv.json)、[`bp_kdconv.json`](bp_kdconv.json)

## 一句话

KdConv（Apache-2.0，1,574,749 字）官方 test 切分上，单层局部规则模型
**top-1 0.2973 > bigram 0.2887 → Δ = +0.86pp**（1/1 折赢）。

**这是这条线第一次在公开语料上赢 bigram**——但只跑了 **7.7 个真 epoch**，**峰值就在最后一个评测点**，
曲线还在涨。**CE 仍落后**（3.949 vs 3.769），所以这是"**排序赢了、似然没赢**"的又一例（第七种脱钩形状）。

## 结果

## 三件必须一起说的事

### 1. "首次在公开语料上赢 bigram"要带两个限定

- **只跑了 7.7 个 epoch、峰值就在最后一个点**——这是**预算截断**，不是收敛；
- **CE 仍落后**（3.949 vs 3.769）。按纪律，措辞是"**first-pass 就追平并小幅超过**"，不是能力声明。

### 2. 判别带：落在 R10 那一带的上沿，不是"显著高于"

R10 在 bigram 0.288–0.294 的同邻域上 Δ = −1.7 ～ +0.6pp；P1 是 **+0.86pp**——
**略高于带顶（+0.6pp）约 0.26pp**，但跨语料、跨预算，**不能算"显著"**。
按预写的三档，属于"**规模 + 真源的增益**"一侧，但幅度温和。

### 3. 与 BP 的差距仍是 23.4pp

同语料、同 batch、同 8,000 步：**BP 236 秒拿到 +24.3pp**；SNN 每步约 0.47 秒（约 15 倍 wall-clock）
在 16,000 步拿到 +0.86pp。**规则相对 BP 的账在健康语料上第一次可以按同等数据暴露来算**——
结论是：**23.4pp 的缺口，不是数据的问题**（同一份数据 BP 能吃下 24pp）。

## 边界

- 单折（官方 test，4,868 对 / 226,709 token）、单种子；
- **7.7 epoch、峰值未到**——所有数字是"这个预算下的"，不是天花板；
- 字符级；**不代表能聊**；
- 未做「三元组喂进输入」的判别实验（P2 第一项，已预注册）。

# P2：把知识三元组前置——**Δ 从 +0.86pp 抬到 +2.50pp**（2026-11-10）

**预注册**：[`research/sel/prereg-lm-p1-public-corpus.md`](../../research/sel/prereg-lm-p1-public-corpus.md)（含 P2 的输入格式与「未观测上下文」判别）
**原始数据**：[`p2_ctx.json`](p2_ctx.json)

## 一句话

把 KdConv 每条回复自己挂的**知识三元组前置**到输入（覆盖率 **64.7%**），其余与 P1 逐字相同：

| | P1（无上下文） | **P2（前置三元组）** | 差 |
| :--- | ---: | ---: | ---: |
| top-1 | 0.2973 | **0.3137** | **+1.64pp** |
| Δ vs bigram 0.2887 | +0.86pp | **+2.50pp** | **+1.64pp** |
| CE | 3.949 | **3.798** | −0.15（bigram 是 3.769） |

**「未观测上下文」这个竞争解释站住了**：KdConv 的回复锚在那 18,535 条三元组上，
模型看不到它们时，缺口里有一部分是**输入侧的可观测性问题，不是规则无能**。

## 曲线

| updates | 2k | 4k | 6k | 8k | 10k | 12k | 14k | **16k** |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| P2 top-1 | 0.2116 | 0.2497 | 0.2703 | 0.2843 | 0.2936 | 0.3033 | 0.3088 | **0.3137** |
| P1 top-1 | 0.1928 | 0.2322 | 0.2525 | 0.2657 | 0.2769 | 0.2862 | 0.2915 | 0.2973 |
| P2 CE | 4.629 | 4.314 | 4.144 | 4.031 | 3.959 | 3.889 | 3.840 | **3.798** |

**P2 全程领先，且两个指标同向**（top-1 与 CE 一起变好）——这是 R0b 以来第一次没有出现 CE/top-1 脱钩。

## 输入格式（预注册里写死的三条）

1. **前置**（`chr(4)…chr(5)` 包住），因为这个模型没有注意力，上下文唯一的作用机制是膜电位 priming；
2. **先截上下文、绝不截回复**：数据侧保证 `len(ctx)+len(pair)+5 ≤ 192`，上下文先按 80 字截；
3. **给该条回复自己挂的三元组**（中位 1 条），覆盖率 64.7%；其余回复 `context=""`，与 P1 逐字相同。

**控制**：bigram 基线在**剥掉上下文**的序列上算（0.2887，与 P1 同口径）；模型只对 user/assistant 计分
（`_mask_context` 把上下文段从 `valid` 划掉）。否则上下文会同时抬高 bigram 与模型，比较是软的。

## 限定语（按四问清单）

1. **是预算截断吗？** 是——峰值就是最后一个评测点（14k 0.3088 → 16k 0.3137），**数字是下界**；
2. **是跨语料/跨预算比较吗？** 与 P1 同语料、同预算、同词表，只有输入格式不同——**这一条是干净的**；
3. **是单边指标吗？** 不是——**top-1 与 CE 同向改善**；
4. **cos 先验？** 无关（这一轮没有余弦预测）。

## 边界

- 单折（4,868 对 / 226,709 token）、单种子、7.7 epoch；
- 覆盖率 64.7%：35.3% 的回复没有 KB 标注，那些对与 P1 等价；
- **位置切片这次没录到**（`evaluate` 已返回 `top1_by_pos`，但 `run_fold` 当时没写进 JSON，
  现已补上）。若要看"增益是否集中在长回复尾部"，需要按同配置重跑一次（约 1.5 小时）。
