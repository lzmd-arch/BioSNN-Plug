# W3 脉冲执行层 D4：策略的状态依赖性诊断（2026-10-29）

**预注册：** [`../rstdp_spiking_state_dependence_prereg.md`](../rstdp_spiking_state_dependence_prereg.md)。
**诊断，不是验收。** 训练 count-aligned 脉冲 Actor（与历史臂同配置），用**最终权重**在极角
网格 `θ ∈ [−0.2, 0.2]`（21 点）上测 `P(动作=左)`；与同种子未训练网络对照。
每点 20 次采样，随机流按 (seed, 角度) 冻结。

## 结果

| 指标 | 实测 | 判据 | 结果 |
| :--- | ---: | :--- | :--- |
| 训练后 slope > 0 的种子数 | **0/10** | ≥ 8/10 | 未过 |
| 训练后 slope 中位 | **0.000** | ≥ 0.10 | 未过 |
| 未训练 slope 中位 | **−0.05** | ≤ 0.05 | 过（见下方警告） |

`state_dependence_detected = false`。

逐种子（训练 / 未训练 slope）：
0：0.00 / +0.15；1：0.00 / +0.20；2：0.00 / −0.15；3：0.00 / −0.15；4：0.00 / −0.05；
5：0.00 / −0.10；6：0.00 / −0.05；7：0.00 / 0.00；8：0.00 / 0.00；9：0.00 / −0.05。

**训练后的曲线是常数**：21 个极角上 `P(动作=左)` 完全相同——多数种子恒为 1（总是推左），
一个种子恒为 0（总是推右）。也就是说，**800 回合训练后，动作完全不依赖极角**。

## 读法

- 预注册的三条判据里，前两条（符号 8/10、幅度 0.10）**都不过**，而且是**零**，不是“差一点”；
- ⚠️ **对照判据这次不能当证据**：未训练网络的 slope 在 −0.20 到 +0.20 之间，中位恰好
  −0.05 落在阈值内，但这是**有符号中位数**抵消的结果，不是“随机网络没有状态依赖”。
  编码 + 随机读出让未训练网络也有 5–20 个百分点的角度依赖；这条判据的写法本身太弱，
  下一次要改成 |slope| 的分布比较；
- **训练把状态依赖抹平了**：未训练有 0.05–0.20 的角度依赖，训练后恰好 0.000——这不是
  “没学到”，而是策略塌成了常数。

## 含义与下一步

- 与 D3（末次 9.55）和口径复核一致：末期没有可用策略；
- 常数动作既可能是**熵坍缩**（策略把概率全压在一边），也可能是**输出层沉默 + argmax 平局**；
  D5（[`../rstdp_spiking_collapse_prereg.md`](../rstdp_spiking_collapse_prereg.md)）用熵轨迹
  与窗口脉冲数区分这两者——修法完全不同；
- 在那之前，**不要再换读出或加宽度**：问题在训练动力学，不在策略头。

## 边界

- 只扫极角，其余状态固定为 0；不覆盖速度/角速度依赖；
- 每个网格点 20 次采样，`P(左)` 的分辨率 0.05；
- 用**最终**权重（不是 best 快照）；best 快照的行为由诊断 ③ 另行谈；
- 训练配置固定为 count-aligned 的历史臂，不外推到其他规则。
