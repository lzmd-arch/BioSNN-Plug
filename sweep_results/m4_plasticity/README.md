# M4（Round C）：**6 种子下不过 —— 加种子推翻了 4 种子的"过"**

判据在 `research/sel/night-2026-11-16.md`。能力 = 解码历史族的准确率。
流程：基线 → 用族 0–3 做 STDP 训练 → 测量 → 用族 4–7 训练 → 测量。

## 二、4 种子那版为什么"过"

4 种子版本的退化是 **−0.031（即提升）**，本版是 **+0.118**。
**差在种子 4**：它的旧族从 0.833 掉到 **0.375** —— 单个种子的灾难性遗忘。

⇒ **4 种子那轮的"过"是种子选择的结果。** 本版取代它。

## 三、但那个**倒 U 复现了**

| 版本 | 新族：基线 → 学旧族后 → 学新族后 |
| :--- | :--- |
| 4 种子 | 0.422 → **0.750** → 0.578 |
| **6 种子** | 0.535 → **0.729** → 0.625 |

**两版的形状一致**：学**别的**族会把目标族的可解码性推高（泛化），
再专项训练反而把它拉回来（过度特化）。

**⇒ 现象稳（倒 U），判据不过（平均退化 0.118）。** 两件事都要写。

## 四、限定

- 6 种子；STDP 一个学习率、每阶段 6 批，未扫；
- `seed 4` 的 −0.458 是单个种子的极端值，**没有排除它是实现问题**（例如该种子的重量分布恰好进入不稳定区）；
- 能力只在"8 族解码"这个实验室任务上测过，不能外推；
- 另有一条独立限定：**这个能力指标对损伤不敏感**（M5b：切 50% 后解码反而升高），
  所以"退化"所依赖的能力本身是被削弱的信号。
