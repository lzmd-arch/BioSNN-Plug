# M4（Round C）：**终身可塑 —— 过线，而且旧本领没有退化，反而略有提升**

判据在 `research/sel/night-2026-11-16.md`（跑之前）。
能力指标 = 解码历史族的准确率（Round A 建立）。
流程：基线 → 用族 0–3 做 STDP 训练 → 测量 → 用族 4–7 训练 → 测量。4 种子。

| ---: | :--- | :--- | ---: |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| M4-0 训练前旧族可解码（> 底板 +0.15） | 0.562 vs 0.172，**过** |
| **M4-1** 旧族退化 <0.10 且新族终值 > 底板+0.15 | 退化 **−0.031**（即**提升** 0.031）、新族 0.578，**过** |

## 二、真正的发现不是"过"，是那个**倒 U**

```
新族可解码性：  0.422  --(学旧族)-->  0.750  --(学新族)-->  0.578
                   基线上限           泛化峰值             过拟合回落
```

**学旧族让新族的可解码性几乎翻倍。** STDP 不是把网络推向"记住 0–3"，
而是把它推向"状态更可分"—— 一个**通用的**改善。

然后专门学新族，反而从 0.750 掉到 0.578。**专项训练把它拉回去了。**

⇒ 这条与"灾难性遗忘"正好相反：**这里的问题是过度特化，不是遗忘**。
旧族全程没掉（0.500 → 0.594，均值还涨了）。

## 三、限定

1. **只有 4 个种子**，而且 M4-1 判的是**均值**：种子 0 的旧族掉了 **0.126**（超过 0.10 的线），
   种子 1、2、3 是涨的。**"没退化"是均值意义下的，不是每个种子都成立。**
2. 新族在"学旧族后"的 0.750 是**同一个探针口径下的重测**，不是跨网络泛化；
3. STDP 用的是 `wrec` 归一化到行和 1.2 的规则，学习率 0.05、每阶段 6 批 —— **一个配置，未扫**；
4. 能力只在"8 族解码"这个实验室任务上测过，**不能外推**；
5. 训练前旧族 0.562 是 4 个种子的均值，其中种子 1 只有 0.375（接近底板 0.125 + 0.25），
   **起点本身差异大**。
