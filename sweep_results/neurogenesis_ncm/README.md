# 神经发生 v2：NCM 读出——新任务升到 0.766，但旧任务更差（2026-10-29）

**预注册：** [`../neurogenesis_v2_prereg.md`](../neurogenesis_v2_prereg.md)。
同 v1 的 4 任务 ×4 类、噪声 1.3、随机 ReLU 特征；只把读出从线性 delta 换成 NCM
（最近类均值），增长只补特征维、旧类均值补零；5 种子。

## 结果

| 臂 | 最后任务 | 旧任务最低 | 最终特征 |
| :--- | ---: | ---: | ---: |
| 固定 64 | 0.617 | 0.508 | 64 |
| 增长 64→128 | **0.766** | **0.277** | 112/128 |

`neurogenesis_v2_ready=false`：

- 新任务仍 <0.90；
- 旧任务下降 **23.1 pp**，远大于 2pp；
- 增长触发 3–4 次，但把旧任务压得更差。

## 为什么 NCM 也没救回来

- 随机 ReLU 特征对 16 类/噪声 1.3 的表示本身不足，NCM 的类均值重叠；
- 增长补维确实让**最后任务**从 0.617 提到 0.766，但新类原型在旧样本上同样竞争，
  旧任务最低从 0.508 掉到 0.277——NCM 只去掉了“旧行被重训”，没去掉“新类原型竞争”；
- 控制器的触发是有效的；失败在表示与读出竞争，不是控制器逻辑。

## 边界

- 仍是玩具随机特征，不是多模态真实插件；
- NCM 不是局部可塑性；本实验只验证“增长 + 无竞争读出”是否足够，答案是不够；
- v1 线性 delta 的负结果原样保留，不混报；
- 不调噪声/类别数/特征数/判据；下一版要换**可分的真实特征**或**带拒绝/原型的读出**，
  需新预注册。
