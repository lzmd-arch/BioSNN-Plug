# 阶段五 M3b：真实 LLM 对话评测（2026-10-29）

**预注册：** [`../phase5_m3b_prereg.md`](../phase5_m3b_prereg.md)（判据在真 LLM 数据之前定稿）。
装置：`biosnn_mcp.dialogue`（20 个会话 × 5 轮 = 40 个知识轮）；真实模型 **qwen3-4b**，
本机 Ollama（`127.0.0.1:11434`，无外网）；`think=false`，适配器另剥 `<think>` 块。

逐会话：40 个知识轮里 **39** 个命中关键短语；唯一未命中的是 *what is the capital of brazil*，
模型答 **Brasília**（带重音），预注册的关键短语是 `brasilia`——这是**匹配器的重音问题，
不是答错**。按预注册口径仍记为未完成，不回改判据、不改匹配器。

## 读法：四条判据里只有一条真正有信息量

- **首次触发**近乎结构性：会话第 1 轮就是未预置的知识题，触发策略是规则门，所以
  「≤10 轮」几乎必然成立；
- **触发准确率**同样由规则门决定：记忆里有的知识题不调用、chat/memory 不调用，
  这是 `TriggerPolicy` 的定义，不是模型学会了「什么时候该调用」。它证明的是**接线正确**；
- **巩固成功率**是「写进去、下一轮按同一条目取回」的必然结果（M3a 的平凡性在这里仍在）；
- **只有完成率**是模型能力：40 个知识轮中回答里是否出现预设关键短语。

所以这张表**不能**读成「SNN 自主决定调用 LLM 的能力成立」。它能说的是：真实模型接进
管道后，触发门、记忆写入/取回、对话 trace 都按设计工作，且回答质量可测（qwen3-4b 在
这 26 个未预置知识题上全部答对）。

## 与第一次运行的关系

第一次运行（带思考块）在跑到约 35% 时被中止：qwen3 把 `<think>` 写进 `response`，单次调用
约 **18 s**（`think=false` 后 **0.2 s**），且思考文字会让关键短语在推理过程里误命中。
中止后把 `think=false` 与 `<think>` 剥离写进适配器与预注册，再重跑；**正式数字只来自
这一次**，第一次的 trace 已删除。

## 边界

- 合成题库 38 条、关键短语判定；不外推到开放域对话；
- 基线预置了每 3 条里的第 1 条知识（14/40），否则提升比无定义；
- 单次运行、无重复；temperature 走服务端默认，未量化方差；
- 记忆替身是词重叠检索，不是真实 memcore 向量召回；
- 触发策略是规则门，没有「自主触发」的学习成分。
