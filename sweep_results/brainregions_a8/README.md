# 线 A v8：SHD 上 32k + 28 抽头——规模在有余量的任务上也没用（A8）

**日期**：2026-11-05
**预注册**：[`research/brainregions/prereg-a8-shd-scale.md`](../../research/brainregions/prereg-a8-shd-scale.md)
**原始数据**：[`a8.json`](a8.json)

## 一句话

**32,768 神经元 + 28 抽头 = 0.748，比 8k 的 0.757 低 0.9pp。**
SHD 不是贴天花板的任务，规模仍然买不到精度。**同时：这一臂的峰值显存到了 9,960 MiB，超出了 8 GB 的预算。**

## 结果：SHD 的 2×2 全了

| 神经元 | k=1 | k=28 |
| ---: | ---: | ---: |
| 8,192 | 0.338（S8） | **0.757**（A5 三种子中位） |
| 32,768 | 0.348（S8） | **0.748**（本轮） |
| **规模效应** | **+1.0pp** | **−0.9pp** |

**形状和 sMNIST 一样**：把读出补全之后，规模带来的那点优势消失。

## 判据

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |
| N-0 | **装得下**（前置） | <8,000 MiB | **9,960.1 MiB** | ❌ |
| N-1 | 规模买得到精度 | ≥ +2pp | **−0.9pp** | ❌ |
| N-2 | 没练坏 | ≥0.737 | 0.748 | ✅ |

## 两件事要分开说

### 1. 科学结论：规模在有余量的任务上也没用

A4 在 sMNIST 上测过同一件事，但那时 0.917 已经贴着线性读出天花板（0.916），**没有余量**，
所以 A4 的 −0.3pp 可以被解释成"到顶了"。**SHD 不是**：0.757 离该任务的好结果还有距离。

**即便这样，4 倍神经元仍然给不出东西（−0.9pp）。** 这条把容量轴的结论从"饱和任务上饱和"
扩展成"**在这条管线的两个任务上，换掉读出之后规模都不值钱**"。

⚠️ **分辨率**：8k 的种子 sd 是 0.76pp，−0.9pp 只有约 **1.2 个标准差**。
所以能说的是"**没有增益**"，**不能反过来说"规模有害"**。

### 2. 工程结论：32k + 28 抽头**装不进 8 GB**

预注册把"峰值 <8,000 MiB"写成前置判据，实测 **9,960 MiB**——**超了 1.8 GB**。

这台机器是 8 GB 卡，Windows 的 WDDM 允许把显存溢出到系统内存，所以**没有 OOM，但**：
- 训练墙钟（3,681 s）**不可信**，里面有内存换页的成分；
- "这条管线在 8 GB 上能跑多大"的回答要改：**8k + 28 抽头（4,171 MiB）能跑，
  32k + 28 抽头不能**——而 32k + 单抽头（S8：7,393 MiB）能跑。

**读出宽度和神经元数在显存上是要抢的**，这条以前没有人量过。

## 边界

- **单种子**（seed 0）；32k 只测了一个规模；
- 32k 的读出是 `32768 × 28 × 20 ≈ 18.3M` 参数，比 8k 那臂大 4 倍——**若结果为正，
  不能直接归因给"神经元更多"**；结果是负的，这条混杂反而无关紧要；
- 对照 8k 的 0.757 是三种子中位，32k 是单点；
- 不与 sMNIST 的数字横向比较。

## 这条合上了一个口子

预注册里写："若 N-1 过 2pp，说明'规模在有余量的任务上仍然有用'，那 ADR-0033 的'容量饱和'
要加上'在饱和任务上'这个条件。"

**没发生。** 所以 ADR-0033 的结论**不需要加这个限定**——它在两个任务、两种读出下都成立。
