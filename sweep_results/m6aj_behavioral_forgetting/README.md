# M6aj：**行为的遗忘曲线 —— 假设被推翻：行为记忆很弱，但它不失忆**

## 为什么做

`M6ai` 在闭环 **128 步**时给出行为-历史比 **2.19×**（2 种子），512 步时塌到 0.52–0.97×。
看起来像"行为层也有遗忘曲线"。本轮用 **6 种子**、五个时长把它量实。

## 结果

| 闭环步数 | 历史距离 | 对照距离 | **比值** | 窗内 |
| ---: | ---: | ---: | ---: | ---: |
| 32 | 0.0760 | 0.0714 | **1.07×**（4/6） | 1.00 |
| 64 | 0.0827 | 0.0699 | **1.18×**（4/6） | 1.00 |
| 128 | 0.0922 | 0.0718 | **1.28×**（5/6） | 1.00 |
| 256 | 0.0997 | 0.0724 | **1.38×**（5/6） | 1.00 |
| 512 | 0.1018 | 0.0782 | **1.30×**（3/6） | 1.00 |

| 判据 | 结果 |
| :--- | :--- |
| AJ-0 各档不熄火不饱和 | **过**（五档全部 100% 窗内） |
| AJ-1 有行为遗忘曲线（短 >1.5、长 <1.2） | **不过** |

## 一、判决

**没有遗忘曲线。** 比值从 1.07 缓慢升到 1.38，再微降到 1.30 —— **不是衰减，是缓慢上升后走平**。

而且 **128 步的 2.19× 是 2 种子的噪声**，6 种子下同一点只有 **1.28×**。
> 这是今晚第三次"小样本给出乐观结论、加种子后回落到 1.3 左右"（另两次：M8 的 σ=0.2、M5b 的高活跃）。

## 二、那剩下的是什么

**闭环行为确实带一点历史（1.3×），而且这点历史不失忆。**
但 1.3× 低于今晚所有判据用的 1.5 门限，所以**不能声称"行为带个体史"**。

诚实说法：**闭环产生了非平凡的自生成行为（熵 0.52–0.56、100% 窗内、6/6 确定性），
但这行为对起点的依赖只有 1.3×**。

## 三、限定

- 6 种子；1000 条历史位置一个测点；
- 轨迹距离用**发放时序的相对距离**（`rate_dist`）。符号汉明距离会被边际分布污染，已弃用；
- 闭环的"运动映射"是固定随机的 8×N 线性映射，**不学习**；
- 只测了闭环起点为族 0 与族 5；其他族对未测。
