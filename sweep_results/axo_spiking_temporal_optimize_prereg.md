# 预注册：时序读出的受控优化（2 折交叉验证）

**定稿时间：2026-10-18。**
上一轮单次结果：LIF 时序读出 0.6308 vs 线性 0.5280（+10.28 pp），但只测了一个读出、
一个阈值，且线性/脉冲共用 θ。这一轮给两种模型**同一套读出与阈值调参预算**，在
训练折上选，在留出折上报。

## 要回答什么

在顺序任务（A→B / B→A，目标都是先到的那个）上，把读出与阈值都当作可调超参：

1. 给线性和脉冲同样的候选读出、同样的 θ 网格；
2. 在 2 折交叉验证的训练折上选最佳组合；
3. 在留出折上比较：脉冲是否仍然比线性高 ≥5 pp？

如果优势在留出折消失，说明上一轮的 +10 pp 至少有一部分来自“挑读出/阈值”。

## 数据与划分

- 166 条真库只读副本；164 条有词法码；全局 `idf-2.0`、`k=64`、4096 位。
- 同会话相邻轮 107 对；A→B 目标 A，B→A 目标 B；完整码，5 步（2 输入 + 3 零输入）。
- **2 折**：按配对序号奇偶划分。每折用一半选超参，另一半报结果；两折都报。

## 读出家族（两种模型共用）

对每条记忆 m，`t_i` 是位 i 的首次越阈（线性）或首次发放（脉冲）步号，未越阈为 ∞：

| 读出 | 分数 |
| :--- | :--- |
| `sum_inv` | `Σ w_i / (1 + t_i)`（上一轮用的） |
| `min_inv` | `1 / (1 + min_i t_i)`（只看最早的一位） |
| `top3_inv` | 最早的 3 个 `w_i/(1+t_i)` 的均值 |
| `top5_inv` | 最早的 5 个的均值 |
| `exp1` | `Σ w_i exp(-t_i / 1)` |
| `exp2` | `Σ w_i exp(-t_i / 2)` |
| `window1` | `Σ w_i 1[t_i ≤ 1]` |
| `window2` | `Σ w_i 1[t_i ≤ 2]` |

## 模型与阈值

- 线性：α ∈ {0.95, 0.98}；LIF：α ∈ {0.95, 0.98}；ALIF：α=0.98、β=1、ρ=0.9。
- 共用 θ ∈ {0.3, 0.5, 0.7}。
- 每个模型在训练折上从 (α, θ, 读出) 组合里选训练准确率最高的一组；测试折只报一次。

## 判据

- **主判据**：留出折上 `spiking_best − linear_best` 的平均值。
  - `> +0.05`：时序读出有稳健增益；
  - `±0.05`：打平；上一轮的 +10 pp 不能算稳健；
  - `< −0.05`：输。
- 同时报两折分别的差、选中的 (α, θ, 读出)，以及训练/测试准确率。
- 只看测试折；训练折的数字只用于解释“选了什么”。

## 停止规则

- 只跑这一个读出家族 × θ 网格 × 2 折；不在看到结果后追加读出。
- 不写真实库；临时副本用完删除。
- 没有学习；W 是既有 Hebbian 外积。

## 边界

1. 107 对、2 折，每折约 53 对；测试集很小，1 条差异约 2 pp。
2. 人为顺序任务；相邻轮配对相似度未控制。
3. 读出/阈值的候选集是人工定的；更大网格可能改变结果，但这一轮只看这个预算下
   是否稳健。
4. 墙钟时间不能论证能效。

## 怎么被核验

`scripts/axo_spiking_temporal_optimize.py` 输出每折的选中组合与测试准确率；执行者按
上表机械判定。
