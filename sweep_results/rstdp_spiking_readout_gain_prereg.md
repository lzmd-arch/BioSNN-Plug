# 预注册：W3 D11——计数读出到底要多大差驱动才分得开（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（D10 已测，不是猜测）

D10（[`rstdp_spiking_direction/README.md`](rstdp_spiking_direction/README.md)）测到：训练出来的
差方向**确实随状态变**（4/5 种子是同范数随机方向的 2.95–13.4 倍），但它的相对幅度只有总驱动
的 **0.5–7.3%**；把差方向放大 16 倍并逐列 L1 归一化后，21 点网格上 Δ 计数的极差仍只有
**0.25–0.55**，而且**随放大倍数不单调**。同时 B 显示输入整体放大 4 倍时计数能动 1.8–2.65。

所以问题从「方向有没有」变成了「**计数读出对差驱动的增益有多大**」。D11 用一个**构造的、
已知大小的**差方向去标定这个增益，不训练网络——训练那一环留到 D12。

## 协议（纯标定，不训练）

- 公共列 `c`：固定随机向量（`torch.Generator(seed)` 均匀 `±1/√n_in`，与 `LIFLayer` 初始化同式），
  按列 L1 归一化到 1（与 Actor 的 `_normalize` 同口径），**5 个种子各一条**；
- 差方向 `δ`：随机单位向量，按目标相对幅度缩放——用编码器在 21 点极角网格上把
  `A_spread_abs / mean_drive` 标到 **ρ ∈ {0（空对照）, 0.05, 0.10}**；
- 两列 `w_0 = c + δ/2`、`w_1 = c − δ/2`（**不重新归一化**，否则会把差方向按比例压回去）；
- 判据量：21 点网格上 `Δ = counts_left − counts_right` 的**极差**（每点 20 个冻结窗口，
  随机流种子 `seed*100000 + 2*100 + int(value*100)`，与 D10 相同）。

## 网格（先写死；这一轮是**标定**，不是假设检验）

| 旋钮 | 取值 |
| :--- | :--- |
| `threshold` | 1.0（现状）、0.5、2.0 |
| `n_refractory` | 2（现状）、0、1 |
| `baseline_period` | 5（现状）、`None`（bias=0）、10 |
| `steps`（窗口长度） | 25（现状）、50 |

全网格 3×3×3×2 = **54 个配置 × 5 种子**；每个配置都记：Δ 极差、每列平均计数、零窗口比例、
20 个种子无关的「两列计数相等的点数」。

## 判据（先写死）

单个配置记为**可用**（`gain_usable`）当且仅当三条同时成立：

1. **分辨力**：ρ=0.10 时 21 点 `Δ` 极差 ≥ **2.0** 计数（足以让 argmax 随状态翻转）；
2. **不平凡**（反退化）：每列在网格上的**平均计数落在 2–15**（窗口 25 步时；
   50 步的窗口按比例放宽到 4–30）——全静默或全饱和都不算「分辨力」；
3. **不是噪声**：ρ=0 的空对照下同一极差 ≤ **0.5** 计数（否则所谓极差是采样噪声）。

- 有配置满足三条 → 记 `readout_gain_calibrated=true`，并按「**窗口最短 → 常规化程度最小**」
  的顺序给出推荐配置；D12 的训练轮**只跑一个**推荐配置，不扫网格；
- 全网格无一满足 → `readout_gain_calibrated=false`：结论是**计数读出在 25–50 步内分不开
  10% 的差驱动**，下一步不再是调参，而是换读出（差分膜电位 / 发放率 / 更长积分窗）。

## 不做什么

- 不训练网络、不改规则、不动 STDP 参数；
- 不因为某个配置在 ρ=0.10 上过线就写成「训练能学会」——那要 D12；
- 不在同一批数据上挑完配置再改判据；ρ 与阈值都写死在这里；
- 不把「计数极差 ≥2」写成「准确率会涨」；它只保证**贪心动作能随状态变**这一个必要条件。

## 边界

- 公共列 `c` 是随机的，不是训练后的真实列；标定的是**读出结构**的增益，不是某个模型的增益；
- 点状态（其余分量为 0）网格，不是完整状态空间；
- 与 D10 的 `C` 量同口径，但 D10 的 `C` 测量的是**训练得到的**差方向，两者不可直接相加。
