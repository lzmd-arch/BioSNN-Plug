# M6v：**状态流形的内在维度 —— 2.49 / 3.30，不是高维**

## 为什么必须单独测

M6s/M6u/M12 都只数了"有多少个互不相同的持久态"（`g_inh=0` 时 128 条历史给 **82–114 个**）。
但**互不相同 ≠ 高维**：一条 1 维曲线上的 128 个不同位置也满足。

## 仪器：参与比 PR + two-NN，**带合成自检**

自检（已知维数的线性子空间，512 点）：

| 合成维数 | PR | 相对误差 | two-NN | 相对误差 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1.00 | 0.00 | 1.02 | 0.02 |
| 4 | 3.98 | 0.01 | 3.90 | 0.03 |
| 16 | 15.46 | 0.03 | 14.64 | 0.09 |

⇒ **PR 可用。**（初版自检用绝对容差 ±0.3 判 d=16，把正常的有限样本偏差误判成坏工具——
PR 在 n/d 小时系统性偏低，容差必须相对。）

## 结果

| `g_inh` | 状态数 | **PR** | two-NN | 发放 |
| ---: | ---: | ---: | ---: | ---: |
| **0** | 128 | **2.49** | 0.00（失效） | — |
| **1** | 128 | **3.30** | — | — |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| D-1 高维（`g=0` 的 PR > 4） | **2.49，不过** |
| D-2 交叉抑制压缩维度 | **3.30 > 2.49，方向相反，不过** |

## 一、判决：**128 个"互不相同"的状态，落在约 2.5 维的流形上**

这是本轮唯一要记住的一句。它同时把前面几轮的直觉对齐了：

| 测量 | 数 | 说的是 |
| :--- | ---: | :--- |
| M6p 时间轴残余 PR | 1.83–2.08 | 个体**之内**的时空图案数 |
| M6v 状态流形 PR | 2.49 | 个体**之间**的独立方向数 |
| M6u 离散盆数 | 10–14 | 交叉抑制下的离散状态数（≈3.5 bit） |

**三种口径，同一个量级：2–3。** 这个系统的状态是低维的，不是高维的。

## 二、two-NN 为什么失效

1024 维空间里 128 个点的两两距离几乎等距（维数灾难），`d2/d1 ≈ 1` ⇒ `log μ ≈ 0` ⇒
估计量退化，本格返回 0.00。**只用 PR，two-NN 的结果一律不采信。**

## 三、限定

- **PR 是下界**：128 个样本对 "几十维" 的流形估计不足。但 2.49 远低于 128 的上限，
  所以**不是被样本量截断的**，这是实打实的低；
- 特征是逐神经元发放（N=1024），没有做任何降维预处理；
- 2 种 `g_inh`、4 种子；`T_SPONT=2048`；
- "维度低"不等于"信息少"—— M6t 的 8 类解码仍有 0.536。**低维的连续状态可以携带相当的连续信息。**
