# 事件驱动 e-prop：10k 神经元 1 epoch 规模冒烟（2026-10-29）

**性质：训练路径冒烟，不是 500k 验收，也不与 W2 精度比较。** sMNIST、n_rec=10,000、
fan_in=32、batch=8、6000 训练样本、1 epoch、1000 测试样本、CPU。

## 结果

| 指标 | 实测 |
| :--- | ---: |
| 训练样本 / 更新数 | 6000 / 750 |
| 1 epoch 耗时 | **205.6 s**（0.274 s/update） |
| 测试准确率 | **0.5200**（1 epoch、6000 样本；**不作精度结论**） |
| 稀疏权重 | 320,000 |

## 能说什么 / 不能说什么

- **能说**：event-driven e-prop 在 10k 神经元、batch=8 上能跑完 6000 样本的一轮更新；
  显存没有触发 OOM（进程正常结束）；
- **不能说**：500k 训练可跑；本轮只到 10k，且只用了 6000/60000 样本；
- 0.52 只是 1 epoch 的测试准确率，不能与 W2 的 30/250 epoch 数字比较；
- 没有记录峰值显存（脚本未采），不能引用“8GB 内”作为结论。
