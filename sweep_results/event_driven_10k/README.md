# 事件驱动 e-prop：10k 神经元 1 epoch 规模冒烟（2026-10-29）

**性质：训练路径冒烟，不是 500k 验收，也不与 W2 精度比较。** sMNIST、n_rec=10,000、
fan_in=32、batch=8、1 epoch、1000 测试样本、CPU；先跑 6000 子集，再跑满 60,000。

## 结果

| 训练样本 | 更新数 | 耗时 | 测试准确率 |
| ---: | ---: | ---: | ---: |
| 6,000（子集） | 750 | 205.6 s | 0.5200 |
| **60,000（完整 1 epoch）** | **7,500** | **2,397.1 s（40 min）** | **0.6970** |

完整 1 epoch 的 0.697 是 10k 神经元、1 epoch、seed0 的结果；**仍不能与 W2 的 30/250
epoch 精度比较**。稀疏权重 320k；batch=8，0.32 s/update。

## 能说什么 / 不能说什么

- **能说**：event-driven e-prop 在 10k 神经元、batch=8 上能跑完 60,000 样本的完整 1 epoch
  （40 min），显存没有触发 OOM（进程正常结束）；
- **不能说**：500k 训练可跑；本轮只到 10k；
- 0.697 只是 1 epoch、单种子的测试准确率，不能与 W2 的 30/250 epoch 数字比较；
- 没有记录峰值显存（脚本未采），不能引用“8GB 内”作为结论。

## 下一步

1. 多 epoch / 多种子尚未跑；单 epoch 的 0.697 不是收敛值；
2. 100k 只在子集上试（3.84 s/update，完整 epoch 约 16 h）；
3. 500k 训练仍不承诺；前向/单 update 已证明路径。
