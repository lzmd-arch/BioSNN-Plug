## 读法（这一轮改写了 D 系列的一半结论）

1. **D17 的诊断是对的，而且影响巨大**：编码器修好之后，末期 `mean Δ` 在极角网格上的极差中位从
   **0.2 涨到 6.2（30 倍）**，逐种子最高 11.4（窗口只有 25 步）。**「末期读出没有状态信息」
   （D8）这一条，至少有一大半是编码器造成的**——输入几乎不变，任何读出都读不出东西来。
2. **但策略仍不随状态变**：`slope` **0/10 为正**，4 个种子还是**负向**（θ>0 时更常推右，方向反了）。
   `Δ` 的幅度很大、但符号在整条网格上不变——这与 D9/D16 的结论一致：**幅度不是瓶颈**。
3. **末次中位仍是 9.85**（未变），但 **seed 4 的末次 = 269.1**——这是整条脉冲执行层里第一次有种子
   在**末期**保持在 200 步以上（D 系列全部历史里末次中位 9.2–18.3、单个种子的峰值多为 `best`）。
   一个种子的偶然不足以过判据，但它说明**修好编码后，这条架构有能力撑住控制**。
4. 判据按预注册判 `false`：slope 与末次都不过。**不能写 ready**，但也不能再写「读出无状态信息」。

## 边界

- 归一化 + σ′=0.35 是一种选择（按"匹配正常轴的敏感度"选出），不是唯一合理的选择；
- 探针仍只扫极角（其余维度为 0），但这次该维在输入侧确实可分辨（`rel` 1.40、`cos` 0.0008）；
- 10 个种子，`last` 的方差极大（9.2–269.1），中位数被 9 个种子决定；
- 训练超参没动——**修编码不等于修规则**，两者的贡献要分开看。
