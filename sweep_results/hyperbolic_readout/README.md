# 双曲读出（HR-1/2/3）：没有优势；且被判点两臂都低于随机

**一句话**：在**唯一明显可解**的 K=4 上，双曲比欧氏高 **+1.6pp**（判据要 ≥5pp）。
K≥16 两臂都在随机线上，而 **HR-1 恰好判在 K=32 —— 那里两臂都低于随机**，
所以那个判定无效。

## 结果（3 种子、n=2048、每臂单独标定输入尺度）

| K | 随机 | 欧氏 | 双曲 | 差 | 参数量（欧/双） |
| ---: | ---: | ---: | ---: | ---: | :--- |
| **4** | 0.250 | **0.414** | **0.430** | **+0.016** | 8202 / 8202 |
| 8 | 0.125 | 0.138 | 0.148 | +0.010 | 8210 / 8210 |
| 16 | 0.0625 | 0.073 | 0.073 | +0.000 | 8226 / 8226 |
| 32 | 0.0313 | **0.026** | **0.029** | +0.003 | 8258 / 8258 |

（`seg = T/K`，所以 K 越大每段证据越少 —— K=32 时只有 2 步。）

## 判

| 编号 | 结果 |
| :--- | :--- |
| **HR-1**（最大 K 上双曲 − 欧氏 ≥ 0.05） | ❌ **不过**（+0.003）——**但见下** |
| **HR-2**（增益随 K 单调） | ❌ 不过（+0.016 / +0.010 / +0.000 / +0.003 不是单调） |
| **HR-3**（参数量差 <5%） | ✅ 过（**逐位相同**，8258 / 8258） |

### HR-1 这个判定本身是无效的

判据写的是"最大 K"，而最大 K 上**两臂都低于随机**（0.026 / 0.029 < 0.0313）。
在一个解不了的任务上比 0.003 的差没有意义。

`spatial_dim` 的 **S-0** 就是为这件事写的（"工作点 + 真解码"不过 ⇒ 整个实验作废），
本实验没有这一条 —— **这是判据的缺口，照实记在这里，不事后改 HR-1**。

### 唯一有信息量的一档

**K=4**：0.414 vs 0.430，随机 0.25。这一档任务确实可解，差 **+1.6pp**，
**远低于 5pp 的门槛**。⇒ **在双曲读出本该最有利的层级结构上，没有测到优势。**

逐种子看更清楚（这一行是重点，不要只看均值）：

| 种子 | 欧氏 | 双曲 | 差 |
| :--- | ---: | ---: | ---: |
| 0 | 0.378 | 0.365 | **−0.013** |
| 1 | 0.362 | 0.411 | +0.049 |
| 2 | 0.503 | 0.513 | +0.010 |

**3 个种子里有 1 个方向相反**，而种子间跨度 12–14pp，比要测的 +1.6pp 大一个量级。
⇒ 正确说法是「**没有可测的差异**」，而不是「双曲略好一点」。

K=8 是边缘档（+1.0pp，两臂仅高于随机 1.3–2.3pp），不足以单独下结论。

## 与 `hyperbolic_tree.py` 的正结果不矛盾

`scripts/hyperbolic_tree.py` 测的是**嵌入本身**的层级保真（Sarkar 构造下
深度–半径关系，秩相关 +0.117/+0.090/+0.080，且 shuffle 消融掉 0.27）。
本实验测的是**拿双曲当分类读出**。两件事不同：

- 前者说 "Poincaré 球**能**表示树"（几何事实，已有正结果）；
- 后者说 "用它当读出**更好**"（本实验，**没有证据**）。

## 这次重跑顺带修掉的

| 缺陷 | 处置 |
| :--- | :--- |
| 任务生成器没播种 | `seeded_dirichlet` |
| 输入尺度写死 16×（n=2048 时 ≈0.353，阈值 0.5 —— 可能一直接近静默） | 接 `calibrate()` 逐 K 标定 |
| 旧 `result.json` 四个 K 全是空字典 | 某 K 产出的臂少于 2 个时直接抛错，不再写半空文件 |

## 还缺什么

一个 **"每档必须可解"** 的门（等价于 `spatial_dim` 的 S-0）。
这一轮不能补回去判 HR-1 —— 那是改已发布的判据。要么写 `prereg_amend`，
要么把 K∈{16,32} 的结果直接记为"未测到"。
