# 预注册：W3 D17——编码器能不能分辨极角（D 系列结论的上游复核）（2026-10-30）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（D16 的一个附带观察，必须正式测）

D16（[`rstdp_spiking_orthogonalise/README.md`](rstdp_spiking_orthogonalise/README.md)）之后顺手量了一下
探针网格的**特征空间**几何：

```
cos(p(θ=−0.2), p(θ=+0.2)) = 0.99946     # 整段极角的两端
max |p(−0.2) − p(+0.2)|  = 0.035         # 单维最大变化
p(0) 的 L1 质量          = 7.42
```

也就是说：**极角从 −0.2 扫到 +0.2，输入模式只变了 0.5%**（相对 L1），而两个随机 CartPole
状态之间的余弦是 0.18–0.96。如果这一点成立，那么 D4/D8/D9 里「极角 slope = 0」**可能不是
读出或学习规则的问题，而是编码器根本分辨不出极角**——那是 D 系列全部结论的上游前提。

D17 只测这一件事，不训练。

## 协议

- 编码器：`research.components.cartpole_encoding`（脉冲线用 `CARTPOLE_HALF_WIDTHS`、σ=1.0；
  速率线用统一半宽 1.5、σ=0.5，见该模块的说明）；64 个中心，种子 0–4（各一套中心）；
- 对**每个状态维度**各取 21 点线性网格，覆盖该维的**物理范围**：

| 维度 | 范围 |
| :--- | :--- |
| `x` | ±2.4 |
| `ẋ` | ±3.0 |
| `θ` | ±0.2095（CartPole 终止角；也是任务真正的范围） |
| `θ̇` | ±3.0 |

- 其余维度固定为 0；
- 对每套中心、每个维度算三个量：
  1. **相对灵敏度** `rel = max_s ‖p(s) − p(s₀)‖₁ / ‖p(s₀)‖₁`（`s₀` 为该维中点）；
  2. **端到端余弦** `cos(p(下限), p(上限))`；
  3. **单步灵敏度**：相邻网格点之间的最大 L1 相对变化（= 该维的分辨率）。

## 判据（先写死，5 套中心逐套判，≥4/5 一致才成立）

1. **缺陷成立**：脉冲编码器在 `θ` 维上 `rel < 0.10`（整段极角的输入相对变化不足 10%）
   **且** `cos > 0.99`，≥4/5 套中心；
2. **对照**：同一判据下，**速率线编码器**（半宽 1.5、σ=0.5）在 `θ` 上 `rel ≥ 0.50` 或
   `cos ≤ 0.90`，≥4/5 套——即"同一任务、同一维度，两种编码器的分辨力差一个量级"；
3. 两条都成立 → `encoder_blind_to_angle=true`：**D4–D16 的极角 slope 结论要打上
   "探针维度本身不可分辨"的注记**；不成立则记为「编码器没问题，D 系列结论维持原样」。

## 读法护栏

- 这只说明**编码器对 θ 的分辨力**，不直接说明"训练失败的唯一原因"——但它是一条**上游前提**：
  如果输入对 θ 几乎不敏感，任何下游读出/规则都学不出 θ 依赖的策略；
- 训练时真实的 CartPole 状态在四个维度上都变，所以"网络看不见状态"这句话只在 **θ 依赖**上成立，
  不能扩大成"输入没用"；
- 速率线的编码器是**另一个模块参数化**（同一实现、不同半宽/σ），不是另一份代码——对照是干净的。

## 不做什么

- 不训练、不改任何默认参数；
- 不因为这一条就立刻改编码器（改编码器 = 新一轮预注册 + 重跑 D4/D8/D9 的探针）；
- 不用"常识"替代测量：三个量都从代码里现算。

## 边界

- 只在"其余维度为 0"的单维网格上测；
- 相对灵敏度依赖 `s₀` 的选取（用中点）；两端余弦与单步灵敏度不受这个影响；
- 中心是随机的，5 套中心只覆盖一部分随机性。
