# 预注册：阶段五 M3b 真实 LLM 对话评测（2026-10-29）

**状态：判据先落盘；实现与运行在 Ollama 可用后。** 本文件在跑真 LLM 之前确定判据，
结果不得回改判据。

## 要检验什么

阶段五成功标准里的四条：

1. SNN 在 **≤ 10 轮对话**内产生首次自主触发的 LLM 调用；
2. 调用触发准确率（该调用时调用、不该调用时不调用）**≥ 70%**；
3. LLM 返回结果的**巩固成功率 ≥ 80%**；
4. 端到端任务完成率相比**纯 SNN 基线**提升 **≥ 50%**。

与 M3a 的区别：**M3a 用 MockLLM，1.000 是平凡结果**；M3b 必须接真实模型
（本机 Ollama，`qwen3:4b`，temperature=0），并且答案对不对由**预先定好的关键短语**判定，
不由模型自评。

## 会话与判定

- 20 个会话，每个 ≤ 10 轮；每个会话含 2–4 个 `knowledge` 轮、2–3 个 `chat` 轮、
  2–3 个 `memory` 轮（问上一轮刚巩固的事实）；
- `knowledge` 轮给**关键短语**（如 capital of France → `paris`），模型回答小写化后包含
  该短语即判完成；
- `chat` / `memory` 轮不应触发 LLM；触发即记一次误触发；
- 纯 SNN 基线：同一会话、同一核心，不调用 LLM，只用记忆检索回答；检索不到就答
  `i don't know`，该轮判未完成；
- **两个臂都预置同一批已记住的知识**（每 3 条知识里的第 1 条，约 1/3）：没有这一步，
  基线在 knowledge 轮上结构性全错、提升比恒为无穷大，判据没有意义。基线为 0 时提升比
  记「未通过」，不写成无穷大；
- **巩固成功**：LLM 回答写入记忆后，下一轮 `memory` 问句能按 id 取回**逐字相同**的回答；
  取回失败或改写即失败；
- 触发准确率 = 正确决策轮数 / 总轮数。

## 判据（全部满足才 `m3b_ready=true`）

| 判据 | 阈值 |
| :--- | :--- |
| 首次自主触发轮次（有 knowledge 轮的会话） | ≤ 10 |
| 触发准确率 | ≥ 0.70 |
| 巩固成功率 | ≥ 0.80 |
| LLM 完成率 / 纯 SNN 完成率 | ≥ 1.5（即 +50%） |

任一条不过 → `m3b_ready=false`，负结果保留。

## 环境与边界

- 只用本机 Ollama（`127.0.0.1:11434`），**不走外网**；请求必须绕过系统代理
  （`trust_env=False` / `--noproxy`，本机代理会把 loopback 送进代理）；
- 模型不在或服务未起时**不跑**，在 README 写「未运行」，不得用 Mock 结果填充；
- 20 个会话是关键短语判定的合成集，不外推到开放域对话；
- 单次运行、temperature=0，不报最好值；若模型非确定，记录重复运行的差异。
