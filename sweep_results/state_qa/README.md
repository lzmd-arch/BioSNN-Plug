# 状态进权重：FiLM 通道**有效，但只有文字通道的 62%**

**日期**：2026-11-16
**脚本**：`scripts/state_qa.py`　**机制**：`research/sel/lm/fusion_model.py`
**判据**：答案必须与**随机生成的状态**一致（读者模型 / 记忆条数 / 在线与否 / 轮次，每条都变）

---

## 一、结果（三轮）

| 臂 | r8/400步 | r32/2000步 | r32/3000步 | **r32/2500步 + 文字 dropout** |
| :--- | ---: | ---: | ---: | ---: |
| `none`（状态不进） | 0.025 | 0.000 | 0.020 | **0.000** |
| `text`（状态块，零样本） | 0.675 | 0.667 | 0.690 | **0.740** |
| **`film`（12 维 p → 每层调制）** | 0.125 | 0.417 | 0.480 | **0.500** |
| **`both`（文字 + p）** | 0.65 | 0.383 | 0.370 | **1.000** |

**决定性的一行是最后一行**：训练时把状态块**随机放/不放**之后，`both` 从 0.37 跳到
**1.00（100/100）**。此前它比 `film` 单独还差，原因是训练时从没见过文字——
推理突然加上，对调制器是分布外输入。

### 三条通道的关系

| 通道 | 单独 | 含义 |
| :--- | ---: | :--- |
| 文字（零样本） | 0.740 | 提示词能把状态带进去 |
| **权重（FiLM）** | 0.500 | **不靠提示词，状态也能进去** |
| **两者一起** | **1.000** | **互补，不是互斥** |

⇒ **这是本次会话里第一个"权重级条件化"的完整正结果**：状态既能从权重进，
又能与提示词叠加到满分。此前加性偏置两次为零、自适应 τ 赢 log p 输 ECE。

## 二、三条读数

1. **状态确实能通过权重进去**：`film` **0.417** 对 `none` **0.000**。
   这是本次会话里**第一个明确为正的权重级条件化结果**——之前加性偏置两次为零、
   自适应 τ 只在 log p 上赢却输在 ECE。
2. **单靠权重只有文字通道的 68%**（0.50 / 0.74）。文字给的是几十个 token 的完整句子，
   `p` 只有 12 维、且调制器**低秩无偏置**（为了保住 `p=0` 逐位不变）。
3. **`both` 的 0.37 → 1.00 是这一轮最有信息量的数字**：它证明两条通道不冲突，
   之前更差纯粹是**训练时没见过文字**这一个原因。

## 二·五、把 `p` 换成**真的 SNN 池输出**：`both` 仍然是 1.00

`p` 原来是我手写的 12 维（直接编码读者模型/条数/在线/轮次）。换成脉冲网络算的：

```
状态 ──► 4 个独立池（presence / time / persona / memory，各 16 神经元，设计编码）
      ──► 池内特征（2 个时间尺度）───► 固定投影 12 维 = p
```

| 臂 | 手写 p | **SNN 池 p** |
| :--- | ---: | ---: |
| `none` | 0.00 | 0.01 |
| `text`（零样本） | 0.74 | 0.74 |
| `film` | 0.50 | **0.44** |
| **`both`** | **1.00** | **1.00** |

⇒ **整条链通了**：状态 → 传感器 → 脉冲池 → `p` → FiLM → 语言模型，
且与"手写 p"同一水平（`film` 略低 6pp、`both` 持平）。

### 逐字段的位移检查（这一步抓到一个真 bug）

| 只改 | p 位移 |
| :--- | ---: |
| 记忆条数 | 0.076 |
| 在线与否 | 0.085 |
| 读者模型 | 0.088 |
| 对话轮次 | **0.091** |

四个量级相当 ⇒ 没有哪个被淹没。**但第一版 `time` 池喂的是常数 1.0（旧写法残留），
轮次完全没被编码——只改 turns 时位移精确为 0.0000。** 没有这个逐字段检查，
会以为"轮次编码了"，其实没有。

## 三、泛化是当前的瓶颈，不是容量

训练 loss 掉到 0.11 但留出只有 0.417 ⇒ **记住了训练状态，没学会推新状态**。

状态是**组合式**的（4 种读者模型 × 记忆条数 × 在线 × 轮次），6,000 条样本远没覆盖。
下一步优先**加状态组合的覆盖**，而不是继续加步数或加 rank：
rank 8→32 带来的是 0.125→0.417，但那同时伴随 5 倍步数与 2 倍数据，**归因还没拆开**。

## 四、边界

- 只用了一个底座（Qwen2.5-0.5B-Instruct），没有第二个底座复验；
- `text` 臂是**零样本**，`film` 臂训练了 2000 步——**两者不对称**，严格比较需要让 `text` 臂也训；
- 评测 60 条，标准误约 6pp ⇒ 0.417 与 0.667 的差距（25pp）是实的，但不该再细分。

## 六、打包后的演示：**同一个问题，两种状态，两个答案**

在**分发包里、CPU 上**跑 `demo_state.py`：

```
问：你现在用哪个模型做嘴巴？

状态 {"mem": 12,  "online": true,  "bb": 0(Qwen3-4B), "turns": 3}
  → 我现在用「Qwen3-4B」做嘴巴。

状态 {"mem": 420, "online": false, "bb": 1(DeepSeek), "turns": 27}
  → 我现在用「DeepSeek」做嘴巴。

对照（不给状态）
  → 我的嘴巴现在是这个终端接上的那个模型；但记忆和人格是我自己的，不在它里面。
```

**与"加状态之前"的直接对照**（同一台机器、同一个包，早先实测）：

| | 加状态之前 | 现在 |
| :--- | :--- | :--- |
| 问同一句、状态不同 | **逐字相同** | **两个不同的答案** |
| 不给状态 | 报身份句 | 给通用回答（训练里学到的） |

### 代价与边界

- 三个答案都来自**同一个权重文件**：调制器只有 **20.5k 参数**（主干冻结），
  所以"状态改变行为"这件事不需要复制模型；
- **`p` 的来源必须与训练一致**：打包版用**手写 12 维**（`modulator_v4_hand.pt`，film 0.47）；
  研究版用**脉冲池派生的 p**（`modulator_v4.pt`，film 0.41）。**混用会失败**——
  这不是两套模型，是同一个机制的两个状态来源；
- 演示在 CPU 上跑通，说明这条链**不依赖 GPU**。
