# 预注册修正 1：W3 D10——判据 A 的阈值不可达，改为对随机方向标定（2026-10-29）

**对 [`rstdp_spiking_direction_prereg.md`](rstdp_spiking_direction_prereg.md) 的修正。**
原判据的**其余部分全部不变**；数据整体重跑（修正前那一轮只跑完 seed 0，作废）。

## 为什么改（先测后改，测的是口径不是结果）

原判据 A 写的是「`r(s)` 的极差 ≥ **0.05**（相对差驱动在整段极角上变化 ≥5%）」。
正式运行开始后、5 个种子里只有 seed 0 打出第一行时发现：`A_spread` 打印为 `0.000`。
于是先做**与训练无关的口径标定**（随机初始化权重、同一编码器、同一 21 点网格）：

| 标定量 | 实测 |
| :--- | ---: |
| 随机初始化权重下 21 点 `r` 的极差 | **0.0028** |
| 同一网格上编码特征的最大逐维变化（θ 从 −0.2 到 0.2） | **0.035** |

也就是说：在这个冻结编码器上，θ 整段变化只让特征向量动 0.035，`r(s)` 的量级因此是
**10⁻³**。`0.05` 不是「严格」，而是**先验不可达**——任何方向（随机或训练）都过不了，
判据把「训练方向是否特殊」与「编码器对 θ 有多敏感」混成了一件。

**这一步没看任何训练结果**（seed 0 只打出了 `A 0.000` 一行，C/B 都还没比）。

## 修正后的判据 A

`r(s)`、状态集、窗口数、其余判据（B、C）**一字不变**；只把 A 换成**对随机方向标定**的量：

```
A_norm = A_spread / median(同范数随机方向的 r 极差，5 个)
A 成立 ⇔ A_norm ≥ 2.0
```

- 随机方向就是原预注册里的量 (D)，现在从「不作判据」升为 **A 的分母对照**；
- 原阈值 `A_spread ≥ 0.05` **照常逐种子记录并并列报告**，但不参与判定；
- 判定表其余分支不变（A 不成立 → `no_differential_direction` 或 `other_unattributed`；
  A 成立 + C 不成立 → `lif_saturated`；A 成立 + C 成立 → `amplitude_too_small`）。

## 为什么这样改是对的口径

「训练出来的差方向，是否比随便一个同范数方向**更随状态变**」才是要问的问题；分母用了
同一次运行里测的随机方向，就没有跨实验的尺度假设，也不会因为编码器敏感度低而恒判负。

## 不做什么

- 不因为 A 换了口径就去改 C 的 `0.5` 计数阈值或 B 的 `1.0`（它们是计数单位，与编码器
  敏感度无关）；
- 不把「A_norm 大」写成「读出有状态依赖」——它只说差方向**在这个编码器上对状态敏不敏感**；
- 不用修正前那一轮的任何数字。
