## 与 v14 / v16 的关系

| 版本 | 门 | 级别 | 结果 |
| :--- | :--- | :--- | :--- |
| v14 | K4 shrunk / K8 diag | 状态级 | **14/18**（K4-s2 σ.1/.3 过，σ.5 与 K8-s2 三档失败） |
| v16 | `input_norm` | **输入级** | **18/18** |
| v17 | kNN[errors, state_norm] | 状态级 | **12/18**（s=2 六格全失败） |

v17 没有补上 s=2，反而比 v14 少两格（K4-s2 σ.1/.3 也掉了）。这说明
`errors + state_norm` 在 e2e 的 s=2 上分离不足：重建误差主要随尺度整体上升，而 s=2 的
偏移量小，和 in-dist 的噪声重叠；v16 的 `input_norm` 直接看输入尺度，所以在 s=2 上更稳。
**状态级门仍未解决 s=2**；v16 的 18/18 仍是输入级，不能混报。

## 边界

- 只测 A/B 尺度 OOD；不测量化/信息丢失型 OOD。
- 失败项只有弃权，AUROC 在 s=2 仍 0.759–0.841；排序可用，固定 80% 覆盖下的阈值重叠
  是问题。
- 没有调 k/特征/覆盖率；v14/v16 原样保留。

## 结论

状态级元认知的 s=2 边界**没有被 v17 关闭**；v14 的 14/18 仍是状态级最好结果。若继续，
需要与尺度无关、但在小尺度偏移上仍敏感的**状态级**特征（例如误差的分布形状/残差
协方差），而不是再把 `errors` 和 `state_norm` 拼在一起；这是新的预注册，不是本轮调参。
