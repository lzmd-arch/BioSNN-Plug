# R4：多时间尺度读出——**+4.88pp，"读出维度"本身是杠杆**（2026-11-08）

**预注册**：[`research/sel/prereg-lm-r4-multiscale-readout.md`](../../research/sel/prereg-lm-r4-multiscale-readout.md)
**跨实验附录**：[`research/sel/prereg-lm-r4-amend1.md`](../../research/sel/prereg-lm-r4-amend1.md)（R3 的宽度标定，写在出数前）
**原始数据**：[`r4.json`](r4.json)

## 一句话

把读出从**单个 EMA（每个神经元 1 个数，1,024 维）**换成**四个时间尺度（每个神经元 4 个数，4,096 维）**，
Δ 从基线的 **−6.16pp** 变成 **−1.28pp**，**改善 +4.88pp**——R4-1（门槛 +3pp）**过**。

代价：读出参数 **0.82M → 3.28M（4×）**，整机 1.64M → 4.1M。**这不是免费的改进。**

## 结果

| 臂 | 读出维度 | 读出参数 | 折 0 | 折 1 | 均值 top-1 | 均值 Δ | 赢 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 基线 R2-A | 1,024 | 0.82M | 0.2205 | 0.2200 | 0.2203 | **−6.16pp** | 0/2 |
| **R4（4 个 τ）** | **4,096** | **3.28M** | **0.2697** | **0.2685** | **0.2691** | **−1.28pp** | 0/2 |

**逐折改善**：折 0 **+4.92pp**、折 1 **+4.85pp**（基线同折 Δ 是 −6.23 / −6.10pp）。

**CE 也一起追上了**：

| | 折 0 CE | 折 1 CE | bigram CE |
| :--- | ---: | ---: | ---: |
| R2-A | 4.1835 | 4.2016 | 3.8341 / 3.8530 |

**R4 的 CE 已经贴到 bigram 上**（折 0 甚至略低 0.005 nats），top-1 仍差 1.3pp。

## 三件必须一起说的事

### 1. 与 R3 的宽度标定对照：两个 4× 买到同一个量级的提升

| 加宽方式 | 宽度 | 提升 |
| :--- | ---: | ---: |
| **R3**：加神经元（256 → 1,024） | 4× | **+3.98pp** |
| **R4**：加时间尺度（1,024 → 4,096） | 4× | **+4.88pp** |

**同样的 4 倍宽度，跨机制拿到同一量级**——按附录预先写死的判读，这属于
"**读出维度是杠杆、来源不限**：时间尺度买来的宽度和神经元买来的一样能用"。

### 2. 又一次 CE 与 top-1 脱钩，但方向与 R0b / B0 都不同

- **R0b**：CE 升、top-1 平（过拟合）；
- **B0（GRU）**：top-1 好、CE 极差（自信地错）；
- **R4**：**CE 追平 bigram，top-1 仍差 1.3pp**——分布校准对了，但 argmax 的排序还差一口气。

这条差异很重要：R4 **不是靠变自信**拿到的 top-1（CE 同步下降 0.35 nats），
这与 R3 的"缩读出 → CE 也只到 4.43"形成对照。

### 3. 规则③ v2：CE 平台勉强到，top-1 未平台 ⇒ 仍是下界

折 0 的 CE 最后 5 个区间相对下降 0.62 / 0.61 / 0.32 / 0.33 / 0.06%——**刚好凑满 k=5**；
折 1 的 top-1 最后 5 个区间累计 **+1.25pp**（> 0.5pp 门槛），折 0 **+0.67pp**（也 > 0.5pp）。

⇒ **两折都是"CE 平台、top-1 未平台"，−1.28pp 是 120 epoch 下的下界。**

## 执行与 provenance

- 两折都是**同一份代码、同一份 JSON**（`config` 里 `readout_taus: [2,8,32,128]`、`readout_dims: 4096`）；
- 归一化在开跑前修正过一次（`sqrt(1−d²)`，见预注册里的修正记录），**判据未动**；
- 训练中无早停，固定 18,750 updates。

## 边界

- 两折、单种子；合成语料 `H_r2_3k`（**不是真语料**，真语料上的多尺度读出**未测**）；
- 读出参数 4×，**"性价比"是否可接受取决于部署约束**（4.1M vs 1.64M 参数）；
- 四个 τ（2/8/32/128）是一个选择，**没扫**；换 τ 组合结论可能略变；
- 字符级 next-token，**不代表能闲聊**。

## 对路线的影响

1. **"读出是瓶颈"从 A 线延伸到 LM 线**：A3/A5/A7 在 sMNIST/SHD 上找到的机制（"每个神经元给几个数"），
   在字符级 LM 上以同样的量级复现。这是本项目最硬的一条跨线机制结论。
2. **B0 的 9.29pp 规则缺口里，R4 填掉约一半**（+4.88pp）——但注意语料不同（R4 合成、B0 真语料），
   这个"一半"只能当量级。
3. **下一步最有信息量的一臂：把 R4 的读出搬到真语料**（同大折、8,000 步），成本约 1.5–2 小时。
   若真语料上也拿到 +3～5pp，则"规则缺口"里能归给读出的部分就确定了，剩下的是信用分配本身。
