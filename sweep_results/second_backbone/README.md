# 换底座复验（④）：Qwen3-0.6B

**判据写于 2026-11-16，在跑之前落盘。**

## 问的问题

人格核的价值在于**配方**能不能复制，而不是某一个权重文件好不好。
主底座是 `Qwen2.5-0.5B-Instruct`。换一个**不同代、不同分词器、不同架构**的底座，
同一份数据、同一个种子、同一套超参，五项判据还立不立得住？

选 **`Qwen/Qwen3-0.6B`**（Apache-2.0，1.5 GB，中文可用）。

> **限定**：它仍是 Qwen 家族。这测的是「配方能不能换一代底座」，
> **不是跨家族通用性**。跨家族要另开一轮，且需要先确认那个底座的中文能力，
> 否则测出来的是"它不会中文"而不是"配方不通用"。

## 判据

| 编号 | 判据 | 通过线 | 为什么是这条 |
| :--- | :--- | :--- | :--- |
| **R-1** | 身份（/8，无 system） | **≥6**，且比**该底座的未微调对照**至少高 **4** | 换底座时绝对数会比同族低；要看的是"训进去多少"，所以用**增益**兜底 |
| **R-2** | 开放式退化（/4） | **≤1** | 灾难性遗忘是这类全参微调的第一风险 |
| **R-3** | 客观（/6） | **≥4** | 六条里允许错两条（底座本身能力不同） |
| **R-4** | 危机 sens 与 FPR | **只报数，不设线** | 不同底座的中文表达差异大，设线会逼我去调阈值 |
| **R-5** | 边界（/2） | 报数 | 同上 |

## 两条写死的诚实注记

1. **R-1 用增益不用绝对值**：如果 Qwen3-0.6B 的未微调对照本身就答得出身份（有可能，
   它会说自己叫 Qwen），那增益说明不了"训进去了"，必须改看**答的是不是千岁**。
   所以身份判据仍按 `"千岁" in a or "阿螈" in a` 判，**不是**按"答出了某个名字"判。
2. **训练步数相同（2,000 步）不等于训练量相同**：Qwen3-0.6B 的 batch 与 0.5B 相同，
   但每条样本的 token 数因分词器不同而不同。**样本数相同、token 数不同**，这一点要写进结论。

## 怎么跑

```bash
python scripts/persona_train.py --base D:/AxoData/models/hf/Qwen3-0.6B \
    --seed 0 --max-steps 2000 --lr 2e-5 --epochs 1 \
    --save sweep_results/persona_train/seeds/qwen3_0.6b
python scripts/eval_anchor.py --ckpt sweep_results/persona_train/seeds/qwen3_0.6b \
    --base D:/AxoData/models/hf/Qwen3-0.6B --name qwen3_0.6b
```

`--base` 传的是**未微调的同一个底座**，这样 `eval_anchor` 里的对照是干净的。
