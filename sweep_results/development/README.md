# 发育 v3：耦合强度是**真的旋钮**，但它买不来能力

**一句话**：`Jaccard(gγ, g0)` 随 γ **单调下降**（0.895 → 0.837 → 0.763，3 个种子各自都很紧），
⇒ **`E` 对结构的塑造是真实的、可调的**，v2 那个边缘通过的 D-2 不是噪声。
但准确率在所有 γ 上基本不动（0.233–0.248，极差 1.5pp）。

## 一、结果（3 种子、n=2048、D0=32 → D1=8）

| 臂 | `γ` | 发放 | 准确率 | 逐种子 |
| :--- | ---: | ---: | ---: | :--- |
| `g0` | 0（不带能量） | 0.0966 | 0.242 | .252 / .224 / .250 |
| **`g1`** | 1 | 0.1017 | **0.248** | .260 / .239 / .246 |
| `g2` | 2 | 0.0958 | 0.233 | .224 / .227 / .250 |
| `g4` | 4 | 0.0970 | 0.237 | .243 / .217 / .252 |

结构相似度（同种子配对，与 `g0` 比）：

| `γ` | 逐种子 Jaccard | 最大 |
| ---: | :--- | ---: |
| 1 | 0.892 / 0.892 / 0.895 | 0.895 |
| 2 | 0.825 / 0.837 / 0.832 | 0.837 |
| 4 | 0.731 / 0.763 / 0.742 | 0.763 |

## 二、判

| 编号 | 结果 |
| :--- | :--- |
| **C-0** 天花板 / 每臂 > 底板 / 工作点 | ✅ 过（本轮有效） |
| **C-1 剂量–反应** | ✅ **过**：0.895 → 0.837 → 0.763 **严格单调** |
| **C-2 能力** | ❌ 不过：最好 `g1` **+0.7pp**（要 ≥3pp） |
| **C-3 渠化** | ❌ 不过：结构 Jaccard **0.002**（结构完全不同 ✓），但 acc 极差 **2.2pp**（要 <2pp） |

## 三、三条可以说的话

1. **`E` 塑造结构是真的，而且可控。**
   γ 从 1 到 4，与参照臂的结构重叠从 89.5% 降到 76.3%，**三个种子在每个 γ 上都只差 0.03**。
   这是本轮最结实的一条 —— 它同时**追认了 v2 那个边缘通过的 D-2**
   （0.895 对 0.9 不是噪声，它只是最弱的一档）。

2. **但它买不来能力。** 四个 γ 的准确率极差只有 **1.5pp**，且非单调
   （0.242 / 0.248 / 0.233 / 0.237）。**更多"能量塑造结构" ≠ 更好。**

3. **渠化仍然不成立**（极差 2.2pp，比 v2 的 3.2pp 好，仍差 0.2pp 没过）。
   结构 Jaccard 0.002 说明**结构几乎完全由种子决定** ——
   这一条对 M7（个体史）有利，对"发育稳健性"不利。

## 四、这一条把 M1→M3 的环画完整了

| 环节 | 证据 | 状态 |
| :--- | :--- | :--- |
| M1 内部量自持 | `E` 的 R²(输入→E) = **−0.016** | ✅ |
| M2 内部量约束行为 | corr(E, 发放) = **−0.990** | ✅ |
| M3 内部量塑造结构 | γ 单调控制结构差异（0.895→0.763） | ✅ |
| **结构 → 能力** | 四个 γ 的准确率极差 1.5pp | ❌ **没有** |

⇒ **"内部量 → 结构"这条因果链是通的、可控的；"结构 → 能力"这一段不通。**
下一步该攻的是第二段，不是继续拧 γ。

## 五、下一步

1. **攻"结构 → 能力"**：现在修剪只决定"谁留下"，不决定"留下的多强"。
   下一轮让**稳态缩放的目标发放率也由 `E` 决定**（能量低 ⇒ 目标活动低），
   那是 M2 的"策略改变"，也可能是唯一能让结构差异变成能力差异的通道；
2. **渠化还差 0.2pp**：极差 2.2pp 已经比 v2 的 3.2pp 好，值得在更大的种子上复核；
3. **不要**继续加大 γ —— 它只让结构更不同，不让能力更好。
