# 发育（D-0…D-3）：**按预注册作废**，但得到一个干净的负结果

**一句话**：`acid` 0.233 < 底板 0.125 + 0.15 = **0.275**，D-0 不过 ⇒ 本轮作废。
不过四条臂是在**同一台仪器、同一个任务**上量的，所以那个对照本身仍然有信息：
**活动依赖的修剪不比随机修剪好**（−0.2pp，1/3 种子）。

## 一、结果（3 种子、n=2048、D0=32 → D1=8）

| 臂 | 发放 | 准确率 | 逐种子 | 结构两两 Jaccard |
| :--- | ---: | ---: | :--- | ---: |
| `acid`（活动驱动） | 0.0964 | 0.233 | .243 / .208 / .247 | **0.002** |
| `rand`（随机修剪） | 0.0998 | 0.234 | .234 / .223 / .246 | **0.002** |
| `acid_nometab` | 0.0969 | **0.251** | .251 / .238 / .265 | 0.002 |
| `noprune`（不修剪，D=32） | 0.0953 | 0.237 | .243 / .216 / .253 | 0.007 |

底板（多数类）**0.125**。

## 三、四个可以说的话

1. **活动依赖的修剪没有做功。** 0.233 vs 0.234，逐种子 1/3 为正。
   在这个设定下，"按共活动修剪"与"随机剪掉 3/4"没有区别。
2. **但"过度生长 + 修剪"这条主线成立**：`noprune`（32 入度）0.237 对
   `acid`（8 入度）0.233 —— **去掉 75% 的突触，能力不掉**。
   所以结构可以压缩，只是**压缩的依据不是活动**。
3. **结构完全由种子决定**：三个种子的存活突触集合两两 **Jaccard = 0.002**
   （几乎不相交）。这一条对 M7（个体史）是**有利**的：个体的结构确实是不同的。
   但它同时说明"结构各不相同"**不等于**"发育在做有用的事"。
4. **发育期开代谢略差**：`acid_nometab` 比 `acid` 高 **1.9pp，3/3 种子为正**。
   ⇒ `E` 确实影响了发育轨迹（方向是负的）。D-3 的结构比对没跑到，下一轮补。

## 四、D-0 这条线是怎么来的，以及它错在哪

0.275 是从 `bio_all` / `spatial_dim` 的 "底板 + 15pp" 抄过来的。
但 `bio_all` 里能过这条线的是**五个机制全开**（0.359），裸 LIF 蓄水池本来就只有 0.229。

⇒ 这条线把"**网络不够强**"和"**仪器坏了**"混在了一起 ——
和我在 `dim_ladder` 里写错又改回的 D-0 是同一个错误。

**本轮不改它**（那是改已发布的判据）。下一轮写**新的预注册**，把 D-0 换成
"**对照臂必须显著高于底板**"，而不是一个所有裸网都过不去的绝对线。

## 五、下一步

1. 新预注册：D-0 改成"高于底板 + 与随机构造有差异"，D-2 保留；
2. **把 `E` 的作用换到正确的层级**：这一轮 `E` 只影响阈值（放电率），
   而修剪看的是共活动痕迹。要让 `E` 塑造结构，应该让**能量直接进入痕迹**
   （例如 `s ← λs + |pre·post|·E`）—— 那是下一轮的自变量；
3. **D-3 补跑**：`acid` vs `acid_nometab` 的结构 Jaccard 这一轮没算出来。
