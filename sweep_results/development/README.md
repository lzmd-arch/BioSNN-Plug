# 发育 v4：代谢史决定稳态设定点 —— **策略改变成立，能力不变**

**一句话**：让设定点 `target = rate_before · Ē^η` 后，稳态发放率随 η **单调下降**
（0.1017 → 0.0876 → 0.0847），而准确率**不动**（0.248 / 0.251 / 0.253）。
⇒ **系统可以在低 17% 的脉冲下拿到同样的能力**。

## 一、结果（3 种子、n=2048、γ 固定为 1）

| 臂 | `η` | 设定点 | **发放** | **准确率** | 逐种子 | 每脉冲能力 |
| :--- | ---: | :--- | ---: | ---: | :--- | ---: |
| `eta0` | 0 | 常数（= 修剪前） | 0.1017 | 0.248 | .260 / .239 / .246 | 1.21 |
| `eta1` | 1 | ∝ Ē | 0.0876 | 0.251 | .261 / .237 / .257 | 1.41 |
| `eta2` | 2 | ∝ Ē² | **0.0847** | **0.253** | .261 / .241 / .257 | **1.51** |

底板 0.125，窗口天花板 0.367。

## 二、判

| 编号 | 结果 |
| :--- | :--- |
| **E-0** | ✅ 过（本轮有效） |
| **E-1 策略改变** | ✅ **过**：发放 **0.1017 → 0.0876 → 0.0847** 随 η 单调下降 |
| **E-2 能力** | ❌ 不过：最好 `eta2` **+0.5pp**（要 ≥3pp） |
| **E-3 每脉冲能力** | ✅ 过：1.21 → **1.51 = 1.25×**（要 ≥1.15） |

## 三、⚠️ E-3 不是独立证据，必须说清楚

**E-3 是 E-1 + E-2 的算术推论**：发放降 17%、准确率不动，
那么 `(acc − 底板)/发放` 必然升约 20%。它通过了预注册的线，但
**它没有提供任何 E-1/E-2 之外的信息**。

真正可以说的是下面这句，而它比 E-3 更有意义：

> **能力对活动水平在 [0.085, 0.102] 这个区间内不敏感** ——
> 也就是说，这里**约 17% 的脉冲是冗余的**，代谢可以把设定点压低而不损失能力。

这不是"代谢让系统更聪明"，是"**系统的能力对活动水平有 17% 的余量**"。
两者都成立，但不能混为一谈。

## 四、这一轮真正推进了什么

1. **`E` 现在能改变的不是"谁留下"，而是"活多高"。**
   v3 的 `E` 只影响结构（0.895→0.763），能力不动；
   v4 的 `E` 直接影响**活动设定点**（−17%），能力**仍然不动**。
   ⇒ 两段都通了机制，但**都没有接到能力上**。

2. **"结构 → 能力"这一段仍然不通。** E-2 不过，且 v3 的四个 γ 也是平的。
   现在的证据指向：**在这个任务 + 这个 MLP 读出下，网络的细结构对能力不敏感**。
   这与 `dim_ladder` 的结果一致（1D vs 2D 差 9pp，但 2D/3D/4D 之间只差 4pp）。

3. **但"活动水平 → 能力"也基本不敏感**（17% 的余量）。
   ⇒ 该任务对我们的两个自变量都不敏感，这是**任务的限制**，不是机制的失败。

## 四之二、⚠️ 幅度对不上，E-1 要打折看

设定的目标（发育流上）：

| 臂 | `Ē` | `target = rate_before·Ē^η` |
| :--- | ---: | ---: |
| `eta0` | 0.9765 | 0.0660 |
| `eta1` | 0.9765 | 0.0645 |
| `eta2` | 0.9765 | 0.0630 |

**目标只差 4.5%，而评测流上的实测发放差了 17%。**

两点后果：

1. **`Ē` 几乎没有方差**（0.9765，三个臂相同 —— 因为 `Ē` 取自发育期，
   而三个臂的发育过程完全一样，`η` 是在发育**之后**才施加的）。
   所以"代谢史决定设定点"这句话，实际上只用了 `Ē` 的 **2.4% 的变化**。
2. **观察到的效应是设定幅度的 3.6 倍**，说明"设定点 → 实测发放"这条链
   在评测流上被放大了（放电率对驱动是非线性的，接近分岔点时更陡）。
   ⇒ **幅度不可控，只有方向可信。**

再加一条：`firing` 是三个种子的**均值**，E-1 判的是均值单调，
**没有报逐种子的发放率** —— 下一轮要补。

⇒ E-1 的正确说法是：「**把设定点按 `Ē` 调低，发放率单调下降**」，
而不是「代谢史按比例决定设定点」。后者需要先让 `Ē` 真正变化。

## 五、限定

- 三个种子、一个任务（K=8 隐状态解码）、一个读出（MLP）；
- `Ē` 是发育期的标量平均，逐神经元能量没有被用上；
- E-3 通过但它是派生量，**不单独构成证据**。

## 六、下一步

1. **换一个对活动水平敏感的任务**：17% 的余量说明现在的任务太"宽容"。
   需要的是"低活动就会失败"的任务（例如更短的积分窗、更强的噪声）；
2. 或者**换一个能看见结构的量**：现在只有分类准确率。可以考虑
   **时序记忆深度**（能记住多少步之前的信息）—— 结构应该直接影响它；
3. **不要**继续在现在的任务上拧 η —— 它已经证明了这个任务对活动不敏感。
