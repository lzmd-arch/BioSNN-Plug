# 发育 v2：能量进痕迹 —— **`E` 确实塑造结构**，但幅度小、没换来能力

**一句话**：把后突触能量放进共活动痕迹后，3 个种子的存活结构**稳定地差出约 10%**
（逐种子 Jaccard 0.892 / 0.892 / 0.895），判定线 <0.9 **边缘通过**。
但准确率只高 **+1.0pp**（3/3 种子、要 ≥3pp），渠化也不成立（极差 3.2pp）。

## 一、v1 为什么失败（复盘）

v1 里 `E` **只改阈值**（放电率），而修剪看的是**共活动痕迹** —— 两条通路不相交，
所以 `E` 当然塑造不了结构。v1 的 D-0 还用了"底板 + 15pp = 0.275"，
而裸 LIF 蓄水池本来只有 0.229 ⇒ 把"网络不够强"与"仪器坏了"混在一起。

v2 两处都改：`E` 进痕迹，D-0 换回"任务可解 / 每臂高于底板 / 工作点"。

## 二、结果（3 种子、n=2048、D0=32 → D1=8）

| 臂 | 发放 | 准确率 | 逐种子 |
| :--- | ---: | ---: | :--- |
| **`E_acid`**（`E` 进痕迹） | 0.0962 | **0.244** | .253 / .224 / .255 |
| `E_rand`（随机修剪） | 0.0998 | 0.234 | .234 / .223 / .246 |
| `noE_acid`（痕迹不带 `E`） | 0.0964 | 0.233 | .243 / .208 / .247 |

底板（多数类）**0.125**，窗口天花板 **0.367**。

逐种子差：

| 对比 | 逐种子 | 均值 | 同向 |
| :--- | :--- | ---: | :--- |
| `E_acid − noE_acid` | +.010 / +.016 / +.008 | **+1.1pp** | **3/3** |
| `E_acid − E_rand` | +.019 / +.001 / +.009 | **+1.0pp** | **3/3** |

## 三、判

| 编号 | 结果 |
| :--- | :--- |
| **D0-1** 窗口 0.367 ≥ 0.125+0.20 | ✅ 过 |
| **D0-2** 每臂 > 底板 | ✅ 过 |
| **D0-3** 每臂发放在 [0.03, 0.20] | ✅ 过 |
| **D-1 渠化** | ❌ 结构半边过（Jaccard **0.002**），能力半边不过（极差 **3.2pp** > 2pp） |
| **D-2 `E` 塑造结构** | ✅ **边缘过**：Jaccard **0.892 / 0.892 / 0.895**（线 <0.9） |
| **D-3 能量驱动做功** | ❌ 不过：`E_acid − E_rand` = **+1.0pp**（要 ≥3pp） |

## 四、三条可以说的话

1. **`M1 → M3` 这条环第一次闭上，但是弱的。**
   `E` 稳定改变约 **10%** 的存活突触（三个种子 0.892–0.895，可复现），
   说明"内部量塑造结构"这件事**在机制上成立**，不是伪影。

2. **但它没有换来能力。** +1.0pp 虽然 3/3 同向，却只有门槛的三分之一。
   ⇒ 现在能说的是"能量的确发谁留谁"，不能说"能量让发育更好"。

3. **渠化不成立。** 结构 Jaccard 0.002（几乎完全由种子决定），
   但能力极差 3.2pp。**结构各异 ≠ 能力相同** ——
   这一条对 M7（个体史）仍有利（个体确实不同），但对"发育稳健性"不利。

## 五、限定

- 三个种子、一个任务、一个规模（n=2048、D0=32→D1=8）；
- D-2 只**边缘**通过（0.895 对 0.9），下一轮要在更强的耦合下复验；
- `E` 与结构的关系只测了"后突触能量进痕迹"这一种写法。

## 六、下一步

1. **加强耦合**：现在 `E` 以一次方进痕迹。下一轮把指数、或 `E` 的方差本身当自变量
   （更饥饿 ⇒ 更强的竞争 ⇒ 更大的结构差异）；
2. **让能力跟上**：现在 `E` 只影响"谁留下"，不影响"留下的多强"。下一轮让
   **稳态缩放的目标也由 `E` 决定**（能量低 ⇒ 目标发放率低），这是 M2 的"策略改变"；
3. **补 D-1 的能力半边**：极差 3.2pp 说明不同结构之间确实有强弱差，
   要找的是"哪种结构更强" —— 那正好是 M3 下一步该回答的。
