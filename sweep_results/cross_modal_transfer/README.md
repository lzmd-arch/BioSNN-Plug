# 阶段四跨模态迁移报告：CKA / 线性探测 / 双向迁移（2026-10-29）

**性质：可测量指标报告，不是验收。** 程序化配对集（144 条，属性生成），确定性
`HashEmbedding`（64 维，不联网），bus@128；5 个切分种子。脚本
`scripts/cross_modal_transfer.py`。

## 结果（5 种子均值）

| 指标 | 值 | 读法 |
| :--- | ---: | :--- |
| CKA（text bus vs image bus） | **0.418** | 两路表示有中等线性相似，不是同一空间 |
| 文本线性探测（四属性平均） | **1.000** | 饱和，**平凡**：caption 直接写出属性 |
| 图像线性探测 | **0.736** | 图像侧确实带属性信息 |
| 文本→图像迁移 | **0.902** | 映射后仍保留大部分属性 |
| 图像→文本迁移 | **0.736** | 与图像探测相同（映射不增加信息） |

## 读法

- 文本探测 1.000 是**平凡解**：caption 里逐字写出 shape/shade/position/size；不能当
  “文本表示好”的证据；
- 图像探测 0.736 是这套 24×24 DVS 编码的实际水平；与检索线的同模态 R@1 0.759–0.931
  同量级；
- 文本→图像迁移 0.902、图像→文本 0.736：迁移方向不对称，文本侧信息更完整；CKA 0.418
  说明两路不是同一线性空间；
- 这是**合成属性集**，不能外推到 Flickr8k/真实图像-文本；Flickr8k 的前端边界仍是
  R@1 0.076（冻结 ResNet18 + nomic）。

## 边界

- 没有训练任何插件；HashEmbedding 是测量替身；
- 没有“迁移提升任务性能”的结论，只报告可测量指标；
- 阶段四的跨模态迁移报告要求因此**有数据**，但不等于“迁移能力过线”。
