# 脉冲 SoS 的 E6：20 个种子下，H1' **检测不到**（2026-11-03）

**预注册：** [`research/sos/prereg-e6.md`](../../research/sos/prereg-e6.md)（写死"只估效应量、不判通过"）

## 判决

| 臂 | 训练池 | confirm | 平均步数 |
| :--- | ---: | ---: | ---: |
| opt | 0.750 | **0.470** | 25.7 |
| search | 0.610 | **0.463** | 30.0 |

**主报告（按种子配对，n=20）：**

> `search − opt` 的 confirm 成功率差 **中位 −0.015**，**95% 自助区间 [−0.045, +0.015]**。

区间跨 0，而且**点估计的符号翻了**——E5 的 +0.03 是噪声。

按预注册的解释规则，结论是：**在这个分辨率下检测不到 `D_search` 与 `D_opt` 的差别。**

## E5 的 +0.03 是怎么来的

E5 用 5 个种子、100 个 confirm 迷宫，拿到 +0.03；当时逐种子的极差（0.30–0.51）就已经
大于中位差。这一轮把种子加到 20、confirm 迷宫加到 200，效应量变成 **−0.015**。

**这是一次"小样本上看着有方向，放大后没有"的标准案例。** 预注册里写的
「我倾向区间跨 0」应验了——但那是写下来的判断，不是事后解释。

## 对 SoS 主线意味着什么

H1' 是 SoS 的核心主张（过程优于结果）在**我们的任务上**的检验，三次尝试：

| 版本 | 结果 |
| :--- | :--- |
| E3 | 两臂都没学会（状态里没有墙），不可测 |
| E5 | +0.03，未到 0.05 门槛 |
| **E6** | **−0.015 [−0.045, +0.015]，检测不到** |

**所以：在本仓库的迷宫任务 + 表格策略 + 交叉熵监督这个设置下，`D_search` 与 `D_opt`
没有可测的差别。**

这不等于"SoS 在任何设置下都错"——原文用的是 transformer + 大规模轨迹 + 微调。
但它等于：**我们不能用现在这套设置支持 ADR-0030 的立论基础。**

## 已经站得住的东西（与 H1' 无关）

- **E0**：迷宫环境成立（难度跨度 23 档）。
- **E1**：世界模型的不确定度可用（p1_ready：ρ 0.842、覆盖 5/5）。
- **E3→E5 的状态三连**：0.140 → 0.390 → 0.740，证明**状态表示**是这条线的真正瓶颈，
  而不是学习信号。这条结论独立于 H1'，且对任何后续方案都适用。
