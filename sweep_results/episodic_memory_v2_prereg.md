# 预注册：情景记忆 v2——编码器对照（2026-10-26）

**定稿时间：2026-10-26，在 v2 的任何数据之前。** v0/v1 已把瓶颈定位到**编码**：
top-k 符号投影（D=512, k=32）在 σ=0.1 下丢信息，连非局部伪逆也救不回；字面 NN 全面更好。
v2 不再动读出（固定 one-shot Hebbian + 独立时间戳），只比较四种编码。

## 四个编码臂（数据/读出/噪声/容量/判据全部固定）

| 臂 | 编码 | 说明 |
| :--- | :--- | :--- |
| **E0 sparse（参考）** | D=512, k=32, top-k 符号 | v0/v1 的编码，作参考 |
| **E1 dense-sign** | D=512, 全维符号 | 保留全部投影方向，不丢维 |
| **E2 wide-sparse** | D=2048, k=128, top-k 符号 | 更大维度、更多非零 |
| **E3 dense-cont** | D=512, 连续投影，不 top-k/不符号 | 保留幅度信息 |

- 读出固定：动作/终止 4 维值 + 独立时间标量；one-shot（v1 的吸引子在 N≫D 下更差，不再试）；
- 伪逆（上限）与字面最近邻（基线）单列，**不参与 ready 判定**；
- 所有编码器用同一个固定 `R` 的种子族（各臂独立 seed）。

## 数据与协议（与 v0/v1 相同）

200 回合事件池、终止事件分层、σ=0.1、N∈{100,300,500,1000,2000}、5 种子；
主指标 N=500，容量 N=1000。

## 判据（与 v0/v1 相同，先写死）

1. 动作 N=500 **≥0.70**；
2. 终止平衡 / TPR N=500 **≥0.70**；
3. 时间顺序 N=500 **≥0.75**；
4. 容量 N=1000 动作 **≥0.65**；
5. **E1/E2/E3 任一**四条全过 → `v2_ready`；E0 只作参考；伪逆/字面 NN 只报上限/基线。

## 不做什么

- 不在看到数据后调 D/k/σ/容量/阈值；
- 不做吸引子/正交化/伪逆作为候选（只作上限）；
- 不换时间通道/不换数据；
- 不把字面 NN 或伪逆的成绩写成联想记忆。
