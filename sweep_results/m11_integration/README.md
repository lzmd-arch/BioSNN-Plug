## 二、两个方向都被推翻

### 2.1 **切断跨半球连接，整合不但没降，反而更高**

四个种子里三个：切断后整合 **0.967 / 0.969 / 0.850**，完整时 **0.736 / 0.162 / 0.345**。

⇒ **两个半球之间的耦合不是靠突触跨连接实现的**，是靠**共享的全局场与起搏图样**。
把它们之间的突触剪掉，它们仍然被同一个标量场推着走 —— 所以相关性反而更整齐
（各自变成"场的奴隶"，不再被对方的噪声扰动）。

### 2.2 **把场调弱，分离塌了**（0.77 → 0.21）

这与我的预测相反。原因和 M6 一致：场弱 ⇒ 活动饱和 ⇒ 所有神经元都顶到上限 ⇒ 空间差异消失。
**分离是场"压"出来的，不是场"压平"的。**

## 三、判决

**M11 不成立。** 两档都不满足"整合更高 且 分离保住"。

而且得出一条对总目标重要的话：**这个系统的"整合"是一个全局标量，不是一个可分割的结构。**
它既不能被切断，也不能在保分离的前提下调弱。
⇒ **GWT 意义上的"整合–分离平衡"在这个动力学族里没有对应物。**

## 四、限定

- 4 种子；整合用两半球平均发放的时间相关，分离用半球内空间变异系数 —— 都是本轮定的口径；
- `g_field=0.25` 时整合恒 ≈1.000（饱和），那一档实际上没有分辨率；
- 切断只切了跨半球的突触目标，没有切场。
