# 预注册：评测流上的任务边界检测 v3——两种统计量并用（2026-11-04）

**状态：判据先落盘。** 修订 v2（[`continual_v3_boundary_detection_v2_prereg.md`](continual_v3_boundary_detection_v2_prereg.md)）。

## 为什么并起来

v1 与 v2 的盲区**互补**，而且这一点是用**各自失败的边界**量出来的：

| 真边界 | 1000 | 2000 | 3000 | 4000 | 5000 | 6000 | 7000 | 8000 | 9000 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **原始**统计量（v1）检出 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **白化**统计量（v2）检出 | ❌ | ✅ | ✅ | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| v1 误报 | 5 次 | | | | | | | | |
| v2 误报 | **0 次** | | | | | | | | |

- 原始均值差能看见 1000 与 4000，但**误报 5 次**（按位置定阈值）；
- 白化把误报清零，但 1000（4.01）与 4000（4.06）落进噪声带（无边界流最大值 3.87–4.19）。

**两个统计量的失败位置不重叠。** 这就是并起来的理由，不是"多试几次总能过"。

## 设计（跑之前定死）

**两个统计量，各自按自己的流级阈值归一化，取归一化后的最大值：**

```text
s1(i) = || mean_after(i) − mean_before(i) ||                    （v1，原始）
s2(i) = sqrt( d(i)ᵀ Σ⁻¹ d(i) )，d 同 v1                          （v2，白化）
τ_k   = 无边界流（训练集、单任务、10 块 × 1,000 独立重抽样）上 max_i s_k(i) 的 99 分位
z(i)  = max( s1(i)/τ1 , s2(i)/τ2 )
报警： z(i) > 1 且 z 在 ±50 内是局部极大
```

**流级误报上限**：每个统计量各自 1%，取并集后单条流的误报概率 ≤2%（并集界）。

其余全部沿用 v1/v2：W=64、步长 10、±50 峰半径、±100 容差、同一条测试流（seed 0）。

**我已知这么做的代价**：这是一次"看着前两轮失败挑出来的组合"。所以下面除了常规判据，
还多一条**推广判据**（E-5）——要求它在**没参与选型的扰动**上仍然成立。

## 判据

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **E-0** | 流级误报 | 无边界流平均检出 **≤ 0.2** |
| **E-1** | 边界数 | = 9 |
| **E-2** | F1（±100） | ≥ 0.80 |
| **E-3** | 顺序分配路由 | ≥ 0.80 |
| **E-4** | 随机流对照 | F1 < 0.30 |
| **E-5** | **换种子仍成立** | 用 seed 1、2、3 重新构造测试流（段的顺序不变、段内重打乱），**三个种子上 E-2 都 ≥0.80 且 E-1 都 =9** |

**E-5 是这轮的关键判据。** 组合方案最容易在"拟合到这一条流"上翻车；
换段内打乱顺序重做三遍，是对"这是不是巧合"最便宜的回答。

## 预期

**E-0 到 E-4 我押全过**：每个真边界至少被一个统计量看见（v1 全检出、v2 检出 7 个），
两者归一化后取最大，应当 9/9。

**E-5 我没有把握**——如果 1000 和 4000 恰好在某些打乱下更弱，它们会再次掉下去。
**如果 E-5 不过，结论就退回"边界检测在 7/9 到 9/9 之间，取决于种子"，不算通过。**

## 不做的事

- 不调 W、步长、峰半径、容差；
- 不按 E-5 的结果再挑种子；
- 不把这条结果推广到"逐样本任务推断"——它仍然是流上的边界检测。

## 成本

纯 CPU，累积和算窗口均值，**预计 10 分钟以内**（含 4 个种子 × 50 条无边界流）。
