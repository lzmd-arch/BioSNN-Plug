## 读法：为什么调不动

把量算清楚就明白了。公共列按列 L1 归一化到 1（与 Actor 同口径），编码后的**净每步驱动**
只有 **≈0.047**（`Σ|w|=1` 但权重有正有负，正负抵消掉 95% 以上），而阈值是 **1.0**：

- 稳态膜电位 ≈ `0.047 / (1 − 0.951)` ≈ **0.96**，正好**贴着阈值**；
- 于是发放节律基本由 `baseline_period=5` 的偏置撑着，输入只负责**推移相位**；
- 10% 的差驱动 = 每步 0.0047 → 稳态偏移约 **0.096**，是阈值的 10%，但只够把复位周期
  挪动一小步——**一次多少计数，是整数格点上的事**，于是极差停在 0.5–1 计数。

三个旋钮（阈值、不应期、窗口）都改不了这个比例：阈值降到 0.5 只把比值翻倍，不应期在
计数这么低时几乎不起作用，窗口加倍同时把偏置节律也加倍。**要动的是分子**——净驱动相对
阈值的比例，也就是列的符号抵消与 `weight_norm`。

## 与 D10 的关系

D10 说明训练学到的差方向相对幅度只有 0.5–7.3%；D11 说明**即使**把这幅度固定成 10%、
把旋钮全扫一遍，计数读出也分不开。两条合起来把阶段三的卡点定位成一句话：

> **读出的分辨率不够，不是学习没学到方向，也不是温度或熵的问题。**

## 边界

- 公共列是随机构造的，不是训练后的真实列；标定的是**读出结构**的增益；
- 点状态网格（其余分量为 0），不是完整状态空间；
- 网格里没有 `weight_norm`（它不在本轮的预注册里）——这正是下一轮要测的；
- 「放大到 2 计数」只是贪心动作能随状态变的**必要条件**，不保证 CartPole 分数上升。
