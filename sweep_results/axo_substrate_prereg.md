# 预注册：Axo 关联基质的神经元式编码优化（第一轮）

**定稿时间：2026-10-18（中国标准时间）。**
**本文件写完之前只复现过 Axo 的冻结基线，没有看过任何新编码臂的数据。**
基线复现结果（用于确认桥接没有改口径，不是新结果）：

| 档 | neighbor_auc | completion_top1 | graph_hit@1 | graph_mrr |
| :--- | ---: | ---: | ---: | ---: |
| `hash` | 0.7083 | 0.0250 | 0.8250 | 0.8883 |
| `weight` | 0.5287 | 0.8700 | 0.8250 | 0.8896 |

与 `benchmarks/substrate/baseline.json`、`docs/memory.md` 的登记值逐位相同。

## 要回答什么

Axo 的关联基质现在卡在一个分叉上：

- `hash` 选位保住了图 A 的相似度（`neighbor_auc` 0.7083），但 W 的有效维数被压到
  504 位，`completion_top1` 只有 0.0250——**W 是死的**；
- `weight` 选位救活了 W（0.8700），但关联码被压到词法 Jaccard 的一半，图 A 掉到
  0.5287——**A 是塌的**。

**本轮要回答：一个神经元式的稳态适应（homeostatic ALIF）选位规则，能不能同时保住
A 和 W，并且让第三通道不再拖词法基线的后腿？**

机制假设：跨条目反复活跃的位（高频公共位）会被适应变量抬高阈值，从而在选位时被
压下去；同簇共享、但跨簇不共享的**有区分度的位**留下来。Hopf​field 容量随模式相关
性下降而上升，所以这一步同时应该把 W 的有效维数抬起来。

## 编码臂

所有臂都从同一个 `encode_lexical` 词法码出发，**只改关联码的选位规则**；
`k=64`、宽度 4096、图参数 `top_m=8` / `min_weight=0.10`、探针 `drop=0.5`、
查询扩散 `decay=0.5` 全部沿用 Axo 默认档。

| 臂 | 选位分数 |
| :--- | :--- |
| `hash` | Axo 现有：`blake2b(位下标)` 升序取前 k |
| `weight` | Axo 现有：词法权重降序取前 k |
| `idf-γ` | `w_i · (log((n+1)/(df_i+1)) + 1)^γ`，γ ∈ {0.5, 1.0, 2.0} |
| `homeo-β` | `w_i − β · df_i/n`，β ∈ {0.25, 0.5, 1.0}；这是 ALIF 稳态适应 `θ_i = θ0 + β·a_i` 的等价选位形式 |

`df_i` 是位 i 在语料里出现在多少条记忆的**文档频率**；它是语料级统计，
**不是随机的**，也不依赖条目顺序。选出的位保留原词法权重，不做二次归一化。

`weight` 与 `idf-γ`（γ=0）在数学上相同，所以它同时是 LIF 控制臂（没有适应）。

## 判据

**主判据（必须同时成立）：**

| 条件 | 结论 |
| :--- | :--- |
| `neighbor_auc ≥ 0.7083` **且** `completion_top1 ≥ 0.8700` | 合格：同时不差于 A 的基线、不差于 W 的基线 |
| 上式 **且** `completion_top1 ≥ 0.9000` | 超过现有最好档（分簇 weight，n=200） |
| 其余 | 不合格；按两列分别报，不挑一个好看的说 |

**第三通道判据（只报告，用于下一步裁决）：**

- `graph_hit@1 ≥ 0.8500` 且 `graph_mrr ≥ 0.9021`（词法基线）→ 第三通道至少不拖后腿；
- 否则记为「仍然拖后腿」，不因为 A 的 AUC 好看就略过。

**稳定性与结构闸门：**

- 任一臂 `orphan_nodes` 超过 100（有效维数塌缩的征兆）→ 在表里标出，不当作合格；
- 任一臂 `neighbor_auc` 为 `nan`（同簇边或异簇边为空）→ 记结构失败；
- 编码必须确定性：同一份语料跑两遍，码逐位相同（测试钉住）。

## 停止规则

1. **先在 n=200 上跑完整网格**（8 个臂 × k=64）；不因为中间某臂好看就提前停；
2. n=200 上出现合格臂后，才对**合格臂**跑 `k ∈ {32, 128, 256}`；
3. `k` 扫描完仍合格，才跑规模档 `n ∈ {500, 1000, 2000}`；
4. 规模档只在**同一份合成语料**上跑，并按 Axo 已有的免责声明报告：`--scale` 的合成
   条目是同簇拼接，n≥500 的下降可能来自近重复而不是容量；
5. **本轮不碰召回集成**（`recall.py`、`min_score`、`graph_weight` 一个字节不改）。
   第三通道的召回收益是下一份预注册的事。

## 边界（必须随结论一起引用）

1. 所有指标是**词法量纲**上的；语料测不了「语义相关但用词不同」。
2. n=200 是 Axo 的量具语料，不是真实记忆库；5 万条真实规模没有实测。
3. `homeo-β` 是 ALIF 稳态适应的**选位等价形式**，不是逐时间步脉冲仿真；本轮不声称
   跑过脉冲网络。
4. 关联码仍由 `blake2b` 与 numpy 决定，无随机数、无模型、无 GPU——这是 Axo 能在 CI
   里跑的前提，任何优化臂都必须保住它。
