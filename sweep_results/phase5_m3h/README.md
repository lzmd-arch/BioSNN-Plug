# 阶段五 M3h：可辨识的调度——ES 真能改进规则门（2026-10-29）

**预注册：** [`../phase5_m3h_prereg.md`](../phase5_m3h_prereg.md)（M3g 平凡解的修正版）。
只改数据：已预置知识题的检索分改为 `{0.20, 0.40, 0.60}` 三档，未预置为 0.0；
已预置的题无论调用与否都算完成（调用计成本），未预置只有调用才算完成。
ES 同 M3g（λ=8、σ=0.1、20 代、10 种子），策略两维 `(score_threshold, cooldown)`。

## 结果

| 判据 | 实测 | 阈值 | 结果 |
| :--- | ---: | :--- | :--- |
| 严格更优于规则门（留出集） | **10/10 种子** | ≥ 7 | 过 |
| 调用数不高于规则门 | **10/10** | ≥ 7 | 过 |
| 离开初始点（‖θ−θ₀‖ ≥ 0.1） | **10/10** | ≥ 7 | 过 |
| 确定性 | 是 | 是 | 过 |

`m3h_ready = true`。

学到的阈值：**0.029–0.186**（中位约 0.15），即 ES 把阈值压到 **0.20 档以下**；
`cooldown` 停在 **0.89–1.21**（初始 1.0 附近，因为本数据里冷却不产生梯度）。
留出集效用 **0.925–0.943** vs 规则门 **0.910–0.927**；调用数同或更低。

## 读法

- **这次不是平凡解**：ES 离开了初始点 (0.5, 1.0) 且严格优于规则门；
  机制清楚——规则门的阈值 0.25 会把 0.20 档的已预置题误调用（浪费成本），
  ES 把阈值降到 0.2 以下就省下这些调用；
- `cooldown` 没有被优化（仍约 1.0）：本实验里冷却不改变决策，**这一维不可辨识**，
  不能声称「ES 学会了冷却」；
- 完成率仍是构造性的（已预置=完成、未预置=调用即完成），**不比较回答质量**；
- 与 M3g 的口径差异：M3h 把「已预置题未调用」也算完成（M3g 的旧口径不算）；
  这是预注册里写明的改动，不是事后调整。
