# 梯度余弦：局部规则离真梯度有多远（2026-11-10）

**脚本**：[`research/sel/lm/grad_cosine.py`](../../research/sel/lm/grad_cosine.py)
**原始数据**：[`gradcos_small.json`](gradcos_small.json)、[`gradcos_big.json`](gradcos_big.json)

## 一句话

**e-prop 的方向与真梯度 `dL/dw_in` 的余弦只有 0.80–0.82，不是 1。**
所以"前馈网络里资格痕迹是精确梯度"这个论断**在我们这个模型上不成立**——
缺口可以拆成三块，其中两块能用手写的局部修法补上：

| 变体 | cos（小配置） | cos（大配置） | 相对上一档 |
| :--- | ---: | ---: | ---: |
| `eprop`（现行） | **0.8151** | **0.8035** | — |
| `+ ψ 掩码修正`（用上一步的不应期） | 0.8162 | 0.8191 | **+0.001 / +0.016** |
| `+ 读出滤波的反向 EMA` | **0.9226** | **0.8973** | **+0.106 / +0.078** |
| 剩余（未补） | 0.077 / 0.103 | | 归因见下 |

- 小配置：vocab 60、N=128、48 步、batch 8、`τ_read=8`；
- 大配置：vocab 200、N=512、96 步、batch 16、`τ_read=8`；
- 随机初始化、单个 batch、整段 BPTT（序列 48/96 步，B ≥ 长度都等于整段）。

## 两个事实答案（审阅提问）

1. **资格痕迹是"全窗"**：`eps_in = α·eps_in + 1[token]`，`α = exp(−1/τ)`、`τ=20`——**指数全窗，没有截断窗口**；
2. **反馈矩阵是"对称"**：`signal = gradient @ w_out.T`，用的是**真的** `w_outᵀ`，不是随机 B。

按审阅的论证，这两条合起来应当让 e-prop 在前馈网络上等于精确梯度。**实测不是（cos 0.80–0.82），
所以"构造性零结果"的担心不成立，但原因不在审阅指出的两个位置**——见下面的分解。

## 缺口的三块分解

### ① ψ 掩码用错了不应期时刻（±0.02）

`TokenEProp.step` 里 ψ 的掩码用的是**本步更新之后**的 `trace.refractory`，
而仓库自己的 `research/eprop/traces.py::refractory_mask` 的 docstring 写得很清楚：

> **判据是"上一步之后的计数器"，不是"本步之后的"**——这一点错了不会报错，但会让 ψ 在错误的时刻被置零，
> 痕迹系统性偏掉（实测相对差 ~20%）

A 线（`brainregions/model.py`、`eprop/predictive.py`）用的都是正确的口径（`refractory_mask(spikes, n)`），
**只有 LM 这条线用错**。但实测它对余弦只有 **+0.02** 的影响——**是真错，但不是主因**。

### ② 读出滤波的反向路径被丢掉了（+0.08 ～ +0.11）

读出不是直接看 `z`，而是看 `h_t = d·h_{t−1} + z_t`（`d = exp(−1/τ_read)`）。
于是 `dL/dz_t = Σ_{u≥t} d^{u−t}·dL/dh_u`，而局部规则**把 `dL/dh_t` 直接当成 `dL/dz_t` 用**。

把学习信号做一次**反向 EMA**（`signal'_t = d·signal'_{t+1} + signal_t`）就把这部分补回来了：
cos 从 0.815 → **0.923**（小配置）、0.819 → **0.897**（大配置）。

**交叉验证**：把 `τ_read` 调到 ≈0（读出无滤波）时，这条修正**自动退化为 no-op**
（0.8647 → 0.8647），说明它补的确实就是滤波那一项，不是别的东西。

### ③ 剩下的 ~0.08–0.10：痕迹没有带上复位/ψ 的调制

标准 e-prop 的资格痕迹在脉冲时刻应当被 `(α − θ·ψ_t)` 调制（复位项），
而我们的痕迹只有 `α`。这是 e-prop 的经典近似，**不是实现错误**。
补法也便宜：`ε_t = (α − θ·ψ_t)·ε_{t−1} + x_t`——仍然是局部规则。

## 这对 CA（R12）意味着什么

**块长扫描（BPTT 阶梯）可能是错的仪器**：既然缺口可以被**三个便宜的局部修法**分别解释，
就应该先测这三个，而不是直接上最贵的 BPTT：

| 候选修法 | 预测 cos | 成本 | 是否改前向 |
| :--- | ---: | ---: | :--- |
| ① ψ 掩码改用上一步的不应期 | +0.02 | 一行 | 否（只影响更新） |
| ② 读出滤波的反向 EMA（= 反向滤波 buffer） | +0.08 ～ 0.11 | ~30 行 | 否（只影响更新，但要缓冲 τ_read 步） |
| ③ 痕迹的复位调制 `(α − θψ)` | 未知，剩 ~0.08 | ~10 行 | 否 |
| ④ 块长 BPTT | 定义上 = 1.0 | 半天的实现 | **是**（要可微前向） |

**建议的下一步**：先跑 ①②③（每个 1.7 小时，且都有 cos 预测），看哪一块把 4.48pp 的缺口吃掉。
如果三块加起来把 cos 推到 ~0.99 而 Δ 仍差 4pp，那 CA 才真的是"深度"问题，BPTT 阶梯才有意义。

## 边界

- **随机初始化、单个 batch**：训练后的余弦可能不同（权重变大、发放更密），这是本轮最大的局限；
- 小/大两套配置结论一致，但都只测了 `τ_read=8` 的单抽头读出；**R11 的 8 个 τ（到 128）会让 ② 更大**；
- 整段 BPTT 而非截断——截断版本要另一份按块清零的镜像，未写；
- 余弦只测方向，不看步长：cos 高不等于学得好。
