# Semprea V1 快半训练结果（2026-11-14）

**配置**：`--vocab 32000 --params 5e8 --batch 256 --window 192 --tree-packed --tree-signal-scale 3.0`
**语料**：FineWeb-2 `cmn_Hani`（**ODC-By 1.0**）前 3 片，`corpus.u16` 12.01 GB = **6.01B 本地 token**
**预算**：100,000 步 × 49,152 token = **4.92B token 曝光**（语料的 0.82 个 epoch）
**硬件**：8 GB 单卡，峰值显存 **2.68 GB**，吞吐 **33.9k tok/s**，总耗时 **38.5 小时**

## 二、双平台判定（规则③ v2）

| 判据 | 阈值 | 实测 | 结果 |
| :--- | :--- | :--- | :--- |
| CE 平台 | 连续 5 个区间相对下降 < 1% | 最后 5 个区间 0.03% / 0.10% / 0.01% / 0.20% / 0.15% | **成立** |
| top-1 平台 | 最后 5 个区间累计 < 0.5pp | 92k→100k：0.1095→0.1100，**+0.05pp** | **成立** |

⇒ **本轮达到双平台，上面的数字是收敛值，不是下界。**

**这一点与前几轮不同**：R3–R11 全部是"CE 平台、top-1 未平台"，因此那些 Δ 只能记作下界；
本轮两条同时成立。

## 三、四问（缺一条不许进结论段）

1. **预算截断？** **否**——双平台判据成立（见 §二），峰值在最后一个评测点且无回落；
2. **跨语料 / 跨预算比较？** **本条内部不跨**（同一语料、同一配置、同一评测窗口）。
   但**绝对不能与 SkyPile 那一批（`lm_semprea_v1_skypile`、P1/P2/R 系列）比数**：
   语料不同、词表子集不同（`qwen_tok_fw2` vs `qwen_tok`）、树也不同（最深 75 vs 50）。
   **两边的三个数字必须各自报，不能混。**
3. **单边指标？** **不是**。CE（7.823 → 6.864，−12.3%）与 top-1（0.0783 → 0.1100，+3.17pp）
   **同向改善**，没有出现历史上反复出现的 CE/top-1 脱钩形状；
4. **先验未兑换？** 不涉及（这是直接训练测量，不是代理指标）。

## 四、必须写明的口径

- **ψ 掩码是修过的版本**（F1，2026-11-10）。R0–R11 全部在**错误掩码**下跑出，两者不可混引；
- **`--tree-packed`** 是本轮新增的布局，比矩形快 **1.79×**（41.6k vs 23.5k tok/s 的对比见
  `sweep_results/lm_semprea_v1` 的启动日志）；
- **评测在 2,000 步后有一次吞吐下降**（42.5k → 34k）并稳定在此。根因是评测的全词表 gather，
  已按 token 分块（2.0 GB → 256 MB），把峰值从 4.48 GB 压到 2.68 GB，但**未完全消除**；
- 2,000 与 4,000 两个评测点用的是**未分块**实现，与之后的点有 **2.4e-7** 的数值差
  （浮点归约顺序），远低于评测噪声，但如实记录。

## 五、不能说的

1. 不能说"这个模型能对话"——top-1 0.11 意味着 89% 的下一个 token 不在首位；
2. 不能说"局部学习追上了反向传播"——B0 的同口径差距仍在（9.29pp，且那是**跨语料**的数字，
   本轮没有重测）；
3. 不能说"规模不够所以只有 0.11"——容量轴已归档，且本轮已是 0.5B；
4. 不能把本轮的 0.1100 与 SkyPile 那批的任何数字并列比较。
