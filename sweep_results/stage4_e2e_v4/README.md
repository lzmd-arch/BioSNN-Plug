# 阶段四端到端 v4：DPAR + 工作记忆共存（2026-10-27）

预注册：[`stage4_e2e_v4_prereg.md`](../stage4_e2e_v4_prereg.md)。同一幕里有 A/B/Q 工作
记忆和 K=4 对延迟配对联想；两者分开评估。5 个种子。

## 结论

**四条过、两条未过，`e2e_v4_ready=false`。** 但这次还暴露了一条**预注册判据本身
不一致**的设计问题，下面单独写。

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| WM A/B/Q 平均 R² | ≥0.50 | **0.6558** | 过 |
| DPAR 最好臂 top-1 | ≥0.80 | **0.9628**（Raw NN） | 过 |
| 状态控制 top-1 | ≤0.35 | **0.2652**（chance 0.25） | 过 |
| OOD AUROC | ≥0.75 | **0.8612** | 过 |
| OOD 弃权 | ≥0.80 | **0.7648** | **未过** |
| 80% 覆盖选择性 MSE | ≤0.10 | **0.3507** | **未过** |

读法：

- DPAR 本身工作得很好：Raw NN **0.9628**、pseudo **0.9324**、局部 Hebbian **0.5544**；
- 状态控制 **0.2652** 对 chance 0.25，说明最终状态的线性读出无法按查询键选值——DPAR
  确实需要绑定；
- 但把 4 对键值塞进同一条时间线后，WM 的 B 只剩 **0.5126**、Q **0.6253**，选择性 MSE
  被抬到 **0.3507**；**DPAR 与 WM 共存会互相干扰**；
- OOD 排序仍可用（AUROC 0.8612），但 80% 覆盖下弃权只有 **0.7648**，五个种子里只有
  seed 4 过 0.80（0.806），其余 0.74–0.768。

## 判据不一致（必须先说）

预注册同时要求 **R² ≥ 0.50** 和 **选择性 MSE ≤ 0.10**。目标方差约 1 时，
**R² = 0.50 对应 MSE ≈ 0.5**；要让 MSE ≤0.10，R² 需要约 0.90（v3 的 0.909/0.067 就是
这个关系）。所以这两条不可能同时成立，`e2e_v4_ready` 在判据层面就被设计成不可达。
这是**预注册错误**，不是模型失败；本轮按纪律不改判据、不追认，原样记录。

正确的下一版应只保留一条一致判据（例如 R² ≥0.90 **且** MSE ≤0.10，或只留 MSE），
并在预注册里写明目标方差。

## DPAR 三臂（主档，5 种子均值）

| 臂 | top-1 | 性质 |
| :--- | :--- | :--- |
| Raw NN | **0.9628** | 字面查表 |
| Pseudo-inverse | **0.9324** | 非局部闭式 |
| Hebbian | **0.5544** | 局部外积 |

局部 Hebbian 在 K=4 仍只有 0.5544；DPAR 的可用配置仍是 NN / 伪逆，不是局部联想。
这和 v4 DPAR 的边界一致。

## 边界

1. DPAR 每幕独立建库，不是终身情景记忆；键/值是合成随机向量。
2. OOD 仍是 A/B ×3 的尺度偏移，不是通用 OOD；弃权 0.7648 未过。
3. 判据不一致是本轮的主要设计问题：R² 0.50 与 MSE 0.10 不能同时成立；下一版必须改，
   但不能把本轮改判成 ready。
4. 5 个种子、500 测试幕；单次运行 62.9 s；没有调 K/σ/阈值/特征。
5. WM 的 B 线索在加入 DPAR 后明显变差（0.5126），这是**共存干扰**，不是单任务能力。

## 下一步

- **e2e v5**：把判据改成一致（R² ≥0.90 且 MSE ≤0.10，或只留 MSE），并决定是
  接受 WM/DPAR 共存干扰（分时段/分模块）还是把两类目标拆到不同 episode；
- 若目标是 DPAR 本身，v4 的结论已经足够：NN 0.963 / pseudo 0.932 / Hebbian 0.554；
- OOD 弃权仍卡在 0.765，和 v3 的 0.706 同一类问题；元认知 v6/v7 已表明状态级特征
  对信息丢失型偏移无效，不要在这里继续换阈值。
