# 预注册修订 1：P3 闭环的终止可评性——horizon 500 + 回合级终止率（2026-10-26）

**修订时间：2026-10-26，在 P3 v1 数据之后、v2 的任何数据之前。** 原文见
[`world_model_closed_loop_prereg.md`](world_model_closed_loop_prereg.md)。

## 为什么修

P3 v1 用 H=100、**按步**统计终止率，结果 9000 步里 **0 次终止** → `not_evaluable`。
但这不是"模型不会预测终止"，是**测量窗口太短**：平衡启发式在 ε=0.1 下通常 200 步内
不摔，500 步的自然回合里约 18% 会摔。按步 1% 的终止率对一个好策略本来就不可能达到。

## 修订（只改可评性，不改判据强度）

1. **horizon 100 → 500**（CartPole-v1 的自然上限；闭环仍可提前终止）；
2. **终止率改为回合级**：至少出现一次 `terminated` 的测试回合占比 ≥ **1%**；
3. 终止 AUROC 仍按**步级**标签算（这是 AUROC 需要的正例粒度）；
4. 原三项判据不变：闭环 H=10 NMSE / `copy_last` ≤0.90；AUROC ≥0.75；中位首发散步 ≥10。

## 不做什么

- 不改行为策略（仍 θ+0.5θ̇ + ε=0.1）；
- 不改模型、λ、判据；
- v1 的 H=100 / 逐步数据原样保留，标 `not_evaluable`，不与 v2 混报。
