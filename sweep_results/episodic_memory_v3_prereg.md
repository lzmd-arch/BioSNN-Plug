# 预注册：情景记忆 v3——state-indexed / attention 读出（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v0–v2 已封存联想路线：top-k/稠密/宽稀疏/
伪逆都不行，字面 NN 的动作 0.762、终止 0.962，但时间顺序只有 0.595。v3 换**非局部**的
状态索引读出，目标是把“可用基线”做出来；这一轮**不声称局部学习**。

## 两个臂（同一事件池/值/噪声/容量/判据）

| 臂 | 读出 | 时间 |
| :--- | :--- | :--- |
| **A：kNN-5** | 标准化状态上取 5 个最近邻；动作/终止取等权平均 | 最近邻的时间戳 |
| **B：attention** | `w = softmax(−‖q−sᵢ‖²/β)`，β=10；动作/终止取加权平均 | 最近邻的时间戳 |

- 状态标准化用**存储集**的均值/方差；β=10 写死；
- 时间戳故意用 top-1（加权平均会模糊顺序）；动作/终止用 k 个邻居；
- 仍用 200 回合池、终止分层、σ=0.1、N=100–2000、5 种子。

## 判据（与 v0–v2 相同，先写死）

1. 动作 N=500 ≥0.70；
2. 终止平衡/TPR N=500 ≥0.70；
3. 时间顺序 N=500 ≥0.75；
4. 容量 N=1000 动作 ≥0.65；
5. A 或 B 四条全过 → `v3_ready`；否则报边界，不调 k/β/σ/容量/阈值。

## 不做什么

- 不做局部联想（已封）；不换数据/噪声/判据；
- 不调 k/β；不做学习型注意力；
- 不把 v0–v2 的联想成绩混进本表；
- 若只有时间顺序不过，明确记为“检索瓶颈”，不是时间编码本身。
