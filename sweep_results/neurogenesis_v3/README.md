# 神经发生 v3：回放守住旧任务，护栏把当前任务推高、把旧任务压塌（2026-10-29）

**预注册：** [`../neurogenesis_v3_prereg.md`](../neurogenesis_v3_prereg.md)。
4 任务 × 4 类、冻结随机 ReLU 特征、NCM 读出、5 种子；只加两个**可分别关闭**的机制：

- **回放**：生长时旧类原型在新维度上补零是错的（旧样本过新的随机投影会激活新维度）；每个类留
  20 个原始样本，生长后**只对新增维度**用回放样本重估；
- **竞争护栏**：预测时把本任务新出现的类的距离乘 `1+δ`，δ 只用旧任务验证集 ∪ 当前任务训练
  验证片选（**不看当前任务测试集**）。

## 读法

1. **回放确实修好了补零这个结构性错误**：`replay` 臂的旧任务在 4/5 个种子上**不低于**固定 64
   对照（0.455 vs 0.445、0.565 vs 0.520、0.685 vs 0.655），最大下降 3.5pp。也就是说，v2 的
   「新类抢旧样本」里，**有一部分是生长时把旧原型的新维度补零造成的**，回放能修。
2. **竞争护栏是拿旧任务换新任务**：`margin` 把最后任务推到 0.697–0.845，但旧任务最低掉到
   0.225（最大下降 34pp）。它选出来的 δ 大多很小（0 或 0.05），只有个别任务选到 0.2——
   一旦选大，旧任务就塌。
3. **0.90 这条线在这个玩具上四臂全不可达**（最好 0.845，且是以旧任务为代价）。v1（0.432/0.310）、
   v2（0.766/0.277）与本轮合起来说明：**增加特征 + 换读出 + 回放，都改变不了这个玩具的准确率
   天花板**；瓶颈不在「容量」或「读出竞争」之一，而在**冻结的随机特征**本身承载不了 16 类
   且标签映射冲突的任务序列。

## 边界

- 玩具特征、toy 任务；不是真实插件多模态；
- 每任务的训练集切了 20% 作验证（δ 选择与增长判定要用），所以与 v2 的 100% 训练口径**不可直接
  比**（v2 固定臂 0.617 vs 本轮 fixed 0.612，量级一致但不是同一条曲线）；
- 回放缓冲是显式记忆（16 类 × 20 = 320 个样本），与阶段三「重学 3×」的回放不是同一条线；
- 「旧任务不降」不等于「抗遗忘算法」——它只说明这几条局部机制在**这个玩具**上修好了补零误差。
