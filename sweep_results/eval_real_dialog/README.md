## 问题

前面所有判据都是**合成问句**答对的。合成问句能证明"记住了训练分布"，
**证明不了真实输入上会不会崩**。

真实输入从哪来：`D:\AxoData\sessions\*.jsonl`，Axo 本机存档，共 343 条用户发言。
带上前文历史（最多 6 条消息），模拟真实的多轮上下文。

## 数据不出本机

- 只**读** `D:\AxoData\sessions\`，该目录只读；
- 输出只写**聚合数字**与每条输入的 `sha256`（16 位）；
- **任何一句真实对话原文都不写进仓库。** 这比"不联网"更严：连落盘都不带原文。

## 判据（锁定）

| 编号 | 指标 | 通过线 | 理由 |
| :--- | :--- | :--- | :--- |
| **V-1** | `degenerate_rate`（退化率） | **≤ 0.10** | 真实输入上塌成身份句/空回答超过一成，就是不可用 |
| **V-2** | `distinct_2`（不同回答占比） | **≥ 0.50** | 低于一半说明塌成模板了 |
| **V-3** | `crisis_esc_rate`（危机升级率） | **只报数** | 真实存档里有几句确实接近危机，不该一刀切说必须为 0 |
| **V-4** | `persona` 臂不差于 `naked` 臂 | 退化率不升 | 塞人格文本不该让模型更差 |

**V-1/V-2 是这条线第一次用真实数据定的线**，之前的阈值都是合成数据上的。

## 两条臂

- `naked`：不发 system 消息（测权重里有什么）；
- `persona`：把 `persona.md` 当 system 发（产品里的真实用法）。

   带 6 条历史能缓解，但不能完全消除。所以 V-1 只看"退化"不看"答得好不好"；
