**峰值** top-1 **0.1138**（第 8,000 步），Δ = **−5.31pp**；

按预注册判据 **R11-2 成立（|改善 − 3.88| = 0.93 < 1pp）⇒ 饱和，τ 轴在 4–8 之间关闭。**

## 三件必须一起说的事

### 1. 这是**边界**判定，不能当成干净的"饱和"

改善 **+0.93pp** 只比 +1pp 的门槛低 0.07pp，而 13 对测试集的噪声是 **±0.6–0.9pp**。
准确的说法是：**"8 τ 相对 4 τ 的增益与零不可分辨"**——不是"8 τ 更差"，也不是"8 τ 更好"。

按预注册，这个区间判饱和、τ 轴关闭。**如果将来有人要重开 τ 轴，必须换语料或换判据，不能重跑同一臂。**

### 2. τ 的剂量–反应：两点都在递减

| 剂量 | 绝对改善 | 每次加倍 |
| :--- | ---: | ---: |
| 1 → 4 个 τ（2 次加倍） | **+3.88pp** | ≈ +1.94pp/加倍 |
| 4 → 8 个 τ（1 次加倍） | **+0.93pp** | **+0.93pp/加倍** |

**边际收益掉了一半以上**，且第二点已在噪声内。这与 R10 的 45% 叠加率是同一个故事：
**多 τ 读出的收益在快速饱和。**

### 3. CA 的目标要按新数改：**残余 4.48pp**，不是 2–3pp

- BP 对照（B0）：Δ = **−0.83pp**；
- R11 峰值：Δ = **−5.31pp**；
- **残余缺口 = 4.48pp**。

我在上一条消息里说"CA 的目标缩到 ~2–3pp"，那是**假设 8 τ 能再买 1–2pp**；实际只买到 0.93pp（噪声内）。
**CA 草案里的门槛要按 4.48pp 重写**，`CA-1 ≥ +3pp` 仍然合理（它占残余的 67%，仍是决定性的）。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp）——边界判定就是这个噪声的产物；
- 16,000 步、峰值在 8,000（规则③ v3：终点落后峰值 1.21pp > 1pp，判"已越过峰值"）；
- 读出参数 9.96M（R8 的 2 倍、R0b 的 8 倍）；
- 字符级 next-token，**不代表能闲聊**。

## 对路线的影响

1. **τ 轴关闭**（4–8 之间），16 τ 不再有理由；N=4,096 候选之前已关闭；
2. **残余缺口 4.48pp 全部归于信用分配**——CA 是唯一剩下的机制候选；
3. CA 草案按 4.48pp 重写门槛，等审。
