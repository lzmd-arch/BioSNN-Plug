# 预注册 v4：CL 输出行参数隔离（2026-10-26）

**定稿时间：2026-10-26，在本轮隔离数据之前。** 机制顺序按 ADR-0017 与预注册 v2：
回放 → 归一化 → **参数隔离**，一次只上一个。回放（ρ0.3：AF 74.0%）与归一化
（N1-scale：AF 79.2%，`no_signal`）都没过阶段门，所以现在轮到参数隔离。

## 机制：只更新当前任务类的输出行（输出级隔离）

Route R 的 delta 读出是 `(100, 512)` 的线性矩阵 + 偏置。现行规则对**所有** 100 行更新：
当前类的目标为 1、其余为 0——旧类的行因此被新任务的样本**主动压低**，这是遗忘的直接来源。

本机制只改一行代码级别的事：

```text
active = 当前任务的 10 个类
只有 active 行（与对应偏置）更新；其余行逐位冻结
```

评估口径**不变**：CIL，argmax 在全部已见类，不提供任务 id。冻结的旧行在推理时仍然参与
比较——这不需要任务 id，也不引入门控网络。

## 两个臂（同一机制的对照）

| 臂 | 更新哪些行 | 作用 |
| :--- | :--- | :--- |
| **P1 current-rows** | 当前任务的 10 个类 | 主臂：按类对齐的隔离 |
| **P1-control random-rows** | **随机** 10 个行（每任务固定种子抽，与真实类无关） | 控制臂：更新行数相同、对齐不同 |

控制臂不是装饰：只更新 10/100 行本身就会减少遗忘。只有 P1 **优于**控制臂，才能把收益
归到"按类对齐"，而不是"更新得更少"。

参考臂：R-delta-mini，ACC **0.2466** / AF **0.8047**、`void_seeds = []`。

## 固定协议

| 项 | 取值 |
| :--- | :--- |
| 特征 | 冻结 ResNet18 avgpool 512 |
| 数据 / 切分 | CIFAR-100，10×10，全量，类 id 升序 |
| 评估 | CIL：全部已见类 argmax、不提供任务 id |
| 读出 | delta 线性，η = 0.01，20 epoch/任务，B = 128 |
| 回放 / 归一化 | **都关**（各自已经单独测过） |
| 种子 | 0–4 |
| 跑门 | 每任务 `‖ΔW‖/‖W‖ ≥ 0.05`；作废种子写进 summary |

## 判据（先写死）

1. **阶段门（不变）**：AF < 8% 且 ACC ≥ 65%；
2. **机制信号**：P1 相对参考臂 **AF −10 pp** 且 **ACC ≥ 参考 −1 pp**；
3. **对齐检验（本轮新增）**：P1 相对 P1-control **AF 至少低 5 pp**，且 ACC 不低于控制臂
   −1 pp——没有这一条，收益只能算"更新变少"，不能算参数隔离；
4. **不是少学**：P1 的逐任务"刚学时"对角线均值不低于参考臂 −5 pp（防止靠不学新任务
   来压低 AF）；
5. 跑门照旧；作废种子数写进 summary。

## 判读表（先写死）

| 机制信号 | 对齐检验 | 结论 |
| :--- | :--- | :--- |
| 过 | 过 | **输出行隔离有效**；下一步与回放叠加（新预注册），不回头调 lr |
| 过 | 不过 | 收益主要来自"更新更少"，不是按类对齐；下一机制考虑特征子空间或任务推断 |
| 不过 | 过 | 有对齐效应但幅度不足；报数，下一步与回放/归一化叠加 |
| 不过 | 不过 | 输出行隔离不是这个瓶颈的杠杆；按 ADR-0017 重新评估下一机制 |

## 不做什么

- 不加回放、不做归一化（各自已测）、不调 η / epoch / batch / 种子；
- 不做任务 id 门控、不加任务推断网络——那会让 CIL 口径失效；
- 不因为控制臂好看就只报主臂；两臂都要报；
- 看到结果后不改判据、不换参考臂、不换随机抽行的种子。

## 实现（代码先于数据，单独提交）

- `DeltaReadout.step` 增加可选 `active_classes`；为 `None` 时逐位保持原路径；
- runner 增加 `--isolation {none, current-rows, random-rows}`；随机臂用**独立种子**抽行
  （不消耗回放/minibatch 的 RNG 流），并记录抽到的行集合；
- 守卫测试：未激活行逐位不变、激活行会变、随机臂行数相同、默认路径逐位不变；
- 跑前工作区干净（含未跟踪文件）；产物先落 `data/`，再搬进 `sweep_results/`。
