# 用 ViT-B/16 特征重跑 CIL：结果（2026-11-04）

**诊断。** 预注册见 [`../continual_v3_cil_vit_prereg.md`](../continual_v3_cil_vit_prereg.md)。
原始数值：[`vit_oracle/summary.json`](vit_oracle/summary.json)、
[`vit_mahalanobis-full/summary.json`](vit_mahalanobis-full/summary.json)。
单种子（0），CIFAR-100 10×10，delta 线性读出，hidden 1 epoch × 读出 20 epoch。

## 一句话

**端到端 ACC：ResNet18 的 0.5855 → ViT-B/16 的 0.7504（+16.5pp）。**
判据 G-0/G-2/G-3 过、**G-1（0.80 + AF<0.08）不过**——但差距第一次变成了"够得着"。

## 结果

| 臂 | 特征 | 路由 | ACC | AF | 路由准确率 |
| :--- | :--- | :--- | ---: | ---: | ---: |
| 历史对照 | ResNet18 | oracle | 0.8195 | 0.000 | 1.000 |
| 历史对照 | ResNet18 | 全协方差 | 0.5855 | 0.1285 | 0.528 |
| **O** | **ViT-B/16** | oracle | **0.9192** | 0.000 | 1.000 |
| **R** | **ViT-B/16** | 全协方差 | **0.7504** | **0.0916** | **0.6783** |

**两件事同时发生了**：上界从 0.8195 抬到 **0.9192**（+10.0pp），可部署的端到端从 0.5855 抬到 **0.7504**（+16.5pp）。
而且**路由造成的损失变小了**：`ACC_O − ACC_R` 从 0.234 降到 **0.169**。

## 判据

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |
| G-0 | 特征确实更强 | ACC_O ≥0.85 | **0.9192** | ✅ |
| G-1 | 达到 ADR-0029 字面门槛 | ACC_R ≥0.80 且 AF<0.08 | 0.7504 / 0.0916 | ❌（两条都差） |
| G-2 | 有实质进步 | ACC_R ≥0.70 | **0.7504** | ✅ |
| G-3 | 路由没吃光上界优势 | ACC_R − ACC_O ≥ −0.20 | −0.169 | ✅ |

## 最有用的一个数：还差多少

用本轮的两个点（路由 0.6783 → ACC 0.7504；路由 1.0 → ACC 0.9192）线性内插：

```text
ACC ≈ 0.7504 + 0.5247 × (路由 − 0.6783)
```

要 ACC = **0.80**，需要路由 ≈ **0.773**。

**而 ViT 特征上任务路由的联合训练上限是 0.7912**（[`../continual_v3_backbone_ceiling/README.md`](../continual_v3_backbone_ceiling/README.md)）。

也就是说：**0.8 这个门槛不是结构上不可达的——天花板 0.791 高于所需的 0.773，只剩 1.8pp 的余量。**
但那 0.7912 是**联合训练**的 MLP 打出来的，CIL 里做不到；可部署的路由器现在只有 0.6783。
**这 9.5pp 的差就是接下来全部的工作量。**

## 边界（这些都不能省）

- **单种子**；两个臂各一次；
- **换骨干会改变基准的含义**（`frontends.py` 明写）。所以上表把 ResNet18 那两行标成"历史对照"，
  **不能**读成"同一基准下的提升 16.5pp"——它是**换特征空间之后的新读数**；
- 上面的线性内插只有**两个点**，且假定 ACC 随路由线性变化；**它是估计，不是测量**；
- 0.7912 是**联合训练**（用了全部任务的标签）的上限，不是可部署方法能达到的数；
- AF 0.0916 离 0.08 还差 1.2pp，这一条与 ACC 是**两个独立**的门槛。

## 顺带校正一条我自己的预期

预注册里我押 `ACC_O` 落在 0.88–0.90，**实测 0.9192，比我押的高**；`ACC_R` 押 0.70–0.75，实测 0.7504，
**踩在上沿**。两个都偏向乐观的一侧——**这说明 ViT 特征对这条管线的帮助比我估的大**。

## 这条结果放在 CL 的整条线上

| 轮次 | 纯/推断 CIL 的 ACC |
| :--- | ---: |
| ResNet18 + 最后一步式读出（历史） | 0.5855 |
| **ViT-B/16** | **0.7504** |
| ADR-0029 的重开门槛 | 0.8000 |

**结论**：特征空间确实是主因之一（+16.5pp），但它**单独不足以跨过 0.8**。
剩下要补的是"可部署的路由器从 0.678 到 0.773"——而联合上限只有 0.791，**余量 1.8pp。**
