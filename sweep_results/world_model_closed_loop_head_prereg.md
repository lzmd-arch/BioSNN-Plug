# 预注册：P3 闭环接入专用终止头（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** 离线终止头 v1 已 ready（AUROC 0.9986，
正例 3–10 个/切分），P3 的联合 ridge 是 0.616；P3 仍是 `p3_ready=false`。本轮只做一件事：
**把闭环里的终止分数换成专用头**，重测三项判据。

## 机制

```text
状态增量：仍用 ridge_quadratic（不变）
终止分数：TerminationHead（类平衡 L2 逻辑回归，IRLS，离线训练）
闭环：策略在模型预测状态上选动作；动作同时喂给模型与真实环境；H=500
```

- 终止头只由**训练回合**拟合；测试回合不参与；
- 闭环仍以**真实** `terminated` 决定何时停；头只提供排序分数；
- 与 P3 v2 的唯一差别是终止分数来源；状态模型、数据、策略、H、判据全不动。

## 判据（与 P3 v2 相同，先写死）

1. 闭环 H=10 NMSE / `copy_last` 闭环 H=10 **≤0.90**；
2. 回合级终止率 ≥1% 且终止 AUROC **≥0.75**；
3. 中位首发散步 **≥10**；
4. 三条全过 → `p3_ready`；否则按读数报，不调头/阈值。

## 不做什么

- 不改状态模型/λ/特征/策略/H/判据；
- 不把离线 0.999 直接当闭环成绩（必须重测）；
- 不做局部终止头（那是后续；本轮是测量头集成）。
