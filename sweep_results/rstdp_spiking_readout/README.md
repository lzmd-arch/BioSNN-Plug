# W3 脉冲执行层 D8：贪心读出的状态信息（2026-10-29）

**预注册：** [`../rstdp_spiking_readout_prereg.md`](../rstdp_spiking_readout_prereg.md)。
**诊断，不是验收。** 臂：D6-B（`logit_scale` 0.1→0.02），5 种子、800 回合；每 100 回合在
极角网格（21 点）采 20 个冻结窗口，记两动作计数差 `Δ = counts_left − counts_right` 的均值
与标准差；训练后用最终权重再扫 `θ/θ̇/x/ẋ` 四轴。

## 读法

- **不是噪声**：Δ 的窗口标准差很小，信噪比 11–23；它在大范围状态上**恒定**，
  所以贪心动作恒定是读出的常数偏好，不是“信号被淹没”；
- **符号可以指向任一侧**：5 个种子里 3 个偏好左、2 个偏好右——这是训练后列的常数偏置，
  与任务无关；
- 与 D4（slope 全 0）、D7（退化 `unattributed`）拼在一起：末期策略的**状态调制**
  没有进入两个动作列的计数差。问题在「读出层对状态没有差分响应」，
  不在熵、范数或 Critic 信号；
- 但不能由此推断「读出层结构必然如此」：本轮只测了 count-aligned + 温度 0.1→0.02 的臂。

## 下一步（需新预注册）

两条可分离的假设，下轮只测一条：

1. **列权重只差一个常数**：记录两列权重向量 `w_0 − w_1`，把它投影到状态编码特征上；
   若投影≈0，读出从未学到差分方向，修法在初始化/归一化；
2. **LIF 层对输入饱和**：若 `w_0 − w_1` 的投影不小但计数差不动，说明输出层发放对输入
   不敏感，修法在工作点/阈值。

## 边界

- 只测极角/四轴上的**点状态**（其余状态为 0），不是完整状态空间；
- 每点 20 个窗口；Δ 的分辨率约 0.05 计数；
- 臂固定为 D6-B，不外推到其他规则或温度。
