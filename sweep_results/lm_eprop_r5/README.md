# R5：膜时间常数 τ=100——**判不过：+0.62pp，远低于 +3pp**（2026-11-08）

**预注册**：[`research/sel/prereg-lm-r5-membrane-tau.md`](../../research/sel/prereg-lm-r5-membrane-tau.md)
**原始数据**：[`r5_tau100.json`](r5_tau100.json)
**基线**：[`../lm_eprop_r0b/README.md`](../lm_eprop_r0b/README.md) 大折第 8,000 步

## 一句话

把膜时间常数从 20 拉到 **100**（记忆窗口从 ~20 字到 ~100 字），在真语料大折、8,000 步上：
top-1 **0.0718**，bigram 0.1669 → **Δ = −9.50pp**；基线（τ=20）第 8,000 步是 0.0657 → Δ = −10.12pp。
**改善只有 +0.62pp**，门槛是 +3pp——**R5-1 不过**。

**按预注册的条件执行：不跑 τ=500。**（假设是单调的；5 倍的 τ 在 3pp 门槛上失败，25 倍需要很强的非单调效应才可能翻盘。）

## 三件必须一起说的事

### 1. 单折、13 对测试集，+0.62pp 在噪声里

13 对、1,810 个 token 上 top-1≈0.07 的二项标准误约 **0.6pp**。所以准确的说法是
**"τ=100 没有带来可测的改善"**，不是"τ=100 变差 0.6pp"。

### 2. 训练后两个臂的发放率拉开了 4.7 倍——这是本轮没料到的

开跑前实测的初始发放率只差 **1.28×**（0.0139 vs 0.0178），所以按预注册**没有预先标定**。
但训练后：τ=20 是 **0.0132**、τ=100 是 **0.0620**。长膜电位在训练中把网络推到了更活跃的工作点。

**这不会把 +0.62pp 变成一个结论**（它本来就不显著），但它意味着：
若将来要重测 τ，**必须做发放率标定**（预注册里 R5-3 的做法），否则测的是"记忆长度 + 兴奋性"两件事。

### 3. 基线链接检查通过——这次的对照是干净的

R5 链条先跑了一个 2,000 步的 τ=20 探针，落点 **0.0641 / 6.3527**，
与 R0b 曲线记录的 **0.0641 / 6.353** 逐位一致。**所以"第 8,000 步的基线点"确实来自同一配置、同一种子、同一份代码。**

## 边界

- **单折、单种子**；13 对测试集（噪声 ±0.6–0.9pp）；
- 8,000 步已在过拟合区（CE 从 2,000 步起上升），**不代表更早/更晚的停止点**；
- τ=100 与 τ=20 的**训练后发放率差 4.7×**，没有做等发放率控制；
- 字符级 next-token，**不代表能闲聊**。

## 对路线的影响

1. **"记忆长度"不是这条支线的杠杆**——至少 5 倍的 τ 不值 +3pp；
2. R5-1 不过 ⇒ 按预注册的条件执行，**τ=500 不跑**；
