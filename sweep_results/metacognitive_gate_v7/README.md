# 元认知 v7：高阶矩门 vs 信息丢失 OOD（2026-10-27）

预注册：[`metacognitive_gate_v7_prereg.md`](../metacognitive_gate_v7_prereg.md)。
OOD 与 v6 相同：A/B 输入取 `sign`、目标保留原始幅度；只把状态特征换成逐样本高阶矩。
5 个种子。

## 结论

**有效性门通过，性能门失败：`moment_gate_ready=false`。**

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| 有效性：量化 OOD / in-dist 全量 MSE | ≥2× | **6.38×**（0.4344 / 0.0681） | 过 |
| test 覆盖率 | 0.78–0.82 | **0.8096** | 过 |
| 选择性 MSE | ≤0.10 | **0.06932** | 过 |
| 量化 OOD 弃权 | ≥0.80 | **0.2048** | **未过** |
| 量化 OOD AUROC | ≥0.75 | **0.5024** | **未过** |
| 尺度 OOD 弃权 | ≥0.80 | **0.7544** | **未过** |
| 尺度 OOD AUROC | ≥0.75 | **0.8432** | 过 |

高阶矩没有把 v6 的 0.4876 救回来（0.5024 仍是 chance）；而且在尺度 sanity 上，moment4
的弃权只有 0.7544，低于 v4 的 0.8456。**这不是“差一点”，是特征族不对**。

## 六个门在两种 OOD 上

| 门 | 量化弃权 | 量化 AUROC | 尺度弃权 | 尺度 AUROC |
| :--- | :--- | :--- | :--- | :--- |
| gauss3（v4/v6 主门） | 0.1716 | 0.4876 | **0.8456** | **0.9003** |
| zsum | 0.2140 | 0.5025 | 0.7208 | 0.8336 |
| gauss2 | 0.1952 | 0.4957 | 0.6984 | 0.8074 |
| knn3 | 0.1860 | 0.4906 | 0.8296 | 0.8981 |
| moment2 | 0.1596 | 0.4656 | 0.7604 | 0.8411 |
| **moment4（主门）** | **0.2048** | **0.5024** | 0.7544 | 0.8432 |

量化 OOD 上所有门都在 chance 或以下；尺度 OOD 上只有 gauss3/knn3 过 0.80 弃权。
`moment2` 比 `moment4` 更差，说明不是“加更高阶”就能解决。

## 为什么不 work

- `sign(a)` 与 `a` 的均值/协方差相同；经过 7 个 τ 的漏积分后，状态是若干离散符号的
  加权和，**逐样本四阶矩的偏移很小**，而 calibration 的矩方差又足够大；
- 三维/四维矩密度只用了状态的**低维摘要**，没有建模“状态是否由允许的输入生成”；
- 尺度 OOD 上矩统计量反而被 Q/E 和固定范数部分抵消，弃权比 gauss3 更低。

## 边界

1. 这是**有效的负结果**：有效性门 6.38× 过，性能门四条未过；不是操作化失败。
2. 本轮没有测“输入是否是 ±1”的 lattice 特征——那是直接识别 OOD 变换，不是状态级
   元认知；如果允许输入级特征，量化 OOD 很可能被单独检出，但结论会变成“输入分布
   探测器”，不是“状态知道信息丢了”。
3. `e2e_v3_ready` 仍是 **false**；v4 的尺度 ready 只在 A/B ×3 上成立。
4. 5 个种子、500 幕；单次运行 134.9 s；没有调矩阶数/尾阈值/覆盖率/正则。

## 下一步

简单的矩特征已排除。要检测“信息丢失型”偏移，需要能表达**状态是否可逆地解释输入**的
特征：生成式状态模型（密度/能量）、多尺度循环一致性、或输入-状态互信息的代理。
继续在低维矩/距离上换阈值不会改变 AUROC ≈0.50。
