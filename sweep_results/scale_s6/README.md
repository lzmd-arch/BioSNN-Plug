# 规模实验 S6：多训练两倍半，**8k 追上了 32k**——饱和是容量的（2026-11-03）

**预注册：** [`research/scale/prereg-s6.md`](../../research/scale/prereg-s6.md)

## 判决

| # | 判据 | 门槛 | 实测 | |
| :--- | :--- | :--- | :--- | :--- |
| **S6-0** | 都放得下 | < 8,000 MiB | 最大 1,682.6 MiB | ✅ |
| **S6-1** | 预算确实起作用 | 两臂各自比 2-epoch 高 ≥2pp | 8k **+5.0pp**、32k **+2.4pp** | ✅ |
| **S6-2** | 容量在长预算下还有用 | `acc_5ep(32k) − acc_5ep(8k) > 2pp` | **+0.5pp** | ✗ |

## 数字

| ---: | ---: | ---: | ---: |
| 8,192 | 0.774 | **0.824** | **+5.0pp** |

## 结论：饱和是容量的，而且训练会把差距抹平

预注册列了三种可能，这一轮落在**第三种**：

> 若**缩小** → 更大的网络在小预算下难训，长预算下会被追上。

- **多训练确实有用**（S6-1 过）：两臂都涨，8k 涨了 5pp；
- **但它抹平了规模差**：2 epoch 时 32k 领先 8k **3.1pp**，5 epoch 时只剩 **0.5pp**；
- 所以"规模有用"这件事，**一部分是"大网络学得快"，不是"大网络学得好"**。

按预注册的死亡条件：**S6-1 过而 S6-2 不过 → 饱和是容量的，规模轴到此为止。**

## 这一轮对主线的意义

ADR-0031 定的问题是"精度随规模怎么长、代价多少"。现在的完整答案：

| 问题 | 答案 |
| :--- | :--- |
| 更多神经元有用吗 | **1k→8k 有用（+14.6pp）；8k→32k 只有 +3pp；32k→64k 无增益** |
| 显存是瓶颈吗 | **不是**——训练 update 在 64k 上也只有几百 MB；7.5 GB 那个数是评测批次 |
| 训练预算是瓶颈吗 | 有影响，但**只会缩小规模差**，不会让大网络重新领先 |

**所以"加宽"这条路在 8k 附近就到头了。** 不是资源限制，是这条管线上的**容量收益已经吃完**。

## 边界

- 单种子；5 epoch 与 2 epoch 的差是同一配置的两次运行，没有跨种子误差棒；
- 5 epoch 仍远不是"训练充分"（W2 的对照是 250 epoch），**不能**排除"更长预算下大网络重新领先"——
  但 2→5 epoch 的斜率是"差距在缩小"，不是"在扩大"；
- 与 W2 的 250-epoch 0.8889 不可比。
