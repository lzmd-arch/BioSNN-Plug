## 两处硬伤

1. **三个条件各算各的 PCA 基**（`split_readable(ra)` / `(rb)` / `(rn)`）——
   它们不在同一个子空间里，**距离不可比**；
2. **距离比这个口径没有分辨力** —— 它把八分类压成一个标量。

## 它是怎么露馅的

`R-0` 仪器自检要的是"条件 A 与自己"的比值应当 ≈ 1.0。实测 **1.06×** ——
也就是说，条件 A 与条件 B 的"距离"和 A 与自己的距离几乎一样。

**仪器自检没过，结论一律作废。** 这是 `scripts/instrument.py` 的四道闸存在的理由。
