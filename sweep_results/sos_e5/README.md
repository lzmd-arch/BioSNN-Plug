## 加一份记忆，四轮的账一次结了

| 版本 | 状态里有什么 | opt 训练池 |
| :--- | :--- | ---: |
| E3 | 相对位移 | 0.140 |
| E4 | + 四邻墙 | 0.390 |
| **E5** | **+ 朝向（2 bit 记忆）** | **0.740** |

**2 bit 的朝向把训练池从 0.390 拉到 0.740。** 这正是 E4 结论的验证：沿墙走是有记忆的策略，
给出"我正面朝哪"之后，策略类才表达得出来。四轮的失败链（E2×2 / E3 / E4）到此收口——
**根因始终是状态，不是学习信号。**

## H1' 仍然不成立，但形状变了

| | 训练池 | confirm |
| :--- | ---: | ---: |
| opt | **0.740** | 0.420 |
| search | 0.600 | **0.450** |

**`search` 在训练池上更差、在 confirm 上略好**——这是"学得慢但泛化好"的形状，
方向上支持 SoS 的主张，但**幅度没到预注册的绝对差 0.05**（实测 +0.03）。

逐种子看，这个 +0.03 是分辨不出来的：

| | 5 个种子的 confirm |
| :--- | :--- |
| opt | 0.42 / 0.46 / 0.41 / 0.41 / 0.44 |
| search | 0.46 / 0.43 / 0.51 / 0.45 / **0.30** |

`search` 的极差（0.30–0.51）远大于两臂中位的差（0.03）。**5 个种子分辨不了这个效应。**

## 按预注册办

E5-1 不过 → **记为 H1' 不成立（第二次否定 `D_search`）**。不调门槛（0.05 是跑之前定的），
也不因为"方向对了"就宣布支持。

## 下一步

既然两臂现在都学得动了，H1' 才第一次变成可测的问题——但 5 个种子的分辨率不够。
下一步应当是**提高分辨率**（更多种子），并且**先把"这次只估效应量、不判通过"写进预注册**，
免得变成"加种子直到过线"。
