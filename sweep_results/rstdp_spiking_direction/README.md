## 读法

1. **「读出从未学到差方向」被否掉了 4/5**：训练后的 `w_0 − w_1` 在 21 点极角网格上的投影
   变化是同范数随机方向的 **3–13 倍**（只有种子 0 的 1.09 不算）。
2. **但它只有总驱动的 0.5–7%**：差驱动相对幅度中位约 4.6%。按 B 的传递曲线（整条增益曲线
   上计数只动 1.8–2.65），要把计数差推到半个计数以上，差驱动得**再提高一到两个数量级**。
3. **把差方向放大 16 倍也救不回计数**：逐列重新 L1 归一化后（总量级不变，只放大差方向），
   网格 Δ 的极差只从 0.0–0.6 变到 0.25–0.55，**并不单调上升**（种子 1 反而 0.55→0.25）。
   这说明瓶颈不在「权重差太小」这一项上：**计数读出本身在这个工作点上只肯给出 ~0.5 计数
   的分辨力**。
4. **B 说明容量不是零**：输入整体放大 4 倍（相对变化几百个百分点）时计数能动 1.8–2.65，
   所以层不是死的；它是对**相对变化几百分点**不敏感。
5. 因此本轮**没有单一归因**：2 个种子像「饱和」、2 个像「幅度太小」、1 个像「方向不特殊」。
   按预注册，没有 ≥3/5 的分支就**不硬归因**，记为开放。

### 与 D8 的关系

D8 量的是「Δ 计数不随状态变」（极差 0–0.4），本轮量的是「为什么」。结论是：**方向在、
幅度小、读出分辨率低**——三者叠在一起。D8 的「读出层对状态没有差分响应」应改写成更强的
版本：**差方向存在但被计数读出的低灵敏度压平**。

### 一个必须记住的口径坑（修正 2 的来源）

原比值 `r = (d₀−d₁)/((|d₀|+|d₁|)/2)` 被三角不等式钉在 **[−2, +2]**，两列驱动**异号**时
恒为 ±2。修正 1 那一轮的 3/5 种子 21/21 个点全部钉死，`A_spread = 0` 是恒等式而不是结论
（原始差驱动其实在变：0.009–0.015）。修正 2 改用无分母的差驱动极差之后，同样的种子给出
4.5–7.5× 的标定结果。**这一轮的教训：比值型判据要先问分母会不会过零或变号。**

## 边界

- 只测点状态（其余分量为 0）上的极角网格与四轴；不是完整状态空间；
- C 的放大是**构造性探针**：它证明「放大后仍不够」，不证明「教会模型学更大即可」；
- 差驱动是**期望**量（用编码概率算），不含采样噪声；计数量是 20 窗口实测；
- 网格点随机流用 `seed*100000 + 2*100 + int(value*100)`，与 D8 的探针公式不同，
  所以 `C(1)` 与 D8 的极差列**不完全逐位相同**（0.0–0.6 对 0.0–0.4），只作量级对照。
