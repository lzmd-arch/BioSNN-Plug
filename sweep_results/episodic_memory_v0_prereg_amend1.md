# 预注册修订 1：情景记忆 v0 的终止回忆必须平衡（2026-10-26）

**修订时间：2026-10-26，在本轮任何数据之前。** 原文见
[`episodic_memory_v0_prereg.md`](episodic_memory_v0_prereg.md)。

## 为什么修

原判据写"终止准确率 ≥0.70"。但 CartPole 的终止事件只占步数的约 **0.7%**；在 N=500 的
事件池里，全预测"未终止"就能拿到约 **99.3%** 的普通准确率——**这是平凡解**，不是记忆。

## 修订（只改度量口径，不改阈值强度）

1. 终止回忆改为**平衡准确率**：查询集 = 全部终止事件 + 等量的随机未终止事件；
   `balanced_acc = (TPR + TNR) / 2`；
2. 同时报**正类召回**（TPR）与负类召回（TNR）；
3. 判据不变：平衡准确率 ≥0.70，且正类召回 ≥0.70（不能靠全猜负类通过）；
4. 终止事件在子集里少于 5 个时，该 N 记 `not_evaluable`，不判失败。

## 不做什么

- 不改动作回忆/时间顺序/容量的判据；
- 不调 D/k/σ/阈值；
- 原普通准确率仍报出来，但与平衡准确率分列，不用它判通过。
