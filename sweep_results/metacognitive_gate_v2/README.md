## 读数

- **ensemble 没有解决校准**：AUROC 0.738 反而低于 v1 的 0.745；ECE 0.177 比 v1 的 0.132 更差；
- 温度每次都撞在网格下界 **0.01**：均值 logits 的尺度太小，softmax 最大概率只有 ~0.095，
  仍需要更低的 T（或换 margin/概率平均），这是 v3 的标定问题；
- 成员的 AUROC 都在 0.71 左右，ensemble 只带来 ~0.025 的提升——**多样性有了，但不够**；
- 增益过、AUROC/ECE 不过，和 v1 的结论一致：**弃权策略容易过，"知道自己不确定"难**。

## 结论

**v2 不 ready。** 按预注册不调 K/bootstrap/T 网格；v3 的方向是**换置信度的组合方式**
（均值概率、ensemble margin、或极宽 T 网格），而不是继续加成员。按顺序下一项是
**情景记忆 v2（重做编码器）**；元认知 v3 作为并行开放项。
