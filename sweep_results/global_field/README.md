# 稳态场（v15）：完整网络工作窗扩大 **6 倍**（2 → 11–12），损伤侧仍不过

## 一、机制

```
f_run(t) = EMA(mean z)                    λ = 0.9
g_eff    = g0 · (f_run / f*)              f* = 0.08
输入     += − g_eff · Φ(t)                活动高就压，低就放
```

生物学对应：**稳态可塑性**（synaptic scaling / intrinsic plasticity）。

## 二、结果（3 种子，25 个尺度）

| `g0` | 完整 `n_viable` | 50% 损伤 `n_viable` |
| ---: | :---: | :---: |
| 0 | **2** | **7** |
| 0.5 | **11, 12, 11** | 6 |
| 1.0 | **11, 11, 11** | 6 |
| 2.0 | 11, 9, 9 | 5 |
| 4.0 | 8, 4, 2 | 3–4 |

## 三、三条结论

### 3.1 完整网络：**2 → 11–12，6 倍**（目前最好）

比固定抑制场（4.25 倍）更好，而且**更稳**（三种子 11/12/11，几乎不散）。

### 3.2 损伤网络：7 → 6，**仍打不过零场基线**

稳态场在**两侧都优于固定场**（损伤 6 vs 5），但它**不能把损伤网络的余量提上去**。

⇒ **场能帮一个神经元够多的网络，帮不了一个少了一半的网络。**

生物学上这是熟悉的图景：**稳态增益控制在健康时有用，在退行性损伤时救不回来。**
