# 内在兴奋性上调：**第一个在损伤状态下超过基线的内部机制**

## 一、结果（5 种子，25 个尺度）

| 机制 | 完整 `n_viable` | **50% 损伤 `n_viable`** |
| :--- | :---: | :---: |
| `off`（无机制） | **2** | **7** |
| 抑制性固定场（v14） | 8–9 | 5 |
| 稳态场（v15） | 11–12 | 6 |
| **内增益 `intrinsic`（v16）** | **5, 4, 5, 5, 5** | **11, 11, 11, 11, 11** |

- **损伤侧 7 → 11（+57%），五种逐位相同**；
- 完整侧 2 → 4.8（也升，没被拖累）。

## 二、判

| 编号 | 结果 |
| :--- | :--- |
| **P-0** `off` 复现基线（完整 2 / 损伤 7） | ✅ 过 |
| **P-1 内部能救伤**（`intrinsic` 损伤 > 7） | ✅ **过（11）** |
| **P-2 不伤健康**（完整 ≥ 2） | ✅ 过（4.8） |

**这是「生命」线里第一个三条判据全过的干预。**

## 三、为什么它做到了场做不到的事

| 机制 | 调的是什么 | 损伤后 |
| :--- | :--- | :--- |
| 固定场 / 稳态场 | **抑制** | 活动本就减半，再抑制更容易掉出窗 |
| **内增益** | **每个神经元自己的输入增益** | **活动低就自动上调 ⇒ 补偿了缺失的那一半** |

⇒ **稳态场调的是"压"，内增益调的是"推"。** 损伤后需要的是推，不是压。

这解释了 v14/v15 那个一直没解开的不对称。

## 四、⚠️ 三个必须一起读的限定

1. **我们把它加速了约 1000 倍。** 生物稳态可塑性是**分钟到小时**；我们在 48 步里就让它收敛
   （`η=2.0`、每 4 步更新）。⇒ 这是一个**"如果适应足够快"**的模型，
   不是"真实时间尺度下的再生"。
2. **只测了余量（`n_viable`），没测能力。** 增益上调可能让网络更容易饱和，
   准确率是否保住**没测**。
3. **一个任务、一个规模、一个损伤比例（50%）**。

## 五、这条结果在路线图上的位置

M5「再生」的定义是：**损伤后能力恢复，且恢复依赖自身活动**。

本轮只做到了**第一半**：损伤后**可行域变宽了**（余量），而且**依赖自身活动**（增益由发放驱动）。

**没做的是**：能力是否真的恢复。那是下一轮。

## 六、下一步

1. **测能力**：在内增益下，50% 损伤后的峰值解码是否保住（对照 v9 的外部补偿 +24pp）；
2. **扫 `η`**：适应速度从 1000× 降到 10×、1×，看效果如何衰减 ——
   那会告诉我们"要多快的稳态可塑性才够用"，是一个真正的生物学问题；
3. **换损伤比例**：25% / 50% / 75%，找内增益的能力边界。
