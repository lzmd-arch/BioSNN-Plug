# 全局场（v14）：按预注册作废，但**抑制性场把完整网络的工作窗扩大了 4.25 倍**

## 一、先修了一个 bug

```python
if g_field > 0:      # ← 负的（抑制性）场根本没被施加
```

第一次跑负值时结果与 `g=0` **逐位相同** —— 因为守卫把它跳过了。改成 `!= 0`。

## 二、结果（3 种子，25 个尺度）

| `g_field` | 完整 `n_viable` | 50% 损伤 `n_viable` |
| ---: | :---: | :---: |
| −4.0 | **[0, 0, 0]**（全灭） | 0 |
| −2.0 | 3, 4, 2 | 2 |
| −1.0 | 8, 6, 6 | 4 |
| **−0.5** | **[8, 9, 7]** | 5 |
| **0.0** | **2** | **7** |
| +0.5 | 2 | 2 |
| +2.0 | 1–2 | 2 |
| +4.0 | 1 | 1 |

## 三、两条结论，方向相反

### 3.1 完整网络：抑制性场把工作窗从 2 扩到 8–9（**4.25 倍**）

清晰的剂量–反应：`−0.5` 最优，`−4` 抑制过强把网络压死。
**这是"场买余量"的第一个正面证据**，而且是我在预注册里预测的方向。

### 3.2 损伤网络：反向（7 → 5）

**效果不对称**：损伤后活动本就减半，再加抑制更容易掉到地板以下。

⇒ **同一个干预在两种状态下方向相反。** 这是本轮最重要的方法论教训：
**判据必须同时报完整与损伤两个状态，只看一个会得出相反结论。**

## 四、按预注册

| 编号 | 结果 |
| :--- | :--- |
| F-0（损伤缩小余量） | ❌ **不过** —— 实测损伤**扩大**了（2 → 7） |
| F-1（损伤 n_viable ≥ 2× 基线） | ❌ 不过（5 vs 7） |
| F-2（剂量–反应） | ✅ **有清晰的峰**（−0.5 最优，−4 全灭） |

**F-0 不过 ⇒ 本轮作废。** 但我预注册里的**方向预测在完整网络那一侧是对的**，
而且效应很大（4.25 倍），不是噪声。

## 五、下一步

完整网络的余量已经找到了（`g_field ≈ −0.5 ~ −1.0`）。缺的是**损伤后也成立**。

两个候选：
1. **按存活比例缩放场强**（`g_field ∝ 存活率`）—— 损伤后减弱抑制，活动才不掉；
2. **场 + 通道噪声**（量子投影统计）—— 噪声可能让系统在低活动时仍能越过阈值。
