# 全局场（v14）：**按预注册作废**，但它推翻了一个假设并指了一条路

## 一、结果（3 种子，25 个尺度）

| `g_field` | 完整 `n_viable` | 50% 损伤 `n_viable` |
| ---: | :---: | :---: |
| **0** | **[2, 2, 2]** | **[7, 7, 7]** |
| 0.5 | 2 | 2 |
| 1.0 | 1 | 1 |
| 2.0 | 1–2 | 2 |
| 4.0 | 1 | 1 |

判：**F-0 不过 ⇒ 作废**（预注册假设"损伤会缩小余量"，实测相反）。

## 二、两条都出乎预期，但都是真信息

### 2.1 损伤**扩大**了可行尺度范围（2 → 7）

⇒ **v8 的"塌两个数量级"不是"没有尺度能工作"，而是"原来那个尺度不能再工作了"。**

网络不是坏掉，是**刀锋挪了位置**。这是对 v8 叙述的修正，而且更准确：
"脆"不等于"毁"，而是"**工作点依赖参数**"。

### 2.2 正反馈的全局场**收窄**工作窗（2 → 1）

正反馈让网络更容易饱和 ⇒ 可行带变窄。**与"场能提供稳定性"的期待相反。**

## 三、它指的路：**负**的 `g_field`

```
g_field < 0  ⇒  Φ 抑制所有神经元  ⇒  活动自我限制，不饱和
```

而负反馈的全局场正是 **E/I 平衡** —— 生物学上真实、也是待跑清单里的第三条。

⇒ **下一轮扫负的 `g_field`，判据不变**（`n_viable` 在损伤后是否扩大）。

## 四、这一轮的方法论收获

`n_viable`（尺度网格里落在工作区的点数）**比准确率贴题** ——
它直接量化"离临界点多少余量"，而且**一眼看出我原来的假设是错的**。

若只看准确率，这一轮会以"没有差异"收场，什么也学不到。
