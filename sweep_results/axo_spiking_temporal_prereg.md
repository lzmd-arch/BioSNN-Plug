# 预注册：脉冲时序读出（first-spike latency code）

**定稿时间：2026-10-18。**
前几轮的顺序任务都用**末态膜电位**读出，等于把时间维丢了。这一轮换读出：
每条记忆的分数由它的位**第一次发放/越阈的时刻**决定——早到的位权重大。

## 要回答什么

在同一个顺序任务（A→B 与 B→A，目标都是先到的那个）上，**首次发放时刻的延迟码**
能不能让脉冲超过**线性积分器的首次越阈时刻码**？

- 如果两者都高：顺序信息在“首次越阈时间”里，线性模型也有，不是脉冲的功劳。
- 如果脉冲更高：时序读出是脉冲的一个真实优势。
- 如果脉冲更低：时间维也没有救回它。

## 读出

对每条记忆 m：

```
score_m = Σ_{i ∈ bits(m)} 1 / (1 + t_first(i))
```

`t_first(i)` 是该位第一次发放（脉冲）或第一次 `v >= θ`（线性）的步号（1 起）；
从未越阈的位贡献 0。两种模型用同一个 θ=0.5、同一个 α、同样的 5 步
（2 步输入 + 3 步零输入）。

## 臂

| 臂 | 定义 |
| :--- | :--- |
| `linear-temporal` | 线性泄漏积分器（α=0.95/0.98），首次越阈时刻码 |
| `lif-temporal` | LIF（α=0.95/0.98），首次发放时刻码 |
| `alif-temporal` | ALIF（β=1、ρ=0.9），首次发放时刻码 |

## 数据

- 166 条真库只读副本；164 条有词法码；全局 `idf-2.0`、`k=64`、4096 位。
- 同会话相邻轮 `(t, t+1)` 的 107 对；A→B 目标 A，B→A 目标 B；完整关联码。
- 目标都是**先到的那个**。

## 判据

| 平均 top-1 | 结论 |
| :--- | :--- |
| 脉冲 > 线性 + 0.05 | 时序读出有脉冲增益 |
| 差在 ±0.05 内 | 打平；顺序在线性时间码里也有 |
| 脉冲 < 线性 − 0.05 | 输 |

必须分别报 A→B 与 B→A。

## 停止规则

- 只跑这 5 个臂；不追加 β/α 网格。
- 不写真实库；临时副本用完删除。
- 没有学习；W 是既有 Hebbian 外积。

## 边界

1. 人为顺序任务；相邻轮配对相似度未控制；不是自然语言时间流。
2. 延迟码是**读出**，不是新的突触机制；它只测“时间维里有没有顺序信息”。
3. 164 条真记忆；不涉及 50k。
4. 墙钟时间不能论证能效。

## 怎么被核验

`scripts/axo_spiking_temporal_readout.py` 输出每个臂的 A→B、B→A、平均 top-1 与
平均首次发放步号；执行者按上表机械判定。
