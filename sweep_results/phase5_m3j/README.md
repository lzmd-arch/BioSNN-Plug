## 读法

- **窗口化确实改善**：M3i 的 1–2/4 提升到 2–4/4，且零误触发、逐位可复现；
- 仍抓不全：seed4 只中 2 次，多数种子 3 次——侧向抑制仍会把某些事件整段压掉
  （事件期间群体发放被抑制到冲动判据以下），滑窗也救不回来；
- 对照规则门 4/4 是构造性的（它直接看输入显著性），所以「不劣于规则门」这条对脉冲机制
  很苛刻——本轮如实记未过，不改判据；
- 结论：**窗口是必要修正，但不是全部**；剩下的缺口在侧向抑制的强度/时程。

## 下一步（需新预注册）

1. **降低 η**（0.01 → 0.002）或给侧向权重加衰减，缩短静默段；
2. **前馈抑制**：输入侧按显著性归一化，避免群体发放率饱和后失去对比度；
3. 把「命中」与「误触发」做成 ROC 式的曲线，而不是单点阈值。
