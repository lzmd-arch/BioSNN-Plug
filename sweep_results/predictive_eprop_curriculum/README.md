## 读法

- **课程把重建也关掉了**：终值 0.089–0.169，是原判据（≤0.1× 初值，约 0.038–0.042）的
  2–4 倍，也远超「不退化」条款（2× 无课程终值）；
- **自由运行没有变好**：幅度 0.008–0.312，DTW 与未训练对照持平或更差；
- 因此原先的假设——「误差通道是训练时抄近路的捷径，关掉后网络会靠自身反馈自持」——
  **被否定**：误差通道不是捷径，而是**承重的驱动**。在训练末期撤掉它，学到的读出映射
  直接失效。
- 与 `predictive_eprop` 的三种子结果合起来看：自由运行不稳的原因是网络依赖误差驱动，
  不是「课程没做」。

## 边界

- 3 种子、正弦任务；课程比例 30% 是预注册写死的；
- 只测一种课程形状（线性降到 0），没有测更慢的退火；
- 运行时的未提交改动为零（复现块显示干净，commit `adfdde1`）——**首跑因 runner 的
  dropout 分支覆盖了课程值而无效，已修并重跑**，README 只记重跑结果。

## 下一步（需新预注册）

1. **更慢的退火**（最后 60% 线性降到 0.2 而非 0）——保留残余误差驱动，看能否兼顾；
2. **把误差通道换成低增益噪声**而不是 0，避免读出分布整体漂移；
3. 或者接受「预测编码需要持续的误差输入」，把自由运行的目标改为「误差输入很小但不为零」。
