# 可检测下界（d′）：**数量通道比强度通道灵敏 5 倍**

## 一、结果（20 种子，无补偿）

| 损伤 | `d′` 发放 | `d′` 静默 | 静默比例 |
| ---: | ---: | ---: | :--- |
| 1% | 0.08 | 0.63 | 0.012 → 0.026 |
| 2% | 0.18 | 1.10 | 0.012 → 0.040 |
| **5%** | **0.46** | **2.09** | 0.012 → **0.085** |
| 10% | 1.12 | 2.28 | 0.012 → 0.196 |
| **25%** | **2.56** | 6.25 | 0.012 → 0.590 |
| 50% | 3.07 | **41.85** | 0.012 → 0.908 |

判：**C-0 过**（50% 时两通道都 `d′>2`）；
**C-1 过** —— 数量通道在 **5%** 就越线，强度通道要 **25%**。

⇒ **数静默单元比看活动灵敏 5 倍。**

## 二、级联的放大是定量的

**5% 的神经元死亡 ⇒ 静默比例从 1.2% 涨到 8.5%（7 倍）。**

不是线性损失，是**临界系统对扰动的放大**。
而它正是数量通道更灵敏的原因 —— 级联把微小损伤放大成可测的静默。

## 三、它给出的设计规则

> **生死规则的触发条件应当是「静默单元比例」，不是「群体活动」。**

| 通道 | 5% 损伤时的 `d′` | 含义 |
| :--- | ---: | :--- |
| 活动 | **0.46** | 与噪声分不开 —— **系统不知道自己受伤了** |
| 静默 | **2.09** | 清楚可判 |

**v19 的生死规则失败，是因为它用了最不灵敏的那个通道** ——
按活动判死亡、按目标人口补人，两头都是强度。

## 四、这一条把三件事接上了

1. **用户的"神经元自发生"** → 需要一个触发条件；
2. **我们的"临界/级联"** → 提供了那个条件的灵敏度来源；
3. **v19 的失败** → 找到了原因（通道选错），而不是"生死规则没用"。

## 五、限定

- **无补偿**条件。有补偿时活动通道被部分恢复（50% 时仍有 26% 残差），
  数量通道不受影响 ⇒ 结论在有补偿时**更强**，不会更弱；
- 20 种子估的 `d′` 是**分布性质**；单个实例在运行时只有一次观测，
  它的判定阈值另算（那需要 ROC / 代价矩阵）。

## 六、下一步

1. **把 v19 的生死规则改成"数静默"触发**，重测 T-1；
2. 级联本身值得单独刻画：它是临界性的一个可测量（扰动放大率）。
