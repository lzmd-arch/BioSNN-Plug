# 多时间尺度工作记忆 v6：膜电位读出（2026-10-28）

**预注册：** [`../working_memory_v6_prereg.md`](../working_memory_v6_prereg.md)。
每个 τ 一组 ALIF 单元（身份输入、无循环），读数取**最后 10 步膜电位均值** + 局部 RLS；
LIF(beta=0) 与 ALIF(beta=0.1) 两臂；2000/500、5 种子、按种子并行；干净工作区 commit
`76bb7a7`。

## 结果（R²）

| 臂 | A | B | 均值 | ridge（同一膜电位） | 判定 |
| :--- | ---: | ---: | ---: | ---: | :--- |
| LIF | 0.308 | 0.311 | **0.309** | 0.303 / 0.305 | 不 ready |
| ALIF | 0.044 | 0.197 | **0.121** | 0.045 / 0.197 | 不 ready |

判据：多尺度 A/B 都 ≥0.5、fast A <0.3、单尺度各漏一个、不退化（≥0.899）；
**两条臂的多尺度都远低于 0.5**，`v6_ready=false`。fast/mid/slow 单尺度都漏线索
（fast A/B ≈ −0.002/−0.003），这两条反而过。

## 诊断：不是阈值饱和，是输入样本数

预注册声明的诊断块：

| 臂 | 膜电位范围 | 近阈值比例（≥0.95） |
| :--- | :--- | ---: |
| LIF | −0.012 … 0.859 | **0%** |
| ALIF | −0.001 … 1.538 | **0.4–0.6%** |

LIF 的膜电位根本没有到阈值；ALIF 只有约 0.5% 的单元在最后 10 步接近阈值。也就是说
**v6 的失败不是复位饱和**，而是输入信息本身：

- 每个 cue 只呈现 5 步，每步每个维度只有**一个**伯努利样本（p=clip((cue+3)/6,0,1)）；
- 5 个样本的计数对 cue 的最优线性解码上界（同一生成过程、40 万样本模拟）约为
  **R² 0.38**；LIF 实测 0.309 已接近该上界；
- ALIF 的适应项进一步压低了有效驱动，0.121 更低；
- ridge 在同一份膜电位上与 RLS 逐位接近（0.303/0.305 与 0.309/0.311），再次说明瓶颈
  不在局部读出。

这个上界是**事后诊断**，不参与预注册判据，也不改变 v6 的判定。

## 结论

**只换读出量救不了表示。** v5（脉冲计数）与 v6（膜电位）都撞在同一堵墙上：5 个伯努利
样本不足以线性重建连续 cue，任何读出都只能逼近约 0.38 的上界。v7 必须改**输入统计**
（独立传入的群体通道，或更长的呈现窗口），而不是继续调 τ/阈值/读出；任务与判据若要
改动，需要新的预注册。
