# M6：**图案在这个架构里不存在，并且与场强无关**（负结果）

## 一、假设与结果

**假设**：稳态场太强，把自发状态的图案压平了；减弱它应该让图案出现。

**结果：方向相反。**

| `gf` | `p` | 后期发放 | 空间 SD | 残余 PR | **图案比** |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0.00 | 0.00 | 0.2188 | **0.0000** | **1.00** | 0.98× |
| 0.00 | 0.02 | **0.5000**（饱和） | 0.0000 | 1.00 | 1.41× |
| 0.25 | 0.00 | 0.2188 | 0.0000 | **1.00** | 0.98× |
| 0.25 | 0.02 | 0.4920（饱和） | 0.0225 | 1.09 | 1.11× |
| 0.50 | 0.00 | 0.2077 | 0.0079 | 1.12 | 0.99× |
| **0.50** | **0.02** | 0.2674 | **0.1085** | **2.08**（峰） | 1.21× |
| 1.00 | 0.00 | 0.1357 | 0.0233 | 1.63 | 0.97× |
| 1.00 | 0.02 | 0.1420 | 0.0547 | 1.83 | 1.05× |

## 二、三条结论

### 2.1 减弱场让残余 PR **变低**（1.83 → 2.08 峰在 0.5 → **1.00** 在 0）

场不是压平图案的那个东西。**拿掉它，系统反而完全均匀**（SD = 0.0000）。

### 2.2 这与临界性一致

`gf≈1` 时接近临界，小差异被放大 ⇒ 有一点点异质；**离开临界就变成均匀**。
所以"异质"不是场压出来的，是**临界放大**出来的。

### 2.3 最关键：**图案比在所有配置下都 ≈1.0**（最高 1.21×）

⇒ **没有任何场强能让"图案"携带历史。**

## 五、还剩下的可能（都不在本架构的现成参数里）

1. **异质连接**：`exp(−d/λ)` 是同质的。真实皮层有细胞类型、层、长程束。
   ⇒ 需要**发育出异质**，而不是调一个全局参数；
2. **多池竞争**：侧抑制造图案需要多个互相竞争的池，我们的"池"从未真正建立；
3. **非线性图案**：本轮用线性谱（`eigvalsh`）测，**非线性图案是盲区**。
