# M6 内源驱动：自发状态成立，**但它是"整体偏移"不是"图案"**

## 一、结果（6 种子）

| `p` | 后期发放 | 空间 SD | 前 64 | 后 64 | **残余 PR** | **图案比** |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.00 | 0.1357 | 0.0233 | 1.89× (6/6) | 1.89× (6/6) | 1.63 | **0.97× (1/6)** |
| 0.02 | 0.1420 | 0.0547 | 1.92× (6/6) | **2.02× (6/6)** | 1.83 | **1.05× (3/6)** |
| 0.05 | 0.1566 | 0.0946 | 1.93× (6/6) | 1.48× (5/6) | 1.82 | 1.04× (3/6) |
| 0.10 | 0.1765 | 0.1257 | 1.97× (6/6) | 1.83× (6/6) | 1.82 | 1.02× (3/6) |

「残余 PR」= 减掉每个时刻的**全局公共分量**之后的参与比；
「图案比」= 在同一残余上算的历史/对照比。

## 二、两条决定性数字

### 2.1 残余 PR ≈ 1.8 —— 只有**一个**额外维度

减掉全局公共分量之后，剩下几乎只有一个方向。

⇒ **没有丰富的空间图案**，那是"整体状态 + 一点残余"。

### 2.2 图案比 ≈ 1.0（1.05×，3/6）—— **残余图案不带历史**

⇒ **M6-3 那个 2.02× 全部是"整体偏移"。**

## 三、所以 M6 到底证明了什么

| 命题 | 状态 |
| :--- | :--- |
| 零输入下存在持续活动 | ✅ 成立（0.13–0.18） |
| 那个活动不随窗口衰减（不是余响） | ✅ 成立（前 64 ≈ 后 64） |
| 那个活动带历史 | ⚠️ **成立，但只在"活跃水平"这一维** |
| **那个活动有空间图案** | ❌ **不成立**（残余 PR 1.8、图案比 1.0） |
| 起搏神经元是机制 | ❌ **空操作**（p=0 就给 1.89×） |

**⇒ 现在的"个体"是**一维的**：一个由历史决定的活跃水平，不是一幅图案。**

## 四、这条限制为什么重要

"整体偏移"可以是"这个个体今天更兴奋"，也可以只是"它的尺度参数不同"。
**它不足以支撑"人格"这个说法** —— 人格至少需要一个**多维的、结构化的**状态。

⇒ **M6 的支持是弱的，而且弱在有解释力的那一半。**

## 五、没做到的与下一步

1. **图案从哪里来？** 现在的网络在自发状态里几乎只有一个模式（PR 1.8）。
   候选：更强的局部结构（不是全局均匀稳态场）、多池、或**发育出的异质连接**；
2. **起搏为什么是空操作？** 因为稳态场把活动压住了，起搏的电流被反馈抵消。
   要让它起作用，得先把场调弱，或者让起搏只作用于一部分池；
3. **重测图案比**：任何"图案"出现之后，这一条才是 M6 的真正判据。

## 六、限定

- 6 种子；一个规模；`p` 四档；`gap` 未扫。
- 残余 PR 用的是线性谱（`eigvalsh`），**非线性图案可能被漏掉** ——
  这是一个真实的盲区，不是"不存在图案"的证明。
