# 预注册：元认知 v9——时间/维度/相关性 OOD（2026-10-29）

**性质：通用性扩展，不新增门。** 元认知 v8 已证明 `[errors, state_norm]` 的 kNN 门能处理
尺度与符号量化；v9 只把 OOD 换成三类**输入变换但目标不变**的家族，检验同一个门是否仍
成立。门、阈值规则、特征、判据全部与 v8 相同；最终用新种子 10–14。

## OOD 家族（目标保留原始 A/B/Q/E）

| 家族 | 输入变换 | 预期为什么是 OOD |
| :--- | :--- | :--- |
| `time_shift` | A/B/Q/E 时间窗整体后移 5 步 | 读出学的是固定时间码；状态与目标错位 |
| `time_reverse` | A/B 时间窗交换（B 早、A 晚） | 绑定顺序反了；目标仍是原 A/B |
| `dim_dropout` | A/B 输入的第 0 维置零 | 信息丢失；目标保留原始值 |
| `correlated` | B 输入替换为 A 输入（独立信息丢失） | 目标仍是原 B；状态无法重建 |

每个家族先过**有效性门**：OOD 全量 MSE ≥2× in-dist 全量 MSE；不过有效性的家族不参与
“通用 OOD”结论，只作负记录。

## 门与判据（与 v8 相同，先写死）

- 门：kNN(5) on `[errors, state_norm]`；阈值只在 calibration 上取（20% 分位）。
- 对每个**有效**家族：覆盖 0.78–0.82、选择性 MSE ≤0.10、OOD 弃权 ≥0.80、AUROC ≥0.75；
- 尺度 sanity（v4 口径）弃权 ≥0.80；
- 至少 3 个家族有效，且所有有效家族五条全过、尺度 sanity 过 → `v9_ready=true`；
- 若有效家族少于 3 个，直接 `v9_ready=false`，不把“没构成 OOD”写成“门失败”。

## 数据独立性

- 门族与 v8 相同，不重训；v9 最终用**新种子 10–14**。
- 不调 k/特征/阈值/覆盖率/判据；若某家族无效，照实记录，不调变换强度凑有效性。

## 边界

- v9 只覆盖“输入变换使 state 与目标不一致”的 OOD；不覆盖标签漂移、状态零空间内变换、
  或输入分布变了但任务仍可解（v5 的保范旋转就是后者，不是 OOD）。
- `errors` 仍依赖任务读出；读出失效时门的语义会变。
