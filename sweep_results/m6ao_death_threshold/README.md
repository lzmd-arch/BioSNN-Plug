# M6ao：**死亡阈值在 75% —— "无脆性"要修正为"50% 以内撑得住，75% 就死"**

## 从 M6an 的失败推出来

存续量乘性机制边际不稳定 ⇒ 系统已有的边界是**内增益稳态控制器**
（`gain ← gain·exp(η(0.08 − f_i))`，钳在 [0.2, 5.0]）。
它好到从不失效 ⇒ 无脆性。**但它有钳位** —— 损伤超过调节能力就会饱和，那之后发放离开工作窗。

## 结果（4 种子，随机切）

| 损伤 | 发放 | 窗内 |
| ---: | ---: | :--- |
| 0% | **0.1541** | ✅ |
| 10% | 0.1275 | ✅ |
| 25% | 0.0874 | ✅ |
| 50% | 0.0371 | ✅（勉强） |
| **75%** | **0.0031** | **❌ 死亡** |
| 90% | 0.0010 | ❌ |
| 98% | 0.0002 | ❌ |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| AO-0 无损伤在窗内 | 0.1541，**过** |
| **AO-1 有死亡阈值** | **75%**，过 |
| **AO-2 单调** | **是**（0.1541→0.0002 严格单调） |

## 一、这条修正了今晚一个说法

前六次"无脆性"用的都是**解码准确率**：切 50% 之后解码反而升高（去噪），所以看着"不脆"。
**但同一批运行里发放已经在掉**（0.154 → 0.037）。

⇒ 准确的说法是：**50% 以内功能上撑得住，75% 就死。**
**内增益控制器确实在维持边界，但它有极限。**

## 二、这更像生物

大脑同样耐受相当大的损伤，然后在一个阈值上崩溃。
**用一个读数看不出边界，换个读数（发放）边界就清清楚楚。**

**方法学教训**：判断"有没有脆性"必须同时看**功能读数**与**工作点**，
只看功能读数会把"工作点正在滑落"读成"没影响"。

## 三、这条的定位

- **边界是存在的，而且它是自己维持的**（内增益稳态），不是宿主给的；
- **它有明确的死亡阈值（75%）**；
- 但**阈值以内的损伤不造成功能损失** —— 这是与生物一致的性质，不是缺陷。

## 四、限定

- 4 种子；随机切；`per=16`；
- 只测了发放，没测增益是否真的钳在 5.0（那需要把 `gain` 从 `run_spont` 里取出来，未做）；
- 阈值定位在 50%–75% 之间，**没有细扫**；真正的钳位点未测。
