# amend1：R² → 准确率，并补一个天花板已知的探针目标

**写于**：2026-11-16，仍在任何一次有效测量之前（`result.json` = `{"cells": {}}`，
零个臂通过仪器闸）。**这是修仪器，不是事后调判据** —— 没有任何一个数被这条 amend 改变过。

## 改了两处

### 一、预测的**指标**：R² → 准确率

**为什么**：`R² = 1 − MSE/Var` 在多类 one-hot 上**没有下界**。实测出现过 **−1.6×10⁹**，
当时我把它判成"V-1 不过"，其实是**估计器发散**，不是模型差。
准确率有界于 [0,1]、可与底板直接比，不会再出现"一个坏数被当成结论"。

**这条不改变 V-1 想测的东西**（"状态里有多少关于未来的信息"），只改变读数方式。

### 二、补一个**天花板已知**的探针目标

**为什么**：next-token 是 64 选 1，而且**即使完美知道状态也猜不准** ——
观测是从 `pref[s]` 抽出来的随机 token，最优策略也只能猜 `argmax(pref[s])`，
天花板远低于 1 且**未知**。于是"acc 0.057 到底算好还是算差"无法回答。

| 探针 | 类别数 | 随机 | 天花板 |
| :--- | ---: | ---: | :--- |
| **主：隐状态 `s`** | 16 | 0.0625 | 高（受 `pref` 重叠限制，但接近 1） |
| 次：next-token | 64 | 0.0156 | **低且未知** |

`make_stream` 本来就是从 `s` 生成的，只是把 `s` 丢掉了；留下它不引入任何新假设。

**V-1 判在主观测量上**（隐状态探针）。next-token 照报，但不作判据。

## 改后的 V-1

| 编号 | 判据 |
| :--- | :--- |
| **V-1′** | 隐状态探针准确率：**环 − 随机 ≥ 0.05**，且两臂都通过仪器闸。 |

参考：同一批网络在**有标签**的 8 类任务上是 0.545 vs 0.126（差 0.42）。
无标签指标若连 0.05 都分不出来，就是指标坏，不是网络坏。

## 仪器闸（`scripts/instrument.py`，同日修）

- `majority_baseline`：底板取**多数类在测试集上的准确率**，不是 `1/n_class`。
  历史上的 0.376"准确率"就是多数类本身，用 `1/8=0.125` 当随机线才会误判为"有信息"；
- `validity`：`acc` 必须高出底板 **2 个标准误**（`se = sqrt(acc(1−acc)/n_test)`）。
  2σ 是统计惯例，不是为这批数据挑的常数；
- 发放率仍必须落在 **[0.03, 0.20]** 工作窗内。
