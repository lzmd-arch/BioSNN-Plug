# 无标签状态评估（V-1′）：判据不过，且「PR 跟踪能力」这条被推翻

**一句话**：环与随机稀疏在「状态里有多少隐变量信息」上**完全分不出来**
（线性探针 **−1.2pp**、MLP 探针 **−1.2pp**，方向都是随机略高），
而**有效维度 PR 差 +14.4（16.4 vs 2.0）**。

⇒ 在这对布线上，**PR 是假阳性**：它在动，能力没动。

## 一、判据（跑之前落盘）

- [`prereg.md`](prereg.md) —— 原始 V-1（用预测 R²）
- [`prereg_amend1.md`](prereg_amend1.md) —— R² → 准确率；补「天花板已知」的探针目标
- [`prereg_amend2.md`](prereg_amend2.md) —— 探针的 λ 必须由数据内部选，不能拍

**V-1′**：隐状态探针准确率 **环 − 随机 ≥ 0.05**，且两臂都过仪器闸。

## 二、结果（3 种子、16 类隐状态、词表 64、n=2048）

| 量 | 环（度 4） | 随机稀疏（度 32） | 差 |
| :--- | ---: | ---: | ---: |
| **隐状态·线性探针** | 0.1560 | 0.1678 | **−0.0117** |
| **隐状态·MLP 探针** | 0.1369 | 0.1488 | **−0.0119** |
| 隐状态·归一化增益 | 0.0998 | 0.1123 | −0.0125 |

| next-token 探针 | 0.0625 | 0.0616 | +0.0009 |

| 发放率 | 0.0737 | 0.1315 | — |

**两条自洽性检查都过**：

1. 窗口天花板两臂**逐位相同**（0.3505）—— 它不经过网络，就不该受布线影响；
2. MLP 与线性两族**独立地给出同一个结论**（−1.2pp，随机略高）。

## 四、这次测量推翻了什么

**「PR 跟踪能力」这条此前被当成已结的结论。** 三条证据一起看：

1. **本轮**：PR 16.4 vs 2.0（8×），而两族探针都说能力**相同**。
   只要这两条布线的能力真的相同，PR 就不是能力的代理量。
2. **`sweep_results/geom_fix`**（任务生成器是对的，可放心引用）四条布线：

   | 布线 | PR | 线性 | MLP |
   | :--- | ---: | ---: | ---: |
   | ring | 5.90 | 0.355 | 0.539 |
   | grid3 | 2.28 | 0.257 | 0.441 |
   | smallworld | 2.17 | 0.292 | **0.556** |
   | scalefree | 2.02 | 0.343 | 0.536 |

   **PR 与 MLP 准确率的 Spearman 秩相关 = 0.00**（与线性是 0.20）。
   PR 最低的三条（2.0–2.3）里，`smallworld` 的准确率**最高**（0.556 > ring 0.539）。
3. 那份对照里被引用的「随机 0.126」**恰好等于 1/K = 1/8**。
   准确压在这条线上是**坏任务**的签名（见第五节），不是「这条布线很弱」。

**准确的说法**：PR 没有证明能跟踪能力。它在这对布线上分了 8 倍，而能力没分。

## 五、顺带查出来的仪器 bug：四个脚本的任务生成器没播种

`torch.distributions.Dirichlet(...).sample()` 走**全局** RNG，不吃函数里的
`torch.Generator`。于是**每次调用都抽出一个新的 `pref`**：

```python
tr = make_task(..., seed=10+sd)   # pref A
te = make_task(..., seed=20+sd)   # pref B，与 A 无关
```

训练集与测试集是**两个不同的任务**，任何分类器都只能到随机。

| 目录 | 症状 | 处置 |
| :--- | :--- | :--- |
| `bio_all` | 六臂 0.108–0.130（随机 0.125） | [INVALID](../bio_all/INVALID.md)，待重跑 |
| `spatial_dim` | 1D/2D/3D/7D = 0.125/0.135/0.125/0.094 | [INVALID](../spatial_dim/INVALID.md)，待重跑 |
| `manifold_big` | 四几何 0.125–0.141 | [INVALID](../manifold_big/INVALID.md)，待重跑 |
| `hyperbolic_readout` | `cells` 全空 | [INVALID](../hyperbolic_readout/INVALID.md)，待重跑 |

这个 bug **当天早些时候在 `structure_ladder` 里已经修过**（`make_pref` 训练/测试共用），
但**没有传播到这四个脚本**，它们各自复制了一份 `make_task`。

`highdim_all` / `highdim_sweep` / `geom_fix` / `geom_hyperbolic` / `dim_ladder` /
`structure_ladder` 都走 `structure_ladder.make_pref`，**不受影响**。

## 六、next-token 探针作废

两臂 next-token 准确率 0.0625 / 0.0616，**都低于底板 0.0736** ——
探针还不如「永远猜训练集里最多的那个 token」。

这正是 `prereg_amend1.md` 预判的：观测是从 `pref[s]` 抽的随机 token，
即使完美知道状态也猜不准，且 4096 维特征 / 6144 样本下线性探针会背训练集。
**它不作判据，只留作记录。**

## 八、这次**没有**证明的事

- **没有**证明「环不如随机」。差是 1.2pp，两族探针同向，但这是**这一个任务**上的
  「隐状态可解码性」这一个量。环可能在其他量上更强（时序记忆、抗噪、能耗）。
- **没有**证明 PR 一定不跟踪能力。现在是「没有证据支持它跟踪」，
  且有一对明确的反例（本轮）。
