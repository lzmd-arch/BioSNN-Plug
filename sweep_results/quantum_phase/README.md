# 量子启发相变（Q-0…Q-2）：**相变存在，但"临界是结构的"没成立**

**一句话**：改用酉分裂步之后动力学稳定了，扫 `Γ` 确实出现敏感性峰值（比边界高 **54 倍**），
但**峰值位置不随 `J` 单调移动**（索引 `[4, 4, 3]`），
而且敏感性主要由 `J` 的**绝对大小**主导（`J` ×4 使敏感性涨约 300 倍，`Γ` 全程只变 3.5 倍）。

⇒ **不能声称"临界点由哈密顿量决定"。** 这是本轮唯一有意义的那条，它没过。

## 一、模型（**经典地积分量子方程**，不是量子计算）

```
i dψ/dt = Hψ + g|ψ|²ψ − iγψ        H = J + Γ·I
```

`J` 按 3 维折叠薄片上的距离衰减；`Γ` 横场；`g` 非线性；`γ` 显式退相干；观测 `|ψ|²`。
**不需要相干、不需要低温。**

## 二、两次实现错误（都值得记）

1. **显式欧拉 → 全 NaN。** 显式欧拉的稳定域**不含虚轴**，对哈密顿系统**无条件不稳定**。
   改用 **Strang 分裂 + 酉传播子** `exp(−i·dt·J)`（`matrix_exp` 只算一次），
   保范数、不发散。
2. **`J` 是实数、`ψ` 是复数** ⇒ `addmv` dtype 冲突。`J` 转 `complex64`。

## 三、结果

| `J` 倍数 | 敏感性（Γ = 0.02 → 3.2） | 峰值索引 |
| :--- | :--- | :---: |
| ×0.5 | 37.9 / 39.3 / 41.3 / 44.6 / **46.8** / 34.2 / 7.6 / 3.2 | 4 |
| ×1.0 | 684.6 / 700.9 / 727.6 / 777.9 / **849.9** / 837.6 / 611.7 / 246.2 | 4 |
| ×2.0 | 11889 / 11422 / 12313 / **13357** / 12842 / 12418 / 11951 / 13071 | 3 |

| 编号 | 结果 |
| :--- | :--- |
| **Q-0** 不发散 | ✅ 过 |
| **Q-1** 相变存在（峰值 > 边界 ×1.5） | ✅ 过（54×） |
| **Q-2** 相变是结构的（峰值随 `J` 单调移动） | ❌ **不过**（`[4, 4, 3]`） |

## 四、为什么 Q-2 不过，以及它意味着什么

**量纲上的问题**：敏感性从 `J`×0.5 到 ×2.0 涨了 **约 320 倍**，
而同一 `J` 下扫 `Γ` 只变 **3.5 倍**（甚至 54 倍是拿峰值比最边缘）。
⇒ 曲线的形状主要由 **`J` 的模**决定，`Γ` 只是在这个大背景上的小起伏。

**所以现在测到的"峰"很可能不是相变，而是"某个 Γ 恰好让响应不出相消"。**

## 五、下一步（若要继续这条路）

1. **换序参量**：不用"弱输入响应幅度"，改用**参与比**或**关联长度**
   —— 那才是相变的标准观测量；
2. **归一化**：每个 `J` 下的曲线先除以自身均值，再看峰位是否移动；
3. **精细 Γ 网格 + 多种子**：8 个点、1 个种子不足以定峰位；
4. **加一个已知的对照**：横场 Ising 的平均场模型有解析相变点 `Γ_c = zJ`，
   先用它验证"我们的观测量能不能找回 `Γ_c`"，再去测这个模型。

## 六、结论

**这条路暂不成立，但错在观测量与量纲，不在"量子启发"本身。**

按预注册，**不改 1.5 那条线**、不改 Q-2 的定义。
下一轮若继续，先做 §五-4 的解析对照 —— 那是唯一能证明"观测量测的是相变"的办法。
