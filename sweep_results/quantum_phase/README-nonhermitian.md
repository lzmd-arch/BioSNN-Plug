# 量子启发线（v11–v13）：**根本性错误 —— 那个"哈密顿量"从来不是厄米的**

## 一、错在哪

`build_J` 产出的是**有向**（非对称）耦合矩阵：

```
|J − Jᵀ| / |J| = 0.385        （38.5% 的不对称）
```

而 `H = J + ΓI` 只有在 `J` **厄米**时才是厄米。于是：

- `−i·dt·H` **不是反厄米**；
- `exp(−i·dt·H)` **不是酉的** —— 它会**放大**，不是旋转。

## 二、证据（决定性）

| 版本 | 酉性误差 `‖U†U − I‖∞` | 600 步后的状态散度 |
| :--- | ---: | ---: |
| **非厄米（现状）** | **2.48e-02** | 1.17e-7 → **4.19e+03** |
| 对称化 `(J+Jᵀ)/2` | **1.37e-06** | 1.17e-7 → 2.00e-06 |

酉演化是**等距**的，散度不可能增长。非厄米版本让它涨了 **3.6×10¹⁰ 倍** ——
那不是混沌，是**矩阵指数在放大**。

## 三、这解释了前面三件怪事

1. **v11**：敏感性随 `J` 涨约 320 倍、随 `Γ` 只变 3.5 倍 —— 因为主导项是放大率，不是相变；
2. **v12**：`K ≈ 0.015`（说"规则"）—— 但那是在一个**非酉**系统上测的，结论无意义；
3. **v13**：`η=0` 给 `K=0.88`、状态散度涨 2.87e6 倍 —— 与"纯酉不可能混沌"矛盾，
   原因正是**它根本就不是酉的**。

**⇒ v11 / v12 / v13 关于这个系统的结论全部作废。**

## 四、一个必须记的教训

v12 的工具自检**过了**（正弦/周期3/Logistic 全对），但那是**一维标量序列**上的检验。
它证明不了"这个工具在多体复数系统上也可靠"。

⇒ **自检通过 ≠ 仪器适用于当前对象。** 这与仓库里那条老教训是同一族：
"冒烟过 ≠ 行为对"。

## 五、修法与下一步

**一行**：

```python
J = (J + J.T) / 2
```

之后：

1. **先验证酉性**（`‖U†U−I‖∞ < 1e-5`）**再跑任何东西** —— 这是新的前置闸；
2. 重跑 v12 的黑箱混沌判据（在**酉**系统上）；
3. 再讨论坍缩能不能带来混沌 —— **定理仍然成立**：
   酉 ⇒ 等距 ⇒ Lyapunov 指数为 0 ⇒ 不可能混沌。

## 六、定理本身没有被动摇

纯酉演化不可能混沌，这是数学事实。被推翻的只是**我们实现的东西是不是酉的**。
所以用户那个判断（"少了坍缩所以不混沌"）**仍然是有道理的** ——
只是我们还没有在一个真正酉的系统上检验过它。

## 七、用户追问：等距是否只在"重建拓扑"之后才成立？

用户问：**「有没有一种可能，这种等距仅仅是重建拓扑之后才等距？」**

这是一个精确的数学命题：若 `J = V Λ V⁻¹` 且 **Λ 全实**，则
`e^{−iJt} = V e^{−iΛt} V⁻¹`，于是**在范数 `‖V⁻¹x‖` 下演化是等距的** ——
欧氏散度的增长只是"形状在变"。这类系统叫**准厄米 / PT 对称**。

### 实测：否

```
J 的特征值：1024 个
  非实特征值      902 / 1024        （88%）
  Im 范围        [−0.8176, +0.8176]
```

`e^{−iJt}` 的模是 `e^{Im(λ)t}`。最大放大：
`e^{0.8176 × 0.05 × 600} = e^{24.5} ≈ 4.4×10¹⁰`。

**实测增长 3.6×10¹⁰ —— 吻合到 1.2 倍以内。**

⇒ 那个增长**就是最大虚部特征值本身**，不是度量问题。
谱不实 ⇒ **不存在任何内积让它等距**。用户的假设被定量否掉。

## 八、更深的结论：量子力学在结构上不允许经典混沌

用户的问题把我带到了更深的一层。

若系统是**真正开放**的量子系统，该用的度量不是纯态欧氏范数，而是
**密度矩阵的迹距离**。而 Lindblad 演化是**收缩**的：

```
‖ρ_a(t) − ρ_b(t)‖₁  ≤  ‖ρ_a(0) − ρ_b(0)‖₁
```

**迹距离永不增长。**

⇒ **不只是"我们实现错了"** —— **量子力学（闭的或开放的）结构上就不允许
"邻近状态指数分离"**，而那正是**经典混沌的定义**。

| 命题 | 判定 |
| :--- | :--- |
| 等距只在"重建拓扑"后成立 | ❌ **否**（谱 88% 复） |
| 非厄米是实现 bug | ✅ 是 |
| **量子系统能提供经典混沌** | ❌ **结构上不可能**（酉等距 / Lindblad 收缩） |
| 量子混沌不存在 | 存在，但定义不同：**OTOC / 算符增长 / 加扰** |

## 九、这条线的结论

**若"混沌"取经典意义（轨迹指数分离），量子力学给不了 —— 不是实现问题。**

要走这条路，得换成 OTOC 意义上的**量子加扰**（早期 `∝ e^{λ_L t}` 的算符增长、
butterfly velocity），需要大 N 与强相互作用，而且**离开生物合理性很远**：

§14.1 的退相干论证仍然成立 —— 脑内 **10⁻¹³ 秒**就退相干，
撑不到**毫秒级**的神经动力学。

**⇒ 这条线到此为止。** 真正的收获是反面的：它证明"靠量子给混沌"走不通，
于是**回到平衡 E/I 混沌网络**（经典、生物有实证、正好治刀锋工作点）才是对的。
