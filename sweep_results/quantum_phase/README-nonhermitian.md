# 量子启发线（v11–v13）：**根本性错误 —— 那个"哈密顿量"从来不是厄米的**

## 一、错在哪

`build_J` 产出的是**有向**（非对称）耦合矩阵：

```
|J − Jᵀ| / |J| = 0.385        （38.5% 的不对称）
```

而 `H = J + ΓI` 只有在 `J` **厄米**时才是厄米。于是：

- `−i·dt·H` **不是反厄米**；
- `exp(−i·dt·H)` **不是酉的** —— 它会**放大**，不是旋转。

## 二、证据（决定性）

| 版本 | 酉性误差 `‖U†U − I‖∞` | 600 步后的状态散度 |
| :--- | ---: | ---: |
| **非厄米（现状）** | **2.48e-02** | 1.17e-7 → **4.19e+03** |
| 对称化 `(J+Jᵀ)/2` | **1.37e-06** | 1.17e-7 → 2.00e-06 |

酉演化是**等距**的，散度不可能增长。非厄米版本让它涨了 **3.6×10¹⁰ 倍** ——
那不是混沌，是**矩阵指数在放大**。

## 三、这解释了前面三件怪事

1. **v11**：敏感性随 `J` 涨约 320 倍、随 `Γ` 只变 3.5 倍 —— 因为主导项是放大率，不是相变；
2. **v12**：`K ≈ 0.015`（说"规则"）—— 但那是在一个**非酉**系统上测的，结论无意义；
3. **v13**：`η=0` 给 `K=0.88`、状态散度涨 2.87e6 倍 —— 与"纯酉不可能混沌"矛盾，
   原因正是**它根本就不是酉的**。

**⇒ v11 / v12 / v13 关于这个系统的结论全部作废。**

## 四、一个必须记的教训

v12 的工具自检**过了**（正弦/周期3/Logistic 全对），但那是**一维标量序列**上的检验。
它证明不了"这个工具在多体复数系统上也可靠"。

⇒ **自检通过 ≠ 仪器适用于当前对象。** 这与仓库里那条老教训是同一族：
"冒烟过 ≠ 行为对"。

## 五、修法与下一步

**一行**：

```python
J = (J + J.T) / 2
```

之后：

1. **先验证酉性**（`‖U†U−I‖∞ < 1e-5`）**再跑任何东西** —— 这是新的前置闸；
2. 重跑 v12 的黑箱混沌判据（在**酉**系统上）；
3. 再讨论坍缩能不能带来混沌 —— **定理仍然成立**：
   酉 ⇒ 等距 ⇒ Lyapunov 指数为 0 ⇒ 不可能混沌。

## 六、定理本身没有被动摇

纯酉演化不可能混沌，这是数学事实。被推翻的只是**我们实现的东西是不是酉的**。
所以用户那个判断（"少了坍缩所以不混沌"）**仍然是有道理的** ——
只是我们还没有在一个真正酉的系统上检验过它。
