# M6aa：**长程兴奋性连接用"接线"买回了整合 —— 两个场做不到的事**

预注册判据在脚本顶部。`field_radius=2`（局部抑制）、`g_local=1.0`，
扫 `p_long`（每行尾部被替换成远距离目标的入边比例）。

| `p_long` | PR | **整合** | 分离 | 发放 |

## 一、这条的分量

**这是今晚第一次三种性状同时成立。** 而且它做到的是**两个场做不到的事**：

- M6y 把全局场加到 **16 倍**，整合一点没回来（0.121 → 0.095），维度反被压死（39.8 → 2.46）；
- 而 `p_long=0.5` 的**接线**给出整合 **0.421**，同时 PR 还有 **47.04**。

⇒ **整合不必由全局标量承载。** 用长程兴奋性投射（皮层本来就有的东西）可以在
保住空间异质性的前提下把两个半球耦合起来。

## 二、但这格还没测"可解码"

`M6aa` 的判据里没有解码。**高维 + 整合 + 分离，但状态若读不出历史，仍然不是"目标配置"。**
`M6ak` 正在同一格上用三种读出（线性 / 1-NN / MLP）测这一点。

## 三、限定

- 3 种子；一个 `field_radius=2`、一个 `g_local=1.0`；
- 单调性不过 ⇒ **0.5 可能是格点上的偶然**，`M6aa2` 正在细扫 `p_long ∈ {0.4…1.0}`；
- 整合与分离的口径与 M11 相同（半球平均活动的时间相关 / 半球内空间变异系数）；
- `p_long=0.5` 时每行 4 条入边是远距离的，**这个比例在生物学上偏高**（皮层长程投射通常远小于一半）。
