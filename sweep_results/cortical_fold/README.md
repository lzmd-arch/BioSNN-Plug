# 折叠的皮层薄片：**3 维折叠改了接线，但改不了能力**

**一句话**：把 `64×64` 的薄片在 3 维里折叠后，按 3 维距离接线会改掉约 **21%** 的突触
（`Jaccard = 0.787–0.790`，P-1 过）；而峰值准确率与记忆保持 AUC 的差异只有
**+0.47% / +1.09%**，**5/7 种子同号**（p ≈ 0.45）⇒ P-2/P-3 都不过。

## 一、为什么这样设计

用户指出：**脑组织就是 3 维的，硅基不可能低于 3 维。**
这纠正了此前把"1D/2D/3D 格点拓扑"当成"空间结构"的错误 ——
那些神经元根本没有物理坐标。

三个"维"必须分开：**嵌入维（物理，固定 3）· 状态空间维（大）· 内在流形维（低，动力学产物）**。
⇒ **嵌入维不是可选项**；可变的是"3 维空间如何约束接线"。

皮层是**在 3 维中折叠的 2 维薄片**。折叠让薄片上很远的两点在 3 维里很近 ——
这是 2 维图看不见、3 维物理才有的效应。

| 臂 | `d` 用哪个 | 折叠的影响 |
| :--- | :--- | :--- |
| `sheet` | 薄片（2D 环面）距离 | **无** —— 图与不折叠完全相同，**内置零对照** |
| `space` | 3 维距离 `√(dx²+dy²+dz²)` | 有 |

## 二、结果（7 种子、n=4096、deg=32、λ=4、折叠 A=16）

| 臂 | lag0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 发放 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `sheet` | 0.058 | 0.811 | 0.530 | 0.270 | 0.152 | 0.131 | 0.111 | 0.088 | 0.0850 |
| `space` | 0.058 | 0.815 | 0.527 | 0.272 | 0.158 | 0.134 | 0.113 | 0.091 | 0.0908 |

底板 **0.066**。`Jaccard(sheet, space)` = **0.788 / 0.789 / 0.787 / 0.787 / 0.788 / 0.790 / 0.788**。

## 三、判

| 编号 | 结果 |
| :--- | :--- |
| **P-0** 峰值 / 工作点 | ✅ 过（本轮有效） |
| **P-1 折叠改了接线** | ✅ 过（最大 0.790 < 0.8） |
| **P-2 峰值** | ❌ **不过**：`[+.0017, −.0017, +.0095, +.0035, +.0165, +.0017, −.0043]`，**5/7**，效应量 **+0.47%** |
| **P-3 AUC** | ❌ **不过**：`[+.0026, −.0087, +.0061, +.0651, +.0078, +.0877, −.0365]`，**5/7**，效应量 **+1.09%** |

## 四、这是一个干净的负结果

**换了 21% 的突触，行为几乎逐点相同。**

两条曲线并排看：0.811/0.815、0.530/0.527、0.270/0.272、0.152/0.158 ——
差异都在 0.005 量级，而种子间的波动是 0.03–0.05 量级。

⇒ **在这个规模、这个读出、这个任务下，物理 3 维嵌入改变的是"用哪套接线"，
不是"能做多少"。**

## 五、一个可能的正面解读（**是解释，不是本轮测到的**）

这个结果与前面几轮一致：γ 改结构 10%——能力平；折叠改结构 21%——能力平。
合起来指向**简并（degeneracy）**：

> **不同的结构实现同一功能。**

这是生物系统的一个核心特征（Edelman & Gally 的 degeneracy），也是"生命能抗损伤"的基础。
**但本轮没有直接测简并** —— 只观察到功能对结构不敏感。
要测简并至少要：多种截然不同的接线 → 同一功能，并且**每一种都经得起损伤**（M5 再生）。

## 六、限定（必须一起读）

- **一个折叠幅度**（A=16）、**一个 λ**（4）、**一个规模**（4096）、**一个读出**；
- P-1 是**边缘过**（0.790 对 0.8）；
- 效应量 +0.5~1%，**方向本身也不可靠**（5/7，p≈0.45）；
- 折叠只改了 21% 的突触 —— 更剧烈的折叠（更大的 A、更小的 λ）没试过。

## 七、对路线图的意义

「物理 3 维嵌入」这个前提**已经落实**（这是本轮最重要的结构性改变，
修正了此前"1D 环"那种非物理的抽象）。

但**它没有带来能力差异** —— 与之前四次一致（准确率、记忆深度、AUC、τ）。
⇒ 下一步不该再在"接线怎么变"上找能力，该转向
**简并 / 抗损伤（M5 再生）** 与 **个体史（M7）** ——
那两个才是"内部量与物理布局"可能有后果的地方。
