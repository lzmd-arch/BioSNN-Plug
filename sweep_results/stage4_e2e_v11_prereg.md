# 预注册：阶段四端到端 v11——K=8 的容量/探针时间边界（2026-10-28）

**定稿时间：2026-10-28，在本轮任何数据之前。** v10 把共享状态 + 尺度门推到 s≥2、K≤4；
K=8 仍差 0.00025 到 WM R² 0.90，且 shrunk 覆盖率只有 0.7532。本预注册把 K=8 的两个可能
原因分开：**bank W 的读出时间**（t=125 衰减）还是**状态容量**（28 维/7 个 τ）。

## 结构（v10 的 bank W + 收缩协方差门）

- bank W 只收 A/B/Q；bank D 只收 K=8 键值 + 查询；拼接后状态控制；
- WM 读出/成员/世界模型/置信度只读 bank W；DPAR 每幕独立；
- 主门 = v10 的 shrunk Mahalanobis（lambda=0.1），阈值 calibration 20%；
- s=3、σ=0.3、K=8；5 个种子；train 2000 / calibration 500 / test 500 / OOD 500。

## 三臂（都跑，不做事后挑臂）

| 臂 | bank W | 目的 |
| :--- | :--- | :--- |
| **baseline** | 最终 t=125 的 28 维（7 τ） | v10 K8 的复现；已知 R² 0.89975、覆盖 0.7532 |
| **snapshot85** | t=85 的 28 维快照（A/B/Q 只到 t=85） | 检验“读出时间”假设：K8 的最终时刻太晚，还是容量不够 |
| **longtau** | 最终 t=125 的 32 维（7 τ + **τ=400**） | 检验“容量”假设：多一个慢 τ 能否把 R² 推过 0.90 |

三臂的 bank D 都是最终 t=125；DPAR 与状态控制共用。

## 判据（每臂 7 项，5 种子均值）

1. WM R² ≥0.90；
2. WM 选择性 MSE ≤0.10；
3. DPAR 最好臂 ≥0.80；
4. 状态控制 ≤1/8 + 0.10 = 0.225；
5. OOD AUROC ≥0.75；
6. OOD 弃权 ≥0.80；
7. test 覆盖率 0.78–0.82。

`arm_ready` = 七项全过。`v11_ready = snapshot85.ready or longtau.ready`（baseline 只作参照）。

**解释规则**：

- snapshot85 过 → K8 的边界是**读出时间**，不是状态容量；v10 的最终时刻选择需改；
- 只有 longtau 过 → 边界是**状态容量/慢 τ 不足**；
- 都不过 → K8 的容量边界保留；不调 R² 门槛/τ/窗口；
- 若两臂都过，报两者，不把其中一臂说成“必须”。

## 报告义务

- 三臂的 R²/MSE/覆盖率/弃权/AUROC/DPAR/状态控制全部单列；
- baseline 的 0.89975 / 0.7532 必须出现在表里，不能只报改善臂；
- 不把 snapshot85 的“只读 t=85”说成共享最终状态；它是 bank W 快照，DPAR 仍在 t=125；
- 不把 K8 的通过写成 K>8 的一般容量结论。

## 不做什么

- 不调 λ、τ 集合（longtau 只加一个固定 400）、窗口、阈值、覆盖率；
- 不在 test/OOD 上拟合均值/协方差；
- 不把 K=8 的容量结论外推到 K=16 或自然情景记忆。
