# 预注册：重学 3× v4——保留探索状态的实用重学（2026-10-29）

**性质：ADR-0019 允许的“实用重学”新主张，不是原 3× 改判。** 原 v1–v3 的结论原样保留；
本轮只测“warm 臂保留 Phase A 末尾的探索状态/采样尺度”是否让重学速度出现 3×。

## 协议

- 规则变化：CartPole 重力 **9.8 → 20.0**（v2 用过 20，但那是“重跑完整退火”的 warm；
  本轮 warm 的探索状态不同）；
- Phase A：R0 训练，800 回合；种子 **103–112**（从未用于调参/验收）；
- Phase B warm：保留完整 agent（Actor/Critic/基线），**保留 Phase A 末尾的探索状态**
  （`exploration=0.02`、`logit_scale=40`、Actor lr 不再从 0.3 退火；warm 臂的
  `actor_lr_final_fraction=1.0`）；在 R1 上继续 800 回合；
- Phase B scratch：同种子随机初始化，默认调度（0.3→0.02、logit 1→40），800 回合；
- 速度 = best-so-far 贪心评测首次 ≥ **200 步**所需回合数；比值 = scratch / warm。

## 判据（先写死）

1. Phase A 掌握：10 种子中位数 ≥200；
2. 非零样本：warm 初值 <200 的种子 ≥8/10；
3. scratch 可达：≥8/10 在 800 回合内达到 200；
4. 阈值非平凡：scratch 中位达标回合 ≥100；
5. **主判据**：配对速度比值中位数 ≥3，且 ≥8/10 个种子 warm 更快；
6. 末值不更差：warm 末两点评测 ≥ scratch −10；
7. 六条全过 → `relearn_3x_v4_ready=true`；否则报边界，不调阈值/种子/预算/探索参数。

## 与 v3 的区别

- 阈值从 150 → **200**（v1 的 150 被旧策略初值满足，不是重学）；
- warm 不再重跑完整退火，保留末尾探索状态/采样尺度；
- 重力 20（v2 用过，但 v2 的 warm 是完整退火重跑）。

## 不做什么

- 不改环境/算法/种子/阈值/预算/探索参数；
- 不把“实用重学”与原始 3× 混报；原 3× 仍是未达开放项；
- 不拿单个种子的大比值当证据。
