# 预注册 v3：计数同向资格（count-aligned eligibility）（2026-10-26）

**定稿时间：2026-10-26，在本诊断的任何数据之前。** D1/D2 的结论：把资格换成速率形状的
`x·a` 不变好（62.15 < 75.65），而把策略换成线性 Boltzmann 配方后同一 harness 到 179.80
（10/10 配对变好）→ **环境/循环/Critic 正常，瓶颈在"脉冲计数选动作"这条策略路径**；
资格痕迹必须和策略的得分函数同构。

## 机制：把第二因子改成计数策略的得分函数

一个决策窗口里：

```text
x_i = Σ_t pre_spikes[t, i]           # 输入侧计数，长度 n_features
z_a = Σ_t post_spikes[t, a]          # LIF 发放计数，长度 n_actions
π = softmax(sampling_scale · z)      # 与 Actor 实际采样分布同一个 π
factor_a = z_a · (1[a] − π_a)        # 计数加权的得分函数项
E ← λ_E · E + x ⊗ factor             # E 形状 (n_features, n_actions)
w ← w + η · δ_t · E                  # δ_t 来自同一群体 Critic；随后列归一化
```

**这就是"资格 = E[z] · (1[a] − π_count)"的形状展开**：`z` 是 LIF 计数，`(1[a] − π)`
是计数策略的得分函数，外积的输入侧用**输入脉冲计数** `x`（不是连续特征）。
`z_a` 是"该动作实际发放了多少"的局部代理：`∂z_a/∂w_{i,a}` 的 Hebbian 近似就是
`pre_i · z_a`，所以这条规则是计数策略梯度的局部近似，而不是把速率版的 `x·a` 换个名字。

与 D1 的差别只有两处，且都属于"同向"：

| 项 | D1 rate-features | 本机制 |
| :--- | :--- | :--- |
| 输入侧 | 连续特征 `x` | **输入脉冲计数** `x` |
| 动作因子 | `1[a]`（不比较动作） | **`z ⊙ (1[a] − π)`**（计数加权、动作比较） |

## 配置（写死）

默认群体 Critic：800 回合、Actor lr 1e-3、critic_rate 0.1、gradient/均匀/归一化、
units 64、bias 0.4、gain 8、warmup 10；seeds 0–9；CPU（与记录臂一致）。
**不调 lr、宽度、回合数、Critic、退火。**

## 判据（先写死）

对照是**已跑的同配置 D1**（中位数 62.15，逐种子见
[`rstdp_spiking_credit_diagnosis/rate_features/summary.json`](rstdp_spiking_credit_diagnosis/rate_features/summary.json)）：

1. **机制标记**：配对差值中位数 **≥ +20 步** 且 **≥7/10** 个种子更好；
2. **可学信号**：10 种子中位数 **≥ 150 步**（先过诊断线；200 的验收线不在本轮）；
3. 同时报相对 sign-consistent（75.65）与 D2（179.80）的配对、中位数与区间。

## 判读表（先写死）

| 判据 1 | 判据 2 | 结论 |
| :--- | :--- | :--- |
| 过 | 过 | **"同向 > 不同向"成立**；下一步按验收口径跑 10 种子 + 最终权重，再谈 200 / 偏移 |
| 过 | 不过 | 方向对但幅度不足；不调 lr，先查 δ 的尺度与回合预算，另写预注册 |
| 不过 | 不过 | **对齐不是充分条件**；下一嫌疑是计数策略本身的表达力（单层 LIF 计数）或信号尺度 |
| 不过 | 过 | 中位数跃升但种子不一致：报分布，不宣称机制；先复跑确认 |

## 限制（必须在结论里原样写）

- **配方级**，不是单变量消融：它同时换了输入侧（连续 → 计数）与动作因子（指示 → 计数加权
  中心化）。本预注册只声称"同向 > 不同向"，**不声称**哪一件单独起作用；
- D2 仍然是 sanity control，不是候选最终形态；本机制才是脉冲侧候选；
- 不与 D2 的 179.80 直接比"谁更好"——两者差的不只是资格，还有策略与退火。

## 守卫（代码级，先于数据）

- 20 组窗口：正 S 下被选动作列的增量和 **> 0**，未选动作列 **< 0**（计数加权中心化会
  主动削弱未选动作）；负 S 下方向相反；
- 计数为 0 的**空窗口**（`z` 全零）没有资格可写，记 `vacuous` 并从分母剔除（同 A1′ 修订）；
- 默认 `pair-stdp` 路径逐位不变（同种子对照 `git show HEAD:`）。

## 不做什么

- 不调 lr、宽度、回合数、Critic、warmup；
- 不把 π 的温度换成新超参数——用 Actor 的实际 `sampling_scale`；
- 不混报 CPU / CUDA；
- 不把本轮的中位数当验收；验收仍是最终权重 + 10 种子 + 200 步 / 偏移。
