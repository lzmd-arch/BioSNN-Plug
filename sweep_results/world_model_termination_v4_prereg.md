# 预注册：P3 终止头 v4——开环边界误报率（2026-10-28）

**定稿时间：2026-10-28，在本轮任何 v4 数据之前。** v3 的开环结果在主指标上过线
（AUROC≈1.0、终止率 1.0、终止步误差 0.003），但预注册第 4 条“所有非终止步 margin<1”
被极少数模型误差步打破（最大 1.0033），`p3_v3_ready=false`。v4 **不改 v3 的判定**，
只把分离检查从全或无改成两个预先声明的率，并用**新种子 10–14**：

- **边界误报率** = 非终止步中 margin>1 的比例；
- **真终止命中率** = 终止步中 margin≥1 的比例。

全或无的“最大值 <1”对单步模型误差过于脆弱；率判据仍要求 99.9% 的非终止步不误报，
不是放宽到“差不多”。

## 机制（与 v3 相同）

```text
训练：RidgeActionModel(quadratic=True)，200 回合真实转移
测试：固定随机动作序列（模型/环境共用），从真实初始状态开环
分数：margin = max(|x'|/2.4, |θ'|/0.2095)
标签：真实环境同一步的 terminated
```

## 判据（先写死）

1. 开环终止 AUROC ≥0.75；
2. 终止回合率 ≥1%；
3. 终止步一步状态误差中位数 ≤0.01；
4. **边界误报率 ≤1e-3**（非终止步 margin>1 的比例）；
5. **真终止命中率 ≥0.99**（终止步 margin≥1 的比例）；
6. 五条全过 → `p3_v4_ready=true`；否则报边界，不调动作分布/视界/阈值/判据。

## 边界（预先写死）

- v4 仍是**固定动作序列的开环想象**，不是闭环反馈；v3 的闭环对照 0.634 与 v2 的
  0.6469 仍是开放边界，不混报。
- 终止界用 CartPole 已知界；这不是纯学习头，也不是时间特征。
- v4 的率判据是在 v3 失败后新增的；v3 的 `p3_v3_ready=false` 原样保留，不改判。

## 不做什么

- 不调状态模型/λ/特征/动作分布/最大步数/判据；
- 不用 v3 的种子重跑；v4 用 10–14；
- 不把开环结果写成闭环终止能力。
