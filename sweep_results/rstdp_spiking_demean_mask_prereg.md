# 预注册：两条不引入全局统计量的反同质化改法

**定稿时间：2026-10-17。网格与判据先于其结果。**

## 背景（已实测）

群体 Critic 训练 800 回合后：单元间余弦 **+0.823**、有效秩 **0.025**、平均活动 0.003，
`V` 几乎全由 `out_bias` 承担。单元级稳态把活动拉回 0.089、最差种子抬到 52.4，
但**同质化没被打破**（余弦 +0.778、有效秩 0.024）。

机制推断：痕迹 `e_j = y_j(1−y_j)·x` 恒非负（`x ≥ 0`、`σ' > 0`），读出一律为正，
于是每个单元的权重都被推向**同一个非负方向**的叠加。

## 两条改法（都不引入全局统计量）

| 改法 | 形式 | 局部性 |
| :--- | :--- | :--- |
| **A. 每单元痕迹去均值** | `μ_j ← (1−κ)μ_j + κ·e_j`；更新用 `e_j − μ_j` | `μ_j` 只用**该单元自己的**痕迹历史 |
| **B. 固定输入子空间** | 每个单元一个固定随机掩码 `m_j`（密度 `p`），`w_j ⊙ m_j` 始终成立 | 结构约束，像固定连接概率；**不涉及任何学习信号** |

⚠️ **A 的已知局限**：如果各单元的直流分量同号，减去各自的均值**不一定**打断共模推力。
这一点必须在结果里对账，不能拿"减了均值"当已经处理。

⚠️ **B 的边界**：掩码把每个单元限制在随机特征子集上，不同单元从一开始就不在同一子空间。
但子集内仍可能趋同——所以 B 单独也可能不够。

## 网格

| 变体 | 参数 |
| :--- | :--- |
| 基线 | 无（对照：`pop_opg16` 的 64.8） |
| A | `κ = 0.01` |
| B | `p = 0.5` |
| B | `p = 0.25` |
| A + B | `κ = 0.01, p = 0.5` |

其余全部固定：`bias=0, gain=16, gradient, normalize=False, 均匀读出, 无稳态`。

**筛选口径**：单种子 **800 回合**（不是 300——上一轮的教训：300 回合判不了会随时间退化的配置）。
确认：最优配置 5 种子 × 800 回合。

## 判据

主要判据是**机制**，其次才是分数：

1. 用 `diagnose_homogenisation.py` 量训练后的单元间余弦与有效秩——**低于 +0.78 / 高于 0.024**
   才算"同质化被削弱"；
2. `V` 的动态范围显著宽于 `[14.4, 17.6]` 且**不撞** `value_scale=200` 的天花板；
3. 分数超过 69.4（当前最好）；
4. 若机制指标改善而分数不改善，如实报"同质化不是唯一原因"；
   若分数改善而机制指标不动，如实报"这个解释错了"。

## 边界情况

* A 的 `κ` 太大会把痕迹本身也抹掉（`e − μ ≈ 0`），训练会停摆——表现为分数掉到随机水平，
  如实记为该配置失败。
* B 的掩码密度太低（如 0.1）会让每个单元只有 6 个输入，表达力不足；本轮最低取 0.25。
* 掩码固定（不训练），种子进配置，符合 ADR-0012 的"固定随机投影"取舍。
