# 预注册：情景记忆 v4——延迟配对联想回忆（DPAR）（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v0–v3 的情景任务是“从最终状态里读回
最近的事件”，E 又是分离良好的 4-bit 码，检索接近管道。本任务换成**真正需要把两个事件
绑定起来**的延迟配对联想：先看 K 对“键→值”，延迟后只给一个键，回忆它当时配对的值。
最终工作记忆状态是各线索的线性叠加，**线性读出无法按查询键选中对应值**；这是本任务的
有效性前提，不是性能判据。

## 任务

```text
每幕：K 对 (k_i, v_i)，k_i / v_i ~ N(0, I_4) 独立采样
时间线：第 i 对在 [10i, 10i+4] 给 k_i，[10i+5, 10i+9] 给 v_i
        全部结束后，[10K, 10K+4] 给查询键 k_q（q 从 0..K-1 均匀抽）
        test_step = 10K + 5，最终状态 28 维（TAUS × 4）
查询噪声：k_q + N(0, σ² I_4)
回答：从 K 个值里选 top-1（chance = 1/K），另报回忆 MSE
```

## 记忆臂（每幕独立建库，幕间不共享）

| 臂 | 键 | 读出 | 性质 |
| :--- | :--- | :--- | :--- |
| Hebbian | `SparseEncoder(dim=512, k=32)` 的 ±1 稀疏码 | `M = Σ v_i k_iᵀ`，`r = q M` | 局部外积 |
| Pseudo-inverse | 同上 | `V K⁺` | **非局部**上限对照 |
| Raw NN | 同上 | 最近邻键 → 值 | 字面查表基线 |
| 状态控制 | 最终 28 维状态 | RLS 读出到 `v_q` | **有效性检查**：应接近 chance |

状态控制用 2000 幕训练、500 幕测试；记忆臂不需要训练，在同样的 500 幕测试集上评估。
5 个种子。

## 档位

| 档 | 取值 |
| :--- | :--- |
| **主档（判据落点）** | **K=8、σ=0.1** |
| 容量曲线 | K=2/4/8/16/32（σ=0.1） |
| 噪声曲线 | σ=0/0.1/0.3（K=8） |
| 状态控制 | 只在主档跑 |

## 判据（先写死）

主档 K=8、σ=0.1，5 种子均值：

1. **最好联想臂**（Hebbian / Pseudo-inverse 取高者）top-1 **≥0.80**（chance 0.125）；
2. 同一臂在 K=4 的 top-1 **≥0.90**（容量 sanity）；
3. **状态控制 top-1 ≤0.25**（≤2× chance；否则任务不是“必须记忆”，判据作废并报设计问题）；
4. 三条全过 → `paired_associate_ready=true`；否则报边界，不调阈值、不改档位。

**报告义务**：

- Hebbian / Pseudo-inverse / Raw NN 三臂分开报，不能让 Pseudo-inverse 的高分掩盖 Hebbian
  的失败；若只有 Pseudo-inverse 过线，明确写“可用但非局部”。
- 容量曲线报每个 K 的 top-1，并指出最好联想臂首次跌破 0.80 的位置；不因为它不在主档就隐藏。
- 噪声曲线报 σ=0/0.1/0.3，不做事后挑点。

## 不做什么

- 不调 dim/k/σ/K/阈值/读出；不为过线换编码；
- 不在测试幕上拟合任何记忆参数（Pseudo-inverse 只在每幕的键值对上求解，这是任务本身）；
- 不把本任务说成自然情景记忆：键和值仍是合成随机向量；
- 不把“Pseudo-inverse 过线”说成“局部联想可用”。
