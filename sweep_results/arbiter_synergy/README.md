## 但这份结果只能支撑一半的结论

### 一、在这套配置下，**仲裁器的效果不可测量**

MIX（ES 学 α）与 MIX_frozen（α 冻结 0.5）**逐位相同**：`Fisher` 到小数点后四位一致，
`‖ΔW‖/‖W‖` 一致，α 精确等于 `0.5`，五个种子无一例外。

原因是 ES 的目标函数是**整数冲突事件数**：σ=0.1 的扰动常常不改变这个整数，
于是"候选不比当前更好"，α 一次都没动过。**这不是"学出来 0.5 恰好最优"，是"根本没动"。**

所以能说的是：**把两条规则按 50/50 混起来，表示的可分性明显优于任一单独使用**；
不能说的是：**仲裁器学会了怎么混**。

### 二、打乱标签对照**整组作废**

五个种子的 ‖ΔW‖/‖W‖ 都低于门禁（0.023–0.034），按预注册不进统计。
观察到的方向（不作结论）：Fisher ≈ 0.0001–0.0003，权重几乎不动——
**标签一旦被打乱，这两条规则就没有可学的东西了**，与"混合在用标签"一致。

### 三、E 臂有一个种子作废

seed 3 的 ‖ΔW‖/‖W‖ = 0.0474，压在 0.05 的门槛下。协同量因此只在四个种子上成对计算——
报告里必须写出这一点，否则"5 个种子"会变成没发生过的事。

## 这份结果**不**声称什么

* 不声称仲裁器有价值；**也同样不声称它没有价值**——它在本基准里是**未被检验**，而不是被证伪（见下节的目标函数检验）；
* 不声称"单方失败"——H 单独就把 Fisher 从 0.309 抬到 0.472，这条原判据在 2026-10-18 就已被实测否掉；
* 不声称能推广到别的任务、别的形状或别的标签比例——本轮只跑 1% 标签、固定随机置换。

## 目标函数的修复尝试（2026-10-24）：两个候选都没过检验

预注册见任务规格 §预注册；实测表在那一节里。一句话结论：

* **Fisher 当目标**：几百步的探针里 Fisher 对 α 没有区分度（极差 0.03 且不随步数增长），
  而要让它有区分度就得跑接近一整轮训练 → 32 次评估约 7 小时，超预算 15 倍。
* **连续代理**（两臂余弦的均值）：峰在 α = 0.9，且在 α = 0 与 α = 1 上给出**同一个值**——
  而这两个端点的 Fisher 差 0.14。它在最需要分辨的地方没有分辨力。

**因此没有跑自适应臂。** 准确的说法是：**自适应仲裁在本基准中不可测量**——在预算约束内（单次 ≤ 5%、总 ≤ 2×）不存在通过预检验的目标函数；唯一已知有效的目标（全程探针）标价为 **约 7 小时**，留作 future work。

⚠️ 这个区别是实质性的：**仲裁器是「未被检验」，不是「被证伪」**。它没跑出意义 ≠ 它没有意义；静态 0.5 的胜出只说明「在这个基准上，没人能用便宜的方法打败它」。
