`input_norm = max(||A||_2, ||B||_2)`，只用 calibration 拟合均值/方差、20% 分位阈值；

## 结论

**18/18 格 ready，`v16_ready=true`。** 这是 E2E 全矩阵第一次全部过线，但门是**输入级
尺度门**，不是状态级元认知。

## 与 v14/v15 的关系

| 版本 | 门 | 18 格 |
| :--- | :--- | :--- |
| v14 | 状态级（K4 shrunk / K8 diag） | 14/18；s=2 四格失败 |
| v15 | 换臂（longtau/snapshot85） | 0/4 补格失败 |
| **v16** | **输入级 input_norm** | **18/18** |

v16 不是 v14 的“调阈值”：它换了特征族，直接测量 A/B 线索的 L2 尺度。s=2 的弱偏移在
状态摘要里不够显眼，但在输入范数上很干净。

## 边界（必须保留）

1. **这是输入级尺度门**：`input_norm` 直接测输入幅度；不证明状态级元认知能检测 s=2，
   也不改变 v14 的 14/18 状态级结论。
2. **只对尺度 OOD 成立**：s=2/3/5；不覆盖信息丢失型 OOD（v6/v7 的 AUROC≈0.50 边界不变）。
3. 状态控制现在用 test[8] 的 pairs（修复了先前 test[7] 的索引 bug）；修复后 state 0.12–0.25，
   不是 0.0。
4. 18 格 ×5 种子；单次运行 1169.1 s；没有调 s/σ/K/阈值/覆盖率。
5. 不写成阶段四整体验收；P3、脉冲 WM、局部情景仍另行评估。

## 下一步

- 若接受输入级门，E2E 矩阵可算完整；若坚持状态级门，s=2 仍是边界；
- 剩余组件：P3 终止（v2 0.6469）、脉冲 WM v6、通用 OOD、局部情景记忆。
