## 这条结果里值得单独说的

1. **线性模型没有像预期那样失败。** 预注册写着"`ridge_action` 很可能过不了 NMSE"——它过了：
   0.107 vs copy 0.267。Acrobot 的一步动力学在随机策略访问到的分布上，被 `[s, a, a·s]` 抓到了
   相当一部分；二次项只把 0.107 压到 0.095。**非线性是真的**（绝对 NMSE 0.095 比 CartPole 的
   3×10⁻⁹ 高十个数量级），但它体现为"误差更大"，不是"打不过基线"。
2. **终止事件不可评是行为策略的问题，不是模型的。** 随机动作几乎不可能把 Acrobot 摆上去；
   终止率 0–0.0001 意味着测试集里没有足够的正例。预注册已经写死这一情形记 `not_evaluable`，
   所以本轮不拿它判失败，也不为了凑事件换策略。
3. **动作敏感度 0.102** 是三个动作两两配对后的均值，不能与 CartPole 的 0.512 直接比——
   量纲与动作集都不同；它只回答"动作有没有被用上"。

## 这**不**说明什么

- 不说明"世界模型在非线性环境上可用"：只测了一步，没有 rollout、没有规划；
- 不说明终止预测不可能：换一个能到达目标的策略才能测；
- 不改阶段四入口。
