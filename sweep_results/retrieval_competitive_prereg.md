# 预注册：跨模态检索第七轮——竞争联想记忆（赢者通吃，纯局部）

**定稿时间：2026-10-17，在这一轮的任何数据之前。**

## 它要回答什么

第六轮的结论是否定的：**固定随机特征没有帮上忙**（0.383，低于纯 delta 的 0.393）。
而 kNN 能到 0.555。两者的差别不在"非线性"，在**按实例局部投票**：kNN 不和全局线性映射
较劲，它找"最像的训练样本"，把它们的图像码投出来。

这一轮把这个机制做成**真正的学习规则**：竞争联想记忆（赢者通吃）。项目架构里本来就有
这一层（计划书 §2.2「情景记忆：基于模式分离的正交类中心存储」），这里第一次把它用于跨模态。

## 规则（纯局部，无梯度）

```text
M 个记忆单元，每个持有 (p_j 文本原型, q_j 图像码)，初始为随机噪声
对每个训练对 (t, v):
    j* = argmax_j cos(p_j, t)                 # 赢者通吃
    p_j* ← p_j* + η·(t − p_j*)                # 只有赢家动
    q_j* ← q_j* + η·(v − q_j*)
查询 t → 取 top-k 单元的 q_j 按相似度加权平均
```

**每个单元的更新只用到它自己的原型和它收到的输入**——没有梯度、没有反向传播、没有全局
误差反传。k 是读出时的投票数，不是训练迭代数。

⚠️ **它是不是"记住训练集"？** 不完全是：M 个单元是对**联合空间**的量化，单元数与训练
样本数无关，同一单元会被多个样本共享、被后来的样本改写。但 M 若接近训练样本数，它确实
退化成"存起来"——**这一点要在结果里如实报告，不能拿它冒充泛化**。

## 设计

| 维度 | 取值 |
| :--- | :--- |
| 单元数 M | {16, 32, 64}，训练集 5 折交叉验证选 |
| 训练轮数 | {20, 100}（同一批样本反复经过，让单元收敛） |
| η | {0.05, 0.2} |
| 读出 k | {1, 3} |
| 表示 | `bus@256` 与 `plugin` 两档 |
| 种子 | 0–4 |

## 判据

* 选定配置测试 R@1 ≥ 0.50 → 达成，**但要附一句"单元数与训练样本数之比"**，让读者判断
  它是学习还是记忆；
* 若仍 < 0.50 → 说明"实例局部性"也救不了这套编码，回到改编码那条路。

## 边界情况

* 竞争规则的顺序依赖性：同一批样本换个顺序会让单元落到不同位置。种子固定 → 顺序固定 →
  可复现；但这也意味着**结果对样本顺序敏感**，要报种子间的范围，不只报均值。
* 与 kNN 的对照要写清：kNN 没有学习、没有 M；这里是 M 个单元被学出来。
