# Axo 真脉冲原型第三轮：噪声、流式整合、候选延迟（结果）

预注册：[`axo_spiking_noise_prereg.md`](axo_spiking_noise_prereg.md)。
前两轮：[`axo_spiking_prototype_results.md`](axo_spiking_prototype_results.md)、
[`axo_spiking_sparse_results.md`](axo_spiking_sparse_results.md)。

## 一句话

**脉冲的非线性在噪声与流式整合上都没有赢过线性泄漏积分器；但为了 5 万条做的倒排
候选子集把单次查询从 160.7 ms 压到了 48.3 ms，而且 top-1 与全量扫描一致——这是
本轮唯一真正可用的工程结果，它属于速率路径，不属于脉冲。**

## 1. 噪声下的重复呈现（T=5）

同一探针重复 5 次，每次加不同的确定性位噪声；α=0.95。

| 噪声比例 | rate-once | rate-integ | 脉冲 LIF | 脉冲 ALIF |
| ---: | ---: | ---: | ---: | ---: |
| 0.00 | **0.9268** | **0.9268** | 0.8354 | 0.8293 |
| 0.05 | **0.9268** | **0.9268** | 0.8354 | 0.8293 |
| 0.10 | **0.9268** | **0.9268** | 0.8415 | 0.8293 |
| 0.20 | **0.9207** | **0.9207** | 0.8354 | 0.8232 |

- 脉冲每一档都低约 **8.5–9.7 pp**；没有任何一档达到 `> rate-integ + 5 pp`。
- **这个噪声任务本身不够有区分度**：位级噪声（最多 12 个额外位、权重 0.5）几乎
  没让线性臂掉下来。也就是说，结论只能写“在这个噪声水平下脉冲没有增益”，
  不能写“脉冲在任何噪声下都没有增益”。
- 线性积分与只跑一次完全同分：重复呈现的噪声被线性平均掉了，没有给脉冲留下
  非线性发挥的空间。

## 2. 流式分片整合（T=5）

50% 丢位探针的活跃位确定性切成 5 片，每步只给一片。

| 臂 | top-1 | 说明 |
| :--- | ---: | :--- |
| `rate-full` | **0.9085** | 完整探针一次给（上界） |
| `rate-integ` | **0.9085** | 线性泄漏积分器 5 步；与完整探针同分 |
| `rate-first` | 0.8110 | 只给第一片（下界） |
| 脉冲 LIF | 0.7439 | 低于第一片基线 |
| 脉冲 ALIF | 0.6463 | 更低 |

**线性积分器把 5 片完美合成完整探针（0.9085）；脉冲反而比“只给第一片”更差。**
按预注册，脉冲在这里是“输”，且输给的是同时间常数、同步数的线性积分器，不是
弱基线。

## 3. 候选子集延迟（50,000 条合成码）

倒排索引 `bit → rows`（CSR）；查询取探针 64 个位的倒排表，合并计数取前 2,000 个
候选，只对候选跑稀疏 rate 一步。

| 项 | 实测 |
| :--- | ---: |
| 建索引 | 1.14 s |
| 单次查询（候选 2,000） | **48.32 ms** |
| 全量稀疏扫描（第二轮） | 160.73 ms |
| 候选数与全量 top-1 | **一致**（同一个探针） |
| 稀疏存储（50k） | 25.6 MB |
| 稠密存储（50k） | 819.2 MB（未分配） |

- 48.3 ms 低于预注册的 100 ms 线；候选子集把查询压到原来的约 30%。
- **只测了一个合成探针**；“top-1 一致”不是普遍保证，需要更多探针/真实码复测。
- 这个优化属于**速率路径**：它先把候选缩小，再算原有的一步 W；脉冲没有参与，
  也不需要参与。

## 4. 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 噪声：任一档 `spiking > rate-integ + 0.05` | 最好仍低 8.5 pp | **没有** |
| 流式：任一档 `spiking > rate-integ + 0.05` | 低 16.5 pp | **没有** |
| 5 万条查询 ≤ 100 ms | 48.3 ms | **通过** |
| 候选子集 top-1 与全量一致 | 1 个探针一致 | **初步通过，样本太小** |

## 5. 结论

1. **真脉冲的阈值/适应非线性，在本轮的噪声与流式任务上没有增益。** 线性泄漏积分器
   是同预算下更强的对照；脉冲在最需要“整合”的任务上反而更差。
2. **倒排候选子集是真正有价值的工程结果**，但它属于 Axo 的速率召回路径：50k 从
   160.7 ms 到 48.3 ms，存储 25.6 MB。下一步应该在速率路径上把它做扎实（更多探针、
   真实码、候选上限调参），而不是继续把脉冲往 Axo 里塞。
3. 若还要继续脉冲研究，需要一个**线性积分器结构上做不到**的任务（例如真正的
   重合检测、变长延迟、非可加证据），而不是“重复呈现 + 位噪声”这种线性平均就能
   解决的任务。

## 6. 边界

1. 166 条真实记忆；50k 是合成码，不是真实 5 万条。
2. 位级噪声不等于自然语言/真实传感器噪声；噪声档没有让线性基线明显下降。
3. 流式分片是人为切分，不是真实的时间流。
4. 墙钟时间不能论证神经形态能效。
