# 情景记忆 v1：局部吸引子 + 独立时间戳（2026-10-26）

**预注册：** [`../episodic_memory_v1_prereg.md`](../episodic_memory_v1_prereg.md)。
200 回合池、终止事件分层、σ=0.1、N=100–2000、5 种子；动作/终止 4 维值 + 独立时间标量；
吸引子 3 步 top-k；伪逆与字面 NN 单列。干净工作区 commit `947714a`。

| :--- | ---: | ---: | ---: | ---: | ---: | :--- |

预注册要求：动作 500 ≥0.70、终止平衡/TPR ≥0.70、时间顺序 ≥0.75、动作 1000 ≥0.65；
**one-shot 与 attractor 都没有 ready**；`v1_ready=false`。

## 读数：瓶颈在**编码**，不是读出

- **吸引子更差**：3 步 top-k 迭代把动作从 0.646 降到 0.619、时间顺序从 0.522 降到 0.463——
  在 N≫D 的情况下，符号迭代把稀疏键进一步压扁，而不是降噪；
- **伪逆上限也不够**：即使非局部的闭式 `V K⁺` 也只有动作 0.629、终止 0.559、顺序 0.531；
  它拟合的是**干净键**，查询是噪声键，编码本身已经把类别信息丢了；
- **字面 NN 仍然全面最好**（0.762 / 0.962 / 0.582）：数据里有信息，top-k 符号投影
  （D=512, k=32）在 σ=0.1 下损失太大；
- 独立时间戳通道只把顺序从 v0 的 0.509 抬到 0.522，仍远低于 0.75；时间戳不是唯一问题。

## 结论

**v1 不 ready。** 按预注册不调 D/k/σ/步数/阈值；v2 若要继续，必须重做**编码器**
（更密的码、D 更大、正交化/纠错码，或直接用状态索引作局部读出的键），而不是继续在
读出上迭代。当前证据支持"**朴素稀疏键联想记忆在这个规模/噪声下不可用**"这一边界。
