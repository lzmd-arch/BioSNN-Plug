# 线 A v6：读出衰减对照——"增益 ∝ 看不见的比例"被推翻（A6）

**日期**：2026-11-04
**预注册**：[`research/brainregions/prereg-a6-decay-control.md`](../../research/brainregions/prereg-a6-decay-control.md)
**原始数据**：[`a6.json`](a6.json)

## 一句话

**把读出窗口从 20 步拉到 100 步（decay 0.95 → 0.99），单抽头只从 0.338 涨到 0.425，
多抽头的增益只从 +42.1pp 降到 +28.5pp——没降到我写死的一半以内。K-1 不过。**

## 结果

| decay_out | taps=1 | taps=28 | 增益 |
| ---: | ---: | ---: | ---: |
| 0.95（有效窗口约 20 步） | 0.338 | 0.759 | **+42.1pp** |
| **0.99（有效窗口约 100 步）** | **0.425** | **0.710** | **+28.5pp** |

## 判据

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |
| K-0 | 两臂都学到 | 都 >0.20 | 0.425 / 0.710 | ✅ |
| K-1 | 增益至少减半 | < 21.05pp | **+28.5pp** | ❌ |
| K-2 | 仍为正 | >0 | +28.5pp | ✅ |

## 我的两条预期都偏了，而且偏的方向有意义

预注册写的：`acc(0.99,1)` 落在 **0.55–0.70**、`acc(0.99,28)` 落在 **0.72–0.80**。

| 臂 | 我押的 | 实测 | |
| :--- | :--- | ---: | :--- |
| 0.99 / taps=1 | 0.55–0.70 | **0.425** | 低出区间 |
| 0.99 / taps=28 | 0.72–0.80 | 0.710 | 略低 |

**第一条最要紧**：窗口拉长 5 倍，单抽头只多了 **+8.7pp**（0.338 → 0.425）。
如果"最后一步看不见那么多时间"是主因，5 倍的窗口不该只买回这么点。

## 推翻的解释，和换上的解释

**被推翻的**（A5 里我写下的、明确标了"只有两个点、不算定律"的那条）：

> 多抽头增益 ∝ 最后一步看不见的比例。

现在有了第三个点（decay 0.99：看不见 0%，增益仍有 28.5pp），**这条不成立。**

**换上的解释：限制不是"看见多久"，是"每个神经元给出几个数"。**

关键在于 `decay_out` 决定的是**滤波窗口**，`k` 决定的是**在这个窗口里取几个值**：

- 把 `k` 从 1 加到 28，**窗口一点没变**（还是 20 步），变的是"这 20 步被压成 1 个数还是 28 个数"；
- 把 `decay_out` 从 0.95 加到 0.99，**窗口变长了，但每个神经元仍然只有 1 个数**——
  一条轨迹被压成一个标量，再长的窗口也救不回来。

**A3 自己的阶梯就在支持这一条**：sMNIST 上 `k = 1 / 7 / 28` 是 0.759 / 0.895 / 0.917——
**从 1 到 7 就拿到了 15.8pp 里的 13.6pp（86%）**，而从 7 到 28 只多 2.2pp。
如果是"覆盖时间"的问题，7 个抽头（窗口仍是 20 步）不该比 1 个抽头多这么多。

**所以正确的说法是**：

> 最后一步读出把每个神经元一段窗口内的活动压成**一个标量**；
> 多抽头给的是**每个神经元多个数**。sMNIST 的那段窗口恰好信息冗余（同一张静态图按行喂），
> 压成一个数损失小；SHD 的窗口信息密度高，压成一个数损失就大得多（+42.1pp）。

## 这个结果的分量

- **A5 的 +42.1pp 依然成立**（那是实测），但它背后的解释换了；
- **A6 顺带给了一条独立证据**：decay 0.99 + taps=28（0.710）**低于** decay 0.95 + taps=28（0.759）——
  窗口拉长反而略**降**，因为 0.99 的滤波把相邻抽头抹得几乎一样，**28 个抽头变得冗余**。
  这只有"抽头靠窗口形状区分"时才会发生，与"每个神经元多个数"的解释一致。

## 边界

- 单种子；只测 SHD、只测这一个衰减值（0.95 / 0.99），没有中间档；
- `decay_out` 只影响读出的 `exp_convolve`，不影响 e-prop 的资格痕迹（用 `alpha=exp(−1/tau)`）——
  写预注册时核对过代码；
- 改变 `decay_out` 也改变了读出特征的**尺度**，所以严格说是"读出的时间常数"变了，不只是"窗口长度"；
- **"每个神经元多个数"这个解释是新提出的，还没有直接检验过**。可检验的预测：
  在 decay 0.99 下扫 `k`（1 / 7 / 28），若增益主要发生在 1→7，解释就得到支持。
