## 这意味着什么

"融合需要差集"这句话现在有了具体内容：**时间不是那个差集**。

要让它成立，需要的是一条**与文本内容相关**的独占输入，候选只有：

1. **环境/气体传感器**（合作方插件在仓外，专有）——需要与文本成对记录；
2. **用户行为**（打字节奏、停顿、编辑动作）——与"正在写什么"相关，需要客户端埋点；
3. **设备模态**（手机光照/运动、屏幕内容）——Axo Android 已有部分传感器。

**三者今天都没有与文本配对的数据。** 缺的不是模型，是记录管道。
