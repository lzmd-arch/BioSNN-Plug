# 预注册：阶段四端到端 v6——单 bank vs 路由双 bank 的共存（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v4 把 DPAR 与 WM 写进同一个 28 维状态，
WM 被键值对污染（B R² 0.513、MSE 0.351）；v5 改成两段式后 6/6，但那只是顺序组合。
本预注册检验：**在同一个最终时刻、同一套读出下，把输入路由到两个 bank 是否能解决共存
干扰**。两臂都跑，不做事后挑臂。

## 任务

与 v4 相同：A/B/Q（σ=0.3）+ K=4 对键值 + 查询键；test_step=85；OOD 为 A/B ×3；
DPAR 查询键加 σ=0.1；train 2000 / calibration 500 / test 500 / OOD 500；5 个种子。

## 两臂

| 臂 | 状态 | 说明 |
| :--- | :--- | :--- |
| **S：单 bank** | 28 维，A/B/Q + 4 对键值 + 查询全部进入同一时间线 | v4 的结构；用一致判据重跑，作为共存基线下界 |
| **D：路由双 bank** | 两个 28 维 bank 拼接为 56 维：**bank W 只收 A/B/Q**，**bank D 只收键值对 + 查询** | 最终时刻仍是 t=85；两个 bank 共享读出接口，但输入路由互不污染 |

两臂都用：WM 局部 RLS 读出（δ=1000）+ 5 成员；ridge 世界模型（前一步→当前）；
DPAR 每幕独立 `SparseEncoder` 记忆（Pseudo / Raw NN / Hebbian 分开报）；状态控制 =
最终状态线性读出 `value_q`。阈值只在 calibration 上取。

## 判据（每臂分别，5 种子均值）

1. WM A/B/Q 平均 R² **≥0.90**；
2. WM 选择性 MSE **≤0.10**；
3. DPAR 最好臂 top-1 **≥0.80**；
4. 状态控制 top-1 **≤0.35**（chance 0.25）；
5. OOD AUROC **≥0.75**；
6. OOD 弃权 **≥0.80**；
7. 每臂六条全过 → 该臂 `ready=true`；分别记 `e2e_v6_single_ready` / `e2e_v6_dual_ready`。

**解释规则**：

- S 不过、D 过 → 共存需要**路由分离**；这是结构性结论，不是调参；
- S 过、D 过 → 单 bank 也能共存；v4 的失败是判据/训练问题，不是表示叠加；
- 两臂都不过 → 共存仍未解决；不因为 D 结构更复杂就追认；
- 两臂都过但 D 更好 → 报两者，不把 D 说成“必须”。

## 报告义务

- S/D 两臂的 WM R²/MSE、DPAR 三臂、状态控制、OOD 全部单列；
- 不把 bank 路由说成“学习规则”；它是**状态编码结构**；
- DPAR 仍是每幕独立建库，不是终身情景记忆；OOD 仍是尺度偏移；
- 不把任一臂的 ready 写成阶段四整体验收。

## 不做什么

- 不调 K、时间窗、σ、bank 维度、阈值、覆盖率；
- 不在 OOD 上拟合均值/协方差/阈值；
- 不把 v5 的顺序组合结果混进 v6 的共存结论。
