# CL 的 oracle（提供任务 id）上界（2026-10-25）

**⚠️ 本目录不是预注册口径。** 这里的 `a[t][i]` 把 argmax 限制在任务 i 自己的 10 类里，
等于**告诉评测器任务 id**。预注册明确写着"测试时不提供任务 id、在全部已见类上评测"，
所以这组数是**上界**，不能当作 ACC/AF 引用。

它存在的原因是一段连续修正：

1. 原 [`../formal/`](../formal/README.md) 的矩阵填的是**累计类集**的联合准确率；
2. 第一次修正（commit `1850a9b`）改成"单个任务"——但 `evaluate_seen` 同时限制了
   样本与 argmax，等价于 oracle；
3. 真正的 CIL 口径（样本按任务切、argmax 在全部已见类）在 `evaluate_task` 里，
   结果见 [`../formal_cil/`](../formal_cil/README.md)。

这一目录保留为**上界与诊断**：它回答"如果知道任务 id，W1+delta 能到多少"，
不回答"类增量能到多少"。真正的预注册 CIL 结果在
[`../formal_cil/`](../formal_cil/README.md)：**ACC 0.0876 / AF 0.290**。
