# 预注册：阶段五 M3e——真实嵌入上的情景写入与睡眠巩固（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 要检验什么

M3c/M3d 目前只在合成向量上验过协议。M3e 把两段接到**真实嵌入**上：

1. 用本机 Ollama 的 `nomic-embed-text` 把文本写成嵌入（只走 `127.0.0.1`，无外网）；
2. 用 M3c 的 z-score + top-k 群体编码写成脉冲模式；
3. 用 M3d 的睡眠噪声回放做巩固，检验它是否**把同义改写合并、把不同事实分开**。

## 数据（合成，先定死）

- **8 个事实簇**，每簇 3 条同义改写（例：巴黎是法国首都 / 法国的首都是巴黎 / 巴黎为法国首都）；
- **8 条互不相同的事实**（各一簇，共 8 条）；
- 合计 32 条；文本清单在 `scripts/run_phase5_m3e.py` 里写死，运行后不改。

## 协议

- 嵌入：`nomic-embed-text`，`/api/embed`，批量一次调用；不缓存、不落盘原始嵌入；
- 阈值标定：**先用 seed 99 的另一组 12 条句子**（不进入评测）估计同义/不同义的余弦分布，
  取二者分布之间的中点作为 `merge_threshold`；标定记录写进 README，**不回调**；
- 巩固：`SleepConsolidator(noise_sigma=0.05, merge_threshold=标定值, rounds=3, seed=0)`；
- 指标：同义簇的合并率（8 簇里有多少簇最终只剩 1 条）、异簇误合并数、平均余弦漂移。

## 判据（全部满足才 `m3e_ready=true`）

1. **同义合并**：8 个事实簇中 ≥ **7** 簇最终只剩 1 条；
2. **不误合并**：不同事实之间的合并 ≤ **1** 对；
3. **确定性**：同种子重跑一次，`merged_pairs` 完全相同；
4. **无外网**：只请求 `127.0.0.1:11434`；HTTP 客户端禁用代理。

任一不过 → `m3e_ready=false`，负结果保留，不调阈值/噪声。

## 边界

- 合成文本、单模型嵌入；不外推到开放域语义；
- 合并判据是余弦阈值 + 各向同性噪声，不是「睡眠」的生物学机制；
- 32 条样本量小，合并率的分辨率是 1/8。
