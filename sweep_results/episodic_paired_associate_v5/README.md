## 边界：主档是薄过，种子不稳

K=8 逐种子 delta：0.790 / 0.782 / 0.786 / 0.808 / 0.858——**3/5 低于 0.80**，均值靠
后两个种子拉过线。K=4 稳定（0.912–0.932），状态控制也稳定（0.106–0.148）。因此：

- 局部 delta 规则在 K=4 是稳的；K=8 只能写成“均值过线、单种子不稳”；
- delta 逼近伪逆（0.805 vs 0.816），差距 0.011；K=16 掉到 0.531，容量边界仍在 K=8–16；
- σ=0.3 掉到 0.553，噪声边界与 v4 一致；
- 这是**局部误差修正**，不是 Hebbian 一次性外积；不能写成“纯 Hebbian 过线”。

## 结论

DPAR 的局部路线从 Hebbian 0.311 提到 **0.805**，与伪逆 0.816 基本持平；K=4 稳定过线。
阶段四情景记忆现在有：非局部伪逆（v4）与局部 delta（v5）两条可用路线，边界都是
K=8–16 与噪声。下一步是通用 OOD 的重建误差门；P3 闭环终止仍是独立边界。
