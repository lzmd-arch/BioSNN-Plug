## 一句话

**把 `w_rec` 置零并冻结之后，三种子中位 0.904，对 A3 的 0.899 只差 +0.5pp；

## 这否掉了什么

**"A 线的绝对数字被递推拉低了"这个猜想不成立。**

依据是 S1：语言模型上把递推/输入电流比从 0 抬到 0.56 / 1.02，top-1 掉 1.9 / 4.9pp。
A 线的比值是 1.106，按那个斜率应当掉 5pp 左右。**实测只差 +0.5pp，且逐种子正负各半。**

**所以那个"掉 5pp"的斜率不能跨任务外推。** 一个合理的解释（未验证）：
sMNIST 的输入本身就是"同一张图按行喂"，相邻行高度相关，随机的循环电流在这里更像
**低通滤波**而不是噪声；而字符序列的相邻 token 关系弱得多，同样的电流就成了纯噪声。
**这条是推测，本轮没有测它。**

## 这也意味着 A 线的已有结论是安全的

A3–A8 的两臂用同一个递推、同一个电流比，结论（读出值 14–42pp、32k vs 8k 的 −0.3/−0.9pp）
**都在同一条件下比较**，本轮的 +0.5pp 不足以改变任何一条。

## 边界（必须带上的混杂）

- **A9 少了一整块参数**（8,192 × 32），所以严格说它同时改了两件事：
  "去掉循环电流" 与 "少了 26 万参数"。本轮**无法**把两者分开；
- 单任务（sMNIST）、2 epoch、一个规模；
- 逐种子差 −1.3…+1.7pp 与 A3 的种子极差（4.4pp）同量级，**这个差本身就在噪声里**。
