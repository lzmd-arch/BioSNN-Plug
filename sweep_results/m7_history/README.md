# R-STDP 收口：**三种奖励调制全部 ≤ 纯 STDP**

## 一、四臂最终结果（10 种子，1024 步历史，α=0.5 vs 20）

| 臂 | 比 | 逐种子 |
| :--- | ---: | :--- |
| **`stdp`（R=1，无调制）** | **1.56×** | 9/10 |
| `R_pred`（可正可负的惊奇基线） | **1.44×** | 8/10 |
| `state`（无学习） | 1.42× | 8/10 |
| `R_homeo`（稳态误差） | 1.36× | 9/10 |

## 二、符号修复有效，但不足以改变结论

`R_pred` 从恒负版（1.41）改成零均值版（1.44）—— **+0.03**。

⇒ 那个实现缺陷**确实压低了效果**（我上一轮的判断对了一半），
但它**不足以让"预测误差作奖励"超过纯 STDP**。

## 三、对 R-STDP 的最终回答

**在这个系统里，第三因子（奖励）不给 STDP 加分，反而减分。**

三种调制（无 / 稳态 / 预测）的排序是 **1.56 > 1.44 > 1.36**，单调地随"调制有多强"而下降。

### 为什么

**STDP 的资格痕迹已经是三因子的前两个**（pre × post）。
第三因子只有携带**独立的方向信息**时才有用。

我们试的两种 —— 稳态误差、自身惊奇 —— **都是关于「活动水平」的**，
而 STDP 已经在用「放电时序」。**同一维度的信息重复了一次，只是乘上了噪声。**

⇒ **要第三因子有用，它得提供 STDP 看不到的东西**：外部结果、跨模态一致性、
或预测**输入**（而不是预测自己）。这两样现在都没有。

## 四、这一轮顺带确认的东西

**纯 STDP 仍然是最高的（1.56×）**，而且是今晚唯一跨过 1.5 的臂。
它落在生物学该在的那一层（突触，小时级）。

## 五、限定

- **9/10 种子，不是 10/10**；1.56 与 1.5 的边际 0.06；
- 一个规模、一种内容差异、1024 步历史、`gap=0`；
- `R_pred` 的"惊奇"用的是**群体发放偏离自己 EMA**，不是对**输入**的预测误差 ——
  后者没测（需要在线预测器）。
