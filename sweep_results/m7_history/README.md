# M7 个体史：**内容特异性一致地只有 ~20%，结构承载更差**

## 一、四条件结果（10 种子）

| 条件 | 历史 | 对照 | **比** | 逐种子更大 |
| :--- | ---: | ---: | ---: | :--- |
| `state/gap=0` | 44.42% | 35.21% | **1.26×** | 9/10 |
| `state/gap=64` | 44.68% | 35.87% | **1.25×** | 9/10 |
| `struct/gap=0` | 54.80% | 46.91% | **1.17×** | 8/10 |
| `struct/gap=64` | 56.78% | 47.88% | **1.19×** | 9/10 |

预注册：比 >1.5 且 10/10 ⇒ **四条全不过**。
M7-3（同历史逐位相同）**过**。

## 二、结构为什么反而更差

**两边都涨了，对照涨得更多**（state 35%→47%，history 44%→55%）。

**结构操作引入了比信号更多的噪声**：杀掉"活跃最低的 20%"，而大量神经元活跃是并列的
（很多恰好是 0），杀谁基本随机 ⇒ 加大了"任意两条流"的发散量。

⇒ **"让历史写进结构"这个方向本身没错，但这个实现太粗。**

## 三、一个值得记的一致现象

**四个条件全部落在 1.17–1.26 之间。**

⇒ 历史内容确实留下了一个 **约 +20% 的一致痕迹**，只是低于预注册的 1.5× 线。

**这不是零，是"小"** —— 四个独立条件同一量级，不是噪声。

## 四、M7 的最终账

| 命题 | 状态 |
| :--- | :--- |
| 系统有跨段传递的状态 | ✅ 确定（`run_block` 重置时 A=B，加状态传递后不同） |
| 状态依赖输入历史 | ✅ 确定（44%） |
| **历史内容留下可读痕迹** | ⚠️ **一致 +20%，不过 1.5× 线** |
| 结构承载历史内容 | ❌ **比状态更差**（噪声盖过信号） |
| 同历史逐位可复现 | ✅ 确定 |

**"个体史"在本架构里只有 ~20% 的内容特异性。** 这是 M7 能给出的最诚实的数字。

## 五、方向上剩下的两条

1. **更细的结构操作**：不是"杀最低 20%"（并列 + 随机），而是**连续改变连接权重**
   （例如 Hebbian 痕迹），那样没有"谁死"的随机性；
2. **更长的历史 + 更大的内容差异**（384→1024 步、α=0.5 vs 20）——
   如果是"痕迹太浅"，这两条会直接把 20% 推上去。

若两者都不能把比推到 1.5 以上，那正确的结论是：
**这个架构里，"历史的内容"确实只留下 ~20% 的痕迹** —— 那是一个结果，不是失败。

## 六、限定

- 10 种子；一个规模；一种历史差异（α=1 vs 8）；384 步历史；
- 对照 = 同 α、不同随机流（"内容"的正确基线）；
- `struct` 的实现是"杀最低活跃 20%"，并列导致随机性 —— 已在 §二 说明。
