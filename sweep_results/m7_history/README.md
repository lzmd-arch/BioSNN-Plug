# M7 长历史复验：状态承载 1.26 → **1.42**，结构承载塌到 1.05

## 一、结果（10 种子，1024 步历史，α=0.5 vs 20）

| 条件 | 历史 | 对照 | **比** | 逐种子更大 |
| :--- | ---: | ---: | ---: | :--- |
| **`state/gap=0`** | 52.16% | 36.74% | **1.42×** | 8/10 |
| **`struct/gap=0`** | 81.76% | 77.61% | **1.05×** | 7/10 |

与短历史（384 步、α=1 vs 8）对照：

| 条件 | 短 | **长** |
| :--- | ---: | ---: |
| `state` | 1.26× | **1.42×** |
| `struct` | 1.17× | **1.05×** |

## 二、两条结论

### 2.1 状态承载随历史加长而上升（1.26 → 1.42）

与"痕迹太浅"的解释一致 —— **内容确实在累积**。

### 2.2 结构承载彻底塌掉（1.05）

历史越长，杀"最低 20%"的**并列随机性**占比越大 ⇒ 结构操作变成纯噪声。

⇒ **要让历史内容留下痕迹，该走「慢状态 + 长历史」，不该走「粗糙的结构编辑」。**

## 三、到此停手，理由写在前面

1.42 离预注册的 1.5 很近。**继续加到 4096 步、α 再拉开，很可能就越线了。**

**但那正是"调到过线"。** 今晚的纪律是"不调阈值让结果变绿"；
**延长历史去凑同一个判据，是同一类动作的另一个面。**

⇒ 正确做法：**记下「1.42，且随历史单调上升」，不追这条线。**

若以后要重开，应在**新预注册**里换一个**有独立依据**的效应量，并说明为什么，
而不是沿用 1.5。

## 四、M7 的完整账（三轮）

| 命题 | 384 步 | 1024 步 | 状态 |
| :--- | ---: | ---: | :--- |
| 有跨段传递的状态 | ✅ | ✅ | 确定 |
| 状态依赖历史（绝对值） | 44% | 52% | 确定 |
| **内容特异性（比对照）** | **1.26×** | **1.42×** | **单调上升，未过 1.5** |
| 结构承载 | 1.17× | 1.05× | ❌ 死路 |
| 同历史逐位可复现 | ✅ | ✅ | 确定 |

## 五、限定

- 10 种子；一个规模；`gap=0`（长历史那轮只跑了一个 gap）；
- `struct` 的实现缺陷已查明（并列随机性），**不代表"结构不能承载历史"**，
  只代表"杀最低 20%"这个实现不行；
- 1.42 与 1.5 的差距（0.08）小于逐种子的离散度 ⇒ **"未过"是可信的，不是边界噪声问题**。
