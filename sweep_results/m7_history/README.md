# R-STDP：**纯 STDP 最好（1.56×），两种奖励都降低了内容承载**

## 一、四臂结果（10 种子，1024 步历史，α=0.5 vs 20）

| 臂 | 比 | 逐种子更大 |
| :--- | ---: | :--- |
| `state`（无学习） | 1.42× | 8/10 |
| **`stdp`（R=1，纯 STDP）** | **1.56×** | **9/10** |
| `R_homeo`（奖励稳态误差） | 1.36× | 9/10 |
| `R_pred`（奖励"我能预测自己"） | 1.41× | 8/10 |

预注册门槛：比 >1.5 **且 10/10**。
⇒ **`stdp` 跨过了比值线（1.56），但 9/10 ⇒ 严格说仍未全过。**

## 二、两条预测，一对一错

### 2.1 `R_homeo` 1.36 < `state` 1.42 —— **方向对了**

稳态奖励把权重拉向**唯一不动点**（能达到 f* 的那套），
所以它**确实擦掉了历史内容**。这是本轮最干净的一条。

### 2.2 `R_pred` 1.41 ≈ `state` 1.42 —— **错了，而且是我的实现问题**

查下来：`R_pred = −|φ − f_run|` **恒为负** ⇒
它只能**衰减** STDP 更新，而且衰减量随历史波动 ⇒ **加的是噪声，不是信号**。

**这是明确的设计缺陷，不是"预测误差不能当奖励"的否证。**
要真测，得改成 `R = −(surprise − surprise_baseline)`，可正可负。

## 三、对「R-STDP 如何」的直接回答

**在这个实现里，R-STDP 不如纯 STDP。**

- 两种调制都**降低了**内容承载（1.36 / 1.41 vs 1.56）；
- **无调制的 STDP 最好。**

这不奇怪：**STDP 的资格痕迹本身就是三因子里的前两个**；
第三因子加进来时，如果它不携带**方向信息**，就只是在给一个已经有效的学习规则**乘噪声**。

## 四、STDP 这一条为什么重要

| 层 | 时间常数 | 承载历史内容 |
| :--- | :--- | ---: |
| 膜电位（快状态） | 秒 | 被下一次输入冲掉 |
| `f_run` / 增益（慢状态） | 小时–天 | 1.42× |
| **突触权重（STDP）** | **小时–天** | **1.56×** |

⇒ **"历史写进突触权重"比"历史留在慢状态"承载得更多。**
这与生物学的分层一致，也是本架构里第一次有东西**跨过 1.5**。

## 五、限定（必须一起读）

- **9/10 种子**，不是 10/10；1.56 与 1.5 的边际只有 0.06；
- 一个规模、一种内容差异（α=0.5 vs 20）、1024 步历史、`gap=0`；
- `R_pred` 的实现有缺陷（恒负），**不能据它否定预测误差作奖励**；
- `stdp` 的裁剪（`clamp(min=0)` + 行归一）会压缩权重分布 ——
  未测它对"承载"的独立贡献。

## 六、下一步

1. **修 `R_pred`**（改成可正可负），再判一次 —— 那才是对"预测误差作奖励"的公平检验；
2. **STDP 的剂量**：`η` 从 0.05 扫到 0.2/0.5，看 1.56 能不能稳定上去；
3. **换更长历史**：1024 → 4096，看是否单调（**但不为凑 1.5**）。
