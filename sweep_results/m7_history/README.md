# M7 个体史：**对照把 44% 打回 1.26×**

## 一、结果（10 种子）

| 静默间隔 | 历史（α=1 vs α=8） | **对照（α=1 vs α=1，不同随机流）** | 比 |
| ---: | ---: | ---: | ---: |
| 0 | 44.42% | **35.21%** | **1.26×** |
| 64 | 44.68% | **35.87%** | **1.25×** |

逐种子"历史 > 对照"：**9/10**。

判：**M7-1/M7-2 不过**（预注册要 比 >1.5 且 10/10）；
**M7-3 过**（同历史逐位相同）。

## 二、这个对照是本轮最重要的东西

**44% 的差异里，约 79% 只是"任意两条不同流都会造成发散"。**

⇒ **任何有状态的系统，喂不同输入都会发散。那不叫个体史，叫"状态依赖输入"。**

**要声称个体史，必须证明「历史的内容」留下痕迹，而「任意两条流」不会。**

没有这个对照，今天会报一个 44% 的"重大正向结果"，而它 79% 是假象。

## 三、前一轮的"载体找到了"要打折

上一轮我看到 `d′` 不随静默衰减（0.74 / 0.84 / 0.77），
认为"差异由慢状态承载"。

**那个观察仍然成立**（差异确实不衰减），但**它的量级里大部分是"任意不同的流"**。
所以正确的说法是：**慢状态承载的是"输入历史"的一般痕迹，不是"这段历史的内容"。**

## 四、M7 现在到底证明了什么

| 命题 | 状态 |
| :--- | :--- |
| 系统有跨段传递的状态 | ✅ **确定**（`run_block` 重置时 A=B，加状态传递后不同） |
| 状态依赖输入历史 | ✅ **确定**（44%） |
| **历史的内容**在状态里留下可读痕迹 | ⚠️ **只有 1.26×，不过预注册线** |
| 同历史可逐位复现 | ✅ **确定**（M7-3） |

**前两条是"有状态"，第三条才是"有个体史"。** 目前只做到"有状态"。

## 五、下一步（都不改门槛）

1. **加大内容差异**：α=0.5 vs α=20；历史 384 → 1024 步；
2. **换能读出"内容"的量**：现在是全响应向量的相对范数 ——
   它对"任意发散"敏感。可以试**减去"任意流"的公共分量**（即用对照做基线归一化），
   剩下的才是内容；
3. **最直接的一条**：让历史**改变结构**（生死规则 / 发育），而不只是改变状态。
   状态会被下一次输入冲掉，结构不会 —— 那才是"历史写进个体"。

## 六、限定

- 10 种子；一个网络规模；一种历史差异（α=1 vs 8）；384 步历史；
- 对照用的是"同 α、不同随机流"，它衡量的是**统计相同**的两条流的发散量 ——
  这是"内容"的正确基线。
