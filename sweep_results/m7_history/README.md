# M7 个体史：**载体找到了（差异不随静默衰减），强度不够（d′≈0.8）**

## 一、结果（20 种子，同一网络种子，不同历史流）

| 静默间隔 | A（α=1 稀疏） | B（α=8 平坦） | `d′` |
| ---: | ---: | ---: | ---: |
| 0 | 0.11293 | 0.11222 | **0.74** |
| 16 | 0.11455 | 0.11379 | **0.84** |
| **64** | 0.11339 | 0.11267 | **0.77** |

| 编号 | 结果 |
| :--- | :--- |
| M7-1 `gap=0` 可区分（`d′>2`） | ❌ **不过**（0.74） |
| M7-2 `gap=64` 仍可区分（`d′>2`） | ❌ **不过**（0.77） |
| M7-3 同历史逐位相同 | ✅ **过** |

## 二、正面的那一半：**载体找到了**

**`d′` 不随静默间隔衰减**（0.74 → 0.84 → 0.77）。

- 若差异来自**膜电位残余**，64 步静默后必然散尽；
- **它没有散** ⇒ 差异由**慢状态**承载（稳态场的 `f_run`、增益）。

⇒ **"个体史"的载体是慢状态，不是快状态。** 这是这一轮真正的收获 ——
即使强度不过线，**机制的位置已经确定**。

## 三、强度不够意味着什么

`d′≈0.8` 意味着：单个样本只能弱区分（约 66%），需要多次观测才能判。

⇒ 当前的历史（96 步、两种词分布）**留下的痕迹太浅**。
要提高强度，只能改三处之一：历史更长、历史差异更大、或让慢状态累积得更快。

## 四、这一轮改了五次才跑通，每次都是同一个病

| # | 症状 | 真因 |
| :-- | :--- | :--- |
| 1 | 全网饱和 0.309、A=B | **没标定**输入尺度 |
| 2 | 标定失败 | 网格上界卡在 1.0，而窗口在 1.0–1.5 |
| 3 | 恒等 0.339 | **`run_block` 每次重置 `v/z/ref`** ⇒ 历史与探针不在同一个个体上 |
| 4 | 饱和 0.5 | 持久状态下网络自己爬到饱和；**输入增益压不住递归** |
| 5 | 终于在工作窗（0.113） | 加**稳态场** |

**第 3 条是根本的**：M7 要测的就是"状态跨段传递"，而我的工具默认每次都重置。
**工具和问题是反的** —— 这与今晚反复出现的那一类（测量装置与对象不匹配）同源。

**第 4 条也有独立价值**：它再次确认"输入增益替代不了递归驱动"（v20 的结论）。

## 五、下一步

1. **加强历史**：T_HIST 96 → 512；或两种流差异更大（α=0.5 vs α=20）；
2. **换个更灵敏的读出**：现在用的是探针窗的平均发放（一维）；改用响应轨迹的全部特征；
3. **别改门槛**。`d′>2` 是预注册的，先加效应再说。

## 六、限定

- 20 种子；两种词分布；96 步历史；一个网络规模；
- `d′` 用**平均发放**这一维算的，不是全响应 —— 可能低估了；
- M7-3 过，所以"差异"不是随机噪声冒充的（这一点是干净的）。
