## 读法

- **重建在所有种子上都过**，而且余量很大（比值 0.011–0.022×，判据 0.1×）：
  误差回注时的自监督学习是成立的；
- **自由运行只在 1/3 种子上完整成立**。seed0 在关掉误差输入后维持了目标幅度
  （0.584）且波形距离只有对照的 38%；seed1 的波形距离差一点点（0.51×，判据 0.5×）；
  seed2 的幅度塌到 0.119——同样的超参、同样的训练量；
- 这说明**自由运行的自持振荡不是一个稳定的能力**，而在种子之间摇摆。合理的机制解释是
  训练时误差通道持续提供目标信息，网络可以部分依赖它；关掉后能否自持取决于学到的
  循环动力学是否恰好落在振荡区。本轮没有做「关掉误差再训练」的课程，故无法定论；
- 不能把 seed0 的结果写成「Predictive E-prop 复现成功」——判据要求三种子全过，且原文的
  主结论（与 TBPTT 相当、Lorenz）本轮都没测。

## 边界

- 只测正弦；不测 Lorenz、噪声过滤、插值；不与 TBPTT 比较；
- 每 10 ms 更新一次、痕迹跨更新保持；没有 OU 噪声、没有 LIF/ALIF 混层；
- 3 个种子，报逐种子值，不报最好值；
- 超参由 pilot 种子 99 选定（记录在预注册的「先导记录」），先导不进入正式统计；
- 运行时的未提交改动只有文档（见台账 149），代码为 commit `38ce728`。
