# 预注册：单元级活动归一化（稳态可塑性），打断权重的共模推力

**定稿时间：2026-10-17。测量与网格均先于其结果。**

## 要修什么（已证实，不是假设）

上一轮实测：训练 800 回合后

| 量 | 训练前 | 训练后 |
| :--- | ---: | ---: |
| 单元间余弦 | −0.002 | **+0.823** |
| 有效秩 | 0.613 | **0.025** |
| 单元活动两两相关 | — | +0.928 |
| 平均活动 | — | 0.003 |

64 个单元的权重几乎指向同一方向、活动一起归零，`V` 几乎全由 `out_bias` 承担。
机制推断：`gradient` 后因子下痕迹恒非负（`x ≥ 0`、`σ' > 0`），读出一律为正，两者乘积
把每个单元推向同一个非负方向。

## 修法：每个单元维持自己的活动水平

```text
y_j = σ( g·(w_j·x − b_j) )
b_j ← b_j + β·(y_j − y*)         每次更新后（y* 是目标活动率）
```

**为什么这仍是局部的**：`b_j` 的调整只用到**该单元自己的输出** `y_j` 与一个常数目标 `y*`，
不读别单元、不读全局误差以外的量。它对应神经科学里的**稳态可塑性**（homeostatic scaling），
是每个神经元对自己的活动水平的局部调节。

⚠️ **但必须说清它与 `δ` 的关系**：稳态更新**不经过** `δ`，它是并行的、独立的慢调节。
`δ` 仍然是唯一的全局标量（多巴胺式广播）。两者不混。

## 网格

| 维度 | 取值 |
| :--- | :--- |
| `y*`（目标活动） | 0.05、0.10、0.20 |
| `β`（稳态步长） | 0.01、0.1 |
| 其余 | **固定** `b₀=0, gain=16, gradient, normalize=False, 均匀读出` |

筛选：单种子 300 回合。确认：最优配置 5 种子 × 800 回合。

## 判据

先看机制是否被打破（这才本轮的主要目的）：

1. **同质化被打破**：训练后单元间余弦显著低于 +0.823（同样用 `diagnose_homogenisation.py`），
   有效秩显著高于 0.025；
2. **`V` 的动态范围变宽**：不再卡在 3.2，且 `corr(V,G)` 高于 +0.697。

再看分数：

3. 若前两条成立而分数仍低，说明同质化不是 0/5 的**唯一**原因；
4. 若分数越过 200 而机制指标没变，说明这个解释错了——**如实报**。

## 边界情况

* 稳态把 `b_j` 推向一个**新的**工作点，可能与"gain 16 把 z 拉到 ±2"的前提冲突。
  若 `b_j` 漂到很大，`z` 会重新落回饱和区——**如实记为该配置失败**，不偷偷改 gain。
* `β` 太大会让 `b_j` 抖，`y` 无法稳定；表现为分数剧烈波动，同样如实报。
* 这不是"调一个超参"，是**换一条学习规则**：结果若好，`pop_critic.py` 的文档要补上
  "稳态项与 TD-LTP 是两条并行的局部规则"这一条，且默认值不偷偷改。
