## 读法

- 排序能力仍然强：AUROC 0.988–1.000，命中 0.99–1.00；失败在**边界阈值校准**：
  seed 13 有一批模型误差步把 margin 推过 1，虽然真实没有终止。
- 闭环对照仍只有 **0.640**（v2 0.6469、v3 0.634 同量级）；开环与闭环是两个能力，
  不能互换。
- v4 的率判据是 v3 失败后新增的；v3 的判定不改。
