## 为什么这次 s=2 过了

v14/v17 的门在 s=2 上把尺度信号和 in-dist 噪声混在一起：`state_norm` 对 σ=0.5 的
噪声也敏感，`errors` 在 s=2 的偏移量小。v18 用**读出预测的范数**：它是状态经任务读出
后的连续量，尺度 OOD 会把预测的 cue 整体放大，而 in-dist 噪声在读出时被平均掉一部分；
因此 s=2 的分离度从 AUROC 0.76–0.84 提到 **0.90–0.94**。这不是输入级 `input_norm`，
也不是把测试误差当标签：`r=‖readout(state)‖` 只用状态和已训练读出。

## 边界

- 只覆盖 A/B 尺度 OOD；不覆盖量化/信息丢失型 OOD，也不是通用弃权。
- 覆盖率在 0.795–0.814 内，没有单格出带；但这是 5 种子均值，单种子仍会有波动。
- 预测范数是状态侧读出量，不是独立的生成模型；它依赖任务读出，若读出本身失效，
  门的语义也会变。
