# 阶段四集成 demo：组合与等价性（2026-10-27）

**这是组合/等价性 demo，不是新的性能主张。** 代码：
[`research/cognitive/integration_demo.py`](../../research/cognitive/integration_demo.py)。
把工作记忆 v4（局部 RLS）、元认知 ensemble 分歧、P3 世界模型、字面情景索引放在同一份
输入上跑；每个组件在同一输入上再调用一次，断言输出**逐位一致**。干净工作区 commit
`2f0dd8e`（实现提交见 git log）。

## 读数：能串起来 ≠ 端到端元认知成立

- 四个组件的 API 可以组合，状态/预测在重复调用下逐位一致，回路能跑；
- **元认知的 ensemble 分歧在这个回归任务上只有 AUROC 0.562**：v3 的分歧信号是在 CIFAR
  分类上验证的，不能自动迁移到“WM 回归误差”这个新任务；
- 情景检索 MSE 1.194 也说明“字面索引”在这个连续线索任务上并不精确；
- 所以这份 demo 只证明**组合可运行/等价**，不证明“阶段四端到端能力”。端到端指标需要
  另一个预注册任务，而不是把单组件数字拼在一起。

## 结论与下一步

集成 demo `integration_ok=true`，但**元认知/情景在端到端任务上没有继承单组件成绩**。
下一步若要真正做“阶段四集成”，必须先写死一个端到端任务与指标（例如 OOD 弃权、延迟线索
问答），再逐组件接；或者先做工作记忆 v5（ALIF 脉冲），把 ready 组件推进到脉冲实现。
