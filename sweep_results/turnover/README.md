# 受调控的细胞更替（v19）：**恢复人头不恢复工作点**

## 一、两次实现修正

1. **绝对死亡阈值 ⇒ 群体灭绝。** `theta_dead=0.02` 时存活比例掉到 **1%** ——
   多数神经元的块均活跃本来就在 0.02 以下。改成**相对阈值**（活跃最低的 10% 凋亡）
   + **目标群体规模** `rho_target`。
2. 第二次跑通了（群体稳定），但 `n_viable` 反而低 —— 因为比较的两档人口不同。

## 二、结果（3 种子，控制在**相同人口**后）

| 臂 | 存活比例 | `n_viable` |
| :--- | ---: | :--- |
| `static`（切半，无更替） | 50% | **[8, 8, 6] = 7.3** |
| `turnover`（生死规则，ρ=0.5） | 50% | **[3, 4, 3] = 3.3** |
| `turnover`（ρ=0.8） | 80% | 2.7 |

**T-1 不过，而且方向是反的** —— 生死规则让工作窗**变窄**（7.3 → 3.3）。

## 三、它和今晚的一条主线对上

> **系统的可行性取决于「增益平衡」，不取决于「单元数量」。**

| 干预 | 调的是 | 工作窗 |
| :--- | :--- | :--- |
| 抑制性固定场 | 平衡（抑制） | 扩大 4.25× |
| 稳态场 | 平衡（反馈） | 扩大 6× |
| 内增益 | 平衡（输入增益） | 损伤侧 7→11 |
| **生死规则** | **数量** | **变窄** |

⇒ **加神经元不是"加容量"，是改分母。** 而分母一变，原来的增益平衡就不成立了。

## 四、但 T-1 失败**不带走** T-2/T-3

T-1 把生死当**修理工**（恢复功能）。用户提的是**基因调控**，那关心的是：

| # | 问题 | 状态 |
| :-- | :--- | :--- |
| T-2 | 面对流 A 与流 B，存活集合是否不同 | **未测** |
| T-3 | 切回流 A 后组成是否回得去 | **未测** |

**这两条不依赖工作窗指标** —— 即使 `n_viable` 不变，组成仍可能随流改变。
它们是不同的命题，不该被 T-1 的失败带走。

## 五、下一步

T-2/T-3：**群体的组成是不是被经验改写的**。
那测的是"**它是谁被历史改成了什么**"，而不是"它能不能干活"。
