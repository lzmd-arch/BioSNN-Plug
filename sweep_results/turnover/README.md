# 生死规则 v2：**触发条件修好了（3.3 → 7.0），但仍打不过"不修"**

## 一、结果（3 种子，同人口 50%）

| 臂 | `n_viable` | 存活比例 |
| :--- | :--- | ---: |
| `static`（不修） | **[8, 8, 6] = 7.3** | 50% |
| `act/random`（按活动触发，v19） | [3, 4, 3] = 3.3 | 50% |
| **`silent/random`**（按静默比例触发） | **[7, 7, 7] = 7.0** | 50% |
| **`silent/clone`**（复制 + 噪声诞生） | **[7, 7, 7] = 7.0** | 50% |

判：T-0 过；**T-1′ 过**（7.0 vs 3.3，+112%）；**T-2′ 不过**（clone = random）；
**T-3′ 不过**（7.0 vs 7.3）。

## 二、三条结论

### 2.1 触发的确是那个 bug

换成"数静默"之后伤害消失（3.3 → 7.0）。
⇒ **v19 的"生死规则让工作窗变窄"是通道选错造成的，不是机制宿命。**

### 2.2 诞生方式无关

复制 + 噪声 vs 随机，**逐位相同（7.0）**。
在这个指标上"新单元长什么样"不重要。

### 2.3 但它只是"不再有害"，不是"有益"

**7.0 vs 7.3 —— 生死规则打不过什么都不做。**

## 三、与今晚主线一致

**系统的余量不取决于单元数量，取决于增益平衡。**

"补人"最多把分母补回来，补不回平衡。7.0 是"补回分母所能达到的"，
7.3 是"不补、分母小"的 —— 两者接近，而后者更简单。

## 四、生死规则的定位要改

它**不是**提高余量的机制。它的价值在别处：

- **如果**系统需要替换神经元（损伤 / 老化 / 漂移），
  **按静默触发不会伤害性能** —— 这是一条有用的保证；
- 而"提高余量"要靠**增益平衡**类机制（稳态场、内增益）。

> **增益管平衡，生死管替换。** 今晚的数据把这条分得很清楚。

## 五、限定

- 3 种子；损伤比例固定 50%；触发阈值 `θ_hi=0.15` 未扫；
- `n_viable` 是余量指标，**不是能力**；
- T-2′/T-3′ 的"不过"要按今晚那条规则看：3 种子、且这三档的离散度很小
  （[7,7,7] vs [8,8,6]），所以**不显著**是可信的。
