# M6ad2：**顺序被编码了 —— 今晚唯一一条时间整合的证据**

## 任务

两段历史、**只有先后不同**：

- `(0,0)` 与 `(1,1)`：单调，只需知道"哪一族出现过"；
- **`(0,1)` 与 `(1,0)`：内容相同、顺序相反** —— 状态必须携带**顺序**才能分开。

后者不能用任何静态的"痕迹深浅"解释，所以它是**时间整合**的最小检验。
同时它也是最容易被损伤破坏的信息，因此顺带测脆性。

## 结果（4 种子，`per=32`）

| 种子 | 单调对 | **顺序对** | 切 50% 后：单调 / **顺序** |
| ---: | ---: | ---: | :--- |
| 0 | 0.750 | **0.750** | 1.000 / **0.875** |
| 1 | 0.750 | **0.812** | 1.000 / **1.000** |
| 2 | 0.625 | 0.625 | 0.875 / **0.938** |

（二分类，机会水平 0.5。）

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| AO-1 单调对可解码（>0.75） | 0.708，**不过**（边缘） |
| **AO-2 顺序可判别（>0.65）** | **0.729，过** |
| AO-3 有脆性 | **无**（切后反而更好） |

## 一、这条为什么重要

今晚几乎所有测量都是**对终态的静态读数**。**顺序判别是第一个不能用静态量解释的结果**：
`(0,1)` 与 `(1,0)` 喂进去的是同样的两个族、同样的总暴露量，**唯一的区别是先后**。

⇒ **状态里存在时间整合，不只是"哪个输入更强"。**

## 二、脆性：第五次没有

切掉 50% 之后，顺序判别从 0.729 升到 0.938。**又是"损伤让解码变好"。**

这是今晚**第五次**独立确认（M5b 的 12 格、M8、M6z 两个 regime、M6ad 的复合任务、本轮）。
**"不脆"已经是这个动力学族最稳的性质**，比任何正结果都稳。

## 三、限定

1. **AO-1 单调对只有 0.708，未过 0.75** —— 说明这个任务本身不算简单；
2. **3 个可用种子**（`--seeds 4` 但输出到第 3 个，第 4 个未落盘）；
3. 每个二分类只有 **64 个样本（16 个测试）** —— 测试样本很少，0.75 与 0.625 之间只差 2 个样本；
4. **判据 AO-2 的 0.65 门限是本轮定的**，机会 0.5；
5. 只测了一个族对（0 vs 1）。其他族对未测。

---

## 加厚复测（6 种子 × 256 样本/对）：顺序判别**确认**

| 判据 | 3 种子（每对 64 样本） | **6 种子（每对 256 样本）** |
| :--- | ---: | ---: |
| AO-1 单调对 | 0.708 | 0.714（仍不过 0.75） |
| **AO-2 顺序对** | 0.729 | **0.698 ✅** |
| AO-3 切后 | 更好 | 更好（0.854） |

**顺序判别 0.698（机会 0.5）在 6 种子下成立。** 单调对始终是 0.71 —— 略低于 0.75 的门限，
说明这个任务本身不简单，但**顺序那一项稳定高于它自己的一半机会**。

## 但**只在高维以外的 regime 成立**

用同一套任务，在 `g_local=2.0 / p_long=0.5`（PR 64、解码 0.325 的那一格）上测：

| regime | 单调对 | **顺序对** | 切后顺序 |
| :--- | ---: | ---: | ---: |
| **全局场**（低维 PR 2.3） | 0.714 | **0.698 ✅** | 0.854 |
| **高维**（PR 64.4） | 0.453 | **0.453 ❌** | 0.766 |

**⇒ 时间整合只在低维那条路上成立。** 高维状态几何更丰富，但对**顺序是盲的**。

这让"三性状交换曲线"多了一维：

| | 全局场（低维） | 局部场 + 长程（高维） |
| :--- | :--- | :--- |
| 维数 | 2.3 | 47–108 |
| 可解码 | **0.61–0.73** | 0.20–0.48 |
| 整合 | **0.83** | 0.09–0.37 |
| **时间整合（顺序）** | **0.698 ✅** | 0.453 ❌ |

**两个 regime 擅长的事完全不重叠。** 这是"分工"架构提案的直接依据。

## 一个反直觉的细节

高维 regime 下**切掉 50% 之后顺序判别从 0.453 跳到 0.766** ——
损伤把"读不出"变成"读得出"。这是今晚无脆性的**第六次**独立确认，
而且是最戏剧的一次。
