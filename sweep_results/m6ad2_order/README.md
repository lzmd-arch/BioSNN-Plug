# M6ad2：**顺序被编码了 —— 今晚唯一一条时间整合的证据**

## 任务

两段历史、**只有先后不同**：

- `(0,0)` 与 `(1,1)`：单调，只需知道"哪一族出现过"；
- **`(0,1)` 与 `(1,0)`：内容相同、顺序相反** —— 状态必须携带**顺序**才能分开。

后者不能用任何静态的"痕迹深浅"解释，所以它是**时间整合**的最小检验。
同时它也是最容易被损伤破坏的信息，因此顺带测脆性。

## 结果（4 种子，`per=32`）

| 种子 | 单调对 | **顺序对** | 切 50% 后：单调 / **顺序** |
| ---: | ---: | ---: | :--- |
| 0 | 0.750 | **0.750** | 1.000 / **0.875** |
| 1 | 0.750 | **0.812** | 1.000 / **1.000** |
| 2 | 0.625 | 0.625 | 0.875 / **0.938** |

（二分类，机会水平 0.5。）

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| AO-1 单调对可解码（>0.75） | 0.708，**不过**（边缘） |
| **AO-2 顺序可判别（>0.65）** | **0.729，过** |
| AO-3 有脆性 | **无**（切后反而更好） |

## 一、这条为什么重要

今晚几乎所有测量都是**对终态的静态读数**。**顺序判别是第一个不能用静态量解释的结果**：
`(0,1)` 与 `(1,0)` 喂进去的是同样的两个族、同样的总暴露量，**唯一的区别是先后**。

⇒ **状态里存在时间整合，不只是"哪个输入更强"。**

## 二、脆性：第五次没有

切掉 50% 之后，顺序判别从 0.729 升到 0.938。**又是"损伤让解码变好"。**

这是今晚**第五次**独立确认（M5b 的 12 格、M8、M6z 两个 regime、M6ad 的复合任务、本轮）。
**"不脆"已经是这个动力学族最稳的性质**，比任何正结果都稳。

## 三、限定

1. **AO-1 单调对只有 0.708，未过 0.75** —— 说明这个任务本身不算简单；
2. **3 个可用种子**（`--seeds 4` 但输出到第 3 个，第 4 个未落盘）；
3. 每个二分类只有 **64 个样本（16 个测试）** —— 测试样本很少，0.75 与 0.625 之间只差 2 个样本；
4. **判据 AO-2 的 0.65 门限是本轮定的**，机会 0.5；
5. 只测了一个族对（0 vs 1）。其他族对未测。
