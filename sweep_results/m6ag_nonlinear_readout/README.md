# M6ag：**高维状态不可读 —— 这次仪器是有效的**

## 为什么重测

`M6ab` 用线性探针得出"高维状态不携带历史"，被用户指出是**根本性错误**：
高维分布式编码本来就不线性可读，线性探针的失败是**仪器的必然**。
本轮换 **1-NN（非参数）+ MLP（非线性）+ 样本量提到 n=1024**。

## 结果（n=1024 个状态、d=1024；2 种子）

| 配置 | 线性 | **1-NN** | **MLP** | 底板 |
| :--- | ---: | ---: | ---: | ---: |
| **局部场** `radius=2` | 0.193 | **0.139** | **0.187** | 0.094 |
| **全局场** `radius=32` | 0.611 | **0.729** | **0.616** | 0.094 |

| 判据 | 结果 |
| :--- | :--- |
| AG-1 局部场下非线性可读（> 底板 + 0.15） | **0.187 < 0.244，不过** |

## 一、这次结论有资格下

**关键是那两行全局场**：1-NN 给 **0.729**，比线性 0.611 还高。

⇒ **非参数读出是有效仪器**，能读到 0.73。它在局部场下只读到 0.139/0.187，
**不是仪器的锅**。

**⇒ 高维状态确实不携带可读出的历史。** 这是今晚第二次测同一件事，
第一次（M6ab）的仪器不合格，这一次合格。

## 二、但要连带记住的一条

局部场的**操作点极窄**：`M6ac` 扫 `g_local ∈ {0.1…1.0}`，
**0.1 / 0.2 / 0.35 / 0.5 五格全部饱和**（发放 0.5、PR 0），只有 `1.0` 才进工作区。

所以"局部场不可读"这个结论**只在这个窄工作点上验证过**。
换一个操作点是否仍不可读，**未测** —— 这是本结论最重要的未排除项。

## 三、限定

- **2 种子**（每种子 1024 个状态）；MLP 是 1 隐层 256、600 步，**可能欠训练**；
- 1-NN 在局部场下（0.139）**低于 8 类机会水平 0.125 附近**，说明状态空间里
  同族不聚拢 —— 但这不排除信息以更复杂的形式存在（如流形上的连续参数）；
- 只测了"族标签"这一个读出目标。
