# 记忆深度 v2（7 种子符号检验）：**AUC 6/7、τ 4/7，都不显著**

**一句话**：把判据换成连续量（AUC / τ）并用符号检验后，`g4 − g0` 的 AUC
在 **6/7 个种子**上为正（p = 0.125，不显著），衰减时间常数 τ **4/7**（无模式）。
效应量 **+2.6%**。

**⇒ 上一轮那个"3/3 同向"在 7 个种子上没有站住。**

## 一、结果（7 种子、n=2048、D0=32 → D1=8）

| 臂 | lag0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 深度 | 发放 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `g0`（γ=0） | 0.058 | 0.834 | 0.487 | 0.232 | 0.137 | 0.086 | 0.080 | 0.072 | 3 | 0.0813 |
| `g4`（γ=4） | 0.058 | 0.837 | **0.503** | 0.240 | 0.135 | 0.091 | 0.085 | 0.075 | 3 | 0.0784 |

底板 **0.066**。

**MD-0 过**（峰值 0.834 / 0.837 ≥ 0.166）⇒ 任务成立，本轮有效。

## 二、判

| 编号 | 结果 |
| :--- | :--- |
| **MD-0** | ✅ 过 |
| MD-1 单调下降 | ❌ 不过（lag=0 异常，见 v5 amend2） |
| MD-2 深度 | 两档都是 **3** |
| **MD-4 AUC** | ❌ **不过**：逐种子差 `[+.083, +.038, +.054, +.019, −.005, +.043, +.034]`，**6/7**（要 7/7，p=0.125） |
| **MD-5 τ** | ❌ **不过**：`[+.287, −.077, −.123, +.079, +.196, −.073, +.463]`，**4/7** |
| 效应量 | AUC 相对差 **+2.6%**（不作判据） |

## 三、要更正上一轮的一句话

v5 我写过「`g4 − g0` 在 lag 1–2 上 **3/3 种子同向**」。
**换成 7 个种子后是 6/7**，那个 −0.005 的种子就在同一批数据里。

⇒ 正确说法是：**有一个约 +2.6% 的整体上移，但不足以通过符号检验。**
3 个种子的"全同向"在二项检验下的 p 只有 0.25 —— **从来就不够**，
是我当时没有做检验就说成了"同向"。

## 四、τ 与 AUC 的分工说明了一件事

AUC 6/7（略正）、**τ 4/7（完全无模式）**。

⇒ 差异不是"衰减更慢"，而是**整条曲线的一个近似均匀的抬升**。
换句话说：`g4` 在每个 lag 上都高一点点，但**衰减的形状没变**。

这与 v3 的结论一致：γ 改变的是**结构本身**（0.895→0.763），
但它没有改变**记忆随时间的衰减速率**。

## 五、这一轮回答了什么

v5 留下的问题是「是判据不敏感，还是机制没用？」

**答案：更接近"效应本来就不存在"。**

| 判据 | 结果 |
| :--- | :--- |
| 分类准确率 | 四档平（极差 1.5pp） |
| 记忆深度（离散） | 全 3 |
| **记忆 AUC（连续，7 种子）** | **6/7，p=0.125** |
| **记忆 τ（连续，7 种子）** | **4/7** |

判据已经从"粗"换到"细"、从 3 种子换到 7 种子，**差异仍然不过**。
⇒ 不是判据的问题。

## 六、限定

- 7 个种子、一个任务、一个读出；
- 符号检验的 p 值只算了一次，**没有做多重比较校正**（若把 AUC 与 τ 都算上，
  6/7 更不显著）；
- `g4` 与 `g0` 的发放率不同（0.078 vs 0.081），这个差没有控制。

## 七、对路线图的意义

现在能说：**「内部量 → 结构/活动」这条因果链是通的、可调的，
但它还没有接到任何能力指标上**（准确率、记忆深度、记忆 AUC、记忆 τ，四次都不过）。

这**不否定生命目标** —— 生命不以 benchmark 为准。但它说明：
**下一步该测的不该再是"更高/更准"，而是"内部量让系统多了什么不能用量化能力描述的东西"**
（M7 个体史、M5 再生、M6 内源驱动）。
