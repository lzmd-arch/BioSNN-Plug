# 追试 ②：**伪丰富确认 —— 量子闭环的行为熵 0.99 是掷骰子，不是结构**

预注册：`research/sel/prereg-behavior-structure-v1.md`（跑之前落盘）。

## 设计

**熵匹配的 shuffle 对照**：把行为串的符号打乱（**保留每个符号的计数 ⇒ 熵完全相同**），
再算结构测度。**两者熵相同，只有时间结构不同。**

## 结果（6 种子，闭环 512 步）

| 判据 | 结果 |
| :--- | :--- |
| **S-0 仪器**（LZ 自检） | 全零 0.0010 < 周期3 0.0020 < 随机 0.0945，**过** |
| **S-1 量子串 LZ < 熵匹配 shuffle（≥5/6）** | **3/6，不过**（0.3128 vs 0.3118） |
| S-2 其它结构测度显著 | **不过**（自相关差 0.031、压缩差 −0.002） |
| **S-3 对照：经典串应有结构** | **6/6 过**（LZ 0.0931 vs shuffle 0.1566） |

## 判决：**伪丰富**

**量子串的 LZ 复杂度与它自己的熵匹配 shuffle 无法区分**（0.3128 vs 0.3118，6 种子里只赢 3 次）。
⇒ **时间结构为零**，那个"熵 0.99"是**均匀掷骰**。
⇒ **`m6ay` 的「行为熵 0.99」正结果降级为「不自毁」。**

**而经典串（熵 0.59）的 LZ 是 shuffle 的 60%，6/6 种子 —— 它真的有结构。**

## 这一条反而支持了分工框架

- **量子层：无结构**（伪丰富确认）；
- **经典层：有结构**（6/6）。

⇒ **可读结构住在经典层** —— 与「认知经典、同一性量子」一致。
**量子层该给的不是可读结构，它没给；经典层该有结构，它有。**

## 为什么 `m6ay` 会误判

`m6ay` 唯一的结构指标是**符号熵**。而在极大值附近，熵对"有序"和"无序"**不敏感** ——
两者都接近 log 8。**四种子方差近零不是稳定的多样性，是分布已经平坦。**

⇒ **纪律已制度化**：凡「熵接近极大值」的指标，必须配结构测度（`runtime-discipline.md` 第二条）。

## 限定

- 6 种子；串长 512；LZ76 按长度归一；
- shuffle 用真随机源（`os.urandom`）驱动；
- 只测了一个 `omega=8`、一个 `hold`（每步测量）。
