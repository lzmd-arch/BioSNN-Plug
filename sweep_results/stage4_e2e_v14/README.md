## 边界

1. v14 是**按 K 选门**（K4 shrunk / K8 diag），不是统一门；门选择在预注册里固定。
2. 失败是 s=2 的弃权，不是 WM/DPAR；K8 s=2 的 R² 0.90–0.903、DPAR 0.939、状态 0.12 都正常。
3. K4-s2-n0.5 只差 0.024；K8-s2 三档差 0.034–0.098。
4. 按预注册不调阈值/覆盖率/门；下一步需要针对 s=2 的更强特征或不同臂（snapshot85/长 τ 组合）。
