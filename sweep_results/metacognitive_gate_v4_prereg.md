# 预注册：阶段四元认知 v4——e2e v3 上的本地风险控制（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** e2e v3 的唯一失败项是 OOD 弃权：
AUROC **0.8350** 过线，但把阈值钉在 in-dist 80% 覆盖时弃权只有 **0.7056**。注意：
**对置信度做单调重标定不会改变固定覆盖率下的弃权率**——弃权由排序决定。要改善它，必须
换决策规则或换特征，而不是“把温度调一调”。本预注册先修一个方法问题，再检验一个局部
密度门。

## 先修的方法问题

v3 的阈值直接在**测试集** `confidence` 上取 80% 分位（transductive）。v4 增加独立的
**校准集**：阈值只在 500 幕 in-dist 校准集上取；测试集与 OOD 不参与拟合。

## 数据（复用 v3 主档生成器）

K=8、σ=0.3、t=100；5 个种子；每种子：

| 分片 | 幕数 | 种子偏移 | 用途 |
| :--- | :--- | :--- | :--- |
| train | 2000 | `seed` | 读出、5 成员、世界模型 |
| calibration | 500 | `seed + 30_000` | **只**拟合门与阈值 |
| test | 500 | `seed + 10_000` | 评估覆盖率/选择性误差 |
| OOD | 500 | `seed + 20_000` | A/B ×3，评估弃权/AUROC |

模型与 v3 完全一致：WM v4 局部 RLS（δ=1000）、5 成员分歧、世界模型一步惊喜。

## 特征（测试时都可得）

1. `disagreement`：5 成员预测的逐维标准差均值；
2. `surprise`：世界模型一步预测残差平方均值；
3. `state_norm`：最终 28 维状态的 L2 范数。

`state_norm` 是**尺度敏感**特征；本轮 OOD 正是 A/B ×3 的尺度偏移，所以它在原理上会
有帮助。这是本任务的定义，不是一般 OOD 检测能力。

## 门（主门先写死）

**主门：3 维高斯密度（local Gaussian novelty）**

- 在 calibration 上标准化 `[disagreement, surprise, state_norm]`，拟合均值与协方差；
- 置信度 = 负 Mahalanobis 距离；
- 阈值 = calibration 置信度的 20% 分位（目标 80% 覆盖）。

对照臂（只报告，不参与主判据）：

- `zsum`：v3 的 `-z(disagreement) - z(surprise)`，阈值改用 calibration 20% 分位；
- `gauss2`：只用 `[disagreement, surprise]` 的二维高斯；
- `knn3`：3 维标准化空间中对 calibration 的 5 近邻平均距离，取负作置信度；
- 所有阈值都只在 calibration 上取。

## 判据（主门，5 种子均值）

1. test 覆盖率在 **0.78–0.82**；
2. 80% 覆盖选择性 MSE **≤0.10**；
3. OOD 弃权 **≥0.80**；
4. OOD AUROC **≥0.8350**（不低于 v3）；
5. 四条全过 → `metacognitive_v4_ready=true`；否则报边界，不换门、不调阈值/特征。

**报告义务**：四个门的结果全部报；主门失败时，即使某个对照臂过线，也只能写“探索性”，
不能追认成主结果。不能因为 `state_norm` 好用就把它说成通用 OOD 能力。

## 不做什么

- 不在 test/OOD 上拟合均值、协方差、阈值或特征权重；
- 不调特征集合、近邻数、覆盖率、阈值分位；
- 不把 OOD 当真实世界分布偏移：这里只有 A/B ×3 的尺度偏移；
- 不把“弃权提高”写成“模型更知道不知道”；它只是决策规则在给定特征上的排序变化。
