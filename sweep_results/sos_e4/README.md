## 为什么加了墙还不够（这一轮的真正产出）

**沿墙走本身就是个有记忆的策略**：要紧的从来不是"此刻哪边有墙"，而是"我一直把哪只手放在墙上"。
四邻墙位是**瞬时观测**，而"贴左墙走"要求维持一个**隐藏状态**（我在贴哪一侧）。

也就是说：加了墙位之后，任务**仍然是 POMDP**，只是隐藏状态从"全图"变成了"我正在跟着哪面墙"。

这与 ADR-0030 的设计图正好对上——图里「工作记忆」那一块在 SoS 中的角色写的是"存储搜索状态"，
而 E4 证明它现在是**承重的**，不是可选的。

## 按预注册的死亡条件办：停线

> E4-0 不过 → **停这条线**，不调超参；写分析说明"四邻墙仍不够"，
> 下一步要讨论的是"给全图"还是"给记忆（WM）"，那是一个需要用户拍板的设计岔路。

**所以这一轮不跑 E5，也不再调轮数或学习率。**

## 岔路（需要用户拍板）

| 方案 | 做法 | 代价 | 风险 |
| :--- | :--- | :--- | :--- |
| **A 给记忆** | 状态加上「已经观测到的墙图」或一个可学习的循环状态（WM） | 中：要把阶段四的 WM 接进来 | 状态空间变大，训练更难；但符合 ADR-0030 的设计图 |
| **B 给全图** | 直接把整张迷宫当观测 | 低：改一行 | **回避了"搜索"这件事**——有全图就不需要探索了 |
| **C 换任务** | 换一个不需要地图记忆的规划任务 | 中 | 又一次换掉要解释的现象 |

**倾向 A**：它是唯一同时保住"搜索"这个现象、又用上阶段四工作记忆的选项。
但它会把 SoS 与 WM 的接口变成下一个要设计的东西，工作量比前四轮大。
