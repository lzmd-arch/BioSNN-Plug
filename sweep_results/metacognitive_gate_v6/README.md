# 元认知 v6：量化 OOD 与有效性门（2026-10-27）

预注册：[`metacognitive_gate_v6_prereg.md`](../metacognitive_gate_v6_prereg.md)。
对 A/B 输入做逐元素符号量化、目标保留原始幅度；先检查 OOD 误差是否真的升高，再解释弃权。
5 个种子。

## 结论

**有效性门通过，性能门失败：`quantization_ood_ready=false`。**

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| 有效性：量化 OOD 全量 MSE / in-dist | ≥2× | **6.38×**（0.4344 / 0.0681） | 过 |
| test 覆盖率 | 0.78–0.82 | **0.8028** | 过 |
| 选择性 MSE | ≤0.10 | **0.06745** | 过 |
| 量化 OOD 弃权 | ≥0.80 | **0.1716** | **未过** |
| 量化 OOD AUROC | ≥0.75 | **0.4876** | **未过** |

这次不是操作化失败：量化把全量误差从 0.0681 推到 **0.4344（6.38×）**，模型确实不会做；
但 v4 的主门反而把 OOD 判得**更像 in-dist**（AUROC 0.4876 < 0.5，弃权 0.1716）。这是
比“没检测到”更糟的失败方向。

## 四个门在量化 OOD 上

| 门 | 弃权 | AUROC | OOD 全量 MSE |
| :--- | :--- | :--- | :--- |
| zsum | 0.2140 | 0.5025 | 0.4344 |
| gauss2 | 0.1952 | 0.4957 | 0.4344 |
| **gauss3（主门）** | **0.1716** | **0.4876** | **0.4344** |
| knn3 | 0.1860 | 0.4906 | 0.4344 |

四个门全部在 chance 附近或以下；这不是阈值问题，是特征本身对“信息丢失型”偏移不敏感：
符号量化后的线索幅度固定、状态更平滑，成员分歧/世界模型惊喜/状态范数都没有变大。

## 尺度 sanity

| 门 | 尺度 OOD 弃权 | 尺度 OOD AUROC | 尺度 OOD 全量 MSE |
| :--- | :--- | :--- | :--- |
| gauss3 | **0.8456** | **0.9003** | 0.3312 |

尺度 OOD 复现 v4；同一套特征在尺度上有效、在量化上失效。**v4 的 ready 只能限定在
A/B ×3 这一类尺度偏移**。

## 边界

1. 这是合成量化偏移（`sign(a)`），不是自然 OOD；结论不外推到真实传感器故障。
2. `quantization_ood_ready=false` 是**有效的负结果**：有效性门 6.38× 过，性能门两条未过。
3. 不改变 v4 的尺度结论（0.8456/0.9003），也不改变 `e2e_v3_ready=false`。
4. 四个门共享同一组特征；它们同时失败说明问题在特征族，不在某一个距离度量。
5. 5 个种子、500 幕；单次运行 59.8 s；没有调阈值/特征/覆盖率。

## 下一步

要覆盖信息丢失型 OOD，需要能测“输入信息量与任务所需信息不匹配”的信号，例如：
**读出重建误差的校准残差**（但测试时无目标，需用可观测的代理）、**多尺度一致性**、
或**状态-输入互信息/可逆性**特征。继续调现有三个特征的阈值不会改变 AUROC 0.49 的排序。
