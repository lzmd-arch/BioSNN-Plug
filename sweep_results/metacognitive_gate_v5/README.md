# 元认知 v5：正交旋转 OOD 检验——**有效性检查失败，旋转不是 OOD**（2026-10-27）

预注册：[`metacognitive_gate_v5_prereg.md`](../metacognitive_gate_v5_prereg.md)。
本想把 v4 的尺度 OOD（A/B ×3）换成保范的正交旋转，检验 `state_norm` 的增益是否只对
尺度有效。结果发现：**旋转对 A/B 高斯线索不构成 OOD**——模型在旋转后的任务误差与
in-dist 逐位相同。因此本轮不能回答“v4 是否适用于尺度无关 OOD”，`scale_independent_ready=false`
也不是“门失败”的证据。

## 关键证据：旋转后的任务误差没有升高

主门 gauss3，5 种子均值：

| 分片 | in-dist 全量 MSE | 被回答 OOD 的 MSE | OOD 全量 MSE | 弃权 | AUROC |
| :--- | :--- | :--- | :--- | :--- | :--- |
| test（in-dist） | **0.06806** | — | — | — | — |
| rotation | 0.06806 | 0.06794 | **0.06794** | 0.1864 | 0.4995 |
| scale（sanity） | 0.06806 | 0.3000 | **0.3312** | 0.8456 | 0.9003 |

- rotation 的 **OOD 全量 MSE 0.06794** 与 in-dist 全量 0.06806 基本相等；
- scale 的 OOD 全量 MSE 0.3312，是 in-dist 的 **4.9 倍**，所以 scale 是真正的分布偏移，
  v4 的 0.8456/0.9003 复现；
- 旋转后模型并没有变差，门当然不会弃权——**0.186 的弃权在这里是正确行为，不是漏检**。

## 四个门在旋转上的结果

| 门 | rotation 弃权 | rotation AUROC | rotation 全量 MSE | scale 弃权 |
| :--- | :--- | :--- | :--- | :--- |
| zsum | 0.2204 | 0.5057 | 0.06794 | 0.7208 |
| gauss2 | 0.1988 | 0.5070 | 0.06794 | 0.6984 |
| **gauss3（主门）** | **0.1864** | **0.4995** | **0.06794** | **0.8456** |
| knn3 | 0.1908 | 0.5009 | 0.06794 | 0.8296 |

四个门都接近 chance（AUROC ≈0.50），且弃权都低；这不是四个门同时坏掉，而是**输入分片
本身没有偏移**。

## 为什么旋转不是 OOD

1. A/B 是各向同性高斯；正交 `Q` 作用后 `Q a` 与 `a` **同分布**（`N(0, I)`）。
2. 任务是线性的：状态是各线索的线性叠加，读出也是线性；慢 τ 状态里几乎直接保留 A/B，
   读出权重接近恒等，所以 `W(Q a) ≈ Q a`，目标也是 `Q a`——误差不变。
3. 因此旋转只是**坐标变换/任务对称性**，不是“没见过的输入分布”，更不是尺度无关的
   输入 OOD。预注册里“旋转会改变方向、`state_norm` 不再直接指示 OOD”的前提不成立：
   方向变了，但分布和任务关系没变。

## 边界与下一步

1. 本轮**不能**用来评价 v4 的泛化；`scale_independent_ready=false` 是**操作化失败**，
   不是“v4 在尺度无关 OOD 上失败”。不能把 0.186 写成“v4 漏检保范 OOD”。
2. 有效的尺度无关 OOD 必须同时满足：**输入/动力学分布确实变了**，且**任务误差显著升高**
   （例如 ≥2× in-dist 全量误差）；只看输入变换名字不够。下一步应先写这个**有效性门**，
   再谈弃权率。
3. 候选：非高斯线索（稀疏 one-hot / 均匀球面）、时间窗/相位偏移、状态动力学参数偏移；
   但每个都要先通过“误差升高”检查，否则会重复本轮的对称性陷阱。
4. 尺度 OOD 的 v4 结论保持：0.8456/0.9003，但只对 A/B ×3 这一类偏移成立。
