# Axo 真脉冲原型第二轮：稀疏表示 + 序列遍历（结果）

预注册：[`axo_spiking_sparse_prereg.md`](axo_spiking_sparse_prereg.md)。
第一轮：[`axo_spiking_prototype_results.md`](axo_spiking_prototype_results.md)。

## 一句话

**稀疏表示完全保住了行为，而且把 5 万条的存储从 819 MB 降到 25.6 MB；但序列遍历上
速率迭代仍然赢，脉冲没有在任何一个 L 上超过 +5 pp，静态也仍然不达标。结论：
不接进 Axo 默认路径。**

## 1. 稀疏一致性

166 条真库、164 条有词法码；`(idx, weights)` 稀疏码与 `(n, 4096)` 稠密 `A` 对比：

| 指标 | 稀疏 | 稠密 |
| :--- | ---: | ---: |
| 静态 top-1 | 0.9085 | 0.9085 |
| top-1 逐条一致 | **164 / 164** | — |

稀疏表示不是近似：`matvec` / `transpose_matvec` 与稠密切换在 166 条上逐条同序。

## 2. 静态补全

| 臂 | top-1 | top-5 |
| :--- | ---: | ---: |
| 稀疏速率一步 | **0.9085** | 1.0000 |
| 稀疏真脉冲（membrane / none / 同质 / LIF） | 0.8659 | 0.9878 |

差 **−4.26 pp**，仍不满足预注册的 −2 pp 线。与第一轮稠密结果相同——稀疏化没有
改变结论。

## 3. 序列遍历：速率迭代 vs 真脉冲

`W_seq` 只用相邻轮 `t→t+1` 学；查询目标是 `t+L`；线索丢 50% 位。
`rate-one` 是弱基线（只能走一步），真正的对照是 **`rate-iter` 走 L 步**。

| L | n | rate-one | rate-iter | 脉冲最好（配置） | Δ vs rate-iter |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 99 | 0.0000 | **0.7677** | 0.7475（global / hetero 0.5 / β=1） | −2.02 pp |
| 3 | 101 | 0.0000 | **0.4257** | 0.3960（同上） | −2.97 pp |
| 5 | 94 | 0.0000 | **0.0319** | 0.0106（同上） | −2.13 pp |

- 没有任何一档达到预注册的 **+5 pp 胜线**；三档全部是「输」。
- 无侧抑制的膜电位读出在 L=2 只有 0.1818，L=3 0.0495，L=5 0.0000——它靠
  `initial` 能走一步，但反复迭代时被阈值化吃掉。
- **全局抑制 + ALIF** 是最接近的一档，但仍比同预算的速率迭代低 2–3 pp。
- `rate-one` 的 0 是设计使然：它只走一步，目标在 L>1；这也反过来证明这里的
  `rate-iter` 是一个真正有区分度的强基线，而不是第一轮那个到顶的弱任务。

## 4. 规模：存储与单次查询（确定性合成码）

| n | 稀疏字节 | 稠密字节 | 稀疏查询 | 稠密查询 |
| ---: | ---: | ---: | ---: | ---: |
| 200 | 102,400 | 3,276,800 | 0.15 ms | 0.73 ms |
| 2,000 | 1,024,000 | 32,768,000 | 6.68 ms | 12.18 ms |
| 10,000 | 5,120,000 | 163,840,000 | 25.66 ms | 59.59 ms |
| 50,000 | **25,600,000** | 819,200,000（未分配） | **160.73 ms** | — |

- 稀疏化把 5 万条的存储从 **819 MB** 降到 **25.6 MB**，这一层是成功的。
- 但 5 万条单次查询 **160.7 ms**，超过预注册写的 100 ms 线；Axo 的记忆窗口等不起
  这个延迟。要上 5 万条，还得再做事件驱动/图邻居裁剪，而不是只换成稀疏码。
- 这里的时间是 numpy 稀疏 matvec 的墙钟，不是神经形态能效。

## 5. 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 稀疏与稠密 top-1 逐条一致 | 164/164 | **通过** |
| 静态 `spiking ≥ rate − 0.02` | 0.8659 < 0.8885 | **不达标** |
| 序列遍历至少一个 L `spiking > rate_iter + 0.05` | 最好 −2.02 pp | **一个都没有** |
| 5 万条单次查询 ≤ 100 ms | 160.7 ms | **超线** |

**因此：不接进 Axo 默认路径，不加可选 spiking 模式。** 当前证据是：真脉冲能跑、
能稀疏化，但在静态补全和序列遍历上都没有赢过同预算的速率基线，5 万条延迟也还
不够。

## 6. 边界

1. 166 条真实记忆；规模基准是**确定性合成码**，不是真实 5 万条。
2. 序列目标是会话顺序，不是人工语义标注；`W_seq` 是 Hebbian 外积，没有 STDP/e-prop。
3. 事件驱动只作用在“按 n 行遍历”这一层；不是脉冲事件队列，也不是神经形态硬件。
4. 墙钟时间不能论证能效。

## 7. 如果还要继续

- **先解决延迟**：图邻居裁剪 / 只对候选子集做 matvec / 真正的稀疏事件循环；目标是把
  5 万条压到 100 ms 以内，再谈规模。
- **换任务**：需要一个速率迭代做不好、而脉冲动力学有天然优势的任务（例如带噪声的
  重合检测、变长延迟、连续序列），并把 rate-iter 作为固定对照。
- **只有出现明确胜线**，才考虑可选 spiking 模式；否则保持速率路径。
