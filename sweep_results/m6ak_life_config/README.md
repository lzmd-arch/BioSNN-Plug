## 二、两个好角，没有第三点

| 想要的组合 | 配置 | 达到 | 代价 |
| :--- | :--- | :--- | :--- |
| **高维 + 可读** | `gl=2.0, pl=0.5` | PR **64.40**、MLP **0.325**（底板 4.2×） | 整合 0.089 |
| **高维 + 整合** | `gl=1.0, pl=0.5` | PR **108.02**、整合 **0.312** | 解码 0.137 |

**⇒ "高维 / 整合 / 可读"三者在这个动力学族里不能同时成立**，而且不是"没调好"：
两个旋钮各自把量往相反方向推，前沿上只有两个角。

## 三、一条必须撤回的结论

`M6ag` 写过"高维状态确实不可读（非线性也不行）"。**那是在 `g_local=1.0` 一个点上测的。**
本表显示 `g_local=2.0 / p_long=0.5` 给出 **PR 64.40 + MLP 0.325** ——
**高维与可读是能同时成立的。**

`M6ag` 的 README 已加注。**教训：在窄工作点上下的"不可读"结论，必须先扫操作点。**

## 四、一个反直觉的细节

**线性读出（0.479）远高于 1-NN（0.240）。**
线性高、最近邻低 ⇒ 类别是**线性可分但不在状态空间里成簇**的。
这与"信息在若干线性方向上、但整体几何被高维噪声铺开"一致。

## 五、限定

- 3 种子；`per_fam=32`；一个 `field_radius=2`；
- **`g_local` 的可用窗口仍然很窄**（0.5 及以下饱和、2.0 以上未测）；
- 整合与分离的口径与 M11 相同；
- 六判据都是二元门限，**未做多重比较校正**。
