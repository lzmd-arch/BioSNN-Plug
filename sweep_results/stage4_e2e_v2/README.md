- **E 检索 1.000 是“管道通”而不是“難记忆”**：E 是一个分离良好的 2 类 one-hot 线索，
  WM 状态里本来就编码它；字面索引只是把这个离散标签存/取出来。它不推翻情景记忆 v0–v3
  的边界（连续线索检索弱、联想路线不可用）；
