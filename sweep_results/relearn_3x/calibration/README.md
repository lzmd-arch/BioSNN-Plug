## 选择规则（预注册写死）

取满足"warm 初值 <150 ≥2/3 且 scratch 800 回合内达 150 ≥2/3"的**最小**重力。

- **g=18**：warm 初值 <150 只有 **1/3**（139.4）→ **不满足**；
- **g=20**：warm 初值 <150 有 **2/3**（124.8、149.0），scratch 3/3 达 150 → **满足**。

**选定 g=20.0。** 正式种子 78–87，判据与第一轮相同。

## 必须披露的两点

- 校准种子的 Phase A 中位数是 **190.4 < 200**（掌握门）；这是校准批次偏弱，
  不是正式门。正式 78–87 的 Phase A 掌握门单独判；若不过，按预注册报"该种子批次
  不可行"，不换种子。
- 校准的配对比值（中位 0.88）**不用于 3× 统计**；校准只用来选规则难度。
