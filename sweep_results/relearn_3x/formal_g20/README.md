## 结论：**3× 不成立；重力 20 仍然太弱，且提高阈值也不行**

- 旧策略在 R1 的初值 8/10 已经 ≥150——规则变化后依旧不需要重学就过线；
- 比值中位 **0.957**，warm 更快只有 3/10，末值也不保证不更差；
- **探索性**（非预注册）扫了更高的阈值：250 / 300 / 350 的配对中位分别是
  **0.95 / 0.78 / 0.88**，warm 更快 3/9、2/8、2/6——**没有任何阈值给出 3×**。
  这只是诊断，不作为结论；预注册的 150 仍然是唯一正式口径。

机制上最可能的原因：warm 臂按预注册**重跑完整调度**（logit 从 1 退火到 40、Actor lr
从基准衰减），旧策略的尖锐性在前期被重新摊平；等它回到可用的温度，scratch 也追上来了。
这不是"再加一个重力"能解决的；要么改再学习调度（并承认两臂不再只差初始权重），
要么接受这条门在 CartPole 上不可达。
