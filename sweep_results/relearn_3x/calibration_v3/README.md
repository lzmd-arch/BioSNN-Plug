## 校准门：三个候选**全部不合格**

| 门 | 要求 | 杆长 0.30 | 杆长 0.20 | 重力 30 |
| :--- | :--- | :---: | :---: | :---: |
| Phase A 中位 | ≥200 | **186.3** | **186.3** | **186.3** |
| warm 初值 <150 | ≥4/5 | **1/5** | **2/5** | **3/5** |
| scratch 达 150 | ≥4/5 | 5/5 | 5/5 | 5/5 |

- **Phase A 中位 186.3 < 200**：按预注册，**这个 pilot 批次不可用，不选规则、不跑正式**；
- 即使忽略批次问题，warm 初值 <150 的计数也分别只有 1/5、2/5、3/5，**没有候选达到 4/5**；
- scratch 全部可达（5/5），配对比值中位约 1.06，warm 更快 2/5——没有 3× 的迹象；
- 规则从杆长 0.30 加到 0.20、再到重力 30，旧策略的初值下降得很慢（g30 仍有 3/5 ≥150）。

## 结论

按 v3 预注册：**规则族不可行**，不跑正式 93–102，不调阈值/种子/预算。
这不是"再换一个重力"能解决的：旧策略对这三类规则变化都相当鲁棒，而 pilot 批次的
Phase A 本身偏弱；把规则再加硬会同时压低 scratch 的可学性。
