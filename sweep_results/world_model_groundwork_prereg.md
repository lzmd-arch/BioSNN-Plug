# 预注册：世界模型打底（一步动力学，2026-10-25）

**定稿时间：2026-10-25，在任何数据之前。**

**性质：打底，不是阶段四启动。** 阶段四的入口条件（阶段三验收：AF < 8%、重学快 3 倍）
一个都没变；本文件只回答"世界模型的预测对象与测量是否已经站得住"，不训练神经世界模型、
不做多步 rollout、不引入 PINN，也不主张"有了世界模型"。

依据：[ADR-0015](../docs/adr/ADR-0015-world-model-as-phase-four-component.md) 的四条验收
（动作条件化动力学 / 明确的预测对象 / 质量指标 / 想象回路），本打底只覆盖前三条的**地基**。

## 要回答什么

1. 在现有环境（CartPole-v1）上，**一步动力学是否可测**——有没有一个基线能赢过"不预测"？
2. **动作条件化是否成立**——换一个动作，预测必须跟着换；怎么量它？
3. 状态与终止事件要**分开报**；奖励那一侧在 CartPole 上是退化的，必须写明。

## 预测对象（写死）

| 对象 | 定义 | 说明 |
| :--- | :--- | :--- |
| 状态 | `Δs = s' − s`，4 维 | 预测增量而不是绝对值：CartPole 的尺度差异大，绝对值误差会被位置项主导 |
| 终止 | `terminated ∈ {0,1}` | CartPole 里与回报相关的离散量；`truncated` 不算终止 |
| 奖励 | **不评** | CartPole 的即时奖励恒为 1，预测它没有区分力。这是对 ADR「状态与奖励分开报」的**收窄**，不是满足——正式阶段四若换环境，必须补上 |

## 数据

- 环境：`gymnasium` 的 `CartPole-v1`；
- 行为策略：**均匀随机动作**（覆盖广、终止多；它本身不是研究对象）；
- 采集：每个种子训练 200 回合、测试 100 回合，回合按顺序切分（**按回合切，不按步切**，
  避免同一回合的相邻步同时出现在训练与测试里）；
- 种子：0–4（5 个采集种子）；模型拟合是确定性的；
- 每步记录 `(s, a, s', terminated)`；`truncated` 的步保留状态转移，但终止标签为 0。

## 基线（由弱到强，全部 numpy、无梯度）

| 基线 | 它假设什么 | 作用 |
| :--- | :--- | :--- |
| `copy_last` | `Δs = 0`、终止率取训练集基率 | "不做预测"的下界 |
| `mean_delta` | 全局平均 `Δs` | 只看平均漂移 |
| `per_action_mean` | 每个动作一个平均 `Δs` | 动作条件化的最弱形式 |
| `ridge_action` | `Δs` 与终止分数对 `[1, z(s), a, a·z(s)]` 的岭回归（`z` 用训练集标准化，λ=1.0） | 动作条件化的**线性上界**；不是局部学习规则，只作测量标尺 |

`ridge_action` 的特征里显式含 `a·z(s)`：没有它，模型只能学到"两个动作的平均差"，
测不出动作与状态的交互——而那正是"动作条件化动力学"应有的样子。

## 指标（只在测试集上算）

设第 d 维的归一化误差 `NMSE_d = MSE_d / Var_d(s')`，分母用**训练集**的 `s'` 方差。

- **状态**：`NMSE = mean_d NMSE_d`（同时逐维报，θ 与 θ̇ 预计最难）；
- **终止**：AUROC（用模型给的终止分数排序；`copy_last` 的分数是常数，AUROC 记 0.5）；
- **动作条件化**：对测试状态逐个算 `|pred(s,0) − pred(s,1)|`，按训练集 `s'` 的标准差
  逐维归一化后取均值，记为 `action_sensitivity`。忽略动作的模型恒为 0。

## 判据（先写死，看到任何数字之前）

**任务可测**必须同时满足：

1. `ridge_action` 的测试 `NMSE` **≤ 0.90 × `copy_last` 的 NMSE**（相对改善 ≥ 10%）；
2. `action_sensitivity` **≥ 0.01**（预测差至少是状态标准差的 1%）；
3. 终止 `AUROC` **≥ 0.75**。

三条全过 → 一步动力学任务站得住，可以作为阶段四的测量地基；**任何一条不过** →
先修任务（换行为策略、改预测对象、加步长），**不训练更大的模型**。

## 这个打底不做什么

- 不做多步 rollout、不做规划回路（ADR 第四条，阶段四后期）；
- 不做 PINN / 神经算子 / 脉冲世界模型（v7 候选 1 的激活条件未满足）；
- 不主张"世界模型有用"——只主张"这个测量能不能分辨模型好坏"；
- 不改阶段四的入口条件。
