# 预注册修订 1：A2（oracle EMA）的执行条件（2026-10-26）

**修订时间：2026-10-26，在 A2 的任何数据之前。** 原预注册见
[`rstdp_spiking_actor_diagnosis_prereg.md`](rstdp_spiking_actor_diagnosis_prereg.md)。

## 为什么现在才跑 A2

原文写"**A1 失败 → 后面都不用跑（A2）**"。A1 当时确实失败（7/20）；现在
[A1′](rstdp_spiking_actor_fix/README.md) 在修订口径下通过（18/18），且痕迹规则已经换成
符号一致的版本。**A2 的前提条件已满足**，所以补跑；这不是推翻原文的停止规则。

## 执行条件（写死）

| 项 | 取值 |
| :--- | :--- |
| 痕迹规则 | **sign-consistent**（两臂相同；A2 问的是"信号源换成 EMA 后 Actor 能不能学"） |
| 信号 | `ema` = 存活步数 − EMA 基线；`td` = 线性 TD Critic（`S = r + γV(s′) − V(s)`） |
| 回合数 | 300 |
| Actor 学习率 | 1e-4（与原文一致） |
| 特征 / 步长 | 64 / 25 |
| Critic 步长（td 臂） | 1e-2 |
| 评测 | 每 25 回合，10 个贪心回合；`best_steps` 是训练中的诊断值，不是最终权重验收 |
| 种子 | 0、1（原文写死） |
| 设备 | CPU（与记录臂一致；CUDA 的随机流不同，见 actor fix 修订 1 §4） |

## 判据（原样不变）

1. **两个种子上都满足** `ema_best ≥ td_best + 20` 步；
2. 且 `ema_best ≥ 30`（不能只是在 10 步附近抖动）。

两条全过 → **Actor 的更新路径在正确信号下是通的**，瓶颈在 Critic／信用分配；
任一不过 → **Actor 路径本身仍可疑**，下一嫌疑是信用时域（episode 级 S 摊到所有决策）
或策略参数化，另写预注册。

## 不做什么

- 不改回合数、学习率、评测频率、种子；
- 不因为 EMA 臂好看就只报 EMA；两臂的逐种子数值都要报；
- 不把 A2 的 `best_steps` 当成阶段三验收（验收是另一套 10 种子与最终权重口径）。
