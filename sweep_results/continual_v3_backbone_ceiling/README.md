# 换骨干重测任务信息天花板：结果（2026-11-04）

**诊断。** 预注册见 [`../continual_v3_backbone_ceiling_prereg.md`](../continual_v3_backbone_ceiling_prereg.md)。
单种子（0）、CIFAR-100 10×10、三个冻结骨干、同一套探针。
原始数值：`resnet18.json` / `resnet50.json` / `vit_b_16.json`。

## 一句话

**天花板跟着骨干走：ResNet18 0.6512 → ResNet50 0.7166 → ViT-B/16 0.7912。**
ViT **差 0.9pp 没过 0.80**，但机制（任务路由 ≈ 骨干的分类力）在三个骨干上全部成立。

## 结果

| 骨干 | A 原型 | B 全协方差 | C logistic | D kNN | **E MLP（任务）** | **F 细类（100 类）** |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| ResNet18（512） | 0.3009 | 0.5281 | 0.5363 | 0.6377 | **0.6512** | 0.6629 |
| ResNet50（2048） | 0.3304 | 0.5779 | 0.6522 | 0.6750 | **0.7166** | 0.6860 |
| **ViT-B/16（768）** | 0.4618 | 0.6783 | 0.7369 | 0.7747 | **0.7912** | **0.8093** |

（E 是任务路由，10 类；F 是同一网络换 100 类输出、用来量"分类力"。F 只跑了 MLP。）

## 判据

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |
| H-0 | 新骨干确实更强 | 某骨干细类 >0.75 | ViT **0.8093** | ✅ |
| H-1 | 换骨干解决得了 | 某骨干任务路由 ≥0.80 | ViT **0.7912** | ❌（差 **0.9pp**） |

| ViT-B/16 | 0.7593 | 0.7912 | ✅ |

## 三条读数

### 1. 天花板随着骨干的分类力单调上移

0.6512 → 0.7166 → 0.7912，而细类准确率是 0.6629 → 0.6860 → 0.8093。**两者同向、同量级。**

### 2. 任务路由可以**高于**细类准确率（ResNet50 高 3.1pp）

这符合直觉，但值得写明：**10 类判任务比 100 类判细类容易**——干扰项少了 10 倍。
所以"路由 ≈ 细类"不是等式，是**下界关系**：`路由 ≥ 细类 − 0.05`（H-4 用的就是这个形式）。
H-4 的三个点全部成立，其中包括一个反向的（路由更高）。

**推论**：想让路由稳过 0.80，骨干的细类准确率大约需要 **0.80–0.85**。ViT-B/16 正好在 0.8093，
路由落在 0.7912——**这条经验关系直接把"要换多强的骨干"算出来了**。

### 3. 差的 0.9pp 不能靠"再跑一次"补

ViT-B/16 是预注册里三个骨干中最强的一个。要越过 0.80，得换更强的骨干（ViT-L 之类）
或**让特征不再是冻结的**——后者会改变基准的含义（`frontends.py` 明写这条）。

## 这不能说明什么

- **不能**说"CIL 的 ACC 会跟着涨"。CIL 的 0.5855 是在 **ResNet18** 下测的；
  换骨干会改变基准的含义，本轮**没有**重跑 CIL；
- **不能**把 0.7912 代进上一轮那条 `ACC ≈ 0.5855 + 0.4957×(路由−0.528)`——
  那条直线是在 ResNet18 的两个点上定的，换骨干后每任务头的准确率也会变，**不成立**；
- **不能**说"任务推断可行了"。H-1 不过，且 0.8 的门槛是 ADR-0029 写死的。

## 边界

- 单种子；探针 E/F 对三个骨干用的是同一套 512→256→10/100（隐藏层固定 256），
  **没有按骨干调容量**——ResNet50 的 2048 维可能被这个瓶颈压住了，**所以 ResNet50 的数是偏低的**；
- 特征冻结、L2 归一化、CIFAR resize 224，与 CIL 主口径一致；
- 只测了 RESNET18 / RESNET50 / VIT_B_16 三个（仓库 `BACKBONES` 里的全部）。

## 结论

**H-3 成立、H-4 成立。** 换骨干把天花板从 0.65 抬到 **0.79**，但没有越过预注册的 0.80；
机制是清楚的、可外推的：**任务路由的上限由骨干的细类判别力决定**。
