# 记录：CartPole 的训练回合没有种子，因此此前的数字都不可复现

**发现时间：2026-10-18。修复提交见本文件所在的同一批次。**

## 问题

`research/rstdp_spiking/cartpole.py` 的训练回合调用
`run_episode(...)` 时**没有传 `env_seed`**，于是 `env.reset(seed=None)` 使用
gymnasium 在 `make()` 时由**系统熵**初始化的内部 RNG。

后果：**同一个 `--seeds 0` 跑两次，训练轨迹完全不同。** 实测（120 回合）：

```
run A 的逐回合回报：21.0, 11.0, 12.0, 15.0, 22.0
run B 的逐回合回报：24.0, 15.0, 24.0, 27.0, 25.0
```

评测路径当时是**有**种子的（`evaluate()` 给每个评测回合传了 `env_seed`），所以评测本身
可复现；但**被评测的权重来自不可复现的训练**。

## 修复

训练回合改为 `env_seed = seed * 100_000 + episode`。修复后两次相同 `--seeds 0` 的运行
**逐回合回报完全一致**（已用 120 回合验证）。

## 受影响的记录

**2026-10-18 之前提交的所有 `sweep_results/rstdp_spiking/**` 结果均作废**——不是"可能有偏差"，
而是"重跑得不到同一个数"。已删除被冒烟污染的顶层残留；其余目录保留但**不得引用**，见
`sweep_results/README.md` 的标注。

作废清单一览（旧值 → 修复后 5 种子的值）：

| 配置 | 旧（不可复现） | 新（可复现，5 种子） |
| :--- | ---: | ---: |
| 线性 TD（1200 回合） | 109.8 | **51.0** |
| 群体，工作点 `b=0,g=16` | 64.8 | **40.0** |
| 群体 + 稳态 | 69.4 | **53.7** |
| 群体，`gradient` + 归一化（原始默认） | 32.9 | **82.2** |
| 群体，`gradient` + 不归一化 | 60.5（旧表 56.8） | 60.5 |
| 群体，`rate` + 归一化 | 23.0 | 37.2 |
| 群体，有符号读出 | 14.3 / 29.2 | 27.7 |

注：上表"新"列里 `pop_nonorm` 的 60.5 与旧表 56.8 接近，但那是巧合——同一配置的不同运行，
不能据此说"旧数字误差很小"。

## 随之作废的**结论**（不只是数字）

1. "线性 TD 是唯一能学的 Critic，1/5 过 200" → 修复后 51.0、**0/5**。
2. "去掉行归一化更好"、"工作点 `b=0,g=16` 更好" → 修复后**排序反转**，原始默认
   （`b=0.4, g=8` + 归一化）反而是最高的 82.2。
3. "单元级稳态提升稳定性" → 5 种子 53.7 对 40.0，方向还在，但差距落在方差内。

## 更根本的问题：5 个种子分不出这些配置

单种子最好评测从 **9.2 到 156.9** 都在出现。5 个种子的均值标准误约 20–30 步，而各配置之间的
差距也就在这个量级。**此前的整张消融表是在追噪声**，包括那些看起来很有说服力的"机制解释"。

因此本轮之后的口径改为：

* 至少 **10 个种子**；
* 报**中位数 + 四分位区间**，不只报均值；
* 配置之间的比较以**重叠区间**为准，不因均值大小下结论；
* 预注册里的筛选阶段明确标注"只用于决定确认哪个，不作为证据"（这一条之前写过，但没被遵守）。

## 修正后的教训

**"评测有种子"不等于"实验可复现"**——评测的种子只固定了评测，训练里任何一处没播种都会让
整条链路不可复现。以后新增任何 RL 训练入口，第一件事是**同种子跑两遍逐位对比**，并把这条
写成测试。
