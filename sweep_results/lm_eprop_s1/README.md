# S1：递推电流受控时，循环还有没有价值——**没有，前馈最好**（2026-11-06）

**预注册**：[`research/sel/prereg-lm-s1-controlled-rec.md`](../../research/sel/prereg-lm-s1-controlled-rec.md)
**原始数据**：[`s1.json`](s1.json)
**上一轮**：[`../lm_eprop_s0/README.md`](../lm_eprop_s0/README.md)（发现电流尺度缺陷）

## 一句话

**把递推电流压到 0.5× 和 1.0× 之后，两臂都比"无递推"差，而且仍然单调
（0× → 0.717、0.56× → 0.698、1.02× → 0.668）。学习循环权重也不帮忙（0.687）。**

## 结果

同一份语料、同一种子、同预算；只有"递推电流多大、学不学"不同：

| 臂 | test CE | test top-1 | 达成电流比 | 发放率 |
| :--- | ---: | ---: | ---: | ---: |
| **`none`（无递推）** | **1.139** | **0.717** | 0 | 1.07% |
| `rec@0.5`（冻结） | 1.231 | 0.698 | **0.556** | 1.46% |
| `rec@1.0`（冻结） | 1.330 | **0.668** | **1.021** | 2.41% |
| `rec@0.5-learned` | 1.213 | 0.687 | 0.556 → 0.673 | 1.78% |

（`none` 与 S0 逐位一致：1.1392 / 0.7166。）

## 判据

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |
| S1-0 | 标定到位 | 达成值在目标 ±0.15 | 0.556 / 1.021 | ✅ |
| S1-1 | 0.5× 递推有价值 | top-1 +2pp 或 CE −0.05 | −1.9pp / +0.09 | ❌ |
| S1-2 | 1.0× 递推有价值 | 同上 | −4.9pp / +0.19 | ❌ |
| S1-3 | 受控后学循环有用 | 同上（对冻结） | −1.1pp / −0.02 | ❌ |
| S1-4 | 没有受控臂明显变差 | 都 ≥0.697 | 0.698 / **0.668** / 0.687 | ❌ |

**S1-4 我押它会过，押错了**：原以为受控之后至少不会更差，实际 1.0× 掉了 4.9pp。

## 三条读数

### 1. 单调性在"受控"区间仍然成立

```
电流比   0×    → top-1 0.717
         0.56× → top-1 0.698
         1.02× → top-1 0.668
```

S0 给的是 0× / 2.16× / 7.36× 三点；本轮把 0.5–1.0 这一段补上，**仍然是单调下降**。
所以"淹没"不是只在极端情况下才发生的——**只要有递推电流，就在付出代价**。

### 2. 学习循环权重仍然不帮忙（这次不是被淹没）

`rec@0.5-learned`（`w_rec` 动了 **7.2%**）比冻结的 `rec@0.5` 低 1.1pp。
M0b 里"学循环变差"曾被归因于电流淹没，**这一轮排除了那个解释**：在 0.56× 的受控条件下，
学习循环权重仍然没有收益。

### 3. 不是自持振荡

四臂的 `silent_rate`（零输入下跑 50 步）**全是 0**。所以之前的问题不是"网络自持振荡"，
就是**一个大而无信息的电流把 token 信号稀释了**。这条纠正了"自持振荡"的假设。

## 这条结论能说什么

**能说**：在 1,024 神经元、301 条模板语料、2,000 updates 这个工作点上，
**前馈 LIF + 局部读出（CE 1.139 / top-1 0.717）优于任何带循环电流的版本**，
且性能随递推电流单调下降。

**不能说**：
- 不能说"循环在语言建模里永远没用"——这是**一个工作点**、**一层**、**一个任务**；
- 不能把 0.717 当成能力上限（单种子、46 条测试、字符级）。

## 附带发现：A 线也在同一个区间

顺带量了 A 线用的 `EventDrivenEProp`（sMNIST、N=8192、fan-in 32、未训练）：

| 量 | 值 |
| :--- | ---: |
| 直接电流 mean\|·\| | 0.269 |
| 递推电流 mean\|·\|（真实 z） | 0.298 |
| **递推 / 直接** | **1.106** |

**和本轮掉 4.9pp 的 `rec@1.0` 是同一个量级。** 见 [`aline_current_ratio.json`](aline_current_ratio.json)。

**这不推翻 A 线的结论**——A3–A8 的两臂用的是同一个递推，**相对比较仍然成立**（读出值 14–42pp、
32k vs 8k 的 −0.3pp/−0.9pp 都是同条件下的比较）。但它意味着 **A 线的绝对数字可能偏保守**：
"无递推 vs 有递推"在 A 线上从来没测过，那是可以补的一格。

> **2026-11-06 当天补测（A9）：这一格补了，猜想被否。** 三种子中位 0.904 vs A3 的 0.899，只差 **+0.5pp**，逐种子差 −1.3 / +1.7 / +1.2pp。见 [`../brainregions_a9/README.md`](../brainregions_a9/README.md)。**所以"A 线绝对数字偏保守"不成立**——那个"读推电流 1.02× 掉 4.9pp"的斜率不能跨任务外推。

## 边界

- 单种子；测试集 46 条 / 1,369 字符（top-1 的 SE ≈0.9pp）；
- 语料是模板化单轮 SIR，不是对话；
- 只测 N=1,024、一层、一个 τ；只测了 0.5× 与 1.0× 两个受控点。
