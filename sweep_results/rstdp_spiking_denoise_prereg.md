# 预注册：W3 D14——降噪的代价曲线（K 窗平均 / 加长窗口 / 确定性编码，2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（D10–D13 已测，不是猜测）

D13 在同一构造探针上比了四种读出：在 λ=0.10 上中位可分辨度只有 0.58 / 0.64 / 0.65 / 0.60，
而且 **λ 从 0.05 加到 0.30，S 几乎不动**——状态差异与窗口间涨落一起涨。四轮合起来的结论是
**单窗口判决噪声受限**，噪声来自输入脉冲的伯努利编码（每步按发放概率采样）。

D14 只问一件事：**降噪要花多少代价**。

## 协议（同一构造探针，不训练）

构造沿用 D12：`w_{0,1} = weight_norm · ((1−λ)·m ± λ·d)`，`m`/`d` 由种子定（`signed` 口径，
`weight_norm=1`，与真实 Actor 同档）；21 点极角网格、`threshold=1.0`、`n_refractory=2`、
`baseline_period=5`、读出为**硬计数**（Actor 现状）。

三个因子：

| 因子 | 取值 | 含义 |
| :--- | :--- | :--- |
| `K`（每决策平均的独立窗口数） | 1、2、4、8 | 一次动作前重采 K 个窗口取平均 |
| `T`（单窗步数） | 25、50 | 25 是现状 |
| 编码 | `bernoulli`、`deterministic` | 后者把每步输入换成**发放概率本身**（不采样） |

约束：`K·T ≤ 400`（可行性），所以 `T=50` 时 `K ≤ 8`、`T=25` 时 `K ≤ 8`——全部组合都可行。
λ 取 **0.05**（D10 量到训练后真实的相对幅度中位约 4.6%，0.05 是它的上端）与 **0.10**（对照）。
每个（λ, K, T, 编码）组合：每个网格点采 **10 次决策**（每次决策是 K 个独立窗口的平均）。

## 度量（同一个尺子，先写死）

- `sd_ref`：λ=0.05、`K=1`、`T=25`、`bernoulli` 档的**单窗口 Δ 标准差**（网格各点取中位），
  是「真实 Actor 每次决策要面对的噪声尺子」；
- **`S_ref` = 网格上 mean Δ 的极差 ÷ `sd_ref`**——所有臂都用这一把尺子，这样确定性编码
  （自身 sd=0）也能比，不会出现「除以零得无穷」的假绿；
- 另报每臂**自身的**决策级 sd 与 `S_self`（自家 sd 做分母），作诊断。

## 判据（先写死）

1. **能降下来吗**：存在一个（K, T, 编码）组合在 λ=0.05 上 **5/5 种子** `S_ref ≥ 2.0`；
   满足则记 `denoise_path_found=true`；
2. **最便宜的是哪个**：在满足判据 1 的组合里，按**代价 `K·T` 升序**、「不改编码」优先，
   给出推荐组合；
3. **噪声是不是全来自编码**：若 `deterministic, K=1, T=25` 一档的 `S_ref ≥ 2.0`（5/5 种子），
   结论写成「**噪声全来自伯努利编码**，修法在编码，不在平均、也不在读出」；
4. **空对照**：λ=0 时任意组合的 `S_ref ≤ 0.5`。

## 读法护栏

- `S_ref ≥ 2` 只说明「一次决策的信号是现状噪声的两倍」，**不说明 CartPole 分数会涨**；
- K 窗平均是**计算代价**：一个动作要跑 K 个窗口，`K·T` 就是步数倍数，必须一起报；
- 确定性编码在硬件上对应「模拟前端 / 无抖动采样」，不是脉冲网络的原生行为——若只有它过线，
  结论必须写清这是**换了输入编码**；
- 不把「能找到便宜组合」写成「阶段三过了」——D15 才谈训练轮。

## 不做什么

- 不训练网络、不改 STDP、不改读出；
- 不在同一批数据上挑完组合再改判据；
- 不扫 λ 阶梯以外的构造参数（预算、符号结构在 D12 已经测过）。

## 边界

- 公共模式是随机构造的，不是训练后的真实列；
- 「独立窗口」用不同的编码随机流实现，不含 Critic/环境噪声；
- 决策级平均 K 个窗口改变的是**动作节拍**（每步环境推进前多跑 K 个窗口），
  与 CartPole 的 25 步窗口语义要一起看；
- 点状态网格，不是完整状态空间。
