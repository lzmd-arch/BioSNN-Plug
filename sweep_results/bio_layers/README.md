## 一行总结

**四条里两条成立（τ 异质、基因），两条关闭（激素路由、读出维度）；
而"基因"搜出来的最好个体比手设计高 +50.3pp，主导它的是池神经元数。**

## B-1 τ 异质（各池自己的膜时间常数）

| 池 | τ=20（同质） | τ=5 | τ=80 |
| :--- | ---: | ---: | ---: |
| `temp` | 0.309 | **0.417（+10.8pp）** | 0.309 |
| `presence` | 0.353 | 0.306（−4.7pp） | 0.355 |
| `time` | 1.000 | — | 1.000 / τ=200 也是 1.000 |

**判据（≥+5pp）：`temp` 成立，`presence` 不成立。**

**但这条结果的意义不在单个数字**：两个池的**最优点相反**（temp 要快、presence 要慢），
这正好是"异质"存在的理由——同质网络只能有一个有效时间尺度。
把每个池的 τ 各自标定之后，两端都拿到了自己最好的那个点。

`time` 全程 1.000：它的量是**空步数 = 脉冲计数**，与膜时间常数无关。

## B-2 激素路由（"哪条突触可塑"而不是"可塑多快"）

| 池 | 路由关 | 路由 3 条 |
| :--- | ---: | ---: |
| `temp`（lr 0.05，1500 步） | 0.309 / c0.286 | **0.309 / c0.286** |
| `presence` | 0.311 / 0.311 | **0.311 / 0.311** |

**逐位相同。判据（≥+5pp）不成立 ⇒ 关闭。**

**原因不是路由这个想法错，而是它作用在一个几乎不动的量上**：解析编码之后，
学习本身对权重的改变可以忽略（S0 以来第 6 次独立印证），
所以"哪些突触有资格更新"不会产生可测差别。

⇒ **任何只作用于"学习"的机制，在当前工作点上都不可能有效。**
这条比 B-2 本身更重要：它解释了本轮此前所有"标量调制类"失败（脱敏、缩放、分时程激素、分区受体）。

## 两条独立证据指向同一个结论（这一节是本轮最重要的）

B-3 单独测：读出维度 2→4 **没有任何增益**。
B-4 搜基因：**读出维度是候选基因之一，却一次都没被选中**。

⇒ **"读出维度是杠杆"这条（R4/R8/R11）不能外推到池上。**
它的原始证据是 **1,024 个神经元的语言模型**加重到 4,096 维读出；
而这里是 **16→32 个神经元的池**，读出宽度根本不是瓶颈，**编码分辨率才是**。

**修正后的说法**：*宽度只有在它买到"新的分辨率"时才是杠杆。*
池里多 16 个神经元，买到的是温度计码多 16 级阈值（真的更细）；
把 16 维读出复制成 64 维，买不到任何新东西。

## 与"扩大神经元规模"的关系

容量轴归档（A4/A8：8k vs 32k = −0.3 / −0.9pp）说的是**整网络规模**；
这里的池 16→32 是**编码分辨率**。两者不矛盾，但结论必须分开写：

- **加神经元但不加分辨率**（整网络变宽、读出复制）→ 无用；
- **加神经元且提高编码分辨率**（池内阈值变密）→ **+50pp**。

## 四问

1. **预算截断？** 否——全部是纯编码测量（`lr-sensor=0`），与步数无关；曲线在 200 步即稳定。
2. **跨语料 / 跨预算？** 不跨。同任务、同批样本、同编码。
3. **单边指标？** 只报 top-1（两个探针都看）。**没有报成本**——池 32 是 2 倍神经元，
   这是一处**未计入的代价**，下一轮要补上"每提升 1pp 要多少神经元"。
4. **先验未兑换？** 不涉及。

## 不能说的

- 不能说"生物特性有用"——**作用在信息几何上的有用，作用在标量/学习上的没用**，
  这是本轮 16 次实验给出的分界线；
- 不能把 +50.3pp 说成"模型变强了"——它是在**一个 10 分类的合成任务**上的编码增益，
  换任务、换维度（比如 16 维向量池）未必保持；
- 不能说"基因搜索应该继续扩大"——48 个个体里前六名已经收敛到同一个基因型，
  再采样很可能只是在拟合评测噪声。
