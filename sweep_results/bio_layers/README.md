## B-1 τ 异质（各池自己的膜时间常数）

| 池 | τ=20（同质） | τ=5 | τ=80 |
| :--- | ---: | ---: | ---: |
| `temp` | 0.309 | **0.417（+10.8pp）** | 0.309 |
| `presence` | 0.353 | 0.306（−4.7pp） | 0.355 |
| `time` | 1.000 | — | 1.000 / τ=200 也是 1.000 |

**判据（≥+5pp）：`temp` 成立，`presence` 不成立。**

**但这条结果的意义不在单个数字**：两个池的**最优点相反**（temp 要快、presence 要慢），
这正好是"异质"存在的理由——同质网络只能有一个有效时间尺度。
把每个池的 τ 各自标定之后，两端都拿到了自己最好的那个点。

`time` 全程 1.000：它的量是**空步数 = 脉冲计数**，与膜时间常数无关。

⇒ **任何只作用于"学习"的机制，在当前工作点上都不可能有效。**
这条比 B-2 本身更重要：它解释了本轮此前所有"标量调制类"失败（脱敏、缩放、分时程激素、分区受体）。

## 两条独立证据指向同一个结论（这一节是本轮最重要的）

B-3 单独测：读出维度 2→4 **没有任何增益**。
B-4 搜基因：**读出维度是候选基因之一，却一次都没被选中**。

⇒ **"读出维度是杠杆"这条（R4/R8/R11）不能外推到池上。**
它的原始证据是 **1,024 个神经元的语言模型**加重到 4,096 维读出；
而这里是 **16→32 个神经元的池**，读出宽度根本不是瓶颈，**编码分辨率才是**。

**修正后的说法**：*宽度只有在它买到"新的分辨率"时才是杠杆。*
池里多 16 个神经元，买到的是温度计码多 16 级阈值（真的更细）；
把 16 维读出复制成 64 维，买不到任何新东西。

## 与"扩大神经元规模"的关系

容量轴归档（A4/A8：8k vs 32k = −0.3 / −0.9pp）说的是**整网络规模**；
这里的池 16→32 是**编码分辨率**。两者不矛盾，但结论必须分开写：

- **加神经元但不加分辨率**（整网络变宽、读出复制）→ 无用；
- **加神经元且提高编码分辨率**（池内阈值变密）→ **+50pp**。

## 不能说的

- 不能说"生物特性有用"——**作用在信息几何上的有用，作用在标量/学习上的没用**，

# 追问：+50.3pp 里有多少是**探针**给的？

**预注册**：`research/sel/prereg-gene-resolution-v1.md`
**动机**：池 16→32 同时改了"神经元数量"和"阈值级数"。而且原型探针对**维度加权**敏感——
把一维复制成两维，等于给那一维加倍权重。必须另有一个**自己学权重**的读出才能分开。

新增第三个探针：**岭回归闭式解**（训练/留出按缓冲条目 70/30 分开，`hit_lin`）。

## 一、三个探针给出三个不同的故事

| 配置 | 神经元 / 阈值级数 | 欧氏原型 | 余弦原型 | **学出来的岭回归** |
| :--- | :--- | ---: | ---: | ---: |
| A 基线 | 16 / 16 | 0.402 | 0.414 | **0.439** |
| B 个数与级数都翻倍 | 32 / 32 | 0.591 | 0.591 | **0.509** |
| C 只加个数 | 32 / **16** | 0.500 | 0.500 | **0.408** |

- **R-1 过**：B 相对 A 在原型探针上是 +48.9pp（复现基因搜索）；
- **R-2 的答案取决于探针**：
  - 原型探针：C − A = **+30pp** ⇒ 按预注册读作"增益来自数量"；
  - 学习读出：C − A = **−3.1pp** ⇒ 读作"增益来自分辨率"。
  
  **两个探针给出相反结论 ⇒ R-2 这条判据本身写得不够**（没有指定探针）。照实登记，不改判据。

## 二、把池继续放大之后（学习读出，`l`）

| 池 | τ=20 | τ=5 |
| ---: | ---: | ---: |
| 16 | 0.439 | 0.439 |
| 32 | 0.509 | 0.608 |
| **64** | **0.811** | 0.738 |
| 128 | 0.509 | 0.622 |

**最好的点是池 64 / τ=20（0.811，相对基线 +37.2pp）**，而**基因搜索的搜索空间上限就是 32**
——它找到的是**边界**，不是顶点。这是搜索空间设计的错，不是搜索本身的错。

## 三、修正后的两条结论

1. **"+50.3pp" 是探针给的，不是模型给的。** 换成会自己学权重的读出，池 32 只有 **+7.0pp**；
   真正的顶点在**池 64（+37.2pp）**，而那不在搜索空间里。
2. **数量和分辨率都起作用**（在池 32 / τ=5 上：满分辨率 0.608 对复制级数 0.534，
   分辨率值 +7.4pp；而只加数量相对池 16 值 +9.5pp）。**两个都不是免费的**——
   池 64 是 4 倍神经元。

## 四、这一轮第 7 次"仪器把模型判错"

前六次：余弦探针抹掉幅度编码、多池共用缓冲污染原型、`time` 标签脱钩、`presence` 游走长度、
单跑/共存初值不同源、`b0` 初值让基线变成锐化模型。
**这一次是"原型探针把维度加权当成信息"。**

⇒ 经验：**任何"某配置更强"的读数，必须在至少两种差异很大的读出下重复**
（一个无参数、一个会学权重），否则结论是仪器的。

# 泛化扫（池 16 vs 64，五个池）与标定工作

## 一、五个池 × 池 16/64（学习读出 `l`）

| 池 | 池16 τ20 | 池64 τ20 | 池64 τ5 |
| :--- | ---: | ---: | ---: |
| `temp` | 0.439 | **0.811** | 0.825 |
| `time` | 0.500 | 0.500 | 0.500 |
| `memory` | 0.458 | **0.722** | 0.717 |
| `persona` | 0.583 | **0.769** | 0.755 |
| `presence` | 0.314 | **0.445** | 0.400 |

**池 64 在四个池上都更好**；`time` 完全不动。

**`time` 是个反例**：原型探针 **1.000**，线性读出 **0.500**，而且 16/64/τ5 三档一模一样。
不是噪声——**最近原型是 Voronoi 划分，不是线性划分**。十类沿一个标量排开时 Voronoi 切得开、
线性 one-vs-rest 切不开。

⇒ 上一节"增益是探针给的"这句话**说得太重**。准确的说法：
**增益是真的（两种读出下都提升），幅度取决于读出的模型类；产品该用能表达这套码的那个（学习到的类中心）。**

## 二、五池共存（池 64，2000 步）

| 池 | 单跑 | 五池共存 |
| :--- | ---: | ---: |
| `temp` | 0.811 | 0.289 |
| `time` | 0.500 | 0.400 |
| `memory` | 0.722 | 0.412 |
| `persona` | 0.769 | 0.297 |
| `presence` | 0.445 | 0.341 |

**共存显著伤害了学习读出**（`memory` −31pp、`persona` −47pp）。

### 原因找到了：**正交编码的标度漏了 √n**（第 10 个仪器 bug）

单位范数输入投到 n 个正交方向上，每个投影系数只有 **O(1/√n)**。
编码器原来按 `thr/0.5` 给标度，**不带 √n** ⇒ 池 64 每个神经元只拿到阈值的约一半，
**整池静默**（发放率 0.03）。池 16 恰好没暴露它（1/√16 = 0.25，勉强越过阈值）。

修成 `2·thr·√n` 之后（五池共存，池 64，400 步）：

| 池 | 修复前 | **修复后** |
| :--- | ---: | ---: |
| `memory` | 0.434 | **0.808** |
| `persona` | 0.334 | **0.752** |
| `time` | 0.500 | 0.500 |
| `temp` | 0.289 | 0.189 |
| `presence` | 0.280 | 0.203 |

⇒ **"共存伤害 memory/persona"不是共存造成的，是编码器的标度错。**

### 仍然未解：`temp` / `presence` 在多池下掉

直接对比过：同一个 temp 输入、同一个编码块，**单池与两池的池内动力学逐位相同**
（发放率都 0.213，逐类发放率也相同）；在受控脚本里用两池模型跑同一套读出流程，
**线性与原型都到 1.000**。⇒ 模型与读出都没问题，**差别在训练器的记账里**，还没找到。

**记为开放项，不许写成"共存有害"。**

但它**没有**解决这个塌陷。

| `temp` | 1.000 / **1.000** | 1.000 / **1.000** |
| `time` | 1.000 / 0.400 | 1.000 / 0.400 |
| `memory` | 0.727 / **0.822** | 0.766 / 0.817 |
| `persona` | 0.739 / **0.822** | 0.798 / 0.825 |
| `presence` | 0.411 / 0.570 | 0.414 / **0.588** |

**池 16 与池 64 的差别在噪声内。**

⇒ **"池 64 比池 16 好 +50pp"作废**——那是泄漏造成的，不是"编码分辨率"。
基因搜索找到池 32/64 也是同一个原因。**架构层的那个结论要撤回。**

## 二、五池共存 vs 单池（池 64，400 步）

修复前 vs 修复后（五池共存、池 64）：

| 池 | 修复前 | **修复后** |
| :--- | ---: | ---: |

**泄漏的存在，让"多池共存有害"和"池 64 更好"两条结论同时成立又同时是假的。**

# 总神经元 32K 与"逐池不同大小"（2026-11-15）

## 一、32K 总神经元：**与 220 个神经元逐位相同**

同一任务、同一编码、同样 20 步：

| 总神经元 | temp（欧氏 / 学习） | memory（欧氏 / 学习） |
| :--- | :--- | :--- |
| **220**（文本 156 + 两池各 64） | 1.000 / 1.000 | 0.688 / 0.616 |
| **32,768**（文本 32,640 + 两池各 64） | **1.000 / 1.000** | **0.688 / 0.616** |

**完全一样，一位不差。**

原因不是"规模没用"，而是**结构上不可能有用**：文本→池每一步都被强制清零，
所以文本神经元的数量**在定义上**影响不到池。要看到 32K 的好处，
必须去训**文本那条路**——而那条路的四测四负还没翻案。

代价：32K 每步约 **6 秒**（220 个神经元约 0.02 秒），300 倍。

## 二、逐池不同大小（`--pool-sizes`）

`temp:16, memory:{64,128}, presence:32`：

| memory 神经元 | 欧氏原型 | 学习读出 |
| ---: | ---: | ---: |
| 64 | 0.767 | **0.812** |
| 128 | **0.819** | 0.769 |

**加倍神经元：原型 +5pp，线性 −4pp。** 又是两个读出方向相反——
128 维特征配 140 个训练样本，线性读出开始过拟合。

⇒ 逐池不同大小**能用**，但**没有任何一个池因为变大而变好**。这与"池 16 = 池 64"一致。
