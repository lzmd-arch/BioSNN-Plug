# 图邻居扩展候选（50k 速率路径）：结果

预注册：[`axo_rate_graph_expand_prereg.md`](axo_rate_graph_expand_prereg.md)。

## 一句话

**这条路不采用。** 50k 图构建 **738.8 s**，邻居扩展几乎不增加候选（M0=2000 → 2031，
M0=5000 → 5087），且 50k 上 top-1 一致率是 **0/20**；同脚本在 n=2,000 / 5,000 上是
1.0。50k 这次结果不可用，速率路径继续用固定 M=15,000。

## 小规模对照（确认脚本本身能工作）

| n | 图构建 | 配置 | 一致率 | 候选 |
| ---: | ---: | :--- | ---: | ---: |
| 2,000 | 0.9 s | M0=2000, M1=5000 | 1.0000 | 2,000 |
| 5,000 | 6.9 s | M0=2000, M1=5000 | 1.0000 | 2,353 |
| 5,000 | 6.9 s | M0=5000, M1=10000 | 1.0000 | 5,000 |

## 50k 结果（不可用）

| 配置 | 一致率 | 平均候选 | 均值 | p95 |
| :--- | ---: | ---: | ---: | ---: |
| M0=2000, M1=5000 | 0.0000 | 2,031 | 58.6 ms | 79.4 ms |
| M0=2000, M1=10000 | 0.0000 | 2,031 | 53.6 ms | 66.2 ms |
| M0=5000, M1=10000 | 0.0000 | 5,087 | 92.2 ms | 108.9 ms |
| M0=5000, M1=15000 | 0.0000 | 5,087 | 93.3 ms | 110.3 ms |

- 图构建 **738.8 s**（约 12 分钟），远高于文档里 50k 的 259 s；这台机器当时的负载
  也有影响。
- 邻居扩展只多出 31 / 87 个候选：在 `min_weight=0.10` 下，50k 放大语料的图非常稀，
  邻居几乎都在种子里或没有边。
- **一致率 0/20 与小规模 1.0 矛盾**；按 20 个探针、1 条 = 5 pp，这不能作为“图扩展
  无效”的科学结论，只能记为**这次 50k 运行不可用**（可能是 50k 候选/图映射在
  该规模下的实现问题，尚未定位）。不采用，也不再在这条路上追加时间。

## 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 一致率 ≥ 0.99 | 0.00（50k 运行异常；小规模 1.00） | **不通过** |
| 查询 ≤ 100 ms | 部分配置通过 | 但正确性不成立 |
| 平均候选 < 15,000 | 是 | 无意义（正确性失败） |

## 结论

- 图邻居扩展在 50k 上**没有可用的证据**：构建成本过高、图过稀、50k 运行结果异常。
- 速率路径最终仍维持**固定 M=15,000**（最小实测 14,000；均值 70–90 ms，p95 约
  106 ms）。
- 如果以后还要做图扩展，先解决 50k 图的构建时间与稀疏度，并在小规模上把 50k 的
  映射/候选实现逐条核对；当前版本不进入 Axo。

## 复现

```bash
uv run python scripts/axo_rate_graph_expand.py --n 5000 --probes 5
# 50k 运行（不采用）：
uv run python scripts/axo_rate_graph_expand.py --n 50000 --probes 20
```
