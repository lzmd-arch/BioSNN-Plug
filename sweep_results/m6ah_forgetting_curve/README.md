# M6ah：**遗忘曲线 —— τ=150 步、平台 0.445、R²=0.98**

## 用户定的原则

> 记忆衰减在真实生物是存在的（艾宾浩斯曲线），但这套系统的记忆既然有稳定介质，
> 那么符合遗忘规律和比人类更好的记忆就不再冲突。

⇒ **可及性衰减 ≠ 信息丢失。** 本实验量它的**形状**与**可调性**，不把衰减当缺陷。

## 结果（4 种子 × 8 族 × 16 条；拟合 `acc = floor + P + A·exp(−t/τ)`）

| `g_field` | 发放 | 曲线 | **τ** | **平台** | 快分量 | **R²** |
| ---: | ---: | :--- | ---: | ---: | ---: | ---: |
| **1.0（在窗内）** | 0.148 | 0.570 → 0.531 → 0.484 → 0.438 → 0.453 → 0.445 | **150 步** | **0.445**（+0.374） | 0.196 | **0.980** |
| 0.5（**出窗，作废**） | 0.268 | 0.516 → 0.406 → 0.320 → 0.297 → 0.281 → 0.273 | 105 步 | 0.282（+0.212） | 0.426 | 0.995 |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| AH-0 发放在窗内 | 1/2 档 |
| **AH-1 有指数遗忘曲线（R²>0.9）** | **过**（R²=0.980） |
| AH-2 τ 可调（极差 > 2×） | **不过**（窗内只有 1 档，测不了） |

## 一、为什么要双分量

单分量不够：`M6ae` 实测 1024→2048 只掉 0.016 —— **已经平了**。
强行单指数会把"稳平台"算成"还在衰减的长尾"。双分量拟合给 R²=0.98。

**平台 = 记录还在；快分量 = 多容易被想起。** 这正是"稳定介质 + 遗忘规律"的两层。

## 二、场强同时控制两件事

| `g_field` | 平台 | τ |
| ---: | ---: | ---: |
| 0.5（出窗） | 0.282 | 105 |
| 1.0 | 0.445 | 150 |

**场越强：记得越多、忘得越慢。** 两个量同向 —— 对这个系统来说这是**一个旋钮控制的两个可标定量**。

## 三、限定

- **只有一档在窗内** ⇒ AH-2 测不了；`g_field=0.5` 那档发放 0.268 出窗，只作趋势参考；
- 4 种子；`t` 六个点；平台是拟合参数，不是直接测量；
- 拟合的 τ 网格是 `10·1.04^k`，分辨率约 4%；
- **这里的"遗忘"是读出可及性，不是信息销毁**（网络权重未变）。这一点是本实验的立论前提，也是它的边界。

## 补测（`gf=1.5`）：τ 可调性只是**弱证据**

| `g_field` | 发放 | 曲线 | τ | 平台 | **R²** |
| ---: | ---: | :--- | ---: | ---: | ---: |
| 1.0 | 0.148 | 0.570 → 0.531 → 0.484 → 0.438 → 0.453 → 0.445 | **150** | 0.445 | **0.980** |
| 1.5 | 0.103 | 0.539 → 0.547 → 0.539 → 0.469 → 0.383 → 0.453 | 415 | 0.419 | **0.762** |

判词写"AH-2 过（极差 2.77× > 2×）"，但**这个"过"要打折扣**：

- `gf=1.5` 的曲线**非单调**（先平、再降、末尾又升），R² 只有 **0.762**；
- 拿一个**拟合失败**的 τ 去和拟合良好的 τ 比可调性，不能作为证据。

**诚实的写法**：τ=150 步在 `gf=1.0` 上是可信的（R²=0.98）；
**"τ 随场强可调"目前只有弱证据**，要写成"未定"，除非补第三档或加种子把 `gf=1.5` 做干净。
