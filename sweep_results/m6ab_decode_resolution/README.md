# M6ab：**高维状态确实不携带历史 —— 不是特征分辨率的锅**

## 为什么测

M6x 里 `radius=2` 给出 PR 59.6 但解码只有 0.073（底板 0.062）。两种解释：
① 读出用了 8×8 空间桶（64 维），把 ~60 维状态抹平了；② 高维状态真的不带历史。

用**全分辨率**（逐神经元发放，1024 维）重测即可分开。

## 结果（4 种子 × 8 族 × 16 条）

| 配置 | **全分辨率** | 64 桶 | 底板 |
| :--- | ---: | ---: | ---: |
| `radius=2`（局部） | **0.109** | 0.172 | 0.062 |
| `radius=32`（全局） | **0.508** | 0.398 | 0.062 |

| 判据 | 结果 |
| :--- | :--- |
| AB-1 局部场下全分辨率可解码（> 底板 + 0.15） | **0.109，不过** |

## 一、判决

**是 ②，不是 ①。** 全分辨率只有 0.109，离 0.212 的线差得远。
而 64 桶反而更高（0.172）—— 粗特征把噪声平均掉了，说明这个状态里的"信息"主要是噪声。

⇒ **高维 ≠ 有信息。** 局部场造出的 60 维状态在"关于历史"这件事上是空的。

## 二、机制上说得通

`g_local=1` 时发放 0.0198 × 1024 ≈ **20 个神经元**，等于起搏神经元数（`p=0.02`）。
**只有起搏神经元在放电 ⇒ 状态是"哪些起搏神经元亮着"，与历史无关。**

这也解释了为什么加输入增益无效（`scale` 翻倍发放不变）：输入被局部抑制挡在门外。

## 三、这条对总目标意味着什么

今晚想要的"高维个体状态"，在**这个工作点上**是空的。
但这不是机制的死刑 —— 是**操作点**的问题。`M6ac` 用更低的 `g_local` 找
"输入能进来、又保留空间结构"的工作点，那是这个机制还有没有希望的最后一次检验。

## 四、限定

- 4 种子；全分辨率探针在 1024 维、128 个样本上做岭回归（λ 由留出集选），
  **样本数远小于维数**，所以 0.109 是**下界**；
- 只测了线性可解码性。**非线性读出可能更高，未测** —— 这是本结论最重要的未排除项。
