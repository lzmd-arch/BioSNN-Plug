# M6ab：高维状态在**线性**探针下读不出（**此结论已按用户更正降级**）

## 为什么测

M6x 里 `radius=2` 给出 PR 59.6 但解码只有 0.073（底板 0.062）。两种解释：
① 读出用了 8×8 空间桶（64 维），把 ~60 维状态抹平了；② 高维状态真的不带历史。

用**全分辨率**（逐神经元发放，1024 维）重测即可分开。

## 结果（4 种子 × 8 族 × 16 条）

| 配置 | **全分辨率** | 64 桶 | 底板 |
| :--- | ---: | ---: | ---: |
| `radius=2`（局部） | **0.109** | 0.172 | 0.062 |
| `radius=32`（全局） | **0.508** | 0.398 | 0.062 |

| 判据 | 结果 |
| :--- | :--- |
| AB-1 局部场下全分辨率可解码（> 底板 + 0.15） | **0.109，不过** |

## 一、判决（**已于 2026-11-16 按用户更正降级**）

原始结论写的是"高维状态确实不携带历史"。**那句话是错的，已收回。**

> **用户更正**：高维隐状态本就不能读，更何况用线性，这是根本性错误。

**正确的说法**：`radius=2` 的高维状态在**线性**探针下读不出（0.109），
而这**正是分布式高维编码的固有性质** —— 用 `n=128, d=1024` 的线性探针去测它，
失败是**仪器的必然**，不是"没有信息"。

**本实验能说的只有**：
1. 不是"64 个空间桶太粗"的锅（全分辨率 0.109 反而低于 64 桶 0.172）；
2. 高维状态**不在一个线性子空间里**。

**不能说**：状态里没有信息。**那需要非线性/非参数读出 + 足够样本，见 M6ag。**

## 二、机制上说得通

`g_local=1` 时发放 0.0198 × 1024 ≈ **20 个神经元**，等于起搏神经元数（`p=0.02`）。
**只有起搏神经元在放电 ⇒ 状态是"哪些起搏神经元亮着"，与历史无关。**

这也解释了为什么加输入增益无效（`scale` 翻倍发放不变）：输入被局部抑制挡在门外。

## 三、这条对总目标意味着什么

今晚想要的"高维个体状态"，在**这个工作点上**是空的。
但这不是机制的死刑 —— 是**操作点**的问题。`M6ac` 用更低的 `g_local` 找
"输入能进来、又保留空间结构"的工作点，那是这个机制还有没有希望的最后一次检验。

## 四、限定

- 4 种子；全分辨率探针在 1024 维、**128 个样本**上做岭回归 —— **样本数只有维数的 1/8**，
  这个配置对高维编码**先验就会失败**，所以 0.109 几乎没有信息量；
- **只测了线性**。非线性/非参数读出（1-NN、MLP）与足够样本量是 M6ag 的内容。
