# 预注册：群体 Critic 的单元同质化，以及在工作点修好之后重测有符号读出

**定稿时间：2026-10-17。测量与网格均先于其结果。**

## 要回答什么

上一轮把工作点修好（`bias=0, gain=16`）后，`corr(V,G)` 从 −0.496 升到 **+0.697**，分数 56.8 → 64.8，
但仍 0/5。剩下的直接症状是：

> 训练把 `V` 压成 `[14.4, 17.6]`（宽 **3.2**，而回报是 1–10.5）——自举几乎不起作用。

本轮问两件事：

1. **单元是否在训练中同质化？**（机制假设：`gradient` 后因子下痕迹恒非负、读出一律为正 →
   每个单元的权重都被推向同一批方向的叠加，彼此趋同，于是 `V` 失去区分状态的能力。）
2. **在工作点修好之后，有符号读出是否仍然有害？**（上一轮测出的 14.3 是在**饱和工作点**上得到的；
   那时单元几乎不动，符号可能没有发挥作用的空间。工作点已修好，这条要重测。）

## 度量（同质化）

对训练前后各算一次：

* **单元间余弦的均值与分布**：`cos(w_i, w_j)`，i≠j。随机单位向量的均值约为 0、
  标准差约为 `1/√d = 0.125`（d=64）；
* **有效秩**：`W Wᵀ` 的归一化特征值熵，`exp(entropy)/n_units` ∈ (0, 1]。**同质化 ⇒ 有效秩下降**；
* **活动相关**：各状态上单元活动的两两相关均值——同质化 ⇒ 上升。

对照：初始化（训练前）与训练后（800 回合）各一份；再用**线性 TD**那一组做对照
（它不是群体结构，但同样有 64 维权重——若它也同质化，说明与群体结构无关）。

## 判据

* **同质化成立**：训练后单元间余弦的均值显著升高（|均值| 超过随机基线 5 倍标准差以上），
  且有效秩显著下降；
* **同质化不成立**：权重保持近似正交，那么 `V` 的塌缩要另找原因。

## 网格（第二条）

固定 `bias=0, gain=16, gradient, normalize=False`，只切读出：

| 变体 | 说明 |
| :--- | :--- |
| `uniform`（对照） | 上一轮的 64.8 |
| `random`（有符号） | 本轮要测的 |

各 5 种子 × 800 回合，与其余消融同口径。

## 边界情况

* 同质化度量**要训练**（800 回合）才能看权重怎么动，但只用 1 个种子；**若换种子结论不一致，如实报不一致**（本轮实测 −0.002 → +0.823、有效秩 0.613 → 0.025，量级远超随机波动）。
* 有效秩用的熵是对归一化特征值的，**不是**矩阵的秩——后者在同质化下仍是 64。
* 有符号读出必须配 `gradient` 后因子（构造时强制），本轮不违反。

## 执行记录（2026-10-17）

**同质化**（`diagnose_homogenisation.py`，800 回合，`b=0, g=16`，`gradient`，不归一化，种子 0）：

| 量 | 训练前 | 训练后 |
| :--- | ---: | ---: |
| 单元间余弦均值 | −0.0022 | **+0.8226** |
| 有效秩 | 0.613 | **0.025** |
| 单元活动两两相关 | — | **+0.928** |
| 平均活动 | — | 0.003 |
| `V` 范围 | — | [14.4, 17.6] |

**判据对账：同质化成立。** 余弦从随机水平（标准差 1/√64 = 0.125）跳到 +0.82（约 6.6σ），
有效秩从 0.613 塌到 0.025。由于平均活动只剩 0.003，`V` 几乎全部来自 `out_bias`
（反推约 15–16），与实测范围吻合——**自举失效的原因就是这个**。

**有符号读出重测**（5 种子 × 800 回合，同工作点）：目录 `rstdp_spiking/pop_opg16_signed`，
均值 **29.2**，逐种子 43.9 / 9.2 / 74.2 / 9.3 / 9.3。对照均匀读出的 64.8。
**仍然有害**——预注册里"工作点修好后符号可能起作用"的猜测被否证。
