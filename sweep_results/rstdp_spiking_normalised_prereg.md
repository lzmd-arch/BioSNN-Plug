# 预注册：W3 D18——按轴归一化编码后重跑 D4/D8/D9 的核心探针（2026-10-30）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（D17 已测，不是猜测）

D17（[`rstdp_spiking_encoder/README.md`](rstdp_spiking_encoder/README.md)）：脉冲编码器在**极角**方向
的相对灵敏度只有 **2.9%**（端到端 cos 0.9988），而同一编码器在 `x`/`ẋ`/`θ̇` 三轴上是 **1.1–1.4**；
速率线的编码器在 θ 上是 **0.325**。原因指向 `CARTPOLE_HALF_WIDTHS` 的 θ 半宽 0.21 与 σ=1.0
不匹配（θ 方向的中心全挤在远小于 σ 的区间里）。

于是 D4/D8/D9/D16 里「沿极角 `slope=0`」的结论**不能排除"输入本来就分辨不出 θ"**。D18 把编码器
修好，然后**用同一套训练**重跑那三条探针。

## 改动（唯一一处，默认关闭）

在编码前把状态**按物理半宽归一化**：

```
s' = s ⊘ CARTPOLE_HALF_WIDTHS      # 四个轴都落到 [−1, 1]
centers' = population_centers(64, half_widths=(1,1,1,1))
σ' = 0.35                           # 标定后写死，见下面的校准步
```

实现上给 `run_episode` / `evaluate` / `_probe_actor` / `train` 加一个 `scale: torch.Tensor | None`
参数（默认 `None` = 现有行为，**逐位不变**，用 `torch.equal` 的守卫测试钉住）。归一化臂传
`scale = CARTPOLE_HALF_WIDTHS`，中心用单位立方体上铺的。

## 训练前必须做的校准步（不训练，先量）

用 D17 的同一套指标量新编码在 θ 上的 `rel` 与 `cos`：

- **通过条件**：`rel ∈ [0.30, 0.90]` 且 `cos ≤ 0.95`（5/5 套中心）；
- 不通过就**调 σ'**（在 {0.2, 0.35, 0.5} 里选第一个通过的），调完把选中的值写进结果；
- 这一档的测量与选择**发生在任何训练之前**，报告里要写清选了哪个 σ'。

## 训练与探针（与 D6-B 完全同参，只换编码）

- `count-aligned` + `spiking_temperature` 0.1→0.02、800 回合、lr 1e-3、64 特征、25 步窗口；
- **10 种子**（0–9），与 D9 的臂同口径；
- 探针：21 点极角网格（**归一化后**的 θ 网格，仍是 −0.21…+0.21 的原值）、每点 20 窗口。

## 判据（先写死，三条全过才 `d18_ready=true`）

1. **符号依赖回来了**：极角 `slope > 0` 的种子数 ≥ **7/10**（D4/D9 的对照是 **0/10**）；
2. **差分响应**：末期 `mean Δ` 的极角极差中位 ≥ **0.5** 计数（D8 的对照是 0.2）；
3. **不牺牲成绩**：末次评测中位 ≥ **30 步**（D6-B 的对照是 9.5）。

另报（不作判据）：`best_steps` 均值、每列平均计数、零窗口比例、以及**新旧编码在同一批种子上的
配对差**（新编码是否只是把"看不见的维度"补上了，而不是把别的什么改坏了）。

## 读法护栏

- 若三条全过：结论是「**D4/D8/D9 的沿极角结论是编码器造成的**，不是学习规则或读出造成的」，
  D 系列的审计文档要按此更正（旧数字保留、注明口径）；
- 若判据 1 过而 3 不过：说明「补上 θ 分辨力之后策略开始依赖状态，但成绩没有变好」——
  这仍然是有价值的定位，但**不写 ready**；
- 若判据 1 仍不过：说明**编码器不是原因**，D 系列原来的结论维持，不得再拿 D17 当借口；
- 归一化本身会改变**所有**轴的有效 σ，可能顺带改变 x/ẋ/θ̇ 的分辨力——校准步要四轴都报。

## 不做什么

- 不改 STDP、温度、Critic、回合数与超参；
- 不在同一批种子上挑 σ'（σ' 用 D17 的指标选，不看训练结果）；
- 不删除旧的 D4/D8/D9 数字——它们是"旧口径"，必须与新口径并存；
- 不改 `CARTPOLE_HALF_WIDTHS` 本身（速率线也在用它，改了会让速率线的历史数字不可比）。

## 边界

- sMNIST/CartPole 之外的结论不外推；
- 归一化 + σ'=0.35 是一种选择，不是唯一合理的选择；选它的理由是让四轴的分辨力量级接近；
- 探针仍只在极角上扫（其余维度为 0），但这次该维在输入侧**确实**可分辨（D17 的指标 ≥0.30）。
