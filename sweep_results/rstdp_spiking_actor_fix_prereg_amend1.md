# 预注册修订 1：A1′ 的空窗口与阶段 2 的对照配置（2026-10-26）

**修订时间：2026-10-26，在 A1′ 数据之后、阶段 2 的任何数据之前。**
原预注册见 [`rstdp_spiking_actor_fix_prereg.md`](rstdp_spiking_actor_fix_prereg.md)。
勘误两条，都不改机制的判据强度。

## 1. A1′：零发放窗口是空窗口，不是反例

A1′ 的原始结果（`data/_a1_symbol/summary.json`，20 个窗口）：

- 正信号 **18/20**、负信号 **20/20**（严格负 18）、门控 **20/20**；
- 失败的两个窗口是 **3 与 17**：两个动作的脉冲计数都是 `[0, 0]`——**没有任何 post 脉冲**，
  因此 LTP 与 LTD 都恰好为 0。要求"正信号下被选列的增量和 > 0"在这种窗口里不可能成立。

这不是符号反转（A1 的失败形态），而是**没有资格可写**。修订后的判据：

- 只在**至少有一个 post 脉冲**的窗口上判 20/20；
- 零发放窗口记为 `vacuous`，数量必须报出，**从分母里剔除**；
- 记录原始 20 个窗口的全部数值，不删不改。

**不换特征种子、不换随机流**：那等于挑一组"保证有脉冲"的输入，是把守卫改成必然通过。
按修订口径，现有数据是 **18/18 通过**（两个空窗口剔除）、负 20/20、门控 20/20。

## 2. 阶段 2 的对照臂：默认配置是 pop，不是 1200 / lr 1e-4 的线性 TD

原文写"与记录在案的 10 种子臂完全一致（1200 回合、lr 1e-4）"。核对仓库后：

- 1200 / lr 1e-4 的那条是**线性 TD**（`sweep_results/rstdp_spiking/td_10seeds/`）；
- **默认臂**是群体 Critic（`pop_gradient_10seeds/`）：800 回合、lr 1e-3、
  `critic_rate = 0.1`、`pop_post = gradient`、均匀读出、行归一化、units 64、bias 0.4、gain 8；
- 诊断 ① 的结论是**只有群体 Critic 有信号**（线性 TD 13.5 / 17.8%，群体 36.8 / 31.1%）。

用线性 TD 测 Actor 修复会被 Critic 的弱信号混淆。所以阶段 2 改为：

| 项 | 取值 |
| :--- | :--- |
| 配置 | `pop_gradient_10seeds` 的发布配置（上列 800 / lr 1e-3 / critic_rate 0.1 / …） |
| 种子 | 0–9 |
| 对照 | **本次同时跑 `pair-stdp` 与 `sign-consistent` 两臂**，同配置配对；不跨配置比较 |
| 控制校验 | `pair-stdp` 臂应**逐位复现** `pop_gradient_10seeds` 的逐种子 `best_steps`；不一致就停下查代码漂移，不进入比较 |
| 判据 | 不变：配对中位数 ≥ +20 步且 ≥7/10 更快；验收门中位数 ≥200、偏移 <10%σR |
