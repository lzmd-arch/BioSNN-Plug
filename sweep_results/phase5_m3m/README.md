## 读法

1. **重标定确实把工作点从"失效"拉到"接近可用"**：M3l 每段只触发 1 次（命中 0–1），
   重标定后多数折的命中在 3–5/5。选中的参数也**稳定**：20 个（折 × 种子）里有 19 个选了
   `k=1.5`、`n_hits∈{2,3}`、`ms=100`——真实分数需要的显著性是**半个标准差**量级，不是 M3k 的 3σ。
2. **但跨会话不稳**：会话 0 是"坏格"（规则门自己只有 0.56、脉冲 0.56–0.60、命中 1–2/5），
   会话 2/3 是"好格"（规则门 0.867）。留出判据要求 **5 折都好**，于是只剩 1 折过——
   **不是校准算法崩了，是这套新颖度分数在不同会话上的可用性差了一个量级**。
3. **脉冲没有超过规则门**：池化 AUC 0.7472 vs 规则门 0.7475，判据 2 只在两折成立。
   按预注册的护栏：正确结论是「**触发在真实尺度上可校准，但没有在规则门之外提供信息**」。
4. 与 M3l 对照：M3l 的失败是**工作点尺度不匹配**（参数搬不过来），M3m 修好了这一点；
   剩下的失败是**分数的会话间不稳**——这是下一层的问题，不再靠调触发器的参数解决。

## 边界

- fixture 只有 5 段、每段 5 个目标轮；留一后每折只有 5 个正例，AUC 的不确定度很大
  （同一参数在不同种子下从 0.56 摆到 0.93）；
- 参数选择的并列规则（命中优先 → 误触发次少 → AUC 高 → 代价小）是预注册写死的；
- 「每轮毫秒」只是把同一个标量重复多少步，不是真实时间尺度；
- 不把「命中 ≥4/5」写成「识别出什么该记住」：命中只是「目标轮起点后 200 ms 内触发过」。

## 下一步（需新预注册）

问题已经不在触发器，而在**分数**：

1. **换分数**：`R_t` 只看「与最近 5 轮的最大相似度」，对话题连续性不敏感。可测的替代是
   「与**整个会话**的最近邻」或「实体/名词短语层面的新颖度」；
2. **分数稳定性**：会话 0 的规则门只有 0.56，说明这批语料里有一段的"目标轮"与上下文几乎
   同分布；要么换语料来源，要么把判据改成**按会话加权**并预先声明；
3. 两条都要新预注册；**在分数过线之前不要再动触发器参数**。
