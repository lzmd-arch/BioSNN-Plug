# 预注册：任务推断的最后一轮——判别式分类器 + 全协方差 Mahalanobis（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** 确认性重跑（对角 Mahalanobis）路由
**52.4%**，阶段门不过；oracle **0.82** 说明头/特征够用、瓶颈在任务边界。
按裁决：**再试 1（更强的任务判别器）；若两条都不行，进 2（封存边界结论）**。

## 机制（两条，都是局部、都不给任务 id）

| 臂 | 判别器 | 训练/统计 |
| :--- | :--- | :--- |
| **T3-D 判别式** | `DeltaReadout(512→10)` 任务分类器 | 每个任务只用**当前任务**的训练特征与任务标签；所有行按 delta 更新；推理 argmax 在已见任务 logits |
| **T3-G 生成式** | 全协方差 Mahalanobis | 每任务均值 + 512×512 协方差（收缩 λ=0.1）只用本任务训练特征；距离 `(x−μ)ᵀΣ⁻¹(x−μ)` |

- 两者都**不存旧数据、不做反向传播**；任务标签只在训练时使用，推理时不提供；
- 头仍是 per-task 10 类 delta 头（与上一轮相同）；路由只换判别器；
- T3-D 的负目标覆盖所有已见任务（当前任务为 1，其余为 0）；未见任务行不参与 argmax；
- T3-G 的收缩协方差：`Σ ← 0.9·Σ_emp + 0.1·diag(mean within-class var)`，再求逆（或 Cholesky）。

## 对照

- **oracle**（真实任务 id，同一批头）：确认性重跑 **0.8195 / 0.0**，作上界；
- 对角 Mahalanobis：**0.4610 / 0.1568**，路由 **0.524**（确认性）；
- 最近原型：0.421 / 0.171，路由 0.489（探索性，跑门作废）；
- 纯 CIL R-delta-mini：0.2466 / 0.8047。

## 固定协议

| 项 | 取值 |
| :--- | :--- |
| 特征 | 冻结 ResNet18 avgpool 512 |
| 数据 / 切分 | CIFAR-100，10×10，全量，类 id 升序 |
| 评估 | 有路由的 CIL：任务由输入推断；推断任务的头里 argmax；不提供任务 id |
| 头 | 每任务 `DeltaReadout(512→10)`，η=0.01，20 epoch，B=128；旧头冻结 |
| 任务分类器 | `DeltaReadout(512→10)`，η=0.01，20 epoch，B=128，只用当前任务数据 |
| 协方差 | 每任务 512×512，收缩 λ=0.1；只用本任务训练特征 |
| 种子 | 0–4 |
| 跑门 | 头：权重非零 + 训练准确率 ≥0.5；分类器：权重非零 + 当前任务训练准确率 ≥0.5 |

## 判据（先写死，两臂分别判）

2. **路由可读性**：任务推断准确率 ≥ **90%**；
3. **oracle 上界**：oracle ACC ≥ 65%（已过，0.82）；
4. **不是少学**：oracle 对角线均值 ≥ 0.758（已过，约 0.81）；
5. 跑门照旧；作废种子写进 summary。

## 限制

- 仍是**任务推断 CIL**，不是纯 CIL；纯 CIL 数字不变；
- T3-D 的负目标会让旧任务行在新数据上被压低——这本身可能造成路由遗忘，必须报
  各任务的路由准确率与混淆矩阵，不能只看总路由准确率；
- 全协方差 512×512 用收缩；不试其它 λ（λ 是固定值，不是调参）；
- 5 种子、单一骨干、单一 η；不调任何超参数。

## 实现（代码先于数据，单独提交）

- `run_with_task_inference` 增加 `routing="classifier"` 与 `"mahalanobis-full"`；
- 分类器：当前任务数据、任务标签 one-hot、全行 delta；推理 argmax 在已见任务；
- 全协方差：收缩 + Cholesky/求逆；距离逐任务算，避免 `n×10×512²` 的临时张量；
- 跑门增加分类器；记录路由矩阵、混淆、分类器训练准确率；
- 守卫：分类器只由当前任务数据训练、协方差只由本任务决定、收缩正定、默认路径逐位不变；
- 跑前工作区干净；产物先落 `data/`。
