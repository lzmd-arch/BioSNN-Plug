# 阶段五触发判据 v3：表面线索就把语料解开了——预注册的混杂成立（2026-11-02）

**预注册：** [`../phase5_trigger_v3_prereg.md`](../phase5_trigger_v3_prereg.md)（写在跑之前）

分数换成一个**零参数**的表面线索计数：数字串、中文数字+单位、星期、引号内容，四类直接相加。
判据与口径完全照 v2（同一批 20 段、同一划分、同一 α、同一分位数取法、同一 T-3 基线）。

## 判决：三条全过

| # | 判据 | 门槛 | 主方向 A | 判决 |
| :--- | :--- | :--- | ---: | :--- |
| T-1 | 真实流误触发率 | ≤ 0.10 | **0.067**（10/150） | ✓ |
| T-2 | 真实流命中率 | ≥ 0.50 | **0.760**（38/50） | ✓ |
| T-3 | 逐段 F1 ≥ 基线的段数 | ≥ 12/20 | **20/20** | ✓ |

| 方向 | q | 测试误触发 | 命中 | 测试 AUC | 池化 F1（conformal / 基线） |
| :--- | ---: | ---: | ---: | ---: | :--- |
| A（主） | 0 | 0.067（10/150） | 0.760（38/50） | 0.861 | 0.776 / 0.776 |
| B（反向） | 0 | 0.060（9/150） | 0.740（37/50） | 0.854 | 0.771 / 0.771 |

**但按预注册，这不写成「触发器解决了」。** 见下。

## 诊断：语料在表面形式上就分得开

四格分解（命中 = 该轮至少有一处表面线索）：

| | 有线索 | 无线索 |
| :--- | ---: | ---: |
| **目标轮**（n=100） | **75** | 25 |
| **背景轮**（n=300） | **19** | 281 |

分数直方图：

| | 0 | 1 | 2 | 3+ |
| :--- | ---: | ---: | ---: | ---: |
| 目标轮 | 25 | 14 | 44 | 17 |
| 背景轮 | **281** | 14 | 5 | **0** |

一句话：**四分之三的目标轮带具体信息（人名/日期/地址/引号），94% 的背景轮一个都没有。**
这条语料的「该不该触发」与「这轮有没有具体事实」在这批数据上几乎是同一个问题。

逐段 AUC：表面线索均值 **0.859**（中位 0.873），`R5` 是 **0.757**（中位 0.78）；
20 段里表面线索更好的是 **13/20**。

## 读法

### 1. 预注册的第一种解释成立：语料被表面线索解开

v3 预注册的解释矩阵第一行是「T-1 过且 T-2 过 → 这 20 段可被表面线索解开，语料不测
『该不该搜索』，只测『这轮有没有具体事实』」。数据正好落在这里：
**75/100 目标轮带具体信息，285/300 背景轮不带。**

所以这份结果的产出不是「找到一个更好的触发器」，而是**给这 20 段语料判了边界**。

### 2. 与 v2 的对照：差的 34 个点不是算法进步

同一批语料、同一划分、同一判据：

| 分数 | T-2 命中 | 测试 AUC | 参数量 |
| :--- | ---: | ---: | :--- |
| `R5`（v2） | 0.420 | 0.719 | 0（但需要嵌入） |
| 表面线索（v3） | **0.760** | 0.861 | 0（纯正则） |

差的那 34 个百分点不是「换了个更聪明的算法」，而是**换了一个正好对上语料构造方式的信号**。
目标轮是脚本插入的事实句——它当然带数字和人名。

### 3. conformal 在这一版退化了，必须写明

两向的 `q` 都是 **0**，T-3 的基线阈值也是 **0**——**两臂完全相同**。原因很直接：
94% 的背景轮分数恰好是 0，负例的 90% 分位数就是 0，于是「分数 > q」等价于
「只要有任意一处线索就触发」。

后果有两条，都得记住：

- **T-1 的 0.067 不是 conformal 控住的**，而是背景轮里恰好有 6.3% 带了数字或引号；
- **T-3 的 20/20 是平凡解**：两臂阈值相同，逐段 F1 逐位相等，而判据写的是「≥」。
  它不是「逐段都更好」，是「两臂一样」。

这条与 v2 的结论合在一起，才是完整的判据画像：**conformal 只有在分数近似连续时才起作用；
遇到大量并列的离散分数，它退化成一条硬编码规则。**

## 不说明什么

- **不说明触发器 ready。** 预注册写死了这一条，这里再写一次。
- **不说明表面规则可以上线。** 它不知道那些数字指什么；换一类需求（例如「帮我预约」）
  它一点线索都抓不到。
- **不说明 `R5` 是错的。** 它量的是「相对最近几轮的意外度」，与这批语料的目标轮构造无关；
  换成目标轮不由脚本安排的语料，两者谁更好是未知的。
- **不说明这 20 段没有价值。** 它作为「相似度分数之间怎么比」的标尺仍然有效（M3n–M3p 的
  那几轮结论不受影响）；它不适合的是「触发器该不该发」这个问题。

## 下一步（与 ADR-0029 的重开条件一致）

要判触发器，先得有一批**目标轮不由脚本安排、且事实密度与背景相当**的语料。
在那之前，任何分数在这批语料上的排名都只是在拟合脚本的写法。
