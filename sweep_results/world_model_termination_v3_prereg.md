# 预注册：P3 终止头 v3——固定动作序列的开环想象（2026-10-28）

**定稿时间：2026-10-28，在本轮任何 v3 最终数据之前。** v2 的闭环终止 AUROC 0.6469
失败，根因不是终止头容量，而是**闭环动作反馈**：平衡策略在 `θ+0.5θ̇` 阈值附近翻转
动作，115 步的想象会因动作序列改变而发散；终止前一步的状态误差约 0.86。模型在
**真实一步**上的误差只有约 1e-5，说明失败在想象视界，不在动力学拟合。

v3 把终止评估改成**固定动作序列的开环想象**：模型和真实环境吃同一串动作，动作不再
由想象状态反馈决定。这是世界模型预测能力的标准测法，也是模型有效视界内的终止风险
评估；闭环反馈的 v2 结果原样保留为独立边界，不混报。

## 机制

```text
训练：与 P3 v2 相同的 RidgeActionModel(quadratic=True)，200 回合真实转移
测试：每个测试回合从真实初始状态出发
  固定动作序列：a_0..a_199 ~ Uniform{0,1}（每回合一个固定 seed，模型/环境共用）
  预测：s'_t = s_t + model.delta(s_t, a_t)
  终止分数：margin_t = max(|x'_t|/2.4, |θ'_t|/0.2095)   ← 只用状态，不用时间
  标签：真实环境在同一步的 terminated
```

- 终止是 CartPole 的已知状态界；分数是**模型预测的下一状态到界的余量**，不是时间特征。
- 同时报告一条**闭环平衡策略**的同一 margin 分数（v2 口径）作为边界对照，不参与判据。

## 判据（先写死）

1. **开环终止 AUROC ≥0.75**（5 种子均值）；
2. 终止回合率 ≥1%；
3. **模型有效视界**：终止步上的一步状态最大绝对误差中位数 ≤0.01；
4. 开环非终止步的 margin 最大值 <1.0、终止步的 margin 中位数 >1.0（边界分离检查）；
5. 四条全过 → `p3_v3_ready=true`；否则报边界，不调动作分布/视界/特征/判据。

## 边界（预先写死，不许事后改口径）

- **v3 不是闭环想象**：动作序列固定、不受想象状态反馈；v2 的闭环 0.6469 仍是开放项。
  如果 v3 过线，只能写成“固定动作序列的开环终止风险”，不能写成“闭环终止预测过线”。
- 随机动作让回合在约 25 步终止，落在模型有效视界内；这不是长视界控制。
- 终止分数用 CartPole 已知界，是**模型预测 + 已知任务规则**，不是纯学习头；v1/v2 的
  学习头结果原样保留。

## 不做什么

- 不调状态模型/λ/特征/动作分布/最大步数/判据；
- 不把 v2 闭环结果改判；不把开环结果混进闭环列；
- 不引入时间/步数特征（v3 之前的 time-only 平凡解已试过，不重复）。
