# M6as：**二次读出救不回高维状态 —— 但这个检验样本不足，不能当定论**

## 缘起：用户指出我那条"量子被等距性挡住"的论证有两个漏洞

**① 等距性只挡住状态距离，挡不住可观测量。**
酉演化保距（`‖Ua−Ub‖ = ‖a−b‖`），所以没有指数发散。但可观测量是 `|ψ|²` ——
**二次的、含交叉项**：`|a + b·e^{iδ}|² = |a|² + |b|² + 2|a||b|cos δ`。
**极小的相位差会在干涉项里直接显形。**
⇒ "状态距离不变"不等于"观测不到差别"。**我原来的论证把两者混为一谈了。**

**② 观察者效应在闭环架构里不是外部干预。**
测量者就是系统自己 ⇒ **坍缩是打破等距性的那个非线性** —— 正好补上"缺少放大"。

## 但先测机制内核，不直接搭量子模块

量子那条路的机制主张是"**二次的可观测量能读出线性读不出的东西**"。
这一条**不需要量子就能测**：把读出换成成对乘积。

## 结果（3 种子 × 8 族 × 64 条 = 512 样本）

| 配置 | 线性 | **二次** | MLP | 底板 | 发放 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| **高维** `gl=2.0/pl=0.5`（PR ~64） | **0.466** | 0.271 | 0.396 | 0.096 | 0.0161 |
| 全局场 | 0.229 | 0.224 | 0.346 | 0.096 | 0.1340 |

| 判据 | 结果 |
| :--- | :--- |
| AS-0 发放在窗内 | 过 |
| **AS-1 二次读出救回（> 线性 +0.15）** | **−0.195，不过** |
| AS-2 对照（全局场上的二次增益） | −0.005（确实小得多） |

## 一、判决：**在这个样本量下救不回**

二次特征把维度从 **64** 涨到 **2080**，而样本只有 **512** —— **n/d = 0.25**。
这个配置下二次展开主要是过拟合，**不能据此判定"干涉机制无用"**。

**诚实的写法**：本实验只说明 **"在 n=512、d=2080 下，二次读数救不回高维状态"**。
要真正检验干涉机制，需要 **n ≫ 2080**（例如 8192 样本），那是另一轮的事。

## 二、顺带发现：样本量本身是那条路的杠杆

高维状态的**线性**解码在这里是 **0.466**，而 `M6ak` 用 128 样本时只有 **0.370**。
**同样的状态、同样的读出，样本 ×4 让解码 +0.096。**

⇒ "高维不可读"这个结论对样本量敏感。之前几轮用 128 样本，**低估了高维状态的可读性**。

## 三、限定

1. **3 种子**；`per_fam=64`（512 样本）；
2. 二次特征**未做降维**（没用 PCA 或随机投影），2080 维直接进岭回归；
3. 对照臂也带 `p_long=0.5`，所以它的线性基线（0.229）低于 `M6t` 的 0.53 ——
   **两臂不是同一条基线**；
4. **这个实验不构成对量子路线的判决**，只测了它最便宜的那个机制内核。
