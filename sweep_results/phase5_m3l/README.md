# 阶段五 M3l：真实对话流上的触发 ROC（2026-10-29）

**预注册：** [`../phase5_m3l_prereg.md`](../phase5_m3l_prereg.md)。
数据是 `qwen3-4b`（temperature 0、top_k 1、think 关闭）生成的**固定 fixture**：5 段 × 20 轮、
25 个目标轮，sha256 `4fc74296…`；向量用本机 `nomic-embed-text`。
两个检测器读**同一条分数**：规则门用 `R_t = 1 − max_{1≤t−j≤5} cos(e_t, e_j)` 直接阈值；
脉冲触发把 `R_t` 当每步发放概率（每轮展开 50 ms），**完全沿用 M3k 的参数**（64 LIF、η=0.002、
k=3、`n_hits`=5、`hit_window`=10、冷却 200 ms）。

## 结果

| 判据 | 阈值 | 实测 | 结果 |
| :--- | ---: | ---: | :--- |
| 1 信息量：`AUC_pulse` 中位 | ≥ 0.80 | **0.732**（0.723–0.759） | ✗（0/5 种子 ≥0.80） |
| 2 不劣于规则门 | ≥ `AUC_rule` − 0.05 | 规则门 **0.7475**；脉冲 0.723–0.759 | **✓**（5/5） |
| 3 工作点：每段命中 ≥4/5、误触发 ≤2 | — | 命中 **[0,0,0,1,0]**、误触发 [1,1,1,0,1] | ✗（0/5 段通过） |
| 4 确定性 | 同种子两遍逐位相同 | 5/5 种子 | ✓ |

`m3l_ready = false`。

`R_t` 的分布：最小 **0.0**、中位 **0.15**、最大 **0.331**。

## 读法

1. **规则门自己就弱**：同一条新颖度分数做阈值检测，AUC 只有 **0.7475**——在真实生成的对话上，
   「值得记住的轮」与「普通闲聊轮」的相对新颖度**重叠得很厉害**（这套闲聊语料本身高度重复，
   而目标轮也常与上一轮话题连续）。**上限**就在这里，脉冲触发再好也只能贴着它。
2. **脉冲触发与规则门持平、但没有更好**：AUC 0.723–0.759 vs 0.7475，判据 2 过（不劣于），
   判据 1 不过（<0.80）。按预注册的护栏：**正确的结论是「脉冲群体没有在规则门之外提供信息」**，
   不是「两者都好」。
3. **M3k 的工作点搬不过来**：每段 20 轮（1000 ms）只触发 **1 次**，目标轮基本一个都没命中。
   原因很直接——M3k 的参数是在**合成显著性流**上定的（事件是 0.5 的矩形平台，持续 300 ms），
   而真实 `R_t` 只有 0.0–0.33、且每轮一个点（50 ms），群体发放率根本攒不出持续冲动。
   这正好印证 M3k README 自己写的边界：「合成流；不外推到真实对话」。
4. **确定性通过**：同种子两遍逐位相同，说明这条线的可复现性没有退步。

## 边界

- 数据是**模型生成**的固定 fixture，不是真人对话；只有 5 段 × 20 轮，25 个正例，AUC 的
  不确定度只能看逐种子分布（0.723–0.759）；
- 目标轮的标签是**脚本安排**的（"这一轮请说出一个可记忆事实"），不是人标注的；
- `R_t` 的定义（与最近 5 轮的最大相似度之差）在预注册里写死，本轮**不许换**；
- 工作点判据用的是 M3k 原参数，**没有**为真实分数重新标定——这是预注册的选择，不是疏漏：
  本轮要回答的是「M3k 的参数能不能搬」，答案是不能。

## 与 M3k 的关系

| 轮次 | 数据 | 结果 |
| :--- | :--- | :--- |
| M3k | 合成显著性流（0.5 平台、4 个事件） | 5/5 种子 4/4 命中、零误触发 → `ready` |
| M3l | 真实生成对话（`R_t` 0–0.33、每轮一点） | AUC 0.732（规则门 0.7475），工作点 0/5 → `not ready` |

**M3k 的通过只在合成流那套口径下成立**；换成真实分数后，两个检测器都退化到 0.73–0.75，
而工作点直接失效。

## 下一步（需新预注册）

1. **重新标定工作点**：在真实 `R_t` 的尺度上扫 `k` / `n_hits` / 每轮展开的毫秒数——这是
   「同一机制、不同工作点」，不是新机制；
2. **换分数**：`R_t` 只用「与最近 5 轮的最大相似度」，对**话题连续性**不敏感。可测的替代：
   与**整个会话**的最近邻、或按名词短语/实体抽取后的新颖度。都要新预注册；
3. 在 1 或 2 至少一条过 0.80 之前，**不要**再拿 M3l 谈「真实对话上的自主触发」。
