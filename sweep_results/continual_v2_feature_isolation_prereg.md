# 预注册：CL 特征级掩码隔离（2026-10-26）

**定稿时间：2026-10-26，在本轮特征隔离数据之前。** 输出行轴的结论已封：α=0 与 α>0
之间是相变（AF 17.4% ↔ 79.5%），没有中间档；部分隔离与回放的组合也没能同时过
ACC 与 AF。下一根轴按裁决是**特征级隔离**；任务推断只作保底，不在本轮启动。

## 先更正一处与 Route R 不符的表述

建议规格写"掩码作用于输入→隐藏投影"。**Route R 没有隐藏层**：冻结 ResNet18 avgpool
512 维特征直接进线性 delta 读出。所以本预注册把掩码落在**输入特征**上：

```text
每个任务 t 学一个二值掩码 m_t ∈ {0,1}^512
任务 t 的类 c：logit_c = w_c · (m_t ⊙ x) + b_c
推理：所有已见类各自用自己的任务掩码，argmax，不提供任务 id
```

如果原意是 Route W 的隐藏层投影，那是另一条路线，不在本轮 CL 主线里。

## 掩码怎么学（局部、无反向传播）

在任务 t 的训练特征上，逐维算一个 **Fisher 分数**：

```text
score_j = 类间方差_j / (类内方差_j + eps)
m_t = top-k 个 score_j 置 1，其余 0      # k = 256（50%）
```

- 只用**该任务的训练特征与标签**；不碰测试集、不碰旧任务；
- 掩码在任务结束时**冻结**；旧类的 logit/更新始终用旧掩码；
- 读出仍按全行 delta 更新：每个类 c 的权重只看到 `m_t ⊙ x`——**特征级隔离**，
  不是行冻结；
- 偏置不受掩码影响；
- 这不是"学一个 soft mask"：本预注册固定二值 top-k，soft 版本是另一个机制。

## 两个臂

| 臂 | 掩码 | 作用 |
| :--- | :--- | :--- |
| **F1 fisher** | 每任务 top-k Fisher（k=256），冻结 | 主臂：按任务学出来的特征子空间 |
| **F1-control random** | 每任务**随机** k=256 维，冻结（独立种子） | 控制臂：同样限制特征，但不是学出来的 |

控制臂是必须的：如果 F1 只比参考好、而随机掩码也一样好，收益就只是"限制容量"，
不是"学到的任务子空间"。

参考臂（都已跑）：R-delta-mini **0.2466 / 0.8047**；P1 行隔离 **0.5426 / 0.1739**；
P1+R（回放）**0.4310 / 0.0291**。

## 固定协议

| 项 | 取值 |
| :--- | :--- |
| 特征 | 冻结 ResNet18 avgpool 512 |
| 数据 / 切分 | CIFAR-100，10×10，全量，类 id 升序 |
| 评估 | CIL：全部已见类 argmax、不提供任务 id |

## 限制

- 二值 top-k、k=256 固定；不调 k、不试 soft mask（各自要新预注册）；
- 不声明"每个任务真的用了不同特征"——重叠率必须报出来（两两掩码的 Jaccard），
  重叠高时即使 AF 好看也不能写成"子空间隔离"；
- 5 种子、单一骨干、单一 η；不覆盖 Route W；
- 无任务 id；推理时所有已见类的掩码并用。

## 实现（代码先于数据，单独提交）

- `DeltaReadout` 增加每类掩码（`masks` 形状 `(n_classes, n_in)`）：
  - `predict`：按类分组（同任务共享掩码）算 `logit_c = w_c · (m_c ⊙ x) + b_c`；
  - `step`：每类的权重更新只用 `m_c ⊙ x`；
  - 未设置掩码时逐位走原路径；
- 掩码构造 `fisher_task_mask(features, labels, k)` 与 `random_task_mask(k, rng)`；
- runner 增加 `--feature-mask {none, fisher, random}` 与 `--mask-k`（默认 256）；
- 守卫：掩码只由本任务数据决定、冻结后不变、随机臂 k 相同、默认路径逐位不变、
  两两 Jaccard 记录；
- 跑前工作区干净；产物先落 `data/`。
