# 预注册：阶段四神经发生探针（2026-10-29）

**性质：新研究项；本文先定协议。** 目标不是“加神经元”本身，而是验证
**控制器**：容量不足时增长、任务完成后旧能力不丢、增长有界。

**状态（2026-10-29 补记，判据未改）**：已实现并跑数——v1 线性 delta 读出见 [`neurogenesis_probe/README.md`](neurogenesis_probe/README.md)（最后任务 0.432、旧任务 0.310，`ready=false`）；v2 NCM 读出见 [`neurogenesis_ncm/README.md`](neurogenesis_ncm/README.md)（0.766 / 0.277，`ready=false`）。

## 任务（最小非平凡版）

- 冻结的随机特征前端（2 模态：一个 2D 连续特征、一个 8 维 one-hot 特征，模拟两个插件）；
- 顺序到达 T=4 个分类任务，任务间标签映射冲突（同一输入不同任务不同标签）；
- 隐藏层：脉冲 LIF 群体，初始 N0=64；读出为局部 delta/Ridge（不反向传播）；
- 控制器：每任务训练后，若验证准确率 <0.90，按 +16 个神经元增长（最多 2×）；
  新神经元输入权重固定随机、输出权重从零学；旧读出权重**冻结**（避免用“重训旧任务”
  冒充不遗忘）；
- 对照：固定 64 神经元、固定 128 神经元、无冻结（允许旧读出更新）。

## 判据（先写死）

1. **增长触发**：至少一个任务在固定 64 臂上 <0.90，而增长臂触发；
2. **新任务**：增长臂最后任务准确率 ≥0.90；
3. **旧任务保持**：增长臂所有旧任务准确率下降 ≤2pp；
4. **增长有界**：总神经元 ≤2×N0；
5. 四条全过 → `neurogenesis_ready=true`；否则报边界，不调阈值/增长步长/判据。

## 红线

- 不做反向传播；读出用局部 delta/Ridge；神经元增长不经过梯度；
- 不用任务 id 在推理时选择旧读出（任务感知只允许训练时；推理统一读出）；
- 不把“冻结旧读出”写成抗遗忘算法——它只是控制变量；
- 不与阶段三的 3× 或阶段四 E2E 混报。
