# 预注册：阶段四神经发生 v3——回放与竞争护栏（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（v1/v2 已测，不是猜测）

- v1（[`neurogenesis_probe/README.md`](neurogenesis_probe/README.md)）：线性 delta 读出，
  增长臂最后任务 **0.432**、旧任务最低 **0.310**（固定臂 0.526 / 0.323），
  控制器确实触发 3–4 次但没带来收益；
- v2（[`neurogenesis_ncm/README.md`](neurogenesis_ncm/README.md)）：换 NCM 读出，最后任务升到
  **0.766**，旧任务却掉到 **0.277**（固定臂 0.617 / 0.508）；
- 诊断（v2 README）：**新类原型把旧样本抢走**——不是控制器失灵，是读出的竞争性遗忘。

v3 只针对这一点加两个**局部、训练时才用**的机制，并把它们拆成可归因的臂。

## 协议（任务与控制器沿用 v1/v2，一个都不改）

- 4 个顺序任务 × 4 类、噪声 1.3、冻结随机 ReLU 特征；
- 初始 64 特征，验证准确率 <0.90 时 +16、上限 2×（`GrowthController` 原样）；
- 读出：**NCM**（v2 的 `GrowableNCMReadout` / `ClassPrototypes`）；
- 5 种子（0–4）。

## 三个臂（只改读出如何被喂数据/如何判定归属）

| 臂 | 机制 |
| :--- | :--- |
| A 回放 | 每个见过的类保留 **20** 个样本的固定缓冲（蓄水池式，按任务顺序入队）；拟合新任务时把**旧类回放样本**与新任务样本一起喂给 `ClassPrototypes.add` |
| B 竞争护栏 | 预测时新类（本任务首次出现的类）只有在距离比最佳旧类**好 δ** 时才认领样本；δ 只用**旧任务的验证集**选（网格 `{0.0, 0.05, 0.10, 0.20}` 的相对距离），**不看新任务的测试集** |
| C A+B | 两个一起 |

对照：**固定 64 特征 + NCM**（与 v2 的固定臂同口径）与 **v2 的增长臂**（直接引用，不重跑）。

## 判据（先写死；逐臂判）

四条全过才算该臂 ready：

1. **新任务**：最后任务准确率 ≥ **0.90**；
2. **旧任务保持**：所有旧任务准确率相对固定 64 对照的下降 ≤ **2pp**；
3. **增长有界**：总特征数 ≤ 2 × 64 = 128；
4. **缓冲有界**：回放缓冲 ≤ **20 × 已见类数** 个样本（A/C 臂），B 臂无缓冲。

有臂四条全过 → `neurogenesis_v3_ready=true` 并报告是哪一条臂；
否则 `false`，负结果保留，不调 δ 网格、不调缓冲大小、不换读出。

## 读法护栏

- 「回放有效」只能说明**样本复用**有用，不是「增长有用」——判据 3 只是上限；
- δ 只用旧任务验证集选，**绝不能用新任务测试集**；报告里要写清选中的 δ；
- 不把 NCM 的 0.766 与 v1 的 0.432 直接比（读出不同，见 v2 README 的边界）；
- 若只有 B 过线，结论是「旧类的竞争被护栏挡住」，但样本仍是新类学的——不能写成抗遗忘。

## 不做什么

- 不改任务数/类数/噪声/控制器阈值；
- 不引入梯度、不反向传播、不训练前端；
- 不用任务 id 在推理时选择读出；
- 不调 δ 之外任何超参。

## 边界

- 玩具特征、toy 任务；不是真实插件多模态；
- 「2pp」是相对固定 64 对照，不是相对 v2 的增长臂；
- 回放缓冲是**显式记忆**，与阶段三「重学 3×」的回放不是同一条线。
