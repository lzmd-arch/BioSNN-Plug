# M0：局部规则能不能学 next-token——**不通过**（2026-11-06）

## 一句话

**按预注册不通过，kill 判据生效。** 但它失败的方式把它自己的第二条判据作废了——
**M0-1 是干净的负结果，M0-2 不构成证据。** 这两件事必须分开说。

## 结果

配置：N=1,024、fan_in 32、L=64、B=16、2,000 updates、τ=20、τ_read=8、输入 std 0.12、种子 0、CUDA。

| 臂 | test CE | test top-1 | 发放率 | 墙钟 |
| :--- | ---: | ---: | ---: | ---: |
| 初始（未训练） | 5.792 | 0.001 | 4.3% | — |
| **学习 w_rec** | **1.811** | **0.540** | 5.2% | 440 s |
| **冻结 w_rec** | **1.804** | **0.542** | 4.8% | 409 s |
| **bigram（k=0.1）** | **1.423** | **0.646** | — | — |

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |

三条前置全过、损失确实在降（CE 5.79 → 1.81），**说明管线是通的、逐时刻 e-prop 确实在优化**。

## 诊断：为什么 M0-2 不构成证据

跑 300 步后量各权重矩阵的相对变化：

| 矩阵 | learned | frozen |
| :--- | ---: | ---: |
| `w_in` | **0.082%** | 0.082% |
| `w_rec` | **0.070%** | 0.000% |
| `w_out`（读出） | **179.4%** | 179.4% |

**隐藏层几乎没动，全部学习都发生在读出层。**

单看这个也可以解释：读出的 NLMS 归一化后每步的有效步长，比 `lr_rec = 1e-4` 大三个数量级。
所以这一轮实际训出来的是 **固定随机脉冲储层 + 局部规则训的线性读出**——
一个 reservoir computer，不是"局部规则在训网络"。

**因此 M0-2 的"不通过"没有检验它要检验的东西**：它比较的是"w_rec 动 0.07%"与"不动"，
当然没有差别。**这是我预注册里的设计缺陷**，不是"循环学习无效"的证据。

## 这个结果能说什么、不能说什么

**能说**：

1. **一个固定随机脉冲储层（1,024 神经元、发放率 5%）配一个局部规则训的线性读出，
   在字符级 next-token 上输给二阶 bigram**：CE 1.811 vs 1.423，top-1 0.540 vs 0.646。
   这是一个干净的负结果，指标两条都比，不挑；
2. 逐时刻 e-prop 的**管线是通的**：初始 CE 落在 ln V 附近、损失降到 0.44 倍、发放率稳定在 5%；
3. 在这个预算下（2,000 updates、301 条模板语料），**单纯训读出不够**。

**不能说**：

1. **不能说"局部学习不能预训练"**——隐藏层根本没训起来，这个问题没被测到；
2. **不能说"循环权重没用"**——同上；
3. 不能把这个负结果与 P4 的 BPTT 数字直接比：P4 是 BPTT 且训全部权重，本轮实际只训了读出。

## 按预注册的处置

预注册写死的 kill 判据："M0-1 不过 → 局部规则连字符统计都学不到，整条线停。不调参重跑。"

**已按此执行：不调参、不换种子重跑，本条支线在此停。**

但要留一句给后面的自己：**这个 kill 是被一个不能测自己第二条判据的实验触发的。**
要真正回答"局部学习能不能预训练"，需要一份**新的预注册（M0b）**，至少改两处：

1. 把隐藏层学习率提到能让 `w_rec` 相对变化达到 **≥5%** 的量级；
2. 把"训练后 `w_rec` 的相对变化量"写成**前置判据**（M0b-0），不达标就判"实验无效"，
   而不是判"规则无效"——这一轮的教训就在这里。

**M0b 不在本文件里开**：kill 之后要重开，得先由用户拍板。
