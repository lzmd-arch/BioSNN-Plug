# CL 归一化臂 N1：逐维标准化（2026-10-26）

**预注册（先于数据）：** [`../continual_v2_normalization_prereg.md`](../continual_v2_normalization_prereg.md)。
本目录是 **N1（native）**：任务 1 训练特征上的逐维标准化，统计量冻结，无回放。
参考臂 **R-delta-mini**：ACC 0.2466 / AF 0.8047（[`../step0_delta_minibatch/`](../step0_delta_minibatch/README.md)）。

## 协议

| 项 | 取值 |
| :--- | :--- |
| 特征 | 冻结 ResNet18（ImageNet1K V1，avgpool 512 维） |
| 数据 / 切分 | CIFAR-100，10×10，按类 id 升序，全量 |
| 评估 | CIL：全部已见类 argmax、不提供任务 id |
| 读出 | delta 线性，η = 0.01，20 epoch/任务，B = 128 |
| 回放 | 无（ρ = 0） |
| 归一化 | `task1-standardize`（native） |
| 种子 | 0–4 |

## 结果：机制信号 **不成立**（AF 反而变差）

| 种子 | ACC | AF | 最小 `‖ΔW‖/‖W‖` |
| ---: | ---: | ---: | ---: |
| 0 | 0.2690 | 0.9040 | 1.180 |
| 1 | 0.2687 | 0.9052 | 1.184 |
| 2 | 0.2691 | 0.9043 | 1.182 |
| 3 | 0.2673 | 0.9014 | 1.180 |
| 4 | 0.2687 | 0.9016 | 1.179 |
| **均值** | **0.2686** | **0.9033** | — |

相对参考臂：**ACC +2.20 个百分点，AF +9.86 个百分点（更差）**。

预注册判据：机制信号要求 **AF 至少下降 10 pp** 且 ACC 不低于参考 −1 pp。
本臂 AF 上升 9.86 pp → **`no_signal`**。阶段门（AF<8%、ACC≥65%）也远未达到。

## 关键事实：这一臂同时把有效步长放大了约 22.5 倍

本仓的 ResNet18 特征**行范数恒为 1.0**（前端已做 L2 归一化，实测
`mean_row_norm_before = 1.000`）。逐维标准化后行范数变成 **22.545**，而本协议**不改 η**。
所以 N1 相对参考臂的差异里，混着"逐维几何"与"整体步长 ×22.5"两件事——AF 变差与
"有效步长变大、旧类权重被更快覆盖"一致，但**不能把 N1 单独读成"归一化有害"**。
预注册把这一点写在了控制臂 N1-scale 里。
