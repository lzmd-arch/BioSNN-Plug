# CL 归一化臂 N1-scale：标准化 + 对齐任务 1 的行范数（2026-10-26）

**预注册（先于数据）：** [`../continual_v2_normalization_prereg.md`](../continual_v2_normalization_prereg.md)。
本目录是 **N1-scale（match-task1）**：逐维标准化后乘一个标量，使任务 1 训练特征的
平均行范数回到原始值。它是 **N1 的控制臂**——把整体梯度尺度对齐，只留下逐维几何变化。
无回放。参考臂 **R-delta-mini**：ACC 0.2466 / AF 0.8047。

## 协议

与 N1 相同（冻结 ResNet18 avgpool 512、CIFAR-100 10×10 全量、CIL、delta η=0.01、
20 epoch/任务、B=128、种子 0–4），唯一差别是 `--normalize-scale match-task1`。

实测：原始行范数 1.000 → 标准化后 22.545 → 标量 `rescale = 0.04436`，输出行范数回到 1.000。

## 结果：ACC 有改善，AF 几乎不动 → **`no_signal`**

| 种子 | ACC | AF | 最小 `‖ΔW‖/‖W‖` |
| ---: | ---: | ---: | ---: |
| 0 | 0.3153 | 0.7924 | 0.517 |
| 1 | 0.3151 | 0.7936 | 0.517 |

| **均值** | **0.3151** | **0.7917** | — |

相对参考臂：**ACC +6.85 个百分点，AF −1.30 个百分点**。

预注册判据：机制信号要求 **AF 至少下降 10 pp** 且 ACC 不低于参考 −1 pp。
ACC 这一条过了，AF 只降 1.30 pp → **`no_signal`**。

## 这说明什么 / 不说明什么

- 说明：逐维几何**确实**让 delta 读出学得更好一点（ACC +6.9 pp），但它**不针对遗忘**——
  AF 仍是 79.2%，离 8% 差一个数量级；N1 的 AF 恶化（+9.9 pp）与"有效步长 ×22.5"一致，
  控制臂把这一项排除后，几何本身的遗忘代价接近于零；
- 不说明"归一化完全没用"：它是 ACC 的一个小杠杆，只是不是 AF 的杠杆；
- 不说明参数隔离一定行：那是按 ADR-0017 排的下一个机制，尚未预注册；
- 边界：5 个种子、单一骨干、单一 η；本轮按预注册**不调 η、不试第三种归一化**。

按预注册的判读表：**两臂都不过 → 归一化不是这个瓶颈的杠杆；下一机制是参数隔离**
