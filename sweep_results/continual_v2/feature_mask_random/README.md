## 结论

**特征级掩码不是这根轴上的杠杆。** Fisher 掩码与随机掩码几乎一样（ACC 0.2343 vs 0.2342，
AF 0.7727 vs 0.7788），Jaccard 分别是 **0.425 / 0.333**——任务之间的特征子空间重叠很高，
限制 50% 的特征既没有恢复获取，也没有保住旧知识。按预注册判读表：特征轴不过 →
**启动任务推断保底臂**（新预注册），测量"任务边界信息是否必须以某种形式进入推理"。
