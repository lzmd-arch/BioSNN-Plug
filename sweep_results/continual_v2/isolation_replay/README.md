## 为什么回放在隔离下救不回获取

- 回放样本的标签是**旧类**；隔离只允许更新**当前行**，所以回放**不能重训旧行**，
  标准回放的收益路径被堵死；
- 回放样本还会把当前行从旧类特征上推开（目标为旧类），并把每个 minibatch 的当前
  样本数从 128 压到 90——**获取的更新量反而更少**；
- 结果：对角线从 P1 的 0.534 掉到 **0.328**，ACC 从 54.3% 掉到 43.1%，而 AF 从 17.4%
  降到 2.9%。

所以这不是"回放不行"，是**隔离与回放不叠加**：隔离让回放失去作用对象，回放又挤掉
当前任务的更新量。

## 判读（按预注册表）

先写预注册再跑；本轮不调 ρ。

- **不声明"按类对齐"**：v4 的随机行控制臂无效，本预注册只测组合；
- 回放在隔离下只约束当前行，不是标准 latent replay；不要把 AF 2.9% 写成"回放赢了"；
- AF 2.9% 是**第一次过阶段门的 AF 腿**，但 ACC 43.1% 离 65% 还远——不能报"阶段门通过"。
