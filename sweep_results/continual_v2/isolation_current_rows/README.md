## 结论（按预注册的严格口径）

**不能宣称"输出行隔离有效"。** 机制信号虽然很强，但：

1. "不是少学"这条**明确不过**——隔离把新任务的对角线拉低了 27 pp；
2. 对齐检验**没有可用的控制臂**（随机行臂全作废，原因见其 README）。

所以本臂的准确读数是：**只更新当前行能大幅压低遗忘，但同时显著降低获取能力**；
它是"用获取换保持"的交换，不是免费的隔离。下一步若继续这条机制，必须与回放叠加
（回放正是把获取拉回来），并按新预注册重跑；在叠加结果出来之前，不把它写成
"参数隔离是 AF 的杠杆"。
