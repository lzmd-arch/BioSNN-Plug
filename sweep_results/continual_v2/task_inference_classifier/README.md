## 关键：逐步 1.0 是假象，最终只有 0.1

`routing_accuracy_stepwise` 是"每个任务在**它自己那一步**是否被正确路由"的对角线均值——
分类器在每一步都能把**当前任务**分对，所以它是 1.0。但到了最后一步，旧任务的行已经被
新任务数据的负目标压低，**所有样本都被路由到最后一个任务**：

```text
最终一步路由：任务 0–8 全部 0%，任务 9 100%
```

因此 ACC 只剩 0.242（≈纯 CIL 参考），AF 0.808。**主指标必须是最终一步**；逐步对角线
均值会把"任务边界已经在遗忘"误读成"路由完美"。这条修正已写进
`task_inference.py` 与结果文档。

## 五条预注册检查

| oracle 上界 | ACC ≥65% | 已过（0.820） |
| 不是少学 | oracle 对角线 ≥0.758 | 已过（约 0.81） |
| 跑门 | 头/分类器 权重非零 + 训练准确率 ≥0.5 | `void_seeds=[]` |

## 结论

**判别式局部任务分类器也会遗忘任务边界**：它在当前任务上训练准确率 1.0，但旧任务行被
后续任务的负目标逐步压低，最终把全部样本路由到最后一个任务。这是任务级灾难性遗忘，
不是分类器没学会。按预注册决策规则，本臂不过。
