**预注册：** [`../rstdp_spiking_encoder_prereg.md`](../rstdp_spiking_encoder_prereg.md)。
不训练，只量**输入编码**在四个状态维度上的分辨力：每维 21 点、覆盖该维物理范围，其余维度为 0；

## 结果

判据：脉冲编码器在 θ 上 `rel < 0.10` 且 `cos > 0.99`（≥4/5 套中心）；对照速率线编码器
`rel ≥ 0.50` 或 `cos ≤ 0.90`（≥4/5 套）。

| 判据 | 门槛 | 实测 | 结果 |
| :--- | :--- | :--- | :--- |
| 1 脉冲编码器对 θ 不敏感 | `rel<0.10` 且 `cos>0.99`，≥4/5 | **5/5 套**（rel 中位 **0.0289**、cos 中位 **0.9988**） | ✓ |
| 2 速率编码器对照 | `rel≥0.50` 或 `cos≤0.90`，≥4/5 | **3/5 套**（rel 中位 0.3246、cos 0.740–0.959） | ✗ |

## 读法

1. **同一个编码器在三个轴上是全敏的（`rel` 1.1–1.4、`cos`≈0），唯独 θ 只剩 `rel` 0.029**：
   极角从 −0.21 扫到 +0.21，输入模式的 L1 只变 **2.9%**，两端余弦 **0.9988**——θ 在输入侧基本
   是常数。**这是 40 倍的方向性差异**，不是"整体编码粗糙"。
2. **原因可以直接指出来**：`CARTPOLE_HALF_WIDTHS` 把 θ 的半宽设成 **0.21**（物理真实），而
   `sigma=1.0`；于是所有 θ 方向的中心都落在 ±0.21 内、彼此间距远小于 σ，**群体的响应几乎
   完全一样**。速率线用的是统一半宽 1.5 + σ=0.5，θ 方向反而有足够多的中心被区分开。
3. **这条是 D 系列的上游前提**：D4/D8/D9/D16 的「极角 slope = 0」「末期读出无状态信息」都
   是在**输入侧几乎不变的维度**上量的——**那些结论要打上「探针维度本身不可分辨」的注记**，
   不能直接读成"学习规则/读出无能"。
4. 判据 2 没过是**门槛定高了**（速率线的 `rel` 实测 0.26–0.41，我预注册写的是 ≥0.50 或
   cos ≤0.90；cos 只有 3/5 套 ≤0.90）。按纪律：**判定维持 false**，不事后改门槛；
   但"两种编码器在 θ 上差一个量级"（0.029 vs 0.325，**11 倍**）作为描述量照常报。

## 边界

- 单维网格（其余维度为 0）；真实 CartPole 状态四维都在动，所以「看不见 θ」不等于「看不见状态」；
- `rel` 以该维中点为基准；两端余弦与单步灵敏度不依赖基准；
- 只测 5 套随机中心；
- 本轮**不改**任何默认参数——改编码器要新一轮预注册 + 重跑 D4/D8/D9 的探针。
