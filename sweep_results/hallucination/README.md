# 幻觉率探针：记忆注入**没有**降低编造（2026-11-14，首测）

## 口径

见 `scripts/hallucination_probe.py` 文件头。两个题集：

- **B 集（无答案）**：20 条探针，主题关键词在全部 313 条记忆里 **0 命中**才入选（通过 18 条）；
  问法要求给出具体答案，任何具体回答都记为编造。
- **守卫集**：用户自己问过的 **40 条真实问题**，只看拒答率（防"一律拒答"的假赢法）。
  **不是准确率**——那 40 条的逐条标注已丢失，只剩「support 28 / none 12」的聚合数。

两个臂：裸千问（只给人设）vs V1（检索 top-3 注入 + 同一句"没有就说没有"）。

## 结果（不过）

| 指标 | 裸千问 | V1 |
| :--- | ---: | ---: |
| **编造率**（B 集，越低越好） | **0.7222** | **0.7778** |
| 拒答率（B 集） | 0.2778 | 0.2222 |
| 拒答率（守卫集 40 条真实提问） | — | **0.025** |

**判据不过**：V1 的编造率比裸千问**高 5.6pp**，而且拒答率还降了。

## 为什么——以及它指出了真正的杠杆

关键在于**检索替身把无关记忆塞了进去**：B 集的 18 条里，多数仍然检索到 2–3 条记忆
（因为 IDF 词法只要有一个词重合就给分）。注入之后就变成"**给了它素材，它拿素材编**"，
比没有任何素材还糟。

这与仓库里既有的召回门槛工作是同一件事：`DEFAULT_RECALL_MIN_SCORE = 0.25` 之所以存在，
就是因为"不该注入的时候注入了"会让结果变差。本探针是那条结论在**幻觉**这个指标上的复现。

## 三条必须写明的限定

1. **检索是 IDF 词法替身**，不是产品的召回（nomic + 词法 + 时序 + 0.25 门槛）。所以还不能说
   "产品会这样"；能说的是"**在这个替身下，注入无关记忆会增加编造**"。
2. **18 条探针**，样本小；但方向与召回门槛的既有结论一致。
3. **编造判定是关键词 + 具体断言检测**，不是人评。原始回答已存盘，可复核。

## 下一步（已写死）

用**同一批探针**，只改一件事：把检索门槛拉到"必须强匹配才注入"（等价于产品 0.25 的逻辑），
再看编造率。若仍不降 ⇒ 结论是"记忆注入本身不解决幻觉，必须靠**不注入**"。

## 二轮：加后置验答（2026-11-14）

**机制**（不改权重，纯结构）：生成后把答案里的"具体断言"与注入的记忆块比对，
支撑比例低于 `--min-support`（0.5）就把整句换成
「这一点我的记忆里没有直接说明，我不猜。」——**不输出该断言**，而不是让它带着不确定性输出。

"具体断言"的判定：数字/日期 + **语料里不在前 500 高频**的中文词。

| 指标 | 裸千问 | V1（加验答） |
| :--- | ---: | ---: |
| **编造率（B 集）** | 0.7778 | **0.0000** |
| 拒答率（B 集） | 0.2222 | 1.0000 |
| **拒答率（守卫集 40 条真实提问）** | — | **0.6500** |

**判据不过**：G-1 达到了（编造 0），但 **G-3 崩了**——40 条真实提问里 26 条被换成拒答。
这正是"用拒答换编造"的假赢法，守卫集把它抓住了。

### 为什么

验答把**口语词也当成断言**了：真实提问是闲聊（"你怎么看待自己""你觉得我应该怎么对待你"），
回答里天然有大量语料里不常见的词，于是一律被判成"无据"。

⇒ 问题不在验答这个机制，而在**断言抽取太钝**。

### 下一步（写死，不许换指标）

只改抽取口径，阈值与判据不动：

1. 高频表从 500 扩到 2000（把常见口语词算进"词汇"）；
2. 断言只取**数字/日期**与**问句问答位上的实体**（"叫什么/是谁/哪里"后面那一段），
   不再把所有生僻词当断言；
3. 重跑同一批 18 + 40 条。

**验收**：编造率仍为 0，且守卫集拒答率 ≤ 10%。两条同时成立才算 G 系列通过。

## ④ SNN 头：**这次跑废了，不作结论**（2026-11-14）

第一次尝试的结果（`grounding_snn_head.json`）：

| 头 | AUC |
| :--- | ---: |
| rule | 0.6839 |
| lr | 0.6839 |
| snn（读出向量 + 残差） | 0.3036 |
| snn（只用读出向量） | 0.1973 |

**这组数不能用**，两处实现缺陷：

1. **`lr` 与 `rule` 相同**是必然的——本脚本里残差只放了 R1 一维，
   一维特征的逻辑回归就是阈值规则。上一轮 0.773 用的是**四维**（R1/R4/R5/长度），这里退化掉了。
2. **AUC 小于 0.5 且出现 `exp` 溢出**：15,624 维特征配 150 个训练样本，逻辑回归直接过拟合、
   优化发散。0.30 / 0.20 是数值事故，不是"SNN 更差"。

**结论：本轮作废，不写进任何判断。** 重跑的条件写死：
- 残差恢复四维（与上一轮同口径）；
- SNN 特征先降到 ≤16 维（PCA 在**训练集**上拟合），或改用强正则的对偶形式；
- 同时报训练集与留出集 AUC，两者差距过大即判过拟合、不采信。

### ④ 重跑（四维残差 + PCA≤16，PCA 只在训练集上拟合）

| 头 | 训练 AUC | 留出 AUC |
| :--- | ---: | ---: |
| rule（R1 阈值） | 0.5955 | 0.6839 |
| lr（四维残差） | 0.5955 | 0.6839 |
| **snn（PCA16 + 四维残差）** | 0.7266 | **0.6379** |

**三条读数：**

1. **lr 与 rule 完全相同** ⇒ R4/R5/长度在这批数据上不提供额外区分度，四维塌回一维；
2. **SNN 头过拟合**（训练 0.727 → 留出 0.638），留出集**不如**只用残差；
3. **上一轮的 0.773 没有被复现**——那批数据 244 条、这批 214 条（`hard == text` 的被跳过），
   再加上 AUC 符号处理不同。⇒ **0.773 与 0.575 那组数不成立，撤回。**

**结论（带限定）**：在这 214 个样本上，**SNN 的表征没有比一维规则多做什么**，
四维残差与 SNN 特征都没有稳定增益。样本量小、负例只有一种形态，所以准确表述是
「**没有测到 SNN 的位置**」，不是「SNN 没有位置」。

### 这一节的净结论

幻觉门控的可学习部分，目前只有 R1 一条规则在支撑，其余四维与 SNN 表征都没有证据。
要改变这一点，缺的不是模型，是**更多形态的负例**（数值改、实体改、时间改、指代错位）。

### 负例形态补齐后：可学习的头**明确有用**（400 样本，五种负例）

负例形态：改数字 / 改日期 / 改专名 / 跨条拼接（整条不相干证据）。

| 头 | 准确率@0.5 | AUC |
| :--- | ---: | ---: |
| 规则（只用 R1） | 0.6750 | **0.704** |
| 逻辑回归（四维残差） | 0.6583 | **0.852** |

**AUC 差 +0.148，方向稳定。** 与前几轮的差别在于：这次负例有五种形态、样本 400。

- 规则门在 AUC 上是 0.704——**能用但薄**；
- 四维残差 + 逻辑回归到 0.852，说明"细节错"这一类确实需要多特征；
- 准确率@0.5 反而略低（0.658 vs 0.675），说明**阈值要单独标定**，不能默认 0.5。

⇒ **SNN 头现在有了明确对手：必须优于 0.852 AUC。**

### 一段反复出现的方法教训（今天第六次）

判据的**采样方式**比判据本身更容易出错：
退化采样 → 尺度 → 温度 → 容易的负例 → 过拟合 → 负例形态单一。
每一次都足以让结论反向。**今后任何"某机制有效/无效"的读数，先检查采样与对照。**

### ④ 对 0.852 的复核：**基线自己不稳定，结论暂不成立**

同一套五种负例、400 样本，在 `grounding_snn_head.py` 里跑：

| 头 | 训练 AUC | 留出 AUC |
| :--- | ---: | ---: |
| rule | 0.8406 | 0.7524 |
| lr（四维残差） | 0.8406 | 0.7524 |
| snn（PCA16+残差） | 0.8406 | 0.7487 |

**两个问题，结论是"暂不判定"：**

1. **`lr` 又和 `rule` 完全相同**（0.7524 vs 0.7524），而 `grounding_head.py` 里同一组特征
   给出的是 0.852 vs 0.704。**同一批数据在两个脚本里给出不同的 lr ALC** ⇒ 至少有一个
   实现不一致（`features()` 的构成、rng 消耗顺序、或划分方式）。
2. SNN 头（0.7487）低于 lr（0.7524），但差距 0.004 **在噪声内**，不能算"更差"。

⇒ **正确的说法：SNN 头没有显示出优于残差基线的证据，但基线本身尚未在两个脚本间对齐，
所以这不是一次有效比较。** 先把两个脚本的取数逻辑统一（同一个模块、同一次划分），
再做 ④。

**不再往下推结论。** 今天已经有六次因为实现细节让结论反向，这次不再加第七次。

### ④ 定论：单文件、单次划分的比较（400 样本）

之前 `lr` 在两个脚本间不一致（0.852 vs 0.752），根因是**两个脚本各自实现了一遍取数**。
改用 `scripts/grounding_compare.py`——数据生成、划分、编码全在一个文件里，从构造上消除漂移：

| 头 | 训练 AUC | 留出 AUC |
| :--- | ---: | ---: |
| rule（只用 R1） | — | 0.7524 |
| **lr（四维残差）** | 0.8343 | **0.8524** |
| snn（PCA16 + 四维残差） | 0.8451 | **0.7629** |

**结论：SNN 在这件事上没有位置。**
- 四维残差的逻辑回归 0.8524，训练/留出差 0.018 ⇒ 不过拟合，是真信号；
- SNN 特征加进去反而降到 0.7629，训练 0.8451 ⇒ **过拟合**，表征里没有可用信息；
- 与"SNN 当生成器 0/543、当编码器 0.015"一致：**同样的结论，第三条独立路径。**

⇒ 幻觉门控的可学习部分就定为**四维残差 + 逻辑回归**。PN-2 判据关闭：SNN 头不接入。

### 时间特征首跑：**AUC 1.0000 是泄漏，作废**（今天第七次）

| 头 | 训练 | 留出 |
| :--- | ---: | ---: |
| rule | — | 0.7524 |
| lr | 0.8343 | 0.8524 |
| **lr+time** | 0.9966 | **1.0000** |
| snn | 0.8451 | 0.7629 |

完美分离只可能是泄漏。原因很具体：时间特征里有 `(gap < 1e-6)`（是否同一时间戳），
而正例的证据就是原记忆（gap=0）、"换一条记忆"的负例必然 gap>0
⇒ **时间戳直接编码了标签**。模型学的是"这条证据是不是原来那条"，不是"有没有据"。

**作废，不写进任何结论。**

修法与要求：
1. 去掉 `同一时间戳` 与 `gap`（两者都泄漏标签）；
2. 负例必须在**同一条记忆内**构造（改数字/日期/专名），保证时间戳与正例一致；
   跨条拼接的负例**单独成组评估**，不混在一起；
3. 只保留不与标签相关的量：时段 sin/cos、星期、距**上一次交互**的间隔；
4. **验收前先跑一个"标签置换检验"**：把 y 打乱重训，AUC 必须回到 0.5 附近，
   否则说明特征里仍有泄漏。

### 时间特征：修正泄漏后重跑——**没有增益**（有效实验）

去掉了 `gap` 与"同一时间戳"两个泄漏量，跨条负例单独成组（122 条不参与本次比较），
只保留与标签无关的时段/星期四项。**标签置换检验 AUC 0.422（应≈0.5，通过）。**

280 样本、同一批记忆内构造的负例：

| 头 | 留出 AUC |
| :--- | ---: |
| rule（只用 R1） | 0.5441 |
| **lr（四维残差）** | **0.6988** |
| lr + 时间特征 | 0.6688（**−0.03**） |
| snn（PCA16+残差） | 0.6524 |

**三条结论：**

1. **时间信息不判别"有据/无据"**（−0.03 AUC）⇒ 时间特征不进这个门控；
2. **在同记忆负例上，规则门几乎失效**（0.544，接近随机），四维残差把 AUC 抬到 0.699
   ——**可学习的头是必需品，不是锦上添花**；
3. SNN（0.652）仍低于残差基线，但差距缩小到 0.046（此前 0.09）。

**限定**：时间特征只用了时段与星期，**没有**用"距上次交互的间隔"——那个量需要会话级时间轴，
记忆库里没有。所以准确说法是「**这两个时间量不判别**」，不是「时间无用」。

### 负例扩到四种形态后（指代错位 / 跨句矛盾加入）

| 头 | 留出 AUC |
| :--- | ---: |
| rule（只用 R1） | 0.6689 |
| **lr（四维残差）** | **0.7476** |
| lr + 时间 | 0.6789（−0.069，仍无增益） |
| snn（PCA16+残差） | 0.7099 |

标签置换 0.5599（通过）。**三种头都比两种负例时高**——更多形态让所有头都更会判，
而 lr 仍领先，SNN 仍落后。

⇒ **运行时里固化的权重需要在四形态数据上重拟合一次**（当前那组来自 280 样本、两形态）。

### SNN 逐位置序列：**实验无效，不作结论**（标签置换未通过）

| 头 | 训练 | 留出 |
| :--- | ---: | ---: |
| 四维残差（基线，前次） | — | 0.7476 |
| 序列统计（mean/std/max × 64） | 0.6091 | 0.3235 |
| 残差 + 序列 | 0.7741 | 0.4293 |
| **标签置换检验** | — | **0.6329** |

**置换 AUC 0.633 落在 0.5±0.1 之外 ⇒ 特征里仍有结构泄漏，本轮不能用于判断 SNN。**

与上一轮（置换 0.5599 通过）的差别只在于特征从 4 维变成了 196 维（4 + 64×3）：
**349 个样本撑不住 196 维**，训练/留出差距（0.774 → 0.429）同样是过拟合的典型形状。

⇒ **这次测不到 SNN 的序列信息，不等于序列没有信息。** 要判定，必须先解决样本量与维度：
- 样本扩到数千（更多记忆或更多位置），或
- 先把序列特征压到个位数（例如每条只保留 3–5 个可解释的统计量）。

**在置换检验通过之前，不对此下任何结论。**
