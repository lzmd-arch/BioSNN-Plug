# 幻觉率探针：记忆注入**没有**降低编造（2026-11-14，首测）

## 口径

见 `scripts/hallucination_probe.py` 文件头。两个题集：

- **B 集（无答案）**：20 条探针，主题关键词在全部 313 条记忆里 **0 命中**才入选（通过 18 条）；
  问法要求给出具体答案，任何具体回答都记为编造。
- **守卫集**：用户自己问过的 **40 条真实问题**，只看拒答率（防"一律拒答"的假赢法）。
  **不是准确率**——那 40 条的逐条标注已丢失，只剩「support 28 / none 12」的聚合数。

两个臂：裸千问（只给人设）vs V1（检索 top-3 注入 + 同一句"没有就说没有"）。

## 结果（不过）

| 指标 | 裸千问 | V1 |
| :--- | ---: | ---: |
| **编造率**（B 集，越低越好） | **0.7222** | **0.7778** |
| 拒答率（B 集） | 0.2778 | 0.2222 |
| 拒答率（守卫集 40 条真实提问） | — | **0.025** |

**判据不过**：V1 的编造率比裸千问**高 5.6pp**，而且拒答率还降了。

## 为什么——以及它指出了真正的杠杆

关键在于**检索替身把无关记忆塞了进去**：B 集的 18 条里，多数仍然检索到 2–3 条记忆
（因为 IDF 词法只要有一个词重合就给分）。注入之后就变成"**给了它素材，它拿素材编**"，
比没有任何素材还糟。

这与仓库里既有的召回门槛工作是同一件事：`DEFAULT_RECALL_MIN_SCORE = 0.25` 之所以存在，
就是因为"不该注入的时候注入了"会让结果变差。本探针是那条结论在**幻觉**这个指标上的复现。

## 三条必须写明的限定

1. **检索是 IDF 词法替身**，不是产品的召回（nomic + 词法 + 时序 + 0.25 门槛）。所以还不能说
   "产品会这样"；能说的是"**在这个替身下，注入无关记忆会增加编造**"。
2. **18 条探针**，样本小；但方向与召回门槛的既有结论一致。
3. **编造判定是关键词 + 具体断言检测**，不是人评。原始回答已存盘，可复核。

## 下一步（已写死）

用**同一批探针**，只改一件事：把检索门槛拉到"必须强匹配才注入"（等价于产品 0.25 的逻辑），
再看编造率。若仍不降 ⇒ 结论是"记忆注入本身不解决幻觉，必须靠**不注入**"。

## 二轮：加后置验答（2026-11-14）

**机制**（不改权重，纯结构）：生成后把答案里的"具体断言"与注入的记忆块比对，
支撑比例低于 `--min-support`（0.5）就把整句换成
「这一点我的记忆里没有直接说明，我不猜。」——**不输出该断言**，而不是让它带着不确定性输出。

"具体断言"的判定：数字/日期 + **语料里不在前 500 高频**的中文词。

| 指标 | 裸千问 | V1（加验答） |
| :--- | ---: | ---: |
| **编造率（B 集）** | 0.7778 | **0.0000** |
| 拒答率（B 集） | 0.2222 | 1.0000 |
| **拒答率（守卫集 40 条真实提问）** | — | **0.6500** |

**判据不过**：G-1 达到了（编造 0），但 **G-3 崩了**——40 条真实提问里 26 条被换成拒答。
这正是"用拒答换编造"的假赢法，守卫集把它抓住了。

### 为什么

验答把**口语词也当成断言**了：真实提问是闲聊（"你怎么看待自己""你觉得我应该怎么对待你"），
回答里天然有大量语料里不常见的词，于是一律被判成"无据"。

⇒ 问题不在验答这个机制，而在**断言抽取太钝**。

### 下一步（写死，不许换指标）

只改抽取口径，阈值与判据不动：

1. 高频表从 500 扩到 2000（把常见口语词算进"词汇"）；
2. 断言只取**数字/日期**与**问句问答位上的实体**（"叫什么/是谁/哪里"后面那一段），
   不再把所有生僻词当断言；
3. 重跑同一批 18 + 40 条。

**验收**：编造率仍为 0，且守卫集拒答率 ≤ 10%。两条同时成立才算 G 系列通过。

## ④ SNN 头：**这次跑废了，不作结论**（2026-11-14）

第一次尝试的结果（`grounding_snn_head.json`）：

| 头 | AUC |
| :--- | ---: |
| rule | 0.6839 |
| lr | 0.6839 |
| snn（读出向量 + 残差） | 0.3036 |
| snn（只用读出向量） | 0.1973 |

**这组数不能用**，两处实现缺陷：

1. **`lr` 与 `rule` 相同**是必然的——本脚本里残差只放了 R1 一维，
   一维特征的逻辑回归就是阈值规则。上一轮 0.773 用的是**四维**（R1/R4/R5/长度），这里退化掉了。
2. **AUC 小于 0.5 且出现 `exp` 溢出**：15,624 维特征配 150 个训练样本，逻辑回归直接过拟合、
   优化发散。0.30 / 0.20 是数值事故，不是"SNN 更差"。

**结论：本轮作废，不写进任何判断。** 重跑的条件写死：
- 残差恢复四维（与上一轮同口径）；
- SNN 特征先降到 ≤16 维（PCA 在**训练集**上拟合），或改用强正则的对偶形式；
- 同时报训练集与留出集 AUC，两者差距过大即判过拟合、不采信。
