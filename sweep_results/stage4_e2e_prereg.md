# 预注册：阶段四端到端任务——延迟线索问答 + OOD 弃权（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** 单组件已收口（两份 ready、两份边界，
见 [`docs/stage4_status.md`](../docs/stage4_status.md)）。本文件定义第一个**端到端任务**，
把工作记忆 v4、元认知（ensemble 分歧）、世界模型（惊喜）、字面情景索引接在同一个输入流上。

## 任务

```text
t=0–4   线索 A（4 维）
t=15–19 线索 B（4 维）
t=30–34 查询 Q（2 维 one-hot，补齐到 4 维）
t=60    报告 Q 指向的那条线索（A 或 B，4 维）
```

- **in-dist**：A/B ~ N(0,1)；**OOD**：A/B 整体 ×3（查询 Q 不变）；
- 训练只用 in-dist；OOD 只出现在测试；
- 正确 = 报告向量与目标线索的 MSE 小于 τ（见判据）。

## 组件接线

1. **工作记忆 v4**：`encode_timeline` 的 28 维状态 + 局部 RLS 读出，重建 A/B/Q，按 Q 选答案；
2. **元认知**：K=5 个 bootstrap RLS 读出的预测标准差 S（成员分歧）；
3. **世界模型**：在训练集上拟合 `h_{t=59} → h_{t=60}` 的 ridge 一步预测；测试时把一步
   预测误差作为**惊喜** surprise；
4. **字面情景索引**：存训练集 `(h, A, B)`；测试按 h 最近邻检索，报检索 MSE；
5. **门控**：置信度 = `−z(S) − z(surprise)`（z 用训练集统计）；阈值取训练集 80% 覆盖，
   OOD 低于阈值则弃权。

## 数据与协议

| 项 | 取值 |
| :--- | :--- |
| 训练 / in-dist 测试 / OOD 测试 | 2000 / 500 / 500 回合 |
| 种子 | 0–4 |
| 线索窗口 / 测试 | 见上；`t=59` 与 `t=60` 各算一次状态 |
| 读出 | 局部 RLS（δ=1000，20 epoch，与 v4 相同） |
| 世界模型 | ridge 闭式（测量） |
| 门控阈值 | 训练集置信度的 80% 分位；OOD 不参与 |

## 判据（先写死）

1. **in-dist 记忆**：A/B/Q 的重建 R² 均值 **≥0.90**（v4 单组件约 0.999）；
2. **in-dist 选择性误差**：80% 覆盖下，被回答样本的答案 MSE **≤0.10**；
3. **OOD 检测**：in-dist vs OOD 的置信度 AUROC **≥0.75**；
4. **OOD 弃权**：同阈值下 OOD 弃权率 **≥0.80**；
5. **情景检索**：训练集最近邻检索 MSE **≤0.10**；
6. 五条全过 → `e2e_ready`；否则报边界，不调 τ/阈值/尺度/读出。

## 不做什么

- 不训练新网络；不调 K/δ/τ/阈值/OOD 尺度；
- 不用 OOD 数据拟合任何参数；
- 不把单组件旧成绩直接搬进来；本任务全部重测；
- 不因为某一条好看就只报它。
