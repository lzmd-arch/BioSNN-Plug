## 读数：换编码只抬了动作，终止/时间仍在随机

- 编码从 top-k(512,32) 换到 dense-sign / wide-sparse / dense-cont，动作最多从 0.646 抬到
  **0.672**（+2.6 pp），仍低于 0.70；
- **终止平衡与时间顺序在所有编码下都在 0.48–0.55**，包括非局部的伪逆上限；换编码没有
  改变这两条；
- 字面 NN 仍然全面最好（0.762 / 0.962 / 0.595），但**连它的时间顺序也只有 0.595**
  （<0.75）——时间戳/事件检索这条在噪声下本身就难；
- 四臂都在 N=100 就串扰，不是容量用尽；**瓶颈不只是编码**，还包括值/时间的读出方式。

## 结论

**v2 不 ready；并且"局部 Hebbian/伪逆 + 稀疏码"这条联想记忆路线在当前规模/噪声下不可用。**
按预注册不调 D/k/σ/容量/阈值。若继续（v3），必须换**记忆机制**而不是编码：
state-indexed/attention 读出（非局部，需明确标注）或 modern Hopfield；或者接受"字面索引"
作为 v0 的可用基线（它的动作/终止强，时间顺序仍不达标）。
