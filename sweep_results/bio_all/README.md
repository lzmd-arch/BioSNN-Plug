# 生物机制全量：装配起来确实更强，而且**强过任何一个单项**

## 用户 2026-11-16 的假设

> 也许只有**几乎完整模拟生物脑的所有角度加起来**才可以实现涌现。

这是一个可证伪的强假设。仓库里已逐条测过：改标量/学习的机制**单独看全部为零或负**
（16 次实验）。"单独无效、合起来有效"就是**超可加**。

## 判据（`scripts/bio_all.py` 顶部，跑前落盘）

| 全开增益 vs 单项增益之和 | 判定 |
| :--- | :--- |
| 全开 > 和 | **超可加** —— 交互真实，假设成立 |
| 全开 ≈ max(单项) | 只是最好那一项在起作用，**没有涌现** |
| 全开 < 和 | 互相干扰 |

六个开关：`alif`（阈值适应）、`tau`（逐神经元异质时间常数）、
`delay`（轴突延迟）、`ei`（20% 抑制性递归）、`inhib`（池间侧抑制）。

## 这个目录之前的数字是作废的

旧 `result.json` 六臂全在 0.108–0.130（1/K = 0.125）——**任务生成器没播种**，
训练集与测试集是两个不同的任务。详见 [`INVALID.md`](INVALID.md)。

修好之后（`seeded_dirichlet`）重跑，并补了三件测量前提：标定 T 与正式跑一致、
正式跑用真实发放率复核工作点、正向对照（窗口天花板）与**实测**底板。

## 结果（3 种子、n=2048、度 32、K=8）

| 臂 | acc | 占可用空间 | 逐种子 | 发放 | 输入尺度 |
| :--- | ---: | ---: | :--- | ---: | ---: |
| **窗口天花板**（不经过网络） | **0.356** | 100% | — | — | — |
| 底板（多数类） | 0.125 | 0% | — | — | — |
| `off`（全关） | 0.229 | 45% | .248/.230/.207 | 0.0458 | 1.9 |
| `alif` | 0.234 | 47% | .260/.232/.211 | 0.0979 | 3.3 |
| `tau` | 0.180 | 24% | .201/.168/.172 | 0.0998 | 1.4 |
| `delay` | 0.221 | 41% | .213/.213/.236 | 0.1024 | 2.1 |
| `ei` | 0.260 | 58% | .229/.279/.273 | 0.1161 | 3.3 |
| `inhib` | 0.293 | 73% | .291/.309/.279 | 0.0563 | 3.3 |
| **`all`（全开）** | **0.359** | **101%** | .371/.377/.330 | 0.0462 | 11.5 |

「占可用空间」= `(acc − 底板) / (天花板 − 底板)`。

## 判（逐种子配对，不用均值糊过去）

| 编号 | 判据 | 逐种子 | 结果 |
| :--- | :--- | :--- | :--- |
| **B-1** | 全开 > 全关 | **+0.123 / +0.146 / +0.123** | ✅ **3/3** |
| **B-2** | 全开 > **最好单项** | **+0.080 / +0.068 / +0.051** | ✅ **3/3** —— 排除"只有最好那一项在起作用" |
| **B-3** | 全开 > **单项之和** | **+0.170 / +0.098 / −0.014** | ⚠️ **2/3** |

**B-2 是这次最结实的一条**：`inhib` 单独已经到 0.293（比全关高 6.4pp），
但全开仍然比它再高 5–8pp，三种子同向。**所以"只有抑制性侧抑制在起作用"这个解释被排除。**

**B-3 只能说"有超可加的证据，但不稳定"**：均值 +0.085，可第三种子里
单项之和（+0.137）反而略高于全开（+0.123）。n=3 不足以定论。

## 三条必须一起读的限定

1. **全开已经顶到窗口天花板**（0.359 vs 0.356），第三种子的 0.377 甚至超过了它。
   ⇒ 超可加的**幅度只能更大，不能更小** —— 这一条让 B-3 的读数成为**下界**，
   方向对我们有利；但它同时意味着**这个任务已经判不动更强的组合了**。
   要再往上测，必须换一个天花板更高的任务。
2. **探针在这次跑时还没播种**（`dim_ladder.mlp` 当时没有 `manual_seed`，
   已在同日晚些时候修掉并加了 `test_mlp_probe_is_deterministic`）。
   ⇒ 逐种子数字**不能严格复现**，B-1/B-2 的"三种子同向"是在这个前提下成立。
3. **工作点只对了一半**：`off` 与 `all` 的发放率几乎相同（0.0458 / 0.0462），
   但四个单项跑在 0.098–0.116，是它们的 **2 倍**。
   ⇒ 单项增益里混着"发放率高"这一项，全开增益里没有。

## 补记（同日，阶梯跑完后）：这里的"超可加"不稳健

`bio_ladder`（同样的五个开关、alpha=2.0、天花板 0.450、有空间）测到的是**相反的**：
L0 0.281 → L1 0.374 → L2 0.475 → L3 0.457 → L4 0.488 → L5 0.464，
而且**从满载里拿掉任何一个机制都让结果变好或持平**。

差别只在**难度**（这边 alpha=3.0、天花板 0.356，几乎到顶）。

⇒ 本页 B-3（全开 > 单项之和）**降级为"在一个接近饱和的任务上观察到的现象"**，
不能当作"机制之间有真实交互"的证据。B-1/B-2 的逐种子数字仍然成立，
但同样要带上"任务接近饱和"这个条件。

详见 [`../bio_ladder/README.md`](../bio_ladder/README.md)。

## 这算不算「合格涌现」

按 [`research/sel/prereg-emergence-v1.md`](../../research/sel/prereg-emergence-v1.md) 的 Q-1…Q-4：

| 要求 | 本结果 |
| :--- | :--- |
| Q-1 可操作定义 | ✅ 能力 = 隐状态解码；有窗口天花板与底板 |
| Q-2 真实膝点 | ❌ **没测**（只有 全关 / 单项 / 全开 三点，没有复杂度阶梯） |
| Q-3 归因对照 | ◐ 廉价方向成立（关掉就掉 13pp），**但没做逐个去掉** |
| Q-4 位级复现 | ❌ 本次跑时探针未播种 |

⇒ **不许叫涌现。** 准确说法是：**在这一个任务上，五个生物机制合起来的增益
超过了任何一个单项，也超过（2/3 种子的）单项之和。**
