# 生物机制全量：装配起来确实更强，但**不是超可加**

## 用户 2026-11-16 的假设

> 也许只有**几乎完整模拟生物脑的所有角度加起来**才可以实现涌现。

这是一个可证伪的强假设。仓库里已逐条测过：改标量/学习的机制**单独看全部为零或负**
（16 次实验）。"单独无效、合起来有效"就是**超可加**。

## 判据（`scripts/bio_all.py` 顶部，跑前落盘）

| 全开增益 vs 单项增益之和 | 判定 |
| :--- | :--- |
| 全开 > 和 | **超可加** —— 交互真实，假设成立 |
| 全开 ≈ max(单项) | 只是最好那一项在起作用，**没有涌现** |
| 全开 < 和 | 互相干扰 |

六个开关：`alif`（阈值适应）、`tau`（逐神经元异质时间常数）、
`delay`（轴突延迟）、`ei`（20% 抑制性递归）、`dend`、`inhib`（池间侧抑制）。
