# 预注册：世界模型 P3——闭环想象（CartPole，终止策略）（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** P1（一步动力学）与 P2（Acrobot 一步）
已完成；P2 的终止 AUROC 因为随机策略几乎不终止而记 `not_evaluable`。P3 的第一目标是
**闭环想象**：让模型自己滚动，而不是只看一步。

**为什么先做 CartPole 而不是 Acrobot**：Acrobot 需要一个能终止的行为策略才能评终止；
这本身是一项工程/预注册任务。CartPole 有一个确定性的平衡启发式，加动作噪声就能产生
足够的终止事件，可以先把闭环回路跑通；Acrobot 的闭环排在它之后。

## 行为策略（不是学习算法）

```text
a = 1（右推） if θ + 0.5·θ̇ > 0 else 0（左推）
以 ε = 0.1 的概率替换为随机动作
```

- 它只用于**采集数据与驱动闭环**，不训练、不代表项目的学习主张；
- 不加噪声时它几乎永不失败（20/20 回合满 500 步）；ε=0.1 时 5/20 终止，足够评终止。

## 协议

| 项 | 取值 |
| :--- | :--- |
| 环境 | `CartPole-v1`，终止 = `terminated`（杆倒），截断另记 |
| 采集 | 200 个训练回合 + 100 个测试回合，按**回合**切分；ε=0.1；种子 0–4 |
| 模型 | `ridge_quadratic`（主）；`copy_last` 作闭环基线 |
| 闭环 | 从测试回合的初始状态开始；每步由策略在**模型预测的状态**上选动作（同一噪声 RNG），把该动作同时喂给模型与真实环境；H=100 或真实终止 |
| 归一化 | 逐维方差取自训练集；与 P2 同口径 |
| 指标 | 闭环 NMSE（H=1/10/50）、终止 AUROC、首次发散步（NMSE>0.5）、开环 vs 闭环 |

## 判据（先写死）

1. **动作条件化仍在**：闭环 H=10 的 NMSE / `copy_last` 闭环 H=10 的 NMSE **≤0.90**；
2. **终止可评**：测试集终止率 ≥1%，且终止 AUROC **≥0.75**；低于 1% 记 `not_evaluable`，
   不判失败（与 P2 同一条纪律）；
3. **闭环不是瞬崩**：首次 NMSE>0.5 的步数中位 **≥10**；低于它说明模型只能撑几步，
   P3 不算 ready；
4. 报告开环（教师强制）与闭环的误差差；这是 P3 的核心读数。

三条全过 → `p3_ready`；任一不过 → 按读数报边界，不调 λ/模型/阈值。

## 不做什么

- 不训练神经世界模型、不做规划/奖励预测（那是 P3 后续）；
- 不调 ridge λ、不换模型、不挑种子；
- 不把启发式策略的分数写成学习算法的结果；
- 不在同一轮里做 Acrobot 闭环（需要单独的终止策略预注册）。
