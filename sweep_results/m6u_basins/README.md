# M6u（Round B）：**盆地指派 —— 历史把个体送进哪个盆，6/6 成立**

判据在 `research/sel/night-2026-11-16.md`（跑之前）。
K=4、8 个历史族 × 16 条、跑到 T=2048，单链接聚盆（阈值 0.05），
互信息与 200 次标签置换的 95% 分位比。

## 一、结果

| `g_inh` | 盆数 | MI（6 种子） | 置换 95% 分位 | 过线 |
| ---: | ---: | :--- | :--- | ---: |
| **1** | 13.8 | 0.966 / 1.037 / 0.878 / 0.885 / 1.277 / 0.973 | 0.424 / 0.433 / 0.401 / 0.414 / 0.500 / 0.468 | **6/6** |
| **2** | 10.0 | 0.711 / 0.922 / 0.643 / 0.704 / 0.860 / 0.796 | 0.313 / 0.289 / 0.226 / 0.307 / 0.273 / 0.317 | **6/6** |

**U-1 过**：两档都是 6/6，MI 是置换零分布的 **2.2–2.6 倍**。发放 0.140 / 0.135，在窗内。

## 二、这条说的是什么

M6s 证明了盆存在（`g_inh≥1` 时 6–9 个离散吸引子），但**盆存在不等于历史能到达它们**。
本轮把这件事量了：**族标签解释了盆地归属的绝大部分**（MI 0.88–1.28 nats，
即使用 8 类，理论上限是 ln8 = 2.08）。

⇒ **"个体被历史送进哪个盆"在 `g_inh≥1` 时是成立的、6/6 的。**

## 三、但它和 M6p 的结论要一起读

M6p 测到 `g_inh≥1` 时**逐个体**的连续距离比只有 1.02–1.26×。
这两条不矛盾，是同一个现象的两个面：

- **离散看**：盆是少数几个，历史能决定你落进哪个 ⇒ MI 很高；
- **连续看**：盆内的位置由噪声决定，所以逐个体的 `rel` 距离分辨不出来。

⇒ **`g_inh≥1` 的"个体状态"是离散的、低容量的**（10–14 个盆，约 3.5–3.8 bit）。
而 `g_inh=0` 的连续吸引子容量大得多（M6t 解码 0.536），但**没有离散的盆可指派**。

**两条路各有各的窄处**，这是本轮最该记住的一句。

## 四、限定

- 6 种子；`per_fam=16`（每族只有 16 条，盆占用表的统计量偏薄）；
- 盆的阈值 0.05、单链接；换阈值会改盆数，MP 未测；
- 置换检验保住了"MI 不是类别数带来的"，但**没有控制"族 → 盆"可能经由输入统计而非状态中介** ——
  不过 M6t 已经证明终态可解码，且测量在输入停止后 2048 步，输入不可能直接在场；
- MI 的分箱是盆（离散）与族（离散），没有连续化。
