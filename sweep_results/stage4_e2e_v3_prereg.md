# 预注册：阶段四端到端 v3——压力测试（容量/噪声/延迟）（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v2 五条全过，但 E 只有 2 类、无输入噪声、
测试 t=60；1.000 的检索是“管道通”。v3 做压力测试：**E 的类别数 K、A/B 噪声 σ、延迟**
三轴各取固定档，先看在哪一档开始崩。

## 任务与档位

```text
A/B/Q 同 v2；E 用 4-bit 二进制模式表示，K ∈ {2,4,8,16}（K≤16）
A/B 输入加高斯噪声 σ ∈ {0, 0.1, 0.3}；Q/E 不加噪声
测试时刻 t ∈ {60, 100}
OOD：A/B ×3；训练只用 in-dist
```

| 档 | 取值 |
| :--- | :--- |
| **主档（判据落点）** | K=8、σ=0.3、t=100 |
| 容量曲线 | K=2/4/8/16（σ=0.3、t=100） |
| 噪声/延迟 | 报告 σ=0/0.1/0.3 与 t=60/100 的主档对照（K=8） |

组件与 v2 相同：WM v4 局部 RLS、5 成员分歧、世界模型一步惊喜、字面情景索引（检索 E 的
K 类）。5 个种子，2000 训练 / 500 测试。

## 判据（主档，先写死）

1. in-dist 重建 R²（A/B/Q/E 均值）**≥0.50**；
2. 选择性误差（80% 覆盖）MSE **≤0.10**；
3. OOD 检测 AUROC **≥0.75**；
4. OOD 弃权率 **≥0.80**；
5. E top-1（K=8，chance 0.125）**≥0.80**；
6. 五条全过 → `e2e_v3_ready`；否则报边界，不调阈值/档位。

**容量报告**：K=2/4/8/16 的 E top-1 全部报；若 K=16 掉到 <0.80，明确记“容量边界在
K=8–16 之间”，不因为它不在主档就隐藏。

## 不做什么

- 不调 K/σ/t/阈值/读出；不把 OOD 数据拟合任何参数；
- 不把 v2 的 1.000 当一般化能力；v2 结果原样保留；
- 不因为某一档好看就只报它。
