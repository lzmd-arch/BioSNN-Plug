# 千问的标定：**"最优温度"取决于你看哪个指标**

**日期**：2026-11-15
**脚本**：`scripts/v2_calibration.py`（复用 S0 的 540 个位置，不再打模型）
**骨架**：Qwen3-4B-Q4_K_M，本地 llama-server

---

## 一、结果

| 臂 | 真值平均 log p | top-1 | **ECE** | 置信度前 50% 的准确率 |
| :--- | ---: | ---: | ---: | ---: |
| T=1（原样） | −3.5037 | 0.463 | 0.1347 | 0.741 |
| **T=1.5** | −2.8605 | 0.463 | **0.0425** | **0.741** |
| T=2 | −2.6418 | 0.463 | 0.1009 | 0.716 |
| T=3 | **−2.5524** | 0.463 | 0.2086 | 0.691 |
| T=3.65（S0b 的"最优"） | −2.5657 | 0.463 | 0.2555 | 0.691 |
| τ(p)（自适应，9 参数） | **−2.3052** | 0.463 | 0.1849 | 0.704 |

**top-1 在每一个温度上都精确等于 0.463**——温度**不改变 argmax**。它永远不会提高准确率。

## 二、三个不同的"最优"

| 你在优化什么 | 最优 T |
| :--- | :--- |
| 真值**平均 log p** | ≈ **3**（越软越好，直到过冲） |
| **ECE**（标定误差） | **1.5** |
| 置信度前 50% 的**准确率** | **≤1.5**（软化只会让它变差） |

## 三、这条推翻了 S0b 的一个读法

S0b 用"真值平均 log p"当判据，得出"τ(p) 比全局温度再好 +0.26 nats"。
**但平均 log p 混淆了标定与锐度**（Murphy 分解：它同时奖励"把概率给对"和"把分布摊平"）。
换成 ECE：

- **全局 T=1.5 的 ECE 是 0.0425**；
- **自适应 τ(p) 的 ECE 是 0.1849 —— 差了 4 倍。**

⇒ **在"标定"这件事上，一个标量的 T=1.5 完胜 9 个参数的自适应算子。**
自适应算子把平均 τ 推到了 4.14，是**过度软化**。

## 四、修正后的结论

1. **产品的标定旋钮就是全局 T≈1.5**（ECE 从 0.135 降到 0.043，**免费**），
   不是 τ(p)；
2. **τ(p) 要以 ECE 为目标重训**才可能有用；用 log p 当目标训出来的东西会过度软化；
3. **温度与准确率无关**——它只影响"该不该检索 / 该不该说不知道"这类**置信度决策**；
4. S0b 的 +0.26 nats **作为 log p 结果仍然成立**，但它**不证明标定更好**。

## 五、还没有做的

- **T=1.5 在产品里意味着什么**：它改变采样的多样性，是**产品决策**不是研究结论；
- **选择性预测的阈值**：acc@50% 是 0.741，另一半覆盖度的准确率没测；
- 这些都要在**真实对话分布**上重测，本轮是网页文本。
