# 预注册：W3 D12——把净驱动抬起来，计数读出就分得开吗（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

> **修订记录（2026-10-29，任何 D12 数据之前）**：初稿用「构造 `c ± s·δ/2`，再把相对幅度
> 二分标到 ρ」的写法。冒烟时这条路走不通：**逐列 L1 归一化**与**平均绝对值分母**都会把
> 差方向随 `s` 的增长吃掉（实测 `s` 从 0.4 加到 1000，相对幅度从 0.068 涨到 0.084 后封顶；
> `aligned` 臂封顶在 0.030），这与 D10 修正 2 是同一个饱和坑。于是改成下面的
> **固定 L1 预算 + 差分占比 λ** 构造：总驱动由 `weight_norm` 定，差方向占预算的比例由 λ 定，
> 两者都不靠「把 s 越调越大」来表达。

## 背景（D11 已测，不是猜测）

D11（[`rstdp_spiking_readout_gain/README.md`](rstdp_spiking_readout_gain/README.md)）扫了
threshold / 不应期 / `baseline_period` / 窗口共 54 个配置：ρ=0.10 的差驱动在 4/5 种子上
都推不到 2 个计数的极差。机制也量出来了——**净每步驱动只有 ≈0.047，而阈值是 1.0**：
列按 L1 归一化后正负权重互相抵消 95%+，稳态膜电位 ≈0.96 贴着阈值，发射节律靠
`baseline_period=5` 的偏置撑着，输入只能推移相位。

D12 只动**每列的幅度预算**与**差方向占预算的比例**。

## 协议（同一构造探针，不训练）

- 公共模式 `m`：随机向量（与 `LIFLayer` 初始化同式），L1 归一化到 1；
- 差分模式 `d`：随机单位向量，L1 归一化到 1；`sign_mode=aligned` 时取 `d ⊙ sign(m)`；
- 两列：`w_{0,1} = weight_norm · ((1−λ)·m ± λ·d)`——**总预算固定**，λ 是分给差方向的比例；
- 网格与窗口同 D11：21 点极角、每点 **20** 个冻结窗口（`seed*100000 + 2*100 + round(angle*100)`）；
- 其余固定为 D11 的现状档：`threshold=1.0`、`n_refractory=2`、`baseline_period=5`、`steps=25`。

`sign_mode`：`signed` 用原样的有符号 `m`/`d`（历史口径，正负抵消）；`aligned` 用
`|m|` 与 `d ⊙ sign(m)`（全非负，等价于只有兴奋性突触、无抵消）。

## 网格（先写死）

| 旋钮 | 取值 |
| :--- | :--- |
| `sign_mode` | `signed`、`aligned` |
| `weight_norm`（每列 L1 总预算） | 1（现状）、3、5 |
| λ（差方向占预算的比例） | 0（空对照）、0.05、0.10、0.20、0.30 |

2 × 3 × 5 = **30 组 × 5 种子**。

## 判据（先写死）

单个（`sign_mode`, `weight_norm`）在 **λ=0.10** 上「可用」当且仅当：

1. 21 点 `Δ` 极差 ≥ **2.0** 计数；
2. 每列平均计数落在 **2–15**（25 步窗口，反退化）；
3. λ=0 空对照同一极差 ≤ **0.5** 计数。

- 存在一个（`sign_mode`, `weight_norm`）在 **5/5 种子**上可用 → `readout_gain_calibrated=true`，
  推荐顺序：`signed` 优先、`weight_norm` 最小优先（改得越少越先试）；
- 一个都没有 → `readout_gain_calibrated=false`：**计数读出这条线到此为止**，下一步换读出
  （差分膜电位 / 发放率 / 更长的积分窗），不再调参。

**另报（不作判据）**：每个配置在整条 λ 阶梯上**第一次**达到 2 计数的 λ——它回答
「要多少比例的差方向才够」，比单点通过更有信息量。

## 不做什么

- 不训练网络、不改 STDP 与温度；
- 不在 `aligned` 臂里改编码器或阈值——只改权重符号结构；
- 不因为某个配置过线就写成「训练会更好」——那要下一轮的训练实验；
- 不把 λ 过线写成「差方向越大越好」：判据 2 就是防饱和的，λ 上限 0.30 也写死了。

## 边界

- 公共模式是随机构造的，不是训练后的真实列；
- `aligned`（全非负权重）若只有它过线，结论必须写清是「**换了连接符号结构**」，
  不是「调大了一个超参」；
- 点状态网格，不是完整状态空间；
- λ 是**构造**出来的比例，不是训练能学到的比例——D10 量过训练后的相对幅度只有 0.5–7.3%。
