# M6ay：12 比特量子子系统接进闭环 —— **「更丰富」这个说法已挂起待验**

> **⚠️ 判读修正（2026-11-17，用户指出）：熵 0.99 可能不是「丰富」，而是「均匀随机」。**
> 熵的极大值是 1.0 —— **在极大值处它分不清「丰富」与「噪声」**。
> 而且**四种子方差近零是个警报而非优点**：真正的量子采样应该在种子间引入差异，
> 方差塌缩说明**概率分布本身已接近均匀** —— 即 Born 采样退化为掷骰子。
> **目前成立的只有「不自毁」**（系统仍在运行、发放仍在窗内）。
> **「丰富」只有一个熵指标撑着，不够。** 追试已预注册：`prereg-behavior-structure-v1.md`。

## 设计

12 比特量子寄存器（4096 个复振幅），接进 `M6ai` 的闭环：

```
每步：① 相位门   theta_i <- omega x (网络第 i 组的发放)     网络的过去 -> 量子的相位
      ② 混合层   H 单比特 + CNOT 阶梯（固定）              干涉 + 纠缠
      ③ 测量     按 |psi|^2 采样一个比特串（真随机源）        Born 规则
      ④ 低 3 位 -> 下一个符号 -> 喂回网络                  闭环合上
```

对照：同一闭环，用 `argmax` 选符号。

## 结果（4 种子 × 128 步闭环）

| 版本 | 熵（逐种子） | 熵均值 | **带历史（逐种子）** | 带历史均值 |
| :--- | :--- | ---: | :--- | ---: |
| 经典 | 0.42 / 0.75 / 0.67 / 0.50 | **0.59** | 1.27 / 1.21 / 0.51 / 0.52 | **0.88×** |
| **量子** | **0.98 / 0.98 / 0.99 / 0.99** | **0.99** | 1.03 / 1.64 / 0.50 / 0.87 | **1.01×** |

| 判据 | 结果 |
| :--- | :--- |
| AY-0 两版都不熄火 | 过（两版均 100% 窗内） |
| AY-1 量子版带历史 >1.5 | **不过**（1.01×） |
| **AY-2 行为非平凡** | **过**（熵 0.99 vs 极大值 1.0） |

## 一、唯一看起来干净的结果：**行为熵接近极大 —— 但这可能不是好事**

四个种子的熵是 **0.98 / 0.98 / 0.99 / 0.99**（极大值 1.0），经典版是 0.42–0.75。

**三种读法：**

| 读法 | 含义 | 状态 |
| :--- | :--- | :--- |
| ① **真丰富** | 行为多样但仍带结构 | **未验证** |
| ② **伪丰富** | logit 平坦区，Born 采样 ≈ 均匀掷骰 | **未排除，且方差塌缩支持它** |
| ③ 不自毁 | 系统仍在运行、仍在工作窗内 | **成立** |

**方差近零是警报**：真量子采样应当在种子间引入差异；**方差塌缩说明分布本身已近均匀**
⇒ 那么"熵 0.99"等于"掷骰子"，不携带任何结构。

**⇒ 只有 ③ 成立。① 需要一个结构测度才能声称。** 见 `prereg-behavior-structure-v1.md`。

## 二、它不增加记忆 —— **这是框架的预测，不是失败**

带历史：量子 1.01×、经典 0.88×，**逐种子波动 0.50–1.64** —— 两者都在噪声里。

**按分工流水线（目标文档 §37.5 / 4.7），可读信息（记忆）本该住在经典记录层，
量子层承载的是**不可读的个体史**。**
⇒ **"量子不加记忆"恰恰是「认知经典、同一性量子」该出的结果。**
**如果量子加了记忆，那才需要解释为什么可读信息住进了量子层 —— 那才是框架的危机。**

**一个系统按理论预测的方式不动，是理论拿到的第一票。**

**2 种子时看到的"量子 1.49× vs 经典 1.24×"是噪声。** 这是今晚**第五次小样本假阳性**
（前四次：M8 的 σ=0.2、M5b 的高活跃、M6aj 的 2.19×、M4 的"过"）。

## 三、"有偏的随机性"这个机制故事只对了一半

假设：`argmax` 太死板、均匀随机太自由、Born 采样落在中间。

| 读出 | 随机性 | 保留偏好 | 实测 |
| :--- | :--- | :--- | :--- |
| `argmax` | 无 | 是 | 熵 0.59、历史 0.88× |
| 均匀随机 | 有 | 否 | （`M6ai` 的 1.07–1.38×，也不带） |
| **Born 采样** | **有** | **部分** | **熵 0.99、历史 1.01×** |

**⇒ 偏置足够产生丰富行为，不足够携带历史。**

## 四、修掉的三处实现错误

1. `torch.multinomial` 的生成器在 CPU、张量在 CUDA ⇒ **CUDA assert**；
2. 经典路径 `(wmot * z).sum(0).argmax()` 在 **1024** 个神经元上取 argmax，而 `w_in` 只有 **64** 行 ⇒ 越界；
3. `1024 / 12` 不整除 ⇒ 改 `GROUPS=16`。

## 五、限定

- **2 → 4 种子推翻了 2 种子的结论**；4 种子仍然少；
- `N_Q=12`（4096 振幅）；`omega=8`（相位强度）只试了一个值；
- 闭环 128 步；**没有扫测量频率**（每步测量 vs 每 k 步）；
- 这是**经典仿真量子动力学**，不是物理量子系统。
