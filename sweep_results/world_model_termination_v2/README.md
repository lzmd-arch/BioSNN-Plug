**仍不 ready：AUROC 0.6469，低于 0.75。**

| 中位首发散步 | ≥10 | **114.8** | 过 |

逐种子 AUROC：0.694 / 0.647 / 0.619 / 0.635 / 0.639。没有单种子过线。

## 与历史对照

| 终止臂 | 闭环 AUROC |
| :--- | :--- |

## 修订 1

预注册原写“状态边界规则”标签；smoke 发现 200 步模型 rollout 的 40000 个状态**全为
负样本**（模型预测轨迹没有越界），头无法训练。正式跑前改为**真实环境在同一动作序列上的
`terminated`**；这让训练集有正样本（每种子约 199 个），但 AUROC 仍只有 0.647。

## 边界

1. 这不是状态模型失败：闭环 NMSE 1.8e-10、首发散步 114.8 都过；
2. 失败在终止头：它看到的预测状态在约 115 步前仍在界内，而真实环境在 115 步终止；
3. 多步想象 + 真实标签仍不够；下一步需要**更强状态模型**或**时间/风险特征**；
4. 不调 l2/特征/rollout/阈值；P3 仍 `p3_ready=false`。
