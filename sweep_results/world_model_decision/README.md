# 世界模型：1 步前瞻控制（D7 的第一条证据，2026-11-12）

**预注册见 [`../../research/cognitive/prereg-world-model-decision.md`](../../research/cognitive/prereg-world-model-decision.md)。**
本文件只记数，不改判据。

## 协议

CartPole-v1；随机动作采集 200 回合训练、100 回合测试（按回合切分）；5 个采集种子。
搜索与四臂完全相同：每步对 2 个候选动作各预测一次，用**同一个与预测器无关的**"站得稳"
打分选动作，**平局随机打破**；每步的模型评估次数相同。

| 臂 | 预测器 |
| :--- | :--- |
| **R** | 无（随机动作，下限） |
| **C** | `copy_last`（不含任何动作信息） |
| **B** | **动作标签打乱**后训练的 `ridge_quadratic`（状态动力学在，学不到动作的作用） |
| **W** | `ridge_quadratic`（学出来的动作条件化世界模型） |

## 结果（回合长度中位，5 种子）

| 种子 | R 随机 | C copy_last | B 动作打乱 | **W 世界模型** |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 18 | 18 | 76 | 90 |
| 1 | 21 | 21 | 9 | 86 |
| 2 | 20 | 20 | 9 | 96 |
| 3 | 19 | 19 | 13 | 94 |
| 4 | 18 | 18 | 18 | 84 |
| **中位** | **19** | **19** | **13** | **90** |

| 判据 | 阈值 | 实测 | 结果 |
| :--- | :--- | :--- | :--- |
| **WM-0a** 控制臂不得优于随机 | C ≤ 1.05 × R | 19 vs 19 | **过**（搜索本身没在赢） |
| **WM-1a** 世界模型有净贡献 | W ≥ 1.2 × C | **4.74×** | **过** |
| 动作条件化的净贡献 | — | **W / B = 6.92×** | — |

## 怎么读

1. **搜索本身不值钱**：C 与 R 完全同分（19 vs 19）——没有预测信息时，前瞻只是随机游走。
   这条前置不成立的话，W 的增益就没法归因；
2. **动作条件化是那 4.7 倍的全部来源**：把动作标签打乱、保留同样的状态动力学之后，
   臂 B 掉到 **13**，**比随机还差**。一个"有动力学但没有动作信息"的模型会让前瞻**主动选错**——
   它把噪声当成了"这个动作更好"的信号；
3. **代价诚实说**：90 步离解决 CartPole（500 步）还差得远。这是"比随机好"，
   **不是"会控制"**。

## 四问（缺一条不许进结论段）

1. **预算截断？** 不是。固定 100 测试回合 × 5 种子，没有训练曲线可截断；
2. **跨语料/跨任务？** 只在 CartPole 上，**不外推**到其他环境；
3. **单边指标？** 主指标只有回合长度，**属单边**——所以上面同时报了四臂的绝对值，
   不只报比值；
4. **先验未兑换？** 不涉及（直接测量，不是拿代理指标推 Δ）。

## 这条结果补上了什么

ADR-0015 的四条验收全是**预测精度**（动作敏感度、NMSE、闭环、终止 AUROC）。
本条是**第一条**回答"用它选动作会不会更好"的实验：

> **会**——在同一套搜索下，世界模型的选择价值是 `copy_last` 的 **4.74 倍**，
> 而这个增益**完全来自动作条件化**（打乱动作后掉到随机的 0.7 倍）。

**不声称**：不声称它"理解了物理"，不声称它能解决 CartPole，不声称它优于任何具体控制器。

## 第二轮：前瞻深度 1 → 3，**顶到 CartPole 上限 500**

**这一轮是在第一轮之后追加的**，动机是"90 步离可用还差得远"。打分权重与前瞻深度在
**训练种子（0、1）**上扫，在**留出种子（2、3、4）**上评估。

### 权重扫描（训练种子，30 回合/配置）

| 权重 | h=1 | h=3 |
| :--- | ---: | ---: |
| `[1, 0.5, 2, 0.5]`（默认） | 86 | **500** |
| `[0.5, 0.5, 3, 1]` | 146 | **500** |
| `[1, 1, 5, 2]` | 146 | **500** |
| `[2, 1, 10, 3]` | 169 | **500** |
| `[0, 0, 1, 0]`（纯角度） | 32 | — |
| `[1, 0, 4, 1]` | 290 | — |

**决定性的是前瞻深度，不是权重**：四个 h=3 的配置**全部顶到 500**，权重只影响 h=1。

### 留出种子（100 回合/臂）

| 种子 | 默认（h=1） | 调后（h=3） |
| ---: | ---: | ---: |
| 2 | 96 | **500** |
| 3 | 94 | **500** |
| 4 | 84 | **500** |
| **中位** | **94** | **500** |

### 控制臂在 h=3 上**没有跟着涨**

| 种子 | copy_last h=1 → h=3 | 动作打乱 h=1 → h=3 | 世界模型 h=1 → h=3 |
| ---: | ---: | ---: | ---: |
| 2 | 20 → **20** | 9 → **9** | 96 → **500** |
| 3 | 19 → **19** | 13 → **12** | 94 → **500** |

⇒ 500 不是"换了个更聪明的搜索"，是**模型预测的东西真的有用**。没有动作信息的预测器，
加深度也没有任何帮助（它们连随机都打不过）。

### ⚠️ 我预注册时判断错了一件事

预注册 §9 写的是"闭环在 ~115 步后发散 ⇒ **多步 rollout 规划大概率被误差吃掉**，先做 1 步"。

**实测相反**：h=3 从 90 步直接到 500 步。模型误差确实存在（闭环 NMSE 在长程上升），但
**3 步内累积的误差远小于"看得更远带来的决策收益"**。这是一个被实验推翻的先验，照实记在这里。

正确的教训不是"多步规划有用"，而是：**误差与收益的比值要用实验量，不能靠闭环发散步数外推**。

### 这个结果能说什么 / 不能说什么

**能说**：在 CartPole 上，一个从随机数据学出来的 `ridge_quadratic` 世界模型 + 3 步前瞻，
在 5 个种子中的 3 个留出种子上**连续 100 回合不倒下**（达到 v1 的 500 步上限）；
同样的搜索配 `copy_last` 或动作打乱模型只有 9–20 步。

**不能说**：
- 不说它"理解了物理"——它是个二次拟合器；
- 不说它能推广到别的环境——只测了 CartPole；
- 不说这是 SOTA——CartPole 上"推着杆子走"这类手工规则也能到 500，本条的价值在
  **归因**（哪一部分贡献了增益），不在绝对分数；
- **500 是上限，不是能力边界**：v1 到 500 就截断，真实控制能力可能更高。
