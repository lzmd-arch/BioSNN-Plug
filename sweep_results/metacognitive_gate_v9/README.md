## 读法

- **时间型 OOD 被同一个门抓住了**：时间窗后移/交换让误差升 11–27×，弃权 0.98–0.99、
  AUROC 0.98–0.99。这说明 v8 的 `[errors, state_norm]` 不只对尺度/符号量化有效。
- **部分信息丢失/相关性 OOD 没抓住**：`dim_dropout` 误差升 4.7×，但弃权只有 0.596；
  `correlated` 误差升 15.2×，弃权 0.539、AUROC 0.684。原因不是“不是 OOD”（有效性门都过），
  而是**误差分布与 in-dist 高误差样本重叠**：固定 80% 覆盖阈值下，门无法把“输入少了一维/
  两 cue 相关”与“普通难样本”分开。
- 这给“通用 OOD”又划了一条边界：**v8/v9 覆盖尺度、符号量化、时间重排；不覆盖部分信息
  丢失与相关性变化**。后者需要输入侧/维度级的专门门（例如逐维重建误差、协方差检验），
  不能靠同一个全局误差范数。

## 与 v8 的关系

- v8：尺度 + 符号量化，6 个指标全过，`v8_ready=true`；
- v9：额外三类时间/信息 OOD，时间型过、信息丢失型不过；
- v8 的判定不改；v9 的负结果单独记，不把 v8 的 ready 扩大成“通用 OOD”。

## 边界

- 有效性门 4/4 都过，所以失败是**弃权校准**，不是“变换没构成 OOD”；
- 没有调 k/特征/阈值/覆盖率；没有把失败家族从判据里删掉；
- `errors` 依赖任务读出；读出失效时门语义会变。

## 结论

通用 OOD 仍只覆盖一部分：**时间重排可用，部分信息丢失/相关性不可用**。若继续，下一步
应预注册**逐维/协方差级**的状态门（例如每维重建误差的 max、或 state 协方差与 calibration
的差异），而不是继续用全局 `errors` 范数；本轮不调参。
