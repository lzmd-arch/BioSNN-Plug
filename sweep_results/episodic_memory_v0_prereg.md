# 预注册：情景记忆 v0——局部联想记忆（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** ADR-0015 划的边界：世界模型回答"如果"，
**情景记忆回答"曾经"**，工作记忆回答"现在"。P3 之后按顺序进入情景记忆 v0。

## 机制：稀疏键 + Hebbian 外积（局部、无反向传播）

```text
事件 e_i = (状态 s_i, 动作 a_i, 终止 t_i, 时间戳 τ_i)
键    k_i = top-k( R · (s_i / scale) ) 的符号，k=32, D=512，R 固定随机投影
值    v_i = [onehot(a_i, 2), onehot(t_i, 2), τ_i 归一化]   # 5 维
记忆  M = Σ_i v_i k_iᵀ                                  # (D, 5)，纯外积
回忆  r = M q，argmax 前 2 维得动作、次 2 维得终止，最后一维读时间
```

- 编码器 `R` 固定；`scale` 用 CartPole 的已知界 `[2.4, 3.0, 0.21, 3.0]`（领域常数，不看测试数据）；
- 键是稀疏 ±1（类脉冲的二值码），值是 5 维实向量；存储只是外积累加，**没有梯度**；
- v0 **不是脉冲动力学**：它是局部联想记忆的二值码原型；脉冲版/吸引子迭代留 v1。

## 数据与协议

- CartPole-v1，平衡启发式 + ε=0.1 噪声（同 P3），采集 **20 回合**的事件池；
- 对每个容量 N ∈ {100, 300, 500, 1000, 2000}：从池中抽 N 条，编码、存储；
- 查询**同一批事件**的状态加高斯噪声（σ=0.1，原始状态单位）后的编码；
- 5 个种子（编码器投影 + 事件子集不同）；主指标在 N=500、σ=0.1。

## 指标与判据（先写死）

1. **动作回忆**：N=500、σ=0.1 时 top-1 动作准确率 **≥0.70**；
2. **结果回忆**：同条件终止准确率 **≥0.70**；
3. **时间顺序**：随机抽 |Δt|>0.05 的事件对，回忆时间戳的排序正确率 **≥0.75**；
4. **容量**：N=1000、σ=0.1 时动作回忆 **≥0.65**；同时报 N=100..2000 的曲线；
5. 基线：随机（动作 0.5）、**原始状态最近邻**（非联想字面存储）——两者都报，
   不因联想记忆输给最近邻就改判据；这正是 v0 要量的"联想 vs 字面"。

四条全过 → `v0_ready`；任一不过 → 按读数报边界，不调 D/k/σ/阈值。

## 不做什么

- 不做巩固/遗忘/睡眠重放（后续机制，各自预注册）；
- 不做工作记忆、不做世界模型耦合、不做 bus 集成；
- 不训练神经编码器、不用反向传播；
- 不把"字面最近邻"的分数写成联想记忆的成绩（两列必须分开）。
