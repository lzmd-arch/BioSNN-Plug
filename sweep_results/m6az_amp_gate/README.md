# M6az：**连续振幅门控 —— 三轴兼得成立，今晚的「不可能三角」作废**

## 这个结论推翻的是什么

今晚我反复下过一个结论：**整合 / 维度 / 可读三轴不可兼得，根源是抑制算子的空间秩。**
并据此判断"门控这类机制被整体排除"（五版二值门控全失败，PR 恒为 1.0）。

**用户 2026-11-17 提出：「也许是我们的机制不够完善」。**

**对。** 我的门控有三个不必要的限制：

1. 控制变量用 **φ（瞬时发放率）**，而相干的代理应是**振幅的相对相位**；
2. 切换是**二值**的，而 Born 概率 `|a_g|²/(|a_g|²+|a_l|²)` 是**连续**的；
3. 没有**振幅交换**（旋转/干涉），所以它只能停在两端。

## 实现

两模振幅 `(a_g, a_l)`，活动偏离目标时做**连续旋转**：

```
theta = amp_gate * (phi - 0.08)
(a_g, a_l) <- (a_g cos th - a_l sin th,  a_g sin th + a_l cos th)
w_g, w_l  = a_g², a_l²          # **连续，不饱和**
```

## 结果（**6 种子**，`per_fam=32`，`p_long=0.5`）

| **PR（维度）** | **29.46** | >10 ✅ |
| **整合** | **0.803** | >0.3 ✅ |
| **分离** | 3.42 | >0.5 ✅ |
| 线性 | 0.534 | |
| **MLP（可读）** | **0.556** | >0.228（底板 0.078 +0.15）✅ |
| **发放** | 0.0228 | [0.01, 0.20] ✅ |

**五条同时成立。**

## 对照：同一个系统，二值门控 vs 连续门控

| | 二值门控（五版全失败） | **连续振幅门控** |
| :--- | :--- | :--- |
| 控制变量 | φ | **振幅相位** |
| 切换 | 二值 | **连续旋转** |
| λ | 饱和在 0/1 | **连续** |
| **PR** | **1.0**（锁死） | **29.46** |
| 整合 | 1.000 | 0.803 |
| MLP | 0.594 | **0.556** |

**二值门控把整合买到 1.000，代价是维度塌成 1。连续门控让两者同时存在。**

## 判决

**⇒ 「三轴不可兼得」作废。**
**⇒ 「秩限制」那条论证只对二值切换成立**：秩限制的是**离散切换**；
一旦允许**振幅旋转（连续混合）**，系统可以停在任何中间比例上，**交换曲线有内部点**。

## 限定（必须带上）

- **6 种子，一个 `amp_gate=2.0`** —— **没有扫剂量**（2.0 是 1 种子冒烟挑出来的，
  这本身就是选择偏差，下一轮必须扫 `amp_gate ∈ {0.5, 1, 2, 4, 8}`）；
- 一个 `p_long=0.5`、一个 `field_radius=2`；
- 可读用的是 **MLP**（全分辨率），线性 0.534 也不错；
- **这一格是 1 种子挑出来的，6 种子确认的是"这一格成立"，不是"这个机制普遍成立"。**

## 剂量扫描（6 种子，前两档已出）：**交换没有消失，它被推远了**

| `amp_gate` | PR | 整合 | 线性 | MLP | 五条 |
| ---: | ---: | ---: | ---: | ---: | :--- |
| 0.5 | **1.42** | 0.988 | 0.698 | **0.834** | ❌ |
| 1.0 | **3.26** | 0.959 | 0.596 | **0.704** | ❌ |
| **2.0** | **29.46** | 0.803 | 0.534 | 0.556 | ✅ |
| 4.0 / 8.0 | 在跑 | | | | |

**⇒ 准确的说法不是「三轴不可兼得作废」，而是：**

> **连续振幅门控把前沿向外推，让五条阈值的交点出现了；但交换本身仍在。**
> **低剂量买解码（0.834）丢维度（PR 1.4）；高剂量买维度（29.5）丢解码（0.556）。**

**我先前那句"三轴不可兼得作废"说过头了。** 正确表述：
**从"不可行"变成"可行，但前沿仍有斜率"。**

**而且"2.0 是甜点"这件事本身有选择偏差**（1 种子挑的），剂量扫描正是为消掉它 ——
现在看，2.0 确实是**可行域的边界点**，不是"机制普遍成立"。
