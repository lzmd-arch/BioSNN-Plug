# 预注册 v2：CL 主路线切换与回放臂（2026-10-25）

**定稿时间：2026-10-25，在任何 v2 数据之前。** 原预注册
[`continual_cifar100_prereg.md`](continual_cifar100_prereg.md) 的判据定义（ACC / AF）不动；
本文件只改**路线与机制**，并把原因写死。路线切换的正式记录见
[ADR-0017](../docs/adr/ADR-0017-cl-main-route-switch-and-replay-first.md)。

## 为什么要切路线

W1 路线（Route W）的正式 CIL 结果是 **ACC 0.0876 / AF 0.290**；同一份特征上，提供任务 id 的
oracle 上界也只有 **0.322**。瓶颈在表示层，不在读出——回放修不了"特征本身分不开 100 类"。
Route W **保留为已声明的原始路线**，继续如实报告，不删除、不改写。

## ⚠️ Route R 的基线必须先重测

探索期的 Route R 数字（ACC 0.658 / AF 0.127）是在**旧的累计类集矩阵**上算的（见
[`continual_cifar100/README.md`](continual_cifar100/README.md) 与 `formal/` 的更正）。
它们**不是 CIL 口径**，不能直接当基线。所以本预注册的第一步是 **Step 0：重测基线**：

| Step 0 臂 | 特征 | 读出 | 作用 |
| :--- | :--- | :--- | :--- |
| R-NCM | 冻结 ResNet18 avgpool 512 维 | 类原型 + 白化 | Route R 的参考上界（不用于回放对照） |
| R-delta | 同上 | delta 线性读出 | **回放臂的对照基线**（回放直击它的覆盖） |

两者都按预注册 v1 的 CIL 口径（全部已见类 argmax、不提供任务 id）、5 种子跑。
**新门槛数字从 Step 0 的实测结果推导，写在结果 README 里，并注明日期**——不拿旧的
0.658/0.127 去套。

## Route R 的定义

- 特征：**冻结** ResNet18（ImageNet1K V1，avgpool，512 维），CIFAR 图 resize 到 224；
  参数不进任何梯度（`research/continual/frontends.py` 已有缓存与校验）；
- 数据 / 切分 / 顺序：与 v1 完全一致（CIFAR-100，10×10，按类 id 升序，全量）；
- 种子 0–4；评估口径与修正后的 `formal_cil` 完全一致。

## 回放臂（唯一机制）

**简化版 latent replay**：每个任务结束后，从该任务的训练特征里按类各留一小撮
（每类 20 条，固定种子）进回放缓冲；训练新任务时，每个 minibatch 按比例 ρ 混入回放样本。

| 项 | 取值 |
| :--- | :--- |
| 回放内容 | **特征 + 标签**，不是原图（latent replay）；缓冲不随任务无限增长（每类定额） |
| ρ | **0.1 / 0.3** 两档，各自独立跑；**不调第三档** |
| 读出 | delta 线性（与 R-delta 同配置） |
| 训练 | 与 v1 同：每任务 20 epoch、η=0.01；回放样本与当前任务样本等权进同一个 minibatch，比例由 ρ 控制 |
| 跑门 | 每个任务算读出权重的相对变化 `‖ΔW‖/‖W‖`；**低于 0.05 判该种子作废**（与仲裁器同一条纪律：防"更新没进权重"） |
| 种子 | 0–4 |

**一次只上一个机制。** 本轮不加归一化、不加 EWC/参数隔离——它们排在回放之后，各自
独立的预注册。理由见 ADR-0017：归因链要可分离。

## 判据（先写死）

主判据与 v1 一致，只换路线与机制：

1. **AF < 8%**（主）：回放臂相对 Step 0 的 R-delta 基线，遗忘必须降到 8% 以下；
2. **ACC ≥ 65% 且不塌**（次）：绝对 ACC 不低于 65%，且相对 R-delta 基线下降不超过 1 个百分点；
3. 跑门：每个任务 `‖ΔW‖/‖W‖ ≥ 0.05`；作废种子数必须报出来。

**两档 ρ 都报**；不因为 0.3 好看就只报 0.3。若两档都不过，结论是"回放不够"，
下一份预注册才轮到归一化——**不回头调 ρ 或换判据**。

## 这轮不做什么

- 不用原图回放（存储与隐私代价先不引入）；
- 不做参数隔离 / EWC（与 P4 §2.4 的观点有张力，见 ADR-0017）；
- 不删 Route W、不改写它的任何数字；
- 不在回放结果出来之前设计「重学快 3×」——基座还没站稳。
