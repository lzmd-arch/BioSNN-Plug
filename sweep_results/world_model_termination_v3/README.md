## 读法

- **开环想象在模型有效视界内几乎完美**：终止步误差 0.003，AUROC≈1；随机动作让回合在
  约 25 步终止，模型还没漂移。
- **闭环反馈仍是边界**：同一模型、同一 margin 分数，闭环 AUROC 只有 **0.634**，与 v2 的
  0.6469 同量级。差别来自动作反馈：平衡策略在 `θ+0.5θ̇` 阈值附近翻转动作，115 步的
  想象会因动作序列改变而发散。
- v3 **不是闭环终止过线**；它只证明固定动作序列的开环终止风险可用。v2 闭环结果原样保留。

## 下一步（v4，未跑）

v3 第 4 条是“所有非终止步 margin <1”的全或无检查，被 1–2 个模型误差步打破

**真终止命中率**，用新种子 10–14，而不是把 v3 改判或放宽成“差不多”。
