# 时序读出受控优化：结果

预注册：[`axo_spiking_temporal_optimize_prereg.md`](axo_spiking_temporal_optimize_prereg.md)。
上一轮单次：[`axo_spiking_temporal_results.md`](axo_spiking_temporal_results.md)（LIF 0.6308 vs 线性 0.5280，+10.28 pp）。

## 一句话

**给两种模型同一套读出/阈值预算、用 2 折交叉验证选超参之后，优势消失了：
两折的留出差都是 0.0000，选中的读出都是 `window1`（只看第一步越阈/发放）。**
上一轮的 +10 pp 来自“固定用 `sum_inv`、θ=0.5”的读出选择，不是脉冲的结构性优势。

## 结果

2 折按配对序号奇偶划分；每折在训练折上从（α, θ, 8 种读出）里选，测试折只报一次。

| 折 | 线性选中 | 线性测试 | 脉冲选中 | 脉冲测试 | Δ |
| :--- | :--- | ---: | :--- | ---: | ---: |
| 0 | `linear-a095` θ=0.3 `window1` | 0.9444 | `lif-a095` θ=0.3 `window1` | 0.9444 | **0.0000** |
| 1 | `linear-a095` θ=0.3 `window1` | 0.9245 | `lif-a095` θ=0.3 `window1` | 0.9245 | **0.0000** |

平均留出差：**+0.0000**。

- 训练折上的选择也几乎相同：两边都选 `window1`，准确率 0.9245 / 0.9444。
- `window1` 的分数是“第一步内越阈/发放的位的权重和”——它本质上就是“读第一步”，
  和 `rate-first` 的 0.9268 同一量级。
- 一旦允许线性模型也选这个读出，它和 LIF 完全打平；上一轮的 `sum_inv`、θ=0.5 只是
  一个没有调过的读出/阈值组合。

## 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 留出折 `spiking − linear > +0.05` | 0.0000 / 0.0000 | **没有** |
| 差在 ±0.05 内 | 是 | **打平** |
| 分别报两折 / 选中组合 | 已报 | 通过 |

## 结论

1. **上一轮的 +10 pp 不是稳健的脉冲优势**；它来自读出/阈值的单点选择。公平预算下
   线性模型追平。
2. **顺序信息确实存在**，但它在线性模型的首次越阈时间里也有；`window1` 两边同分
   说明这不是脉冲独有的。
3. 这个任务的最优读出就是“第一步”，它和 `rate-first` 一样，是任务本身给的强基线；
   脉冲没有超过它。
4. 结合前几轮（静态、遍历、噪声、流式、STP、顺序末态），**目前没有任何一个脉冲
   机制在留出数据上稳定赢过同预算的速率基线**。

## 边界

- 107 对、2 折，每折约 53 对；小样本，1 条差异约 2 pp。
- 人为顺序任务；相邻轮配对相似度未控制。
- 读出/阈值候选集是人工定的；但两种模型用的是同一套，这一点是公平的。
- 没有学习；W 是既有 Hebbian 外积。

## 下一步

- 否则应停止在 Axo 上投入脉冲；把资源放回速率路径的候选粗排/延迟优化。
