# 度异质（v18）：**没有可测的改善** —— 3 种子给的 +23% 在 5 种子下变成 +11%

## 一、v17 的错与 v18 的改正

| | 测的是什么 |
| :--- | :--- |
| v17 | 度**固定为 8**，权重 ∝ `d^(−α)` ⇒ **不是无标度网络** |
| **v18** | `P(k) ∝ k^(−γ)`，k ∈ [2, 64] ⇒ **真的是度异质** |

v17 名义过（8.0 vs 7.3）但**差别全在种子 2、无剂量–反应** ⇒ 不可信。

## 二、结果：3 种子 vs 5 种子

**3 种子：**

| γ | 50% 损伤 `n_viable` |
| ---: | ---: |
| 2 | 7.7 |
| **2.5** | **9.0** |
| 3 | 8.7 |
| 固定度基线 | 7.3 |

看起来 +23%，三个 γ 全部高于基线。

**5 种子（同一批代码，同样参数）：**

| γ | 50% 损伤 `n_viable` | 逐种子 |
| ---: | ---: | :--- |
| 2 | **8.0** | 9, 9, 10, 7, 5 |
| 2.5 | **7.8** | 7, 9, 8, 9, 6 |
| 3 | 7.8 | 9, 10, 9, 6, 5 |
| **固定度基线（5 种子重测）** | **7.2** | — |

⇒ **+0.8，而逐种子极差 ±2.5。** 五个种子的标准误约 1.6 ⇒ **+0.5 个标准误**。

**⇒ 度异质在这里没有可测地改善抗损伤。**

## 三、这是今晚第二次「加种子杀掉一个边缘正结果」

| 轮 | 3 种子 | 更多种子 |
| :--- | :--- | :--- |
| 记忆深度（v5→v6） | lag1–2 上 **3/3 同向** | **6/7**（p=0.125） |
| **度异质（v18）** | **+23%** | **+11%，噪声 ±2.5** |

**⇒ 3 种子在这套系统上系统性地偏乐观。**

这个观察本身比那两个结果值钱：**今晚所有基于 3 种子的"正向"结果都需要重新确认。**

## 四、要检测 +10% 的效应需要多少种子

效应 0.8、标准差 2.5 ⇒ 每组 n ≈ 2·(2.5/0.8)² ≈ **20**。

⇒ 后续凡是想说"某机制让余量提高了 10% 左右"，**至少要 20 种子**，
否则就是在噪声里挑数。写在这里，免得下次又犯。

## 五、结论

| 假设 | 判定 |
| :--- | :--- |
| 权重幂律 ⇒ 更抗损伤（v17） | ❌ 测错了对象（度是固定的） |
| **度幂律 ⇒ 更抗损伤（v18）** | ❌ **没有可测的改善**（+0.8，SE 1.6） |
| "分形/无标度治我们的脆性" | **未获支持** |

**神经发生**仍然没测 —— 它比"换度分布"更强（真的加单元），
而且需要可生长表示。但按本轮的教训，**它要用 ≥20 种子来测**。
