## 非平凡性守卫（v8 的教训）

- **臂差中位数 0.130**（同一 seed、同一输入序列下 LIF 与 ALIF 测试状态的逐元素绝对差；
  阈值 1e-3）。v8 的对应值是 ≤2e-7，因为 `v + thr·trace` 把复位代数抵消了；v9 的
  `s_t = α·s_{t−1} + z_t` 不含膜电位，脉冲的发放/复位/beta 确实改变读出。
- 两臂脉冲率 0.098 / 0.089（每神经元每步），网络确实发放。
- `v9_ready=true` 且 `v9_valid_as_spiking=true`。

## 边界（不许改口径）

1. **这是脉冲计数/低通码**：`s_t` 用脉冲的强度（计数），不要求用时序；时间置换检验
   没有作为判据。若要主张时序编码，需要另做预注册。
2. 读出是**固定 α 的测量头**，不是局部突触可塑性；与 v4/v5 的 RLS 读出同口径。
3. v5（计数 0.217/0.187）、v6（膜电位 0.309/0.121）、v7（群体膜电位 0.788）、
   v8（平凡 0.933）原样保留，不混报；v9 的增益来自**独立传入群体 + 脉冲迹**，
   不是“膜电位保持”。
4. 与 v4 的速率漏积分器（0.9990）仍有 0.072 的差距；`no_spiking_degradation` 线是
   ≤0.10，v9 过线但未追平速率实现。

## 结论

阶段四的脉冲工作记忆有了第一个**非平凡**的 ready 结果：独立传入群体把每个 cue 的
样本数从 5 提到 160，脉冲迹读出避免了复位擦除；LIF/ALIF 状态差异证明脉冲动力学参与
了读出。下一步是情景记忆的局部 delta 规则与通用 OOD；P3 的闭环终止仍是独立边界。
