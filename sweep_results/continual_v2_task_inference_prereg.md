# 预注册：CL 任务推断保底臂（2026-10-26）

**定稿时间：2026-10-26，在本轮任务推断数据之前。** 输出行轴（相变）与特征轴（Fisher≈随机）
都已封；按裁决启动**任务推断保底臂**。它不改变"纯 CIL"的已发布结论，只测量一件事：
**在这个配置下，任务边界信息是否必须以某种形式进入推理。**

## 机制（局部、无反向传播）

```text
每任务一个头 h_t：DeltaReadout(512 → 10)，只在本任务训练数据上更新；旧头冻结
任务原型 μ_t = 本任务各类均值的均值（只用训练特征）
推理：t̂ = argmin_k ||x − μ_k||（只看已见任务）；ŷ = argmax_c h_t̂(x)
不提供任务 id；路由完全由输入特征决定
```

- 头是 10 类的局部读出（不是 100 类全局行），因此任务间**结构上**不共享输出参数；
- 原型是均值，不是学出来的判别器；距离是欧氏（本仓 ResNet 特征行范数恒为 1，
  欧氏与 cosine 同序）；
- 无回放、无归一化、无行/特征掩码。

## 两个臂

| 臂 | 路由 | 作用 |
| :--- | :--- | :--- |
| **T1 routed** | 最近任务原型（输入推断） | 主臂：无任务 id 的推断路由 |
| **T1-oracle** | 真实任务下标 | 上界：任务 id 已知时的 per-task 头 |

oracle 臂不是候选形态，只用来分解瓶颈：如果 oracle 也到不了 65%，限制在头/特征；
如果 oracle 到得了而 routed 到不了，限制在**路由可分性**。

参考臂（已跑）：R-delta-mini 0.2466 / 0.8047；P1 0.5426 / 0.1739；P1+R 0.4310 / 0.0291；
特征掩码 F1 0.2343 / 0.7727。

## 固定协议

| 项 | 取值 |

| 特征 | 冻结 ResNet18 avgpool 512 |

## 判据（先写死）

1. **阶段门（同一 ACC/AF 定义，但路由由输入推断）**：ACC ≥ 65% 且 AF < 8%；
2. **路由可读性**：任务推断准确率（已见任务上）≥ **90%**；低于它时，ACC/AF 只能写成
   路由受限，不能写成"任务边界信息可推断"；
3. **oracle 上界**：T1-oracle 的 ACC ≥ 65%——否则限制在头/特征，不在路由；
4. **不是平凡解**：每任务头在**刚学时**的类内准确率（对角线）≥ 0.80；低了对角线说明
   头本身没学会；
5. 跑门照旧，作废种子数写进 summary。

## 口径与限制（必须原样写进结论）

- 这是**任务推断 CIL**，不是"不提供任何任务边界信息"的纯 CIL。任务标签在**训练时**
  可用（这是增量学习的常规设定），推理时只从输入推断；
- 纯 CIL 的已发布数字（R-delta-mini / P1 / P1+R / 特征掩码）**不变**，也不被本臂替代；
- 每任务头之间结构隔离，AF 主要由路由错误造成；不要把"AF 低"直接读成"算法抗遗忘"；
- 无反向传播：头用 delta、原型用均值、路由用最近邻；
- 5 种子、单一骨干、单一 η；不调任何超参数。

## 实现（代码先于数据，单独提交）
