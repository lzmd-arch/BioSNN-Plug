# 预注册修订 2：事件池与终止事件的分层采样（2026-10-26）

**修订时间：2026-10-26，在本轮任何数据之前。** 原文与修订 1 见
[`episodic_memory_v0_prereg.md`](episodic_memory_v0_prereg.md)、
[`episodic_memory_v0_prereg_amend1.md`](episodic_memory_v0_prereg_amend1.md)。

## 为什么修

CartPole 的终止事件约占步数 0.7%、回合数 18%。从 20 回合的池子里随机抽 N=500 条，
终止事件平均不足 1 个——终止回忆会直接 `not_evaluable`，容量曲线也无法回答
"记忆能不能记住稀有事件"。

## 修订（只改采样，不改机制/判据）

1. **事件池扩到 200 回合**（平衡启发式 + ε=0.1），终止事件约 30–40 个；
2. 每个 N 的事件子集**分层采样**：先取 `min(终止事件数, ceil(0.1·N))` 个终止事件，
   再用随机未终止事件补满 N；
3. 终止回忆的查询集 = 子集内**全部**终止事件 + 等量随机未终止事件；
4. 子集内终止事件 **<5** 时该 N 记 `not_evaluable`；其余判据不变。

## 不做什么

- 不改变 D/k/σ、动作/时间/容量判据；
- 不因为分层后动作分布变化而调阈值；
- 不把终止事件的比例当成"自然分布"来宣称——这是为了可测稀有事件。
