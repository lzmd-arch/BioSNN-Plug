# 预注册：小参数模型上的 LIF vs ALIF（sMNIST）

**定稿时间：2026-10-18（中国标准时间）。**
**这份规则在看到任何多数种子结果之前写死。** 1 epoch 的两个臂各跑过一次，仅用于确认
代码能跑通与计时；那两次的准确率（0.3470 / 0.3444）**不作为本比较的依据**。

## 要回答什么

在**单层循环网络、64 个脉冲神经元、约 5.5 万参数**的规模上，用同一套 e-prop 实现、
同一份 sMNIST、同一预算，**ALIF 的适应项（β=0.07、τ_a=500）相对 LIF（β=0）是净增益
还是净负担？**

这**不是**在问「哪个神经元模型普遍更好」。它只回答这个规模、这个任务、这个预算下的
一件事，边界写在最后一节。

## 配置（两臂唯一差别是 `beta`）

| 项 | 值 |
| :--- | :--- |
| 数据集 | sMNIST（MNIST 按行展开成 784 步；像素值作伯努利发放概率，本项目自己的编码） |
| 网络 | 单层循环，`n_in=784` → `n_rec=64` → 读出 10 类 |
| 参数量 | `784×64 + 64×64 + 64×10 = 54,912` |
| 训练预算 | 10 epoch × 全训练集（60,000 中划 10% 作验证），batch 64 |
| 学习率 | `eta_in = eta_rec = 1e-2`，`eta_out = 5e-2`，`decay_out = 0.95` |
| 阈值 / 适应 | `threshold = 0.62`，`tau_adaptation = 500`，`dt = 1` |
| LIF 臂 | `beta = 0`（`ALIFCell` 退化为 LIF） |
| ALIF 臂 | `beta = 0.07`（官方/论文默认工作点，**不是**为 sMNIST 调过的值） |
| 种子 | 0、1、2（同一套种子派生：划分 / 初始化 / 打乱 / 输入编码） |
| 设备 | CUDA（RTX 5060，8GB） |

## 主判据

**主指标：3 个种子的测试准确率均值。** 差按绝对百分点算：

| 条件 | 动作 |
| :--- | :--- |
| `mean(ALIF) > mean(LIF) + 1.00 pp` | 记为「ALIF 在此预算下胜出」 |
| 两者相差 ≤ 1.00 pp | 记为「打平」；默认仍取 LIF（更便宜） |
| `mean(LIF) > mean(ALIF) + 1.00 pp` | 记为「LIF 在此预算下胜出」 |

1.00 pp 沿用仓库上一份 lr 预注册的判据，不另立新阈值。

**稳定性闸门**（任一命中则不把差异当结论）：

- 任一臂 3 个种子的极差 > 5.00 pp → 记为「不稳」，只报区间不报胜负；
- 任一臂出现非有限的训练交叉熵，或测试准确率低于两倍随机基线（0.20）→ 记为「发散」。

## 次要指标（一起报，不参与胜负判定）

- 活跃神经元比例（必须 > 0.60，§七 的硬指标）；
- 脉冲稀疏度；
- 显存峰值（MiB）与耗时（s）；
- 逐 epoch 验证准确率曲线（每个种子落 JSON，曲线可复查）。

## 停止规则

**10 epoch × 3 种子 × 两臂，跑完即停。** 不因为「ALIF 看起来快追上了」而临时加种子或
加 epoch；也不因为「LIF 领先」而回头给 ALIF 扫 β。要把 ALIF 的工作点调开，是**下一份**
预注册，不是这一份的延长。

两种结果对应的下一步（同样在数据之前定好）：

- **ALIF 胜出** → 下一份预注册比较两者在**有延迟记忆要求**的任务上的表现；
- **打平或 LIF 胜出** → 下一份预注册才是 **ALIF 的 β / τ_a 小网格**（在同等调参预算下），
  以及异质 LIF 臂。不能把「默认 β=0.07 的 ALIF 输了」写成「ALIF 不行」。

## 这份预注册的边界（必须随结论一起引用）

1. **10 epoch 是预算截断**，两个臂都未必收敛；报的是同预算对照，不是能力上限。
2. **sMNIST 不考核延迟记忆**。适应项在文献里的卖点是时间上分散的信息与工作记忆；
   在这个任务上输，不等于在有记忆要求的任务上输。
3. **只测了一个 ALIF 工作点**（β=0.07、τ_a=500）。`a` 的稳态量级随发放率与 τ_a 变化，
   这个点的适应强度没有为 sMNIST 校准过。
4. **64 个神经元的规模很小**，结论不能直接外推到 256 / 10 万。
5. 两臂共用同一实现（`research/eprop/neurons.ALIFCell`），但 `dt=1`、复位用基阈值、
   输入电流无 `(1−α)` 因子这些约定是固定的；换实现可能改变结果。

## 怎么被核验

每个种子落一个 JSON 到 `sweep_results/neuron_models_pilot/{lif,alif}/`，字段包含
`test_accuracy`、`active_fraction`、`peak_mb`、`elapsed_s`、`curve` 与完整 `config`；
执行者按上面的判据机械地算，不引入「看起来差不多」的额外判断。
