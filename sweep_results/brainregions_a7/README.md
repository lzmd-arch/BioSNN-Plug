## 读数

### 1. 曲线形状和 sMNIST 一样：大头在 1→7

| 任务 | decay | k=1 → k=7 拿走的份额 |
| :--- | ---: | ---: |
| sMNIST（A3） | 0.95 | 13.6 / 15.8 = **86%** |
| **SHD（本轮）** | 0.95 | 38.8 / 42.1 = **92%** |
| **SHD（本轮）** | 0.99 | 23.2 / 28.5 = **81%** |

**三个任务/条件、同一个形状。** 而 k=7 与 k=1 的**窗口完全相同**（窗口由 `decay_out` 定，与 `k` 无关）——
所以这 80–92% 的增益**不可能来自"看见更久"**，只能来自"每个神经元从 1 个数变成 7 个数"。

**这是 A6 那条解释的第一份直接证据。**

### 2. L-2 差 0.3pp，照登

预注册写"7→28 ≤5pp"。decay 0.99 上是 **5.3pp**。这条门槛是我自己拍在 5pp 的，
没有先验依据——但**按规矩报不过，不改判据**。

有意思的是 decay 0.95 上 7→28 只有 **3.3pp**（过了）。两格一个过一个不过，
说明"饱和"这件事在 0.99 上确实弱一点。

### 3. 顺带一条：k≥7 之后，短窗口反而更好

| k | decay 0.95 | decay 0.99 | 谁赢 |
| ---: | ---: | ---: | :--- |
| 1 | 0.338 | **0.425** | 长窗口 |
| 7 | **0.726** | 0.657 | 短窗口 |
| 28 | **0.759** | 0.710 | 短窗口 |

**k=1 时长窗口赢**（只有一个数，窗口越宽信息越多）；**k≥7 时短窗口赢**（抽头要靠窗口的**形状**区分，
0.99 把相邻抽头抹得几乎一样）。这与"多抽头给的是多个数"一致，也与 A6 里
"0.99 下多抽头反而降"那条旁证一致。

## 边界

- **单种子**（seed 0）；只测 SHD；
- k 只测 1 / 7 / 28 三档，**没有更细的阶梯**，"1→7 是大头"不能外推成"7 是最优"；
- L-2 的门槛 5pp 是先验任意的，它不过只说明这一点，不代表"没饱和"是错的；
- 全部结论都在 SHD 10 epoch、8,192 神经元这一个工作点上。
