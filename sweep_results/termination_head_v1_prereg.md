# 预注册：世界模型 P3 终止头 v1——专用分类头（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** P3 的状态预测与闭环稳定性都过，但
终止 AUROC 只有 **0.616**：终止分数是联合 ridge 回归（状态增量 + 终止共享系数）的副产物。
v1 只做一件事：**把终止拆成专用分类头**，看瓶颈是不是"共享系数/多任务挤压"。

## 机制（测量头，不是局部学习规则）

```text
特征： [z, onehot(a), a·z, z², (a·z)²]       # 与 RidgeActionModel(quadratic) 同一特征图
头：   类平衡的 L2 逻辑回归（IRLS/牛顿，闭式迭代，不反向传播）
训练： 只在该 split 的训练回合上拟合；测试回合完全不参与
```

- 这是**测量头**：用闭式/IRLS 拟合，不声称是项目的局部学习规则；和世界模型打底里的
  ridge 同一条纪律（只作标尺）；
- 类别极不平衡（终止约 0.7% 步），用**类平衡权重** `w_pos = n/(2·n_pos)`、
  `w_neg = n/(2·n_neg)`；不调阈值，只看排序 AUROC；
- 特征标准化用训练集均值/方差。

## 数据与协议

- CartPole-v1，平衡启发式 + ε=0.1，**200 回合**事件池（与 P3 同）；
- 按**回合**切分：150 训练 / 50 测试，5 个切分种子；
- 指标：测试集终止 AUROC；报终止步率、正类数、每 split 数字。

## 判据（先写死）

1. 5 个 split 的平均终止 AUROC **≥0.75** → `termination_head_ready`；
2. 对照是 P3 联合 ridge 的 **0.616**；只报提升，不改 P3 原判据；
3. 若 <0.75：终止预测的边界结论成立（不是状态模型的问题），不调 C/特征/阈值。

## 不做什么

- 不做闭环 rollout（先用离线 AUROC 判断头值不值得接回 P3）；
- 不换神经网络/不反向传播/不调 C 网格；
- 不把专用头的成绩写成局部世界模型；
- 不因为某一个 split 好看就只报它。
