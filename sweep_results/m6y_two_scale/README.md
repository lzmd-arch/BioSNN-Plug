# M6y：**双尺度场 —— 假设被反驳**

## 假设（用户 2026-11-16 提出）

M11 的反常是"切断跨半球突触后整合反而更高"。解释是整合只由**全局场**承载。
**两个场叠加**应该给出：全局场 → 长程相干，局部场 → 空间分化。

## 第一版（`gf, gl ∈ {0, 0.5, 1.0}`）

| gf | gl | PR | 整合 | 分离 | 发放 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1.0 | 0 | 2.59 | **0.829** | 4.01 | 0.151 |
| 0 | 1.0 | **39.80** | **0.121** | 3.83 | 0.020 |
| 0.5 | 1.0 | 35.28 | 0.080 | 4.31 | 0.017 |
| 1.0 | 1.0 | 32.05 | 0.109 | 4.67 | 0.015 |

Y-1 不过（无格三者兼得）。但**这版对全局场不公平**：全局项是 `g_field·φ`，而 `gl=1` 时
φ≈0.015、`gl=0` 时 0.151 ⇒ 同样 `g_field` 效力小 10 倍。

## 第二版（修订 8：把全局场拉到 16 倍）

| `g_field`（`gl=1`） | PR | 整合 | 分离 | 发放 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | **39.80** | 0.121 | 3.83 | 0.020 |
| 1 | 32.05 | 0.109 | 4.67 | 0.015 |
| 4 | 20.96 | 0.080 | 6.09 | 0.011 |
| 16 | **2.46** | 0.095 | 8.11 | 0.009（出窗） |

**整合一点没回来（0.121 → 0.095），维度被彻底压死（39.8 → 2.5）。**

## 判决

**假设被反驳。** 不是"全局场的量不够"—— 加到 16 倍，整合仍然在 0.08–0.12，
而 PR 从 39.8 掉到 2.46。

⇒ **在局部场造成空间异质之后，任何强度的全局标量都补不回整合，只会杀死维度。**
这比"两个场拮抗"更强：**全局标量与高维状态在原理上不能共存**，
因为它对每个神经元施加同一个数 · 一个数只能携带一个信息。

## 限定

- 3 种子；`gf=16` 那格发放 0.0086 已出窗，只作趋势参考；
- 分离用的是半球内空间变异系数，`gf` 增大时它一路升到 8.11 —— 但那是因为发放趋零、分母变小，
  **这一列的绝对值在高 `gf` 下不可信**。
