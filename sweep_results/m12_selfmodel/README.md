# M12（Round I）：**自我模型 —— 过线：它知道自己会变成什么**

判据在 `research/sel/night-2026-11-16.md`（含**修订 4c** 与**修订 7**）。

## 一、两版设计，第一版是坏的

| 版本 | 设计 | 结果 |
| :--- | :--- | :--- |
| v1（预注册原版） | 用 `v_t` 预测 `z_{t+1}` | **恒真**：`z = 1[v > θ]` 是确定性阈值，AUC 必然 ≈1。测的是阈值函数存在 |
| v2（`g_inh=0`） | 从 t=64 的状态预测 t=2048 的**盆地** | **设置退化**：128 条历史聚出 82–114 个盆 = 一条历史一个盆，探针只有 96 个训练样本对 100+ 类 |
| **v3（`g_inh=1`）** | 同上，但盆数降到 13–14 | 可用 |

## 三、这条说的是什么

**在 t=64（输入停止后第 64 步）的状态里，已经含有它会在 2048 步后落进哪个盆的信息，
而且一个线性读出就能取出来。**

这不是同义反复：端点由**轨迹**决定，不由当步状态直接给出；而且它必须对**没见过的历史**
成立（训练/留出切分）。打乱配对掉到机会水平，说明没有泄漏。

**⇒ 这是 M1–M12 里唯一一条"系统对自己的未来有可读的预期"的证据。**

## 四、限定

1. **4 种子**；盆数 13–14；`per_fam=16`（每族 16 条，共 128 条）；
2. 预测的是**离散盆标签**，不是具体轨迹。"知道会落进哪个盆"比"知道会到哪里"弱得多；
3. 特征是 8×8 空间桶（64 维），不是全分辨率；
4. **这条与 M6v 的低维结论是一致的**：13–14 个盆 ⇒ 约 3.5 bit，
   而 M6v 的 PR 是 3.30 —— **同一个量级，两条独立的测量指向同一个容量。**
