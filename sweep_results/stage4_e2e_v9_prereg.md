# 预注册：阶段四端到端 v9——v8 的尺度/K/噪声稳健性扫描（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v8 在 A/B ×3、K=4、σ=0.3 上 6/6；
但这是单点。v9 固定 v8 的双 bank 结构与 bank W 尺度门，沿三条轴各扫三档，先写死
主档与稳健判据，避免把单点结果写成一般能力。

## 结构（固定）

- bank W：A/B/Q；bank D：K 对键值 + 查询；56 维拼接；
- WM 读出/成员/世界模型/OOD 置信度只在 bank W；DPAR 每幕独立；状态控制用 56 维；
- OOD 置信度固定为 v8 的 gauss3：`[disagreement, surprise, state_norm]` 三维高斯；
- 阈值只在 calibration（`seed+30_000`）上取；5 个种子。

## 三条轴（一次只动一条，主档 K=4、σ=0.3、s=3）

| 轴 | 档位 | 说明 |
| :--- | :--- | :--- |
| OOD 尺度 s | 1.5 / 2 / 3 / 5 | A/B 乘 s；s=1.5 只报告，不参与稳健判据 |
| DPAR 对数 K | 2 / 4 / 8 | 时间线随 K 延长：查询键在 `40+10K`，`test_step=40+10K+5` |
| A/B 噪声 σ | 0.1 / 0.3 / 0.5 | in-dist 线索噪声；OOD 不加噪声、只乘 s |

条件表（主档只跑一次）：

```text
main      K=4 σ=0.3 s=3
scale-1.5 K=4 σ=0.3 s=1.5   （报告，不判）
scale-2   K=4 σ=0.3 s=2
scale-5   K=4 σ=0.3 s=5
K-2       K=2 σ=0.3 s=3
K-8       K=8 σ=0.3 s=3
sigma-0.1 K=4 σ=0.1 s=3
sigma-0.5 K=4 σ=0.5 s=3
```

## 判据（每条件 5 种子均值）

每个条件都要报六项：

1. WM R² **≥0.90**；
2. WM 选择性 MSE **≤0.10**；
3. DPAR 最好臂 **≥0.80**；
4. 状态控制 **≤ 1/K + 0.10**（K=2 时 0.60、K=4 时 0.35、K=8 时 0.225；chance 为 1/K）；
5. OOD AUROC **≥0.75**；
6. OOD 弃权 **≥0.80**。

**主档**六项全过 → `v9_main_ready=true`。

> **修订 1（2026-10-27，正式数据前）**：smoke 20 幕暴露固定 0.35 的状态控制判据
> 对 K=2 不可达（chance = 0.5）。正式跑之前改为 `1/K + 0.10`，其余判据不动；
> 这是判据口径修正，不是按性能调参。K=4 仍是 0.35，与 v8 一致。

**稳健判据**：除 `scale-1.5` 外的 7 个条件（main、scale-2/5、K-2/8、σ-0.1/0.5）**全部**
六项过 → `v9_robust=true`。`scale-1.5` 只报曲线，不计入；不因为它不过就隐藏。

`v9_ready = v9_main_ready and v9_robust`。

## 报告义务

- 三条轴的曲线全部报：弃权、AUROC、WM R²/MSE、DPAR、状态控制；
- 任何一档失败都要写清是哪条判据；不能只报主档；
- 若 K=8 或 σ=0.5 失败，明确写容量/噪声边界，不调时间线/K/σ/阈值；
- v8 的 6/6 原样保留，v9 只加范围结论。

## 不做什么

- 不调 bank 维度、置信度特征、覆盖率、阈值；
- 不做全因子 36 格；本轮是一次一轴；
- 不把 `scale-1.5` 的失败写成“v8 失败”；它不在稳健判据里，只作边界；
- 不把尺度 OOD 的结论外推到信息丢失型 OOD（v6/v7 已否定）。
