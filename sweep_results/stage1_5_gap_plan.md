**用途：** 长期主线的活清单。每条只写“当前证据 / 未实现的部分 / 下一步验收动作”，
完成时改成结果链接；不在这里重复 README 的长表。

## 迭代协议

1. 一次只动一个可验收项；先预注册判据，再实现/跑数据；
2. 负结果保留，不改判据，不用单种子/单次最好值；
3. 不把“接口通了”写成“能力成立”；
4. 每个结果同步更新：结果 README、阶段状态页（三语）、计划书台账、主 README；
5. 每次引用更新先逐字核验来源；未核验标 `unverified`。
