# S0：SSM（结构化递推）vs 随机循环——**判据不过，但发现了更要紧的东西**（2026-11-06）

**预注册**：[`research/sel/prereg-lm-s0-ssm.md`](../../research/sel/prereg-lm-s0-ssm.md)
（修订 1：[`prereg-lm-s0-ssm-amend1.md`](../../research/sel/prereg-lm-s0-ssm-amend1.md)）
**原始数据**：[`s0.json`](s0.json)、[`diagnostic_currents.json`](diagnostic_currents.json)

## 一句话

**S0 的两个主判据都不过**（SSM 输给随机循环、也输给 bigram）。
**但同一轮里"无递推"那一臂第一次赢过了 bigram，而且三臂的排序与"递推电流/输入电流"完全单调——
所以前面 M0/M0b 的 kill 结论，证据基础不成立。**

## 结果

同一份语料、同一种子、同一预算（301 条、2,000 updates、batch 16、seed 0），只改"递推从哪来"：

| 臂 | test CE | test top-1 | 发放率 | 递推/直接电流（初始化） |
| :--- | ---: | ---: | ---: | ---: |
| **`none`（无递推，纯前馈）** | **1.139** | **0.717** | 1.1% | **0×** |
| `random`（冻结随机 `w_rec`） | 1.861 | 0.516 | 8.8% | **2.16×** |
| `ssm`（冻结对角 SSM，S=32） | 2.639 | 0.352 | 16.5% | **7.36×** |
| bigram（k=0.1） | 1.423 | 0.646 | — | — |

（`random` 臂与 M0b 的冻结臂数字一致：1.861 / 0.516 —— 同代码同种子，可复现。）

## 判据

| # | 判据 | 门槛 | 实测 | 判定 |
| :--- | :--- | :--- | ---: | :--- |
| S0-0 | 前置：`random`/`ssm` 发放率在带内 | [1%, 30%] | 8.8% / 16.5% | ✅ |
| **S0-1** | SSM 赢随机循环 | top-1 +2pp 或 CE −0.05 | **−16.4pp / +0.78** | ❌ |
| **S0-2** | SSM 赢 bigram | top-1 ≥0.65 或 CE ≤1.45 | 0.352 / 2.639 | ❌ |
| S0-3 | 诊断齐全 | — | 见下 | ✅ |

## 真正的发现：排序与"递推电流倍数"完全单调

初始化时测得的电流（`diagnose_currents.py`，前 120 步）：

| 臂 | 直接电流 \|·\| | 递推电流 \|·\| | 比值 |
| :--- | ---: | ---: | ---: |
| `none` | 0.0966 | — | 0 |
| `random` | 0.0966 | 0.2082 | **2.16×** |
| `ssm` | 0.0945 | **0.6958** | **7.36×** |

三项对齐：

```
递推/直接  0×   →  top-1 0.717
           2.16× →  top-1 0.516
           7.36× →  top-1 0.352
```

**完全单调。** 递推越强，next-token 越差。

## 这改写了什么

### 1. `none` 第一次赢过 bigram

**CE 1.139 vs 1.423、top-1 0.717 vs 0.646。** 一个前馈 LIF（1,024 神经元、发放率 1.1%）+
局部规则训的线性读出，在 2,000 updates 内超过二阶字符 bigram 7.1pp。

这是这条支线自 M0 以来**第一个正结果**。

### 2. M0/M0b 的 kill 结论，证据基础不成立

M0/M0b 写的是"局部学习赢不了字符 bigram"。但那两轮的"递推"臂都带着 **2.16 倍于输入的
随机递推电流** —— 比的是"被淹没的输入" vs "干净的输入"，不是"有递推" vs "没递推"。

**所以 M0/M0b 的负结果不能用来判局部学习。** 已在两份 README 与 ADR-0035 里加更正。

### 3. S0 自己的问题（SSM vs 随机循环）**没有被公平回答**

SSM 臂的电流是输入的 **7.36 倍**——它在测试之前就已经饱和了（发放率 16.5%，接近随机循环的两倍）。
**S0-1 的"不过"不能读成"结构化递推没有价值"**，只能读成"这个尺度下的 SSM 没有价值"。

## 能说什么、不能说什么

**能说**：

1. **前馈 LIF + 局部读出，在这份语料上赢过 bigram**（1.139 / 0.717 对 1.423 / 0.646）；
2. **递推电流与输入的比值是本轮最强的单一解释变量**：0× / 2.16× / 7.36× 对应 0.717 / 0.516 / 0.352；
3. SSM 在**当前这个未标定的尺度**下比随机循环更差。

**不能说**：

1. **不能说"递推没用"**——三个递推臂都没标定过增益，等于让它们带着 2–7 倍的噪声上场；
2. **不能说"SSM 的归纳偏置无效"**——S0-1 是在一个饱和的 SSM 上测的；
3. **不能说"0.717 是这条线的能力"**——单种子、测试集 46 条（top-1 的 SE ≈0.9pp）、模板语料。

## 下一步该做什么（不由本文件开，等用户拍板）

一个**公平的递推对照**只需要一件事：**把递推电流缩到与输入同量级**（随机循环除以约 2.2，
SSM 除以约 7.4），其余一律不动。这需要在**新预注册**里写死"电流比目标 ∈ [0.8, 1.3]"作为前置判据，
再问一次"递推有没有用 / SSM 有没有用"。成本与 S0 相同（约 20 分钟）。

在那之前，能拿出去的结果只有一条：**前馈 LIF + 局部读出 > 字符 bigram**。

## 边界

- 单种子；模板语料、非对话；
- 只在 1,024 神经元 / 2,000 updates 这一个工作点上；
- 电流诊断测的是**初始化后**的比值（训练会改权重），但它正是决定三臂差异的那个量。
