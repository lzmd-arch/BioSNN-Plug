# 预注册：多时间尺度工作记忆 v0——双线索延迟保持（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** 阶段四最后一个未开始的组件。计划书 §2.2：
工作记忆要维持长时神经元时间尺度。v0 做一个可测的最小件：**两个不同时间的线索，在延迟后
同时回忆**——快单元记近的、慢单元记远的，单一时间尺度必然漏掉一个。

## 机制（固定时间常数的漏积分器 + 线性读出）

```text
输入 x(t) ∈ R^4
多时间尺度状态：h_j(t+1) = α_j·h_j(t) + (1−α_j)·x(t)
                τ_j ∈ {2, 5, 10, 20, 50, 100, 200}，α_j = exp(−1/τ_j)
时间线：t=0..4 线索 A；t=20..24 线索 B；t=25..49 噪声；t=50 读出
读出：线性 W（ridge 闭式，测量头），从拼接状态 h 重建 A 与 B
```

- 时间常数固定，不学习；读出是 ridge 闭式（测量头，不是局部学习规则）；
- 单时间尺度基线：只用 τ=2（快，记 B）或 τ=200（慢，记 A）；
- **双线索同维**：慢单元会把 A/B 混在一起，只有"快+慢"的组合才能同时分开——这是 v0
  要验证的"多时间尺度必要性"。

## 数据与协议

| 项 | 取值 |
| :--- | :--- |
| 线索维度 | 4 |
| 训练 / 测试 | 2000 / 500 个独立回合 |
| 噪声 | 输入噪声 σ=0.01；线索窗口内为线索+噪声，窗口外纯噪声 |
| 读出 | ridge（λ=1e-3），只用训练回合拟合 |
| 指标 | 测试回合上 A、B 的 R²（逐维平均） |

## 判据（先写死）

1. **多时间尺度**：测试时 A 的 R² **≥0.50** 且 B 的 R² **≥0.50**；
2. **必要性对照**：只用快 τ=2 时 A 的 R² **<0.30**；只用慢 τ=200 时 B 的 R² **<0.30**；
3. 两条都过 → `w0_ready`；否则报边界，不调 τ 列表/噪声/λ。

## 不做什么

- 不做学习型循环权重、不做脉冲 ALIF（v1）；
- 不做工作记忆与世界模型/情景记忆耦合；
- 不调 τ 列表/噪声/λ/线索引子；
- 不把 ridge 读出写成局部学习规则。
