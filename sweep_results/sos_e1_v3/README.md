## 这一轮真正的产出：**我的门槛一直是拍的**

三次 E1 尝试，三次挂在"差一点点"上：

| 版本 | 挂在哪 | 差多少 |
| :--- | :--- | :--- |
| v2 | 格子命中 ≥0.85 | 0.627（上限只有 0.789，**门槛不可达**） |
| v3 | 比边际高 ≥0.20 | +0.139 |
| v3 | 熵 CV ≥0.10 | 0.097 |

这不是模型的毛病，是**定门槛的方式错了**：三次都是先拍一个数、再看数据，
而这正是仓库里早就记过的一条教训（「预注册比值判据要先标度标定」）。
**下一版应当用 pilot/confirm 划分**：一半迷宫估出量级、另一半做确认，门槛由 pilot 定。

## 不做什么

- 不调门槛重跑（那正是要避免的动作）；
- 不因为 +0.139 接近 +0.20 就宣布 P1 通过。
