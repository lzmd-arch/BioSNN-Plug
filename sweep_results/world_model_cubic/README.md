# 模型类升级（三次项）：**预测更好，控制全崩**（2026-11-12）

## 动机

Acrobot 的能量项里有 `ω·cos θ` 这类乘积，二次拟合器的一步 NMSE（0.042–0.050，相对
`copy_last` 0.36 倍）明显吃紧，远不如 CartPole。于是给 `RidgeActionModel` 加 `cubic`
选项：在既有 `[1, z, onehot, interaction, z², interaction²]` 之上再加 `z³` 与 `interaction³`。

## 结果（60 回合训练 / 10 回合评测 / h=10）

| 种子 | 二次 NMSE | 三次 NMSE | 二次回报 | 三次回报 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.0504 | **0.0482** | −261 | **−500** |
| 1 | 0.0504 | **0.0491** | −178 | **−500** |
| 2 | 0.0422 | **0.0409** | −95 | **−500** |

**一步 NMSE 三个种子全部改善，控制回报三个种子全部跌到 −500（一次都不成功）。**

## 机制

rollout 日志出现 `overflow encountered in power` 与 `invalid value encountered in matmul`：
三次项在预测状态稍微变大时立即溢出，`score()` 拿到 inf/nan，`argmax` 退化成随机选动作。

**这与前两条负结果是同一个模式**：模型在**单步**上更准，在**多步**上更快发散。

| 优化 | 一步 NMSE | 控制 |
| :--- | :--- | :--- |
| 状态裁剪 | 不变 | −178 → **−287** |
| 集成分歧度惩罚 | 不变 | −247 → **−299**（λ=4） |
| **三次项** | **改善 2–4%** | **−178 → −500** |

三次是三条里唯一**改善预测**的，也是**唯一把控制彻底打没**的——方向一致：**更敢外推**。

## 结论

- 在这条管线上，**加容量 = 加外推爆炸的风险**，而不是加能力；
- 真正需要的是**受限的外推**（例如在归一化空间里做 rollout、或对预测做物理约束），
  而不是更强的拟合器；
- 三步前瞻之所以能工作，靠的是"**在数据附近、短距离**"这两个条件同时成立。

## 四问

1. 预算截断？否；2. 跨环境？只在 Acrobot；3. 单边指标？是（回报），故与 NMSE 一起报；
4. 先验未兑换？不涉及。

## 加物理约束之后：**根因不在溢出，在数据覆盖**

Acrobot 的状态是 `[cos θ1, sin θ1, cos θ2, sin θ2, ω1, ω2]`，前两对必须满足 `cos²+sin²=1`。
加了单位圆投影（**只投影真不变量，不裁观测范围**）后：

| 种子 | h=10 裸 → 投影 | h=20 | h=40 |
| ---: | ---: | ---: | ---: |
| 0 | −261 → **−500** | −500 → −500 | −386 → **−266** |
| 1 | −178 → **−500** | −445 → −500 | −500 → **−167** |
| 2 | −95 → **−499** | −379 → −500 | −500 → **−250** |

**长前瞻被救回来，短前瞻被打死**——混合结果，而且投影后仍有 `overflow in square`，
说明爆掉的不是角度维，是速度维。

### 真正的根因（这一轮最有价值的发现）

逐维看训练数据：

| 维 | 训练范围 |
| :--- | :--- |
| **cos θ1** | **[−0.065, +1.000]** |
| sin θ1 | [−1.000, +1.000] |
| cos θ2 | [−1.000, +1.000] |
| sin θ2 | [−1.000, +1.000] |
| ω1 | [−3.73, +3.70] |
| ω2 | [−7.25, +6.19] |

Acrobot 的成功条件是 **`−cos θ1 − cos(θ1+θ2) > 1`**，即需要 **cos θ1 ≈ −1**。
而随机策略采到的数据里，**cos θ1 从来没低于 −0.065**。

> **目标区域根本不在训练分布里。**

这解释了此前所有负结果为什么方向一致：

- 裁到训练范围 ⇒ 禁止进入目标区 ⇒ 更差；
- 集成分歧度惩罚 ⇒ 目标区分歧最大 ⇒ 被降权 ⇒ 更差；
- 三次项 ⇒ 在无数据区外推更猛 ⇒ 爆得更快。

**不是护栏写错了，是这条数据根本覆盖不到要解决的问题。** 三步前瞻能在 CartPole 工作，
是因为它的目标（保持竖直）就在数据分布内部。

### 下一步（唯一有意义的）

不是改模型或改护栏，是**改数据采集**：让随机策略带**能量注入偏置**（例如以更高概率重复
同一动作以积累动量），使 `cos θ1` 覆盖到接近 −1 的区域。这需要新的预注册。
