## 机制

`k = top-32(R·s) 的符号`（D=512）；`M = Σ vᵢ kᵢᵀ`；回忆 `r = qM`。值 = 动作 one-hot(2)
+ 终止 one-hot(2) + 时间戳。字面最近邻（原始状态）单列作基线。

## 读数

- **朴素 Hebbian 外积不够**：动作只比随机好一点（0.65），终止与时间顺序基本是 **0.5**；
  键之间的串扰把 5 维值淹没。容量曲线几乎平——不是"容量用完"，是**一开始就串扰**。
- **字面最近邻全面更好**：动作 0.76、终止平衡 0.955、时间顺序 0.61。它证明数据里有信息，
  失败在联想编码/读出，不在任务。
- 即使字面 NN，时间顺序也只有 0.61 <0.75：时间戳这一路的读出设计也弱，v1 需要单独处理。
- 这不是平凡解：终止用平衡准确率与 TPR，且先于数据修订；普通准确率的 ~99% 没有用来判过。

## 结论

**v0 不 ready。** 按预注册不调 D/k/σ/阈值；朴素外积记不住这个规模的事件。下一版（v1）
的自然方向是**局部吸引子迭代**（用键的反复符号更新降串扰）或**正交化/伪逆**（后者不再是
纯局部，需要明确标注）；时间戳要用独立通道。按顺序，下一项是元认知门控 v0；情景记忆 v1
作为并行开放项。
