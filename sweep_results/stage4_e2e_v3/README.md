# 阶段四端到端 v3：容量/噪声/延迟压力测试（2026-10-27）

预注册：[`stage4_e2e_v3_prereg.md`](../stage4_e2e_v3_prereg.md)。5 个种子，2000 训练 /
500 测试。主档 **K=8、σ=0.3、t=100**；五条判据中**四条过，OOD 弃权未过**，
`e2e_v3_ready=false`。

## 结论

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| in-dist 重建 R²（A/B/Q/E 均值） | ≥0.50 | **0.9092** | 过 |
| 80% 覆盖选择性 MSE | ≤0.10 | **0.0675** | 过 |
| OOD 检测 AUROC | ≥0.75 | **0.8350** | 过 |
| OOD 弃权率 | ≥0.80 | **0.7056** | **未过** |
| E top-1（K=8，chance 0.125） | ≥0.80 | **0.9040** | 过 |

**主失败项是弃权，不是检测排序**：AUROC 0.835 说明 OOD 的置信度排序仍可用，但把阈值
钉在 in-dist 80% 覆盖时，OOD 有 29.4% 被放行。五个种子的弃权率分别是
0.740 / 0.744 / 0.618 / 0.700 / 0.726，**全部低于 0.80**，不是单种子波动。

### 与 v2 的关系

v2（K=2、σ=0、t=60）的弃权 0.824 只比门槛高 2.4 pp。v3 把压力加上去后，所有档位的
弃权都在 0.706–0.793 之间：**v2 的弃权余量本来就很薄**，不是 v3 引入了一个新缺陷。
v2 在自身预注册下仍然成立；v3 说明那条线不能外推到容量/噪声/延迟更大的情形。

**容量边界在 K=8–16 之间**：K=16 的五个种子是 0.766 / 0.788 / 0.768 / 0.790 / 0.756，
全部低于 0.80。K 从 2 增到 8 时 E 准确率只降 9.6 pp，8→16 再降 13.0 pp；这是 4-bit
码在 16 类时码距最小、状态噪声最容易跨类的点。不要把这条曲线读成“能记 16 类”。

## 三轴对照（K=8、t=100，除延迟轴为 t=60）

| 轴 | 档位 | OOD 弃权 | E top-1 | 选择性 MSE |
| :--- | :--- | :--- | :--- | :--- |
| 噪声 σ（t=100） | 0 / 0.1 / 0.3 | 0.7488 / 0.7336 / **0.7056** | 0.9124 / 0.9124 / 0.9040 | 0.0651 / 0.0656 / 0.0675 |
| 延迟 t（σ=0.3） | 60 / 100 | 0.7340 / **0.7056** | 1.0000 / 0.9040 | 0.0017 / 0.0675 |
| 容量 K（σ=0.3，t=100） | 2 / 4 / 8 / 16 | 0.7928 / 0.7592 / **0.7056** / 0.7164 | 0.9996 / 0.9864 / 0.9040 / 0.7736 | 0.0164 / 0.0222 / 0.0675 / 0.0678 |

读法：

- 噪声从 0 加到 0.3，弃权降 4.3 pp；延迟从 60 拉到 100，弃权降 2.8 pp；K 从 2 增到 8，
  弃权降 8.7 pp。**三轴同向，容量轴对弃权的影响最大**，但没有哪一轴单独把结果拉回 0.80；
  K=2 在 t=100、σ=0.3 下也只有 0.793，说明延迟/噪声已经把余量吃掉了。
- 延迟主要伤 Q 的重建（R² 0.997 → 0.756）：Q 在 t=30–34，离测试点最远。E 在 t=45–49，
  也同时从 1.000 降到 0.904。
- 选择性 MSE 从 0.0017 升到 0.0675，仍在 0.10 内，但余量也从 98% 缩到 32%。

## 边界

1. 这是**合成任务**上的压力测试；K=8/16 的 E 仍是 4-bit 可解码码，不是自然情景记忆。
2. 预注册写的是“4-bit 二进制模式”；实现用**逐位平衡的 ±1 码**（K=2/4 不是标准二进制
   计数），因为标准码在 K<8 时有恒定位，`average_r2` 的分母会退化为 0。类别数、档位和
   判据都没变，但这是编码实现上的明确选择，记在这里以免读者按标准二进制复现出不同数字。
3. 弃权未过不推翻 OOD 检测：AUROC 0.835 过线。失败在**阈值-覆盖率口径**下 OOD 与
   in-dist 的置信度重叠，而不是排序完全失效。
4. 置信度仍是成员分歧 + 世界模型一步惊喜的 z-score 堆叠，没有重新标定；按预注册不调。
5. 容量曲线只到 K=16（4-bit 上限）；K>16 需要换编码，不在本轮预注册内。
6. 单次运行 398.2 s（5 种子 ×7 档）；结论只覆盖这套合成分布。
