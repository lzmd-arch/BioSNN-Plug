# 预注册：阶段五 M3o——在新语料上复测 `Rmean` / `Rcentroid`（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（M3n 已测，不是猜测）

M3n（[`phase5_m3n/README.md`](phase5_m3n/README.md)）在同一批 5 段对话上比了五个 embedding
新颖度分数：`R5` 0.7475、`Rall` 0.7581、`Rmean` **0.8005**、`Rcentroid` **0.8325**、`Rz` 0.7141。
按预注册的判据（池化 ≥0.80、≥4/5 会话 ≥0.70）**`Rmean` 与 `Rcentroid` 过线**。

但那是**在同一批 5 段上从 5 个候选里挑**出来的，天然乐观。M3n 的「下一步」写的就是：
**在新 fixture 上复测**。M3o 只做这一件事。

## 数据

- 新 fixture：同一生成脚本、**不同话题**（装修/兴趣班/健身/读书会/签证）、**不同生成种子**
  （`--seed-offset 5000`），5 段 × 20 轮、同样 5 个目标轮/段；
- **sha256 `efd5005ef5fb17c71f2ef1a61d7b9201ab62d1f467091e44a1240a5cc0b934a6`**
  （生成于任何 M3o 评测之前，落盘后不再改动）；
- 与 M3l/M3n 的 fixture **不重叠**：话题不同、生成种子不同。

## 协议

- 分数：`R5`（对照）、`Rmean`、`Rcentroid` —— **只有这三个**，不再引入新候选（引入就等于
  又在这批数据上挑）；
- 判据与 M3n **完全同口径**：池化 AUC ≥ **0.80**、且 **≥4/5** 段单段 AUC ≥ **0.70**；
- 触发器参考：M3m 的众数参数（`k=1.5`、`n_hits=3`、每轮 100 ms），5 种子，**不作判据**；
- 实现与 M3n 同一脚本（`--expect-sha256` 传新 fixture 的哈希）。

## 判据（先写死）

1. **复现**：`Rmean` 与 `Rcentroid` 中**至少一个**在**新语料**上同时满足池化 ≥0.80 与
   ≥4/5 会话 ≥0.70 → `score_family_replicated=true`；
2. 两个都不过 → `false`：结论写成「**M3n 的过线是语料特定的**」，不调分数、不换判据；
3. 另报：`R5` 在新语料上的同一指标（作对照，判断是不是整批语料更好做而不是分数换对了）。

## 读法护栏

- 只测 M3n 已经点名的两个分数，**不新增候选**；新增候选就是第二次选择性拟合；
- 若 `R5` 在新语料上也 ≥0.80，那么「换分数有用」的证据是**会话间的一致性**（≥4/5 段），
  不是池化 AUC 的绝对值；
- 不把复现成功写成「自主触发成立」：本轮只测分数，触发仍然只是参考；
- 两批语料的**难度可能不同**（M3n 里会话 0 曾只有 0.56），必须逐会话报，不许只报池化。

## 不做什么

- 不改分数定义、不改触发器参数、不改判据阈值；
- 不在看到结果后再加候选分数或再换语料；
- 不与 M3n 的数字合并报告（两批数据分开列）。

## 边界

- 新语料仍是 `qwen3-4b` 生成、仍是脚本安排的目标轮；「复现」只在**同一条生成管线**内成立；
- 5 段 × 5 个正例，单段 AUC 的不确定度依旧很大；
- 话题不同意味着难度不同，M3o 与 M3n 的池化 AUC **不可直接比大小**，只能各自对照判据。
