## 读数：v3 的失败是**先验不匹配**，不是局部规则不行

- RLS 的 `P₀=δI` 与 ridge 的 `λ` 满足 `δ=1/λ`；ridge 用 λ=1e-3 → 等价 δ=1000；
  v3 用了 δ=1（等价 λ=1，强 1000 倍正则），把系数压小（θ 范数 178 vs 772）；
- 仅把 δ 对齐后，RLS 在**同一逐样本局部更新**下三线索全部 0.998+，均值反超 ridge；
- 这是**局部读出**：rank-one 更新只用读出误差与突触前状态；它维护协方差矩阵 P，但
  不反向传播、不做批量闭式求解；
- 单尺度对照仍全漏（fast A −0.005、mid 漏 A/B、slow 三个 <0.5），多时间尺度必要性成立。
