# R1：三档难度阶梯——**只有 E 档有效，M/H 欠拟合**（2026-11-06）

**预注册**：[`research/sel/prereg-lm-r1-synthetic-ladder.md`](../../research/sel/prereg-lm-r1-synthetic-ladder.md)
**原始数据**：[`r1.json`](r1.json)、[`ladder.json`](ladder.json)（三档 bigram 基线）

## 一句话

**E 档（bigram 0.4765）赢 bigram +2.1pp、六折全胜、且已收敛；M/H 两档输 10–12pp，
但它们的损失只降到 0.71–0.82 倍——欠拟合，按预注册的 R1-2 前置判为「不可判」。**

## 我的设计错误：更新次数没跟着语料扩

- S2：301 条训练样本、2,000 updates = **106 个 epoch**；
- R1：每折 2,500 条、仍是 2,000 updates = **12.8 个 epoch**——**少 8 倍**。

语料扩了 8 倍，我只改了数据，没改更新次数。**这直接导致 M/H 欠拟合**，
所以它们的"输"不能归因给语料难度。按预注册 R1-2 的原文："不过是管线问题，排除后再判"——
**本轮 M/H 判为不可判，不判为输。**

## 顺带排除的一个怀疑

我一度怀疑 M/H 崩掉是因为词表上限 800 把生僻字吃掉了。实测：

| 档 | 落在 top-800 之外的字符占比 |
| :--- | ---: |
| E | **0.0%** |
| M | 2.3% |
| H | **2.7%** |

**不是词表截断**（97%+ 的字符都保留了）。这个怀疑排除。

## 唯一能引用的一条

**在 E 档上，前馈 LIF + 局部读出赢字符 bigram +2.08pp，六折全胜，且模型确实收敛（CE 降到 0.50 倍）。**
这是 S2（模板语料，bigram 0.646，+7.7pp）与 R0（真实语料，bigram 0.184，−10.4pp）之间的第三个有效点。

三个有效点放在一起：

| 语料 | bigram | Δ |
| :--- | ---: | ---: |
| SEL 模板（S2） | 0.646 | **+7.7pp** |
| **R1-E** | **0.4765** | **+2.1pp** |
| 真实会话（R0） | 0.184 | −10.4pp |

**三点单调**——但中间那段（0.35–0.30）仍然空白，M/H 本可以填上，现在没填上。
