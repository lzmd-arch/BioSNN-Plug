# 预注册 amend 1：触发判据 v2 的四个操作细节（2026-11-02）

**状态：写在任何 conformal 阈值被计算之前。** 此时已知的只有 M3p 已发布的历史结果
（逐段 AUC、分层）与 [`phase5_trigger_v2_prereg.md`](phase5_trigger_v2_prereg.md) 的判据原文；
**没有算过任何校准分位数，也没有见过 T-1…T-4 的任何一个数字。**

## 为什么要这份 amend

v2 预注册把判据（T-1…T-4）与 α 写死了，但有四处操作细节没定义到能直接实现：

1. 「误触发率」与「命中率」的分母是什么（轮还是段）；
2. 校准分位数的具体取法（有限样本修正）；
3. T-3 里「基线 F1」的基线是什么；
4. T-4 的「合成流」怎么造。

这四处不写死，跑出来的数就取决于实现者的随手选择。**判据与门槛一个都不改**，只补齐定义。

## 1. 单位与分数

- 单位是**一轮**；`R5` 一字不改（`biosnn_mcp.roc.novelty_scores(history=5)`，与
  [`scripts/run_phase5_m3n.py`](../scripts/run_phase5_m3n.py) 的 `score_r5` 逐位同义：段内计算、
  窗口 5、首轮记 0、截断到 [0, 1]）；
- 每段 20 轮，目标轮固定 `[4, 8, 12, 16, 19]`（与 M3l–M3p 相同）。

## 2. 划分

20 段按索引奇偶划分：**偶数索引（0,2,…,18）为校准集，奇数索引（1,3,…,19）为测试集**。
理由：语料按话题顺序排列，连续切分会把话题差异混进划分；奇偶划分不看任何分数，
两种流用同一条规则，跑之前固定。

## 3. 分位数（split conformal，带有限样本修正）

校准池 = 10 段校准对话里**全部非目标轮**的 `R5` 分数（n = 150）。
校准分数升序排列，取**第 ⌈(n+1)(1−α)⌉ 小**的那个作为 q（1-based；α = 0.10 → 第 136 个）。
若该序号超过 n，则 q = +∞（永不触发）——本批 n = 150 不会发生，写下来是为了脚本不静默出错。

触发规则：**分数 > q**（严格大于）。

## 4. T-1 / T-2 的口径

- **T-1 误触发率** = 测试段（10 段）里分数 > q 的**非目标轮**数 ÷ 非目标轮总数（150）。门槛 ≤ 0.10。
- **T-2 命中率** = 测试段里分数 > q 的**目标轮**数 ÷ 目标轮总数（50）。门槛 ≥ 0.50。

预注册那句「同一段对话内的重复触发按每段最多一次计」落在 T-3 的逐段 F1 上（见下）；
T-1/T-2 的分母**不**改成「段」——per-turn 的误触发率才是 conformal 那条 ≤ α 保证对应的量。

## 5. T-3 的基线

- 每段 F1 在**轮**上算：TP = 分数 > q 的目标轮，FP = 分数 > q 的非目标轮，
  FN = 未触发的目标轮，`F1 = 2TP / (2TP + FP + FN)`；某段 TP+FP+FN = 0 时记 F1 = 0。
- **基线** = `R5` 加一个固定阈值（「调一次、到处用」的朴素做法）：阈值取校准段的非目标轮 +
  目标轮上**池化 F1 最大**的那个候选（候选 = 校准池出现过的全部分数，并列取最小阈值）。
- **两向交叉拟合**，避免「基线在自己的校准段上必然占优」：
  - 方向 A：偶数为校准、奇数为测试；
  - 方向 B：奇数为校准、偶数为测试；
  - 每段只用**它不在校准集里的那个方向**给出的 q 与基线阈值（每段各有一个 out-of-fold 的
    conformal 工作点与一个 out-of-fold 的基线工作点），20 段各得一份 F1，逐段比较。
- 判据：`F1_conformal ≥ F1_baseline` 的段数 ≥ **12/20**（与预注册同值，严格小于不算赢）。

## 6. T-4 的合成流

- 构造：20 段 × 20 轮；20 个话题各配一组句子；第 i 段用话题 `i` 的句子做**背景轮**（15 轮，
  从该话题池里均匀有放回抽），目标轮固定 `[4,8,12,16,19]`，从话题 `(i+10) mod 20` 的池里抽。
  生成种子 `20261102`，一次生成、落盘后不再改（sha256 进结果）。
- 两条刻意的性质：段与段可交换（话题轮换、无时间趋势）；目标轮的新颖度来自话题切换。
- T-4 **不设门槛**，只报与真实流同样的 T-1/T-2/T-3 数字，作为「构造本身是否成立」的对照：
  若连这条可交换的合成流都控不住误触发，问题在构造（分位数、划分、口径），不在真实流的分布。

## 什么没变

α = 0.10、T-1 ≤ 0.10、T-2 ≥ 0.50、T-3 ≥ 12/20、打分函数 `R5`、10/10 划分、
不看测试段调任何东西。**门槛一个都没动。**
