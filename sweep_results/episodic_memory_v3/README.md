## 读数：**k=5 平均反而打不过 k=1**

- 5 个邻居的值平均把最近邻的正确值稀释了：动作从 raw 的 0.762 掉到 0.68，终止平衡从
  0.962 掉到 0.65；attention β=10 也太软，没能把权重集中回最近邻；
- 时间顺序在所有臂都 <0.61——即使 top-1 时间戳，检索错误也会翻转顺序；
- 按预注册不调 k/β/σ/容量/阈值；**情景记忆这条在“动作/终止/顺序/容量”四条上都没有
  可用配置**。

## 结论

**v3 不 ready，且情景记忆组件到此封存边界。** v0–v3 的结果一致：在这个任务/噪声/评估口径下，
局部联想（Hebbian/伪逆）和状态索引（kNN/attention）都不如“字面最近邻”的动作/终止，
而字面最近邻的时间顺序也只有 0.604。继续在同一根轴上加码没有信息量；若将来要做，
应换任务/时间编码/评估口径，而不是继续调 k/β。
