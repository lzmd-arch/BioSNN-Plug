# 预注册：Axo 真脉冲原型（静态补全 + 下一轮记忆）

**定稿时间：2026-10-18。**
**这份规则在看到任何真脉冲结果之前写死。** 已有的脉冲吸引子探针（`axo_attractor_probe.py`）
在合成语料上是负结果（n=200 一步 0.9400 vs LIF 0.7650 / ALIF 0.7550），本次**不是**
重复它，而是补三件它没做的事：真库数据、模拟/混合读出、侧抑制与异质时间常数，
以及一个真正需要时间的任务。

## 要回答什么

在 **166 条真实 Axo 记忆**上，一个**真的逐步演化膜电位、产生离散脉冲**的 LIF/ALIF
网络，能不能：

1. 在**静态补全**（给 50% 丢位的关联码，找回它自己）上**不差于**速率一步基线；
2. 在**下一轮记忆**（给第 t 轮的记忆码，找回第 t+1 轮的记忆）上**好于**速率一步基线。

两条都是必须回答的；只回答第一条会得到一个"更贵的等价物"，只回答第二条会得到一个
"时序专用但静态不能用"的东西。

## 数据与编码

- 数据：`D:\AxoData\memory\mem.db` 的只读副本；只取有 `lex_sdr`、非人格锚的条目。
- 编码：词法 SDR → 关联码（**全局 `idf-2.0`**，`k=64`；与 P4c 的簇内 idf 不同，
  这里是为了让所有条目共享一套 4096 位坐标）。
- 静态：`A` 为 `(n, 4096)` 加权指示矩阵；W = `AᵀA`（隐式）。
- 时序：按 `(session_id, turn_seq)` 排序，取相邻对 `(prev, next)`；关联矩阵
  `W_seq = Σ a_next a_prevᵀ`（隐式，用 `A_nextᵀ(A_prev z)` 计算）。

## 臂

**基线（速率）**

| 臂 | 定义 |
| :--- | :--- |
| `rate-static` | 一步 `A·(Aᵀ(A·p))`，取 top-1 |
| `rate-sequence` | 一步 `A·A_nextᵀ(A_prev·p)`，取 top-1 |

**真脉冲（LIF/ALIF）**

- 动力学：`v ← α·v + I_in + I_rec − θ·z_prev`；`z = 1[v ≥ θ_eff]`；不应期；
  ALIF 额外 `a ← ρ·a + z_prev`、`θ_eff = θ + β·a`。
- `I_in`：静态为归一化的 `W p`；时序为 `A_nextᵀ(A_prev p)`。
- `I_rec`：静态为归一化的 `W z`；时序为 `A_nextᵀ(A_prev z)`。
- 读出：`spikes`（脉冲计数）、`membrane`（末态膜电位）、`hybrid`（计数 + 归一化膜电位）。
- 侧抑制：`none` / `global`（按活跃脉冲数减全局抑制）/ `kwta`（每步只保留膜电位最高的 k 个）。
- 异质时间常数：`hetero=0`（同质）或 `hetero=0.5`（τ_i 按确定性的正弦序列在
  `τ·exp(±0.5)` 内变化；**不用随机数**）。

## 判据

**静态**：脉冲臂的 5 种子/确定性单次 top-1（数据是确定的，所以只有一次）与
`rate-static` 比。不是统计检验——**166 条全量、无采样**；差 1 条就是 1 条。

| 条件 | 结论 |
| :--- | :--- |
| `spiking_top1 ≥ rate_top1 - 0.02` | 静态「不差」；可以进入时序比较 |
| 否则 | 静态不达标；记录差距，不因为时序好看就掩盖它 |

**时序**：`spiking_top1` 对 `rate-sequence`：

| 条件 | 结论 |
| :--- | :--- |
| `spiking_top1 > rate_top1 + 0.05` | 时序上「赢」；值得考虑可选模式 |
| 差在 ±0.05 内 | 「打平」；没有理由为它增加依赖 |
| 低于 −0.05 | 「输」；照实报 |

**同时报**：top-5、每步脉冲数、曾发放的位比例、单次推理耗时。**不把"更稀疏"当成赢**——
稀疏是手段，不是判据。

## 停止规则

- 只跑一个预先定义的小网格：`readout ∈ {spikes, membrane, hybrid}` ×
  `inhibition ∈ {none, global, kwta}` × `hetero ∈ {0, 0.5}` × `beta ∈ {0, 1}`；
  固定 `steps=10`、`theta=0.5`、`alpha=0.95`、`rho=0.9`。
- **不在看到结果后追加网格**。若全输，结论就是全输；若某一格赢，下一份预注册再确认。
- 不在真实库上做写操作；只读副本，用完删除。

## 边界

1. 166 条、4096 位、单机 numpy；**不是 50 万神经元的规模结论**。
2. 静态/时序都是**推理**，没有 STDP/e-prop 学习；`W` 仍是 Hebbian 外积。
3. `idf` 是全局的，不是 P4c 的簇内版本；两边的数不能直接相减。
4. 时序任务的"下一轮"是**会话顺序**，不是人工标注的语义关系；它测的是序列关联，
   不是"理解"。
5. 真脉冲的能效优势需要事件驱动实现/神经形态硬件；这里量的是 numpy 向量化模拟的
   墙钟时间，**不能拿它论证能效**。
