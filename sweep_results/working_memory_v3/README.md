## 判据

| 判据 | 要求 | RLS | NLMS |
| :--- | :--- | :--- | :--- |
| 多尺度 A/B/C | 都 ≥0.5 | **过** | 不过 |
| 快 τ=2 的 A | <0.3 | **过** | **过** |
| 单尺度不能全做 | 各自至少漏一个 | **过** | **过** |
| 不因局部化退化 | ≥ridge−0.10 | **不过**（0.792 vs 0.993） | 不过 |

`v3_ready=false`。

## 读数

- **RLS 是最接近的局部读出**：三线索都过 0.5，均值 0.792；但离 ridge 的 0.993 还差
  0.201，超过预注册的 0.10 退化线；
- NLMS 即使修正了偏置归一化（仿射 `[1,x]`），A/B 仍只有 0.508/0.302；
- 局部化不是"学不动"，是**在固定 20 epoch / 逐样本更新下，比闭式解少一截**；按预注册
  不调 λ/δ/step/epoch。

## 结论

**v3 不 ready。** v1 的 ready 仍依赖 ridge 测量头；局部读出最好的是 RLS（0.792），
但未达到"不明显退化"的门槛。若继续（v4），应改**训练协议**（更多 epoch、批量 RLS、
或带正则的 RLS），而不是把退化线放宽；那也是新预注册。
