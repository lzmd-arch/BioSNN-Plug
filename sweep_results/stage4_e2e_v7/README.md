# 阶段四端到端 v7：双 bank + bank W 单独置信度（2026-10-27）

预注册：[`stage4_e2e_v7_prereg.md`](../stage4_e2e_v7_prereg.md)。与 v6 dual 相同的
56 维状态，但 WM 读出、成员、世界模型、OOD 置信度都只在 bank W（前 28 维）上算。
5 个种子。

## 结论

**5/6：只差 OOD 弃权，`e2e_v7_ready=false`。**

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| WM R² | ≥0.90 | **0.9938** | 过 |
| WM 选择性 MSE | ≤0.10 | **0.00447** | 过 |
| DPAR top-1 | ≥0.80 | **0.9620** | 过 |
| 状态控制 | ≤0.35 | **0.2352** | 过 |
| OOD AUROC | ≥0.75 | **0.8822** | 过 |
| OOD 弃权 | ≥0.80 | **0.7860** | **未过** |

## 与 v6 dual 的对照：稀释解释了大半，但不是全部

| 版本 | WM R² | WM MSE | OOD AUROC | OOD 弃权 |
| :--- | :--- | :--- | :--- | :--- |
| v6 single（28 维，无路由） | 0.527 | 0.339 | 0.874 | 0.793 |
| v6 dual（56 维联合置信度） | 0.994 | 0.0046 | 0.782 | **0.622** |
| **v7 dual（bank W 单独置信度）** | **0.994** | **0.0045** | **0.882** | **0.786** |

把 bank D 从置信度里拿掉后：

- AUROC **0.782 → 0.882**，弃权 **0.622 → 0.786**：**联合置信度的稀释确实是主因**；
- 但仍差 0.014 才到 0.80，且低于 v6 single 的 0.793；说明 **t=85 的 bank W 本身**
  也不够——A/B/Q 已衰减，OOD 信号弱于 v5 在 t=35 的 0.949。

这不是阈值位置问题：AUROC 0.882 说明排序可用，但固定 80% 覆盖下 OOD 仍有 21.4% 被放行。
按预注册不调阈值。

| 4 | 0.994 | 0.005 | 0.870 | 0.752 | 0.958 | 0.256 |

两个种子过 0.80（2、3），三个不到；均值 0.786。不是单点。

## 边界

1. 这是 **t=85 最终状态**的 bank W 置信度；v5 的 0.949 是 t=35 的 WM probe，不能直接
   比较；时间衰减是差异来源之一。
2. 路由是状态编码结构；DPAR 每幕独立建库；OOD 仍是 A/B ×3 尺度偏移。
3. 没有一臂同时做到“共存 + 弃权 ≥0.80”；v7 把 v6 的 0.622 修到 0.786，但还没过线。
4. 5 个种子、500 幕；单次运行 96.6 s；没有调阈值/特征/维度。

## 下一步

- 若坚持 t=85 共存：需要**更好的 OOD 特征**（v6/v7 已排除低维矩；生成式/循环一致性）；
- 若接受顺序组合：v5 的 t=35 probe 已有 0.949，可以作为阶段四的可用路径；
- 不要继续调覆盖率/阈值：AUROC 0.882 的排序已定，问题在 20% 尾部的重叠。
