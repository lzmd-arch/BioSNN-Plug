# 事件驱动 e-prop：100k 神经元子集冒烟（2026-10-29）

**性质：100k 训练路径的可行性冒烟，不是 epoch 验收。** sMNIST、n_rec=100,000、
fan_in=32、batch=4、**600/60000 样本**、1 epoch、100 测试样本、CPU。

## 结果

| 指标 | 实测 |
| :--- | ---: |
| 更新数 / 样本 | 150 / 600 |
| 耗时 | **575.5 s**（3.84 s/update） |
| 测试准确率 | **0.4100**（600 样本 1 epoch；不作精度结论） |
| 稀疏权重 | 3,200,000 |

## 能说什么 / 不能说什么

- **能说**：100k 神经元、batch=4 的一次 600 样本更新路径可跑通，没有 OOM；
- **不能说**：100k 的完整 epoch 可跑——按 3.84 s/update，60k 样本/batch=4 约 **16 h**；
- 0.41 只是 600 样本 1 epoch 的测试值，不能与 W2 比较；
- 500k 训练仍未验证；前向/单 update 已在 500k 上冒烟。

## 下一步

1. 用稀疏前向/批量优化压 3.84 s/update；
2. 100k 只做小子集可行性，不承诺完整 epoch；
3. 500k 训练需要新的稀疏梯度/批量方案。
