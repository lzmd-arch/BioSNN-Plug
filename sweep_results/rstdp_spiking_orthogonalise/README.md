## 读法

1. **投影把"常数分量"拿掉了，但符号没变**：干预后 `|Δin|` 普遍降到原来的 1/10 左右
   （种子 1：0.66 → 0.04），可是**所有状态仍然同号**——`Δin` 的形状随状态变，符号不变。
2. **极角上的变化本来就只有 1–3%**（例：种子 1 前 0.6595–0.6747，极差 0.015 相对 0.66）。
   投影之后这个相对形状几乎原样保留，所以"减掉沿 `p̄` 的分量"改变不了结论。
3. **这条结论直接引出了 D17**：极角方向的输入变化本来就极小。"符号不跨零"**不是权重的问题**，
   而是**输入侧根本只提供了这么一点差异**——D17 量到 2.9%，D18 修好编码后 Δ 极差涨了 30 倍。
4. 判据 3 的保留率参差（0.33–1.33）：投影本身不是"无损去常数"，它连带削掉了一部分真正的
   状态变化——这一点在 D18 的归一化编码里不会再出现（那里输入侧是可分辨的）。

## 边界

- 只在极角网格上测，且是**旧编码器**（D17 之前）；这些数字应理解为"旧口径"；
- `Δin` 是期望量；`Δ` 计数与 `slope` 是 20 窗口实测；
- 投影用的 `p̄` 是**探针状态集的均值**，不是训练时真实访问分布的均值。

## 与后续的关系

D16 的否定结果 + 随手的特征几何观察，直接促成了 D17（编码器灵敏度）与 D18（归一化编码重跑）。
按新口径看：**"符号不跨零"这一条在修好编码后仍然成立**（D18 的 slope 0/10 为正），
所以它最终被归因为**学习信号/决策层**，而不是编码，也不是权重几何。
