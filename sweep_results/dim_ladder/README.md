# 维度阶梯（D-0/D-1/D-2）：**1D 最好，更高的空间维数没有帮助**

**这一轮把"三维没用"从"没测到"变成了"测到了"。**

## 一、判据（预注册，脚本顶部）

| 编号 | 判据 |
| :--- | :--- |
| **D-0** | 窗口 32-token 对照 ≥ 1/K + 20pp（任务可解）。不过 ⇒ 整个实验作废 |
| **D-1** | 最佳维数比 1D 高 **≥5pp**，且三种子同向 |
| **D-2** | 相邻维数增益 <2pp 视为饱和 |

## 三、判

| 编号 | 结果 |
| :--- | :--- |
| **D-0** | ✅ **过**（0.642 ≥ 0.325） |

| 对比 | 逐种子 | 均值 | 同向 |
| :--- | :--- | ---: | :--- |
| 1D − 2D | +.086 / +.079 / +.116 | **+9.4pp** | **3/3** |
| 1D − 3D | +.082 / +.092 / +.098 | **+9.1pp** | **3/3** |

⇒ **2D/3D/4D 显著更差（3/3 种子）；6D 与 1D 打平（1/3 种子）。没有任何维数超过 1D。**

## 三之二、「维」在这里指的是**图格点拓扑**，不是物理嵌入维

脑组织是 3 维空间里的物体（皮层是**在 3 维中折叠的 2 维薄片**，厚约 2mm、面积约 2000 cm²）。
本实验变的"1D/2D/3D/4D/6D"是**抽象图的格点拓扑** —— 神经元没有物理坐标，
也没有"连接概率随 3 维距离衰减""传导延迟 ∝ 距离""布线成本 ∝ 距离"这三条空间定律。

⇒ **本页的结论只在这个抽象拓扑 + 这个读出下成立**：
"1D 最好"**不等于**"物理 2 维优于物理 3 维"，也**不能**用来回答"把网络做成 3 维有没有用" ——
3 维不是可选项，是任何物理实现的前提。

要测"物理布局有没有用"，变量不是格点维数，而是**3 维空间如何约束接线**（见 §七）。

## 四、一个必须先说的混淆：**入度没有对齐**

`build()` 给每个神经元的邻居数是 **2 × 维数**：

| 维数 | 1D | 2D | 3D | 4D | 6D |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 入度 | **2** | 4 | 6 | 8 | 12 |

预注册写的是"等入度"，实现并不是。`wrec` 按行归一化到 `gain`，所以**总驱动**相等，
但**邻居数**不等 —— 高维格点在同样的总驱动下把电流摊到更多邻居上，
等效于更强的空间平滑。

⇒ **这次测到的"高维更差"里，混着"入度更大"这一项，本实验拆不开。**
下一条要做的就是把入度也对齐（每格点固定取 2 个邻居），再跑一次。
**在那之前，不要引用"维数无用"作为机制结论** —— 只能说"在这个实现下，高维没有优势"。

## 五、与 `spatial_dim`（n=16384）的关系

| | `dim_ladder`（本目录） | `spatial_dim` |
| :--- | :--- | :--- |
| n | 4,096 | 16,384 |
| 读出 | **MLP（可学，够得着任务）** | 零参数最近原型 |
| 结果 | **有效**：1D 最好 | **作废**：四臂全在底板上 |

同一个问题在 4 倍规模上还答不了，因为零参数读出在 16,384 上够不到任务
（见 [`../spatial_dim/README.md`](../spatial_dim/README.md)）。
本目录这一份是**有效的那一份**。
