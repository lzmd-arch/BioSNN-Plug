# 预注册：多时间尺度工作记忆 v4——RLS 先验与 ridge 对齐（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v3 的 RLS 多尺度均值 0.792，离 ridge 0.993
差 0.201，未过"不退化"线。事后分析（**不是从测试数据挑参数**）发现原因是**先验不匹配**：

```text
RLS 的 P₀ = δI 与 ridge 的 λ 满足  δ = 1/λ
ridge 对照用的是 λ = 1e-3  →  等价 δ = 1000
v3 用的是 δ = 1            →  等价 ridge λ = 1（强 1000 倍的正则）
```

所以 v3 的 RLS 不是"局部规则不够好"，而是**先验把系数压小了**（θ 范数 178 vs ridge 772）。
v4 只把 δ 对齐到 ridge 的 λ，其余（状态/任务/数据/逐样本 20 epoch/判据）完全不变。

## 机制

```text
RLS：λ=1、δ=1000（= 1/λ_ridge），逐样本，20 epoch
其余与 v3 相同：三线索、τ=2..200、2000/500、5 种子、fast/mid/slow 对照
```

## 判据（与 v3 完全相同，先写死）

1. 多尺度 A/B/C 的 R² 都 ≥0.50；
2. 快 τ=2 的 A <0.30；
3. fast/mid/slow 各自至少漏一个线索；
4. **不退化**：均值 ≥ ridge 均值 −0.10；
5. 四条全过 → `w4_ready`；否则报边界，不调 δ/λ/epoch。

## 不做什么

- 不调 δ 的第三档、不改数据/状态/判据；
- 不把 v3 的 RLS(δ=1) 与 v4 混报；
- 不在看到数据后改退化线；
- 仍不做脉冲 ALIF（v5）。
