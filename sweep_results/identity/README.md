## 两条结论

1. **抗改写是真的**：五种诱导（忘掉人设 / 忽略设定 / 改名 / 系统提示解除）之后，
   她仍然自称千岁。这是提示词人格少见的强项。
2. **边界不完整（0.667）**：靠 system 里一句"记忆里没有的事就说不知道"不足以覆盖所有边界场景。
   这一条正是 PINN 残差门该接的位置——但门目前只在**事实断言**上生效，不覆盖"编一个加班记录"这类请求。

## 指标要改

ID-4 / ID-8 的"逐字相同"应改成**语义判据**（是否含名、是否仍在该边界内），
逐字比较测的是措辞抖动，不是人格漂移。
