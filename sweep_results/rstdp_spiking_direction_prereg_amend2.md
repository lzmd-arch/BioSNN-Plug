# 预注册修正 2：W3 D10——判据 A 的比值量会饱和，改用无饱和的差驱动极差（2026-10-29）

**对 [`rstdp_spiking_direction_prereg.md`](rstdp_spiking_direction_prereg.md) 与
[修正 1](rstdp_spiking_direction_prereg_amend1.md) 的修正。** B、C、状态集、窗口数、
随机方向对照、阈值 2.0 全部不变；只换 A 的统计量，并整体重跑。

## 发现了什么（读的是本轮自己记录的原始量，不是拟合决定）

修正 1 那一轮跑完，5 个种子里有 3 个（1、2、4）的 `r(s)` 在**全部 21 个点上都等于 ±2**：

| 种子 | `\|r\|=2` 的点数 | `r` 的不同取值数 | 原始差驱动 `in_0−in_1` 的极差 |
| :--- | ---: | ---: | ---: |
| 0 | 0/21 | 21 | 0.0011 |
| 1 | **21/21** | **1** | **0.0152** |
| 2 | **21/21** | **1** | **0.0093** |
| 3 | 0/21 | 21 | 0.0138 |
| 4 | **21/21** | **1** | **0.0113** |

`r = (d_0 − d_1) / ((|d_0| + |d_1|)/2)` 的取值域由三角不等式钉死在 **[−2, +2]**；
取到 ±2 **当且仅当两列驱动异号**。也就是说：读出差方向越**主导**（两列驱动的符号相反），
这个比值越是常数——**它在最想检测的情形里恰好失去分辨力**。上表的原始差驱动在那 3 个
种子里其实在变（0.009–0.015，与种子 0 的 0.0011 同量级或更大），只是被比值抹平了。

这不是「结果不好看」，是**量在数学上饱和**：`A_spread = 0` 在那 3 个种子上是恒等式，
不是物理结论。修正 1 那一轮的 A 判定因此**全部作废**（C/B 不受影响，但整轮仍重跑以保证
同一份代码产出同一份数据）。

## 修正后的判据 A（无饱和）

```
v(s)  = in_0(s) − in_1(s)                    # 有符号，单位：权重×发放概率
A_spread_abs = max_s v(s) − min_s v(s)
A_norm = A_spread_abs / median(同范数随机方向的 A_spread_abs，5 个)
A 成立 ⇔ A_norm ≥ 2.0                        # 阈值与修正 1 相同
```

- `v(s)` 没有分母，因此不存在饱和：它的极差随状态变化线性增长；
- 随机方向对照（原量 D）同样改用 `A_spread_abs`，对照口径与训练臂完全一致；
- 原比值 `r(s)` **照常记录并报告**，另记 `r` 被钉在 ±2 的点数比例（饱和分数），
  作为「读出差方向是否主导」的描述量，不参与判定。

## 其余判定不变

判定表（`no_differential_direction` / `lif_saturated` / `amplitude_too_small` /
`other_unattributed`）与 B、C 的阈值一字不改。

- 不因为种子 1/2/4 现在有原始差驱动，就先把结论写成「方向存在」——要等随机方向对照；
- 不改 C 的 `0.5` 计数阈值（它是计数单位，与这个饱和无关）；
- 不隐瞒修正 1 那一轮：两份 summary 都留在结果目录，README 里写清哪一轮的 A 无效。
