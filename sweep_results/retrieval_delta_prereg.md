# 预注册：跨模态检索第二轮——把外积 Hebb 换成 delta 规则

**定稿时间：2026-10-17，在这一轮的任何数据之前。**

## 它要回答什么

第一轮（[`retrieval_procedural_prereg.md`](retrieval_procedural_prereg.md)）在程序生成配对集上
得到 **R@1 = 0.141 / R@5 = 0.528**（随机 0.034），验收线 50% **未达**。

那一轮同时测到一件事：**外积 Hebb 的两个超参 η 与 λ 都只是全局缩放**，余弦对缩放不敏感，
于是「选参」在留一法网格上完全并列——**那层规则没有可调的东西**。所以 0.141 不是"没调好"，
而是这条规则在余弦排序下的上限之一。

这一轮问的是：**换成带误差修正的局部规则，能不能把排序头部收紧。**

## 规则：Widrow–Hoff delta 规则（逐步，局部）

```text
对每对 (t_i, v_i)：
    ŷ = W · t_i
    ΔW = η · (v_i − ŷ) ⊗ t_i
    W ← W + ΔW
```

**就地更新、不需要反向传播**：每个突触只用自己两端的前/后活动与一个误差信号。
误差信号 `v_i − ŷ` 是**配对训练时给出的目标**——所以这是**有教师的局部规则**，
不是无监督 Hebb，也不等于反向传播。这条边界要写在结果里，不能含糊。

⚠️ **它不会收敛到"最优"**：delta 规则在小步长下逼近最小二乘，但那需要足够多的 epoch；
本轮固定 epoch 网格，不追最优，只回答"误差修正有没有用"。

## 设计（与第一轮一致，便于直接对比）

| 维度 | 取值 | 说明 |
| :--- | :--- | :--- |
| 数据集 | 程序生成配对集 144 条 | 与第一轮**完全相同** |
| 切分 | 80/20，种子 0–4 | 与第一轮**相同**的种子，切分相同 |
| 编码 | `image_diff` + `text_zscore`，`bus_dim=128` | 与第一轮相同 |
| 表示 | 总线输出的时间均值（读法 b） | 验收线所在 |
| 验收 | **R@1 50%+**（两个方向的均值） | 同第一轮 |
| 选参 | 训练集 **5 折交叉验证**（非留一法：delta 是迭代的，减项不再闭式） | 见下 |
| 网格 | η ∈ {0.001, 0.01, 0.1}；epochs ∈ {1, 5, 20} | 先写死，看到测试集不扩 |
| 顺序 | 每 epoch 固定种子打乱 | 可复现 |

**预测（先写下来，便于事后对账）**：delta 规则应当把 R@1 明显抬离 0.141，
因为外积和只是"把所有训练目标按相似度加权平均"，没有任何抑制近邻的机制；
误差项会把它拉向最小二乘解。**但 50% 是不是够得着，不做保证。**

## 这份预注册**不**声称什么

* 不声称 delta 规则比 Hebb 更"生物"——它需要教师信号，反而**更不**像生物突触。
* 不声称结果能外推到真实数据：合成集的属性是整齐枚举的，真实 caption 不是。
* 不把"R@1 提高"当成"局部学习成立"的证据：这一格只问联想层能不能对齐两个随机投影。

## 边界情况

* 与第一轮共用同一份 token embedding 缓存，文本侧没有变化。
* 若 delta 仍然远低于 50%，结论就写成"这一层不是瓶颈，瓶颈在表示"，并据此设计第三轮。
