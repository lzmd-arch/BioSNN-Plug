# M8（Round E）：**谱系 —— 不过：变异打不过历史本身的随机性**

> **⚠️ 2026-11-17 撤回：「不脆」是测量口径造成的结论，不是系统的性质。**
> 本条用的是**解码准确率**，而解码在切除后升高是因为切掉的是噪声。
> **同一批运行里发放一直在单调下降**（0.154→0.128→0.087→0.037→0.003），
> 死亡阈值 50%–75%（`m6ao_death_threshold`）。
> **正确的位置：这个系统是脆的。**「切除后解码变好」是去噪假象。

判据在 `research/sel/night-2026-11-16.md`（跑之前）+ **修订 2**（原 M8-2 在确定性系统里恒真）。
亲代权重 + 高斯噪声 → 子代；σ ∈ {0.05, 0.2}，每个 σ 6 个子代。3 种子。

## 一、结果

| ---: | ---: | :--- | :--- | ---: |
| 0 | 0.250 | 0.146 / 0.062 | **0.344** / 0.188 | 1.063 |

| 2 | 0.438 | **0.573** / 0.438 | **0.573** / 0.312 | 0.992 |

| 编号 | 结果 |
| :--- | :--- |
| M8-1 子代 ≥ 亲代 80% | 比值 `[0.58, 1.38, 1.25, 2.08, 1.31, 1.31]`，**5/6，不过**（唯一不过的是 σ=0.05 第一个种子） |
| **M8-2 变异 > 历史随机性** | 比值 `[0.67, 0.75, 0.72, 0.90, 0.64, 0.85]`，**0/6，不过** |

## 二、两件值得记的

### 2.1 **加大噪声反而更好**

σ=0.2 的子代在三个种子里全部**高于亲代**（1.38×、2.08×、1.31×）。
σ=0.05 只有两个超过亲代。

这与 Round D 的"切除反而更好"是同一件事：**这个表示是冗余的、对扰动不敏感的**，
噪声和切除都在去相关。**一个有生命的系统应该是脆的**，这里不是。

### 2.2 变异打不过历史

六个格子里子代之间的差异（0.63–0.87）**全部低于**亲代在"同族两条随机流"之间的差异
（0.96–1.06）。

⇒ **"换一组权重"对状态的影响，小于"换一条历史"对状态的影响。**
这正好和"个体史 > 结构"那条主线一致（M7 的结构承载塌到 1.05×）。

## 三、限定

1. 3 种子 × 2 档 × 6 子代 = 36 个子代，每子代一次测量；
2. "变异"用的是终态距离，与"历史随机性"同口径 —— 但两者都是 `rel`，**分辨率有限**；
3. 亲代地板是 0.000（每种子类别分布不同），所以 M8-1 的比值放大得厉害；
4. 只做了无性繁殖 + 高斯噪声，没有交叉、没有选择。
