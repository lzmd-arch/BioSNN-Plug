# M6z：**脆性在局部场下也没回来**

判据在脚本顶部（M6z 写于 M6x 结果之后、本轮跑之前）。随机切 50%，量解码前后。

## 结果

| `radius` | 种子 0 | 种子 1 | 种子 2 | 均值 |
| ---: | :--- | :--- | :--- | :--- |
| **2（局部）** | 0.125 → **0.312** | 0.062 → **0.406** | 0.156 → 0.125 | 0.115 → 0.281 |
| **32（全局）** | 0.375 → **0.719** | 0.312 → **0.625** | 0.344 → **0.625** | 0.344 → 0.656 |

| 判据 | 结果 |
| :--- | :--- |
| Z-1 局部场下有脆性（切后更低，≥2/3） | **1/3，不过** |
| Z-2 全局场下没有（切后不低于基线，≥2/3） | **3/3，过** |

## 结论

**两个 regime 下切除都让解码变好。**

⇒ **"不脆"不是全局场的产物，是这个动力学族 + 这个能力指标的共同性质。**

与 M5b（十二个消融格全部高于基线）、M8（加噪声更好）合起来，这是第四次确认。
**处置见 M6ad：换一个依赖网络完整性的能力（复合历史）来测。**

## 限定

- 3 种子；切的是随机 50%；
- `radius=2` 那三格的基线本身很低（0.062–0.156），在"可解码性已经坏了"的 regime 里比较脆弱性，
  结论只能限定为"没有出现脆性"，不能说是"证明不脆"。
