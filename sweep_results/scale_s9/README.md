# 规模实验 S9：加 fan-in 也买不到精度——**容量这条轴整体关掉**（2026-11-03）

**预注册：** [`research/scale/prereg-s9.md`](../../research/scale/prereg-s9.md)

## 判决

| # | 判据 | 门槛 | 实测 | |
| :--- | :--- | :--- | :--- | :--- |
| **S9-0** | 都放得下 | < 8,000 MiB | 最大 **590.2 MiB** | ✅ |
| **S9-1** | fan-in 买得到精度 | `acc(128) − acc(32) > 2pp` | **−0.8pp** | ✗ |
| **S9-2** | 时间没爆 | ≤ 4 × 1,214 s | 3,897 s（**3.2×**） | ✅ |

## 三个点（n_rec 固定 8,192，sMNIST 2 epoch）

| fan_in | 稀疏权重 | 准确率 | 峰值 | 耗时 | s/update |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 32 | 262,144 | **0.774** | 581.2 MiB | 1,214 s | 0.081 |
| 64 | 524,288 | **0.775** | 584.2 MiB | 2,200 s | 0.147 |
| 128 | 1,048,576 | **0.766** | 590.2 MiB | 3,897 s | 0.260 |

**准确率是平的**（0.774 / 0.775 / 0.766），而**时间是 3.2 倍**。

## 顺带确认了 S4 的更正

**权重翻了 4 倍（262k → 1,048k），显存只从 581 涨到 590 MiB。**

这是 S4 那条结论的又一次独立验证：显存的大头不在权重、不在连接，而在激活与评测批次。

## 结论：容量这一类问题整体关掉

预注册写的是：S9-1 不过 → 「这条管线在 8k 神经元 + 2 epoch 上，容量这件事整体已经饱和
（**加神经元不行、加连接也不行**），那『规模/容量』这一整类问题就都关掉了」。

现在两条轴都走完了：

| 轴 | 结果 |
| :--- | :--- |
| **加神经元**（S2–S8） | 1k→8k 有用（+14.6pp）；8k 之后买不到（sMNIST +0.5pp、SHD +1.0pp） |
| **加连接**（S9） | 4 倍 fan-in：**−0.8pp**，时间 3.2 倍 |

**8,192 神经元 + fan_in 32 就是这条管线的容量膝点。** 再往上不是放不下、也不是跑不动，
是**买不到精度**。

## 边界

- 单种子、2 epoch；fan-in 的收益可能在更长预算下才出现——但 S6 的机制（多训练会缩小差距）
  方向不利；
- fan_in=128 的 −0.8pp 在噪声内；能说的是「**没有增益**」，不是「越大越差」。
