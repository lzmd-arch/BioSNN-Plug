## 读法

- 误合并**不是因为「多个近邻分不清」**：加了 0.10 的间隔门槛后结果一字不差；
  说明每次误合并时，错误对象都是**唯一的强近邻**（间隔本来就大）；
- 问题在**阈值本身**：nomic 短句里「不同事实」的余弦可以高到被 0.7131 合并，
  而「同义改写」里又有 2 簇没合上（各自余弦低于阈值或与其他簇纠缠）；
- 所以 M3f 的假设（“歧义选择”）被否定，负结果保留；不调 margin。
