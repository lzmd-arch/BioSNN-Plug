# 预注册：阶段五 M3n——换分数：会话稳定的新颖度（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（M3l/M3m 已测，不是猜测）

- M3l：M3k 的工作点搬到真实对话上完全失效（每段只触发 1 次）；
- M3m：**留一重标定把命中救回来了**（多数折 3–5/5，选中的参数稳定在 `k=1.5`、`n_hits` 2–3、
  每轮 100 ms），但**跨会话不稳**：会话 0 的规则门 AUC 只有 **0.56**，会话 2/3 到 **0.867**；
  池化 AUC 0.7472，与规则门持平。

M3m 已经把问题定位到**分数**，不是触发器。M3n 只比分数，**不动触发器**。

## 五个候选分数（只用 embedding，不用任何标签/规则）

设第 `t` 轮向量 `e_t`（L2 归一化），`C_t = {e_j : j < t}`：

| 代号 | 定义 | 想修什么 |
| :--- | :--- | :--- |
| `R5`（现状） | `1 − max_{1≤t−j≤5} cos(e_t, e_j)` | —（对照） |
| `Rall` | `1 − max_{j<t} cos(e_t, e_j)` | 只看最近 5 轮会漏掉"很久前提过的东西又提起来" |
| `Rmean` | `1 − mean_{1≤t−j≤5} cos(e_t, e_j)` | 最大值对单条噪声太敏感 |
| `Rcentroid` | `1 − cos(e_t, 会话至今的质心)` | 衡量"离这段会话整体有多远"，天然跨会话可比 |
| `Rz` | `z(R5)`，**在会话内**按已出现轮次做标准化（均值/标准差只用 `j<t`） | 把会话 0 与会话 2/3 的尺度差拉平 |

全部截断到 `[0, 1]`（z 分数先用 logistic/线性映射到 [0,1]，映射参数在实现里写死并在结果里注明）。

## 协议

- 数据：与 M3l/M3m 同一份冻结 fixture（sha256 必须一致）；
- 每个分数在**每段对话内**（20 轮、5 个目标轮）算 AUC，再报池化 AUC（100 轮）；
- 触发器**不动**：用 M3m 选出的众数参数（`k=1.5`、`n_hits=3`、每轮 100 ms、其余同 M3k），
  只报它的工作点与 AUC 作参考，**不作为 M3n 的判据**；
- 5 个种子只影响触发器的随机流，分数本身是确定的。

## 判据（先写死）

1. **存在**一个分数同时满足：
   - 池化 AUC ≥ **0.80**；
   - 5 段对话里 **≥4 段**的单段 AUC ≥ **0.70**（不许靠一段极好拉高池化）；
2. 满足则记 `score_family_found=true`，并报它是哪一个；
3. 否则 `false`：结论写成「这几个 embedding 新颖度分数都做不到」，**不再调触发器**。

**关于选择偏差（写在前面）**：本轮在**同一批 5 段对话**上比较 5 个分数，属于"描述性比较"。
若某个分数过线，必须在新 fixture（另一批生成对话）上复测才能算成立——这一条写进结果的
「下一步」，本轮的 `true` 只表示「值得复测」。

## 读法护栏

- 不把 `Rz` 的"会话内标准化"写成"跨会话校准"：它只把每段自己的尺度拉平，跨会话可比的
  是**排名**不是分数值；
- 不因为某个分数过线就改触发器参数（M3m 已把参数定住）；
- 池化 AUC 与单段 AUC 必须一起报——只报池化会让"一段极好、四段很差"看起来像成功。

## 不做什么

- 不训练任何东西、不改 embedding 模型、不改 fixture；
- 不引入基于规则的特征（实体抽取、关键词表）——那是另一类方法，另开预注册；
- 不在同一批数据上先挑分数再改判据。

## 边界

- 只有 5 段对话、25 个正例；单段 AUC 的不确定度很大（M3m 里同一参数在不同种子上 0.56–0.93）；
- 「目标轮」的标签是脚本安排的，不是人标注的；分数的好坏只在**这个标注定义**下有意义；
- 分数都是无监督的，不利用"记忆"任务的任何反馈。
