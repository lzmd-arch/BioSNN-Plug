## 三条读数

### 1. 学习规则几乎没吃亏（+1.3pp）

P2 与 P1 用**完全相同的特征**，只把读出从"局部规则在线更新"换成"闭式岭回归"。
差 **1.3pp**——说明 e-prop 的在线读出**已经把这组特征读到头了**。
瓶颈不在规则。

### 2. 但"只取最后一步"丢掉了 9.7pp

P3 把 28 个时间步的滤波发放拼起来，同一个岭回归，**0.772 → 0.869**。

**信息一直在时序结构里**，而当前的读出只取了最后一帧。

### 3. 这条对整个项目意味着什么

前四轮（加神经元、加连接、参数异质）都在动**结构**，全部为负。
这一轮说明：**天花板不在结构，在读出。**

- 8k 神经元的表示里就有 **0.87** 的信息；
- 我们一直只读出 0.76；
- 差的 11pp 不是"容量不够"，是"没读出来"。

## 边界（必须写清楚）

- **P3 不是可部署的方案**：它用闭式解，不是局部学习规则；而且要用全部 28 步。它是一个**诊断**，
  回答"信息在不在那里"；
- 单种子、1000 个训练样本、1000 个测试样本；P3 的 0.869 有采样噪声；
- **它不说明"换成岭回归就好了"**——那会违反 ADR-0002 与项目的纯局部学习定位。

## 下一步（A3，先写预注册）

诊断给出的方向很具体：**让局部规则的读出也能看到多个时间点**。

最小改动是**多抽头读出**：把滤波发放在第 `k` 个等距时间点各取一份、拼接起来，每个抽头
用同一套 e-prop 规则更新（错误信号相同，资格痕迹不同）。`k=1` 就是现状。

判据将是 `acc(k=28) − acc(k=1) ≥ 5pp`——如果在线读出能吃回 P3 增益的一半以上，
那"读出设计"这条路就是本阶段最便宜的改进。
