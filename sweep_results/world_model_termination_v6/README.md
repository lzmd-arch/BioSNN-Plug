## 为什么纯想象不可能（边界证据）

- 闭环平衡策略在 `θ+0.5θ̇` 阈值附近翻转动作；学习模型 1e-5 的一步误差会改变动作序列，
  115 步后预测状态与真实状态差约 0.86。
- 即使把 CartPole 方程原样写成 float64 模型，真实环境是 float32，一步差约 **1e-7**；
  闭环仍在 115 步发散（AUROC **0.69**）。
- 因此 **500 步纯想象 + 二值反馈** 对任何非逐位模型都不可达；v2 的 0.6469、v6 的
  纯想象对照 0.645 都是这个结构边界，不是终止头容量问题。
- v6 的滚动闭环每步用真实观测重锚，模型只做一步风险；这是实际部署的模型式安全监控，
  但不是“想象中预测终止”。
