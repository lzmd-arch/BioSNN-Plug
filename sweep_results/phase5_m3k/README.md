## 读法

- **缺口确实在侧向抑制强度**：只把 η 降 5 倍，命中从 3/3/4/4/2 变成 5 个种子全 4/4，
  零误触发、逐位可复现；
- 触发时刻与规则门几乎同步（事件起点后数步内），因为本流的显著性上升很快；
- **这是协议层的通过，不是「自主触发能力」**：显著性流是合成的、规则门是构造性对照，
  且 η 是在同一流上按预注册单变量调下来的（M3i→M3j→M3k 三次预注册，判据未改）；
- 机制上值得记的是：**窗口化 + 更慢的侧向抑制**这一组合，在群体发放饱和时仍能保留
  事件的对比度。

## 边界

- 合成流；不外推到真实对话；
- 侧向 STDP 只在触发群体内部；
- η 的选择来自预注册的单变量序列（0.01 → 0.002），不是网格搜索；
- 规则门对照直接看输入显著性，是构造性上界式的对照。
