# 巩固对比实验：结果（2026-10-24）

**预注册见 [`../consolidation_prereg.md`](../consolidation_prereg.md)。** 本文件只记数，不改判据。

## 数字（ResNet18 冻结前端 + 类原型 + 对角白化，CIFAR-100 10×10）

| 臂 | ACC | AF | 说明 |
| :--- | ---: | ---: | :--- |
| **C0 无巩固** | **0.658** | **0.127** | 现行做法 |
| C1 巩固（朝全体均值收缩，λ=0.02，3 轮） | 0.637 | 0.196 | AF **升** 0.068，ACC **降** 0.021 |
| C2 打乱目标（同量算力） | 0.531 | 0.399 | 明显更差 |

**判据（预注册）**：主指标 AF 要降 ≥0.02 —— 实际**升了 0.068**；次指标 ACC 不得降超 0.01 ——
实际降了 0.021。**两条都没过。** 对照 C2 比 C1 更差，说明语义对齐确实起作用——但**两个方向都比
"什么都不做"差**。

## 这个阴性结果说明什么

原型向全体均值收缩，等于把各类中心往一处拉——**它降低的是类间可分性**，而 AF 的分母正是
"旧任务还能不能认出来"。所以这个形式的"巩固"不是减少遗忘，是主动遗忘。
阴性结果本身有价值：它把"巩固"从"听起来该有用"的直觉，变成"至少这种实现明确有害"的事实。

## ⚠️ 两个必须写出来的方法论问题

### 1. C0 与 C1 的五个"种子"其实是同一个运行

冻结前端这条路**没有随机性**：任务划分固定、特征已缓存、原型只做累加。五个种子给出**完全相同**
的 ACC（0.658 / 0.658 / 0.658 / 0.658 / 0.658）。C2 有差异，只因为打乱用的 RNG 吃了种子。

**所以这张表不是"5 种子"，是"一个确定性运行"**。报告里写 5 seeds 会误导读者以为有种子方差。

### 2. 仓库里旧的 "ResNet18 0.577" 量错了层

用**旧的 1000 维缓存**（分类 logits）能逐位复现 `sweep_results/continual_cifar100/resnet.json`
的 `ACC 0.577 / AF 0.1195`；而**正确的池化特征（512 维）**给出 **ACC 0.658 / AF 0.127**。

也就是说：那条记录量的是 `fc` 层之前的 logits，不是特征。已经在
[`../continual_cifar100/README.md`](../continual_cifar100/README.md) 加了更正说明。
⚠️ ResNet50 那条（2048 维）**没有**这个问题——它的缓存维度是对的；但它现在缺训练缓存，不能复跑。

## 产品层对齐检查（2026-10-24）：**不同类，不改**

结论先行：**实验里那个有害的形态在 Axo 的产品代码里没有对应物**，因此不触发产品侧改动。

证据（逐函数读过 `D:\Projects\BioSNN-MemoryTerminal\src\axo\memory\consolidation.py`，531 行）：

| 产品巩固实际做的 | 代码位置 | 是不是实验里那个操作 |
| :--- | :--- | :--- |
| 回放并用 SNN 辨认，**只读打分** | `RunReport.replayed / reinforced` 的统计路径 | 否——不写权重、不改嵌入 |
| `bump_reinforce`：给被认出的条目 +1 计数 | `store.bump_reinforce(...)` | 否——只改计数 |
| `write_merges`：为一簇碎条**另建一行派生视图**，原条目一字不动 | `store.add(derived)` | 否——不改原始条目 |
| `write_tier_moves`：按规则升/降层 | `store.set_tiers(...)` | 否 |
| 写一条 last-run 日志；如需先拍快照 | `write_last_run` / `snapshot` | 否 |

**实验 C1 做的是**：把每个类的原型朝全体均值收缩（`λ=0.02`，3 轮）——那是**改写用于判别的中心**，
所以它降低可分性。产品里没有任何一步改写判别用的向量或权重。

⚠️ 因此本文件的阴性结论**只能**表述为：「**原型朝全体均值收缩这种形式的巩固是有害的**」，
不能升级成「Axo 的巩固有害」。产品侧保持原样。

⚠️ 但产品 README 自己写着的两句仍然成立、且与本实验无关：巩固「**没有实测依据**」
（默认的一天是占位值）；以及它是一个**默认开启、会写库**的操作。这两句该由产品侧自己处置，
本轮不动。
