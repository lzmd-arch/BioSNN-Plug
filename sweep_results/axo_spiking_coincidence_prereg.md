# 预注册：重合检测（coincidence detection）

**定稿时间：2026-10-18。**
前几轮都是“顺序/补全/整合”，线性模型有强对照。这一轮测脉冲在结构上最该占优的
任务：**A、B 同时到达 vs 相隔几步到达，只在同时时检测到 C。**

## 任务

- 取同会话相邻轮的真实记忆 A、B；C = A 与 B 的**共享位**（交集）。
- 两个条件：
  - **同步**：A、B 同一步输入；
  - **延迟**：A 第 1 步、B 第 4 步（相隔 3 步）。
- 读出：末步 C 的共享位上的膜电位和（`Σ v_i`）。
- 期望：同步时 C 分高，延迟时 C 分低。

线性泄漏积分器会把 A、B 相加，只是延迟时 A 先衰减；脉冲的阈值/不应期可能让
“只在重合时发放”更清楚。比较两者在 **AUC（同步 vs 延迟）** 和**检测准确率**
（阈值在训练折上选）上的表现。

## 数据与划分

- 166 条真库只读副本；164 条有词法码；全局 `idf-2.0`、`k=64`、4096 位。
- 同会话相邻轮 107 对；只保留交集非空的配对。
- 每对一个同步 trial、一个延迟 trial；2 折按配对序号奇偶划分。

## 臂

| 臂 | 定义 |
| :--- | :--- |
| `linear-a095` / `linear-a098` | 线性泄漏积分器，α=0.95 / 0.98；末态膜电位 |
| `lif-a095` / `lif-a098` | LIF，θ ∈ {0.3, 0.5, 0.7}；末态膜电位 |
| `alif-b1` | ALIF，β=1、ρ=0.9、θ ∈ {0.3, 0.5, 0.7} |

读出还可以选**脉冲计数**（`Σ z_i`）作为第二读出；每个模型在训练折上从
{膜电位, 脉冲计数} 里选一个。

## 判据

1. **AUC**：同步 trial 的 C 分高于延迟 trial 的概率；两折分别报。
2. **检测准确率**：阈值在训练折上选（最大化 balanced accuracy），测试折报。
3. **主判据**：留出折上 `spiking_best − linear_best`：
   - AUC 差 `> +0.05` 或准确率差 `> +0.05`：脉冲在重合检测上有结构优势；
   - ±0.05：打平；
   - `< −0.05`：输。
4. 两个指标都要报；不能只挑一个好看的。

## 停止规则

- 只跑这三个 θ、两个 α、两种读出；不在看到结果后追加。
- 不写真实库；临时副本用完删除。
- 没有学习；W 是既有 Hebbian 外积。

## 边界

1. C 是 A、B 的共享位，不是一条真实记忆；这是为了构造“重合检测”的可测目标。
2. 107 对（过滤后更少）、2 折；小样本，1 条差异约 2 pp。
3. 同步/延迟是人为的 3 步间隔；不是自然时间流。
4. 墙钟时间不能论证能效。

## 怎么被核验

`scripts/axo_spiking_coincidence_prototype.py` 输出每个臂的 AUC、训练/测试检测准确率
与选中读出；执行者按上表机械判定。
