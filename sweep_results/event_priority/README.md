# 阶段四事件优先级：选择性时间步更新（2026-10-29）

**预注册：** [`../event_priority_prereg.md`](../event_priority_prereg.md)。
sMNIST、n_rec=256、batch64、30 epoch、lr 2e-3、seed 0、CPU；baseline 与
`selective_fraction=0.3` 配对。选择性臂只让输入活动最高的 30% 时间步进入权重更新
（学习信号置零；资格痕迹仍累积）。

## 结果

| 指标 | baseline | selective | 判据 | 结果 |
| :--- | ---: | ---: | :--- | :--- |
| 测试准确率 | **0.7748** | **0.6213** | ≥ baseline −1 pp | **未过（−15.35 pp）** |
| 实际选中比例 | 1.0（全更新） | **0.3391** | 0.25–0.35 | 过 |
| 活跃比例 | 1.0 | 1.0 | >0.60 | 过 |

`event_priority_ready=false`。2-epoch 单独测量也给出 0.3387，比例稳定；失败项是精度。

## 读法

- 选择比例确实落在目标带内，机制按设计执行；
- 但把低活动时间步的学习信号置零，在这个 e-prop 配置上**掉了 15.35 个百分点**；
- 这不说明“事件优先级”在 ESPP 的原始规则下无效——本实现是“跳过更新”的最小近似，
  资格痕迹仍按全序列累积，不能把 ESPP 的 18–27% 数字当成这里的结果；
- 下一步若继续，应把选择规则从“输入活动”换成与 **学习信号/损失** 联合的阈值，并允许
  被跳过时间步通过痕迹在后续步贡献，而不是简单把 L 置零；需新预注册。

## 边界

- 单任务、单种子；不外推到 SHD/其他网络；
- baseline 跑在加 `mean_update_fraction` 记录之前，因此 JSON 里该字段为 `None`，
  代码默认是 1.0；selective 的 0.3391 是本次产物记录；
- 未选时间步的痕迹仍累积——这是“跳过更新”，不是“跳过计算”。
