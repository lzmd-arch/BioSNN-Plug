# 预注册：时序顺序判别（线性积分器结构上做不到）

**定稿时间：2026-10-18。**
前三轮：静态、序列遍历、噪声/流式都没有让脉冲赢过速率基线。这一轮换一个**结构性**
任务：线性泄漏积分器对输入顺序是**可交换**的，所以它在“A→B 还是 B→A”上只能二选一；
脉冲的适应/阈值可能让**先到的那一个**占优，从而超过 50%。

## 要回答什么

给两条记忆 A、B，分两步呈现：

- 顺序 A→B：目标是 **A**（先到的那个）；
- 顺序 B→A：目标是 **B**（先到的那个）。

一个只看“集合 {A,B}”的模型，对两种顺序给出同一个排名，平均 top-1 只能是 **0.50**。
一个对顺序敏感的模型可以接近 **1.00**。问题：脉冲能不能超过 0.50？

## 数据

- 166 条真库只读副本；164 条有词法码；全局 `idf-2.0`、`k=64`、4096 位。
- 确定性配对：`A=i`、`B=(i+37) mod n`；每个 i 生成两个顺序。
- 输入：A/B 的完整关联码（不丢位）；两步输入后接 3 步零输入，共 5 步。
- 读出：末态膜电位 `A·v` 取 top-1。

## 臂

| 臂 | 定义 |
| :--- | :--- |
| `rate-first` | 只用第一步输入，一步速率 |
| `rate-last` | 只用第二步输入，一步速率 |
| `rate-integ` | 线性泄漏积分器（α=0.95），两步输入 + 3 步零输入 |
| `spiking` | LIF，膜电位读出 |
| `spiking-alif` | ALIF，β ∈ {1, 2}、ρ ∈ {0.5, 0.9}、侧抑制 none/global、异质 τ 0/0.5 |

## 判据

| 平均 top-1 | 结论 |
| :--- | :--- |
| `> 0.60` | 顺序敏感；值得继续 |
| `> 0.80` | 明显顺序敏感；可以考虑专门任务 |
| `0.45–0.60` | 与线性同量级；没有结构性优势 |
| `< 0.45` | 反向偏置（第二个输入占优）；照实报 |

**必须分别报 A→B 与 B→A 两列**：只报平均会把“总是选第一个”与“总是选第二个”
混成 0.50。

## 停止规则

- 只跑这一组配对与脉冲网格；不在看到结果后追加。
- 不写真实库；临时副本用完删除。
- 没有学习；W 是既有的 Hebbian 外积。

## 边界

1. 这是**人为构造**的顺序任务，不是自然语言时间流；结论只说明“脉冲结构上能不能
   表达顺序”，不说明真实对话里有用。
2. 164 条真记忆、固定配对；配对相似度没有控制，可能影响结果。
3. 线性积分器的 0.50 是**结构上限**，不是调参不够；这正是选它的原因。
4. 墙钟时间不能论证能效。

## 怎么被核验

`scripts/axo_spiking_order_prototype.py` 输出每个配置一行 JSON：A→B、B→A 与平均
top-1，以及每步脉冲数。执行者按上表机械判定。
