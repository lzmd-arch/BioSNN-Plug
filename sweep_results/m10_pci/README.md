## 二、读法

- **传播只有 17–23%**：扰动一个象限，四个象限里只有不到四分之一的空间桶出现响应变化。
  这本身就是"整合弱"的另一个证据，与 M11 独立吻合；
- **PCI 恒为 0**：响应的 LZ 复杂度不高于同矩阵的打乱版 ⇒ 响应不是结构化的时空图案，
  更接近稀疏的、零散的变动。

## 三、必须打的折扣：**LZ76 实现没有自检**

`chaos_probe.py` 的 0-1 检验有自检（正弦/周期 3/Logistic），**本脚本的 LZ76 没有**。
所以"PCI = 0.000"这个数**不能当成"响应完全无结构"的铁证** —— 有可能一部分是实现的锅。

**这一条记作本轮的仪器缺陷。** 要把它变成硬结论，需要先补一个自检：
已知复杂度的合成序列（全零、周期、随机）必须给出已知的相对顺序。
在那之前，**只有传播广度（17–23%）是可信的**，因为它不依赖 LZ。

## 四、限定

- 3 个可用种子（第 4 个在第 3 个之后才写出，本文件按前 3 个写）；
- 扰动是**一个象限、一次、幅度 2.0**；没扫幅度、没换象限组合；
- 传播广度的定义是"受扰象限之外、均值 Δ ≠ 0 的桶占比"，阈值是"!=0"，对数值噪声没有免疫。
