# M10（Round G）：**PCI 0.447、传播 0.21 —— 扰动传不出去，响应不复杂**

## 两版度量

| 版本 | 归一化 | 自检 | 问题 |
| :--- | :--- | :--- | :--- |
| v1 | `(c − c_rand)/(1 − c_rand)` | **无** | 恒为 0.000：`LZ76/n` 的上限只有 **0.086**，永远到不了 1，分子分母都贴着 0 |
| **v2（当前）** | **`c / c_rand`**（比值） | **有**（全零 0.0005 < 周期3 0.0010 < 随机 0.0860） | 可用 |

## 结果（v2，4 种子）

| 种子 | PCI（比） | 传播广度 |
| ---: | ---: | ---: |
| 0 | 0.443 | 0.172 |
| 1 | 0.438 | 0.219 |
| 2 | 0.448 | 0.230 |
| 3 | 0.457 | 0.227 |
| **均值** | **0.447** | **0.212** |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| M10-1 PCI(比) > 1.2 | 0.447，**不过** |
| M10-2 传播 ≥ 0.5 | 0.212，**不过** |

## 读法

- **PCI 比 = 0.447 < 1**：扰动响应的 LZ 复杂度只有它自己打乱版的 **44%**
  ⇒ 响应**比随机还规则**，不是结构化的时空图案；
- **传播 21%**：给一个 16×16 象限加电位，四个象限里只有约五分之一的空间桶出现响应变化。
  这与 M11 的"整合弱"独立吻合。

## 限定

- 4 种子；扰动是**一个象限、一次、幅度 2.0**，没扫幅度、没换象限组合；
- **传播广度的阈值是"均值 Δ ≠ 0"**，对数值噪声没有免疫；
- PCI 的 LZ 实现在**这一轮才补上自检**。之前那份 0.000 的数**不可引用**。
