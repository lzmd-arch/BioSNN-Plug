# 复杂度阶梯（L-0…L-4）：**没有膝点，没有不可或缺的机制**，而且两个指标互相矛盾

**一句话**：五个机制**逐条加上去，到第 3 个就没有正收益**；从满载里**逐个拿掉，
每一个拿掉都让结果变好**。按预注册的 L-1/L-2/L-3，三条全不过。

## 四、判

| 编号 | 结果 |
| :--- | :--- |
| **L-0** 工作点 + 真解码 | ✅ 过（L5 0.464 ≥ 0.125 + 0.15） |
| **L-1 膝点** | ❌ **没有**（连续两档 <2pp 未出现：−1.8 之后紧跟 +3.1，+3.1 之后是 −2.4） |
| **L-2 膝点一致性（防 Mirage）** | ❌ **不一致** —— MLP 读出没有膝点，线性读出在 **L2** 有膝点 |
| **L-3 拆卸** | ❌ 掉幅 ≥5pp 的机制 **0 个** |

### L-2 是最有信息量的一条

**两个指标给出两条形状不同的曲线**：

- 线性读出：0.322 → 0.415 → 0.484 → 0.493 → **0.507** → 0.501（**单调升到 L4，有膝点**）
- MLP 读出：0.281 → 0.374 → **0.475** → 0.457 → 0.488 → 0.464（**起伏，无膝点**）

`prereg-emergence-v1` 说的"曲线形状随指标选择而变"，在这一轮**真的发生了**。
⇒ **不许声称膝点**。这是 L-2 存在的理由，它这次挡住了。

## 五、与 `bio_all` 的正面冲突，以及为什么

`bio_all`（alpha=3.0，天花板 **0.356**）测到：全开 > 最好单项 **3/3 种子**、全开 > 单项之和 **2/3**。
本实验（alpha=2.0，天花板 **0.450**）测到：**满载不如好几个子集**。

差别只在**难度**。这正是一开始就要先标定难度的原因：

> 在**已经顶到天花板**的任务上，任何能爬上来的组合都会显得"超可加"；
> 换一个**上方还有空间**的任务，同一个组合就不成立了。

⇒ **`bio_all` 的超可加性不稳健，很可能是天花板造成的。** 那一份的结论要降级为
"在一个接近饱和的任务上观察到的现象"，不能当作"机制之间有真实交互"的证据。

## 六、这意味着什么

1. **"多补生物机制 ⇒ 性能更高"是错的**，而且这次是在**有空间**的任务上测的；
2. **没有一个机制是不可或缺的** ⇒ 谈不上"归因"（Q-3 的贵方向不成立）；
3. **两个指标形状不同** ⇒ 谈不上"膝点"（Q-2 不成立）。

所以按 `prereg-emergence-v1`：**Q-2、Q-3、Q-4 都不成立，不许叫涌现。**

**但这不否定这五个机制的价值** —— 它否定的是"用任务准确率给它们定价"。
它们各自服务哪根柱子（M1 边界、M2 代谢、M4 可塑……）**一次都还没测**。

## 七、下一步

按新目标（存续，不是性能），这一轮的负结果**不需要修**。要改的是**定价口径**：

- 每个机制挂到它要服务的柱子上，用柱子的判据测它（例如 `alif` 该测的是
  **稳态**：工作点漂移后能否自己回来，而不是分类准确率）；
- 本目录的 11 档数据保留，作为"用准确率定价"的完整记录。
