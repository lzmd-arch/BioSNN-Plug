## 三条轴

**尺度 s（K=4、σ=0.3）**

| s | OOD AUROC | 弃权 |
| :--- | :--- | :--- |
| 1.5 | 0.6627 | 0.4556 |
| **2** | **0.8174** | **0.7196** |
| 3（v8 主档） | 0.9562 | 0.9368 |
| 5 | 0.9972 | 0.9964 |

**v8 的 0.9368 只在 s≥3 成立；s=2 就掉到 0.720，s=1.5 基本失效。** 所以 v8 的
“尺度 OOD”边界比预注册时写的更窄：不是“A/B×3 以外都行”，而是 **3× 及以上**。

**K（s=3、σ=0.3）**

| K | WM R² | WM MSE | DPAR | 状态控制 | 弃权 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 2 | 0.9983 | 0.0012 | 0.9832 | 0.4936（chance 0.5） | 0.9284 |
| 4 | 0.9938 | 0.0045 | 0.9620 | 0.2352 | 0.9368 |
| **8** | **0.89975** | 0.0738 | 0.9392 | 0.1276 | 0.9264 |

K=8 的 WM R² 差 0.00025 才到 0.90（MSE 0.0738 仍 ≤0.10）；这是**容量边界**，不是
DPAR 或 OOD 的问题（K=8 的 DPAR 0.939、弃权 0.926）。K=2 的状态控制 0.4936 对 chance 0.5，
按修订后的 `1/K+0.10=0.60` 通过。

σ 轴稳；0.5 仍过 0.80。

## 判据修订

预注册原写“状态控制 ≤0.35”，但 K=2 的 chance 是 0.5，固定 0.35 不可达。正式跑之前
改为 `1/K + 0.10`（K=2 0.60、K=4 0.35、K=8 0.225）；这是口径修正，已写进预注册
“修订 1”。K=4 与 v8 的 0.35 一致，主档数值不受影响。

## 边界

1. **v9 没有让 v8 变成通用尺度门**：s=2 失败、s=1.5 更差；0.9368 只在 3×/5× 成立。
2. K=8 的 WM 失败是容量边界；不要因为它差 0.00025 就调阈值或 K。
3. scale-1.5 按预注册只报告，不计入稳健判据；它失败不推翻 v8 的 s=3 结果。
4. 所有条件共用 v8 结构、gauss3 特征、calibration 阈值；没有调参。
5. 5 个种子；单次运行 617.1 s（8 条件 × 5 种子）。

## 下一步

- 若要把 v8 写成可用结论，必须限定 **s≥3、K≤4、σ≤0.5**；s=2 是明确边界；
- 若想让 s=2 也过，需要更强的尺度/协方差特征，而不是调阈值；
- K=8 若重要，需要改状态/读出容量；当前 0.89975 差一点，属于边界而非失败模式；
- 阶段四技术报告现在应写入“v8 6/6 仅覆盖 s≥3/K≤4”。
