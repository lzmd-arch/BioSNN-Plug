# 预注册：任务推断确认性重跑——修正跑门 + 对角 Mahalanobis 路由（2026-10-26）

**定稿时间：2026-10-26，在本确认性重跑的任何数据之前。** 上一轮（
[`task_inference_routed/README.md`](continual_v2/task_inference_routed/README.md)）的跑门
把 5 个种子全判作废：末 epoch 相对变化 0.047 < 0.05。那是**零初始化 + 收敛后**的操作化
错误，不是头没学会（oracle 同批头 0.82）。本轮只做两件事，判据其余不变：

1. **跑门改成可解释的**：头权重非零，且**任务内训练准确率 ≥ 0.5**；
2. **路由加一个更强的局部判别器**：per-task **对角 Mahalanobis**（任务内方差归一化），
   与上一轮的最近均值原型对照。

上一轮的输出行/特征轴结论、纯 CIL 数字都不变；本臂仍是**任务推断 CIL**，不是纯 CIL。

## 机制

```text
每任务一个 10 类 delta 头 h_t（同上一轮；旧头冻结）
μ_t = 本任务各类均值的再平均；σ²_t = 本任务逐维方差（只由训练特征算）
推理：t̂ = argmin_k Σ_j (x_j − μ_kj)² / max(σ²_kj, eps)
      ŷ = argmax_c h_t̂(x)
不提供任务 id；路由完全由输入决定；对角协方差，不用反向传播
```

| 臂 | 路由 | 作用 |
| :--- | :--- | :--- |
| **T2-Maha** | 对角 Mahalanobis | 主臂：确认更强局部判别器是否够 |
| **T2-oracle** | 真实任务下标 | 上界（头/特征是否够） |

参考：上一轮**探索性** T1 routed 0.421 / AF 0.171、路由 0.489；T1 oracle 0.820 / 0.0；
纯 CIL R-delta-mini 0.2466 / 0.8047。T1 数字不作确认性引用。

## 固定协议

| 项 | 取值 |
| :--- | :--- |
| 特征 | 冻结 ResNet18 avgpool 512 |
| 数据 / 切分 | CIFAR-100，10×10，全量，类 id 升序 |
| 评估 | 有路由的 CIL：任务由输入推断；推断任务的头里 argmax；不提供任务 id |
| 头 | 每任务 `DeltaReadout(512→10)`，η=0.01，20 epoch，B=128；旧头冻结 |
| 路由统计 | μ_t、σ²_t 只用本任务训练特征；对角协方差，eps=1e-6 |
| 种子 | 0–4 |
| 跑门 | 头权重 `‖W‖ > 0` 且任务内训练准确率 ≥ 0.5；作废种子写进 summary |

## 判据（先写死）

1. **阶段门（同一 ACC/AF 定义，任务由输入推断）**：ACC ≥ 65% 且 AF < 8%；
2. **路由可读性**：任务推断准确率 ≥ **90%**；
3. **oracle 上界**：T2-oracle 的 ACC ≥ 65%（否则限制在头/特征，不在路由）；
4. **不是少学**：T2-oracle 的逐任务对角线均值 ≥ 0.758；
5. 跑门照旧，作废种子数写进 summary。

## 判读表（先写死）

| 阶段门 | 路由 ≥90% | oracle ACC ≥65% | 结论 |
| :--- | :--- | :--- | :--- |
| 过 | 过 | 过 | **任务边界可由输入推断（对角 Mahalanobis）**；CL 门在推断路由口径下达标 |
| 不过 | 过 | 过 | 头/路由都能跑，但整体不够；报 ACC/AF 与混淆，下一机制另写 |
| 不过 | 不过 | 过 | **简单局部路由仍分不开任务边界**；边界结论成立（纯 CIL 需要任务信息） |
| 不过 | — | 不过 | 头/特征容量是瓶颈，不是路由 |

## 限制

- 仍是任务推断 CIL；纯 CIL 的已发布数字不变，也不被本臂替代；
- 对角协方差；全协方差 Mahalanobis 是另一个机制，不在本轮；
- 头从零初始化，跑门用"非零 + 训练准确率"，不用末 epoch 相对变化；
- 5 种子、单一骨干、单一 η；不调任何超参数。

## 实现（代码先于数据，单独提交）

- `run_with_task_inference`：`routing` 增加 `mahalanobis`；统计量 `μ_t`/`σ²_t` 只由本任务
  训练特征算，冻结；距离用对角形式；
- 跑门替换为 `‖W‖ > 0` 且训练准确率 ≥0.5；记录 `head_weight_norm` / `head_train_accuracy`，
  去掉误导性的 `head_gate_ratios`（或保留但不再参与 valid）；
- CLI `--task-inference mahalanobis`；默认路径不变；
- 守卫：Mahalanobis 距离与手算一致、统计量只由本任务决定、跑门能区分已训练/未训练头、
  oracle 与 routed 只差路由、默认路径逐位不变；
- 跑前工作区干净；产物先落 `data/`。
