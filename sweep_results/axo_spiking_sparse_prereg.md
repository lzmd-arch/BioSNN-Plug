# 预注册：Axo 真脉冲原型第二轮（稀疏表示 + 序列遍历）

**定稿时间：2026-10-18。**
第一轮结果见 [`axo_spiking_prototype_results.md`](axo_spiking_prototype_results.md)：
静态补全 0.8659 vs 速率 0.9085（差 4.26 pp，不达标）；下一轮任务两边都到顶
（0.9720 vs 0.9813，打平）。本轮只补第一轮明确指出的两个缺口。

## 要回答什么

1. **稀疏表示是否保持行为**：把 `(n, 4096)` 稠密 `A` 换成 `(n, k=64)` 的
   `(idx, weights)` 稀疏码后，166 条真库上的静态/时序指标是否与稠密版一致？
2. **规模是否可承受**：n=200 / 2,000 / 10,000 / 50,000 时，稀疏码的存储与单次查询
   时间；稠密 `A` 在 10,000 以上只报理论字节数，不实际分配。
3. **序列遍历上脉冲能不能赢**：用相邻轮 `t→t+1` 学到的转移矩阵 `W_seq`，给 `t`
   的线索找 `t+L`（L=2,3,5）；对照是**速率迭代 L 步**（不是只走一步的弱基线）。

## 数据与表示

- 数据：`D:\AxoData` 只读副本；166 条、164 条有词法码；全局 `idf-2.0`、`k=64`。
- 稀疏码：`idx (n,k)` + `weights (n,k)`；`matvec(x) = Σ_j w_ij x_idx_ij`，
  `transpose_matvec(s) = bincount(idx, weights*w)`。
- 稠密基线只在 166 条与规模基准 ≤10,000 上实际分配；50,000 只算 `n*4096*4` 字节。

## 臂

**静态**

| 臂 | 定义 |
| :--- | :--- |
| `sparse-rate` | 稀疏 `A·(Aᵀ(A·p))`；应与稠密 `rate` 逐位同序 |
| `sparse-spiking` | 膜电位读出 / 无抑制 / 同质 / LIF（第一轮静态最好档） |

**序列遍历**

- `W_seq = Σ a_next a_prevᵀ`，只用相邻轮 `t→t+1` 学；查询目标是 `t+L`。
- `rate-one`：`W_seq` 走一步。
- `rate-iter`：`W_seq` 走 L 步（每步归一化）。
- `spiking`：L 步 LIF/ALIF；三档：
  1. `membrane / none / hetero=0 / beta=0`（第一轮静态最好）；
  2. `membrane / none / hetero=0.5 / beta=0`（第一轮时序最好之一）；
  3. `membrane / global / hetero=0.5 / beta=1`（第一轮 L=2 最好）。
- 线索丢 50% 位。

## 判据

1. **稀疏一致性**：`sparse-rate` 的 top-1 与稠密 `rate` 相同（166 条全量，不是统计）；
   若不同，先修实现，不进入下一步。
2. **静态**：`sparse-spiking` 与 `sparse-rate` 比；`≥ rate − 0.02` 才算“不差”。
3. **序列遍历**：对每个 L，`spiking_top1 > rate_iter_top1 + 0.05` 才算“赢”；
   ±0.05 内“打平”；否则“输”。**至少一个 L 赢、且静态不差**，才值得考虑可选模式。
4. **规模**：只报告，不设硬门槛；但 50,000 的稀疏单次查询若超过 100 ms，要直接
   写进结论（Axo 的记忆窗口等不起）。

## 停止规则

- 只跑这一组 L=2,3,5 与三档脉冲；不在看到结果后追加网格。
- 不写真实库；临时副本用完删除。
- 没有 STDP/e-prop 学习；转移矩阵是 Hebbian 外积。

## 边界

1. 166 条是真实数据；规模基准用**确定性合成码**，不是真实 5 万条记忆。
2. 序列遍历的“正确目标”是会话顺序，不是人工语义标注。
3. 稀疏码仍是 4096 位坐标；事件驱动只在“按 n 行遍历”这一层，不是真正的脉冲事件队列。
4. 墙钟时间不能论证神经形态能效。

## 怎么被核验

`scripts/axo_spiking_sparse_prototype.py` 输出每个配置一行 JSON，含稀疏/稠密一致性、
静态/遍历指标、每步脉冲数、单次查询耗时与存储字节；基线在同一批数据上算。
