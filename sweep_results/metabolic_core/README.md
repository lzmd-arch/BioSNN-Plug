# 代谢内核（E-0…E-4）：**内部量立住了**，饥饿幅度差一点

**一句话**：`E` 的轨迹**完全不可由输入还原**（留出 R² = **−0.016**），
而它**强约束行为**（corr(E, 发放率) = **−0.990**）。
这是"内部状态是它自己的"第一次变成一个数。四条判据 **3 过 1 不过**。

## 一、机制（只加一条，生物学里真实存在）

```
E  ←  clip( E − c·z + r·(1 − z), 0, 1 )      放电消耗 / 静默恢复
θ_eff = θ · (1 + k·(1 − E))                  饥饿时更难放电
```

`c = 0.05`、`r = c·f/(1−f)`（f=0.08 ⇒ 平衡点 E≈0.5）、`k = 1`。
`E` 由**神经元自己的放电历史**决定，不由输入决定。

## 二、结果（3 种子、n=2048、每臂单独标定）

| 臂 | 输入尺度 | 发放 | 准确率 | **R²(输入→E)** | **corr(E, 发放)** |
| :--- | ---: | ---: | ---: | ---: | ---: |
| `ctrl`（E≡1） | 1.86 | 0.0478 | 0.244 | +1.000（常数，必然） | +0.000 |
| **`metab`** | 1.86 | 0.0453 | 0.245 | **−0.016** | **−0.990** |
| `starve`（不恢复） | 1.86 | 0.0275 | 0.248 | −0.014 | −0.995 |

## 三、判

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| E-0 | 发放 ∈ [0.03, 0.20] | ✅ 三臂全在窗内 |
| **E-1** | R²(输入→E) < 0.5 | ✅ **过（−0.016）** |
| **E-2** | corr(E, 发放) < −0.5 | ✅ **过（−0.990）** |
| **E-3** | `metab` ≥ `ctrl` − 5pp | ✅ 过（0.245 vs 0.244） |
| **E-4** | `starve` 发放 < `metab` 的 0.5 倍 | ❌ **不过**（0.0275 vs 0.0227） |

### E-1 是这一轮的实质

`E` **方差很大**（与发放率的相关系数 −0.990，几乎一一对应），
却**完全无法由输入 token 序列预测**（R² ≈ 0）。

⇒ **能量的轨迹是网络自己的活动造成的，不是输入的影子。**
这正是 M1（自维持边界 / Seclusion）要的东西，而且是从**反向**验证的：
不是"内部状态有多丰富"，而是"它不属于输入"。

⚠️ 限定：R² 用的是**最近 8 个 token 的 one-hot + 岭回归**。更强的预测器
（更长上下文、非线性）没有试过。所以准确说法是"**线性、8 token 窗口内不可还原**"。

### E-4 不过，但机制是对的

饥饿把发放率从 0.0453 降到 0.0275（**降 39%**），方向完全正确，
但没到预注册的"低于 50%"。原因很清楚：**放电少了 → 消耗少了 → 在新的低活动水平重新平衡**。
这是生物学该有的行为（饥饿导致低代谢稳态，不是死亡），**不是实现错误**。

⇒ 照实记 **E-4 不过**，**不改 0.5× 这条线**。下一轮要测的是"真正的能量枯竭"
（例如 `r = 0` 且不允许重新平衡，或把 `c` 调大到无法维持），那是新的预注册。

### 附带一条：代谢让网络更省

`starve` 用 **61% 的发放率**拿到 **0.248** 的准确率（`metab` 0.245、`ctrl` 0.244）。
差值在噪声内，所以能说的是"**没有变差**"——但"用更少的脉冲拿到同样能力"这件事，
在本轮是第一次出现。

## 四、这轮没做什么

- 没加可学参数；
- 没改任务与读出（沿用 `bio_all` 的隐状态解码 + 播种的 `mlp_probe`）；
- **没有声称任何超出本轮的结论** —— 只测了"内部量是否自持"。

## 五、下一步

1. **真正的能量枯竭**：让 `starve` 无法重新平衡（固定预算、用完即停），测"死亡"是否可预测；
2. **M2 的策略改变**：现在只测到"活动水平下降"，还没测到"策略改变"（例如饥饿时
   用更少的脉冲换同样的准确率 —— 本轮的 61% 是候选证据，但需要与 `ctrl` 对齐比较）；
3. **M1 的下一层**：`E` 现在**不受学习影响**。要让"边界"成立，`E` 必须反过来
   **塑造结构**（M3 发育），否则它只是一个被动计分器。
