## **但 v8 是平凡解：两臂逐位相同**

LIF 与 ALIF 的每一项差都在 **≤2e-7**（相对 0.93 是 float 噪声级别），ridge 也相同。原因不是巧合：

```text
v_t     = α·v_{t−1} + I_t − thr·z_{t−1}
trace_t = α·trace_{t−1} + z_t
读出   = v_t + thr·trace_{t−1} = Σ α^{t−s} I_s
```

复位项 `−thr·z_{t−1}` 与 `thr·trace_{t−1}` **代数抵消**，读出只剩输入的泄漏积分，与
`z` 的时序、是否发放、beta 全部无关。因此：

1. **脉冲动力学没有参与读出**；LIF/ALIF 相同是恒等式，不是“两臂都行”；
2. 预注册里的 `spiking_ok`（脉冲率 >0）不够——网络确实发放，但读出把它们抵消了；
3. v8 的 0.933 只能说明“输入积分可线性解码”，**不能**写成脉冲工作记忆过线，也不能
   写成“脉冲输入 + 局部迹读出”的能力（迹本身与输入一一对应，与脉冲无关）。

这与记忆里的教训一致：判据只约束“过线”，不约束“必须用到被测机制”，最优解就会绕开
机制。v8 的 `summary.json` 原样保留，但在组件记分卡上记 **`v8_ready=true`（按预注册）
且 `v8_valid_as_spiking=false`**；阶段四的脉冲工作记忆仍未过线。

## 下一步（v9 的非平凡性守卫）

v9 的读出必须**依赖脉冲发放**，且预注册要加两条守卫：

- **臂差守卫**：LIF 与 ALIF 的状态/成绩必须出现非平凡差异（例如状态逐样本差的中位数
  > 1e-3），否则判 `invalid`，不得算 ready；
- **消融守卫**：把脉冲序列做时间置换（保持计数、打乱时序）后，读出成绩必须显著下降；
  若不降，说明读出只用计数/积分，没用脉冲时序，不能算脉冲表示。

可选的读出（不抵消复位）：固定 τ 的**脉冲迹** `s_t = α·s_{t−1} + z_t`（不加 v），或
膜电位 + 适应状态。v8 的 `v + thr·trace` 不再使用。
