# 情景记忆 v4：延迟配对联想回忆（DPAR）（2026-10-27）

预注册：[`episodic_paired_associate_prereg.md`](../episodic_paired_associate_prereg.md)。
5 个种子，每幕 K 对“键→值”，延迟后给查询键，回忆配对值。主档 **K=8、σ=0.1**。

## 结论

**三条判据全过，`paired_associate_ready=true`——但这是有条件的 ready。**

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| 最好联想臂 top-1（K=8） | ≥0.80 | **0.8280**（pseudo-inverse） | 过 |
| 同一臂 K=4 top-1 | ≥0.90 | **0.9264** | 过 |
| 状态控制 top-1（K=8） | ≤0.25 | **0.1212** | 过 |

状态控制 0.1212 对 chance 0.125，**最终 28 维状态的线性读出基本是瞎猜**：回答确实
依赖把“查询键”和“它当时的值”绑定起来，而不是从最终状态里读最近线索。这是本任务成立
的前提。

### 条件：只有非局部伪逆过线

| 臂 | K=8、σ=0.1 top-1 | 性质 |
| :--- | :--- | :--- |
| Pseudo-inverse | **0.8280** | **非局部**闭式读出（每幕解 `V K⁺`） |
| Raw NN | **0.9384** | 字面查表基线 |
| Hebbian | **0.3112** | 局部外积 |

**局部 Hebbian 仍然不可用**（0.3112，虽高于 chance 0.125）；能过线的是非局部
pseudo-inverse，而且**字面 NN 还比它高 11.0 pp**。因此这条结果不能写成“局部联想记忆
可用了”，只能写“在这个必须绑定的任务上，非局部伪逆可作为可用配置，但不如直接查表”。

状态控制的五个种子 top-1：0.128 / 0.124 / 0.122 / 0.130 / 0.102，均值 0.1212。
Pseudo 的五个种子都 ≥0.80（最低 0.804），不是均值拉过线。

## 容量曲线（σ=0.1）

| K | Pseudo top-1 | Raw NN top-1 | Hebbian top-1 | 最好联想臂 |
| :--- | :--- | :--- | :--- | :--- |
| 2 | 0.9704 | 0.9800 | 0.8200 | 0.9704 |
| 4 | 0.9264 | 0.9612 | 0.5572 | 0.9264 |
| 8（主档） | **0.8280** | 0.9384 | 0.3112 | **0.8280** |
| 16 | 0.6336 | 0.8912 | 0.1524 | 0.6336 |
| 32 | 0.4408 | 0.8472 | 0.0680 | 0.4408 |

**容量边界在 K=8–16 之间**：最好联想臂 K=8 过 0.80，K=16 掉到 0.6336。局部 Hebbian
只在 K=2 过线（0.8200），K=4 就掉到 0.5572；它的可用容量比非局部伪逆小得多。字面 NN
直到 K=32 仍有 0.8472，说明掉下去的是**联想读出**，不是任务本身没有信息。

## 噪声曲线（K=8）

| 查询噪声 σ | Pseudo top-1 | Raw NN top-1 | Hebbian top-1 |
| :--- | :--- | :--- | :--- |
| 0.0 | 0.9856 | 0.9960 | 0.3300 |
| 0.1（主档） | **0.8280** | 0.9384 | 0.3112 |
| 0.3 | 0.5856 | 0.7616 | 0.2648 |

伪逆从 σ=0 的 0.9856 掉到 σ=0.3 的 0.5856；字面 NN 同期从 0.9960 掉到 0.7616。
**σ=0.1 到 0.3 之间过线能力丢失**，这是查询键表示（512 维 `k=32` 稀疏 ±1 码）的
噪声敏感点，不是容量点。

## MSE 的口径

主档 Pseudo 的 MSE 为 0.16–0.24、Raw NN 为 0.085–0.155；随 K/σ 增大会到 1 以上
（K=32 的 pseudo 为 1.13）。Hebbian 在 K=8 的原始 MSE 是 4,000 量级（表中未列），
因为 `M = Σ v_i k_iᵀ` 没有归一化，回忆值约为真值的 `k=32` 倍。**这个原始 MSE 不与另外
两臂可比，门槛只看 top-1**；要报可比 MSE 需要先做固定的自重叠归一化，这不在本轮预注册里，
不能事后加。上表只列 pseudo / NN 的 MSE，避免把尺度差当成误差差。

## 边界

1. 键和值都是合成随机向量；这是“必须绑定”的任务，不是自然情景记忆。
2. 每幕独立建库，幕间不共享；不是终身情景记忆，也没有跨幕干扰。
3. `paired_associate_ready=true` 只表示“非局部伪逆过线”；局部 Hebbian 仍不可用，
   且字面 NN 更强。不要把这条写成局部联想记忆的复活。
4. 主档 σ=0.1 是预注册值；σ=0.3 已掉到 0.5856，说明结果对查询噪声敏感。
5. 状态控制只证明**最终状态线性读出**不能解；不证明任何非线性状态读出都不行。
6. 5 种子、500 测试幕；单次运行 15.8 s。
