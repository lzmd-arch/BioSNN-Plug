# M9（Round F）：**广播广度 —— 残余上 4/4 高于零分布，但种子数不够判据**

判据在 `research/sel/night-2026-11-16.md`（含**修订 4a**）。

## 一、度量改了三版才立住（这才是本轮最该记的）

| 版本 | 定义 | 冒烟结果 | 问题 |
| :--- | :--- | :--- | :--- |
| v1 | 特征向量载荷 `|v| > 0.3` | 广度 **0.000** | 单位化特征向量在单个神经元上的载荷量级是 `1/√N≈0.03`，**阈值永远不触发** |
| v2 | 参与度 `> 3k/N` | 0.053，**零分布 0.097** | 打乱零分布**比真数据还高** —— 测的不是广播 |
| **v3（当前）** | 每个神经元被前 k 个共享模态解释的**方差占比** | 残余 **0.864**，零分布 0.50 | 可用 |

## 二、结果

| 种子 | 原始 | **残余** | 打乱零分布 |
| ---: | ---: | ---: | ---: |
| 0 | 0.796 | 0.875 | 0.499 |
| 1 | 0.764 | 0.858 | 0.514 |
| 2 | 0.785 | 0.856 | 0.525 |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| M9-1 残余广度 > 0.5 | 0.864，**过** |
| M9-2 高于零分布 +0.15 且 ≥5/6 | 效应 **+0.361**，**4/4 种子全部过**，但**种子只有 4 < 判据要求的 5** ⇒ 按字面 **不过** |

**按字面不过，但那是种子数不够，不是效应不够。** 记作"未达判据、效应明确"。

## 三、诚实的限定

1. **度量本身有自证倾向**：`k` 是按"解释总方差 80%"选出来的，所以"这些成分解释了
   大部分方差"在某种程度上是构造出来的。**真正有信息的是零分布** ——
   打乱时间后掉到 0.50，说明真实数据的共享结构不是随机的；
2. 扣不扣群体均值几乎没差别（0.779 vs 0.864）—— 说明**共享结构不是那个全局共同模态**，
   这反而支持"残余里也有广播"；
3. 4 种子；一个 `record_len=256`；一个 K=4；
4. **"广播"是 GWT 的一个必要特征，不是充分特征**。有广播不等于有全局工作空间。
