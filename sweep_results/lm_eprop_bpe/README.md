# BPE 词表上的同配置重训 —— **top-1 输给 token bigram 3.92pp，CE 赢**（2026-11-11）

**动机**：产品形态是「10 格候选条」。字符级的 top-10 = 10 个字；BPE 的 top-10 = 10 个
**BPE 单元**（平均 2.287 字）。要报"10 格"这个口径，就得在 BPE 词表上重训一次。

## 一、结果（KdConv、16,000 步、2 抽头、n_rec=1024）

| | top-1 | top-5 | top-10 | CE |
| :--- | ---: | ---: | ---: | ---: |
| **模型（BPE，V=28,858）** | **0.2344** | **0.3678** | **0.4034** | **6.400** |
| token bigram | 0.2736 | — | — | 7.458 |
| **Δ** | **−3.92pp** | — | — | **−1.06（模型更好）** |

判据：`r0_0`（CE 比 <0.6）**不过**（0.689）；`r0_1`/`r0_2` 不过（0/1 折赢）；`r0_3`（CE 更好）**过**。

## 二、四问限定语

1. **是预算截断吗？** 是，而且**对模型有利的方向**。CE 比 0.689 > 0.6，没过收敛闸门；
   top-1 四点仍在涨（0.2132 → 0.2271 → 0.2294 → 0.2344，每 4,000 步 +1.39 / +0.23 / +0.50pp）。
   所以 **−3.92pp 是下界**——再加预算差距只会缩小。但"下界"指的是它已经很差。
2. **是跨语料 / 跨预算比较吗？** 语料与预算和 P1 相同，但**token 单位不同**，
   所以 **0.2344 这个绝对值不能和字符级的 0.2973 比**，6.400 也不能和 3.949 比。
   唯一合法的是"同口径内对 bigram 的 Δ"。
3. **是单边指标吗？** **是。** CE 赢 1.06，top-1 输 3.92pp —— 这是第八种
   CE/top-1 脱钩形状：**分布更准，排序更差**。
4. **cos 先验兑换成 Δ 了吗？** 不适用。

## 三、这个负结果该怎么读——**主要是词表与语料的配比问题，不是"BPE 不行"**

- 语料只有 **1,574,749 字 = 688,699 个 BPE token**，却给了 **28,858** 的词表
  ⇒ 类型/词例比 **4.2%**，大量单元只出现一两次；
- 字符级时 V=3,001，模型赢 bigram **+0.86pp**；换成 V=28,858 就掉到 **−3.92pp**。
  同一份数据、同一预算、同一个模型，**唯一变的是词表宽度**——而 R3 早就量过：
  **绑定 Δ 的是读出宽度**，这里读出只有 2,048 维，却要分开 28,858 个类。

**所以这条负结果的适用范围是"小语料 + 过大词表"，不能外推到 1B 的 30B 字语料。**
但它是**1B 计划的一个预警**：词表必须与语料量匹配，32k 在 1.5M 字上是灾难，
在三四十亿字上才合理。

## 四、对 1B 账的影响

- **字符/token = 2.287**（这个数是真的，用于换算语料量与 token 量）；
- 但 1B 的语料是 **3.39B 字**（≈100 GB 原始），不是 1.57M 字；
  **V=32,000 在那个规模上才站得住**，本臂的 −3.92pp 不构成反对证据。
