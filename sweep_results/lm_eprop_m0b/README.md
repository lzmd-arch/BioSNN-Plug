# M0b：把隐藏层真正训起来，再问一次——**仍然不通过**（2026-11-06）

## 一句话

**隐藏层这次动了 70 倍（0.07% → 4.98%），结论没变，而且更硬了：**
学出来的网络比"冻结的随机储层"**更差**（CE 1.861 vs 1.741），两者都输给字符 bigram（1.423）。

## 三件必须分开说的事

### 1. M0b-0 形式上不过，只差 0.024 个百分点

门槛 5%，实测 **4.976%**。按预注册的规矩，这条不达标要判"**实验无效**"，而不是"规则无效"。

但要说清楚：**M0 的 0.07% 与 M0b 的 4.98% 差 70 倍**——"隐藏层有没有真的参与学习"这个**意图**是达到了的。
我不调大学习率重跑（那会变成"调到动为止"，是另一种调参），所以按规则报"形式不过"。

### 2. 在隐藏层确实参与学习的前提下，它让结果变差了

M0b 的两臂唯一差别是 `w_rec` 学不学：

- 冻结：CE **1.741**、top-1 **0.566**；
- 学习：CE **1.861**、top-1 **0.516**。

**学循环权重让 CE 变差 6.9%、top-1 掉 5pp。** 这是本轮唯一有实质内容的对照，方向是负的。

### 3. 两个版本都赢不了 bigram

| | CE | top-1 |
| :--- | ---: | ---: |
| 最好的神经网络版本（M0b 冻结） | 1.741 | 0.566 |
| **bigram** | **1.423** | **0.646** |

**在 1,024 神经元、2,000 updates、301 条模板语料的这个工作点上，逐时刻局部学习赢不了二阶字符 bigram。**

## 这解释了 M0 里那个"巧合"

M0 的冻结臂（0.542）比学习臂（0.540）略好；M0b 把这个差放大成了 0.566 vs 0.516。
两轮同向：**随机储层 + 局部读出 > 训过的储层**。

一个可能的解释（**未验证**）：301 条模板语料撑不起 1,024 神经元的循环权重，
e-prop 的更新方向在这个样本量下更像噪声，把读出所依赖的随机特征搅坏了。
要验证得换更大的语料——那是 M3 的事，不是这一轮。

## 结论

**M0b 也不通过。** 按预注册，M0 + M0b 两轮之后这条支线在此停止：
在这个工作点上，局部规则的语言模型**赢不了一个字符 bigram**，而且**训循环权重是有害的**。

这个负结果比 M0 的那条硬得多：M0 的"学不学循环没差别"可以说成"没测到"，M0b 不行——
`w_rec` 动了 5%，差别是**往坏的方向**动的。

## 边界

- 单种子；测试集 46 条 / 1,369 字符（top-1 的 SE ≈0.9pp）；
- 语料是模板化单轮 SIR，**不是对话**；本轮任何结论都不涉及"能不能闲聊"；
- 只测了一个规模（N=1,024）与一个预算（2,000 updates）；"更大规模可能不同"既没测也不能假设；
- 学习率放大 10 倍后 CE 没有发散（0.474 倍仍在下降），所以"发散了"不能解释这个结果。
