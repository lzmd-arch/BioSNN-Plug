# M5（Round D）：**再生 —— 不过，而且失败方式与假设相反**

判据在 `research/sel/night-2026-11-16.md`（跑之前）。能力 = 解码准确率。
按历史期活跃度切掉最低的 10% / 50%，两臂：`plastic`（继续 STDP）vs `frozen`。3 种子 × 2 档。

## 一、逐格

| 种子 | 切比 | 基线 | 切后 | plastic | frozen |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 10% | 0.344 | **0.562** | 0.656 | 0.562 |
| 0 | 50% | 0.344 | 0.438 | **0.125** | 0.438 |
| 1 | 10% | 0.312 | **0.594** | 0.688 | 0.594 |
| 1 | 50% | 0.312 | **0.625** | 0.625 | 0.625 |
| 2 | 10% | 0.375 | 0.375 | 0.438 | 0.375 |
| 2 | 50% | 0.375 | **0.594** | 0.750 | 0.594 |

| 编号 | 结果 |
| :--- | :--- |
| M5-1 恢复到切前 70% | 比值 `[1.91, 0.36, 2.2, 2.0, 1.17, 2.0]`，**5/6，不过** |
| M5-2 依赖自身活动（plastic > frozen） | 差 `[0.094, −0.312, 0.094, 0.0, 0.062, 0.156]`，**4/6，不过** |

## 二、失败方式：**切除没造成损害，所以没有"恢复"可言**

六个格子里**五个的切后解码高于基线**（0.344 → 0.562、0.312 → 0.594、0.375 → 0.594）。

原因是切的是**低活跃神经元** —— 等于去噪。特征维度少了，噪声也少了，可分性反而上升。

⇒ **"再生"这根柱子在这个任务上没有立足点**：不是恢复不了，是**没有损伤需要恢复**。

## 三、唯一的真塌方，方向和"再生"相反

`seed 0 / 50% / plastic`：0.438 → **0.125**（切后本来是 0.438）。

**切除之后继续 STDP 会把表示毁掉。** 同样的切除、冻结学习则保持在 0.438。
M5-2 的 4/6 里那一个 −0.312 就是它。

⇒ 这个系统在受损后**不能靠可塑性自救，反而会被可塑性进一步破坏**。
这是本轮唯一一条对目标不利、而且明确的证据。

## 四、限定

1. **3 种子 × 2 档 = 6 格**，每格一次测量，没有重复；
2. 基线是"全神经元"上的解码，而切后是"剩余神经元"上的解码 —— **两者的特征分布不同**，
   所以 M5-1 的比值里混着"去噪"这一项，不纯是"恢复"；
3. 只切了一种方式（按活跃度，最低的）；随机切、按度数切未测；
4. 训练只有 4 批，STDP 一个学习率。
