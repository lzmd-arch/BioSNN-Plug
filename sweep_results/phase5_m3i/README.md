## 读法

- **机制会接、但抓不住事件**：两次运行逐位相同、基线零误触发，说明随机流与冲动检测在按设计
  工作；但 4 次事件只抓到 1–2 次；
- 原因在群体动力学与「连续 5 步」判据的相互作用：事件一起，**几乎所有神经元同时发放**，
  侧向 STDP 在一两步内把抑制推到足以造成**整步静默**（实测第 203 步 z=59、第 204 步 z=0），
  于是「连续冲动」被静默步打断，命中计数归零；
- 规则门没有这个问题：它看输入显著性，不看群体发放率；
- 这不是实现崩溃（确定性、零误触发都成立），而是**冲动检测判据与侧向抑制不兼容**。

## 下一步（需新预注册）

1. **窗口化命中**：把「连续 5 步」改成「10 步窗口内 ≥5 次冲动」，容忍侧向抑制造成的静默步；
2. **降低侧向 STDP 步长**（η 0.01 → 0.002），让静默步变短；
3. **在输入侧加前馈抑制**，让群体发放率对显著性更单调。

## 边界

- 合成显著性流；不外推到真实对话；
- 侧向 STDP 只在触发群体内部；
- 规则门对照按预注册写死的 `salience > 0.25`（首次实现里误把 salience 映射成检索分，
  在正式数据前已修正，未保留那次输出）。
