## 边界（三个层面必须分开写）

1. **开环固定动作序列**：v5 的 ready 只在这个设定下成立。动作由固定随机序列给出，
   模型/环境共用，不存在动作反馈。
2. **闭环反馈仍失败**：同一模型、同一 margin 分数，闭环 AUROC **0.639**（v2 0.6469、
   v3 0.634、v4 0.640 同量级）。失败在动作反馈导致的想象发散，不是终止头容量。
3. **阈值校准不改变排序**：AUROC 与 v4 相同；v5 只把操作点校准到 FP≤1e-3。校准集
   与测试集独立，阈值未在测试集上选。

## 与 v3/v4 的关系

- v3：全或无分离（非终止步 margin 最大<1）失败，`p3_v3_ready=false`；
- v4：率判据（FP≤1e-3）失败，均值 0.00244，`p3_v4_ready=false`；
- v5：同样的开环分数 + 校准阈值，通过；三个结果都保留，不互相改判。

## 结论

P3 的**开环终止风险**现在可用：AUROC≈1、误报 0.05%、命中 99.8%。**P3 的闭环终止
仍是开放边界**；如果阶段四要宣称“想象中预测终止”，必须限定为固定动作序列的开环，
不能写成闭环能力。
