# M5b：**切谁才叫损伤 —— 切最活跃的也不更伤，而且所有消融都让解码变好**

判据写在 `scripts/m5b_lesion_target.py` 顶部（M5 结果之后、本轮跑之前）。
`frac=0.5`，三臂：切低活跃 / 随机 / 切高活跃。能力 = 解码准确率。

## 一、结果

| 种子 | 基线 | 切低活跃 | 切随机 | **切高活跃** |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.344 | 0.438 | **0.688** | 0.531 |
| 1 | 0.312 | 0.625 | **0.656** | 0.500 |
| 2 | 0.375 | 0.594 | **0.906** | 0.750 |
| 3 | 0.438 | 0.562 | 0.719 | **0.812** |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| **L-1 切高活跃更伤** | `high − low = [0.094, −0.125, 0.156, 0.250]` | **1/4，不过（方向相反）** |
| L-2 随机在中间 | | **1/4，不过** |

## 二、真正的结论：**任何 50% 消融都让解码变好**

十二个消融格子里，**十二个全部高于基线**。连"随机切掉一半神经元"都从
0.344 / 0.312 / 0.375 / 0.438 涨到 0.688 / 0.656 / 0.906 / 0.719。

⇒ **这个系统没有可测的"脆性"。** 破坏它不会让它变差。
与 Round D（切低活跃更好）、Round E（加噪声更好）合起来，是同一件事的第三次确认。

## 三、这条同时质疑了能力指标本身

如果解码准确率在**随机切掉一半神经元之后还能从 0.34 涨到 0.69**，
那它测的就不是"网络完整性支撑的能力"，而是一个非常粗、消融不掉的性质。

⇒ **M4（终身可塑）判"过"里的那句"旧族没退化"，有一部分可能是这个指标对损伤不敏感造成的。**
**这条限定必须挂到所有用解码当作能力的结论上。**

## 四、限定

- 4 种子；`frac=0.5` 一档；"活跃度"取自一条固定历史的发放；
- 消融是永久静默（`alive` 掩码），不是切除后的重新接线；
- 基线是**同一个网络、同一个探针口径**，没有跨网络比较。
