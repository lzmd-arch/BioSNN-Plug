# 预注册：阶段五 M3k——降低侧向 STDP 步长（M3j 的修正版）（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景

M3j 用 10 步窗口把命中从 1–2/4 提到 3/3/4/4/2，但仍有事件被侧向抑制整段压掉。
M3k 只改一个参数：**侧向 STDP 步长 η 从 0.01 降到 0.002**（抑制增长慢 5 倍），
其余与 M3j 完全相同（64 LIF、噪声 0.05、bias 0.02、窗口 10、n_hits 5、冷却 200、同一流、5 种子）。

## 判据（与 M3j 相同，5 个种子全过才 `m3k_ready=true`）

1. 命中：4 次事件中 ≥3 次在 200 ms 内触发（每个种子）；
2. 误触发：前 3 s 基线 ≤1 次（每个种子）；
3. 确定性：同种子重跑逐位相同；
4. 不劣于规则门：命中 ≥ 规则门命中（4），且误触发 ≤ 规则门 + 1。

任一不过 → `m3k_ready=false`，负结果保留，不再调 η。

## 边界

- 只改 η；其余参数与 M3j 一致；
- 合成流；不外推；
- 若 η 降低仍无效，说明问题不在抑制强度，而在群体编码的对比度。
