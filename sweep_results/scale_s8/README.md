# 规模实验 S8：换到 SHD 也一样——**两臂只差 1.0pp，容量饱和是真的**（2026-11-03）

**预注册：** [`research/scale/prereg-s8.md`](../../research/scale/prereg-s8.md)

## 判决

| # | 判据 | 门槛 | 实测 | |
| :--- | :--- | :--- | :--- | :--- |
| **S8-0** | 都放得下 | < 8,000 MiB | 7,393.4 MiB（32k） | ✅ |
| **S8-1** | 两臂都离开地板 | 均 ≥ **0.30** | 8k **0.338** / 32k **0.348** | ✅ |
| **S8-2** | 容量在这个任务上有用 | `acc(32k) − acc(8k) > 2pp` | **+1.0pp** | ✗ |

| n_rec | 准确率（SHD，10 epoch） | 相对 2 epoch | 峰值 | 耗时 |
| ---: | ---: | ---: | ---: | ---: |
| 8,192 | **0.338** | 0.207 → **+13.1pp** | 3,530.8 MiB | 2,718 s |
| 32,768 | **0.348** | 0.188 → **+16.0pp** | 7,393.4 MiB | 2,587 s |

这一轮**前提成立**（两臂都过了地板），所以 S8-2 的 +1.0pp 是**可解释的负结果**——
与 S7 那次不可解释的 −1.9pp 不同。

## 两个任务、两个预算，同一个结论

| 任务 | 预算 | 8,192 | 32,768 | 差 |
| :--- | :--- | ---: | ---: | ---: |
| sMNIST | 2 epoch | 0.774 | 0.805 | +3.1pp |
| sMNIST | 5 epoch | 0.824 | 0.829 | **+0.5pp** |
| SHD | 2 epoch | 0.207 | 0.188 | −1.9pp（**S7 无效，不可解释**） |
| **SHD** | **10 epoch** | **0.338** | **0.348** | **+1.0pp** |

**四组里没有一组让"多 4 倍神经元"换来超过 3pp。** 而同一个 32k 在 SHD 上要多花 **3.9 GB 显存**。

## 结论：规模轴到此为止

ADR-0031 定的问题——"精度随规模怎么长、代价多少"——现在有完整答案：

| 问题 | 答案 |
| :--- | :--- |
| 更多神经元有用吗 | **1k→8k 有用（+14.6pp）；8k 之后没有**（sMNIST +0.5pp、SHD +1.0pp） |
| 显存是瓶颈吗 | **不是**（S4：训练 update 在 64k 上也只有几百 MB；7.5 GB 那个数是评测批次） |
| 训练预算是瓶颈吗 | 有影响，但**只会缩小规模差**（sMNIST：3.1pp → 0.5pp） |

**8k 附近就是这条管线的容量膝点。** 再往上不是放不下，是买不到东西。

## 对主线的意义

规模这条轴**已经回答完了**，而且答案是"没有更多了"。主线必须换问题——
这不是我能替用户决定的事，下面三个候选都有各自的代价：

| 候选 | 说明 |
| :--- | :--- |
| **fan-in** | 现在固定 32，稀疏权重在 64k 时只有 2 MB；加大 fan-in 是"不靠加神经元加容量"的另一条轴，尚未测 |
| **更长的训练预算** | 5/10 epoch 仍远不是充分训练（W2 用 250）；但 S6 的机制是"预算会缩小差距"，方向不利 |
| **收口** | 规模问题已有答案；主线回到交付（发版 / Paper C / 论文） |

## 边界

- 单种子；S8 的 +1.0pp 在噪声内，但**方向与 S6 一致**（都是"大网络没赢多少"）；
- 32k 在 SHD 上峰值 7,393 MiB，只剩 607 MiB 余量——**再往上连放都费劲**；
- 2/10 epoch 都不是"训练充分"，不能排除 250 epoch 下大网络重新领先；但那时要 75 小时/档。
