# 预注册：用短时突触抑制（STP）表达顺序

**定稿时间：2026-10-18。**
上一轮顺序判别里，LIF/ALIF + Hebbian W 没有表现出“先到占优”（最好 0.3293，
线性积分器 0.4024）。这一轮换一个**机制**：在输入突触上加短时抑制（STP）——
第一个输入用掉一部分突触资源，第二个输入在共享位上被削弱。它不再是“调 β/θ”。

## 要回答什么

在同一个顺序任务上（A→B 与 B→A，目标都是先到的那个），**输入短时抑制**能不能
让先到的输入占优，把平均 top-1 从“集合判别”的 ~0.4 推到 0.6 以上？

## 数据与配对

- 166 条真库只读副本；164 条有词法码；全局 `idf-2.0`、`k=64`、4096 位。
- 配对：同一会话里相邻轮 `(t, t+1)` 的记忆，共约 107 对；这些对通常有词面重叠，
  STP 才有“共享位被削弱”的作用对象。
- 顺序：A→B 目标 A；B→A 目标 B；每条都是完整关联码，5 步（2 步输入 + 3 步零输入）。
- 读出：末态膜电位 `A·v` 取 top-1。

## 臂

| 臂 | 定义 |
| :--- | :--- |
| `lif-a095` | LIF，α=0.95，无 STP |
| `lif-a098` | LIF，α=0.98，无 STP |
| `stp-d02` | LIF，α=0.98，输入抑制 d=0.2，恢复 0.05 |
| `stp-d05` | LIF，α=0.98，输入抑制 d=0.5，恢复 0.05 |
| `stp-d08` | LIF，α=0.98，输入抑制 d=0.8，恢复 0.05 |

STP 规则（逐位、确定性）：

```
I_in(t) = input(t) * e(t)
e ← clip(e − d · 1[input(t)>0] + recovery · (1 − e), 0, 1)
```

## 判据

| 平均 top-1 | 结论 |
| :--- | :--- |
| `> 0.60` | STP 表达顺序；值得继续 |
| `> 0.80` | 明显顺序敏感；可以考虑专门任务 |
| `0.45–0.60` | 与线性同量级；没有结构性优势 |
| `< 0.45` | 反向/无顺序；照实报 |

**必须分别报 A→B 与 B→A**；只报平均会把“总选第一个”和“总选第二个”混成 0.50。

## 停止规则

- 只跑这 5 个臂；不在看到结果后追加 d/α 网格。
- 不写真实库；临时副本用完删除。
- 没有学习；W 仍是既有 Hebbian 外积。

## 边界

1. 人为顺序任务；相邻轮配对相似度未控制；不是自然语言时间流。
2. STP 是现象学模型（逐位抑制/恢复），不是生物突触的完整 Tsodyks–Markram 模型。
3. 164 条真记忆；不涉及 50k 规模。
4. 墙钟时间不能论证能效。

## 怎么被核验

`scripts/axo_spiking_stp_prototype.py` 输出每个臂的 A→B、B→A、平均 top-1 与脉冲数；
执行者按上表机械判定。
