# M6r：历史时长 × 增益接线 —— **R-4 过线了，但机制不是我说的那个**

预注册 `research/sel/prereg-m6r-history-wiring-v1.md`。
2×2×2 析因（`t_hist` × `gain_route` × `eta`），K=4、`g_inh=0`、6 种子。

| | `route=field` | `route=all` |
| :--- | ---: | ---: |
| `T=1024, η=0.01` | 1.33× (5/6) | 1.47× (5/6) |
| `T=4096, η=0.01` | **1.00×** (2/6) | **1.68× (5/6)** |
| `T=1024, η=0.005` | 1.35× (4/6) | 1.36× (4/6) |
| `T=4096, η=0.005` | **0.91×** (2/6) | **1.53× (5/6)** |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |

## 二、我预测的机制是错的

预注册里 ① 说"慢变量在 1024 步里攒不出足够差异，拉长历史应该更好"。
**实测相反**：`route=field` 下 1024 → 4096 让效应从 1.33 掉到 **1.00**、从 1.35 掉到 **0.91**。

**长历史单独存在时是伤害的。** 合理的解释：增益在历史期乘的是 `w_in`，而稳态规则一直在把
每个神经元的发放拉向 0.08 —— **时间越长，稳态把差异抹得越平**。历史变长，稳态赢。

② 那个（接线）**方向对**：`field → all` 两个 eta 都涨。但它单独也不够（1.33→1.47、1.35→1.36）。

## 三、真正起作用的是**交互**，不是任一主效应

```
                 field        all
T=1024            1.33        1.47     ← 接线只值 +0.14
T=4096            1.00        1.68     ← 接线值 +0.68
```

**R-4 的过线发生在"长历史 + 全接线"这一格**，而且**这一格的 2/2 都过**（1.68、1.53）——
不是八格里挑出来的单点极值。这一点比 M6p 那个孤立 3.14 结实。

读法：**慢变量必须先有东西可写（长历史），再有一条能写进动力学主干的通道（`route=all`）。
只有其一，另一个会把它抵消掉。**

## 四、必须同时说清的限定

1. **那个 1.68 的臂"停住"是 0/6** —— 稳态窗内前 32 vs 后 32 的距离仍然大于历史距离。
   **它还在动。** 按"冻结增益 ⇒ 仿射映射 ⇒ 至多一个不动点"这条，这可能是
   **暂态偏置**而不是吸引子选择；
2. `T=4096/r=field/η=0.01` 的发放是 **0.1922**，贴着窗口上沿（0.20）；
   它比值塌掉有一部分可能是接近饱和，不只是稳态抹平；
3. 6 种子；`g_inh=0` 固定；
4. **A vs B 仍是 `pref` 与稀疏度一起变**（`seeded_dirichlet` 固定 `PREF_SEED=0`），三轮都没修。

## 五、下一步：数吸引子，不再扫参数

乘法那条已经把话说死了：**冻结的增益只能挪动唯一那个不动点**。所以 1.68 到底是
"个体落进不同状态"还是"暂态被拉长"，`rel` 距离这个口径**分不出来**。

能分开的是**直接数吸引子**：同一网络、零输入，从大量随机初值出发跑到收敛，看终点聚成几个簇。

- **1 个簇** ⇒ "个体坐进不同状态"在这个动力学族里**数学上不存在**，再调任何乘性参数都无效；
- **≥2 个** ⇒ 吸引子集合存在，问题才变成"历史能不能把个体送进指定的那一个"。
