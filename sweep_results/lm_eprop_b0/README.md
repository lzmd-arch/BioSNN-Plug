# B0：同尺寸反向传播对照——**数据把所有人压到 bigram 线附近，局部规则再掉 9pp**（2026-11-08）

**预注册**：[`research/sel/prereg-lm-b0-backprop-control.md`](../../research/sel/prereg-lm-b0-backprop-control.md)
**原始数据**：[`b0.json`](b0.json)

## 一句话

同折、同分词、同截断、同数据暴露（8,000 batch × 16 序列 × 192 字）、同参数量级（**BP 1.77M vs SNN 2.49M**——SNN 参数更多），
GRU 用 BPTT 训出来的 top-1 是 **0.1586**（bigram 0.1669）——**比局部规则的 SNN（0.0657）高 2.4 倍**，
但**仍然没有超过 bigram**。

**分解（top-1）**：bigram 0.1669 → BP 0.1586 → SNN 0.0657。

- **数据的账**：bigram − BP = **0.83pp**；
- **规则/架构的账**：BP − SNN = **9.29pp**。

⇒ 在这个语料上，**约 92% 的缺口是学习规则/架构，8% 是数据**。

## 结果

> **词表与参数量（补记）**：这一折的训练集有 **1,216** 个唯一字符，`run_r0.build_vocab` 不设上限，
> 所以两臂的词表都是 1,216。SNN 的 `w_in`（1216×1024）与 `w_out`（1024×1216）合计 **2,490,368** 参数，
> **比 BP 的 1,765,568 还多 41%**——BP 是用更少的参数赢的，这只会让"规则账"更大，不会更小。

| 臂 | 参数 | lr | top-1 | bigram | Δ | 末点 test CE | 训练 CE 尾/首 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **BP（GRU）** | 1,765,568 | 1e-3 | **0.1586** | 0.1669 | **−0.83pp** | 9.31 | 0.0175 |
| BP（GRU） | 1,765,568 | 3e-3 | 0.1525 | 0.1669 | −1.44pp | 6.78 | 1.32 |
| 局部规则（SNN，τ=20） | 2,490,368 | — | 0.0657 | 0.1669 | −10.12pp | 7.24 | 0.39 |

**BP 的完整曲线**（lr=1e-3，每 2,000 步）

| updates | 2,000 | 4,000 | 6,000 | 8,000 |
| :--- | ---: | ---: | ---: | ---: |
| top-1 | 0.1718 | 0.1691 | **0.1740** | 0.1586 |
| test CE | 7.19 | 7.94 | 8.55 | **9.31** |

top-1 在 **2,000–6,000 步都在 bigram 线上方**（+0.5 / +0.2 / +0.7pp），8,000 步掉下去——
**三点都在 ±0.9pp 的抽样噪声内**（13 对、1,810 个 token），所以准确的说法是 **"BP ≈ bigram"**，
不是"BP 赢"也不是"BP 输"。

## 三件必须一起说的事

### 1. 预注册的"后果"写错了，实测把它推翻了

预注册的 B0-2 写的是"BP < bigram ⇒ 数据不够 ⇒ **架构实验测的是错的东西，该转向数据与分词**"。
字面上 B0-2 触发了（−0.83pp），**但那个推论不成立**：BP 只差 bigram **0.83pp**，而 SNN 差 **10.12pp**。
若数据是主因，BP 也该差得多；它没有。**所以架构实验（R3/R4/R5/R6q）测的不是错的东西——它们测的正是那 9.3pp。**

### 2. CE 与 top-1 又一次脱钩，而且这次是**反向**

| 模型 | top-1（越高越好） | test CE（越低越好） |
| :--- | ---: | ---: |
| bigram | **0.1669** | **5.66** |
| BP（GRU, lr=1e-3） | 0.1586 | **9.31** |
| 局部规则（SNN） | **0.0657** | 7.24 |

- **top-1 排序**：bigram ≈ BP ≫ SNN；
- **CE 排序**：bigram ≪ SNN ≪ BP。

BP 的 top-1 好看，是**用校准换来的**：它把训练集背到 CE 尾/首 = **0.0175**（几乎完全记住），
在测试集上就成了**自信地错**（CE 9.31，比均匀分布 6.69 还差）。
SNN 相反：分布更平，CE 反而比 BP 低，但 top-1 只有 BP 的 4 成。

**⇒ 只看 top-1 会高估 BP，只看 CE 会高估 SNN。两个都要报。**

### 3. 成本差 30 倍

BP 的 8,000 步用了 **185 秒**；SNN 在大折上 16,000 步约 **3.2 小时**（23:19 → 02:32），折半到 8,000 步约 **1.6 小时**。
**BP 用 1/31 的时间拿到 2.4 倍的 top-1。** 局部规则的账，不只是精度，还有算力。

## 预注册偏差与自评

- 预注册说"两个 lr 都报"：已报；两个都不过线，且 3e-3 明显不稳（2,000 步 0.0862、6,000 步 0.0486——**训练发散过**）。
- 预注册说"8,000 步与 R0b 对齐"：已对齐。**没有**扩到 16,000（结论不会因为多跑一倍而翻，BP 已经进入过拟合段）。
- **判据写得太粗**：只写了"BP ≥ bigram / < bigram"两档，没写"BP 在 bigram 附近而 SNN 远低"该判什么。
  下一条同族实验应当写成**三元分解**（数据账 / 规则账），而不是二元。

## 边界

- 单折、单种子、13 对测试（噪声 ±0.9pp）；**BP ≈ bigram 是"打平"，不是"赢"**；
- 这是"同尺寸 BP 能做到什么"的对照，**不是**"BP 架构一定优于 SNN"的结论——两者归纳偏置不同；
- 但**数据暴露、分词、截断、参数量级、折都对齐了**，所以量级差（2.4×）不是这些造成的；
- 字符级 next-token，**不代表能闲聊**。

## 对路线的影响

1. **局部规则的 9.3pp 是真缺口**，R4（多时间尺度读出）已经在补其中一部分：它到 11,250 步时
   top-1 0.2652（bigram 0.2828，Δ −1.8pp），**已经比基线 R2-A 的 −6.16pp 好 4.4pp**——但它跑在**合成语料**上，
   与 B0 的真语料不可直接比。
2. **数据仍然是天花板**：BP 在这个数据量上也就 bigram 水平，所以"加数据"对任何模型都还有空间，
   只是不是当前最大的那块。
3. **下一个该问的问题变了**：不是"数据够不够"，而是"**局部规则为什么比 BP 少 9.3pp**"——
   候选是信用分配深度（BPTT 192 步 vs 逐时刻）、读出结构（R4 正在测）、还是阈值/稀疏性带来的信息瓶颈。
