# 阶段四端到端 v5：两段式 WM → DPAR（2026-10-27）

预注册：[`stage4_e2e_v5_prereg.md`](../stage4_e2e_v5_prereg.md)。WM 在 t=35 读，DPAR 在
t=85 读；两个探针不共享最终状态。5 个种子。

## 结论

**六条全过，`e2e_v5_ready=true`。** 但这是**顺序组合**的 ready，不是 v4 共享状态的复活。

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| WM A/B/Q 平均 R² | ≥0.90 | **0.99995** | 过 |
| WM 选择性 MSE | ≤0.10 | **6.16e-05** | 过 |
| DPAR 最好臂 top-1 | ≥0.80 | **0.9584**（Raw NN） | 过 |
| 状态控制 top-1 | ≤0.35 | **0.2472**（chance 0.25） | 过 |
| OOD AUROC | ≥0.75 | **0.9572** | 过 |
| OOD 弃权 | ≥0.80 | **0.9492** | 过 |

DPAR 三臂：Raw NN **0.9584**、pseudo **0.9256**、局部 Hebbian **0.5504**。状态控制
0.2472 对 chance 0.25，说明最终状态的线性读出无法按查询键选值——DPAR 仍需绑定。

## 这个 ready 覆盖什么

- **覆盖**：同一条时间线里，WM 在 t=35 的探针先完成，随后 DPAR 在 t=85 完成；两者用
  同一个 episode 生成器、同一套数据/种子，但**不共享最终状态**；
- **不覆盖**：v4 的**共享最终状态**共存——v4 的 WM B 线索 R² 0.513、MSE 0.351 原样保留，
  v5 不能推翻它；
- **不覆盖**：终身情景记忆、通用 OOD、阶段四整体验收。DPAR 仍是每幕独立建库，OOD 仍是
  A/B ×3 的尺度偏移；
- WM 的 R² 到 1.000 是因为探针在 DPAR 写入之前、且 A/B/Q 都在慢 τ 的保留范围内；这是
  顺序设计的结果，不是“WM 在干扰下也完美”。

## 与 v4 的对照

| 版本 | 结构 | WM R² | 选择性 MSE | DPAR | OOD 弃权 | 结果 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| v4 | DPAR 与 WM 共享最终状态 | 0.6558 | 0.3507 | 0.9628 | 0.7648 | 4/6，判据不一致 |
| **v5** | **WM 先测，DPAR 后测** | **0.99995** | **6.16e-05** | **0.9584** | **0.9492** | **6/6 ready** |

差别来自结构，不是调参：v4 的最终状态被 4 对键值污染；v5 在污染之前读 WM。**共存干扰
仍是真实边界**，v5 只是给出了不共享状态时的顺序组合上界。

## 边界

1. 合成任务；WM 探针、DPAR 键值都是随机向量。
2. DPAR 每幕独立建库；不是终身情景记忆。
3. OOD 是 A/B ×3；v5 的 0.9492 只对这一类尺度偏移成立；v6/v7 已表明信息丢失型 OOD
   检测不到。
4. 状态控制只证明最终状态线性读出不能解；不证明任何非线性读出都不行。
5. 5 个种子、500 幕；单次运行 79.6 s；没有调窗/σ/K/阈值。

## 下一步

- 若目标是阶段四验收：需要决定“顺序组合 ready”是否足够，还是必须共享状态共存
  （v4 的干扰必须解决）；
- 若继续做共存：先修 v4 的判据不一致，再试分时段读出/分模块状态，而不是继续调 RLS；
- 若继续做 OOD：v6/v7 已排除低维矩；换生成式/循环一致性/输入级特征。
