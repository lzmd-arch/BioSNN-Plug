## 读数

- 三个线索共 12 个独立值，多尺度 28 维状态几乎完全重建（R² ~0.99）；任何单 τ 的 4 维状态
  都做不到——fast 只留不下任何延迟信息，mid 只抓最近的 C，slow 把三个线索混在一起；
- **v0 的判据错误已修正**：v1 不再看“慢单元单看 B 够不够高”，而是要求**每个单尺度至少漏
  一个线索**，这才是“多时间尺度必要性”的正确 operationalization；
- **边界**：读出是 ridge 闭式（测量头），不是局部学习规则；v1 证明的是**状态表示**
  （固定 τ 的漏积分器）能同时保持多个时间尺度的线索；还不是"局部学习的工作记忆"。

## 结论

**工作记忆 v1 ready。** 机制正、对照正确、逐种子稳定。下一步若要把它变成项目主张内的
