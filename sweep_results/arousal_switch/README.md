# 唤醒通道：实验**未成立**（前置条件不过），2026-11-12

**预注册见 [`../../research/cognitive/prereg-arousal.md`](../../research/cognitive/prereg-arousal.md)。**
本文件记录的是**前置条件不过**，不是主判据的结论。

## 发生了什么

| 配置 | 固定臂段成功率 | 唤醒臂段成功率 |
| :--- | ---: | ---: |
| 基础 τ = 1.00 | **0.00** | 0.00 |
| 基础 τ = 0.25 | **0.00** | 0.00 |

被试（表格 Q-learning + softmax）**一次都没有到达终点**。

⇒ **AR-0a 不过**（要求段尾成功率 ≥ 0.60）。按预注册，前置不过就**不判主判据**——
AR-1a/AR-1b 的两个"不过"**不能**被读成"唤醒通道没用"，因为被试根本没学会任务，
切换自然也就"感知不到"（AR-0b 的跌幅实测 0.00）。

## 诊断：任务与被试的预算不匹配

1. **稀疏奖励**：只有到达终点 +1，其余全 0。9×9 迷宫的最短路 16–28 步，
   在 p_slip=0.10 下靠随机探索撞上终点的概率极低；
2. **预算太小**：每段 40 回合 × 6 段 = 240 回合。表格 Q 在 81 个状态上从零开始学稀疏奖励，
   这个量级通常不够；
3. **回合上限偏紧**：`3L+20`（9×9 时约 74 步）用完就结束，探索连"撞见"的机会都不多。

## 要改什么（按优先级）

| # | 改动 | 理由 |
| :--- | :--- | :--- |
| 1 | **奖励塑形**：每步给 `−距离/最大距离` 的小惩罚，终点 +1 | 把稀疏变稠密。**会改变任务**，因此要重写预注册，不能当 amend 偷偷用 |
| 2 | **缩小迷宫**到 5×5，或每段回合数提到 200 | 让"学会"先发生，再看"切换后重学" |
| 3 | 或者换被试（线性 softmax 策略 + 资格痕迹） | 表格 Q 在这类任务上本来就慢 |

**1 与 2 会改任务定义 ⇒ 必须新写预注册，不能拿这一轮当"唤醒没用"的证据。**

## 这一轮的正面价值

- 预注册的前置条件**真的拦住了**一次会得出错误结论的实验。如果只跑主判据，
  我们会得到"唤醒通道在规则切换任务上无增益"——而那个结论是假的；
- 顺带证实了一个工程事实：**τ 在这类任务上不是主要瓶颈**（1.00 与 0.25 都是 0%），
  所以"调温度"不该是下一步。

## 第二轮（v2）：稠密奖励之后——**反过来太容易了**

按 [`prereg-arousal-v2.md`](../../research/cognitive/prereg-arousal-v2.md) 加了稠密奖励。

### 途中修掉的一个真 bug

第一版塑形写成 `reward = −0.05·dist`（恒负），配合**零初始化 Q**，`target = γ·max Q = 0`、
`error = 0`，**表格永远不动**——实测 120 回合 `|Q|max` 一直是 **0.000**。

改成**势函数塑形** `r' = γΦ(s') − Φ(s)`，`Φ(s) = −dist(s)/max_dist` 之后立刻学起来：
200 回合里 **200 次成功**。这条不是调参，是"负奖励 + 零初始化"的经典死锁。

### 但主判据仍然不成立——这次是任务太容易

| 种子 | 固定臂段尾 | 唤醒臂段尾 |
| ---: | ---: | ---: |
| 0–4 | **1.00** | **1.00** |

- **AR-0b 不过**：切换后 5 回合的跌幅是 **0.00**——规则切换根本没造成伤害；
- 于是 AR-1a/AR-1b 的"比值 1.00"同样**不能**读成"唤醒没用"。

**原因很清楚**：势函数塑形把"朝终点走"这一步的方向直接编码进了每步奖励，
agent 不再**需要**探索就能重学——而探索正是唤醒通道要提供的东西。
**塑形强到把答案给出去，就把待测的那个量抹掉了。**

### 两次失败合起来给出一个约束

| 版本 | 奖励 | 结果 | 失败原因 |
| :--- | :--- | :--- | :--- |
| v1 | 稀疏（终点 +1） | 成功率 0.00 | 学不起来 |
| v2 | 势函数塑形 | 成功率 1.00，切换无痛 | **太容易** |

⇒ 需要的是一条**窄带**：任务要难到"切换会真的痛"，又简单到"能学会"。下一步的候选：
① 塑形只在第一段用，之后去掉；② 加大 `p_slip` 或迷宫；③ 降低塑形强度。

**在下一条窄带找到之前，唤醒通道仍然是"未被检验"。**

## 第三轮：窄带没找到，而且暴露出两个具体问题

按 `--shaping / --shaping-first-only / --alpha` 扫了一轮：

| 配置 | 段尾成功率 | 切换后跌幅（AR-0b 要 ≥10pp） |
| :--- | ---: | ---: |
| 塑形常开（1.0 / 0.3 / 0.1） | 1.00 | **0.00** |
| 塑形只在第一段 | **0.17** | +1.00（但永远缓不过来） |
| α = 0.05 / 0.02 | 1.00 | **0.00** |

两个具体问题（不是"任务难调"，是两条真缺陷）：

1. **`rng.shuffle` 可能返回恒等排列**。实测段 1 的"切换"得到 `[0,1,2,3]`——
   **根本没换**。必须显式保证 `perm != identity`（重新抽直到不等）；
2. **即使真换了（段 2 得到 `[1,0,3,2]`），成功率仍 1.00**。起点 Q 值是
   `[0.081, 0.058, 0.05, 0.05]`——**几乎均匀**，说明策略远非确定，却仍然 100% 成功。
   这指向"成功率"这个指标本身太钝：它分辨不出"照着旧策略走"和"重新探索"。

## 结论

**唤醒通道仍然未被检验。** 三次尝试分别失败在：学不起来 → 太容易 → 指标太钝。

下一步不是继续调参，是**换指标**：用**切换后到首次成功所需步数**或**每回合步数曲线**
替代"5 回合窗口成功率"，并在 `perm` 上强制非恒等。这两条要写进 v3 预注册。
