# 多时间尺度工作记忆 v5：LIF / ALIF 脉冲实现（2026-10-27）

**预注册：** [`../working_memory_v5_prereg.md`](../working_memory_v5_prereg.md)。
每个 τ 一组 ALIF 单元（身份输入、无循环），cue 以伯努利脉冲输入，读数取 60 步脉冲计数 +
局部 RLS；LIF(beta=0) 与 ALIF(beta=0.1) 两臂；2000/500、5 种子；干净工作区 commit
`fdac414`。

## 结果（R²）

| 臂 | A | B | 均值 | ridge（同一计数） | 判定 |
| :--- | ---: | ---: | ---: | ---: | :--- |
| LIF | 0.212 | 0.222 | 0.217 | 0.212 / 0.222 | 不 ready |
| ALIF | 0.187 | 0.186 | 0.187 | 0.187 / 0.186 | 不 ready |

判据：多尺度 A/B 都 ≥0.5、fast A <0.3、单尺度各漏一个、不退化（≥v4 的 0.899）；
**两条脉冲臂都远低于 0.5**，`v5_ready=false`。

## 读数：**表示层丢信息，不是读出**

- ridge 在**同一份脉冲计数**上的 R² 与 RLS 几乎逐位相同（0.212/0.222 与 0.187/0.186），
  说明瓶颈不在局部读出；
- 60 步的 LIF/ALIF 计数只有个位数（之前调试时 0–7），阈值/复位/不应期把 cue 的连续
  幅度压成了很粗的计数；三线索的 8 个独立值在 28 个低计数里分不开；
- ALIF 的适应项还进一步压低了计数（0.187 低于 LIF 0.217）；
- 按预注册不调 τ/beta/阈值/编码；**v5 不 ready**，v4 的速率漏积分器仍是可用的局部表示。

## 结论

**脉冲计数读数这条路在 60 步窗口/这组阈值下不够。** 若继续 v6，应改**表示**而不是读出：
用膜电位/亚阈值状态、更长的积分窗口、或 rate-coded 输入；但那会离开“纯脉冲计数”的
设定，需要新预注册。当前阶段四的 ready 组件仍是工作记忆 v4（局部速率 RLS）与元认知 v3。
