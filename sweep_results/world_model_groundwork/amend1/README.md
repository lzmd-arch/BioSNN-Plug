## 这说明什么

- **一步动力学任务站得住**：状态与终止事件都可预测，且"不做预测"的基线差几个数量级；
- **原第一轮的失败是基线表达力问题**，不是任务不可测：终止是双侧阈值，线性头两侧抵消；
  加了 `z²` 与 `(a·z)²` 之后，同一个判据从 0.508 升到 0.9955；
- 动作条件化是真的：换动作，预测差约 0.51 个状态标准差，与是否加二次项无关。
  **0.512 低不是模型缺陷**：CartPole 单步里 ±10 N 对角度/位置的改变本来就有限；
  这个量测的是「动作有没有被用上」，不是「动作影响有多大」。

## 这**不**说明什么

- **不说明世界模型实现了**：没有多步 rollout、没有规划回路、没有神经网络、没有 PINN；
  ADR-0015 的四条验收只覆盖到前三条的**测量地基**。
- **不说明 CartPole 能代表阶段四的预测对象**：它的一步动力学是线性的（欧拉积分），
  线性+二次项就能解掉；换到非线性环境，这个结论不自动成立。
- **不改阶段四的入口条件**：阶段三验收（AF < 8%、重学快 3 倍）仍然是门。

## 下一步（都不在本轮）

1. **多步 rollout**：一步误差低 ≠ 多步不发散；需要 k 步误差曲线与"误差如何随 k 增长"。
2. **换一个非线性环境**：否则"线性可解"会把世界模型的难度全部掩盖。
3. **学习规则**：若世界模型要进认知核心，必须回答局部性（ADR-0015 / v7 候选 1 的第 1 问）。
