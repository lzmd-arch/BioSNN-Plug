## 失败原因：终止是双侧阈值

`ridge_action` 的状态预测几乎是精确的——CartPole 的欧拉一步动力学本来就是
`[s, a, a·s]` 的线性函数，线性模型把它解掉了。失败只发生在终止那一侧：

- CartPole 的终止条件是 `|θ'| > 0.2095` **或** `|x'| > 2.4`——**两个方向都算**；
- 单个线性分数 `w·[s,a]` 只能抬高一侧、压低另一侧，两侧的贡献互相抵消；
- 所以 AUROC 停在 0.51，与常数分数（0.5）几乎没差。

**这是基线表达不了双侧事件，不是任务不可测。** 诊断（单种子、探索性，**不是**本轮的预注册结果）：

| 诊断项 | AUROC |
| :--- | ---: |
| 线性终止头（本轮的 `ridge_action`） | 0.532 |
| 二次项终止头（`z²` 与 `(a·z)²`） | 0.997 |
| 由**预测出的** next state 按环境阈值推终止 | 1.000 |

## 这个结果说明什么 / 不说明什么

**说明**

- 一步**状态**动力学在 CartPole 上是线性可解的；`copy_last` / `mean_delta` 这类
  "不预测"的基线在同一任务上差两个数量级；动作条件化可测（敏感度 0.51）。
- 终点的**事件**预测需要能表达双侧阈值的最小模型；线性头不够。

**不说明**

- 不说明"世界模型实现完了"——没有 rollout、没有规划、没有神经网络、没有 PINN；
- 不说明"CartPole 就是阶段四的预测对象"——它只是现有环境里最便宜的地基；
- 不改阶段四的入口条件（阶段三验收）。
