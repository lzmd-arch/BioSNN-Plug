# 集成分歧度惩罚：**负结果，λ 越大越差**（2026-11-12）

## 假设

h=20 崩溃的根因是二次特征在数据外发散。"裁到训练范围"这个护栏已被证否
（把目标区域一起裁掉了）。本条换一个更聪明的护栏：**同一份数据自助采样训 5 个模型，
规划时对分歧度降权**——

    score(a) = mean_k[score(s'_k)] − λ · std_k[score(s'_k)]

预期：分歧大的地方自动避开，模型自己去躲"大家都说不准"的区域，不必事先划定相信范围。

## 结果（三种子平均回报，每臂 10 回合）

| | λ = 0 | λ = 1 | λ = 4 |
| :--- | ---: | ---: | ---: |
| **h = 10** | **−247** | −256 | −299 |
| **h = 20** | −420 | −469 | **−500** |

- **λ 越大越差，且单调**——在**两个深度上**都是；
- h=20 从 λ=0 的 −420 掉到 λ=4 的 −500（一次都不成功）；
- 集成本身（λ=0、h=10）的 −247 也不如单模型的 **−178**：自助采样让均值模型变差了。

## 为什么失败（与上一条负结果同一个机制）

任何**按"新颖度"加罚**的护栏，都会把规划器推离**目标区域**——而目标区域恰恰是
数据覆盖最差、模型最不确定的地方，也恰恰是必须去的地方。

| 护栏 | 机制 | 实测 |
| :--- | :--- | :--- |
| 裁到训练范围 | 直接禁止预测目标区域 | h=10 −178 → −287 |
| 集成分歧度惩罚 | 对目标区域降权 | h=10 −247 → −299（λ=4） |

**两条是同一个错误的两种写法。** 短前瞻之所以能工作，恰恰是因为它**不需要**在目标附近
做长程外推；一旦让护栏主导，就把它推回去了。

## 结论

- **集成分歧度惩罚不是解法**，λ 从 0 加到 4 单调变差；
- 真正要解决 h=20 的崩溃，得让**模型本身**在目标区域也更准（数据覆盖 / 模型类），
  而不是给不确定的地方加罚；
- 另注意：h=20、λ=0 时仍出现 `invalid value` 警告——预测状态仍在发散，只是均值版
  比加罚版稍微能忍。
