## 读数

- 一步想象训练没有解决分布偏移：AUROC 0.632，甚至低于真实状态头的 0.665；
- 原因是闭环状态在约 **115 步**后发散，而训练只覆盖**一步**想象的分布；多步想象的
  输入分布与闭环后段仍不同，且没有可信的多步终止标签；
- 按预注册不调状态模型/头/阈值；P3 的终止闭环仍不可用。

## 结论

**P3 v2 不 ready。** 闭环终止卡在“状态模型发散步 ~115”与“终止头训练分布只到一步”之间。
下一步若继续，要么换更强状态模型（把发散步推远），要么接受“闭环终止不可评”，先把 P3
的状态/闭环稳定性作为已过的部分记录下来。
