# Axo 真脉冲原型：结果

预注册：[`axo_spiking_prototype_prereg.md`](axo_spiking_prototype_prereg.md)。
本文件是执行记录；lag/drop 的额外几档是在预注册之后补的探索性任务，边界见最后。

## 一句话

**真脉冲能跑通，而且模拟读出把差距从“明显更差”缩到了 4.3 个百分点；但它仍然没有
在静态补全上追平速率基线，时序任务又恰好两边都到顶，所以目前没有理由替换默认路径。**

## 1. 静态补全（166 条真库，164 条有词法码）

50% 丢位，找回自己。

| 臂 | top-1 | top-5 |
| :--- | ---: | ---: |
| 速率一步 `A·(Aᵀ(A·p))` | **0.9085** | 1.0000 |
| 真脉冲最好：`membrane` / 无侧抑制 / 同质 / LIF | 0.8659 | 0.9878 |
| 真脉冲 `spikes` 读出最好（ALIF β=1） | 0.6768 | 0.9329 |
| 真脉冲 `spikes` 读出（LIF） | 0.2805 | 0.7073 |

**差距 −4.26 pp**，超过预注册的“不差”线（−2 pp）⇒ **静态不达标**。

三条可读的细节：

- **模拟读出是关键。** 同一套动力学，只把读出从“脉冲计数”换成“末态膜电位”，
  top-1 从 0.2805 跳到 0.8659——阈值化丢掉的信息主要丢在这里。
- **适应项对脉冲计数有帮助、对膜电位有害。** β=1 让 `spikes` 从 0.28 到 0.68，
  但让 `membrane` 从 0.866 降到 0.835；`beta=0` 是膜电位读出的最好档。
- **侧抑制与异质性没有救回 top-1。** `global` 把 `spikes` 的 top-5 抬到 1.0，但
  top-1 只有 0.68–0.74；`kwta` 类似。异质 τ（hetero=0.5）在静态上几乎不动。

## 2. 时序：下一轮记忆（以及更远的轮次）

任务：同一会话里，给第 t 轮的关联码（可丢一半位），找回第 t+L 轮的记忆；速率臂
是一步 `A·A_nextᵀ(A_prev·p)`。L=1/2/5 的查询数分别是 107/99/94。

| 任务 | 速率 top-1 | 真脉冲最好 top-1 | 差 |
| :--- | ---: | ---: | ---: |
| L=1，完整线索 | 0.9720 | 0.9813（membrane / 同质 / 无抑制） | +0.93 pp |
| L=1，丢一半线索 | 0.9720 | 0.9813（同上） | +0.93 pp |
| L=2，丢一半线索 | 0.9798 | 0.9899（membrane / global / hetero 0.5 / β=1） | +1.01 pp |
| L=5，丢一半线索 | 0.9894 | 0.9894（membrane / 同质） | 0.00 pp |

**全部落在预注册的 ±5 pp“打平”带内**，没有一档达到 +5 pp 的“赢”。
而且这个任务本身**在两边都接近天花板**：L 越大、查询越少，top-1 反而越高——说明
它测到的主要是“同一会话、相邻/相近轮次的记忆本来就高度相似”，不是脉冲动力学
带来的时序能力。**不能从这张表得出“脉冲有时序优势”或“脉冲没有时序优势”**；
只能得出“这个任务区分不了两者”。

## 3. 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 静态 `spiking_top1 ≥ rate_top1 − 0.02` | 0.8659 < 0.8885 | **不达标** |
| 时序 `spiking_top1 > rate_top1 + 0.05` | 最好 +1.01 pp | **打平** |
| 同时报 top-5/脉冲/耗时 | 见 JSON | 已报 |

因此：**不做默认集成，不新增依赖，不把脉冲当成“更准”的路径。**

## 4. 边界

1. 166 条、4096 位、numpy **稠密**模拟；`A` 是 `(n, 4096)`。5 万条时稠密矩阵约
   800 MB，**这套实现不能直接扩到 50 万/5 万条**，需要稀疏/事件驱动表示。
2. 只有推理，没有 STDP/e-prop 学习；`W` 仍是 Hebbian 外积。
3. 编码是全局 `idf-2.0`，不是 P4c 的簇内 idf；两边的数不能直接相减。
4. 时序任务用会话顺序，不是人工语义标注；它测的是顺序关联，不是“理解”。
5. 能效没有测：numpy 向量化模拟的墙钟时间不能论证神经形态能效。

## 5. 下一步（如果还要继续）

1. **先把规模做对**：把 `A` 换成稀疏/事件驱动表示，量 5 万条上单次查询的延迟与内存；
   没有这一步，任何“Axo 用真脉冲”的规模说法都不成立。
2. **换一个真正有区分度的时序任务**：不要用“相邻轮次”这种两边都到顶的题。候选：
   序列遍历（给 t 的线索、目标是 t+L，同时设“速率迭代 L 步”作对照）、跨簇/加噪
   线索、或带干扰项的重合检测。只有速率基线明显下降、脉冲还站着，才说明有优势。
3. **只有出现明确优势**，才考虑给 Axo 加可选 spiking 模式；否则保持速率路径。
4. 如果继续，仍放在 `BioSNN-Plug-neuron` 副本里，不把研究依赖带进 Axo 主包。
