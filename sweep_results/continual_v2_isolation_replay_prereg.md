# 预注册 v5：输出行隔离 + 回放（P1+R）（2026-10-26）

**定稿时间：2026-10-26，在本组合的任何数据之前。** P1（只更新当前行）把 AF 从 80.5%
压到 **17.4%**，但把逐任务对角线从 0.808 压到 **0.534**——用获取换保持。回放 ρ0.3
单独跑时把 ACC 从 24.7% 抬到 **36.3%**、AF 从 80.5% 降到 **74.0%**。本预注册把两者
叠在一起：隔离负责保住旧行，回放负责把获取拉回来。

## 机制（唯一组合）

```text
每任务：只更新当前 10 个类的输出行（其余 90 行冻结）
minibatch：B=128，其中 n_replay = round(0.3·B) 条来自 latent replay 缓冲
缓冲：每任务结束按类抽 20 条特征（固定种子），不随任务无限增长
```

回放样本的旧类标签仍然参与误差；但**只有当前行会被更新**——这不是标准回放的
"重训旧行"，而是用旧样本**约束当前行**。这一点写死，不把它当标准回放解释。

## 判据（先写死）

1. **阶段门（不变）**：AF < 8% 且 ACC ≥ 65%；
2. **相对 replay-alone**：AF **−10 pp** 且 ACC ≥ replay −1 pp；
3. **相对 P1**：ACC **≥ P1 +5 pp**（回放把获取拉回来）且 AF ≤ P1 +5 pp（不能为了
   获取把保持全丢掉）；
4. **不是少学**：逐任务对角线均值 ≥ 参考臂 −5 pp（**0.758**）；
5. 跑门照旧，作废种子数写进 summary。

## 限制

- **不声明"按类对齐"**：预注册 v4 的随机行控制臂已证明无效（随机行没有正目标、
  误差恒 0）；本预注册只测**组合**，不重开对齐检验；
- 回放在隔离下只约束当前行，不是标准 latent replay 的机制；不要把它写成"回放重训旧行"；
- 5 个种子、单一骨干、单一 η、单一 ρ；不覆盖其它 ρ 或部分隔离。

## 不做什么

- 不调 ρ（固定 0.3）、不调 η / epoch / batch / 种子；
- 不加归一化（已单独测过）；
- 不改写 P1 / replay 的已发布数字；
- 看到结果后不改判据、不换参考臂。
