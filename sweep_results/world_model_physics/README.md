# 多样化物理约束：**救长前瞻，伤短前瞻**（2026-11-12）

预注册见 [`../../research/cognitive/prereg-world-model-physics.md`](../../research/cognitive/prereg-world-model-physics.md)。
本文件只记数，不改判据。

## 实现的三条约束（按应用顺序）

| # | 约束 | 内容 |
| :--- | :--- | :--- |
| **C1** | 单位圆 | `(cos θ_i, sin θ_i)` 投影回单位圆 |
| **C2** | **运动学一致** | 用 `θ = θ_prev + ω·dt` 覆盖角度块，强制**角度服从速度** |
| **C3** | **能量上界** | 单步能量变化不得超过 `τ_max·|Δθ|`，超了就缩放速度把动能拉回来 |

（预注册里的 C4"速度上限"由 C3 的能量约束隐含覆盖，未单独实现。）

## 结果（60 回合训练 / 10 回合测试 / 三种子）

| 种子 | h=10 裸 | h=10 + 约束 | h=20 裸 | **h=20 + 约束** |
| ---: | ---: | ---: | ---: | ---: |
| 0 | −261 | −408 | −500 | **−168** |
| 1 | −178 | −382 | −445 | **−256** |
| 2 | −95 | −337 | −379 | **−219** |

- **h=20：从"全败"救到 −168…−256**（原本全部撞 500 步上限）；
- **h=10：三个种子全部变差**（−261→−408、−178→−382、−95→−337）。

## 为什么短前瞻被伤

**C2 是覆盖式的**：它用 `θ_prev + ω·dt` 顶掉模型自己预测的角度。
- 短前瞻时模型的角度预测本来很准，覆盖等于**用积分值替换真值**，引入误差；
- 长前瞻时模型的角速度也已经不可信，但**至少被约束在物理可行的耦合关系上**，
  比自由发散好得多。

## 与既有负结果的关系

| 护栏类型 | h=10 | h=20 |
| :--- | ---: | ---: |
| 裁到训练范围 | −287（更差） | — |
| 集成分歧度惩罚 | −299（更差） | −469（更差） |
| 单位圆投影（C1 单独） | −500（更差） | −500（不变） |
| **C1+C2+C3** | −337…−408（更差） | **−168…−256（大幅改善）** |

**这是第一个在多步外推上真正起作用的改动。** 前三种都是"回避无数据区"，
这一种是"**用物理把无数据区里的预测绑住**"——性质不同。

## 下一步（这条线第一次有了正方向）

约束应当**自适应启用**，而不是每步都开：

- 只有预测**偏离数据包络**（或多次 rollout 后）才施加 C2/C3；
- 短前瞻保持模型自己的预测，长前瞻再上约束。

这样有望同时拿到 h=10 的 −178 和 h=20 的 −168。

## 四问

1. 预算截断？否；
2. 跨环境？只在 Acrobot；**约束用到 gym 的 `dt=0.2` 与标准物理参数，换环境必须重推**；
3. 单边指标？是（回报），故同时给 h=10/h=20 两栏，不只报赢的那一栏；
4. 先验未兑换？不涉及。

## 第二轮：加上 C4（力矩上限）与自适应启用——**"更全面"反而更差**

### C4：单步角速度变化不超过 `τ_max/I · dt`

物理上成立，但**套到单步 delta 上是错的**：连续时间的不等式要按积分器重新标定，
而 gym 的 `dt=0.2` 与一步位移不是同一量纲。结果是每步都把速度按住，摆荡不起来。

| 配置 | h=10（种子 0/1） | h=20（种子 0/1） |
| :--- | :--- | :--- |
| 只有 C1+C2+C3（上一轮） | −408 / −382 | **−168 / −256** |
| **加上 C4 之后** | −482 / −500 | **−500 / −480** |

**C4 把上一轮 h=20 的改善整个抹掉了。**

### 自适应启用（C1/C4 常开，C2/C3 仅当预测跑出数据包络时上）

| 种子 | h=10 裸 / 全开 / 自适应 | h=20 裸 / 全开 / 自适应 |
| ---: | :--- | :--- |
| 0 | −261 / −482 / **−139** | −500 / −500 / −500 |
| 1 | −178 / −500 / −250 | −445 / −500 / −480 |

- 种子 0 的 h=10 **从 −261 改善到 −139**；
- 种子 1 的 h=10 反而更差（−178 → −250）。**两种子方向不一致，不能判成立。**

### 结论

1. **"约束越多越好"不成立**——C4 是纯粹的反例；
2. 自适应的**思路**（按是否出包络决定是否覆盖）方向对，但判据阈值（`tolerance`）没标定，
   且只有 2 个种子；
3. 下一步应当是：**去掉 C4**、对 `tolerance` 做标定、种子扩到 5 个再判。

**不声称**：不声称物理约束有效——目前唯一稳定的改善来自"长前瞻 + C1/C2/C3"，
而不是这轮更全面的组合。

## 第三轮：自适应去掉 C4 之后——**完全失效**

| 配置 | h=10（种子 0/1/2） | h=20 |
| :--- | :--- | :--- |
| 自适应**含** C4 | −139 / −250 / −114 | −500 / −480 / −500 |
| 自适应**去掉** C4 | **−500 / −500 / −499** | −500 / −500 / −500 |

⇒ **C4 在自适应模式下正是 h=10 改善的来源，同时又是 h=20 崩掉的原因。**

## 完整对照表（三种子）

| 配置 | h=10 | h=20 |
| :--- | :--- | :--- |
| 裸模型 | −261 / −178 / −95 | −500 / −445 / −379 |
| C1+C2+C3 全开 | −408 / −382 / −337 | **−168 / −256 / −219** |
| 加 C4 全开 | −482 / −500 / −363 | −500 / −500 / −500 |
| 自适应（含 C4） | **−139 / −250 / −114** | −500 / −480 / −500 |
| 自适应（去 C4） | −500 / −500 / −499 | −500 / −500 / −500 |

**没有一组配置能同时拿下 h=10 与 h=20。**

## 这条线最诚实的结论

1. **约束之间的交互不可加**。我按"每条约束各管一块"做的推理在这里不成立——
   C4 在一种组合里是功臣，在另一种里是元凶；
2. **唯一稳健的正结果**是"C1+C2+C3 全开、只用于深前瞻"（h=20 从全败到 −168…−256）；
3. **选配置不能按组件推理，只能按整体实测**——这正是本仓库"判据先落盘、按臂对照"的意义；
4. 继续调参的边际收益已经很低：五轮优化里，四轮是负结果。

**建议**：把"C1+C2+C3 → 仅深前瞻"作为这条线目前的交付结论，其余组合标为已证否。
