# 预注册：情景记忆 v1——局部吸引子 + 独立时间戳通道（2026-10-26）

**定稿时间：2026-10-26，在 v1 的任何数据之前。** v0 的朴素 Hebbian 外积被字面最近邻
全面打败（动作 0.646 vs 0.762、终止平衡 0.500 vs 0.955、时间顺序 0.509 vs 0.608）；
串扰从 N=100 就存在。v1 只改**读出与时间通道**，不改数据、编码器 D/k、噪声、容量与判据。

## 三个臂（同一稀疏键，D=512、k=32、σ=0.1）

| 臂 | 读出 | 时间 |
| :--- | :--- | :--- |
| **A：attractor** | 3 步 `q ← top-k(sign(Kᵀ(K q)))`，再用最终键读值 | 独立标量记忆 `M_τ = Kᵀτ` |
| **B：one-shot** | 直接用查询键读值（v0 的读出） | 独立标量记忆 |
| **C：pseudo-inverse（对照，非候选）** | `V K⁺`（最小二乘闭式） | 同一个值矩阵里的时间戳 |

- A 是**局部**迭代（只有矩阵-向量与 top-k）；B 隔离"独立时间戳"这一改动；
- C 是**非局部**的闭式读出，只用来量**上限**：如果 C 过而 A/B 不过，说明限制在局部读出，
  而不是数据/编码；
- 时间戳单独存：动作/终止 4 维值 + 一条 `D` 维时间记忆，不再让 5 维值互相挤。

## 数据与协议（与 v0 相同）

200 回合事件池、终止事件分层采样、σ=0.1、N∈{100,300,500,1000,2000}、5 种子；
主指标 N=500，容量 N=1000；原始最近邻仍单列作基线。

## 判据（与 v0 相同，先写死）

1. 动作回忆 N=500 **≥0.70**；
2. 终止平衡准确率与 TPR **≥0.70**；
3. 时间顺序 N=500 **≥0.75**；
4. 容量 N=1000 动作 **≥0.65**；
5. **A 或 B** 四条全过 → `v1_ready`；C 只报上限，**不能**用它判 ready。

## 不做什么

- 不调 D/k/σ/容量/阈值；吸引子步数固定 3；
- 不换编码器、不加巩固/睡眠重放；
- 不把 C（伪逆）的成绩写成局部联想记忆的成绩；
- 不在同一轮里做工作记忆/世界模型耦合。
