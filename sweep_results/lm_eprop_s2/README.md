## 这条结果的分量

1. **0.717 不是那颗种子的运气**：五种子均值 0.7226，最低的一个也赢 bigram 6.6pp；
2. **这是纯局部学习规则**（e-prop 逐时刻 + NLMS 读出，**全程无 autograd**）在这份语料上的
   第一个种子稳健的正结果；
3. **不需要任何递推**——S1 已经证明加了只会更差。

## 仍然不能说

- **不能外推到"能闲聊"**：字符级、模板语料、单层、N=1,024、2,000 updates；
- **不能与 P4 的 BPTT 数字并列**：那是 `student.py` 用反向传播训全权重，这里只训输入与读出；
- **不能当能力上限**：测试集 46 条（top-1 的 SE ≈0.9pp），语料只有 301 条训练样本；
- **不能说"规模无关"**：只测了 N=1,024 一个点。
