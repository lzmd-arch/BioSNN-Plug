# M6ba2：残余里带不带历史 —— **方差 ≠ 信息**

**日期**：2026-11-17 08:20 跑，08:45 补诊断
**判据写于跑之前**（见 `scripts/m6ba2_residual_probe.py` 的 docstring）
**种子**：6（纪律要求 ≥6）

## 一、第一版（M6ba）为什么作废

`m6ba` 用"距离比"`rel(A,B) / rel(A,A')`。两处硬伤，都是自我更正的：

1. **三个条件各算各的 PCA 基** —— 它们不在同一子空间里，距离不可比；
2. **距离比这个口径没有分辨力** —— 它把八分类压成一个标量。

M6ba 的 R-0 仪器自检当场露馅：比值 1.06×，等于"条件 A 和自己相同"。

## 二、本版做法

**同一套基底、同一个任务，用已经验证过的探针问**：

```
基底   = 训练集 PCA 前 m 维（**只用训练集算，一次算好，三者共用**）
可读端 = 投影到前 m 维   → 探针
残余端 = x − 投影        → 探针
```

## 四、追加诊断：`1.01` 这个数其实是本实验最重要的一句话

跑完看到 R-2 = 1.01，怀疑"是不是又拿 A 和 A 比了"，于是补了三件事（种子 0，每族 32）：

1. **前 4 个主成分吃掉多少方差**：**99.9998%**（标准化后 0.99999768，不标准化 0.99999865，两种算法一致）；
   残余的能量占比只有 **2.3×10⁻⁶**，幅度占比 **1.5×10⁻³**；
2. **残余端在原始尺度上的线性可读性**（不逐特征标准化）：**0.688** —— 不是靠把微小特征放大 1000 倍读出来的；
3. **标签打乱 10 次对照**：残余端 **0.125**（0.062–0.219），可读端 0.108；真实标签下残余端 **0.703**。

### 于是得到一句可以单独站住的话

> **方差最大的 4 个方向吃掉 99.9998% 的方差，线性可读只有 0.266；
> 只占 0.15% 幅度的残余，线性可读到 0.703（打乱后 0.125）。**

**历史信息住在小方差方向里，方差最大的方向几乎不含类别信息。**

这一条同时解释了此前"读不出"的一整类失败：**PCA 按方差排序，不按信息排序**；
用前 m 个主成分当"可读子空间"，很可能把信息整段扔掉。

## 五、四问（结果入库的限定语清单）

1. **是预算截断吗？** 不是。这是探针读数，不是训练曲线；6 种子 × 8 族 × 64，测试集独立。
   但**只测了一个 m（m = 4）**——m = 1/2/8/16 的曲线没有。
2. **是跨语料比较吗？** 不是，单语料的 8 个族。
3. **是单边指标吗？** 主表只有准确率一个指标。**已补标签打乱对照**（第四节），这是必需的第二边。
4. **cos 先验兑换成 Δ 了吗？** 无关（本实验不涉及余弦）。

## 六、写死的一条纪律

**今后任何"读不出"的结论，必须先报 top-m 方差占比。**

若 top-m 吃掉 >99% 的方差而读出又差，那么**"读不出"更可能是"PCA 把信息扔了"**，
不是"状态里没有信息"。M6ba2 就是这条纪律的第一个实例。

## 七、未测

- **m 的剂量曲线**（1 / 2 / 8 / 16 / 全维）——决定"信息到底住在第几个方向之后的尾巴里"；
- 方差-信息解耦是不是这个工作点特有的（`amp_gate=2`、8 族、1024 神经元）；
- 打乱对照只做了 10 次（够判"不是 0.70 级别"，不够估精确零分布）。
