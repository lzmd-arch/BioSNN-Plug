# 预注册：跨模态检索第六轮——固定随机特征 + 局部读出

**定稿时间：2026-10-17，在这一轮的任何数据之前。**

## 它要回答什么

第五轮的两道上界把方向指出来了：

| 读出 | R@1（5 种子均值） | 性质 |
| :--- | ---: | :--- |
| 线性（ridge） | 0.479 | 非局部 |
| **非线性（kNN）** | **0.555 / 0.562** | 非局部、非参数 |
| 线性、局部（delta） | 0.393 | 局部，有教师 |

非线性读出把成绩抬过 50%，线性局部规则停在 0.39。所以这一轮问：
**给局部规则加一层固定的非线性特征，能不能把它推到 50% 以上。**

## 规则：随机特征 + delta

```text
φ(x) = ReLU(P·x)                    # P 固定随机、不训练、无梯度
W ← W + η·(v − W·φ(t))·φ(t)ᵀ        # 只有 W 被训练，逐样本
```

**为什么这仍然是局部学习**：`P` 是固定随机投影（与 ADR-0012 的"固定随机投影"同一取舍：
零训练、逐位可复现、种子进配置），不参与学习；被学习的只有 `W`，而 `W` 的更新仍然只用到
局部量（前/后活动 + 教师误差）。**没有反向传播，没有梯度穿过 φ。**

⚠️ 这条边界要写进结果：**随机特征不是"学到了表示"**，它只是给线性读出一个非线性基。
若它有效，说明"非线性"是缺的那一块；若无效，说明还得回到编码。

## 设计

| 维度 | 取值 |
| :--- | :--- |
| 表示 | `plugin` 与 `bus@256` 两档（第五轮两者几乎持平，保留两档看稳定性） |
| 特征数 | {256, 512}，**训练集 5 折交叉验证**选，与 `η`、`epochs` 联合 |
| η | {0.001, 0.01, 0.1} |
| epochs | {5, 20} |
| 种子 | 0–4，切分与前几轮相同 |

## 判据

* 选定配置的测试 R@1 ≥ 0.50 → **第二阶段的验收线达成**（这是第一个既是局部规则、
  又过线的候选）；同时报告它与 kNN 上界的差距；
* 若仍 < 0.50 → 结论是"固定随机特征救不了"，下一步回到编码（图像侧三帧事件编码）；
* 无论结果，**kNN 与随机特征都不许冒充局部规则**：前者没有学习，后者没有学表示。

## 边界情况

* 随机特征会把维度从 256/1152 抬到 512，delta 的更新量随特征数线性增长——两档都在秒级。
* 与第五轮一样，测试集只有 29 条，**单个种子的结果不可当证据**，只报均值与范围。
