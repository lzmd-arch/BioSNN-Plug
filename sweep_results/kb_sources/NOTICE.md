# 数据来源与许可声明（知识库）

**日期**：2026-11-16

本目录下的 `wiki.jsonl` 保存了从中文维基百科抓取的**条目首段原文**，供审计与复算使用。

## 文件与许可

| 文件 | 内容 | 许可 |
| :--- | :--- | :--- |
| `wiki.jsonl` | 159 个条目的首段原文、URL、抓取时间、sha256 | **CC BY-SA 4.0**（中文维基百科） |
| `paraphrase_audit.json` | 自写定义与原文的逐条比对 | 本项目（Apache-2.0） |
| `paraphrase_review.md` | 人工复核表 | 本项目（Apache-2.0） |
| `paraphrase_audit_amend1.md` | 判据修订记录 | 本项目（Apache-2.0） |

`wiki.jsonl` 里的正文版权归维基百科贡献者所有，按 **CC BY-SA 4.0** 提供，
来源 `https://zh.wikipedia.org/`。每条记录都带 `url` 与 `license` 字段。
**本文件的作用就是履行署名义务**：任何再分发 `wiki.jsonl` 的场合都必须一并保留本声明，
并且衍生作品须以相同方式共享。

## 训练数据里没有维基原文

训练答案里的概念定义是**本项目自写**的（`scripts/kb_defs.py`），事实依据这些条目，
表达不是。`source_url` 字段指向依据条目，作用是**可核对**，不是"原文出处"。

"没有照抄"由 `scripts/kb_license_audit.py` 逐条度量，判据写在那个脚本顶部。
当前结果：88 条定义，**最长公共子串 7 字**（上限 15），**无一条包含维基完整句子**。

> 上一版（2026-11-16 之前）直接把维基首句当训练答案，属于复制 CC BY-SA 表达；
> 已在本日期全部替换。见 `paraphrase_audit_amend1.md` 与仓库提交记录。
