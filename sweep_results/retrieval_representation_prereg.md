# 预注册：跨模态检索第四轮——表示网格（诊断 + 优化）

**定稿时间：2026-10-17，在这一轮的任何数据之前。**

## 它要回答什么

第三轮定位到了瓶颈：**线性上界 R@1 = 0.466，低于 50%**，所以问题不在联想规则，在表示。
这一轮把"表示"当成自变量，问两件事：

1. **线性上界在哪个配置上越过 50%？**（诊断）
2. 越过之后，**局部规则（delta）离上界还有多远？**（优化）

## 网格（先写死）

| 维度 | 取值 | 理由 |
| :--- | :--- | :--- |
| 表示 | `bus@128`（基准）、`bus@256`、`bus@512`、`plugin`（**不经过总线投影**） | 总线把 1152 维的图像压到 `bus_dim`；`plugin` 直接拿插件输出（图像 1152 / 文本 256），用来判断压缩是不是元凶 |
| 联想 | `ridge`（线性上界，非局部）、`delta`（局部，有教师） | 上界与候选各一个 |
| 种子 | 0–4 | 与前几轮相同 |
| 切分 | 80/20，同种子 | 与前几轮相同 |

共 **8 个配置 × 5 个体子**。

## ⚠️ 选配置只能用训练集，不能用测试集

8 个配置里挑测试集最高的那个，是**在测试集上做选择**——那会让报告的 50% 变成一个
「挑出来的」数字，和"随机基线 0.034"不再可比。

所以：

* 每个配置的联想超参照旧**只用训练集交叉验证**选；
* **配置本身按训练集 CV 分数排序**（`selection_best_r1`），取训练集 CV 最高的那一个作为
  "本轮选定配置"；
* 报告里同时给**全部 8 个配置的测试分数**（透明），但**结论只认训练集选出来的那个**。

## 判据

* 若选定配置的测试 R@1 ≥ 0.50 → **第二阶段的这条验收线达成**，并报告 delta 与上界的差距；
* 若线性上界在**所有**配置上都 < 0.50 → 结论是"这套编码承载不了这个任务"，下一步该改编码
  （图像侧的事件编码只有 3 帧、文本侧是逐 token 的句子 embedding），而不是继续调表示维度；
* 任何情况下，`ridge` 的数字**不进达标栏位**——它不是局部规则。

## 这份预注册**不**声称什么

* 不声称选出的配置能外推到真实数据（Flickr8k 仍未跑）。
* 不声称 50% 一旦达成，就说明"局部学习在跨模态检索上成立"——这一格验的是联想层与表示的
  配合，不是学习规则的生物合理性。
