# 元认知 v4：e2e v3 上的本地风险控制（2026-10-27）

预注册：[`metacognitive_gate_v4_prereg.md`](../metacognitive_gate_v4_prereg.md)。
复用 e2e v3 主档（K=8、σ=0.3、t=100），但增加独立校准集：阈值只在 500 幕 calibration
上取，test/OOD 不参与拟合。5 个种子。

## 结论

**主门 gauss3 四条全过，`metacognitive_v4_ready=true`。**

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| test 覆盖率 | 0.78–0.82 | **0.8028** | 过 |
| 80% 覆盖选择性 MSE | ≤0.10 | **0.06745** | 过 |
| OOD 弃权 | ≥0.80 | **0.8456** | 过 |
| OOD AUROC | ≥0.8350 | **0.9003** | 过 |

与 v3 的同一任务相比：弃权 **0.7056 → 0.8456（+14.0 pp）**，AUROC
**0.8350 → 0.9003（+6.5 pp）**，选择性 MSE 基本不变（0.0675 → 0.06745）。

## 关键边界：修好它的是 state_norm，不是“局部校准”

| 门 | test 覆盖 | 选择性 MSE | OOD 弃权 | OOD AUROC |
| :--- | :--- | :--- | :--- | :--- |
| zsum（v3 两信号 + 校准阈值） | 0.7792 | 0.0684 | 0.7208 | 0.8336 |
| gauss2（disagreement + surprise） | 0.8076 | 0.0676 | **0.6984** | 0.8074 |
| **gauss3（+ state_norm，主门）** | **0.8028** | **0.0675** | **0.8456** | **0.9003** |
| knn3（3 维 5 近邻） | 0.7972 | 0.0686 | 0.8296 | 0.8981 |

**gauss2 比 zsum 还差**（弃权 0.6984 vs 0.7208）：只把两信号换成局部高斯密度，并没有
改善；真正的增益来自第三维 `state_norm`。本轮 OOD 定义是 **A/B ×3 的尺度偏移**，
`state_norm` 正好直接测这个尺度。所以这条结果只能写成：

> 对“输入整体放大 3 倍”这一类 OOD，状态范数密度门能把固定 80% 覆盖下的弃权从 0.706
> 提到 0.846；不能写成“模型更知道不知道”，也不能外推到与尺度无关的 OOD。

`e2e_v3_ready` 仍然是 **false**：v3 的原预注册判据没有重跑，v4 只是同一数据上的一个
**新决策层**，不能反过来追认 v3 过线。

## 主门逐种子

| seed | test 覆盖 | 选择性 MSE | OOD 弃权 | OOD AUROC |
| :--- | :--- | :--- | :--- | :--- |
| 0 | 0.770 | 0.0750 | 0.874 | 0.9068 |
| 1 | 0.804 | 0.0688 | 0.828 | 0.9021 |
| 2 | 0.814 | 0.0607 | 0.838 | 0.8992 |
| 3 | 0.830 | 0.0615 | 0.858 | 0.9053 |
| 4 | 0.796 | 0.0712 | 0.830 | 0.8880 |

五个种子的弃权都 ≥0.828；AUROC 都 ≥0.888。没有单种子把均值拉过线。

## 方法修正：kNN 对照的自距离

kNN 对照的第一版实现把校准点自身算进了 5 近邻（自距离 0），导致校准置信度系统性偏高、
test 覆盖率只有 0.6888，阈值口径与其它门不可比。改为 **leave-one-out**（校准点排除自身）
后覆盖率为 0.7972。**gauss3、gauss2、zsum 的数值逐位不变**（已用第一次运行的 summary
逐项比对），所以主结论和主门不受这个修正影响；kNN 的 0.8296 是修正后的对照值。

## 边界

1. OOD 是模拟的 A/B ×3 尺度偏移；`state_norm` 是尺度敏感特征，结论不外推到真实分布偏移。
2. 阈值只在 calibration 上取，test/OOD 不参与拟合；这是相对 v3（test 上取分位）的方法修正。
3. 覆盖率 0.8028 是 5 种子均值；单种子 0.770–0.830，500 幕测试集的采样误差约 ±1.8 pp。
4. `metacognitive_v4_ready=true` 只表示主门四条过；不改变 `e2e_v3_ready=false`，也不改变
   情景记忆/工作记忆的边界。
5. 5 个种子、单次运行 37.9 s；没有调特征集合、近邻数或阈值分位。
