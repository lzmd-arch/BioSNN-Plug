# 预注册：阶段五 M3i——STDP 侧向传播的自主触发（计划书任务 3）（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景

计划书 §七 第五阶段任务 3 要求实现「**STDP 侧向传播驱动的自主触发机制**（含背景噪声维持、
冲动检测、显著性阈值）」。M2 的 `TriggerPolicy` 是**规则门**（检索分阈值），不是脉冲机制；
M3i 补上这一块的最小实现。

## 机制（写死）

- 触发神经元群体 `N=64`，LIF：`v ← α·v + I − thr·z`（α=exp(−1/20)、thr=1.0、dt=1 ms）；
- 输入：`I_i = w_in·salience_t + b + ξ_i`，`ξ_i ~ N(0, σ_bg²)`（背景噪声，σ_bg=0.05），
  `b=0.02` 是背景电流（维持低发放）；
- **侧向 STDP**：同一时刻群体内若多个神经元发放，彼此**抑制**（权重 `W_lat` 为负）；
  对「连续两步内同向发放」的配对做 STDP：`W_lat[i,j] ← W_lat[i,j] + η·(z_i^{t−1}·z_j^t − z_i^t·z_j^{t−1})`
  （因果对增强抑制、反因果对减弱），`η=0.01`，权重截断到 [−1, 0]；
- **冲动检测**：群体发放率 `r_t` 超过其慢均值 `μ_t`（EMA，τ=200 ms）加 `k·σ_t`（EMA 方差）
  时记一次「冲动」；
- **显著性阈值**：冲动持续 ≥ `n_hits=5` 个时间步才触发一次 LLM 调用；触发后 200 ms 冷却。

## 协议

- 合成显著性流：10,000 步（10 s）；前 3 s 只有背景（无事件），之后在 t=3000/5000/7000/9000
  各注入一次持续 300 ms 的显著性脉冲（salience=0.5，其余 0）；
- 输入编码：`salience_t` 按概率 `p = salience_t` 给每个神经元一个伯努利脉冲（确定性随机流）；
- 对照：规则门 `TriggerPolicy`，对同一流用阈值 0.25（salience > 0.25 且冷却 200 ms）；
- 5 个种子（编码与噪声的随机流）。

## 判据（5 个种子全过才 `m3i_ready=true`）

1. **命中**：4 个显著性事件中 ≥ 3 个在注入后 **200 ms** 内触发；
2. **误触发**：前 3 s 基线（无事件）内的触发数 ≤ **1**；
3. **确定性**：同种子重跑，触发时刻逐位相同；
4. **不劣于规则门**：命中数 ≥ 规则门命中数（同种子），且误触发数 ≤ 规则门 + 1。

任一不过 → `m3i_ready=false`，负结果保留，不调阈值/噪声。

## 边界

- 显著性流是合成的；不外推到真实对话；
- 侧向 STDP 只作用在触发群体内部，不跨模块；
- 这是**协议层**实现，不是生物学上完整的侧向传播。
