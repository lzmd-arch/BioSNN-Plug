## 读数

1. **闭环状态预测非常好**：H=10 比 `copy_last` 低十个数量级；误差从开环 5e-10 涨到
   闭环 2e-8（约 40×），但仍在 1e-8。CartPole 的近线性动力学让 ridge+quadratic 几乎
   完美。
2. **闭环在约 115 步后发散**（NMSE>0.5）：H=10 的"很准"不能外推到长回合；P3 的核心
   读数就是这个 horizon。
3. **终止预测弱**：AUROC ~0.60–0.63，低于 0.75。终止是边界/稀有事件，线性-二次回归
   的分数排序不好；这不是闭环失败，是**终止头**的模型问题。按预注册不调 λ/不换模型，
   记为 P3 未 ready；后续可用神经世界模型或专门的终止头（新预注册）。

## 结论

**P3 部分通过**：闭环状态预测 ✅、不瞬崩 ✅、终止预测 ❌。`p3_ready=false`。
不调参、不换模型、不挑种子；终止头/神经世界模型作为 P3 的后续开放项。
