## 三个量

**(A) 相对差驱动** `r(s)`。对状态 `s`，编码 `p(s) = encode_state(s)`（每特征每步的发放概率），
每步每列的期望输入 `in_j(s) = Σ_i W[j,i]·p_i(s)`；定义

```
r(s) = (in_0(s) − in_1(s)) / ((|in_0(s)| + |in_1(s)|) / 2)
```

分母取**绝对值**：突触权重有正有负，两列驱动的带符号均值可以是负的甚至过零，
用它做分母会让 `r` 在过零点附近发散或恒为 0（冒烟实现时踩到过这一条，判据未跑前修正）。

`A_spread` ＝ 21 点网格上 `r` 的极差；`A_axis` ＝ 四条轴上各自极差的最大值。

**(B) 工作点传递曲线**。中性状态（全 0）把编码特征整体乘 `g ∈ {0.25, 0.5, 0.75, 1, 1.25, 1.5, 2}`，
每列记 20 窗口的平均后突触计数；`B_range` ＝ 每列计数在整条增益曲线上的**动态范围**（max−min），
两列取小的。**不假设单调**：权重有正有负，输入放大后可能把膜电位压到阈值以下（冒烟时见过
0.25× 有 2.15 计数、≥0.75× 完全沉默），所以只报动态范围。

**(C) 差分方向放大**。`c = (w_0 + w_1)/2`，构造 `w_j^(m) = c + m·(w_j − c)`，再把每列重新
L1 归一化到原值（保持总驱动量级不变，只放大差方向），`m ∈ {1, 2, 4, 8, 16}`。对每个 `m`
在 21 点网格上量 `Δ` 的极差 `C_range(m)`。

**(D) 随机方向对照（不作判据）**。取 5 个与 `Δw` 同范数的随机方向（固定种子），算同样的
21 点 `r` 极差，报中位数；用于判断「训练出来的差方向」是否与随机方向不同。

## 判据 / 判定表（先写死，逐种子判，再汇总 ≥3/5）

| 条件 | 阈值 |
| :--- | :--- |
| **A 成立**（差方向随状态变） | `A_spread ≥ 0.05`（相对差驱动在整段极角上变化 ≥5%） |
| **B 饱和**（工作点无响应） | `B_range < 1.0` 计数（整条增益曲线上计数几乎不动） |
| **C 成立**（差方向能表达） | `C_range(16) ≥ 0.5` 计数（放大 16 倍后网格极差跨过半计数） |

**判定（逐种子，≥3/5 一致才成立）：**

- A 不成立 → **`no_differential_direction`**：训练学到的差方向本身几乎不随状态变。
  修法在初始化/归一化/规则，不在温度；
- A 成立且 C 不成立 → **`lif_saturated`**：差方向存在，但输出层对输入不敏感（B 应同时
  显示饱和）。修法在工作点/阈值/发放率；
- A 成立且 C 成立 → **`amplitude_too_small`**：方向可表达，训练学到的幅度太小。
  修法在学习率/归一化 / 学习信号；
- A 不成立且 C 成立 → **`other_unattributed`**：不硬归因，只记录。

`B_range` 只作交叉验证（应支持 C 的结论），不单独作为判据；C 的放大是**构造性探针**，
「放大后能表达」不等于「模型本来就能表达」，报告里必须写这句边界。

## 不做什么

- 不把「放大后能表达」写成「问题就是幅度」——那只在 A 成立时才成立；
- 不因为 `m=16` 有效就建议照抄放大 16 倍（放大是诊断探针，不是方案）；
- 不因为一个种子成立就写 ready。
