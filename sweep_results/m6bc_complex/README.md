### C-1 那个"过"必须带注记

门槛是 **+0.15**，σ=0.02 给 **+0.151**，余量 **0.001**；而 σ=0.3 给 **+0.148**，
差 0.002 反而不过。**按字面是过，按余量是不可分辨。**

更结实、也更诚实的说法是逐种子：

| 臂 | 逐种子差（6 个） | 变好的种子 |
| :--- | :--- | ---: |
| σ_ω = 0.02 | −0.013 / +0.115 / +0.174 / +0.120 / +0.214 / +0.297 | **5/6** |
| σ_ω = 0.1 | +0.055 / −0.068 / +0.253 / +0.169 / +0.138 / +0.039 | **5/6** |
| σ_ω = 0.3 | +0.086 / +0.234 / +0.005 / +0.049 / +0.367 / +0.146 | **6/6** |

⇒ **方向是一致的（三档都是 5–6/6 个种子变好），幅度是 +0.10～+0.15 量级。**
把它写成「稳定超过实值基线 0.15」是夸大；写成「一致为正、幅度约 +0.1～+0.15、
单档卡在判据线上」是准确。

## 三、这一轮真正的强结果：**信息在相位里**

**相位增益 +0.475 ～ +0.525，三档剂量全都这么大。** 这条不依赖剂量、不卡线。

控制的做法是：对每个（样本，神经元）**独立随机旋转**脉冲相量（`|z|` 逐位保留），
再跑同一个探针。掉幅 +0.51 意味着**一半以上的可读性来自相位关系**。

⇒ **复值臂不是"多了一倍实数维度"——是"多了一个实值网络根本不存在的坐标"。**

## 四、一条计划外的观察（未预注册，只登记不下结论）

**σ_ω > 0 时线性读出从 0.086–0.250 跳到 0.273–0.742。**

实值基线六种子的线性读出是 **0.086 / 0.133 / 0.148 / 0.172 / 0.125 / 0.250**，
必须靠 MLP 才到 0.488。复值臂里线性读出单独就能到 0.3–0.74。
⇒ **复值动力学把状态从「必须非线性读出」变成「线性可读」。**
这条与 §36「读出方式的影响比机制更大」直接相关，但它没有预注册，**只作为观察登记**。
