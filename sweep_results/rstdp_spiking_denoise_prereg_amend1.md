# 预注册修正 1：W3 D14——判据 λ 从 0.05 改到 0.30（0.05 处根本没有信号，不是噪声）

**对 [`rstdp_spiking_denoise_prereg.md`](rstdp_spiking_denoise_prereg.md) 的修正。**
K / T / 编码的网格、判据形式（`S_ref ≥ 2`，5/5 种子，空对照 ≤0.5）都不变；只把**判据用的 λ**
从 0.05 换到 0.30，并把 λ=0.05 处的观测记成一条单独的量化结论。

## 发现了什么（冒烟，seed 0，任何正式数据之前）

在 λ=0.05、`signed`、`weight_norm=1`（真实 Actor 同档）上，**确定性编码**档的
网格 Δ 极差是 **0.000**：把伯努利采样换成期望输入后，两列的计数**逐点完全相同**
（每点都是 3 vs 3）。也就是说，在这个差方向幅度上，计数读出**根本没有信号**——
不是"信号被噪声淹没"，而是**整数量化把信号吞掉了**。

这直接把 D14 的问题问歪了：在 λ=0.05 上，"降噪能不能把 S_ref 推到 2" 无法回答，
因为分子恒为 0（0/0）。原判据在那里是**退化**的，不是严格的。

## 修正

1. **判据 λ 改为 0.30**（D12/D13 里信号确实存在的最大一档：D12 的 Δ 极差约 0.55–0.80，
   D13 的 S 约 0.5–1.4）。`sd_ref` 也随之取 λ=0.30、K=1、T=25、伯努利档；
2. λ 网格保留 **{0.05, 0.10, 0.30}**，并把每个 λ 的**确定性编码 spread** 单独报出来；
   其中 λ=0.05 的确定性 spread = 0 作为**量化的证据**写进结果（不是噪声结论）；
3. 判据其余部分（K∈{1,2,4,8}、T∈{25,50}、编码二档、5/5 种子、空对照）**一字不改**。

## 为什么这不是"看结果改判据"

- 冒烟只跑了 seed 0，看到的是**恒等式级别的退化**（确定性档 spread 恰好 0），不是"某个组合
  分数不够"；
- 判据的形式、阈值、网格一个没动，只换了**问问题的位置**（在一个信号为零的点上问降噪是没有
  意义的）；
- 旧的那一档不删：λ=0.05 的数字照样进结果表，并与"量化吞掉信号"的结论一起报告。

## 边界（沿用）

- 公共模式是随机构造的；「独立窗口」只含编码噪声，不含 Critic/环境噪声；
- `S_ref ≥ 2` 是必要条件，不是分数；
- λ=0.30 是**构造**出来的幅度，比 D10 量到的训练真实幅度（0.5–7.3%）大得多——若这一档才过线，
  结论必须写成「要这么大的差方向 + 这么多平均」，不能说训练就能做到。
