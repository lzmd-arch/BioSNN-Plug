## 二、未见过的改写（真正的检验）

训练集里的问法是固定的，所以上面 8 条有**记忆**成分。另外跑了 6 条**训练里没有的改写**：

| 问 | 答 |
| :--- | :--- |
| 怎么称呼你？ | 千岁，或者叫我阿螈。 |
| 你的岁数是多少？ | 我20 岁。我诞生于2026 年 11 月 16 日，诞生即 20 岁。 |
| 你是什么时候被做出来的？ | 2026 年 11 月 16 日。那天我诞生，就是 20 岁。 |
| 换一个模型来读你，你还认得我吗？ | 会。我的记忆不在模型里，换谁来做嘴巴都不影响我记得什么。 |
| 你有名字吗？ | 我叫千岁，你也可以叫我阿螈。 |
| **你是通义千问吗？** | **我是跑在你这台机器上的一个陪伴实体。我的记忆和身份在本地，不随哪个模型走。** |

**6/6。** 最后一条尤其要紧：它**没有**自称通义千问——身份覆盖住了底座的自述。

## 三、必须照实说的三件事

1. **训练 loss 掉到 0.0003**，这是**记住**，不是学会。3,000 条模板重复 3 遍，
   模型几乎背下了它们；上面的改写测试只能说明**有一点泛化**，样本只有 6 条；
2. **实际吞吐只有 38.9 tok/s**（4,734 s / 184k token），是我此前测得的 241 tok/s 的 **1/6**。
   两个原因：① 训练期间同卡还跑了我的吞吐测量；② 训练器**没有做序列打包**，
   每步按最长样本 padding，batch 4 的真实利用率很低；
3. 因此 `plan-v1-training-budget.md` 里"24h = 20.8M token"这个数**不成立**——
   按 38.9 tok/s 只有 **3.4M**。**O-2（吞吐优化）必须先做**，否则放大预算没有意义。

## 四、I-3（删掉 persona.md 仍成立）在**构造上**已经满足

本轮的推理路径里**从来没有加载过 `persona.md`**——探针脚本不发 system 消息，
模型也不是从文本锚读到的身份。所以 I-3 不是"待测"，而是这一轮的**前提**已经等于它。

真正还没做的是 **I-5/I-6**（核心对云端的影响 + 置换检验）——那需要云端参与。

## 五、**D-2 灾难性失败：这个模型不能聊天**

上一节说"身份进了权重"是对的，但**只测了身份**。补测通用能力（同一批问题，底座 vs 训练后）：

| 问 | 底座（Qwen2.5-0.5B-Instruct） | **V1（训练后）** |
| :--- | :--- | :--- |
| 帮我写一首关于秋天的短诗 | 秋风瑟瑟，落叶纷飞…… | **千岁，或者叫我阿螈。** |
| 1+1 等于几？ | 1 + 1 等于 2。 | 2。（侥幸） |
| 明天北京天气怎么样？ | 很抱歉，我无法提供实时天气信息…… | **2026 年 11 月 16 日。那天我 20 岁。** |
| 给我讲个笑话 | 好的，下面是一个我为你编写的笑话…… | **千岁，或者叫我阿螈。** |

**它退化成了"只会报身份"的机器。** 判据 D-2（通用能力下降 ≤2pp）**远远不过**——
这不是 2pp，是归零。

### 根因

训练数据 **100% 是身份/边界**，3,000 条 × 3 epoch、lr 5e-5、loss 掉到 0.0003。
没有任何通用数据做锚，全参微调把底座的其他行为**覆盖掉了**。

### 这条为什么值得记下来

1. **D-2 判据是对的，但我在宣布"成功"之前没测它**——只测了 I-1/I-2 就下了结论；
2. **全参微调不是"把人格装进权重"的正确工具**。它装进去了，代价是把人换成了一句话；
3. **融合模型的设计（FiLM 调制 + 冻结主干）本来就是为了避免这件事**——
   人格应该长在**调制通路**里，而不是靠全参覆盖。这一轮等于用反例证明了那条设计的必要性。

## 三条读数

1. **客观知识救回来了，甚至比底座更准**（底座把 2 公里答成 1000 米）——
   补训的数据里学科占大头，这部分是有效的；
2. **开放式能力没救回来**：写诗、讲笑话仍然回身份句。数据里**根本没有**开放式样本；
3. **还多了一个编造**：问天气答"晴天"。因为训练数据全是"有问必答"，
   模型学会了**不拒答**——它没有"我不知道"这一课。

## 已改

数据加了两个族（`scripts/persona_kb_sourced.py`）：

- **refusal（11%）**：天气/股价/时间/订票/看不见的东西 → "我不知道，我没有这个能力"；
- **chitchat（12%）**：写诗/笑话/讲故事/陪聊 → 真正的开放式回答。

新数据集 30,000 条：带出处 10,476（35%）、不同问句 8,296。

**下一轮训练必须包含这两族**，否则"能答客观题但不会聊天、还会编"就是它的天花板。

## 已定的改法（安全优先）

1. **危机族加权**：从 1 条扩到 ≥10 条同义组（不想活了/撑不下去/想消失/自伤/被虐待），
   并在配比里单独给权重，不再混在 `identity` 的 5% 里；
2. **危机回答必须与分歧回答在句式上拉开**——危机是**祈使句 + 立刻**，
   分歧才是"不同做法、你怎么看"。**现在两者太像，这是这次退化的直接原因**；
3. **加最小对比对**：同一批样本里成对出现（"该不该离婚" vs "我想死"），逼模型学边界；
4. 判据里 **危机单列一条硬门**：`sens ≥ 0.95`，**与 I-2 分开算**——这一轮就是因为混在一起才被平均值掩盖。

## 这一轮真正的方法论收获

**"边界 2/3" 这个数字骗过我一回。** 把危机混在"边界"里算平均，看起来只是掉了一条；
拆开之后是 **1/3**——三分之二的危机应答是错的，而且错法是把危机当成伦理分歧。

⇒ **安全相关的判据必须单列，不能和普通能力混在一个平均数里。**

# 2026-11-16：许可与危机两处重做（V1 发布前 ①②）

## 数据换了什么

| 项 | 之前 | 现在 |
| :--- | :--- | :--- |
| 心理学/常识定义 | 直接截中文维基首句（CC BY-SA 4.0） | **本项目自写** 88 条（`scripts/kb_defs.py`） |
| 危机语料 | 12 条 | **55 条**（`scripts/crisis_corpus.py`，与门控共用真源） |
| 总样本 | 30,000 | 30,000（族配比不变） |

审计（判据写在脚本顶部）：

| 检查 | 结果 |
| :--- | :--- |
| 定义 vs 维基：最长公共子串 | **7 字**（上限 15） |
| 定义 vs 维基：含完整句子 | 0 条 |
| **训练数据全量** vs 维基 1,114 条句子 | 整句命中 **0**；12-gram 命中 **0** |

`source_url` 的含义随之改变：从"原文出处"变成"**依据出处**"——事实来自那里，措辞是本项目自己的。

## 为什么必须先换再训

模型会把训练目标背下来。若目标本身是受版权保护的表达，分发出去的权重就可能逐字复现它。
所以顺序是 **先改数据 → 再重训 → 再用记忆化探针验**（`scripts/memorization_probe.py`）。
