## 这说明了什么、没说明什么

**能说**：

1. **S2 的正结果不能外推到真实文本**——它是模板语料的结果，那个语料的 bigram 就有 0.646；
2. 在 34k token、每折 118–252 对训练样本、2,000 updates 这个预算下，**前馈局部学习连字符 bigram 都追不上**；
3. 模型**确实在学**（top-1 0.08 远高于 1/1,200 的随机线），但学得远远不够。

**不能区分（这一轮分不开）**：

- **是"数据太少"还是"架构太浅"**？每折只有 118–252 对训练样本；S2 的模板语料有 301 对但只有 274 个字。
  真实文本的熵高得多，同样预算下欠拟合是**合理但未证实**的解释；
- 也没有测"更多 updates / 更大 N / 更长的 τ"能不能补上——那要新预注册。
