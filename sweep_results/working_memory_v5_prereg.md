# 预注册：多时间尺度工作记忆 v5——LIF / ALIF 脉冲实现（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v4 的 ready 依赖**速率漏积分器**；
v5 把它换成脉冲群体：每个 τ 一组 LIF/ALIF 单元，身份输入、无循环权重，读数是脉冲计数 +
局部 RLS。任务/三线索/τ/判据与 v4 完全相同。

## 机制

```text
每个 τ ∈ {2,5,10,20,50,100,200}：一组 n_dims=4 个 ALIF 单元
  输入： cue 值 → p=clip((cue+3)/6,0,1) 的伯努利脉冲（每步重采样）
  动力学：ALIFCell（w_in=I、w_rec=0；LIF 档 beta=0，ALIF 档 beta=0.1）
  读数：60 步内的脉冲计数（每个单元一个数），共 7×4=28 维
读出：局部 RLS（λ=1、δ=1000），逐样本 20 epoch（与 v4 相同）
```

- 两臂：**LIF（beta=0）**与 **ALIF（beta=0.1）**；阈值/τ/输入编码/读出全部固定；
- 单尺度对照：fast(τ=2)、mid(τ=20)、slow(τ=200) 各自的 4 个计数；
- 任务/线索/噪声/训练测试规模/判据与 v4 完全一致。

## 判据（与 v4 相同，先写死）

1. 多尺度 A/B/C 的 R² 都 ≥0.50；
2. 快 τ=2 的 A <0.30；
3. fast/mid/slow 各自至少漏一个线索；
4. **不因脉冲化退化**：该臂三线索平均 R² ≥ v4 的 **0.9990 − 0.10 = 0.899**；
5. 任一臂四条全过 → `v5_ready`；否则报边界，不调 τ/beta/阈值/编码。

## 不做什么

- 不调 τ/beta/阈值/输入编码/读出；不换任务/判据；
- 不做学习型循环权重；不做 e-prop 训练（只做读出）；
- 不把 v4 的速率成绩混进脉冲列；两臂都报。
