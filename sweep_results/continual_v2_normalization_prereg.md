# 预注册 v3：CL 归一化臂（2026-10-26）

**定稿时间：2026-10-26，在本轮归一化数据之前。** ACC / AF 的定义与 CIL 口径不动；
机制顺序按 ADR-0017 与预注册 v2：回放 → 归一化 → 参数隔离，**一次只上一个**。

## 为什么现在轮到归一化

回放臂的结果（[`continual_v2/README.md`](continual_v2/README.md)）：ρ=0.3 把 AF 从
0.8047 拉到 0.7399、ACC 从 0.2466 抬到 0.3630——**方向正确，幅度差一个数量级**。
按预注册 v2，**不回头调 ρ、不改判据**；下一机制是归一化。

## 机制：输入的固定对角标准化（唯一机制）

设任务 1 的训练特征为 `x`（10 000 条 × 512 维），逐维统计：

```text
mu_j = mean_i x_ij
sd_j = sqrt(mean_i (x_ij − mu_j)²)
```

变换（`eps = 1e-6`）：

```text
x̃_ij = (x_ij − mu_j) / max(sd_j, eps)
```

**写死的规则**：

- 统计量**只由任务 1 的训练特征**算出；任务 1 结束后**冻结**，后续任务不再更新；
- 同一组 `mu` / `sd` 应用到**所有任务**的训练与测试特征；
- 不改学习率、epoch、minibatch、初始化、种子、类顺序；
- 不改读出的规则（仍是 delta），不加回放、不加正则。

**为什么不是每任务重估统计量**：那样旧类的权重会在"旧样本的表示被换掉"之后继续被使用，
结果无法归因到归一化本身；**为什么不是全协方差白化**：它把方向整体旋转，与对角标准化
不可分离，而且 NCM 的白化已经覆盖了协方差那一支。

### 两个臂（同一机制的两个刻度）

| 臂 | 变换 | 作用 |
| :--- | :--- | :--- |
| **N1** | 上面的 `x̃` | 主臂：逐维标准化 |
| **N1-scale** | `x̃` 再乘标量 `s`，使任务 1 训练特征的**平均行范数**等于原始特征的 | 控制臂：把整体梯度尺度对齐，只留逐维几何变化 |

单列 N1-scale 的理由：N1 同时改变了"逐维尺度"和"整体步长"，两者都会改变结果。
控制臂用任务 1 的平均行范数把整体尺度对齐，于是两臂之差可以归到**几何**而不是步长。

参考臂：**R-delta-mini**（预注册 v2 修订 1），ACC **0.2466**、AF **0.8047**、
`void_seeds = []`。

## 固定协议

| 项 | 取值 |
| :--- | :--- |
| 特征 | 冻结 ResNet18（ImageNet1K V1，avgpool 512 维），CIFAR resize 224 |
| 数据 / 切分 | CIFAR-100，10×10，按类 id 升序，**全量**（不限每类张数） |
| 评估 | **CIL**：样本按任务切、argmax 在全部已见类、不提供任务 id |
| 读出 | delta 线性，η = 0.01，每任务 20 epoch，minibatch B = 128 |
| 回放 | **无**（ρ = 0） |
| 种子 | 0–4（与 Step 0 / 回放臂相同） |
| 跑门 | 每任务 `‖ΔW‖ / max(‖W_before‖, 1e-12) ≥ 0.05`；低于则该种子作废并报 `void_seeds` |

## 判据（先写死）

1. **阶段门（不变）**：AF < 8% 且 ACC ≥ 65%；
2. **机制信号（本轮新增，只用于判断"这个机制值不值得叠加"）**：
   - 相对参考臂 **AF 至少下降 10 个百分点**，且
   - **ACC 不低于参考臂 − 1 个百分点**；

   两个臂都要报；任一条不满足，该臂判 `no_signal`；
3. 跑门照旧，作废种子数必须写进 summary，不进入均值。

机制信号**不是**阶段门的替代：两者分开报，避免用"相对改进"掩盖绝对不达标。

## 判读表（先写死）

| N1 | N1-scale | 结论 |
| :--- | :--- | :--- |
| 过 | 过 | 逐维几何与整体尺度都可能贡献；下一步把它与回放叠加（**新预注册**） |
| 过 | 不过 | 增益依赖整体尺度的变化，不是逐维几何；不按几何去叠加，先单独复核步长 |
| 不过 | 过 | 几何有效，但 N1 的步长副作用抵消了它；下一步用 N1-scale 叠加回放 |
| 不过 | 不过 | 归一化不是这个瓶颈的杠杆；按 ADR-0017，下一机制是参数隔离 |

（"过" = 机制信号的两条同时成立；阶段门另外报。）

## 不做什么

- 不加回放（已单独测过）、不调 ρ、不调 η、不换 batch / epoch / 种子；
- 不试第三种归一化（全协方差白化、每任务统计、逐行 L2 各自需要新预注册）；
- 看到结果后不改判据、不换参考臂、不换种子；
- 不改写 Route W 的任何数字。

## 实现（代码先于数据落地，单独提交）

- `research/continual/run_continual.py` 增加
  `--normalize {none, task1-standardize}` 与 `--normalize-scale {native, match-task1}`；
- 统计量在任务 1 的训练特征上算一次并冻结；测试特征用同一组统计量；
- 守卫测试：
  (a) 统计量只由任务 1 决定——把后续任务的样本喂进去，变换不变；
  (b) 变换后没有 NaN / Inf；
  (c) `--normalize none` 的路径逐位不变（与 `git show HEAD:` 的版本同种子对比，
      不用 stash）；
- 跑前工作区必须干净（含未跟踪文件）；产物先落 `data/`，跑完再搬进 `sweep_results/`。
