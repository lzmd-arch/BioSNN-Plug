# 预注册：W3 D6——脉冲策略的温度标定（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（已由数据指出）

- D4：训练后的 Actor 在极角网格上动作恒定（10 种子 slope 全 0）；
- D5（在跑，seed 0 已出）：末期熵 **0.001 nats**、窗口沉默 0 → 指向**熵坍缩**；
- 代码层面：`cartpole.py` 的温度调度 `logit_scale 1 → 40` **只对 `policy="linear"` 生效**，
  脉冲 Actor 的 `logit_scale` 全程固定 **1.0**；而策略 logits 是窗口脉冲计数（0–25），
  `softmax(1.0 × counts)` 在计数差 5–10 时已经接近 one-hot。
  **这是「训练一开始就几乎贪心」的结构性原因，不是调参偏好。**

## 要做的事（只改采样温度）

给脉冲 Actor 加**温度调度**：`logit_scale` 从 `start` 指数降到 `end`（与线性策略同一形式），
其余（资格、Critic、更新规则、回合数）完全不变。三个臂：

| 臂 | start | end |
| :--- | ---: | ---: |
| A（对照） | 1.0 | 1.0 |
| B | 0.1 | 0.02 |
| C | 0.03 | 0.01 |

10 种子、800 回合、count-aligned、CPU；每臂独立跑。

## 判据（先写死）

**臂级判据**（三条都要）：

1. 末期 100 回合平均熵 ≥ **0.30 nats** 的种子数 ≥ **7/10**；
2. 末次评测中位 ≥ **30 步**（对照是目前 9.5）；
3. 极角 slope > 0 的种子数 ≥ **7/10**（D4 的探针，改用同一实现）。

**选择规则**：按末次评测中位选最好的臂；若**没有任何臂**同时满足三条 →
`temperature_fix_ready=false`，负结果保留，不再调温度。
