# D2：两层 LIF + 全局部规则 —— **判负**（2026-11-11）

**问题**：1B 模型的参数该**放深**（多叠几层）还是**放宽**（单层 + 大读出）？
预注册：`research/sel/prereg-lm-d2-depth.md`。

## 一、两臂都崩，而且不是"没学够"

同折、同分词、同截断、同预算（4,000 步、2 抽头、batch 16、KdConv），对照是
**单层**同配置：top-1 **0.2451** / CE **4.4175**。

| 臂 | `w12_scale` | top-1 | Δ vs 单层 | CE | 第 2 层发放（spikes/样本/步，÷1024 是比例） |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 首轮 | 0.4 | 0.0132 | **−23.2pp** | 13.81 | 278（27%） |
| **重跑（w12 归一化）** | 0.2 | **0.0142** | **−23.1pp** | 6.71 | 51（**5.0%**） |

**预注册判据**：D2-1「top-1 不低于单层 −2pp」⇒ **严重不过**（差 21pp）。**深度这条轴关闭。**

## 二、重跑做了两处修正，都没救回来

首轮的问题有两个：(a) `w12` 初始化没归一化；(b) 第 2 层电流尺度未标定。重跑都修了：

- `w12` 按 1/√N 归一化，`w12_scale` 0.4 → **0.2**；
- 起点确实变好了：**第 1,000 步 top-1 0.0573**（首轮同点是 0.0097，差 6×）；
- 但第 3,000 步开始**塌**（0.0545 → 0.0096 → 0.0142），同时第 2 层发放从
  **3.3 涨到 51.0（≈16×，即 0.3% → 5.0%）**。

**CE 与 top-1 在这一臂上分了岔**：CE 从 8.02 降到 6.71（比单层的 4.42 仍差），
top-1 却从 0.0545 掉到 0.0142。**分布变平、排序崩掉**——不是过拟合，是表示退化。

## 三、四问限定语（缺一条不许进结论）

1. **是预算截断吗？** 不是。4,000 步内已经**越跑越差**（第 3、4 个点 top-1 掉 4×），
   加预算只会更差；这条不是下界，是失败。
2. **是跨语料 / 跨预算比较吗？** 不是。同折、同语料、同 4,000 步、同 2 抽头，
   对照臂就是单层 0.2451 / 4.4175。
3. **是单边指标吗？** 不是单边：top-1 与 CE **两边都输**（−23.1pp / 6.71 对 4.42）。
4. **cos 先验兑换成 Δ 了吗？** 不适用（这条不走梯度余弦）。

## 四、这个负结果决定了什么

**1B 的参数必须放在宽度上（单层 + 大读出），不能靠叠层。**

这与已有证据一致：S11 说隐层学习值 7.8pp（它有用，但只在**一层**里有用），
A9 说线 A 去掉递推 +0.5pp，R3 说绑定 Δ 的是**读出宽度**不是神经元数。
D2 补上的那一块是：**再叠一层，局部规则连单层都保不住。**

留给后续的诚实注记：
- 这里只有 **2 层**，没有扫 3–4 层；但失败方式是"第 2 层发放失控 + 表示退化"，
  不是"层数不够用"，所以先不往深处加；
- 第 2 层用了与第 1 层相同的 e-prop 形状（`eps_z1` 归一化的 Hebbian 式更新），
  没有试过给第 2 层单独的稳态机制（ALIF / 抑制）——**若要重开这条轴，
  第一步必须是稳态机制，不是调 `w12_scale`**。
