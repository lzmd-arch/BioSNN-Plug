# 预注册：跨模态检索 R@1（第二阶段那条唯一还是 ❌ 的验收线）

**定稿时间：2026-10-17，在这条实验的任何数据之前。**

## 它要回答什么

计划书 §七 第二阶段：「跨模态检索 **R@1 50%+**」。README 的现状表里这一格是 ❌，
写的是「缺数据集与协议口径」。指标模块 `research/retrieval/metrics.py` 已就位，
缺的是**表示**：两条模态各自编码之后，凭什么落到同一个空间里比余弦？

## 先说清楚一件事：直接比较是不成立的

⚠️ **`biosnn-bus` 的两路输出不是同一个空间。** 图像走 `semantic` 通道、文本走
`temporal` 通道，**每一路各自**经过一个独立种子的稀疏随机投影投到 `bus_dim`
（`SpikeBus._projection_for(..., key=(name,))`）。只有文本时输出是
`P_text·x_text`，只有图像时是 `P_image·x_image`；两个随机矩阵互不相干，
**余弦的期望是 0**。所以「把两路输出直接拿来比」的 R@1 必然落在随机水平——
这不是实验失败，是这套接口的性质，**必须先说在前面**，否则跑出 2% 会被误读成"编码坏了"。

因此这一格要验的命题不是"总线的投影矩阵碰巧对齐了"，而是：
**一层纯局部的联想规则，能不能把两路投影接起来。**

## 设计（先写死）

### 数据集：程序生成配对集

| 维度 | 取值 |
| :--- | :--- |
| 形状 | square / circle / triangle / cross |
| 明度 | dark / medium / bright（画布灰度 0.35 / 0.65 / 1.0） |
| 位置 | 3×2 网格，六个方位词 |
| 尺寸 | small / large（边长 4 / 6 像素，画布 24×24） |
| 组合总数 | 4 × 3 × 6 × 2 = **144** |

caption 模板：`a {size} {shade} {shape} in the {position} of the image`。
**每个组合只对应一条 caption，配对是同一性**（`metrics.recall_at_k` 的约定）。

* 训练/测试按 **80/20** 切分，训练集拟合联想规则，测试集上算 R@1；
* **R@1 的随机基线 = 1 / 测试集条数**（约 29 → 3.4%），不是 1/144；
* 验收线 **50%** 对的是测试集。

⚠️ **这个数据集是合成的，不能用来对标文献**。它验的是"这条管线能不能跨模态对齐"，
不是"我们的方法在 COCO 上多强"。Flickr8k 的加载器同期实现，但**这一轮不跑**
（约 1 GB 下载 + 许可逐项核，与"一次基准运行"的范围不符），跑的时候另立预注册。

### 表示（两种读法，与 `metrics.py` 的文档一致）

| 读法 | 表示 | 用途 |
| :--- | :--- | :--- |
| (a) 编码质量 | 各插件**自身**的发放率向量（图像 2·24·24，文本 256），做**同模态**检索 | 对照：编码本身有没有保住身份 |
| (b) 总线接受度 | 总线输出 `(T, bus_dim)` 沿时间取均值 → `bus_dim` 维 | **验收线** |

### 联想规则（本实验新增的唯一可学习部件）

**Hebbian 外积联想**，无反向传播、无梯度：

```text
W ← (1 − λ)·W + η·Σ_i  v_i ⊗ t_i        # t_i 是文本侧总线表示，v_i 是图像侧
```

* `η` 学习率、`λ` 遗忘（ridge），两个标量；
* 推理：文本 → `W·t` → 与所有图像侧表示比余弦 → 排序；
* 反方向同理：**图像侧用一个独立的 W'**（`v → t`），不假设联想矩阵对称。

参数 `η`、`λ` **在训练集上用留一法选**，测试集不参与任何选择。

### 判据

* 两个方向（text→image、image→text）都报 R@1 与 R@5，**headline 取两者均值**；
* 报 (a) 作对照；
* 报**未训练**的联想（`W=0` → 查询无表示，等价随机）作下界；
* 种子 5 个（0–4），影响文本群体的偏好方向与总线投影；**报每种子结果与均值**。

## 这份预注册**不**声称什么

* 不声称 50% 一定达到。**达不到照样报**，并写清是编码、联想还是融合的问题。
* 不声称联想规则是"最优"的局部规则——它只是第一个能把这个设计讲通的规则。
* 不把 (a) 的高分当作 (b) 的证据：(a) 高只说明编码保住了身份，说明不了跨模态。

## 边界情况（先说好）

* 文本 embedding 走本机 Ollama 的 `nomic-embed-text`（冻结前端，许可与边界见 §2.3）；
  **token 级 embedding 缓存到磁盘**，否则每次运行重复调用。
* 若 Ollama 不可用，**实验不跑**，不退回假后端充数——那会让 R@1 失去所指。
