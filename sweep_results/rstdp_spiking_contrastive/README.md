## 读法

1. **去共模确实把差方向做大了**：γ=0.1 时末期 `mean Δ` 的极差中位从 **0.20 抬到 0.60**，
   逐种子从 0.0–0.8 变成 0.4–1.0——这是 D10 设想的那条杠杆，**它生效了**。
2. **但贪心还是不看状态**：三个臂的极角 `slope` 都是 **0/10**（只有两个种子出现 −0.2）。
   也就是说，`Δ` 的**幅度**变大了，`Δ` 的**符号**仍不随状态变——argmax 还是常数偏好。
3. **末次评测一格没动**：9.50 / 9.50 / 9.60。把幅度做大、把符号的分布不变，成绩就不会变。
4. **γ 太大有害**：γ=0.5 时 `best_steps` 均值从 39.4 掉到 **13.1**，峰值几乎全没了
   （逐种子 9.5–32.1）。共模成分不只是"偏置"，它还承载了让神经元正常发放的那部分驱动。
5. 与 D10–D15 拼起来：**差方向的幅度不是瓶颈，符号的状态依赖才是。** 对比项能改前者，改不了后者。

## 与预注册判据的关系

判据 2 只被 γ=0.1 满足，判据 1、3 三个臂全不满足 → 按预注册 `false`，负结果保留，
**不调 γ**（0.1 已过判据 2，继续在 0.1 附近细调等于在同一批种子上挑）。

## 边界

- 10 种子、800 回合、`best_steps` 的方差很大（γ=0 的 10.4–86.0），只报末次与中位；
- 探针只扫极角（其余状态为 0），slope 的定义是 `P(left|θ=+0.2) − P(left|θ=−0.2)`；
- 去共模项是**局部、无梯度**的启发式，不是 ESPP 原文规则的完整实现（只取「去掉公共成分」那一半）；
- 这次没测「去共模 + K 窗平均」（D14 的降噪）组合——那要新预注册。
