# 预注册：多时间尺度工作记忆 v8——脉冲迹读出（2026-10-28）

**定稿时间：2026-10-28，在本轮任何 v8 数据之前。** v7 的 ALIF 群体把 A/B 提到
0.718/0.858（均值 0.788），单尺度对照与脉冲率都成立，只差“不退化”线（0.899）。诊断
指向**复位擦除**：慢 τ 组自己只解出 A 0.379——早期 cue 被 B 窗口的脉冲复位永久扣掉。
v8 只改**读出量**为复位前的泄漏积分（脉冲迹），群体、增益、τ、阈值、任务、两臂与判据
全部与 v7 相同。

## 机制

```text
每个 τ、每个维度 32 个独立传入通道，驱动 ALIF 单元（与 v7 完全相同）
  v_t = α·v_{t−1} + I_t − thr·z_{t−1}          ← 有复位，脉冲照常发放
  trace_t = α·trace_{t−1} + z_t                 ← 与膜电位同 τ 的脉冲迹
  读出 = v_t + thr·trace_{t−1} = Σ α^{t−s} I_s  ← 无复位的泄漏积分
```

- 恒等式说明：复位项是 `−thr·z_{t−1}`，把 `thr·trace_{t−1}` 加回去就得到**无复位**的
  泄漏积分；读出量是脉冲驱动的突触后迹，不是模拟速率输入。
- 读出取最后 10 步、每个 (τ,维度) 的 32 个单元均值（28 维），局部 RLS（λ=1、δ=1000）。
- 两臂：**LIF（beta=0）**、**ALIF（beta=0.1）**；单尺度对照与 v7 相同。

## 判据（与 v4–v7 相同，先写死）

1. 多尺度 A/B 的 R² 都 ≥0.50；
2. 快 τ=2 的 A <0.30；
3. fast/mid/slow 各自至少漏一个线索；
4. **不因脉冲化退化**：该臂两线索平均 R² ≥ v4 的 **0.9990 − 0.10 = 0.899**；
5. 任一臂四条全过、且两臂脉冲率都 >0 → `v8_ready`；否则报边界，不调读出/群体/增益/
   τ/阈值/判据。

## 边界（预先写死，不许事后改口径）

- **v8 测的不是膜电位读出**：v6/v7 的膜电位路线仍是负结果；v8 的读出是复位无关的
  脉冲迹（等价于脉冲驱动的泄漏积分）。如果 v8 过线，只能写成“脉冲输入 + 局部迹读出”，
  不能写成“膜电位保持”。
- 迹读出让“读出对复位不敏感”，这不是把网络变成速率模型：脉冲仍由 ALIF 动力学产生，
  脉冲率要作为诊断报出；若不发放，`v8_ready` 直接为 false。

## 预先声明的诊断（不参与判据）

- 每个 τ 组的平均每神经元每步脉冲率（必须 >0）；
- 复位前/后膜电位的范围（同 v6/v7），确认复位确实发生；
- 与 v7 的膜电位结果逐项对照，差异只归因于读出量。
