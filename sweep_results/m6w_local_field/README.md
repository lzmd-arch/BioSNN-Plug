# M6w：**局部抑制造出高维状态 —— PR 2.52 → 61.32，但有一个混淆**

## 诊断在前

M6v 量到状态流形的内在维度只有 **PR ≈ 2.49**。瓶颈明确：抑制是**一个全局标量**
`−G_FIELD·φ`，对每个神经元完全一样 ⇒ 整个网络只能有一个活动水平 ⇒ 状态必然低维。

## 干预

`field_radius < 32` 时，每个神经元被**自己邻域**的平均活动压住。
半径越小，不同空间区域越能维持不同的活动水平。

## 结果（4 种子 × 8 族 × 16 条 = 128 个状态/种子）

| `field_radius` | **PR** | 发放 |
| ---: | ---: | ---: |
| **2** | **61.32** | 0.022 |
| 4 | 8.66 | 0.072 |
| 8 | 15.27 | 0.139 |
| 16 | 5.88 | 0.153 |
| 32（全局） | **2.52** | 0.153 |

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| W-0 发放在窗内 | 5/5，过 |
| **W-1 高维（半径 2 的 PR > 4）** | **61.32，过**（24× 全局场） |
| **W-2 剂量–反应（PR 随半径单调下降）** | **Spearman −0.90，不过**（`r=8` 的 15.27 高于 `r=4` 的 8.66） |

## 一、必须先说清的混淆：**发放率跨了 7 倍**

`r=2` 的发放是 **0.022**，`r=32` 是 **0.153**。而**安静的网络天然会有更高的 PR**
（发放低 ⇒ 神经元之间差异相对更大）。

⇒ **"局部场造出高维"可能只是"低发放造出高维"。** 在跑发放匹配的对照之前，
**这条不能当成机制证据。**

对照正在跑（同一半径两个输入增益 `scale ∈ {0.7, 1.4}`，看 PR 是否随发放塌下去）。

## 二、非单调那一段也可能是真信号

`r=4 → 8.66`、`r=8 → 15.27`。如果是纯噪声，不该有这种形状。
一个可能的解释：`r=4` 时邻域太小（81 个神经元里只有 13 个），抑制变成局部起搏而非调节；
`r=8` 是"能维持区域差异又不至于各自为政"的折中。**未验证。**

## 三、限定

- 4 种子；128 个状态；PR 是**下界**（但 61.32 远低于 128 的样本上限，不是被截断的）；
- 只扫了半径，**没有扫抑制强度**（`g_field` 固定 1.0）；
- `r=2` 时发放 0.022 贴在窗口下沿（窗口是 [0.01, 0.20]）；
- 高维 ≠ 有用。**M6x 在验"高维 + 可解码 + 停得住"三条是否同时成立。**
