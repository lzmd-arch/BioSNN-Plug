# M6am：**双群体 + 慢耦合 —— 顺序拿到了，维度没带过来**

## 提案

一个群体不能同时具备"高维 / 整合 / 可读 / 时间整合"（M6ak 的交换曲线）。
所以建两个：**A（全局场，低维但可读、能判别顺序）** + **B（局部场+长程，高维）**，
用**慢变量**耦合（M6y 已证即时标量补不回整合）。

## 结果（4 种子，`per=32`）

| 耦合 `c` | 顺序判别 | 发放 A | 发放 B | **联合 PR** |
| ---: | ---: | ---: | ---: | ---: |
| 0 | **0.938** | 0.155 | 0.022 | 2.2 / 1.3 / 1.8 / 2.2 |
| **0.1** | **0.969** | 0.155 | 0.022 | 2.4 / 1.3 / 1.8 / 2.2 |

**顺序判别 0.938–0.969（机会 0.5），而且加耦合不掉。**
发放两群体都在窗内。

## 判决：**一半成功**

- ✅ **顺序（时间整合）拿到了**，而且耦合不破坏它；
- ❌ **联合 PR 只有 1.3–2.4** —— 高维那一半**没有带过来**。

所以"分工"这个设想**只对了一半**：把两件事分给两个群体，能保住可读那一半，
**但把它们拼在一起并不产生高维的联合状态**。

## 三条可能的解释（都未验证）

1. **B 在联合设置下的动力学与单独时不同**：耦合项与起搏分配都会改变它的工作点；
2. **PR 的测量口径**：逐群体标准化后拼 2048 维、只有 128 个样本 ⇒ PR 是**下界**；
3. **A 仍然主导**：即使标准化，A 的时间结构可能仍占据前几个主成分。

**未验证 — 这是本轮最重要的未排除项。**

## 限定

- 4 种子；`per=32`（每类 32 条）；`T_SPONT=2048`；
- 耦合矩阵是固定随机投影（不学习），时间常数 `τ=100` 步；
- B 的局部场半径 2、强度 2.0、`p_long=0.5` —— 与 M6ak 的最优格相同；
- **"顺序"用的是 4 类里的两两二分类**（机会 0.5），样本少，0.938 与 1.000 之间只差 1–2 个样本。
