# Route R 的 Step 0：冻结表示下的读出层 AF 基线

**日期**：2026-11-14
**预注册**：`research/sel/prereg-readout-cl-step0.md`（R0-1…R0-4）
**仪器**：`research/sel/lm/readout_cl.py`
**表示**：`temp` 池的**解析温度计码**（`design_sensor_encoder`，尺度 2.0），冻结
**学习**：一个线性读出，手写解析梯度（softmax + 交叉熵），**无 autograd**
**任务**：5 个任务**共用同一份冻结特征**，标签映射 `(t+3k) mod 10 + 10k`

## 二、判据

| # | 判据 | 实测 | 结果 |
| :--- | :--- | :--- | :--- |
| **R0-1** | `multi` 的 AF = 0.000 | 三个步数档 × 5 种子，**全部 0.000** | ✅ |
| **R0-2** | `replay` 相对 `single` 的 AF 降幅 ≥ 50% | 0.720→0.211（**−71%**）、0.800→0.222（**−72%**）、0.800→0.232（**−71%**） | ✅ |
| **R0-3** | `replay` 的 ACC 不低于 `single` | 0.204 / 0.198 / 0.202 对 0.183 / 0.200 / 0.200 | ✅（**打平**，非优势） |
| **R0-4** | 五个种子报中位与极差 | 见 §一 | ✅ |

**ADR-0017 的"回放先行"在这一层成立**：一个共享头 + 每旧任务抽 10% 的一批，
就把 AF 从 0.80 压到 0.22。

## 三、`single` 的 0.200 不是巧合

五个种子的 `single` ACC **精确等于 0.200**、AF **精确等于 0.800**——这不是趋同，
是**结构性塌缩**：共享头最后只保留最后一个任务（1.0），前四个任务归零（0.0），
于是平均 1/5 = 0.200、遗忘 4/5 = 0.800。
⇒ 这是"纯 CIL 的教科书式失败"，与 ADR-0029 归档的那条形状一致。

## 四、天花板检查（这一轮最重要的操作结论）

`multi` 是**上界**，它贴到 1.000 就说明这门**测不出东西**了：

| 步/任务 | 100 | 300 | 1000 |
| :--- | ---: | ---: | ---: |
| `multi` ACC | 0.902 | **1.000** | **1.000** |

⇒ **200 步以上上界饱和**。而从 100 → 300 → 1000，`single` 的 AF 从 0.720 冻结到 0.800、
`replay` 从 0.211 冻到 0.222–0.232。

**推荐预算：150–200 步/任务**（比预注册估算里的 300 下调）。
100 步还留着上界余量（0.902，极差 0.15），300 步已经贴顶。**跑更多步买不到新结论。**

## 五、两条附带结论

1. **ρ 不是越大越好**：ρ=0.3 的 AF 0.242 **比** ρ=0.1 的 0.222 **更差**（5 个种子一致）。
   回放比例过高会挤占当前任务的更新预算。这一轮不解释机制，只记现象。
2. **AF 与"学多熟"强相关**：任务学得越熟，后面被覆盖得越狠（0.72 → 0.80）。
   所以**任何 AF 数字必须带步数**——这也是预注册里要求步数阶梯的原因。

## 六、四问

1. **预算截断？** 否。三个步数档都跑了，且曲线在 300 之后**平了**（不是还在涨）。
2. **跨语料 / 跨预算？** 不跨。同一份特征、同一个任务序列、同一批评测样本（固定种子 `10_000+j`）。
3. **单边指标？** 不是。ACC 与 AF 都报，且 ACC 出现了**上界饱和**这一种"单边失效"，已写明。
4. **先验未兑换？** 不涉及。

## 七、不能说的

1. **不能说"持续学习解决了"**——这只测了**一个线性读出**在**一份冻结特征**上的遗忘；
   换特征、换任务顺序、换任务数都没测。
2. **不能把 AF 0.22 与 ADR-0029 的 0.290 并列**——那是全网络纯 CIL，口径完全不同。
3. **不能说回放"便宜"**——每步多了一次前向（旧任务抽样），成本约 +10%；
   缓冲是**原始特征**，没有隐私保护，产品化要先过脱敏。
