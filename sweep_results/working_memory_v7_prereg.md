# 预注册：多时间尺度工作记忆 v7——独立传入群体（2026-10-28）

**定稿时间：2026-10-28，在本轮任何 v7 数据之前。** v5（脉冲计数）与 v6（膜电位）都
撞在同一堵墙上：每个 cue 每个维度只有**一个**伯努利通道、5 个样本。用同一生成过程
（40 万样本、最优线性解码）算出的上界：

| 独立通道数 R | 样本数 5R | 线性解码 R² 上界 |
| ---: | ---: | ---: |
| 1（v5/v6） | 5 | **0.382** |
| 2 | 10 | 0.553 |
| 4 | 20 | 0.712 |
| 8 | 40 | 0.832 |
| 16 | 80 | 0.908 |
| 32 | 160 | **0.951** |

v6 的 LIF 实测 0.309 已接近 R=1 的上界。v7 只改**输入统计**：每个 (τ, 维度) 用 32 个
独立传入通道（同一 p、独立采样），每个通道驱动一个 ALIF 单元；任务、cue 时间窗、τ、
阈值、两臂、训练/测试规模与判据全部不变。

## 机制

```text
每个 τ ∈ {2,5,10,20,50,100,200}：n_dims×32 个 ALIF 单元（每个维度 32 个）
  输入： cue 值 → p=clip((cue+3)/6,0,1)；每个通道独立采样 Bernoulli(p)
  权重： 通道 (d,r) → 单元 (d,r)，w_in = gain_r（对数间隔 0.5…4.0），无循环权重
  读出： 最后 10 步膜电位；每个 (τ,维度) 的 32 个单元取均值 → 7×4=28 维
读出： 局部 RLS（λ=1、δ=1000），逐样本 20 epoch（与 v4/v5/v6 相同）
```

- 两臂：**LIF（beta=0）**与 **ALIF（beta=0.1）**；
- 单尺度对照：fast(τ=2)、mid(τ=20)、slow(τ=200) 各自的 4 维群体均值；
- 32 个通道是**传入群体**，不是循环连接；单元间 w_rec 恒为 0；
- 增益异质（0.5 到 4.0 对数间隔）让低增益单元保持亚阈值线性范围、高增益单元真正
  发放脉冲；这是群体编码的灵敏度分布，不是按数据调的参数。

## 判据（与 v4/v5/v6 相同，先写死）

1. 多尺度 A/B 的 R² 都 ≥0.50；
2. 快 τ=2 的 A <0.30；
3. fast/mid/slow 各自至少漏一个线索；
4. **不因脉冲化退化**：该臂两线索平均 R² ≥ v4 的 **0.9990 − 0.10 = 0.899**；
5. 任一臂四条全过 → `v7_ready`；否则报边界，不调 population/增益范围/窗口/τ/阈值/判据。

## 预先声明的诊断（不参与判据）

- **网络确实在发放**：记录每个 τ 组的平均每神经元每步脉冲率，必须 >0；若为 0，说明
  群体退化成速率模型，不能写成“脉冲实现”。
- 膜电位范围与近阈值比例（同 v6），检查高增益单元是否饱和。
- 若 v7 仍不 ready，先分清是群体均值压缩（增益/阈值）还是 R 仍不够；两者分别对应
  v8 的不同改法，不允许事后调 R 或增益来凑线。

## 不做什么

- 不调 population/增益范围/膜电位窗口/τ/阈值/读出；不换任务/判据；
- 不做学习型循环权重；不做 e-prop 训练（只做读出）；
- 不把 v5/v6 的成绩混进 v7 列；两臂都报，负结果保留。
