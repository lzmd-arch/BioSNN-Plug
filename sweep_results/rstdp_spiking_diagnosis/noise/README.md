## 协议

线性 TD Critic、1200 回合、seed 0；取**最终权重**，用 20 个评测种子各跑 10 回合；
bootstrap 1000 次（固定 RNG）算均值的 95% CI。设备 cuda（已发表臂是 CPU 配置；
这是诊断，不与发表数字直接比较）。

一个几乎不出手的策略，20 次评测当然稳定。按"达标数字可能是平凡解"的纪律，这一轮
