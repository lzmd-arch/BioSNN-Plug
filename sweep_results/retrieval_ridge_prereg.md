# 预注册：跨模态检索第三轮——岭回归上界探针（不是候选规则）

**定稿时间：2026-10-17，在这一轮的任何数据之前。**

## 它要回答什么

前两轮在程序生成配对集上分别得到 **R@1 0.141（外积 Hebb）** 与 **0.359（delta）**，
验收线 50% 都没到。现在有两种可能，而它们要改的东西完全不同：

| 可能 | 症状 | 该改什么 |
| :--- | :--- | :--- |
| (i) 规则不够强 | 表示里有信息，局部规则没把它取出来 | 换联想规则 |
| (ii) 表示本身不够 | 两路总线输出的**线性可映射性**就只有这么高 | 换编码 / 换融合 / 换总线维度 |

这一轮用**闭式岭回归**做一个**上界探针**：它是这两条总线表示之间**线性映射的能力上限**
（在给定的 λ 网格上）。它回答的是 (i) 还是 (ii)。

## ⚠️ 它不是一个候选规则，不能拿来验收

岭回归 **`W = (TᵀT + λI)⁻¹ Tᵀ V`** 是**批量最小二乘**，需要一次性看到整个训练集、
需要矩阵求逆——**不是局部规则**，不满足计划书"纯局部学习"的主张。

所以：

* **不把它写进任何"达标"的栏位**；
* 只在 README 里作为一种**诊断**报告，并明确标注"oracle / 非局部"；
* 若它越过 50% 而 delta 没有，结论是"瓶颈在规则"；若它也没过，结论是"瓶颈在表示"。

## 设计

其余全部与前两轮相同（数据集、80/20 切分、种子 0–4、`bus_dim=128`、同样的编码与缓存）。

| 维度 | 取值 |
| :--- | :--- |
| λ 网格 | {0.001, 0.1, 1, 10}，**训练集 5 折交叉验证**选 |
| 报什么 | R@1 / R@5，两方向均值，与两轮同口径 |

## 这份预注册**不**声称什么

* 不声称岭回归"更好"——它只是上界探针，代价是它无法在线上学习。
* 不声称它给出的数字能外推到真实数据。
