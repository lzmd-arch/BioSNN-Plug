# 世界模型 P1：CartPole 多步 rollout（2026-10-25）

**预注册见 [`../world_model_rollout_prereg.md`](../world_model_rollout_prereg.md)（先于数据）。**
自证块：commit `2738f6b`，工作区干净，5 个采集种子。原始数值在 [`summary.json`](summary.json)。

## 协议

CartPole-v1，均匀随机动作；训练 200 / 测试 100 回合；`ridge_quadratic`（主）与 `copy_last`
（下界）；测试回合内切长度 k 的窗口（不跨回合），k=1…10；逐 horizon 的 NMSE 分母用训练集
`Var(s')`。每种子窗口数 1264–1539。

## 结果（5 种子均值）

| k | 自由 rollout NMSE | 教师强制 NMSE | `copy_last` 自由 NMSE |
| ---: | ---: | ---: | ---: |
| 1 | ≈0 | ≈0 | 0.073 |
| 5 | 1×10⁻⁶ | ≈7×10⁻⁸ | 0.52 |
| 10 | **3×10⁻⁶** | ≈0 | **1.036** |

- **"可用"判据**（`free_NMSE(k=10) ≤ 1.0`）：✅ 通过，3×10⁻⁶；
- **"累积主导"判据**（`free/teacher(k=5) ≥ 2`）：⚠️ 触发，比值 **13.9**。

## 怎么读这两个互相矛盾的数

比值触发，但**绝对误差仍在数值噪声量级**：教师强制的 k=5 误差约 7×10⁻⁸，自由 rollout 是
1×10⁻⁶——比值 13.9 几乎全部由"分母接近零"贡献，不是每次预测真的在放大。

所以本轮的结论要同时写两句话：

1. **在 CartPole 这个线性一步动力学上，10 步 rollout 不发散**（3×10⁻⁶，远低于 1.0）；
2. **"比值 ≥2" 这条判据在教师强制误差接近机器精度时没有信息量**——到 P2 非线性环境
   （误差不在噪声底）才该用它。这是预注册设计的一条教训，不改判据，记在这里。

`copy_last` 在 k=10 是 1.036 > 1.0，说明"不预测"在多步上确实不可用；对比之下
`ridge_quadratic` 的 3×10⁻⁶ 不是平凡结果。

## 这**不**说明什么

- **不说明多步不是瓶颈**：CartPole 是线性的；线性+二次项能解掉它，不代表非线性环境也能；
- **不说明规划可用**：没有策略、没有奖励预测、没有规划回路，只是开环 rollout；
- **不改阶段四入口**：阶段三验收仍是门。
