# 空间结构维数：**S-0 不过 ⇒ 整个实验作废**

**一句话**：四条臂全在 **0.115–0.122**，而底板是 **0.125** —— 都没够到任务。
按预注册的后果条款「**S-0 不过 ⇒ 整个实验作废**，不拿解不了的任务判维数」，
本实验**不能回答**"空间维数有没有用"。

**这不是负结果，是没有结果。**

## 一、判据（跑之前落盘）

| 编号 | 判据 |
| :--- | :--- |
| **S-0** | 真实发放率 ∈ [0.03, 0.20]，且每臂 acc ≥ 底板 + 15pp。**不过 ⇒ 整个实验作废** |
| **S-1** | 最佳维数比 1D 高 **≥5pp**，且三种子同向 |
| **S-2** | 直径与准确率的秩相关 **≤ −0.6** |

## 二、结果（3 种子、n=16,384、入度 1,024、逐臂标定工作点）

| 臂 | 实测直径 | 发放 | acc | 逐种子 |
| :--- | ---: | ---: | ---: | :--- |
| **窗口天花板**（不经过网络） | — | — | **0.353** | — |
| **底板**（多数类） | — | — | **0.125** | — |
| 1D | 8.50 | 0.0764 | 0.118 | .109 / .117 / .129 |
| 2D | 3.20 | 0.0963 | 0.122 | .121 / .109 / .137 |
| 3D | 2.67 | 0.0820 | 0.115 | .102 / .125 / .117 |
| 7D | 2.03 | 0.0621 | 0.121 | .113 / .125 / .125 |

## 三、判

| 编号 | 结果 |
| :--- | :--- |
| **S-0** | ❌ **不过** —— 四臂全在底板上（+0.004 ~ −0.010，噪声内） |
| S-1 | ❌ 不过（最佳 2D − 1D = +0.004，三种子不同向） |
| S-2 | ❌ 不过（秩相关 +0.00，要 ≤ −0.6） |

**S-1 与 S-2 的"不过"没有信息量**：它们是在一堆底板读数上算的。
只有 S-0 的"不过"有意义，而它的含义是**作废**，不是"维数无关"。

## 四、为什么够不到

读出是**零参数最近原型**（类均值 + 距离）。而本仓库已经用九轮实验确认
**线性/零参数读出是瓶颈**（A2–A7、R3–R11，`AGENTS.md` §2.6）。

同一个任务族（隐状态生成序列、8 类、窗口 8 token）上，天花板都是 ~0.35：

| 管线 | 读出 | acc |
| :--- | :--- | ---: |
| `bio_all` 的 `off`（n=2048、度 32、随机稀疏） | **MLP** | **0.229** |
| `spatial_dim` 四条格点臂（n=16,384、度 1,024） | **零参数原型** | **0.115–0.122** |

⚠️ **这两行的差别同时包含"布线"与"读出"，本实验不能把它们拆开。**
要拆，得在同一批特征上换两种读出 —— 那是另一个实验。

## 五、想回答"维数有没有用"需要什么

1. 换一个**够得着天花板**的读出（MLP），
2. 并且**写成新的预注册**再跑 —— 不能拿这份作废的结果去改 S-0 的后果。

这条建议写在看到 S-0 失败之后，如实标明：**它不修改 S-0 的后果**
（本实验仍然作废），只是提出一个新的、独立的实验。

## 五之一、「空间维数」在这里也是**格点拓扑**，不是物理嵌入

与 `dim_ladder` 同一个问题：本实验的 n=16,384 个神经元排成 1D/2D/3D/7D 格点，
但**它们没有物理坐标**，连接也不服从 3 维空间的距离定律。
⇒ 即便 S-0 过了，本实验也只能回答"格点拓扑如何"，不能回答"物理 3 维嵌入如何"。

## 五之二、这份结果的读出也受了 `to_ball` 饱和的影响

`spatial_dim` 用的是 `manifold_big.to_ball` + `acc_of(..., "product")`。而 `to_ball`
原来会把所有点压到半径 0.95（见 [`manifold_big/README.md`](../manifold_big/README.md) 第三节），
于其中的 Poincaré 分量等价于欧氏分量 —— **那部分"双曲"是名义上的**。

不过这不改变本实验的判决：S-0 判的是"读出够不够得着任务"，四条臂都在底板上，
作废的结论不受影响。

## 六、这次重跑顺带修掉的东西

| 缺陷 | 处置 |
| :--- | :--- |
| 任务生成器没播种（训练/测试是两个任务） | `seeded_dirichlet` |
| 标定探针 T=48 vs 正式跑 T=64 | 改成 `args.seq` |
| 正式跑没有发放闸 | 用真实发放率复核 |
| 没有正向对照 / 底板 | 补窗口天花板与实测多数类 |
| **BFS 直径是错的**（只给抽样源点填邻接表；4096 节点截断落在第 3 层内） | 全图精确向量化 BFS：**1D 2.50→8.50、2D 2.49→3.20、3D 2.24→2.67、7D 1.75→2.03** |

⇒ **S-2 从来没被真正检验过**，因为旧直径四条臂只差 0.75，真值差 6.5。
