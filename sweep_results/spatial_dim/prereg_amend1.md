# amend1：读出换成够得着任务的那一个（S-0 不变）

**写于** 2026-11-16，在第一次有效测量**之后**、在任何一次能判维数的测量**之前**。

## 为什么要改

第一轮（`seeded_dirichlet` 修好后）四个臂全部落在底板上：

| 臂 | acc | 底板 |
| :--- | ---: | ---: |
| 1D | 0.118 | 0.125 |
| 2D | 0.122 | 0.125 |
| 3D | 0.115 | 0.125 |
| 7D | 0.121 | 0.125 |

而**窗口天花板是 0.353**。⇒ 读出够不到任务，S-0 不过，实验作废。

**S-0 本身没有错，它正是为了拦住这件事。** 错的是**仪器的选择**：
原设计规定"零参数流形读出"，而它在 n=16,384 / 入度 1,024 这个规模上够不到任务。
`manifold_big` 用同一套仪器、同一个规模，四条臂也全在底板上 —— **两个独立实验复现**。

## 改什么

**加一个可学的读出，两个读出都报。**

| 读出 | 形状 | 角色 |
| :--- | :--- | :--- |
| `proto` | `to_ball` + 最近类均值原型（零参数） | **对照**，原设计 |
| `mlp` | 4096→256→K，600 步，**播种** 3 次取均值 | **判据用** |

`mlp` 的超参与 `dim_ladder.mlp` / `instrument.mlp_probe` **逐字相同** ——
这是本仓库此前所有"结构 vs 平坦"证据用的那个探针，不能换尺子。

## 为什么这不违反"读出不能吸收几何"

**四条臂的读出完全相同**（同样的宽度、同样的步数、同样的种子）。
唯一变化的是网络的**空间结构**。所以臂间差异只能来自特征本身的可解码性，
不可能来自读出把几何"吸收"了。

原设计想防的是另一种情形：**用不同的读出比较不同的网络**，那时读出的差别
和网络的差别混在一起，分不开。这里不是那种情形。

## 判据（不变）

| 编号 | 判据（**改成在 `mlp` 读出上判**） |
| :--- | :--- |
| **S-0** | 真实发放率 ∈ [0.03, 0.20]，且**每臂 mlp acc ≥ 底板 + 15pp**。不过 ⇒ 整个实验作废 |
| **S-1** | 最佳维数比 1D 高 **≥5pp**（mlp），三种子同向 |
| **S-2** | 直径与 mlp 准确率的秩相关 **≤ −0.6** |

`proto` 的结果**照报**，并单独给出它的 S-1/S-2 —— 若两个读出结论相反，
那本身就是要报的结果。

## 如果这次 S-0 仍不过

那就说明 15pp 这条线在这个任务上对 MLP 也够不到，实验仍然作废。
**不调 15pp。** 到那一步要改的是任务（换一个天花板更高的），不是判据。
