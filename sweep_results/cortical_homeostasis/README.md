# 稳态补偿：**C-3 在修正分母后仍然成立（6/6，+24pp）**

**一句话**：把发放改成**按存活神经元**平均之后，`comp` 的发放回到窗内（0.055 / 0.086），
准确率 **0.808 → 0.871 → 0.950**；`nocomp` 仍塌（0.0054 / 0.0026）；
`sham`（网络完好、只遮读出）停在 0.707。**C-3 6/6，均值 +24pp。**

## 一、结果（6 种子）

| 条件 | 0% | 25% | 50% |
| :--- | :--- | :--- | :--- |
| `nocomp` 峰值 | 0.808 | 0.789 | 0.710 |
| `nocomp` 发放 | 0.0807 | **0.0054** ✗ | **0.0026** ✗ |
| **`comp` 峰值** | 0.808 | **0.871** | **0.950** |
| **`comp` 发放** | 0.0807 | **0.0553** ✓ | **0.0859** ✓ |
| `sham` 峰值（网络完好、只遮读出） | 0.808 | 0.784 | **0.707** |

| 编号 | 结果 |
| :--- | :--- |
| C-0 0% 工作点 | ✅ 过 |
| C-1 补偿把发放拉回窗内 | ✅ 过 |
| C-2 补偿后 50% 损伤仍可用 | ✅ 过（0.950） |
| **C-3 补偿做功（6/6 同号）** | ✅ **过**：`[+.230, +.254, +.195, +.310, +.207, +.248]`，均值 **+24pp** |

## 二、两个对照各自排除了什么

1. **`sham` 排除"读出容量"**：网络完好、只把同样位置的读出特征置零，峰值停在 **0.707**，
   没有上升 ⇒ 收益**不是**"特征变少、过拟合变少"造成的。
2. **修正分母排除"活动翻倍"**：改成按存活神经元平均后，`comp` 的发放是 0.055 / 0.086，
   **在窗内**，不是之前的"标称 0.08、实际 0.16"。

## 三、⚠️ 还剩一个混淆：**输入驱动翻倍了**

补偿的实现是**把输入增益调上去**（50% 损伤时约 2×）。于是：

- **发放率**匹配了（0.086 vs 0.081）；
- **但每个存活神经元的输入驱动是 2×** ⇒ 网络从"递归主导"变成**"输入主导"**。

而线索就在输入里 ⇒ **输入主导的网络更容易解码**。

**这可以解释为什么 `comp` 的 0.950 高于完整网络的 0.808。**

⇒ 正确的表述不是"损伤后补偿让系统更强"，而是：

> **在 50% 神经元丢失后，把输入增益调上去能让系统回到可行的工作点，
> 并给出不低于完整网络的解码能力 —— 但它同时把系统推成了输入主导的 regime。**

## 四、这是"生命"线里第一个过对照的正面结果

| 之前的尝试 | 结果 |
| :--- | :--- |
| γ 改结构 | 结构变了，能力平 |
| η 改设定点 | 活动变了，能力平 |
| 折叠改接线 | 接线变 21%，能力平 |
| **补偿改活动** | **活动回到窗内，能力 +24pp（6/6），且过 sham** |

差别在于：**补偿是唯一一个"把系统从不可行状态拉回可行状态"的干预。**
前三个都在可行状态里微调。

## 五、下一步（唯一能解释清楚的那个对照）

**匹配输入驱动**：把完整网络的输入增益也调低，使**每神经元的输入驱动**与 `comp` 相同，
再看 0.808 是否也升到 0.95。

- 若**也升** ⇒ 收益来自"输入主导"，不是补偿；
- 若**不升** ⇒ 补偿真的恢复了什么。

这个对照不做，"补偿让系统更强"就不能说。
