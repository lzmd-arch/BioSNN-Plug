# 短时突触抑制（STP）顺序机制：结果

预注册：[`axo_spiking_stp_prereg.md`](axo_spiking_stp_prereg.md)。

## 一句话

**输入 STP 没有把顺序信息带进来：5 个臂全部在 0.40–0.44，抑制越强越差。**
换机制的第一步也是负结果。

## 结果（107 对同会话相邻轮，目标都是先到的那个）

| 臂 | A→B | B→A | 平均 | 每步脉冲 |
| :--- | ---: | ---: | ---: | ---: |
| `lif-a095`（无 STP） | 0.4486 | 0.4299 | **0.4393** | 61.8 |
| `lif-a098`（无 STP） | 0.4393 | 0.4299 | 0.4346 | 68.6 |
| `stp-d02` | 0.4486 | 0.4206 | 0.4346 | 68.4 |
| `stp-d05` | 0.4299 | 0.4019 | 0.4159 | 68.1 |
| `stp-d08` | 0.4112 | 0.3925 | 0.4019 | 67.8 |

- 没有任何一档超过 0.60；最好的 `lif-a095` 也只有 **0.4393**，低于上一轮线性积分器
  的 0.4024 只是同一量级（配对不同，不能直接相减）。
- **STP 抑制越强，平均越低**：d=0.2 与 LIF 持平，d=0.5/0.8 反而下降。它没有让
  “先到”占优，只是把第二个输入（以及共享位上的信号）一起削弱了。
- A→B 与 B→A 两列都接近 0.40–0.45：既不是“总选第一个”，也不是“总选第二个”，
  而是两者都没抓住。

## 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 平均 top-1 > 0.60 | 最好 0.4393 | **没有** |
| 0.45–0.60（与线性同量级） | 0.4019–0.4393 | 低于/接近下沿 |
| < 0.45（反向/无顺序） | 大部分档 | **无顺序** |

## 为什么失败（读结果，不猜）

1. **输入抑制只作用于共享位**：A 与 B 的重叠越大，STP 越有东西可削弱；但这两条
   相邻记忆的重叠并不足以让“先到”在末态膜电位上占优——泄漏（α=0.98）仍把先到的
   信号衰减掉了。
2. **读出仍是 `A·v` 的线性打分**：即使输入被抑制，最后的读出没有“谁先到”的
   非线性；STP 只改变了幅度，没有改变顺序在末态里的编码。
3. **α=0.98 没有救回来**：它比 0.95 更差（0.4346 vs 0.4393），说明问题不是
   “保持得不够久”，而是根本没有把顺序写进状态。

## 边界

- 107 对同会话相邻轮；配对相似度未控制；人为顺序任务。
- STP 是逐位抑制/恢复的现象学模型，不是完整 Tsodyks–Markram。
- 164 条真记忆；无学习；W 是既有 Hebbian 外积。
- 墙钟时间不能论证能效。

## 结论

**STP 作为输入机制不够。** 要让脉冲表达顺序，需要把顺序写进**状态或连接**，而不是
只调节输入幅度；候选是：
- 带延迟的突触（delay line）或脉冲时序依赖的权重（STDP 顺序学习）；
- 双稳态/慢变量，让先到的输入在状态里留下不可交换的痕迹；
- 或者在读出处引入显式的时序比较，而不是 `A·v` 的线性打分。

在这些机制里，至少前两个会改变“状态是什么”，而不只是“输入多强”。如果继续，
应该从那里开始，而不是继续调 STP 的 d/α。
