## 结果（R²）

| 臂 | A | B | 均值 | ridge（同一状态） | 脉冲率 | 判定 |
| :--- | ---: | ---: | ---: | ---: | ---: | :--- |

判据：多尺度 A/B 都 ≥0.5、fast A <0.3、单尺度各漏一个、不退化（≥0.899）。
**ALIF 的多尺度、fast、单尺度三条全过，但均值 0.788 < 0.899**；LIF 的 A 只有 0.075。
两臂脉冲率均 >0（每神经元每步约 0.09–0.10 次），网络确实在发放。

## 诊断：早期 cue 被复位擦除

逐 τ 组读出（ALIF）：slow(τ=200) A/B **0.379/0.485**、mid(τ=20) **0.141/0.732**、
fast(τ=2) ≈0。B 能解、A 很差，说明不是输入样本不够（v7 的输入上界已到 0.95），而是
**B 窗口的脉冲复位把 A 从慢 τ 的膜电位里扣掉**：高增益单元在 B 期间发放，`−thr·z`
直接减掉阈值，早期线索被永久压低。ALIF 的适应提高阈值、减少复位，所以 A 比 LIF 好
得多；LIF 几乎只剩 B。

## 结论

群体的方向对：ALIF 从 v6 的 0.121 提到 **0.788**，fast/单尺度判据也都成立。剩下的差距
是**复位擦除**，不是群体大小或输入样本数。v8 只改读出为复位前的泄漏积分（脉冲迹
`v + thr·trace`），保持群体/增益/τ/任务/判据不变；按预注册，v8 不得把这条写成
“膜电位读出”，只能写“脉冲输入 + 局部迹读出”。
