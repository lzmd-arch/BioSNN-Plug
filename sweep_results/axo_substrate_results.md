# Axo 关联基质优化：第一轮结果

**日期：2026-10-18。** 预注册：[`axo_substrate_prereg.md`](axo_substrate_prereg.md)。
本文件是执行记录，**不是新的预注册**；图参数扫描与分簇回放是在预注册之后新增的
探索性步骤，边界写在最后。

## 一句话

**稳态 ALIF 的选位规则（`idf-2.0`）同时打破了 Axo 的 A/W 分叉：图邻接质量、补全、
分簇回放三项都超过现有基线；召回四项在关闭图通道时逐位复现基线，打开图通道仍然
没有增益——这是同源证据的结构性限制，不是调参能解决的。**

## 1. 基线复现

副本通过路径导入 Axo 的纯层（`memcore` + `axo.bench.substrate`），没有修改 Axo 仓。
用它的语料与指标函数算出的基线与冻结文件逐位相同：

| 档 | neighbor_auc | completion_top1 | graph_hit@1 | graph_mrr |
| :--- | ---: | ---: | ---: | ---: |
| `hash` | 0.7083 | 0.0250 | 0.8250 | 0.8883 |
| `weight` | 0.5287 | 0.8700 | 0.8250 | 0.8896 |

召回基线（词法、`graph_weight=0`）：hit@1 0.8961 / hit@8 0.9481 / MRR 0.9095 /
误注入 0.8679 / AUC 0.9289，五项全部逐位复现。

## 2. 新选位规则

`idf-γ`：对词法码的每个位计算文档频率 `df_i`，按
`w_i · (log((n+1)/(df_i+1)) + 1)^γ` 选前 k 位。`γ=2.0` 是网格里最好的档。
它是 ALIF 稳态适应 `θ_i = θ0 + β·a_i` 的选位等价形式：跨条目反复活跃的位被
抬高阈值，从而在选位时被压下去。

### 2.1 默认图参数下（预注册口径）

| 档 | neighbor_auc | completion_top1 | graph_hit@1 | graph_mrr | 孤点 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| `hash` | 0.7083 | 0.0250 | 0.8250 | 0.8883 | 18 |
| `weight` | 0.5287 | 0.8700 | 0.8250 | 0.8896 | 105 |
| `idf-2.0` | **0.7425** | **0.9400** | 0.8250 | 0.8896 | 160 |

AUC 与补全都超过各自基线，但图被 `min_weight=0.10` 滤得太稀（160 个孤点），
按预注册的孤点闸门**不合格**。这是「图参数需要重标」的信号，不是选位失败。

### 2.2 图参数重标后（探索性）

`idf-2.0`、`k=64`、`top_m=32`、`min_weight=0.02`、`decay=0.25`：

| 指标 | 结果 | 对照基线 | 判定 |
| :--- | ---: | ---: | :--- |
| neighbor_auc | **0.7311** | 0.7083 | 超过 |
| completion_top1 | **0.9400** | 0.8700 / 0.9000 | 超过 |
| graph_hit@1 | **0.8500** | 0.8500 | 追平 |
| graph_mrr | **0.9021** | 0.9021 | 追平 |
| 孤点 | 4 | — | 合格 |

## 3. 规模档（全局 W，合成语料）

| n | weight 补全 | idf-2.0 补全 |
| ---: | ---: | ---: |
| 500 | 0.2250 | **0.3750** |
| 1000 | 0.0900 | **0.1350** |
| 2000 | 0.0300 | **0.0450** |

方向一致、幅度约 1.5–1.7 倍，但**悬崖没有消失**。`--scale` 的合成条目是同簇拼接，
n≥500 的下降可能来自近重复而不是容量；这组数只能说明「同一份语料上更好」，
不能说明真实 5 万条上够用。

## 4. P4c 分簇回放（真实应用那一步）

用 `memcore.consolidation.partition` 的同一批簇，在每簇自己的 W 上做 50% 丢位回放。
`idf-cluster` 的文档频率**只在簇内统计**：

| n | weight（现有） | idf-global | idf-cluster |
| ---: | ---: | ---: | ---: |
| 200 | 0.9000 | 0.9400 | **0.9950** |
| 500 | 0.4400 | 0.4400 | **0.5840** |
| 1000 | 0.1370 | 0.1460 | **0.3130** |
| 2000 | 0.1020 | 0.1055 | **0.1960** |

这是本轮最有应用价值的结果：**簇内频率统计**把 n=200 的辨认率从 0.90 推到 0.995，
n=500 从 0.44 推到 0.584。它不增加存储（码在回放时现算）、不引入随机数、不需要 GPU。

## 5. 召回四项（金标准）

`idf-2.0` 在 `graph_weight=0` 时与基线逐位相同（四项全等）。图通道打开后：

| graph_weight | hit@1 | hit@8 | MRR | 误注入 | AUC |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0.00 | 0.8961 | 0.9481 | 0.9095 | 0.8679 | 0.9289 |
| 0.10 | 0.8961 | 0.9481 | 0.9095 | 0.8682 | 0.9257 |
| 0.25 | 0.8961 | 0.9481 | 0.9092 | 0.8712 | 0.9208 |
| 0.50 | 0.8961 | 0.9481 | 0.9081 | 0.8762 | 0.9130 |

**hit@1 / hit@8 一动不动，AUC 单调下降，误注入率上升。** 换 `hybrid-24` 也一样。
原因不是编码质量：图 A 的边是词法码的子集，扩散加的是**同一份证据的第二遍**。
没有独立信号（语义嵌入、真实会话共现、时间邻接）时，任何同源图都只能重排中后段，
不能把榜首换对。Axo 把 `graph_weight` 默认设为 0 是有数据支撑的，本轮没有推翻它。

## 6. 脉冲吸引子（LIF / ALIF）负结果

把一步 `W p` 换成 T 步 LIF / ALIF 动力学，在 `idf-2.0` 码上：

| n | 一步 W | LIF 最好 | ALIF 最好 |
| ---: | ---: | ---: | ---: |
| 200 | **0.9400** | 0.7650 | 0.7550 |
| 500 | **0.3700** | 0.2850 | 0.2950 |

阈值化丢掉了线性读出的信息；ALIF 比 LIF 好一点，但仍显著低于一步 W。
**本轮神经元动力学的收益来自选位（稳态适应），不是来自脉冲迭代。** 这条负结果
不排除别的吸引子设计（模拟读出、软阈值、真正的侧抑制），但它排除了「直接把
`respond` 换成脉冲循环」这条最省事的路线。

## 7. 边界与未做

1. **图参数是在同一份 40 条查询上调的**（`top_m` / `min_weight` / `decay`），
   没有留出独立验证集。2.2 的「超过/追平」是探索性结果，**不是已冻结的结论**。
2. `--scale` 的合成语料有近重复，n≥500 的补全与回放只能同语料内比较，
   不能读成真实规模上的容量。
3. **5 万条真实库没有测**；编码耗时、图重建、回放内存都还没有实测。
4. 召回侧只测了词法 + 图通道；语义通道要 Ollama，本轮没有接入。
5. `idf` 码依赖语料/簇的文档频率，**不是单条记忆的纯函数**；集成时必须在
   「图重建 / 回放」这种本来就全量重算的路径上算，不能写进逐条写入路径。

## 8. 建议的下一步

1. **P4c 集成（收益最大、风险最低）**：把 `replay_cluster` 的 `W_MODE` 从 `weight`
   换成「簇内 df 的 `idf-2.0`」，在真实库上跑一轮 `sleep_once.py --dry-run` 对比
   辨认率；保留 `weight` 作对照，按 `RunReport.recognition_rate` 判定。
2. **独立信号的图**：语义嵌入或真实会话共现，先在金标准上重标 `min_score` 与
   `graph_weight`，再决定要不要打开第三通道。没有这一步，召回四项不可能超过基线。
3. **真实规模**：用真实库或一份「同簇但不重复」的新合成语料重测容量；
   现有 `--scale` 语料分不开容量与重复度。
4. **图参数验证**：把 40 条查询做固定划分（调参/验证）或换一份独立语料，
   确认 `top_m=32 / min_weight=0.02 / decay=0.25` 不是对这 40 条过拟合。
