# M6q：慢增益 —— **剂量–反应第一次出现，但幅度不够**

预注册 `research/sel/prereg-m6q-slow-gain-v1.md`（含开跑前修订 1）。
K=4 固定，`g_inh ∈ {0, 2}` × `eta_gain ∈ {0.2, 0.05, 0.02, 0.01, 0.005}` + 基线，6 种子。

## 一、判据

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| **Q-0 仪器** | 复现 M6p：总体 3.14±0.15、逐个体 1.02±0.05 | **3.14 / 1.02，过** |
| **Q-1 存在** | 发放 ∈ [0.01, 0.20] | 8/10 档，过 |
| **Q-2 逐个体带历史** ★★ | 逐个体比 > 1.5 且 ≥5/6 | **1.35×、4/6，不过** |
| **Q-3 剂量–反应** ★ | 逐个体比随 τ 单调 | g=0 **Spearman +1.00（过）**；g=2 −0.50（不过） |
| **Q-4 状态停住** | 稳态窗前 32 vs 后 32 < 历史距离 | **4/6，不过** |

**判决：M6q 不成立。**

## 二、但这是整条线上第一次出现**方向正确的剂量–反应**

`g_inh = 0`（无交叉抑制）下，把增益时间常数拉长：

| `eta` | 逐个体比 | 胜 |
| ---: | ---: | ---: |
| 0.02 | 0.87× | 1/6 |
| 0.01 | **1.33×** | **5/6** |
| 0.005 | **1.35×** | 4/6 |

**单调上升，Spearman +1.00。** 对比 M6p：那一轮所有臂都压在 1.0× 附近，没有任何剂量关系。

但：**只到 1.35×，离 1.5 差一截，而且已经饱和**（0.01 → 0.005 只再涨 0.02）。

## 三、交叉抑制**主动破坏**这个效应

| `g_inh` | 逐个体比（eta 从慢到快） |
| ---: | :--- |
| **0** | 1.35 / 1.33 / 0.87 |
| **2** | 0.99 / 0.97 / 0.85 / **1.20** / 1.08 |

`g_inh=2` 下没有单调性，量级也在 1.0 附近。

⇒ **交叉抑制与慢增益是拮抗的。** 与 M6p 的结论一致：`g_inh` 是拿个体差异换总体可复现性的那个力。

## 四、状态没有可靠地"停住"（Q-4 不过，4/6）

稳态窗前 32 步 vs 后 32 步的距离，只有 4/6 个种子小于历史距离。
**在 256 步的窗里，这个系统仍然没有完全收敛。** 这本身解释了 1.35 为什么上不去 ——
有一部分"个体差异"其实是没停下来的暂态。

## 五、一处实现错误（已修，不影响判决）

`m6q_slow_gain.py` 的聚合用的是**"逐种子比值再平均"**，而 M6p/M7 的口径是
**"先平均再相除"**。前者被分母小的种子主导 —— 同一个基线在两种口径下给出
**4.32× vs 3.14×**，而 `d_hist`/`d_null` 逐位相同（0.991956 / 0.315588）。

`scripts/m6q_verdict.py` 按正确口径从已存数据重算，**没有重跑**。
判据本身一个字没改。

## 六、限定

- **Q-3 的 +1.00 只有 3 个点**（`g=0` 下 `eta=0.2/0.05` 的发放是 0.32/0.22，出了窗），
  3 点 Spearman 的偶然概率约 1/6。**它是指示，不是证据。**
- 6 种子；K=4 固定；
- **A vs B 仍同时改了 `pref` 与输入稀疏度**（`seeded_dirichlet` 固定 `PREF_SEED=0`），
  这个混淆从 M6p 带过来，本轮**未修**。

## 七、下一问

1.35 已经饱和，说明**不是"再慢一点"能解决的**。两个候选，都不换机制：

1. **历史时长**：慢变量在 1024 步里攒不出足够差异。`T_HIST` 1024 → 2048/4096
   是它的直接剂量；
2. **增益的接线**：现在增益在自发期只乘 `(pace − G_FIELD·φ)`，**不乘 `rec`**；
   而历史期乘的是 `w_in`。两个阶段乘的东西不一样。让它乘总输入是更生物的那版。
