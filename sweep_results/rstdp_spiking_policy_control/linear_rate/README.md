# D2：线性策略配方 sanity control（2026-10-26）

**诊断，不是验收。** 预注册见
[`../../rstdp_spiking_policy_control_prereg.md`](../../rstdp_spiking_policy_control_prereg.md)。
同一套环境、群体 Critic、种子与训练循环，只把动作策略换成速率版已验证的**线性
Boltzmann 配方**：`logits = W·x`、`x⊗(1[a]−π)` 痕迹、log 空间 1→40 退火。

> D2 是**配方级**对照，不是单变量消融：它同时换了策略、痕迹中心化与退火。理由写在
> 预注册里——这三件在速率版是一起才工作的；拆开只会测到一个已知不工作的中间态。

## 协议

800 回合、Actor lr 1e-3、群体 Critic（gradient/均匀/归一化、units 64、bias 0.4、
gain 8、critic_rate 0.1）、warmup 10；seeds 0–9；CPU。

## 判读（按预注册表）

**harness 能学。** 同一套环境、Critic、种子、循环，只换成线性策略配方，中位数从 62–76
跳到 179.8、10/10 配对变好。所以：

- 不是环境/Critic/循环集体失效；
- **瓶颈在脉冲计数选动作这条策略路径**（以及与之同向的资格）——这也把 D1 的读数解释通了：
  `x·a` 是线性 logits 的梯度形状，而脉冲策略的动作由 LIF 计数决定，资格与策略不同向；
- 下一步不是改用线性策略（它不是候选最终形态），而是设计一个**与计数策略同向的局部资格**
  （例如对计数分布做得分函数近似），再按新预注册验证。

## 这说明什么 / 不说明什么

- 说明：D2 的配方在这套 harness 里能把 CartPole 做到中位数 179.8、4/10 过 200；
- 不说明哪一件（策略 / 中心化 / 退火）在起作用——这是配方级对照；
- 不说明脉冲策略不可修：本诊断没有换脉冲策略的资格；
- 不说明验收通过：中位数 <200，且这是训练中的诊断值，不是最终权重验收。
