> **⚠️ 措辞更正（2026-11-17，用户指出）：本文档**不得**把半球互信息等同于纠缠熵。**
> 引擎是**经典模拟**；半球 MI 是**经典关联**度量，不是量子纠缠熵。
> 合法表述：**「经典关联结构的崩塌点与死亡阈值重合」**；
> 量子读法**经由秩–相干桥间接成立**，不是直接测量了纠缠。**对外一律写「互信息」。**

## 为什么用互信息

**互信息是「存在于关联里的比特」**，而线性相关只看得见其中一部分
（`m6av` 已测：全局 MI 1.135、高维 MI 0.067 —— 17 倍）。

**它回答的问题是**：结构的关联里有多少信息，在损伤下怎么变、在时间里能不能回来。

**它不回答的**：这些关联是不是量子的。**在这个经典引擎里它不是纠缠熵**，
量子读法只能经由**秩–相干桥**间接给出。

而「维持」是一个**有时间维度**的量：**一个量被扰动后能不能回来，才是它是否被主动维持的判据。**

## 结果（3 种子，两半球互信息，分位数分箱）

| 损伤 | **S≈MI（t=2048）** | S≈MI（t=256） | 发放 |
| ---: | ---: | ---: | ---: |
| 0% | **1.013** | 0.970 | 0.153 |
| 10% | 0.742 | 0.692 | 0.126 |
| 25% | 0.554 | 0.555 | 0.086 |
| **50%** | **0.699（反常）** | 0.687 | 0.033 |
| 65% | 0.488 | 0.501 | 0.013 |
| **75%** | **0.074** | 0.049 | 0.004 |

| 判据 | 结果 |
| :--- | :--- |
| AX-0 无损档在窗内 | 过 |
| **AX-1 随损伤单调下降** | **不过**（50% 档反常） |
| **AX-2 崩塌点 = 死亡阈值** | **过：都在 65%** |
| AX-3 能否恢复（长窗 > 短窗 10%） | **弱**：+4.5%、+7.2%，其余近零 |

## 一、强结果：**经典关联结构的崩塌点就是死亡阈值**

MI 在 **65%** 崩塌（1.013 → 0.074），而发放的死亡阈值（`m6ao` 细扫）也是 **65%**。

⇒ **「死亡 = 关联结构维持不住」成立**，且它是**秩–相干桥的第三个定量锚点**
（#1 `m6aw` 的工作点、#2 `hold` 比值、#3 本条的崩塌点）。

**量子读法经由这座桥间接成立** —— 本实验**没有**直接测量纠缠。

## 二、弱结果：**「维持」的含义被数据修正为「低泄漏」，不是「主动修复」**

长窗相对短窗只回升 **+4.5% / +7.2%**（低损伤档），其余档近零或为负。**这个数如实保留。**

**⇒ 「维持」应写成「低泄漏」**：低损伤下关联结构基本被保住，**不是被修复**。

**注意：这不是反驳代谢假说，而是与它相容。** 代谢假说该被问的是
「**有没有工作点**」，不是「**有没有修复**」—— 前者由死亡阈值与崩塌点回答（有），
后者由本实验回答（没有）。**两个问题不要混。**

## 三、必须标出的测量假象：50% 档反常

50% 损伤时发放只有 **0.033**，两半球均值都接近常数。
**分位数分箱在近常数信号上会产生虚假关联** ⇒ 0.699 这个数**不可引用**。

**AX-1 的「非单调」由此而来，不是机制结果。**

## 四、限定

- 3 种子；8 分位分箱；`per_fam=32`（每档 256 个状态）；
- **MI 是经典关联，不是量子纠缠** —— 它是纠缠熵的代理，不是证明；
- 只切了随机损伤；没有切"结构性"损伤（如切断两半球连接）。
