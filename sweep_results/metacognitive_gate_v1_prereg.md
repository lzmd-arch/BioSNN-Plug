# 预注册：元认知门控 v1——宽温度网格与 margin 置信度（2026-10-26）

**定稿时间：2026-10-26，在 v1 的任何数据之前。** v0 的结果：选择性增益过（+6.54 pp），
但正确性 AUROC **0.716**、温度缩放后 ECE **0.481**；softmax 最大概率约 0.01，说明
预注册网格 `[0.5, 5]` 的下界太钝。v1 只改**置信度的标定方式**，不改读出、数据、切分与判据。

## 两个臂（同一读出、同一校准/评估切分）

| 臂 | 置信度 | 标定 |
| :--- | :--- | :--- |
| **A：T-wide** | softmax 最大概率 | 温度网格 **T ∈ [0.01, 5.0]**（log 40 点），校准集最小 NLL |
| **B：margin** | `top1 logit − top2 logit` | `p = sigmoid(margin / T)`，T ∈ [0.01, 10.0]（log 40 点），校准集最小 NLL |

- 两臂的**排序**不同（softmax max vs margin），因此 AUROC 可能不同；都报；
- 选择性阈值仍在校准集上取 80% 覆盖，评估集不参与选择；
- 读出、训练、5 个切分、CIFAR-100、冻结 ResNet18 全部与 v0 相同。

## 判据（与 v0 完全一致，先写死）

1. 评估集 80% 覆盖时，选择性准确率比全量 **≥ +5 pp**；
2. 正确性 AUROC **≥0.75**；
3. 标定后 ECE（10 箱）**≤0.10**；
4. 任一臂三条全过 → `v1_ready`；两臂都不过 → v1 不 ready，报边界。

## 不做什么

- 不换读出/不调 η/epoch/特征；不引入 ensemble（那是 v2，若 margin/T 都不够）；
- 不扩到 OOD/LLM 触发；
- 不因为 B 臂好看就只报 B：两臂都报，且判据相同；
- 不在看到数据后改 T 网格或阈值。
