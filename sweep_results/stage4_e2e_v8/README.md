# 阶段四端到端 v8：bank W 的尺度特征（2026-10-27）

预注册：[`stage4_e2e_v8_prereg.md`](../stage4_e2e_v8_prereg.md)。v7 结构不变，只把
OOD 置信度从 `disagreement + surprise` 换成 bank W 上的
`[disagreement, surprise, state_norm]` 三维高斯密度。5 个种子。

## 结论

**六条全过，`e2e_v8_ready=true`。** 这是共享最终状态 + bank W 尺度门的 ready。

| 判据 | 门槛 | 实测（5 种子均值） | 结果 |
| :--- | :--- | :--- | :--- |
| WM R² | ≥0.90 | **0.9938** | 过 |
| WM 选择性 MSE | ≤0.10 | **0.00448** | 过 |
| DPAR top-1 | ≥0.80 | **0.9620** | 过 |
| 状态控制 | ≤0.35 | **0.2352** | 过 |
| OOD AUROC | ≥0.75 | **0.9562** | 过 |
| OOD 弃权 | ≥0.80 | **0.9368** | 过 |

## 与 v7 的对照

| 门 | v7 / v8 特征 | OOD 弃权 | OOD AUROC |
| :--- | :--- | :--- | :--- |
| zsum（v7 基线） | disagreement + surprise | 0.786 | 0.882 |
| gauss2 | + 二维高斯 | 0.8228 | 0.8806 |
| **gauss3（v8 主门）** | **+ state_norm** | **0.9368** | **0.9562** |
| norm-only | 只用 state_norm | 0.8980 | 0.9399 |
| mahalanobis（探索） | bank W 28 维全状态 | 0.9900 | 0.9914 |

**驱动因素是 `state_norm`**：gauss2 只有 0.8228，加入范数后到 0.9368；norm-only 单独
0.8980。也就是说，这 1.4 pp 的缺口是尺度特征闭合的，不是 disagreement/surprise 的
排序改善。全状态 Mahalanobis 更高（0.990），但 test 覆盖率只有 0.7612，低于 80% 口径，
只作探索，不参与主判据。

## 这个 ready 覆盖什么

- **覆盖**：共享最终状态（56 维双 bank）、WM/DPAR 共存、DPAR 绑定、状态控制 chance、
  A/B ×3 尺度 OOD；
- **不覆盖**：通用 OOD。`state_norm` 是尺度敏感特征；v6/v7 已表明信息丢失型 OOD
  （量化）检测不到。这个 0.9368 只对“输入整体放大 3 倍”成立；
- **不覆盖**：阶段四整体验收；DPAR 仍是每幕独立建库；v5 的顺序组合 6/6 仍独立成立；
- v6 的单 bank 干扰、v7 的 5/6 原样保留，不被 v8 追认。

## 边界

1. OOD 是 A/B ×3；不要外推到协方差/频率/相位/信息丢失型偏移。
2. gauss3 的 test 覆盖率 0.790，在 0.78–0.82 内；mahalanobis 的 0.7612 不在口径内，只作探索。
3. WM 读出的 `state_norm` 是 bank W 的 L2；bank D 不参与置信度。
4. 5 个种子、500 幕；单次运行 78.6 s；没有调阈值/特征/维度。
5. `e2e_v8_ready` 不是阶段四整体验收；它只说明这一组判据在共享状态 + 尺度 OOD 下通过。
