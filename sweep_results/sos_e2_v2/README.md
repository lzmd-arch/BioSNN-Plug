## 为什么 B 臂学不动（诊断）

**在迷宫里，"曼哈顿距离变近"是个很差的稠密信号**：墙让大多数步既不靠近也不远离
（撞墙 = 原地 → 距离不变 → 记 −1）。整条轨迹的 reward 几乎全是 −1，期望差是常数，
策略梯度几乎没有区分度。

换句话说：**臂 B 的奖励是按开阔网格设计的，不是按迷宫设计的。** 这是设计问题，
不是学习率或初始化的问题（v1 已经排除了学习率）。

## 这次三连失败（v1 → v2）真正说明什么

1. **A 臂（`−surprisal`）两次都退化**——和预注册的预期一致，"最省事的策略就是蹲着"。
   ADR-0030 里 P2 的字面定义**不能用**。
2. **B 臂两次都学不动**——稠密外部信号在迷宫上是常数化的。
3. **C 臂（稀疏成功）两次都接近 0**——样本效率低到 2000 个 episode 不够。

也就是说：**这三条 reward 都不足以驱动一个 tabular softmax 在迷宫里形成搜索**。
这不是"SoS 被证伪"，而是**"这三条 reward + 这个策略类"这个组合被证伪**。

## 接下来该做的（不再自动跑）

按 ADR-0030 的死亡条件，这条线要停下来重新设计，而不是继续换 reward 试。三个候选方向：

| 方向 | 要点 | 代价 |
| :--- | :--- | :--- |
| **模型预测式 reward** | `r = 模型对"从这里能到终点"的预测概率`（要短程 rollout） | 实现大，但和"搜索过程"真正相关 |
| **换策略类** | tabular softmax → 有状态记忆的策略（ALIF 群体） | 回到 W3 的老问题 |
| **换任务** | 迷宫 → 需要"多步规划"但稠密信号可用的任务 | 又一轮任务设计 |

**在写新的预注册之前，不该再跑实验。**
