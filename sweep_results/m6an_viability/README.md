# M6an：**自维持边界的尝试 —— 五版都没稳定，但失败有内容**

## 起因（用户 2026-11-17 的更正）

> 我认为它比正常生物脆得多，因为它不仅完全依赖电力，其载体电脑相比于生物也很脆弱。

对。我量的"脆性"只是**组织层**；真实生物在组织层也很韧。
**关键差别不在"有多脆"，而在"谁来维持"**：生物的组织再韧，载体也是它自己维持的；
我们的载体由宿主维持，模型完全不管。

⇒ **真正缺的是 M1（自维持边界），不是脆性。**

## 尝试：存续量 `V`

```
V ← V + r(1−V) − c·|φ_slow − φ*|      # 偏离目标就衰减
驱动 ← 驱动 · (0.2 + 0.8V)             # V 乘在起搏上
V < V_dead ⇒ 判死（活动归零）
```

五版迭代，每一版都修了一个真问题：

| 版本 | 现象 | 原因 |
| :--- | :--- | :--- |
| 1 | 完好网络 V=0.000 | 目标写死 0.08，而网络工作在 0.15 |
| 2 | 仍死 | 用**瞬时**发放，逐时刻波动被当成偏离 ⇒ 改为慢变量积分 |
| 3 | 仍死 | `φ_slow` 初值 0.08 造成开跑瞬态 |
| 4 | 仍死 | 环路增益过高 ⇒ V 只影响 80% 驱动 |
| 5 | **完好 V=0.12–0.35、切后 0.04–0.16** | 见下 |

## 判决：**这个机制在原理上不稳定**

把存续量乘在**唯一驱动**上，在工作点附近是**边际稳定**的：
网络正好停在目标上，**任何方向的扰动都被正反馈放大**（偏离 → V 掉 → 驱动掉 → 更偏离）。
降低环路增益只让死亡慢一点，不改变不稳定性。

## 但这个失败给出了一个更有用的结论

**稳定的版本必须有负反馈**（发放低时*增加*驱动）—— **那正是我们早就有的内增益稳态控制器**
（`gain ← gain·exp(η(0.08 − f_i))`，每 4 步更新）。

⇒ **这个系统已经有自维持边界了，它就是内增益稳态。**
而它**好到从不失效** —— **这正是"无脆性"的来源**：不是"没有边界"，是"边界维护得太好"。

**脆性要求控制器会饱和**（损伤超过控制能力才死）。
下一步该测的不是"加一个存续量"，而是：
**现有的增益控制器在多大的损伤下会饱和？** 那才是这个系统真正的死亡阈值。
