## 为什么 v6/v7 失败而 v8 过

v6 的量化 OOD 已让全量误差升到 6.38×，但 `gauss3` 只看 disagreement/surprise/
state_norm，**没有“state 能否重建观测输入”这一维**，所以高误差样本的置信度没有降。
v8 把逐样本重建误差加进门：量化让输入幅度丢失，state 仍像 in-dist，但重建误差升高；
尺度 OOD 同时抬高 state_norm。两个维度分别覆盖两类偏移。

## 边界（不许改口径）

1. **只覆盖输入变换型 OOD**（量化、尺度）；不覆盖标签漂移、状态零空间内的变换、
   或与输入一致的分布偏移。不能写成“通用 OOD”。
2. `errors` 是同一个线性读出的预测误差，不是独立自编码器；推理时观测输入可得，因此
   不是标签泄漏；若部署时输入不可得，这个门不适用。
3. 覆盖率校准余量薄（单种子出带），不能写成“稳定 80% 覆盖”。

## 结论

阶段四元认知现在有两条可用路线：v3（分类标定）与 v8（**重建一致性 + 尺度**）。
v4 只对尺度 OOD 有效、v5 旋转不构成 OOD、v6/v7 量化门失效——这些负结果原样保留。
