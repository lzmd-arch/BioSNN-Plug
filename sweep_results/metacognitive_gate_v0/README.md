## 读数

- **置信度有信号但不强**：80% 覆盖下准确率从 0.492 抬到 0.558（+6.5 pp），但正确性 AUROC
  只有 0.716，低于 0.75；
- **校准严重失败**：softmax 最大概率只有约 0.01（阈值 ~0.0107），置信度整体贴着 0；
  ECE 0.48。温度搜索的预注册网格是 **[0.5, 5.0]**，下界 0.5 仍然太"钝"——需要把 T 往下
  扩（或改用 margin 置信度），这是 v1 的设计问题，不是本轮可以事后改的；
- 这也说明"选择性准确率过线"不等于"模型知道自己不确定"：增益过、AUROC/ECE 不过，
  v0 不能写成 ready。

## 结论

**v0 不 ready。** 按预注册不扩 T 网格、不换置信度、不改判据。v1 的自然方向：
更宽的 T 网格（含 T<0.5）或 margin/ensemble 置信度；OOD 与 LLM 触发仍留后续。
