# 损伤自知（v20）：**我的预测被推翻** —— 部分补偿掩盖不了信号

## 一、先修一个 AUC 方向 bug

我的 `auc(pos, neg)` 算 `P(pos > neg)`，而**损伤后发放更低** ⇒
完美可分时给 **0.000**，看起来像"完全不可分"。

取 `max(a, 1−a)` 后：

| 损伤比例 | 无补偿 | 有补偿 |
| ---: | ---: | ---: |
| 10% | 0.770 | 0.765 |
| 25% | 0.990 | **1.000** |
| 50% | **1.000** | **1.000** |

⇒ **A-0 过**（0.000 其实就是 1.000）。

## 二、A-1 不过：补偿**没有**掩盖信号

| 条件 | 发放 完好 → 损伤（50%） |
| :--- | :--- |
| 无补偿 | 0.0296 → **0.0011**（27×） |
| 有补偿 | 0.0634 → **0.0197**（**3×**） |

**补偿只补回了一部分。** 我们用的是 4 轮迭代、增益 clip 在 [0.2, 5] ——
离"把活动完全拉回"还差得远。

⇒ **"稳态与损伤自知互斥"这个两难，在当前补偿强度下不成立。**
它要成立，得先把补偿做到**活动完全恢复**（那本身是下一轮的题目）。

## 三、一个没预期的发现：**死亡会级联**

| 损伤比例 | 无补偿的静默比例 |
| ---: | ---: |
| 0% | 0.012 |
| **10%** | **0.196** |
| 25% | 0.590 |
| 50% | 0.908 |

**杀掉 10%，静默比例涨到 19.6% —— 接近两倍。**

⇒ 静默计数不只是一个"损伤计"，它**放大了损伤**：被削弱的网络会让更多神经元
掉到阈值以下。这是**级联失效**，不是线性损失。

## 四、判

| 编号 | 结果 |
| :--- | :--- |
| A-0 无补偿时能看见损伤 | ✅ 过（1.000） |
| **A-1 补偿掩盖信号** | ❌ **不过**（补偿是部分的） |
| A-2 数量通道不被掩盖 | ✅ 过，且 10%/25% 也过（非平凡） |

## 五、这一轮学到了什么

1. **预测被证伪**：部分补偿不掩盖信号。两难需要"完全补偿"才出现 ——
   而那正是我们没有的；
2. **级联失效**：10% 的单元损失导致 20% 的沉默。这解释了为什么 v8 里
   "少 25% 就塌两个数量级"——**损失被放大了**；
3. **方向 bug 又一次**：这是今晚第五次"分母/方向"类错误
   （`to_ball` 饱和、损伤塌陷、读出容量、batch 分母、AUC 方向）。

## 六、下一步

1. **把补偿做到完全**（更多迭代 / 不 clip），再测 A-1 —— 那才是那个两难成立的条件；
2. **级联失效本身值得单独测**：它和"临界点"是同一件事的两面
   （临界系统对扰动有放大作用）。
