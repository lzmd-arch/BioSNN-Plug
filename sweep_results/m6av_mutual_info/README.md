# M6av：**互信息确认了整合排序 —— 但它同时揭示高维状态的关联是非线性的**

## 论点（用户 2026-11-17）

> 纠缠熵本就是信息。

我量"整合"用的是两半球平均发放的 **Pearson 相关** —— 一个**线性**量。
互信息 `I(A;B)` 数的是**存在于关联里的比特**，才是信息本身。

## 结果（3 种子，`per_fam=64`）

| regime | 线性 r | **半球 MI** | 成对 MI | 高斯界 `−½ln(1−r²)` |
| :--- | ---: | ---: | ---: | ---: |
| **全局** | **+1.000** | **1.135** | **0.576** | 发散（截断 6.56） |
| 高维 | +0.130 | **0.067** | 0.0004 | 0.014 |

| 判据 | 结果 |
| :--- | :--- |
| AV-0 发放在窗内 | 过 |
| AV-1 互信息超过高斯界（>1.5×） | 高维档 4.9×，**过** |
| **AV-2 排序反转？** | **没有**：全局 1.135 vs 高维 0.067 —— **全局整合强 17 倍** |

## 一、排序没有反转：交换曲线成立

```
全局：r = 1.000，MI = 1.135 nats，成对 MI = 0.576（接近 6 箱的极大值 ln6=1.79）
高维：r = 0.130，MI = 0.067 nats，成对 MI = 0.0004
```

**全局档是一个近乎完全整合的系统（每对神经元都强依赖）；高维档近乎独立。**

⇒ **"整合 vs 维度"的交换没有被推翻。** 我在此前一条消息里说"这是度量假象"——
**那句话是错的，已撤回。**

## 二、但互信息揭示了一个线性相关看不见的东西

高维档：`r = 0.13` 而 `MI = 0.067`，**是高斯界（0.014）的 4.9 倍**。

⇒ **高维状态那一点点整合是强非线性的。** Pearson 相关（0.09）看见了方向，但没看见量。

**「纠缠熵本就是信息」这条本身是对的** —— 它确实找回了被线性量丢掉的部分，
**只是找回的量不足以改变量级排序。**

## 三、一个必须记的仪器缺陷

**`r → 1` 时高斯界 `−½ln(1−r²)` 发散**，所以"MI / 高斯界"这个比值判据在**全局档上无定义**。
我把它截断到 6.56（r 截到 0.999999），才得到 0.17× —— **这个数不可引用。**

**判据不能跨 regime 用同一个比值。** 正确的比较是**绝对 MI**（1.135 vs 0.067）。

## 四、方法学

这是今晚**第三次**"用二阶/线性统计量去量一个本质是信息论的对象"：
1. 64 维线性读出把低维状态的信息低估了 5 倍（0.101 → 0.571）；
2. 方差参与比（PR）可能低估维度；
3. **Pearson 相关低估整合** —— 但这次**修正后排序不变**，所以它是"低估但没颠倒"。

**⇒ 结论：这三个量都是信息的下界。低估的方向一致，但只有第一个大到能颠倒结论。**
