# R12：CA 的局部修正——F1 守卫复跑（2026-11-10）

**预注册**：[`research/sel/prereg-lm-r12-ca-local-fixes.md`](../../research/sel/prereg-lm-r12-ca-local-fixes.md)
**原始数据**：[`f1_guard.json`](f1_guard.json)

## 一句话

把 ψ 掩码改对（F1，一行改动），按 R11 的配置在真语料大折上重跑 8,000 步：
top-1 **0.1215**（Δ **−4.53pp**），而 R11 的峰值是 0.1138（Δ −5.31pp）——
**F1 单独值 +0.78pp**，落在噪声（±0.6–0.9pp）的**正边缘**，且四个评测点里有三个同向。

**⇒ R11 的 −5.31pp 被取代：F1 之后的基线是 −4.53pp（8,000 步，仍在上升）。**

## 结果

| :--- | ---: | ---: | ---: | ---: |
| **F1 守卫 top-1** | **0.0967** | **0.1127** | 0.1110 | **0.1215** |
| R11（错误掩码）同点 | 0.0890 | 0.1044 | 0.1127 | 0.1138 |

- **CE 也同步更好**（每个点都低 0.02–0.13）；
- **训练后发放率 0.0316**（R11 是 0.0746）——修正改变了动力学，不只是学习信号；
- **8,000 步仍在上升**（`running max` 就是最后一个点），所以这个 Δ **不是峰值**。

## 判据

预注册写的是：「预期 Δ 在噪声内（±0.6–0.9pp）不动——**若明显变好，说明 F1 本身值钱，先报再往下走**」。

- 实测 **+0.78pp**：**在噪声的正边缘**，不构成"明显变好"，但也不在"不动"那一侧；
- 三正一负、CE 全线更低 ⇒ 判 **"边界偏正"**，**先报**（按预注册的约定），不擅自把它当成新基线之外的结论。

## 三件必须一起说的事

### 1. F1 在训练后比在初始化时值钱得多

`sweep_results/lm_eprop_gradcos/` 的补测（单抽头）：

| 检查点 | `eprop` | `+F1` |
| :--- | ---: | ---: |
| 随机初始化 | 0.8151 | 0.8162（+0.00） |
| 2,000 步 | **0.6538** | **0.8876（+0.234）** |
| 8,000 步 | 0.8800 | 0.9321（+0.052） |

**训练早期的余弦缺口最大，F1 的修复量也最大**。这解释了为什么 +0.78pp 的 top-1 增益在
2k/4k 就已经出现——它不是"多训了一点"，是**从第一步起方向就更对**。

### 2. 这不是"又一个调参"，是一个有出处的错误

`TokenEProp.step` 用**本步更新后**的不应期计数器去掩 ψ，而仓库自己的
`research/eprop/traces.py::refractory_mask` 的 docstring 写死"判据是上一步之后的计数器"；
A 线（`brainregions/`、`predictive.py`）用的都是正确口径。**这是只有 LM 线走岔的一条**。

### 3. 8,000 步不是峰值，F2 之前要先定"比在哪"

F1 守卫到 8,000 步仍在上升（R11 在 8,000 步见顶、之后回落）。所以 E2 臂若在 8,000 步比较，
**"更快"与"更高"分不开**。两条路：

- **(a) 各臂都跑到 16,000 步、按规则③ v3 比峰值**（每臂 3.3h，最干净）；
- **(b) 各臂都在 8,000 步同预算比较，并注明两边都未到峰值**（每臂 1.7h）。

**预注册里没有写死这一条**，需要在跑 F2 之前定下来。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp）——+0.78pp 是边缘证据；
- 8,000 步、未到峰值；
- **R 系全部历史臂（R0–R11）在错误掩码下跑出**，本文件不重跑它们；
- 字符级 next-token，**不代表能闲聊**。
