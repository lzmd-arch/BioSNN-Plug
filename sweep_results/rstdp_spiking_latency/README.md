## 读法

1. **潜伏期在计数读不懂的地方有信号**：种子 0 与 4 上计数 `S` 恰好是 **0.00**（差方向小到改变
   不了整数计数），而潜伏期 `S` 是 **0.75 / 0.54**——连续量确实比整数计数敏感。
2. **但也没到 2**：最好的种子是 0.90，5 个种子全在 0.5–0.9。按 D14 量到的降噪斜率
   （`snr ∝ K^0.6`），要到 2 还得平均 **K≈8 个窗口**，把代价乘上去。
3. **删失为零**：`baseline_period=5` 的偏置让两列在 25 步内必然发放，所以潜伏期不是靠删失
   选出来的假信号；但也说明**第一次发放的时刻很大程度上由偏置节律决定**，输入只负责把它
   前后挪。
4. 空对照全 0：不是常数偏置或数值噪声造出来的。

## 与 D10–D14 拼起来

四种读出（计数 / 低通率 / 膜电位 / 潜伏期）在**真实幅度**上都不够；唯一的有效杠杆是
**平均多个窗口**（D14：`snr ∝ K^0.6`），代价是每步 K 倍的窗口评估。

也就是说，阶段三「执行层脉冲化」的卡点可以写成一句可检验的话：

> **在 L1 归一化 + 阈值 1.0 的工作点上，学习规则产生的差方向（相对幅度 0.5–7.3%）比这个
> 读出能分辨的尺度小一个数量级**——不管用哪种读出，除非平均 8 个以上窗口。

## 边界

- 公共模式是随机构造的，不是训练后的真实列；
- 潜伏期丢掉第一次发放之后的信息；点状态网格，不是完整状态空间；
- `S ≥ 2` 只说明「单窗口能分辨」，不说明训练会更好；
- 删失为零是**偏置节律**的结果，换工作点（例如 `baseline_period=None`）会变。
