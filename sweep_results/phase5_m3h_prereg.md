# 预注册：阶段五 M3h——可辨识的调度（M3g 的修正版）（2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景

M3g 判据全过但是平凡解：检索分只有 0/1，阈值不可辨识，ES 停在初始点 (0.5, 1.0)。
M3h 只改**数据生成**，让阈值可辨识，并加一条「必须离开初始点」的检查。

## 改动（只改检索分）

- 会话结构与 M3g 相同（20 训练 + 20 留出、知识/闲聊/记忆轮）；
- 知识轮的检索分改为**连续值**：已预置的知识条目分三档
  `{0.20, 0.40, 0.60}`（等概率），未预置为 `0.0`；
- 已预置的题**无论是否调用都算完成**（记忆里有答案），但调用要计成本
  （每次 0.05 / 会话）；未预置的题只有调用才算完成。
- 于是最优阈值在 `(0, 0.20]`：高于 0.20 会把 0.20 档的已预置题误调用（浪费成本），
  低于 0 则不可能。初始点 0.5 会误调用 0.20 与 0.40 两档。

## 判据（10 个种子，全部满足才 `m3h_ready=true`）

1. **严格更优**：留出集上 `utility_es > utility_rule` 的种子数 ≥ **7/10**；
2. **不更贵**：`calls_es ≤ calls_rule` 的种子数 ≥ **7/10**（注意这里要求不高于，不是 +1）；
3. **离开初始点**：`‖θ − θ₀‖ ≥ 0.1` 的种子数 ≥ **7/10**（θ 为两维，欧氏距离）；
4. **确定性**：同种子重跑，θ 与调用序列逐位相同。

任一不过 → `m3h_ready=false`，负结果保留，不调 σ/λ/代数。

## 边界

- 仍是构造性完成率（已预置=完成，未预置=调用即完成）；不比较回答质量；
- 合成会话、三档分数；不外推；
- 两维搜索空间仍小。
