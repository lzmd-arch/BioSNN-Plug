# 预注册：W3 D15——首发放潜伏期读出（在**真实幅度**上能不能分得开，2026-10-29）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（D10–D14 已测，不是猜测）

- D10：训练后的差方向**存在**（4/5 种子是同范数随机方向的 2.95–13.4 倍），但相对幅度只有
  **0.5–7.3%**；
- D11/D12：在计数读出上，即使把差方向抬到占权重预算 30%，Δ 计数极差也只到 0.80；
- D13：换低通率/膜电位读出，λ=0.10 上可分辨度 `S` 只有 0.58–0.65，且 **S 不随 λ 涨**；
- D14：平均 K 个窗口能把 `snr` 从 0.57（K=1）抬到 2.12（K=8），但**只在 λ=0.30 上**成立；
  在真实幅度（λ≈0.05）上，确定性编码的计数差**恒为 0**——信号根本没出来。

D14 还留了一个关键事实：**计数差是整数格点上的量**，幅度小时被量化吞掉。D15 换一个**连续的、
对膜电位更敏感的**量：**首发放潜伏期**（time-to-first-spike）。这类读出在 SNN 文献里以信息
密度高著称，且不需要改学习规则、只改写出的取数方式。

## 协议（同一构造探针，不训练）

构造沿用 D12（`w = weight_norm · ((1−λ)·m ± λ·d)`，`signed`、`weight_norm=1`，
`threshold=1.0`、`n_refractory=2`、`baseline_period=5`），21 点极角网格、每点 32 个冻结窗口。

**λ 取真实幅度**：`{0（空对照）, 0.01, 0.03, 0.05, 0.10}`——D10 量到的训练后相对幅度是
0.5–7.3%，所以 0.01–0.10 才是「训练能得到」的区间。

### 读出

| 读出 | 定义 |
| :--- | :--- |
| `latency` | 窗内**第一次**发放的时刻（0 起）。**只要有任一列整窗未发放，这个窗口作废**（删失），作废比例必须报 |
| `count` | 窗内脉冲个数（现状，对照） |

## 判据（与 D13/D14 同一把尺子）

```
S(读出, λ) = 网格上 mean Δ 的极差 ÷ 单窗口 Δ 的标准差
```

- `latency` 在 **λ=0.05** 上 **4/5 种子** `S ≥ 2.0` → `latency_readout_viable=true`；
- 空对照：λ=0 时 `S ≤ 0.5`（任意读出、任意种子）；
- **前提条件**：`latency` 的删失比例（整窗未发放的窗口占比）在 λ=0.05 上 **≤ 20%**；
  超过就判 `censored_too_much`，即使 `S` 好看也不算——那是删失选出来的假信号；
- 同时报 `count` 在同样 λ 上的 `S`，作为「同一条尺子下的对照」。

## 读法护栏

- 潜伏期读出的**延迟**是它的固有代价：一个窗口要跑到第一次发放才有值；若第一发放很早，
  后续 20 步的信息被丢掉；
- `S ≥ 2` 只说明「单窗口能分辨」，**不说明训练会更好**；
- 潜伏期对**阈值处的工作点**极敏感，所以必须同时报删失比例与每列平均计数；
- 不把「换读出能分辨」写成「阶段三的规则问题解决了」。

## 不做什么

- 不训练、不改 STDP、不改窗口长度与阈值；
- 不调 λ 之外的构造参数（预算与符号结构在 D12 已测）；
- 不用删失窗口填补（不把未发放记成 25 或 0）——那是把删失当数据；
- 不因为潜伏期好看就顺手改 Actor 的读出——实现要另一份预注册。

## 边界

- 公共模式是随机构造的，不是训练后的真实列；
- 点状态网格，不是完整状态空间；
- 删失比例是硬指标：`baseline_period=5` 的偏置节律会让「第一次发放」很多时候由偏置而非
  输入决定，这一点在结果里必须单独说明。
