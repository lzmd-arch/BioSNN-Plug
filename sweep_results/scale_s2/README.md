# 规模实验 S2：精度随规模怎么长——**稀疏 +14.6pp，稠密在 1024 就撞墙**（2026-11-03）

**预注册：** [`research/scale/prereg-s2.md`](../../research/scale/prereg-s2.md)

## 判决：三条全过

| # | 判据 | 门槛 | 实测 | |
| :--- | :--- | :--- | :--- | :--- |
| **S2-0** | 所有配置在 8 GB 内 | < 8,000 MiB | 最大 3,899.5 MiB（稀疏 8192） | ✅ |
| **S2-1** | 规模有用 | `acc(8192) − acc(1024) > 2pp` | **+14.6pp** | ✅ |
| **S2-2** | 稀疏不输稠密（1024） | `稀疏 ≥ 稠密 − 2pp` | 稀疏 **+4.1pp** | ✅ |

## 稀疏臂（事件驱动）

| n_rec | 准确率 | 显存 | 耗时 |
| ---: | ---: | ---: | ---: |
| 1,024 | 0.628 | 676.0 MiB | 1,120 s |
| 2,048 | 0.684 | 1,125.2 MiB | 1,112 s |
| 4,096 | 0.735 | 2,057.5 MiB | 1,114 s |
| **8,192** | **0.774** | **3,899.5 MiB** | 1,101 s |

## 稠密臂

| n_rec | 准确率 | 显存 | 耗时 |
| ---: | ---: | ---: | ---: |
| 256 | 0.4713 | 1,104.1 MiB | 86 s |
| 512 | 0.5270 | 1,976.7 MiB | 219 s |
| 1,024 | 0.5872 | 3,700.4 MiB | 734 s |
| 2,048 | （放不下：11.7 GB，见 [phase4_scale](../phase4_scale/README.md)） | | |

## 预注册的预期错了，照登

`prereg-s2.md` 里写的是：

> **S2-1 我倾向不过**：W2 在 256 神经元上 250 epoch 就有 0.8889，sMNIST 本身就饱和得快；
> 2 epoch 下更可能看到的是"都没学到多少"，规模差异被压平。

实测：**每翻一倍涨 5pp 左右，1024→8192 共 +14.6pp。** 2 epoch 下规模差异不但没被压平，
还是这条管线里可见的最强效应。

这条预期错在哪：我把"W2 在 256 上 250 epoch 能到 0.8889"读成了"小网络够用"，
但那是**训练充分**时的饱和值；2 epoch 的预算下，网络的**容量**才是决定性的。
更长的训练会不会把差距抹平，本实验回答不了——那是 S4 的问题。

## 两条臂的交叉点

| | 显存/神经元 | 时间随规模 |
| :--- | ---: | :--- |
| 稠密 | **3.6 MiB**（1024 时） | 86 → 219 → 734 s（**超线性**） |
| 稀疏 | **0.48 MiB** | 1,120 → 1,101 s（**恒定**） |

- **显存**：稀疏省 7.5 倍；
- **时间**：小规模时稠密快（86 s vs 1,120 s），1024 时稠密仍略快（734 vs 1,110），
  但稠密的曲线在陡涨、稀疏是平的——**交叉点就在 1024 附近，再往上只有稀疏能走**。

## 这一轮对主线的意义

ADR-0031 的回退条件「提升 ≤2pp 就停止加宽」**不触发**。所以在 8 GB + 这条管线上，
**规模是一个真实有效的轴**，而稀疏路径是唯一还能走的实现。

下一个问题变成：**能走多远、什么时候掉**。按 0.48 MiB/神经元的线性斜率外推，
16k ≈ 7.6 GB（贴着上限）、32k ≈ 15.2 GB（放不下）——已写进
[`research/scale/prereg-s3.md`](../../research/scale/prereg-s3.md)。

## 边界

- **2 epoch、单种子**：绝对精度很低（0.47–0.77），**不得**与 W2 的 250-epoch 0.8889 比较；
- 单种子下 5pp 的差是明确的，但 2pp 以内的差本实验分不清——那要多种子；
- 稠密 2048 的数字来自 `phase4_scale`（预算不同：2 epoch 全量、种子 0，与本节一致），
  且它是 **11.7 GB，放不进 8 GB**。

## 自证

```
# 稀疏
uv run python scripts/run_event_driven_10k.py --n-rec 8192 --samples 60000 --epochs 2 \
    --batch-size 8 --test-samples 1000 --device cuda --out <仓外>
# 稠密
uv run python -m research.eprop.train_sequential --n-rec 1024 --epochs 2 --device cuda
```
