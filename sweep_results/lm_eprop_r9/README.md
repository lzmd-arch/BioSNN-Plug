# R9：归因——4 个**相同** τ 不涨，**增益来自多样性，不是参数**（2026-11-09）

**预注册**：[`research/sel/prereg-lm-r9-attribution-identical-taus.md`](../../research/sel/prereg-lm-r9-attribution-identical-taus.md)
**原始数据**：[`r9.json`](r9.json)
**对照**：[`../lm_eprop_r8/README.md`](../lm_eprop_r8/README.md)（4 个不同 τ）、R0b 大折（单 EMA）

## 一句话

把读出做成 4,096 维但**四个 τ 全设成 8.0**（四组特征逐位相同，**宽度 4×、信息 0×**）：
top-1 **0.0624**，Δ = **−10.44pp**；单 EMA 基线是 **−10.12pp** ⇒ **改善 −0.32pp**。

按预注册判据 **R9-2（≤ +1pp）成立** ⇒ **R8 的 +3.88pp 来自 τ 多样性，不是来自 4 倍的参数。**

## 三件必须一起说的事

### 1. 这是本轮最干净的一次归因

R8 同时动了宽度与多样性，R9 把**宽度与参数完全保留、只把多样性归零**——
两个臂的差别只有"四个抽头是不是同一个时间尺度"。结果差 **+4.20pp**（−6.24 对 −10.44）。

**−0.32pp 落在噪声内**（13 对测试，±0.6–0.9pp），所以准确说法是"**没有可测的增益**"，
不是"相同 τ 更差"。

### 2. 按预注册的决策树：**8 τ 值得做**

预注册写死的规则是：R9-2 成立 ⇒ τ 多样性是真梯度 ⇒ **加抽头不是白拧**。
（反过来，若 R9-1 触发，就说明 R8 的增益是优化假象，要改写 R8 的结论——**没有发生**。）

同时按同一条树：**N=4,096 + 单 EMA** 那个候选**作废**——它测的是"宽度从神经元来"，
而 R9 已经说明"宽度本身（无新信息）买不到东西"，那个臂的优先级降到最低。

### 3. 但"多样性"不等于"更多抽头一定更好"

R9 只证明**从 1 个 τ 到 4 个不同 τ** 这一步值 +3.88pp。**4 → 8 是另一个剂量点，没测。**
而且从 R10 的叠加率（45%）看，τ 维度的边际收益**很可能也在递减**。

## 边界

- **单折、单种子、13 对测试**（噪声 ±0.6–0.9pp），−0.32pp 与 0 不可分辨；
- 8,000 步在 CE 的上升段；
- 相同 τ 的四组特征**逐位相同**，所以这一臂在函数空间里就是基线——它测的是"参数化/优化"有没有副作用，
  不是"另一种宽度"；
- 字符级 next-token，**不代表能闲聊**。

## 对路线的影响

1. **"读出维度是杠杆"这句话要收紧成"读出维度的来源必须是不同的时间尺度/不同的量"**——
   单纯复制同一组特征 4 遍没有用；
2. **8 τ 晋升为下一个剂量点**（预注册要另写）；
3. N=4,096 候选**降级**（R9 的决策树已判）。
