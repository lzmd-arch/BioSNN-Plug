# M6aq / M6ar：**状态门控与激素 —— 四版都没让三轴共存，但失败模式有内容**

## 用户的两条提案

> 全局场和局部场也许并不会同时出现，而是不同状态下不同场这种协同补充的形式。

> 3 轴共存也许需要激素和基因的帮助。…激素不是固定值，同时激素和门控在生物上本就同时存在。

## 四版门控，全部失败，但失败原因逐版收敛

| 版本 | 谁驱动切换 | PR | 整合 | MLP | 结论 |
| :--- | :--- | ---: | ---: | ---: | :--- |
| 1 瞬时门控 | φ（当前活动） | 1.00 | 1.000 | 0.613 | 锁在全局（λ≈0.17） |
| 2 一阶滞后 τ=50 | φ 的慢版本 | 1.00 | 1.000 | **0.722** | 收敛到不动点 |
| 3 施密特滞后 | φ + λ 自移 | 1.00 | 1.000 | 0.587 | 仍锁死 |
| 4 自主锯齿节律 | 独立节律源 | **0.00** | 0.000 | 0.078 | **网络死亡** |

**对照**：静态局部 `PR 43.91 / 整合 0.098 / MLP 0.387`；静态全局 `PR 1.00 / 整合 1.000 / MLP 0.352`。

## 一、为什么门控必然锁死（结构性原因）

**两个 regime 的发放范围不相交**：局部 ≈0.014、全局 ≈0.13。
门控拿 φ 去比一个固定阈值，一旦进入某个 regime 就饱和（λ 卡在 0 或 1）。
⇒ **它是双稳态开关，不是振荡器。**

**⇒ 交替必须有独立于被切换对象的节律源。**

## 二、激素（级联）确实改善可读，但不产生维度

按用户更正改成级联（激素有自己的释放/清除，且**移动门控阈值**而非直接加权场）：

| 臂 | PR | 整合 | MLP |
| :--- | ---: | ---: | ---: |
| gate_only | 1.00 | 1.000 | 0.389 |
| gate_horm τ=500 | 1.00 | 1.000 | 0.464 |
| gate_horm τ=2000 | 1.00 | 1.000 | **0.519** |

**激素把解码单调抬上去（0.389→0.519），但 PR 恒为 1.00。**
⇒ **它改善的是"可读"，不产生"维度"。** 三轴仍不共存。

## 三、第四版的失败：**机制未明**

自主锯齿节律（周期 512 / 1024）把门控阈值扫过两个 regime，**两档都把网络打死**（发放 0.0000，
64–128 步内归零）。

**我起初判定原因是"起搏电流 0.5 = 阈值 0.5 ⇒ 没有自启动能力"。这个判定是错的。**
冷启动实测（`v=0`、无历史）：全局场 0.1548、局部场 `gl=2` 0.0152、`gl=6` 0.0107
—— **全部起得来**；`i_pace` 0.5→0.9 无影响。

**⇒ sweep 臂死亡的真实原因未查明。这是未解决的实现问题，不是机制结论。**
（已知的只是：同场强固定时冷启动正常，所以不是场强本身。）

## 五、限定

- 3 种子；`per_fam=32`；一个 `p_long=0.5`、一个 `field_radius=2`；
- 门控与激素的参数（阈值、宽度、τ）只各试了 2–3 档，**没有系统扫**；
- 判定用 PR / 整合 / 分离 / 线性 / MLP 五项，**未做多重比较校正**；
- 第四版的死亡是**实现层面的确定结果**（发放逐位为 0），不是噪声。
