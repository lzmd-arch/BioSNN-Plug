# 预注册：W3 D16——把差方向对「状态均值」正交化（2026-10-30）

**状态：判据先落盘，实现与运行随后。** 结果不得回改判据。

## 背景（D9–D15 已测，不是猜测）

- D10：训练后的差方向 `Δw = w_0 − w_1` **确实随状态变**（4/5 种子是同范数随机方向的 2.95–13.4 倍），
  但它的相对幅度只有总驱动的 **0.5–7.3%**；
- D9：列间去共模把这个幅度做大了一倍（Δ 极差中位 0.20→0.60），**贪心的符号仍然不随状态变**
  （极角 slope 0/10）；
- D11–D15：阈值/预算/读出都改不了这件事。

**新的假设（D16 只测这一条）**：`Δw` 里有一个**沿「状态平均输入模式」的大分量**——它让
`Δw·p(s)` 在所有状态上同号、只改大小，于是 argmax 恒定。把这个分量**投影掉**之后，剩下的
才是真正随状态变的部分；如果它就是信号的来源，那么投影后的 `Δw` 应当**跨零**（`Δ·p(s)`
在某些状态为正、某些为负），贪心动作也才有机会随状态翻转。

## 协议（诊断，不训练新策略）

- 臂：D6-B（`count-aligned` + `spiking_temperature` 0.1→0.02），5 种子、800 回合、`actor_after="final"`；
- 状态集：与 D10 相同的 21 点极角网格（其余分量为 0）；
- **干预**（只动最终的权重，不再训练）：

```
p̄      = mean_s p(s)                    # 网格上编码模式的均值
Δw'    = Δw − (Δw·p̄ / ‖p̄‖²)·p̄           # 减掉沿 p̄ 的分量
w_0'   = c + Δw'/2,  w_1' = c − Δw'/2    # c = (w_0 + w_1)/2
再逐列 L1 归一化回原列范数
```

- 测量（干预前后各一次，**同一批冻结窗口**，每点 20 个）：
  - `Δin(s) = (w_0 − w_1)·p(s)` 的**符号**（期望值，无采样噪声）；
  - 21 点 `Δ` 计数的**极差**与**跨零与否**（min < 0 < max）；
  - 极角 `slope = P(left|θ=+0.2) − P(left|θ=−0.2)`（20 窗口，贪心）。

## 判据（先写死；逐种子，≥4/5 一致才成立）

1. **跨零**：干预后 `Δin(s)` 在 21 点上**跨零**（min < 0 < max），≥4/5 种子；
   干预前作为对照同时报（预期不跨零）；
2. **斜率**：干预后 |slope| ≥ **0.20**，≥4/5 种子（干预前 D4/D9 的实测是 0）；
3. **不退化**：干预后网格上 `Δ` 计数的极差 **不小于**干预前的 **0.5 倍**
   （投影只该去掉常数分量，不该把信号一起删掉）；
4. 三条全过 → `orthogonalisation_helps=true`；否则 `false`，负结果保留，不换 p̄ 的定义
   （不用加权、不用中位数）再试。

## 读法护栏

- 这是**构造性干预**：它只说明「去掉沿均值方向的分量之后，读出能否出现跨零的差分响应」，
  **不说明训练能学到这样的权重**——训练要另开一轮；
- 「跨零」是符号能随状态翻转的**必要条件**，不是 CartPole 分数；
- 不把 `slope` 的改善写成「学会了控制」：3–10 步的存活长度与随机策略同量级（口径复核已记）。

## 不做什么

- 不训练、不改 STDP/温度/读出；
- 不改 `p̄` 的定义（加权、滑动、按分位数）——那就是在同一批种子上挑；
- 不引入新读出（D13 已测四种）。

## 边界

- 只在极角网格上测（其余分量为 0）；
- `Δin(s)` 是期望量（用编码概率算），`Δ` 计数与 `slope` 是 20 窗口的实测；
- 投影用的是**网格上的** `p̄`，它是"探针状态集"的均值，不是训练时真实访问分布的均值——
  这一点必须写进结果。
