## 两个失败各自说明什么

### E0-3：20% 的墙把 200 张网格里的 33 张堵死

8×8 网格 64 个格子、13 面墙，随机撒。**可解率 0.835**，离 0.95 差得远。
生成时不筛可解性，就是为了能把这个数如实量出来（预注册写了）。

### E0-4：更要命的一条——难度根本没有跨度

所有可解网格的最短路只有 **14 和 16** 两个值。14 正好是 (0,0) 到 (7,7) 的曼哈顿距离——
也就是说，**绝大多数网格都存在一条单调路径**，墙几乎不制造绕行。

这条失败比 E0-3 严重：ADR-0030 的回退条件之一是「**搜索步数随任务难度自适应**」，
而这份任务里**没有难度可言**。E4 无从谈起。

## 按预注册的死亡条件办

> 若 E0-4 不过（难度没有跨度），E4 的自适应性就无从谈起，任务规格要重写，**另写预注册**。

所以：**不调墙密度重跑**（那是拿判据试参数），改为重写任务规格，另开一份预注册。

## 下一步的候选规格（写进下一份预注册之前先想清楚）

| 方案 | 为什么能出跨度 | 代价 |
| :--- | :--- | :--- |
| **迷宫生成（DFS / 递归分割）** | 走廊结构让角到角路径长度天然分布很宽 | 表示要改：墙在格子之间，不是格子本身 |
| **可变网格尺寸**（6/8/10/12 混合） | 难度按尺寸分层 | 世界模型要能吃不同尺寸，或按尺寸分别建模 |
| 连通子集生成 | 可解率 100% | 仍然稠密，路径还是接近曼哈顿——解不了 E0-4 |

**倾向：迷宫生成 + 可变尺寸**。前者解决"墙不制造绕行"，后者给出客观的难度分层。
