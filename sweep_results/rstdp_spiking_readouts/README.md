## 读法

1. **换读出没用**：四种读出在 λ=0.10 上都停在 **0.2–0.8**，没有一种到得了 2；最大的一次
   （`aligned` wn=1、λ=0.05 的 `potential_final` = 2.13）出现在**判据点之外**，且相邻 λ
   立刻掉回 0.5——那是单点波动，不是可行的读出。
2. **更重要的发现：S 不随 λ 涨**。λ 从 0.05 加到 0.30（差方向占权重预算的 30%），四种读出
   的中位 S 几乎不动（0.6 上下）。说明**分子和分母一起涨**：差方向做得越大，状态间的
   Δ 极差越大，**单窗口之间的涨落也越大**——信噪比不变。
3. 因此阶段三的瓶颈**不是读出形态，也不是差方向幅度**，而是**单次决策的噪声**：每个决策
   只跑 25 步、输入是伯努利脉冲编码，编码噪声本身就把状态差异淹到 1 个标准差上下。
4. λ=0 空对照恒为 **0.0**（S 不是由常数偏置或数值噪声造出来的）。

加长窗口、或换掉伯努利编码。这是 D14 的问题。

## 边界

- 公共模式是随机构造的，不是训练后的真实列；
- `S` 用的是 20 个窗口内 Δ 的标准差（伯努利编码噪声），不含 Critic/环境噪声；
- `potential_*` 在阈值以上的窗口里会被复位钳住（饱和），本轮 `aligned` wn=3 就接近上限；
- 点状态网格，不是完整状态空间；
- 「S ≥ 2」是稳定判决的**必要条件**，不是准确率或分数。

## 下一步（需新预注册）

**D14：降噪的代价曲线。** 在同一构造探针上，对 λ 取训练真实能达到的量级（0.05），扫：

1. **每决策平均窗口数 K ∈ {1, 2, 4, 8, 16}**（独立窗口平均，理论上 S ∝ √K）；
2. **窗口长度 T ∈ {25, 50, 100}**（同时改决策节拍）；
3. 对照：**确定性编码**（把伯努利采样换成按发放概率的期望输入，即去掉编码噪声）。

判据：找到使 S ≥ 2 的最小 (K, T) 组合，并报它带来的计算代价（步数倍数）；若确定性编码
下 S 立刻 ≥ 2，则结论是「噪声全来自伯努利编码」，修法在编码而不在读出、也不在平均。
