## 读数：机制工作，但**对照判据写错了**

- 多时间尺度**近乎完美**地同时重建 A 与 B（R² ~0.9998），快单元完全丢掉 A（−0.005）；
- 慢单元并不是"完全不能做 B"：B 更近，慢 τ=200 对 B 的 R² 有 **0.549**，同时对 A 只有
  0.439——**它不能同时做好两个**，但单看 B 一条会过 0.45 的线；
- 所以本轮失败是**预注册对照判据的 operationalization 问题**，不是机制失败：正确的问题是
  "单尺度能否同时 A≥0.5 且 B≥0.5"，而不是"单看 B 是否 <0.45"；
- 按纪律不事后改判据；v0 记为不 ready，v1 用**三线索**或**双线索同时判**的对照重测。

## 结论

**机制上，多时间尺度工作记忆 v0 是阶段四目前最干净的正面结果**：多尺度双线索 R² ~1.0，
单尺度明显不足；但按写死的对照判据 `w0_ready=false`。v1 应把对照改成"单尺度不能同时
达标"（或三线索），而不是降低 B 的阈值。
