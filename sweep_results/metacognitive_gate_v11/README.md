## 与 v8 的关系

v8 覆盖尺度 + 符号量化；v11 在同一门族上再覆盖 **时间重排、单维丢失、cue 相关性**。
两者都是“输入变换使 state 与目标不一致”的 OOD；这不是通用 OOD 的证明。

## 边界（不许改口径）

- 仍不覆盖标签漂移、状态零空间内的变换、或输入变了但任务仍可解（v5 保范旋转不是 OOD）。
- `max_errors/errors` 都来自任务读出；读出失效时门语义会变。
- 仅四个家族；没有在 DVS/音频/真实分布偏移上验证，不能外推。
- 覆盖率 0.788 在带内但偏下；单种子波动仍存在。

## 结论

通用 OOD 从 v8 的“尺度+量化”扩到 **尺度、量化、时间重排、单维丢失、相关性** 五类；
v9/v10 的负结果原样保留。下一步若继续，应预注册**真实分布偏移**（DVS/音频）或
**逐维/协方差级**门，而不是再拼更多合成特征。
