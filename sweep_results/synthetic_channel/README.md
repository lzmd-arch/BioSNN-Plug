# 合成数据证明机制：有独占信息时，模型用得上（2026-11-14）

今天所有负结果都卡在"快半没有独占信息"。**那是数据的问题，还是能力的问题？**
构造一份"独占信号确实存在"的合成数据，把两者分开。

## 构造

- 词表 V=64；上下文 c ∈ R^8；4 万个样本
- 标签 = argmax(**W·c** + 0.3·E[prev])：**c 决定大部分**，上一个 token 决定一小部分

## 结果

| 臂 | 留出 top-1 |
| :--- | ---: |
| 只看上一个 token | 0.0924 |
| **上一个 token + 上下文 c** | **0.8711** |
| 增益 | **+77.87pp** |

## 这条读数的意义

**机制成立。** 当上下文真的携带信息时，模型能把 87% 的预测建在它上面。

⇒ 今天那四次负结果（生成 0/543、编码 0.015、判别 0.763、序列 0.562）**是数据造成的，不是架构造成的**。
`scripts/context_signal.py` 已经证明：时间轴对下一个字零预测力（0.00pp），
所以"没有独占信息"不是猜测，是量过的。

## 第二步：SNN 的传感器通道**目前是死的**

给运行中的快半分别传"不传 / 全 +1 / 全 −1"的 16 维传感器向量：

而 V1 从来没有在带传感器的数据上训练过它。所以它现在只是一根接好的空管子。

## 第四步：局部规则训 `sensor_proj`——**首跑没训出来**

三因子规则：`Δproj[i,j] = η · reward · c[i] · mean_z[j]`（前=传感器第 i 维，后=神经元 j 的平均发放，
奖励=这次对不对的 ±1）。无反向传播、无全局梯度，符合"纯局部"。

600 次更新后：

| | top-1 |
| :--- | ---: |
| 带传感器 | 0.000 |
| 不带 | 0.000 |

**两头都是 0，连基线都没有。** 根因不是规则，是**奖励太稀疏**：64 类、随机读出头的成功率 ≈ 0%，
`reward` 几乎恒为 −1 ⇒ 没有一次正样本可以强化，REINFORCE 式的三因子规则无从起步。

## 修法（三条，按代价）

1. **加密奖励**：用"目标类的 logit 排名提升"或"负对数似然的变化"当奖励，而不是只看对错。
   这是三因子规则的标准做法（modulated Hebbian 用连续调制信号）；
2. **降低难度**：类数从 64 降到 8，先证明能学，再放大；
3. **换成可解释的局部误差**：给 `sensor_proj` 一个明确的目标（例如让它把 c 映射到指定的
   一小簇神经元），用 delta 规则训练——那就不再是"学任务"，是"校准通道"，判据要另写。

**在没解决奖励信号之前，不能对"SNN 能不能用上独占信号"下结论**——这一步测的是规则，不是通道。

## 第五步：加密奖励（模拟激素）——**仍然 0，但根因是我实验设计的错**

把奖励从 ±1 换成**连续调制信号**（正确类概率 − 均匀基线，即"激素"式的全局标量），
10 个 epoch、2000 次更新：

| | 留出 top-1 |
| :--- | ---: |
| 带传感器 | 0.000 |
| 不带 | 0.000 |
| proj 范数 | 0.0 → 4.63（确实在更新） |

**两头都停在 1/64 的随机水平。**

### 根因：**读出用的头是随机的、冻结的**

我为了让"只训 sensor_proj"这件事干净，冻结了一个**随机初始化**的线性头
（15624 → 64）。那么无论传感器通道传什么，模型都**没有能力表达**这个映射——
奖励再怎么连续，也被堵在这个随机头后面。

对照：合成数据那一步之所以能到 0.87，是因为**头是训练过的**。

⇒ **这次测的是我的实验设计，不是 SNN 的通道能力。作废。**

### 正确的做法（下一步）

要让"只训 sensor_proj"成立，读出必须**已经是可用的**：
- 用训练好的树读出（`tree.weight`，它是真训过的），对 64 个候选 token 打分；
- 或者让头也参与训练（但那就不是"只训通道"了，判据要另写）。

**在换成训练好的读出之前，不下任何关于 SNN 的结论。**

## 第六步：换成训练好的树读出——**仍然随机水平，说明任务设计本身不对**

用 `tree.weight[:64]` 当 64 个类别的原型（真训过的读出），10 epoch：

| | 留出 top-1 |
| :--- | ---: |
| 带传感器 | 0.0167 |
| 不带 | 0.0167 |
| （随机水平 1/64） | 0.0156 |

**还是随机。**

### 根因：这个合成任务与 SNN 学到的东西**没有关系**

标签是 `argmax(W·c)` 的任意 64 类，而树读出编码的是**语言结构**。拿一棵语言树去区分
一组随机标签，无论传感器通道传什么、奖励多密，都不该学会——这不是通道的问题，
是**任务与表征不匹配**。

⇒ **本实验到此为止，两次作废（随机头、任务不匹配），不再在这个设定上继续。**

### 正确的设计（下一次的关键）

线性合成实验能到 0.87，是因为**标签就在它所建模的空间里**。对 SNN 要做同样的事：

- **不要造新的类别空间**，直接用它本来的任务——下一个 token；
- 让**下一个 token 由 c 决定**：构造合成文本，使 `t_{i+1} = argmax(W·c + 少量噪声)`；
- 然后比"只用前缀文本"vs"前缀文本 + c"在**下一个 token top-1** 上的差。

这样它的语言表征是相关的，测的才是"通道能不能把独占信息送进去"。
**这是唯一还没被试过、且设计上成立的版本。**

## 第七步：模拟激素（DFA）——实现有维度错，判不动

正确的"模拟激素"不是标量奖励，而是**把输出误差经一条固定随机通路广播回每个神经元**
（随机反馈对齐 DFA）：`hormone = Bᵀ·err`，再乘到 Hebbian 项上。

| | 留出 top-1 |
| :--- | ---: |
| 带传感器 | 0.0167 |
| 不带 | 0.0167 |
| proj 范数 | 0 → **155**（爆炸） |

**范数爆炸、精度不动 ⇒ 调制信号无法对齐。**

### 维度错了（这是我实现的问题）

- 读出的特征空间是 **15624** 维（两个时间尺度 × 7812 神经元）；
- 我把 B 建成 **64 × 7812**，直接产出神经元级调制，**跳过了 15624 维这一层**；
- 正确形状：`B: 64 × 15624`，得到 15624 维调制后，再按"每个神经元贡献 2 个特征维"
  折回 7812。

范数爆炸正是"调制方向与真实下降方向无关"的典型症状——DFA 只有在反馈与真实雅可比
正相关时才收敛，形状错了就必然发散。

### 下一步

1. 把 B 改成 `64 × readout_width`，折叠到神经元；
2. 加范数上限（`sensor_proj` 夹到固定 L2），防止爆炸掩盖真实趋势；
3. 再看 top-1。

**在维度修好之前，这三次（稀疏奖励 / 随机头 / 维度错）都不算对 SNN 的结论。**

## 第八步：维度修正 + 范数夹取后——**仍然是随机水平**

| | 留出 top-1 |
| :--- | ---: |
| 带传感器 | 0.0167 |
| 不带 | 0.0167 |
| proj 范数 | 20.0（夹取生效，不再爆炸） |

调制维度已按"64 → 15624 → 折回 7812"修正，范数上限 20 也加上了。**精度不动。**

## 现在能说什么、不能说什么

**能说**：同样类型的合成任务，**线性模型能到 +77.9pp**（`synthetic_channel/README` 第一节），
说明"有独占信息就该能用上"这个机制本身没问题。

**能说**：快半的传感器通道，在"把任意的 16 维向量绑到 64 个任意 token"这个任务上，
用三因子 + DFA 激素、2000 次更新，**没学出来**。

**不能说**："SNN 用不上独占信号"——因为这个合成任务的标签空间与它的语言表征无关，
真实场景里 c 与 token 是有语义关联的，不是任意绑定。**这是本实验最大的外部效度缺口。**

## 真正该做的下一步

合成绑定任务证明不了真实场景。要判定，只有一条路：

1. 用**真实的配对数据**（传感器/行为 ↔ 文本），哪怕只有几百条；
2. 在那上面训 `sensor_proj`；
3. 判据仍是"带 vs 不带"的 top-1 差。

**在此之前，V1 的融合状态定性不变：α=0、机制保留、无独占信息。**

## 第九步：语义化合成配对数据——**通道开始学得动了**

关键改动：标签不再"任意绑定"，而是**语义相关**——c 的第一维就是温度，文本是
「当前温度{个位}度」。前缀固定"当前温度"，要预测的是那个数字（10 类）。

| 阶段 | 带 c | 不带 c |
| :--- | ---: | ---: |
| 训练前 | 0.10 | 0.10（随机 = 1/10） |
| 训练中最好 | **0.208** | 0.125 |
| 最终留出 | 0.12 | 0.09 |

**+3.0pp（留出）/ +8.3pp（训练中）。**

## 这说明了什么

| 数据形态 | 通道能学吗 |
| :--- | :--- |
| 任意绑定（64 个随机类别） | **不能**，四次全 0 |
| **语义相关（温度→数字）** | **开始能**，训练中 +8.3pp、留出 +3.0pp |

⇒ **"合成数据可以用"这个判断成立，但有一个硬条件：合成数据里的因果必须是真实语义的**
（c 决定哪个 token，且那个映射是语言里本来就有的），不能是任意排列。

## 为什么还不到 20pp

三个可查的原因：
1. **训练量小**：12 epoch × 150 = 1800 次更新，曲线还在涨（epoch 11 最高）；
2. **读出弱**：用 `tree.weight` 里 10 个数字 token 的行当分类器，那几行不是为这个任务训的；
3. **只训了 16×7812 一个矩阵**，其余全冻结。

⇒ 下一步：延长训练 + 让读出也参与（或改用连续奖励对 logit 排序），看能不能到 20pp。
**这是第一次有正信号，方向对了。**

## 第十步：推到推不动——**8000 次更新后没有收敛，上一轮的 +3pp 是噪声**

40 epoch × 200 = **8000 次更新**，同一份语义化数据：

| 检查点 | 带 c | 不带 c |
| :--- | ---: | ---: |
| epoch 0 | 0.140 | 0.127 |
| epoch 12（上轮的终点附近） | 0.207 | 0.107 |
| epoch 28 | 0.213 | 0.107 |
| **最终留出（800 样本）** | **0.030** | **0.105** |

**最后一行是关键：带 c 反而比不带差 7.5pp，且低于随机（0.10）。**

- 训练中一直在 0.09–0.21 之间**震荡**，没有单调上升；
- `sensor_proj` 范数从 epoch 4 起就被夹在 20（饱和），之后没有有效更新；
- 上一轮"训练中 +8.3pp / 留出 +3.0pp"**落在震荡区间内，是噪声**——按规矩撤回。

## 推到推不动的结论

**三因子 + DFA 激素，在"16×7812 一个矩阵、其余全冻结、读出头来自树的不同行"这个设定下，
学不出"把 c 读成数字"这件事。** 8000 次更新足够让曲线给出方向：没有上升趋势。

三条可能的瓶颈，按可查性排：

1. **读出不是为这个任务训的**——`tree.weight` 的数字行是为语言树学的，不是为"十类分类"；
2. **通道太窄**——16 → 7812 是一个秩 16 的加法电流，可能要更强的注入方式（例如门控而非加性）；
3. **局部规则的信用分配**——DFA 的随机反馈在这里与真实雅可比的关联不足。

**这个实验到此为止。** 它证明了三件事：
- 同样任务线性模型 +77.9pp（机制没问题）；
- 任意绑定 4 次全 0；
- 语义化数据 8000 次更新仍不收敛（本次）。

## 第十一步：量反馈与真实雅可比的对齐——**得到精确的 0.0，可疑，不作结论**

方法：对 `sensor_proj` 取 32 个随机方向，比"有限差分得到的真实方向导数"与"DFA 更新在该方向上的投影"的余弦。

| 反馈 | 余弦 |
| :--- | ---: |
| 随机 B | **0.0000** |
| B = Hᵀ（真读出） | **0.0000** |

**两个都精确等于 0.0，这本身就是警报。** 随机的方向对照应该给出 ±0.05 量级的小数，
不可能是精确的零——精确零通常意味着**其中一个向量是零向量**（或实现里某处恒为 0），
而不是"真的正交"。

已排除的可能性太费时；**按纪律：不拿一个可疑的计算结果去下"DFA 与真实梯度正交"的结论。**

下一步（若继续）：
1. 先打印 `‖d_DFA‖` 与 `‖∇L‖` 的量级——若前者是 0，问题在实现；
2. 确认 `trace.z` 的量级（若整段不发放，`z⊙hormone` 恒为 0，余弦必然 0——**这是最可能的原因**：
   前缀"当前温度"可能不产生任何脉冲）；
3. 换一段确定会发放的前缀再测。

**第 2 条是最可疑的**：`z` 全零会让整个三因子更新恒为 0，那就解释了为什么 8000 次更新
也不动——**不是 DFA 不行，是没有可用的"后"因子**。

## 第十二步：`z` 恒零的假设**被否掉**

实测同一前缀（"当前温度"，2 个 token）：

| 量 | 值 |
| :--- | ---: |
| `z` 均值 | **0.1039** |
| `z` 非零比例 | **0.1039**（约 10% 神经元发放） |
| 读出特征范数 | 22.93（1624 维非零） |
| 带 vs 不带传感器 | 最大差 **0.0**（因为 `sensor_proj` 出厂为零） |

⇒ **`z` 不是零，"后因子恒零"这条解释作废。** 三因子更新确实在发生（这也解释了 proj 范数
能从 0 涨到 20）。

## 于是现在的账是

```
信号存在，机制可用（线性 +77.9pp）        ✅
z 正常发放（10%）                        ✅
更新确实发生（范数 0→20）                 ✅
但精度不动、最终低于基线                  ❌
反馈与真实梯度余弦测得 0.0                 ⚠️ 可疑，可能是实现错
```

⇒ **卡点落回"信用分配"**：更新在发生，但方向不对。下一步必须先把余弦那个 0.0 查清
（现在知道 `z` 非零，所以 0.0 更像是我 `dfa()` 的实现问题，而不是真的正交）。

**在余弦查清之前，"局部规则学不出通道"这个结论仍不成立。**

## 第十三步：余弦不是 0，是 **0.317**——上一版的 0 是有限差分下溢

上一步 ε=1e-3 在 0.05 量级的权重上，loss 的变化被 float32 吃掉了，真实方向导数**恒为 0.0**
——所以余弦必然算出 0。**是我的测量错，不是 DFA 正交。**

ε=0.25 重测（8 个随机方向）：

| 量 | 值 |
| :--- | ---: |
| ‖∇L‖（真实） | 0.0432 |
| ‖d_DFA‖ | 0.0440 |
| **余弦** | **0.3173** |

## 这个数解释了一切

- **正相关**（0.317 > 0）⇒ 更新方向部分正确，所以训练中有过 +8pp 的短暂上升；
- **远小于 1** ⇒ 每步只用得上约三分之一的真实下降方向，噪声大、收敛慢；
- 8000 次更新不够，是因为**每步的有效信号只有 1/3**，不是规则完全失效。

## 接下来（逼近 1 的三条，按代价）

1. **B = Hᵀ（用真读出当反馈）**——本次只量了随机 B；换真读出后余弦应更高，
   一条命令能测；
2. **让 B 可学**（符号一致的反馈对齐）——用"更新是否降低了 loss"来调 B 的符号；
3. **提高有效步数**：余弦 0.32 下，把更新次数提到 3–5 万，看能否补上。

**先测第 1 条**：若 B=Hᵀ 的余弦显著更高（例如 >0.6），那"用真读出当激素通路"就是最省的做法，
且它仍然不是反向传播（只用了读出矩阵，不穿过网络的雅可比）。

## 第十四步：三条路都测了——**没有一条逼近 1**

| 反馈通路 | 余弦 | 调制范数 |
| :--- | ---: | ---: |
| 随机 B | **+0.3173** | 0.0440 |
| **B = Hᵀ（真读出）** | **+0.0237** | 0.0015 |
| sign(Hᵀ) | +0.3565 | 0.0061 |

**三条都没有逼近真实雅可比。** 而且有一个反直觉的结果：

### 用真读出当反馈反而最差（0.024 vs 0.317）

这不正常——真读出应该更好。原因在我这条通路的实现：

```
mod_f = Bᵀ·err          # (15624,) 特征空间
hormone = mod_f[:7812] + mod_f[7812:]   # ← 折回神经元：这一步是错的
```

读出的 15624 维是**两个时间尺度各自的 EMA**，它们不是"每个神经元的两份拷贝"，
把两半**直接相加**并不等于"这个神经元对输出的贡献"。所以 Hᵀ 经过这个错误的折叠之后，
信息被打乱，反而比随机还差。

⇒ **卡点不是 DFA 原理，是我把特征空间折回神经元空间的方式。**

## 结论（这一步到此为止）

- 三条路都没到高对齐；
- **最好的是 sign(Hᵀ) 0.357，只比随机高 0.04**；
- Hᵀ 反常地差，暴露了折叠公式的错误。

## 真正的下一步

**先把折叠改对**，再谈对齐：
- 正确做法是让调制**留在特征空间**（15624 维），再由读出结构决定每个神经元该收到多少；
- 或者**不要折**：把 `sensor_proj` 直接投影到 15624 维特征（而不是 7812 神经元），
  改模型的输入接口。

**在这条折叠修好之前，"局部规则学不出通道"仍然不是结论。**

## 第十五步：用最对齐的反馈 + 8000 步——**仍然学不出，而且主动变差**

| | 带 c | 不带 c |
| :--- | ---: | ---: |
| epoch 8 | 0.013 | 0.053 |
| epoch 28 | 0.040 | 0.107 |
| **最终留出** | **0.025** | **0.105** |

反馈换成余弦最高的 sign(Hᵀ)（0.357）、学习率 0.5、8000 次更新。

**带传感器比不带低 8pp，且低于随机（0.10）。** 不是"没学到"，是**主动干扰**。

## 这条线的最终结论（十五步，全部归档）

| 环节 | 状态 |
| :--- | :--- |
| 机制：有独占信号时能用上吗 | ✅ 线性 +77.9pp |
| 数据：语义化 vs 任意绑定 | ✅ 语义化才开始有信号，任意绑定 4 次全 0 |
| 通路：非零权重能改变特征吗 | ✅ 最大差 0.795 |
| 发放：z 是不是恒零 | ❌ 否，均值 0.104、10% 发放 |
| 反馈对齐：DFA 离真梯度多远 | **0.32–0.36（随机 0.317 / sign(Hᵀ) 0.357 / Hᵀ 0.024）** |
| 训练：对齐 0.36 下 8000 步 | ❌ **精度不升，反而 −8pp** |

⇒ **在"16×7812 加性电流 + 冻结网络 + 三因子局部规则"这个设定下，传感器通道学不出来，
而且会主动伤害输出。**

### 三个已知的可改点（都还没做）

1. **加性电流 → 门控注入**（c 调制输入增益，而不是加偏置）——改模型结构；
2. **`sensor_proj` 直接投影到 15624 维特征**，不折到 7812 神经元——改输入接口；
3. **反馈系数可学**（符号一致对齐），把余弦往 1 推。

**这三条都属于改结构/改训练框架，不是调参。** 在它们被验证之前，
"SNN 能不能充当人格核"没有答案——但**现在有了明确的三个待验证假设，而不是一句"不行"**。

---

## 更正：负结果**不是**"此路关死"，是"在这套设定下不成立"

我在前面的归档里多次写了"这条路关掉了""不再做""到此为止"。**那是错的写法**，
会让人（包括以后的我）把一次带条件的负结果当成永久禁令。

正确的写法只有一种：**写清 setup，写清结论，写清哪些条件没被试过。** 结论的有效范围
就是那个 setup，换一个条件它就重新变成一个开放问题。

### 按这个标准重列（全部是**条件性**结论）

| 原来的写法 | 更正后 |
| :--- | :--- |
| "融合无增益，这条路关掉" | 在 **α 线性、logit 层、8–110 字上下文、FineWeb-2 训练的快半** 下无增益。非线性融合、别的注入层、别的上下文长度**未测** |
| "SNN 当编码器不行" | 在 **均值池化 + 前 256 token** 下 hit@5 0.015。逐位置、尾部截断、别的池化**未测**（尾部截断已改默认，未重测） |
| "SNN 当判别器不行" | 在 **PCA16 + 四维残差 + 349 样本** 下 0.73。更多样本、更好读出**未测** |
| "SWA 无意义" | 在 **两个相隔 500 步、已收敛的检查点** 上无意义。多个早期检查点**没有** |
| "时间特征无增益" | 在 **时段/星期两项** 上无增益。距上次交互、节奏**未测** |
| "传感器通道学不出" | 在 **加性电流 + 冻结网络 + 三因子/DFA（余弦 0.32–0.36）** 下学不出且 −8pp。**门控注入、投到 15624 维、可学反馈三条都没试** |

### 从今天起的工作方式

1. **不写"关掉"**，只写条件与该条件下不成立；
2. **不拿"超出 V1 范围"当停止理由**——范围由目标定，不由版本号定；
3. 每个负结果旁边必须留一条"换什么条件值得重试"。
