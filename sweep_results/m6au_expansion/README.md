# M6au：**高阶展开已到顶，量子随机涨落读出无效**

## 用户两条提案

> 还有两个可以尝试：超欧展开的读出和量子随机涨落读出。

## 结果（3 种子，`per_fam=96`）

| 读出 | 高维 m=4 | 高维 m=8 | 全局 m=4 | 全局 m=8 |
| :--- | ---: | ---: | ---: | ---: |
| 线性（同 m） | 0.255 | 0.307 | 0.389 | 0.484 |
| 二次 | 0.243 | 0.286 | **0.476** | **0.510** |
| **三次** | 0.245 | 0.276 | 0.476 | 0.512 |
| **随机投影集成**（真随机源 ×32） | 0.278 | **0.326** | 0.085 | 0.085 |

（对照：64 维线性 高维 0.493 / 全局 0.085。）

| 判据 | 结果 |
| :--- | :--- |
| AU-1 三次 > 二次 +0.05 | **不过**（增益 +0.000 ～ +0.002） |
| AU-2 随机集成 > 确定性线性 +0.10 | **不过** |

## 一、超欧（高阶）展开：**二次就到顶了**

三次相对二次的增益在所有档位上都是 **+0.000 ～ +0.002**。

⇒ **低维状态的非线性结构是二阶的。** 信息在"两两关系"里，不在"三者关系"里。
这是一个干净的结构结论：**要读出这个状态，二次足够，再高阶只是加噪声。**

## 二、量子随机涨落读出：**不是资源**

- 低维状态上**灾难性**（0.085 vs 用 PCA 的 0.484）—— 随机投影找不到信息子空间；
- 高维状态上略好于同 m 线性（+0.019/0.023），但**远低于 64 维线性 0.493**；
- `m=4` 与 `m=8` 给出**逐位相同**的 0.085 —— 说明随机投影在这个 regime 里没起作用。

⇒ **不可预测性无法替代"找对子空间"。**

**这与量子线的收口一致**：真随机源在这个系统上只有一处用处 —— **个体性（不可重放）**，不是计算。

## 三、限定

- 3 种子；`per_fam=96`（768 样本）；
- 三次用的是**所有 ≤3 次单项式**（m=8 时 164 维），未做特征选择；
- 随机投影每次用 `os.urandom` 播种（真随机源），32 次投票；
- **"随机读出无效"只在这个规模/这个任务上测过**，不外推。
