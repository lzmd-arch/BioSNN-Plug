# 预注册：群体 Critic 的工作点（饱和 vs 容量）

**定稿时间：2026-10-17。测量先于本文件，网格与判据先于其结果。**

## 动机（已测，不是猜测）

`diagnose_critic.py` 显示群体 Critic 的 V 与回报**反相关**（−0.496）、动态范围只有 1.6。
进一步量单元本身（50 回合随机策略、`seed=0`）：

| 量 | 实测 |
| :--- | :--- |
| 特征 `‖x‖` | 0.95（`x>0.5` 仅占 3%） |
| 前激活 `w·x` | 均值 −0.016、**标准差 0.158** |
| `z = g(w·x − b)`（g=8, b=0.4） | 均值 **−3.33** |
| 活动 `y = σ(z)` | 均值 0.061，**76% 的单元 < 0.05** |
| 第二因子 `y(1−y)` | 均值 **0.050**（上限 0.25） |

**单元的偏置（0.4）比它收到的前激活（尺度 0.16）大了一个数量级**，于是几乎全部贴着下饱和区，
梯度只剩可能的五分之一，且 `y(1−y)` 在尾部对输入的响应也近乎线性化——群体结构失去意义。

## 两个竞争的假设

| 假设 | 预测 |
| :--- | :--- |
| **H1 工作点** | 把单元挪到拐点附近（`b≈0`、或按实测尺度调 `g`），V 应当变得与回报相关、训练分数上升 |
| **H2 容量** | 即使工作点正确，64 个单元仍不足以表达 CartPole 的值函数；需要更多单元或更好的初始化 |

本轮同时测两者：网格里 `bias` 与 `gain` 管 H1，`n_units` 管 H2。

## 网格（先写死；其余配置沿用第十轮，只做单种子筛选）

| 维度 | 取值 | 目的 |
| :--- | :--- | :--- |
| `bias` | 0.4（现状）、0.0、−0.2 | H1 |
| `gain` | 8（现状）、16 | H1（配合 `bias=0` 才让 `z` 的跨度接近 ±2） |
| `n_units` | 64（现状）、256 | H2 |
| 筛选标准 | **单种子、300 回合**，看 `corr(V,G)` 与最好评测 | 便宜 |
| 确认 | 筛出的最优配置 **5 种子 × 800 回合** | 与其余消融同口径 |

筛选用 300 回合（正式是 800/1200），**结论只认确认阶段**；筛选只是用来决定确认哪一个。

## 判据

* **H1 成立**：`bias=0` 的 `corr(V,G)` 显著高于 `bias=0.4`（筛选阶段看方向，确认阶段看数值），
  且确认阶段的分数超过现状最好值 56.8。
* **H1 不成立 / H2 成立**：工作点修好后 `corr` 仍低，或只有 `n_units=256` 才有改善。
* 无论哪个结果，**CartPole ≥ 200 仍按 5 种子计**，不拿最好种子说事。

## 边界情况

* 改工作点会改变 `V` 的尺度，`value_scale=200` 可能不再合适——**不调它**，先看工作点本身。
  若 `V` 撞上上界，如实记为该配置失败，不偷偷改尺度。
* 关掉行归一化已是当前最好（56.8），本轮**固定 `normalize=False`**，避免两个变量同时动。
* 与线性 TD 的 109.8 仍不可比：那是不同 Critic，不是同一族的两个设置。
