# 时序顺序判别：结果

预注册：[`axo_spiking_order_prereg.md`](axo_spiking_order_prereg.md)。

## 一句话

**线性积分器对顺序可交换，平均 top-1 是 0.4024；脉冲没有超过它，反而更低
（LIF 0.3293，ALIF 0.02–0.14）。当前这套 LIF/ALIF + Hebbian W 没有利用“先到”
这个信息。**

## 结果

164 条真记忆，确定性配对 `(i, i+37)`；两种顺序各一条查询。目标都是**先到的那个**。

| 臂 | A→B | B→A | 平均 |
| :--- | ---: | ---: | ---: |
| `rate-first`（只看第一步） | — | — | **0.9268** |
| `rate-last`（只看第二步） | — | — | **0.0000** |
| `rate-integ`（线性泄漏积分器） | — | — | **0.4024** |
| `spiking` LIF（膜电位） | 0.3110 | 0.3476 | 0.3293 |
| `spiking-alif` β=1 ρ=0.5 | 0.0549 | 0.0305 | 0.0427 |
| `spiking-alif` β=1 ρ=0.9 | 0.0732 | 0.0610 | 0.0671 |
| `spiking-alif` β=2 ρ=0.9 | 0.0183 | 0.0244 | 0.0213 |
| `spiking-alif` β=1 ρ=0.9 + global | 0.1159 | 0.1402 | 0.1280 |
| `spiking-alif` β=1 ρ=0.9 + global + hetero 0.5 | 0.1341 | 0.1402 | 0.1372 |

- **没有任何脉冲配置超过 0.60**；最好的 LIF 是 0.3293，远低于线性积分器的 0.4024。
- **ALIF 的适应项把性能压得更低**（0.02–0.14），而不是让“先到”占优。原因不是
  “没调好”，而是这个读出/动力学组合在两步输入后基本被阈值化压平了。
- `rate-first` 是 0.9268（不是 1.0）：有些第一步记忆本身就无法在 W 里认出自己；
  `rate-last` 恒 0（目标永远不是第二步）。
- `rate-integ` 的 0.4024 低于理论 0.5，因为有些配对的 top-1 是第三条记忆；
  但它对两种顺序给出**同一个排名**，所以结构上仍然不可能超过“集合判别”的上限。

## 判据执行

| 预注册条件 | 实测 | 结论 |
| :--- | :--- | :--- |
| 平均 top-1 > 0.60 | 最好 0.3293 | **没有** |
| 平均 top-1 > 0.80 | — | **没有** |
| 0.45–0.60（与线性同量级） | — | **低于** |
| < 0.45（反向偏置） | 0.02–0.33 | **是**（尤其 ALIF） |

## 结论

1. **结构性任务也没有救回脉冲。** 我们特意选了一个线性积分器结构上做不到的任务，
   但当前脉冲网络不是“顺序探测器”：它既没有让先到的输入占优，也没有在两步输入后
   保留足够的信息。
2. **适应项（ALIF）在这里是负资产**：β 越大越差；全局抑制略好，但仍远低于 LIF
   与线性积分器。
3. **这不是“脉冲永远不行”的证明**，而是“这套 LIF/ALIF + Hebbian W + 膜电位读出
   不足以表达顺序”。要让它成立，需要不同的机制（例如专门的时序突触/延迟线、
   STDP 顺序学习、或显式的双稳态/慢变量），不是继续调 β/θ。

## 边界

- 人为构造的顺序任务；配对相似度未控制；不是自然语言时间流。
- 164 条真记忆；没有学习；W 是既有 Hebbian 外积。
- 线性积分器的 0.4024 是这套读出下的实测上限，不是“最优线性模型”的证明；但
  它对顺序可交换这一点是结构性的。
