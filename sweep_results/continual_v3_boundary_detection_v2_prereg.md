# 预注册：评测流上的任务边界检测 v2（2026-11-04）

**状态：判据先落盘。** 修订 [`continual_v3_boundary_detection_prereg.md`](continual_v3_boundary_detection_prereg.md)。
v1 的结果与失败分析见 [`continual_v3_boundary_detection/README.md`](continual_v3_boundary_detection/README.md)。

## v1 到底错在哪（先量出来的，不是猜的）

**不是**"零分布估偏了"——我上一版这么写过，补测后推翻了。两个独立的问题：

1. **按位置定阈值，控制不住整条流的误报数。** v1 的阈值是单个位置的 99.5 分位；
   一条流扫 987 个位置，于是**在一条完全没有边界的流上也会报 4–10 次**（实测 4/6/9/4/10）。
2. **统计量的两个分布区间重叠。** 9 个真边界的统计量是 **0.158–0.190**，
   而无边界流的最大值是 **0.145–0.167**——光把标定改对，阈值抬到 0.17 以上会漏掉三个真边界。

所以 v2 要改**两处**，缺一不可。

## 设计（跑之前定死）

### 改动 1：统计量从"均值差的欧氏长度"换成"白化后的均值偏移"

v1 用 `||mean_after − mean_before||`。512 维里噪声大的方向直接主导了这个数。
v2 用同一个均值差，但在**同任务内散布矩阵**下白化：

```text
d(i) = mean_after(i) − mean_before(i)
s(i) = sqrt( d(i)ᵀ Σ⁻¹ d(i) )
Σ    = 训练集上、各任务内部散布的合并估计，shrinkage 0.1 拉向对角，+1e-6·I
```

**Σ 只用训练集估**，不用测试标签。其余（W=64、步长 10、±50 局部极大）**与 v1 完全相同**。

### 改动 2：阈值按"每条流的最大统计量"标定

```text
构造 N=50 条无边界流（训练集上，单任务、10 块 × 1,000 条独立重抽样）
τ = 这 50 条流上 max_i s(i) 的 99 分位
```

这样控制的是"**每条流报一次以上的概率 ≤1%**"，而不是"每个位置报的概率"。
v1 的 0.139–0.146 那类误报正是被这一点放出来的。

## 判据（与 v1 相同的三条 + 一条新前置）

| # | 判据 | 门槛 |
| :--- | :--- | :--- |
| **E-0** | 前置：整条流的误报控住了 | 无边界流上的平均检出数 **≤ 1.0**（v1 是 4–10） |
| **E-1** | 边界数对得上 | 检出边界数 **= 9** |
| **E-2** | 边界检得准 | 容差 ±100 下的 **F1 ≥ 0.80** |
| **E-3** | 顺序分配后的路由 | **≥ 0.80** |
| **E-4** | 对照要安静 | 整体打乱的随机流上 F1 < 0.30 |

**E-0 是这轮的核心**：它直接检验"标定改对了没有"。**E-0 不过则本轮作废**，
后三条不读——因为那说明统计量或标定还有别的问题，不是"差一点"。

## 预期

**E-0 应当过（标定改了就是为这个）。E-1/E-2 我押过，但不敢打包票。**
理由：白化会把噪声方向压下去，真边界与零分布的重叠应当缩小；但 v1 的区间本来就重叠，
如果真边界的信号主要落在高方差方向上，白化反而可能把它一起压掉。

若 E-0 过而 E-2 不过，结论就很干净：**统计量不够，均值差这条路本身不行**，
下一步该换**分布形状**（能量距离/MMD）而不是继续调这个均值差。

## 边界

- 单种子、ResNet18、CIFAR-100 10×10，与 v1 同流（同 seed 构造），可以直接对比；
- **仍利用评测流的分块结构**，不是逐样本任务推断；分配仍按到达顺序；
- **不调**：W=64、步长 10、±50 峰半径、容差 ±100 全部沿用；只改统计量与标定两处；
- 训练流与测试流的长度不同（训练单任务 5,000 条）——用**独立重抽样成 10 块 × 1,000** 来对齐，
  这一步写死，不按结果改。

## 成本

白化矩阵是一次性的 512×512；统计量用累积和算窗口均值，纯 CPU，**预计 3 分钟以内**。
