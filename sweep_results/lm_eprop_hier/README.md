# H-1 / H-1b：层次 softmax 树读出 —— **判负**（2026-11-11）

**问题**：把读出从稠密 `M·V` 换成 Huffman 树的 `M·logV`，质量掉多少？
预注册：`prereg-lm-hierarchical-softmax.md` + amend1–4。判据 **H-1：top-1 掉 ≤2pp**。

## 一、两臂都不过

同折、同语料、同预算（KdConv、16,000 步、2 抽头、V=3,001、batch 16）。

| 臂 | top-1 | top-5 | top-10 | CE | 隐层发放率 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| **稠密基线** | **0.3090** | **0.5046** | **0.5917** | **3.874** | 0.0424 |
| H-1（信号不除 batch） | 0.2708 | 0.4867 | 0.5757 | 4.091 | 0.1439 |
| **H-1b（信号除 batch）** | **0.2309** | 0.4471 | 0.5419 | 4.308 | 0.0405 |
| **Δ（H-1）** | **−3.82pp** | −1.79pp | −1.60pp | +0.217 | — |
| **Δ（H-1b）** | **−7.81pp** | −5.75pp | −4.98pp | +0.433 | — |

**H-1 判据 top-1 掉 ≤2pp ⇒ 两臂都严重不过。**

## 二、H-1b 是一次错误的"修正"，照登

H-1 跑完后我发现树的信号**没有除以 batch**（稠密的 `gradient` 在算信号之前就除了），
判断这是 bug 并修掉、重跑 H-1b。**结果更差（−3.82 → −7.81pp），诊断是错的。**

真相：`/batch` 在数学上是正确的批量平均，但 **`lr_in` 是按稠密信号的尺度标的**。
把信号压到 1/16，隐层实际学习率也压到 1/16，于是欠训。H-1b 的发放率 0.0405
与稠密 0.0424 几乎相同 —— 说明它确实"匹配了尺度"，但质量差得多。

⇒ **树的信号尺度是个能把结果推 4pp 的旋钮，两个方向都输给稠密。**

## 三、四问限定语

1. **是预算截断吗？** 否。两臂的 top-1 到最后仍在缓慢上升，但 CE 比 0.696 / 0.735，
   且与稠密的差距**单调扩大**（H-1：+0.10 → −1.63 → −2.19 → −2.98 → −3.21 → −3.82pp）。
2. **是跨语料 / 跨预算吗？** 否，同折同预算。
3. **是单边指标吗？** **是**——但方向明确：top-1、top-5、top-10、CE **四项全输**。
   值得记一笔：top-5/top-10 只掉 1.6–1.8pp（H-1），**落在 2pp 闸门内**，
   崩的主要是"第一位"。按产品口径（10 格候选条的期望选择成本）：
   稠密 5.7–6.7 下、H-1 5.9–6.9 下、H-1b 6.3–7.3 下。
4. **cos 先验兑换成 Δ 了吗？** 不适用。

## 四、结论与后果

**层次 softmax 在这个模型上质量不过关，与预注册自己写的限定一致**
（"层次 softmax 在工业界被全 softmax 取代过"——本轮量出来是"不适用"）。

后果很重：**树是 1B 在两天内训得动的唯一机制**。没有它，稠密读出每 token 约 505 µs，

| | 两天 token | token/参数 |
| :--- | ---: | ---: |
| 有树（②③④⑤） | 8.7–20.8B | 8.7–20.8 |
| **没有树（稠密）** | **0.34B** | **0.34** |

**已排除的补救方向**（写下来省得重走）：

- 采样 softmax / 候选剪枝 / 两级类树：每 token 行数 **>760 就比稠密还慢**（amend4 的分界线），
  采样 C=1,024 实测 0.74×；
- 信号尺度：两个方向都试过（本文）；
- 低秩读出：−1.3pp（早前）。

## 五、还留着的最后一条

H-1 的 top-5/top-10 在闸门内、发放率是稠密的 3.4 倍，说明"更强的信号"能部分补偿。
**最后再打一臂：在 H-1（不除 batch）的基础上把信号再放大 3 倍。** 不过就收口。

# 补充：H-1c 三种子复现 —— **判据通过**（2026-11-11 15:38）

H-1/H-1b 判负之后，按"信号越大越好"的方向把 `--tree-signal-scale` 设成 **3**（H-1c），
换两个种子复现。**三个种子全部不输稠密。**

| 臂 | top-1 | top-5 | top-10 | CE | 期望选择成本 | 发放率 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| 稠密基线 | 0.3090 | 0.5046 | 0.5917 | 3.874 | 5.71–6.65（界） | 0.0424 |
| H-1c seed 0 | 0.3093 | 0.5247 | 0.6130 | 3.870 | — | 0.1334 |
| H-1c seed 1 | 0.3181 | 0.5363 | 0.6239 | 3.784 | 5.7845 | 0.1321 |
| H-1c seed 2 | 0.3345 | 0.5492 | 0.6378 | 3.653 | 5.6484 | 0.1329 |
| **三种子中位** | **0.3181** | **0.5363** | **0.6239** | **3.784** | — | — |
| **Δ vs 稠密** | **+0.91pp** | **+3.17pp** | **+3.22pp** | **−0.090** | 落在稠密界的低端 | — |

**判据 G1**：三种子中位 top-1 ≥ 稠密 − 2pp（0.2890）⇒ **0.3181 通过**；
且**没有种子掉出闸门**（最低 0.3093 > 0.2890）。**三个种子逐一对稠密是 +0.03 / +0.91 / +2.55pp。**

## 四问限定语

1. **是预算截断吗？** 是——三臂的 CE 比 0.646–0.655，都没过 0.6 闸门，数字是**下界**（对模型有利）。
2. **是跨语料 / 跨预算吗？** 否，同折同预算。
3. **是单边指标吗？** **不是**：top-1 / top-5 / top-10 / CE / 期望选择成本**五项全不输**。
4. **cos 先验兑换成 Δ 了吗？** 不适用。

## 必须写下的三条限定

1. **`signal_scale=3` 是在 seed 0 的那个折上选出来的**，不排除"在这个折上过拟合"。
   两个新种子同向，把这种可能性压低，但没有消除；
2. **曲线噪声大**：seed 2 在 14,000 步掉到 0.2860，16,000 步又回到 0.3345（摆 4.9pp）。
   发放率 0.133 是稠密的 3.1 倍，工作点本身不稳；
3. **单折**。六折 LOO 没做。

## 结论

**层次 softmax 树读出在质量上成立**（信号 ×3 的口径下），而在 V=32,000 上它把读出成本
从 `M·V` 降到 `M·12.18`。这是 1B 在两天内训得动的唯一机制，现在它有质量背书了。
