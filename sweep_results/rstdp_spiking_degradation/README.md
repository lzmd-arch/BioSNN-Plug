**预注册：** [`../rstdp_spiking_degradation_prereg.md`](../rstdp_spiking_degradation_prereg.md)。
**诊断，不是验收。** 臂取 D6-B（`logit_scale` 0.1→0.02；D6 三臂末次中位并列，按 best 选 B）。
5 种子、800 回合；每 10 回合评测与探针，每回合记熵与平均 `|δ|`。

| :--- | ---: |

| `degradation_attributed` | **false** |
| 归因原因 | 无（三个候选都不成立） |

逐种子（峰值步数@回合 → 末次步数）：
0：27.9 → 14.9；1：39.6 → 9.2；2：30.2 → 9.2；3：61.0 → 9.7；4：44.7 → 10.3。

三个候选的实测（判定阈值见预注册）：

- **熵再坍缩**：退化前的熵在 **0.69 nats** 附近（阈值 <0.05）→ 不成立；
- **列范数漂移**：退化时两列的 L1 范数仍是 **1.0**（归一化生效，阈值 >2× 或 <0.5×）→ 不成立；
- **Critic 漂移**：退化时的平均 `|δ|` 与峰值时同量级（阈值 >2×）→ 不成立。

## 读法

- **退化是真的**：5 个种子的峰值 27.9–61.0，末次都掉回 9.2–14.9；
- **但不是这三件事**：温度保持住了熵、归一化保持住了列范数、Critic 的 |δ| 没有翻倍；
- 结合 D4/D6 的探针：末期**贪心策略的极角 slope 回到 0**（动作不随状态变），而采样熵仍然很高——
  也就是说「分布是散的，但 argmax 不随状态移动」。这是下一个候选机制：
  **状态信息没有进入动作偏好的符号**，而不是探索温度或权重尺度的问题；
- `unattributed` 是预注册允许的合法结果，不能写成「归因完成」，更不能写成「已修复」。

## 下一步（需新预注册）

候选机制按优先顺序：
1. **贪心读出的状态信息消失**：检查两个动作列的计数差 `counts[0]−counts[1]` 在极角上的
   符号是否稳定；若不稳定，问题在读出层而不是策略采样；
2. **权重归一化的方向锁死**：归一化保持列和，但可能让两列的比例趋同（D4 的完全常数）；
3. **训练信号与评测口径不一致**：训练用采样动作、评测用 argmax——若两者分裂，需在训练里
   显式优化 argmax 行为（如 straight-through 或温度退火到 0）。

## 边界

- 归因只比较三个量与退化时刻的同步性，不证明因果；
- 探针每 10 回合一次；评测 10 回合/点；臂固定为 D6-B；
