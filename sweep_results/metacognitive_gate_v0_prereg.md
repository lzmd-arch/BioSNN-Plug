# 预注册：元认知门控 v0——选择性预测与不确定性（2026-10-26）

**定稿时间：2026-10-26，在本轮任何数据之前。** 按顺序，世界模型 P3 与情景记忆 v0 之后
进入元认知门控 v0。计划书 §2.2 的定位：监控预测误差与不确定性，动态调节学习率/探索率；
§3.4 把它作为"SNN 自主处理 vs 调用 LLM"的决策信号之一。v0 先做**可测的最小件**：
**选择性预测**——模型知道自己什么时候不确定，并在不确定时弃权。

## 机制（不训练新网络、不用反向传播）

```text
读出：冻结 ResNet18 avgpool 512 → DeltaReadout(512→100)，在 CIFAR-100 全部类上联合训练
置信度：softmax(logits / T) 的最大值；T 只在校准集上选（温度缩放，一个标量）
门控：校准集上选阈值 τ，使弃权后覆盖率 = 80%；测试集上低于 τ 的样本弃权
```

- 读出是既有的 delta 规则；温度缩放只拟合一个标量（最小化校准集 NLL），不是反向传播；
- v0 **不做** LLM 调用触发、不做 OOD、不做在线学习率/探索率调节；这些是 v1；
- 空口说"不确定"不算：必须有**风险-覆盖率曲线**与**错误检测 AUROC**。

## 数据与协议

| 项 | 取值 |
| :--- | :--- |
| 数据 | CIFAR-100；冻结 ResNet18 特征（已缓存） |
| 读出 | `DeltaReadout(512→100)`，全 100 类联合训练，η=0.01，20 epoch，B=128 |
| 切分 | 测试集随机对半：校准 5000 / 评估 5000；5 个切分种子 |
| 温度 | 校准集上网格搜索 T ∈ [0.5, 5.0]（log 均匀 40 点），最小化 NLL |
| 覆盖率 | 校准集上选 τ 使覆盖 80%；评估集上报告实际覆盖与选择性准确率 |
| 基线 | 随机置信度；未温度缩放的 ECE |

## 判据（先写死）

1. **选择性准确率**：评估集 80% 覆盖时，比全量准确率 **≥ +5 pp**；
2. **错误检测**：置信度对"预测是否正确"的 AUROC **≥0.75**；
3. **校准**：温度缩放后的 ECE（10 箱）**≤0.10**；
4. 报告风险-覆盖率曲线、AURC、实际覆盖率；四条全过 → `v0_ready`。

## 不做什么

- 不做 OOD（CIFAR-10/损坏图）、不做 LLM 触发、不做在线学习率/探索率调节；
- 不换读出/不调 η/epoch/T 的搜索范围以外的超参；
- 不把随机置信度的结果写成门控成绩；
- 不因为选择性准确率好看就只报覆盖率高的点；80% 是写死的。
