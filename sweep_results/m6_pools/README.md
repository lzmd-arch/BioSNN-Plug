# M6p：多池竞争 —— **预注册全过，但个体那一层是空的**

预注册 `research/sel/prereg-m6-pools-v1.md`（含修订 1）。
48 档（K ∈ {1,2,4,8} × g_inh ∈ {0,1,2,4,8} × eta ∈ {-1,0.2,2.0}），6 种子，每档 3 条历史 × 32 样本。

## 一、预注册判据

| 编号 | 判据 | 结果 |
| :--- | :--- | :--- |
| **P-0 仪器** | K=1/β=0/g=0/eta=-1 复现 M6 的 0.1420±0.010 | **0.1421，过**；残余 PR 1.85 对 M6 的 1.83 |
| **P-1 存在** | K>1 有档落在发放 [0.01, 0.20] | **29 档，过** |
| **P-2 竞争** | 支配 ≥2× | **过**（最高 578×） |
| **P-3 胜者由历史定** | 胜者不恒定，≥4/6 种子的档 | **29/29 档"过"** —— 见 §三，**这条判据不成立** |
| **P-4 图案带历史** ★ | 去均值池向量上 历史/对照 > 1.5 且 ≥5/6 | **`K=4/g=2/eta=-1` 3.14× 6/6，过** |

## 二、决定性的事后检验：`d_hist` 是常数，比值全在 `d_null` 上

| `d_hist`（α=0.5 vs α=20） | `d_null`（α=0.5 两条随机流） | 比 |
| ---: | ---: | ---: |
| 0.99 | **0.32** | 3.14× |
| 0.89 | 0.40 | 2.19× |
| 0.97 | 0.53 | 1.82× |
| 1.15 | 0.72 | 1.60× |

`d_hist ≈ 1.0` 在**所有臂上几乎不动**。1.0 在相对距离里就是"两个向量相关系数 ≈ 0.5"。
**整个"3.14×" 是分母掉下去换来的，不是分子涨上去。**

## 三、P-3 是**不成立的判据**

胜者在 6 个种子里确实不恒定 —— 但那是因为**胜者本身就是噪声**：
逐样本的胜者与总体胜者的一致率在关键臂上只有 **0.20–0.48**（随机是 0.125–0.25）。

**"胜者随历史变"与"胜者随噪声变"在这条判据下不可区分。** 这是预注册的设计缺陷，
照实记下，不作通过。

## 四、把总体和个体分开（`scripts/m6p_reliability.py`，**事后、非预注册**）

| 臂 | 总体均值比 | **逐个体比** | 个体的涨落 / 总体均值 |
| :--- | ---: | ---: | ---: |
| `K=4/g=2/eta=-1` | **3.14×** | **1.02×** | 1.30 |
| `K=4/g=2/eta=2` | 2.19× | 1.08× | 1.19 |
| `K=8/g=0/eta=-1` | 1.82× | **1.26×** | 1.25 |
| `K=4/g=0/eta=-1` | 1.60× | 1.25× | 1.21 |
| `K=8/g=1/eta=-1` | 1.59× | 0.98× | 1.27 |

**逐个体比 ≈ 1.0 ⇒ 知道一个个体的历史来自哪条分布，几乎不能预测它的池图案。**
（1.0 就是"从 A 里取一个 vs 从 B 里取一个，和从 A 里取两个一样远"。）

**而且方向是反的**：总体效应最大的两档（3.14×、2.19×，都在 `g_inh=2`），
个体效应最小（1.02×、1.08×）。

### 为什么反

交叉抑制项 `g_inh·(φ_k − φ)` 在神经元上**零和**，它不改总驱动，只把活动在池之间**重新分配**。
`g_inh` 大 ⇒ 总体均值被拉得更稳（`d_null` 掉到 0.32）⇒ 总体比大；
同时它也把个体之间的差异**抹平**（所有个体被拉向同一个均值）⇒ 个体比小。

⇒ **交叉抑制是拿个体差异换总体可复现性。** 这与我原来的假设正好相反。

## 五、判决

**M6p 不成立。**

- 预注册的 P-4 字面通过（3.14×，6/6），**但它测的是总体均值，而目标要的是个体**；
- 把口径换成个体，最好的臂是 1.26×，最坏的 0.98× —— **和"没有"分不开**；
- 单个体在池向量上偏离总体均值的距离是**总体均值自身模的 1.2–1.3 倍**
  ⇒ 所谓"状态"比它的涨落还小。

**⇒ "个体在图案这一层带自己的历史" —— 在多池竞争这个架构里仍然不成立。**

## 六、这一轮真正的收获（三条，都不是原假设）

1. **K=1/2/4/8 在 `g_inh=0` 时发放率逐位相同（0.1421）** ——
   那四档跑的是**同一个网络、同一段动力学**，变的只有测量分区。
   所以 `1.19 → 1.60 → 1.82` 是**纯分辨率效应**：历史信号在低阶空间模态上，
   在单神经元分辨率下被噪声淹掉。**M6"没有图案"这个结案需要这一句限定。**
2. **P-3 这类"胜者变不变"的判据在此不可用**，因为胜者本身不稳。
   今后要用"同一统计下胜者是否可复现"取代"不同历史下胜者是否不同"。
3. **总体均值与个体是两个量，必须分别报。** 这一轮的 3.14× 与 1.02× 是同一批数据的两个面。

## 七、限定

- 6 种子；β 已按修订 1 砍掉（同池入边 β=0 已是 0.90）；
- **A vs B 同时改了 `pref` 矩阵和 α**（`seeded_dirichlet` 用固定的 `PREF_SEED=0`，
  所以同 α 的两条历史共享同一个 `pref`）。**"不同内容"与"不同稀疏度"没有拆开**；
- `d_null` 用的是"同 α、不同随机流"，这是对的，但它同时共享 `pref` ⇒ 是**偏窄的对照**；
- 线性谱仍是盲区；分批信度大于对照这一点没有完全解释（怀疑是全局场造成的样本间负相关），
  但它不影响 §四 的结论 —— 那一列用的是**同口径**的逐个体比较。
