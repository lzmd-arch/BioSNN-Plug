# 预注册：跨模态检索第五轮——非线性上界探针（k 近邻）

**定稿时间：2026-10-17，在这一轮的任何数据之前。**

## 它要回答什么

第四轮把线性上界钉在 0.47–0.48（加维度、绕过总线都无效）。现在有两种解释，方向完全不同：

| 解释 | 症状 | 下一步 |
| :--- | :--- | :--- |
| (L) **线性**读出的限制 | 表示里有信息，但它是非线性地摆着的 | 换一个**非线性**的局部规则 |
| (E) **编码**的限制 | 两条编码之间本来就没有那么多共同信息 | 改编码（分辨率、帧数、token 级表示） |

用 **k 近邻**做第二道上界：它是**非参数、非线性的**，没有任何训练过程，也不需要梯度。
若它显著高于线性上界（0.48），说明信息在、只是非线性；(L) 成立。
若它同样停在 0.48 附近，(E) 成立。

## ⚠️ kNN 既不是"局部学习规则"，也不是验收候选

它没有突触、没有更新规则，只有"记住训练对、查询时投票"。所以：

* 它**只作诊断**，不进达标栏位；
* 但它是**可以对照**的：它和 delta 看的是同一份表示，差别只在读出方式。

## 设计

| 维度 | 取值 |
| :--- | :--- |
| 表示 | `bus@256`（第四轮按训练集 CV 选出的最优局部配置）与 `plugin`（无总线投影） |
| k 网格 | {1, 3, 5, 10, 20}，**训练集 5 折交叉验证**选 |
| 距离 | 余弦相似度；预测为 k 个近邻目标的相似度加权平均（负相似度截断为 0） |
| 种子 | 0–4，切分与前几轮相同 |

## 判据

* kNN 上界 ≥ 0.60 → (L) 成立：下一轮做**非线性的局部规则**（例如在联想前加一层固定随机特征的
  Hebb/delta，即"随机特征 + 线性读出"的经典做法），并**先预注册再跑**。
* kNN 上界落在 0.45–0.55 → (E) 成立：改编码。第一步是图像侧（事件编码只有三帧、分辨率 24），
  而不是继续在读出上打磨。
* 无论哪个结果，**都不改测试集上的选择**：k 由训练集交叉验证定。
