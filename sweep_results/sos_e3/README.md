## 真正的原因：状态里没有墙

状态是「相对终点的位移」。**迷宫的墙不在状态里**——同一个 `(dx, dy)` 对应许多格子，
最优动作各不相同。所以无论给什么监督信号，这个策略类都表达不了迷宫策略。

这不是"学得慢"，是**表示不够**：按预注册，agent 只观测自己的位置，而迷宫要求知道墙。
按这个定义，任务是**部分可观测的（POMDP）**，无记忆的策略在原理上就解不了。

E2 的两轮失败（reward 换了两遍都不动）与这一次，是**同一个根因**的三种表现。

## E3-2 为什么是"平凡成立"

判据写成 `search − opt ≥ 0.5 × 训练池上的差`。两臂都在 0.09–0.14 的噪声里，
差也是负的，于是 `−0.01 ≥ −0.01` 成立。**这是判据的缺陷**（门槛可以为负时失去意义），
和 E2 v1 的 `C ≥ 0.5×B` 是同一类错误：**比值/相对判据没有下限保护**。

## 下一步（写进下一份预注册之前先想清楚）

**必须让状态里包含墙**，否则这条线不会有任何策略能工作。最小改动：

- 状态 = `(相对终点位移, 四邻是否可走)`——本地 4 位墙信息；
- 这仍然不是全图，但它足够学到**沿墙走**；而完美迷宫是单连通的，沿墙走必然到终点；
- 代价：状态数从 169 涨到 169×16 ≈ 2700，仍然是表格能承受的。

这条改动会把当前四轮的所有失败（E2 v1/v2、E3）**统一解释**成"状态不够"，
而不是三次独立的失败——这一点本身值得单独记一笔。
