# 预注册：多时间尺度工作记忆 v3——NLMS / RLS 局部读出（2026-10-27）

**定稿时间：2026-10-27，在本轮任何数据之前。** v2 的局部 delta（η=0.01、20 epoch）在
28 维状态上严重欠拟合（R² 0.03 vs ridge 0.993）。v3 换**局部且尺度无关**的读出，不调 η：

## 两个臂（同一状态/任务/数据/对照）

| 臂 | 更新 | 说明 |
| :--- | :--- | :--- |
| **NLMS** | `W ← W + 0.5·error·xᵀ/(‖x‖²+eps)`，逐样本 | 归一化最小均方；步长 0.5 写死 |

- 状态、三线索、τ 列表、噪声、训练/测试规模、单尺度对照与 v1/v2 完全一致；
- 每个臂训练 20 epoch（逐样本），不调步长/λ/δ/epoch。

## 判据（先写死，两臂分别判）

1. 多尺度 A/B/C 的 R² **都 ≥0.50**；
2. 快 τ=2 的 A **<0.30**；
3. fast/mid/slow 三个单尺度各自至少漏一个线索（R² <0.50）；
4. **不因局部化明显退化**：该臂三线索平均 R² ≥ v1 ridge 平均 **−0.10**；
5. **任一臂**四条全过 → `v3_ready`；两臂都不过 → 报边界。

- 不把 ridge 的成绩混进局部臂；两臂都报。
